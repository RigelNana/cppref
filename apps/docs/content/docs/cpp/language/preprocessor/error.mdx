{/* source:cpp-preprocessor-error:0000 */}
Shows the given error message and renders the program ill-formed<InlineRevision since="C++23">, or shows the given warning message without affecting the validity of the program</InlineRevision>.

## Syntax

{/* source:cpp-preprocessor-error:0001 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code={`#error diagnostic-message`} />
  <Declaration id="2" language="cpp" since="C++23" grammar code={`#warning diagnostic-message`} />
</DeclarationDoc>

{/* source:cpp-preprocessor-error:0002 */}
1. After encountering the `#error` directive, an implementation displays the message `diagnostic-message` and renders the program ill-formed (the compilation stops).

{/* source:cpp-preprocessor-error:0003 */}
2. Same as (1), except the validity of the program is not affected and the compilation continues.

{/* source:cpp-preprocessor-error:0004 */}
`diagnostic-message` can consist of several words not necessarily in quotes.

## Notes

{/* source:cpp-preprocessor-error:0005 */}
Before its standardization in C++23, `#warning` has been provided by many compilers in all modes as a conforming extension.

## Example

{/* source:cpp-preprocessor-error:0006 */}
```cpp
#if __STDC_HOSTED__ != 1
#   error "Not a hosted implementation"
#endif

#if __cplusplus >= 202302L
#   warning "Using #warning as a standard feature"
#endif

#include <iostream>

int main()
{
    std::cout << "The implementation used is hosted\n";
}
```

Possible output:

```text
The implementation used is hosted
```
