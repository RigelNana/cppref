## Explanation

{/* source:cpp-language-bool-literal:0001 */}
The Boolean literals are the keywords `true` and `false`. They are [prvalues](/docs/cpp/language/expressions/value_category#prvalue) of type [`bool`](/docs/cpp/language/basic_concepts/types#Boolean_type).

## Notes

{/* source:cpp-language-bool-literal:0002 */}
See [Integral conversions](/docs/cpp/language/expressions/implicit_cast#Integral_conversions) for implicit conversions from `bool` to other types and [boolean conversions](/docs/cpp/language/expressions/implicit_cast#Boolean_conversions) for the implicit conversions from other types to `bool`.

## Keywords

{/* source:cpp-language-bool-literal:0003 */}
[`false`](/docs/cpp/language/keywords/false), [`true`](/docs/cpp/language/keywords/true)

## Example

{/* source:cpp-language-bool-literal:0004 */}
```cpp
#include <iostream>

int main()
{
    std::cout << std::boolalpha
              << true << '\n'
              << false << '\n'
              << std::noboolalpha
              << true << '\n'
              << false << '\n';
}
```

Output:

```text
true
false
1
0
```
