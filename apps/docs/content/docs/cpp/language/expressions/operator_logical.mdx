{/* source:cpp-language-operator-logical:0000 */}
Returns the result of a boolean operation.

{/* source:cpp-language-operator-logical:0001 */}
Prototype examples (for `class T`):

| Operator name | Syntax | Over​load​able | Inside class definition | Outside class definition |
| --- | --- | --- | --- | --- |
| negation | `not a` `!a` | Yes | `bool T::operator!() const;` | `bool operator!(const T &a);` |
| AND | `a and b` `a && b` | Yes | `bool T::operator&&(const T2 &b) const;` | `bool operator&&(const T &a, const T2 &b);` |
| inclusive OR | `a or b` `a || b` | Yes | `bool T::operator||(const T2 &b) const;` | `bool operator||(const T &a, const T2 &b);` |

**Notes**

- The keyword-like forms (`and`,`or`,`not`) and the symbol-like forms (`&&`,`||`,`!`) can be used interchangeably (see [alternative representations](/docs/cpp/language/expressions/operator_alternative)).
- All built-in operators return `bool`, and most [user-defined overloads](/docs/cpp/language/expressions/operators) also return `bool` so that the user-defined operators can be used in the same manner as the built-ins. However, in a user-defined operator overload, any type can be used as return type (including `void`).
- Builtin operators `&&` and `||` perform short-circuit evaluation (do not evaluate the second operand if the result is known after evaluating the first), but overloaded operators behave like regular function calls and always evaluate both operands.

## Explanation

{/* source:cpp-language-operator-logical:0002 */}
The logic operator expressions have the form

{/* source:cpp-language-operator-logical:0003 */}

  <Declaration id="1" language="cpp" grammar code="! rhs" />
  <Declaration id="2" language="cpp" grammar code="lhs && rhs" />
  <Declaration id="3" language="cpp" grammar code="lhs || rhs" />
</DeclarationDoc>

{/* source:cpp-language-operator-logical:0004 */}
1. Logical NOT

{/* source:cpp-language-operator-logical:0005 */}
2. Logical AND

{/* source:cpp-language-operator-logical:0006 */}
3. Logical inclusive OR

{/* source:cpp-language-operator-logical:0007 */}
If the operand is not `bool`, it is converted to `bool` using [contextual conversion to bool](/docs/cpp/language/expressions/implicit_cast): it is only well-formed if the declaration `bool t(arg)` is well-formed, for some invented temporary `t`.

{/* source:cpp-language-operator-logical:0008 */}
The result is a `bool` prvalue.

{/* source:cpp-language-operator-logical:0009 */}
For the built-in logical NOT operator, the result is `true` if the operand is `false`. Otherwise, the result is `false`.

{/* source:cpp-language-operator-logical:0010 */}
For the built-in logical AND operator, the result is `true` if both operands are `true`. Otherwise, the result is `false`. This operator is [short-circuiting](https://en.wikipedia.org/wiki/Short-circuit_evaluation): if the first operand is `false`, the second operand is not evaluated.

{/* source:cpp-language-operator-logical:0011 */}
For the built-in logical OR operator, the result is `true` if either the first or the second operand (or both) is `true`. This operator is short-circuiting: if the first operand is `true`, the second operand is not evaluated.

{/* source:cpp-language-operator-logical:0012 */}
Note that [bitwise logic operators](/docs/cpp/language/expressions/operator_arithmetic) do not perform short-circuiting.

| --- | --- | --- |
| `!a` | `false` | `true` |

## Example

{/* source:cpp-language-operator-logical:0018 */}
```cpp
#include <iostream>
#include <sstream>
#include <string>

int main()
{
    int n = 2;
    int* p = &n;
    // pointers are convertible to bool
    if (    p && *p == 2  // "*p" is safe to use after "p &&"
        || !p &&  n != 2) // || has lower precedence than &&
        std::cout << "true\n";

    // streams are also convertible to bool
    std::stringstream cin;
    cin << "3...\n" << "2...\n" << "1...\n" << "quit";
    std::cout << "Enter 'quit' to quit.\n";
    for (std::string line;    std::cout << "> "
                           && std::getline(cin, line)
                           && line != "quit";)
        std::cout << line << '\n';
}
```

Output:

```text
true
Enter 'quit' to quit.
> 3...
> 2...
> 1...
>
```

**Common operators**

- [assignment](/docs/cpp/language/expressions/operator_assignment): `a = b`, `a += b`, `a -= b`, `a *= b`, `a /= b`, `a %= b`, `a &= b`, `a |= b`, `a ^= b`, `a <<= b`, `a >>= b`
- [increment decrement](/docs/cpp/language/expressions/operator_incdec): `++a`, `--a`, `a++`, `a--`
- [arithmetic](/docs/cpp/language/expressions/operator_arithmetic): `+a`, `-a`, `a + b`, `a - b`, `a * b`, `a / b`, `a % b`, `~a`, `a & b`, `a | b`, `a ^ b`, `a << b`, `a >> b`
- **logical**: `!a`, `a && b`, `a || b`
- [comparison](/docs/cpp/language/expressions/operator_comparison): `a == b`, `a != b`, `a < b`, `a > b`, `a <= b`, `a >= b`, `a <=> b`
- [member access](/docs/cpp/language/expressions/operator_member_access): `a[...]`, `*a`, `&a`, `a->b`, `a.b`, `a->*b`, `a.*b`
- [other](/docs/cpp/language/expressions/operator_other): function call `a(...)`, comma `a, b`, conditional `a ? b : c`

**Special operators**

- [`static_cast`](/docs/cpp/language/expressions/static_cast) converts one type to another related type
- [`dynamic_cast`](/docs/cpp/language/expressions/dynamic_cast) converts within inheritance hierarchies
- [`const_cast`](/docs/cpp/language/expressions/const_cast) adds or removes [`cv`](/docs/cpp/language/declarations/cv)-qualifiers
- [`reinterpret_cast`](/docs/cpp/language/expressions/reinterpret_cast) converts type to unrelated type
- [C-style cast](/docs/cpp/language/expressions/explicit_cast) converts one type to another by a mix of `static_cast`, `const_cast`, and `reinterpret_cast`
- [`new`](/docs/cpp/language/expressions/new) creates objects with dynamic storage duration
- [`delete`](/docs/cpp/language/expressions/delete) destructs objects previously created by the new expression and releases obtained memory area
- [`sizeof`](/docs/cpp/language/expressions/sizeof) queries the size of a type
- [`sizeof...`](/docs/cpp/language/templates/sizeof...) queries the size of a [`pack`](/docs/cpp/language/templates/parameter_pack) <InlineRevision since="C++11" />
- [`typeid`](/docs/cpp/language/expressions/typeid) queries the type information of a type
- [`noexcept`](/docs/cpp/language/exceptions/noexcept) checks if an expression can throw an exception <InlineRevision since="C++11" />
- [`alignof`](/docs/cpp/language/expressions/alignof) queries alignment requirements of a type <InlineRevision since="C++11" />
