{/* source:cpp-language-typeid:0000 */}
Queries information of a type.

{/* source:cpp-language-typeid:0001 */}
Used where the [dynamic type](/docs/cpp/language/basic_concepts/type-id#Dynamic_type) of a [polymorphic object](/docs/cpp/language/basic_concepts/objects#Polymorphic_objects) must be known and for static type identification.

## Syntax

{/* source:cpp-language-typeid:0002 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="typeid ( type )" />
  <Declaration id="2" language="cpp" grammar code="typeid ( expression )" />
</DeclarationDoc>

{/* source:cpp-language-typeid:0003 */}
The `typeid` expression is an [lvalue expression](/docs/cpp/language/expressions/value_category) which refers to an object with [static storage duration](/docs/cpp/language/classes/static), of const-qualified version of the polymorphic type [std::type_info](/docs/cpp/library/utility/types/type_info) or some type derived from it.

{/* source:cpp-language-typeid:0004 */}
If the standard library definition of [std::type_info](/docs/cpp/library/utility/types/type_info) is not visible when using `typeid`, the program is ill-formed.

## Explanation

{/* source:cpp-language-typeid:0005 */}
If *type* or the type of *expression* is a class type or a reference to a class type, then that class type cannot be an [incomplete type](/docs/cpp/language/basic_concepts/incomplete_type).

{/* source:cpp-language-typeid:0006 */}
1. Refers to a [std::type_info](/docs/cpp/library/utility/types/type_info) object representing *type*. If *type* is a reference type, the result refers to a [std::type_info](/docs/cpp/library/utility/types/type_info) object representing the cv-unqualified version of the referenced type.

{/* source:cpp-language-typeid:0007 */}
2. Examines *expression*:

   - If *expression* is <InlineRevision until="C++11">an [lvalue](/docs/cpp/language/expressions/value_category#lvalue)</InlineRevision><InlineRevision since="C++11">a [glvalue](/docs/cpp/language/expressions/value_category#glvalue)</InlineRevision> expression that identifies an [object of a polymorphic type](/docs/cpp/language/basic_concepts/objects#Polymorphic_objects) (that is, a class that declares or inherits at least one [virtual function](/docs/cpp/language/classes/virtual)), the `typeid` expression evaluates the expression and then refers to the [std::type_info](/docs/cpp/library/utility/types/type_info) object that represents the dynamic type of the expression.
     - If *expression* is an [indirection expression](/docs/cpp/language/expressions/operator_member_access#Built-in_indirection_operator) and its operand evaluates to a [null pointer value](/docs/cpp/language/declarations/pointer#Null_pointers), an exception of a type matching handlers of type [std::bad_typeid](/docs/cpp/library/utility/types/bad_typeid) is thrown[^1].
   - Otherwise, `typeid` does [not evaluate the expression](/docs/cpp/language/expressions#Potentially-evaluated_expressions), and the [std::type_info](/docs/cpp/library/utility/types/type_info) object it identifies represents the static type of the expression. Lvalue-to-rvalue, array-to-pointer, or function-to-pointer conversions are not performed.

<Revision since="C++17">
[Temporary materialization](/docs/cpp/language/expressions/implicit_cast#Temporary_materialization), however, is (formally) performed for prvalue arguments: the argument must be destructible in the context in which the `typeid` expression appears.
</Revision>

{/* source:cpp-language-typeid:0008 */}
If *type* or the type of *expression* is cv-qualified, the result of the `typeid` refers to a [std::type_info](/docs/cpp/library/utility/types/type_info) object representing the cv-unqualified type (that is, `typeid(const T) == typeid(T)`).

{/* source:cpp-language-typeid:0009 */}
If `typeid` is used on an object under construction or destruction (in a destructor or in a constructor, including constructor's [initializer list](/docs/cpp/language/classes/initializer_list) or [default member initializers](/docs/cpp/language/classes/data_members#Member_initialization)), then the [std::type_info](/docs/cpp/library/utility/types/type_info) object referred to by this `typeid` represents the class that is being constructed or destroyed even if it is not the most-derived class.

{/* source:cpp-language-typeid:0010 */}
[^1]: In other contexts, evaluating such an *expression* results in undefined behavior.

## Notes

{/* source:cpp-language-typeid:0011 */}
When applied to an expression of polymorphic type, evaluation of a typeid expression may involve runtime overhead (a virtual table lookup), otherwise typeid expression is resolved at compile time.

{/* source:cpp-language-typeid:0012 */}
It is unspecified whether the destructor for the object referred to by `typeid` is executed at the end of the program.

{/* source:cpp-language-typeid:0013 */}
There is no guarantee that the same [std::type_info](/docs/cpp/library/utility/types/type_info) object will be referred to by all evaluations of the typeid expression on the same type, although they would compare equal, [std::type_info::hash_code](/docs/cpp/library/utility/types/type_info/hash_code) of those `type_info` objects would be identical, as would be their [std::type_index](/docs/cpp/library/utility/types/type_index).

{/* source:cpp-language-typeid:0014 */}
```cpp
const std::type_info& ti1 = typeid(A);
const std::type_info& ti2 = typeid(A);

assert(&ti1 == &ti2); // not guaranteed
assert(ti1 == ti2); // guaranteed
assert(ti1.hash_code() == ti2.hash_code()); // guaranteed
assert(std::type_index(ti1) == std::type_index(ti2)); // guaranteed
```

## Example

{/* source:cpp-language-typeid:0016 */}
The example showing output using one of the implementations where `type_info::name` returns full type names; filter through c++filt -t if using gcc or similar.

```cpp
#include <iostream>
#include <string>
#include <typeinfo>

struct Base {}; // non-polymorphic
struct Derived : Base {};

struct Base2 { virtual void foo() {} }; // polymorphic
struct Derived2 : Base2 {};

int main()
{
    int myint = 50;
    std::string mystr = "string";
    double *mydoubleptr = nullptr;

    std::cout << "myint has type: " << typeid(myint).name() << '\n'
              << "mystr has type: " << typeid(mystr).name() << '\n'
              << "mydoubleptr has type: " << typeid(mydoubleptr).name() << '\n';

    // std::cout << myint is a glvalue expression of polymorphic type; it is evaluated
    const std::type_info& r1 = typeid(std::cout << myint); // side-effect: prints 50
    std::cout << '\n' << "std::cout<<myint has type : " << r1.name() << '\n';

    // std::printf() is not a glvalue expression of polymorphic type; NOT evaluated
    const std::type_info& r2 = typeid(std::printf("%d\n", myint));
    std::cout << "printf(\"%d\\n\",myint) has type : " << r2.name() << '\n';

    // Non-polymorphic lvalue is a static type
    Derived d1;
    Base& b1 = d1;
    std::cout << "reference to non-polymorphic base: " << typeid(b1).name() << '\n';

    Derived2 d2;
    Base2& b2 = d2;
    std::cout << "reference to polymorphic base: " << typeid(b2).name() << '\n';

    try
    {
        // dereferencing a null pointer: okay for a non-polymorphic expression
        std::cout << "mydoubleptr points to " << typeid(*mydoubleptr).name() << '\n'; 
        // dereferencing a null pointer: not okay for a polymorphic lvalue
        Derived2* bad_ptr = nullptr;
        std::cout << "bad_ptr points to... ";
        std::cout << typeid(*bad_ptr).name() << '\n';
    }
    catch (const std::bad_typeid& e)
    {
        std::cout << " caught " << e.what() << '\n';
    }
}
```
