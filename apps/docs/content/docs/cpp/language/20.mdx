{/* source:cpp-20:0000 */}
C++20 is a major version after C++17, featuring major features (concepts, modules, coroutines, and ranges) and other language and library features. The standard was published in December 2020.

{/* source:cpp-20:0001 */}
This section is incomplete

## New language features

{/* source:cpp-20:0002 */}
- [Feature test macros](/docs/cpp/library/feature_test)
- [Three-way comparison](/docs/cpp/language/expressions/operator_comparison#Three-way_comparison) operator `<=>` and [`operator==() = default`](/docs/cpp/language/expressions/default_comparisons)
- [Designated initializers](/docs/cpp/language/initialization/aggregate_initialization#Designated_initializers)
- Init-statements and initializers in [range-`for`](/docs/cpp/language/statements/range-for)
- [`char8_t`](/docs/cpp/language/keywords/char8_t)
- New [attributes](/docs/cpp/language/declarations/attributes): [`[[no_unique_address]]`](/docs/cpp/language/declarations/attributes/no_unique_address), [`[[likely]]`](/docs/cpp/language/declarations/attributes/likely), [`[[unlikely]]`](/docs/cpp/language/declarations/attributes/likely)
- [`Pack-expansions`](/docs/cpp/language/templates/parameter_pack) in [lambda init-captures](/docs/cpp/language/functions/lambda#Lambda_capture)
- Removed the requirement to use `typename` to disambiguate types in many contexts
- [`consteval`](/docs/cpp/language/declarations/consteval), [`constinit`](/docs/cpp/language/declarations/constinit)
- Further relaxed constexpr
- Signed integers are 2's complement
- [Bitwise shift operators](/docs/cpp/language/expressions/operator_arithmetic) unified behavior
- [aggregate initialization](/docs/cpp/language/initialization/aggregate_initialization) using parentheses
- [coroutines](/docs/cpp/language/functions/coroutines)
- [modules](/docs/cpp/language/basic_concepts/modules)
- [Constraints and concepts](/docs/cpp/language/templates/constraints)
- [Abbreviated function template](/docs/cpp/language/templates/function_template#Abbreviated_function_template)
- DR11: [array new](/docs/cpp/language/expressions/new#Defect_reports) can deduce array size
