{/* source:cpp-language-static:0000 */}
Inside a class definition, the keyword [`static`](/docs/cpp/language/keywords/static) declares members that are not bound to class instances.

{/* source:cpp-language-static:0001 */}
Outside a class definition, it has a different meaning: see [storage duration](/docs/cpp/language/declarations/storage_duration).

## Syntax

{/* source:cpp-language-static:0002 */}
A declaration for a static member is a [member declaration](/docs/cpp/language/classes/class#Member_specification) whose declaration specifiers contain the keyword `static`. The keyword `static` usually appears before other specifiers (which is why the syntax is often informally described as `static` `data-member` or `static` `member-function`), but may appear anywhere in the specifier sequence.

{/* source:cpp-language-static:0003 */}
The name of any static data member and static member function must be different from the name of the containing class.

## Explanation

{/* source:cpp-language-static:0004 */}
Static members of a class are not associated with the objects of the class: they are independent variables with static<InlineRevision since="C++11"> or thread</InlineRevision> [storage duration](/docs/cpp/language/declarations/storage_duration) or regular functions.

{/* source:cpp-language-static:0005 */}
The `static` keyword is only used with the declaration of a static member, inside the class definition, but not with the definition of that static member:

{/* source:cpp-language-static:0006 */}
```cpp
class X { static int n; }; // declaration (uses 'static')
int X::n = 1;              // definition (does not use 'static')
```

{/* source:cpp-language-static:0007 */}
The declaration inside the class body is not a definition and may declare the member to be of [incomplete type](/docs/cpp/language/basic_concepts/incomplete_type) (other than `void`), including the type in which the member is declared:

{/* source:cpp-language-static:0008 */}
```cpp
struct Foo;

struct S
{
    static int a[]; // declaration, incomplete type
    static Foo x;   // declaration, incomplete type
    static S s;     // declaration, incomplete type (inside its own definition)
};

int S::a[10]; // definition, complete type
struct Foo {};
Foo S::x;     // definition, complete type
S S::s;       // definition, complete type
```

{/* source:cpp-language-static:0009 */}
<Revision since="C++11">
However, if the declaration uses [`constexpr`](/docs/cpp/language/declarations/constexpr)<InlineRevision since="C++17"> or [`inline`](/docs/cpp/language/declarations/inline)</InlineRevision> specifier, the member must be declared to have complete type.
</Revision>

{/* source:cpp-language-static:0010 */}
To refer to a static member `m` of class `T`, two forms may be used: qualified name `T::m` or member access expression `E.m` or `E->m`, where `E` is an expression that evaluates to `T` or `T*` respectively. When in the same class scope, the qualification is unnecessary:

{/* source:cpp-language-static:0011 */}
```cpp
struct X
{
    static void f(); // declaration
    static int n;    // declaration
};

X g() { return X(); } // some function returning X

void f()
{
    X::f();  // X::f is a qualified name of static member function
    g().f(); // g().f is member access expression referring to a static member function
}

int X::n = 7; // definition

void X::f() // definition
{
    n = 1; // X::n is accessible as just n in this scope
}
```

{/* source:cpp-language-static:0012 */}
Static members obey the [class member access rules (private, protected, public)](/docs/cpp/language/classes/access).

### Static member functions

{/* source:cpp-language-static:0013 */}
Static member functions are not associated with any object. When called, they have no `this` pointer.

{/* source:cpp-language-static:0014 */}
Static member functions cannot be `virtual`, `const`, `volatile`, or [ref-qualified](/docs/cpp/language/classes/member_functions#ref-qualified_member_functions).

{/* source:cpp-language-static:0015 */}
The address of a static member function may be stored in a regular [pointer to function](/docs/cpp/language/declarations/pointer#Pointers_to_functions), but not in a [pointer to member function](/docs/cpp/language/declarations/pointer#Pointers_to_member_functions).

### Static data members

{/* source:cpp-language-static:0016 */}
Static data members are not associated with any object. They exist even if no objects of the class have been defined. There is only one instance of the static data member in the entire program with static [storage duration](/docs/cpp/language/declarations/storage_duration)<InlineRevision since="C++11">, unless the keyword [`thread_local`](/docs/cpp/language/keywords/thread_local) is used, in which case there is one such object per thread with thread storage duration</InlineRevision>.

{/* source:cpp-language-static:0017 */}
Static data members cannot be `mutable`.

{/* source:cpp-language-static:0018 */}
Static data members of a class in namespace scope have [external linkage](/docs/cpp/language/declarations/storage_duration) if the class itself has external linkage (is not a member of [unnamed namespace](/docs/cpp/language/declarations/namespace#Unnamed_namespaces)). Local classes (classes defined inside functions) and unnamed classes, including member classes of unnamed classes, cannot have static data members.

{/* source:cpp-language-static:0019 */}
<Revision since="C++17">
A static data member may be declared [`inline`](/docs/cpp/language/declarations/inline). An inline static data member can be defined in the class definition and may specify an initializer. It does not need an out-of-class definition:

```cpp
struct X
{
    inline static int fully_usable = 1; // No out-of-class definition required, ODR-usable
    inline static const std::string class_name{"X"}; // Likewise

    static const int non_addressable = 1; // C.f. non-inline constants, usable
                                          // for its value, but not ODR-usable
    // static const std::string class_name{"X"}; // Non-integral declaration of this
                                                 // form is disallowed entirely
};
```
</Revision>

### Constant static members

{/* source:cpp-language-static:0020 */}
If a static data member of integral or enumeration type is declared `const` (and not `volatile`), it can be initialized with an [initializer](/docs/cpp/language/initialization) in which every expression is a [constant expression](/docs/cpp/language/declarations/constexpr), right inside the class definition:

{/* source:cpp-language-static:0021 */}
```cpp
struct X
{
    const static int n = 1;
    const static int m{2}; // since C++11
    const static int k;
};
const int X::k = 3;
```

{/* source:cpp-language-static:0022 */}
<Revision since="C++11">
If a static data member of [LiteralType](/docs/cpp/library/named_req/LiteralType) is declared `constexpr`, it must be initialized with an initializer in which every expression is a constant expression, right inside the class definition:

```cpp
struct X
{
    constexpr static int arr[] = { 1, 2, 3 };        // OK
    constexpr static std::complex<double> n = {1,2}; // OK
    constexpr static int k; // Error: constexpr static requires an initializer
};
```
</Revision>

{/* source:cpp-language-static:0023 */}
If a const <InlineRevision since="C++17">non-inline</InlineRevision> static data member <InlineRevision since="C++11" until="C++17">or a constexpr static data member</InlineRevision> is [ODR-use](/docs/cpp/language/basic_concepts/definition#ODR-use), a definition at namespace scope is still required, but it cannot have an initializer.

{/* source:cpp-language-static:0024 */}
<Revision since="C++17">
A `constexpr` static data member is implicitly `inline` and does not need to be redeclared at namespace scope. This redeclaration without an initializer (formerly required) is still permitted, but is deprecated.
</Revision>

{/* source:cpp-language-static:0025 */}
```cpp
struct X
{
    static const int n = 1;
    static constexpr int m = 4;
};

const int *p = &X::n, *q = &X::m; // X::n and X::m are ODR-used
const int X::n;             // … so a definition is necessary
constexpr int X::m;         // … (except for X::m in C++17)
```
