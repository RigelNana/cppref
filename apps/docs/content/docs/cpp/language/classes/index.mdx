{/* source:cpp-language-classes:0000 */}
A class is a user-defined type.

{/* source:cpp-language-classes:0001 */}
A class type is defined by class-specifier, which appears in decl-specifier-seq of the [declaration](/docs/cpp/language/declarations) syntax. See [class declaration](/docs/cpp/language/classes/class) for the syntax of the class specifier.

{/* source:cpp-language-classes:0002 */}
A class can have the following kinds of members:

{/* source:cpp-language-classes:0003 */}
1) data members:

{/* source:cpp-language-classes:0004 */}
a) [non-static data members](/docs/cpp/language/classes/data_members), including [bit-fields](/docs/cpp/language/classes/bit_field).

{/* source:cpp-language-classes:0005 */}
b) [static data members](/docs/cpp/language/classes/static#Static_data_members)

{/* source:cpp-language-classes:0006 */}
2) member functions:

{/* source:cpp-language-classes:0007 */}
a) [non-static member functions](/docs/cpp/language/classes/member_functions)

{/* source:cpp-language-classes:0008 */}
b) [static member functions](/docs/cpp/language/classes/static#Static_member_functions)

{/* source:cpp-language-classes:0009 */}
3) nested types:

{/* source:cpp-language-classes:0010 */}
a) [nested classes](/docs/cpp/language/classes/nested_classes) and [enumerations](/docs/cpp/language/declarations/enum) defined within the class definition

{/* source:cpp-language-classes:0011 */}
b) aliases of existing types, defined with [`typedef`](/docs/cpp/language/declarations/typedef) <InlineRevision since="C++11">or [type alias](/docs/cpp/language/declarations/type_alias) </InlineRevision>declarations

{/* source:cpp-language-classes:0012 */}
c) the name of the class within its own definition acts as a public member type alias of itself for the purpose of [lookup](/docs/cpp/language/basic_concepts/unqualified_lookup#Injected_class_name) (except when used to name a [constructor](/docs/cpp/language/classes/initializer_list)): this is known as [injected-class-name](/docs/cpp/language/classes/injected-class-name)

{/* source:cpp-language-classes:0013 */}
4) [enumerators](/docs/cpp/language/declarations/enum) from all unscoped enumerations defined within the class<InlineRevision since="C++20">, or introduced by [using-declarations](/docs/cpp/language/classes/using_declaration) or [using-enum-declarations](/docs/cpp/language/declarations/enum#Using-enum-declaration)</InlineRevision>

{/* source:cpp-language-classes:0014 */}
5) [member templates](/docs/cpp/language/templates/member_template) (<InlineRevision since="C++14">variable templates, </InlineRevision>class templates or function templates) may appear in the body of any non-local class/struct/union.

{/* source:cpp-language-classes:0015 */}
All members are defined at once in the class definition, they cannot be added to an already-defined class (unlike the members of namespaces)

{/* source:cpp-language-classes:0016 */}
A member of a class `T` cannot use `T` as its name if the member is

{/* source:cpp-language-classes:0017 */}
- a static data member,
- a member function,
- a member type,
- a member template,
- an enumerator of an enumeration <InlineRevision since="C++11">(unless the enumeration is scoped)</InlineRevision>, or
- a member of a member anonymous union.

{/* source:cpp-language-classes:0018 */}
However, a non-static data member may use the name `T` as long as there are no user-declared constructors.

{/* source:cpp-language-classes:0019 */}
A class with at least one declared or inherited [virtual](/docs/cpp/language/classes/virtual) member function is polymorphic. Objects of this type are [polymorphic objects](/docs/cpp/language/basic_concepts/objects#Polymorphic_objects) and have runtime type information stored as part of the object representation, which may be queried with [`dynamic_cast`](/docs/cpp/language/expressions/dynamic_cast) and [`typeid`](/docs/cpp/language/expressions/typeid). Virtual member functions participate in dynamic binding.

{/* source:cpp-language-classes:0020 */}
A class with at least one declared or inherited pure virtual member function is an [abstract class](/docs/cpp/language/classes/abstract_class). Objects of this type cannot be created.

{/* source:cpp-language-classes:0021 */}
<Revision since="C++11">
A class with a [constexpr](/docs/cpp/language/declarations/constexpr) constructor is a [LiteralType](/docs/cpp/library/named_req/LiteralType): objects of this type can be manipulated by [constexpr](/docs/cpp/language/declarations/constexpr) functions at compile time.
</Revision>

## Properties of classes

{/* source:cpp-language-classes:0022 */}
<Revision since="C++11">
### Trivially copyable class
A trivially copyable class is a class that
  - has at least one eligible [copy constructor](/docs/cpp/language/classes/copy_constructor#Eligible_copy_constructor), [move constructor](/docs/cpp/language/classes/move_constructor#Eligible_move_constructor), [copy assignment operator](/docs/cpp/language/classes/as_operator#Eligible_copy_assignment_operator), or [move assignment operator](/docs/cpp/language/classes/move_operator#Eligible_move_assignment_operator),
  - each eligible copy constructor is [trivial](/docs/cpp/language/classes/copy_constructor#Trivial_copy_constructor)
  - each eligible move constructor is [trivial](/docs/cpp/language/classes/move_constructor#Trivial_move_constructor)
  - each eligible copy assignment operator is [trivial](/docs/cpp/language/classes/as_operator#Trivial_copy_assignment_operator)
  - each eligible move assignment operator is [trivial](/docs/cpp/language/classes/move_operator#Trivial_move_assignment_operator), and
  - has a non-deleted [trivial destructor](/docs/cpp/language/classes/destructor#Trivial_destructor).
<Revision>
### Trivial class
A trivial class is a class that
    - is trivially copyable, and
    - has one or more [eligible default constructors](/docs/cpp/language/classes/default_constructor#Eligible_default_constructor) such that each is [trivial](/docs/cpp/language/classes/default_constructor#Trivial_default_constructor).
(deprecated in C++26)
</Revision>
### Standard-layout class
A standard-layout class is a class that
  - has no [non-static data members](/docs/cpp/language/classes/data_members) of type non-standard-layout class (or array of such types) or reference,
  - has no [virtual functions](/docs/cpp/language/classes/virtual) and no [virtual base classes](/docs/cpp/language/classes/derived_class#Virtual_base_classes),
  - has the same [access control](/docs/cpp/language/classes/access) for all non-static data members,
  - has no non-standard-layout base classes,
  - only one class in the hierarchy has non-static data members, and
  - Informally, none of the base classes has the same type as the first non-static data member. Or, formally: given the class as S, has no element of the set M(S) of types as a base class, where M(X) for a type X is defined as:
  - If X is a non-union class type with no (possibly inherited) non-static data members, the set M(X) is empty.
  - If X is a non-union class type whose first non-static data member has type X0 (where said member may be an anonymous union), the set M(X) consists of X0 and the elements of M(X0).
  - If X is a union type, the set M(X) is the union of all M(Ui) and the set containing all Ui, where each Ui is the type of the ith non-static data member of X.
  - If X is an array type with element type Xe, the set M(X) consists of Xe and the elements of M(Xe).
  - If X is a non-class, non-array type, the set M(X) is empty.
A standard-layout struct is a standard-layout class defined with the class keyword [`struct`](/docs/cpp/language/keywords/struct) or the class keyword [`class`](/docs/cpp/language/keywords/class). A standard-layout union is a standard-layout class defined with the class keyword [`union`](/docs/cpp/language/keywords/union).
</Revision>

### Implicit-lifetime class

{/* source:cpp-language-classes:0023 */}
An implicit-lifetime class is a class that

{/* source:cpp-language-classes:0024 */}
- is an [aggregate](/docs/cpp/language/initialization/aggregate_initialization) whose destructor is not <InlineRevision until="C++11">user-declared</InlineRevision><InlineRevision since="C++11">[user-provided](/docs/cpp/language/functions/function#User-provided_functions)</InlineRevision>, or
- has at least one trivial eligible constructor and a trivial, non-deleted destructor.

{/* source:cpp-language-classes:0025 */}
Notes: the implicit-lifetime property is clarified by defect report [P0593R6](https://wg21.link/P0593R6).

{/* source:cpp-language-classes:0026 */}
<Revision>
### POD class
A POD class is a class that
<Revision until="C++11">
    - is an [aggregate](/docs/cpp/language/initialization/aggregate_initialization),
    - has no user-declared copy assignment operator,
    - has no user-declared destructor, and
    - has no non-static data members of type non-POD class (or array of such types) or reference.
</Revision>
<Revision since="C++11">
    - is a trivial class,
    - is a standard-layout class, and
    - has no non-static data members of type non-POD class (or array of such types).
</Revision>
A POD struct is a non-union POD class. A POD union is a union that is a POD class.
(deprecated in C++20)
</Revision>
