## New language features

{/* source:cpp-23:0002 */}
- New [language feature testing macros](/docs/cpp/library/feature_test#Language_features)
- [Explicit object parameter](/docs/cpp/language/functions/function#Explicit_object_parameter), [explicit object member functions](/docs/cpp/language/classes/member_functions#Explicit_object_member_functions), a.k.a. "deducing `this`" ([P0847R7](https://wg21.link/P0847R7))
- [Multidimensional subscript operator](/docs/cpp/language/expressions/operators#Array_subscript_operator) (e.g. `v[1, 3, 7] = 42;`) ([P2128R6](https://wg21.link/P2128R6))
- `static operator[]` ([P2589R1](https://wg21.link/P2589R1)), `static operator()`, and static lambdas ([P1169R4](https://wg21.link/P1169R4))
- `auto(x)` and `auto{x}`: [decay-copy](/docs/cpp/language/expressions/explicit_cast#Syntax) in the language ([P0849R8](https://wg21.link/P0849R8))
- Assumptions via new attribute [`[[assume(expression)]]`](/docs/cpp/language/declarations/attributes/assume) ([P1774R8](https://wg21.link/P1774R8))
- Attributes on [lambda-expressions](/docs/cpp/language/functions/lambda#Syntax) ([P2173R1](https://wg21.link/P2173R1))
- Optional [extended floating-point types](/docs/cpp/library/utility/types/floating-point): `std::float{16|32|64|128}_t`, and `std::bfloat16_t` ([P1467R9](https://wg21.link/P1467R9))
- New preprocessor directives: [`#elifdef`, `#elifndef`](/docs/cpp/language/preprocessor/conditional) ([P2334R1](https://wg21.link/P2334R1)), and [`#warning`](/docs/cpp/language/preprocessor/error) ([P2437R1](https://wg21.link/P2437R1))
- [Literal suffix '`Z`'/'`z`'](/docs/cpp/language/expressions/integer_literal#The_type_of_the_literal) for (`signed`) `std::size_t` literals ([P0330R8](https://wg21.link/P0330R8)), e.g. `auto ouz = 0uz;`
- White-spaces trimming before line splicing. ([P2223R2](https://wg21.link/P2223R2))
- Simpler implicit move ([P2266R3](https://wg21.link/P2266R3))
- Extending the lifetime of temporaries in range-based for loop initializer ([P2718R0](https://wg21.link/P2718R0))
- CTAD from inherited constructors ([P2582R1](https://wg21.link/P2582R1))
- Labels at the end of compound statements ([P2324R2](https://wg21.link/P2324R2)), e.g.

{/* source:cpp-23:0003 */}
```cpp
void f(int& x)
{
    if (x)
        goto END;
    x = 42;
END:
}
```

{/* source:cpp-23:0005 */}

```cpp
    /* ... */
```

  - [Character sets and encodings](/docs/cpp/language/basic_concepts/charset) ([P2314R4](https://wg21.link/P2314R4))

- `constexpr` changes:
  - Non-literal variables, labels, and `gotos` in `constexpr` functions ([P2242R3](https://wg21.link/P2242R3))
  - Permitting `static` and `thread_local` variables in constant expressions in `constexpr` functions ([P2647R1](https://wg21.link/P2647R1))
  - `constexpr` function does not need its return type and parameter types to be literal type ([P2448R2](https://wg21.link/P2448R2))

## Obsolete features

##### Removed features

{/* source:cpp-23:0021 */}
- Garbage collection support and reachability-based leak detection. ([P2186R2](https://wg21.link/P2186R2))
- Mixed wide string literals [concatenation](/docs/cpp/language/expressions/string_literal#Concatenation) support, e.g., `const auto* no = u"q" U"p"` is ill-formed. ([P2201R1](https://wg21.link/P2201R1))
- Non-encodable wide character literals and multicharacter wide character literals, e.g. `wchar_t x = 'db'` is ill-formed. ([P2362R3](https://wg21.link/P2362R3))

##### Deprecated features

{/* source:cpp-23:0022 */}
- `std::aligned_storage` and `std::aligned_union` ([P1413R3](https://wg21.link/P1413R3))

##### Reverted deprecations

{/* source:cpp-23:0023 */}
- The `operator,` (comma operator) in subscript expressions (but the semantics has been changed to support overloadable multidimensional subscript `operator[]`).
