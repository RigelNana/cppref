{/* source:cpp-language-templates:0000 */}
A template is a C++ entity that defines one of the following:

{/* source:cpp-language-templates:0001 */}
- a family of classes ([class template](/docs/cpp/language/templates/class_template)), which may be [nested classes](/docs/cpp/language/templates/member_template)
- a family of functions ([function template](/docs/cpp/language/templates/function_template)), which may be [member functions](/docs/cpp/language/templates/member_template)

{/* source:cpp-language-templates:0002 */}
<Revision since="C++11">
- an alias to a family of types ([alias template](/docs/cpp/language/declarations/type_alias))
</Revision>

{/* source:cpp-language-templates:0003 */}
<Revision since="C++14">
- a family of variables ([variable template](/docs/cpp/language/templates/variable_template))
</Revision>

{/* source:cpp-language-templates:0004 */}
<Revision since="C++20">
- a concept ([constraints and concepts](/docs/cpp/language/templates/constraints))
</Revision>

{/* source:cpp-language-templates:0005 */}
Templates are parameterized by one or more [template parameters](/docs/cpp/language/templates/template_parameters), of three kinds: type template parameters, non-type template parameters, and template template parameters.

{/* source:cpp-language-templates:0006 */}
When template arguments are provided, or, for [function](/docs/cpp/language/templates/function_template#Template_argument_deduction)<InlineRevision since="C++17"> and [class](/docs/cpp/language/templates/ctad)</InlineRevision> templates only, deduced, they are substituted for the template parameters to obtain a *specialization* of the template, that is, a specific type or a specific function lvalue.

{/* source:cpp-language-templates:0007 */}
Specializations may also be provided explicitly: [full specializations](/docs/cpp/language/templates/template_specialization) are allowed for class<InlineRevision since="C++14">, variable</InlineRevision> and function templates, [partial specializations](/docs/cpp/language/templates/partial_specialization) are only allowed for class templates<InlineRevision since="C++14"> and variable templates</InlineRevision>.

{/* source:cpp-language-templates:0008 */}
When a class template specialization is referenced in context that requires a complete object type, or when a function template specialization is referenced in context that requires a function definition to exist, the template is *instantiated* (the code for it is actually compiled), unless the template was already explicitly specialized or explicitly instantiated. Instantiation of a class template does not instantiate any of its member functions unless they are also used. At link time, identical instantiations generated by different translation units are merged.

{/* source:cpp-language-templates:0009 */}
The definition of a class template must be visible at the point of implicit instantiation, which is why template libraries typically provide all template definitions in the headers (e.g. [most boost libraries are header-only](https://www.boost.org/doc/libs/release/more/getting_started/unix-variants.html#header-only-libraries)).

## Template identifiers

{/* source:cpp-language-templates:0014 */}
A template identifier has one of the following syntaxes:

{/* source:cpp-language-templates:0015 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code={`template-name < template-argument-list (optional) >`} />
  <Declaration id="2" language="cpp" grammar code={`operator op < template-argument-list (optional) >`} />
  <Declaration id="3" language="cpp" since="C++11" grammar code={`operator "" identifier < template-argument-list (optional) >`} />
  (deprecated)
  <Declaration id="4" language="cpp" since="C++11" grammar code={`operator user-defined-string-literal < template-argument-list (optional) >`} />
</DeclarationDoc>

{/* source:cpp-language-templates:0016 */}
1. A *simple template identifier*.

{/* source:cpp-language-templates:0017 */}
2. An operator function template identifier.

{/* source:cpp-language-templates:0018 */}
3,4. A [literal operator](/docs/cpp/language/expressions/user_literal#Literal_operators) function template identifier.

{/* source:cpp-language-templates:0019 */}
<ParameterList>
  <Parameter name="template-name">an [identifier](/docs/cpp/language/basic_concepts/name) that names a template</Parameter>
  <Parameter name="op">an [overloadable operator](/docs/cpp/language/expressions/operators)</Parameter>
  <Parameter name="identifier">an identifier</Parameter>
  <Parameter name="user-defined-string-literal">`""` followed by an identifier</Parameter>
</ParameterList>

{/* source:cpp-language-templates:0020 */}
A simple template identifier that names a class template specialization names a class.

{/* source:cpp-language-templates:0021 */}
A template identifier that names an alias template specialization names a type.

{/* source:cpp-language-templates:0022 */}
A template identifier that names a function template specialization names a function.

{/* source:cpp-language-templates:0023 */}
If all following conditions are satisfied, a template identifier is *valid*:

{/* source:cpp-language-templates:0024 */}
- There are at most as many arguments as there are parameters<InlineRevision since="C++11"> or a parameter is a template [parameter pack](/docs/cpp/language/templates/parameter_pack)</InlineRevision>.
- There is an argument for each non-deducible<InlineRevision since="C++11"> non-pack</InlineRevision> parameter that does not have a default template argument.
- Each template argument matches the corresponding template parameter.
- Substitution of each template argument into the following template parameters (if any) succeeds.

{/* source:cpp-language-templates:0025 */}
<Revision since="C++20">
- If the template identifier is [non-dependent](/docs/cpp/language/templates/dependent_name), the associated constraints are satisfied as specified below.
</Revision>

{/* source:cpp-language-templates:0026 */}
An invalid simple template id is a compile-time error, unless it names a function template specialization (in which case [SFINAE](/docs/cpp/language/templates/sfinae) may apply).

{/* source:cpp-language-templates:0027 */}
```cpp
template<class T, T::type n = 0>
class X;

struct S
{
    using type = int;
};

using T1 = X<S, int, int>; // error: too many arguments
using T2 = X<>;            // error: no default argument for first template parameter
using T3 = X<1>;           // error: value 1 does not match type-parameter
using T4 = X<int>;         // error: substitution failure for second template parameter
using T5 = X<S>;           // OK
```

{/* source:cpp-language-templates:0028 */}
<Revision since="C++20">
When the `template-name` of a simple template id names a constrained non-function template or a constrained template template parameter, but not a member template that is a member of an unknown specialization, and all template arguments in the simple template id are non-dependent, the associated constraints of the constrained template must be satisfied:

```cpp
template<typename T>
concept C1 = sizeof(T) != sizeof(int);

template<C1 T>
struct S1 {};

template<C1 T>
using Ptr = T*;

S1<int>* p;                      // error: constraints not satisfied
Ptr<int> p;                      // error: constraints not satisfied

template<typename T>
struct S2 { Ptr<int> x; };       // error, no diagnostic required

template<typename T>
struct S3 { Ptr<T> x; };         // OK, satisfaction is not required

S3<int> x;                       // error: constraints not satisfied

template<template<C1 T> class X>
struct S4
{
    X<int> x;                    // error, no diagnostic required
};

template<typename T>
concept C2 = sizeof(T) == 1;

template<C2 T> struct S {};

template struct S<char[2]>;      // error: constraints not satisfied
template<> struct S<char[2]> {}; // error: constraints not satisfied
```
</Revision>

{/* source:cpp-language-templates:0029 */}
If all following conditions are satisfied, two template identifiers are *same*:

{/* source:cpp-language-templates:0030 */}
- Their template-name s or operators refer to the same template.
- Their corresponding type template arguments are the same type.
- The template parameter values determined by their corresponding non-type template arguments are [template-argument-equivalent](/docs/cpp/language/templates/template_parameters#Template_argument_equivalence).
- Their corresponding template template arguments refer to the same template.

{/* source:cpp-language-templates:0031 */}
Two template identifier that are the same refer to the same<InlineRevision since="C++14"> variable,</InlineRevision> class, or function.

## Templated entity

{/* source:cpp-language-templates:0032 */}
A *templated entity* (or, in some sources, "temploid") is any entity that is defined<InlineRevision since="C++11"> (or, for a [lambda expression](/docs/cpp/language/functions/lambda), created)</InlineRevision> within a template definition. All of the following are templated entities:

{/* source:cpp-language-templates:0033 */}
- a class/function<InlineRevision since="C++14">/variable</InlineRevision> template

{/* source:cpp-language-templates:0034 */}
<Revision since="C++20">
- a [concept](/docs/cpp/language/templates/constraints)
</Revision>

{/* source:cpp-language-templates:0035 */}
- a member of a templated entity (such as a non-template member function of a class template)
- an enumerator of an enumeration that is a templated entity
- any entity defined or created within a templated entity: a local class, a local variable, a friend function, etc

{/* source:cpp-language-templates:0036 */}
<Revision since="C++11">
- the closure type of a lambda expression that appears in the declaration of a templated entity
</Revision>

{/* source:cpp-language-templates:0037 */}
For example, in

{/* source:cpp-language-templates:0038 */}
```cpp
template<typename T>
struct A
{
    void f() {}
};
```

{/* source:cpp-language-templates:0039 */}
the function `A::f` is not a function template, but is still considered to be templated.

{/* source:cpp-language-templates:0040 */}
A *templated function* is a function template or a function that is templated.

{/* source:cpp-language-templates:0041 */}
A *templated class* is a class template or a class that is templated.

{/* source:cpp-language-templates:0042 */}
<Revision since="C++14">
A *templated variable* is a variable template or a variable that is templated.
</Revision>
