{/* source:cpp-language-sizeof:0000 */}
Queries the number of elements in a [`pack`](/docs/cpp/language/templates/parameter_pack).

## Syntax

{/* source:cpp-language-sizeof:0001 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="sizeof...( pack )" />
</DeclarationDoc>

{/* source:cpp-language-sizeof:0002 */}
Returns a constant of type [`std::size_t`](/docs/cpp/library/utility/types/size_t).

## Explanation

{/* source:cpp-language-sizeof:0003 */}
Returns the number of elements in a [`pack`](/docs/cpp/language/templates/parameter_pack).

## Keywords

{/* source:cpp-language-sizeof:0004 */}
[`sizeof`](/docs/cpp/language/keywords/sizeof)

## Example

{/* source:cpp-language-sizeof:0005 */}
```cpp
#include <array>
#include <iostream>
#include <type_traits>

template<typename... Ts>
constexpr auto make_array(Ts&&... ts)
{
    using CT = std::common_type_t<Ts...>;
    return std::array<CT, sizeof...(Ts)>{std::forward<CT>(ts)...};
}

int main()
{
    std::array<double, 4ul> arr = make_array(1, 2.71f, 3.14, '*');
    std::cout << "arr = { ";
    for (auto s{arr.size()}; double elem : arr)
        std::cout << elem << (--s ? ", " : " ");
    std::cout << "}\n";
}
```

Output:

```text
arr = { 1, 2.71, 3.14, 42 }
```
