### Usage

{/* source:cpp-keyword-not:0000 */}
- [alternative operators](/docs/cpp/language/expressions/operator_alternative): as an alternative for `!`

### Example

{/* source:cpp-keyword-not:0001 */}
```cpp
#include <iostream>

void show(bool z, const char* s, int n)
{
    const char* r{z ? " true  " : " false "};
    if (n == 0) std::cout << "┌───────────┬─────────┐\n";
    if (n <= 1) std::cout << "│ " <<s<< " │ "<<r<<" │\n";
    if (n == 1) std::cout << "└───────────┴─────────┘\n";
}

int main()
{
    show(not true , "not true ", 0);
    show(not false, "not false", 1);
}
```

Output:

```text
┌───────────┬─────────┐
│ not true  │  false  │
│ not false │  true   │
└───────────┴─────────┘
```
