### Usage

{/* source:cpp-keywords-typename:0000 */}
- In the template parameter list of a [template declaration](/docs/cpp/language/templates), `typename` can be used as an alternative to [class](/docs/cpp/language/keywords/class) to declare [type template parameters](/docs/cpp/language/templates/template_parameters#Type_template_parameter)<InlineRevision since="C++17"> and template template parameters</InlineRevision>.
- Inside a declaration or a definition of a template, `typename` can be used to declare that a [dependent qualified name](/docs/cpp/language/templates/dependent_name) is a type.
- `typename` can be used before a non-dependent qualified type name. It has no effect in this case.

{/* source:cpp-keywords-typename:0001 */}
<Revision since="C++20">
- Inside a [requirements](/docs/cpp/language/templates/constraints) for type requirements
</Revision>
