- [`alignof` operator](/docs/cpp/language/expressions/alignof)

### Example

{/* source:cpp-keyword-alignof:0001 */}
```cpp
#include <cstddef>
#include <iostream>
 
int main()
{
    std::cout << alignof(std::max_align_t) << '\n';
}
```

Possible output:

```text
16
```
