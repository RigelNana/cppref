### Usage

{/* source:cpp-keyword-export:0000 */}
<Revision until="C++11">
Used to mark a [template definition](/docs/cpp/language/templates/class_template) *exported*, which allows the same template to be declared, but not defined, in other translation units.
</Revision>

<Revision since="C++11" until="C++20">
*The keyword is unused and reserved.*
</Revision>

<Revision since="C++20">
Marks a declaration, a group of declarations, or another [module](/docs/cpp/language/basic_concepts/modules) as exported by the current [module](/docs/cpp/language/basic_concepts/modules).
</Revision>
