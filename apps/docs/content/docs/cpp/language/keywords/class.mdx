### Usage

{/* source:cpp-keyword-class:0000 */}
- [declaration of a class](/docs/cpp/language/classes/class)

{/* source:cpp-keyword-class:0001 */}
<Revision since="C++11">
- [declaration of a scoped enumeration type](/docs/cpp/language/declarations/enum)
</Revision>

{/* source:cpp-keyword-class:0002 */}
- In a [template declaration](/docs/cpp/language/templates), `class` can be used to introduce [type template parameters](/docs/cpp/language/templates/template_parameters#Type_template_parameter) and [template template parameters](/docs/cpp/language/templates/template_parameters#Template_template_parameter)
- If a function or a variable exists in scope with the name identical to the name of a class type, `class` can be prepended to the name for disambiguation, resulting in an [elaborated type specifier](/docs/cpp/language/declarations/elaborated_type_specifier)

### Example

{/* source:cpp-keyword-class:0003 */}
```cpp
class Foo; // forward declaration of a class
 
class Bar  // definition of a class
{
public:
    Bar(int i) : m_i(i) {}
private:
    int m_i;
};
 
template<class T> // template argument
void qux()
{
    T t;
}
 
enum class Pub // scoped enum, since C++11
{
    b, d, p, q
};
 
int main()
{
    Bar Bar(1); // variable Bar hides type Bar
    Bar Bar2(2); // compiler error
    class Bar Bar3(3); // elaborated type
}
```
