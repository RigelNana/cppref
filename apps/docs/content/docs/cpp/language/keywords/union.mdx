### Usage

{/* source:cpp-keyword-union:0000 */}
- [declaration of a union type](/docs/cpp/language/classes/union)
- If a function or a variable exists in scope with the name identical to the name of a union type, `union` can be prepended to the name for disambiguation, resulting in an [elaborated type specifier](/docs/cpp/language/declarations/elaborated_type_specifier)
