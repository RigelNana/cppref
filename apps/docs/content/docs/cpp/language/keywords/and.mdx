### Usage

{/* source:cpp-keyword-and:0000 */}
- [`alternative operators`](/docs/cpp/language/expressions/operator_alternative): as an alternative for `&&`

### Example

{/* source:cpp-keyword-and:0001 */}
```cpp
int main()
{
    static_assert((false and false) == false);
    static_assert((false and true)  == false);
    static_assert((true  and false) == false);
    static_assert((true  and true)  == true);
}
```
