### Usage

{/* source:cpp-keyword-requires:0000 */}
- specifies a constant expression on template parameters that [evaluate a requirement](/docs/cpp/language/templates/requires)

{/* source:cpp-keyword-requires:0001 */}
  - within such a requirement, introduces a [nested requirement](/docs/cpp/language/templates/requires#Nested_requirements)

{/* source:cpp-keyword-requires:0002 */}
- in a template declaration, specifies an [associated constraint](/docs/cpp/language/templates/constraints)
