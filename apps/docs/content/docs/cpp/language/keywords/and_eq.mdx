### Usage

{/* source:cpp-keyword-and-eq:0000 */}
- [`alternative operators`](/docs/cpp/language/expressions/operator_alternative): as an alternative for `&=`

### Example

{/* source:cpp-keyword-and-eq:0001 */}
```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::bitset<4> mask("1100");
    std::bitset<4> val("0111");
    val and_eq mask;
    std::cout << val << '\n';
}
```

Output:

```text
0100
```
