### Usage

{/* source:cpp-keyword-struct:0000 */}
- [declaration of a compound type](/docs/cpp/language/classes/class)

{/* source:cpp-keyword-struct:0001 */}
<Revision since="C++11">
- [declaration of a scoped enumeration type](/docs/cpp/language/declarations/enum)
</Revision>

{/* source:cpp-keyword-struct:0002 */}
- If a function or a variable exists in scope with the name identical to the name of a non-union class type, `struct` can be prepended to the name for disambiguation, resulting in an [elaborated type specifier](/docs/cpp/language/declarations/elaborated_type_specifier).

### Example

{/* source:cpp-keyword-struct:0003 */}
```cpp
struct Foo; // forward declaration of a struct
 
struct Bar  // definition of a struct
{
    Bar(int i) : i(i + i) {}
 
    int i;
};
 
enum struct Pub // scoped enum, since C++11
{
    b, d, p, q,
};
 
int main()
{
    Bar Bar(1);
    struct Bar Bar2(2); // elaborated type
}
```
