### Usage

{/* source:cpp-keyword-return:0000 */}
- [`return`](/docs/cpp/language/statements/return) statement: as the declaration of the statement

### Example

{/* source:cpp-keyword-return:0001 */}
```cpp
#include <cstdlib>
#include <iostream>
 
[[nodiscard]] constexpr auto clamp(int value, int min, int max) noexcept
{
    if (value <= min)
        return min;
    else if (max <= value)
        return max;
 
    return value;
    // won't be executed past 'return' statement
 
    std::exit(value);
}
 
int main() noexcept
{
    std::cout << clamp(1, 2, 4);
    std::cout << clamp(3, 2, 4);
    std::cout << clamp(5, 2, 4);
 
    return 0; // the value '0' that in main() indicates a success
}
```
Output:

```text
234
```
