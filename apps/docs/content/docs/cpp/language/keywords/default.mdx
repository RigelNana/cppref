### Usage

{/* source:cpp-keyword-default:0000 */}
- [`switch` statement](/docs/cpp/language/statements/switch): as the declaration of the default case label

{/* source:cpp-keyword-default:0001 */}
<Revision since="C++11">
- explicitly-defaulted function definition: as an explicit instruction to the compiler to generate [special member function](/docs/cpp/language/classes/member_functions#Special_member_functions)<InlineRevision since="C++20"> or a [comparison operator](/docs/cpp/language/expressions/default_comparisons)</InlineRevision> for a class.
</Revision>
