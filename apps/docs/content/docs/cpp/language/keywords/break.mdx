### Usage

{/* source:cpp-keyword-break:0000 */}
- [`break` statement](/docs/cpp/language/statements/break): as the declaration of the statement

### Example

{/* source:cpp-keyword-break:0001 */}
```cpp
#include <iostream>
 
int main() noexcept
{
    for (int i{0}; i < 69; ++i)
    {
        if (i == 3) [[unlikely]]
            break; // breaks from the 'for' loop
        std::cout << i;
    }
}
```

Output:

```text
012
```
