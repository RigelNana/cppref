### Usage

{/* source:cpp-keyword-compl:0000 */}
- [alternative operators](/docs/cpp/language/expressions/operator_alternative): as an alternative for `~`

### Example

{/* source:cpp-keyword-compl:0001 */}
```cpp
#include <bitset>
#include <iostream>
 
using bin = std::bitset<8>;
 
void show(bin z, const char* s, int n)
{
    if (n == 0) std::cout << "┌─────────┬──────────┐\n";
    if (n <= 2) std::cout << "│ "<<s<<" │ " <<z<<" │\n";
    if (n == 2) std::cout << "└─────────┴──────────┘\n";
}
 
struct A
{
    compl A() { std::cout << "A dtor\n"; }
};
 
int main()
{
    bin x{"01011010"}; show(x, "x      ", 0);
    bin z = compl x;   show(z, "compl x", 2);
    A a;
}
```

Output:

```text
┌─────────┬──────────┐
│ x       │ 01011010 │
│ compl x │ 10100101 │
└─────────┴──────────┘
A dtor
```
