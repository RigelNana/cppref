### Usage

{/* source:cpp-keyword-int:0000 */}
- [`short int` type](/docs/cpp/language/basic_concepts/types#Integral_types): as the declaration of the type when combined with [`short`](/docs/cpp/language/keywords/short)
- [`unsigned short int` type](/docs/cpp/language/basic_concepts/types#Integral_types): as the declaration of the type when combined with [`unsigned`](/docs/cpp/language/keywords/unsigned) and [`short`](/docs/cpp/language/keywords/short)
- [`int` type](/docs/cpp/language/basic_concepts/types#Integral_types): as the declaration of the type
- [`unsigned int` type](/docs/cpp/language/basic_concepts/types#Integral_types): as the declaration of the type when combined with [`unsigned`](/docs/cpp/language/keywords/unsigned)
- [`long int` type](/docs/cpp/language/basic_concepts/types#Integral_types): as the declaration of the type when combined with [`long`](/docs/cpp/language/keywords/long)
- [`unsigned long int` type](/docs/cpp/language/basic_concepts/types#Integral_types): as the declaration of the type when combined with [`unsigned`](/docs/cpp/language/keywords/unsigned) and [`long`](/docs/cpp/language/keywords/long)

{/* source:cpp-keyword-int:0001 */}
<Revision since="C++11">
- [`long long int` type](/docs/cpp/language/basic_concepts/types#Integral_types): as the declaration of the type when combined with two [`longs`](/docs/cpp/language/keywords/long)
- [`unsigned long long int` type](/docs/cpp/language/basic_concepts/types#Integral_types): as the declaration of the type when combined with [`unsigned`](/docs/cpp/language/keywords/unsigned) and two [`longs`](/docs/cpp/language/keywords/long)
