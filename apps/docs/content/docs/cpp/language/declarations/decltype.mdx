{/* source:cpp-language-decltype:0000 */}
Inspects the declared type of an entity or the type and value category of an expression.

## Syntax

{/* source:cpp-language-decltype:0001 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="decltype ( entity )" />
  <Declaration id="2" language="cpp" grammar code="decltype ( expression )" />
</DeclarationDoc>

## Explanation

{/* source:cpp-language-decltype:0002 */}
1. If the argument is an unparenthesized [id-expression](/docs/cpp/language/basic_concepts/name) or an unparenthesized [class member access](/docs/cpp/language/expressions/operator_member_access) expression, then decltype yields the type of the *entity* named by this expression. If there is no such entity, or if the argument names a set of overloaded functions, the program is ill-formed.

   <Revision since="C++17">
   If the argument is an unparenthesized [id-expression](/docs/cpp/language/basic_concepts/name) naming a [structured binding](/docs/cpp/language/declarations/structured_binding), then decltype yields the *referenced type* (described in the specification of the structured binding declaration).
   </Revision>

   <Revision since="C++20">
   If the argument is an unparenthesized [id-expression](/docs/cpp/language/basic_concepts/name) naming a [non-type template parameter](/docs/cpp/language/templates/template_parameters#Non-type_template_parameter), then decltype yields the type of the template parameter (after performing any necessary type deduction if the template parameter is declared with a placeholder type). The type is non-const even if the entity is a template parameter object (which is a const object).
   </Revision>

{/* source:cpp-language-decltype:0003 */}
2. If the argument is any other expression of type `T`, and

{/* source:cpp-language-decltype:0004 */}
   a. if the [value category](/docs/cpp/language/expressions/value_category) of *expression* is [*xvalue*](/docs/cpp/language/expressions/value_category#xvalue), then decltype yields `T&&`;

{/* source:cpp-language-decltype:0005 */}
   b. if the [value category](/docs/cpp/language/expressions/value_category) of *expression* is [*lvalue*](/docs/cpp/language/expressions/value_category#lvalue), then decltype yields `T&`;

{/* source:cpp-language-decltype:0006 */}
   c. if the [value category](/docs/cpp/language/expressions/value_category) of *expression* is [*prvalue*](/docs/cpp/language/expressions/value_category#prvalue), then decltype yields `T`.

   <Revision until="C++17">
   If *expression* is a function call which returns a prvalue of class type or is a [comma expression](/docs/cpp/language/expressions/operator_other) whose right operand is such a function call, a temporary object is not introduced for that prvalue.
   </Revision>

   <Revision since="C++17">
   If *expression* is a prvalue<InlineRevision since="C++20"> other than a (possibly parenthesized) [immediate invocation](/docs/cpp/language/declarations/consteval)</InlineRevision>, a temporary object is not [materialized](/docs/cpp/language/expressions/implicit_cast#Temporary_materialization) from that prvalue: such prvalue has no result object.
   </Revision>

   Because no temporary object is created, the type need not be [complete](/docs/cpp/language/basic_concepts/incomplete_type) or have an available [destructor](/docs/cpp/language/classes/destructor), and can be [abstract](/docs/cpp/language/classes/abstract_class). This rule doesn't apply to sub-expressions: in `decltype(f(g()))`, `g()` must have a complete type, but `f()` need not.

{/* source:cpp-language-decltype:0007 */}
Note that if the name of an object is parenthesized, it is treated as an ordinary lvalue expression, thus `decltype(x)` and `decltype((x))` are often different types.

{/* source:cpp-language-decltype:0008 */}
decltype is useful when declaring types that are difficult or impossible to declare using standard notation, like lambda-related types or types that depend on template parameters.

## Example

{/* source:cpp-language-decltype:0011 */}
```cpp
#include <cassert>
#include <iostream>
#include <type_traits>

struct A { double x; };
const A* a;

decltype(a->x) y;       // type of y is double (declared type)
decltype((a->x)) z = y; // type of z is const double& (lvalue expression)

template<typename T, typename U>
auto add(T t, U u) -> decltype(t + u) // return type depends on template parameters
                                      // return type can be deduced since C++14
{
    return t + u;
}

const int& getRef(const int* p) { return *p; }
static_assert(std::is_same_v<decltype(getRef), const int&(const int*)>);
auto getRefFwdBad(const int* p) { return getRef(p); }
static_assert(std::is_same_v<decltype(getRefFwdBad), int(const int*)>,
    "Just returning auto isn't perfect forwarding.");
decltype(auto) getRefFwdGood(const int* p) { return getRef(p); }
static_assert(std::is_same_v<decltype(getRefFwdGood), const int&(const int*)>,
    "Returning decltype(auto) perfectly forwards the return type.");

// Alternatively:
auto getRefFwdGood1(const int* p) -> decltype(getRef(p)) { return getRef(p); }
static_assert(std::is_same_v<decltype(getRefFwdGood1), const int&(const int*)>,
    "Returning decltype(return expression) also perfectly forwards the return type.");

int main()
{
    int i = 33;
    decltype(i) j = i * 2;
    static_assert(std::is_same_v<decltype(i), decltype(j)>);
    assert(i == 33 && 66 == j);

    auto f = [i](int av, int bv) -> int { return av * bv + i; };
    auto h = [i](int av, int bv) -> int { return av * bv + i; };
    static_assert(!std::is_same_v<decltype(f), decltype(h)>,
        "The type of a lambda function is unique and unnamed");

    decltype(f) g = f;
    std::cout << f(3, 3) << ' ' << g(3, 3) << '\n';
}
```

Output:

```text
42 42
```
