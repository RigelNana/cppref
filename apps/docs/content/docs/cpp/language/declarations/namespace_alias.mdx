{/* source:cpp-language-namespace-alias:0000 */}
Namespace aliases allow the programmer to define an alternate name for a namespace.

{/* source:cpp-language-namespace-alias:0001 */}
They are commonly used as a convenient shortcut for long or deeply-nested namespaces.

## Syntax

{/* source:cpp-language-namespace-alias:0002 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="namespace alias_name = ns_name;" />
  <Declaration id="2" language="cpp" grammar code="namespace alias_name = ::ns_name;" />
  <Declaration id="3" language="cpp" grammar code="namespace alias_name = nested_name::ns_name;" />
</DeclarationDoc>

## Explanation

{/* source:cpp-language-namespace-alias:0003 */}
The new alias `alias_name` provides an alternate method of accessing `ns_name`.

{/* source:cpp-language-namespace-alias:0004 */}
`alias_name` must be a name not previously used. `alias_name` is valid for the duration of the scope in which it is introduced.

## Keywords

{/* source:cpp-language-namespace-alias:0005 */}
[`namespace`](/docs/cpp/language/keywords/namespace)

## Example

{/* source:cpp-language-namespace-alias:0006 */}
```cpp
#include <iostream>

namespace foo
{
    namespace bar
    {
         namespace baz
         {
             int qux = 42;
         }
    }
}

namespace fbz = foo::bar::baz;

int main()
{
    std::cout << fbz::qux << '\n';
}
```

Output:

```text
42
```
