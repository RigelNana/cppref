{/* source:cpp-language-attributes-indeterminate:0000 */}
Indicates that the variable or function parameter has an indeterminate value if it is not initialized.

## Syntax

{/* source:cpp-language-attributes-indeterminate:0001 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="[[indeterminate]]" />
</DeclarationDoc>

## Explanation

{/* source:cpp-language-attributes-indeterminate:0002 */}
`[[indeterminate]]` can be applied to the definition of a block variable with automatic [storage duration](/docs/cpp/language/declarations/storage_duration) or to a declaration of a parameter of a [function declaration](/docs/cpp/language/functions/function). The attribute specifies that the bytes comprising the storage of an object with automatic storage duration is initially [indeterminate](/docs/cpp/language/initialization/default_initialization#Indeterminate_and_erroneous_values) rather than erroneous.

{/* source:cpp-language-attributes-indeterminate:0003 */}
If a function parameter is declared with `[[indeterminate]]`, it must be declared in the first declaration of its function. If a function parameter is declared with `[[indeterminate]]` in the first declaration of its function in one translation unit and the same function is declared without `[[indeterminate]]` on the same parameter in its first declaration in another translation unit, the program is [ill-formed, no diagnostic required](/docs/cpp/language/basic_concepts/ub#Explanation).

## Notes

{/* source:cpp-language-attributes-indeterminate:0004 */}
The `[[indeterminate]]` attribute restores the undefined behavior that was implicitly introduced until C++26. It may make compilers consider a code path reading an indeterminate value unreachable.

## Example

{/* source:cpp-language-attributes-indeterminate:0005 */}
```cpp
void f(int);

void g()
{
    int x [[indeterminate]]; // indeterminate value
    int y;                   // erroneous value

    f(x); // undefined behavior
    f(y); // erroneous behavior
}

struct T
{
    T() {}
    int x;
};

void h(T a [[indeterminate]], T b)
{
    f(a.x); // undefined behavior when called below
    f(b.x); // erroneous behavior when called below
}

h(T(), T());
```
