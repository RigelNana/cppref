Indicates that the function definition should be optimized for invocation from a [synchronized statement](/docs/cpp/language/statements/transactional_memory).

## Syntax

{/* source:cpp-language-attributes-optimize-for-synchronized:0001 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="[[optimize_for_synchronized]]" />
</DeclarationDoc>

## Explanation

{/* source:cpp-language-attributes-optimize-for-synchronized:0002 */}
Applies to the name being declared in a function declaration, which must be the first declaration of the function.

{/* source:cpp-language-attributes-optimize-for-synchronized:0003 */}
Indicates that the function definition should be optimized for invocation from a [synchronized statement](/docs/cpp/language/statements/transactional_memory). In particular, it avoids serializing synchronized blocks that make a call to a function that is transaction-safe for the majority of calls, but not for all calls.
