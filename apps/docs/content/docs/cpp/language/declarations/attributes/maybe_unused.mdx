{/* source:cpp-language-attributes-maybe-unused:0000 */}
Suppresses warnings on unused entities.

## Syntax

{/* source:cpp-language-attributes-maybe-unused:0001 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="[[maybe_unused]]" />
</DeclarationDoc>

## Explanation

{/* source:cpp-language-attributes-maybe-unused:0002 */}
This attribute can appear in the declaration of the following entities:

{/* source:cpp-language-attributes-maybe-unused:0003 */}
- [class/struct/union](/docs/cpp/language/classes): `struct [[maybe_unused]] S;`
- [typedef](/docs/cpp/language/declarations/typedef), including those declared by [alias declaration](/docs/cpp/language/declarations/type_alias): `[[maybe_unused]] typedef S* PS;`, `using PS [[maybe_unused]] = S*;`
- variable, including [static data member](/docs/cpp/language/classes/static): `[[maybe_unused]] int x;`
- [non-static data member](/docs/cpp/language/classes/data_members): `union U { [[maybe_unused]] int n; };`,
- [function](/docs/cpp/language/functions/function): `[[maybe_unused]] void f();`
- [enumeration](/docs/cpp/language/declarations/enum): `enum [[maybe_unused]] E {};`
- enumerator: `enum { A [[maybe_unused]], B [[maybe_unused]] = 42 };`
- [structured binding](/docs/cpp/language/declarations/structured_binding): `[[maybe_unused]] auto [a, b] = std::make_pair(42, 0.23);`

{/* source:cpp-language-attributes-maybe-unused:0004 */}
For entities declared `[[maybe_unused]]`, if the entities or their structured bindings are unused, the warning on unused entities issued by the compiler is suppressed.

{/* source:cpp-language-attributes-maybe-unused:0005 */}
<Revision since="C++26">
For labels declared `[[maybe_unused]]`, if they are unused, the warning on unused labels issued by the compiler is suppressed.
</Revision>

## Example

{/* source:cpp-language-attributes-maybe-unused:0006 */}
```cpp
#include <cassert>

[[maybe_unused]] void f([[maybe_unused]] bool thing1,
                        [[maybe_unused]] bool thing2)
{
    [[maybe_unused]] lb: // the label “lb” is not used, no warning
    [[maybe_unused]] bool b = thing1 && thing2;
    assert(b); // in release mode, assert is compiled out, and “b” is unused
               // no warning because it is declared [[maybe_unused]]
} // parameters “thing1” and “thing2” are not used, no warning

int main() {}
```
