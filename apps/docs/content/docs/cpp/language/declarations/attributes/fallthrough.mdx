{/* source:cpp-language-attributes-fallthrough:0000 */}
Indicates that the fall through from the previous case label is intentional and should not be diagnosed by a compiler that warns on fallthrough.

## Syntax

{/* source:cpp-language-attributes-fallthrough:0001 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="[[fallthrough]]" />
</DeclarationDoc>

## Explanation

{/* source:cpp-language-attributes-fallthrough:0002 */}
May only be applied to a [null statement](/docs/cpp/language/statements#Expression_statements) to create a *fallthrough statement* (`[[fallthrough]];`).

{/* source:cpp-language-attributes-fallthrough:0003 */}
A fallthrough statement may only be used in a [switch](/docs/cpp/language/statements/switch) statement, where the next statement to be executed is a statement with a case or default label for that switch statement. If the fallthrough statement is inside a loop, the next (labeled) statement must be part of the same iteration of that loop.

## Example

{/* source:cpp-language-attributes-fallthrough:0004 */}
```cpp
void f(int n)
{
    void g(), h(), i();
 
    switch (n)
    {
        case 1:
        case 2:
            g();
            [[fallthrough]];
        case 3: // no warning on fallthrough
            h();
        case 4: // compiler may warn on fallthrough
            if (n < 3)
            {
                i();
                [[fallthrough]]; // OK
            }
            else
            {
                return;
            }
        case 5:
            while (false)
            {
                [[fallthrough]]; // ill-formed: next statement is not
                                 //             part of the same iteration
            }
        case 6:
            [[fallthrough]]; // ill-formed, no subsequent case or default label
    }
}
```
