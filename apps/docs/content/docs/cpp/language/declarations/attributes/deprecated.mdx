{/* source:cpp-language-attributes-deprecated:0000 */}
Indicates that the name or entity declared with this attribute is [deprecated](https://en.wikipedia.org/wiki/Deprecation), that is, the use is allowed, but discouraged for some reason.

## Syntax

{/* source:cpp-language-attributes-deprecated:0001 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="[[deprecated]]" />
  <Declaration id="2" language="cpp" grammar code="[[deprecated( string-literal )]]" />
</DeclarationDoc>

{/* source:cpp-language-attributes-deprecated:0002 */}
<ParameterList>
  <Parameter name="string-literal">an [unevaluated string literal](/docs/cpp/language/expressions/string_literal#Unevaluated_strings) that could be used to explain the rationale for deprecation and/or to suggest a replacing entity</Parameter>
</ParameterList>

## Explanation

{/* source:cpp-language-attributes-deprecated:0003 */}
Indicates that the use of the name or entity declared with this attribute is allowed, but discouraged for some reason. Compilers typically issue warnings on such uses. The *string-literal*, if specified, is usually included in the warnings.

{/* source:cpp-language-attributes-deprecated:0004 */}
This attribute is allowed in declarations of the following names or entities:

{/* source:cpp-language-attributes-deprecated:0005 */}
- [class/struct/union](/docs/cpp/language/classes), e.g., `struct [[deprecated]] S;`,
- [typedef-name](/docs/cpp/language/declarations/typedef), including those declared by [alias declaration](/docs/cpp/language/declarations/type_alias), e.g.,

{/* source:cpp-language-attributes-deprecated:0006 */}
  - `[[deprecated]] typedef S* PS;`,
  - `using PS [[deprecated]] = S*;`,

{/* source:cpp-language-attributes-deprecated:0007 */}
- (non-member) variable, e.g., `[[deprecated]] int x;`,
- [static data member](/docs/cpp/language/classes/static), e.g., `struct S { [[deprecated]] static constexpr char CR{13}; };`,
- [non-static data member](/docs/cpp/language/classes/data_members), e.g., `union U { [[deprecated]] int n; };`,
- [function](/docs/cpp/language/functions/function), e.g., `[[deprecated]] void f();`,
- [namespace](/docs/cpp/language/declarations/namespace), e.g., `namespace [[deprecated]] NS { int x; }`,
- [enumeration](/docs/cpp/language/declarations/enum), e.g., `enum [[deprecated]] E {};`,

{/* source:cpp-language-attributes-deprecated:0008 */}
<Revision since="C++17">
- enumerator, e.g., `enum { A [[deprecated]], B [[deprecated]] = 42 };`,
</Revision>

{/* source:cpp-language-attributes-deprecated:0009 */}
- [template specialization](/docs/cpp/language/templates/template_specialization), e.g., `template<> struct [[deprecated]] X<int> {};`.

{/* source:cpp-language-attributes-deprecated:0010 */}
A name declared non-deprecated may be redeclared deprecated. A name declared deprecated cannot be un-deprecated by redeclaring it without this attribute.

## Example

{/* source:cpp-language-attributes-deprecated:0011 */}
```cpp
#include <iostream>

[[deprecated]]
void TriassicPeriod()
{
    std::clog << "Triassic Period: [251.9 - 208.5] million years ago.\n";
}

[[deprecated("Use NeogenePeriod() instead.")]]
void JurassicPeriod()
{
    std::clog << "Jurassic Period: [201.3 - 152.1] million years ago.\n";
}

[[deprecated("Use calcSomethingDifferently(int).")]]
int calcSomething(int x)
{
    return x * 2;
}

int main()
{
    TriassicPeriod();
    JurassicPeriod();
}
```

Possible output:

```text
Triassic Period: [251.9 - 208.5] million years ago.
Jurassic Period: [201.3 - 152.1] million years ago.

main.cpp:20:5: warning: 'TriassicPeriod' is deprecated [-Wdeprecated-declarations]
    TriassicPeriod();
    ^
main.cpp:3:3: note: 'TriassicPeriod' has been explicitly marked deprecated here
[[deprecated]]
  ^
main.cpp:21:5: warning: 'JurassicPeriod' is deprecated: Use NeogenePeriod() instead ⮠
 [-Wdeprecated-declarations]
    JurassicPeriod();
    ^
main.cpp:8:3: note: 'JurassicPeriod' has been explicitly marked deprecated here
[[deprecated("Use NeogenePeriod() instead")]]
  ^
2 warnings generated.
```
