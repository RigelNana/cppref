{/* source:cpp-language-auto:0000 */}
A placeholder type specifier designates a placeholder type that will be replaced later, typically by deduction from an [initializer](/docs/cpp/language/initialization).

## Syntax

{/* source:cpp-language-auto:0001 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="type-constraint (optional) auto" />
  <Declaration id="2" language="cpp" grammar since="C++14" code="type-constraint (optional) decltype(auto)" />
</DeclarationDoc>

{/* source:cpp-language-auto:0002 */}
<ParameterList>
  <Parameter name="type-constraint">
    <Revision since="C++20">
    a [concept](/docs/cpp/language/templates/constraints#Concepts) name, optionally qualified, optionally followed by a template argument list enclosed in `<>`
    </Revision>
  </Parameter>
</ParameterList>

{/* source:cpp-language-auto:0003 */}
1. Type is deduced using the rules for [template argument deduction](/docs/cpp/language/templates/template_argument_deduction#Other_contexts).

{/* source:cpp-language-auto:0004 */}
2. Type is [`decltype(expr)`](/docs/cpp/language/declarations/decltype), where `expr` is the initializer or ones used in return statements.

{/* source:cpp-language-auto:0005 */}
The placeholder `auto` may be accompanied by modifiers, such as `const` or `&`, which will participate in the type deduction. <InlineRevision since="C++14">The placeholder `decltype(auto)` must be the sole constituent of the declared type.</InlineRevision>

{/* source:cpp-language-auto:0006 */}
<Revision since="C++20">
If *type-constraint* is present, let `T` be the type deduced for the placeholder, the *type-constraint* introduces a [constraint expression](/docs/cpp/language/templates/constraints) as follows:

- If *type-constraint* is `Concept<A1, ..., An>`, then the constraint expression is `Concept<T, A1, ..., An>`;
- otherwise (*type-constraint* is `Concept` without an argument list), the constraint expression is `Concept<T>`.

Deduction fails if the constraint expression is invalid or returns `false`.
</Revision>

## Explanation

{/* source:cpp-language-auto:0007 */}
A placeholder type specifier may appear in the following contexts:

{/* source:cpp-language-auto:0008 */}
<Revision since="C++14">
### Parameter declarations

In the following parameter declarations, the type of the parameter declared can be of syntax (1):

- If a parameter of a [lambda expression](/docs/cpp/language/functions/lambda) has a placeholder type, the lambda expression is a generic lambda.
</Revision>

<Revision since="C++17">
- If a [non-type template parameter](/docs/cpp/language/templates/template_parameters#Template_non-type_arguments) has a placeholder type, its type is deduced from the corresponding template argument.
</Revision>

<Revision since="C++20">
- If a parameter of a [function declaration](/docs/cpp/language/functions/function) has a placeholder type, an [abbreviated function template](/docs/cpp/language/templates/function_template#Abbreviated_function_template) is declared.
</Revision>

### Function declarations

{/* source:cpp-language-auto:0009 */}
A placeholder type can appear in the [declaration specifiers](/docs/cpp/language/declarations#Specifiers) for a [function declarator](/docs/cpp/language/functions/function) that includes a trailing return type.

{/* source:cpp-language-auto:0010 */}
<Revision since="C++14">
A placeholder type can appear in the declaration specifiers or [type specifiers](/docs/cpp/language/declarations#Specifiers) in the declared return type of a [function declarator](/docs/cpp/language/functions/function). [Return type deduction](/docs/cpp/language/functions/function#Return_type_deduction) will be applied in this case.
</Revision>

{/* source:cpp-language-auto:0011 */}
```cpp
auto f() -> int; // OK: f returns int
auto g() { return 0.0; } // OK since C++14: g returns double
auto h(); // OK since C++14: h’s return type will be deduced when it is defined
```

### Variable declarations

{/* source:cpp-language-auto:0012 */}
The type of a variable declared using a placeholder type is deduced from its [initializer](/docs/cpp/language/initialization). This use is allowed in an initializing declaration of a variable.

{/* source:cpp-language-auto:0013 */}
The placeholder type can only appear as one of the [declaration specifiers](/docs/cpp/language/declarations#Specifiers) in the declaration specifier sequence or as one of the type specifiers in a trailing return type that specifies the type that replaces such a declaration specifier. In this case, the declaration must declare at least one variable, and each variable must have a non-empty initializer.

{/* source:cpp-language-auto:0014 */}
```cpp
// “auto”s in declaration specifiers
auto x = 5; // OK: x has type int
const auto *v = &x, u = 6; // OK: v has type const int*, u has type const int
static auto y = 0.0; // OK: y has type double

auto f() -> int;
auto (*fp)() -> auto = f; // OK: the “auto” in the trailing return type
                          // can be deduced from f
```

{/* source:cpp-language-auto:0015 */}
<Revision since="C++17">
### Structured binding declarations

The `auto` specifier can be used in a [structured binding](/docs/cpp/language/declarations/structured_binding) declaration.
</Revision>

### new expressions

{/* source:cpp-language-auto:0016 */}
A placeholder type can be used in the type specifier sequence of the type-id of a [new expression](/docs/cpp/language/expressions/new). In such a type-id, the placeholder type must appear as one of the type specifiers in the type specifier sequence or a trailing return type that specifies the type that replaces such a type specifier.

{/* source:cpp-language-auto:0017 */}
<Revision since="C++23">
### Function-style cast

The `auto` type specifier can be used as the type specifier of a [function-style cast](/docs/cpp/language/expressions/explicit_cast).
</Revision>

## Notes

{/* source:cpp-language-auto:0018 */}
Until C++11, `auto` had the semantic of a [storage duration specifier](/docs/cpp/language/declarations/storage_duration).

{/* source:cpp-language-auto:0019 */}
A program that uses a placeholder type in a context not explicitly stated above is ill-formed.

{/* source:cpp-language-auto:0020 */}
If a declaration declares multiple entities, and the declaration specifier sequence uses a placeholder type, the program is ill-formed if any of the following conditions is satisfied:

{/* source:cpp-language-auto:0021 */}
- Some of the entities declared are not variables.
- The type that replaces the placeholder type is not the same in each deduction.

{/* source:cpp-language-auto:0022 */}
```cpp
auto f() -> int, i = 0; // Error: declares a function and a variable with “auto”
auto a = 5, b = {1, 2}; // Error: different types for “auto”
```

{/* source:cpp-language-auto:0023 */}
The `auto` keyword may also be used in a nested name specifier. A nested name specifier of the form `auto::` is a placeholder that is replaced by a class or enumeration type following the rules for [constrained type](/docs/cpp/library/experimental/constraints) placeholder deduction. (Concepts TS)

## Example

{/* source:cpp-language-auto:0026 */}
```cpp
#include <iostream>
#include <utility>

template<class T, class U>
auto add(T t, U u) { return t + u; } // the return type is the type of operator+(T, U)

// perfect forwarding of a function call must use decltype(auto)
// in case the function it calls returns by reference
template<class F, class... Args>
decltype(auto) PerfectForward(F fun, Args&&... args) 
{ 
    return fun(std::forward<Args>(args)...); 
}

template<auto n> // C++17 auto parameter declaration
auto f() -> std::pair<decltype(n), decltype(n)> // auto can't deduce from brace-init-list
{
    return {n, n};
}

int main()
{
    auto a = 1 + 2;          // type of a is int
    auto b = add(1, 1.2);    // type of b is double
    static_assert(std::is_same_v<decltype(a), int>);
    static_assert(std::is_same_v<decltype(b), double>);

    auto c0 = a;             // type of c0 is int, holding a copy of a
    decltype(auto) c1 = a;   // type of c1 is int, holding a copy of a
    decltype(auto) c2 = (a); // type of c2 is int&, an alias of a
    std::cout << "before modification through c2, a = " << a << '\n';
    ++c2;
    std::cout << " after modification through c2, a = " << a << '\n';

    auto [v, w] = f<0>(); //structured binding declaration

    auto d = {1, 2}; // OK: type of d is std::initializer_list<int>
    auto n = {5};    // OK: type of n is std::initializer_list<int>
//  auto e{1, 2};    // Error as of DR n3922, std::initializer_list<int> before
    auto m{5};       // OK: type of m is int as of DR n3922, initializer_list<int> before
//  decltype(auto) z = { 1, 2 } // Error: {1, 2} is not an expression

    // auto is commonly used for unnamed types such as the types of lambda expressions
    auto lambda = [](int x) { return x + 3; };

//  auto int x; // valid C++98, error as of C++11
//  auto x;     // valid C, error in C++

    [](...){}(c0, c1, v, w, d, n, m, lambda); // suppresses "unused variable" warnings
}
```

Possible output:

```text
before modification through c2, a = 3
 after modification through c2, a = 4
```
