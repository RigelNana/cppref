{/* source:cpp-language-declarations:0000 */}
*Declarations* are how names are introduced (or re-introduced) into the C++ program. Not all declarations actually declare anything, and each kind of entity is declared differently. [Definitions](/docs/cpp/language/basic_concepts/definition) are declarations that are sufficient to use the entity identified by the name.

{/* source:cpp-language-declarations:0001 */}
A declaration is one of the following:

{/* source:cpp-language-declarations:0002 */}
- [Function definition](/docs/cpp/language/functions/function#Function_definition)
- [Template declaration](/docs/cpp/language/templates) (including [Partial template specialization](/docs/cpp/language/templates/partial_specialization))
- [Explicit template instantiation](/docs/cpp/language/templates/class_template#Explicit_instantiation)
- [Explicit template specialization](/docs/cpp/language/templates/template_specialization)
- [Namespace definition](/docs/cpp/language/declarations/namespace)
- [Linkage specification](/docs/cpp/language/declarations/language_linkage)

{/* source:cpp-language-declarations:0003 */}
<Revision since="C++11">
- Attribute declaration ([*attr*](/docs/cpp/language/declarations/attributes) `;`)
</Revision>

{/* source:cpp-language-declarations:0004 */}
- Empty declaration (`;`)
- A function declaration without a *decl-specifier-seq*:

It can only be used as part of a [template declaration](/docs/cpp/language/templates), [explicit specialization](/docs/cpp/language/templates/template_specialization), or explicit instantiation.

- *block-declaration* (a declaration that can appear inside a [block](/docs/cpp/language/statements#Compound_statement)), which, in turn, can be one of the following:

## Simple declaration

{/* source:cpp-language-declarations:0015 */}
A simple declaration is a statement that introduces, creates, and optionally initializes one or several identifiers, typically variables.

{/* source:cpp-language-declarations:0016 */}

  <Declaration id="2" language="cpp" grammar code="attr decl-specifier-seq init-declarator-list ;" />
</DeclarationDoc>

{/* source:cpp-language-declarations:0017 */}

  <Parameter name="init-declarator-list">comma-separated list of *declarators* with optional [initializers](/docs/cpp/language/initialization#Initializers). *init-declarator-list* is optional when declaring a named class/struct/union or a named enumeration</Parameter>
</ParameterList>

## Specifiers

{/* source:cpp-language-declarations:0019 */}
Declaration specifiers (*decl-specifier-seq*) is a sequence of the following whitespace-separated specifiers, in any order:

{/* source:cpp-language-declarations:0020 */}
- the [`typedef`](/docs/cpp/language/declarations/typedef) specifier. If present, the entire declaration is a [typedef declaration](/docs/cpp/language/declarations/typedef) and each declarator introduces a new type name, not an object or a function.
- function specifiers ([`inline`](/docs/cpp/language/declarations/inline), [`virtual`](/docs/cpp/language/classes/virtual), [`explicit`](/docs/cpp/language/classes/explicit)), only allowed in [function declarations](/docs/cpp/language/functions/function).

{/* source:cpp-language-declarations:0021 */}
<Revision since="C++17">
- the [`inline`](/docs/cpp/language/declarations/inline) specifier is also allowed on variable declarations.
</Revision>

{/* source:cpp-language-declarations:0022 */}
- the [friend](/docs/cpp/language/classes/friend) specifier, allowed in class and function declarations.

{/* source:cpp-language-declarations:0023 */}
<Revision since="C++11">
- the [`constexpr`](/docs/cpp/language/declarations/constexpr) specifier, only allowed in variable definitions, function and function template declarations, and the declaration of static data members of literal type.
</Revision>

<Revision since="C++20">
- the [`consteval`](/docs/cpp/language/declarations/consteval) specifier, only allowed in function and function template declarations.
- the [`constinit`](/docs/cpp/language/declarations/constinit) specifier, only allowed in declaration of a variable with static or thread storage duration. At most one of the `constexpr`, `consteval`, and `constinit` specifiers is allowed to appear in a *decl-specifier-seq*.
</Revision>

{/* source:cpp-language-declarations:0024 */}
- [storage class specifier](/docs/cpp/language/declarations/storage_duration) (<InlineRevision until="C++17">[`register`](/docs/cpp/language/keywords/register), </InlineRevision> [`static`](/docs/cpp/language/keywords/static), <InlineRevision since="C++11">[`thread_local`](/docs/cpp/language/keywords/thread_local), </InlineRevision> [`extern`](/docs/cpp/language/keywords/extern), [`mutable`](/docs/cpp/language/keywords/mutable)). Only one storage class specifier is allowed<InlineRevision since="C++11">, except that `thread_local` may appear together with `extern` or `static`</InlineRevision>.
- **Type specifiers** (*type-specifier-seq*), a sequence of specifiers that names a type. The type of every entity introduced by the declaration is this type, optionally modified by the declarator (see below). This sequence of specifiers is also used by [type-id](/docs/cpp/language/basic_concepts/type-id#Type_naming). Only the following specifiers are part of *type-specifier-seq*, in any order:

{/* source:cpp-language-declarations:0025 */}
- [class specifier](/docs/cpp/language/classes/class)
- [enum specifier](/docs/cpp/language/declarations/enum)
- simple type specifier
  - [`char`](/docs/cpp/language/keywords/char), <InlineRevision since="C++20">[`char8_t`](/docs/cpp/language/keywords/char8_t), </InlineRevision><InlineRevision since="C++11">[`char16_t`](/docs/cpp/language/keywords/char16_t), [`char32_t`](/docs/cpp/language/keywords/char32_t), </InlineRevision>[`wchar_t`](/docs/cpp/language/keywords/wchar_t), [`bool`](/docs/cpp/language/keywords/bool), [`short`](/docs/cpp/language/keywords/short), [`int`](/docs/cpp/language/keywords/int), [`long`](/docs/cpp/language/keywords/long), [`signed`](/docs/cpp/language/keywords/signed), [`unsigned`](/docs/cpp/language/keywords/unsigned), [`float`](/docs/cpp/language/keywords/float), [`double`](/docs/cpp/language/keywords/double), [`void`](/docs/cpp/language/keywords/void)

{/* source:cpp-language-declarations:0026 */}
<Revision since="C++11">
- [`auto`](/docs/cpp/language/declarations/auto)
- [decltype specifier](/docs/cpp/language/declarations/decltype)
</Revision>

<Revision since="C++26">
- [pack indexing specifier](/docs/cpp/language/templates/pack_indexing)
</Revision>

{/* source:cpp-language-declarations:0027 */}
- previously declared class name (optionally [qualified](/docs/cpp/language/basic_concepts/name#Qualified_identifiers))
- previously declared enum name (optionally [qualified](/docs/cpp/language/basic_concepts/name#Qualified_identifiers))
- previously declared [typedef-name](/docs/cpp/language/declarations/typedef)<InlineRevision since="C++11"> or [type alias](/docs/cpp/language/declarations/type_alias)</InlineRevision> (optionally [qualified](/docs/cpp/language/basic_concepts/name#Qualified_identifiers))
- template name with template arguments (optionally [qualified](/docs/cpp/language/basic_concepts/name#Qualified_identifiers), optionally using [template disambiguator](/docs/cpp/language/templates/dependent_name#template_disambiguator))

{/* source:cpp-language-declarations:0028 */}
<Revision since="C++17">
- template name without template arguments (optionally [qualified](/docs/cpp/language/basic_concepts/name#Qualified_identifiers)): see [class template argument deduction](/docs/cpp/language/templates/ctad)
</Revision>

{/* source:cpp-language-declarations:0029 */}
- [elaborated type specifier](/docs/cpp/language/declarations/elaborated_type_specifier)
  - the keyword [`class`](/docs/cpp/language/keywords/class), [`struct`](/docs/cpp/language/keywords/struct), or [`union`](/docs/cpp/language/keywords/union), followed by the identifier (optionally [qualified](/docs/cpp/language/basic_concepts/name#Qualified_identifiers)), previously defined as the name of a class.
  - the keyword [`class`](/docs/cpp/language/keywords/class), [`struct`](/docs/cpp/language/keywords/struct), or [`union`](/docs/cpp/language/keywords/union), followed by template name with template arguments (optionally [qualified](/docs/cpp/language/basic_concepts/name#Qualified_identifiers), optionally using [template disambiguator](/docs/cpp/language/templates/dependent_name)), previously defined as the name of a class template.
  - the keyword [`enum`](/docs/cpp/language/keywords/enum) followed by the identifier (optionally [qualified](/docs/cpp/language/basic_concepts/name#Qualified_identifiers)), previously declared as the name of an enumeration.
- [typename specifier](/docs/cpp/language/templates/dependent_name)
- [cv qualifier](/docs/cpp/language/declarations/cv)

only one type specifier is allowed in a *decl-specifier-seq*, with the following exceptions:

- `const` can be combined with any type specifier except itself.
- `volatile` can be combined with any type specifier except itself.
- `signed` or `unsigned` can be combined with `char`, `long`, `short`, or `int`.
- `short` or `long` can be combined with `int`.
- `long` can be combined with `double`.

{/* source:cpp-language-declarations:0030 */}
<Revision since="C++11">
- `long` can be combined with `long`.
</Revision>

{/* source:cpp-language-declarations:0031 */}
[Attributes](/docs/cpp/language/declarations/attributes) may appear in *decl-specifier-seq*, in which case they apply to the type determined by the preceding specifiers.

{/* source:cpp-language-declarations:0032 */}
Repetitions of any specifier in a *decl-specifier-seq*, such as `const static const`, or `virtual inline virtual` are errors<InlineRevision since="C++11">, except that `long` is allowed to appear twice</InlineRevision>.

## Declarators

{/* source:cpp-language-declarations:0033 */}
*init-declarator-list* is a comma-separated sequence of one or more *init-declarators*, which have the following syntax:

{/* source:cpp-language-declarations:0034 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="declarator initializer (optional)" />
  <Declaration id="2" language="cpp" since="C++20" grammar code="declarator requires-clause" />
</DeclarationDoc>

{/* source:cpp-language-declarations:0035 */}
<ParameterList>
  <Parameter name="declarator">the declarator</Parameter>
  <Parameter name="initializer">optional initializer (except where required, such as when initializing references or const objects). See [Initialization](/docs/cpp/language/initialization) for details.</Parameter>
  <Parameter name="requires-clause">[a requires-clause](/docs/cpp/language/templates/constraints#Requires_clauses), which adds a [constraint](/docs/cpp/language/templates/constraints) to a [function declaration](/docs/cpp/language/functions/function)</Parameter>
</ParameterList>

{/* source:cpp-language-declarations:0036 */}
Each *init-declarator* in an init-declarator sequence `S D1, D2, D3;` is processed as if it were a standalone declaration with the same specifiers: `S D1; S D2; S D3;`.

{/* source:cpp-language-declarations:0037 */}
Each declarator introduces exactly one object, reference, function, or (for typedef declarations) type alias, whose type is provided by *decl-specifier-seq* and optionally modified by operators such as `&` (reference to) or `[]` (array of) or `()` (function returning) in the declarator. These operators can be applied recursively, as shown below.

{/* source:cpp-language-declarations:0038 */}
A *declarator* is one of the following:

{/* source:cpp-language-declarations:0039 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="unqualified-id attr (optional)" />
  <Declaration id="2" language="cpp" grammar code="qualified-id attr (optional)" />
  <Declaration id="3" language="cpp" since="C++11" grammar code="... identifier attr (optional)" />
  <Declaration id="4" language="cpp" grammar code="* attr (optional) cv (optional) declarator" />
  <Declaration id="5" language="cpp" grammar code="nested-name-specifier * attr (optional) cv (optional) declarator" />
  <Declaration id="6" language="cpp" grammar code="& attr (optional) declarator" />
  <Declaration id="7" language="cpp" since="C++11" grammar code="&& attr (optional) declarator" />
  <Declaration id="8" language="cpp" grammar code="noptr-declarator [ constexpr (optional) ] attr (optional)" />
  <Declaration id="9" language="cpp" grammar code="noptr-declarator ( parameter-list ) cv (optional) ref (optional) except (optional) attr (optional)" />
</DeclarationDoc>

{/* source:cpp-language-declarations:0040 */}
1. The [name](/docs/cpp/language/basic_concepts/name) that is declared.
{/* source:cpp-language-declarations:0041 */}
2. A declarator that uses a [qualified identifier](/docs/cpp/language/basic_concepts/name#Qualified_identifiers) (*qualified-id*) defines or redeclares a previously declared [namespace member](/docs/cpp/language/declarations/namespace#Namespaces) or [class member](/docs/cpp/language/classes).
{/* source:cpp-language-declarations:0042 */}
3. [Parameter pack](/docs/cpp/language/templates/parameter_pack), only appears in [parameter declarations](/docs/cpp/language/functions/function#Parameter_list).
{/* source:cpp-language-declarations:0043 */}
4. [Pointer declarator](/docs/cpp/language/declarations/pointer): the declaration `S * D;` declares `D` as a pointer to the type determined by *decl-specifier-seq* `S`.
{/* source:cpp-language-declarations:0044 */}
5. [Pointer to member declaration](/docs/cpp/language/declarations/pointer): the declaration `S C::* D;` declares `D` as a pointer to member of `C` of type determined by *decl-specifier-seq* `S`. *nested-name-specifier* is a [sequence of names and scope resolution operators `::`](/docs/cpp/language/basic_concepts/name#Qualified_identifiers)
{/* source:cpp-language-declarations:0045 */}
6. [Lvalue reference declarator](/docs/cpp/language/declarations/reference): the declaration `S & D;` declares `D` as an lvalue reference to the type determined by *decl-specifier-seq* `S`.
{/* source:cpp-language-declarations:0046 */}
7. [Rvalue reference declarator](/docs/cpp/language/declarations/reference): the declaration `S && D;` declares `D` as an rvalue reference to the type determined by *decl-specifier-seq* `S`.
{/* source:cpp-language-declarations:0047 */}
8. [Array declarator](/docs/cpp/language/declarations/array). *noptr-declarator* any valid declarator, but if it begins with `*`, `&`, or `&&`, it has to be surrounded by parentheses.
{/* source:cpp-language-declarations:0048 */}
9. [Function declarator](/docs/cpp/language/functions/function). *noptr-declarator* any valid declarator, but if it begins with `*`, `&`, or `&&`, it has to be surrounded by parentheses. <InlineRevision since="C++11">It may end with the optional trailing return type.</InlineRevision>

{/* source:cpp-language-declarations:0049 */}
<Revision since="C++11">
In all cases, *attr* is an optional sequence of [attributes](/docs/cpp/language/declarations/attributes). When appearing immediately after the identifier, it applies to the object being declared.
</Revision>

{/* source:cpp-language-declarations:0050 */}
*cv* is a sequence of [const and volatile](/docs/cpp/language/declarations/cv) qualifiers, where either qualifier may appear at most once in the sequence.

## Notes

{/* source:cpp-language-declarations:0052 */}
When a *block-declaration* appears [inside a block](/docs/cpp/language/statements#Compound_statements), and an identifier introduced by a declaration was previously declared in an outer block, the [outer declaration is hidden](/docs/cpp/language/basic_concepts/scope) for the remainder of the block.

{/* source:cpp-language-declarations:0053 */}
If a declaration introduces a variable with automatic storage duration, it is initialized when its declaration statement is executed. All automatic variables declared in a block are destroyed on exit from the block (regardless how the block is exited: via [exception](/docs/cpp/language/exceptions), [goto](/docs/cpp/language/statements/goto), or by reaching its end), in order opposite to their order of initialization.

## Example

{/* source:cpp-language-declarations:0054 */}
Note: this example demonstrates how some complex declarations are parsed in terms of the language grammar. Other popular mnemonics are: [the spiral rule](https://c-faq.com/decl/spiral.anderson.html), reading [inside-out](https://stackoverflow.com/a/34560439/273767), and [declaration mirrors use](https://stackoverflow.com/a/34552915/273767). There is also an automated parser at [https://cdecl.org](https://cdecl.org).

```cpp
#include <type_traits>

struct S
{
    int member;
    // decl-specifier-seq is "int"
    // declarator is "member"
} obj, *pObj(&obj);
// decl-specifier-seq is "struct S { int member; }"
// declarator "obj" declares an object of type S
// declarator "*pObj" declares a pointer to S,
//     and initializer "(&obj)" initializes it

int i = 1, *p = nullptr, f(), (*pf)(double);
// decl-specifier-seq is "int"
// declarator "i" declares a variable of type int,
//     and initializer "= 1" initializes it
// declarator "*p" declares a variable of type int*,
//     and initializer "= nullptr" initializes it
// declarator "f()" declares (but doesn't define)
//     a function taking no arguments and returning int
// declarator "(*pf)(double)" declares a pointer to function
//     taking double and returning int

int (*(*var1)(double))[3] = nullptr;
// decl-specifier-seq is "int"
// declarator is "(*(*var1)(double))[3]"
// initializer is "= nullptr"

// 1. declarator "(*(*var1)(double))[3]" is an array declarator:
//    Type declared is: "(*(*var1)(double))" array of 3 elements
// 2. declarator "(*(*var1)(double))" is a pointer declarator:
//    Type declared is: "(*var1)(double)" pointer to array of 3 elements
// 3. declarator "(*var1)(double)" is a function declarator:
//    Type declared is: "(*var1)" function taking "(double)",
//    returning pointer to array of 3 elements.
// 4. declarator "(*var1)" is a pointer declarator:
//    Type declared is: "var1" pointer to function taking "(double)",
//    returning pointer to array of 3 elements.
// 5. declarator "var1" is an identifier.
// This declaration declares the object var1 of type "pointer to function
// taking double and returning pointer to array of 3 elements of type int"
// The initializer "= nullptr" provides the initial value of this pointer.

// C++11 alternative syntax:
auto (*var2)(double) -> int (*)[3] = nullptr;
// decl-specifier-seq is "auto"
// declarator is "(*var2)(double) -> int (*)[3]"
// initializer is "= nullptr"

// 1. declarator "(*var2)(double) -> int (*)[3]" is a function declarator:
//    Type declared is: "(*var2)" function taking "(double)", returning "int (*)[3]"
// ...

int main()
{
    static_assert(std::is_same_v<decltype(var1), decltype(var2)>);
}
```
