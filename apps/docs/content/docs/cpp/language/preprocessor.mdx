{/* source:cpp-preprocessor:0000 */}
The preprocessor is executed at [translation phase 4](/docs/cpp/language/basic_concepts/translation_phases#Phase_4), before the compilation. The result of preprocessing is a single file which is then passed to the actual compiler.

### Directives

{/* source:cpp-preprocessor:0001 */}
The preprocessing directives control the behavior of the preprocessor. Each directive occupies one line and has the following format:

{/* source:cpp-preprocessor:0002 */}
- the `#` character.
- a sequence of:

{/* source:cpp-preprocessor:0003 */}
  - a standard-defined directive name (listed [below](/docs/cpp/language/preprocessor#Capabilities)) followed by the corresponding arguments, or
  - one or more [preprocessing tokens](/docs/cpp/language/basic_concepts/translation_phases#Phase_3) where the beginning token is not a standard-defined directive name, in this case the directive is conditionally-supported with implementation-defined semantics <InlineRevision until="C++23">(e.g. a common non-standard extension is the directive `#warning` which emits a user-defined message during compilation)</InlineRevision>, or
  - nothing, in this case the directive has no effect.

{/* source:cpp-preprocessor:0004 */}
- a line break.

{/* source:cpp-preprocessor:0005 */}
<Revision since="C++20">
The [module and import directives](/docs/cpp/language/basic_concepts/modules) are also preprocessing directives.
</Revision>

{/* source:cpp-preprocessor:0006 */}
Preprocessing directives must not come from macro expansion.

{/* source:cpp-preprocessor:0007 */}
```cpp
#define EMPTY
EMPTY   #   include <file.h> // not a preprocessing directive
```

### Capabilities

{/* source:cpp-preprocessor:0008 */}
The preprocessor has the source file translation capabilities:

{/* source:cpp-preprocessor:0009 */}
- **[conditionally](/docs/cpp/language/preprocessor/conditional)** compile parts of source file (controlled by directive `#if`, `#ifdef`, `#ifndef`, `#else`, `#elif`<InlineRevision since="C++23">, `#elifdef`, `#elifndef`</InlineRevision>, and `#endif`).
- **[replace](/docs/cpp/language/preprocessor/replace)** text macros while possibly concatenating or quoting identifiers (controlled by directives `#define` and `#undef`, and operators `#` and `##`).
- **[include](/docs/cpp/language/preprocessor/include)** other files (controlled by directive `#include` <InlineRevision since="C++17">and checked with `__has_include`</InlineRevision>).
- cause an **[error](/docs/cpp/language/preprocessor/error)** <InlineRevision since="C++23">or [warning](/docs/cpp/language/preprocessor/error)</InlineRevision> (controlled by directive `#error`<InlineRevision since="C++23"> or `#warning` respectively</InlineRevision>).

{/* source:cpp-preprocessor:0010 */}
The following aspects of the preprocessor can be controlled:

{/* source:cpp-preprocessor:0011 */}
- **[implementation-defined](/docs/cpp/language/preprocessor/impl)** behavior (controlled by directive `#pragma` <InlineRevision since="C++11">and operator `_Pragma`</InlineRevision>). In addition, some compilers support (to varying degrees) the operator `__pragma` as a *non-standard* extension.
- **[file name and line information](/docs/cpp/language/preprocessor/line)** available to the preprocessor (controlled by directive `#line`).
