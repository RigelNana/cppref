{/* source:cpp-language-try:0000 */}
An [exception](/docs/cpp/language/exceptions) thrown in a `try` block can possibly be handled by an associated handler.

## Syntax

{/* source:cpp-language-try:0001 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="try compound-statement handler-seq" />
  <Declaration id="2" language="cpp" grammar code="try ctor-initializer (optional) compound-statement handler-seq" />
</DeclarationDoc>

{/* source:cpp-language-try:0002 */}
1. An [ordinary `try` block](/docs/cpp/language/exceptions/try#Ordinary_try_block).

{/* source:cpp-language-try:0003 */}
2. A [function `try` block](/docs/cpp/language/exceptions/try#Function_try_block). `compound-statement` must be the compound statement component of a function body.

{/* source:cpp-language-try:0004 */}
<ParameterList>
  <Parameter name="compound-statement">a [compound statement](/docs/cpp/language/statements#Compound_statements)</Parameter>
  <Parameter name="handler-seq">a non-empty sequence of [handlers](/docs/cpp/language/exceptions/catch)</Parameter>
  <Parameter name="ctor-initializer">member initializer list (for [constructors](/docs/cpp/language/classes/initializer_list#Member_initializer_list) only)</Parameter>
</ParameterList>

## Ordinary try block

{/* source:cpp-language-try:0005 */}
An ordinary `try` block is a [statement](/docs/cpp/language/statements).

{/* source:cpp-language-try:0006 */}
If an exception is thrown from its `compound-statement`, the exception will be matched against the [handlers](/docs/cpp/language/exceptions/catch) in its `handler-seq`:

{/* source:cpp-language-try:0007 */}
```cpp
void f()
{
    throw 1;     // NOT handled by the handler below
    try
    {
        throw 2; // handled by the associated handler
    }
    catch (...)
    {
        // handles the exception 2
    }
    throw 3;     // NOT handled by the handler above
}
```

## Function try block

{/* source:cpp-language-try:0008 */}
A function `try` block is a special kind of [function body](/docs/cpp/language/functions/function#Function_definition).

{/* source:cpp-language-try:0009 */}
If an exception is thrown from its `compound-statement` or `ctor-initializer` (if any), the exception will be matched against the [handlers](/docs/cpp/language/exceptions/catch) in its `handler-seq`:

{/* source:cpp-language-try:0010 */}
```cpp
int f(bool cond)
{
    if (cond)
        throw 1;
    return 0;
}

struct X
{
    int mem;

    X() try : mem(f(true)) {}
    catch (...)
    {
        // handles the exception 1
    }

    X(int) try
    {
        throw 2;
    }
    catch (...)
    {
        // handles the exception 2
    }
};
```

{/* source:cpp-language-try:0011 */}
Exceptions thrown in destructors of objects with static [storage duration](/docs/cpp/language/declarations/storage_duration) or in constructors of objects associated with [non-block variables](/docs/cpp/language/basic_concepts/scope#Block_scope) with static storage duration are not caught by a function `try` block on the [`main` function](/docs/cpp/language/basic_concepts/main_function).

{/* source:cpp-language-try:0012 */}
<Revision since="C++11">
Exceptions thrown in destructors of objects with thread storage duration or in constructors of objects associated with non-block variables with thread storage duration are not caught by a function `try` block on the initial function of the thread.
</Revision>

{/* source:cpp-language-try:0013 */}
Flowing off the end of the `compound-statement` of a [handler](/docs/cpp/language/exceptions/catch) of a function `try` block is equivalent to flowing off the end of the `compound-statement` of that function `try` block, unless the function is a constructor or destructor (see below).

### Constructor and destructor try block

{/* source:cpp-language-try:0014 */}
For a class `C`, if the function body of its constuctor or destructor definition is a function `try` block, and an exception is thrown during the initialization or destruction, respectively, of `C`’s subobjects, the exception will also be matched against the [handlers](/docs/cpp/language/exceptions/catch) in the `handler-seq` of the function `try` block:

{/* source:cpp-language-try:0015 */}
```cpp
int f(bool cond = true)
{
    if (cond)
        throw 1;
    return 0;
}

struct X
{
    int mem = f();

    ~X()
    {
        throw 2;
    }
};

struct Y
{
    X mem;

    Y() try {}
    catch (...)
    {
        // handles the exception 1
    }

    ~Y() try {}
    catch (...)
    {
        // handles the exception 2
    }
};
```

{/* source:cpp-language-try:0016 */}
Referring to any non-static member or base class of an object in the handler for a function `try` block of a constructor or destructor for that object results in undefined behavior.

{/* source:cpp-language-try:0017 */}
If a [`return` statement](/docs/cpp/language/statements/return) appears in a handler of the function `try` block of a constructor, the program is ill-formed.

{/* source:cpp-language-try:0018 */}
The [currently handled exception](/docs/cpp/language/exceptions/catch#Activating_the_handler) is rethrown if control reaches the end of a handler of the function `try` block of a constructor or destructor.

## Control flow

{/* source:cpp-language-try:0019 */}
The `compound-statement` of a `try` block is a [control-flow-limited statement](/docs/cpp/language/statements#Control-flow-limited_statements):

{/* source:cpp-language-try:0020 */}
```cpp
void f()
{
    goto label;     // error
    try
    {
        goto label; // OK
        label: ;
    }
    catch (...)
    {
        goto label; // error
    }
}
```

{/* source:cpp-language-try:0021 */}
A [jump statement](/docs/cpp/language/statements#Jump_statements) ([`goto`](/docs/cpp/language/statements/goto), [`break`](/docs/cpp/language/statements/break), [`return`](/docs/cpp/language/statements/return), [`continue`](/docs/cpp/language/statements/continue)) can be used to transfer control out of a `try` block (including its handlers). When this happens, each variable declared in the `try` block will be destroyed in the context that directly contains its declaration:

{/* source:cpp-language-try:0022 */}
```cpp
try
{
    T1 t1;
    try
    {
        T2 t2;
        goto label; // destroy t2 first, then t1
    }
    catch(...)
    {
        // executed if an exception is thrown while destroying t2
    }
}
catch(...)
{
    // executed if an exception is thrown while destroying t1
}
label: ;
```
