## Early C++

{/* source:cpp-language-history:0000 */}
- 1979: C with Classes first implemented

{/* source:cpp-language-history:0001 */}
1. New features: [classes](/docs/cpp/language/classes), [member functions](/docs/cpp/language/classes/member_functions), [derived classes](/docs/cpp/language/classes/derived_class), separate compilation, [public and private access control](/docs/cpp/language/classes/access), [friends](/docs/cpp/language/classes/friend), type checking of function arguments, [default arguments](/docs/cpp/language/functions/default_arguments), [inline functions](/docs/cpp/language/declarations/inline), [overloaded assignment operator](/docs/cpp/language/classes/as_operator), [constructors](/docs/cpp/language/classes/initializer_list), [destructors](/docs/cpp/language/classes/destructor), `f()` same as `f(void)`, call-function and return-function (synchronization features, not in C++)
2. Libraries: the concurrent task library (not in C++)

{/* source:cpp-language-history:0002 */}
- 1982: C with Classes reference manual published
- 1984: C84 implemented, reference manual published
- 1985: Cfront 1.0

{/* source:cpp-language-history:0003 */}
1. New features: [virtual functions](/docs/cpp/language/classes/virtual), function and [operator overloading](/docs/cpp/language/expressions/operators), [references](/docs/cpp/language/declarations/reference), [`new`](/docs/cpp/library/memory/new/operator_new) and [`delete`](/docs/cpp/library/memory/new/operator_delete) operators, [the keyword `const`](/docs/cpp/language/declarations/cv), scope resolution operator
2. Library additions: [complex number](/docs/cpp/library/numeric/complex), `string` (AT&T version), [I/O stream](/docs/cpp/library/headers/iostream)

{/* source:cpp-language-history:0004 */}
- 1985: The C++ Programming Language, 1st edition
- 1986: The "whatis?" paper documenting the remaining design goals, including multiple inheritance, exception handling, and templates.
- 1987: C++ support in GCC 1.15.3
- 1989: Cfront 2.0

{/* source:cpp-language-history:0005 */}
1. New features: [multiple inheritance](/docs/cpp/language/classes/derived_class), [pointers to members](/docs/cpp/language/declarations/pointer), [protected access](/docs/cpp/language/classes/access), type-safe linkage, [abstract classes](/docs/cpp/language/classes/abstract_class), [static](/docs/cpp/language/classes/static#Static_member_functions) and [const-qualified](/docs/cpp/language/classes/member_functions#const-_and_volatile-qualified_member_functions) member functions, class-specific [`new`](/docs/cpp/library/memory/new/operator_new#Class-specific_overloads) and [`delete`](/docs/cpp/library/memory/new/operator_delete#Class-specific_overloads)
2. Library additions: [I/O manipulators](/docs/cpp/library/io/manip)

{/* source:cpp-language-history:0006 */}
- 1990: The Annotated C++ Reference Manual

{/* source:cpp-language-history:0007 */}
This book described the language as designed, including some features that were not yet implemented. It served as the de-facto standard until the ISO.

{/* source:cpp-language-history:0008 */}
1. New features: [namespaces](/docs/cpp/language/declarations/namespace), [exception handling](/docs/cpp/language/exceptions), [nested classes](/docs/cpp/language/classes/nested_classes), [templates](/docs/cpp/language/templates)

{/* source:cpp-language-history:0009 */}
- 1991: Cfront 3.0
- 1991: The C++ Programming Language, 2nd edition

## Standard C++

{/* source:cpp-language-history:0010 */}
- 1990: ANSI C++ Committee founded
- 1991: ISO C++ Committee founded
- 1992: [STL](https://www.rrsd.com/software_development/stl/stl/) implemented in C++

## C++98/03 period

{/* source:cpp-language-history:0011 */}
- 1998: C++98 (ISO/IEC 14882:1998)

{/* source:cpp-language-history:0012 */}
1. New features: RTTI ([`dynamic_cast`](/docs/cpp/language/expressions/dynamic_cast), [`typeid`](/docs/cpp/language/expressions/typeid)), [covariant return types](/docs/cpp/language/classes/virtual#Covariant_return_types), [cast operators](/docs/cpp/language/expressions/cast_operator), [`mutable`](/docs/cpp/language/declarations/cv), [`bool`](/docs/cpp/language/basic_concepts/types#Boolean_type), declarations in conditions, [template instantiations](/docs/cpp/language/templates), [member templates](/docs/cpp/language/templates/member_template), export
2. Library additions: [locales](/docs/cpp/library/text/locale), [`bitset`](/docs/cpp/library/utility/bitset), [`valarray`](/docs/cpp/library/numeric/valarray), [`auto_ptr`](/docs/cpp/library/memory/auto_ptr), [templatized string](/docs/cpp/library/string/basic_string), [I/O streams](/docs/cpp/library/io), and [complex numbers](/docs/cpp/library/numeric/complex).
3. Based on STL: [containers](/docs/cpp/library/container), [algorithms](/docs/cpp/library/algorithm), [iterators](/docs/cpp/library/iterator), [function objects](/docs/cpp/library/utility/functional)

{/* source:cpp-language-history:0013 */}
- 1998: The C++ Programming Language, 3rd edition
- 1999: [Boost](https://www.boost.org) founded by the committee members to produce new high-quality candidate libraries for the standard.
- 2003: C++03 (ISO/IEC 14882:2003)

{/* source:cpp-language-history:0014 */}
This was a minor revision, intended to be little more than a technical corrigendum. This revision introduces the definition of [value initialization](/docs/cpp/language/initialization/value_initialization).

- 2006: Performance TR (ISO/IEC TR 18015:2006) ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=43351)) ([2006 draft](https://www.open-std.org/jtc1/sc22/wg21/docs/TR18015.pdf))

{/* source:cpp-language-history:0017 */}
This TR discussed the costs of various C++ abstractions, provided implementation guidance, discussed use of C++ in embedded systems and introduced \<hardware\> interface to C's ISO/IEC TR 18037:2008 \<iohw.h\>.

{/* source:cpp-language-history:0018 */}
- 2007: Library extension TR1 (ISO/IEC TR 19768:2007) ([ISO store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=43289)) ([2005 draft](https://wg21.link/n1745)).

{/* source:cpp-language-history:0019 */}
This TR is a C++ library extension, which adds the following to the C++ standard library:

{/* source:cpp-language-history:0020 */}
1. From Boost: [`reference_wrapper`](/docs/cpp/library/utility/functional/reference_wrapper), [Smart pointers](/docs/cpp/library/memory#Smart_pointers), [Member function](/docs/cpp/library/utility/functional/mem_fn), [`result_of`](/docs/cpp/library/meta/result_of), [`bind`](/docs/cpp/library/utility/functional/bind), [`function`](/docs/cpp/library/utility/functional/function), [Type Traits](/docs/cpp/library/utility/types), [Random](/docs/cpp/library/numeric/random), Mathematical Special Functions, [`tuple`](/docs/cpp/library/utility/tuple), [`array`](/docs/cpp/library/container/array), [Unordered Containers](/docs/cpp/library/container#Unordered_associative_containers) (including [`hash`](/docs/cpp/library/utility/hash)), and [Regular Expressions](/docs/cpp/library/text/regex).
2. From C99: mathematical functions from [\<math.h\>](/docs/c/library/numeric/math) that were new in C99, [blank character class](/docs/cpp/library/text/byte/isblank), [Floating-point environment](/docs/cpp/library/numeric/fenv), [`hexfloat`](/docs/cpp/library/io/manip/fixed) I/O Manipulator, [fixed-size integral types](/docs/cpp/library/utility/types/integer), the [`long long`](/docs/cpp/language/basic_concepts/types#Modifiers) type, [`va_copy`](/docs/cpp/library/utility/variadic/va_copy), the [`snprintf()`](/docs/cpp/library/io/c/snprintf) and [`vfscanf()`](/docs/cpp/library/io/c/vfscanf) families of functions, and the C99 conversion specifies for [`printf()`](/docs/cpp/library/io/c/printf) and [`scanf()`](/docs/cpp/library/io/c/scanf) families of functions.

{/* source:cpp-language-history:0021 */}
All of TR1 except for the special functions was included in C++11, with minor changes.

{/* source:cpp-language-history:0022 */}
- 2010: Mathematical special functions (ISO/IEC 29124:2010) ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=50511)) ([2010 draft](https://wg21.link/n3060))

{/* source:cpp-language-history:0023 */}
This international standard is a C++ standard library extension, which adds the special functions that were part of TR1, but were not included in C++11: elliptic integrals, exponential integral, Laguerre polynomials, Legendre polynomials, Hermite polynomials, Bessel functions, Neumann functions, beta function, and Riemann zeta function. This standard was [merged into C++17](/docs/cpp/library/numeric/special_functions).

## C++11 period

{/* source:cpp-language-history:0024 */}
- 2011: C++11 (ISO/IEC 14882:2011) ([ISO Store](https://www.iso.org/iso/iso_catalogue/catalogue_tc/catalogue_detail.htm?csnumber=50372)) ([2012 post-publication draft](https://wg21.link/n3337)).

{/* source:cpp-language-history:0025 */}
[Main Article: C++11](/docs/cpp/language/11)

{/* source:cpp-language-history:0026 */}
A large number of changes were introduced to both standardize existing practices and improve the abstractions available to the C++ programmers

{/* source:cpp-language-history:0027 */}
- 2011: Decimal floating-point TR (ISO/IEC TR 24733:2011) ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=38843)) ([2009 draft](https://wg21.link/n2849))

{/* source:cpp-language-history:0028 */}
This TR implements the decimal floating-point types from IEEE 754-2008 Standard for Floating-Point Arithmetic: `std::decimal::decimal32`, `std::decimal::decimal64`, and `std::decimal::decimal128`.

{/* source:cpp-language-history:0029 */}
- 2012: [The Standard C++ Foundation](https://isocpp.org) founded
- 2013: The C++ Programming Language, 4th edition

## C++14 period

{/* source:cpp-language-history:0030 */}
- 2014: C++14 ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=64029)) ([ANSI Store](https://webstore.ansi.org/RecordDetail.aspx?sku=INCITS%2fISO%2fIEC+14882%3a2014+(2016))) ([2014 final draft](https://github.com/cplusplus/draft/blob/master/papers/n4140.pdf?raw=true))

{/* source:cpp-language-history:0031 */}
[Main Article: C++14](/docs/cpp/language/14)

{/* source:cpp-language-history:0032 */}
Minor revision of the C++ standard

{/* source:cpp-language-history:0033 */}
- 2015: Filesystem library TS (ISO/IEC TS 18822:2015) ([ISO Store](https://www.iso.org/iso/catalogue_detail.htm?csnumber=63483)) ([2014 draft](https://wg21.link/n4100))

{/* source:cpp-language-history:0034 */}
This TS is an experimental C++ library extension that specifies a filesystem library based on boost.filesystem V3 (with some modifications and extensions). This TS was merged into C++17.

{/* source:cpp-language-history:0035 */}
- 2015: Extensions for Parallelism TS (ISO/IEC TS 19570:2015) ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=65241)) ([2015 draft](https://wg21.link/n4507))

{/* source:cpp-language-history:0036 */}
This TS standardizes parallel and vector-parallel API for all standard library algorithms, as well as adds new algorithms such as reduce, transform_reduce, or exclusive_scan. This TS was merged into C++17.

{/* source:cpp-language-history:0037 */}
- 2015: Extensions for Transactional Memory TS (ISO/IEC TS 19841:2015) ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=66343)) ([2015 draft](https://wg21.link/n4514))

{/* source:cpp-language-history:0038 */}
This TS extends the C++ core language with synchronized and atomic blocks, as well as transaction-safe functions, which implement transactional memory semantics.

{/* source:cpp-language-history:0039 */}
- 2015: Extensions for Library Fundamentals TS (ISO/IEC TS 19568:2015) ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=65238)) ([2015 draft](https://wg21.link/n4480))

{/* source:cpp-language-history:0040 */}
This TS adds several new components to the C++ standard library: [`optional`](/docs/cpp/library/experimental/memory/optional), [`any`](/docs/cpp/library/experimental/memory/any), [`string_view`](/docs/cpp/library/experimental/memory/basic_string_view), [`sample`](/docs/cpp/library/experimental/memory/sample), [`search`](/docs/cpp/library/experimental/memory/search), [`apply`](/docs/cpp/library/experimental/memory/apply), [polymorphic allocators](/docs/cpp/library/experimental/memory#Type-erased_and_polymorphic_allocators), and [variable templates](/docs/cpp/library/experimental/memory) for type traits. This TS was merged into C++17.

{/* source:cpp-language-history:0041 */}
- 2015: Extensions for Concepts TS (ISO/IEC TS 19217:2015) ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=64031)) ([2015 draft](https://wg21.link/n4553))

{/* source:cpp-language-history:0042 */}
This TS extends the C++ core language with concepts (named type requirements) and constraints (limits on the types allowed in template, function, and variable declarations), which aids metaprogramming and simplifies template instantiation diagnostics, see [concepts](/docs/cpp/library/experimental/constraints). This TS was merged into C++20, with some omissions.

{/* source:cpp-language-history:0043 */}
- 2016: Extensions for Concurrency TS (ISO/IEC TS 19571:2016) ([ISO Store](https://www.iso.org/iso/home/store/catalogue_tc/catalogue_detail.htm?csnumber=65242)) ([2015 draft](https://wg21.link/p0159r0))

{/* source:cpp-language-history:0044 */}
This TS extends the C++ library to include [several extensions](/docs/cpp/library/experimental/concurrency) to [`std::future`](/docs/cpp/library/atomic/future), [`latches`](/docs/cpp/library/atomic/latch) and [`barriers`](/docs/cpp/library/atomic/barrier), and atomic smart pointers.

## C++17 period

{/* source:cpp-language-history:0045 */}
- 2017: C++17 ([ISO Store](https://www.iso.org/standard/68564.html)) ([ANSI Store](https://webstore.ansi.org/RecordDetail.aspx?sku=INCITS%2fISO%2fIEC+14882%3a2017+(2018))) ([n4659 2017-03-21 final draft](https://wg21.link/n4659))

{/* source:cpp-language-history:0046 */}
[Main Article: C++17](/docs/cpp/language/17)

{/* source:cpp-language-history:0047 */}
The major revision of the C++ standard after C++11

{/* source:cpp-language-history:0048 */}
- 2017: Extensions for Ranges TS (ISO/IEC TS 21425:2017) ([ISO Store](https://www.iso.org/standard/70910.html)) ([2017 draft](https://wg21.link/n4685))

{/* source:cpp-language-history:0049 */}
This TS extends the C++ library to include [ranges](/docs/cpp/library/experimental/ranges), a new, more powerful, abstraction to replace iterator pairs, along with range views, sentinel ranges, projections for on-the-fly transformations, new iterator adaptors and algorithms. This extension finally makes it possible to sort a vector with `sort(v);`

{/* source:cpp-language-history:0050 */}
- 2017: Extensions for Coroutines TS (ISO/IEC TS 22277:2017) ([ISO Store](https://www.iso.org/standard/73008.html)) ([2017 draft](https://wg21.link/n4680))

{/* source:cpp-language-history:0051 */}
This TS extends the C++ core language and the standard library to include stackless coroutines (resumable functions). This adds the keywords [`co_await`](/docs/cpp/language/keywords/co_await), [`co_yield`](/docs/cpp/language/keywords/co_yield), and [`co_return`](/docs/cpp/language/keywords/co_return).

{/* source:cpp-language-history:0052 */}
- 2018: Extensions for Networking TS (ISO/IEC TS 19216:2018) ([ISO Store](https://www.iso.org/standard/64030.html)) ([2017 draft](https://wg21.link/n4734))

{/* source:cpp-language-history:0053 */}
This TS extends the C++ library to include TCP/IP networking based on [boost.asio](https://www.boost.org/doc/libs/1_67_0/doc/html/boost_asio.html).

{/* source:cpp-language-history:0054 */}
- 2018: Extensions for modules TS (ISO/IEC TS 21544:2018) ([ISO Store](https://www.iso.org/standard/71051.html)) ([2018 draft](https://wg21.link/n4720))

{/* source:cpp-language-history:0055 */}
This TS extends the C++ core language to include modules. This adds the special identifiers [`module`](/docs/cpp/language/keywords/module), [`import`](/docs/cpp/language/keywords/import), and reintroduces the keyword [`export`](/docs/cpp/language/keywords/export) with a new meaning.

{/* source:cpp-language-history:0056 */}
- 2018: Extensions for Parallelism version 2 TS (ISO/IEC TS 19570:2018) ([ISO Store](https://www.iso.org/standard/70588.html)) ([2018 draft](https://wg21.link/n4773))

{/* source:cpp-language-history:0057 */}
This TS extends the C++ library to include two new execution policies (`unseq` and `vec`), additional parallel algorithms such as `reduction_plus` or `for_loop_strided`, task blocks for forking and joining parallel tasks, SIMD types and operations on those types.
