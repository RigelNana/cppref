C++14 is a minor version after the major version C++11, featuring mainly minor improvements and defect fixes. Its approval was announced on August 18, 2014. It was released on December 15, 2014.

{/* source:cpp-14:0001 */}
Before its approval, C++1y is sometimes used to indicate its release in 2010s.

{/* source:cpp-14:0002 */}
This section is incomplete

## New language features

{/* source:cpp-14:0003 */}
- [variable templates](/docs/cpp/language/templates/variable_template)
- [generic lambdas](/docs/cpp/language/functions/lambda)
- lambda init-capture
- new/delete elision
- [relaxed restrictions on constexpr functions](/docs/cpp/language/declarations/constexpr)
- [binary literals](/docs/cpp/language/expressions/integer_literal)
- [digit separators](/docs/cpp/language/expressions/integer_literal#Single_quote)
- [return type deduction for functions](/docs/cpp/language/functions/function#Return_type_deduction_.28since_C.2B.2B14.29)
- [aggregate classes](/docs/cpp/language/initialization/aggregate_initialization) with default non-static member initializers.

## New library features

{/* source:cpp-14:0004 */}
- [std::make_unique](/docs/cpp/library/memory/unique_ptr/make_unique)
- [std::shared_timed_mutex](/docs/cpp/library/thread/shared_timed_mutex) and [std::shared_lock](/docs/cpp/library/thread/shared_lock)
- [std::integer_sequence](/docs/cpp/library/meta/integer_sequence)
- [std::exchange](/docs/cpp/library/utility/exchange)
- [std::quoted](/docs/cpp/library/io/manip/quoted)
- and many small improvements to existing library facilities, such as
  - two-range overloads for some algorithms
  - type alias versions of type traits
  - user-defined literals for [`basic_string`](/docs/cpp/library/string/basic_string), [`duration`](/docs/cpp/library/chrono/duration) and [`complex`](/docs/cpp/library/numeric/complex)
  - etc.
