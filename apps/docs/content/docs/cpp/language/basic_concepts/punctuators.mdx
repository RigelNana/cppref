These are the punctuation symbols in C++. The meaning of each symbol is detailed in the linked pages.

## Preprocessing operators

{/* source:cpp-language-punctuators:0001 */}
Preprocessing operators are recognized by [preprocessors](/docs/cpp/language/preprocessor).

### # (including % :)

{/* source:cpp-language-punctuators:0002 */}
- Introduce a [preprocessing directive](/docs/cpp/language/preprocessor).
- The [preprocessing operator for stringification](/docs/cpp/language/preprocessor/replace#.23_and_.23.23_operators).

### ##(including % : % :)

{/* source:cpp-language-punctuators:0003 */}
- The [preprocessing operator for token pasting](/docs/cpp/language/preprocessor/replace#.23_and_.23.23_operators).

## Single-character operators and punctuators

### { and } (including `< % and % >`)

{/* source:cpp-language-punctuators:0004 */}
- In a [class](/docs/cpp/language/classes/class) definition, delimit the [member specification](/docs/cpp/language/classes/class#Member_specification).
- In an [enumeration](/docs/cpp/language/declarations/enum) definition, delimit the enumerator list.
- Delimit a [compound statement](/docs/cpp/language/statements#Compound_statements). The compound statement may be part of

  {/* source:cpp-language-punctuators:0005 */}
  - a [function definition](/docs/cpp/language/functions/function#Function_definition)
  - a [`try` block](/docs/cpp/language/exceptions/try)

  {/* source:cpp-language-punctuators:0006 */}
  <Revision since="C++11">
  - a [lambda expression](/docs/cpp/language/functions/lambda)
  </Revision>

{/* source:cpp-language-punctuators:0007 */}
- Part of the <InlineRevision until="C++11">[aggregate initialization](/docs/cpp/language/initialization/aggregate_initialization)</InlineRevision><InlineRevision since="C++11">[list-initialization](/docs/cpp/language/initialization/list_initialization)</InlineRevision> syntax of an [initializer](/docs/cpp/language/initialization).
- In a [namespace definition](/docs/cpp/language/declarations/namespace), delimit the namespace body.
- In a [language linkage specification](/docs/cpp/language/declarations/language_linkage), delimit the declarations.

{/* source:cpp-language-punctuators:0008 */}
<Revision since="C++20">
- In a [`requires` expression](/docs/cpp/language/templates/constraints#Requires_expressions), delimit the requirements.
- In a [compound requirement](/docs/cpp/language/templates/constraints#Compound_Requirements), delimit the expression.
- In an [export declaration](/docs/cpp/language/basic_concepts/modules), delimit the declarations.
</Revision>

### [ and ] (including `< : and : >`)

{/* source:cpp-language-punctuators:0009 */}
- [Subscript operator](/docs/cpp/language/expressions/operator_member_access#Built-in_subscript_operator); part of `operator[]` in [operator overloading](/docs/cpp/language/expressions/operators#Array_subscript_operator).
- Part of [array declarator](/docs/cpp/language/declarations#Declarators) in a [declaration](/docs/cpp/language/declarations) or a [type-id](/docs/cpp/language/basic_concepts/type-id#Type_naming) (e.g. in a [`new` expression](/docs/cpp/language/expressions/new)).
- Part of `new[]` operator in [operator overloading (allocation function)](/docs/cpp/library/memory/new/operator_new).
- Part of `delete[]` operator in [delete expression](/docs/cpp/language/expressions/delete) and [operator overloading (deallocation function)](/docs/cpp/library/memory/new/operator_delete).

{/* source:cpp-language-punctuators:0010 */}
<Revision since="C++11">
- In a [lambda expression](/docs/cpp/language/functions/lambda), delimit the [captures](/docs/cpp/language/functions/lambda#Lambda_capture).
- In an [attribute specifier](/docs/cpp/language/declarations/attributes), delimit the attributes.
</Revision>

<Revision since="C++17">
- In a [structured binding declaration](/docs/cpp/language/declarations/structured_binding), delimit the identifier list.
</Revision>

<Revision since="C++26">
- In a [pack indexing](/docs/cpp/language/templates/pack_indexing), delimit [converted constant expression](/docs/cpp/language/expressions/constant_expression) representing an index.
</Revision>

- In a [`new` expression](/docs/cpp/language/expressions/new), delimit the initializers.
- In a [C-style cast](/docs/cpp/language/expressions/explicit_cast), delimit the type-id.
- In a [declaration](/docs/cpp/language/declarations) or a [type-id](/docs/cpp/language/basic_concepts/type-id#Type_naming), indicate grouping.
- Delimit the parameter list in

  {/* source:cpp-language-punctuators:0015 */}
  - a [function declarator](/docs/cpp/language/functions/function) (in a [declaration](/docs/cpp/language/declarations) or a [type-id](/docs/cpp/language/basic_concepts/type-id#Type_naming))

  {/* source:cpp-language-punctuators:0016 */}
  <Revision since="C++11">
  - a [lambda expression](/docs/cpp/language/functions/lambda)
  </Revision>
  <Revision since="C++17">
  - a [user-defined deduction guide](/docs/cpp/language/templates/ctad)
  </Revision>
  <Revision since="C++20">
  - a [`requires` expression](/docs/cpp/language/templates/constraints#Requires_expressions)
  </Revision>

{/* source:cpp-language-punctuators:0017 */}
- Part of the [direct-initialization](/docs/cpp/language/initialization/direct_initialization) syntax of an [initializer](/docs/cpp/language/initialization).
- In an [asm declaration](/docs/cpp/language/declarations/asm), delimit the string literal.
- In a [member initializer list](/docs/cpp/language/classes/initializer_list), delimit the initializers to a base or member.
- Delimit the controlling clause of a selection statement or iteration statement, including:

  {/* source:cpp-language-punctuators:0018 */}
  - [`if`](/docs/cpp/language/statements/if)<InlineRevision since="C++23"> (except [consteval if](/docs/cpp/language/statements/if#Consteval_if))</InlineRevision>
  - [`switch`](/docs/cpp/language/statements/switch)
  - [`while`](/docs/cpp/language/statements/while)
  - [`do-while`](/docs/cpp/language/statements/do)
  - [`for`](/docs/cpp/language/statements/for)

  {/* source:cpp-language-punctuators:0019 */}
  <Revision since="C++11">
  - [range-based `for`](/docs/cpp/language/statements/range-for)
  </Revision>

{/* source:cpp-language-punctuators:0020 */}
- In a [handler](/docs/cpp/language/exceptions/catch), delimit the parameter declaration.
- In a [function-like macro definition](/docs/cpp/language/preprocessor/replace#Function-like_macros), delimit the macro parameters.
- In a [function-like macro invocation](/docs/cpp/language/preprocessor/replace#Function-like_macros), delimit the macro arguments or prevent commas from being interpreted as argument separators.
- Part of a `defined`<InlineRevision since="C++17">, `__has_include`</InlineRevision><InlineRevision since="C++20">, `__has_cpp_attribute`</InlineRevision> preprocessing operator.

{/* source:cpp-language-punctuators:0021 */}
<Revision since="C++11">
- In a [`static_assert`](/docs/cpp/language/declarations/static_assert) declaration, delimit the operands.

  - <Revision since="C++20">[`explicit`](/docs/cpp/language/classes/explicit)</Revision>

<Revision since="C++14">
- Part of [`decltype(auto)`](/docs/cpp/language/declarations/decltype) specifier.

<Revision since="C++17">

### ;

{/* source:cpp-language-punctuators:0022 */}
- Indicate the end of

  {/* source:cpp-language-punctuators:0023 */}
  - a [statement](/docs/cpp/language/statements)
  - a [declaration](/docs/cpp/language/declarations) or [member declaration](/docs/cpp/language/classes/class#Member_specification)

  {/* source:cpp-language-punctuators:0024 */}
  <Revision since="C++20">
  - a [module declaration](/docs/cpp/language/basic_concepts/modules), import declaration, global module fragment introducer, or private module fragment introducer
  - a [requirement](/docs/cpp/language/templates/constraints#Requires_expressions)
  </Revision>

{/* source:cpp-language-punctuators:0025 */}
- Separate the *condition* and *statement* of a [`for` statement](/docs/cpp/language/statements/for).

### :

{/* source:cpp-language-punctuators:0026 */}
- Part of [conditional operator](/docs/cpp/language/expressions/operator_other#Conditional_operator).
- Part of [label declaration](/docs/cpp/language/statements#Labels).
- In the *base-clause* of a [class definition](/docs/cpp/language/classes/class), introduce the [base class](/docs/cpp/language/classes/derived_class).
- Part of [access specifier](/docs/cpp/language/classes/access) in member specification.
- In a [bit-field member declaration](/docs/cpp/language/classes/bit_field), introduce the width.
- In a [constructor](/docs/cpp/language/classes/initializer_list) definition, introduce the member initializer list.

{/* source:cpp-language-punctuators:0027 */}
<Revision since="C++11">
- In a [range-based `for`](/docs/cpp/language/statements/range-for) statement, separate the *item-declaration* and the *range-initializer*.
- In the *enum-base* of an [enumeration declaration](/docs/cpp/language/declarations/enum), introduce the underlying type.
</Revision>

<Revision since="C++17">
- In an [attribute specifier](/docs/cpp/language/declarations/attributes), separate the *attribute-namespace* and the *attribute-list*.
</Revision>

<Revision since="C++20">
- In a [module declaration](/docs/cpp/language/basic_concepts/modules) or import declaration of module partition, introduce the module partition name.
- Part of a [private module fragment](/docs/cpp/language/basic_concepts/modules#Private_module_fragment) introducer (`module :private;`).
</Revision>
