{/* source:cpp-language-lookup:0000 */}
Name lookup is the procedure by which a [`name`](/docs/cpp/language/basic_concepts/name), when encountered in a program, is associated with the [`declaration`](/docs/cpp/language/declarations) that introduced it.

{/* source:cpp-language-lookup:0001 */}
For example, to compile `std::cout << std::endl;`, the compiler performs:

{/* source:cpp-language-lookup:0002 */}
- unqualified name lookup for the name `std`, which finds the declaration of namespace `std` in the header [`<iostream>`](/docs/cpp/library/headers/iostream)
- qualified name lookup for the name `cout`, which finds a variable declaration in the namespace `std`
- qualified name lookup for the name `endl`, which finds a function template declaration in the namespace `std`
- both [`argument-dependent lookup`](/docs/cpp/language/functions/adl) for the name `operator<<`, which finds multiple function template declarations in the namespace `std`, and qualified name lookup for the name `std::ostream::operator<<`, which finds multiple member function declarations in class [`std::ostream`](/docs/cpp/library/io/basic_ostream).

{/* source:cpp-language-lookup:0003 */}
For function and function template names, name lookup can associate multiple declarations with the same name, and may obtain additional declarations from [`argument-dependent lookup`](/docs/cpp/language/functions/adl). [`Template argument deduction`](/docs/cpp/language/templates/function_template) may also apply, and the set of declarations is passed to [`overload resolution`](/docs/cpp/language/functions/overload_resolution), which selects the declaration that will be used. [`Member access`](/docs/cpp/language/classes/access) rules, if applicable, are considered only after name lookup and overload resolution.

{/* source:cpp-language-lookup:0004 */}
For all other names (variables, namespaces, classes, etc), name lookup can associate multiple declarations only if they declare the same [`entity`](/docs/cpp/language/basic_concepts), otherwise it must produce a single declaration in order for the program to compile. Lookup for a name in a scope finds all declarations of that name, with one exception, known as the "struct hack" or "type/non-type hiding": Within the same scope, some occurrences of a name may refer to a declaration of a class/struct/union/enum that is not a `typedef`, while all other occurrences of the same name either all refer to the same variable, non-static data member, or enumerator, or they all refer to possibly overloaded function or function template names. In this case, there is no error, but the type name is hidden from lookup (the code must use [`elaborated type specifier`](/docs/cpp/language/declarations/elaborated_type_specifier) to access it).

## Types of lookup

{/* source:cpp-language-lookup:0005 */}
If the name appears immediately to the right of the scope resolution operator `::` or possibly after `::` followed by the disambiguating keyword `template`, see

{/* source:cpp-language-lookup:0006 */}
- [Qualified name lookup](/docs/cpp/language/basic_concepts/qualified_lookup)

{/* source:cpp-language-lookup:0007 */}
Otherwise, see

{/* source:cpp-language-lookup:0008 */}
- [Unqualified name lookup](/docs/cpp/language/basic_concepts/unqualified_lookup)

{/* source:cpp-language-lookup:0009 */}
(which, for function names, includes [Argument-dependent lookup](/docs/cpp/language/functions/adl))
