{/* source:cpp-language-scope:0000 */}
Each [declaration](/docs/cpp/language/declarations) that appears in a C++ program is only visible in some possibly discontiguous scopes.

{/* source:cpp-language-scope:0001 */}
Within a scope, [unqualified name lookup](/docs/cpp/language/basic_concepts/lookup) can be used to associate a name with its declaration.

## General

{/* source:cpp-language-scope:0002 */}
Each program has a *global scope*, which *contains* the entire program.

{/* source:cpp-language-scope:0003 */}
Every other scope `S` is introduced by

{/* source:cpp-language-scope:0004 */}
- a [declaration](/docs/cpp/language/declarations),
- a parameter in [parameter list](/docs/cpp/language/functions/function#Parameter_list),
- a [statement](/docs/cpp/language/statements), or
- a [handler](/docs/cpp/language/exceptions/catch).

{/* source:cpp-language-scope:0005 */}
`S` always appear in another scope, which thereby *contains* `S`.

{/* source:cpp-language-scope:0006 */}
An *enclosing scope* at a program point is any scope that contains it; the smallest such scope is said to be the *immediate scope* at that point.

{/* source:cpp-language-scope:0007 */}
A scope *intervenes* between a program point `P` and a scope `S` (that does not contain `P`) if it is or contains `S` but does not contain `P`.

{/* source:cpp-language-scope:0008 */}
The *parent scope* of any scope `S` that is not a [template parameter scope](/docs/cpp/language/basic_concepts/scope#Template_parameter_scope) is the smallest scope that contains `S` and is not a template parameter scope.

{/* source:cpp-language-scope:0009 */}
Unless otherwise specified:

{/* source:cpp-language-scope:0010 */}
- A declaration *inhabits* the immediate scope at its [locus](/docs/cpp/language/basic_concepts/scope#Point_of_declaration).
- A declaration's *target scope* is the scope it inhabits.
- Any names (re)introduced by a declaration are *bound* to it in its target scope.

{/* source:cpp-language-scope:0011 */}
An entity belongs to a scope `S` if `S` is the target scope of a declaration of the entity.

{/* source:cpp-language-scope:0012 */}
```cpp
//                global  scope  scope
//                scope     S      T
int x;         //   ─┐                 // program point X
               //    │
{              //    │     ─┐
    {          //    │      │     ─┐
        int y; //    │      │      │   // program point Y
    }          //    │      │     ─┘
}              //   ─┘     ─┘
```

{/* source:cpp-language-scope:0013 */}
In the program above:

{/* source:cpp-language-scope:0014 */}
- The global scope, scope `S` and scope `T` contains program point `Y`.

{/* source:cpp-language-scope:0015 */}
  - In other words, these three scopes are all enclosing scopes at program point `Y`.

{/* source:cpp-language-scope:0016 */}
- The global scope contains scopes `S` and `T`, and scope `S` contains scope `T`.

{/* source:cpp-language-scope:0017 */}
  - Therefore, scope `T` is the smallest scope among all three, which means:
    - Scope `T` is the immediate scope at program point `Y`.
    - The declaration of the variable `y` inhabits scope `T` at its locus.
    - Scope `T` is the target scope of the declaration of `y`.
    - The variable `y` belongs to scope `T`.
  - Scope `S` is the parent scope of scope `T`, and the global scope is the parent scope of scope `S`.

{/* source:cpp-language-scope:0018 */}
- Scope `S` intervenes between program point `X` and scope `T`.

## Block scope

{/* source:cpp-language-scope:0019 */}
Each

{/* source:cpp-language-scope:0020 */}
- [selection statement](/docs/cpp/language/statements#Selection_statements) ([`if`](/docs/cpp/language/statements/if), [`switch`](/docs/cpp/language/statements/switch)),
- [iteration statement](/docs/cpp/language/statements#Iteration_statements) ([`for`](/docs/cpp/language/statements/for)<InlineRevision since="C++11">, [range-`for`](/docs/cpp/language/statements/range-for)</InlineRevision>, [`while`](/docs/cpp/language/statements/while), [`do`-`while`](/docs/cpp/language/statements/do)),
- [handler](/docs/cpp/language/exceptions/catch), or
- [compound statement](/docs/cpp/language/statements#Compound_statements) that is not the compound-statement of a handler

{/* source:cpp-language-scope:0021 */}
introduces a *block scope* that includes the statement or handler.

{/* source:cpp-language-scope:0022 */}
A variable that belongs to a block scope is a *block variable*.

{/* source:cpp-language-scope:0023 */}
```cpp
int i = 42;
int a[10];

for (int i = 0; i < 10; i++) // inner “i” inhabits the block scope
    a[i] = i;                // introduced by the for-statement

int j = i; // j = 42
```

{/* source:cpp-language-scope:0024 */}
Block-scope `extern` declarations target a larger enclosing scope, but bind a name in their immediate scope.

{/* source:cpp-language-scope:0025 */}
If a declaration<InlineRevision since="C++26"> that is not a [name-independent declaration](/docs/cpp/language/declarations/conflicting_declarations#Potentially-conflict_declarations) and</InlineRevision> that binds a name in the block scope `S` of

{/* source:cpp-language-scope:0026 */}
- the *compound-statement* of a [function body](/docs/cpp/language/functions/function#Function_definition) or [function `try` block](/docs/cpp/language/exceptions/try#Function_try_block),

{/* source:cpp-language-scope:0027 */}
- <Revision since="C++11">the compund statement `{` *body* `}` of a [lambda expression](/docs/cpp/language/functions/lambda),</Revision>

{/* source:cpp-language-scope:0028 */}
- a substatement of a selection or iteration statement that is not itself a selection or iteration statement, or
- a handler of a function `try` block

{/* source:cpp-language-scope:0029 */}
[potentially conflicts](/docs/cpp/language/declarations/conflicting_declarations#Potentially-conflict_declarations) with a declaration whose target scope is the parent scope of `S`, the program is ill-formed.

{/* source:cpp-language-scope:0030 */}
```cpp
if (int x = f())  // declares “x”
{ // the if-block is a substatement of the if-statement
    int x;        // error: redeclaration of “x”
}
else
{ // the else-block is also a substatement of the if-statement
    int x;        // error: redeclaration of “x”
}

void g(int i)
{
    extern int i; // error: redeclaration of “i”
}
```

## Function parameter scope

{/* source:cpp-language-scope:0031 */}
Each [parameter declaration](/docs/cpp/language/functions/function#Parameter_list) `P` introduces a *function parameter scope* that includes `P`.

{/* source:cpp-language-scope:0032 */}
- If the declared parameter is of the parameter list of a [function declaration](/docs/cpp/language/functions/function):

{/* source:cpp-language-scope:0033 */}
  - If the function declaration is a [function definition](/docs/cpp/language/functions/function#Function_definition), the scope introduced is extended to the end of the function definition. Otherwise (the function declaration is a function prototype), the scope introduced is extended to the end of the function declarator. In both cases, the scope does not include the [locus](/docs/cpp/language/basic_concepts/scope#Point_of_declaration) of the function declaration.

{/* source:cpp-language-scope:0034 */}
  - <Revision since="C++11">If the declared parameter is of the parameter list of a [lambda expression](/docs/cpp/language/functions/lambda), the scope introduced is extended to the end of `{` *body* `}`.</Revision>
  - <Revision since="C++17">If the declared parameter is of the parameter list of a [deduction guide](/docs/cpp/language/templates/deduction_guide), the scope introduced is extended to the end of that deduction guide.</Revision>
  - <Revision since="C++20">If the declared parameter is of the parameter list of a [`requires` expression](/docs/cpp/language/templates/requires), the scope introduced is extended to the end of `{` *requirement-seq* `}`.</Revision>

{/* source:cpp-language-scope:0035 */}
```cpp
int f(int n) // the declaration of the parameter “n”
{            // introduces a function parameter scope
    /* ... */
}            // the function parameter scope ends here
```

{/* source:cpp-language-scope:0036 */}
## Lambda scope

<Revision since="C++14">
Each [lambda expression](/docs/cpp/language/functions/lambda) introduces a *lambda scope* that starts immediately after `[` *captures* `]` and extends to the end of `{` *body* `}`.

The [captures](/docs/cpp/language/functions/lambda#Lambda_captures) with initializers of a lambda expression `E` inhabit the lambda scope introduced by `E`.

```cpp
auto lambda = [x = 1, y]() // this lambda expression introduces a lambda scope,
{                          // it is the target scope of capture “x”
    /* ... */
};                         // the lambda scope ends before the semicolon
```
</Revision>

## Namespace scope

{/* source:cpp-language-scope:0037 */}
Every [namespace definition](/docs/cpp/language/declarations/namespace) for a namespace `N` introduces a namespace scope `S` that includes the declarations for every namespace definition for `N`.

{/* source:cpp-language-scope:0038 */}
For each non-friend redeclaration or specialization whose target scope is `S` or is contained by `S`, the following portions are also included in scope `S`:

{/* source:cpp-language-scope:0039 */}
- For a [class](/docs/cpp/language/classes/class) (template) redeclaration or class template specialization, the portion after its *class-head-name*.
- For a [enumeration](/docs/cpp/language/declarations/enum) redeclaration, the portion after its *enum-head-name*.
- For any other redeclaration or specialization, the portion after the *unqualified-id* or *qualified-id* of the [declarator](/docs/cpp/language/declarations#Declarators).

{/* source:cpp-language-scope:0040 */}
The [global scope](/docs/cpp/language/basic_concepts/scope#General) is the namespace scope of the [global namespace](/docs/cpp/language/declarations/namespace).

{/* source:cpp-language-scope:0041 */}
```cpp
namespace V   // the namespace definition of “V”
{             // introduces a namespace scope “S”
    // the first part of scope “S” begins here
    void f();
    // the first part of scope “S” ends here
}

void V::f()   // the portion after “f” is also a part of scope “S”
{
    void h(); // declares V::h
}             // the second part of scope “S” ends here
```

## Class scope

{/* source:cpp-language-scope:0042 */}
Each declaration of a class or class template `C` introduces a class scope `S` that includes the member-specification of the [class definition](/docs/cpp/language/classes/class) of `C`.

{/* source:cpp-language-scope:0043 */}
For each non-friend redeclaration or specialization whose target scope is `S` or is contained by `S`, the following portions are also included in scope `S`:

{/* source:cpp-language-scope:0044 */}
- For a [class](/docs/cpp/language/classes/class) (template) redeclaration or class template specialization, the portion after its *class-head-name*.
- For a [enumeration](/docs/cpp/language/declarations/enum) redeclaration, the portion after its *enum-head-name*.
- For any other redeclaration or specialization, the portion after the *unqualified-id* or *qualified-id* of the [declarator](/docs/cpp/language/declarations#Declarators).

{/* source:cpp-language-scope:0045 */}
```cpp
class C       // the class definition of “C”
{             // introduces a class scope “S”
    // the first part of scope “S” begins here
    void f();
    // the first part of scope “S” ends here
}

void C::f()   // the portion after “f” is also a part of scope “S”
{
    /* ... */
}             // the second part of scope “S” ends here
```

## Enumeration scope

{/* source:cpp-language-scope:0046 */}
Each declaration of an enumeration `E` introduces an *enumeration scope* that includes the *enumerator-list* of the<InlineRevision since="C++11"> non-opaque</InlineRevision> [enumeration declaration](/docs/cpp/language/declarations/enum) of `E` (if present).

{/* source:cpp-language-scope:0047 */}
```cpp
enum class E // the enumeration declaration of “E”
{            // introduces an enumeration scope “S”
    // scope “S” begins here
    e1, e2, e3
    // scope “S” ends here
}
```

## Template parameter scope

{/* source:cpp-language-scope:0048 */}
Each [template template parameter](/docs/cpp/language/templates/template_parameters#Template_template_parameter) introduces a *template parameter scope* that includes the entire template parameter list<InlineRevision since="C++20"> and the [`require` clauses](/docs/cpp/language/templates/constraints#Requires_clauses)</InlineRevision> of that template template parameter.

{/* source:cpp-language-scope:0049 */}
Each template declaration `D` introduces a *template parameter scope* `S` that extends from the beginning of the template parameter list of `D` to the end of `D`. Any declaration outside the template parameter list that would inhabit `S` instead inhabits the same scope as `D`.

{/* source:cpp-language-scope:0050 */}
```cpp
// the class template declaration of “X”
// introduces a template parameter scope “S1”
template
<
    // scope “S1” begins here
    template // the template template parameter “T”
             // introduces another template parameter scope “S2”
    <
        typename T1
        typename T2
    > requires std::convertible_from<T1, T2> // scope “S2” ends here
    class T,
    typename U
>
class X; // scope “S1” ends before the semicolon
```

## Point of declaration

{/* source:cpp-language-scope:0051 */}
In general, a name is visible after the *locus* of its first declaration, which is located as follows.

{/* source:cpp-language-scope:0052 */}
The locus of a name declared in a simple declaration is immediately after that name's [declarator](/docs/cpp/language/declarations#Declarators) and before its initializer, if any.

{/* source:cpp-language-scope:0053 */}
```cpp
int x = 32; // outer x is in scope

{
    int x = x; // inner x is in scope before the initializer (= x)
               // this does not initialize inner x with the value of outer x (32),
               // this initializes inner x with its own (indeterminate) value
}

std::function<int(int)> f = [&](int n){ return n > 1 ? n * f(n - 1) : n; };
// the name of the function f is in scope in the lambda and can
// be correctly captured by reference, giving a recursive function
```

{/* source:cpp-language-scope:0054 */}
```cpp
const int x = 2; // outer x is in scope

{
    int x[x] = {}; // inner x is in scope before the initializer (= {}),
                   // but after the declarator (x[x])
                   // in the declarator, outer x is still in scope
                   // this declares an array of 2 int
}
```

{/* source:cpp-language-scope:0055 */}
The locus of a class or class template declaration is immediately after the identifier that names the class (or the [template-id](/docs/cpp/language/templates#template-id) that names the template specialization) in its [class-head](/docs/cpp/language/classes/class). The class or class template name is already in scope in the list of base classes.

{/* source:cpp-language-scope:0056 */}
```cpp
struct S: std::enable_shared_from_this<S> {}; // S is in scope at the colon
```

{/* source:cpp-language-scope:0057 */}
The locus of [enum specifier](/docs/cpp/language/declarations/enum)<InlineRevision since="C++11"> or opaque enum declaration</InlineRevision> is immediately after the identifier that names the enumeration.

{/* source:cpp-language-scope:0058 */}
```cpp
enum E : int // E is in scope at the colon
{
    A = sizeof(E)
};
```

{/* source:cpp-language-scope:0059 */}
The locus of a [type alias or alias template](/docs/cpp/language/declarations/type_alias) declaration is immediately after the type-id to which the alias refers.

{/* source:cpp-language-scope:0060 */}
```cpp
using T = int; // outer T is in scope at the semicolon

{
    using T = T*; // inner T is in scope at the semicolon,
                  // outer T is still in scope before the semicolon
                  // same as T = int*
}
```

{/* source:cpp-language-scope:0061 */}
The locus for a declarator in a [using declaration](/docs/cpp/language/classes/using_declaration) that does not name a constructor is immediately after the declarator.

{/* source:cpp-language-scope:0062 */}
```cpp
template<int N>
class Base
{
protected:
    static const int next = N + 1;
    static const int value = N;
};

struct Derived: Base<0>, Base<1>, Base<2>
{
    using Base<0>::next,     // next is in scope at the comma
          Base<next>::value; // Derived::value is 1
};
```

{/* source:cpp-language-scope:0063 */}
The locus of an enumerator is immediately after its definition (not before the initializer as it is for variables).

{/* source:cpp-language-scope:0064 */}
```cpp
const int x = 12;

{
    enum
    {
        x = x + 1, // enumerator x is in scope at the comma,
                   // outer x is in scope before the comma,
                   // enumerator x is initialized to 13
        y = x + 1  // y is initialized to 14
    };
}
```

{/* source:cpp-language-scope:0065 */}
The locus for an [injected-class-name](/docs/cpp/language/classes/injected-class-name) is immediately following the opening brace of its class (or class template) definition.

{/* source:cpp-language-scope:0066 */}
```cpp
template<typename T>
struct Array
//  : std::enable_shared_from_this<Array> // error: the injected class name is not in scope
    : std::enable_shared_from_this< Array<T> > // OK: the template-name Array is in scope
{ // the injected class name Array is now in scope as if a public member name
    Array* p; // pointer to Array<T>
};
```

{/* source:cpp-language-scope:0067 */}
<Revision since="C++11">
The locus of the implicit declaration for a function-local predefined variable `__func__` is immediately before the function body of a function definition.
</Revision>

{/* source:cpp-language-scope:0068 */}
<Revision since="C++17">
The locus of a [structured binding declaration](/docs/cpp/language/declarations/structured_binding) is immediately after the *identifier-list*, but structured binding initializers are prohibited from referring to any of the names being declared.
</Revision>

{/* source:cpp-language-scope:0069 */}
<Revision since="C++11">
The locus of the variable<InlineRevision since="C++17"> or the structured bindings</InlineRevision> declared in the *range-declaration* of a [range-`for` loop](/docs/cpp/language/statements/range-for) is immediately after the *range-expression*.

```cpp
std::vector<int> x;

for (auto x : x) // vector x is in scope before the closing parenthesis,
                 // auto x is in scope at the closing parenthesis
{
    // the auto x is in scope
}
```
</Revision>

{/* source:cpp-language-scope:0070 */}
The locus of a [template parameter](/docs/cpp/language/templates/template_parameters) is immediately after its complete template parameter (including the optional default argument).

{/* source:cpp-language-scope:0071 */}
```cpp
typedef unsigned char T;

template<
    class T = T, // template parameter T is in scope at the comma,
                 // typedef name of unsigned char is in scope before the comma
    T // template parameter T is in scope
    N = 0
>
struct A
{
};
```

{/* source:cpp-language-scope:0072 */}
<Revision since="C++20">
The locus of a [concept definition](/docs/cpp/language/templates/constraints) is immediately after the concept name, but concept definitions are prohibited from referring to the concept name being declared.
</Revision>

{/* source:cpp-language-scope:0073 */}
The locus of a named [namespace definition](/docs/cpp/language/declarations/namespace) is immediately after the namespace name.
