{/* source:cpp-language-basic-concepts:0000 */}
This section provides definitions for the specific terminology and the concepts used when describing the C++ programming language.

{/* source:cpp-language-basic-concepts:0001 */}
A C++ program is a sequence of text files (typically header and source files) that contain [declarations](/docs/cpp/language/declarations). They undergo [translation](/docs/cpp/language/basic_concepts/translation_phases) to become an executable program, which is executed when the C++ implementation calls its [main function](/docs/cpp/language/basic_concepts/main_function).

{/* source:cpp-language-basic-concepts:0002 */}
Certain words in a C++ program have special meaning, and these are known as [keywords](/docs/cpp/language/keywords). Others can be used as [identifiers](/docs/cpp/language/basic_concepts/name). [Comments](/docs/cpp/language/basic_concepts/comments) are ignored during translation. C++ programs also contain [literals](/docs/cpp/language/expressions#Literals), the values of characters inside them are determined by [character sets and encodings](/docs/cpp/language/basic_concepts/charset). Certain characters in the program have to be represented with [escape sequences](/docs/cpp/language/expressions/escape).

{/* source:cpp-language-basic-concepts:0003 */}
The *entities* of a C++ program are values, [objects](/docs/cpp/language/basic_concepts/objects), [references](/docs/cpp/language/declarations/reference)<InlineRevision since="C++17">, [structured bindings](/docs/cpp/language/declarations/structured_binding)</InlineRevision>, [functions](/docs/cpp/language/functions), [enumerators](/docs/cpp/language/declarations/enum), [types](/docs/cpp/language/basic_concepts/type-id), class members, [templates](/docs/cpp/language/templates), [template specializations](/docs/cpp/language/templates/template_specialization)<InlineRevision since="C++11">, [packs](/docs/cpp/language/templates/parameter_pack)</InlineRevision>, and [namespaces](/docs/cpp/language/declarations/namespace). Preprocessor [macros](/docs/cpp/language/preprocessor/replace) are not C++ entities.

{/* source:cpp-language-basic-concepts:0004 */}
[Declarations](/docs/cpp/language/declarations) may introduce entities, associate them with [names](/docs/cpp/language/basic_concepts/name) and define their properties. The declarations that define all properties required to use an entity are [definitions](/docs/cpp/language/basic_concepts/definition). A program must contain only one definition of any non-inline function or variable that is [odr-used](/docs/cpp/language/basic_concepts/definition#ODR-use).

{/* source:cpp-language-basic-concepts:0005 */}
Definitions of functions usually include sequences of [statements](/docs/cpp/language/statements), some of which include [expressions](/docs/cpp/language/expressions), which specify the computations to be performed by the program.

{/* source:cpp-language-basic-concepts:0006 */}
Names encountered in a program are associated with the declarations that introduced them using [name lookup](/docs/cpp/language/basic_concepts/lookup). Each name is only valid within a part of the program called its [scope](/docs/cpp/language/basic_concepts/scope). Some names have [linkage](/docs/cpp/language/declarations/storage_duration) which makes them refer to the same entities when they appear in different scopes or translation units.

{/* source:cpp-language-basic-concepts:0007 */}
Each object, reference, function, expression in C++ is associated with a [type](/docs/cpp/language/basic_concepts/type-id), which may be [fundamental](/docs/cpp/language/basic_concepts/types), compound, or [user-defined](/docs/cpp/language/classes), complete or [incomplete](/docs/cpp/language/basic_concepts/incomplete_type), etc.

{/* source:cpp-language-basic-concepts:0008 */}
Declared objects and declared references that are not [non-static data members](/docs/cpp/language/classes/data_members) are variables.
