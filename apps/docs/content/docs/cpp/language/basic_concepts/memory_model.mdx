{/* source:cpp-language-memory-model:0000 */}
Defines the semantics of computer memory storage for the purpose of the C++ abstract machine.

{/* source:cpp-language-memory-model:0001 */}
The memory available to a C++ program is one or more contiguous sequences of *bytes*. Each byte in memory has a unique *address*.

## Byte

{/* source:cpp-language-memory-model:0002 */}
A *byte* is the smallest addressable unit of memory. It is defined as a contiguous sequence of bits, large enough to hold

{/* source:cpp-language-memory-model:0003 */}
- the value of any `UTF-8` code unit (256 distinct values) and of

{/* source:cpp-language-memory-model:0004 */}
<Revision until="C++23">
- any member of the [basic execution character set](/docs/cpp/language/basic_concepts/charset#Basic_execution_character_set).
</Revision>
<Revision since="C++23">
- the ordinary literal encoding of any element of the [basic literal character set](/docs/cpp/language/basic_concepts/charset#Basic_literal_character_set).
</Revision>

{/* source:cpp-language-memory-model:0005 */}
Similar to C, C++ supports bytes of sizes 8 bits and greater.

{/* source:cpp-language-memory-model:0006 */}
The [types](/docs/cpp/language/basic_concepts/types) `char`, `unsigned char`, and `signed char` use one byte for both storage and [value representation](/docs/cpp/language/basic_concepts/objects). The number of bits in a byte is accessible as [`CHAR_BIT`](/docs/cpp/library/utility/types/climits) or `std::numeric_limits<unsigned char>::digits`.

## Memory location

{/* source:cpp-language-memory-model:0007 */}
A *memory location* is the storage occupied by the [object representation](/docs/cpp/language/basic_concepts/objects#Object_representation_and_value_representation) of either an object of [scalar type](/docs/cpp/language/basic_concepts/type-id#Scalar_type) that is not a [bit-field](/docs/cpp/language/classes/bit_field), or the largest contiguous sequence of bit-fields of non-zero length.

{/* source:cpp-language-memory-model:0008 */}
Note: Various features of the language, such as [references](/docs/cpp/language/declarations/reference) and [virtual functions](/docs/cpp/language/classes/virtual), might involve additional memory locations that are not accessible to programs but are managed by the implementation.

{/* source:cpp-language-memory-model:0009 */}
```cpp
struct S
{
    char a;     // memory location #1
    int b : 5;  // memory location #2
    int c : 11, // memory location #2 (continued)
          : 0,
        d : 8;  // memory location #3
    struct
    {
        int ee : 8; // memory location #4
    } e;
} obj; // The object “obj” consists of 4 separate memory locations
```
