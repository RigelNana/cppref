{/* source:cpp-language-main-function:0000 */}
A program shall contain a global function named `main`, which is the designated start of the program in hosted environment. It shall have one of the following forms:

{/* source:cpp-language-main-function:0001 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" grammar code="int main() { body }" />
  <Declaration id="2" language="cpp" grammar code="int main( int argc, char *argv[] ) { body }" />
  <Declaration id="3" language="cpp" grammar code="int main( /* implementation-defined */ ) { body }" />
</DeclarationDoc>

{/* source:cpp-language-main-function:0002 */}
1. A main function running independently of environment-provided arguments.

{/* source:cpp-language-main-function:0003 */}
2. A main function accepting environment-provided arguments.

{/* source:cpp-language-main-function:0004 */}
   The names of argc and argv are arbitrary, as well as the representation of the types of the parameters: `int main(int ac, char** av)` is equally valid.

{/* source:cpp-language-main-function:0005 */}
3. A main function of implement-defined type, returning `int`.

{/* source:cpp-language-main-function:0006 */}
   The C++ standard recommends implementation-defined main functions to place the extra (optional) parameters after `argv`.

{/* source:cpp-language-main-function:0007 */}
<ParameterList>
  <Parameter name="argc">Non-negative value representing the number of arguments passed to the program from the environment in which the program is run.</Parameter>
  <Parameter name="argv">Pointer to the first element of an array of `argc + 1` pointers, of which the last one is null and the previous ones, if any, point to [null-terminated multibyte strings](/docs/cpp/library/text/multibyte) that represent the arguments passed to the program from the execution environment. If `argv[0]` is not a null pointer (or, equivalently, if `argc > 0`), it points to a string that represents the name used to invoke the program, or to an empty string.</Parameter>
  <Parameter name="body">The body of the `main` function.</Parameter>
</ParameterList>

## Explanation

{/* source:cpp-language-main-function:0008 */}
The `main` function is called at program startup after [initialization](/docs/cpp/language/initialization) of the non-local objects with static [storage duration](/docs/cpp/language/declarations/storage_duration). It is the designated entry point to a program that is executed in hosted environment (that is, with an operating system). The entry points to freestanding programs (boot loaders, OS kernels, etc) are implementation-defined.

{/* source:cpp-language-main-function:0009 */}
The parameters of the two-parameter form of the `main` function allow arbitrary multibyte character strings to be passed from the execution environment (these are typically known as *command line arguments*), the pointers `argv[1]` .. `argv[argc - 1]` point at the first characters in each of these strings. `argv[0]` (if non-null) is the pointer to the initial character of a null-terminated multibyte string that represents the name used to invoke the program itself (or an empty string `""` if this is not supported by the execution environment). The strings are modifiable, although these modifications do not propagate back to the execution environment: they can be used, for example, with [`std::strtok`](/docs/cpp/library/text/byte/strtok). The size of the array pointed to by `argv` is at least `argc + 1`, and the last element, `argv[argc]`, is guaranteed to be a null pointer.

{/* source:cpp-language-main-function:0010 */}
The main function has the following several special properties:

{/* source:cpp-language-main-function:0011 */}
1. The body of the `main` function does not need to contain the [`return` statement](/docs/cpp/language/statements/return): if control reaches the end of `main` without encountering a return statement, the effect is that of executing `return 0;`.

{/* source:cpp-language-main-function:0012 */}
2. Execution of the return (or the implicit return upon reaching the end of `main`) is equivalent to first leaving the function normally (which destroys the objects with automatic storage duration) and then calling [`std::exit`](/docs/cpp/library/utility/program/exit) with the same argument as the argument of the [return](/docs/cpp/language/statements/return) ([`std::exit`](/docs/cpp/library/utility/program/exit) then destroys static objects and terminates the program).

{/* source:cpp-language-main-function:0013 */}
The main function has several restrictions (violation of which renders the program ill-formed):

{/* source:cpp-language-main-function:0014 */}
1. It cannot be [named](/docs/cpp/language/basic_concepts/definition#Naming_a_function) anywhere in the program

{/* source:cpp-language-main-function:0015 */}
   a. in particular, it cannot be called recursively

{/* source:cpp-language-main-function:0016 */}
   b. its address cannot be taken

{/* source:cpp-language-main-function:0017 */}
   c. it cannot be used in a [`typeid`](/docs/cpp/language/expressions/typeid) expression <InlineRevision since="C++11">or a [`decltype`](/docs/cpp/language/declarations/decltype)-specifier</InlineRevision>

{/* source:cpp-language-main-function:0018 */}
2. It cannot be predefined and cannot be overloaded: effectively, the name `main` in the global namespace is reserved for functions (although it can be used to name classes, namespaces, enumerations, and any entity in a non-global namespace, except that an entity named `main` cannot be declared with C [language linkage](/docs/cpp/language/declarations/language_linkage) in any namespace.

{/* source:cpp-language-main-function:0019 */}
3. It cannot be <InlineRevision since="C++11">defined as deleted or</InlineRevision> declared with any language linkage<InlineRevision since="C++11">, [`constexpr`](/docs/cpp/language/declarations/constexpr)</InlineRevision><InlineRevision since="C++20">, [`consteval`](/docs/cpp/language/declarations/consteval)</InlineRevision>, [`inline`](/docs/cpp/language/declarations/inline), or [`static`](/docs/cpp/language/classes/static).

{/* source:cpp-language-main-function:0020 */}
<Revision since="C++14">
4. The return type of the `main` function cannot be deduced (`auto main() {...}` is not allowed).
</Revision>

{/* source:cpp-language-main-function:0021 */}
<Revision since="C++20">
5. The `main` function cannot be a [coroutine](/docs/cpp/language/functions/coroutines).
</Revision>

{/* source:cpp-language-main-function:0022 */}
<Revision since="C++20">
6. The `main` function cannot attach to a named [module](/docs/cpp/language/basic_concepts/modules).
</Revision>

## Notes

{/* source:cpp-language-main-function:0023 */}
If the `main` function is defined with a [function try block](/docs/cpp/language/exceptions/try#Function_try_block), the exceptions thrown by the destructors of static objects (which are destroyed by the implied [`std::exit`](/docs/cpp/library/utility/program/exit)) are not [caught](/docs/cpp/language/exceptions/catch) by it.

{/* source:cpp-language-main-function:0024 */}
The manner in which the arguments given at the OS command line are converted into the multibyte character arrays referenced by `argv` may involve implementation-defined processing:

{/* source:cpp-language-main-function:0025 */}
- [Parsing C++ Command-Line Arguments](https://docs.microsoft.com/en-us/cpp/cpp/main-function-command-line-args) MSDN
- [Shell Introduction](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/V3_chap02.html#tag_18_01) POSIX

{/* source:cpp-language-main-function:0026 */}
A very common implementation-defined form of `main()` has a third argument (in addition to `argc` and `argv`), of type `char**`, pointing at [an array of pointers to the execution environment variables](https://pubs.opengroup.org/onlinepubs/9699919799/functions/exec.html).

## Example

{/* source:cpp-language-main-function:0027 */}
Demonstrates how to inform a program about where to find its input and where to write its results.

A possible invocation: `./convert table_in.dat table_out.dat`

```cpp
#include <cstdlib>
#include <iomanip>
#include <iostream>

int main(int argc, char *argv[])
{
    std::cout << "argc == " << argc << '\n';

    for (int ndx{}; ndx != argc; ++ndx)
        std::cout << "argv[" << ndx << "] == " << std::quoted(argv[ndx]) << '\n';
    std::cout << "argv[" << argc << "] == "
              << static_cast<void*>(argv[argc]) << '\n';

    /* ... */

    return argc == 3 ? EXIT_SUCCESS : EXIT_FAILURE; // optional return value
}
```

Possible output:

```text
argc == 3
argv[0] == "./convert"
argv[1] == "table_in.dat"
argv[2] == "table_out.dat"
argv[3] == 0
```
