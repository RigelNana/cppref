{/* source:cpp-language-break:0000 */}
Causes the enclosing [for](/docs/cpp/language/statements/for), [range-for](/docs/cpp/language/statements/range-for), [while](/docs/cpp/language/statements/while) or [do-while](/docs/cpp/language/statements/do) loop or [switch statement](/docs/cpp/language/statements/switch) to terminate.

{/* source:cpp-language-break:0001 */}
Used when it is otherwise awkward to terminate the loop using the condition expression and conditional statements.

## Syntax

{/* source:cpp-language-break:0002 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="attr (optional) break ;" />
</DeclarationDoc>

{/* source:cpp-language-break:0003 */}
<ParameterList>
  <Parameter name="attr">
    <Revision since="C++11">
      any number of [attributes](/docs/cpp/language/declarations/attributes)
    </Revision>
  </Parameter>
</ParameterList>

## Explanation

{/* source:cpp-language-break:0004 */}
Appears only within the *statement* of a loop body ([`while`](/docs/cpp/language/statements/while), [`do-while`](/docs/cpp/language/statements/do), [`for`](/docs/cpp/language/statements/for)) or within the *statement* of a [`switch`](/docs/cpp/language/statements/switch).
After this statement the control is transferred to the statement immediately following the enclosing loop or switch. As with any block exit, all automatic storage objects declared in enclosing compound statement or in the *condition* of a loop/switch are destroyed, in reverse order of construction, before the execution of the first line following the enclosing loop.

## Notes

{/* source:cpp-language-break:0005 */}
A break statement cannot be used to break out of multiple nested loops. The [goto statement](/docs/cpp/language/statements/goto) may be used for this purpose.

## Keywords

{/* source:cpp-language-break:0006 */}
[`break`](/docs/cpp/language/keywords/break)

## Example

{/* source:cpp-language-break:0007 */}
```cpp
#include <iostream>

int main()
{
    int i = 2;
    switch (i)
    {
        case 1: std::cout << "1";   // <---- maybe warning: fall through
        case 2: std::cout << "2";   // execution starts at this case label (+warning)
        case 3: std::cout << "3";   // <---- maybe warning: fall through
        case 4:                     // <---- maybe warning: fall through
        case 5: std::cout << "45";  //
                break;              // execution of subsequent statements is terminated
        case 6: std::cout << "6";
    }
    std::cout << '\n';

    for (char c = 'a'; c < 'c'; c++)
    {
        for (int i = 0; i < 5; i++)      // only this loop is affected by break
        {                                //
            if (i == 2)                  //
                break;                   //
            std::cout << c << i << ' ';  //
        }
    }
    std::cout << '\n';
}
```

Possible output:

```text
2345
a0 a1 b0 b1
```
