{/* source:cpp-language-continue:0000 */}
Causes the remaining portion of the enclosing [`for`](/docs/cpp/language/statements/for), [`range-for`](/docs/cpp/language/statements/range-for), [`while`](/docs/cpp/language/statements/while) or [`do-while`](/docs/cpp/language/statements/do) loop body to be skipped.

{/* source:cpp-language-continue:0001 */}
Used when it is otherwise awkward to ignore the remaining portion of the loop using conditional statements.

## Syntax

{/* source:cpp-language-continue:0002 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="attr (optional) continue ;" />
</DeclarationDoc>

## Explanation

{/* source:cpp-language-continue:0003 */}
The continue statement causes a jump, as if by [`goto`](/docs/cpp/language/statements/goto) to the end of the loop body (it may only appear within the loop body of [`for`](/docs/cpp/language/statements/for), [`range-for`](/docs/cpp/language/statements/range-for), [`while`](/docs/cpp/language/statements/while), and [`do-while`](/docs/cpp/language/statements/do) loops).

{/* source:cpp-language-continue:0004 */}
More precisely,

{/* source:cpp-language-continue:0005 */}
For [`while`](/docs/cpp/language/statements/while) loop, it acts as

{/* source:cpp-language-continue:0006 */}
```cpp
while (/* ... */)
{
   // ...
   continue; // acts as goto contin;
   // ...
   contin:;
}
```

{/* source:cpp-language-continue:0007 */}
For [`do-while`](/docs/cpp/language/statements/do) loop, it acts as:

{/* source:cpp-language-continue:0008 */}
```cpp
do
{
   // ...
   continue; // acts as goto contin;
   // ...
   contin:;
} while (/* ... */);
```

{/* source:cpp-language-continue:0009 */}
For [`for`](/docs/cpp/language/statements/for) and [`range-for`](/docs/cpp/language/statements/range-for) loop, it acts as:

{/* source:cpp-language-continue:0010 */}
```cpp
for (/* ... */)
{
   // ...
   continue; // acts as goto contin;
   // ...
   contin:;
}
```

## Keywords

[`continue`](/docs/cpp/language/keywords/continue)

## Example

{/* source:cpp-language-continue:0012 */}
```cpp
#include <iostream>

int main()
{
    for (int i = 0; i < 10; ++i)
    {
        if (i != 5)
            continue;
        std::cout << i << ' ';      // this statement is skipped each time i != 5
    }
    std::cout << '\n';

    for (int j = 0; 2 != j; ++j)
        for (int k = 0; k < 5; ++k) // only this loop is affected by continue
        {
            if (k == 3)
                continue;
            // this statement is skipped each time k == 3:
            std::cout << '(' << j << ',' << k << ") ";
        }
    std::cout << '\n';
}
```

Output:

```text
5
(0,0) (0,1) (0,2) (0,4) (1,0) (1,1) (1,2) (1,4)
```
