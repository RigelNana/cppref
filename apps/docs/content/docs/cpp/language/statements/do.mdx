{/* source:cpp-language-do:0000 */}
Conditionally executes a statement repeatedly (at least once).

## Syntax

{/* source:cpp-language-do:0001 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="attr (optional) do statement while ( expression );" />
</DeclarationDoc>

{/* source:cpp-language-do:0002 */}
<ParameterList>
  <Parameter name="attr">
    <Revision since="C++11">
      any number of [attributes](/docs/cpp/language/declarations/attributes)
    </Revision>
  </Parameter>
  <Parameter name="expression">
    an [expression](/docs/cpp/language/expressions)
  </Parameter>
  <Parameter name="statement">
    a [statement](/docs/cpp/language/statements) (typically a compound statement)
  </Parameter>
</ParameterList>

## Explanation

{/* source:cpp-language-do:0003 */}
When control reaches a `do` statement, its *statement* will be executed unconditionally.

{/* source:cpp-language-do:0004 */}
Every time *statement* finishes its execution, *expression* will be evaluated and contextually converted to `bool`. If the result is `true`, *statement* will be executed again.

{/* source:cpp-language-do:0005 */}
If the loop needs to be terminated within *statement*, a [`break` statement](/docs/cpp/language/statements/break) can be used as terminating statement.

{/* source:cpp-language-do:0006 */}
If the current iteration needs to be terminated within *statement*, a [`continue` statement](/docs/cpp/language/statements/continue) can be used as shortcut.

## Notes

{/* source:cpp-language-do:0007 */}
As part of the C++ [forward progress guarantee](/docs/cpp/language/basic_concepts/multithread#Progress_guarantee), the behavior is [undefined](/docs/cpp/language/basic_concepts/ub) if a loop<InlineRevision since="C++26"> that is not a [trivial infinite loop](/docs/cpp/language/basic_concepts/multithread#Trivial_infinite_loops)</InlineRevision> without [observable behavior](/docs/cpp/language/basic_concepts/as_if) does not terminate. Compilers are permitted to remove such loops.

## Keywords

{/* source:cpp-language-do:0008 */}
[`do`](/docs/cpp/language/keywords/do), [`while`](/docs/cpp/language/keywords/while)

## Example

{/* source:cpp-language-do:0009 */}
```cpp
#include <algorithm>
#include <iostream>
#include <string>

int main()
{
    int j = 2;
    do // compound statement is the loop body
    {
        j += 2;
        std::cout << j << ' ';
    }
    while (j < 9);
    std::cout << '\n';

    // common situation where do-while loop is used
    std::string s = "aba";
    std::sort(s.begin(), s.end());

    do std::cout << s << '\n'; // expression statement is the loop body
    while (std::next_permutation(s.begin(), s.end()));
}
```

Output:

```text
4 6 8 10
aab
aba
baa
```
