{/* source:cpp-17:0000 */}
C++17 is a major version that follows the minor version C++14 and introduces new language and library features. The standard was published in December 2017.

{/* source:cpp-17:0001 */}
The following features were merged into C++17:

{/* source:cpp-17:0002 */}
- From the [File System TS](/docs/cpp/library/experimental/fs): the [filesystem library](/docs/cpp/library/filesystem).
- From the [Library fundamentals v1 TS](/docs/cpp/library/experimental/memory): features, including [std::any](/docs/cpp/library/utility/any), [std::optional](/docs/cpp/library/utility/optional), [std::string_view](/docs/cpp/library/string/basic_string_view), [std::apply](/docs/cpp/library/utility/apply), [polymorphic allocators](/docs/cpp/library/memory#Allocators), [searchers](/docs/cpp/library/utility/functional#Searchers).
- From [Library fundamentals v2 TS](/docs/cpp/library/experimental/lib_extensions_2): [std::void_t](/docs/cpp/library/meta/void_t), [std::conjunction](/docs/cpp/library/meta/conjunction), [std::disjunction](/docs/cpp/library/meta/disjunction), [std::negation](/docs/cpp/library/meta/negation), [std::not_fn](/docs/cpp/library/utility/functional/not_fn), [std::gcd](/docs/cpp/library/numeric/gcd), [std::lcm](/docs/cpp/library/numeric/lcm).
- From [Parallelism v1 TS](/docs/cpp/library/experimental/parallelism): features, including [execution policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [std::reduce](/docs/cpp/library/numeric/reduce), [std::inclusive_scan](/docs/cpp/library/numeric/inclusive_scan), [std::exclusive_scan](/docs/cpp/library/numeric/exclusive_scan), but removing `exception_list`.
- From [Mathematical special functions IS](/docs/cpp/library/experimental/special_math): [mathematical special functions](/docs/cpp/library/numeric/special_functions).
- From C11: [std::aligned_alloc](/docs/cpp/library/memory/c/aligned_alloc), [std::timespec_get](/docs/cpp/library/chrono/c/timespec_get).

## Obsolete features

##### Removed features

- [std::auto_ptr](/docs/cpp/library/memory/auto_ptr),

## New language features

{/* source:cpp-17:0006 */}
- [`u8` character literal](/docs/cpp/language/expressions/character_literal)
- made [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) part of type system
- new [order of evaluation](/docs/cpp/language/expressions/eval_order) rules
- [lambda capture of `*this`](/docs/cpp/language/functions/lambda#Lambda_capture)

{/* source:cpp-17:0007 */}
- [`constexpr`](/docs/cpp/language/keywords/constexpr)
  - compile-time [`if constexpr`](/docs/cpp/language/statements/if)
  - [constexpr lambda](/docs/cpp/language/functions/lambda)

{/* source:cpp-17:0008 */}
- Variables
  - [inline variables](/docs/cpp/language/declarations/inline)
  - [structured bindings](/docs/cpp/language/declarations/structured_binding)
  - initializers for [`if`](/docs/cpp/language/statements/if) and [`switch`](/docs/cpp/language/statements/switch)
  - guaranteed [copy elision](/docs/cpp/language/initialization/copy_elision)
  - [temporary materialization](/docs/cpp/language/expressions/implicit_cast#Temporary_materialization)

{/* source:cpp-17:0009 */}
- Templates
  - [fold-expressions](/docs/cpp/language/templates/fold) `( ... )`
  - [class template argument deduction](/docs/cpp/language/templates/ctad) `tuple t(4, 3, 2.5)`
  - non-type [template parameters](/docs/cpp/language/templates/template_parameters) declared with `auto`

{/* source:cpp-17:0010 */}
- [Namespaces](/docs/cpp/language/declarations/namespace)
  - simplified nested namespaces
  - `using`-declaration declaring multiple names
  - [attribute namespaces](/docs/cpp/language/declarations/attributes) don't have to repeat
- new [attributes](/docs/cpp/language/declarations/attributes):
  - [`[[fallthrough]]`](/docs/cpp/language/declarations/attributes/fallthrough)
  - [`[[maybe_unused]]`](/docs/cpp/language/declarations/attributes/maybe_unused)
  - [`[[nodiscard]]`](/docs/cpp/language/declarations/attributes/nodiscard)
- [`__has_include`](/docs/cpp/language/preprocessor/include)
