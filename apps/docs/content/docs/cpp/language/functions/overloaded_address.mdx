{/* source:cpp-language-overloaded-address:0000 */}
Besides [function-call expressions](/docs/cpp/language/expressions/operator_other), where [overload resolution](/docs/cpp/language/functions/overload_resolution) takes place, the name of an overloaded function may appear in the following 7 contexts:

{/* source:cpp-language-overloaded-address:0001 */}
| Context | Target |
| --- | --- |
| [initializer](/docs/cpp/language/initialization) in a [declaration](/docs/cpp/language/declarations) of an object or [reference](/docs/cpp/language/initialization/reference_initialization) | the object or reference being initialized |
| on the right-hand-side of an assignment expression | the left-hand side of the assignment |
| as a function call argument | the function parameter |
| as a user-defined operator argument | the operator parameter |
| the [`return`](/docs/cpp/language/statements/return) statement | the return value of a function or conversion |
| [explicit cast](/docs/cpp/language/expressions/explicit_cast) or [`static_cast`](/docs/cpp/language/expressions/static_cast) argument | the corresponding cast |
| non-type [template argument](/docs/cpp/language/templates/template_parameters) | the corresponding template parameter |

{/* source:cpp-language-overloaded-address:0002 */}
In each context, the name of an overloaded function may be preceded by address-of operator `&` and may be enclosed in a redundant set of parentheses.

{/* source:cpp-language-overloaded-address:0003 */}
<Revision since="C++26">
If the target type contains a [placeholder type](/docs/cpp/language/declarations/auto), placeholder type deduction is performed, and the following description uses the deduced type as target type.
</Revision>

## Selecting functions

{/* source:cpp-language-overloaded-address:0004 */}
When the address of an overloaded function is taken, a set `S` of functions is selected from the overload set referred to by the name of the overload function:

{/* source:cpp-language-overloaded-address:0005 */}
- If there is no target, all non-template functions named are selected.
- Otherwise, a non-template function with type `F` is selected for the function type `FT` of the target type if `F`<InlineRevision since="C++17"> (after possibly applying the [function pointer conversion](/docs/cpp/language/expressions/implicit_cast#Function_pointer_conversions))</InlineRevision> is identical to `FT`.[^1]
- The specialization (if any) generated by [template argument deduction](/docs/cpp/language/templates/template_argument_deduction) for each function template named is also added to `S`.

{/* source:cpp-language-overloaded-address:0006 */}
If the target is of function pointer type or reference to function type, `S` can only include non-member functions<InlineRevision since="C++23">, explicit object member functions</InlineRevision> and static member functions. If the target is of pointer-to-member-function type, `S` can only include implicit object member functions.

{/* source:cpp-language-overloaded-address:0007 */}
[^1]: In other words, the class of which the function is a member is ignored if the target type is a pointer-to-member-function type.

## Eliminating functions

{/* source:cpp-language-overloaded-address:0008 */}
After forming the set `S`, functions are elimiated in the following order:

{/* source:cpp-language-overloaded-address:0009 */}
<Revision since="C++20">
- All functions with associated [constraints](/docs/cpp/language/templates/constraints#Constraints) that are not satisfied are eliminated from the `S`.
</Revision>

{/* source:cpp-language-overloaded-address:0010 */}
- If more than one function in `S` remains, all function template specializations in `S` are eliminated if `S` also contains a non-template function.

{/* source:cpp-language-overloaded-address:0011 */}
<Revision since="C++20">
- Any given non-template function `func` is eliminated if `S` contains a second non-template function that is [more partial-ordering-constrained](/docs/cpp/language/templates/constraints#Partial_ordering_of_constraints) than `func`.
</Revision>

{/* source:cpp-language-overloaded-address:0012 */}
- Any given function template specialization `spec` is eliminated if `S` contains a second function template specialization whose function template is [more specialized](/docs/cpp/language/templates/function_template#Function_template_overloading) than the function template of `spec`.

{/* source:cpp-language-overloaded-address:0013 */}
After such eliminations (if any), exactly one selected function should remain in `S`. Otherwise, the program is ill-formed.

## Example

{/* source:cpp-language-overloaded-address:0014 */}
```cpp
int f(int) { return 1; }
int f(double) { return 2; }
 
void g(int(&f1)(int), int(*f2)(double)) { f1(0); f2(0.0); }
 
template<int(*F)(int)>
struct Templ {};
 
struct Foo
{
    int mf(int) { return 3; }
    int mf(double) { return 4; }
};
 
struct Emp
{
    void operator<<(int (*)(double)) {}
};
 
int main()
{
    // 1. initialization
    int (*pf)(double) = f; // selects int f(double)
    int (&rf)(int) = f; // selects int f(int)
    int (Foo::*mpf)(int) = &Foo::mf; // selects int mf(int)
 
    // 2. assignment
    pf = nullptr;
    pf = &f; // selects int f(double)
 
    // 3. function argument
    g(f, f); // selects int f(int) for the 1st argument
             // and int f(double) for the second
 
    // 4. user-defined operator
    Emp{} << f; //selects int f(double)
 
    // 5. return value
    auto foo = []() -> int (*)(int)
    {
        return f; // selects int f(int)
    };
 
    // 6. cast
    auto p = static_cast<int(*)(int)>(f); // selects int f(int)
 
    // 7. template argument
    Templ<f> t;  // selects int f(int)
 
    // prevent “unused variable” warnings as if by [[maybe_unused]]
    [](...){}(pf, rf, mpf, foo, p, t);
}
```
