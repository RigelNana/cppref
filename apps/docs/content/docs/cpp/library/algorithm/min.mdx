{/* source:cpp-algorithm-min:0001 */}
Returns the smaller of the given values.

{/* source:cpp-algorithm-min:0002 */}
1. 1,2) Returns the smaller of `a` and `b`.

{/* source:cpp-algorithm-min:0003 */}
2. 1) Uses `operator<` to compare the values.

{/* source:cpp-algorithm-min:0004 */}
3. If `T` is not [*LessThanComparable*](/docs/cpp/library/named_req/LessThanComparable), the behavior is undefined.

{/* source:cpp-algorithm-min:0005 */}
4. 2) Use the comparison function `comp` to compare the values.

{/* source:cpp-algorithm-min:0006 */}
5. 3,4) Returns the smallest of the values in initializer list `ilist`.

{/* source:cpp-algorithm-min:0007 */}
6. If `ilist.size()` is zero, or `T` is not [*CopyConstructible*](/docs/cpp/library/named_req/CopyConstructible), the behavior is undefined.

{/* source:cpp-algorithm-min:0008 */}
7. 3) Uses `operator<` to compare the values.

{/* source:cpp-algorithm-min:0009 */}
8. If `T` is not [*LessThanComparable*](/docs/cpp/library/named_req/LessThanComparable), the behavior is undefined.

{/* source:cpp-algorithm-min:0010 */}
9. 4) Use the comparison function `comp` to compare the values.

### Parameters

{/* source:cpp-algorithm-min:0011 */}
<ParameterList>
  <Parameter name="a, b">the values to compare</Parameter>
  <Parameter name="ilist">initializer list with the values to compare</Parameter>
  <Parameter name="cmp">
comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if `a` is *less* than `b`.

The signature of the comparison function should be equivalent to the following:

`bool cmp( const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The types `Type1` and `Type2` must be such that an object of type `T` can be implicitly converted to both of them.
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-min:0012 */}
1. 1,2) The smaller of `a` and `b`. If the values are equivalent, returns `a`.

{/* source:cpp-algorithm-min:0013 */}
2. 3,4) The smallest value in `ilist`. If several values are equivalent to the smallest, returns the leftmost such value.

### Complexity

{/* source:cpp-algorithm-min:0014 */}
1. 1) Exactly one comparison using `operator<`.

{/* source:cpp-algorithm-min:0015 */}
2. 2) Exactly one application of the comparison function `comp`.

{/* source:cpp-algorithm-min:0016 */}
3. 3,4) Given `N` as `ilist.size()`:

{/* source:cpp-algorithm-min:0017 */}
4. 3) Exactly `N-1` comparisons using `operator<`.

{/* source:cpp-algorithm-min:0018 */}
5. 4) Exactly `N-1` applications of the comparison function `comp`.

### Possible implementation

{/* source:cpp-algorithm-min:0019 */}
[`min (1)`](/docs/cpp/library/algorithm/min#Version_1)

```cpp
template<class T>
const T& min(const T& a, const T& b)
{
    return (b < a) ? b : a;
}
```

[`min (2)`](/docs/cpp/library/algorithm/min#Version_2)

```cpp
template<class T, class Compare>
const T& min(const T& a, const T& b, Compare comp)
{
    return (comp(b, a)) ? b : a;
}
```

[`min (3)`](/docs/cpp/library/algorithm/min#Version_3)

```cpp
template<class T>
T min(std::initializer_list<T> ilist)
{
    return *std::min_element(ilist.begin(), ilist.end());
}
```

[`min (4)`](/docs/cpp/library/algorithm/min#Version_4)

```cpp
template<class T, class Compare>
T min(std::initializer_list<T> ilist, Compare comp)
{
    return *std::min_element(ilist.begin(), ilist.end(), comp);
}
```

### Notes

{/* source:cpp-algorithm-min:0020 */}
Capturing the result of `std::min` by reference produces a dangling reference if one of the parameters is a temporary and that parameter is returned:

{/* source:cpp-algorithm-min:0021 */}
```cpp
int n = -1;
const int& r = std::min(n + 2, n * 2); // r is dangling
```

### Example

{/* source:cpp-algorithm-min:0022 */}
```cpp
#include <algorithm>
#include <iostream>
#include <string_view>
 
int main()
{
    std::cout << "smaller of 10 and 010 is " << std::min(10, 010) << '\n'
              << "smaller of 'd' and 'b' is '" << std::min('d', 'b') << "'\n"
              << "shortest of \"foo\", \"bar\", and \"hello\" is \""
              << std::min({"foo", "bar", "hello"},
                          [](const std::string_view s1, const std::string_view s2)
                          {
                              return s1.size() < s2.size();
                          }) << "\"\n";
}
```

Output:

```text
smaller of 10 and 010 is 8
smaller of 'd' and 'b' is 'b'
shortest of "foo", "bar", and "hello" is "foo"
```
