{/* source:cpp-algorithm-search-n:0001 */}
Searches the range `[first, last)` for the first sequence of `count` identical elements, each equal to the given `value`.

{/* source:cpp-algorithm-search-n:0002 */}
1. 1) Elements are compared using `operator==`.

{/* source:cpp-algorithm-search-n:0003 */}
2. 3) Elements are compared using the given binary predicate `p`.

{/* source:cpp-algorithm-search-n:0004 */}
3. 2,4) Same as (1,3), but executed according to `policy`.

{/* source:cpp-algorithm-search-n:0005 */}
4. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

### Parameters

{/* source:cpp-algorithm-search-n:0006 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to examine</Parameter>
  <Parameter name="count">the length of the sequence to search for</Parameter>
  <Parameter name="value">the value of the elements to search for</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="p">
binary predicate which returns `true` if the elements should be treated as equal.

The signature of the predicate function should be equivalent to the following:

`bool pred(const Type1 &a, const Type2 &b);`

While the signature does not need to have `const &`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1 &` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The type `Type1` must be such that an object of type `ForwardIt` can be dereferenced and then implicitly converted to `Type1`. The type `Type2` must be such that an object of type `T` can be implicitly converted to `Type2`.
  </Parameter>
</ParameterList>

**Type requirements**

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `BinaryPred` must meet the requirements of [*BinaryPredicate*](/docs/cpp/library/named_req/BinaryPredicate).
- `Size` must be [convertible](/docs/cpp/language/expressions/implicit_cast) to an [integral type](/docs/cpp/language/basic_concepts/type-id).

### Return value

{/* source:cpp-algorithm-search-n:0007 */}
If `count` is positive, returns an iterator to the beginning of the first sequence found in the range `[first, last)`. Each iterator `it` in the sequence should satisfy the following condition:

{/* source:cpp-algorithm-search-n:0008 */}
1. 1,2) `*it == value` is `true`.

{/* source:cpp-algorithm-search-n:0009 */}
2. 3,4) `p(*it, value) != false` is `true`.

{/* source:cpp-algorithm-search-n:0010 */}
If no such sequence is found, `last` is returned.

{/* source:cpp-algorithm-search-n:0011 */}
If `count` is zero or negative, `first` is returned.

### Complexity

{/* source:cpp-algorithm-search-n:0012 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-search-n:0013 */}
1. 1,2) At most `N` comparisons using `operator==`.

{/* source:cpp-algorithm-search-n:0014 */}
2. 3,4) At most `N` applications of the predicate `p`.

### Exceptions

{/* source:cpp-algorithm-search-n:0015 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-search-n:0016 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-search-n:0017 */}
[`search_n (1)`](/docs/cpp/library/algorithm/search_n#Version_1)

```cpp
template<class ForwardIt, class Size,
         class T = typename std::iterator_traits<ForwardIt>::value_type>
ForwardIt search_n(ForwardIt first, ForwardIt last, Size count, const T& value)
{
    if (count <= 0)
        return first;
 
    for (; first != last; ++first)
    {
        if (!(*first == value))
            continue;
 
        ForwardIt candidate = first;
 
        for (Size cur_count = 1; true; ++cur_count)
        {
            if (cur_count >= count)
                return candidate; // success
 
            ++first;
            if (first == last)
                return last; // exhausted the list
 
            if (!(*first == value))
                break; // too few in a row
        }
    }
    return last;
}
```

[`search_n (3)`](/docs/cpp/library/algorithm/search_n#Version_3)

```cpp
template<class ForwardIt, class Size,
         class T = typename std::iterator_traits<ForwardIt>::value_type,
         class BinaryPred>
ForwardIt search_n(ForwardIt first, ForwardIt last, Size count, const T& value,
                   BinaryPred p)
{
    if (count <= 0)
        return first;
 
    for (; first != last; ++first)
    {
        if (!p(*first, value))
            continue;
 
        ForwardIt candidate = first;
 
        for (Size cur_count = 1; true; ++cur_count)
        {
            if (cur_count >= count)
                return candidate; // success
 
            ++first;
            if (first == last)
                return last; // exhausted the list
 
            if (!p(*first, value))
                break; // too few in a row
        }
    }
    return last;
}
```

### Example

{/* source:cpp-algorithm-search-n:0019 */}
```cpp
#include <algorithm>
#include <cassert>
#include <complex>
#include <iostream>
#include <iterator>
#include <vector>
 
template<class Container, class Size, class T>
constexpr bool consecutive_values(const Container& c, Size count, const T& v)
{
    return std::search_n(std::begin(c), std::end(c), count, v) != std::end(c);
}
 
int main()
{
    constexpr char sequence[] = ".0_0.000.0_0.";
 
    static_assert(consecutive_values(sequence, 3, '0'));
 
    for (int n : {4, 3, 2})
        std::cout << std::boolalpha
                  << "Has " << n << " consecutive zeros: "
                  << consecutive_values(sequence, n, '0') << '\n';
 
    std::vector<std::complex<double>> nums{{4, 2}, {4, 2}, {1, 3}};
    #ifdef __cpp_lib_algorithm_default_value_type
        auto it = std::search_n(nums.cbegin(), nums.cend(), 2, {4, 2});
    #else
        auto it = std::search_n(nums.cbegin(), nums.cend(), 2, std::complex<double>{4, 2});
    #endif
    assert(it == nums.begin());
}
```

Output:

```text
Has 4 consecutive zeros: false
Has 3 consecutive zeros: true
Has 2 consecutive zeros: true
```
