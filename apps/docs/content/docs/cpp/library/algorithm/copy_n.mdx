{/* source:cpp-algorithm-copy-n:0001 */}
1. 1) Copies exactly `count` values from the range beginning at `first` to the range beginning at `result`. Formally, for each integer `i` in `[0, count)`, performs `*(result + i) = *(first + i)`.

{/* source:cpp-algorithm-copy-n:0002 */}
2. Overlap of ranges is formally permitted, but leads to unpredictable ordering of the results.

{/* source:cpp-algorithm-copy-n:0003 */}
3. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-algorithm-copy-n:0004 */}
4. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

### Parameters

{/* source:cpp-algorithm-copy-n:0005 */}
<ParameterList>
  <Parameter name="first">the beginning of the range of elements to copy from</Parameter>
  <Parameter name="count">number of the elements to copy</Parameter>
  <Parameter name="result">the beginning of the destination range</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
</ParameterList>

**Type requirements**

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `OutputIt` must meet the requirements of [*LegacyOutputIterator*](/docs/cpp/library/named_req/OutputIterator).
- `ForwardIt1, ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-algorithm-copy-n:0006 */}
Iterator in the destination range, pointing past the last element copied if `count > 0` or `result` otherwise.

### Complexity

{/* source:cpp-algorithm-copy-n:0007 */}
Zero assignments if `count < 0`; `count` assignments otherwise.

### Exceptions

{/* source:cpp-algorithm-copy-n:0008 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-algorithm-copy-n:0009 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-copy-n:0010 */}
```cpp
template<class InputIt, class Size, class OutputIt>
constexpr //< since C++20
OutputIt copy_n(InputIt first, Size count, OutputIt result)
{
    if (count > 0)
    {
        *result = *first;
        ++result;
        for (Size i = 1; i != count; ++i, ++result)
            *result = *++first;
    }
 
    return result;
}
```

### Example

{/* source:cpp-algorithm-copy-n:0011 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <numeric>
#include <string>
#include <vector>
 
int main()
{
    std::string in {"1234567890"};
    std::string out;
 
    std::copy_n(in.begin(), 4, std::back_inserter(out));
    std::cout << out << '\n';
 
    std::vector<int> v_in(128);
    std::iota(v_in.begin(), v_in.end(), 1);
    std::vector<int> v_out(v_in.size());
 
    std::copy_n(v_in.cbegin(), 100, v_out.begin());
    std::cout << std::accumulate(v_out.begin(), v_out.end(), 0) << '\n';
}
```

Output:

```text
1234
5050
```
