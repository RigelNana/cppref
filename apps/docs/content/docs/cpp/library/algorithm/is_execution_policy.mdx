{/* source:cpp-algorithm-is-execution-policy:0001 */}
Checks whether `T` is a standard or implementation-defined execution policy type.

{/* source:cpp-algorithm-is-execution-policy:0002 */}
Provides the member constant `value` which is equal to `true`, if `T` is [a standard execution policy type](/docs/cpp/library/algorithm/execution_policy_tag_t), or an implementation-defined execution policy type. Otherwise, `value` is equal to `false`.

{/* source:cpp-algorithm-is-execution-policy:0003 */}
If the program adds specializations for `std::is_execution_policy` or `std::is_execution_policy_v`, the behavior is undefined.
