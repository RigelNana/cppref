{/* source:cpp-algorithm-lower-bound:0001 */}
Searches for the first element in the partitioned range `[first, last)` which is not ordered before `value`.

{/* source:cpp-algorithm-lower-bound:0002 */}
1. 1) The order is determined by `operator<`:
   - Returns the first iterator `iter` in `[first, last)` where `bool(*iter < value)` is `false`, or `last` if no such `iter` exists. If the elements `elem` of `[first, last)` are not [partitioned](/docs/cpp/library/algorithm#Requirements) with respect to the expression `bool(elem < value)`, the behavior is undefined. <InlineRevision until="C++20" />
   - Equivalent to `std::lower_bound(first, last, value, std::less{})`. <InlineRevision since="C++20" />

{/* source:cpp-algorithm-lower-bound:0003 */}
2. 2) The order is determined by `comp`:

{/* source:cpp-algorithm-lower-bound:0004 */}
3. Returns the first iterator `iter` in `[first, last)` where `bool(comp(*iter, value))` is `false`, or `last` if no such `iter` exists.

{/* source:cpp-algorithm-lower-bound:0005 */}
4. If the elements `elem` of `[first, last)` are not [partitioned](/docs/cpp/library/algorithm#Requirements) with respect to the expression `bool(comp(elem, value))`, the behavior is undefined.

### Parameters

{/* source:cpp-algorithm-lower-bound:0006 */}
<ParameterList>
  <Parameter name="first, last">the partitioned range of elements to examine</Parameter>
  <Parameter name="value">value to compare the elements to</Parameter>
  <Parameter name="comp">
binary predicate which returns `true` if the first argument is ordered before the second.

The signature of the predicate function should be equivalent to the following:

` bool pred(const Type1 &a, const Type2 &b);`

While the signature does not need to have `const &`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1 &` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>).

The type `Type1` must be such that an object of type `ForwardIt` can be dereferenced and then implicitly converted to `Type1`. The type `Type2` must be such that an object of type `T` can be implicitly converted to `Type2`.
  </Parameter>
</ParameterList>

Type requirements
- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `Compare` must meet the requirements of [*BinaryPredicate*](/docs/cpp/library/named_req/BinaryPredicate). It is not required to satisfy [*Compare*](/docs/cpp/library/named_req/Compare).

### Return value

{/* source:cpp-algorithm-lower-bound:0007 */}
Iterator to the first element of the range `[first, last)` not ordered before `value`, or `last` if no such element is found.

### Complexity

{/* source:cpp-algorithm-lower-bound:0008 */}
Given N as `std::distance(first, last)`:

{/* source:cpp-algorithm-lower-bound:0009 */}
1. 1) At most log2(N)+O(1) comparisons with `value` using <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-lower-bound:0010 */}
2. 2) At most log2(N)+O(1) applications of the comparator `comp`.

{/* source:cpp-algorithm-lower-bound:0011 */}
However, if `ForwardIt` is not a [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator), the number of iterator increments is linear in N. Notably, [`std::map`](/docs/cpp/library/container/map), [`std::multimap`](/docs/cpp/library/container/multimap), [`std::set`](/docs/cpp/library/container/set), and [`std::multiset`](/docs/cpp/library/container/multiset) iterators are not random access, and so their member `lower_bound` functions should be preferred.

[`lower_bound (1)`](/docs/cpp/library/algorithm/lower_bound#Version_1)

```cpp
template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type>
ForwardIt lower_bound(ForwardIt first, ForwardIt last, const T& value)
{
    return std::lower_bound(first, last, value, std::less{});
}
```

[`lower_bound (2)`](/docs/cpp/library/algorithm/lower_bound#Version_2)

```cpp
template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type,
         class Compare>
ForwardIt lower_bound(ForwardIt first, ForwardIt last, const T& value, Compare comp)
{
    ForwardIt it;
    typename std::iterator_traits<ForwardIt>::difference_type count, step;
    count = std::distance(first, last);
 
    while (count > 0)
    {
        it = first;
        step = count / 2;
        std::advance(it, step);
 
        if (comp(*it, value))
        {
            first = ++it;
            count -= step + 1;
        }
        else
            count = step;
    }
 
    return first;
}
```

### Notes

{/* source:cpp-algorithm-lower-bound:0014 */}
Although `std::lower_bound` only requires `[first, last)` to be partitioned, this algorithm is usually used in the case where `[first, last)` is sorted, so that the binary search is valid for any `value`.

{/* source:cpp-algorithm-lower-bound:0015 */}
Unlike [`std::binary_search`](/docs/cpp/library/algorithm/binary_search), `std::lower_bound` does not require `operator<` or `comp` to be asymmetric (i.e., `a < b` and `b < a` always have different results). In fact, it does not even require `value < *iter` or `comp(value, *iter)` to be well-formed for any iterator `iter` in `[first, last)`.

### Example

{/* source:cpp-algorithm-lower-bound:0017 */}
```cpp
#include <algorithm>
#include <cassert>
#include <complex>
#include <iostream>
#include <vector>
 
struct PriceInfo { double price; };
 
int main()
{
    const std::vector<int> data{1, 2, 4, 5, 5, 6};
 
    for (int i = 0; i < 8; ++i)
    {
        // Search for first element x such that i ≤ x
        auto lower = std::lower_bound(data.begin(), data.end(), i);
 
        std::cout << i << " ≤ ";
        lower != data.end()
            ? std::cout << *lower << " at index " << std::distance(data.begin(), lower)
            : std::cout << "not found";
        std::cout << '\n';
    }
 
    std::vector<PriceInfo> prices{{100.0}, {101.5}, {102.5}, {102.5}, {107.3}};
 
    for (const double to_find : {102.5, 110.2})
    {
        auto prc_info = std::lower_bound(prices.begin(), prices.end(), to_find,
            [](const PriceInfo& info, double value)
            {
                return info.price < value;
            });
 
        prc_info != prices.end()
            ? std::cout << prc_info->price << " at index " << prc_info - prices.begin()
            : std::cout << to_find << " not found";
        std::cout << '\n';
    }
 
    using CD = std::complex<double>;
    std::vector<CD> nums{{1, 0}, {2, 2}, {2, 1}, {3, 0}};
    auto cmpz = [](CD x, CD y) { return x.real() < y.real(); };
    #ifdef __cpp_lib_algorithm_default_value_type
        auto it = std::lower_bound(nums.cbegin(), nums.cend(), {2, 0}, cmpz);
    #else
        auto it = std::lower_bound(nums.cbegin(), nums.cend(), CD{2, 0}, cmpz);
    #endif
    assert((*it == CD{2, 2}));
}
```

Output:

```text
0 ≤ 1 at index 0
1 ≤ 1 at index 0
2 ≤ 2 at index 1
3 ≤ 4 at index 2
4 ≤ 4 at index 2
5 ≤ 5 at index 3
6 ≤ 6 at index 5
7 ≤ not found
102.5 at index 2
110.2 not found
```
