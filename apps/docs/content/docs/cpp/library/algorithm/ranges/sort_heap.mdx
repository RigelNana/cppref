{/* source:cpp-algorithm-ranges-sort-heap:0001 */}
[Sorts](/docs/cpp/library/algorithm#Requirements) the elements in the specified range with respect to `comp` and `proj`, where the range originally represents a [heap](/docs/cpp/library/algorithm#Heap_operations) with respect to `comp` and `proj`. The sorted range no longer maintains the heap property.

{/* source:cpp-algorithm-ranges-sort-heap:0002 */}
1. 1) The specified range is `[first, last)`.

{/* source:cpp-algorithm-ranges-sort-heap:0003 */}
2. 2) The specified range is `r`.

{/* source:cpp-algorithm-ranges-sort-heap:0004 */}
If the specified range is not a heap with respect to `comp` and `proj`, the behavior is undefined.

{/* source:cpp-algorithm-ranges-sort-heap:0005 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-sort-heap:0006 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Parameters

{/* source:cpp-algorithm-ranges-sort-heap:0007 */}
<ParameterList>
  <Parameter name="first, last">the iterator and sentinel designating the range of elements to modify</Parameter>
  <Parameter name="r">the range of elements to modify</Parameter>
  <Parameter name="comp">comparator to apply to the projected elements</Parameter>
  <Parameter name="proj">projection to apply to the elements</Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-ranges-sort-heap:0008 */}
1. 1) `last`

{/* source:cpp-algorithm-ranges-sort-heap:0009 */}
2. 2) `ranges::end(r)`

### Complexity

{/* source:cpp-algorithm-ranges-sort-heap:0010 */}
At most 2N⋅log(N) applications of `comp` and 4N⋅log(N) applications of `proj`, where N is:

{/* source:cpp-algorithm-ranges-sort-heap:0011 */}
1. 1) `ranges::distance(first, last)`

{/* source:cpp-algorithm-ranges-sort-heap:0012 */}
2. 2) `ranges::distance(r)`

### Possible implementation

{/* source:cpp-algorithm-ranges-sort-heap:0013 */}
```cpp
struct sort_heap_fn
{
    template<std::random_access_iterator I, std::sentinel_for<I> S,
             class Comp = ranges::less, class Proj = std::identity>
        requires std::sortable<I, Comp, Proj>
    constexpr I operator()(I first, S last, Comp comp = {}, Proj proj = {}) const
    {
        auto ret{ranges::next(first, last)};
        for (; first != last; --last)
            ranges::pop_heap(first, last, comp, proj);
        return ret;
    }
 
    template<ranges::random_access_range R,
             class Comp = ranges::less, class Proj = std::identity>
        requires std::sortable<ranges::iterator_t<R>, Comp, Proj>
    constexpr ranges::borrowed_iterator_t<R>
        operator()(R&& r, Comp comp = {}, Proj proj = {}) const
    {
        return (*this)(ranges::begin(r), ranges::end(r), std::move(comp), std::move(proj));
    }
};
 
inline constexpr sort_heap_fn sort_heap{};
```

### Example

{/* source:cpp-algorithm-ranges-sort-heap:0014 */}
```cpp
#include <algorithm>
#include <array>
#include <iostream>
 
void print(auto const& rem, const auto& v)
{
    std::cout << rem;
    for (const auto i : v)
        std::cout << i << ' ';
    std::cout << '\n';
}
 
int main()
{
    std::array v{3, 1, 4, 1, 5, 9};
    print("original array:  ", v);
 
    std::ranges::make_heap(v);
    print("after make_heap: ", v);
 
    std::ranges::sort_heap(v);
    print("after sort_heap: ", v);
}
```

Output:

```text
original array:  3 1 4 1 5 9
after make_heap: 9 5 4 1 1 3
after sort_heap: 1 1 3 4 5 9
```
