{/* source:cpp-algorithm-ranges-fill-n:0001 */}
Assigns the given `value` to all elements in the range `[first, first + n)`.

{/* source:cpp-algorithm-ranges-fill-n:0002 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-fill-n:0003 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Parameters

{/* source:cpp-algorithm-ranges-fill-n:0004 */}
<ParameterList>
  <Parameter name="first">the beginning of the range of elements to modify</Parameter>
  <Parameter name="n">number of elements to modify</Parameter>
  <Parameter name="value">the value to be assigned</Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-ranges-fill-n:0005 */}
An output iterator that compares equal to `first + n`.

### Complexity

{/* source:cpp-algorithm-ranges-fill-n:0006 */}
Exactly `n` assignments.

### Possible implementation

{/* source:cpp-algorithm-ranges-fill-n:0007 */}
```cpp
struct fill_n_fn
{
    template<class O, class T = std::iter_value_t<O>>
    requires std::output_iterator<O, const T&>
    constexpr O operator()(O first, std::iter_difference_t<O> n, const T& value) const
    {
        for (std::iter_difference_t<O> i {}; i != n; ++first, ++i)
            *first = value;
        return first;
    }
};
 
inline constexpr fill_n_fn fill_n {};
```

### Example

{/* source:cpp-algorithm-ranges-fill-n:0009 */}
```cpp
#include <algorithm>
#include <complex>
#include <iostream>
#include <string>
#include <vector>
 
void println(const auto& v)
{
    for (const auto& elem : v)
        std::cout << ' ' << elem;
    std::cout << '\n';
}
 
int main()
{
    constexpr auto n{8};
 
    std::vector<std::string> v(n, "▓▓░░");
    println(v);
 
    std::ranges::fill_n(v.begin(), n, "░░▓▓");
    println(v);
 
    std::vector<std::complex<double>> nums{{1, 3}, {2, 2}, {4, 8}};
    println(nums);
    #ifdef __cpp_lib_algorithm_default_value_type
        std::ranges::fill_n(nums.begin(), 2, {4, 2});
    #else
        std::ranges::fill_n(nums.begin(), 2, std::complex<double>{4, 2});
    #endif
    println(nums);
}
```

Output:

```text
 ▓▓░░ ▓▓░░ ▓▓░░ ▓▓░░ ▓▓░░ ▓▓░░ ▓▓░░ ▓▓░░
 ░░▓▓ ░░▓▓ ░░▓▓ ░░▓▓ ░░▓▓ ░░▓▓ ░░▓▓ ░░▓▓
 (1,3) (2,2) (4,8)
 (4,2) (4,2) (4,8)
```
