{/* source:cpp-algorithm-ranges-generate-random:0001 */}
Attempts to generate random numbers with the `generate_random` member function of the random number generator or the distribution, which is expected to be more efficient. Falls back to element-wise generation if no `generate_random` member function is available.

{/* source:cpp-algorithm-ranges-generate-random:0002 */}
Let fallback operation be calling `ranges::generate(std::forward<R>(r), std::ref(g))` or `ranges::generate(std::forward<R>(r), [&d, &g] { return std::invoke(d, g); })` for (1) or (3) respectively.

{/* source:cpp-algorithm-ranges-generate-random:0003 */}
1. 1) Calls `g.generate_random(std::forward<R>(r))` if this expression is well-formed.

{/* source:cpp-algorithm-ranges-generate-random:0004 */}
2. Otherwise, let `I` be `std::invoke_result_t<G&>`. If `R` models [`sized_range`](/docs/cpp/library/ranges/sized_range), fills `r` with `ranges::size(r)` values of `I` by performing an unspecified number of invocations of the form `g()` or `g.generate_random(s)`, if such an expression is well-formed for a value `N` and an object `s` of type `std::span<I, N>`.

{/* source:cpp-algorithm-ranges-generate-random:0005 */}
3. Otherwise, performs the fallback operation.

{/* source:cpp-algorithm-ranges-generate-random:0006 */}
4. 3) Calls `d.generate_random(std::forward<R>(r), g)` if this expression is well-formed.

{/* source:cpp-algorithm-ranges-generate-random:0007 */}
5. Otherwise, let `I` be `std::invoke_result_t<D&, G&>`. If `R` models [`sized_range`](/docs/cpp/library/ranges/sized_range), fills `r` with `ranges::size(r)` values of type `I` by performing an unspecified number of invocations of the form `std::invoke(d, g)` or `d.generate_random(s, g)`, if such an expression is well-formed for a value `N` and an object `s` of type `std::span<I, N>`.

{/* source:cpp-algorithm-ranges-generate-random:0008 */}
6. Otherwise, performs the fallback operation.

{/* source:cpp-algorithm-ranges-generate-random:0009 */}
7. 2,4) Equivalent to (1,3) respectively, where `r` is obtained from `ranges::subrange<O, S>(std::move(first), last)`.

{/* source:cpp-algorithm-ranges-generate-random:0010 */}
If the effects of (1) or (3) are not equivalent to those of the corresponding fallback operation, the behavior is undefined.

{/* source:cpp-algorithm-ranges-generate-random:0011 */}
The value of `N` can differ between invocations. Implementations may select smaller values for shorter ranges.

{/* source:cpp-algorithm-ranges-generate-random:0012 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-generate-random:0013 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Notes

{/* source:cpp-algorithm-ranges-generate-random:0015 */}
At the time of the standardization of `std::ranges::generate_random`, there is no random number generator or distribution in the standard library that provides a `generate_random` member function.

{/* source:cpp-algorithm-ranges-generate-random:0016 */}
`std::ranges::generate_random` can be more efficient when used with a user-defined random number generator that wraps an underlying vectorized API.

### Example

{/* source:cpp-algorithm-ranges-generate-random:0018 */}
```cpp
#include <algorithm>
#include <iomanip>
#include <iostream>
#include <random>
 
int main()
{
    std::default_random_engine eng;
    std::default_random_engine::result_type rs[16]{};
    std::ranges::generate_random(rs, eng);
 
    std::cout << std::left;
    for (int i{}; auto n : rs)
        std::cout << std::setw(11) << n << (++i % 4 ? ' ' : '\n');
}
```
