{/* source:cpp-algorithm-ranges-make-heap:0001 */}
Constructs a [heap](/docs/cpp/library/algorithm#Heap_operations) with respect to `comp` and `proj` from the elements in the specified range.

{/* source:cpp-algorithm-ranges-make-heap:0002 */}
1. 1) The specified range is `[first, last)`.

{/* source:cpp-algorithm-ranges-make-heap:0003 */}
2. 2) The specified range is `r`.

{/* source:cpp-algorithm-ranges-make-heap:0004 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-make-heap:0005 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Parameters

{/* source:cpp-algorithm-ranges-make-heap:0006 */}
<ParameterList>
  <Parameter name="first, last">the iterator and sentinel designating the range of elements to modify</Parameter>
  <Parameter name="r">the range of elements to modify</Parameter>
  <Parameter name="comp">comparator to apply to the projected elements</Parameter>
  <Parameter name="proj">projection to apply to the elements</Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-ranges-make-heap:0007 */}
1. 1) `last`

{/* source:cpp-algorithm-ranges-make-heap:0008 */}
2. 2) `ranges::end(r)`

### Complexity

{/* source:cpp-algorithm-ranges-make-heap:0009 */}
At most 3·N applications of `comp` and 6·N applications of `proj`, where `N` is:

{/* source:cpp-algorithm-ranges-make-heap:0010 */}
1. 1) `ranges::distance(first, last)`

{/* source:cpp-algorithm-ranges-make-heap:0011 */}
2. 2) `ranges::distance(r)`

### Example

{/* source:cpp-algorithm-ranges-make-heap:0012 */}
```cpp
#include <algorithm>
#include <cmath>
#include <functional>
#include <iostream>
#include <vector>
 
void out(const auto& what, int n = 1)
{
    while (n-- > 0)
        std::cout << what;
}
 
void print(auto rem, const auto& v)
{
    out(rem);
    for (auto e : v)
        out(e), out(' ');
    out('\n');
}
 
void draw_heap(const auto& v)
{
    auto bails = [](int n, int w)
    {
        auto b = [](int w) { out("┌"), out("─", w), out("┴"), out("─", w), out("┐"); };
        if (!(n /= 2))
            return;
        for (out(' ', w); n-- > 0;)
            b(w), out(' ', w + w + 1);
        out('\n');
    };
 
    auto data = [](int n, int w, auto& first, auto last)
    {
        for (out(' ', w); n-- > 0 && first != last; ++first)
            out(*first), out(' ', w + w + 1);
        out('\n');
    };
 
    auto tier = [&](int t, int m, auto& first, auto last)
    {
        const int n{1 << t};
        const int w{(1 << (m - t - 1)) - 1};
        bails(n, w), data(n, w, first, last);
    };
 
    const int m{static_cast<int>(std::ceil(std::log2(1 + v.size())))};
    auto first{v.cbegin()};
    for (int i{}; i != m; ++i)
        tier(i, m, first, v.cend());
}
 
int main()
{
    std::vector h{1, 6, 1, 8, 0, 3, 3, 9, 8, 8, 7, 4, 9, 8, 9};
    print("source: ", h);
 
    std::ranges::make_heap(h);
    print("\n" "max-heap: ", h);
    draw_heap(h);
 
    std::ranges::make_heap(h, std::greater{});
    print("\n" "min-heap: ", h);
    draw_heap(h);
}
```
