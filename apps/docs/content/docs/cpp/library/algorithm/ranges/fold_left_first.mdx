{/* source:cpp-algorithm-ranges-fold-left-first:0001 */}
Left-[folds](https://en.wikipedia.org/wiki/Fold_(higher-order_function)) the elements of given range, that is, returns the result of evaluation of the chain expression: `f(f(f(f(x1, x2), x3), ...), xn)`, where `x1`, `x2`, ..., `xn` are elements of the range.

{/* source:cpp-algorithm-ranges-fold-left-first:0002 */}
Informally, `ranges::fold_left_first` behaves like [`std::accumulate`](/docs/cpp/library/numeric/accumulate)'s overload that accepts a binary predicate, except that the `*first` is used internally as an initial element.

{/* source:cpp-algorithm-ranges-fold-left-first:0003 */}
The behavior is undefined if [`first`, `last`) is not a valid range.

{/* source:cpp-algorithm-ranges-fold-left-first:0004 */}
1. 1) The range is [`first`, `last`). Equivalent to `return ranges::fold_left_first_with_iter(std::move(first), last, f).value`.

{/* source:cpp-algorithm-ranges-fold-left-first:0005 */}
2. 2) Same as (1), except that uses `r` as the range, as if by using `ranges::begin(r)` as `first` and `ranges::end(r)` as `last`.

### Return value

{/* source:cpp-algorithm-ranges-fold-left-first:0010 */}
An object of type `std::optional<U>` that contains the result of left-[fold](https://en.wikipedia.org/wiki/Fold_(higher-order_function)) of the given range over `f`, where `U` is equivalent to `decltype(ranges::fold_left(std::move(first), last, std::iter_value_t<I>(*first), f))`.

{/* source:cpp-algorithm-ranges-fold-left-first:0011 */}
If the range is empty, `std::optional<U>()` is returned.

### Possible implementations

{/* source:cpp-algorithm-ranges-fold-left-first:0012 */}
```cpp
struct fold_left_first_fn
{
    template<std::input_iterator I, std::sentinel_for<I> S,
             /*indirectly-binary-left-foldable*/<std::iter_value_t<I>, I> F>
    requires
        std::constructible_from<std::iter_value_t<I>, std::iter_reference_t<I>>
    constexpr auto operator()(I first, S last, F f) const
    {
        using U = decltype(
            ranges::fold_left(std::move(first), last, std::iter_value_t<I>(*first), f)
        );
        if (first == last)
            return std::optional<U>();
        std::optional<U> init(std::in_place, *first);
        for (++first; first != last; ++first)
            *init = std::invoke(f, std::move(*init), *first);
        return std::move(init);
    }
 
    template<ranges::input_range R,
             /*indirectly-binary-left-foldable*/<
                 ranges::range_value_t<R>, ranges::iterator_t<R>> F>
    requires
        std::constructible_from<ranges::range_value_t<R>, ranges::range_reference_t<R>>
    constexpr auto operator()(R&& r, F f) const
    {
        return (*this)(ranges::begin(r), ranges::end(r), std::ref(f));
    }
};
 
inline constexpr fold_left_first_fn fold_left_first;
```

### Complexity

{/* source:cpp-algorithm-ranges-fold-left-first:0013 */}
Exactly `ranges::distance(first, last) - 1` (assuming the range is not empty) applications of the function object `f`.

### Notes

{/* source:cpp-algorithm-ranges-fold-left-first:0014 */}
The following table compares all constrained folding algorithms:

{/* source:cpp-algorithm-ranges-fold-left-first:0015 */}

| --- | --- | --- | --- |
| `ranges::fold_left` | left | `init` | `U` |

| `ranges::fold_right_last` | right | last element | `std::optional<U>` |

### Example

{/* source:cpp-algorithm-ranges-fold-left-first:0017 */}
```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <ranges>
#include <utility>
#include <vector>
 
int main()
{
    std::vector v{1, 2, 3, 4, 5, 6, 7, 8};
 
    auto sum = std::ranges::fold_left_first(v.begin(), v.end(), std::plus<int>()); // (1)
    std::cout << "*sum: " << sum.value() << '\n';
 
    auto mul = std::ranges::fold_left_first(v, std::multiplies<int>()); // (2)
    std::cout << "*mul: " << mul.value() << '\n';
 
    // get the product of the std::pair::second of all pairs in the vector:
    std::vector<std::pair<char, float>> data {{'A', 3.f}, {'B', 3.5f}, {'C', 4.f}};
    auto sec = std::ranges::fold_left_first
    (
        data | std::ranges::views::values, std::multiplies<>()
    );
    std::cout << "*sec: " << *sec << '\n';
 
    // use a program defined function object (lambda-expression):
    auto val = std::ranges::fold_left_first(v, [](int x, int y) { return x + y + 13; });
    std::cout << "*val: " << *val << '\n';
}
```

Output:

```text
*sum: 36
*mul: 40320
*sec: 42
*val: 127
```
