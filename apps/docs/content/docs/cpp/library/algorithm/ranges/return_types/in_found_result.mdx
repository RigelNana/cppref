`ranges::in_found_result` is a class template that provides a way to store an iterator and a boolean flag as a single unit.

{/* source:cpp-algorithm-ranges-return-types-in-found-result:0002 */}
This class template has no base classes or declared members other than those shown below. Thus it is suitable for use with [structured bindings](/docs/cpp/language/declarations/structured_binding).

{/* source:cpp-algorithm-ranges-return-types-in-found-result:0003 */}
All special member functions of this class template are implicitly declared, which makes specializations be [aggregate classes](/docs/cpp/language/initialization/aggregate_initialization), and propagate triviality, potentially-throwing-ness, and constexpr-ness of corresponding operations on data members.

### Synopsis

{/* source:cpp-algorithm-ranges-return-types-in-found-result:0009 */}
```cpp
namespace std::ranges
{
    template<class I>
    struct in_found_result
    {
        [[no_unique_address]] I in;
        bool found;

        template<class I2>
        requires std::convertible_to<const I&, I2>
        constexpr operator in_found_result<I2>() const &
        {
            return {in, found};
        }

        template<class I2>
        requires std::convertible_to<I, I2>
        constexpr operator in_found_result<I2>() &&
        {
            return {std::move(in), found};
        }
    };
}
```

### Notes

{/* source:cpp-algorithm-ranges-return-types-in-found-result:0010 */}
Each standard library algorithm that uses this family of return types declares a new [alias type](/docs/cpp/language/declarations/type_alias), e.g. `using merge_result = in_in_out_result<I1, I2, O>;`.

{/* source:cpp-algorithm-ranges-return-types-in-found-result:0011 */}
The names for such aliases are formed by adding the suffix `_result` to the algorithm's name. So, the return type of `std::ranges::merge` can be named as `std::ranges::merge_result`.

{/* source:cpp-algorithm-ranges-return-types-in-found-result:0012 */}
Unlike [`std::pair`](/docs/cpp/library/utility/pair) and [`std::tuple`](/docs/cpp/library/utility/tuple), this class template has data members of meaningful names.

### Example

{/* source:cpp-algorithm-ranges-return-types-in-found-result:0013 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <ranges>

int main()
{
    int v[] {1, 2, 3};

    const auto result = std::ranges::next_permutation(v);

    std::ranges::for_each(std::cbegin(v), result.in, [](int e) {std::cout << e << ' ';});

    std::cout << std::boolalpha << "\n" "result.found: " << result.found << '\n';
}
```

Output:

```text
1 3 2 
result.found = true
```
