{/* source:cpp-algorithm-ranges-partial-sort:0001 */}
1. 1) Rearranges elements such that the range `[first, middle)` contains the sorted `middle - first` smallest elements in the range `[first, last)`.

{/* source:cpp-algorithm-ranges-partial-sort:0002 */}
2. The order of equal elements is *not* guaranteed to be preserved. The order of the remaining elements in the range `[middle, last)` is *unspecified*.

{/* source:cpp-algorithm-ranges-partial-sort:0003 */}
3. The elements are compared using the given binary comparison function `comp` and projected using `proj` function object.

{/* source:cpp-algorithm-ranges-partial-sort:0004 */}
4. 2) Same as (1), but uses `r` as the range, as if using `ranges::begin(r)` as `first` and `ranges::end(r)` as `last`.

{/* source:cpp-algorithm-ranges-partial-sort:0005 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-partial-sort:0006 */}
Explicit template argument lists cannot be specified when calling any of them.
None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Return value

{/* source:cpp-algorithm-ranges-partial-sort:0008 */}
An iterator equal to `last`.

### Complexity

{/* source:cpp-algorithm-ranges-partial-sort:0009 */}
𝓞(N·log(M)) comparisons and twice as many projections, where `N` is `ranges::distance(first, last)`, `M` is `ranges::distance(first, middle)`.

### Possible implementation

{/* source:cpp-algorithm-ranges-partial-sort:0010 */}
```cpp
struct partial_sort_fn
{
    template<std::random_access_iterator I, std::sentinel_for<I> S,
             class Comp = ranges::less, class Proj = std::identity>
    requires std::sortable<I, Comp, Proj>
    constexpr I
        operator()(I first, I middle, S last, Comp comp = {}, Proj proj = {}) const
    {
        if (first == middle)
            return ranges::next(first, last);
        ranges::make_heap(first, middle, comp, proj);
        auto it {middle};
        for (; it != last; ++it)
        {
            if (std::invoke(comp, std::invoke(proj, *it), std::invoke(proj, *first)))
            {
                ranges::pop_heap(first, middle, comp, proj);
                ranges::iter_swap(middle - 1, it);
                ranges::push_heap(first, middle, comp, proj);
            }
        }
        ranges::sort_heap(first, middle, comp, proj);
        return it;
    }
 
    template<ranges::random_access_range R, class Comp = ranges::less,
             class Proj = std::identity>
    requires std::sortable<ranges::iterator_t<R>, Comp, Proj>
    constexpr ranges::borrowed_iterator_t<R>
        operator()(R&& r, ranges::iterator_t<R> middle, Comp comp = {}, Proj proj = {}) const
    {
        return (*this)(ranges::begin(r), std::move(middle), ranges::end(r),
                       std::move(comp), std::move(proj));
    }
};
 
inline constexpr partial_sort_fn partial_sort {};
```

### Example

{/* source:cpp-algorithm-ranges-partial-sort:0011 */}
```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <string>
#include <vector>
 
void print(const auto& v)
{
    for (const char e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}
 
void underscore(int n)
{
    while (n-- > 0)
        std::cout << "^ ";
    std::cout << '\n';
}
 
int main()
{
    static_assert('A' < 'a');
    std::vector<char> v {'x', 'P', 'y', 'C', 'z', 'w', 'P', 'o'};
    print(v);
    const int m {3};
    std::ranges::partial_sort(v, v.begin() + m);
    print(v), underscore(m);
 
    static_assert('1' < 'a');
    std::string s {"3a1b41c5"};
    print(s);
    std::ranges::partial_sort(s.begin(), s.begin() + m, s.end(), std::greater {});
    print(s), underscore(m);
}
```
Output:
```text
x P y C z w P o
C P P y z x w o
^ ^ ^
3 a 1 b 4 1 c 5
c b a 1 3 1 4 5
^ ^ ^
```
