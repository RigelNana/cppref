{/* source:cpp-algorithm-ranges-copy-n:0001 */}
1. 1) Copies exactly `n` values from the range beginning at `first` to the range beginning at `result` by performing `*(result + i) = *(first + i)` for each integer in `[0, n)`. The behavior is undefined if `result` is within the range `[first, first + n)` ([`ranges::copy_backward`](/docs/cpp/library/algorithm/ranges/copy_backward) might be used instead in this case).

{/* source:cpp-algorithm-ranges-copy-n:0002 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-copy-n:0003 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Parameters

{/* source:cpp-algorithm-ranges-copy-n:0004 */}
<ParameterList>
  <Parameter name="first">the beginning of the range of elements to copy from</Parameter>
  <Parameter name="n">number of the elements to copy</Parameter>
  <Parameter name="result">the beginning of the destination range</Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-ranges-copy-n:0005 */}
`ranges::copy_n_result{first + n, result + n}` or more formally, a value of type [`ranges::in_out_result`](/docs/cpp/library/algorithm/ranges/return_types/in_out_result) that contains an [`std::input_iterator`](/docs/cpp/library/iterator/input_iterator) iterator equals to `ranges::next(first, n)` and a [`std::weakly_incrementable`](/docs/cpp/library/iterator/weakly_incrementable) iterator equals to `ranges::next(result, n)`.

### Complexity

{/* source:cpp-algorithm-ranges-copy-n:0006 */}
Exactly `n` assignments.

### Notes

{/* source:cpp-algorithm-ranges-copy-n:0007 */}
In practice, implementations of `std::ranges::copy_n` may avoid multiple assignments and use bulk copy functions such as [`std::memmove`](/docs/cpp/library/text/byte/memmove) if the value type is [*TriviallyCopyable*](/docs/cpp/library/named_req/TriviallyCopyable) and the iterator types satisfy [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator). Alternatively, such copy acceleration can be injected during an optimization phase of a compiler.

{/* source:cpp-algorithm-ranges-copy-n:0008 */}
When copying overlapping ranges, `std::ranges::copy_n` is appropriate when copying to the left (beginning of the destination range is outside the source range) while `std::ranges::copy_backward` is appropriate when copying to the right (end of the destination range is outside the source range).

### Possible implementation

{/* source:cpp-algorithm-ranges-copy-n:0009 */}
```cpp
struct copy_n_fn
{
    template<std::input_iterator I, std::weakly_incrementable O>
    requires std::indirectly_copyable<I, O>
    constexpr ranges::copy_n_result<I, O>
        operator()(I first, std::iter_difference_t<I> n, O result) const
    {
        for (std::iter_difference_t<I> i {}; i != n; ++i, ++first, ++result)
            *result = *first;
        return {std::move(first), std::move(result)};
    }
};
 
inline constexpr copy_n_fn copy_n {};
```

### Example

{/* source:cpp-algorithm-ranges-copy-n:0010 */}
```cpp
#include <algorithm>
#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>
#include <string_view>
 
int main()
{
    const std::string_view in {"ABCDEFGH"};
    std::string out;
 
    std::ranges::copy_n(in.begin(), 4, std::back_inserter(out));
    std::cout << std::quoted(out) << '\n';
 
    out = "abcdefgh";
    const auto res = std::ranges::copy_n(in.begin(), 5, out.begin());
    std::cout
        << "*(res.in): '" << *(res.in) << "', distance: "
        << std::distance(std::begin(in), res.in) << '\n'
        << "*(res.out): '" << *(res.out) << "', distance: "
        << std::distance(std::begin(out), res.out) << '\n';
}
```

Output:

```text
"ABCD"
*(res.in): 'F', distance: 5
*(res.out): 'f', distance: 5
```
