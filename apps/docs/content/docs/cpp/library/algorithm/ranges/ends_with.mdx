{/* source:cpp-algorithm-ranges-ends-with:0001 */}
Checks whether the second range matches the suffix of the first range.

{/* source:cpp-algorithm-ranges-ends-with:0002 */}
1. 1) Let `N1` be `ranges::distance(first1, last1)` and `N2` be `ranges::distance(first2, last2)`: If `N1 < N2` is `true`, returns `false`. Otherwise, returns `ranges::equal(std::move(first1) + (N1 - N2), last1, std::move(first2), last2, pred, proj1, proj2)`.

{/* source:cpp-algorithm-ranges-ends-with:0003 */}
2. 2) Let `N1` be `ranges::distance(r1)` and `N2` be `ranges::distance(r2)`. If `N1 < N2` is `true`, returns `false`. Otherwise, returns `ranges::equal(views::drop(ranges::ref_view(r1), N1 - static_cast<decltype(N1)>(N2)), r2, pred, proj1, proj2)`.

{/* source:cpp-algorithm-ranges-ends-with:0004 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-ends-with:0005 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Return value

{/* source:cpp-algorithm-ranges-ends-with:0007 */}
`true` if the second range matches the suffix of the first range, `false` otherwise.

### Complexity

{/* source:cpp-algorithm-ranges-ends-with:0008 */}
Generally linear: at most `min(N1,N2)` applications of the predicate and both projections. The predicate and both projections are not applied if `N1 < N2` is `true`.

{/* source:cpp-algorithm-ranges-ends-with:0009 */}
If both `N1` and `N2` can be calculated in constant time (i.e. both iterator-sentinel type pairs model [`sized_sentinel_for`](/docs/cpp/library/iterator/sized_sentinel_for), or both range types model [`sized_range`](/docs/cpp/library/ranges/sized_range)) and `N1 < N2` is `true`, the time complexity is constant.

### Possible implementation

{/* source:cpp-algorithm-ranges-ends-with:0010 */}
```cpp
struct ends_with_fn
{
    template<std::input_iterator I1, std::sentinel_for<I1> S1,
             std::input_iterator I2, std::sentinel_for<I2> S2,
             class Pred = ranges::equal_to,
             class Proj1 = std::identity, class Proj2 = std::identity>
    requires (std::forward_iterator<I1> || std::sized_sentinel_for<S1, I1>) &&
             (std::forward_iterator<I2> || std::sized_sentinel_for<S2, I2>) &&
             std::indirectly_comparable<I1, I2, Pred, Proj1, Proj2>
    constexpr bool operator()(I1 first1, S1 last1, I2 first2, S2 last2,
                              Pred pred = {}, Proj1 proj1 = {}, Proj2 proj2 = {}) const
    {
        const auto n1 = ranges::distance(first1, last1);
        const auto n2 = ranges::distance(first2, last2);
        if (n1 < n2)
            return false;
        ranges::advance(first1, n1 - n2);
        return ranges::equal(std::move(first1), last1,
                             std::move(first2), last2,
                             pred, proj1, proj2);
    }
 
    template<ranges::input_range R1, ranges::input_range R2,
             class Pred = ranges::equal_to,
             class Proj1 = std::identity, class Proj2 = std::identity>
    requires (ranges::forward_range<R1> || ranges::sized_range<R1>) &&
             (ranges::forward_range<R2> || ranges::sized_range<R2>) &&
             std::indirectly_comparable<ranges::iterator_t<R1>,
                                        ranges::iterator_t<R2>,
                                        Pred, Proj1, Proj2>
    constexpr bool operator()(R1&& r1, R2&& r2,
                              Pred pred = {}, Proj1 proj1 = {}, Proj2 proj2 = {}) const
    {
        const auto n1 = ranges::distance(r1);
        const auto n2 = ranges::distance(r2);
        if (n1 < n2)
            return false;
        return ranges::equal(views::drop(ranges::ref_view(r1),
                                         n1 - static_cast<decltype(n1)>(n2)),
                             r2, pred, proj1, proj2);
    }
};
 
inline constexpr ends_with_fn ends_with{};
```

### Example

{/* source:cpp-algorithm-ranges-ends-with:0012 */}
```cpp
#include <algorithm>
#include <array>
 
static_assert
(
    ! std::ranges::ends_with("for", "cast") &&
    std::ranges::ends_with("dynamic_cast", "cast") &&
    ! std::ranges::ends_with("as_const", "cast") &&
    std::ranges::ends_with("bit_cast", "cast") &&
    ! std::ranges::ends_with("to_underlying", "cast") &&
    std::ranges::ends_with(std::array{1, 2, 3, 4}, std::array{3, 4}) &&
    ! std::ranges::ends_with(std::array{1, 2, 3, 4}, std::array{4, 5})
);
 
int main() {}
```
