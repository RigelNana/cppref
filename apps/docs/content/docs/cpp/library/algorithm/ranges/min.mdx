{/* source:cpp-algorithm-ranges-min:0001 */}
Returns the smaller of the given projected elements.

{/* source:cpp-algorithm-ranges-min:0002 */}
1. 1) Returns the smaller of `a` and `b`.

{/* source:cpp-algorithm-ranges-min:0003 */}
2. 2) Returns the first smallest element in the initializer list `r`.

{/* source:cpp-algorithm-ranges-min:0004 */}
3. 3) Returns the first smallest value in the range `r`.

{/* source:cpp-algorithm-ranges-min:0005 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-min:0006 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Parameters

{/* source:cpp-algorithm-ranges-min:0007 */}
<ParameterList>
  <Parameter name="a, b">the values to compare</Parameter>
  <Parameter name="r">the range of values to compare</Parameter>
  <Parameter name="comp">comparison to apply to the projected elements</Parameter>
  <Parameter name="proj">projection to apply to the elements</Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-ranges-min:0008 */}
1. 1) The smaller of `a` and `b`, according to the projection. If they are equivalent, returns `a`.

{/* source:cpp-algorithm-ranges-min:0009 */}
2. 2,3) The smallest element in `r`, according to the projection. If several values are equivalent to the smallest, returns the leftmost one. If the range is empty (as determined by `ranges::distance(r)`), the behavior is undefined.

### Complexity

{/* source:cpp-algorithm-ranges-min:0010 */}
1. 1) Exactly one comparison.

{/* source:cpp-algorithm-ranges-min:0011 */}
2. 2,3) Exactly `ranges::distance(r) - 1` comparisons.

### Possible implementation

{/* source:cpp-algorithm-ranges-min:0012 */}
```cpp
struct min_fn
{
    template<class T, class Proj = std::identity,
             std::indirect_strict_weak_order<
                 std::projected<const T*, Proj>> Comp = ranges::less>
    constexpr
    const T& operator()(const T& a, const T& b, Comp comp = {}, Proj proj = {}) const
    {
        return std::invoke(comp, std::invoke(proj, b), std::invoke(proj, a)) ? b : a;
    }
 
    template<std::copyable T, class Proj = std::identity,
             std::indirect_strict_weak_order<
                 std::projected<const T*, Proj>> Comp = ranges::less>
    constexpr
    T operator()(std::initializer_list<T> r, Comp comp = {}, Proj proj = {}) const
    {
        return *ranges::min_element(r, std::ref(comp), std::ref(proj));
    }
 
    template<ranges::input_range R, class Proj = std::identity,
             std::indirect_strict_weak_order<
                  std::projected<ranges::iterator_t<R>, Proj>> Comp = ranges::less>
    requires std::indirectly_copyable_storable<ranges::iterator_t<R>,
                                               ranges::range_value_t<R>*>
    constexpr
    ranges::range_value_t<R> operator()(R&& r, Comp comp = {}, Proj proj = {}) const
    {
        using V = ranges::range_value_t<R>;
        if constexpr (ranges::forward_range<R>)
            return
                static_cast<V>(*ranges::min_element(r, std::ref(comp), std::ref(proj)));
        else
        {
            auto i = ranges::begin(r);
            auto s = ranges::end(r);
            V m(*i);
            while (++i != s)
                if (std::invoke(comp, std::invoke(proj, *i), std::invoke(proj, m)))
                    m = *i;
            return m;
        }
    }
};
 
inline constexpr min_fn min;
```

### Notes

{/* source:cpp-algorithm-ranges-min:0013 */}
Capturing the result of `std::ranges::min` by reference produces a dangling reference if one of the parameters is a temporary and that parameter is returned:

{/* source:cpp-algorithm-ranges-min:0014 */}
```cpp
int n = -1;
const int& r = std::ranges::min(n + 2, n * 2); // r is dangling
```

### Example

{/* source:cpp-algorithm-ranges-min:0015 */}
```cpp
#include <algorithm>
#include <iostream>
#include <string>
 
int main()
{
    namespace ranges = std::ranges;
    using namespace std::string_view_literals;
 
    std::cout << "smaller of 1 and 9999: " << ranges::min(1, 9999) << '\n'
              << "smaller of 'a', and 'b': '" << ranges::min('a', 'b') << "'\n"
              << "shortest of \"foo\", \"bar\", and \"hello\": \""
              << ranges::min({"foo"sv, "bar"sv, "hello"sv}, {},
                             &std::string_view::size) << "\"\n";
}
```

Output:

```text
smaller of 1 and 9999: 1
smaller of 'a', and 'b': 'a'
shortest of "foo", "bar", and "hello": "foo"
```
