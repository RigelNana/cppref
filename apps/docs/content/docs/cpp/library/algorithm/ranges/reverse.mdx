{/* source:cpp-algorithm-ranges-reverse:0001 */}
1. 1) Reverses the order of the elements in the range `[first, last)`.

{/* source:cpp-algorithm-ranges-reverse:0002 */}
2. Behaves as if applying [`ranges::iter_swap`](/docs/cpp/library/iterator/ranges/iter_swap) to every pair of iterators `first + i, last - i - 1` for each integer `i`, where `0 ≤ i < (last - first) / 2`.

{/* source:cpp-algorithm-ranges-reverse:0003 */}
3. 2) Same as (1), but uses `r` as the range, as if using `ranges::begin(r)` as `first` and `ranges::end(r)` as `last`.

{/* source:cpp-algorithm-ranges-reverse:0004 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-reverse:0005 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Return value

{/* source:cpp-algorithm-ranges-reverse:0007 */}
An iterator equal to `last`.

### Complexity

{/* source:cpp-algorithm-ranges-reverse:0008 */}
Exactly `(last - first) / 2` swaps.

### Notes

{/* source:cpp-algorithm-ranges-reverse:0009 */}
Implementations (e.g. [MSVC STL](https://github.com/microsoft/STL/blob/main/stl/src/vector_algorithms.cpp)) may enable vectorization when the iterator type models [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator) and swapping its value type calls neither non-trivial special member function nor [ADL](/docs/cpp/language/functions/adl)-found `swap`.

### Possible implementation

{/* source:cpp-algorithm-ranges-reverse:0010 */}
See also implementations in [libstdc++](https://github.com/gcc-mirror/gcc/blob/14d8a5ae472ca5743016f37da2dd4770d83dea21/libstdc%2B%2B-v3/include/bits/ranges_algo.h#L1278-L1325) and [MSVC STL](https://github.com/microsoft/STL/blob/472161105d596192194d4715ccad307c6c163b4a/stl/inc/algorithm#L4154-L4180).

{/* source:cpp-algorithm-ranges-reverse:0011 */}
```cpp
struct reverse_fn
{
    template<std::bidirectional_iterator I, std::sentinel_for<I> S>
    requires std::permutable<I>
    constexpr I operator()(I first, S last) const
    {
        auto last2 {ranges::next(first, last)};
        for (auto tail {last2}; !(first == tail or first == --tail); ++first)
            ranges::iter_swap(first, tail);
        return last2;
    }
 
    template<ranges::bidirectional_range R>
    requires std::permutable<ranges::iterator_t<R>>
    constexpr ranges::borrowed_iterator_t<R>
        operator()(R&& r) const
    {
        return (*this)(ranges::begin(r), ranges::end(r));
    }
};
 
inline constexpr reverse_fn reverse {};
```

### Example

{/* source:cpp-algorithm-ranges-reverse:0012 */}
```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <string>
 
int main()
{
    std::string s {"ABCDEF"};
    std::cout << s << " → ";
    std::ranges::reverse(s.begin(), s.end());
    std::cout << s << " → ";
    std::ranges::reverse(s);
    std::cout << s << " │ ";
 
    std::array a {1, 2, 3, 4, 5};
    for (auto e : a)
        std::cout << e << ' ';
    std::cout << "→ ";
    std::ranges::reverse(a);
    for (auto e : a)
        std::cout << e << ' ';
    std::cout << '\n';
}
```

Output:

```text
ABCDEF → FEDCBA → ABCDEF │ 1 2 3 4 5 → 5 4 3 2 1
```
