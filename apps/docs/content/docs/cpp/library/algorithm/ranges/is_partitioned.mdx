{/* source:cpp-algorithm-ranges-is-partitioned:0001 */}
1. 1) Returns `true` if all elements in the range `[first, last)` that satisfy the predicate `pred` after projection appear before all elements that don't. Also returns `true` if `[first, last)` is empty.

{/* source:cpp-algorithm-ranges-is-partitioned:0002 */}
2. 2) Same as (1), but uses `r` as the source range, as if using `ranges::begin(r)` as `first` and `ranges::end(r)` as `last`.

{/* source:cpp-algorithm-ranges-is-partitioned:0003 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-is-partitioned:0004 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Return value

{/* source:cpp-algorithm-ranges-is-partitioned:0006 */}
`true` if the range `[first, last)` is empty or is partitioned by `pred`, `false` otherwise.

### Complexity

{/* source:cpp-algorithm-ranges-is-partitioned:0007 */}
At most `ranges::distance(first, last)` applications of `pred` and `proj`.

### Possible implementation

{/* source:cpp-algorithm-ranges-is-partitioned:0008 */}
```cpp
struct is_partitioned_fn
{
    template<std::input_iterator I, std::sentinel_for<I> S, class Proj = std::identity,
             std::indirect_unary_predicate<std::projected<I, Proj>> Pred>
    constexpr bool operator()(I first, S last, Pred pred, Proj proj = {}) const
    {
        for (; first != last; ++first)
            if (!std::invoke(pred, std::invoke(proj, *first)))
                break;
 
        for (; first != last; ++first)
            if (std::invoke(pred, std::invoke(proj, *first)))
                return false;
 
        return true;
    }
 
    template<ranges::input_range R, class Proj = std::identity,
             std::indirect_unary_predicate<std::projected<ranges::iterator_t<R>, Proj>> Pred>
    constexpr bool operator()(R&& r, Pred pred, Proj proj = {}) const
    {
        return (*this)(ranges::begin(r), ranges::end(r), std::ref(pred), std::ref(proj));
    }
};
 
inline constexpr auto is_partitioned = is_partitioned_fn();
```

### Example

{/* source:cpp-algorithm-ranges-is-partitioned:0009 */}
```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <numeric>
#include <utility>
 
int main()
{
    std::array<int, 9> v;
 
    auto print = [&v](bool o)
    {
        for (int x : v)
            std::cout << x << ' ';
        std::cout << (o ? "=> " : "=> not ") << "partitioned\n";
    };
 
    auto is_even = [](int i) { return i % 2 == 0; };
 
    std::iota(v.begin(), v.end(), 1); // or std::ranges::iota(v, 1);
    print(std::ranges::is_partitioned(v, is_even));
 
    std::ranges::partition(v, is_even);
    print(std::ranges::is_partitioned(std::as_const(v), is_even));
 
    std::ranges::reverse(v);
    print(std::ranges::is_partitioned(v.cbegin(), v.cend(), is_even));
    print(std::ranges::is_partitioned(v.crbegin(), v.crend(), is_even));
}
```

Output:

```text
1 2 3 4 5 6 7 8 9 => not partitioned
2 4 6 8 5 3 7 1 9 => partitioned
9 1 7 3 5 8 6 4 2 => not partitioned
9 1 7 3 5 8 6 4 2 => partitioned
```
