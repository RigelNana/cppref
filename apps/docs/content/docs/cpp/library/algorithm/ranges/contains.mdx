{/* source:cpp-algorithm-ranges-contains:0001 */}
1. 1) Search-based algorithm that checks whether or not a given range contains a value with iterator-sentinel pairs.

{/* source:cpp-algorithm-ranges-contains:0002 */}
2. 2) Same as (1) but uses `r` as the source range, as if using `ranges::begin(r)` as `first` and `ranges::end(r)` as `last`.

{/* source:cpp-algorithm-ranges-contains:0003 */}
3. 3) Search-based algorithm that checks whether or not a given range is a subrange of another range with iterator-sentinel pairs.

{/* source:cpp-algorithm-ranges-contains:0004 */}
4. 4) Same as (3) but uses `r1` as the first source range and `r2` as the second source range, as if using `ranges::begin(r1)` as `first1`, `ranges::end(r1)` as `last1`, `ranges::begin(r2)` as `first2`, and `ranges::end(r2)` as `last2`.

{/* source:cpp-algorithm-ranges-contains:0005 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-contains:0006 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Return value

{/* source:cpp-algorithm-ranges-contains:0008 */}
1. 1,2) : `ranges::find(std::move(first), last, value, proj) != last`

{/* source:cpp-algorithm-ranges-contains:0009 */}
2. 3,4) : `first2 == last2 || !ranges::search(first1, last1, first2, last2, pred, proj1, proj2).empty()`

### Complexity

{/* source:cpp-algorithm-ranges-contains:0010 */}
At most `last - first` applications of the predicate and projection.

### Notes

{/* source:cpp-algorithm-ranges-contains:0011 */}
Up until C++20, we've had to write `std::ranges::find(r, value) != std::ranges::end(r)` to determine if a single value is inside a range. And to check if a range contains a subrange of interest, we use `not std::ranges::search(haystack, needle).empty()`. While this is accurate, it isn't necessarily convenient, and it hardly expresses intent (especially in the latter case). Being able to say `std::ranges::contains(r, value)` addresses both of these points.

{/* source:cpp-algorithm-ranges-contains:0012 */}
`ranges::contains_subrange`, same as [`ranges::search`](/docs/cpp/library/algorithm/ranges/search), but as opposed to [`std::search`](/docs/cpp/library/algorithm/search), provides no access to [Searchers](https://en.cppreference.com/mwiki/index.php?title=cpp/named_req/Searcher&action=edit&redlink=1) (such as [Boyer-Moore](/docs/cpp/library/utility/functional#Searchers)).

### Possible implementation

{/* source:cpp-algorithm-ranges-contains:0014 */}
[`contains (1,2)`](/docs/cpp/library/algorithm/ranges/contains#Version_1)

```cpp
struct __contains_fn
{
    template<std::input_iterator I, std::sentinel_for<I> S,
             class Proj = std::identity,
             class T = std::projected_value_t<I, Proj>>
    requires std::indirect_binary_predicate<ranges::equal_to, std::projected<I, Proj>,
                                            const T*>
    constexpr bool operator()(I first, S last, const T& value, Proj proj = {}) const
    {
        return ranges::find(std::move(first), last, value, proj) != last;
    }
 
    template<ranges::input_range R,
             class Proj = std::identity,
             class T = std::projected_value_t<ranges::iterator_t<R>, Proj>>
    requires std::indirect_binary_predicate<ranges::equal_to,
                                            std::projected<ranges::iterator_t<R>, Proj>,
                                            const T*>
    constexpr bool operator()(R&& r, const T& value, Proj proj = {}) const
    {
        return (*this)(ranges::begin(r), ranges::end(r), std::move(value), proj);
    }
};
 
inline constexpr __contains_fn contains {};
```

[`contains_subrange (3,4)`](/docs/cpp/library/algorithm/ranges/contains#Version_3)

```cpp
struct __contains_subrange_fn
{
    template<std::forward_iterator I1, std::sentinel_for<I1> S1,
             std::forward_iterator I2, std::sentinel_for<I2> S2,
             class Pred = ranges::equal_to,
             class Proj1 = std::identity, class Proj2 = std::identity>
    requires std::indirectly_comparable<I1, I2, Pred, Proj1, Proj2>
    constexpr bool operator()(I1 first1, S1 last1,
                              I2 first2, S2 last2,
                              Pred pred = {},
                              Proj1 proj1 = {}, Proj2 proj2 = {}) const
    {
        return (first2 == last2) ||
               !ranges::search(first1, last1, first2, last2, pred, proj1, proj2).empty();
    }
 
    template<ranges::forward_range R1, ranges::forward_range R2,
             class Pred = ranges::equal_to,
             class Proj1 = std::identity, class Proj2 = std::identity>
    requires std::indirectly_comparable<ranges::iterator_t<R1>,
                                        ranges::iterator_t<R2>, Pred, Proj1, Proj2>
    constexpr bool operator()(R1&& r1, R2&& r2,
                              Pred pred = {},
                              Proj1 proj1 = {}, Proj2 proj2 = {}) const
    {
        return (*this)(ranges::begin(r1), ranges::end(r1),
                       ranges::begin(r2), ranges::end(r2), std::move(pred),
                       std::move(proj1), std::move(proj2));
    }
};
 
inline constexpr __contains_subrange_fn contains_subrange {};
```

### Example

{/* source:cpp-algorithm-ranges-contains:0015 */}
```cpp
#include <algorithm>
#include <array>
#include <complex>
 
namespace ranges = std::ranges;
 
int main()
{
    constexpr auto haystack = std::array{3, 1, 4, 1, 5};
    constexpr auto needle = std::array{1, 4, 1};
    constexpr auto bodkin = std::array{2, 5, 2};
 
    static_assert(
        ranges::contains(haystack, 4) &&
       !ranges::contains(haystack, 6) &&
        ranges::contains_subrange(haystack, needle) &&
       !ranges::contains_subrange(haystack, bodkin)
    );
 
    constexpr std::array<std::complex<double>, 3> nums{{{1, 2}, {3, 4}, {5, 6}}};
    #ifdef __cpp_lib_algorithm_default_value_type
        static_assert(ranges::contains(nums, {3, 4}));
    #else
        static_assert(ranges::contains(nums, std::complex<double>{3, 4}));
    #endif
}
```
