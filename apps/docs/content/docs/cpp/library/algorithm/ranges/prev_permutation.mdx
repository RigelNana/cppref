{/* source:cpp-algorithm-ranges-prev-permutation:0001 */}
1. 1) Transforms the range `[first, last)` into the previous [permutation](https://en.wikipedia.org/wiki/permutation), where the set of all permutations is ordered [lexicographically](https://en.wikipedia.org/wiki/Lexicographic_order) with respect to binary comparison function object `comp` and projection function object `proj`.

{/* source:cpp-algorithm-ranges-prev-permutation:0002 */}
2. Returns: `{last, true}` if "previous" permutation exists. Otherwise, `{last, false}`, and transforms the range into the (lexicographically) last permutation, as if by

   ```cpp
   ranges::sort(first, last, comp, proj);
   ranges::reverse(first, last);
   ```

{/* source:cpp-algorithm-ranges-prev-permutation:0003 */}
3. 2) Same as (1), but uses `r` as the source range, as if using `ranges::begin(r)` as `first`, and `ranges::end(r)` as `last`.

{/* source:cpp-algorithm-ranges-prev-permutation:0004 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-algorithm-ranges-prev-permutation:0005 */}
Explicit template argument lists cannot be specified when calling any of them.
None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Parameters

{/* source:cpp-algorithm-ranges-prev-permutation:0006 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to "permute"</Parameter>
  <Parameter name="r">the range of elements to "permute"</Parameter>
  <Parameter name="comp">comparison function object which returns `true` if the first argument is less than the second</Parameter>
  <Parameter name="proj">projection to apply to the elements</Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-ranges-prev-permutation:0007 */}
1. 1) `ranges::prev_permutation_result<I>{last, true}` if the new permutation is lexicographically less than the old one. `ranges::prev_permutation_result<I>{last, false}` if the first permutation was reached and the range was reset to the last permutation.

{/* source:cpp-algorithm-ranges-prev-permutation:0008 */}
2. 2) Same as (1) except that the return type is `ranges::prev_permutation_result<ranges::borrowed_iterator_t<R>>`.

### Exceptions

{/* source:cpp-algorithm-ranges-prev-permutation:0009 */}
Any exceptions thrown from iterator operations or the element swap.

### Complexity

{/* source:cpp-algorithm-ranges-prev-permutation:0010 */}
At most `N / 2` swaps, where `N` is `ranges::distance(first, last)` in case (1) or `ranges::distance(r)` in case (2). Averaged over the entire sequence of permutations, typical implementations use about 3 comparisons and 1.5 swaps per call.

### Notes

{/* source:cpp-algorithm-ranges-prev-permutation:0011 */}
Implementations (e.g. [MSVC STL](https://github.com/microsoft/STL/blob/main/stl/src/vector_algorithms.cpp)) may enable vectorization when the iterator type models [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator) and swapping its value type calls neither non-trivial special member function nor [ADL](/docs/cpp/language/functions/adl)-found swap.

### Possible implementation

{/* source:cpp-algorithm-ranges-prev-permutation:0012 */}
```cpp
struct prev_permutation_fn
{
    template<std::bidirectional_iterator I, std::sentinel_for<I> S,
             class Comp = ranges::less, class Proj = std::identity>
    requires std::sortable<I, Comp, Proj>
    constexpr ranges::prev_permutation_result<I>
        operator()(I first, S last, Comp comp = {}, Proj proj = {}) const
    {
        // check that the sequence has at least two elements
        if (first == last)
            return {std::move(first), false};
        auto i{first};
        ++i;
        if (i == last)
            return {std::move(i), false};
        auto i_last{ranges::next(first, last)};
        i = i_last;
        --i;
        // main "permutating" loop
        for (;;)
        {
            auto i1{i};
            --i;
            if (std::invoke(comp, std::invoke(proj, *i1), std::invoke(proj, *i)))
            {
                auto j{i_last};
                while (!std::invoke(comp, std::invoke(proj, *--j), std::invoke(proj, *i)))
                    ;
                ranges::iter_swap(i, j);
                ranges::reverse(i1, last);
                return {std::move(i_last), true};
            }
            // permutation "space" is exhausted
            if (i == first)
            {
                ranges::reverse(first, last);
                return {std::move(i_last), false};
            }
        }
    }
 
    template<ranges::bidirectional_range R, class Comp = ranges::less,
             class Proj = std::identity>
    requires std::sortable<ranges::iterator_t<R>, Comp, Proj>
    constexpr ranges::prev_permutation_result<ranges::borrowed_iterator_t<R>>
        operator()(R&& r, Comp comp = {}, Proj proj = {}) const
    {
        return (*this)(ranges::begin(r), ranges::end(r),
                       std::move(comp), std::move(proj));
    }
};
 
inline constexpr prev_permutation_fn prev_permutation {};
```

### Example

{/* source:cpp-algorithm-ranges-prev-permutation:0013 */}
```cpp
#include <algorithm>
#include <array>
#include <compare>
#include <functional>
#include <iostream>
#include <string>
 
struct S
{
    char c{};
    int i{};
    auto operator<=>(const S&) const = default;
    friend std::ostream& operator<<(std::ostream& os, const S& s)
    {
        return os << "{'" << s.c << "', " << s.i << "}";
    }
};
 
auto print = [](auto const& v, char term = ' ')
{
    std::cout << "{ ";
    for (const auto& e : v)
        std::cout << e << ' ';
    std::cout << '}' << term;
};
 
int main()
{
    std::cout << "Generate all permutations (iterators case):\n";
    std::string s{"cba"};
    do print(s);
    while (std::ranges::prev_permutation(s.begin(), s.end()).found);
 
    std::cout << "\nGenerate all permutations (range case):\n";
    std::array a{'c', 'b', 'a'};
    do print(a);
    while (std::ranges::prev_permutation(a).found);
 
    std::cout << "\nGenerate all permutations using comparator:\n";
    using namespace std::literals;
    std::array z{"▁"s, "▄"s, "█"s};
    do print(z);
    while (std::ranges::prev_permutation(z, std::greater()).found);
 
    std::cout << "\nGenerate all permutations using projection:\n";
    std::array<S, 3> r{S{'C',1}, S{'B',2}, S{'A',3}};
    do print(r, '\n');
    while (std::ranges::prev_permutation(r, {}, &S::c).found);
}
```

Generate all permutations using comparator:

Generate all permutations using projection:
