{/* source:cpp-algorithm-ranges-return-types-in-in-out-result:0001 */}
`ranges::in_in_out_result` is a class template that provides a way to store three iterators as a single unit.

{/* source:cpp-algorithm-ranges-return-types-in-in-out-result:0002 */}
This class template has no base classes or declared members other than those shown below. Thus it is suitable for use with [structured bindings](/docs/cpp/language/declarations/structured_binding).

{/* source:cpp-algorithm-ranges-return-types-in-in-out-result:0003 */}
All special member functions of this class template are implicitly declared, which makes specializations be [aggregate classes](/docs/cpp/language/initialization/aggregate_initialization), and propagate triviality, potentially-throwing-ness, and constexpr-ness of corresponding operations on data members.

1. 1) Equivalent to `return {in1, in2, out};`.

2. 2) Equivalent to `return {std::move(in1), std::move(in2), std::move(out)};`.

### Synopsis

{/* source:cpp-algorithm-ranges-return-types-in-in-out-result:0010 */}
```cpp
namespace std::ranges
{
    template<class I1, class I2, class O>
    struct in_in_out_result
    {
        [[no_unique_address]] I1 in1;
        [[no_unique_address]] I2 in2;
        [[no_unique_address]] O  out;

        template<class II1, class II2, class OO>
        requires std::convertible_to<const I1&, II1> &&
                 std::convertible_to<const I2&, II2> &&
                 std::convertible_to<const O&, OO>
        constexpr operator in_in_out_result<II1, II2, OO>() const &
        {
            return {in1, in2, out};
        }

        template<class II1, class II2, class OO>
        requires std::convertible_to<I1, II1> &&
                 std::convertible_to<I2, II2> &&
                 std::convertible_to<O, OO>
        constexpr operator in_in_out_result<II1, II2, OO>() &&
        {
            return {std::move(in1), std::move(in2), std::move(out)};
        }
    };
}
```

### Notes

{/* source:cpp-algorithm-ranges-return-types-in-in-out-result:0011 */}
Each standard library algorithm that uses this family of return types declares a new [alias type](/docs/cpp/language/declarations/type_alias), e.g. `using merge_result = in_in_out_result<I1, I2, O>;`.

{/* source:cpp-algorithm-ranges-return-types-in-in-out-result:0012 */}
The names for such aliases are formed by adding the suffix `_result` to the algorithm's name. So, the return type of `std::ranges::merge` can be named as `std::ranges::merge_result`.

{/* source:cpp-algorithm-ranges-return-types-in-in-out-result:0013 */}
Unlike [`std::pair`](/docs/cpp/library/utility/pair) and [`std::tuple`](/docs/cpp/library/utility/tuple), this class template has data members of meaningful names.

### Example

{/* source:cpp-algorithm-ranges-return-types-in-in-out-result:0014 */}
```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <iterator>
#include <ranges>

void print(auto rem, auto first, auto last)
{
    for (std::cout << rem << ": "; first != last; ++first)
        std::cout << *first << ' ';
    std::cout << '\n';
}

int main()
{
    constexpr static auto in1 = {1, 2, 3, 4, 5, 5};
    constexpr static auto in2 = {3, 4, 5, 6, 7};
    std::array<int, std::size(in1) + std::size(in2)> out;

    const auto result = std::ranges::merge(in1, in2, out.begin());
    print("in1", in1.begin(), result.in1);
    print("in2", in2.begin(), result.in2);
    print("out", out.begin(), result.out);
}
```

Output:

```text
in1: 1 2 3 4 5 5 
in2: 3 4 5 6 7 
out: 1 2 3 3 4 4 5 5 5 6 7
```
