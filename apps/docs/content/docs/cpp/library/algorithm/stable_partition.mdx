{/* source:cpp-algorithm-stable-partition:0001 */}
1. 1) Reorders the elements in the range `[first, last)` in such a way that all elements for which the predicate `p` returns `true` precede the elements for which predicate `p` returns `false`. Relative order of the elements is preserved.

{/* source:cpp-algorithm-stable-partition:0002 */}
2. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-algorithm-stable-partition:0003 */}
3. This overload participates in overload resolution only if all following conditions are satisfied:

<Revision until="C++20">

`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.

</Revision>

<Revision since="C++20">

`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.

</Revision>

{/* source:cpp-algorithm-stable-partition:0004 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-stable-partition:0005 */}
<Revision until="C++11">

- The type of `*first` is not [*Swappable*](/docs/cpp/library/named_req/Swappable).

</Revision>

<Revision since="C++11">

- `BidirIt` is not [*ValueSwappable*](/docs/cpp/library/named_req/ValueSwappable).
- The type of `*first` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
- The type of `*first` is not [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable).

</Revision>

### Parameters

{/* source:cpp-algorithm-stable-partition:0006 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to reorder</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="p">

unary predicate which returns `true` if the element should be ordered before other elements.

The expression `p(v)` must be convertible to `bool` for every argument `v` of type (possibly const) `VT`, where `VT` is the value type of `BidirIt`, regardless of [value category](/docs/cpp/language/expressions/value_category), and must not modify `v`. Thus, a parameter type of `VT&` is not allowed<InlineRevision since="C++11">, nor is `VT` unless for `VT` a move is equivalent to a copy</InlineRevision>.

Type requirements:

- `BidirIt` must meet the requirements of [*LegacyBidirectionalIterator*](/docs/cpp/library/named_req/BidirectionalIterator).
- `UnaryPred` must meet the requirements of [*Predicate*](/docs/cpp/library/named_req/Predicate).

</Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-stable-partition:0007 */}
Iterator to the first element of the second group.

### Complexity

{/* source:cpp-algorithm-stable-partition:0008 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-stable-partition:0009 */}
1. 1) Exactly `N` applications of `p`.

{/* source:cpp-algorithm-stable-partition:0010 */}
2. O(N) swaps if there is enough extra memory, otherwise at most N⋅log2(N) swaps.

{/* source:cpp-algorithm-stable-partition:0011 */}
3. 2) O(N) applications of `p`.

{/* source:cpp-algorithm-stable-partition:0012 */}
4. N⋅log(N) swaps.

### Exceptions

{/* source:cpp-algorithm-stable-partition:0013 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-algorithm-stable-partition:0014 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Notes

{/* source:cpp-algorithm-stable-partition:0015 */}
This function attempts to allocate a temporary buffer. If the allocation fails, the less efficient algorithm is chosen.

{/* source:cpp-algorithm-stable-partition:0016 */}
Implementations in [libc++](https://github.com/llvm/llvm-project/blob/eda14ebf6a43d9ada6a2be3d1b06b8b6036eb774/libcxx/include/__algorithm/stable_partition.h#L316) and [libstdc++](https://github.com/gcc-mirror/gcc/blob/d2a499a9881c7c079d2a722b57c7fcf022a864dd/libstdc%2B%2B-v3/include/bits/stl_algo.h#L1608) also accept ranges denoted by [*LegacyForwardIterators*](/docs/cpp/library/named_req/ForwardIterator) as an extension.

### Example

{/* source:cpp-algorithm-stable-partition:0018 */}
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
 
int main()
{
    std::vector<int> v{0, 0, 3, -1, 2, 4, 5, 0, 7};
    std::stable_partition(v.begin(), v.end(), [](int n) { return n > 0; });
    for (int n : v)
        std::cout << n << ' ';
    std::cout << '\n';
}
```

Output:

```text
3 2 4 5 7 0 0 -1 0
```
