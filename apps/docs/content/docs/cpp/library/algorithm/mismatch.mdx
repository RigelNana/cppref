{/* source:cpp-algorithm-mismatch:0001 */}
Returns a pair of iterators to the first mismatching of elements from `[first1, last1)` and a range starting from `first2`:

{/* source:cpp-algorithm-mismatch:0002 */}
- For overloads (1-4), the second range has `std::distance(first1, last1)` elements.
- For overloads (5-8), the second range is `[first2, last2)`.

{/* source:cpp-algorithm-mismatch:0003 */}
- If `std::distance(first1, last1)` and `std::distance(first2, last2)` are different, the comparison stops when `last1` or `last2` is reached.

{/* source:cpp-algorithm-mismatch:0004 */}
1. 1,5) Elements are compared using `operator==`.

{/* source:cpp-algorithm-mismatch:0005 */}
2. 3,7) Elements are compared using the given binary predicate `p`.

{/* source:cpp-algorithm-mismatch:0006 */}
3. 2,4,6,8) Same as (1,3,5,7), but executed according to `policy`.

{/* source:cpp-algorithm-mismatch:0007 */}
4. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

### Parameters

{/* source:cpp-algorithm-mismatch:0008 */}
<ParameterList>
  <Parameter name="first1, last1">the first range of the elements</Parameter>
  <Parameter name="first2, last2">the second range of the elements</Parameter>
  <Parameter name="policy">the execution policy to use</Parameter>
  <Parameter name="p">
binary predicate which returns `true` if the elements should be treated as equal.

The signature of the predicate function should be equivalent to the following:

`bool pred(const Type1 &a, const Type2 &b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The types `Type1` and `Type2` must be such that objects of types `InputIt1` and `InputIt2` can be dereferenced and then implicitly converted to `Type1` and `Type2` respectively.
  </Parameter>
</ParameterList>

Type requirements

- `InputIt1` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `InputIt2` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `ForwardIt1` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `BinaryPred` must meet the requirements of [*BinaryPredicate*](/docs/cpp/library/named_req/BinaryPredicate).

### Return value

{/* source:cpp-algorithm-mismatch:0009 */}
[`std::pair`](/docs/cpp/library/utility/pair) with iterators to the first two non-equal elements.

{/* source:cpp-algorithm-mismatch:0010 */}
If `last1` is reached, the second iterator in the pair is the `std::distance(first1, last1)` th iterator after `first2`.

{/* source:cpp-algorithm-mismatch:0011 */}
For overloads (5-8), if `last2` is reached, the first iterator in the pair is the `std::distance(first2, last2)` th iterator after `first1`.

### Complexity

{/* source:cpp-algorithm-mismatch:0012 */}
Given `N1` as `std::distance(first1, last1)` and `N2` as `std::distance(first2, last2)`:

{/* source:cpp-algorithm-mismatch:0013 */}
1. 1,2) At most `N1` comparisons using `operator==`.

{/* source:cpp-algorithm-mismatch:0014 */}
2. 3,4) At most `N1` applications of the predicate `p`.

{/* source:cpp-algorithm-mismatch:0015 */}
3. 5,6) At most `min(N1,N2)` comparisons using `operator==`.

{/* source:cpp-algorithm-mismatch:0016 */}
4. 7,8) At most `min(N1,N2)` applications of the predicate `p`.

### Exceptions

{/* source:cpp-algorithm-mismatch:0017 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-mismatch:0018 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined. If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-mismatch:0019 */}
[`mismatch (1)`](/docs/cpp/library/algorithm/mismatch#Version_1)

```cpp
template<class InputIt1, class InputIt2>
std::pair<InputIt1, InputIt2>
    mismatch(InputIt1 first1, InputIt1 last1, InputIt2 first2)
{
    while (first1 != last1 && *first1 == *first2)
        ++first1, ++first2;
 
    return std::make_pair(first1, first2);
}
```

[`mismatch (3)`](/docs/cpp/library/algorithm/mismatch#Version_3)

```cpp
template<class InputIt1, class InputIt2, class BinaryPred>
std::pair<InputIt1, InputIt2>
    mismatch(InputIt1 first1, InputIt1 last1, InputIt2 first2, BinaryPred p)
{
    while (first1 != last1 && p(*first1, *first2))
        ++first1, ++first2;
 
    return std::make_pair(first1, first2);
}
```

[`mismatch (5)`](/docs/cpp/library/algorithm/mismatch#Version_5)

```cpp
template<class InputIt1, class InputIt2>
std::pair<InputIt1, InputIt2>
    mismatch(InputIt1 first1, InputIt1 last1, InputIt2 first2, InputIt2 last2)
{
    while (first1 != last1 && first2 != last2 && *first1 == *first2)
        ++first1, ++first2;
 
    return std::make_pair(first1, first2);
}
```

[`mismatch (7)`](/docs/cpp/library/algorithm/mismatch#Version_7)

```cpp
template<class InputIt1, class InputIt2, class BinaryPred>
std::pair<InputIt1, InputIt2>
    mismatch(InputIt1 first1, InputIt1 last1,
             InputIt2 first2, InputIt2 last2, BinaryPred p)
{
    while (first1 != last1 && first2 != last2 && p(*first1, *first2))
        ++first1, ++first2;
 
    return std::make_pair(first1, first2);
}
```

### Example

{/* source:cpp-algorithm-mismatch:0020 */}
This program determines the longest substring that is simultaneously found at the very beginning of the given string and at the very end of it, in reverse order (possibly overlapping).

```cpp
#include <algorithm>
#include <iostream>
#include <string>
 
std::string mirror_ends(const std::string& in)
{
    return std::string(in.begin(),
                       std::mismatch(in.begin(), in.end(), in.rbegin()).first);
}
 
int main()
{
    std::cout << mirror_ends("abXYZba") << '\n'
              << mirror_ends("abca") << '\n'
              << mirror_ends("aba") << '\n';
}
```

Output:

```text
ab
a
aba
```
