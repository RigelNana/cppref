{/* source:cpp-algorithm-remove-copy:0001 */}
Copies elements from the range `[first, last)`, to another range beginning at `d_first`, omitting the elements which satisfy specific criteria.

{/* source:cpp-algorithm-remove-copy:0002 */}
1. 1) Ignores all elements that are equal to `value` (using `operator==`).

{/* source:cpp-algorithm-remove-copy:0003 */}
2. 3) Ignores all elements for which predicate `p` returns `true`.

{/* source:cpp-algorithm-remove-copy:0004 */}
3. 2,4) Same as (1,3), but executed according to `policy`.

{/* source:cpp-algorithm-remove-copy:0005 */}
4. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">[`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

   <Revision since="C++20">[`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

{/* source:cpp-algorithm-remove-copy:0006 */}
If <InlineRevision until="C++20">`*d_first = *first` is invalid</InlineRevision><InlineRevision since="C++20">`*first` is not [writable](/docs/cpp/library/iterator#Types_and_writability) to `d_first`</InlineRevision>, the program is ill-formed.

{/* source:cpp-algorithm-remove-copy:0007 */}
If source and destination ranges overlap, the behavior is undefined.

### Parameters

{/* source:cpp-algorithm-remove-copy:0008 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to copy</Parameter>
  <Parameter name="d_first">the beginning of the destination range</Parameter>
  <Parameter name="value">the value of the elements not to copy</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
</ParameterList>

Type requirements

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `OutputIt` must meet the requirements of [*LegacyOutputIterator*](/docs/cpp/library/named_req/OutputIterator).
- `ForwardIt1, ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `UnaryPred` must meet the requirements of [*Predicate*](/docs/cpp/library/named_req/Predicate).

### Return value

{/* source:cpp-algorithm-remove-copy:0009 */}
Iterator to the element past the last element copied.

### Complexity

{/* source:cpp-algorithm-remove-copy:0010 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-remove-copy:0011 */}
1. 1,2) Exactly `N` comparisons with `value` using `operator==`.

{/* source:cpp-algorithm-remove-copy:0012 */}
2. 3,4) Exactly `N` applications of the predicate `p`.

{/* source:cpp-algorithm-remove-copy:0013 */}
For the overloads with an `ExecutionPolicy`, there may be a performance cost if `ForwardIt1`'s `value_type` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).

### Exceptions

{/* source:cpp-algorithm-remove-copy:0014 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-remove-copy:0015 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-remove-copy:0016 */}
[`remove_copy (1)`](/docs/cpp/library/algorithm/remove_copy#Version_1)

```cpp
template<class InputIt, class OutputIt,
         class T = typename std::iterator_traits<InputIt>::value_type>
constexpr OutputIt remove_copy(InputIt first, InputIt last,
                               OutputIt d_first, const T& value)
{
    for (; first != last; ++first)
        if (!(*first == value))
            *d_first++ = *first;
    return d_first;
}
```

[`remove_copy_if (3)`](/docs/cpp/library/algorithm/remove_copy#Version_3)

```cpp
template<class InputIt, class OutputIt, class UnaryPred>
constexpr OutputIt remove_copy_if(InputIt first, InputIt last,
                                  OutputIt d_first, UnaryPred p)
{
    for (; first != last; ++first)
        if (!p(*first))
            *d_first++ = *first;
    return d_first;
}
```

### Example

{/* source:cpp-algorithm-remove-copy:0018 */}
```cpp
#include <algorithm>
#include <complex>
#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>
 
int main()
{
    // Erase the hash characters '#' on the fly.
    std::string str = "#Return #Value #Optimization";
    std::cout << "before: " << std::quoted(str) << '\n';
 
    std::cout << "after:  \"";
    std::remove_copy(str.begin(), str.end(),
                     std::ostream_iterator<char>(std::cout), '#');
    std::cout << "\"\n";
 
    // Erase {1, 3} value on the fly.
    std::vector<std::complex<double>> nums{{2, 2}, {1, 3}, {4, 8}, {1, 3}};
    std::remove_copy(nums.begin(), nums.end(),
                     std::ostream_iterator<std::complex<double>>(std::cout),
    #ifdef __cpp_lib_algorithm_default_value_type
                     {1, 3}); // T gets deduced
    #else
                     std::complex<double>{1, 3});
    #endif
}
```

Output:

```text
before: "#Return #Value #Optimization"
after:  "Return Value Optimization"
(2,2)(4,8)
```
