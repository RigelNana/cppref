{/* source:cpp-algorithm-upper-bound:0001 */}
Searches for the first element in the partitioned range `[first, last)` which is ordered after `value`.

{/* source:cpp-algorithm-upper-bound:0002 */}
1. 1) The order is determined by `operator<`:

<Revision until="C++20">

Returns the first iterator `iter` in `[first, last)` where `bool(value < *iter)` is `true`, or `last` if no such `iter` exists.

If the elements `elem` of `[first, last)` are not [partitioned](/docs/cpp/library/algorithm#Requirements) with respect to the expression `bool(value < elem)`, the behavior is undefined.

</Revision>

<Revision since="C++20">

Equivalent to `std::upper_bound(first, last, value, std::less{})`.

</Revision>

{/* source:cpp-algorithm-upper-bound:0003 */}
2. 2) The order is determined by `comp`:

{/* source:cpp-algorithm-upper-bound:0004 */}
3. Returns the first iterator `iter` in `[first, last)` where `bool(comp(value, *iter))` is `true`, or `last` if no such `iter` exists.

{/* source:cpp-algorithm-upper-bound:0005 */}
4. If the elements `elem` of `[first, last)` are not [partitioned](/docs/cpp/library/algorithm#Requirements) with respect to the expression `bool(comp(value, elem))`, the behavior is undefined.

### Parameters

{/* source:cpp-algorithm-upper-bound:0006 */}
<ParameterList>
  <Parameter name="first, last">the partitioned range of elements to examine</Parameter>
  <Parameter name="value">value to compare the elements to</Parameter>
  <Parameter name="comp">

binary predicate which returns `true` if the first argument is ordered before the second.

The signature of the predicate function should be equivalent to the following:

`bool pred(const Type1 &a, const Type2 &b);`

While the signature does not need to have `const &`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1 &` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The type `Type1` must be such that an object of type `T` can be implicitly converted to `Type1`. The type `Type2` must be such that an object of type `ForwardIt` can be dereferenced and then implicitly converted to `Type2`.

</Parameter>
</ParameterList>

Type requirements:

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `Compare` must meet the requirements of [*BinaryPredicate*](/docs/cpp/library/named_req/BinaryPredicate). It is not required to satisfy [*Compare*](/docs/cpp/library/named_req/Compare).

### Return value

{/* source:cpp-algorithm-upper-bound:0007 */}
Iterator to the first element of the range `[first, last)` ordered after `value`, or `last` if no such element is found.

### Complexity

{/* source:cpp-algorithm-upper-bound:0008 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-upper-bound:0009 */}
1. 1) At most log2(N)+O(1) comparisons with `value` using <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-upper-bound:0010 */}
2. 2) At most log2(N)+O(1) applications of the comparator `comp`.

{/* source:cpp-algorithm-upper-bound:0011 */}
However, if `ForwardIt` is not a [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator), the number of iterator increments is linear in `N`. Notably, [`std::map`](/docs/cpp/library/container/map), [`std::multimap`](/docs/cpp/library/container/multimap), [`std::set`](/docs/cpp/library/container/set), and [`std::multiset`](/docs/cpp/library/container/multiset) iterators are not random access, and so their member `upper_bound` functions should be preferred.

[`upper_bound (1)`](/docs/cpp/library/algorithm/upper_bound#Version_1)

```cpp
template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type>
ForwardIt upper_bound(ForwardIt first, ForwardIt last, const T& value)
{
    return std::upper_bound(first, last, value, std::less{});
}
```

[`upper_bound (2)`](/docs/cpp/library/algorithm/upper_bound#Version_2)

```cpp
template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type,
         class Compare>
ForwardIt upper_bound(ForwardIt first, ForwardIt last, const T& value, Compare comp)
{
    ForwardIt it;
    typename std::iterator_traits<ForwardIt>::difference_type count, step;
    count = std::distance(first, last);
 
    while (count > 0)
    {
        it = first; 
        step = count / 2;
        std::advance(it, step);
 
        if (!comp(value, *it))
        {
            first = ++it;
            count -= step + 1;
        } 
        else
            count = step;
    }
 
    return first;
}
```

### Notes

{/* source:cpp-algorithm-upper-bound:0014 */}
Although `std::upper_bound` only requires `[first, last)` to be partitioned, this algorithm is usually used in the case where `[first, last)` is sorted, so that the binary search is valid for any `value`.

{/* source:cpp-algorithm-upper-bound:0015 */}
For any iterator `iter` in `[first, last)`, `std::upper_bound` requires `value < *iter` and `comp(value, *iter)` to be well-formed, while [`std::lower_bound`](/docs/cpp/library/algorithm/lower_bound) requires `*iter < value` and `comp(*iter, value)` to be well-formed instead.

### Example

{/* source:cpp-algorithm-upper-bound:0017 */}
```cpp
#include <algorithm>
#include <cassert>
#include <complex>
#include <iostream>
#include <vector>
 
struct PriceInfo { double price; };
 
int main()
{
    const std::vector<int> data{1, 2, 4, 5, 5, 6};
 
    for (int i = 0; i < 7; ++i)
    {
        // Search first element that is greater than i
        auto upper = std::upper_bound(data.begin(), data.end(), i);
 
        std::cout << i << " < ";
        upper != data.end()
            ? std::cout << *upper << " at index " << std::distance(data.begin(), upper)
            : std::cout << "not found";
        std::cout << '\n';
    }
 
    std::vector<PriceInfo> prices{{100.0}, {101.5}, {102.5}, {102.5}, {107.3}};
 
    for (double to_find : {102.5, 110.2})
    {
        auto prc_info = std::upper_bound(prices.begin(), prices.end(), to_find,
            [](double value, const PriceInfo& info)
            {
                return value < info.price;
            });
 
        prc_info != prices.end()
            ? std::cout << prc_info->price << " at index " << prc_info - prices.begin()
            : std::cout << to_find << " not found";
        std::cout << '\n';
    }
 
    using CD = std::complex<double>;
    std::vector<CD> nums{{1, 0}, {2, 2}, {2, 1}, {3, 0}, {3, 1}};
    auto cmpz = [](CD x, CD y) { return x.real() < y.real(); };
    #ifdef __cpp_lib_algorithm_default_value_type
        auto it = std::upper_bound(nums.cbegin(), nums.cend(), {2, 0}, cmpz);
    #else
        auto it = std::upper_bound(nums.cbegin(), nums.cend(), CD{2, 0}, cmpz);
    #endif
    assert((*it == CD{3, 0}));
}
```

Output:

```text
0 < 1 at index 0
1 < 2 at index 1
2 < 4 at index 2
3 < 4 at index 2
4 < 5 at index 3
5 < 6 at index 5
6 < not found 
107.3 at index 4
110.2 not found
```
