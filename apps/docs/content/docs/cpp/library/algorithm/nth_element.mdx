{/* source:cpp-algorithm-nth-element:0001 */}
`nth_element` rearranges elements in `[first, last)` such that after the rearrangement:

{/* source:cpp-algorithm-nth-element:0002 */}
1. The element pointed at by `nth` is changed to whatever element would occur in that position if `[first, last)` were sorted. For every iterator `i` in `[first, nth)` and every iterator `j` in `[nth, last)`, the following condition is met:

{/* source:cpp-algorithm-nth-element:0003 */}
2. 1,2) <InlineRevision until="C++20">`bool(*j < *i)`</InlineRevision> <InlineRevision since="C++20">`std::less{}(*j, *i)`</InlineRevision> is `false`.

{/* source:cpp-algorithm-nth-element:0004 */}
3. 3,4) `bool(comp(*j, *i))` is `false`.

{/* source:cpp-algorithm-nth-element:0005 */}
4. 1) Elements are hypothetically [sorted](/docs/cpp/library/algorithm#Requirements) with respect to <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-nth-element:0006 */}
5. 3) Elements are hypothetically sorted with respect to `comp`.

{/* source:cpp-algorithm-nth-element:0007 */}
6. 2,4) Same as (1,3), but executed according to `policy`.

{/* source:cpp-algorithm-nth-element:0008 */}
7. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

{/* source:cpp-algorithm-nth-element:0009 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-nth-element:0010 */}
- `[first, nth)` or `[nth, last)` is not a [valid range](/docs/cpp/library/iterator#Ranges).

{/* source:cpp-algorithm-nth-element:0011 */}
<Revision until="C++11">
The type of `*first` is not [*Swappable*](/docs/cpp/library/named_req/Swappable).
</Revision>

<Revision since="C++11">
`RandomIt` is not [*ValueSwappable*](/docs/cpp/library/named_req/ValueSwappable).

The type of `*first` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).

The type of `*first` is not [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable).
</Revision>

### Parameters

{/* source:cpp-algorithm-nth-element:0012 */}
<ParameterList>
  <Parameter name="first, last">random access iterators defining the range sort</Parameter>
  <Parameter name="nth">random access iterator defining the sort partition point</Parameter>
  <Parameter name="policy">the execution policy to use</Parameter>
  <Parameter name="comp">
comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is less than (i.e. is ordered before) the second.

The signature of the comparison function should be equivalent to the following:

`bool cmp(const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The types `Type1` and `Type2` must be such that an object of type `RandomIt` can be dereferenced and then implicitly converted to both of them.
  </Parameter>
</ParameterList>

Type requirements

- `RandomIt` must meet the requirements of [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator).
- `Compare` must meet the requirements of [*Compare*](/docs/cpp/library/named_req/Compare).

### Complexity

{/* source:cpp-algorithm-nth-element:0013 */}
Given `N` as `last - first`:

{/* source:cpp-algorithm-nth-element:0014 */}
1. 1) `O(N)` comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision> on average.

{/* source:cpp-algorithm-nth-element:0015 */}
2. 2) `O(N)` comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision>, and `O(N·log(N))` swaps.

{/* source:cpp-algorithm-nth-element:0016 */}
3. 3) `O(N)` applications of the comparator `comp` on average.

{/* source:cpp-algorithm-nth-element:0017 */}
4. 4) `O(N)` applications of the comparator `comp`, and `O(N·log(N))` swaps.

### Exceptions

{/* source:cpp-algorithm-nth-element:0018 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-nth-element:0019 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined. If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

See also the implementations in [libstdc++](https://github.com/gcc-mirror/gcc/blob/d9375e490072d1aae73a93949aa158fcd2a27018/libstdc%2B%2B-v3/include/bits/stl_algo.h#L4718), [libc++](https://github.com/llvm/llvm-project/blob/ed2d364/libcxx/include/__algorithm/nth_element.h), and [MSVC STL](https://github.com/microsoft/STL/blob/e97bb2b50a12816ce68cc5147b7a3a21fb68bfa3/stl/inc/algorithm#L8849-L8894).

### Notes

{/* source:cpp-algorithm-nth-element:0021 */}
The algorithm used is typically [Introselect](https://en.wikipedia.org/wiki/Introselect) although other [Selection algorithm](https://en.wikipedia.org/wiki/Selection_algorithm) with suitable average-case complexity are allowed.

### Example

{/* source:cpp-algorithm-nth-element:0022 */}
```cpp
#include <algorithm>
#include <cassert>
#include <functional>
#include <iostream>
#include <numeric>
#include <vector>
 
void printVec(const std::vector<int>& vec)
{
    std::cout << "v = {";
    for (char sep[]{0, ' ', 0}; const int i : vec)
        std::cout << sep << i, sep[0] = ',';
    std::cout << "};\n";
}
 
int main()
{
    std::vector<int> v{5, 10, 6, 4, 3, 2, 6, 7, 9, 3};
    printVec(v);
 
    auto m = v.begin() + v.size() / 2;
    std::nth_element(v.begin(), m, v.end());
    std::cout << "\nThe median is " << v[v.size() / 2] << '\n';
    // The consequence of the inequality of elements before/after the Nth one:
    assert(std::accumulate(v.begin(), m, 0) < std::accumulate(m, v.end(), 0));
    printVec(v);
 
    // Note: comp function changed
    std::nth_element(v.begin(), v.begin() + 1, v.end(), std::greater{});
    std::cout << "\nThe second largest element is " << v[1] << '\n';
    std::cout << "The largest element is " << v[0] << '\n';
    printVec(v);
}
```

Possible output:

```text
v = {5, 10, 6, 4, 3, 2, 6, 7, 9, 3};
 
The median is 6
v = {3, 2, 3, 4, 5, 6, 10, 7, 9, 6};
 
The second largest element is 9
The largest element is 10
v = {10, 9, 6, 7, 6, 3, 5, 4, 3, 2};
```
