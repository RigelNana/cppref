{/* source:cpp-algorithm-includes:0001 */}
Returns `true` if the sorted range [`first2`, `last2`) is a [subsequence](https://en.wikipedia.org/wiki/subsequence) of the sorted range [`first1`, `last1`) (a subsequence need not be contiguous).

{/* source:cpp-algorithm-includes:0002 */}
1. 1) If [`first1`, `last1`) or [`first2`, `last2`) is not [sorted](/docs/cpp/library/algorithm#Requirements) with respect to <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision>, the behavior is undefined.

{/* source:cpp-algorithm-includes:0003 */}
2. 3) If [`first1`, `last1`) or [`first2`, `last2`) is not sorted with respect to `comp`, the behavior is undefined.

{/* source:cpp-algorithm-includes:0004 */}
3. 2,4) Same as (1,3), but executed according to `policy`.

{/* source:cpp-algorithm-includes:0005 */}
4. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">
   `std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.
   </Revision>

   <Revision since="C++20">
   `std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.
   </Revision>

### Parameters

{/* source:cpp-algorithm-includes:0006 */}
<ParameterList>
  <Parameter name="first1, last1">the sorted range of elements to examine</Parameter>
  <Parameter name="first2, last2">the sorted range of elements to search for</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="comp">
comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is *less* than (i.e. is ordered *before*) the second.

The signature of the comparison function should be equivalent to the following:

`bool cmp(const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>).
The types `Type1` and `Type2` must be such that an object of type `InputIt` can be dereferenced and then implicitly converted to both of them.
  </Parameter>
</ParameterList>

Type requirements

- `InputIt1, InputIt2` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `ForwardIt1, ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `Compare` must meet the requirements of [*Compare*](/docs/cpp/library/named_req/Compare).

### Return value

{/* source:cpp-algorithm-includes:0007 */}
`true` if [`first2`, `last2`) is a subsequence of [`first1`, `last1`); otherwise `false`.

{/* source:cpp-algorithm-includes:0008 */}
An empty sequence is a subsequence of any sequence, so `true` is returned if [`first2`, `last2`) is empty.

### Complexity

{/* source:cpp-algorithm-includes:0009 */}
Given `N1` as `std::distance(first1, last1)` and `N2` as `std::distance(first2, last2)`:

{/* source:cpp-algorithm-includes:0010 */}
1. 1,2) At most 2⋅(N1+N2)-1 comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-includes:0011 */}
2. 3,4) At most 2⋅(N1+N2)-1 applications of the comparison function `comp`.

### Exceptions

{/* source:cpp-algorithm-includes:0012 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-includes:0013 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-includes:0014 */}
[`include (1)`](/docs/cpp/library/algorithm/includes#Version_1)

```cpp
template<class InputIt1, class InputIt2>
bool includes(InputIt1 first1, InputIt1 last1,
              InputIt2 first2, InputIt2 last2)
{
    for (; first2 != last2; ++first1)
    {
        if (first1 == last1 || *first2 < *first1)
            return false;
        if (!(*first1 < *first2))
            ++first2;
    }
    return true;
}
```

[`include (3)`](/docs/cpp/library/algorithm/includes#Version_3)

```cpp
template<class InputIt1, class InputIt2, class Compare>
bool includes(InputIt1 first1, InputIt1 last1,
              InputIt2 first2, InputIt2 last2, Compare comp)
{
    for (; first2 != last2; ++first1)
    {
        if (first1 == last1 || comp(*first2, *first1))
            return false;
        if (!comp(*first1, *first2))
            ++first2;
    }
    return true;
}
```

### Example

{/* source:cpp-algorithm-includes:0015 */}
```cpp
#include <algorithm>
#include <cctype>
#include <iostream>
 
template<class Os, class Co>
Os& operator<<(Os& os, const Co& v)
{
    for (const auto& i : v)
        os << i << ' ';
    return os << '\t';
}
 
int main()
{
    const auto
        v1 = {'a', 'b', 'c', 'f', 'h', 'x'},
        v2 = {'a', 'b', 'c'},
        v3 = {'a', 'c'},
        v4 = {'a', 'a', 'b'},
        v5 = {'g'},
        v6 = {'a', 'c', 'g'},
        v7 = {'A', 'B', 'C'};
 
    auto no_case = [](char a, char b) { return std::tolower(a) < std::tolower(b); };
 
    std::cout
    << v1 << "\nincludes:\n" << std::boolalpha
    << v2 << ": " << std::includes(v1.begin(), v1.end(), v2.begin(), v2.end()) << '\n'
    << v3 << ": " << std::includes(v1.begin(), v1.end(), v3.begin(), v3.end()) << '\n'
    << v4 << ": " << std::includes(v1.begin(), v1.end(), v4.begin(), v4.end()) << '\n'
    << v5 << ": " << std::includes(v1.begin(), v1.end(), v5.begin(), v5.end()) << '\n'
    << v6 << ": " << std::includes(v1.begin(), v1.end(), v6.begin(), v6.end()) << '\n'
    << v7 << ": " << std::includes(v1.begin(), v1.end(), v7.begin(), v7.end(), no_case)
          << " (case-insensitive)\n";
}
```

Output:

```text
a b c f h x
includes:
a b c   : true
a c     : true
a a b   : false
g       : false
a c g   : false
A B C   : true (case-insensitive)
```
