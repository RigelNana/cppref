{/* source:cpp-algorithm-equal:0001 */}
Checks whether `[first1, last1)` and a range starting from `first2` are equal:

{/* source:cpp-algorithm-equal:0002 */}
- For overloads (1-4), the second range has `std::distance(first1, last1)` elements.
- For overloads (5-8), the second range is `[first2, last2)`.

{/* source:cpp-algorithm-equal:0003 */}
1. 1,5) Elements are compared using `operator==`.

{/* source:cpp-algorithm-equal:0004 */}
2. 3,7) Elements are compared using the given binary predicate `p`.

{/* source:cpp-algorithm-equal:0005 */}
3. 2,4,6,8) Same as (1,3,5,7), but executed according to `policy`.

{/* source:cpp-algorithm-equal:0006 */}
4. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

### Parameters

{/* source:cpp-algorithm-equal:0007 */}
<ParameterList>
  <Parameter name="first1, last1">the first range of the elements to compare</Parameter>
  <Parameter name="first2, last2">the second range of the elements to compare</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="p">
binary predicate which returns `true` if the elements should be treated as equal.

The signature of the predicate function should be equivalent to the following:

`bool pred(const Type1 &a, const Type2 &b);`

While the signature does not need to have `const &`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1 &` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>).

The types `Type1` and `Type2` must be such that objects of types `InputIt1` and `InputIt2` can be dereferenced and then implicitly converted to `Type1` and `Type2` respectively.
  </Parameter>
</ParameterList>

**Type requirements**

- `InputIt1, InputIt2` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `ForwardIt1, ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `BinaryPred` must meet the requirements of [*BinaryPredicate*](/docs/cpp/library/named_req/BinaryPredicate).

### Return value

{/* source:cpp-algorithm-equal:0008 */}
1. 1-4) If each corresponding elements in the two ranges are equal, returns `true`. Otherwise returns `false`.

{/* source:cpp-algorithm-equal:0009 */}
2. 5-8) If `std::distance(first1, last1)` and `std::distance(first2, last2)` are equal, and each corresponding elements in the two ranges are equal, returns `true`. Otherwise returns `false`.

### Complexity

{/* source:cpp-algorithm-equal:0010 */}
Given `N1` as `std::distance(first1, last1)` and `N2` as `std::distance(first2, last2)`:

{/* source:cpp-algorithm-equal:0011 */}
1. 1) At most `N1` comparisons using `operator==`.

{/* source:cpp-algorithm-equal:0012 */}
2. 2) O(N1) comparisons using `operator==`.

{/* source:cpp-algorithm-equal:0013 */}
3. 3) At most `N1` applications of the predicate `p`.

{/* source:cpp-algorithm-equal:0014 */}
4. 4) O(N1) applications of the predicate `p`.

{/* source:cpp-algorithm-equal:0015 */}
5. 5-8) If `InputIt1` and `InputIt2` are both [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator), and `last1 - first1 != last2 - first2` is `true`, no comparison will be made.

{/* source:cpp-algorithm-equal:0016 */}
6. Otherwise, given `N` as min(N1,N2):

{/* source:cpp-algorithm-equal:0017 */}
7. 5) At most `N` comparisons using `operator==`.

{/* source:cpp-algorithm-equal:0018 */}
8. 6) O(N) comparisons using `operator==`.

{/* source:cpp-algorithm-equal:0019 */}
9. 7) At most `N` applications of the predicate `p`.

{/* source:cpp-algorithm-equal:0020 */}
10. 8) O(N) applications of the predicate `p`.

### Exceptions

{/* source:cpp-algorithm-equal:0021 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-equal:0022 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-equal:0023 */}
[`equal (1)`](/docs/cpp/library/algorithm/equal#Version_1)

```cpp
template<class InputIt1, class InputIt2>
constexpr //< since C++20
bool equal(InputIt1 first1, InputIt1 last1, InputIt2 first2)
{
    for (; first1 != last1; ++first1, ++first2)
        if (!(*first1 == *first2))
            return false;
 
    return true;
}
```

[`equal (5)`](/docs/cpp/library/algorithm/equal#Version_5)

```cpp
namespace detail
{
    // random-access iterator implementation (allows quick range size detection)
    template<class RandomIt1, class RandomIt2>
    constexpr //< since C++20
    bool equal(RandomIt1 first1, RandomIt1 last1, RandomIt2 first2, RandomIt2 last2,
               std::random_access_iterator_tag, std::random_access_iterator_tag)
    {
        if (last1 - first1 != last2 - first2)
            return false;
 
        for (; first1 != last1; ++first1, ++first2)
            if (!(*first1 == *first2))
                return false;
 
        return true;
    }
 
    // input iterator implementation (needs to manually compare with “last2”)
    template<class InputIt1, class InputIt2>
    constexpr //< since C++20
    bool equal(InputIt1 first1, InputIt1 last1, InputIt2 first2, InputIt2 last2,
               std::input_iterator_tag, std::input_iterator_tag)
    {
        for (; first1 != last1 && first2 != last2; ++first1, ++first2)
            if (!(*first1 == *first2))
                return false;
 
        return first1 == last1 && first2 == last2;
    }
}
 
template<class InputIt1, class InputIt2>
constexpr //< since C++20
bool equal(InputIt1 first1, InputIt1 last1, InputIt2 first2, InputIt2 last2)
{
    details::equal(first1, last1, first2, last2,
                   typename std::iterator_traits<InputIt1>::iterator_category(),
                   typename std::iterator_traits<InputIt2>::iterator_category());
}
```

### Notes

{/* source:cpp-algorithm-equal:0024 */}
`std::equal` should not be used to compare the ranges formed by the iterators from [`std::unordered_set`](/docs/cpp/library/container/unordered_set), [`std::unordered_multiset`](/docs/cpp/library/container/unordered_multiset), [`std::unordered_map`](/docs/cpp/library/container/unordered_map), or [`std::unordered_multimap`](/docs/cpp/library/container/unordered_multimap) because the order in which the elements are stored in those containers may be different even if the two containers store the same elements.

{/* source:cpp-algorithm-equal:0025 */}
When comparing entire containers <InlineRevision since="C++17">or string views</InlineRevision> for equality, `operator==` for the corresponding type are usually preferred.

{/* source:cpp-algorithm-equal:0026 */}
Sequential `std::equal` is not guaranteed to be short-circuit. E.g. if the first pair elements of both ranges do not compare equal, the rest of elements may also be compared. Non-short-circuit comparison may happen when the ranges are compared with [`std::memcmp`](/docs/cpp/library/text/byte/memcmp) or implementation-specific vectorized algorithms.

### Example

{/* source:cpp-algorithm-equal:0027 */}
The following code uses [`std::equal`](/docs/cpp/library/algorithm/equal#top) to test if a string is a palindrome.

```cpp
#include <algorithm>
#include <iomanip>
#include <iostream>
#include <string_view>
 
constexpr bool is_palindrome(const std::string_view& s)
{
    return std::equal(s.cbegin(), s.cbegin() + s.size() / 2, s.crbegin());
}
 
void test(const std::string_view& s)
{
    std::cout << std::quoted(s)
              << (is_palindrome(s) ? " is" : " is not")
              << " a palindrome\n";
}
 
int main()
{
    test("radar");
    test("hello");
}
```

Output:

```text
"radar" is a palindrome
"hello" is not a palindrome
```
