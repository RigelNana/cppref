{/* source:cpp-algorithm-unique:0001 */}
Removes all except the first element from every consecutive group of equivalent elements from the range `[first, last)` and returns a past-the-end iterator for the new end of the range.

{/* source:cpp-algorithm-unique:0002 */}
1. 1) Elements are compared using `operator==`.

{/* source:cpp-algorithm-unique:0003 */}
2. If `operator==` does not establish an [equivalence relation](https://en.wikipedia.org/wiki/equivalence_relation), the behavior is undefined.

{/* source:cpp-algorithm-unique:0004 */}
3. 3) Elements are compared using the given binary predicate `p`.

{/* source:cpp-algorithm-unique:0005 */}
4. If `p` does not establish an equivalence relation, the behavior is undefined.

{/* source:cpp-algorithm-unique:0006 */}
5. 2,4) Same as (1,3), but executed according to `policy`.

{/* source:cpp-algorithm-unique:0007 */}
6. These overloads participate in overload resolution only if all following conditions are satisfied:

<Revision until="C++20">

`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.

</Revision>

<Revision since="C++20">

`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.

</Revision>

### Explanation

{/* source:cpp-algorithm-unique:0008 */}
Removing is done by shifting the elements in the range in such a way that the elements that are not to be removed appear in the beginning of the range.

{/* source:cpp-algorithm-unique:0009 */}
- Shifting is done by <InlineRevision until="C++11">[copy assignment](/docs/cpp/language/classes/as_operator)</InlineRevision><InlineRevision since="C++11">[move assignment](/docs/cpp/language/classes/move_operator)</InlineRevision>.
- The removing operation is stable: the relative order of the elements not to be removed stays the same.
- The underlying sequence of `[first, last)` is not shortened by the removing operation. Given `result` as the returned iterator:

{/* source:cpp-algorithm-unique:0010 */}
- All iterators in `[result, last)` are still [dereferenceable](/docs/cpp/library/iterator#Dereferenceability_and_validity).

{/* source:cpp-algorithm-unique:0011 */}
<Revision since="C++11">

- Each element of `[result, last)` has a valid but unspecified state, because move assignment can eliminate elements by moving from elements that were originally in that range.

</Revision>

### Parameters

{/* source:cpp-algorithm-unique:0012 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to process</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="p">

binary predicate which returns `true` if the elements should be treated as equal.

The signature of the predicate function should be equivalent to the following:

`bool pred(const Type1 &a, const Type2 &b);`

While the signature does not need to have `const &`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1 &` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The types `Type1` and `Type2` must be such that an object of type `ForwardIt` can be dereferenced and then implicitly converted to both of them.

</Parameter>
</ParameterList>

Type requirements:

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- The type of dereferenced `ForwardIt` must meet the requirements of [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable).

### Return value

{/* source:cpp-algorithm-unique:0013 */}
A `ForwardIt` to the new end of the range.

### Complexity

{/* source:cpp-algorithm-unique:0014 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-unique:0015 */}
1. 1,2) Exactly max(0,N-1) comparisons using `operator==`.

{/* source:cpp-algorithm-unique:0016 */}
2. 3,4) Exactly max(0,N-1) applications of the predicate `p`.

### Exceptions

{/* source:cpp-algorithm-unique:0017 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-unique:0018 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

{/* source:cpp-algorithm-unique:0020 */}
[`unique (1)`](/docs/cpp/library/algorithm/unique#Version_1)

```cpp
template<class ForwardIt>
ForwardIt unique(ForwardIt first, ForwardIt last)
{
    if (first == last)
        return last;
 
    ForwardIt result = first;
    while (++first != last)
        if (!(*result == *first) && ++result != first)
            *result = std::move(*first);
 
    return ++result;
}
```

[`unique (3)`](/docs/cpp/library/algorithm/unique#Version_3)

```cpp
template<class ForwardIt, class BinaryPredicate>
ForwardIt unique(ForwardIt first, ForwardIt last, BinaryPredicate p)
{
    if (first == last)
        return last;
 
    ForwardIt result = first;
    while (++first != last)
        if (!p(*result, *first) && ++result != first)
            *result = std::move(*first);
 
    return ++result;
}
```

### Notes

{/* source:cpp-algorithm-unique:0021 */}
A call to `unique` is typically followed by a call to a container's `erase` member function to actually remove elements from the container.

### Example

{/* source:cpp-algorithm-unique:0022 */}
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
 
int main()
{
    // a vector containing several duplicate elements
    std::vector<int> v{1, 2, 1, 1, 3, 3, 3, 4, 5, 4};
    auto print = [&](int id)
    {
        std::cout << "@" << id << ": ";
        for (int i : v)
            std::cout << i << ' ';
        std::cout << '\n';
    };
    print(1);
 
    // remove consecutive (adjacent) duplicates
    auto last = std::unique(v.begin(), v.end());
    // v now holds {1 2 1 3 4 5 4 x x x}, where 'x' is indeterminate
    v.erase(last, v.end());
    print(2);
 
    // sort followed by unique, to remove all duplicates
    std::sort(v.begin(), v.end()); // {1 1 2 3 4 4 5}
    print(3);
 
    last = std::unique(v.begin(), v.end());
    // v now holds {1 2 3 4 5 x x}, where 'x' is indeterminate
    v.erase(last, v.end());
    print(4);
}
```

Output:

```text
@1: 1 2 1 1 3 3 3 4 5 4
@2: 1 2 1 3 4 5 4
@3: 1 1 2 3 4 4 5
@4: 1 2 3 4 5
```
