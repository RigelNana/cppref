{/* source:cpp-algorithm-swap-ranges:0001 */}
1. 1) Exchanges elements between range `[first1, last1)` and another range of `std::distance(first1, last1)` elements starting at `first2`.

{/* source:cpp-algorithm-swap-ranges:0002 */}
2. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-algorithm-swap-ranges:0003 */}
3. This overload participates in overload resolution only if all following conditions are satisfied:

<Revision until="C++20">

`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.

</Revision>

<Revision since="C++20">

`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.

</Revision>

{/* source:cpp-algorithm-swap-ranges:0004 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-swap-ranges:0005 */}
- The two ranges overlap.
- There exists a pair of corresponding iterators `iter1` and `iter2` in the two ranges such that `*iter1` is not [*Swappable*](/docs/cpp/library/named_req/Swappable) with `*iter2`.

### Parameters

{/* source:cpp-algorithm-swap-ranges:0006 */}
<ParameterList>
  <Parameter name="first1, last1">the first range of elements to swap</Parameter>
  <Parameter name="first2">beginning of the second range of elements to swap</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
</ParameterList>

Type requirements:

- `ForwardIt1`, `ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-algorithm-swap-ranges:0007 */}
Iterator to the element past the last element exchanged in the range beginning with `first2`.

### Complexity

{/* source:cpp-algorithm-swap-ranges:0008 */}
Exactly `std::distance(first1, last1)` swaps.

### Exceptions

{/* source:cpp-algorithm-swap-ranges:0009 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-algorithm-swap-ranges:0010 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Notes

{/* source:cpp-algorithm-swap-ranges:0011 */}
Implementations (e.g. [MSVC STL](https://github.com/microsoft/STL/blob/main/stl/src/vector_algorithms.cpp)) may enable vectorization when the iterator type satisfies [*LegacyContiguousIterator*](/docs/cpp/library/named_req/ContiguousIterator) and swapping its value type calls neither non-trivial special member function nor [ADL](/docs/cpp/language/functions/adl)-found swap.

### Possible implementation

{/* source:cpp-algorithm-swap-ranges:0012 */}
```cpp
template<class ForwardIt1, class ForwardIt2>
constexpr //< since C++20
ForwardIt2 swap_ranges(ForwardIt1 first1, ForwardIt1 last1, ForwardIt2 first2)
{
    for (; first1 != last1; ++first1, ++first2)
        std::iter_swap(first1, first2);
 
    return first2;
}
```

### Example

{/* source:cpp-algorithm-swap-ranges:0013 */}
Demonstrates swapping of subranges from different containers.

```cpp
#include <algorithm>
#include <iostream>
#include <list>
#include <vector>
 
auto print = [](auto comment, auto const& seq)
{
    std::cout << comment;
    for (const auto& e : seq)
        std::cout << e << ' ';
    std::cout << '\n';
};
 
int main()
{
    std::vector<char> v{'a', 'b', 'c', 'd', 'e'};
    std::list<char> l{'1', '2', '3', '4', '5'};
 
    print("Before swap_ranges:\n" "v: ", v);
    print("l: ", l);
 
    std::swap_ranges(v.begin(), v.begin() + 3, l.begin());
 
    print("After swap_ranges:\n" "v: ", v);
    print("l: ", l);
}
```

Output:

```text
Before swap_ranges:
v: a b c d e
l: 1 2 3 4 5
After swap_ranges:
v: 1 2 3 d e
l: a b c 4 5
```
