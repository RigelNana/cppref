{/* source:cpp-algorithm-sort-heap:0001 */}
Converts the [heap](/docs/cpp/library/algorithm#Heap_operations) `[first, last)` into a sorted range. The heap property is no longer maintained.

{/* source:cpp-algorithm-sort-heap:0002 */}
1. 1) The heap is with respect to <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">`std::less{}`</InlineRevision>, and will be sorted with respect to <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-sort-heap:0003 */}
2. 2) The heap is with respect to `comp`, and will be sorted with respect to `comp`.

{/* source:cpp-algorithm-sort-heap:0004 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-sort-heap:0005 */}
- `[first, last)` is not a heap.

{/* source:cpp-algorithm-sort-heap:0006 */}
<Revision until="C++11">

- The type of `*first` is not [*Swappable*](/docs/cpp/library/named_req/Swappable).

</Revision>

<Revision since="C++11">

- `RandomIt` is not [*ValueSwappable*](/docs/cpp/library/named_req/ValueSwappable).
- The type of `*first` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
- The type of `*first` is not [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable).

</Revision>

### Parameters

{/* source:cpp-algorithm-sort-heap:0007 */}
<ParameterList>
  <Parameter name="first, last">the heap to be sorted</Parameter>
  <Parameter name="comp">

comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is *less* than the second.

The signature of the comparison function should be equivalent to the following:

`bool cmp(const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The types `Type1` and `Type2` must be such that an object of type `RandomIt` can be dereferenced and then implicitly converted to both of them.

Type requirements:

- `RandomIt` must meet the requirements of [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator).
- `Compare` must meet the requirements of [*Compare*](/docs/cpp/library/named_req/Compare).

</Parameter>
</ParameterList>

### Complexity

{/* source:cpp-algorithm-sort-heap:0008 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-sort-heap:0009 */}
1. 1) At most 2N⋅log(N) comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-sort-heap:0010 */}
2. 2) At most 2N⋅log(N) applications of the comparison function `comp`.

### Possible implementation

{/* source:cpp-algorithm-sort-heap:0011 */}
[`sort_heap (1)`](/docs/cpp/library/algorithm/sort_heap#Version_1)

```cpp
template<class RandomIt>
void sort_heap(RandomIt first, RandomIt last)
{
    while (first != last)
        std::pop_heap(first, last--);
}
```

[`sort_heap (2)`](/docs/cpp/library/algorithm/sort_heap#Version_2)

```cpp
template<class RandomIt, class Compare>
void sort_heap(RandomIt first, RandomIt last, Compare comp)
{
    while (first != last)
        std::pop_heap(first, last--, comp);
}
```

### Example

{/* source:cpp-algorithm-sort-heap:0012 */}
```cpp
#include <algorithm>
#include <iostream>
#include <string_view>
#include <vector>
 
void println(std::string_view fmt, const auto& v)
{
    for (std::cout << fmt; const auto &i : v)
        std::cout << i << ' ';
    std::cout << '\n';
}
 
int main()
{
    std::vector<int> v{3, 1, 4, 1, 5, 9};
 
    std::make_heap(v.begin(), v.end());
    println("after make_heap, v: ", v);
 
    std::sort_heap(v.begin(), v.end());
    println("after sort_heap, v: ", v);
}
```

Output:

```text
after make_heap, v: 9 4 5 1 1 3
after sort_heap, v: 1 1 3 4 5 9
```
