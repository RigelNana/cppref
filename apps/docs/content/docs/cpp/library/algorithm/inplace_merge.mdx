{/* source:cpp-algorithm-inplace-merge:0001 */}
Merges two consecutive sorted ranges [`first`, `middle`) and [`middle`, `last`) into one sorted range [`first`, `last`).

{/* source:cpp-algorithm-inplace-merge:0002 */}
1. 1) If [`first`, `middle`) or [`middle`, `last`) is not [sorted](/docs/cpp/library/algorithm#Requirements) with respect to <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision>, the behavior is undefined.

{/* source:cpp-algorithm-inplace-merge:0003 */}
2. 3) If [`first`, `middle`) or [`middle`, `last`) is not sorted with respect to `comp`, the behavior is undefined.

{/* source:cpp-algorithm-inplace-merge:0004 */}
3. 2,4) Same as (1,3), but executed according to `policy`.

{/* source:cpp-algorithm-inplace-merge:0005 */}
4. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">
   `std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.
   </Revision>

   <Revision since="C++20">
   `std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.
   </Revision>

{/* source:cpp-algorithm-inplace-merge:0006 */}
This merge function is stable, which means that for equivalent elements in the original two ranges, the elements from the first range (preserving their original order) precede the elements from the second range (preserving their original order).

{/* source:cpp-algorithm-inplace-merge:0007 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-inplace-merge:0008 */}
- [`first`, `middle`) or [`middle`, `last`) is not a [valid range](/docs/cpp/library/iterator#Ranges).

{/* source:cpp-algorithm-inplace-merge:0009 */}
<Revision until="C++11">
- The type of `*first` is not [*Swappable*](/docs/cpp/library/named_req/Swappable).
</Revision>

<Revision since="C++11">
- `BiditIt` is not [*ValueSwappable*](/docs/cpp/library/named_req/ValueSwappable).
- The type of `*first` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
- The type of `*first` is not [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable).
</Revision>

### Parameters

{/* source:cpp-algorithm-inplace-merge:0010 */}
<ParameterList>
  <Parameter name="first">the beginning of the first sorted range</Parameter>
  <Parameter name="middle">the end of the first sorted range and the beginning of the second</Parameter>
  <Parameter name="last">the end of the second sorted range</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="comp">
comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is *less* than (i.e. is ordered *before*) the second.

The signature of the comparison function should be equivalent to the following:

`bool cmp(const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>).
The types `Type1` and `Type2` must be such that an object of type `BidirIt` can be dereferenced and then implicitly converted to both of them.
  </Parameter>
</ParameterList>

Type requirements

- `BidirIt` must meet the requirements of [*LegacyBidirectionalIterator*](/docs/cpp/library/named_req/BidirectionalIterator).
- `Compare` must meet the requirements of [*Compare*](/docs/cpp/library/named_req/Compare).

### Complexity

{/* source:cpp-algorithm-inplace-merge:0011 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-inplace-merge:0012 */}
1. 1) Exactly N-1 comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision> if enough additional memory is available, O(N⋅log(N)) comparisons otherwise.

{/* source:cpp-algorithm-inplace-merge:0013 */}
2. 2) O(N⋅log(N)) comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-inplace-merge:0014 */}
3. 3) Exactly N-1 applications of the comparison function `comp` if enough additional memory is available, O(N⋅log(N)) applications otherwise.

{/* source:cpp-algorithm-inplace-merge:0015 */}
4. 4) O(N⋅log(N)) applications of the comparison function `comp`.

### Exceptions

{/* source:cpp-algorithm-inplace-merge:0016 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-inplace-merge:0017 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Example

{/* source:cpp-algorithm-inplace-merge:0021 */}
The following code is an implementation of merge sort.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
 
template<class Iter>
void merge_sort(Iter first, Iter last)
{
    if (last - first > 1)
    {
        Iter middle = first + (last - first) / 2;
        merge_sort(first, middle);
        merge_sort(middle, last);
        std::inplace_merge(first, middle, last);
    }
}
 
int main()
{
    std::vector<int> v{8, 2, -2, 0, 11, 11, 1, 7, 3};
    merge_sort(v.begin(), v.end());
    for (const auto& n : v)
        std::cout << n << ' ';
    std::cout << '\n';
}
```

Output:

```text
-2 0 1 2 3 7 8 11 11
```
