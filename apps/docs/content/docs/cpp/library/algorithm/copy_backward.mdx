{/* source:cpp-algorithm-copy-backward:0001 */}
Copies the elements from the range `[first, last)` to another range ending at `d_last`. The elements are copied in reverse order (the last element is copied first), but their relative order is preserved.

{/* source:cpp-algorithm-copy-backward:0002 */}
The behavior is undefined if `d_last` is within `(first, last]`. [`std::copy`](/docs/cpp/library/algorithm/copy) must be used instead of `std::copy_backward` in that case.

### Parameters

{/* source:cpp-algorithm-copy-backward:0003 */}
<ParameterList>
  <Parameter name="first, last">the range of the elements to copy from</Parameter>
  <Parameter name="d_last">the end of the destination range</Parameter>
</ParameterList>

**Type requirements**

- `BidirIt` must meet the requirements of [*LegacyBidirectionalIterator*](/docs/cpp/library/named_req/BidirectionalIterator).

### Return value

{/* source:cpp-algorithm-copy-backward:0004 */}
Iterator to the last element copied.

### Complexity

{/* source:cpp-algorithm-copy-backward:0005 */}
Exactly `std::distance(first, last)` assignments.

### Notes

{/* source:cpp-algorithm-copy-backward:0006 */}
When copying overlapping ranges, `std::copy` is appropriate when copying to the left (beginning of the destination range is outside the source range) while `std::copy_backward` is appropriate when copying to the right (end of the destination range is outside the source range).

### Possible implementation

{/* source:cpp-algorithm-copy-backward:0007 */}
```cpp
template<class BidirIt1, class BidirIt2>
BidirIt2 copy_backward(BidirIt1 first, BidirIt1 last, BidirIt2 d_last)
{
    while (first != last)
        *(--d_last) = *(--last);
    return d_last;
}
```

### Example

{/* source:cpp-algorithm-copy-backward:0008 */}
```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <vector>
 
int main()
{
    std::vector<int> source(4);
    std::iota(source.begin(), source.end(), 1); // fills with 1, 2, 3, 4
 
    std::vector<int> destination(6);
 
    std::copy_backward(source.begin(), source.end(), destination.end());
 
    std::cout << "destination contains: ";
    for (auto i: destination)
        std::cout << i << ' ';
    std::cout << '\n';
}
```

Output:

```text
destination contains: 0 0 1 2 3 4
```
