{/* source:cpp-algorithm-make-heap:0001 */}
Constructs a [heap](/docs/cpp/library/algorithm#Heap_operations) in the range `[first, last)`.

{/* source:cpp-algorithm-make-heap:0002 */}
1. 1) The constructed heap is with respect to <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-make-heap:0003 */}
2. 2) The constructed heap is with respect to `comp`.

{/* source:cpp-algorithm-make-heap:0004 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-make-heap:0005 */}
<Revision until="C++11">
- The type of `*first` is not [*Swappable*](/docs/cpp/library/named_req/Swappable).
</Revision>
<Revision since="C++11">
- `RandomIt` is not [*ValueSwappable*](/docs/cpp/library/named_req/ValueSwappable).
- The type of `*first` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
- The type of `*first` is not [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable).
</Revision>

### Parameters

{/* source:cpp-algorithm-make-heap:0006 */}
<ParameterList>
  <Parameter name="first, last">the range to make the heap from</Parameter>
  <Parameter name="comp">
comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is *less* than the second.

The signature of the comparison function should be equivalent to the following:

`bool cmp(const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>).

The types `Type1` and `Type2` must be such that an object of type `RandomIt` can be dereferenced and then implicitly converted to both of them.
  </Parameter>
</ParameterList>

Type requirements
- `RandomIt` must meet the requirements of [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator).
- `Compare` must meet the requirements of [*Compare*](/docs/cpp/library/named_req/Compare).

### Complexity

{/* source:cpp-algorithm-make-heap:0007 */}
Given N as `std::distance(first, last)`:

{/* source:cpp-algorithm-make-heap:0008 */}
1. 1) At most 3N comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-make-heap:0009 */}
2. 2) At most 3N applications of the comparison function `comp`.

### Example

{/* source:cpp-algorithm-make-heap:0010 */}
```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <string_view>
#include <vector>
 
void print(std::string_view text, const std::vector<int>& v = {})
{
    std::cout << text << ": ";
    for (const auto& e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}
 
int main()
{
    print("Max heap");
 
    std::vector<int> v{3, 2, 4, 1, 5, 9};
    print("initially, v", v);
 
    std::make_heap(v.begin(), v.end());
    print("after make_heap, v", v);
 
    std::pop_heap(v.begin(), v.end());
    print("after pop_heap, v", v);
 
    auto top = v.back();
    v.pop_back();
    print("former top element", {top});
    print("after removing the former top element, v", v);
 
    print("\nMin heap");
 
    std::vector<int> v1{3, 2, 4, 1, 5, 9};
    print("initially, v1", v1);
 
    std::make_heap(v1.begin(), v1.end(), std::greater<>{});
    print("after make_heap, v1", v1);
 
    std::pop_heap(v1.begin(), v1.end(), std::greater<>{});
    print("after pop_heap, v1", v1);
 
    auto top1 = v1.back();
    v1.pop_back();
    print("former top element", {top1});
    print("after removing the former top element, v1", v1);
}
```

Output:

```text
Max heap:
initially, v: 3 2 4 1 5 9
after make_heap, v: 9 5 4 1 2 3
after pop_heap, v: 5 3 4 1 2 9
former top element: 9
after removing the former top element, v: 5 3 4 1 2
 
Min heap:
initially, v1: 3 2 4 1 5 9
after make_heap, v1: 1 2 4 3 5 9
after pop_heap, v1: 2 3 4 9 5 1
former top element: 1
after removing the former top element, v1: 2 3 4 9 5
```
