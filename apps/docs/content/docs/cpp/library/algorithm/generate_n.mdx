{/* source:cpp-algorithm-generate-n:0001 */}
1. 1) Assigns values, generated by given function object `g`, to the first `count` elements in the range beginning at `first`, if `count > 0`. Does nothing otherwise.

{/* source:cpp-algorithm-generate-n:0002 */}
2. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-algorithm-generate-n:0003 */}
3. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">
   `std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.
   </Revision>

   <Revision since="C++20">
   `std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.
   </Revision>

{/* source:cpp-algorithm-generate-n:0004 */}
If `Size` is not [convertible](/docs/cpp/language/expressions/implicit_cast) to an [integral type](/docs/cpp/language/basic_concepts/type-id), the program is ill-formed.

### Parameters

{/* source:cpp-algorithm-generate-n:0005 */}
<ParameterList>
  <Parameter name="first">the beginning of the range of elements to generate</Parameter>
  <Parameter name="count">number of the elements to generate</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="g">
generator function object that will be called. The signature of the function should be equivalent to the following:

`Ret fun();`

The type `Ret` must be such that an object of type `OutputIt` can be dereferenced and assigned a value of type `Ret`.
  </Parameter>
</ParameterList>

Type requirements

- `OutputIt` must meet the requirements of [*LegacyOutputIterator*](/docs/cpp/library/named_req/OutputIterator).
- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-algorithm-generate-n:0006 */}
Iterator one past the last element assigned if `count > 0`, `first` otherwise.

### Complexity

{/* source:cpp-algorithm-generate-n:0007 */}
Exactly `std::max(0, count)` invocations of `g()` and assignments.

### Exceptions

{/* source:cpp-algorithm-generate-n:0008 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-algorithm-generate-n:0009 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-generate-n:0010 */}
```cpp
template<class OutputIt, class Size, class Generator>
constexpr // since C++20
OutputIt generate_n(OutputIt first, Size count, Generator g)
{
    for (Size i = 0; i < count; ++i, ++first)
        *first = g();
 
    return first;
}
```

### Example

{/* source:cpp-algorithm-generate-n:0011 */}
```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <iterator>
#include <random>
 
int main()
{
    std::mt19937 rng; // default constructed, seeded with fixed seed
    std::generate_n(std::ostream_iterator<std::mt19937::result_type>(std::cout, " "),
                    5, std::ref(rng));
    std::cout << '\n';
}
```

Output:

```text
3499211612 581869302 3890346734 3586334585 545404204
```
