{/* source:cpp-algorithm-minmax:0001 */}
Returns the lowest and the greatest of the given values.

{/* source:cpp-algorithm-minmax:0002 */}
1. 1,2) Returns references to the smaller and the greater of `a` and `b`.

{/* source:cpp-algorithm-minmax:0003 */}
2. 1) Uses `operator<` to compare the values.

{/* source:cpp-algorithm-minmax:0004 */}
3. If `T` is not [*LessThanComparable*](/docs/cpp/library/named_req/LessThanComparable), the behavior is undefined.

{/* source:cpp-algorithm-minmax:0005 */}
4. 2) Use the comparison function `comp` to compare the values.

{/* source:cpp-algorithm-minmax:0006 */}
5. 3,4) Returns the smallest and the greatest of the values in initializer list `ilist`.

{/* source:cpp-algorithm-minmax:0007 */}
6. If `ilist.size()` is zero, or `T` is not [*CopyConstructible*](/docs/cpp/library/named_req/CopyConstructible), the behavior is undefined.

{/* source:cpp-algorithm-minmax:0008 */}
7. 3) Uses `operator<` to compare the values.

{/* source:cpp-algorithm-minmax:0009 */}
8. If `T` is not [*LessThanComparable*](/docs/cpp/library/named_req/LessThanComparable), the behavior is undefined.

{/* source:cpp-algorithm-minmax:0010 */}
9. 4) Use the comparison function `comp` to compare the values.

### Parameters

{/* source:cpp-algorithm-minmax:0011 */}
<ParameterList>
  <Parameter name="a, b">the values to compare</Parameter>
  <Parameter name="ilist">initializer list with the values to compare</Parameter>
  <Parameter name="comp">
comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is less than the second.

The signature of the comparison function should be equivalent to the following:

`bool cmp(const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The types `Type1` and `Type2` must be such that an object of type `T` can be implicitly converted to both of them.
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-algorithm-minmax:0012 */}
1. 1,2) Returns the result of `std::pair<const T&, const T&>(a, b)` if `a < b` or if `a` is equivalent to `b`. Returns the result of `std::pair<const T&, const T&>(b, a)` if `b < a`.

{/* source:cpp-algorithm-minmax:0013 */}
2. 3,4) A pair with the smallest value in `ilist` as the first element and the greatest as the second. If several elements are equivalent to the smallest, the leftmost such element is returned. If several elements are equivalent to the largest, the rightmost such element is returned.

### Complexity

{/* source:cpp-algorithm-minmax:0014 */}
1. 1) Exactly one comparison using `operator<`.

{/* source:cpp-algorithm-minmax:0015 */}
2. 2) Exactly one application of the comparison function `comp`.

{/* source:cpp-algorithm-minmax:0016 */}
3. 3,4) Given `N` as `ilist.size()`:

{/* source:cpp-algorithm-minmax:0017 */}
4. 3) At most `3N/2` comparisons using `operator<`.

{/* source:cpp-algorithm-minmax:0018 */}
5. 4) At most `3N/2` applications of the comparison function `comp`.

### Possible implementation

{/* source:cpp-algorithm-minmax:0019 */}
[`minmax (1)`](/docs/cpp/library/algorithm/minmax#Version_1)

```cpp
template<class T>
constexpr std::pair<const T&, const T&> minmax(const T& a, const T& b)
{
    return (b < a) ? std::pair<const T&, const T&>(b, a)
                   : std::pair<const T&, const T&>(a, b);
}
```

[`minmax (2)`](/docs/cpp/library/algorithm/minmax#Version_2)

```cpp
template<class T, class Compare>
constexpr std::pair<const T&, const T&> minmax(const T& a, const T& b, Compare comp)
{
    return comp(b, a) ? std::pair<const T&, const T&>(b, a)
                      : std::pair<const T&, const T&>(a, b);
}
```

[`minmax (3)`](/docs/cpp/library/algorithm/minmax#Version_3)

```cpp
template<class T>
constexpr std::pair<T, T> minmax(std::initializer_list<T> ilist)
{
    auto p = std::minmax_element(ilist.begin(), ilist.end());
    return std::pair(*p.first, *p.second);
}
```

[`minmax (4)`](/docs/cpp/library/algorithm/minmax#Version_4)

```cpp
template<class T, class Compare>
constexpr std::pair<T, T> minmax(std::initializer_list<T> ilist, Compare comp)
{
    auto p = std::minmax_element(ilist.begin(), ilist.end(), comp);
    return std::pair(*p.first, *p.second);
}
```

### Notes

{/* source:cpp-algorithm-minmax:0020 */}
For overloads ([1,2](/docs/cpp/library/algorithm/minmax#Version_1)), if one of the parameters is a temporary, the reference returned becomes a dangling reference at the end of the full expression that contains the call to `minmax`:

{/* source:cpp-algorithm-minmax:0021 */}
```cpp
int n = 1;
auto p = std::minmax(n, n + 1);
int m = p.first; // ok
int x = p.second; // undefined behavior
 
// Note that structured bindings have the same issue
auto [mm, xx] = std::minmax(n, n + 1);
xx; // undefined behavior
```

### Example

{/* source:cpp-algorithm-minmax:0022 */}
```cpp
#include <algorithm>
#include <cstdlib>
#include <ctime>
#include <iostream>
#include <vector>
 
int main()
{
    std::vector<int> v{3, 1, 4, 1, 5, 9, 2, 6};
    std::srand(std::time(0));
    std::pair<int, int> bounds = std::minmax(std::rand() % v.size(),
                                             std::rand() % v.size());
 
    std::cout << "v[" << bounds.first << "," << bounds.second << "]: ";
    for (int i = bounds.first; i < bounds.second; ++i)
        std::cout << v[i] << ' ';
    std::cout << '\n';
}
```

Possible output:

```text
v[2,7]: 4 1 5 9 2
```
