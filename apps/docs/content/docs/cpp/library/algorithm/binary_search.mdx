{/* source:cpp-algorithm-binary-search:0001 */}
Checks if an element equivalent to `value` appears within the partitioned range `[first, last)`.

{/* source:cpp-algorithm-binary-search:0002 */}
1. 1) The equivalence is checked using `operator<`:

   <Revision until="C++20">
   If `!bool(*iter < value) && !bool(value < *iter)` is `true` for some iterator `iter` in `[first, last)`, returns `true`. Otherwise returns `false`.

   If any of the following conditions is satisfied, the behavior is undefined:

   - For any element `elem` of `[first, last)`, `bool(elem < value)` does not imply `!bool(value < elem)`.
   - The elements `elem` of `[first, last)` are not [partitioned](/docs/cpp/library/algorithm#Requirements) with respect to expressions `bool(elem < value)` and `!bool(value < elem)`.
   </Revision>

   <Revision since="C++20">
   Equivalent to `std::binary_search(first, last, value, std::less{})`.
   </Revision>

{/* source:cpp-algorithm-binary-search:0003 */}
2. 2) The equivalence is checked using `comp`:

{/* source:cpp-algorithm-binary-search:0004 */}
3. If `!bool(comp(*iter, value)) && !bool(comp(value, *iter))` is `true` for some iterator `iter` in `[first, last)`, returns `true`. Otherwise returns `false`.

{/* source:cpp-algorithm-binary-search:0005 */}
4. If any of the following conditions is satisfied, the behavior is undefined:

   - For any element `elem` of `[first, last)`, `bool(comp(elem, value))` does not imply `!bool(comp(value, elem))`.
   - The elements `elem` of `[first, last)` are not [partitioned](/docs/cpp/library/algorithm#Requirements) with respect to expressions `bool(comp(elem, value))` and `!bool(comp(value, elem))`.

### Parameters

{/* source:cpp-algorithm-binary-search:0006 */}
<ParameterList>
  <Parameter name="first, last">the partitioned range of elements to examine</Parameter>
  <Parameter name="value">value to compare the elements to</Parameter>
  <Parameter name="comp">
binary predicate which returns `true` if the first argument is ordered before the second.

The signature of the predicate function should be equivalent to the following:

`bool pred(const Type1 &a, const Type2 &b);`

While the signature does not need to have `const &`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1 &` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>).

The types `Type1` and `Type2` must be such that an object of type `T` can be implicitly converted to both `Type1` and `Type2`, and an object of type `ForwardIt` can be dereferenced and then implicitly converted to both `Type1` and `Type2`.
  </Parameter>
</ParameterList>

**Type requirements**

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `Compare` must meet the requirements of [*BinaryPredicate*](/docs/cpp/library/named_req/BinaryPredicate). It is not required to satisfy [*Compare*](/docs/cpp/library/named_req/Compare).

### Return value

{/* source:cpp-algorithm-binary-search:0007 */}
`true` if an element equivalent to `value` is found, `false` otherwise.

### Complexity

{/* source:cpp-algorithm-binary-search:0008 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-binary-search:0009 */}
1. 1) At most log2(N)+O(1) comparisons with `value` using <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-binary-search:0010 */}
2. 2) At most log2(N)+O(1) applications of the comparator `comp`.

{/* source:cpp-algorithm-binary-search:0011 */}
However, if `ForwardIt` is not a [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator), the number of iterator increments is linear in `N`.

### Notes

{/* source:cpp-algorithm-binary-search:0012 */}
Although `std::binary_search` only requires `[first, last)` to be partitioned, this algorithm is usually used in the case where `[first, last)` is sorted, so that the binary search is valid for any value.

{/* source:cpp-algorithm-binary-search:0013 */}
`std::binary_search` only checks whether an equivalent element exists. To obtain an iterator to that element (if exists), [`std::lower_bound`](/docs/cpp/library/algorithm/lower_bound) should be used instead.

{/* source:cpp-algorithm-binary-search:0016 */}
[`binary_search (1)`](/docs/cpp/library/algorithm/binary_search#Version_1)

```cpp
template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type>
bool binary_search(ForwardIt first, ForwardIt last, const T& value)
{
    return std::binary_search(first, last, value, std::less{});
}
```

[`binary_search (2)`](/docs/cpp/library/algorithm/binary_search#Version_2)

```cpp
template<class ForwardIt, class T = typename std::iterator_traits<ForwardIt>::value_type,
         class Compare>
bool binary_search(ForwardIt first, ForwardIt last, const T& value, Compare comp)
{
    first = std::lower_bound(first, last, value, comp);
    return (!(first == last) and !(comp(value, *first)));
}
```

### Example

{/* source:cpp-algorithm-binary-search:0017 */}
```cpp
#include <algorithm>
#include <cassert>
#include <complex>
#include <iostream>
#include <vector>
 
int main()
{
    const auto haystack = {1, 3, 4, 5, 9};
 
    for (const auto needle : {1, 2, 3})
    {
        std::cout << "Searching for " << needle << '\n';
        if (std::binary_search(haystack.begin(), haystack.end(), needle))
            std::cout << "Found " << needle << '\n';
        else
            std::cout << "Not found!\n";
    }
 
    using CD = std::complex<double>;
    std::vector<CD> nums{{1, 1}, {2, 3}, {4, 2}, {4, 3}};
    auto cmpz = [](CD x, CD y){ return abs(x) < abs(y); };
    #ifdef __cpp_lib_algorithm_default_value_type
        assert(std::binary_search(nums.cbegin(), nums.cend(), {4, 2}, cmpz));
    #else
        assert(std::binary_search(nums.cbegin(), nums.cend(), CD{4, 2}, cmpz));
    #endif
}
```

Output:

```text
Searching for 1
Found 1
Searching for 2
Not found!
Searching for 3
Found 3
```
