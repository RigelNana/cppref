{/* source:cpp-algorithm-min-element:0001 */}
Finds the smallest element in the range `[first, last)`.

{/* source:cpp-algorithm-min-element:0002 */}
1. 1) Elements are compared using <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-min-element:0003 */}
2. 3) Elements are compared using the comparison function `comp`.

{/* source:cpp-algorithm-min-element:0004 */}
3. 2,4) Same as (1,3), but executed according to `policy`.

{/* source:cpp-algorithm-min-element:0005 */}
4. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

### Parameters

{/* source:cpp-algorithm-min-element:0006 */}
<ParameterList>
  <Parameter name="first, last">forward iterators defining the range to examine</Parameter>
  <Parameter name="policy">the execution policy to use</Parameter>
  <Parameter name="comp">
comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is less than the second.

The signature of the comparison function should be equivalent to the following:

`bool cmp(const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The types `Type1` and `Type2` must be such that an object of type `ForwardIt` can be dereferenced and then implicitly converted to both of them.
  </Parameter>
</ParameterList>

Type requirements

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-algorithm-min-element:0007 */}
Iterator to the smallest element in the range `[first, last)`. If several elements in the range are equivalent to the smallest element, returns the iterator to the first such element. Returns `last` if the range is empty.

### Complexity

{/* source:cpp-algorithm-min-element:0008 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-min-element:0009 */}
1. 1,2) Exactly `max(N-1,0)` comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision> <InlineRevision since="C++20">`std::less{}`</InlineRevision>.

{/* source:cpp-algorithm-min-element:0010 */}
2. 3,4) Exactly `max(N-1,0)` applications of the comparison function `comp`.

### Exceptions

{/* source:cpp-algorithm-min-element:0011 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-min-element:0012 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined. If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-min-element:0013 */}
[`min_element (1)`](/docs/cpp/library/algorithm/min_element#Version_1)

```cpp
template<class ForwardIt>
ForwardIt min_element(ForwardIt first, ForwardIt last)
{
    if (first == last)
        return last;
 
    ForwardIt smallest = first;
 
    while (++first != last)
        if (*first < *smallest)
            smallest = first;
 
    return smallest;
}
```

[`min_element (3)`](/docs/cpp/library/algorithm/min_element#Version_3)

```cpp
template<class ForwardIt, class Compare>
ForwardIt min_element(ForwardIt first, ForwardIt last, Compare comp)
{
    if (first == last)
        return last;
 
    ForwardIt smallest = first;
 
    while (++first != last)
        if (comp(*first, *smallest))
            smallest = first;
 
    return smallest;
}
```

### Example

{/* source:cpp-algorithm-min-element:0014 */}
```cpp
#include <algorithm>
#include <iostream>
#include <vector>
 
int main()
{
    std::vector<int> v{3, 1, -4, 1, 5, 9};
 
    std::vector<int>::iterator result = std::min_element(v.begin(), v.end());
    std::cout << "min element has value " << *result << " and index ["
              << std::distance(v.begin(), result) << "]\n";
}
```

Output:

```text
min element has value -4 and index [2]
```
