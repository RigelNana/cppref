{/* source:cpp-algorithm-iter-swap:0001 */}
Swaps the values of the elements the given iterators are pointing to.

{/* source:cpp-algorithm-iter-swap:0002 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-iter-swap:0003 */}
- `a` or `b` is not [dereferenceable](/docs/cpp/library/iterator#Dereferenceability_and_validity).
- `*a` is not [*Swappable*](/docs/cpp/library/named_req/Swappable) with `*b`.

### Parameters

{/* source:cpp-algorithm-iter-swap:0004 */}
<ParameterList>
  <Parameter name="a, b">iterators to the elements to swap</Parameter>
</ParameterList>

Type requirements
- `ForwardIt1, ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-algorithm-iter-swap:0005 */}
(none)

### Complexity

{/* source:cpp-algorithm-iter-swap:0006 */}
Constant.

### Notes

{/* source:cpp-algorithm-iter-swap:0007 */}
This function template models the semantics of the swap operation given by [*Swappable*](/docs/cpp/library/named_req/Swappable). That is, overloads of `swap` found by [ADL](/docs/cpp/language/functions/adl) and the fall back of [`std::swap`](/docs/cpp/library/algorithm/swap) are considered.

### Possible implementation

{/* source:cpp-algorithm-iter-swap:0008 */}
```cpp
template<class ForwardIt1, class ForwardIt2>
constexpr //< since C++20
void iter_swap(ForwardIt1 a, ForwardIt2 b)
{
    using std::swap;
    swap(*a, *b);
}
```

### Example

{/* source:cpp-algorithm-iter-swap:0009 */}
The following is an implementation of selection sort in C++.

```cpp
#include <algorithm>
#include <iostream>
#include <random>
#include <string_view>
#include <vector>
 
template<class ForwardIt>
void selection_sort(ForwardIt begin, ForwardIt end)
{
    for (ForwardIt it = begin; it != end; ++it)
        std::iter_swap(it, std::min_element(it, end));
}
 
void println(std::string_view rem, std::vector<int> const& v)
{
    std::cout << rem;
    for (int e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}
 
template<int min, int max>
int rand_int()
{
    static std::uniform_int_distribution dist(min, max);
    static std::mt19937 gen(std::random_device{}());
    return dist(gen);
}
 
int main()
{
    std::vector<int> v;
    std::generate_n(std::back_inserter(v), 20, rand_int<-9, +9>);
 
    std::cout << std::showpos;
    println("Before sort: ", v);
    selection_sort(v.begin(), v.end());
    println("After sort:  ", v);
}
```

Possible output:

```text
Before sort: -9 -3 +2 -8 +0 -1 +8 -4 -5 +1 -4 -5 +4 -9 -8 -6 -6 +8 -4 -6 
After sort:  -9 -9 -8 -8 -6 -6 -6 -5 -5 -4 -4 -4 -3 -1 +0 +1 +2 +4 +8 +8
```
