{/* source:cpp-algorithm-fill:0001 */}
1. 1) Assigns the given `value` to all elements in the range `[first, last)`.

{/* source:cpp-algorithm-fill:0002 */}
2. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-algorithm-fill:0003 */}
3. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

{/* source:cpp-algorithm-fill:0004 */}
If `value` is not [writable](/docs/cpp/library/iterator#Types_and_writability) to `first`, the program is ill-formed.

### Parameters

{/* source:cpp-algorithm-fill:0005 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to modify</Parameter>
  <Parameter name="value">the value to be assigned</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
</ParameterList>

**Type requirements**

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Complexity

{/* source:cpp-algorithm-fill:0006 */}
Exactly `std::distance(first, last)` assignments.

### Exceptions

{/* source:cpp-algorithm-fill:0007 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-algorithm-fill:0008 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-algorithm-fill:0009 */}
[`fill`](/docs/cpp/library/algorithm/fill#Version_1)

```cpp
template<class ForwardIt,
         class T = typename std::iterator_traits<ForwardIt>::value_type>
void fill(ForwardIt first, ForwardIt last, const T& value)
{
    for (; first != last; ++first)
        *first = value;
}
```

### Example

{/* source:cpp-algorithm-fill:0011 */}
```cpp
#include <algorithm>
#include <complex>
#include <iostream>
#include <vector>
 
void println(const auto& seq)
{
    for (const auto& e : seq)
        std::cout << e << ' ';
    std::cout << '\n';
}
 
int main()
{
    std::vector<int> v{0, 1, 2, 3, 4, 5, 6, 7, 8};
    println(v);
 
    // set all of the elements to 8
    std::fill(v.begin(), v.end(), 8);
    println(v);
 
    std::vector<std::complex<double>> nums{{1, 3}, {2, 2}, {4, 8}};
    println(nums);
    #ifdef __cpp_lib_algorithm_default_value_type
        std::fill(nums.begin(), nums.end(), {4, 2});
    #else
        std::fill(nums.begin(), nums.end(), std::complex<double>{4, 2});
    #endif
    println(nums);
}
```

Output:

```text
0 1 2 3 4 5 6 7 8
8 8 8 8 8 8 8 8 8
(1,3) (2,2) (4,8) 
(4,2) (4,2) (4,2)
```
