{/* source:cpp-algorithm-pop-heap:0001 */}
Swaps the value in the position `first` and the value in the position `last - 1` and makes the subrange `[first, last - 1)` into a [heap](/docs/cpp/library/algorithm#Heap_operations). This has the effect of removing the first element from the heap `[first, last)`.

{/* source:cpp-algorithm-pop-heap:0002 */}
1. 1) `[first, last)` is a heap with respect to <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">[`std::less{}`](/docs/cpp/library/utility/functional/less)</InlineRevision>.

{/* source:cpp-algorithm-pop-heap:0003 */}
2. 2) `[first, last)` is a heap with respect to `comp`.

{/* source:cpp-algorithm-pop-heap:0004 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-pop-heap:0005 */}
- `[first, last)` is empty.
- `[first, last)` is not a heap with respect to the corresponding comparator.

{/* source:cpp-algorithm-pop-heap:0006 */}
<Revision until="C++11">
- The type of `*first` is not [*Swappable*](/docs/cpp/library/named_req/Swappable).
</Revision>

<Revision since="C++11">
- `RandomIt` is not [*ValueSwappable*](/docs/cpp/library/named_req/ValueSwappable).
- The type of `*first` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
- The type of `*first` is not [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable).
</Revision>

### Parameters

{/* source:cpp-algorithm-pop-heap:0007 */}
<ParameterList>
  <Parameter name="first, last">the non-empty heap to modify</Parameter>
  <Parameter name="comp">
comparison function object (i.e. an object that satisfies the requirements of [*Compare*](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is *less* than the second.

The signature of the comparison function should be equivalent to the following:

`bool cmp(const Type1& a, const Type2& b);`

While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>). The types `Type1` and `Type2` must be such that an object of type `RandomIt` can be dereferenced and then implicitly converted to both of them.
  </Parameter>
</ParameterList>

Type requirements

- `RandomIt` must meet the requirements of [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator).
- `Compare` must meet the requirements of [*Compare*](/docs/cpp/library/named_req/Compare).

### Complexity

{/* source:cpp-algorithm-pop-heap:0008 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-pop-heap:0009 */}
1. 1) At most `2log(N)` comparisons using <InlineRevision until="C++20">`operator<`</InlineRevision><InlineRevision since="C++20">[`std::less{}`](/docs/cpp/library/utility/functional/less)</InlineRevision>.

{/* source:cpp-algorithm-pop-heap:0010 */}
2. 2) At most `2log(N)` applications of the comparison function `comp`.

### Example

{/* source:cpp-algorithm-pop-heap:0011 */}
```cpp
#include <algorithm>
#include <iostream>
#include <string_view>
#include <type_traits>
#include <vector>
 
void println(std::string_view rem, const auto& v)
{
    std::cout << rem;
    if constexpr (std::is_scalar_v<std::decay_t<decltype(v)>>)
        std::cout << v;
    else
        for (int e : v)
            std::cout << e << ' ';
    std::cout << '\n';
}
 
int main()
{
    std::vector<int> v{3, 1, 4, 1, 5, 9};
 
    std::make_heap(v.begin(), v.end());
    println("after make_heap: ", v);
 
    std::pop_heap(v.begin(), v.end()); // moves the largest to the end
    println("after pop_heap:  ", v);
 
    int largest = v.back();
    println("largest element: ", largest);
 
    v.pop_back(); // actually removes the largest element
    println("after pop_back:  ", v);
}
```

Output:

```text
after make_heap: 9 5 4 1 1 3
after pop_heap:  5 3 4 1 1 9
largest element: 9
after pop_back:  5 3 4 1 1
```
