{/* source:cpp-algorithm-swap:0001 */}
Exchanges the given values.

{/* source:cpp-algorithm-swap:0002 */}
1. 1) Swaps the values `a` and `b`.

<Revision since="C++17">

This overload participates in overload resolution only if `std::is_move_constructible_v<T> && std::is_move_assignable_v<T>` is `true`.

</Revision>

{/* source:cpp-algorithm-swap:0003 */}
2. 2) Swaps the arrays `a` and `b`. Equivalent to `std::swap_ranges(a, a + N, b)`.

<Revision since="C++17">

This overload participates in overload resolution only if `std::is_swappable_v<T2>` is `true`.

</Revision>

### Parameters

{/* source:cpp-algorithm-swap:0004 */}
<ParameterList>
  <Parameter name="a, b">the values to be swapped</Parameter>
</ParameterList>

Type requirements:

- `T` must meet the requirements of <InlineRevision until="C++11">[*CopyConstructible*](/docs/cpp/library/named_req/CopyConstructible) and [*CopyAssignable*](/docs/cpp/library/named_req/CopyAssignable)</InlineRevision><InlineRevision since="C++11">[*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible) and [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable)</InlineRevision>.
- `T2` must meet the requirements of [*Swappable*](/docs/cpp/library/named_req/Swappable).

### Return value

{/* source:cpp-algorithm-swap:0005 */}
(none)

### Exceptions

{/* source:cpp-algorithm-swap:0006 */}
1. 1)

<Revision until="C++11">

(none)

</Revision>

<Revision since="C++11">

[noexcept](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(
    std::is_nothrow_move_constructible<T>::value &&
    std::is_nothrow_move_assignable<T>::value

)
```

</Revision>

{/* source:cpp-algorithm-swap:0007 */}
2. 2)

<Revision since="C++11" until="C++17">

[noexcept](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(noexcept(swap(*a, *b)))
```

The lookup for the identifier `swap` in the exception specification finds this function template in addition to anything found by the usual lookup rules, making the exception specification equivalent to C++17 [`std::is_nothrow_swappable`](/docs/cpp/library/meta/is_swappable).

</Revision>

<Revision since="C++17">

[noexcept](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(std::is_nothrow_swappable_v<T2>)
```

</Revision>

### Complexity

{/* source:cpp-algorithm-swap:0008 */}
1. 1) Constant.

{/* source:cpp-algorithm-swap:0009 */}
2. 2) Linear in `N`.

### Specializations

{/* source:cpp-algorithm-swap:0010 */}
<Revision until="C++20">

`std::swap` may be [specialized in namespace std](/docs/cpp/language/extending_std) for program-defined types, but such specializations are not found by [ADL](/docs/cpp/language/functions/adl) (the namespace std is not the associated namespace for the program-defined type).

</Revision>

{/* source:cpp-algorithm-swap:0011 */}
The expected way to make a [program-defined type](/docs/cpp/language/basic_concepts/type-id#Program-defined_type) swappable is to provide a non-member function `swap` in the same namespace as the type: see [*Swappable*](/docs/cpp/library/named_req/Swappable) for details.

### Example

{/* source:cpp-algorithm-swap:0014 */}
```cpp
#include <algorithm>
#include <iostream>
 
namespace Ns
{
    class A
    {
        int id {};
 
        friend void swap(A& lhs, A& rhs)
        {
            std::cout << "swap(" << lhs << ", " << rhs << ")\n";
            std::swap(lhs.id, rhs.id);
        }
 
        friend std::ostream& operator<<(std::ostream& os, A const& a)
        {
            return os << "A::id=" << a.id;
        }
 
    public:
        A(int i) : id {i} {}
        A(A const&) = delete;
        A& operator = (A const&) = delete;
    };
}
 
int main()
{
    int a = 5, b = 3;
    std::cout << a << ' ' << b << '\n';
    std::swap(a, b);
    std::cout << a << ' ' << b << '\n';
 
    Ns::A p {6}, q {9};
    std::cout << p << ' ' << q << '\n';
//  std::swap(p, q); // error, type requirements are not satisfied
    swap(p, q);      // OK, ADL finds the appropriate friend `swap`
    std::cout << p << ' ' << q << '\n';
}
```

Output:

```text
5 3
3 5
A::id=6 A::id=9
swap(A::id=6, A::id=9)
A::id=9 A::id=6
```
