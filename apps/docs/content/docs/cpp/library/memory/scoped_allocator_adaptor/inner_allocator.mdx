Obtains a reference to the inner allocator used to declare this `scoped_allocator_adaptor`.

{/* source:cpp-memory-scoped-allocator-adaptor-inner-allocator:0002 */}
If `sizeof...(InnerAllocs) == 0`, that is, no inner allocators were declared, returns `*this`. Otherwise returns a reference to [`std::scoped_allocator_adaptor<InnerAllocs...>`](/docs/cpp/library/memory/scoped_allocator_adaptor), that is, a scoped allocator composed of all inner allocators of `*this`, with the first inner allocator becoming the outer allocator.

### Parameters

{/* source:cpp-memory-scoped-allocator-adaptor-inner-allocator:0003 */}
(none)

### Return value

{/* source:cpp-memory-scoped-allocator-adaptor-inner-allocator:0004 */}
A reference to the inner allocator, which is itself a `std::scoped_allocator_adaptor`.
