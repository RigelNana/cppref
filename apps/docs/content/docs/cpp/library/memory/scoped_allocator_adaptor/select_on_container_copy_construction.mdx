Creates a new instance of `std::scoped_allocator_adaptor`, where the outer allocator base class and each inner allocator subobject are obtained by calling [`std::allocator_traits<A>::select_on_container_copy_construction()`](/docs/cpp/library/memory/allocator_traits).

### Parameters

{/* source:cpp-memory-scoped-allocator-adaptor-select-on-container-copy-construction:0002 */}
(none)

### Return value

{/* source:cpp-memory-scoped-allocator-adaptor-select-on-container-copy-construction:0003 */}
A new `std::scoped_allocator_adaptor` object, constructed from correctly copied allocators.
