{/* source:cpp-memory-scoped-allocator-adaptor-allocate:0001 */}
Uses the outer allocator to allocate uninitialized storage.

{/* source:cpp-memory-scoped-allocator-adaptor-allocate:0002 */}
1. Calls `std::allocator_traits<OuterAlloc>::allocate(outer_allocator(), n)`.

{/* source:cpp-memory-scoped-allocator-adaptor-allocate:0003 */}
2. Additionally provides memory locality hint, by calling `std::allocator_traits<OuterAlloc>::allocate(outer_allocator(), n, hint)`.

## Parameters

{/* source:cpp-memory-scoped-allocator-adaptor-allocate:0004 */}
<ParameterList>
  <Parameter name="n">the number of objects to allocate storage for</Parameter>
  <Parameter name="hint">pointer to a nearby memory location</Parameter>
</ParameterList>

## Return value

{/* source:cpp-memory-scoped-allocator-adaptor-allocate:0005 */}
The pointer to the allocated storage.
