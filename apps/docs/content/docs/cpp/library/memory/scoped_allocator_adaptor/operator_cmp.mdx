{/* source:cpp-memory-scoped-allocator-adaptor-operator-cmp:0001 */}
Compares two scoped allocator adaptors. Two such allocators are equal if:

{/* source:cpp-memory-scoped-allocator-adaptor-operator-cmp:0002 */}
- `lhs.outer_allocator() == rhs.outer_allocator()`, and
- if `sizeof...(InnerAllocs) > 0`, `lhs.inner_allocator() == rhs.inner_allocator()`.

{/* source:cpp-memory-scoped-allocator-adaptor-operator-cmp:0003 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Return value

{/* source:cpp-memory-scoped-allocator-adaptor-operator-cmp:0005 */}
1. Returns `true` if `lhs` and `rhs` are equal, `false` otherwise.

{/* source:cpp-memory-scoped-allocator-adaptor-operator-cmp:0006 */}
2. Returns `true` if `lhs` and `rhs` are not equal, `false` otherwise.
