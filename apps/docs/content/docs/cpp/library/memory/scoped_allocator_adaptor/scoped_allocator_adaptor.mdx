  <DeclarationDescription>
    {/* source:cpp-memory-scoped-allocator-adaptor-scoped-allocator-adaptor:0001 */}
    1. Default constructor: value-initializes the `OuterAlloc` base class and the inner allocator member object, if used by the implementation.

    {/* source:cpp-memory-scoped-allocator-adaptor-scoped-allocator-adaptor:0002 */}
    2. Constructs the base class `OuterAlloc` from [`std::forward<OuterA2>(outerAlloc)`](/docs/cpp/library/utility/forward), and the inner allocators with `innerAllocs...`. This overload participates in overload resolution only if [`std::is_constructible<OuterAlloc, OuterA2>::value`](/docs/cpp/library/meta/is_constructible) is `true`.

    {/* source:cpp-memory-scoped-allocator-adaptor-scoped-allocator-adaptor:0003 */}
    3. Copy-constructor: initializes each allocator from the corresponding allocator of `other`.

    {/* source:cpp-memory-scoped-allocator-adaptor-scoped-allocator-adaptor:0004 */}
    4. Move-constructor: moves each allocator from the corresponding allocator of `other` into `*this`.

    {/* source:cpp-memory-scoped-allocator-adaptor-scoped-allocator-adaptor:0005 */}
    5. Initializes each allocator from the corresponding allocator of `other`. This overload participates in overload resolution only if [`std::is_constructible<OuterAlloc, const OuterA2&>::value`](/docs/cpp/library/meta/is_constructible) is `true`.

    {/* source:cpp-memory-scoped-allocator-adaptor-scoped-allocator-adaptor:0006 */}
    6. Initializes each allocator from the corresponding allocator of `other`, using move semantics. This overload participates in overload resolution only if [`std::is_constructible<OuterAlloc, OuterA2>::value`](/docs/cpp/library/meta/is_constructible) is `true`.

  </DeclarationDescription>
