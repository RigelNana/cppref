{/* source:cpp-memory-scoped-allocator-adaptor-helpers:0001 */}
These exposition-only helper member function templates are used in member functions [`construct()`](/docs/cpp/library/memory/scoped_allocator_adaptor/construct) and [`destroy()`](/docs/cpp/library/memory/scoped_allocator_adaptor/destroy).

{/* source:cpp-memory-scoped-allocator-adaptor-helpers:0002 */}
1. Obtains the outermost allocator of `alloc`.

- If the expression `alloc.outer_allocator()` is valid, returns `outermost` `(alloc.outer_allocator())`.
- Otherwise, returns `alloc`.

{/* source:cpp-memory-scoped-allocator-adaptor-helpers:0003 */}
2,3. Constructs or destroys an object using the outermost allocator of `*this`.

{/* source:cpp-memory-scoped-allocator-adaptor-helpers:0004 */}
Given the type `std::allocator_traits<std::remove_reference_t<decltype(`outermost`())>>` as `outermost_traits`:

{/* source:cpp-memory-scoped-allocator-adaptor-helpers:0005 */}
2. Equivalent to `outermost_traits::construct(outermost(), p, std::forward<Args>(args)...);`.

{/* source:cpp-memory-scoped-allocator-adaptor-helpers:0006 */}
3. Equivalent to `outermost_traits::destroy(outermost(), p);`.
