{/* source:cpp-memory-scoped-allocator-adaptor-deallocate:0001 */}
Uses the outer allocator to deallocate the storage referenced by `p`, by calling `std::allocator_traits<OuterAlloc>::deallocate(outer_allocator(), p, n)`.

## Parameters

{/* source:cpp-memory-scoped-allocator-adaptor-deallocate:0002 */}
<ParameterList>
  <Parameter name="p">pointer to the previously allocated memory</Parameter>
  <Parameter name="n">the number of objects for which the memory was allocated</Parameter>
</ParameterList>

## Return value

{/* source:cpp-memory-scoped-allocator-adaptor-deallocate:0003 */}
(none)
