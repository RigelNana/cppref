{/* source:cpp-memory-scoped-allocator-adaptor-construct:0001 */}
Constructs an object in allocated, but not initialized storage pointed to by `p` using the outer allocator and the provided constructor arguments. If the object is of a type that itself uses allocators<InlineRevision until="C++20">, or if it is [`std::pair`](/docs/cpp/library/utility/pair)</InlineRevision>, passes the inner allocator down to the constructed object.

{/* source:cpp-memory-scoped-allocator-adaptor-construct:0002 */}
1. Constructs an object of type `T` by [uses-allocator construction](/docs/cpp/library/memory/uses_allocator#Uses-allocator_construction) at the uninitialized memory location indicated by `p` using the outermost allocator.

<Revision until="C++20">

Given `std::uses_allocator<T, inner_allocator_type>::value` as `uses_inner`:

- If `uses_inner` is `false` and `std::is_constructible<T, Args...>::value` is `true`, calls [`outermost-construct`](/docs/cpp/library/memory/scoped_allocator_adaptor/helpers#outermost-construct) `(p, std::forward<Args>(args)...)`.
- Otherwise, if `uses_inner` and `std::is_constructible<T, std::allocator_arg_t, inner_allocator_type&, Args...>::value` are both `true`, calls [`outermost-construct`](/docs/cpp/library/memory/scoped_allocator_adaptor/helpers#outermost-construct) `(p, std::allocator_arg, inner_allocator(), std::forward<Args>(args)...)`.
- Otherwise, if `uses_inner` and `std::is_constructible<T, Args..., inner_allocator_type&>::value` are both `true`, calls [`outermost-construct`](/docs/cpp/library/memory/scoped_allocator_adaptor/helpers#outermost-construct) `(p, std::forward<Args>(args)..., inner_allocator())`.
- Otherwise, the program is ill-formed.

This overload participates in overload resolution only if `T` is not a specialization of [`std::pair`](/docs/cpp/library/utility/pair).

</Revision>

<Revision since="C++20">

Equivalent to

```cpp
std::apply
(
    [p, this](auto&&... newargs)
    {
        outermost-construct(p, std::forward<decltype(newargs)>(newargs)...);
    },
    std::uses_allocator_construction_args
        (inner_allocator(), std::forward<Args>(args)...)
);
```

</Revision>

7. Merges the arguments contained in `tup` and additional arguments required by [uses-allocator construction](/docs/cpp/library/memory/uses_allocator#Uses-allocator_construction) of an object of type `T`.

{/* source:cpp-memory-scoped-allocator-adaptor-construct:0008 */}
Given `std::uses_allocator<T, inner_allocator_type>::value` as `uses_inner`:

- If `uses_inner` is `false` and `std::is_constructible<T, Args...>::value` is `true`, returns `std::tuple<Args&&...>(std::move(tup))`.
- Otherwise, if `uses_inner` and `std::is_constructible<T, std::allocator_arg_t, inner_allocator_type&, Args...>::value` are both `true`, returns `std::tuple_cat(std::tuple<std::allocator_arg_t, inner_allocator_type&>(std::allocator_arg, inner_allocator()), std::tuple<Args&&...>(std::move(tup)))`.
- Otherwise, if `uses_inner` and `std::is_constructible<T, Args..., inner_allocator_type&>::value` are both `true`, returns `std::tuple_cat(std::tuple<Args&&...>(std::move(tup)), std::tuple<inner_allocator_type&>(inner_allocator()))`.
- Otherwise, the program is ill-formed.

## Notes

{/* source:cpp-memory-scoped-allocator-adaptor-construct:0010 */}
This function is called (through [`std::allocator_traits`](/docs/cpp/library/memory/allocator_traits)) by any allocator-aware object, such as [`std::vector`](/docs/cpp/library/container/vector), that was given a [`std::scoped_allocator_adaptor`](/docs/cpp/library/memory/scoped_allocator_adaptor) as the allocator to use. Since `inner_allocator_type` is itself a specialization of [`std::scoped_allocator_adaptor`](/docs/cpp/library/memory/scoped_allocator_adaptor), this function will also be called when the allocator-aware objects constructed through this function start constructing their own members.
