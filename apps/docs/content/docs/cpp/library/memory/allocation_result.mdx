{/* source:cpp-memory-allocation-result:0001 */}
`allocation_result` specializations are returned from the `allocate_at_least` member function of appropriate [`Allocator`](/docs/cpp/library/named_req/Allocator) types (e.g. [`std::allocator::allocate_at_least`](/docs/cpp/library/memory/allocator/allocate_at_least)) and [`std::allocator_traits::allocate_at_least`](/docs/cpp/library/memory/allocator_traits/allocate_at_least).

{/* source:cpp-memory-allocation-result:0002 */}
Every specialization of `allocation_result` has no base classes or declared members other than `ptr` and `count`, thus it is suitable for [aggregate initialization](/docs/cpp/language/initialization/aggregate_initialization) and [structured binding](/docs/cpp/language/declarations/structured_binding).

### Template parameters

{/* source:cpp-memory-allocation-result:0003 */}
<ParameterList>
  <Parameter name="Pointer">typically `std::allocator_traits<Alloc>::pointer`, where `Alloc` is an [`Allocator`](/docs/cpp/library/named_req/Allocator) type</Parameter>
  <Parameter name="SizeType">typically `std::allocator_traits<Alloc>::size_type`, where `Alloc` is an [`Allocator`](/docs/cpp/library/named_req/Allocator) type</Parameter>
</ParameterList>

### Data members

{/* source:cpp-memory-allocation-result:0004 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`ptr`</DescriptionTerm>
    <DescriptionBody>a pointer of type `Pointer` which is typically used for the address of the first element in the storage allocated by `allocate_at_least` (public member object)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`count`</DescriptionTerm>
    <DescriptionBody>a value of type `SizeType` which is typically used for the actual number of elements in the storage allocated by `allocate_at_least` (public member object)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Notes

{/* source:cpp-memory-allocation-result:0005 */}
`Pointer` and `SizeType` are a pointer to an object type and `std::make_unsigned_t<std::ptrdiff_t>` (which is almost always same as [`std::size_t`](/docs/cpp/library/utility/types/size_t)) by default.
