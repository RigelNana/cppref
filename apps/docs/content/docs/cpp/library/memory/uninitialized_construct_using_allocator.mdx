{/* source:cpp-memory-uninitialized-construct-using-allocator:0001 */}
Creates an object of the given type `T` by means of [uses-allocator construction](/docs/cpp/library/memory/uses_allocator) at the uninitialized memory location indicated by `p`.

{/* source:cpp-memory-uninitialized-construct-using-allocator:0002 */}
Equivalent to

{/* source:cpp-memory-uninitialized-construct-using-allocator:0003 */}
```cpp
return std::apply(
    [&]<class... Xs>(Xs&&...xs)
    {
        return std::construct_at(p, std::forward<Xs>(xs)...);
    },
    std::uses_allocator_construction_args<T>(alloc, std::forward<Args>(args)...));```

### Parameters

{/* source:cpp-memory-uninitialized-construct-using-allocator:0004 */}
<ParameterList>
  <Parameter name="p">the memory location where the object will be placed</Parameter>
  <Parameter name="alloc">the allocator to use</Parameter>
  <Parameter name="args">the arguments to pass to `T`'s constructor</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-uninitialized-construct-using-allocator:0005 */}
Pointer to the newly-created object of type `T`.

### Exceptions

{/* source:cpp-memory-uninitialized-construct-using-allocator:0006 */}
May throw any exception thrown by the constructor of `T`, typically including [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc).
