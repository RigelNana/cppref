`std::nothrow_t` is an empty class type used to disambiguate the overloads of throwing and non-throwing [allocation functions](/docs/cpp/library/memory/new/operator_new). `std::nothrow` is a constant of it.

### Example

{/* source:cpp-memory-new-nothrow:0002 */}
```cpp
#include <iostream>
#include <new>
 
int main()
{
    try
    {
        while (true)
        {
            new int[100000000ul];   // throwing overload
        }
    }
    catch (const std::bad_alloc& e)
    {
        std::cout << e.what() << '\n';
    }
 
    while (true)
    {
        int* p = new(std::nothrow) int[100000000ul]; // non-throwing overload
        if (p == nullptr)
        {
            std::cout << "Allocation returned nullptr\n";
            break;
        }
    }
}
```

Output:

```text
std::bad_alloc
Allocation returned nullptr
```
