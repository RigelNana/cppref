{/* source:cpp-memory-new-align-val-t:0001 */}
Both [new-expression](/docs/cpp/language/expressions/new) and [delete-expression](/docs/cpp/language/expressions/delete), when used with objects whose alignment requirement is greater than `__STDCPP_DEFAULT_NEW_ALIGNMENT__`, pass that alignment requirement as an argument of type `std::align_val_t` to the selected allocation/deallocation function.

### Notes

{/* source:cpp-memory-new-align-val-t:0002 */}
Alignment (as obtained by `alignof`) has the type [`std::size_t`](/docs/cpp/library/utility/types/size_t), but placement forms of allocation and deallocation functions that take [`std::size_t`](/docs/cpp/library/utility/types/size_t) as an additional parameter are already in use, so this type is used instead.
