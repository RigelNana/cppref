{/* source:cpp-memory-new:0000 */}
The [new-expression](/docs/cpp/language/expressions/new) is the only way to create an object or an array of objects with dynamic storage duration, that is, with lifetime not restricted to the scope in which it is created. A new-expression obtains storage by calling an allocation function. A [delete-expression](/docs/cpp/language/expressions/delete) destroys a most derived object or an array created by a new-expression and calls the deallocation function. The default allocation and deallocation functions, along with related functions, types, and objects, are declared in the header [`<new>`](/docs/cpp/library/headers/new).
