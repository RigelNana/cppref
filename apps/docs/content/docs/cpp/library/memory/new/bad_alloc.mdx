Constructs a new `bad_alloc` object with an implementation-defined null-terminated byte string which is accessible through [`what()`](/docs/cpp/library/error/exception/what).

1. Default constructor.
2. Copy constructor. <InlineRevision since="C++11">If `*this` and `other` both have dynamic type `std::bad_alloc` then `std::strcmp(what(), other.what()) == 0`.</InlineRevision>

#### `std::bad_alloc::what`

<DeclarationDoc>
  <Declaration language="cpp" until="C++11" code={`virtual const char* what() const throw();`} />
  <Declaration language="cpp" since="C++11" code={`virtual const char* what() const noexcept;`} />
  <InlineRevision since="C++26">constexpr</InlineRevision>
</DeclarationDoc>

Returns the explanatory string.

##### Return value

Pointer to an implementation-defined null-terminated string with explanatory information. The string is suitable for conversion and display as a [`std::wstring`](/docs/cpp/library/string/basic_string). The pointer is guaranteed to be valid at least until the exception object from which it is obtained is destroyed, or until a non-const member function (e.g. copy assignment operator) on the exception object is called.

<Revision since="C++26">
The returned string is encoded with the ordinary literal encoding during constant evaluation.
</Revision>

##### Notes

Implementations are allowed but not required to override `what()`.

### Example

{/* source:cpp-memory-new-bad-alloc:0009 */}
```cpp
#include <iostream>
#include <new>
 
int main()
{
    try
    {
        while (true)
        {
            new int[100000000ul];
        }
    }
    catch (const std::bad_alloc& e)
    {
        std::cout << "Allocation failed: " << e.what() << '\n';
    }
}
```

Possible output:

```text
Allocation failed: std::bad_alloc
```
