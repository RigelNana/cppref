{/* source:cpp-memory-new-get-new-handler:0001 */}
Returns the currently installed new-handler, which may be a null pointer.

{/* source:cpp-memory-new-get-new-handler:0002 */}
This function is thread-safe. Previous call to [`std::set_new_handler`](/docs/cpp/library/memory/new/set_new_handler) synchronizes-with (see [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) the subsequent calls to `std::get_new_handler`.

### Parameters

{/* source:cpp-memory-new-get-new-handler:0003 */}
(none)

### Return value

{/* source:cpp-memory-new-get-new-handler:0004 */}
The currently installed new-handler, which may be a null pointer value.
