{/* source:cpp-memory-weak-ptr-operator:0001 */}
Replaces the managed object with the one managed by `r`. The object is shared with `r`. If `r` manages no object, `*this` manages no object too.

{/* source:cpp-memory-weak-ptr-operator:0002 */}
1. 1-3) Equivalent to `std::weak_ptr<T>(r).swap(*this)`.

{/* source:cpp-memory-weak-ptr-operator:0003 */}
2. 4,5) Equivalent to `std::weak_ptr<T>(std::move(r)).swap(*this)`.

### Parameters

{/* source:cpp-memory-weak-ptr-operator:0004 */}
<ParameterList>
  <Parameter name="r">smart pointer to share an object with</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-weak-ptr-operator:0005 */}
`*this`

### Notes

{/* source:cpp-memory-weak-ptr-operator:0006 */}
The implementation may meet the requirements without creating a temporary `weak_ptr` object.
