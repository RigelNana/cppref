{/* source:cpp-memory-out-ptr-t-out-ptr-t:0001 */}
1. 1) Creates an `out_ptr_t`. Adapts `sp` as if binds it to the `Smart&` member, captures every argument `t` in `args...` as if initializes the corresponding member of type `T` in `Args...` with `std::forward<T>(t)`, then value-initializes the stored `Pointer`. Then calls `sp.reset()` if the expression is well-formed; otherwise, calls `sp = Smart()` if `std::is_default_constructible_v<Smart>` is `true`. The program is ill-formed if both resetting operations are ill-formed.

{/* source:cpp-memory-out-ptr-t-out-ptr-t:0002 */}
2. 2) Copy constructor is explicitly deleted. `out_ptr_t` is neither copyable nor movable.

### Exceptions

{/* source:cpp-memory-out-ptr-t-out-ptr-t:0005 */}
May throw implementation-defined exceptions.

### Notes

{/* source:cpp-memory-out-ptr-t-out-ptr-t:0006 */}
After construction, the `Pointer` or `void*` object pointed by the return value of either conversion function is equal to `nullptr`.

{/* source:cpp-memory-out-ptr-t-out-ptr-t:0007 */}
Every argument in `args...` is moved into the created `out_ptr_t` if it is of an object type, or transferred into the created `out_ptr_t` as-is if it is of a reference type.

{/* source:cpp-memory-out-ptr-t-out-ptr-t:0008 */}
The constructor of `out_ptr_t` is allowed to throw exceptions. For example, when `sp` is a [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr), the allocation for the new control block may be performed within the constructor rather than the destructor.
