Exposes the address of a `Pointer` or `void*` object to a foreign function which will generally re-initialize it.

{/* source:cpp-memory-out-ptr-t-operator-ptr:0002 */}
1. 1) Converts `*this` to the address of stored `Pointer` object.

{/* source:cpp-memory-out-ptr-t-operator-ptr:0003 */}
2. 2) Converts `*this` to the address of a `void*` object. This conversion function participates in overload resolution only if `Pointer` is not same as `void*`, and the program is ill-formed if `Pointer` is not a pointer type.<br />The initial value of the `void*` object is equal the value of the stored `Pointer` object converted to `void*`, and any modification to it affects the `Pointer` value used in the [destructor](/docs/cpp/library/memory/out_ptr_t/~out_ptr_t). Accessing the `void*` object outside the lifetime of `*this` has undefined behavior.

{/* source:cpp-memory-out-ptr-t-operator-ptr:0004 */}
Once one of these two conversion functions has been called on an `out_ptr_t` object, the other shall not be called on it, otherwise, the behavior is undefined.

### Parameters

{/* source:cpp-memory-out-ptr-t-operator-ptr:0005 */}
(none)

### Return value

{/* source:cpp-memory-out-ptr-t-operator-ptr:0006 */}
1. 1) The address of stored `Pointer` object.

{/* source:cpp-memory-out-ptr-t-operator-ptr:0007 */}
2. 2) The address of the `void*` object that satisfies aforementioned requirements.

### Notes

{/* source:cpp-memory-out-ptr-t-operator-ptr:0008 */}
If the object pointed by the return value has not been rewritten, it is equal to `nullptr`.

{/* source:cpp-memory-out-ptr-t-operator-ptr:0009 */}
On common implementations, the object representation of every `Pointer` that is a pointer type is compatible with that of `void*`, and therefore these implementations typically store the `void*` object within the storage for the `Pointer` object, no additional storage needed:

{/* source:cpp-memory-out-ptr-t-operator-ptr:0010 */}
- If the implementation enables type-based alias analysis (which relies on the [strict aliasing rule](/docs/cpp/language/expressions/reinterpret_cast#Type_aliasing)), a properly aligned `std::byte[sizeof(void*)]` member subobject may be used, and both conversion functions return the address of objects [implicitly created](/docs/cpp/language/basic_concepts/objects#Object_creation) within the array.
- Otherwise, a `Pointer` member subobject may be used for both conversion functions, and (2) may directly returns its address [`reinterpret_cast`](/docs/cpp/language/expressions/reinterpret_cast) to `void**`.

{/* source:cpp-memory-out-ptr-t-operator-ptr:0011 */}
If `Pointer` is a pointer type whose object representation is incompatible with that of `void*`, an additional `bool` flag may be needed for recording whether (1) (or (2)) has been called.
