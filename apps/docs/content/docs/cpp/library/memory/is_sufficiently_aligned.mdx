{/* source:cpp-memory-is-sufficiently-aligned:0001 */}
Checks whether the pointer `ptr` points to an object whose alignment has a value of at least `N`.

{/* source:cpp-memory-is-sufficiently-aligned:0002 */}
The behavior is undefined if `ptr` does not point to an object of type `T` (ignoring cv-qualification at every level).

### Return value

{/* source:cpp-memory-is-sufficiently-aligned:0003 */}
`true` if `ptr` points to an object that has alignment at least `N`; otherwise `false`.

### Exceptions

{/* source:cpp-memory-is-sufficiently-aligned:0004 */}
Throws nothing.

### Notes

{/* source:cpp-memory-is-sufficiently-aligned:0005 */}
`std::is_sufficiently_aligned` can be used as a precondition to [`std::assume_aligned`](/docs/cpp/library/memory/assume_aligned).

### Possible implementation

{/* source:cpp-memory-is-sufficiently-aligned:0007 */}
```cpp
template<std::size_t N, class T>
bool is_sufficiently_aligned(T* ptr)
{
    return std::bit_cast<std::uintptr_t>(ptr) % N == 0;
}
```
