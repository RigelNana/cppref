{/* source:cpp-memory-owner-less:0001 */}
This function object provides owner-based (as opposed to value-based) mixed-type ordering of both [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr) and [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr). The order is such that two smart pointers compare equivalent only if they are both empty or if they share ownership, even if the values of the raw pointers obtained by `get()` are different (e.g. because they point at different subobjects within the same object).

{/* source:cpp-memory-owner-less:0002 */}
1. 1) Owner-based mixed-type ordering is not provided for types other than [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) and [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr).

{/* source:cpp-memory-owner-less:0003 */}
2. 2) The owner-based mixed-type ordering of [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr).

{/* source:cpp-memory-owner-less:0004 */}
It is the preferred comparison predicate when building associative containers with [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) as keys, that is, `std::map<std::shared_ptr<T>, U, std::owner_less<std::shared_ptr<T>>>`.

{/* source:cpp-memory-owner-less:0005 */}
3. 3) The owner-based mixed-type ordering of [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr).

{/* source:cpp-memory-owner-less:0006 */}
It is the preferred comparison predicate when building associative containers with [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr) as keys, that is, `std::map<std::weak_ptr<T>, U, std::owner_less<std::weak_ptr<T>>>`.

{/* source:cpp-memory-owner-less:0007 */}
4. 4) The `void` specialization deduces the parameter types from the arguments.

{/* source:cpp-memory-owner-less:0008 */}
The default `operator<` is not defined for weak pointers, and may wrongly consider two shared pointers for the same object non-equivalent (see [`std::shared_ptr::owner_before`](/docs/cpp/library/memory/shared_ptr/owner_before)).

{/* source:cpp-memory-owner-less:0009 */}

### Specializations

The standard library provides a specialization of `std::owner_less` when `T` is not specified. In this case, the parameter types are deduced from the arguments (each of which must still be either a [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) or a [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr)).

## std::owner_less::operator()

<DeclarationDoc>
member only of specialization (2)

  <Declaration language="cpp" since="C++11" code={`bool operator()( const std::shared_ptr<T>& lhs, 
                 const std::shared_ptr<T>& rhs ) const noexcept;`} />

member only of specialization (3)

  <Declaration language="cpp" since="C++11" code={`bool operator()( const std::weak_ptr<T>& lhs, 
                 const std::weak_ptr<T>& rhs ) const noexcept;`} />

member of both template specializations

  <Declaration language="cpp" since="C++11" code={`bool operator()( const std::shared_ptr<T>& lhs, 
                 const std::weak_ptr<T>& rhs ) const noexcept;`} />
  <Declaration language="cpp" since="C++11" code={`bool operator()( const std::weak_ptr<T>& lhs, 
                 const std::shared_ptr<T>& rhs ) const noexcept;`} />
</DeclarationDoc>

Compares `lhs` and `rhs` using owner-based semantics. Effectively calls `lhs.owner_before(rhs)`.

The ordering is strict weak ordering relation.

`lhs` and `rhs` are equivalent only if they are both empty or share ownership.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">shared-ownership pointers to compare</Parameter>
</ParameterList>

### Return value

`true` if `lhs` is *less than* `rhs` as determined by the owner-based ordering, `false` otherwise.
