{/* source:cpp-memory-polymorphic-allocator-deallocate-bytes:0001 */}
Deallocates the storage pointed to by `p`, which must have been allocated from a [`std::pmr::memory_resource`](/docs/cpp/library/memory/memory_resource) `x` that compares equal to `*resource()`, using `x.allocate(nbytes, alignment)`, typically through a call to `allocate_bytes(nbytes, alignment)`.

{/* source:cpp-memory-polymorphic-allocator-deallocate-bytes:0002 */}
Equivalent to `resource()->deallocate(p, nbytes, alignment);`.

### Parameters

{/* source:cpp-memory-polymorphic-allocator-deallocate-bytes:0003 */}
<ParameterList>
  <Parameter name="p">pointer to memory to deallocate</Parameter>
  <Parameter name="nbytes">the number of bytes originally allocated</Parameter>
  <Parameter name="alignment">the alignment originally allocated</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-memory-polymorphic-allocator-deallocate-bytes:0004 */}
Throws nothing.

### Notes

{/* source:cpp-memory-polymorphic-allocator-deallocate-bytes:0005 */}
This function was introduced for use with the fully-specialized allocator `std::pmr::polymorphic_allocator<>`, but it may be useful in any specialization.
