{/* source:cpp-memory-polymorphic-allocator-allocate-bytes:0001 */}
Allocates `nbytes` bytes of storage at specified alignment `alignment` using the underlying memory resource. Equivalent to `return resource()->allocate(nbytes, alignment);`.

### Parameters

{/* source:cpp-memory-polymorphic-allocator-allocate-bytes:0002 */}
<ParameterList>
  <Parameter name="nbytes">the number of bytes to allocate</Parameter>
  <Parameter name="alignment">the alignment to use</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-polymorphic-allocator-allocate-bytes:0003 */}
A pointer to the allocated storage.

### Notes

{/* source:cpp-memory-polymorphic-allocator-allocate-bytes:0004 */}
This function was introduced for use with the fully-specialized allocator `std::pmr::polymorphic_allocator<>`, but it may be useful in any specialization.

{/* source:cpp-memory-polymorphic-allocator-allocate-bytes:0005 */}
The return type is `void*` (rather than, e.g., `std::byte*`) to support conversion to an arbitrary pointer type `U*` by `static_cast<U*>`.

### Exceptions

{/* source:cpp-memory-polymorphic-allocator-allocate-bytes:0006 */}
May throw any exceptions thrown by the call to `resource()->allocate`.
