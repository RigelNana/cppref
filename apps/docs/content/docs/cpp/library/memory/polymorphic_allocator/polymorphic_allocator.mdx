Constructs a new `polymorphic_allocator`.

{/* source:cpp-memory-polymorphic-allocator-polymorphic-allocator:0002 */}
1) Constructs a `polymorphic_allocator` using the return value of `std::pmr::get_default_resource()` as the underlying memory resource.

{/* source:cpp-memory-polymorphic-allocator-polymorphic-allocator:0003 */}
2,3) Constructs a `polymorphic_allocator` using `other.resource()` as the underlying memory resource.

{/* source:cpp-memory-polymorphic-allocator-polymorphic-allocator:0004 */}
4) Constructs a `polymorphic_allocator` using `r` as the underlying memory resource. This constructor provides an implicit conversion from `std::pmr::memory_resource*`.

### Parameters

{/* source:cpp-memory-polymorphic-allocator-polymorphic-allocator:0005 */}
<ParameterList>
  <Parameter name="other">another `polymorphic_allocator` to copy from</Parameter>
  <Parameter name="r">pointer to the memory resource to use. May not be null</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-memory-polymorphic-allocator-polymorphic-allocator:0006 */}
4) Throws nothing.

### Notes

{/* source:cpp-memory-polymorphic-allocator-polymorphic-allocator:0007 */}
Copying a container using a `polymorphic_allocator` will not call the allocator's copy constructor. Instead, the new container will use the return value of [`select_on_container_copy_construction`](/docs/cpp/library/memory/polymorphic_allocator/select_on_container_copy_construction) (a default-constructed `polymorphic_allocator`) as its allocator.
