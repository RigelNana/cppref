{/* source:cpp-memory-polymorphic-allocator-allocate:0001 */}
Allocates storage for `n` objects of type `T` using the underlying memory resource. Equivalent to `return static_cast<T*>(resource()->allocate(n * sizeof(T), alignof(T)));`.

### Parameters

{/* source:cpp-memory-polymorphic-allocator-allocate:0002 */}
<ParameterList>
  <Parameter name="n">the number of objects to allocate storage for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-polymorphic-allocator-allocate:0003 */}
A pointer to the allocated storage.

### Exceptions

{/* source:cpp-memory-polymorphic-allocator-allocate:0004 */}
Throws [`std::bad_array_new_length`](/docs/cpp/library/memory/new/bad_array_new_length) if `n > std::numeric_limits<std::size_t>::max() / sizeof(T)`; may also throw any exceptions thrown by the call to `resource()->allocate`.
