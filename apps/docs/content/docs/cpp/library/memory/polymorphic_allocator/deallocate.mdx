{/* source:cpp-memory-polymorphic-allocator-deallocate:0001 */}
Deallocates the storage pointed to by `p`, which must have been allocated from a [`std::pmr::memory_resource`](/docs/cpp/library/memory/memory_resource) `x` that compares equal to `*resource()` using `x.allocate(n * sizeof(T), alignof(T))`.

{/* source:cpp-memory-polymorphic-allocator-deallocate:0002 */}
Equivalent to `this->resource()->deallocate(p, n * sizeof(T), alignof(T));`.

### Parameters

{/* source:cpp-memory-polymorphic-allocator-deallocate:0003 */}
<ParameterList>
  <Parameter name="p">pointer to memory to deallocate</Parameter>
  <Parameter name="n">the number of objects originally allocated</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-memory-polymorphic-allocator-deallocate:0004 */}
Throws nothing.
