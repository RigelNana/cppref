{/* source:cpp-memory-polymorphic-allocator-allocate-object:0001 */}
Allocates storage for `n` objects of type `U` using the underlying memory resource.

{/* source:cpp-memory-polymorphic-allocator-allocate-object:0002 */}
If `std::numeric_limits<std::size_t>::max() / sizeof(U) < n`, throws [`std::bad_array_new_length`](/docs/cpp/library/memory/new/bad_array_new_length), otherwise equivalent to `return static_cast<U*>(allocate_bytes(n * sizeof(U), alignof(U)));`.

### Parameters

{/* source:cpp-memory-polymorphic-allocator-allocate-object:0003 */}
<ParameterList>
  <Parameter name="n">the number of objects to allocate storage for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-polymorphic-allocator-allocate-object:0004 */}
A pointer to the allocated storage.

### Notes

{/* source:cpp-memory-polymorphic-allocator-allocate-object:0005 */}
This function was introduced for use with the fully-specialized allocator `std::pmr::polymorphic_allocator<>`, but it may be useful in any specialization as a shortcut to avoid having to rebind from `std::pmr::polymorphic_allocator<T>` to `std::pmr::polymorphic_allocator<U>`.

{/* source:cpp-memory-polymorphic-allocator-allocate-object:0006 */}
Since `U` is not deduced, it must be provided as a template argument when calling this function.

### Exceptions

{/* source:cpp-memory-polymorphic-allocator-allocate-object:0007 */}
Throws `std::bad_array_new_length` if `n > std::numeric_limits<std::size_t>::max() / sizeof(U)`; may also be any exceptions thrown by the call to `resource()->allocate`.
