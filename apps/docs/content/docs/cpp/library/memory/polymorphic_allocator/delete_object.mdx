{/* source:cpp-memory-polymorphic-allocator-delete-object:0001 */}
Destroys the object of type `U` and deallocates storage allocated for it.

{/* source:cpp-memory-polymorphic-allocator-delete-object:0002 */}
Equivalent to `std::allocator_traits<polymorphic_allocator>::destroy(*this, p);` `deallocate_object(p);`

### Parameters

{/* source:cpp-memory-polymorphic-allocator-delete-object:0003 */}
<ParameterList>
  <Parameter name="p">pointer to the object to destroy and deallocate</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-memory-polymorphic-allocator-delete-object:0004 */}
Throws nothing.

### Notes

{/* source:cpp-memory-polymorphic-allocator-delete-object:0005 */}
This function was introduced for use with the fully-specialized allocator `std::pmr::polymorphic_allocator<>`, but it may be useful in any specialization.
