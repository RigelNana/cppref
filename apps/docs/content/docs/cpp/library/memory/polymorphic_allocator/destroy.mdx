{/* source:cpp-memory-polymorphic-allocator-destroy:0001 */}
Destroys the object pointed to by `p`, as if by calling `p->~U()`.

### Parameters

{/* source:cpp-memory-polymorphic-allocator-destroy:0002 */}
<ParameterList>
  <Parameter name="p">pointer to the object being destroyed</Parameter>
</ParameterList>

### Notes

{/* source:cpp-memory-polymorphic-allocator-destroy:0003 */}
This function is deprecated via [LWG issue 3036](https://cplusplus.github.io/LWG/issue3036), because its functionality can be provided by the default implementation of [`std::allocator_traits::destroy`](/docs/cpp/library/memory/allocator_traits/destroy) and hence extraneous.

{/* source:cpp-memory-polymorphic-allocator-destroy:0004 */}
This function is undeprecated via [P2875R4](https://wg21.link/P2875R4).
