{/* source:cpp-memory-polymorphic-allocator-operator-eq:0001 */}
Compares two polymorphic allocators. Two polymorphic allocators compare equal if their underlying memory resource compares equal.

{/* source:cpp-memory-polymorphic-allocator-operator-eq:0002 */}
1. 1) Returns `*lhs.resource() == *rhs.resource()`.

{/* source:cpp-memory-polymorphic-allocator-operator-eq:0003 */}
2. 2) Same as (1), allowing conversion to `polymorphic_allocator`. This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::pmr::polymorphic_allocator` is an associated class of the arguments.

{/* source:cpp-memory-polymorphic-allocator-operator-eq:0004 */}
3. 3) Returns `!(lhs == rhs)`.

{/* source:cpp-memory-polymorphic-allocator-operator-eq:0005 */}
4. 4) Same as (3), allowing conversion to `polymorphic_allocator`. This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::pmr::polymorphic_allocator` is an associated class of the arguments.

{/* source:cpp-memory-polymorphic-allocator-operator-eq:0006 */}
<Revision since="C++20">
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>
