void deallocate_object( U* p, std::size_t n = 1 );`} />

{/* source:cpp-memory-polymorphic-allocator-deallocate-object:0001 */}
Deallocates the storage pointed to by `p`, which must have been allocated from a [`std::pmr::memory_resource`](/docs/cpp/library/memory/memory_resource) `x` that compares equal to `*resource()`, using `x.allocate(n * sizeof(U), alignof(U))`, typically through a call to `allocate_object<U>(n)`.

{/* source:cpp-memory-polymorphic-allocator-deallocate-object:0002 */}
Equivalent to `deallocate_bytes(p, n * sizeof(U), alignof(U));`.

### Parameters

{/* source:cpp-memory-polymorphic-allocator-deallocate-object:0003 */}
<ParameterList>
  <Parameter name="p">pointer to memory to deallocate</Parameter>
  <Parameter name="n">number of objects of type `U` the memory was for</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-memory-polymorphic-allocator-deallocate-object:0004 */}
Throws nothing.

### Notes

{/* source:cpp-memory-polymorphic-allocator-deallocate-object:0005 */}
This function was introduced for use with the fully-specialized allocator `std::pmr::polymorphic_allocator<>`, but it may be useful in any specialization.
