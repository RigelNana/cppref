    Constructs a `synchronized_pool_resource`.

    {/* source:cpp-memory-synchronized-pool-resource-synchronized-pool-resource:0002 */}
    1-4) Constructs a `synchronized_pool_resource` using the specified upstream memory resource and tuned according to the specified options. The resulting object holds a copy of `upstream` but does not own the resource to which `upstream` points.<br />
    The overloads not taking `opts` as a parameter uses a default constructed instance of [`pool_options`](/docs/cpp/library/memory/pool_options) as the options. The overloads not taking `upstream` as a parameter uses the return value of [`std::pmr::get_default_resource`](/docs/cpp/library/memory/get_default_resource) as the upstream memory resource.

    {/* source:cpp-memory-synchronized-pool-resource-synchronized-pool-resource:0003 */}
    5) Copy constructor is deleted.
  </DeclarationDescription>
</DeclarationDoc>

### Exceptions

{/* source:cpp-memory-synchronized-pool-resource-synchronized-pool-resource:0005 */}
1-4) Throws only if a call to the `allocate()` function of the upstream resource throws. It is unspecified if or under what conditions such a call takes place.
