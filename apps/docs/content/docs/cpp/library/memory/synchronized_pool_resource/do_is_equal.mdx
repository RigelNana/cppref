{/* source:cpp-memory-synchronized-pool-resource-do-is-equal:0001 */}
Compare `*this` with `other` for identity - memory allocated using a `synchronized_pool_resource` can only be deallocated using that same resource.

### Return value

{/* source:cpp-memory-synchronized-pool-resource-do-is-equal:0002 */}
`this == &other`
