<DeclarationDoc>
Defined in header [`<cstdlib>`](/docs/cpp/library/headers/cstdlib)

  <Declaration language="cpp" since="C++17" code={`void* aligned_alloc( std::size_t alignment, std::size_t size );`} />
</DeclarationDoc>

{/* source:cpp-memory-c-aligned-alloc:0001 */}
Allocate `size` bytes of uninitialized storage whose alignment is specified by `alignment` ([implicitly creating](/docs/cpp/language/basic_concepts/objects#Object_creation) objects in the destination area). The `size` parameter must be an integral multiple of `alignment`.

{/* source:cpp-memory-c-aligned-alloc:0002 */}
The following functions are required to be thread-safe:

{/* source:cpp-memory-c-aligned-alloc:0003 */}
- The library versions of [`operator new`](/docs/cpp/library/memory/new/operator_new) and [`operator delete`](/docs/cpp/library/memory/new/operator_delete)
- User replacement versions of global [`operator new`](/docs/cpp/library/memory/new/operator_new) and [`operator delete`](/docs/cpp/library/memory/new/operator_delete)
- [`std::calloc`](/docs/cpp/library/memory/c/calloc), [`std::malloc`](/docs/cpp/library/memory/c/malloc), [`std::realloc`](/docs/cpp/library/memory/c/realloc), [`std::aligned_alloc`](/docs/cpp/library/memory/c/aligned_alloc), [`std::free`](/docs/cpp/library/memory/c/free)

{/* source:cpp-memory-c-aligned-alloc:0004 */}
Calls to these functions that allocate or deallocate a particular unit of storage occur in a single total order, and each such deallocation call [happens-before](/docs/cpp/library/atomic/memory_order) the next allocation (if any) in this order.

### Parameters

{/* source:cpp-memory-c-aligned-alloc:0005 */}
<ParameterList>
  <Parameter name="alignment">specifies the alignment. Must be a valid alignment supported by the implementation.</Parameter>
  <Parameter name="size">number of bytes to allocate. An integral multiple of `alignment`.</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-c-aligned-alloc:0006 */}
On success, returns the pointer to the beginning of newly allocated memory. To avoid a memory leak, the returned pointer must be deallocated with [`std::free`](/docs/cpp/library/memory/c/free) or [`std::realloc`](/docs/cpp/library/memory/c/realloc).

{/* source:cpp-memory-c-aligned-alloc:0007 */}
On failure, returns a null pointer.

### Notes

{/* source:cpp-memory-c-aligned-alloc:0008 */}
Passing a `size` which is not an integral multiple of `alignment` or an `alignment` which is not valid or not supported by the implementation causes the function to fail and return a null pointer (C11, as published, specified undefined behavior in this case, this was corrected by [DR460](https://open-std.org/JTC1/SC22/WG14/www/docs/summary.htm#dr_460)).

{/* source:cpp-memory-c-aligned-alloc:0009 */}
As an example of the "supported by the implementation" requirement, POSIX function [posix_memalign](https://pubs.opengroup.org/onlinepubs/9699919799/functions/posix_memalign.html) accepts any `alignment` that is a power of two and a multiple of `sizeof(void*)`, and POSIX-based implementations of `aligned_alloc` inherit this requirements.

{/* source:cpp-memory-c-aligned-alloc:0010 */}
Fundamental alignments are always supported. If `alignment` is a power of two and not greater than `alignof(std::max_align_t)`, `aligned_alloc` may simply call [`std::malloc`](/docs/cpp/library/memory/c/malloc).

{/* source:cpp-memory-c-aligned-alloc:0011 */}
Regular [`std::malloc`](/docs/cpp/library/memory/c/malloc) aligns memory suitable for any object type with a fundamental alignment. This function is useful for over-aligned allocations, such as to [SSE](https://en.wikipedia.org/wiki/Streaming_SIMD_Extensions), cache line, or [VM page](https://en.wikipedia.org/wiki/Page_(computer_memory)#Multiple_page_sizes) boundary.

{/* source:cpp-memory-c-aligned-alloc:0012 */}
This function is not supported in Microsoft C Runtime library because its implementation of [`std::free`](/docs/cpp/library/memory/c/free) is [unable to handle aligned allocations](https://learn.microsoft.com/en-us/cpp/standard-library/cstdlib#remarks-6) of any kind. Instead, MS CRT provides [_aligned_malloc](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/aligned-malloc) (to be freed with [_aligned_free](https://learn.microsoft.com/en-us/cpp/c-runtime-library/reference/aligned-free)).

### Example

{/* source:cpp-memory-c-aligned-alloc:0013 */}
```cpp
#include <cstdio>
#include <cstdlib>
 
int main()
{
    int* p1 = static_cast<int*>(std::malloc(10 * sizeof *p1));
    std::printf("default-aligned address:   %p\n", static_cast<void*>(p1));
    std::free(p1);
 
    int* p2 = static_cast<int*>(std::aligned_alloc(1024, 1024));
    std::printf("1024-byte aligned address: %p\n", static_cast<void*>(p2));
    std::free(p2);
}
```

Possible output:

```text
default-aligned address:   0x2221c20
1024-byte aligned address: 0x2222400
```
