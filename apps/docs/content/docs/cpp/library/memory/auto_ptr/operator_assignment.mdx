{/* source:cpp-memory-auto-ptr-operator:0001 */}
Replaces the managed object with the one managed by `r` or `m`.

{/* source:cpp-memory-auto-ptr-operator:0002 */}
1. 1) Effectively calls `reset(r.release())`.

{/* source:cpp-memory-auto-ptr-operator:0003 */}
2. 2) Effectively calls `reset(r.release())`. `Y*` must be implicitly convertible to `T*`.

{/* source:cpp-memory-auto-ptr-operator:0004 */}
3. 3) Effectively calls `reset(m.release())`. `auto_ptr_ref` is an implementation-defined type that holds a reference to `auto_ptr`. [`std::auto_ptr`](/docs/cpp/library/memory/auto_ptr) is implicitly [convertible to](/docs/cpp/library/memory/auto_ptr/operator_auto_ptr) and [from](/docs/cpp/library/memory/auto_ptr/auto_ptr) this type. The implementation is allowed to provide the template with a different name or implement equivalent functionality in other ways.

<ParameterList>

### Return value

{/* source:cpp-memory-auto-ptr-operator:0006 */}
`*this`.

### Notes

{/* source:cpp-memory-auto-ptr-operator:0007 */}
The constructor and the copy assignment operator from `auto_ptr_ref` is provided to allow copy-constructing and assigning `std::auto_ptr` from nameless temporaries. Since its copy constructor and copy assignment operator take the argument as non-const reference, they cannot bind rvalue arguments directly. However, a [user-defined conversion](/docs/cpp/library/memory/auto_ptr/operator_auto_ptr) can be executed (which releases the original `auto_ptr`), followed by a call to the constructor or copy-assignment operator that take `auto_ptr_ref` by value. This is an early implementation of [move semantics](/docs/cpp/library/utility/move).
