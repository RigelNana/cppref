Converts `*this` to an `auto_ptr` for a different type `Y`.

{/* source:cpp-memory-auto-ptr-operator-auto-ptr:0002 */}
1. 1) Returns an implementation-defined type that holds a reference to `*this`. [`std::auto_ptr`](/docs/cpp/library/memory/auto_ptr) is [convertible](/docs/cpp/library/memory/auto_ptr/auto_ptr) and [assignable](/docs/cpp/library/memory/auto_ptr/operator_assignment) from this template. The implementation is allowed to provide the template with a different name or implement equivalent functionality in other ways.

{/* source:cpp-memory-auto-ptr-operator-auto-ptr:0003 */}
2. 2) Constructs a new `auto_ptr` with a pointer obtained by calling [`release()`](/docs/cpp/library/memory/auto_ptr/release).

### Parameters

{/* source:cpp-memory-auto-ptr-operator-auto-ptr:0004 */}
(none)

### Return value

{/* source:cpp-memory-auto-ptr-operator-auto-ptr:0005 */}
1. 1) An implementation-defined type that holds a reference to `*this`.

{/* source:cpp-memory-auto-ptr-operator-auto-ptr:0006 */}
2. 2) An `auto_ptr` with a pointer obtained by calling [`release()`](/docs/cpp/library/memory/auto_ptr/release).

### Notes

{/* source:cpp-memory-auto-ptr-operator-auto-ptr:0007 */}
The constructor and the copy assignment operator from `auto_ptr_ref` is provided to allow copy-constructing and assigning `std::auto_ptr` from nameless temporaries. Since its copy constructor and copy assignment operator take the argument as non-const reference, they cannot bind rvalue arguments directly. However, a user-defined conversion (1) or (2) can be executed (which releases the original `auto_ptr`), followed by a call to the constructor or copy-assignment operator that take `auto_ptr_ref` by value. This is an early implementation of [move semantics](/docs/cpp/library/utility/move).
