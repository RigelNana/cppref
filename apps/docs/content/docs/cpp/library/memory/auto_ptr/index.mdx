{/* source:cpp-memory-auto-ptr:0001 */}
`auto_ptr` is a smart pointer that manages an object obtained via [new expression](/docs/cpp/language/expressions/new) and deletes that object when `auto_ptr` itself is destroyed. It may be used to provide exception safety for dynamically allocated objects, for passing ownership of dynamically allocated objects into functions and for returning dynamically allocated objects from functions.

{/* source:cpp-memory-auto-ptr:0002 */}
Copying an `auto_ptr` copies the pointer and transfers ownership to the destination: both copy construction and copy assignment of `auto_ptr` modify their right-hand arguments, and the "copy" is not equal to the original. Because of these unusual copy semantics, `auto_ptr` may not be placed in standard containers. <InlineRevision since="C++11">[`std::unique_ptr`](/docs/cpp/library/memory/unique_ptr) is preferred for this and other uses.</InlineRevision>

{/* source:cpp-memory-auto-ptr:0003 */}
1. 2) Specialization for type `void` is provided, it declares the typedef `element_type`, but no member functions.

{/* source:cpp-memory-auto-ptr:0004 */}
An additional class template `auto_ptr_ref` is referred to throughout the documentation. It is an implementation-defined type that holds a reference to `auto_ptr`. The implementation is allowed to provide the template with a different name or implement the functions returning it or accepting it as parameter in other ways.
