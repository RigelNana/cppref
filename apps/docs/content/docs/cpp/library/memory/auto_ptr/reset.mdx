{/* source:cpp-memory-auto-ptr-reset:0001 */}
Replaces the held pointer by `p`. If the currently held pointer is not null pointer, `delete get()` is called.

### Parameters

{/* source:cpp-memory-auto-ptr-reset:0002 */}
<ParameterList>
  <Parameter name="p">a pointer to an object to manage</Parameter>
</ParameterList>

### Return value

(none)
