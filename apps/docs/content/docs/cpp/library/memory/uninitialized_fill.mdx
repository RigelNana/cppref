{/* source:cpp-memory-uninitialized-fill:0001 */}
1. 1) Copies `value` to an uninitialized memory area `[first, last)` as if by `for (; first != last; ++first)` `::new (`[`voidify`](/docs/cpp/library/memory/voidify)`(*first))` `typename std::iterator_traits<NoThrowForwardIt>::value_type(value);`

{/* source:cpp-memory-uninitialized-fill:0002 */}
2. If an exception is thrown during the initialization, the objects already constructed are destroyed in an unspecified order.

{/* source:cpp-memory-uninitialized-fill:0003 */}
3. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-memory-uninitialized-fill:0004 */}
4. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">[`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

   <Revision since="C++20">[`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

### Parameters

{/* source:cpp-memory-uninitialized-fill:0005 */}
<ParameterList>
  <Parameter name="first, last">the range of the elements to initialize</Parameter>
  <Parameter name="value">the value to construct the elements with</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
</ParameterList>

**Type requirements**

- `NoThrowForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- No increment, assignment, comparison, or indirection through valid instances of `NoThrowForwardIt` may throw exceptions. <InlineRevision until="C++11">Applying `&*` to a `NoThrowForwardIt` value must yield a pointer to its value type.</InlineRevision>

### Complexity

{/* source:cpp-memory-uninitialized-fill:0006 */}
Linear in the distance between `first` and `last`.

### Exceptions

{/* source:cpp-memory-uninitialized-fill:0007 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-memory-uninitialized-fill:0008 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-memory-uninitialized-fill:0010 */}
[`uninitialized_fill (1)`](/docs/cpp/library/memory/uninitialized_fill#Version_1)

```cpp
template<class NoThrowForwardIt, class T>
constexpr void uninitialized_fill(NoThrowForwardIt first, NoThrowForwardIt last,
                                  const T& value)
{
    using V = typename std::iterator_traits<NoThrowForwardIt>::value_type;
    NoThrowForwardIt current = first;
    try
    {
        for (; current != last; ++current)
            ::new (static_cast<void*>(std::addressof(*current))) V(value);
    } 
    catch (...)
    {
        for (; first != current; ++first)
            first->~V();
        throw;
    }
}```

### Example

{/* source:cpp-memory-uninitialized-fill:0011 */}
```cpp
#include <algorithm>
#include <iostream>
#include <memory>
#include <string>
 
int main()
{
    const std::size_t sz = 4;
    std::allocator<std::string> alloc;
    std::string* p = alloc.allocate(sz);
 
    std::uninitialized_fill(p, p + sz, "Example");
 
    for (std::string* i = p; i != p + sz; ++i)
    {
        std::cout << *i << '\n';
        i->~basic_string<char>();
    }
 
    alloc.deallocate(p, sz);
}```
