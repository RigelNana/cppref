{/* source:cpp-memory-make-obj-using-allocator:0001 */}
Creates an object of the given type `T` by means of [uses-allocator construction](/docs/cpp/library/memory/uses_allocator).

{/* source:cpp-memory-make-obj-using-allocator:0002 */}
Equivalent to

{/* source:cpp-memory-make-obj-using-allocator:0003 */}
```cpp
return std::make_from_tuple<T>(
    std::uses_allocator_construction_args<T>(alloc, std::forward<Args>(args)...)
);
```

### Parameters

{/* source:cpp-memory-make-obj-using-allocator:0004 */}
<ParameterList>
  <Parameter name="alloc">the allocator to use</Parameter>
  <Parameter name="args">the arguments to pass to `T`'s constructor</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-make-obj-using-allocator:0005 */}
The newly-created object of type `T`.

### Exceptions

{/* source:cpp-memory-make-obj-using-allocator:0006 */}
May throw any exception thrown by the constructor of `T`, typically including [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc).
