{/* source:cpp-memory-uninitialized-default-construct-n:0001 */}
1. 1) Constructs objects of type `typename std::iterator_traits<NoThrowForwardIt>::value_type` in the uninitialized memory area `first` + [`0`, `count`) by [default-initialization](/docs/cpp/language/initialization/default_initialization), as if by `for (; count > 0; (void)++first, --count)` `::new (`[`voidify`](/docs/cpp/library/memory/voidify)`(*first))` `typename std::iterator_traits<NoThrowForwardIt>::value_type;` `return first;`

{/* source:cpp-memory-uninitialized-default-construct-n:0002 */}
2. If an exception is thrown during the initialization, the objects already constructed are destroyed in an unspecified order.

{/* source:cpp-memory-uninitialized-default-construct-n:0003 */}
3. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-memory-uninitialized-default-construct-n:0004 */}
4. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">[`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

   <Revision since="C++20">[`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

### Parameters

</ParameterList>

**Type requirements**

- `NoThrowForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- No increment, assignment, comparison, or indirection through valid instances of `NoThrowForwardIt` may throw exceptions.

### Return value

{/* source:cpp-memory-uninitialized-default-construct-n:0006 */}
As described above.

### Complexity

{/* source:cpp-memory-uninitialized-default-construct-n:0007 */}
Linear in `n`.

### Exceptions

{/* source:cpp-memory-uninitialized-default-construct-n:0008 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-memory-uninitialized-default-construct-n:0009 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-memory-uninitialized-default-construct-n:0011 */}
[`uninitialized_default_construct_n (1)`](/docs/cpp/library/memory/uninitialized_default_construct_n#Version_1)

```cpp
template<class NoThrowForwardIt, class Size>
constexpr ForwardIt uninitialized_default_construct_n(NoThrowForwardIt first, Size count)
{
    using T = typename std::iterator_traits<NoThrowForwardIt>::value_type;
    NoThrowForwardIt current = first;
 
    try
    {
        for (; countn > 0; (void) ++current, --count)
            ::new (static_cast<void*>(std::addressof(*current))) T;
        return current;
    }
    catch (...)
    {
        std::destroy(first, current);
        throw;
    }
}```

### Example

{/* source:cpp-memory-uninitialized-default-construct-n:0012 */}
```cpp
#include <cstring>
#include <iostream>
#include <memory>
#include <string>
 
struct S
{
    std::string m{"default value"};
};
 
int main()
{
    constexpr int n{3};
    alignas(alignof(S)) unsigned char mem[n * sizeof(S)];
 
    try
    {
        auto first{reinterpret_cast<S*>(mem)};
        auto last = std::uninitialized_default_construct_n(first, n);
 
        for (auto it{first}; it != last; ++it)
            std::cout << it->m << '\n';
 
        std::destroy(first, last);
    }
    catch(...)
    {
        std::cout << "Exception!\n";
    }
 
    // For scalar types, uninitialized_default_construct_n
    // generally does not zero-initialize the given uninitialized memory area.
    int v[]{1, 2, 3, 4};
    const int original[]{1, 2, 3, 4};
    std::uninitialized_default_construct_n(std::begin(v), std::size(v));
 
    // An attempt to access v might be an undefined behavior,
    // pending CWG 1997 to be resolved:
    // for (const int i : v)
    //     std::cout << i << ' ';
 
    // The result is unspecified:
    std::cout << (std::memcmp(v, original, sizeof(v)) == 0 ? "un" : "") << "modified\n";
}```
