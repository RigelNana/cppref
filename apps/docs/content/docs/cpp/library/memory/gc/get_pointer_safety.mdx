Obtains the implementation-defined pointer safety model, which is a value of type [`std::pointer_safety`](/docs/cpp/library/memory/gc/pointer_safety).

### Parameters

{/* source:cpp-memory-gc-get-pointer-safety:0002 */}
(none)

### Return value

{/* source:cpp-memory-gc-get-pointer-safety:0003 */}
The pointer safety used by this implementation.

### Example

{/* source:cpp-memory-gc-get-pointer-safety:0004 */}
```cpp
#include <iostream>
#include <memory>
 
int main()
{
    std::cout << "Pointer safety: ";
    switch (std::get_pointer_safety())
    {
        case std::pointer_safety::strict:
            std::cout << "strict\n";
            break;
        case std::pointer_safety::preferred:
            std::cout << "preferred\n";
            break;
        case std::pointer_safety::relaxed:
            std::cout << "relaxed\n";
            break;
    }
}
```

Possible output:

```text
Pointer safety: relaxed
```
