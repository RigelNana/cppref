{/* source:cpp-memory-gc-undeclare-reachable:0001 */}
Removes the reachable status of the object, referenced by the pointer `p`, if it was previously set by [`std::declare_reachable`](/docs/cpp/library/memory/gc/declare_reachable). If the object was declared reachable multiple times, equal number of calls to `undeclare_reachable` would be needed to remove this status. Once the object is not declared reachable and has no pointers referencing it, it may be reclaimed by garbage collector or reported as a leak by a leak detector.

### Parameters

{/* source:cpp-memory-gc-undeclare-reachable:0002 */}
<ParameterList>
  <Parameter name="p">a pointer to an object previously declared reachable and not destructed since then</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-gc-undeclare-reachable:0003 */}
A safely-derived copy of `p`.

### Exceptions

{/* source:cpp-memory-gc-undeclare-reachable:0004 */}
Throws nothing.
