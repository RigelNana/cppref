Unregisters a range earlier registered with `std::declare_no_pointers()`.

### Parameters

{/* source:cpp-memory-gc-undeclare-no-pointers:0002 */}
<ParameterList>
  <Parameter name="p">pointer to the beginning of the range previously registered with [`std::declare_no_pointers`](/docs/cpp/library/memory/gc/declare_no_pointers)</Parameter>
  <Parameter name="n">the number of bytes in the range, same value as previously used with [`std::declare_no_pointers`](/docs/cpp/library/memory/gc/declare_no_pointers)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-gc-undeclare-no-pointers:0003 */}
(none)

### Exceptions

{/* source:cpp-memory-gc-undeclare-no-pointers:0004 */}
