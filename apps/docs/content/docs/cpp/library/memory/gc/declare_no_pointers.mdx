{/* source:cpp-memory-gc-declare-no-pointers:0001 */}
Informs the garbage collector or leak detector that the specified memory region (`n` bytes beginning at the byte pointed to by `p`) contains no traceable pointers. If any part of the region is within an allocated object, the entire region must be contained in the same object.

### Parameters

{/* source:cpp-memory-gc-declare-no-pointers:0002 */}
<ParameterList>
  <Parameter name="p">pointer to the beginning of the range</Parameter>
  <Parameter name="n">the number of bytes in the range</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-gc-declare-no-pointers:0003 */}
(none)

### Exceptions

{/* source:cpp-memory-gc-declare-no-pointers:0004 */}
Throws nothing.
