    {/* source:cpp-memory-shared-ptr-operator-bool:0001 */}
    Checks if `*this` stores a non-null pointer, i.e. whether `get() != nullptr`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-memory-shared-ptr-operator-bool:0002 */}
(none)

### Return value

{/* source:cpp-memory-shared-ptr-operator-bool:0003 */}
`true` if `*this` stores a pointer, `false` otherwise.

### Notes

{/* source:cpp-memory-shared-ptr-operator-bool:0004 */}
An empty `shared_ptr` (where `use_count() == 0`) may store a non-null pointer accessible by [`get()`](/docs/cpp/library/memory/shared_ptr/get), e.g. if it were created using the aliasing constructor.

### Example

{/* source:cpp-memory-shared-ptr-operator-bool:0005 */}
```cpp
#include <iostream>
#include <memory>
 
void report(std::shared_ptr<int> ptr) 
{
    if (ptr)
        std::cout << "*ptr=" << *ptr << "\n";
    else
        std::cout << "ptr is not a valid pointer.\n";
}
 
int main()
{
    std::shared_ptr<int> ptr;
    report(ptr);
 
    ptr = std::make_shared<int>(7);
    report(ptr);
}
```

Output:

```text
ptr is not a valid pointer.
*ptr=7
```
