{/* source:cpp-memory-shared-ptr-atomic:0001 */}
If multiple threads of execution access the same [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) object without synchronization and any of those accesses uses a non-const member function of `shared_ptr` then a data race will occur unless all such access is performed through these functions, which are overloads of the corresponding atomic access functions ([`std::atomic_load`](/docs/cpp/library/atomic/atomic_load), [`std::atomic_store`](/docs/cpp/library/atomic/atomic_store), etc.).

{/* source:cpp-memory-shared-ptr-atomic:0002 */}
Note that the control block of a `shared_ptr` is thread-safe: different [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) objects can be accessed using mutable operations, such as `operator=` or `reset`, simultaneously by multiple threads, even when these instances are copies, and share the same control block internally.

{/* source:cpp-memory-shared-ptr-atomic:0003 */}
1. Determines whether atomic access to the shared pointer pointed-to by `p` is lock-free.

{/* source:cpp-memory-shared-ptr-atomic:0004 */}
2. Equivalent to `atomic_load_explicit(p, std::memory_order_seq_cst)`.

{/* source:cpp-memory-shared-ptr-atomic:0005 */}
3. Returns the shared pointer pointed-to by `p`.

{/* source:cpp-memory-shared-ptr-atomic:0006 */}
As with the non-specialized [`std::atomic_load_explicit`](/docs/cpp/library/atomic/atomic_load), if `mo` is `std::memory_order_release` or `std::memory_order_acq_rel`, the behavior is undefined.

{/* source:cpp-memory-shared-ptr-atomic:0007 */}
4. Equivalent to `atomic_store_explicit(p, r, std::memory_order_seq_cst)`.

{/* source:cpp-memory-shared-ptr-atomic:0008 */}
5. Stores the shared pointer `r` in the shared pointer pointed-to by `p` atomically, [as if](/docs/cpp/language/basic_concepts/as_if) by `p->swap(r)`.

{/* source:cpp-memory-shared-ptr-atomic:0009 */}
As with the non-specialized [`std::atomic_store_explicit`](/docs/cpp/library/atomic/atomic_store), if `mo` is `std::memory_order_acquire` or `std::memory_order_acq_rel`, the behavior is undefined.

{/* source:cpp-memory-shared-ptr-atomic:0010 */}
6. Equivalent to `atomic_exchange_explicit(p, r, std::memory_order_seq_cst)`.

{/* source:cpp-memory-shared-ptr-atomic:0011 */}
7. Stores the shared pointer `r` in the shared pointer pointed to by `p` and returns the value formerly pointed-to by `p`, atomically, [as if](/docs/cpp/language/basic_concepts/as_if) by `p->swap(r)` and returns a copy of `r` after the swap.

{/* source:cpp-memory-shared-ptr-atomic:0012 */}
8. Equivalent to

{/* source:cpp-memory-shared-ptr-atomic:0013 */}
`atomic_compare_exchange_weak_explicit(p, expected, desired, std::memory_order_seq_cst, std::memory_order_seq_cst)`.

{/* source:cpp-memory-shared-ptr-atomic:0014 */}
9. Equivalent to

{/* source:cpp-memory-shared-ptr-atomic:0015 */}
`atomic_compare_exchange_strong_explicit(p, expected, desired, std::memory_order_seq_cst, std::memory_order_seq_cst)`.

{/* source:cpp-memory-shared-ptr-atomic:0016 */}
10,11. Compares the shared pointers pointed-to by `p` and `expected`.

- If they are equivalent (store the same pointer value, and either share ownership of the same object or are both empty), assigns `desired` into `*p` using the memory ordering constraints specified by `success` and returns `true`.
- If they are not equivalent, assigns `*p` into `*expected` using the memory ordering constraints specified by `failure` and returns `false`.

{/* source:cpp-memory-shared-ptr-atomic:0017 */}
`atomic_compare_exchange_weak_explicit` may fail spuriously.

{/* source:cpp-memory-shared-ptr-atomic:0018 */}
If `expected` is a null pointer, or `failure` is `std::memory_order_release` or `std::memory_order_acq_rel`, the behavior is undefined.

{/* source:cpp-memory-shared-ptr-atomic:0019 */}
If `p` is a null pointer, the behaviors of these functions are all undefined.

### Parameters

{/* source:cpp-memory-shared-ptr-atomic:0020 */}
<ParameterList>
  <Parameter name="p, expected">a pointer to a [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr)</Parameter>
  <Parameter name="r, desired">a [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr)</Parameter>
  <Parameter name="mo, success, failure">memory ordering selectors of type [`std::memory_order`](/docs/cpp/library/atomic/memory_order)</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-memory-shared-ptr-atomic:0021 */}
These functions do not throw exceptions.

### Return value

{/* source:cpp-memory-shared-ptr-atomic:0022 */}
1. `true` if atomic access is implemented using lock-free instructions.

{/* source:cpp-memory-shared-ptr-atomic:0023 */}
2,3. A copy of the pointed-to shared pointer.

{/* source:cpp-memory-shared-ptr-atomic:0024 */}
4,5. (none)

{/* source:cpp-memory-shared-ptr-atomic:0025 */}
6,7. A copy of the formerly pointed-to shared pointer.

{/* source:cpp-memory-shared-ptr-atomic:0026 */}
8-11. `true` if the shared pointers were equivalent and the exchange was performed, `false` otherwise.

### Notes

{/* source:cpp-memory-shared-ptr-atomic:0027 */}
These functions are typically implemented using mutexes, stored in a global hash table where the pointer value is used as the key.

{/* source:cpp-memory-shared-ptr-atomic:0028 */}
The [Concurrency TS](/docs/cpp/library/experimental/concurrency) offers atomic smart pointer classes `atomic_shared_ptr` and `atomic_weak_ptr` as a replacement for the use of these functions.

{/* source:cpp-memory-shared-ptr-atomic:0029 */}

These functions were deprecated in favor of the specializations of the [`std::atomic`](/docs/cpp/library/atomic/atomic) template: `std::atomic<std::shared_ptr>` and `std::atomic<std::weak_ptr>`.
</Revision>

</Revision>
