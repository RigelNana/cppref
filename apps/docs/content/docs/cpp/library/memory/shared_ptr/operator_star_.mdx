<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++11" code={`T& operator*() const noexcept;`} />
  <Declaration id="2" language="cpp" since="C++11" code={`T* operator->() const noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-memory-shared-ptr-operator-star:0001 */}
    Dereferences the stored pointer. The behavior is undefined if the stored pointer is null.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-memory-shared-ptr-operator-star:0002 */}
(none)

### Return value

{/* source:cpp-memory-shared-ptr-operator-star:0003 */}
1. 1) The result of dereferencing the stored pointer, i.e., `*get()`.

{/* source:cpp-memory-shared-ptr-operator-star:0004 */}
2. 2) The stored pointer, i.e., `get()`.

### Remarks

{/* source:cpp-memory-shared-ptr-operator-star:0005 */}
When `T` is <InlineRevision since="C++17">an array type or (possibly cv-qualified)</InlineRevision> `void`, it is unspecified whether function (1) is declared. If it is declared, it is unspecified what its return type is, except that the declaration (although not necessarily the definition) of the function shall be well formed. This makes it possible to instantiate `std::shared_ptr<void>`.

{/* source:cpp-memory-shared-ptr-operator-star:0006 */}
<Revision since="C++17">
When `T` is an array type, it is unspecified whether function (2) is declared. If it is declared, it is unspecified what its return type is, except that the declaration of the function shall be well-formed.
</Revision>

### Example

{/* source:cpp-memory-shared-ptr-operator-star:0007 */}
```cpp
#include <iostream>
#include <memory>
 
struct Foo
{
    Foo(int in) : a(in) {}
    void print() const
    {
        std::cout << "a = " << a << '\n';
    }
    int a;
};
 
int main()
{
    auto ptr = std::make_shared<Foo>(10);
    ptr->print();
    (*ptr).print();
}
```

Output:

```text
a = 10
a = 10
```
