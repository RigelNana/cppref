{/* source:cpp-memory-shared-ptr-allocate-shared:0001 */}
1. Constructs an object of type `T` and wraps it in a [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) using `args` as the parameter list for the constructor of `T`. The object is constructed as if by the expression <InlineRevision until="C++20">`::new (pv) T(v)`</InlineRevision> <InlineRevision since="C++20">[`std::allocator_traits<A2>::construct(a, pv, v)`](/docs/cpp/library/memory/allocator_traits)</InlineRevision>, where `pv` is an internal `void*` pointer to storage suitable to hold an object of type `T` and `a` is a copy of the allocator rebound to `std::remove_cv_t<T>`. The storage is typically larger than `sizeof(T)` in order to use one allocation for both the control block of the shared pointer and the `T` object. The [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) constructor called by this function enables `shared_from_this` with a pointer to the newly constructed object of type `T`. All memory allocation is done using a copy of `alloc`, which must satisfy the [*Allocator*](/docs/cpp/library/named_req/Allocator) requirements. This overload participates in overload resolution only if `T` is not an array type.

{/* source:cpp-memory-shared-ptr-allocate-shared:0002 */}
2,3. Same as (1), but the object constructed is a possibly-multidimensional array whose every non-array element is initialized as if by the expression `std::allocator_traits<A2>::construct(a2, pv)` where `a2` of type `A2` is the copy of the allocator rebound to manage objects of type `std::remove_cv_t<std::remove_all_extents_t<T>>`. The overload (2) creates an array of size `N` along its first dimension. The array elements are initialized in ascending order of their addresses, and when their lifetime ends are destroyed in the reverse order of their original construction.

{/* source:cpp-memory-shared-ptr-allocate-shared:0003 */}
4,5. Same as (2,3), but the elements of the array are initialized from the default value `u`. If `std::remove_extent_t<T>` is not itself an array type, then this is performed as if by the same allocator expression as in (1), except that the allocator is rebound to the `std::remove_cv_t<std::remove_all_extents_t<T>>`. Otherwise, this is performed as if by initializing every non-array element of the (possibly multidimensional) array with the corresponding element from `u` using the same allocator expression as in (1), except that the allocator is rebound to the type `std::remove_cv_t<std::remove_all_extents_t<T>>`. The overload (4) creates an array of size `N` along the first dimension. The array elements are initialized in ascending order of their addresses, and when their lifetime ends are destroyed in the reverse order of their original construction.

{/* source:cpp-memory-shared-ptr-allocate-shared:0004 */}
6. Same as (1) if `T` is not an array type and (3) if `T` is `U[N]`, except that the created object is [default-initialized](/docs/cpp/language/initialization/default_initialization).

{/* source:cpp-memory-shared-ptr-allocate-shared:0005 */}
7. Same as (2), except that the individual array elements are [default-initialized](/docs/cpp/language/initialization/default_initialization).

{/* source:cpp-memory-shared-ptr-allocate-shared:0006 */}
For `allocate_shared`, the object <InlineRevision since="C++20">(or the individual array elements for (2-5))</InlineRevision> are destroyed via the expression `std::allocator_traits<A2>::destroy(a, p)`, where `p` is a pointer to the object and `a` is a copy of the allocator passed to `allocate_shared`, rebound to the type of the object being destroyed.

{/* source:cpp-memory-shared-ptr-allocate-shared:0007 */}
<Revision since="C++20">
For `allocate_shared_for_overwrite`, the object (or individual elements if `T` is an array type) will be destroyed by `p->~X()`, where `p` is a pointer to the object and `X` is its type.
</Revision>

### Exceptions

{/* source:cpp-memory-shared-ptr-allocate-shared:0010 */}
Can throw the exceptions thrown from `Alloc::allocate()` or from the constructor of `T`. If an exception is thrown, (1) has no effect. <InlineRevision since="C++20">If an exception is thrown during the construction of the array, already-initialized elements are destroyed in reverse order</InlineRevision>.

### Notes

{/* source:cpp-memory-shared-ptr-allocate-shared:0011 */}
Like [`std::make_shared`](/docs/cpp/library/memory/shared_ptr/make_shared), this function typically performs only one allocation, and places both the `T` object and the control block in the allocated memory block (the standard recommends but does not require this, all known implementations do this). A copy of `alloc` is stored as part of the control block so that it can be used to deallocate it once both shared and weak reference counts reach zero.

{/* source:cpp-memory-shared-ptr-allocate-shared:0012 */}
Unlike the `std::shared_ptr` [`constructors`](/docs/cpp/library/memory/shared_ptr/shared_ptr), `std::allocate_shared` does not accept a separate custom deleter: the supplied allocator is used for destruction of the control block and the `T` object, and for deallocation of their shared memory block.

{/* source:cpp-memory-shared-ptr-allocate-shared:0013 */}
<Revision until="C++20">
[`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) supports array types (as of C++17), but `std::allocate_shared` does not. This functionality is supported by [`boost::allocate_shared`](https://www.boost.org/doc/libs/1_66_0/libs/smart_ptr/doc/html/smart_ptr.html#make_shared).
</Revision>

{/* source:cpp-memory-shared-ptr-allocate-shared:0014 */}
A constructor *enables `shared_from_this`* with a pointer `ptr` of type `U*` means that it determines if `U` has an <InlineRevision since="C++17">unambiguous and accessible</InlineRevision> base class that is a specialization of [`std::enable_shared_from_this`](/docs/cpp/library/memory/enable_shared_from_this), and if so, the constructor evaluates `if (ptr != nullptr && ptr->`[`weak_this`](/docs/cpp/library/memory/enable_shared_from_this#weak_this)`.expired())` `ptr->`[`weak_this`](/docs/cpp/library/memory/enable_shared_from_this#weak_this)`= std::shared_ptr<std::remove_cv_t<U>>(*this, const_cast<std::remove_cv_t<U>*>(ptr));`.

{/* source:cpp-memory-shared-ptr-allocate-shared:0015 */}
The assignment to the [`weak_this`](/docs/cpp/library/memory/enable_shared_from_this#weak_this) is not atomic and conflicts with any potentially concurrent access to the same object. This ensures that future calls to [`shared_from_this()`](/docs/cpp/library/memory/enable_shared_from_this/shared_from_this) would share ownership with the [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) created by this raw pointer constructor.

{/* source:cpp-memory-shared-ptr-allocate-shared:0016 */}
The test `ptr->`[`weak_this`](/docs/cpp/library/memory/enable_shared_from_this#weak_this)`.expired()` in the code above makes sure that [`weak_this`](/docs/cpp/library/memory/enable_shared_from_this#weak_this) is not reassigned if it already indicates an owner. This test is required as of C++17.

### Example

{/* source:cpp-memory-shared-ptr-allocate-shared:0018 */}
```cpp
#include <cstddef>
#include <iostream>
#include <memory>
#include <memory_resource>
#include <vector>
 
class Value
{
    int i;
 
public:
    Value(int i) : i(i) { std::cout << "Value(), i = " << i << '\n'; }
    ~Value() { std::cout << "~Value(), i = " << i << '\n'; }
    void print() const { std::cout << "i = " << i << '\n'; }
};
 
int main()
{
    // Create a polymorphic allocator using the monotonic buffer resource
    std::byte buffer[sizeof(Value) * 8];
    std::pmr::monotonic_buffer_resource resource(buffer, sizeof(buffer));
    std::pmr::polymorphic_allocator<Value> allocator(&resource);
 
    std::vector<std::shared_ptr<Value>> v;
 
    for (int i{}; i != 4; ++i)
        // Use std::allocate_shared with the custom allocator
        v.emplace_back(std::allocate_shared<Value>(allocator, i));
 
    for (const auto& sp : v)
        sp->print();
 
} //< All shared pointers will automatically clean up when they go out of scope.
```

Output:

```text
Value(), i = 0
Value(), i = 1
Value(), i = 2
Value(), i = 3
i = 0
i = 1
i = 2
i = 3
~Value(), i = 0
~Value(), i = 1
~Value(), i = 2
~Value(), i = 3
```
