{/* source:cpp-memory-shared-ptr-operator-cmp:0001 */}
Compares two `shared_ptr<T>` objects or compares `shared_ptr<T>` with a null pointer.

{/* source:cpp-memory-shared-ptr-operator-cmp:0002 */}
Note that the comparison operators for `shared_ptr` simply compare pointer values; the actual objects pointed to are not compared. Having `operator<` defined for `shared_ptr` allows `shared_ptrs` to be used as keys in associative containers, like [`std::map`](/docs/cpp/library/container/map) and [`std::set`](/docs/cpp/library/container/set).

{/* source:cpp-memory-shared-ptr-operator-cmp:0003 */}
<Revision since="C++20">
The \<, \<=, \>, \>=, and \!= operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Parameters

### Return value

{/* source:cpp-memory-shared-ptr-operator-cmp:0005 */}
1. 1) `lhs.get() == rhs.get()`

{/* source:cpp-memory-shared-ptr-operator-cmp:0006 */}
2. 2) `!(lhs == rhs)`

{/* source:cpp-memory-shared-ptr-operator-cmp:0007 */}
3. 3) `std::less<V>()(lhs.get(), rhs.get())`, where `V` is the [composite pointer type](/docs/cpp/language/expressions/operator_comparison#Pointer_comparison_operators) of `std::shared_ptr<T>::element_type*` and `std::shared_ptr<U>::element_type*`.

{/* source:cpp-memory-shared-ptr-operator-cmp:0008 */}
4. 4) `rhs < lhs`

{/* source:cpp-memory-shared-ptr-operator-cmp:0009 */}
5. 5) `!(rhs < lhs)`

{/* source:cpp-memory-shared-ptr-operator-cmp:0010 */}
6. 6) `!(lhs < rhs)`

{/* source:cpp-memory-shared-ptr-operator-cmp:0011 */}
7. 7) `std::compare_three_way{}(x.get(), y.get())`

{/* source:cpp-memory-shared-ptr-operator-cmp:0012 */}
8. 8) `!lhs`

{/* source:cpp-memory-shared-ptr-operator-cmp:0013 */}
9. 9) `!rhs`

{/* source:cpp-memory-shared-ptr-operator-cmp:0014 */}
10. 10) `(bool)lhs`

{/* source:cpp-memory-shared-ptr-operator-cmp:0015 */}
11. 11) `(bool)rhs`

{/* source:cpp-memory-shared-ptr-operator-cmp:0016 */}
12. 12) `std::less<std::shared_ptr<T>::element_type*>()(lhs.get(), nullptr)`

{/* source:cpp-memory-shared-ptr-operator-cmp:0017 */}
13. 13) `std::less<std::shared_ptr<T>::element_type*>()(nullptr, rhs.get())`

{/* source:cpp-memory-shared-ptr-operator-cmp:0018 */}
14. 14) `nullptr < lhs`

{/* source:cpp-memory-shared-ptr-operator-cmp:0019 */}
15. 15) `rhs < nullptr`

{/* source:cpp-memory-shared-ptr-operator-cmp:0020 */}
16. 16) `!(nullptr < lhs)`

{/* source:cpp-memory-shared-ptr-operator-cmp:0021 */}
17. 17) `!(rhs < nullptr)`

{/* source:cpp-memory-shared-ptr-operator-cmp:0022 */}
18. 18) `!(lhs < nullptr)`

{/* source:cpp-memory-shared-ptr-operator-cmp:0023 */}
19. 19) `!(nullptr < rhs)`

{/* source:cpp-memory-shared-ptr-operator-cmp:0024 */}
20. 20) `std::compare_three_way{}(x.get(), static_cast<std::shared_ptr<T>::element_type*>(nullptr))`

### Notes

{/* source:cpp-memory-shared-ptr-operator-cmp:0025 */}
In all cases, it is the stored pointer (the one returned by [`get()`](/docs/cpp/library/memory/shared_ptr/get)) that is compared, rather than the managed pointer (the one passed to the deleter when [`use_count`](/docs/cpp/library/memory/shared_ptr/use_count) goes to zero). The two pointers may differ in a `shared_ptr` created using the aliasing constructor.

### Example

{/* source:cpp-memory-shared-ptr-operator-cmp:0026 */}
```cpp
#include <iostream>
#include <memory>
 
int main()
{
    std::shared_ptr<int> p1(new int(42));
    std::shared_ptr<int> p2(new int(42));
 
    std::cout << std::boolalpha
        << "(p1 == p1)       : " << (p1 == p1) << '\n'
        << "(p1 <=> p1) == 0 : " << ((p1 <=> p1) == 0) << '\n' // Since C++20
 
    // p1 and p2 point to different memory locations, so p1 != p2
        << "(p1 == p2)       : " << (p1 == p2) << '\n'
        << "(p1 < p2)        : " << (p1 < p2) << '\n'
        << "(p1 <=> p2) < 0  : " << ((p1 <=> p2) < 0) << '\n'   // Since C++20
        << "(p1 <=> p2) == 0 : " << ((p1 <=> p2) == 0) << '\n'; // Since C++20
}
```

Possible output:

```text
(p1 == p1)       : true
(p1 <=> p1) == 0 : true
(p1 == p2)       : false
(p1 < p2)        : true
(p1 <=> p2) < 0  : true
(p1 <=> p2) == 0 : false
```
