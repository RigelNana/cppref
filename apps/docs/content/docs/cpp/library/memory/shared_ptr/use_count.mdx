{/* source:cpp-memory-shared-ptr-use-count:0001 */}
Returns the number of different `shared_ptr` instances (`*this` included) managing the current object. If there is no managed object, `0` is returned.

{/* source:cpp-memory-shared-ptr-use-count:0002 */}
In multithreaded environment, use_count atomically retrieves the number of instances (typical implementations use a [`memory_order_relaxed`](/docs/cpp/library/atomic/memory_order) load).

## Parameters

{/* source:cpp-memory-shared-ptr-use-count:0003 */}
(none)

## Return value

{/* source:cpp-memory-shared-ptr-use-count:0004 */}
The number of [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) instances managing the current object or `0` if there is no managed object.

## Notes

{/* source:cpp-memory-shared-ptr-use-count:0005 */}
Common use cases include

{/* source:cpp-memory-shared-ptr-use-count:0006 */}
- comparison with `0`. If `use_count` returns zero, the shared pointer is *empty* and manages no objects (whether or not its stored pointer is [`nullptr`](/docs/cpp/language/expressions/nullptr)).
- comparison with `1`. If `use_count` returns 1, there are no other owners. <InlineRevision until="C++20">The <InlineRevision since="C++17">deprecated</InlineRevision> member function [`unique()`](/docs/cpp/library/memory/shared_ptr/unique) is provided for this use case.</InlineRevision>

{/* source:cpp-memory-shared-ptr-use-count:0007 */}
In multithreaded environment

{/* source:cpp-memory-shared-ptr-use-count:0008 */}
The value returned by `use_count` should be considered approximate, as the number of shared owners might change in other threads between the atomic retrieval and meaningful use of the value. When `use_count` returns 1, it does not imply that the object is safe to modify because accesses to the managed object by former shared owners may not have completed, and because new shared owners may be introduced concurrently, such as by [`std::weak_ptr::lock`](/docs/cpp/library/memory/weak_ptr/lock). Only when `use_count` returns 0 is the count accurate.

## Example

{/* source:cpp-memory-shared-ptr-use-count:0009 */}
```cpp
#include <iostream>
#include <memory>
 
void fun(std::shared_ptr<int> sp)
{
    std::cout << "in fun(): sp.use_count() == " << sp.use_count()
              << " (object @ " << sp << ")\n";
}
 
int main()
{
    auto sp1 = std::make_shared<int>(5);
    std::cout << "in main(): sp1.use_count() == " << sp1.use_count()
              << " (object @ " << sp1 << ")\n";
 
    fun(sp1);
}
```

Possible output:

```text
in main(): sp1.use_count() == 1 (object @ 0x20eec30)
in fun(): sp.use_count() == 2 (object @ 0x20eec30)
```
