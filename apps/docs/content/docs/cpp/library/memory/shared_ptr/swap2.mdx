Specializes the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for `std::shared_ptr`. Swaps the contents of `lhs` and `rhs`. Calls `lhs.swap(rhs)`.

## Parameters

{/* source:cpp-memory-shared-ptr-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">smart pointers whose contents to swap</Parameter>
</ParameterList>

## Return value

{/* source:cpp-memory-shared-ptr-swap2:0003 */}
(none)

## Complexity

{/* source:cpp-memory-shared-ptr-swap2:0004 */}
Constant.

## Example

{/* source:cpp-memory-shared-ptr-swap2:0005 */}
```cpp
#include <iostream>
#include <memory>
#include <string>
 
struct Foo {
    Foo(int _val) : val(_val) { std::cout << "Foo...\n"; }
    ~Foo() { std::cout << "~Foo...\n"; }
    std::string print() { return std::to_string(val); }
    int val;
};
 
int main()
{
    std::shared_ptr<Foo> p1 = std::make_shared<Foo>(100);
    std::shared_ptr<Foo> p2 = std::make_shared<Foo>(200);
    auto print = [&]() {
        std::cout << " p1=" << (p1 ? p1->print() : "nullptr");
        std::cout << " p2=" << (p2 ? p2->print() : "nullptr") << '\n';  
    };
    print();
 
    std::swap(p1, p2);
    print();
 
    p1.reset();
    print();
 
    std::swap(p1, p2);
    print();   
}
```

Output:

```text
Foo...
Foo...
 p1=100 p2=200
 p1=200 p2=100
~Foo...
 p1=nullptr p2=100
 p1=100 p2=nullptr
~Foo...
```
