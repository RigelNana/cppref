<DeclarationDoc>
  <Declaration language="cpp" code={`template< class T, class U, class V >
std::basic_ostream<U, V>& operator<<( std::basic_ostream<U, V>& os, const std::shared_ptr<T>& ptr );`} />
</DeclarationDoc>

{/* source:cpp-memory-shared-ptr-operator-ltlt:0001 */}
Inserts the value of the pointer stored in `ptr` into the output stream `os`.

{/* source:cpp-memory-shared-ptr-operator-ltlt:0002 */}
Equivalent to `os << ptr.get()`.

### Parameters

{/* source:cpp-memory-shared-ptr-operator-ltlt:0003 */}
<ParameterList>
  <Parameter name="os">a [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) to insert `ptr` into</Parameter>
  <Parameter name="ptr">the data to be inserted into `os`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-shared-ptr-operator-ltlt:0004 */}
`os`

### Example

{/* source:cpp-memory-shared-ptr-operator-ltlt:0005 */}
```cpp
#include <iostream>
#include <memory>
 
class Foo {};
 
int main()
{
    auto sp = std::make_shared<Foo>();
    std::cout << sp << '\n';
    std::cout << sp.get() << '\n';
}
```

Possible output:

```text
0x6d9028
0x6d9028
```
