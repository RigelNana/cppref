{/* source:cpp-memory-shared-ptr-unique:0001 */}
Checks if `*this` is the only `shared_ptr` instance managing the current object, i.e. whether `use_count() == 1`.

## Parameters

{/* source:cpp-memory-shared-ptr-unique:0002 */}
(none)

## Return value

{/* source:cpp-memory-shared-ptr-unique:0003 */}
`true` if `*this` is the only `shared_ptr` instance managing the current object, `false` otherwise.

## Notes

{/* source:cpp-memory-shared-ptr-unique:0004 */}
This function was deprecated in C++17 and removed in C++20 because `use_count() == 1` is meaningless in multithreaded environment (see [Notes](/docs/cpp/library/memory/shared_ptr/use_count#Notes) in [`use_count`](/docs/cpp/library/memory/shared_ptr/use_count)).

## Example

{/* source:cpp-memory-shared-ptr-unique:0005 */}
```cpp
#include <iostream> 
#include <memory> 
 
int main() 
{ 
    auto sp1 = std::make_shared<int>(5);
    std::cout << std::boolalpha;
    std::cout << "sp1.unique() == " << sp1.unique() << '\n'; 
 
    std::shared_ptr<int> sp2 = sp1; 
    std::cout << "sp1.unique() == " << sp1.unique() << '\n'; 
}
```

Output:

```text
sp1.unique() == true
sp1.unique() == false
```
