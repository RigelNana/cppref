{/* source:cpp-memory-shared-ptr-reset:0001 */}
Replaces the managed object with an object pointed to by `ptr`. Optional deleter `d` can be supplied, which is later used to destroy the new object when no `shared_ptr` objects own it. By default, [`delete`](/docs/cpp/language/expressions/delete) expression is used as deleter. Proper [`delete`](/docs/cpp/language/expressions/delete) expression corresponding to the supplied type is always selected, this is the reason why the function is implemented as template using a separate parameter `Y`.

{/* source:cpp-memory-shared-ptr-reset:0002 */}
If `*this` already owns an object and it is the last `shared_ptr` owning it, the object is destroyed through the owned deleter.

{/* source:cpp-memory-shared-ptr-reset:0003 */}
If the object pointed to by `ptr` is already owned, the function generally results in undefined behavior.

{/* source:cpp-memory-shared-ptr-reset:0004 */}
1. 1) Releases the ownership of the managed object, if any. After the call, `*this` manages no object. Equivalent to `shared_ptr().swap(*this);`.

{/* source:cpp-memory-shared-ptr-reset:0005 */}
2. 2-4) Replaces the managed object with an object pointed to by `ptr`. `Y` must be a complete type and implicitly convertible to `T`. Additionally:

   {/* source:cpp-memory-shared-ptr-reset:0006 */}
   1. 2) Uses the delete expression as the deleter. A valid delete expression must be available, i.e. `delete ptr` must be well formed, have well-defined behavior and not throw any exceptions. Equivalent to `shared_ptr<T>(ptr).swap(*this);`.

   {/* source:cpp-memory-shared-ptr-reset:0007 */}
   2. 3) Uses the specified deleter `d` as the deleter. `Deleter` must be callable for the type `T`, i.e. `d(ptr)` must be well formed, have well-defined behavior and not throw any exceptions. `Deleter` must be [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible), and its copy constructor and destructor must not throw exceptions. Equivalent to `shared_ptr<T>(ptr, d).swap(*this);`.

   {/* source:cpp-memory-shared-ptr-reset:0008 */}
   3. 4) Same as (3), but additionally uses a copy of `alloc` for allocation of data for internal use. `Alloc` must be an [Allocator](/docs/cpp/library/named_req/Allocator). The copy constructor and destructor must not throw exceptions. Equivalent to `shared_ptr<T>(ptr, d, alloc).swap(*this);`.

## Parameters

{/* source:cpp-memory-shared-ptr-reset:0009 */}
<ParameterList>
  <Parameter name="ptr">pointer to an object to acquire ownership of</Parameter>
  <Parameter name="d">deleter to store for deletion of the object</Parameter>
  <Parameter name="alloc">allocator to use for internal allocations</Parameter>
</ParameterList>

## Return value

{/* source:cpp-memory-shared-ptr-reset:0010 */}
(none)

## Exceptions

{/* source:cpp-memory-shared-ptr-reset:0011 */}
1. 2) [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if required additional memory could not be obtained. May throw implementation-defined exception for other errors. `delete ptr` is called if an exception occurs.

{/* source:cpp-memory-shared-ptr-reset:0012 */}
2. 3,4) [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if required additional memory could not be obtained. May throw implementation-defined exception for other errors. `d(ptr)` is called if an exception occurs.

## Example

{/* source:cpp-memory-shared-ptr-reset:0013 */}
```cpp
#include <iostream>
#include <memory>
 
struct Foo
{
    Foo(int n = 0) noexcept : bar(n)
    {
        std::cout << "Foo::Foo(), bar = " << bar << " @ " << this << '\n';
    }
    ~Foo()
    {
        std::cout << "Foo::~Foo(), bar = " << bar << " @ " << this << '\n';
    }
    int getBar() const noexcept { return bar; }
private:
    int bar;
};
 
int main()
{
    std::cout << "1) unique ownership\n";
    {
        std::shared_ptr<Foo> sptr = std::make_shared<Foo>(100);
 
        std::cout << "Foo::bar = " << sptr->getBar() << ", use_count() = "
                  << sptr.use_count() << '\n';
 
        // Reset the shared_ptr without handing it a fresh instance of Foo.
        // The old instance will be destroyed after this call.
        std::cout << "call sptr.reset()...\n";
        sptr.reset(); // calls Foo's destructor here
        std::cout << "After reset(): use_count() = " << sptr.use_count()
                  << ", sptr = " << sptr << '\n';
    }   // No call to Foo's destructor, it was done earlier in reset().
 
    std::cout << "\n2) unique ownership\n";
    {
        std::shared_ptr<Foo> sptr = std::make_shared<Foo>(200);
 
        std::cout << "Foo::bar = " << sptr->getBar() << ", use_count() = "
                  << sptr.use_count() << '\n';
 
        // Reset the shared_ptr, hand it a fresh instance of Foo.
        // The old instance will be destroyed after this call.
        std::cout << "call sptr.reset()...\n";
        sptr.reset(new Foo{222});
        std::cout << "After reset(): use_count() = " << sptr.use_count()
                  << ", sptr = " << sptr << "\nLeaving the scope...\n";
    }   // Calls Foo's destructor.
 
    std::cout << "\n3) multiple ownership\n";
    {
        std::shared_ptr<Foo> sptr1 = std::make_shared<Foo>(300);
        std::shared_ptr<Foo> sptr2 = sptr1;
        std::shared_ptr<Foo> sptr3 = sptr2;
 
        std::cout << "Foo::bar = " << sptr1->getBar() << ", use_count() = "
                  << sptr1.use_count() << '\n';
 
        // Reset the shared_ptr sptr1, hand it a fresh instance of Foo.
        // The old instance will stay shared between sptr2 and sptr3.
        std::cout << "call sptr1.reset()...\n";
        sptr1.reset(new Foo{333});
 
        std::cout << "After reset():\n"
                  << "sptr1.use_count() = " << sptr1.use_count()
                  << ", sptr1 @ " << sptr1 << '\n'
                  << "sptr2.use_count() = " << sptr2.use_count()
                  << ", sptr2 @ " << sptr2 << '\n'
                  << "sptr3.use_count() = " << sptr3.use_count()
                  << ", sptr3 @ " << sptr3 << '\n'
                  << "Leaving the scope...\n";
    }   // Calls two destructors of: 1) Foo owned by sptr1,
        // 2) Foo shared between sptr2/sptr3.
}
```
