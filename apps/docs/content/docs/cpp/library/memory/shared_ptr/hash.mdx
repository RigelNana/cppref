{/* source:cpp-memory-shared-ptr-hash:0001 */}
The template specialization of [`std::hash`](/docs/cpp/library/utility/hash) for `std::shared_ptr<T>` allows users to obtain hashes of objects of type `std::shared_ptr<T>`.

{/* source:cpp-memory-shared-ptr-hash:0002 */}
For a given `std::shared_ptr<T> p`, this specialization ensures that `std::hash<std::shared_ptr<T>>()(p) == std::hash<decltype(p.get())>()(p.get())`.
