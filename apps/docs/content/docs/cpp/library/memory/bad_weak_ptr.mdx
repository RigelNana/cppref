`std::bad_weak_ptr` is the type of the object thrown as exceptions by the constructors of [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) that take [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr) as the argument, when the [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr) refers to an already deleted object.

## std::bad_weak_ptr::bad_weak_ptr

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++11" code={`bad_weak_ptr() noexcept;`} />
  <Declaration id="2" language="cpp" since="C++11" code={`bad_weak_ptr( const bad_weak_ptr& other ) noexcept;`} />
</DeclarationDoc>

Constructs a new `bad_weak_ptr` object with an implementation-defined null-terminated byte string which is accessible through [`what()`](/docs/cpp/library/error/exception/what).

1. 1) Default constructor.
2. 2) Copy constructor. If `*this` and `other` both have dynamic type `std::bad_weak_ptr` then `std::strcmp(what(), other.what()) == 0`.

## std::bad_weak_ptr::what

<DeclarationDoc>
  <Declaration language="cpp" since="C++11" code={`virtual const char* what() const noexcept;`} />
</DeclarationDoc>

Returns the explanatory string.

### Return value

Pointer to an implementation-defined null-terminated string with explanatory information. The string is suitable for conversion and display as a [`std::wstring`](/docs/cpp/library/string/basic_string). The pointer is guaranteed to be valid at least until the exception object from which it is obtained is destroyed, or until a non-const member function (e.g. copy assignment operator) on the exception object is called.

<Revision since="C++26">
The returned string is encoded with the ordinary literal encoding during constant evaluation.
</Revision>

### Notes

Implementations are allowed but not required to override `what()`.

### Example

{/* source:cpp-memory-bad-weak-ptr:0008 */}
```cpp
#include <iostream>
#include <memory>
 
int main()
{
    std::shared_ptr<int> p1(new int(42));
    std::weak_ptr<int> wp(p1);
    p1.reset();
    try
    {
        std::shared_ptr<int> p2(wp);
    }
    catch (const std::bad_weak_ptr& e)
    {
        std::cout << e.what() << '\n';
    }
}
```

Possible output:

```text
std::bad_weak_ptr
```
