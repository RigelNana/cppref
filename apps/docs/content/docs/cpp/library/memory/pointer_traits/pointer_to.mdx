{/* source:cpp-memory-pointer-traits-pointer-to:0001 */}
Constructs a dereferenceable pointer or pointer-like object (["fancy pointer"](/docs/cpp/library/named_req/Allocator#Fancy_pointers)) to its argument.

{/* source:cpp-memory-pointer-traits-pointer-to:0002 */}
1. 1) The version of this function in the non-specialized [`std::pointer_traits`](/docs/cpp/library/memory/pointer_traits) template simply calls `Ptr::pointer_to(r)`, and if `Ptr` does not provide a static member function `pointer_to`, instantiation of this function is a compile-time error.

{/* source:cpp-memory-pointer-traits-pointer-to:0003 */}
2. 2) The version of this function in the specialization of [`std::pointer_traits`](/docs/cpp/library/memory/pointer_traits) for pointer types returns `std::addressof(r)`.

### Parameters

{/* source:cpp-memory-pointer-traits-pointer-to:0004 */}
<ParameterList>
  <Parameter name="r">reference to an object of type `element_type&`, except if `element_type` is `void`, in which case the type of `r` is unspecified</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-pointer-traits-pointer-to:0005 */}
A dereferenceable pointer to `r`, of the type `pointer_traits<>::pointer`.

### Exceptions

{/* source:cpp-memory-pointer-traits-pointer-to:0006 */}
1. 1) Unspecified (typically same as `Ptr::pointer_to`).

### Notes

{/* source:cpp-memory-pointer-traits-pointer-to:0007 */}
The [Boost.Intrusive library version](https://www.boost.org/doc/libs/release/doc/html/boost/intrusive/pointer_traits.html) of this function returns `pointer(std::addressof(r))` if `Ptr::pointer_to` does not exist.
