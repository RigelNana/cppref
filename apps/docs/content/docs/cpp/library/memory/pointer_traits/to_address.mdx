{/* source:cpp-memory-pointer-traits-to-address:0001 */}
Constructs a raw pointer that references the same object as its pointer-like (["fancy pointer"](/docs/cpp/library/named_req/Allocator#Fancy_pointers)) argument.

{/* source:cpp-memory-pointer-traits-to-address:0002 */}
This function, if defined, is the inverse of [`pointer_to`](/docs/cpp/library/memory/pointer_traits/pointer_to), and exists as the customization point to be called by [`std::to_address`](/docs/cpp/library/memory/to_address).

### Parameters

{/* source:cpp-memory-pointer-traits-to-address:0003 */}
<ParameterList>
  <Parameter name="p">fancy pointer/pointer-like object</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-pointer-traits-to-address:0004 */}
A raw pointer of the type `element_type*` that references the same memory location as the argument `p`.
