Returns the actual address of `x` even in presence of overloaded `operator&`.

### Parameters

{/* source:cpp-memory-allocator-address:0002 */}
<ParameterList>
  <Parameter name="x">the object to acquire address of</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-allocator-address:0003 */}
The actual address of `x`.
