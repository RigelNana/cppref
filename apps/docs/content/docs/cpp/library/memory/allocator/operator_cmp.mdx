Compares two default allocators. Since default allocators are stateless, two default allocators are always equal.

{/* source:cpp-memory-allocator-operator-cmp:0002 */}
1. 1) Returns `true`.

{/* source:cpp-memory-allocator-operator-cmp:0003 */}
2. 2) Returns `false`.

{/* source:cpp-memory-allocator-operator-cmp:0004 */}
