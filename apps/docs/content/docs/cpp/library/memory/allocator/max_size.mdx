{/* source:cpp-memory-allocator-max-size:0001 */}
Returns the maximum theoretically possible value of `n`, for which the call [`allocate`](/docs/cpp/library/memory/allocator/allocate)`(n, 0)` could succeed.

{/* source:cpp-memory-allocator-max-size:0002 */}
In most implementations, this returns `std::numeric_limits<size_type>::max() / sizeof(value_type)`.

### Parameters

{/* source:cpp-memory-allocator-max-size:0003 */}
(none)

### Return value

{/* source:cpp-memory-allocator-max-size:0004 */}
The maximum supported allocation size.
