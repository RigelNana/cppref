{/* source:cpp-memory-allocator-destroy:0001 */}
Calls the destructor of the object pointed to by `p`.

{/* source:cpp-memory-allocator-destroy:0002 */}
1. 1) Calls `p->~T()`.

{/* source:cpp-memory-allocator-destroy:0003 */}
2. 2) Calls `p->~U()`.

### Parameters

{/* source:cpp-memory-allocator-destroy:0004 */}
<ParameterList>
  <Parameter name="p">pointer to the object that is going to be destroyed</Parameter>
</ParameterList>

{/* source:cpp-memory-allocator-destroy:0005 */}
(none)
