{/* source:cpp-memory-allocator-construct:0001 */}
Constructs an object of type `T` in allocated uninitialized storage pointed to by `p`, using global placement-new.

{/* source:cpp-memory-allocator-construct:0002 */}
1. 1) Calls `::new((void*)p) T(val)`.

{/* source:cpp-memory-allocator-construct:0003 */}
2. 2) Calls `::new((void*)p) U(std::forward<Args>(args)...)`.

### Parameters

{/* source:cpp-memory-allocator-construct:0004 */}
<ParameterList>
  <Parameter name="p">pointer to allocated uninitialized storage</Parameter>
  <Parameter name="val">the value to use as the copy constructor argument</Parameter>
  <Parameter name="args...">the constructor arguments to use</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-allocator-construct:0005 */}
(none)
