{/* source:cpp-memory-ranges-destroy:0001 */}
1. 1) Destroys the objects in the range `[first, last)`, as if by `for (; first != last; ++first) std::ranges::destroy_at(std::addressof(*first)); return first;`.

{/* source:cpp-memory-ranges-destroy:0002 */}
2. 2) Same as (1), but uses `r` as the source range, as if using `ranges::begin(r)` as `first` and `ranges::end(r)` as `last`.

{/* source:cpp-memory-ranges-destroy:0003 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-memory-ranges-destroy:0004 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [`argument-dependent lookup`](/docs/cpp/language/functions/adl).
- When any of them are found by [`normal unqualified lookup`](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [`argument-dependent lookup`](/docs/cpp/language/functions/adl) is inhibited.

### Parameters

{/* source:cpp-memory-ranges-destroy:0005 */}
<ParameterList>
  <Parameter name="first, last">iterator-sentinel pair denoting the range of elements to destroy</Parameter>
  <Parameter name="r">the range to destroy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-ranges-destroy:0006 */}
An iterator compares equal to `last`.

### Complexity

{/* source:cpp-memory-ranges-destroy:0007 */}
Linear in the distance between `first` and `last`.

### Possible implementation

{/* source:cpp-memory-ranges-destroy:0008 */}
```cpp
struct destroy_fn
{
    template<no-throw-input-iterator I, no-throw-sentinel-for<I> S>
        requires std::destructible<std::iter_value_t<I>>
    constexpr I operator()(I first, S last) const noexcept
    {
        for (; first != last; ++first)
            std::ranges::destroy_at(std::addressof(*first));
        return first;
    }
 
    template<no-throw-input-range R>
        requires std::destructible<std::ranges::range_value_t<R>>
    constexpr std::ranges::borrowed_iterator_t<R> operator()(R&& r) const noexcept
    {
        return operator()(std::ranges::begin(r), std::ranges::end(r));
    }
};
 
inline constexpr destroy_fn destroy{};
```

### Example

{/* source:cpp-memory-ranges-destroy:0009 */}
The following example demonstrates how to use `ranges::destroy` to destroy a contiguous sequence of elements.

{/* source:cpp-memory-ranges-destroy:0010 */}
```cpp
#include <iostream>
#include <memory>
#include <new>
 
struct Tracer
{
    int value;
    ~Tracer() { std::cout << value << " destructed\n"; }
};
 
int main()
{
    alignas(Tracer) unsigned char buffer[sizeof(Tracer) * 8];
 
    for (int i = 0; i < 8; ++i)
        new(buffer + sizeof(Tracer) * i) Tracer{i}; //manually construct objects
 
    auto ptr = std::launder(reinterpret_cast<Tracer*>(buffer));
 
    std::ranges::destroy(ptr, ptr + 8);
}
```

Output:

```text
0 destructed
1 destructed
2 destructed
3 destructed
4 destructed
5 destructed
6 destructed
7 destructed
```
