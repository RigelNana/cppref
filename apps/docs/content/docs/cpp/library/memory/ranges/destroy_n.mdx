{/* source:cpp-memory-ranges-destroy-n:0001 */}
Destroys the `n` objects in the range starting at `first`, equivalent to

{/* source:cpp-memory-ranges-destroy-n:0002 */}
`return std::ranges::destroy(std::counted_iterator(first, n), std::default_sentinel).base();`

{/* source:cpp-memory-ranges-destroy-n:0003 */}
The function-like entities described on this page are [*algorithm function objects*](/docs/cpp/library/algorithm/ranges#Algorithm_function_objects) (informally known as *niebloids*), that is:

{/* source:cpp-memory-ranges-destroy-n:0004 */}
- Explicit template argument lists cannot be specified when calling any of them.
- None of them are visible to [argument-dependent lookup](/docs/cpp/language/functions/adl).
- When any of them are found by [normal unqualified lookup](/docs/cpp/language/basic_concepts/unqualified_lookup) as the name to the left of the function-call operator, [argument-dependent lookup](/docs/cpp/language/functions/adl) is inhibited.

### Parameters

{/* source:cpp-memory-ranges-destroy-n:0005 */}
<ParameterList>
  <Parameter name="first">the beginning of the range of elements to destroy</Parameter>
  <Parameter name="n">the number of elements to destroy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-ranges-destroy-n:0006 */}
The end of the range of objects that has been destroyed.

### Complexity

{/* source:cpp-memory-ranges-destroy-n:0007 */}
Linear in `n`.

### Possible implementation

{/* source:cpp-memory-ranges-destroy-n:0008 */}
```cpp
struct destroy_n_fn
{
    template<no-throw-input-iterator I>
        requires std::destructible<std::iter_value_t<I>>
    constexpr I operator()(I first, std::iter_difference_t<I> n) const noexcept
    {
        for (; n != 0; (void)++first, --n)
            std::ranges::destroy_at(std::addressof(*first));
        return first;
    }
};
 
inline constexpr destroy_n_fn destroy_n{};
```

### Example

{/* source:cpp-memory-ranges-destroy-n:0009 */}
The following example demonstrates how to use `ranges::destroy_n` to destroy a contiguous sequence of elements.

{/* source:cpp-memory-ranges-destroy-n:0010 */}
```cpp
#include <iostream>
#include <memory>
#include <new>
 
struct Tracer
{
    int value;
    ~Tracer() { std::cout << value << " destructed\n"; }
};
 
int main()
{
    alignas(Tracer) unsigned char buffer[sizeof(Tracer) * 8];
 
    for (int i = 0; i < 8; ++i)
        new(buffer + sizeof(Tracer) * i) Tracer{i}; //manually construct objects
 
    auto ptr = std::launder(reinterpret_cast<Tracer*>(buffer));
 
    std::ranges::destroy_n(ptr, 8);
}
```

Output:

```text
0 destructed
1 destructed
2 destructed
3 destructed
4 destructed
5 destructed
6 destructed
7 destructed
```
