{/* source:cpp-memory-new-delete-resource:0001 */}
Returns a pointer to a `memory_resource` that uses the global [`operator new`](/docs/cpp/library/memory/new/operator_new) and [`operator delete`](/docs/cpp/library/memory/new/operator_delete) to allocate memory.

### Return value

{/* source:cpp-memory-new-delete-resource:0002 */}
Returns a pointer `p` to a static storage duration object of a type derived from [`std::pmr::memory_resource`](/docs/cpp/library/memory/memory_resource), with the following properties:

{/* source:cpp-memory-new-delete-resource:0003 */}
- its `allocate()` function uses `::operator new` to allocate memory;
- its `deallocate()` function uses `::operator delete` to deallocate memory;
- for any `memory_resource` `r`, `p->is_equal(r)` returns `&r == p`.

{/* source:cpp-memory-new-delete-resource:0004 */}
The same value is returned every time this function is called.
