{/* source:cpp-memory-uninitialized-fill-n:0001 */}
1. 1) Copies `value` to an uninitialized memory area `first` + [`0`, `count`) as if by

   `for (; count--; ++first)`\
   `::new (`[`voidify`](/docs/cpp/library/memory/voidify)`(*first))`\
   `typename std::iterator_traits<NoThrowForwardIt>::value_type(value);`\
   `return first;`

{/* source:cpp-memory-uninitialized-fill-n:0002 */}
If an exception is thrown during the initialization, the objects already constructed are destroyed in an unspecified order.

{/* source:cpp-memory-uninitialized-fill-n:0003 */}
2. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-memory-uninitialized-fill-n:0004 */}
This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">
   `std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.
   </Revision>

   <Revision since="C++20">
   `std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.
   </Revision>

Type requirements

- `NoThrowForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- No increment, assignment, comparison, or indirection through valid instances of `NoThrowForwardIt` may throw exceptions.
- <InlineRevision until="C++11">Applying `&*` to a `NoThrowForwardIt` value must yield a pointer to its value type.</InlineRevision>

### Return value

{/* source:cpp-memory-uninitialized-fill-n:0006 */}

### Complexity

{/* source:cpp-memory-uninitialized-fill-n:0007 */}
Linear in `count`.

### Exceptions

{/* source:cpp-memory-uninitialized-fill-n:0008 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-memory-uninitialized-fill-n:0009 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-memory-uninitialized-fill-n:0011 */}
```cpp
template<class NoThrowForwardIt, class Size, class T>
constexpr NoThrowForwardIt uninitialized_fill_n(NoThrowForwardIt first,
                                                Size count, const T& value)
{
    using V = typename std::iterator_traits<NoThrowForwardIt>::value_type;
    NoThrowForwardIt current = first;
    try
    {
        for (; count > 0; ++current, (void) --count)
            ::new (static_cast<void*>(std::addressof(*current))) V(value);
        return current;
    }
    catch (...)
    {
        for (; first != current; ++first)
            first->~V();
        throw;
    }
    return current;
}
```

### Example

{/* source:cpp-memory-uninitialized-fill-n:0012 */}
```cpp
#include <algorithm>
#include <iostream>
#include <memory>
#include <string>
#include <tuple>
 
int main()
{
    std::string* p;
    std::size_t sz;
    std::tie(p, sz) = std::get_temporary_buffer<std::string>(4);
    std::uninitialized_fill_n(p, sz, "Example");
 
    for (std::string* i = p; i != p + sz; ++i)
    {
        std::cout << *i << '\n';
        i->~basic_string<char>();
    }
    std::return_temporary_buffer(p);
}
```
