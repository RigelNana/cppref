{/* source:cpp-memory-uninitialized-copy:0001 */}
1. 1) Copies elements from the range `[first, last)` to an uninitialized memory area beginning at `d_first` as if by `for (; first != last; ++d_first, (void) ++first)` `::new (`[`voidify`](/docs/cpp/library/memory/voidify)`(*d_first))` `typename std::iterator_traits<NoThrowForwardIt>::value_type(*first);`

{/* source:cpp-memory-uninitialized-copy:0002 */}
2. If an exception is thrown during the initialization, the objects already constructed are destroyed in an unspecified order.

{/* source:cpp-memory-uninitialized-copy:0003 */}
3. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-memory-uninitialized-copy:0004 */}
4. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">[`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

   <Revision since="C++20">[`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

{/* source:cpp-memory-uninitialized-copy:0005 */}
<Revision since="C++20">If `d_first` + [`0`, `std::distance(first, last)`) overlaps with [`first`, `last`), the behavior is undefined.</Revision>

**Type requirements**

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `NoThrowForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- No increment, assignment, comparison, or indirection through valid instances of `NoThrowForwardIt` may throw exceptions. <InlineRevision until="C++11">Applying `&*` to a `NoThrowForwardIt` value must yield a pointer to its value type.</InlineRevision>

### Return value

{/* source:cpp-memory-uninitialized-copy:0007 */}
Iterator to the element past the last element copied.

### Complexity

{/* source:cpp-memory-uninitialized-copy:0008 */}
Linear in the distance between `first` and `last`.

### Exceptions

{/* source:cpp-memory-uninitialized-copy:0009 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-memory-uninitialized-copy:0010 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-memory-uninitialized-copy:0012 */}
[`uninitialized_copy (1)`](/docs/cpp/library/memory/uninitialized_copy#Version_1)

```cpp
template<class InputIt, class NoThrowForwardIt>
constexpr NoThrowForwardIt uninitialized_copy(InputIt first, InputIt last,
                                              NoThrowForwardIt d_first)
{
    using T = typename std::iterator_traits<NoThrowForwardIt>::value_type;
    NoThrowForwardIt current = d_first;
    try
    {
        for (; first != last; ++first, (void) ++current)
            ::new (static_cast<void*>(std::addressof(*current))) T(*first);
        return current;
    }
    catch (...)
    {
        for (; d_first != current; ++d_first)
            d_first->~T();
        throw;
    }
}```

### Example

{/* source:cpp-memory-uninitialized-copy:0013 */}
```cpp
#include <cstdlib>
#include <iostream>
#include <memory>
#include <string>
 
int main()
{
    const char *v[] = {"This", "is", "an", "example"};
 
    auto sz = std::size(v);
 
    if (void *pbuf = std::aligned_alloc(alignof(std::string), sizeof(std::string) * sz))
    {
        try
        {
            auto first = static_cast<std::string*>(pbuf);
            auto last = std::uninitialized_copy(std::begin(v), std::end(v), first);
 
            for (auto it = first; it != last; ++it)
                std::cout << *it << '_';
            std::cout << '\n';
 
            std::destroy(first, last);
        }
        catch (...) {}
        std::free(pbuf);
    }
}```
