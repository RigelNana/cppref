{/* source:cpp-memory-uninitialized-move:0001 */}
1. 1) Copies the elements from [`first`, `last`) (using move semantics if supported) to an uninitialized memory area beginning at `d_first` as if by

   `for (; first != last; ++d_first, (void) ++first)`\
   `::new (`[`voidify`](/docs/cpp/library/memory/voidify)`(*d_first))`\
   `typename std::iterator_traits<NoThrowForwardIt>::value_type(/* value */);`\
   `return d_first;`

{/* source:cpp-memory-uninitialized-move:0002 */}
where `/* value */` is `std::move(*first)` if `*first` is of an lvalue reference type, or `*first` otherwise.

{/* source:cpp-memory-uninitialized-move:0003 */}
If an exception is thrown during the initialization, some objects in [`first`, `last`) are left in a valid but unspecified state, and the objects already constructed are destroyed in an unspecified order.

{/* source:cpp-memory-uninitialized-move:0004 */}
2. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-memory-uninitialized-move:0005 */}
This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">
   `std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.
   </Revision>

   <Revision since="C++20">
   `std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.
   </Revision>

{/* source:cpp-memory-uninitialized-move:0006 */}
<Revision since="C++20">
If `d_first` + [`0`, `std::distance(first, last)`) overlaps with [`first`, `last`), the behavior is undefined.
</Revision>

### Parameters

<ParameterList>
  <Parameter name="first, last">the range of the elements to move</Parameter>

Type requirements

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- `NoThrowForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- No increment, assignment, comparison, or indirection through valid instances of `NoThrowForwardIt` may throw exceptions.

### Return value

{/* source:cpp-memory-uninitialized-move:0008 */}
As described above.

### Complexity

{/* source:cpp-memory-uninitialized-move:0009 */}
Linear in the distance between `first` and `last`.

### Exceptions

{/* source:cpp-memory-uninitialized-move:0010 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-memory-uninitialized-move:0011 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Notes

{/* source:cpp-memory-uninitialized-move:0012 */}
When the input iterator deferences to an rvalue, the behavior of `std::uninitialized_move` is same as [`std::uninitialized_copy`](/docs/cpp/library/memory/uninitialized_copy).

### Possible implementation

{/* source:cpp-memory-uninitialized-move:0014 */}
```cpp
template<class InputIt, class NoThrowForwardIt>
constexpr NoThrowForwardIt uninitialized_move(InputIt first, InputIt last,
                                              NoThrowForwardIt d_first)
{
    using ValueType = typename std::iterator_traits<NoThrowForwardIt>::value_type;
    auto current = d_first;
    try
    {
        for (; first != last; ++first, (void) ++current)
        {
            auto addr = static_cast<void*>(std::addressof(*current));
            if constexpr (std::is_lvalue_reference_v<decltype(*first)>)
                ::new (addr) ValueType(std::move(*first));
            else
                ::new (addr) ValueType(*first);
        }
        return current;
    }
    catch (...)
    {
        std::destroy(d_first, current);
        throw;
    }
}
```

### Example

{/* source:cpp-memory-uninitialized-move:0015 */}
```cpp
#include <cstdlib>
#include <iomanip>
#include <iostream>
#include <memory>
#include <string>
 
void print(auto rem, auto first, auto last)
{
    for (std::cout << rem; first != last; ++first)
        std::cout << std::quoted(*first) << ' ';
    std::cout << '\n';
}
 
int main()
{
    std::string in[]{"Home", "Work!"};
    print("initially, in: ", std::begin(in), std::end(in));
 
    if (
        constexpr auto sz = std::size(in);
        void* out = std::aligned_alloc(alignof(std::string), sizeof(std::string) * sz))
    {
        try
        {
            auto first{static_cast<std::string*>(out)};
            auto last{first + sz};
            std::uninitialized_move(std::begin(in), std::end(in), first);
 
            print("after move, in: ", std::begin(in), std::end(in));
            print("after move, out: ", first, last);
 
            std::destroy(first, last);
        }
        catch (...)
        {
            std::cout << "Exception!\n";
        }
        std::free(out);
    }
}
```

Possible output:

```text
initially, in: "Home" "Work!"
after move, in: "" ""
after move, out: "Home" "Work!"
```
