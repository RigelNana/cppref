{/* source:cpp-memory-monotonic-buffer-resource-monotonic-buffer-resource:0001 */}
Constructs a [`monotonic_buffer_resource`](/docs/cpp/library/memory/monotonic_buffer_resource). The constructors not taking an upstream memory resource pointer use the return value of [`std::pmr::get_default_resource`](/docs/cpp/library/memory/get_default_resource) as the upstream memory resource.

{/* source:cpp-memory-monotonic-buffer-resource-monotonic-buffer-resource:0002 */}
1. 1,2) Sets the current buffer to null and the next buffer size to an implementation-defined size.

{/* source:cpp-memory-monotonic-buffer-resource-monotonic-buffer-resource:0003 */}
2. 3,4) Sets the current buffer to null and the next buffer size to a size no smaller than `initial_size`.

{/* source:cpp-memory-monotonic-buffer-resource-monotonic-buffer-resource:0004 */}
3. 5,6) Sets the current buffer to `buffer` and the next buffer size to `buffer_size` (but not less than 1). Then increase the next buffer size by an implementation-defined growth factor (which does not have to be integral).

{/* source:cpp-memory-monotonic-buffer-resource-monotonic-buffer-resource:0005 */}
4. 7) Copy constructor is deleted.

### Parameters

{/* source:cpp-memory-monotonic-buffer-resource-monotonic-buffer-resource:0006 */}
<ParameterList>
  <Parameter name="upstream">the upstream memory resource to use; must point to a valid memory resource</Parameter>
  <Parameter name="initial_size">the minimum size of the first buffer to allocate; must be greater than zero</Parameter>
  <Parameter name="buffer">the initial buffer to use</Parameter>
  <Parameter name="buffer_size">the size of the initial buffer; cannot be greater than the number of bytes in `buffer`</Parameter>
</ParameterList>
