{/* source:cpp-memory-monotonic-buffer-resource-do-deallocate:0001 */}
This function has no effect. Memory used by a [`monotonic_buffer_resource`](/docs/cpp/library/memory/monotonic_buffer_resource), as its name indicates, increases monotonically until the resource is destroyed.

### Exceptions

{/* source:cpp-memory-monotonic-buffer-resource-do-deallocate:0002 */}
Throws nothing.
