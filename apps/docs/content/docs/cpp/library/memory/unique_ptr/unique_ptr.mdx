  <DeclarationDescription>
    {/* source:cpp-memory-unique-ptr-unique-ptr:0001 */}
    1) Constructs a `std::unique_ptr` that owns nothing. Value-initializes the stored pointer and the stored deleter. Requires that `Deleter` is [DefaultConstructible](/docs/cpp/library/named_req/DefaultConstructible) and that construction does not throw an exception. These overloads participate in overload resolution only if `std::is_default_constructible<Deleter>::value` is `true` and `Deleter` is not a pointer type.

    {/* source:cpp-memory-unique-ptr-unique-ptr:0002 */}
    2) Constructs a `std::unique_ptr` which owns `p`, initializing the stored pointer with `p` and value-initializing the stored deleter. Requires that `Deleter` is [DefaultConstructible](/docs/cpp/library/named_req/DefaultConstructible) and that construction does not throw an exception. This overload participates in overload resolution only if `std::is_default_constructible<Deleter>::value` is `true` and `Deleter` is not a pointer type.

    <Revision since="C++17">
    This constructor is not selected by [class template argument deduction](/docs/cpp/language/templates/ctad).
    </Revision>

    {/* source:cpp-memory-unique-ptr-unique-ptr:0003 */}
    3,4) Constructs a `std::unique_ptr` object which owns `p`, initializing the stored pointer with `p` and initializing a deleter `D` as below (depends upon whether `D` is a reference type).

    {/* source:cpp-memory-unique-ptr-unique-ptr:0004 */}
    - a) If `D` is non-reference type `A`, then the signatures are:<br />`unique_ptr(pointer p, const A& d) noexcept;` (1) (requires that `Deleter` is nothrow-[CopyConstructible](/docs/cpp/library/named_req/CopyConstructible))<br />`unique_ptr(pointer p, A&& d) noexcept;` (2) (requires that `Deleter` is nothrow-[MoveConstructible](/docs/cpp/library/named_req/MoveConstructible))
    {/* source:cpp-memory-unique-ptr-unique-ptr:0005 */}
    - b) If `D` is an lvalue-reference type `A&`, then the signatures are:<br />`unique_ptr(pointer p, A& d) noexcept;` (1)<br />`unique_ptr(pointer p, A&& d) = delete;` (2)
    {/* source:cpp-memory-unique-ptr-unique-ptr:0006 */}
    - c) If `D` is an lvalue-reference type `const A&`, then the signatures are:<br />`unique_ptr(pointer p, const A& d) noexcept;` (1)<br />`unique_ptr(pointer p, const A&& d) = delete;` (2)

    {/* source:cpp-memory-unique-ptr-unique-ptr:0007 */}
    In all cases the deleter is initialized from `std::forward<decltype(d)>(d)`. These overloads participate in overload resolution only if `std::is_constructible<D, decltype(d)>::value` is `true`.

    <Revision since="C++17">
    These two constructors are not selected by [class template argument deduction](/docs/cpp/language/templates/ctad).
    </Revision>

    {/* source:cpp-memory-unique-ptr-unique-ptr:0008 */}
    2-4) In the specialization for arrays behave the same as the constructors that take a pointer parameter in the primary template except that they additionally do not participate in overload resolution unless one of the following is true:

    - `U` is the same type as `pointer`, or
    - `U` is [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t), or
    - `pointer` is the same type as `element_type*` and `U` is some pointer type `V*` such that `V(*)[]` is implicitly convertible to `element_type(*)[]`.

    {/* source:cpp-memory-unique-ptr-unique-ptr:0009 */}
    5) Constructs a `unique_ptr` by transferring ownership from `u` to `*this` and stores the null pointer in `u`. This constructor only participates in overload resolution if `std::is_move_constructible<Deleter>::value` is `true`. If `Deleter` is not a reference type, requires that it is nothrow-[MoveConstructible](/docs/cpp/library/named_req/MoveConstructible) (if `Deleter` is a reference, `get_deleter()` and `u.get_deleter()` after move construction reference the same value).

    {/* source:cpp-memory-unique-ptr-unique-ptr:0010 */}
    6) Constructs a `unique_ptr` by transferring ownership from `u` to `*this`, where `u` is constructed with a specified deleter (`E`). It depends upon whether `E` is a reference type, as following:

    {/* source:cpp-memory-unique-ptr-unique-ptr:0011 */}
    - a) if `E` is a reference type, this deleter is copy constructed from `u`'s deleter (requires that this construction does not throw),
    {/* source:cpp-memory-unique-ptr-unique-ptr:0012 */}
    - b) if `E` is a non-reference type, this deleter is move constructed from `u`'s deleter (requires that this construction does not throw).

    {/* source:cpp-memory-unique-ptr-unique-ptr:0013 */}
    This constructor only participates in overload resolution if all of the following is true:

    {/* source:cpp-memory-unique-ptr-unique-ptr:0014 */}
    - a) `unique_ptr<U, E>::pointer` is implicitly convertible to `pointer`,
    {/* source:cpp-memory-unique-ptr-unique-ptr:0015 */}
    - b) `U` is not an array type,
    {/* source:cpp-memory-unique-ptr-unique-ptr:0016 */}
    - c) either `Deleter` is a reference type and `E` is the same type as `Deleter`, or `Deleter` is not a reference type and `E` is implicitly convertible to `Deleter`.

    {/* source:cpp-memory-unique-ptr-unique-ptr:0017 */}
    6) In the specialization for arrays behaves the same as in the primary template, except that it will only participate in overload resolution if all of the following is true:

    - `U` is an array type,
    - `pointer` is the same type as `element_type*`,
    - `unique_ptr<U,E>::pointer` is the same type as `unique_ptr<U,E>::element_type*`,
    - `unique_ptr<U,E>::element_type(*)[]` is convertible to `element_type(*)[]`,
    - either `Deleter` is a reference type and `E` is the same type as `Deleter`, or `Deleter` is not a reference type and `E` is implicitly convertible to `Deleter`.

    {/* source:cpp-memory-unique-ptr-unique-ptr:0018 */}
    7) Copy constructor is explicitly deleted.

    {/* source:cpp-memory-unique-ptr-unique-ptr:0019 */}
    8) Constructs a `unique_ptr` where the stored pointer is initialized with [`u.release()`](/docs/cpp/library/memory/auto_ptr/release) and the stored deleter is value-initialized. This constructor only participates in overload resolution if `U*` is implicitly convertible to `T*` and `Deleter` is the same type as `std::default_delete<T>`.
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-memory-unique-ptr-unique-ptr:0021 */}
<Revision since="C++14">
Instead of using the overload (2) together with new, it is often a better idea to use [`std::make_unique<T>`](/docs/cpp/library/memory/unique_ptr/make_unique).
</Revision>

{/* source:cpp-memory-unique-ptr-unique-ptr:0022 */}
`std::unique_ptr<Derived>` is implicitly convertible to `std::unique_ptr<Base>` through the overload (6) (because both the managed pointer and [`std::default_delete`](/docs/cpp/library/memory/default_delete) are implicitly convertible).

{/* source:cpp-memory-unique-ptr-unique-ptr:0023 */}
Because the default constructor is `constexpr`, static unique_ptrs are initialized as part of [static non-local initialization](/docs/cpp/language/initialization#Non-local_variables), before any dynamic non-local initialization begins. This makes it safe to use a unique_ptr in a constructor of any static object.

{/* source:cpp-memory-unique-ptr-unique-ptr:0024 */}
<Revision since="C++17">
There is no [class template argument deduction](/docs/cpp/language/templates/ctad) from pointer type because it is impossible to distinguish a pointer obtained from array and non-array forms of `new`.
</Revision>

### Example

{/* source:cpp-memory-unique-ptr-unique-ptr:0025 */}
```cpp
#include <iostream>
#include <memory>
 
struct Foo // object to manage
{
    Foo() { std::cout << "Foo ctor\n"; }
    Foo(const Foo&) { std::cout << "Foo copy ctor\n"; }
    Foo(Foo&&) { std::cout << "Foo move ctor\n"; }
    ~Foo() { std::cout << "~Foo dtor\n"; }
};
 
struct D // deleter
{
    D() {};
    D(const D&) { std::cout << "D copy ctor\n"; }
    D(D&) { std::cout << "D non-const copy ctor\n"; }
    D(D&&) { std::cout << "D move ctor \n"; }
    void operator()(Foo* p) const
    {
        std::cout << "D is deleting a Foo\n";
        delete p;
    };
};
 
int main()
{
    std::cout << "Example constructor(1)...\n";
    std::unique_ptr<Foo> up1; // up1 is empty
    std::unique_ptr<Foo> up1b(nullptr); // up1b is empty
 
    std::cout << "Example constructor(2)...\n";
    {
        std::unique_ptr<Foo> up2(new Foo); //up2 now owns a Foo
    } // Foo deleted
 
    std::cout << "Example constructor(3)...\n";
    D d;
    {   // deleter type is not a reference
        std::unique_ptr<Foo, D> up3(new Foo, d); // deleter copied
    }
    {   // deleter type is a reference
        std::unique_ptr<Foo, D&> up3b(new Foo, d); // up3b holds a reference to d
    }
 
    std::cout << "Example constructor(4)...\n";
    {   // deleter is not a reference
        std::unique_ptr<Foo, D> up4(new Foo, D()); // deleter moved
    }
 
    std::cout << "Example constructor(5)...\n";
    {
        std::unique_ptr<Foo> up5a(new Foo);
        std::unique_ptr<Foo> up5b(std::move(up5a)); // ownership transfer
    }
 
    std::cout << "Example constructor(6)...\n";
    {
        std::unique_ptr<Foo, D> up6a(new Foo, d); // D is copied
        std::unique_ptr<Foo, D> up6b(std::move(up6a)); // D is moved
 
        std::unique_ptr<Foo, D&> up6c(new Foo, d); // D is a reference
        std::unique_ptr<Foo, D> up6d(std::move(up6c)); // D is copied
    }
 
#if (__cplusplus < 201703L)
    std::cout << "Example constructor(7)...\n";
    {
        std::auto_ptr<Foo> up7a(new Foo);
        std::unique_ptr<Foo> up7b(std::move(up7a)); // ownership transfer
    }
#endif
 
    std::cout << "Example array constructor...\n";
    {
        std::unique_ptr<Foo[]> up(new Foo[3]);
    } // three Foo objects deleted
}
```
