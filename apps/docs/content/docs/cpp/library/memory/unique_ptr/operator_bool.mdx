{/* source:cpp-memory-unique-ptr-operator-bool:0001 */}
Checks whether `*this` owns an object, i.e. whether [`get()`](/docs/cpp/library/memory/unique_ptr/get) != `nullptr`.

### Parameters

{/* source:cpp-memory-unique-ptr-operator-bool:0002 */}
(none)

### Return value

{/* source:cpp-memory-unique-ptr-operator-bool:0003 */}
`true` if `*this` owns an object, `false` otherwise.

### Example

{/* source:cpp-memory-unique-ptr-operator-bool:0004 */}
```cpp
#include <iostream>
#include <memory>
 
int main()
{
    std::unique_ptr<int> ptr(new int(42));
 
    if (ptr)
        std::cout << "before reset, ptr is: " << *ptr << '\n';
    ptr.reset();
    (ptr ? (std::cout << "after reset, ptr is: " << *ptr)
        : (std::cout << "after reset ptr is empty")) << '\n';
}
```

Output:

```text
before reset, ptr is: 42
after reset ptr is empty
```
