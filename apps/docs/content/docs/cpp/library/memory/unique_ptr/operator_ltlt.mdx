std::basic_ostream<CharT, Traits>& operator<<( std::basic_ostream<CharT, Traits>& os,
                                               const std::unique_ptr<Y, D>& p );`} />

{/* source:cpp-memory-unique-ptr-operator-ltlt:0001 */}
Inserts the value of the pointer managed by `p` into the output stream `os`.

{/* source:cpp-memory-unique-ptr-operator-ltlt:0002 */}
Equivalent to `os << p.get()`.

{/* source:cpp-memory-unique-ptr-operator-ltlt:0003 */}
This overload participates in overload resolution only if `os << p.get()` is a valid expression.

### Parameters

{/* source:cpp-memory-unique-ptr-operator-ltlt:0004 */}
<ParameterList>
  <Parameter name="os">a [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) to insert `p` into</Parameter>
  <Parameter name="p">the pointer to be inserted into `os`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-unique-ptr-operator-ltlt:0005 */}
`os`

### Notes

{/* source:cpp-memory-unique-ptr-operator-ltlt:0006 */}
If `std::unique_ptr<Y, D>::pointer` is a pointer to a character type (e.g., when `Y` is `char`(`[]`) or `CharT`(`[]`)), this may end up calling the [overloads of `operator<<` for null-terminated character strings](/docs/cpp/library/io/basic_ostream/operator_ltlt2) (causing undefined behavior if the pointer does not in fact point to such a string), rather than [the overload for printing the value of the pointer itself](/docs/cpp/library/io/basic_ostream/operator_ltlt).

### Example

{/* source:cpp-memory-unique-ptr-operator-ltlt:0007 */}
```cpp
#include <iostream>
#include <memory>
 
class Foo {};
 
int main()
{
    auto p = std::make_unique<Foo>();
    std::cout << p << '\n';
    std::cout << p.get() << '\n';
}
```

Possible output:

```text
0x6d9028
0x6d9028
```
