{/* source:cpp-memory-unique-ptr-operator-cmp:0001 */}
Compares the pointer values of two `unique_ptr`s, or a `unique_ptr` and `nullptr`.

{/* source:cpp-memory-unique-ptr-operator-cmp:0002 */}
1-7) Compares two `unique_ptr`s.

{/* source:cpp-memory-unique-ptr-operator-cmp:0003 */}
8-20) Compares a `unique_ptr` and `nullptr`.

{/* source:cpp-memory-unique-ptr-operator-cmp:0004 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Return value

{/* source:cpp-memory-unique-ptr-operator-cmp:0006 */}
1. 1) `x.get() == y.get()`

{/* source:cpp-memory-unique-ptr-operator-cmp:0007 */}
2. 2) `x.get() != y.get()`

{/* source:cpp-memory-unique-ptr-operator-cmp:0008 */}
3. 3) `std::less<CT>()(x.get(), y.get())`, where `CT` is `std::common_type<unique_ptr<T1, D1>::pointer, unique_ptr<T2, D2>::pointer>::type`.

{/* source:cpp-memory-unique-ptr-operator-cmp:0009 */}
4. 4) `!(y < x)`

{/* source:cpp-memory-unique-ptr-operator-cmp:0010 */}
5. 5) `y < x`

{/* source:cpp-memory-unique-ptr-operator-cmp:0011 */}
6. 6) `!(x < y)`

{/* source:cpp-memory-unique-ptr-operator-cmp:0012 */}
7. 7) `std::compare_three_way{}(x.get(), y.get())`

{/* source:cpp-memory-unique-ptr-operator-cmp:0013 */}
8. 8,9) `!x`

{/* source:cpp-memory-unique-ptr-operator-cmp:0014 */}
9. 10,11) `(bool)x`

{/* source:cpp-memory-unique-ptr-operator-cmp:0015 */}
10. 12) `std::less<unique_ptr<T,D>::pointer>()(x.get(), nullptr)`

{/* source:cpp-memory-unique-ptr-operator-cmp:0016 */}
11. 13) `std::less<unique_ptr<T,D>::pointer>()(nullptr, y.get())`

{/* source:cpp-memory-unique-ptr-operator-cmp:0017 */}
12. 14) `!(nullptr < x)`

{/* source:cpp-memory-unique-ptr-operator-cmp:0018 */}
13. 15) `!(y < nullptr)`

{/* source:cpp-memory-unique-ptr-operator-cmp:0019 */}
14. 16) `nullptr < x`

{/* source:cpp-memory-unique-ptr-operator-cmp:0020 */}
15. 17) `y < nullptr`

{/* source:cpp-memory-unique-ptr-operator-cmp:0021 */}
16. 18) `!(x < nullptr)`

{/* source:cpp-memory-unique-ptr-operator-cmp:0022 */}
17. 19) `!(nullptr < y)`

{/* source:cpp-memory-unique-ptr-operator-cmp:0023 */}
18. 20) `std::compare_three_way{}(x.get(), static_cast<typename unique_ptr<T, D>::pointer>(nullptr))`

### Example

{/* source:cpp-memory-unique-ptr-operator-cmp:0024 */}
```cpp
#include <iostream>
#include <memory>
 
int main()
{
    std::unique_ptr<int> p1(new int(42));
    std::unique_ptr<int> p2(new int(42));
 
    std::cout << std::boolalpha
        << "(p1 == p1)       : " << (p1 == p1) << '\n'
        << "(p1 <=> p1) == 0 : " << ((p1 <=> p1) == 0) << '\n' // Since C++20
 
    // p1 and p2 point to different memory locations, so p1 != p2
        << "(p1 == p2)       : " << (p1 == p2) << '\n'
        << "(p1 < p2)        : " << (p1 < p2) << '\n'
        << "(p1 <=> p2) < 0  : " << ((p1 <=> p2) < 0) << '\n'   // Since C++20
        << "(p1 <=> p2) == 0 : " << ((p1 <=> p2) == 0) << '\n'; // Since C++20
}
```

Possible output:

```text
(p1 == p1)       : true
(p1 <=> p1) == 0 : true
(p1 == p2)       : false
(p1 < p2)        : true
(p1 <=> p2) < 0  : true
(p1 <=> p2) == 0 : false
```
