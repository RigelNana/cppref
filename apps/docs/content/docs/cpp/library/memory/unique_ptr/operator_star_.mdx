{/* source:cpp-memory-unique-ptr-operator-star:0001 */}
`operator*` and `operator->` provide access to the object owned by `*this`.

{/* source:cpp-memory-unique-ptr-operator-star:0002 */}
The behavior is undefined if `get() == nullptr`.

{/* source:cpp-memory-unique-ptr-operator-star:0003 */}
These member functions are only provided for `unique_ptr` for the single objects i.e. the primary template.

### Parameters

{/* source:cpp-memory-unique-ptr-operator-star:0004 */}
(none)

### Return value

{/* source:cpp-memory-unique-ptr-operator-star:0005 */}
1. 1) Returns the object owned by `*this`, equivalent to `*get()`.

{/* source:cpp-memory-unique-ptr-operator-star:0006 */}
2. 2) Returns a pointer to the object owned by `*this`, i.e. `get()`.

### Exceptions

{/* source:cpp-memory-unique-ptr-operator-star:0007 */}
1. 1) May throw if `pointer` has a throwing `operator*`.

### Notes

{/* source:cpp-memory-unique-ptr-operator-star:0008 */}
The use of [`std::add_lvalue_reference`](/docs/cpp/library/meta/add_reference) is to make it possible to instantiate `std::unique_ptr<void>` since `void&` isn't allowed in C++ while `std::add_lvalue_reference<void>` produces `void`. See [LWG673](https://cplusplus.github.io/LWG/issue673) for details.

### Example

{/* source:cpp-memory-unique-ptr-operator-star:0009 */}
```cpp
#include <iostream>
#include <memory>
 
struct Foo
{
    void bar() { std::cout << "Foo::bar\n"; }
};
 
void f(const Foo&) 
{
    std::cout << "f(const Foo&)\n";
}
 
int main() 
{
    std::unique_ptr<Foo> ptr(new Foo);
 
    ptr->bar();
    f(*ptr);
}
```

Output:

```text
Foo::bar
f(const Foo&)
```
