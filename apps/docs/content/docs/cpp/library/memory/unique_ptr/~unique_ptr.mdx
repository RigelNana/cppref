{/* source:cpp-memory-unique-ptr-unique-ptr:0001 */}
If [`get()`](/docs/cpp/library/memory/unique_ptr/get) == `nullptr` there are no effects. Otherwise, the owned object is destroyed via [`get_deleter()`](/docs/cpp/library/memory/unique_ptr/get_deleter)`(`[`get()`](/docs/cpp/library/memory/unique_ptr/get)`)`.

{/* source:cpp-memory-unique-ptr-unique-ptr:0002 */}
Requires that `get_deleter()(get())` does not throw exceptions.

### Notes

{/* source:cpp-memory-unique-ptr-unique-ptr:0003 */}
Although `std::unique_ptr<T>` with the default deleter may be constructed with [incomplete type](/docs/cpp/language/basic_concepts/incomplete_type) `T`, the type `T` must be complete at the point of code where the destructor is called.

### Example

{/* source:cpp-memory-unique-ptr-unique-ptr:0004 */}
The following program demonstrates usage of a custom deleter.

```cpp
#include <iostream>
#include <memory>
 
int main () 
{
    auto deleter = [](int* ptr)
    {
        std::cout << "[deleter called]\n";
        delete ptr;
    };
 
    std::unique_ptr<int, decltype(deleter)> uniq(new int, deleter);
    std::cout << (uniq ? "not empty\n" : "empty\n");
    uniq.reset();
    std::cout << (uniq ? "not empty\n" : "empty\n");
}
```

Output:

```text
not empty
[deleter called]
empty
```
