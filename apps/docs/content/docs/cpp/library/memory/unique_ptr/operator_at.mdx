{/* source:cpp-memory-unique-ptr-operator-at:0001 */}
`operator[]` provides access to elements of an array managed by a `unique_ptr`.

{/* source:cpp-memory-unique-ptr-operator-at:0002 */}
The parameter `i` shall be less than the number of elements in the array; otherwise, the behavior is undefined.

{/* source:cpp-memory-unique-ptr-operator-at:0003 */}
This member function is only provided for specializations for array types.

### Parameters

{/* source:cpp-memory-unique-ptr-operator-at:0004 */}
<ParameterList>
  <Parameter name="i">the index of the element to be returned</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-unique-ptr-operator-at:0005 */}
Returns the element at index `i`, i.e. [`get()[i]`](/docs/cpp/library/memory/unique_ptr/get).

### Example

{/* source:cpp-memory-unique-ptr-operator-at:0006 */}
```cpp
#include <iostream>
#include <memory>
 
int main() 
{
    const int size = 10; 
    std::unique_ptr<int[]> fact(new int[size]);
 
    for (int i = 0; i < size; ++i)
        fact[i] = (i == 0) ? 1 : i * fact[i - 1];
 
    for (int i = 0; i < size; ++i)
        std::cout << i << "! = " << fact[i] << '\n';
}
```

Output:

```text
0! = 1
1! = 1
2! = 2
3! = 6
4! = 24
5! = 120
6! = 720
7! = 5040
8! = 40320
9! = 362880
```
