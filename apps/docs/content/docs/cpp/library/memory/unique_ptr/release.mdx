{/* source:cpp-memory-unique-ptr-release:0001 */}
Releases the ownership of the managed object, if any.

{/* source:cpp-memory-unique-ptr-release:0002 */}
[`get()`](/docs/cpp/library/memory/unique_ptr/get) returns `nullptr` after the call.

{/* source:cpp-memory-unique-ptr-release:0003 */}
The caller is responsible for cleaning up the object (e.g. by use of [`get_deleter()`](/docs/cpp/library/memory/unique_ptr/get_deleter)).

### Parameters

{/* source:cpp-memory-unique-ptr-release:0004 */}
(none)

### Return value

{/* source:cpp-memory-unique-ptr-release:0005 */}
Pointer to the managed object or `nullptr` if there was no managed object, i.e. the value which would be returned by [`get()`](/docs/cpp/library/memory/unique_ptr/get) before the call.

### Example

{/* source:cpp-memory-unique-ptr-release:0006 */}
```cpp
#include <cassert>
#include <iostream>
#include <memory>
 
struct Foo
{
    Foo() { std::cout << "Foo\n"; }
    ~Foo() { std::cout << "~Foo\n"; }
};
 
// Ownership of the Foo resource is transferred when calling this function
void legacy_api(Foo* owning_foo)
{
    std::cout << __func__ << '\n';
    // [legacy code that no one understands or dares touch anymore]
    // [...]
    delete owning_foo;
}
 
int main()
{
    std::unique_ptr<Foo> managed_foo(new Foo);
    // [code that might return or throw or some such]
    // [...]
    legacy_api(managed_foo.release());
 
    assert(managed_foo == nullptr);
}
```

Output:

```text
Foo
legacy_api
~Foo
```
