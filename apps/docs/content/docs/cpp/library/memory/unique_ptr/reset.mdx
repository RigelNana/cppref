{/* source:cpp-memory-unique-ptr-reset:0001 */}
Replaces the managed object.

{/* source:cpp-memory-unique-ptr-reset:0002 */}
1. 1,2) Equivalent to `auto old_ptr = get();`<br />`/* assigns “ptr” to the stored pointer */`<br />`if (old_ptr)`<br />`    get_deleter()(old_ptr);`.

{/* source:cpp-memory-unique-ptr-reset:0003 */}
If `get_deleter()(old_ptr)` throws an exception, the behavior is undefined.

{/* source:cpp-memory-unique-ptr-reset:0004 */}
2. 2) This overload participates in overload resolution only if `U` is the same type as `pointer`, or all following conditions are satisfied:
   - `pointer` is the same type as `element_type*`.
   - `U` is a pointer type `V*` such that `V(*)[]` is convertible to `element_type(*)[]`.

{/* source:cpp-memory-unique-ptr-reset:0005 */}
3. 3) Equivalent to `reset(pointer())`.

### Parameters

<ParameterList>
  <Parameter name="ptr">pointer to a new object to manage</Parameter>

### Notes

{/* source:cpp-memory-unique-ptr-reset:0007 */}
To replace the managed object while supplying a new deleter as well, move assignment operator may be used.

{/* source:cpp-memory-unique-ptr-reset:0008 */}
A test for self-reset, i.e. whether `ptr` points to an object already managed by `*this`, is not performed, except where provided as a compiler extension or as a debugging assert. Note that code such as `p.reset(p.release())` does not involve self-reset, only code like `p.reset(p.get())` does.

### Example

{/* source:cpp-memory-unique-ptr-reset:0009 */}
```cpp
#include <iostream>
#include <memory>
 
struct Foo // object to manage
{
    Foo() { std::cout << "Foo...\n"; }
    ~Foo() { std::cout << "~Foo...\n"; }
};
 
struct D // deleter
{
    void operator() (Foo* p)
    {
        std::cout << "Calling delete for Foo object... \n";
        delete p;
    }
};
 
int main()
{
    std::cout << "Creating new Foo...\n";
    std::unique_ptr<Foo, D> up(new Foo(), D()); // up owns the Foo pointer (deleter D)
 
    std::cout << "Replace owned Foo with a new Foo...\n";
    up.reset(new Foo());  // calls deleter for the old one
 
    std::cout << "Release and delete the owned Foo...\n";
    up.reset(nullptr);      
}
```

Output:

```text
Creating new Foo...
Foo...
Replace owned Foo with a new Foo...
Foo...
Calling delete for Foo object...
~Foo...
Release and delete the owned Foo...
Calling delete for Foo object...
~Foo...
```
