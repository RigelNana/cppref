{/* source:cpp-memory-uses-allocator-construction-args:0001 */}
Prepares the argument list needed to create an object of the given type `T` by means of [uses-allocator construction](/docs/cpp/library/memory/uses_allocator).

{/* source:cpp-memory-uses-allocator-construction-args:0002 */}
1. 1) This overload participates in overload resolution only if `T` is not a specialization of [`std::pair`](/docs/cpp/library/utility/pair). Returns [`std::tuple`](/docs/cpp/library/utility/tuple) determined as follows:

   - If `std::uses_allocator_v<T, Alloc>` is `false` and `std::is_constructible_v<T, Args...>` is `true`, returns `std::forward_as_tuple(std::forward<Args>(args)...)`.
   - Otherwise, if `std::uses_allocator_v<T, Alloc>` is `true` and `std::is_constructible_v<T, std::allocator_arg_t, const Alloc&, Args...>` is `true`, returns `std::tuple<std::allocator_arg_t, const Alloc&, Args&&...>(std::allocator_arg, alloc,`<br />`                                                          std::forward<Args>(args)...)`.
   - Otherwise, if `std::uses_allocator_v<T, Alloc>` is `true` and `std::is_constructible_v<T, Args..., const Alloc&>` is `true`, returns `std::forward_as_tuple(std::forward<Args>(args)..., alloc)`.
   - Otherwise, the program is ill-formed.

{/* source:cpp-memory-uses-allocator-construction-args:0003 */}
2. 2) This overload participates in overload resolution only if `T` is a specialization of [`std::pair`](/docs/cpp/library/utility/pair). For `T` that is `std::pair<T1, T2>`, equivalent to

   ```cpp
   return std::make_tuple(std::piecewise_construct,
       std::apply([&alloc](auto&&... args1)
           {
               return std::uses_allocator_construction_args<T1>(alloc,
                          std::forward<decltype(args1)>(args1)...);
           }, std::forward<Tuple1>(x)
       ),
       std::apply([&alloc](auto&&... args2)
           {
               return std::uses_allocator_construction_args<T2>(alloc,
                          std::forward<decltype(args2)>(args2)...);
           }, std::forward<Tuple2>(y)
       )
   );
   ```

{/* source:cpp-memory-uses-allocator-construction-args:0004 */}
3. 3) This overload participates in overload resolution only if `T` is a specialization of [`std::pair`](/docs/cpp/library/utility/pair). Equivalent to

   ```cpp
   return std::uses_allocator_construction_args<T>(alloc,
       std::piecewise_construct, std::tuple<>{}, std::tuple<>{}
   );
   ```

{/* source:cpp-memory-uses-allocator-construction-args:0005 */}
4. 4) This overload participates in overload resolution only if `T` is a specialization of [`std::pair`](/docs/cpp/library/utility/pair). Equivalent to

   ```cpp
   return std::uses_allocator_construction_args<T>(alloc,
       std::piecewise_construct,
       std::forward_as_tuple(std::forward<U>(u)),
       std::forward_as_tuple(std::forward<V>(v))
   );
   ```

{/* source:cpp-memory-uses-allocator-construction-args:0006 */}
5. 5,6) This overload participates in overload resolution only if `T` is a specialization of [`std::pair`](/docs/cpp/library/utility/pair). Equivalent to

   ```cpp
   return std::uses_allocator_construction_args<T>(alloc,
       std::piecewise_construct,
       std::forward_as_tuple(pr.first),
       std::forward_as_tuple(pr.second)
   );
   ```

{/* source:cpp-memory-uses-allocator-construction-args:0007 */}
6. 7,8) This overload participates in overload resolution only if `T` is a specialization of [`std::pair`](/docs/cpp/library/utility/pair). Equivalent to

   ```cpp
   return std::uses_allocator_construction_args<T>(alloc,
       std::piecewise_construct,
       std::forward_as_tuple(std::get<0>(std::move(pr))),
       std::forward_as_tuple(std::get<1>(std::move(pr)))
   );
   ```

{/* source:cpp-memory-uses-allocator-construction-args:0008 */}
7. 9) This overload participates in overload resolution only if `T` is a specialization of [`std::pair`](/docs/cpp/library/utility/pair), and given the exposition-only function template

   ```cpp
   template<class A, class B>
   void /*deduce-as-pair*/(const std::pair<A, B>&);
   ```

   , `/*deduce-as-pair*/(non_pair)` is ill-formed when considered as an unevaluated operand.

   Let the exposition-only class *pair-constructor* be defined as

   ```cpp
   class /*pair-constructor*/
   {
       const Alloc& alloc_; // exposition only
       NonPair&     u_;     // exposition only
    
       constexpr reconstruct(const std::remove_cv<T>& p) const // exposition only
       {
           return std::make_obj_using_allocator<std::remove_cv<T>>(alloc_, p);
       }
    
       constexpr reconstruct(std::remove_cv<T>&& p) const // exposition only
       {
           return std::make_obj_using_allocator<std::remove_cv<T>>(alloc_, std::move(p));
       }
    
   public:
       constexpr operator std::remove_cv<T>() const
       {
           return reconstruct(std::forward<NonPair>(u_));
       }
   };
   ```

   This overload is equivalent to `return std::make_tuple(pair_construction);`, where `pair_construction` is a value of type *pair-constructor* whose `alloc_` and `u_` members are `alloc` and `non_pair` respectively.

### Return value

{/* source:cpp-memory-uses-allocator-construction-args:0010 */}
[`std::tuple`](/docs/cpp/library/utility/tuple) of arguments suitable for passing to the constructor of `T`.

### Notes

{/* source:cpp-memory-uses-allocator-construction-args:0011 */}
The overloads (2-9) provide allocator propagation into [`std::pair`](/docs/cpp/library/utility/pair), which supports neither leading-allocator nor trailing-allocator calling conventions (unlike, e.g. [`std::tuple`](/docs/cpp/library/utility/tuple), which uses leading-allocator convention).

{/* source:cpp-memory-uses-allocator-construction-args:0012 */}
When used in uses-allocator construction, the conversion function of *pair-constructor* converts the provided argument to [`std::pair`](/docs/cpp/library/utility/pair) at first, and then constructs the result from that [`std::pair`](/docs/cpp/library/utility/pair) by uses-allocator construction.
