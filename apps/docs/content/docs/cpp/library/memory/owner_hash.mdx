{/* source:cpp-memory-owner-hash:0001 */}
This function object provides owner-based (as opposed to value-based) hashing of both [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr) and [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr).

## std::owner_hash::operator()

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++26" code={`template< class T >

</DeclarationDoc>

Equivalent to `return key.owner_hash();`.

### Parameters

<ParameterList>
  <Parameter name="key">shared-ownership pointer to be hashed</Parameter>
</ParameterList>

### Return value

A hash value that is identical for any [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr) or [`std::weak_ptr`](/docs/cpp/library/memory/weak_ptr) object sharing the same ownership.
