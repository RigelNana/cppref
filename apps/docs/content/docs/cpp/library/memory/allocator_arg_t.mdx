{/* source:cpp-memory-allocator-arg-t:0001 */}
1. 1) `std::allocator_arg_t` is an empty class type used to disambiguate the overloads of constructors and member functions of allocator-aware objects, including [`std::tuple`](/docs/cpp/library/utility/tuple)<InlineRevision until="C++17">, [`std::function`](/docs/cpp/library/utility/functional/function), [`std::packaged_task`](/docs/cpp/library/atomic/packaged_task),</InlineRevision> and [`std::promise`](/docs/cpp/library/atomic/promise).

{/* source:cpp-memory-allocator-arg-t:0002 */}
2. 2) `std::allocator_arg` is an instance of ([1](/docs/cpp/library/memory/allocator_arg_t#Version_1)) that can be passed to the constructors and member functions of such permitted types.
