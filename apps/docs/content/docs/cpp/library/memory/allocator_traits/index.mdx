{/* source:cpp-memory-allocator-traits:0001 */}
The `allocator_traits` class template provides the standardized way to access various properties of [*Allocator*s](/docs/cpp/library/named_req/Allocator). The standard containers and other standard library components access allocators through this template, which makes it possible to use any class type as an allocator, as long as the user-provided specialization of `std::allocator_traits` implements all required functionality.

{/* source:cpp-memory-allocator-traits:0002 */}
<Revision since="C++23">
A program that declares an explicit or partial specialization of `std::allocator_traits` is ill-formed, no diagnostic required.
</Revision>

{/* source:cpp-memory-allocator-traits:0003 */}
