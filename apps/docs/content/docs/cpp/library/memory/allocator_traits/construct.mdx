  <Declaration language="cpp" since="C++11" code={`template< class T, class... Args >
static void construct( Alloc& a, T* p, Args&&... args );`} />
  <InlineRevision since="C++20">constexpr</InlineRevision>

{/* source:cpp-memory-allocator-traits-construct:0001 */}
If possible, constructs an object of type `T` in allocated uninitialized storage pointed to by `p`, by calling `a.construct(p, std::forward<Args>(args)...)`.

{/* source:cpp-memory-allocator-traits-construct:0002 */}
If the above is not possible (e.g. `Alloc` does not have the member function `construct()`), then calls

{/* source:cpp-memory-allocator-traits-construct:0003 */}
<Revision until="C++20">
`::new (static_cast<void*>(p)) T(std::forward<Args>(args)...)`
</Revision>

<Revision since="C++20">
`std::construct_at(p, std::forward<Args>(args)...)`
</Revision>

### Parameters

{/* source:cpp-memory-allocator-traits-construct:0004 */}
<ParameterList>
  <Parameter name="a">allocator to use for construction</Parameter>
  <Parameter name="p">pointer to the uninitialized storage on which a `T` object will be constructed</Parameter>
  <Parameter name="args...">the constructor arguments to pass to `a.construct()` or to <InlineRevision until="C++20">placement-new</InlineRevision><InlineRevision since="C++20">[`std::construct_at()`](/docs/cpp/library/memory/construct_at)</InlineRevision></Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-allocator-traits-construct:0005 */}
(none)

### Notes

{/* source:cpp-memory-allocator-traits-construct:0006 */}
This function is used by the standard library containers when inserting, copying, or moving elements.

{/* source:cpp-memory-allocator-traits-construct:0007 */}
Because this function provides the automatic fall back to placement new, the member function `construct()` is an optional [*Allocator*](/docs/cpp/library/named_req/Allocator) requirement since C++11.
