{/* source:cpp-memory-allocator-traits-destroy:0001 */}
Calls the destructor of the object pointed to by `p`. If possible, does so by calling `a.destroy(p)`. If not possible (e.g. `Alloc` does not have the member function `destroy()`), then calls <InlineRevision until="C++20">the destructor of `*p` directly, as `p->~T()`</InlineRevision><InlineRevision since="C++20">`std::destroy_at(p)`</InlineRevision>.

### Parameters

{/* source:cpp-memory-allocator-traits-destroy:0002 */}
<ParameterList>
  <Parameter name="a">allocator to use for destruction</Parameter>
  <Parameter name="p">pointer to the object being destroyed</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-allocator-traits-destroy:0003 */}
(none)

### Notes

{/* source:cpp-memory-allocator-traits-destroy:0004 */}
Because this function provides the automatic fall back to direct call to the destructor, the member function `destroy()` is an optional [*Allocator*](/docs/cpp/library/named_req/Allocator) requirement since C++11.
