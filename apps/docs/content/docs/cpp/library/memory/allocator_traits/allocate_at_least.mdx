{/* source:cpp-memory-allocator-traits-allocate-at-least:0001 */}
`allocate_at_least` calls `a.allocate_at_least(n)` and returns its result if the call is well-formed, otherwise, it is equivalent to `return {a.allocate(n), n};`.

{/* source:cpp-memory-allocator-traits-allocate-at-least:0002 */}
`allocator_at_least` tries to allocate a storage for at least `n` `value_type` objects, and provides a fallback mechanism that allocates a storage for exact `n` objects.

### Parameters

{/* source:cpp-memory-allocator-traits-allocate-at-least:0003 */}
<ParameterList>
  <Parameter name="a">an allocator used for allocating storage</Parameter>
  <Parameter name="n">the lower bound of number of objects to allocate storage for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-memory-allocator-traits-allocate-at-least:0004 */}
`a.allocate_at_least(n)` if it is well-formed.

{/* source:cpp-memory-allocator-traits-allocate-at-least:0005 */}
Otherwise, `std::allocation_result<pointer, size_type>{a.allocate(n), n}`.

### Exceptions

{/* source:cpp-memory-allocator-traits-allocate-at-least:0006 */}
Throws what and when the selected allocation function throws.

### Notes

{/* source:cpp-memory-allocator-traits-allocate-at-least:0007 */}
The `allocate_at_least` member function of [*Allocator*](/docs/cpp/library/named_req/Allocator) types are mainly provided for contiguous containers, e.g. [`std::vector`](/docs/cpp/library/container/vector) and [`std::basic_string`](/docs/cpp/library/string/basic_string), in order to reduce reallocation by making their capacity match the actually allocated size when possible. Because `allocate_at_least` provides a fallback mechanism, it can be directly used where appropriate.

{/* source:cpp-memory-allocator-traits-allocate-at-least:0008 */}
Given an allocator object `a` of type `Alloc`, let `result` denote the value returned from `std::allocator_traits<Alloc>::allocate_at_least(a, n)`, the storage should be deallocated by `a.deallocate(result.ptr, m)` (typically called via `std::allocator_traits<Alloc>::deallocate(a, result.ptr, m)`) in order to avoid memory leak.

{/* source:cpp-memory-allocator-traits-allocate-at-least:0009 */}
The argument `m` used in deallocation must be not less than `n` and not greater than `result.count`, otherwise, the behavior is undefined. Note that `n` is always equal to `result.count` if the allocator does not provide `allocate_at_least`, which means that `m` is required to be equal to `n`.
