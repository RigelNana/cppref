Uses the allocator `a` to deallocate the storage referenced by `p`, by calling `a.deallocate(p, n)`.

### Parameters

{/* source:cpp-memory-allocator-traits-deallocate:0002 */}
<ParameterList>
  <Parameter name="a">allocator to use</Parameter>
  <Parameter name="p">pointer to the previously allocated storage</Parameter>
  <Parameter name="n">the number of objects the storage was allocated for</Parameter>
</ParameterList>
