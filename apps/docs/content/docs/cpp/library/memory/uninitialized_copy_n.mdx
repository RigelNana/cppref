{/* source:cpp-memory-uninitialized-copy-n:0001 */}
1. 1) Copies `count` elements from a range beginning at `first` to an uninitialized memory area beginning at `d_first` as if by `for (; count > 0; ++d_first, (void) ++first, --count)` `::new (`[`voidify`](/docs/cpp/library/memory/voidify)`(*d_first))` `typename std::iterator_traits<NoThrowForwardIt>::value_type(*first);`

{/* source:cpp-memory-uninitialized-copy-n:0002 */}
2. If an exception is thrown during the initialization, the objects already constructed are destroyed in an unspecified order.

{/* source:cpp-memory-uninitialized-copy-n:0003 */}
3. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-memory-uninitialized-copy-n:0004 */}
4. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">[`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

   <Revision since="C++20">[`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>`](/docs/cpp/library/algorithm/is_execution_policy) is `true`.</Revision>

{/* source:cpp-memory-uninitialized-copy-n:0005 */}
<Revision since="C++20">If `d_first` + [`0`, `count`) overlaps with `first` + [`0`, `count`), the behavior is undefined.</Revision>

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-memory-uninitialized-copy-n:0007 */}
Iterator to the element past the last element copied.

### Complexity

{/* source:cpp-memory-uninitialized-copy-n:0008 */}
Linear in `count`.

### Exceptions

{/* source:cpp-memory-uninitialized-copy-n:0009 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-memory-uninitialized-copy-n:0010 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-memory-uninitialized-copy-n:0012 */}
[`uninitialized_copy_n (1)`](/docs/cpp/library/memory/uninitialized_copy_n#Version_1)

```cpp
template<class InputIt, class Size, class NoThrowForwardIt>
constexpr NoThrowForwardIt uninitialized_copy_n(InputIt first, Size count,
                                                NoThrowForwardIt d_first)
{
    using T = typename std::iterator_traits<NoThrowForwardIt>::value_type;
    NoThrowForwardIt current = d_first;
    try
    {
        for (; count > 0; ++first, (void) ++current, --count)
            ::new (static_cast<void*>(std::addressof(*current))) T(*first);
    }
    catch (...)
    {
        for (; d_first != current; ++d_first)
            d_first->~T();
        throw;
    }
    return current;
}```

### Example

{/* source:cpp-memory-uninitialized-copy-n:0013 */}
```cpp
#include <algorithm>
#include <iostream>
#include <memory>
#include <string>
#include <tuple>
#include <vector>
 
int main()
{
    std::vector<std::string> v = {"This", "is", "an", "example"};
 
    std::string* p;
    std::size_t sz;
    std::tie(p, sz) = std::get_temporary_buffer<std::string>(v.size());
    sz = std::min(sz, v.size());
 
    std::uninitialized_copy_n(v.begin(), sz, p);
 
    for (std::string* i = p; i != p + sz; ++i)
    {
        std::cout << *i << ' ';
        i->~basic_string<char>();
    }
    std::cout << '\n';
 
    std::return_temporary_buffer(p);
}```
