{/* source:cpp-memory-memory-resource-do-is-equal:0001 */}
Compares `*this` for equality with `other`.

{/* source:cpp-memory-memory-resource-do-is-equal:0002 */}
Two `memory_resource`s compare equal if and only if memory allocated from one `memory_resource` can be deallocated from the other and vice versa.

### Notes

{/* source:cpp-memory-memory-resource-do-is-equal:0003 */}
The most-derived type of `other` may not match the most derived type of `*this`. A derived class implementation therefore must typically check whether the most derived types of `*this` and `other` match using [`dynamic_cast`](/docs/cpp/language/expressions/dynamic_cast), and immediately return `false` if the cast fails.
