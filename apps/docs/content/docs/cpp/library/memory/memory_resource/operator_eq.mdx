{/* source:cpp-memory-memory-resource-operator-eq:0001 */}
Compares the `memory_resource`s `a` and `b` for equality. Two `memory_resource`s compare equal if and only if memory allocated from one `memory_resource` can be deallocated from the other and vice versa.

{/* source:cpp-memory-memory-resource-operator-eq:0002 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Return value

{/* source:cpp-memory-memory-resource-operator-eq:0003 */}
1. 1) `&a == &b || a.is_equal(b)`

{/* source:cpp-memory-memory-resource-operator-eq:0004 */}
2. 2) `!(a == b)`
