{/* source:cpp-memory-enable-shared-from-this-enable-shared-from-this:0001 */}
Constructs a new `enable_shared_from_this` object. [`weak_this`](/docs/cpp/library/memory/enable_shared_from_this#weak_this) is [value-initialized](/docs/cpp/language/initialization/value_initialization).

### Parameters

{/* source:cpp-memory-enable-shared-from-this-enable-shared-from-this:0002 */}
<ParameterList>
  <Parameter name="other">an `enable_shared_from_this` to copy</Parameter>
</ParameterList>

### Notes

{/* source:cpp-memory-enable-shared-from-this-enable-shared-from-this:0003 */}
There is no move constructor: moving from an object derived from `enable_shared_from_this` does not transfer its shared identity.

### Example

{/* source:cpp-memory-enable-shared-from-this-enable-shared-from-this:0004 */}
```cpp
#include <memory>
 
struct Foo : public std::enable_shared_from_this<Foo>
{
    Foo() {} // implicitly calls enable_shared_from_this constructor
    std::shared_ptr<Foo> getFoo() { return shared_from_this(); }
};
 
int main()
{
    std::shared_ptr<Foo> pf1(new Foo);
    auto pf2 = pf1->getFoo(); // shares ownership of object with pf1
}
```
