{/* source:cpp-memory-enable-shared-from-this-shared-from-this:0001 */}
Returns a `std::shared_ptr<T>` that shares ownership of `*this` with all existing `std::shared_ptr` that refer to `*this`.

### Return value

{/* source:cpp-memory-enable-shared-from-this-shared-from-this:0002 */}
`std::shared_ptr<T>(`[`weak_this`](/docs/cpp/library/memory/enable_shared_from_this#weak_this)`)`

### Exceptions

{/* source:cpp-memory-enable-shared-from-this-shared-from-this:0003 */}
If `shared_from_this` is called on an object that is not previously shared by [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr), [`std::bad_weak_ptr`](/docs/cpp/library/memory/bad_weak_ptr) is thrown by the `std::shared_ptr` constructor.

### Example

{/* source:cpp-memory-enable-shared-from-this-shared-from-this:0004 */}
```cpp
#include <iostream>
#include <memory>
 
struct Foo : public std::enable_shared_from_this<Foo>
{
    Foo() { std::cout << "Foo::Foo\n"; }
    ~Foo() { std::cout << "Foo::~Foo\n"; } 
    std::shared_ptr<Foo> getFoo() { return shared_from_this(); }
};
 
int main()
{
    Foo *f = new Foo;
    std::shared_ptr<Foo> pf1;
 
    {
        std::shared_ptr<Foo> pf2(f);
        pf1 = pf2->getFoo(); // shares ownership of object with pf2
    }
 
    std::cout << "pf2 is gone\n";   
}
```

Output:

```text
Foo::Foo
pf2 is gone
Foo::~Foo
```
