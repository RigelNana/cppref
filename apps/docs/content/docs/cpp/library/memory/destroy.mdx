{/* source:cpp-memory-destroy:0001 */}
1. 1) Destroys the objects in the range `[first, last)`, as if by

   ```cpp
   for (; first != last; ++first)
       std::destroy_at(std::addressof(*first));
   ```

{/* source:cpp-memory-destroy:0002 */}
2. 2) Same as (1), but executed according to `policy`. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

### Parameters

{/* source:cpp-memory-destroy:0003 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to destroy</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
</ParameterList>

Type requirements

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).
- No increment, assignment, comparison, or indirection through valid instances of `ForwardIt` may throw exceptions.

### Return value

{/* source:cpp-memory-destroy:0004 */}
(none)

### Complexity

{/* source:cpp-memory-destroy:0005 */}
Linear in the distance between `first` and `last`.

### Exceptions

{/* source:cpp-memory-destroy:0006 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-memory-destroy:0007 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Possible implementation

{/* source:cpp-memory-destroy:0008 */}
```cpp
template<class ForwardIt>
constexpr // since C++20
void destroy(ForwardIt first, ForwardIt last)
{
    for (; first != last; ++first)
        std::destroy_at(std::addressof(*first));
}
```

### Example

{/* source:cpp-memory-destroy:0009 */}
The following example demonstrates how to use `destroy` to destroy a contiguous sequence of elements.

{/* source:cpp-memory-destroy:0010 */}
```cpp
#include <iostream>
#include <memory>
#include <new>
 
struct Tracer
{
    int value;
    ~Tracer() { std::cout << value << " destructed\n"; }
};
 
int main()
{
    alignas(Tracer) unsigned char buffer[sizeof(Tracer) * 8];
 
    for (int i = 0; i < 8; ++i)
        new(buffer + sizeof(Tracer) * i) Tracer{i}; //manually construct objects
 
    auto ptr = std::launder(reinterpret_cast<Tracer*>(buffer));
 
    std::destroy(ptr, ptr + 8);
}
```

Output:

```text
0 destructed
1 destructed
2 destructed
3 destructed
4 destructed
5 destructed
6 destructed
7 destructed
```
