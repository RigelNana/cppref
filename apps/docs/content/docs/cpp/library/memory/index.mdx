### Smart pointers (since C++11)

{/* source:cpp-memory:0000 */}
Smart pointers enable automatic, exception-safe, object lifetime management.

{/* source:cpp-memory:0001 */}
Defined in header [`<memory>`](/docs/cpp/library/headers/memory)

  <DescriptionItem>
