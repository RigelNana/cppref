{/* source:cpp-memory-get-default-resource:0001 */}
Gets the default memory resource pointer.

{/* source:cpp-memory-get-default-resource:0002 */}
The default memory resource pointer is used by certain facilities when an explicit memory resource is not supplied. The initial default memory resource pointer is the return value of [`std::pmr::new_delete_resource`](/docs/cpp/library/memory/new_delete_resource).

{/* source:cpp-memory-get-default-resource:0003 */}
This function is thread-safe. Previous call to [`std::pmr::set_default_resource`](/docs/cpp/library/memory/set_default_resource) synchronizes with (see [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) the subsequent `std::pmr::get_default_resource` calls.

### Return value

{/* source:cpp-memory-get-default-resource:0004 */}
Returns the value of the default memory resource pointer.
