{/* source:cpp-iterator-projected:0001 */}
1. 1) <InlineRevision until="C++26">Class</InlineRevision> <InlineRevision since="C++26">Alias</InlineRevision> template `projected` combines an [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) type `I` and a callable object type `Proj` into a new `indirectly_readable` type whose reference type is the result of applying `Proj` to the `std::iter_reference_t<I>`.

{/* source:cpp-iterator-projected:0002 */}
2. 2) This specialization of [`std::incrementable_traits`](/docs/cpp/library/iterator/incrementable_traits) makes `std::projected<I, Proj>` a [`weakly_incrementable`](/docs/cpp/library/iterator/weakly_incrementable) type when `I` is also a `weakly_incrementable` type.

{/* source:cpp-iterator-projected:0003 */}
3. 3) An indirect layer used for avoiding unexpected [argument-dependent lookup](/docs/cpp/language/functions/adl). The member type `difference_type` exists only if `I` models [`weakly_incrementable`](/docs/cpp/library/iterator/weakly_incrementable).

{/* source:cpp-iterator-projected:0004 */}
`projected` is used only to constrain algorithms that accept callable objects and projections, and hence its `operator*()` is not defined.

### Template parameters

{/* source:cpp-iterator-projected:0005 */}
<ParameterList>
  <Parameter name="I">an indirectly readable type</Parameter>
  <Parameter name="Proj">projection applied to a dereferenced `I`</Parameter>
</ParameterList>

### Notes

{/* source:cpp-iterator-projected:0006 */}
The indirect layer prevents `I` and `Proj` to be associated classes of `projected`. When an associated class of `I` or `Proj` is an incomplete class type, the indirect layer avoids the unnecessary attempt to inspect the definition of that type that results in hard error.

### Example

{/* source:cpp-iterator-projected:0007 */}
```cpp
#include <algorithm>
#include <cassert>
#include <functional>
#include <iterator>

template<class T>
struct Holder
{
    T t;
};

struct Incomplete;

using P = Holder<Incomplete>*;

static_assert(std::equality_comparable<P>); // OK
static_assert(std::indirectly_comparable<P*, P*, std::equal_to<>>); // Error before C++26
static_assert(std::sortable<P*>); // Error before C++26

int main()
{
    P a[10] = {}; // ten null pointers
    assert(std::count(a, a + 10, nullptr) == 10); // OK
    assert(std::ranges::count(a, a + 10, nullptr) == 10); // Error before C++26
}
```
