{/* source:cpp-iterator-ranges-iter-move:0001 */}
Obtains an rvalue reference or a prvalue temporary from a given iterator.

{/* source:cpp-iterator-ranges-iter-move:0002 */}
A `ranges::iter_move(t)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

{/* source:cpp-iterator-ranges-iter-move:0003 */}
1. `iter_move(t)`, if `t` has a class or enumeration type and the expression is well-formed when treated as an [unevaluated operand](/docs/cpp/language/expressions#Potentially-evaluated_expressions), where the [overload resolution](/docs/cpp/language/functions/overload_resolution) of `iter_move` is performed only with the candidates found by [argument-dependent lookup](/docs/cpp/language/functions/adl).
2. Otherwise, `std::move(*t)` if `*t` is well-formed and is an lvalue.
3. Otherwise, `*t` if `*t` is well-formed and is an rvalue.

{/* source:cpp-iterator-ranges-iter-move:0004 */}
In all other cases, a call to `ranges::iter_move` is ill-formed, which can result in [substitution failure](/docs/cpp/language/templates/sfinae) when `ranges::iter_move(e)` appears in the immediate context of a template instantiation.

{/* source:cpp-iterator-ranges-iter-move:0005 */}
If `ranges::iter_move(e)` is not equal to `*e`, the program is ill-formed, no diagnostic required.

### Customization point objects

{/* source:cpp-iterator-ranges-iter-move:0006 */}
The name `ranges::iter_move` denotes a *customization point object*, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as `__iter_move_fn`.

{/* source:cpp-iterator-ranges-iter-move:0007 */}
All instances of `__iter_move_fn` are equal. The effects of invoking different instances of type `__iter_move_fn` on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `ranges::iter_move` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-iterator-ranges-iter-move:0008 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `ranges::iter_move` above, `__iter_move_fn` models

{/* source:cpp-iterator-ranges-iter-move:0009 */}
- `std::invocable<__iter_move_fn, Args...>`,
- `std::invocable<const __iter_move_fn, Args...>`,
- `std::invocable<__iter_move_fn&, Args...>`, and
- `std::invocable<const __iter_move_fn&, Args...>`.

{/* source:cpp-iterator-ranges-iter-move:0010 */}
Otherwise, no function call operator of `__iter_move_fn` participates in overload resolution.
