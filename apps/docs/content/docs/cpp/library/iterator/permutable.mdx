  <Declaration language="cpp" code={`template< class I >
concept permutable =
    std::forward_iterator<I> &&
    std::indirectly_movable_storable<I, I> &&

    std::indirectly_swappable<I, I>;`} />

{/* source:cpp-iterator-permutable:0001 */}
The concept `permutable` refines [`std::forward_iterator`](/docs/cpp/library/iterator/forward_iterator) by adding requirements for reordering through moves and swaps.

### Semantic requirements

{/* source:cpp-iterator-permutable:0002 */}
`I` models `permutable` only if all concepts it subsumes are modeled.
