{/* source:cpp-iterator-indirect-result-t:0001 */}
The alias template `indirect_result_t` obtains the result type of invoking an [invocable](/docs/cpp/library/concepts/invocable) type `F` on the result of dereferencing [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) types `Is...`.

### Template parameters

{/* source:cpp-iterator-indirect-result-t:0002 */}
<ParameterList>
  <Parameter name="F">an invocable type</Parameter>
  <Parameter name="Is">indirectly readable types that are dereferenced to arguments</Parameter>
</ParameterList>

### Example

{/* source:cpp-iterator-indirect-result-t:0003 */}
```cpp
#include <iterator>
#include <type_traits>

struct Fn
{
    long operator()(const int&);
    int operator()(int&&);
    short operator()(int, int) const;
    auto operator()(const float) -> int&;
    void operator()(int[8]);
};

static_assert(
    std::is_same_v<std::indirect_result_t<Fn, const int*>, long> and
    std::is_same_v<std::indirect_result_t<Fn, std::move_iterator<int*>>, int> and
    std::is_same_v<std::indirect_result_t<const Fn, int*, int*>, short> and
    std::is_same_v<std::indirect_result_t<Fn, float*>, int&> and
    std::is_same_v<std::indirect_result_t<Fn, int**>, void>
);

int main() {}
```
