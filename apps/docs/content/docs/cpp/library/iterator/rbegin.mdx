{/* source:cpp-iterator-rbegin:0001 */}
Returns an iterator to the reverse-beginning of the given range.

{/* source:cpp-iterator-rbegin:0002 */}
1,2) Returns `c.rbegin()`, which is typically an iterator to the reverse-beginning of the sequence represented by `c`.

{/* source:cpp-iterator-rbegin:0003 */}
1) If `C` is a standard [`Container`](/docs/cpp/library/named_req/Container), returns a `C::reverse_iterator` object.

{/* source:cpp-iterator-rbegin:0004 */}
2) If `C` is a standard `Container`, returns a `C::const_reverse_iterator` object.

{/* source:cpp-iterator-rbegin:0005 */}
3) Returns a `std::reverse_iterator<T*>` object to the reverse-beginning of `array`.

{/* source:cpp-iterator-rbegin:0006 */}
4) Returns a `std::reverse_iterator<const T*>` object to the reverse-beginning of `il`.

{/* source:cpp-iterator-rbegin:0007 */}
5) Returns `std::rbegin(c)`, with `c` always treated as const-qualified.

{/* source:cpp-iterator-rbegin:0008 */}
If `C` is a standard `Container`, returns a `C::const_reverse_iterator` object.

### Parameters

{/* source:cpp-iterator-rbegin:0009 */}
<ParameterList>
  <Parameter name="c">a container or view with a rbegin member function</Parameter>
  <Parameter name="array">an array of arbitrary type</Parameter>
  <Parameter name="il">an `std::initializer_list`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-rbegin:0010 */}
1,2) `c.rbegin()`

{/* source:cpp-iterator-rbegin:0011 */}
3) `std::reverse_iterator<T*>(array + N)`

{/* source:cpp-iterator-rbegin:0012 */}
4) `std::reverse_iterator<const T*>(il.end())`

{/* source:cpp-iterator-rbegin:0013 */}
5) `c.rbegin()`

### Exceptions

{/* source:cpp-iterator-rbegin:0014 */}
May throw implementation-defined exceptions.

### Overloads

{/* source:cpp-iterator-rbegin:0015 */}
Custom overloads of `rbegin` may be provided for classes and enumerations that do not expose a suitable `rbegin()` member function, yet can be iterated.

{/* source:cpp-iterator-rbegin:0016 */}
<Revision since="C++20">
Overloads of `rbegin` found by [argument-dependent lookup](/docs/cpp/language/functions/adl) can be used to customize the behavior of `std::ranges::rbegin` and [`std::ranges::crbegin`](/docs/cpp/library/ranges/crbegin).
</Revision>

### Notes

{/* source:cpp-iterator-rbegin:0017 */}
The overload for [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) is necessary because it does not have a member function `rbegin`.

### Example

{/* source:cpp-iterator-rbegin:0018 */}
```cpp
#include <iostream>
#include <iterator>
#include <vector>
 
int main()
{
    std::vector<int> v = {3, 1, 4};
    auto vi = std::rbegin(v); // the type of “vi” is std::vector<int>::reverse_iterator
    std::cout << "*vi = " << *vi << '\n';
 
    *std::rbegin(v) = 42; // OK: after assignment v[2] == 42
//  *std::crbegin(v) = 13; // error: the location is read-only
 
    int a[] = {-5, 10, 15};
    auto ai = std::rbegin(a); // the type of “ai” is std::reverse_iterator<int*>
    std::cout << "*ai = " << *ai << '\n';
 
    auto il = {3, 1, 4};
    // the type of “it” below is std::reverse_iterator<int const*>:
    for (auto it = std::rbegin(il); it != std::rend(il); ++it)
        std::cout << *it << ' ';
    std::cout << '\n';
}
```

Output:

```text
*vi = 4
*ai = 15
4 1 3
```
