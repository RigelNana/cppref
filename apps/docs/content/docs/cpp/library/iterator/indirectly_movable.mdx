{/* source:cpp-iterator-indirectly-movable:0001 */}
The `indirectly_movable` concept specifies the relationship between an [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) type and a type that is [`indirectly_writable`](/docs/cpp/library/iterator/indirectly_writable). The `indirectly_writable` type must be able to directly move the object that the `indirectly_readable` type references.
