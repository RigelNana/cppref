{/* source:cpp-iterator-counted-iterator-count:0001 */}
Returns the underlying `length` that is the distance to the end.

### Parameters

{/* source:cpp-iterator-counted-iterator-count:0002 */}
(none)

### Return value

{/* source:cpp-iterator-counted-iterator-count:0003 */}
The underlying `length`.

### Example

{/* source:cpp-iterator-counted-iterator-count:0004 */}
```cpp
#include <cassert>
#include <iostream>
#include <iterator>
 
int main()
{
    constexpr static auto il = {1, 2, 3, 4, 5};
    constexpr std::counted_iterator i1{il.begin() + 1, 3};
    static_assert(i1.count() == 3);
    auto i2{i1};
    for (; std::default_sentinel != i2; ++i2)
        std::cout << "*i2: " << *i2 << ", count(): " << i2.count() << '\n';
    assert(i2.count() == 0);
}
```

Output:

```text
*i2: 2, count(): 3
*i2: 3, count(): 2
*i2: 4, count(): 1
```
