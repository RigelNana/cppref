{/* source:cpp-iterator-counted-iterator-operator:0001 */}
The underlying iterator and length are assigned with those of `other`.

### Parameters

{/* source:cpp-iterator-counted-iterator-operator:0002 */}
<ParameterList>
  <Parameter name="other">iterator adaptor to assign from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-counted-iterator-operator:0003 */}
`*this`

### Example

{/* source:cpp-iterator-counted-iterator-operator:0004 */}
```cpp
#include <algorithm>
#include <cassert>
#include <initializer_list>
#include <iterator>
 
int main()
{
    auto a = {3, 1, 4, 1, 5, 9, 2};
    std::counted_iterator<std::initializer_list<int>::iterator> p(begin(a), size(a) - 2);
    std::counted_iterator<std::initializer_list<int>::iterator> q;
    assert(q.count() == 0);
    assert(q.count() != p.count());
    q = p;
    assert(q.count() == p.count());
    assert(std::ranges::equal(p, std::default_sentinel, q, std::default_sentinel));
}
```
