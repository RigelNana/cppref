  {/* source:cpp-iterator-counted-iterator-counted-iterator:0001 */}
  Constructs a new iterator adaptor.

  <DeclarationDescription>
    {/* source:cpp-iterator-counted-iterator-counted-iterator:0002 */}
    1. 1) Default constructor. [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) the underlying iterator and initialized the underlying `length` with `0`. Operations on the resulting iterator have defined behavior if and only if the corresponding operations on a value-initialized `I` also have defined behavior.

    {/* source:cpp-iterator-counted-iterator-counted-iterator:0003 */}
    2. 2) The underlying iterator is initialized with `std::move(x)` and the underlying length is initialized with `n`. The behavior is undefined if `n` is negative.

    {/* source:cpp-iterator-counted-iterator-counted-iterator:0004 */}
    3. 3) The underlying iterator and length are initialized with those of `other`.
  </DeclarationDescription>
</DeclarationDoc>

### Example

{/* source:cpp-iterator-counted-iterator-counted-iterator:0006 */}
```cpp
#include <algorithm>
#include <initializer_list>
#include <iostream>
#include <iterator>
 
int main()
{
    static constexpr auto pi = {3, 1, 4, 1, 5, 9, 2};
 
    // (1) default constructor:
    constexpr std::counted_iterator<std::initializer_list<int>::iterator> i1{};
    static_assert(i1 == std::default_sentinel);
    static_assert(i1.count() == 0);
 
    // (2) initializes the iterator and length respectively:
    constexpr std::counted_iterator<std::initializer_list<int>::iterator> i2{
        pi.begin(), pi.size() - 2
    };
    static_assert(i2.count() == 5);
    static_assert(*i2 == 3 && i2[1] == 1);
 
    // (3) converting-constructor:
    std::counted_iterator<std::initializer_list<const int>::iterator> i3{i2};
 
    std::ranges::copy(i3, std::default_sentinel,
        std::ostream_iterator<const int>{std::cout, " "});
}
```

Output:

```text
3 1 4 1 5
```
