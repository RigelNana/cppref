  <Declaration id="2" language="cpp" since="C++20" code={`constexpr decltype(auto) operator*() const
    requires /*dereferenceable*/<const I>;`} />
  <Declaration id="3" language="cpp" since="C++20" code={`constexpr auto operator->() const noexcept
    requires std::contiguous_iterator<I>;`} />

  <DeclarationDescription>
    {/* source:cpp-iterator-counted-iterator-operator-star:0001 */}
    1. 1,2) Returns a reference to the current element. The behavior is undefined if `this->count() <= 0`. The function's body is equivalent to `return *current;`.

    {/* source:cpp-iterator-counted-iterator-operator-star:0002 */}
    2. 3) Returns a pointer to the current element. The function's body is equivalent to `return std::to_address(current);`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-iterator-counted-iterator-operator-star:0003 */}
(none)

### Return value

{/* source:cpp-iterator-counted-iterator-operator-star:0004 */}
Reference or pointer to the current element.

### Example

{/* source:cpp-iterator-counted-iterator-operator-star:0005 */}
```cpp
#include <complex>
#include <iostream>
#include <iterator>
 
using std::operator""i;
 
int main()
{
    const auto il = {1.i, 2.i, 3.i, 4.i, 5.i};
 
    for (std::counted_iterator i{il.begin() + 1, 3}; i != std::default_sentinel; ++i)
        std::cout << *i << ' ';
    std::cout << '\n';
 
    for (std::counted_iterator i{il.begin() + 1, 3}; i != std::default_sentinel; ++i)
        std::cout << i->imag() << ' ';
    std::cout << '\n';
}
```

Output:

```text
(0,2) (0,3) (0,4)
2 3 4
```
