{/* source:cpp-iterator-counted-iterator-operator:0001 */}
Computes the distance between two iterator adaptors.

{/* source:cpp-iterator-counted-iterator-operator:0002 */}
The behavior is undefined if `x` and `y` do not point to elements of the same sequence. That is, there must exist some `n` such that `std::next(x.base(), x.count() + n)` and `std::next(y.base(), y.count() + n)` refer to the same element.

{/* source:cpp-iterator-counted-iterator-operator:0003 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::counted_iterator<I>` is an associated class of the arguments.

### Parameters

{/* source:cpp-iterator-counted-iterator-operator:0004 */}
<ParameterList>
  <Parameter name="x, y">iterator adaptors to compute the difference of</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-counted-iterator-operator:0005 */}
`y.count() - x.count()`

### Notes

{/* source:cpp-iterator-counted-iterator-operator:0006 */}
Since the length counts down, not up, the order of the arguments of `operator-` in the underlying expression is reversed, i.e. `y` is lhs and `x` is rhs.

### Example

{/* source:cpp-iterator-counted-iterator-operator:0007 */}
```cpp
#include <initializer_list>
#include <iterator>
 
int main()
{
    static constexpr auto v = {1, 2, 3, 4, 5, 6};
    constexpr std::counted_iterator<std::initializer_list<int>::iterator>
        it1{v.begin(), 5},
        it2{it1 + 3},
        it3{v.begin(), 2};
 
    static_assert(it1 - it2 == -3);
    static_assert(it2 - it1 == +3);
//  static_assert(it1 - it3 == -3); // UB: operands of operator- do not refer to
                                    // elements of the same sequence
}
```
