{/* source:cpp-iterator-counted-iterator-operator-at:0001 */}
Accesses the element at specified relative location. The behavior is undefined if `n` is not less than the recorded distance to the end.

### Parameters

{/* source:cpp-iterator-counted-iterator-operator-at:0002 */}
<ParameterList>
  <Parameter name="n">position relative to current location</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-counted-iterator-operator-at:0003 */}
`this->base()[n]`

### Example

{/* source:cpp-iterator-counted-iterator-operator-at:0004 */}
```cpp
#include <array>
#include <iostream>
#include <iterator>
#include <list>
 
int main()
{
    std::array array{'A', 'B', 'C', 'D', 'E'};
 
    std::counted_iterator it{array.begin() + 1, /*count:*/ 3};
 
    for (int i{}; i != it.count(); ++i)
        std::cout << it[i] << ' ';
    std::cout << '\n';
 
    for (int i{}; i != it.count(); ++i)
        it[i] += ('E' - 'A');
 
    for (int i{}; i != it.count(); ++i)
        std::cout << it[i] << ' ';
    std::cout << '\n';
 
    std::list list{'X', 'Y', 'Z', 'W'};
    std::counted_iterator it2{list.begin(), 3};
//  char x = it2[0]; // Error: requirement `random_access_iterator` was not satisfied.
    std::cout << *it2 << '\n'; // OK
}
```

Output:

```text
B C D
F G H
X
```
