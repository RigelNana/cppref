{/* source:cpp-iterator-counted-iterator-iter-move:0001 */}
Casts the result of dereferencing the underlying iterator to its associated rvalue reference type.

{/* source:cpp-iterator-counted-iterator-iter-move:0002 */}
The function body is equivalent to `return ranges::iter_move(i.base());`.

{/* source:cpp-iterator-counted-iterator-iter-move:0003 */}
This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::counted_iterator<I>` is an associated class of the arguments.

{/* source:cpp-iterator-counted-iterator-iter-move:0004 */}
If `i.count()` is equal to `0`, the behavior is undefined.

### Parameters

{/* source:cpp-iterator-counted-iterator-iter-move:0005 */}
<ParameterList>
  <Parameter name="i">a source iterator adaptor</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-counted-iterator-iter-move:0006 */}
An rvalue reference or a prvalue temporary.

### Complexity

{/* source:cpp-iterator-counted-iterator-iter-move:0007 */}
Constant.

### Example

{/* source:cpp-iterator-counted-iterator-iter-move:0008 */}
```cpp
#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>
 
void print(auto const& rem, auto const& v)
{
    std::cout << rem << '[' << size(v) << "] {";
    for (char comma[]{0, ' ', 0}; auto const& s : v)
        std::cout << comma << std::quoted(s), *comma = ',';
    std::cout << "}\n";
}
 
int main()
{
    std::vector<std::string> p{"Alpha", "Bravo", "Charlie"}, q;
    print("p", p);
    print("q", q);
 
    using RI = std::counted_iterator<std::vector<std::string>::iterator>;
 
    for (RI iter{p.begin(), 2}; iter != std::default_sentinel; ++iter)
        q.emplace_back(/* ADL */ iter_move(iter));
 
    print("p", p);
    print("q", q);
}
```

Possible output:

```text
p[3] {"Alpha", "Bravo", "Charlie"}
q[0] {}
p[3] {"", "", "Charlie"}
q[2] {"Alpha", "Bravo"}
```
