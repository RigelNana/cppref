{/* source:cpp-iterator-counted-iterator-operator-cmp2:0001 */}
Checks if the underlying length (i.e. distance to the end) is equal to `0`.

{/* source:cpp-iterator-counted-iterator-operator-cmp2:0002 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::counted_iterator<I>` is an associated class of the arguments.

{/* source:cpp-iterator-counted-iterator-operator-cmp2:0003 */}
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Parameters

{/* source:cpp-iterator-counted-iterator-operator-cmp2:0004 */}
<ParameterList>
  <Parameter name="x">an iterator adaptor</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-counted-iterator-operator-cmp2:0005 */}
`true` if `x.count()` is equal to `0`, `false` otherwise.

### Example

{/* source:cpp-iterator-counted-iterator-operator-cmp2:0006 */}
```cpp
#include <initializer_list>
#include <iterator>
 
int main()
{
    static constexpr auto v = {1, 2, 3, 4};
    constexpr std::counted_iterator<std::initializer_list<int>::iterator>
        it1{v.begin(), 3},
        it2{v.begin(), 0};
    static_assert(it1 != std::default_sentinel);
    static_assert(it2 == std::default_sentinel);
    static_assert(std::default_sentinel != it1);
    static_assert(std::default_sentinel == it2);
}
```
