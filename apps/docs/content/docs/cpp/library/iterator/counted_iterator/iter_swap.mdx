    friend constexpr void
        iter_swap( const counted_iterator& x, const std::counted_iterator<I2>& y )

{/* source:cpp-iterator-counted-iterator-iter-swap:0001 */}
Swaps the objects pointed to by two underlying iterators. The behavior is undefined if either `x.count()` or `y.count()` is equal to `0`.

{/* source:cpp-iterator-counted-iterator-iter-swap:0002 */}
The function body is equivalent to: `ranges::iter_swap(x.base(), y.base());`.

{/* source:cpp-iterator-counted-iterator-iter-swap:0003 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::counted_iterator<I>` is an associated class of the arguments.

### Parameters

{/* source:cpp-iterator-counted-iterator-iter-swap:0004 */}

### Return value

{/* source:cpp-iterator-counted-iterator-iter-swap:0005 */}

### Complexity

{/* source:cpp-iterator-counted-iterator-iter-swap:0006 */}
Constant.

### Example

{/* source:cpp-iterator-counted-iterator-iter-swap:0007 */}
```cpp
#include <iostream>
#include <iterator>
#include <list>
#include <vector>
 
int main()
{
    std::vector p{1, 2, 3, 4},
                q{5, 6, 7, 8};
 
    std::counted_iterator<std::vector<int>::iterator> ip{p.begin(), 2};
    std::counted_iterator<std::vector<int>::iterator> iq{q.begin(), 3};
 
    std::cout << *ip << ' ' << *iq << '\n';
    iter_swap(ip, iq); // ADL
    std::cout << *ip << ' ' << *iq << '\n';
 
    std::list x{0, 1, 3};
    std::counted_iterator<std::list<int>::iterator> ix{x.begin(), 2};
//  iter_swap(ip, ix); // error: not indirectly swappable
}
```

Output:

```text
1 5
5 1
```
