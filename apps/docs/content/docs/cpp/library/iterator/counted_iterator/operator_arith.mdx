  {/* source:cpp-iterator-counted-iterator-operator-arith:0001 */}
  Increments or decrements the underlying iterator `current` and the distance to the end `length`.

  {/* source:cpp-iterator-counted-iterator-operator-arith:0002 */}
  The behavior of these functions is undefined if the length would be set to a minus value.

  <DeclarationDescription>
    {/* source:cpp-iterator-counted-iterator-operator-arith:0003 */}
    1. 1) Pre-increments by one. Equivalent to `++current; --length; return *this;`.

    {/* source:cpp-iterator-counted-iterator-operator-arith:0004 */}
    2. 2) Post-increments by one. Equivalent to `--length; try { return current++; } catch(...) { ++length; throw; }`.

    {/* source:cpp-iterator-counted-iterator-operator-arith:0005 */}
    3. 3) Post-increments by one. Equivalent to `counted_iterator temp{*this}; ++*this; return temp;`.

    {/* source:cpp-iterator-counted-iterator-operator-arith:0006 */}
    4. 4) Pre-decrements by one. Equivalent to `--current; ++length; return *this;`.

    {/* source:cpp-iterator-counted-iterator-operator-arith:0007 */}
    5. 5) Post-decrements by one. Equivalent to `counted_iterator temp{*this}; --*this; return temp;`.

    {/* source:cpp-iterator-counted-iterator-operator-arith:0008 */}
    6. 6) Returns an iterator adaptor which is advanced by `n`. Equivalent to `return counted_iterator(current + n, length - n);`.

    {/* source:cpp-iterator-counted-iterator-operator-arith:0009 */}
    7. 7) Advances the iterator adaptor by `n`. Equivalent to `current += n; length -= n; return *this;`.

    {/* source:cpp-iterator-counted-iterator-operator-arith:0010 */}
    8. 8) Returns an iterator adaptor which is advanced by `-n`. Equivalent to `return counted_iterator(current - n, length + n);`.

    {/* source:cpp-iterator-counted-iterator-operator-arith:0011 */}
    9. 9) Advances the iterator adaptor by `-n`. Equivalent to `current -= n; length += n; return *this;`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-iterator-counted-iterator-operator-arith:0015 */}

{/* source:cpp-iterator-counted-iterator-operator-arith:0016 */}

{/* source:cpp-iterator-counted-iterator-operator-arith:0018 */}

### Example

{/* source:cpp-iterator-counted-iterator-operator-arith:0021 */}
```cpp
#include <cassert>
#include <initializer_list>
#include <iterator>
 
int main()
{
    const auto v = {1, 2, 3, 4, 5, 6};
    std::counted_iterator<std::initializer_list<int>::iterator> it1{v.begin(), 5};
 
    ++it1;              assert(*it1 == 2 && it1.count() == 4); // (1)
    auto it2 = it1++;   assert(*it2 == 2 && *it1 == 3);        // (3)
    --it1;              assert(*it1 == 2 && it1.count() == 4); // (4)
    auto it3 = it1--;   assert(*it3 == 2 && *it1 == 1);        // (5)
    auto it4 = it1 + 3; assert(*it4 == 4 && it4.count() == 2); // (6)
    auto it5 = it4 - 3; assert(*it5 == 1 && it5.count() == 5); // (8)
    it1 += 3;           assert(*it1 == 4 && it1.count() == 2); // (7)
    it1 -= 3;           assert(*it1 == 1 && it1.count() == 5); // (9)
}
```
