  <DeclarationDescription>
    {/* source:cpp-iterator-iter-t:0001 */}
    Compute the associated types of an iterator.

    {/* source:cpp-iterator-iter-t:0002 */}
    1. 1) Computes the [value type](/docs/cpp/library/iterator#Types_and_writability) of `T`.
    - If `std::iterator_traits<std::remove_cvref_t<T>>` is not specialized, then `std::iter_value_t<T>` is `std::indirectly_readable_traits<std::remove_cvref_t<T>>::value_type`.
    - Otherwise, it is `std::iterator_traits<std::remove_cvref_t<T>>::value_type`.

    {/* source:cpp-iterator-iter-t:0003 */}
    2. 2) Computes the *reference type* of `T`.

    {/* source:cpp-iterator-iter-t:0004 */}
    3. 3) Computes the *const reference type* of `T`.

    {/* source:cpp-iterator-iter-t:0005 */}
    4. 4) Computes the [difference type](/docs/cpp/library/iterator#Types_and_writability) of `T`.
    - If `std::iterator_traits<std::remove_cvref_t<T>>` is not specialized, then `std::iter_difference_t<T>` is `std::incrementable_traits<std::remove_cvref_t<T>>::difference_type`.
    - Otherwise, it is `std::iterator_traits<std::remove_cvref_t<T>>::difference_type`.

    {/* source:cpp-iterator-iter-t:0006 */}
    5. 5) Computes the *rvalue reference type* of `T`. The constraint on this alias template is satisfied if and only if the expression `ranges::iter_move(std::declval<T&>())` is valid and has a referenceable type.

    {/* source:cpp-iterator-iter-t:0007 */}
    6. 6) Computes the *common reference type* of `T`. This is the common reference type between its reference type and an lvalue reference to its value type.

    {/* source:cpp-iterator-iter-t:0008 */}
    7. 7) The exposition-only concept *dereferenceable* is satisfied if and only if the expression `*std::declval<T&>()` is valid and has a [referenceable type](/docs/cpp/library/meta#Definitions).

    {/* source:cpp-iterator-iter-t:0009 */}
    8. 8) The exposition-only alias template *indirect-value-t* denotes the following:
    - `std::invoke_result_t<Proj&, /*indirect-value-t*/<I>>` if `T` is the same as `std::projected<I, Proj>` for some types `I` and `Proj`.
    - Otherwise, `std::iter_value_t<T>&`.
  </DeclarationDescription>
</DeclarationDoc>

### Defect reports

{/* source:cpp-iterator-iter-t:0010 */}
The following behavior-changing defect reports were applied retroactively to previously published C++ standards.

{/* source:cpp-iterator-iter-t:0011 */}
<DefectReportList>
  <DefectReport kind="paper" id="P2609R3" standard="C++20">
    <PublishedBehavior>`std::iter_common_reference_t` was defined in terms of `std::iter_value_t<T>&` which incorrectly handled [`std::projected`](/docs/cpp/library/iterator/projected) types that project into rvalue reference types</PublishedBehavior>
    <CorrectedBehavior>defined in terms of `/*indirect-value-t*/<T>` to handle such cases</CorrectedBehavior>
  </DefectReport>
</DefectReportList>
