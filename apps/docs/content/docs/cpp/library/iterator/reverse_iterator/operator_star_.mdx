{/* source:cpp-iterator-reverse-iterator-operator-star:0001 */}
Returns a reference or pointer to the element previous to [`current`](/docs/cpp/library/iterator/reverse_iterator#current).

{/* source:cpp-iterator-reverse-iterator-operator-star:0002 */}
| Member function | Equivalent to |
| --- | --- |
| `operator*` | `Iter tmp = current; return *--tmp;` |
| `operator->` | <Revision until="C++11">`return &(operator*());`</Revision> <Revision since="C++11" until="C++20">`return std::addressof(operator*());`</Revision> <Revision since="C++20">`return current - 1;` if `Iter` is a pointer type `return std::prev(current).operator->();` otherwise</Revision> |

### Return value

{/* source:cpp-iterator-reverse-iterator-operator-star:0003 */}
As described above.

### Example

{/* source:cpp-iterator-reverse-iterator-operator-star:0004 */}
```cpp
#include <complex>
#include <iostream>
#include <iterator>
#include <vector>

int main()
{
    using RI0 = std::reverse_iterator<int*>;
    int a[]{0, 1, 2, 3};
    RI0 r0{std::rbegin(a)};
    std::cout << "*r0 = " << *r0 << '\n';
    *r0 = 42;
    std::cout << "a[3] = " << a[3] << '\n';

    using RI1 = std::reverse_iterator<std::vector<int>::iterator>;
    std::vector<int> vi{0, 1, 2, 3};
    RI1 r1{vi.rend() - 2};
    std::cout << "*r1 = " << *r1 << '\n';

    using RI2 = std::reverse_iterator<std::vector<std::complex<double>>::iterator>;
    std::vector<std::complex<double>> vc{{1, 2}, {3, 4}, {5, 6}, {7, 8}};
    RI2 r2{vc.rbegin() + 1};
    std::cout << "vc[2] = (" << r2->real() << ',' << r2->imag() << ")\n";
}
```

Output:

```text
*r0 = 3
a[3] = 42
*r1 = 1
vc[2] = (5,6)
```
