reverse_iterator& operator=( const reverse_iterator<U>& other );`} />
</DeclarationDoc>

{/* source:cpp-iterator-reverse-iterator-operator:0001 */}
Assigns `other.`[`current`](/docs/cpp/library/iterator/reverse_iterator#current) to `current`.

{/* source:cpp-iterator-reverse-iterator-operator:0002 */}
<Revision since="C++20">
This overload participates in overload resolution only if `std::is_same_v<U, Iter>` is false and both `std::convertible_to<const U&, Iter>` and `std::assignable_from<Iter&, const U&>` are modeled.
</Revision>

### Parameters

{/* source:cpp-iterator-reverse-iterator-operator:0003 */}
<ParameterList>
  <Parameter name="other">iterator adaptor to assign</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-reverse-iterator-operator:0004 */}
`*this`

### Example

{/* source:cpp-iterator-reverse-iterator-operator:0005 */}
```cpp
#include <iostream>
#include <iterator>

int main()
{
    const int a1[]{0, 1, 2};
    int a2[]{0, 1, 2, 3};
    short a3[]{40, 41, 42};

    std::reverse_iterator<const int*> it1{std::crbegin(a1)};
    it1 = std::reverse_iterator<int*>{std::rbegin(a2)};   // OK
//  it1 = std::reverse_iterator<short*>{std::rbegin(a3)}; // Compilation error:
                                                          // incompatible pointer types
    std::reverse_iterator<const short*> it2{nullptr};
    it2 = std::rbegin(a3); // OK
//  it2 = std::begin(a3);  // Compilation error: no viable operator= overload
    std::cout << *it2 << '\n';
}
```

Output:

```text
42
```
