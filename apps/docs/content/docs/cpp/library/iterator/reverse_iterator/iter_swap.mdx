{/* source:cpp-iterator-reverse-iterator-iter-swap:0001 */}
Swaps the objects pointed to by two adjusted underlying iterators.

{/* source:cpp-iterator-reverse-iterator-iter-swap:0002 */}
Equivalent to `auto tmp_x = x.base(); auto tmp_y = y.base(); ranges::iter_swap(--tmp_x, --tmp_y);`.

{/* source:cpp-iterator-reverse-iterator-iter-swap:0003 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::reverse_iterator<Iter>` is an associated class of the arguments.

### Parameters

{/* source:cpp-iterator-reverse-iterator-iter-swap:0004 */}
<ParameterList>
  <Parameter name="x, y">reverse iterators to the elements to swap</Parameter>
</ParameterList>

### Complexity

{/* source:cpp-iterator-reverse-iterator-iter-swap:0005 */}
Constant.

### Exceptions

{/* source:cpp-iterator-reverse-iterator-iter-swap:0006 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(
    std::is_nothrow_copy_constructible_v<Iter> &&
    std::is_nothrow_copy_constructible_v<Iter2> &&
    noexcept(ranges::iter_swap(--std::declval<Iter&>(), --std::declval<Iter2&>()))
)
```

### Example

{/* source:cpp-iterator-reverse-iterator-iter-swap:0007 */}
```cpp
#include <iostream>
#include <iterator>
#include <list>
#include <vector>

int main()
{
    std::vector v{1, 2, 3};
    std::list l{4, 5, 6};

    std::reverse_iterator<std::vector<int>::iterator> r1{v.rbegin()};
    std::reverse_iterator<std::list<int>::iterator> r2{l.rbegin()};

    std::cout << *r1 << ' ' << *r2 << '\n';

    iter_swap(r1, r2); // ADL

    std::cout << *r1 << ' ' << *r2 << '\n';
}
```

Output:

```text
3 6
6 3
```
