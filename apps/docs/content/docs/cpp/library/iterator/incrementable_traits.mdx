{/* source:cpp-iterator-incrementable-traits:0001 */}
Computes the associated difference type of the type `I`, if any. A program may specialize `incrementable_traits` for a [program-defined type](/docs/cpp/language/basic_concepts/type-id#Program-defined_type).

{/* source:cpp-iterator-incrementable-traits:0002 */}
1. 1) Primary template is an empty struct.

{/* source:cpp-iterator-incrementable-traits:0003 */}
2. 2) Specialization for pointers.

{/* source:cpp-iterator-incrementable-traits:0004 */}
Provides a member type `difference_type` same as [`std::ptrdiff_t`](/docs/cpp/library/utility/types/ptrdiff_t).

{/* source:cpp-iterator-incrementable-traits:0005 */}
3. 3) Specialization for const-qualified types.

{/* source:cpp-iterator-incrementable-traits:0006 */}
4. 4) Specialization for types that define a public and accessible member type `difference_type`.

{/* source:cpp-iterator-incrementable-traits:0007 */}
Provides a member type `difference_type` same as `T::difference_type`.

{/* source:cpp-iterator-incrementable-traits:0008 */}
5. 5) Specialization for types that do not define a public and accessible member type `difference_type` but do support subtraction.

{/* source:cpp-iterator-incrementable-traits:0009 */}
Provides a member type `difference_type` same as `std::make_signed_t<decltype(std::declval<T>() - std::declval<T>())>`. The implicit expression variations rule (see below) applies to the expression `a - b`.

### Implicit expression variations

{/* source:cpp-iterator-incrementable-traits:0010 */}
A [`requires` expression](/docs/cpp/language/templates/requires) that uses an expression that is non-modifying for some constant lvalue operand also requires [implicit expression variations](/docs/cpp/library/concepts#Implicit_expression_variations).
