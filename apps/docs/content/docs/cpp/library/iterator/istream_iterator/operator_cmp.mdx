{/* source:cpp-iterator-istream-iterator-operator-cmp:0001 */}
Checks whether both `lhs` and `rhs` are equal. Two stream iterators are equal if both of them are end-of-stream iterators or both of them refer to the same stream.

{/* source:cpp-iterator-istream-iterator-operator-cmp:0002 */}
1. 1) Checks whether `lhs` is *equal to* `rhs`.

{/* source:cpp-iterator-istream-iterator-operator-cmp:0003 */}
2. 2) Checks whether `lhs` is *not equal to* `rhs`.

{/* source:cpp-iterator-istream-iterator-operator-cmp:0004 */}
3. 3) Checks whether `lhs` is an end-of-stream iterator. This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::istream_iterator<T, CharT, Traits, Dist>` is an associated class of the arguments.

{/* source:cpp-iterator-istream-iterator-operator-cmp:0005 */}
<Revision since="C++20">
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Return value

{/* source:cpp-iterator-istream-iterator-operator-cmp:0007 */}
1. 1) `true` if `lhs` is *equal to* `rhs`, `false` otherwise.

{/* source:cpp-iterator-istream-iterator-operator-cmp:0008 */}
2. 2) `true` if `lhs` is *not equal to* `rhs`, `false` otherwise.

{/* source:cpp-iterator-istream-iterator-operator-cmp:0009 */}
3. 3) `true` if `lhs` is an end-of-stream iterator, `false` otherwise.
