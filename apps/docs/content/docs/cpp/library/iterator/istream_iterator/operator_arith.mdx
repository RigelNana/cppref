{/* source:cpp-iterator-istream-iterator-operator-arith:0001 */}
Reads a value from the underlying stream (using its [`operator>>`](/docs/cpp/library/io/basic_istream/operator_gtgt)) and stores it into the iterator object. If the read fails (the underlying stream's [`fail()`](/docs/cpp/library/io/basic_ios/fail) returns `true`), the iterator becomes the end-of-stream iterator.

{/* source:cpp-iterator-istream-iterator-operator-arith:0002 */}
The behavior is undefined if the iterator is end-of-stream iterator.

### Parameters

{/* source:cpp-iterator-istream-iterator-operator-arith:0003 */}
(none)

### Return value

{/* source:cpp-iterator-istream-iterator-operator-arith:0004 */}
1. 1) `*this`

{/* source:cpp-iterator-istream-iterator-operator-arith:0005 */}
2. 2) An `istream_iterator` that holds an unchanged value.

### Exceptions

{/* source:cpp-iterator-istream-iterator-operator-arith:0006 */}
May throw implementation-defined exceptions.
