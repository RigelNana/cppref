{/* source:cpp-iterator-istream-iterator-istream-iterator:0001 */}
1,2) Constructs the end-of-stream iterator<InlineRevision since="C++11">, value-initializes the stored value. This constructor is constexpr if the initializer in the definition `auto x = T();` is a constant initializer</InlineRevision>.

{/* source:cpp-iterator-istream-iterator-istream-iterator:0002 */}
3. 3) Initializes the iterator, stores the address of `stream` in a data member, and performs the first read from the input stream to initialize the cached value data member.

{/* source:cpp-iterator-istream-iterator-istream-iterator:0003 */}
4. 4) Constructs a copy of `other`.<InlineRevision since="C++11"> If `std::is_trivially_copy_constructible<T>::value` is `true`, this copy constructor is a trivial copy constructor.</InlineRevision>

### Example

{/* source:cpp-iterator-istream-iterator-istream-iterator:0005 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <sstream>

int main()
{
    std::istringstream stream("1 2 3 4 5");
    std::copy(
        std::istream_iterator<int>(stream),
        std::istream_iterator<int>(),
        std::ostream_iterator<int>(std::cout, " ")
    );
}
```

Output:

```text
1 2 3 4 5
```
