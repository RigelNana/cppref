{/* source:cpp-iterator-istream-iterator-operator-star:0002 */}
The behavior is undefined if the iterator is end-of-stream iterator.

### Parameters

{/* source:cpp-iterator-istream-iterator-operator-star:0003 */}
(none)

### Return value

{/* source:cpp-iterator-istream-iterator-operator-star:0004 */}

{/* source:cpp-iterator-istream-iterator-operator-star:0005 */}
