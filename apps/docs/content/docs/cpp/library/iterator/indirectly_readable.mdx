{/* source:cpp-iterator-indirectly-readable:0001 */}
The concept `indirectly_readable` is modeled by types that are readable by applying `operator*`, such as pointers, smart pointers, and input iterators.

### Semantic requirements

{/* source:cpp-iterator-indirectly-readable:0002 */}
Given a value `i` of type `I`, `I` models `indirectly_readable` only if all concepts it subsumes are modeled and the expression `*i` is [equality-preserving](/docs/cpp/library/concepts#Equality_preservation).

### Equality preservation

{/* source:cpp-iterator-indirectly-readable:0003 */}
Expressions declared in [requires expressions](/docs/cpp/language/templates/requires) of the standard library concepts are required to be equality-preserving (except where stated otherwise).
