{/* source:cpp-iterator-data:0001 */}
Returns a pointer to the block of memory containing the elements of the range.

{/* source:cpp-iterator-data:0002 */}
1,2) Returns `c.data()`.

{/* source:cpp-iterator-data:0003 */}
3) Returns `array`.

{/* source:cpp-iterator-data:0004 */}
4) Returns `il.begin()`.

### Parameters

{/* source:cpp-iterator-data:0005 */}
<ParameterList>
  <Parameter name="c">a container or view with a `data()` member function</Parameter>
  <Parameter name="array">an array of arbitrary type</Parameter>
  <Parameter name="il">an [`std::initializer_list`](/docs/cpp/library/utility/initializer_list)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-data:0006 */}
1,2) `c.data()`

{/* source:cpp-iterator-data:0007 */}
3) `array`

{/* source:cpp-iterator-data:0008 */}
4) `il.begin()`

### Exceptions

{/* source:cpp-iterator-data:0009 */}
1) May throw implementation-defined exceptions.

### Notes

{/* source:cpp-iterator-data:0010 */}
The overload for [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) is necessary because it does not have a member function `data`.

### Possible implementation

{/* source:cpp-iterator-data:0012 */}
[`First version`](/docs/cpp/library/iterator/data#Version_1)

```cpp
template<class C>
constexpr auto data(C& c) -> decltype(c.data())
{
    return c.data();
}
```

[`Second version`](/docs/cpp/library/iterator/data#Version_2)

```cpp
template<class C>
constexpr auto data(const C& c) -> decltype(c.data())
{
    return c.data();
}
```

[`Third version`](/docs/cpp/library/iterator/data#Version_3)

```cpp
template<class T, std::size_t N>
constexpr T* data(T (&array)[N]) noexcept
{
    return array;
}
```

[`Fourth version`](/docs/cpp/library/iterator/data#Version_4)

```cpp
template<class E>
constexpr const E* data(std::initializer_list<E> il) noexcept
{
    return il.begin();
}
```

### Example

{/* source:cpp-iterator-data:0013 */}
```cpp
#include <cstring>
#include <iostream>
#include <string>
 
int main()
{
    std::string s{"Hello world!\n"};
 
    char a[20]; // storage for a C-style string
    std::strcpy(a, std::data(s));
//  [s.data(), s.data() + s.size()] is guaranteed to be an NTBS since C++11
 
    std::cout << a;
}
```

Output:

```text
Hello world!
```
