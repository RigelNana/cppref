The concept `indirect_binary_predicate` specifies requirements for algorithms that call binary predicates as their arguments. The key difference between this concept and [`std::predicate`](/docs/cpp/library/concepts/predicate) is that it is applied to the types that `I1` and `I2` references, rather than `I1` and `I2` themselves.
