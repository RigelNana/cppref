{/* source:cpp-iterator-istreambuf-iterator-operator-cmp:0001 */}
Checks whether both `lhs` and `rhs` are valid, or both are invalid, regardless of the stream buffer objects they use.

{/* source:cpp-iterator-istreambuf-iterator-operator-cmp:0002 */}
1. 1) Equivalent to `lhs.equal(rhs)`.

{/* source:cpp-iterator-istreambuf-iterator-operator-cmp:0003 */}
2. 2) Equivalent to `!lhs.equal(rhs)`.

{/* source:cpp-iterator-istreambuf-iterator-operator-cmp:0004 */}
3. 3) Checks whether `lhs` is invalid. Equivalent to `lhs.equal(istreambuf_iterator{})`. This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::istreambuf_iterator<CharT,Traits>` is an associated class of the arguments.

{/* source:cpp-iterator-istreambuf-iterator-operator-cmp:0005 */}
<Revision since="C++20">
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>
