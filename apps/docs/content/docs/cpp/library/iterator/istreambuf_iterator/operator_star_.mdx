{/* source:cpp-iterator-istreambuf-iterator-operator-star:0001 */}
Reads a single character by calling `sbuf_->sgetc()` where `sbuf_` is the stored pointer to the stream buffer.

{/* source:cpp-iterator-istreambuf-iterator-operator-star:0002 */}
The behavior is undefined if the iterator is end-of-stream iterator.

### Parameters

{/* source:cpp-iterator-istreambuf-iterator-operator-star:0003 */}
(none)

### Return value

{/* source:cpp-iterator-istreambuf-iterator-operator-star:0004 */}
The value of the obtained character.

### Exceptions

{/* source:cpp-iterator-istreambuf-iterator-operator-star:0005 */}
May throw implementation-defined exceptions.
