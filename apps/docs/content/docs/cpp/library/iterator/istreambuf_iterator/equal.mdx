{/* source:cpp-iterator-istreambuf-iterator-equal:0001 */}
Checks whether both `*this` and `it` are valid, or both are invalid, regardless of the stream buffer objects they use.

### Parameters

{/* source:cpp-iterator-istreambuf-iterator-equal:0002 */}
<ParameterList>
  <Parameter name="it">another stream buffer iterator to compare to</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-istreambuf-iterator-equal:0003 */}
`true` if both `*this` and `it` are valid, or both are invalid, `false` otherwise.

### Exceptions

{/* source:cpp-iterator-istreambuf-iterator-equal:0004 */}
May throw implementation-defined exceptions.
