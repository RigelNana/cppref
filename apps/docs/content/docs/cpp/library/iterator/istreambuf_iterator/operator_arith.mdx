{/* source:cpp-iterator-istreambuf-iterator-operator-arith:0001 */}
Advances the iterator by calling `sbuf_->sbumpc()` where `sbuf_` is the stored pointer to the stream buffer.

{/* source:cpp-iterator-istreambuf-iterator-operator-arith:0002 */}
The behavior is undefined if the iterator is end-of-stream iterator.

### Parameters

{/* source:cpp-iterator-istreambuf-iterator-operator-arith:0003 */}
(none)

### Return value

{/* source:cpp-iterator-istreambuf-iterator-operator-arith:0004 */}
1. 1) `*this`

{/* source:cpp-iterator-istreambuf-iterator-operator-arith:0005 */}
2. 2) A `proxy` object holding the current character obtained via `operator*()` and the `sbuf_` pointer. Dereferencing a `proxy` object with `operator*` yields the stored character.

{/* source:cpp-iterator-istreambuf-iterator-operator-arith:0006 */}
The name `proxy` is for exposition only.

### Exceptions

{/* source:cpp-iterator-istreambuf-iterator-operator-arith:0007 */}
May throw implementation-defined exceptions.
