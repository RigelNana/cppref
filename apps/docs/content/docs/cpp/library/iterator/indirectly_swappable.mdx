concept indirectly_swappable =
    std::indirectly_readable<I1> &&
    std::indirectly_readable<I2> &&
    requires( const I1 i1, const I2 i2 )
    {
        ranges::iter_swap(i1, i1);

{/* source:cpp-iterator-indirectly-swappable:0001 */}
The concept `indirectly_swappable` specifies a relationship between two types respectively modelling [`std::indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable), where their referenced types can be swapped.

### Semantic requirements

{/* source:cpp-iterator-indirectly-swappable:0002 */}
`I1` and `I2` model `indirectly_swappable` only if all concepts it subsumes are modeled.

### Equality preservation

{/* source:cpp-iterator-indirectly-swappable:0003 */}
Expressions declared in [requires expressions](/docs/cpp/language/templates/requires) of the standard library concepts are required to be [equality-preserving](/docs/cpp/library/concepts#Equality_preservation) (except where stated otherwise).
