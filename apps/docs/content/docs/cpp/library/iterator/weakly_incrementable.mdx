{/* source:cpp-iterator-weakly-incrementable:0002 */}
This concept specifies requirements on types that can be incremented with the pre- and post-increment operators, but those increment operations are not necessarily [equality-preserving](/docs/cpp/library/concepts#Equality_preservation), and the type itself is not required to be [`std::equality_comparable`](/docs/cpp/library/concepts/equality_comparable).

{/* source:cpp-iterator-weakly-incrementable:0003 */}
For `std::weakly_incrementable` types, `a == b` does not imply that `++a == ++b`. Algorithms on weakly incrementable types must be single-pass algorithms. These algorithms can be used with istreams as the source of the input data through [`std::istream_iterator`](/docs/cpp/library/iterator/istream_iterator).

### Semantic requirements

{/* source:cpp-iterator-weakly-incrementable:0004 */}
For an object `i` of type `I`, `I` models `std::weakly_incrementable` only if all following conditions are satisfied:

{/* source:cpp-iterator-weakly-incrementable:0005 */}
- The expressions `++i` and `i++` have the same domain. If `i` is incrementable, then both `++i` and `i++` advance `i`. If `i` is incrementable, then `std::addressof(++i) == std::addressof(i)`.
