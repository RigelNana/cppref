Returns whether the given range is empty.

{/* source:cpp-iterator-empty:0002 */}
1) Returns `c.empty()`.

{/* source:cpp-iterator-empty:0003 */}
2) Returns `false`.

{/* source:cpp-iterator-empty:0004 */}
3) Returns `il.size() == 0`.

### Parameters

{/* source:cpp-iterator-empty:0005 */}
<ParameterList>
  <Parameter name="c">a container or view with an empty member function</Parameter>
  <Parameter name="array">an array of arbitrary type</Parameter>
  <Parameter name="il">an [`std::initializer_list`](/docs/cpp/library/utility/initializer_list)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-empty:0006 */}
1) `c.empty()`

{/* source:cpp-iterator-empty:0007 */}
2) `false`

{/* source:cpp-iterator-empty:0008 */}
3) `il.size() == 0`

### Exceptions

{/* source:cpp-iterator-empty:0009 */}
1) May throw implementation-defined exceptions.

### Notes

{/* source:cpp-iterator-empty:0010 */}
The overload for [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) is necessary because it does not have a member function `empty`.

### Possible implementation

{/* source:cpp-iterator-empty:0012 */}
[`First version`](/docs/cpp/library/iterator/empty#Version_1)

```cpp
template<class C>
[[nodiscard]] constexpr auto empty(const C& c) -> decltype(c.empty())
{
    return c.empty();
}
```

[`Second version`](/docs/cpp/library/iterator/empty#Version_2)

```cpp
template<class T, std::size_t N>
[[nodiscard]] constexpr bool empty(const T (&array)[N]) noexcept
{
    return false;
}
```

[`Third version`](/docs/cpp/library/iterator/empty#Version_3)

```cpp
template<class E>
[[nodiscard]] constexpr bool empty(std::initializer_list<E> il) noexcept
{
    return il.size() == 0;
}
```

### Example

{/* source:cpp-iterator-empty:0013 */}
```cpp
#include <iostream>
#include <vector>
 
template<class T>
void print(const T& container)
{
    if (std::empty(container))
        std::cout << "Empty\n";
    else
    {
        std::cout << "Elements:";
        for (const auto& element : container)
            std::cout << ' ' << element;
        std::cout << '\n';
    }
}
 
int main()
{
    std::vector<int> c = {1, 2, 3};
    print(c);
    c.clear();
    print(c);
 
    int array[] = {4, 5, 6};
    print(array);
 
    auto il = {7, 8, 9};
    print(il);
}
```

Output:

```text
Elements: 1 2 3
Empty
Elements: 4 5 6
Elements: 7 8 9
```
