{/* source:cpp-iterator-indirect-unary-predicate:0001 */}
The concept `indirect_unary_predicate` specifies requirements for algorithms that call unary predicates as their arguments. The key difference between this concept and [`std::predicate`](/docs/cpp/library/concepts/predicate) is that it is applied to the type that `I` references, rather than `I` itself.
