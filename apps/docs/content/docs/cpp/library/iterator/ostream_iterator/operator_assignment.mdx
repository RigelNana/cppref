{/* source:cpp-iterator-ostream-iterator-operator:0001 */}
1. Copy assignment operator. Assigns the contents of `other`

{/* source:cpp-iterator-ostream-iterator-operator:0002 */}
2. Inserts `value` into the associated stream, then inserts the delimiter, if one was specified at construction time.

{/* source:cpp-iterator-ostream-iterator-operator:0003 */}
If `out_stream` is a pointer to the associated [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) and `delim` is the delimiter specified at the construction of this object, then the effect is equivalent to

{/* source:cpp-iterator-ostream-iterator-operator:0004 */}
```cpp
*out_stream << value;
if (delim != 0)
    *out_stream << delim;
return *this;
```

{/* source:cpp-iterator-ostream-iterator-operator:0006 */}
`*this`

{/* source:cpp-iterator-ostream-iterator-operator:0007 */}
`T` can be any class with a user-defined `operator<<`.

{/* source:cpp-iterator-ostream-iterator-operator:0008 */}
Prior to C++20, the existence of the copy assignment operator relied on the [deprecated implicit generation](/docs/cpp/language/classes/as_operator#Implicitly-defined_copy_assignment_operator).

{/* source:cpp-iterator-ostream-iterator-operator:0009 */}
```cpp
#include <iostream>
#include <iterator>
 
int main()
{
    std::ostream_iterator<int> i1(std::cout, ", ");
    *i1++ = 1; // usual form, used by standard algorithms
    *++i1 = 2;
    i1 = 3; // neither * nor ++ are necessary
    std::ostream_iterator<double> i2(std::cout);
    i2 = 3.14;
    std::cout << '\n';
}
```

Output:

```text
1, 2, 3, 3.14
```
