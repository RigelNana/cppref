{/* source:cpp-iterator-ostream-iterator:0001 */}
`std::ostream_iterator` is a single-pass [`LegacyOutputIterator`](/docs/cpp/library/named_req/OutputIterator) that writes successive objects of type `T` into the [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) object for which it was constructed, using `operator<<`. Optional delimiter string is written to the output stream after every write operation. The write operation is performed when the iterator (whether dereferenced or not) is assigned to. Incrementing the `std::ostream_iterator` is a no-op.

{/* source:cpp-iterator-ostream-iterator:0002 */}
In a typical implementation, the only data members of `std::ostream_iterator` are a pointer to the associated `std::basic_ostream` and a pointer to the first character in the delimiter string.

{/* source:cpp-iterator-ostream-iterator:0003 */}
When writing characters, [`std::ostreambuf_iterator`](/docs/cpp/library/iterator/ostreambuf_iterator) is more efficient, since it avoids the overhead of constructing and destructing the sentry object once per character.

{/* source:cpp-iterator-ostream-iterator:0007 */}
```cpp
#include <iostream>
#include <iterator>
#include <numeric>
#include <sstream>
 
int main()
{
    std::istringstream str("0.11 0.22 0.33 0.44");
 
    std::partial_sum(std::istream_iterator<double>(str),
                     std::istream_iterator<double>(),
                     std::ostream_iterator<double>(std::cout, ", "));
    std::cout << '\n';
}
```

Output:

```text
0.11, 0.33, 0.66, 1.1,
```
