{/* source:cpp-iterator-insert-iterator-operator-star:0001 */}
Does nothing, this member function is provided to satisfy the requirements of [`LegacyOutputIterator`](/docs/cpp/library/named_req/OutputIterator).

{/* source:cpp-iterator-insert-iterator-operator-star:0002 */}
It returns the iterator itself, which makes it possible to use code such as `*iter = value` to output (insert) the value into the underlying container.
