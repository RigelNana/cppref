{/* source:cpp-iterator-insert-iterator-insert-iterator:0001 */}
Initializes the underlying pointer to the container to `std::addressof(c)` and the underlying iterator to `i`.

{/* source:cpp-iterator-insert-iterator-insert-iterator:0002 */}
<ParameterList>
  <Parameter name="c">container to initialize the inserter with</Parameter>
  <Parameter name="i">iterator to initialize the inserter with</Parameter>
</ParameterList>
