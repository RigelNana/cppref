{/* source:cpp-iterator-common-iterator-iter-move:0001 */}
Casts the result of dereferencing the underlying iterator to its associated rvalue reference type.

{/* source:cpp-iterator-common-iterator-iter-move:0002 */}
The function body is equivalent to: `return std::ranges::iter_move(std::get<I>(i.var));`

{/* source:cpp-iterator-common-iterator-iter-move:0003 */}
This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::common_iterator<I, S>` is an associated class of the arguments.

{/* source:cpp-iterator-common-iterator-iter-move:0004 */}
If `i.var` does not hold an `I` object (i.e. an iterator), the behavior is undefined.

### Parameters

{/* source:cpp-iterator-common-iterator-iter-move:0005 */}
<ParameterList>
  <Parameter name="i">a source iterator adaptor</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-common-iterator-iter-move:0006 */}
An rvalue reference or a prvalue temporary.

### Complexity

{/* source:cpp-iterator-common-iterator-iter-move:0007 */}
Constant.

### Example

{/* source:cpp-iterator-common-iterator-iter-move:0008 */}
```cpp
#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>
 
void print(auto const& rem, auto const& v)
{
    std::cout << rem << '[' << size(v) << "] { ";
    for (int o{}; auto const& s : v)
        std::cout << (o++ ? ", " : "") << std::quoted(s);
    std::cout << " }\n";
}
 
int main()
{
    std::vector<std::string> p{"Andromeda", "Cassiopeia", "Phoenix"}, q;
    print("p", p);
    print("q", q);
 
    using CTI = std::counted_iterator<std::vector<std::string>::iterator>;
    using CI = std::common_iterator<CTI, std::default_sentinel_t>;
    CI last{std::default_sentinel};
 
    for (CI first{{p.begin(), 2}}; first != last; ++first)
        q.emplace_back(/* ADL */ iter_move(first));
 
    print("p", p);
    print("q", q);
}
```

Possible output:

```text
p[3] { "Andromeda", "Cassiopeia", "Phoenix" }
q[0] {  }
p[3] { "", "", "Phoenix" }
q[2] { "Andromeda", "Cassiopeia" }
```
