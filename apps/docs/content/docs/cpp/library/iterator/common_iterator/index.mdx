{/* source:cpp-iterator-common-iterator:0001 */}
`std::common_iterator` is an iterator `I` / sentinel `S` adaptor that may represent a non-common range (where the types of `I` and `S` differ) as a [`common_range`](/docs/cpp/library/ranges/common_range), by containing either an iterator or a sentinel, and defining the appropriate equality comparison operators `operator==`.

{/* source:cpp-iterator-common-iterator:0002 */}
`std::common_iterator` can be used as a "bridge" between sequences represented by iterator/sentinel pair and legacy functions that expect [`common_range`](/docs/cpp/library/ranges/common_range)-like sequences.

### Example

{/* source:cpp-iterator-common-iterator:0007 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <list>
#include <string>
 
template<class ForwardIter>
void fire(ForwardIter first, ForwardIter last)
{
    std::copy(first, last, std::ostream_iterator<std::string>{std::cout, " "});    
}
 
int main()
{
    std::list<std::string> stars{"Pollux", "Arcturus", "Mira", "Aldebaran", "Sun"};
 
    using IT = std::common_iterator<
                   std::counted_iterator<std::list<std::string>::iterator>,
                   std::default_sentinel_t>;
 
    fire(IT(std::counted_iterator(stars.begin(), stars.size() - 1)),
         IT(std::default_sentinel));
}
```

Output:

```text
Pollux Arcturus Mira Aldebaran
```
