{/* source:cpp-iterator-common-iterator-iter-swap:0001 */}
Swaps the objects pointed to by two underlying iterators. The behavior is undefined if `x` does not hold an `I` object or `y` does not hold an `I2` object (i.e. at least one of `x` and `y` does not hold an iterator).

{/* source:cpp-iterator-common-iterator-iter-swap:0002 */}
The function body is equivalent to `ranges::iter_swap(std::get<I>(x.var), std::get<I2>(y.var))`.

{/* source:cpp-iterator-common-iterator-iter-swap:0003 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::common_iterator<I,S>` is an associated class of the arguments.

### Example

{/* source:cpp-iterator-common-iterator-iter-swap:0008 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>
 
int main()
{
    std::vector<std::string> v1{"1", "2", "3", "4", "5"},
                             v2{"α", "β", "γ", "δ", "ε"};
 
    using CI = std::common_iterator<
                   std::counted_iterator<std::vector<std::string>::iterator>,
                   std::default_sentinel_t
                   >;
 
    CI first1{std::counted_iterator{v1.begin(), 3}};
    CI first2{std::counted_iterator{v2.begin(), 4}};
    CI last{std::default_sentinel};
 
    auto print = [&](auto rem)
    {
        std::cout << rem << "v1 = ";
        std::ranges::copy(v1, std::ostream_iterator<std::string>{std::cout, " "});
        std::cout << "\nv2 = ";
        std::ranges::copy(v2, std::ostream_iterator<std::string>{std::cout, " "});
        std::cout << '\n';
    };
 
    print("Before iter_swap:\n");
 
    for (; first1 != last && first2 != last; ++first1, ++first2)
        iter_swap(first1, first2); // ADL
 
    print("After iter_swap:\n");
}
```

Output:

```text
Before iter_swap:
v1 = 1 2 3 4 5 
v2 = α β γ δ ε 
After iter_swap:
v1 = α β γ 4 5 
v2 = 1 2 3 δ ε
```
