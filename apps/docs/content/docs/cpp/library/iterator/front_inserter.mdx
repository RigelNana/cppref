{/* source:cpp-iterator-front-inserter:0001 */}
`front_inserter` is a convenience function template that constructs a [`std::front_insert_iterator`](/docs/cpp/library/iterator/front_insert_iterator) for the container `c` with the type deduced from the type of the argument.

### Parameters

{/* source:cpp-iterator-front-inserter:0002 */}
<ParameterList>
  <Parameter name="c">container that supports a `push_front` operation</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-front-inserter:0003 */}
A [`std::front_insert_iterator`](/docs/cpp/library/iterator/front_insert_iterator) which can be used to add elements to the beginning of the container `c`.

### Possible implementation

{/* source:cpp-iterator-front-inserter:0004 */}
```cpp
template<class Container>
std::front_insert_iterator<Container> front_inserter( Container& c )
{
    return std::front_insert_iterator<Container>(c);
}
```

### Example

{/* source:cpp-iterator-front-inserter:0005 */}
```cpp
#include <algorithm>
#include <deque>
#include <iostream>
#include <iterator>
#include <vector>
 
int main()
{
    std::vector<int> v{1, 2, 3, 4, 5};
    std::deque<int> d;
    std::copy(v.begin(), v.end(), std::front_inserter(d));
    for (int n : d)
        std::cout << n << ' ';
    std::cout << '\n';
}
```

Output:

```text
5 4 3 2 1
```
