{/* source:cpp-iterator-ostreambuf-iterator-ostreambuf-iterator:0001 */}
1. 1) Constructs the iterator with the private `streambuf_type*` member set to `buffer` and the [`failed()`](/docs/cpp/library/iterator/ostreambuf_iterator/failed) flag set to `false`. The behavior is undefined if `buffer` is a null pointer.

{/* source:cpp-iterator-ostreambuf-iterator-ostreambuf-iterator:0002 */}
2. 2) Same as `ostreambuf_iterator(stream.rdbuf())`.

{/* source:cpp-iterator-ostreambuf-iterator-ostreambuf-iterator:0003 */}
<ParameterList>
  <Parameter name="stream">the output stream whose `rdbuf()` will be accessed by this iterator</Parameter>
  <Parameter name="buffer">the output stream buffer to be accessed by this iterator</Parameter>
</ParameterList>

{/* source:cpp-iterator-ostreambuf-iterator-ostreambuf-iterator:0004 */}
```cpp
#include <fstream>
#include <iostream>
#include <iterator>
 
int main()
{
    const char* file = "test.txt";
    {
        std::basic_filebuf<char> f;
        f.open(file, std::ios::out);
        std::ostreambuf_iterator<char> out1(&f);
        *out1 = 'a'; // writes to file via iterator
    }
 
    // read back from the file
    char a;
    std::cout << ((std::ifstream{file} >> a), a) << std::endl;
 
    std::ostreambuf_iterator<wchar_t> out2{std::wcout};
    *out2 = L'b';
}
```

Output:

```text
a
b
```
