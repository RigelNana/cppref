{/* source:cpp-iterator-ostreambuf-iterator-failed:0001 */}
Returns `true` if the iterator encountered the end-of-file condition, that is, if an earlier call to [`std::basic_streambuf::sputc`](/docs/cpp/library/io/basic_streambuf/sputc) (made by [`operator=`](/docs/cpp/library/iterator/ostreambuf_iterator/operator_assignment)) returned `Traits::eof`.

{/* source:cpp-iterator-ostreambuf-iterator-failed:0002 */}
(none)

{/* source:cpp-iterator-ostreambuf-iterator-failed:0003 */}
`true` if this iterator has encountered the end-of-file condition on output, `false` otherwise.
