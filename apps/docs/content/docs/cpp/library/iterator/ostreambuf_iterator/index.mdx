{/* source:cpp-iterator-ostreambuf-iterator:0001 */}
`std::ostreambuf_iterator` is a single-pass [`LegacyOutputIterator`](/docs/cpp/library/named_req/OutputIterator) that writes successive characters into the [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf) object for which it was constructed. The actual write operation is performed when the iterator (whether dereferenced or not) is assigned to. Incrementing the `std::ostreambuf_iterator` is a no-op.

{/* source:cpp-iterator-ostreambuf-iterator:0002 */}
In a typical implementation, the only data members of `std::ostreambuf_iterator` are a pointer to the associated `std::basic_streambuf` and a boolean flag indicating if the end of file condition has been reached.
