{/* source:cpp-iterator-ostreambuf-iterator-operator-arith:0001 */}
Does nothing. These operator overloads are provided to satisfy the requirements of [`LegacyOutputIterator`](/docs/cpp/library/named_req/OutputIterator). They make it possible for the expressions `*iter++=value` and `*++iter=value` to be used to output (insert) a value into the underlying stream.
