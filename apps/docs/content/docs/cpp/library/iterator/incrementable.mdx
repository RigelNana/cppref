{/* source:cpp-iterator-incrementable:0001 */}
This concept specifies requirements on types that can be incremented with the pre- and post-increment operators, whose increment operations are [equality-preserving](/docs/cpp/library/concepts#Equality_preservation), and the type is [`std::equality_comparable`](/docs/cpp/library/concepts/equality_comparable).

{/* source:cpp-iterator-incrementable:0002 */}
Unlike with [`std::weakly_incrementable`](/docs/cpp/library/iterator/weakly_incrementable), which only support single-pass algorithms, multi-pass one-directional algorithms can be used with types that model `std::incrementable`.

### Semantic requirements

{/* source:cpp-iterator-incrementable:0003 */}
`I` models `std::incrementable` only if given any two incrementable objects `a` and `b` of type `I`:

{/* source:cpp-iterator-incrementable:0004 */}
- `bool(a == b)` implies `bool(a++ == b)`, and
- `bool(a == b)` implies `bool(((void)a++, a) == ++b)`.

### Equality preservation

{/* source:cpp-iterator-incrementable:0005 */}
Expressions declared in [requires expressions](/docs/cpp/language/templates/requires) of the standard library concepts are required to be [equality-preserving](/docs/cpp/library/concepts#Equality_preservation) (except where stated otherwise).
