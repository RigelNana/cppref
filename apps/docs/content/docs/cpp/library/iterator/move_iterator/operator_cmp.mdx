Compares the underlying iterators of `lhs` and `rhs`.

{/* source:cpp-iterator-move-iterator-operator-cmp:0002 */}
<Revision since="C++20">

1) This overload participates in overload resolution only if `lhs.base() == rhs.base()` is well-formed and convertible to `bool`.

3-6) These overloads participate in overload resolution only if `lhs.base() < rhs.base()` is well-formed and convertible to `bool`. The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

</Revision>

### Parameters

### Return value

{/* source:cpp-iterator-move-iterator-operator-cmp:0004 */}
1. 1) `lhs.base() == rhs.base()`

{/* source:cpp-iterator-move-iterator-operator-cmp:0005 */}
2. 2) `!(lhs == rhs)`

{/* source:cpp-iterator-move-iterator-operator-cmp:0006 */}
3. 3) `lhs.base() < rhs.base()`

{/* source:cpp-iterator-move-iterator-operator-cmp:0007 */}
4. 4) `!(rhs < lhs)`

{/* source:cpp-iterator-move-iterator-operator-cmp:0008 */}
5. 5) `rhs < lhs`

{/* source:cpp-iterator-move-iterator-operator-cmp:0009 */}
6. 6) `!(lhs < rhs)`

{/* source:cpp-iterator-move-iterator-operator-cmp:0010 */}
7. 7) `lhs.base() <=> rhs.base()`

### Example

{/* source:cpp-iterator-move-iterator-operator-cmp:0011 */}
```cpp
#include <cassert>
#include <iterator>

int main()
{
    int a[]{9, 8, 7, 6};
    //            │  └───── x, y
    //            └──────── z

    // “x” and “y” are equal, but “x” is greater than “z”
    std::move_iterator<int*>
        x{std::end(a) - 1},
        y{std::end(a) - 1},
        z{std::end(a) - 2};

    // two-way comparisons
    assert(  x == y );
    assert(!(x != y));
    assert(!(x <  y));
    assert(  x <= y );
    assert(!(x == z));
    assert(  x != z );
    assert(!(x <  z));
    assert(!(x <= z));

    // three-way comparisons
    assert(  x <=> y == 0 );
    assert(!(x <=> y <  0));
    assert(!(x <=> y >  0));
    assert(!(x <=> z == 0));
    assert(!(x <=> z <  0));
    assert(  x <=> z >  0 );
}
```
