{/* source:cpp-iterator-move-iterator-operator-cmp2:0001 */}
Compares a `move_iterator` and a `move_sentinel`.

{/* source:cpp-iterator-move-iterator-operator-cmp2:0002 */}
This overload participates in overload resolution only if `i.base() == s.base()` is well-formed and convertible to `bool`.

{/* source:cpp-iterator-move-iterator-operator-cmp2:0003 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::move_iterator<Iter>` is an associated class of the arguments.

{/* source:cpp-iterator-move-iterator-operator-cmp2:0004 */}
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Return value

{/* source:cpp-iterator-move-iterator-operator-cmp2:0006 */}
