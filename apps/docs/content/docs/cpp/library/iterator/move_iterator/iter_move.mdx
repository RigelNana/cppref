{/* source:cpp-iterator-move-iterator-iter-move:0001 */}
Casts the result of dereferencing the underlying iterator to its associated rvalue reference type.

{/* source:cpp-iterator-move-iterator-iter-move:0002 */}
Equivalent to `return std::ranges::iter_move(i.base());`.

{/* source:cpp-iterator-move-iterator-iter-move:0003 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::move_iterator<Iter>` is an associated class of the arguments.

### Parameters

{/* source:cpp-iterator-move-iterator-iter-move:0004 */}
<ParameterList>
  <Parameter name="i">a source move iterator</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-move-iterator-iter-move:0005 */}
An rvalue reference or a prvalue temporary.

### Complexity

{/* source:cpp-iterator-move-iterator-iter-move:0006 */}
Constant.

### Exceptions

{/* source:cpp-iterator-move-iterator-iter-move:0007 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(noexcept(ranges::iter_move(i.base())))
```

### Example

{/* source:cpp-iterator-move-iterator-iter-move:0008 */}
```cpp
#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>

void print(const auto& rem, const auto& v)
{
    std::cout << rem << '[' << size(v) << "] { ";
    for (char comma[]{0, ' ', 0}; const auto& s : v)
        std::cout << comma << std::quoted(s), comma[0] = ',';
    std::cout << " }\n";
}

int main()
{
    std::vector<std::string> p{"Andromeda", "Cassiopeia", "Phoenix"}, q;

    print("p", p), print("q", q);

    using MI = std::move_iterator<std::vector<std::string>::iterator>;

    for (MI first{p.begin()}, last{p.end()}; first != last; ++first)
        q.emplace_back(/* ADL */ iter_move(first));

    print("p", p), print("q", q);
}
```

Possible output:

```text
p[3] { "Andromeda", "Cassiopeia", "Phoenix" }
q[0] {  }
p[3] { "", "", "" }
q[3] { "Andromeda", "Cassiopeia", "Phoenix" }
```
