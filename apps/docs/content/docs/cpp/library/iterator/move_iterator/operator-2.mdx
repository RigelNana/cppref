Returns the distance between a `move_iterator` and a `move_sentinel`.

{/* source:cpp-iterator-move-iterator-operator-2:0002 */}
These function templates are not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::move_iterator<Iter>` is an associated class of the arguments.
