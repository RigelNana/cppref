{/* source:cpp-iterator-move-iterator-base:0001 */}
Returns the underlying iterator.

{/* source:cpp-iterator-move-iterator-base:0002 */}
1. 1) Returns a <InlineRevision until="C++20">copy of</InlineRevision><InlineRevision since="C++20">reference to</InlineRevision> the underlying iterator.

{/* source:cpp-iterator-move-iterator-base:0003 */}
2. 2) Returns an iterator move constructed from the underlying iterator.

### Return value

{/* source:cpp-iterator-move-iterator-base:0004 */}
1. 1) [`current`](/docs/cpp/library/iterator/move_iterator#current)

{/* source:cpp-iterator-move-iterator-base:0005 */}
2. 2) `std::move(`[`current`](/docs/cpp/library/iterator/move_iterator#current)`)`

### Example

{/* source:cpp-iterator-move-iterator-base:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <vector>

int main()
{
    std::vector<int> v{0, 1, 2, 3, 4};
    std::move_iterator<std::vector<int>::reverse_iterator>
        m1{v.rbegin()},
        m2{v.rend()};

    std::copy(m1.base(), m2.base(), std::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';
}
```

Output:

```text
4 3 2 1 0
```
