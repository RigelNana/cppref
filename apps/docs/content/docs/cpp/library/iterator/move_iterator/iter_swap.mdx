{/* source:cpp-iterator-move-iterator-iter-swap:0001 */}
Swaps the objects pointed to by two underlying iterators.

{/* source:cpp-iterator-move-iterator-iter-swap:0002 */}
Equivalent to `ranges::iter_swap(x.base(), y.base());`.

{/* source:cpp-iterator-move-iterator-iter-swap:0003 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::move_iterator<Iter>` is an associated class of the arguments.

### Parameters

{/* source:cpp-iterator-move-iterator-iter-swap:0004 */}
<ParameterList>
  <Parameter name="x, y">move iterators to the elements to swap</Parameter>
</ParameterList>

### Complexity

{/* source:cpp-iterator-move-iterator-iter-swap:0005 */}
Constant.

### Exceptions

{/* source:cpp-iterator-move-iterator-iter-swap:0006 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(noexcept(ranges::iter_swap(x.base(), y.base())))
```

### Example

{/* source:cpp-iterator-move-iterator-iter-swap:0007 */}
```cpp
#include <iostream>
#include <iterator>
#include <string>
#include <vector>

int main()
{
    std::vector<std::string> p{"AA", "EE"},
                             q{"ⱯⱯ", "ƎƎ"};

    std::move_iterator<std::vector<std::string>::iterator>
        x = std::make_move_iterator(p.begin()),
        y = std::make_move_iterator(q.begin());

    std::cout << *x << ' ' << *y << '\n';

    iter_swap(x, y); // ADL

    std::cout << *x << ' ' << *y << '\n';
}
```

Output:

```text
AA ⱯⱯ
ⱯⱯ AA
```
