{/* source:cpp-iterator-move-iterator-operator-arith:0001 */}
Increments or decrements the underlying iterator.

{/* source:cpp-iterator-move-iterator-operator-arith:0002 */}
| Overload | Equivalent to |
| --- | --- |
| (1) | `++current; return *this;` |
| (2) | `--current; return *this;` |
| (3) | <Revision until="C++20">`move_iterator tmp = *this; ++current; return tmp;`</Revision><Revision since="C++20">`move_iterator tmp = *this; ++current; return tmp;` if `Iter` models [`forward_iterator`](/docs/cpp/library/iterator/forward_iterator) `++current;` otherwise</Revision> |
| (4) | `move_iterator tmp = *this; --current; return tmp;` |
| (5) | `return move_iterator(current + n);` |
| (6) | `return move_iterator(current - n);` |
| (7) | `current += n; return *this;` |
| (8) | `current -= n; return *this;` |
