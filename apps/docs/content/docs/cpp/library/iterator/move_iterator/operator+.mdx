{/* source:cpp-iterator-move-iterator-operator:0001 */}
Returns the iterator `it` incremented by `n`.

{/* source:cpp-iterator-move-iterator-operator:0002 */}
<Revision since="C++20">
This overload participates in overload resolution only if `it.base() + n` is well-formed and has type `Iter`.
</Revision>

### Parameters

{/* source:cpp-iterator-move-iterator-operator:0003 */}
<ParameterList>
  <Parameter name="n">the number of positions to increment the iterator</Parameter>
  <Parameter name="it">the iterator adaptor to increment</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-move-iterator-operator:0004 */}
`it + n`
