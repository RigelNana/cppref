{/* source:cpp-iterator-rend:0001 */}
Returns an iterator to the reverse-end of the given range.

{/* source:cpp-iterator-rend:0002 */}
1,2) Returns `c.rend()`, which is typically an iterator one past the reverse-end of the sequence represented by `c`.

{/* source:cpp-iterator-rend:0003 */}
1) If `C` is a standard [`Container`](/docs/cpp/library/named_req/Container), returns a `C::reverse_iterator` object.

{/* source:cpp-iterator-rend:0004 */}
2) If `C` is a standard `Container`, returns a `C::const_reverse_iterator` object.

{/* source:cpp-iterator-rend:0005 */}
3) Returns an `std::reverse_iterator<T*>` object to the reverse-end of `array`.

{/* source:cpp-iterator-rend:0006 */}
4) Returns an `std::reverse_iterator<const T*>` object to the reverse-end of `il`.

{/* source:cpp-iterator-rend:0007 */}
5) Returns `std::end(c)`, with `c` always treated as const-qualified.

{/* source:cpp-iterator-rend:0008 */}
If `C` is a standard `Container`, returns a `C::const_reverse_iterator` object.

### Parameters

{/* source:cpp-iterator-rend:0009 */}
<ParameterList>
  <Parameter name="c">a container or view with a rend member function</Parameter>
  <Parameter name="array">an array of arbitrary type</Parameter>
  <Parameter name="il">an `std::initializer_list`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-iterator-rend:0010 */}
1,2) `c.rend()`

{/* source:cpp-iterator-rend:0011 */}
3) `std::reverse_iterator<T*>(array)`

{/* source:cpp-iterator-rend:0012 */}
4) `std::reverse_iterator<const T*>(il.begin())`

{/* source:cpp-iterator-rend:0013 */}
5) `c.rend()`

### Exceptions

{/* source:cpp-iterator-rend:0014 */}
May throw implementation-defined exceptions.

### Overloads

{/* source:cpp-iterator-rend:0015 */}
Custom overloads of `rend` may be provided for classes and enumerations that do not expose a suitable `rend()` member function, yet can be iterated.

{/* source:cpp-iterator-rend:0016 */}
<Revision since="C++20">
Overloads of `rend` found by [argument-dependent lookup](/docs/cpp/language/functions/adl) can be used to customize the behavior of `std::ranges::rend` and [`std::ranges::crend`](/docs/cpp/library/ranges/crend).
</Revision>

### Notes

{/* source:cpp-iterator-rend:0017 */}
The overload for [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) is necessary because it does not have a member function `rend`.

### Example

{/* source:cpp-iterator-rend:0018 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <vector>
 
int main()
{
    int a[]{4, 6, -3, 9, 10};
    std::cout << "C-style array `a` backwards: ";
    std::copy(std::rbegin(a), std::rend(a), std::ostream_iterator<int>(std::cout, " "));
 
    auto il = {3, 1, 4};
    std::cout << "\nstd::initializer_list `il` backwards: ";
    std::copy(std::rbegin(il), std::rend(il), std::ostream_iterator<int>(std::cout, " "));
 
    std::vector<int> v{4, 6, -3, 9, 10};
    std::cout << "\nstd::vector `v` backwards: ";
    std::copy(std::rbegin(v), std::rend(v), std::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';
}
```

Output:

```text
C-style array `a` backwards: 10 9 -3 6 4
std::initializer_list `il` backwards: 4 1 3
std::vector `v` backwards: 10 9 -3 6 4
```
