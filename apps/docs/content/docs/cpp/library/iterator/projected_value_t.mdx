{/* source:cpp-iterator-projected-value-t:0001 */}
The alias template `projected_value_t` obtains the value type by stripping any reference and its topmost cv-qualifiers of the result type of applying `Proj` to `std::iter_value_t<I>&`.

{/* source:cpp-iterator-projected-value-t:0002 */}
`projected_value_t` is used to determine the default value type in some algorithms such as `ranges::contains`.

### Template parameters

{/* source:cpp-iterator-projected-value-t:0003 */}
<ParameterList>
  <Parameter name="I">an indirectly readable type</Parameter>
  <Parameter name="Proj">projection applied to an lvalue reference to value type of `I`</Parameter>
</ParameterList>
