{/* source:cpp-iterator-input-or-output-iterator:0001 */}
The `input_or_output_iterator` concept forms the basis of the iterator concept taxonomy; every iterator type satisfies the `input_or_output_iterator` requirements.

{/* source:cpp-iterator-input-or-output-iterator:0002 */}
The exposition-only concept `/*can-reference*/` is satisfied if and only if the type is [referenceable](/docs/cpp/library/meta#Definitions).

### Notes

{/* source:cpp-iterator-input-or-output-iterator:0003 */}
`input_or_output_iterator` itself only specifies operations for dereferencing and incrementing an iterator. Most algorithms will require additional operations, for example:

{/* source:cpp-iterator-input-or-output-iterator:0004 */}
- comparing iterators with sentinels (see [`sentinel_for`](/docs/cpp/library/iterator/sentinel_for));
- reading values from an iterator (see [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) and [`input_iterator`](/docs/cpp/library/iterator/input_iterator));
- writing values to an iterator (see [`indirectly_writable`](/docs/cpp/library/iterator/indirectly_writable) and [`output_iterator`](/docs/cpp/library/iterator/output_iterator));
- a richer set of iterator movements (see [`forward_iterator`](/docs/cpp/library/iterator/forward_iterator), [`bidirectional_iterator`](/docs/cpp/library/iterator/bidirectional_iterator), [`random_access_iterator`](/docs/cpp/library/iterator/random_access_iterator)).

{/* source:cpp-iterator-input-or-output-iterator:0005 */}
Unlike the [*LegacyIterator*](/docs/cpp/library/named_req/Iterator) requirements, the `input_or_output_iterator` concept does not require copyability.

{/* source:cpp-iterator-input-or-output-iterator:0006 */}
`*i` is required to be equality-preserving, although the increment operations required by [`weakly_incrementable`](/docs/cpp/library/iterator/weakly_incrementable) are not.

### Example

{/* source:cpp-iterator-input-or-output-iterator:0007 */}
A minimum iterator.

{/* source:cpp-iterator-input-or-output-iterator:0008 */}
```cpp
#include <cstddef>
#include <iterator>

struct SimpleIterator
{
    using difference_type = std::ptrdiff_t;

    int operator*();

    SimpleIterator& operator++();

    void operator++(int) { ++*this; }
};

static_assert(std::input_or_output_iterator<SimpleIterator>);
```
