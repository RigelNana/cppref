<DeclarationDoc since="C++20">
Defined in header [`<iterator>`](/docs/cpp/library/headers/iterator)

  <Declaration id="1" language="cpp" code={`struct default_sentinel_t {};`} />
  <Declaration id="2" language="cpp" code={`inline constexpr default_sentinel_t default_sentinel{};`} />

  <DeclarationDescription>
    {/* source:cpp-iterator-default-sentinel:0001 */}
    1. 1) `default_sentinel_t` is an empty class type used to denote the end of a range. It can be used together with iterator types that know the bound of their range (e.g., [`std::counted_iterator`](/docs/cpp/library/iterator/counted_iterator)).

    {/* source:cpp-iterator-default-sentinel:0002 */}
    2. 2) `default_sentinel` is a constant of type `default_sentinel_t`.
  </DeclarationDescription>
</DeclarationDoc>

### Example

{/* source:cpp-iterator-default-sentinel:0003 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <list>
 
int main()
{
    std::list<int> l{3, 1, 4, 1, 5, 9, 2, 6};
 
    std::ranges::copy(std::counted_iterator(std::begin(l), 4),
        std::default_sentinel, std::ostream_iterator<int>{std::cout, " "});
    std::cout << '\n';
}
```

Output:

```text
3 1 4 1
```
