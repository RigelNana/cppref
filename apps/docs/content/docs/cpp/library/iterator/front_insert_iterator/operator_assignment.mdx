{/* source:cpp-iterator-front-insert-iterator-operator:0001 */}
Inserts the given value `value` to the container.

{/* source:cpp-iterator-front-insert-iterator-operator:0002 */}
1. Results in `container->push_front(value)`.

{/* source:cpp-iterator-front-insert-iterator-operator:0003 */}
2. Results in `container->push_front(std::move(value))`.

{/* source:cpp-iterator-front-insert-iterator-operator:0004 */}
<ParameterList>
  <Parameter name="value">the value to insert</Parameter>
</ParameterList>

{/* source:cpp-iterator-front-insert-iterator-operator:0005 */}
`*this`

{/* source:cpp-iterator-front-insert-iterator-operator:0006 */}
```cpp
#include <deque>
#include <iostream>
#include <iterator>
 
int main()
{
    std::deque<int> q;
    std::front_insert_iterator<std::deque<int>> it(q);
 
    for (int i = 0; i < 10; ++i)
        it = i; // calls q.push_front(i)
 
    for (auto& elem : q)
        std::cout << elem << ' ';
    std::cout << '\n';
}
```

Output:

```text
9 8 7 6 5 4 3 2 1 0
```
