{/* source:cpp-iterator-front-insert-iterator:0001 */}
`std::front_insert_iterator` is a [`LegacyOutputIterator`](/docs/cpp/library/named_req/OutputIterator) that prepends elements to a container for which it was constructed. The container's `push_front()` member function is called whenever the iterator (whether dereferenced or not) is assigned to. Incrementing the `std::front_insert_iterator` is a no-op.

{/* source:cpp-iterator-front-insert-iterator:0006 */}
```cpp
#include <algorithm>
#include <deque>
#include <iostream>
#include <iterator>
#include <vector>
 
namespace stb
{
    void println(auto, auto const& d)
    {
        std::ranges::copy(d, std::ostream_iterator<int>(std::cout, " "));
        std::cout << '\n';
    }
}
 
int main()
{
    std::vector<int> v{1, 2, 3, 4, 5};
    std::deque<int> d;
 
    std::copy(v.begin(), v.end(),
              std::front_insert_iterator<std::deque<int>>(d));
              // or std::front_inserter(d)
 
    stb::println("{}", d);
}
```

Output:

```text
5 4 3 2 1
```
