{/* source:cpp-iterator-basic-const-iterator-operator-constant-iterator:0001 */}
Returns the converted constant iterator to which an underlying iterator [`current`](/docs/cpp/library/iterator/basic_const_iterator#Member_objects) can be explicitly or implicitly convertible.

{/* source:cpp-iterator-basic-const-iterator-operator-constant-iterator:0002 */}
`CI` satisfies the exposition-only concept `/*not-a-const-iterator*/` if and only if it's not a specialization of `basic_const_iterator`.

### Return value

{/* source:cpp-iterator-basic-const-iterator-operator-constant-iterator:0003 */}
1. 1) `current`

{/* source:cpp-iterator-basic-const-iterator-operator-constant-iterator:0004 */}
2. 2) `std::move(`*current*`)`

### Example

{/* source:cpp-iterator-basic-const-iterator-operator-constant-iterator:0005 */}
```cpp
#include <iterator>
#include <ranges>
#include <vector>

void foo(std::vector<int>::const_iterator) {}

int main()
{
    auto v = std::vector<int>();
    {
        // ranges::cbegin below returns vector<int>::const_iterator
        auto i1 = std::ranges::cbegin(v);
        foo(i1); // okay
    }

    auto t = v | std::views::take_while([](int const x) { return x < 100; });
    {
        // ranges::cbegin below returns basic_const_iterator<vector<int>::iterator>
        auto i2 = std::ranges::cbegin(t);
        foo(i2); // error until P2836R1
    }
}
```
