Compare a `basic_const_iterator` with another value. These function templates are used when the left operand is not a `basic_const_iterator`.

{/* source:cpp-iterator-basic-const-iterator-operator-cmp2:0002 */}
`I` satisfies the exposition-only concept `/*not-a-const-iterator*/` if and only if it's not a specialization of `basic_const_iterator`.

{/* source:cpp-iterator-basic-const-iterator-operator-cmp2:0003 */}
These functions are not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `basic_const_iterator<Iter>` is an associated class of the arguments.

### Parameters

### Return value

{/* source:cpp-iterator-basic-const-iterator-operator-cmp2:0005 */}
1. 1) `x < y.base()`

{/* source:cpp-iterator-basic-const-iterator-operator-cmp2:0006 */}
2. 2) `x > y.base()`

{/* source:cpp-iterator-basic-const-iterator-operator-cmp2:0007 */}
3. 3) `x <= y.base()`

{/* source:cpp-iterator-basic-const-iterator-operator-cmp2:0008 */}
4. 4) `x >= y.base()`

### Notes

{/* source:cpp-iterator-basic-const-iterator-operator-cmp2:0009 */}
If the left operand is a `basic_const_iterator`, the [`member comparison functions`](/docs/cpp/library/iterator/basic_const_iterator/operator_cmp) are used.

### Example

{/* source:cpp-iterator-basic-const-iterator-operator-cmp2:0010 */}
```cpp
#include <iterator>

int main()
{
    static int arr[1];
    static constexpr std::basic_const_iterator<int*> it = std::end(arr);
    static_assert(arr < it);
}
```
