{/* source:cpp-iterator-basic-const-iterator-operator-star:0001 */}
Returns a reference or pointer to the const version of the current element.

{/* source:cpp-iterator-basic-const-iterator-operator-star:0002 */}
1. 1) Returns `static_cast<std::iter_const_reference_t<Iter>>(*base())`.

{/* source:cpp-iterator-basic-const-iterator-operator-star:0003 */}
2. 2) If `Iter` models [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator), returns `std::to_address(base())`; otherwise, returns `std::addressof(*base())`.

### Parameters

{/* source:cpp-iterator-basic-const-iterator-operator-star:0004 */}
(none)

### Return value

{/* source:cpp-iterator-basic-const-iterator-operator-star:0005 */}
1. 1) Reference-to-const that refers to the current element. The result may be a prvalue (e.g. if `*base()` is a prvalue).

{/* source:cpp-iterator-basic-const-iterator-operator-star:0006 */}
2. 2) Pointer-to-const that points to the current element.
