{/* source:cpp-iterator-basic-const-iterator-common-type:0001 */}
The common type of two `basic_const_iterator`s or a `basic_const_iterator` and another iterator type is a `basic_const_iterator` of the common underlying type.

{/* source:cpp-iterator-basic-const-iterator-common-type:0002 */}
The common type is defined only if `T` and `U` share a common type which models [`input_iterator`](/docs/cpp/library/iterator/input_iterator).
