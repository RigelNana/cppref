Constructs a new iterator adaptor.

{/* source:cpp-iterator-basic-const-iterator-basic-const-iterator:0002 */}
1. 1) Default constructor. The underlying iterator is value-initialized.

{/* source:cpp-iterator-basic-const-iterator-basic-const-iterator:0003 */}
2. 2) The underlying iterator is initialized with `std::move(x)`.

{/* source:cpp-iterator-basic-const-iterator-basic-const-iterator:0004 */}
3. 3) The underlying iterator is initialized with that of `other`.

{/* source:cpp-iterator-basic-const-iterator-basic-const-iterator:0005 */}
4. 4) The underlying iterator is initialized with `std::forward<T>(x)`.
