{/* source:cpp-iterator-basic-const-iterator-operator-arith:0001 */}
Increments or decrements the iterator, by applying the corresponding operation on the underlying iterator.

{/* source:cpp-iterator-basic-const-iterator-operator-arith:0002 */}
1-3. Increments by one.

{/* source:cpp-iterator-basic-const-iterator-operator-arith:0003 */}
4,5) Decrements by one.

{/* source:cpp-iterator-basic-const-iterator-operator-arith:0004 */}
6,7) Advances the iterator by `n` or `-n` positions respectively.

### Return value

{/* source:cpp-iterator-basic-const-iterator-operator-arith:0005 */}
1,4,6,7) `*this`

{/* source:cpp-iterator-basic-const-iterator-operator-arith:0006 */}
3,5) A copy of `*this` that was made before the change

{/* source:cpp-iterator-basic-const-iterator-operator-arith:0007 */}
2. 2) (none)
