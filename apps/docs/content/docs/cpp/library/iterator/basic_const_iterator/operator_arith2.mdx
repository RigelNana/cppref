{/* source:cpp-iterator-basic-const-iterator-operator-arith2:0001 */}
Returns the iterator `i` incremented or decremented by `n`.

{/* source:cpp-iterator-basic-const-iterator-operator-arith2:0002 */}
1,2) Returns an iterator which is advanced by `n` positions.

{/* source:cpp-iterator-basic-const-iterator-operator-arith2:0003 */}
3. 3) Returns an iterator which is advanced by `-n` positions.

{/* source:cpp-iterator-basic-const-iterator-operator-arith2:0004 */}
These functions are not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::basic_const_iterator<Iter>` is an associated class of the arguments..

### Return value

{/* source:cpp-iterator-basic-const-iterator-operator-arith2:0005 */}
1,2) `basic_const_iterator(i.base() + n)`

{/* source:cpp-iterator-basic-const-iterator-operator-arith2:0006 */}
3. 3) `basic_const_iterator(i.base() - n)`
