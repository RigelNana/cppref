{/* source:cpp-iterator-basic-const-iterator-iter-move:0001 */}
Casts the result of dereferencing the underlying iterator to its associated const rvalue reference type.

{/* source:cpp-iterator-basic-const-iterator-iter-move:0002 */}
The return type `/*rvalue-reference*/` is `std::common_reference_t<const std::iter_value_t<Iter>&&, std::iter_rvalue_reference_t<Iter>>`.

{/* source:cpp-iterator-basic-const-iterator-iter-move:0003 */}
The function body is equivalent to `return static_cast</*rvalue-reference*/>(std::ranges::iter_move(i.base()));`.

{/* source:cpp-iterator-basic-const-iterator-iter-move:0004 */}
This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::basic_const_iterator<Iter>` is an associated class of the arguments.

### Parameter

{/* source:cpp-iterator-basic-const-iterator-iter-move:0005 */}
<ParameterList>

### Return value

{/* source:cpp-iterator-basic-const-iterator-iter-move:0006 */}

### Exceptions

{/* source:cpp-iterator-basic-const-iterator-iter-move:0007 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(noexcept(static_cast</*rvalue-reference*/>(std::ranges::iter_move(i.base()))))`
