<DeclarationDoc>
Defined in header [`<type_traits>`](/docs/cpp/library/headers/type_traits)

  <Declaration language="cpp" since="C++11" code={`template< bool B, class T, class F >
struct conditional;`} />

  <DeclarationDescription>
    {/* source:cpp-types-conditional:0001 */}
    Provides member typedef `type`, which is defined as `T` if `B` is `true` at compile time, or as `F` if `B` is `false`.

    {/* source:cpp-types-conditional:0002 */}
    If the program adds specializations for `std::conditional`, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

### Member types

### Possible implementation

{/* source:cpp-types-conditional:0005 */}
```cpp
template<bool B, class T, class F>
struct conditional { using type = T; };
 
template<class T, class F>
struct conditional<false, T, F> { using type = F; };
```

### Example

{/* source:cpp-types-conditional:0006 */}
```cpp
#include <iostream>
#include <type_traits>
#include <typeinfo>
 
int main() 
{
    using Type1 = std::conditional<true, int, double>::type;
    using Type2 = std::conditional<false, int, double>::type;
    using Type3 = std::conditional<sizeof(int) >= sizeof(double), int, double>::type;
 
    std::cout << typeid(Type1).name() << '\n';
    std::cout << typeid(Type2).name() << '\n';
    std::cout << typeid(Type3).name() << '\n';
}
```

Possible output:

```text
int
double
double
```
