`std::is_arithmetic` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-arithmetic:0002 */}
If `T` is an arithmetic type (that is, an integral type or a floating-point type) or a cv-qualified version thereof, provides the member constant `value` equal to `true`. For any other type, `value` is `false`.

{/* source:cpp-types-is-arithmetic:0003 */}
If the program adds specializations for `std::is_arithmetic` <InlineRevision since="C++17">or `std::is_arithmetic_v`</InlineRevision>, the behavior is undefined.

### Notes

{/* source:cpp-types-is-arithmetic:0007 */}
Arithmetic types are the built-in types for which the [arithmetic operators](/docs/cpp/language/expressions/operator_arithmetic) (`+`, `-`, `*`, `/`) are defined (possibly in combination with the usual arithmetic conversions).

{/* source:cpp-types-is-arithmetic:0008 */}
Specializations of [`std::numeric_limits`](/docs/cpp/library/utility/types/numeric_limits) are provided for all arithmetic types.

### Possible implementation

{/* source:cpp-types-is-arithmetic:0009 */}
```cpp
template<class T>
struct is_arithmetic : std::integral_constant<bool,
                                              std::is_integral<T>::value ||
                                              std::is_floating_point<T>::value> {};
```

### Example

{/* source:cpp-types-is-arithmetic:0010 */}
```cpp
#include <atomic>
#include <cstddef>
#include <type_traits>
 
class A {};
 
enum class B : int { e };
 
static_assert(
    std::is_arithmetic_v<bool>            == true  and
    std::is_arithmetic_v<char>            == true  and
    std::is_arithmetic_v<char const>      == true  and
    std::is_arithmetic_v<int>             == true  and
    std::is_arithmetic_v<int const>       == true  and
    std::is_arithmetic_v<float>           == true  and
    std::is_arithmetic_v<float const>     == true  and
    std::is_arithmetic_v<std::size_t>     == true  and
 
    std::is_arithmetic_v<char&>           == false and
    std::is_arithmetic_v<char*>           == false and
    std::is_arithmetic_v<int&>            == false and
    std::is_arithmetic_v<int*>            == false and
    std::is_arithmetic_v<float&>          == false and
    std::is_arithmetic_v<float*>          == false and
    std::is_arithmetic_v<A>               == false and
    std::is_arithmetic_v<B>               == false and
    std::is_arithmetic_v<decltype(B::e)>  == false and
    std::is_arithmetic_v<std::byte>       == false and
    std::is_arithmetic_v<std::atomic_int> == false
);
 
int main() {}
```
