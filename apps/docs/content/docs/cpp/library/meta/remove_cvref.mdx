{/* source:cpp-types-remove-cvref:0001 */}
If the type `T` is a reference type, provides the member typedef `type` which is the type referred to by `T` with its topmost cv-qualifiers removed. Otherwise `type` is `T` with its topmost cv-qualifiers removed.

{/* source:cpp-types-remove-cvref:0002 */}
If the program adds specializations for `std::remove_cvref`, the behavior is undefined.

### Member types

{/* source:cpp-types-remove-cvref:0003 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`type`</DescriptionTerm>
    <DescriptionBody>the type referred by `T` or `T` itself if it is not a reference, with top-level cv-qualifiers removed</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Helper types

{/* source:cpp-types-remove-cvref:0004 */}
<DeclarationDoc>

### Possible implementation

{/* source:cpp-types-remove-cvref:0005 */}
```cpp
template<class T>
struct remove_cvref
{
    using type = std::remove_cv_t<std::remove_reference_t<T>>;
};
```

### Example

{/* source:cpp-types-remove-cvref:0007 */}
```cpp
#include <type_traits>
 
int main()
{
    static_assert(std::is_same_v<std::remove_cvref_t<int>, int>);
    static_assert(std::is_same_v<std::remove_cvref_t<int&>, int>);
    static_assert(std::is_same_v<std::remove_cvref_t<int&&>, int>);
    static_assert(std::is_same_v<std::remove_cvref_t<const int&>, int>);
    static_assert(std::is_same_v<std::remove_cvref_t<const int[2]>, int[2]>);
    static_assert(std::is_same_v<std::remove_cvref_t<const int(&)[2]>, int[2]>);
    static_assert(std::is_same_v<std::remove_cvref_t<int(int)>, int(int)>);
}
```
