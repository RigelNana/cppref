<DeclarationDoc>
Defined in header [`<type_traits>`](/docs/cpp/library/headers/type_traits)

  <Declaration language="cpp" since="C++11" code={`template< class T >
struct make_unsigned;`} />
</DeclarationDoc>

{/* source:cpp-types-make-unsigned:0001 */}
If `T` is an integral (except `bool`) or enumeration type, provides the member typedef `type` which is the unsigned integer type corresponding to `T`, with the same cv-qualifiers.

{/* source:cpp-types-make-unsigned:0002 */}
If `T` is signed or unsigned `char`, `short`, `int`, `long`, `long long`; the unsigned type from this list corresponding to `T` is provided.

{/* source:cpp-types-make-unsigned:0003 */}
If `T` is an enumeration type or `char`, `wchar_t`<InlineRevision since="C++20">, `char8_t`</InlineRevision>, `char16_t`, `char32_t`; the unsigned integer type with the smallest [rank](/docs/cpp/language/expressions/implicit_cast#Integral_promotion) having the same `sizeof` as `T` is provided.

{/* source:cpp-types-make-unsigned:0004 */}
<Revision until="C++20">
Otherwise, the behavior is undefined.
</Revision>
<Revision since="C++20">
Otherwise, the program is ill-formed.
</Revision>

{/* source:cpp-types-make-unsigned:0005 */}
If the program adds specializations for `std::make_unsigned`, the behavior is undefined.

### Example

{/* source:cpp-types-make-unsigned:0008 */}
```cpp
#include <type_traits>

int main()
{
    using uchar_type = std::make_unsigned_t<char>;
    using uint_type  = std::make_unsigned_t<int>;
    using ulong_type = std::make_unsigned_t<volatile long>;

    static_assert(
        std::is_same_v<uchar_type, unsigned char> and
        std::is_same_v<uint_type, unsigned int> and
        std::is_same_v<ulong_type, volatile unsigned long>
    );
}
```
