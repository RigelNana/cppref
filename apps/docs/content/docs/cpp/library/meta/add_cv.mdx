    Provides the member typedef `type` which is the same as `T`, except it has a cv-qualifier added (unless `T` is a function, a reference, or already has this cv-qualifier)

    {/* source:cpp-types-add-cv:0002 */}
    1) adds both `const` and `volatile`

    {/* source:cpp-types-add-cv:0003 */}
    2) adds `const`

    {/* source:cpp-types-add-cv:0004 */}
    3) adds `volatile`

    {/* source:cpp-types-add-cv:0005 */}
    If the program adds specializations for any of the templates described on this page, the behavior is undefined.
  </DeclarationDescription>

### Possible implementation

{/* source:cpp-types-add-cv:0008 */}
```cpp
template<class T> struct add_cv { typedef const volatile T type; };
 
template<class T> struct add_const { typedef const T type; };
 
template<class T> struct add_volatile { typedef volatile T type; };
```

### Notes

{/* source:cpp-types-add-cv:0009 */}
These transformation traits can be used to establish [non-deduced contexts](/docs/cpp/language/templates/template_argument_deduction#Non-deduced_contexts) in template argument deduction:

{/* source:cpp-types-add-cv:0010 */}
```cpp
template<class T>
void f(const T&, const T&);
 
template<class T>
void g(const T&, std::add_const_t<T>&);
 
f(4.2, 0); // error, deduced conflicting types for 'T'
g(4.2, 0); // OK, calls g<double>
```

### Example

{/* source:cpp-types-add-cv:0011 */}
```cpp
#include <iostream>
#include <type_traits>
 
struct foo
{
    void m() { std::cout << "Non-cv\n"; }
    void m() const { std::cout << "Const\n"; }
    void m() volatile { std::cout << "Volatile\n"; }
    void m() const volatile { std::cout << "Const-volatile\n"; }
};
 
int main()
{
    foo{}.m();
    std::add_const<foo>::type{}.m();
    std::add_volatile<foo>::type{}.m();
    std::add_cv<foo>::type{}.m();
}
```

Output:

```text
Non-cv
Const
Volatile
Const-volatile
```
