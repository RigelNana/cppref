  <DeclarationDescription>
    {/* source:cpp-types-is-swappable:0001 */}
    1. If the expressions `swap(std::declval<T>(), std::declval<U>())` and `swap(std::declval<U>(), std::declval<T>())` are both well-formed in unevaluated context after `using std::swap;` (see [Swappable](/docs/cpp/library/named_req/Swappable)), provides the member constant `value` equal `true`. Otherwise, `value` is `false`.

    {/* source:cpp-types-is-swappable:0002 */}
    2. [Access checks](/docs/cpp/language/classes/access) are performed as if from a context unrelated to either type.

    {/* source:cpp-types-is-swappable:0003 */}
    3. Same as (1), but evaluations of both expressions from (1) are known not to throw exceptions.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-types-is-swappable:0004 */}
| Type trait | The value of the member constant `value` | |
| --- | --- | --- |
| | `T` is a [referenceable type](/docs/cpp/library/meta#Definitions) | `T` is not a referenceable type |
| (2) | `std::is_swappable_with<T&, T&>::value` | `false` |
| (4) | `std::is_nothrow_swappable_with<T&, T&>::value` | `false` |

{/* source:cpp-types-is-swappable:0005 */}
If `T` or `U` is not a complete type, (possibly cv-qualified) `void`, or an array of unknown bound, the behavior is undefined.

{/* source:cpp-types-is-swappable:0006 */}
If an instantiation of a template above depends, directly or indirectly, on an incomplete type, and that instantiation could yield a different result if that type were hypothetically completed, the behavior is undefined.

{/* source:cpp-types-is-swappable:0007 */}
If the program adds specializations for any of the templates described on this page, the behavior is undefined.

### Notes

{/* source:cpp-types-is-swappable:0010 */}
This trait does not check anything outside the immediate context of the swap expressions: if the use of `T` or `U` would trigger template specializations, generation of implicitly-defined special member functions etc, and those have errors, the actual swap may not compile even if `std::is_swappable_with<T, U>::value` compiles and evaluates to `true`.
