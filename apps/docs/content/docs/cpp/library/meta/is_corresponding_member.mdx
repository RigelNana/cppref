  <Declaration language="cpp" since="C++20" code={`template< class S1, class S2, class M1, class M2 >
constexpr bool is_corresponding_member( M1 S1::* mp, M2 S2::* mq ) noexcept;`} />
</DeclarationDoc>

{/* source:cpp-types-is-corresponding-member:0001 */}
Determines whether `mp` and `mq` refer corresponding members in the [common initial sequence](/docs/cpp/language/classes/data_members#Standard-layout) of `S1` and `S2`. The program is ill-formed if either `S1` or `S2` is an [incomplete type](/docs/cpp/language/basic_concepts/type-id#Incomplete_type).

{/* source:cpp-types-is-corresponding-member:0002 */}
If either `S1` or `S2` is not a [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType), or either `M1` or `M2` is not an object type, or either `mp` or `mq` is equal to `nullptr`, the result is always `false`.

### Parameters

{/* source:cpp-types-is-corresponding-member:0003 */}
<ParameterList>
  <Parameter name="mp, mq">pointers-to-member to detect</Parameter>
</ParameterList>

### Return value

{/* source:cpp-types-is-corresponding-member:0004 */}
`true` if `mp` and `mq` refer corresponding members in the common initial sequence of `S1` and `S2`, otherwise `false`.

### Notes

{/* source:cpp-types-is-corresponding-member:0005 */}
The type of a pointer-to-member expression `&S::m` is not always `M S::*`, where `m` is of type `M`, because `m` may be a member inherited from a base class of `S`. The template arguments can be specified in order to avoid potentially surprising results.

### Example

{/* source:cpp-types-is-corresponding-member:0006 */}
```cpp
#include <type_traits>
 
struct Foo
{
    int x;
    double d;
};
 
struct Bar
{
    int y;
    double z;
};
 
struct Baz : Foo, Bar {}; // not standard-layout
 
static_assert(
    std::is_same_v<decltype(&Baz::x), int Foo::*> == true &&
    std::is_same_v<decltype(&Baz::y), int Bar::*> == true &&
    std::is_corresponding_member(&Foo::x, &Bar::y) == true &&
    std::is_corresponding_member(&Foo::d, &Bar::z) == true &&
    std::is_corresponding_member(&Baz::x, &Baz::y) == true &&
    std::is_corresponding_member<Baz, Baz, int, int>(&Baz::x, &Baz::y) == false
);
 
int main() {}
```
