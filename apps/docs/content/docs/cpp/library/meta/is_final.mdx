{/* source:cpp-types-is-final:0001 */}
`std::is_final` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-final:0002 */}
If `T` is a [final](/docs/cpp/language/classes/final) class, provides the member constant `value` equal `true`. For any other type, `value` is `false`.

{/* source:cpp-types-is-final:0003 */}
If `T` is an incomplete class type, the behavior is undefined.

{/* source:cpp-types-is-final:0004 */}
If the program adds specializations for `std::is_final`<InlineRevision since="C++17"> or `std::is_final_v`</InlineRevision>, the behavior is undefined.

### Notes

{/* source:cpp-types-is-final:0008 */}
`std::is_final` is introduced by the resolution of [LWG issue 2112](https://cplusplus.github.io/LWG/issue2112).

{/* source:cpp-types-is-final:0009 */}
A [union](/docs/cpp/language/classes/union) can be declared `final` (and `std::is_final` will detect that), even though unions cannot be used as bases in any case.

### Example

{/* source:cpp-types-is-final:0011 */}
```cpp
#include <type_traits>

class A {};
static_assert(std::is_final_v<A> == false);

class B final {};
static_assert(std::is_final_v<B> == true);

union U final
{
    int x;
    double d;
};
static_assert(std::is_final_v<U> == true);

int main()
{
}
```
