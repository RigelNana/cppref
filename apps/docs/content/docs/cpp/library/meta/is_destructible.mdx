  <DeclarationDescription>
    {/* source:cpp-types-is-destructible:0001 */}
    1. If `T` is a reference type, provides the member constant `value` equal to `true`.
       {/* source:cpp-types-is-destructible:0002 */}
       - If `T` is (possibly cv-qualified) `void`, a function type, or an array of unknown bound, `value` equals `false`.
       {/* source:cpp-types-is-destructible:0003 */}
       - If `T` is an object type, then, for the type `U` that is `std::remove_all_extents<T>::type`, if the expression `std::declval<U&>().~U()` is well-formed in unevaluated context, `value` equals `true`. Otherwise, `value` equals `false`.
    {/* source:cpp-types-is-destructible:0004 */}
    2. Same as (1) and additionally `std::remove_all_extents<T>::type` is either a non-class type or a class type with a [trivial destructor](/docs/cpp/language/classes/destructor#Trivial_destructor).
    {/* source:cpp-types-is-destructible:0005 */}
    3. Same as (1), but the destructor is `noexcept`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-types-is-destructible:0006 */}
If `T` is not a complete type, (possibly cv-qualified) `void`, or an array of unknown bound, the behavior is undefined.

{/* source:cpp-types-is-destructible:0007 */}
If an instantiation of a template above depends, directly or indirectly, on an incomplete type, and that instantiation could yield a different result if that type were hypothetically completed, the behavior is undefined.

{/* source:cpp-types-is-destructible:0008 */}
If the program adds specializations for any of the templates described on this page, the behavior is undefined.

### Notes

{/* source:cpp-types-is-destructible:0011 */}
Because the C++ program terminates if a destructor throws an exception during stack unwinding (which usually cannot be predicted), all practical destructors are non-throwing even if they are not declared `noexcept`. All destructors found in the C++ standard library are non-throwing.

{/* source:cpp-types-is-destructible:0012 */}
Storage occupied by [trivially destructible](/docs/cpp/language/classes/destructor#Trivial_destructor) objects [may be reused](/docs/cpp/language/basic_concepts/lifetime#Storage_reuse) without calling the destructor.

### Possible implementation

{/* source:cpp-types-is-destructible:0013 */}
[`is_destructible (1)`](/docs/cpp/library/meta/is_destructible#Version_1)

```cpp
// C++20 required
template<typename t>
struct is_destructible
    : std::integral_constant<bool, requires(t object) { object.~t(); }>
{};
```

[`is_trivially_destructible (2)`](/docs/cpp/library/meta/is_destructible#Version_2)

```cpp
// Not real C++. Shall P2996 be approved, the following implementation will be available:
template<typename t>
struct is_trivially_destructible
     : std::integral_constant<bool, std::meta::type_is_trivially_destructible(^t)>
{};
```

[`is_nothrow_destructible (3)`](/docs/cpp/library/meta/is_destructible#Version_3)

```cpp
// C++20 required
template<typename t>
struct is_nothrow_destructible
    : std::integral_constant<bool, requires(t object) { {object.~t()} noexcept; }>
{};
```

### Example

{/* source:cpp-types-is-destructible:0014 */}
```cpp
#include <iostream>
#include <string>
#include <type_traits>

struct Foo
{
    std::string str;
    ~Foo() noexcept {};
};

struct Bar
{
    ~Bar() = default;
};

static_assert(std::is_destructible<std::string>::value == true);
static_assert(std::is_trivially_destructible_v<Foo> == false);
static_assert(std::is_nothrow_destructible<Foo>() == true);
static_assert(std::is_trivially_destructible<Bar>{} == true);

int main() {}
```
