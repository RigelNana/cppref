<DeclarationDoc>
Defined in header [`<type_traits>`](/docs/cpp/library/headers/type_traits)

  <Declaration language="cpp" since="C++11" code={`template< std::size_t Len, class... Types >
struct aligned_union;`} /> (deprecated in C++23)

  <DeclarationDescription>
    {/* source:cpp-types-aligned-union:0001 */}
    Provides the nested type `type`, which is a [trivial](/docs/cpp/library/named_req/TrivialType) [standard-layout](/docs/cpp/library/named_req/StandardLayoutType) type of a size and alignment suitable for use as uninitialized storage for an object of any of the types listed in `Types`. The size of the storage is at least `Len`. `std::aligned_union` also determines the strictest (largest) alignment requirement among all `Types` and makes it available as the constant `alignment_value`.

    {/* source:cpp-types-aligned-union:0002 */}
    If `sizeof...(Types) == 0` or if any of the types in `Types` is not a complete object type, the behavior is undefined.

    {/* source:cpp-types-aligned-union:0003 */}
    It is implementation-defined whether any [extended alignment](/docs/cpp/language/basic_concepts/objects#Alignment) is supported.

    {/* source:cpp-types-aligned-union:0004 */}
    If the program adds specializations for `std::aligned_union`, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

### Possible implementation

{/* source:cpp-types-aligned-union:0008 */}
```cpp
#include <algorithm>
 
template<std::size_t Len, class... Types>
struct aligned_union
{
    static constexpr std::size_t alignment_value = std::max({alignof(Types)...});
 
    struct type
    {
        alignas(alignment_value) char _s[std::max({Len, sizeof(Types)...})];
    };
};
```

### Example

{/* source:cpp-types-aligned-union:0009 */}
```cpp
#include <iostream>
#include <string>
#include <type_traits>
 
int main()
{
    std::cout << sizeof(std::aligned_union_t<0, char>) << ' ' // 1
              << sizeof(std::aligned_union_t<2, char>) << ' ' // 2
              << sizeof(std::aligned_union_t<2, char[3]>) << ' ' // 3 (!)
              << sizeof(std::aligned_union_t<3, char[4]>) << ' ' // 4
              << sizeof(std::aligned_union_t<1, char, int, double>) << ' '    // 8
              << sizeof(std::aligned_union_t<12, char, int, double>) << '\n'; // 16 (!)
 
    using var_t = std::aligned_union<16, int, std::string>;
 
    std::cout << "var_t::alignment_value = " << var_t::alignment_value << '\n'
              << "sizeof(var_t::type) = " << sizeof(var_t::type) << '\n';
 
    var_t::type aligned_storage;
    int* int_ptr = new(&aligned_storage) int(42); // placement new
    std::cout << "*int_ptr = " << *int_ptr << '\n';
 
    std::string* string_ptr = new(&aligned_storage) std::string("bar");
    std::cout << "*string_ptr = " << *string_ptr << '\n';
    *string_ptr = "baz";
    std::cout << "*string_ptr = " << *string_ptr << '\n';
    string_ptr->~basic_string();
}
```

Possible output:

```text
1 2 3 4 8 16
var_t::alignment_value = 8
sizeof(var_t::type) = 32
*int_ptr = 42
*string_ptr = bar
*string_ptr = baz
```
