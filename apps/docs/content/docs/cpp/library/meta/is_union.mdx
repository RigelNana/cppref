`std::is_union` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-union:0002 */}
Checks whether `T` is a [union type](/docs/cpp/language/classes/union). Provides the member constant `value`, which is equal to `true` if `T` is a union type. Otherwise, `value` is equal to `false`.

{/* source:cpp-types-is-union:0003 */}
If the program adds specializations for `std::is_union` or `std::is_union_v`, the behavior is undefined.

### Example

{/* source:cpp-types-is-union:0007 */}
```cpp
#include <type_traits>

struct A {};
static_assert(!std::is_union_v<A>);

typedef union
{
    int a;
    float b;
} B;
static_assert(std::is_union_v<B>);

struct C { B d; };
static_assert(!std::is_union_v<C>);

static_assert(!std::is_union_v<int>);

int main() {}
```
