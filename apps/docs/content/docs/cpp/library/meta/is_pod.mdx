{/* source:cpp-types-is-pod:0001 */}
`std::is_pod` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-pod:0002 */}
If `T` is a [POD type](/docs/cpp/library/named_req/PODType) ("plain old data type"), provides the member constant `value` equal to `true`. For any other type, `value` is `false`.

{/* source:cpp-types-is-pod:0003 */}
If `std::remove_all_extents_t<T>` is an incomplete type and not (possibly cv-qualified) `void`, the behavior is undefined.

{/* source:cpp-types-is-pod:0004 */}
If the program adds specializations for `std::is_pod` or `std::is_pod_v`, the behavior is undefined.

### Example

{/* source:cpp-types-is-pod:0008 */}
```cpp
#include <type_traits>

struct A { int m; };
static_assert(std::is_pod_v<A> == true);

class B: public A { int m; };
static_assert(std::is_pod_v<B> == false);

struct C { virtual void foo(); };
static_assert(std::is_pod_v<C> == false);

int main() {}
```
