{/* source:cpp-types-is-copy-assignable:0001 */}
| Type trait | The value of the member constant `value` | |
| --- | --- | --- |
| | `T` is a [referenceable type](/docs/cpp/library/meta#Definitions) | `T` is not a referenceable type |
| (1) | `std::is_assignable<T&, const T&>::value` | `false` |
| (2) | `std::is_trivially_assignable<T&, const T&>::value` | `false` |
| (3) | `std::is_nothrow_assignable<T&, const T&>::value` | `false` |

{/* source:cpp-types-is-copy-assignable:0002 */}
If `T` is not a complete type, (possibly cv-qualified) `void`, or an array of unknown bound, the behavior is undefined.

{/* source:cpp-types-is-copy-assignable:0003 */}
If an instantiation of a template above depends, directly or indirectly, on an incomplete type, and that instantiation could yield a different result if that type were hypothetically completed, the behavior is undefined.

{/* source:cpp-types-is-copy-assignable:0004 */}
If the program adds specializations for any of the templates described on this page, the behavior is undefined.

### Possible implementation

{/* source:cpp-types-is-copy-assignable:0007 */}
```cpp
template<class T>
struct is_copy_assignable
    : std::is_assignable<typename std::add_lvalue_reference<T>::type,
                         typename std::add_lvalue_reference<const T>::type> {};
 
template<class T>
struct is_trivially_copy_assignable
    : std::is_trivially_assignable<typename std::add_lvalue_reference<T>::type,
                                   typename std::add_lvalue_reference<const T>::type> {};
 
template<class T>
struct is_nothrow_copy_assignable
    : std::is_nothrow_assignable<typename std::add_lvalue_reference<T>::type,
                                 typename std::add_lvalue_reference<const T>::type> {};
```

### Notes

{/* source:cpp-types-is-copy-assignable:0008 */}
The trait `std::is_copy_assignable` is less strict than [CopyAssignable](/docs/cpp/library/named_req/CopyAssignable) because it does not check the type of the result of the assignment (which, for a [CopyAssignable](/docs/cpp/library/named_req/CopyAssignable) type, must be an lvalue of type `T`) and does not check the semantic requirement that the argument expression remains unchanged. It also does not check that `T` satisfies [MoveAssignable](/docs/cpp/library/named_req/MoveAssignable), which is required of all [CopyAssignable](/docs/cpp/library/named_req/CopyAssignable) types.

### Example

{/* source:cpp-types-is-copy-assignable:0009 */}
```cpp
#include <iostream>
#include <type_traits>
#include <utility>
 
struct Foo { int n; };
 
int main()
{
    std::cout << std::boolalpha
              << "Foo is trivially copy-assignable? "
              << std::is_trivially_copy_assignable<Foo>::value << '\n'
              << "int[2] is copy-assignable? "
              << std::is_copy_assignable<int[2]>::value << '\n'
              << "int is nothrow copy-assignable? "
              << std::is_nothrow_copy_assignable<int>::value << '\n';
}
```

Output:

```text
Foo is trivially copy-assignable? true
int[2] is copy-assignable? false
int is nothrow copy-assignable? true
```
