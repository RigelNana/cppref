{/* source:cpp-types-is-literal-type:0001 */}
`std::is_literal_type` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-literal-type:0002 */}
(This type trait has been deprecated[1] and removed[2] as offering negligible value to generic code.)

{/* source:cpp-types-is-literal-type:0003 */}
If `T` satisfies all requirements of [LiteralType](/docs/cpp/library/named_req/LiteralType), provides the member constant `value` equal to `true`. For any other type, `value` is `false`.

{/* source:cpp-types-is-literal-type:0004 */}
If `std::remove_all_extents_t<T>` is an incomplete type and not (possibly cv-qualified) `void`, the behavior is undefined.

{/* source:cpp-types-is-literal-type:0005 */}
If the program adds specializations for `std::is_literal_type` or `std::is_literal_type_v`, the behavior is undefined.

### Notes

{/* source:cpp-types-is-literal-type:0009 */}
Only literal types may be used as parameters to or returned from [constexpr functions](/docs/cpp/language/declarations/constexpr#constexpr_function). Only literal classes may have constexpr member functions.

### Example

{/* source:cpp-types-is-literal-type:0010 */}
```cpp
#include <type_traits>

struct A { int m; };
static_assert(std::is_literal_type_v<A> == true);

struct B { virtual ~B(); };
static_assert(std::is_literal_type_v<B> == false);

int main() {}
```
