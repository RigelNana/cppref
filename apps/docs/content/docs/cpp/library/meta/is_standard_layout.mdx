{/* source:cpp-types-is-standard-layout:0001 */}
`std::is_standard_layout` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-standard-layout:0002 */}
If `T` is a [standard-layout type](/docs/cpp/library/named_req/StandardLayoutType), provides the member constant `value` equal to `true`. For any other type, `value` is `false`.

{/* source:cpp-types-is-standard-layout:0003 */}
If `std::remove_all_extents_t<T>` is an incomplete type and not (possibly cv-qualified) `void`, the behavior is undefined.

{/* source:cpp-types-is-standard-layout:0004 */}
If the program adds specializations for `std::is_standard_layout` or `std::is_standard_layout_v`, the behavior is undefined.

### Notes

{/* source:cpp-types-is-standard-layout:0008 */}
A pointer to a standard-layout class may be converted (with `reinterpret_cast`) to a pointer to its first non-static data member and vice versa.

{/* source:cpp-types-is-standard-layout:0009 */}
If a standard-layout union holds two or more standard-layout structs, it is permitted to inspect the common initial part of them.

{/* source:cpp-types-is-standard-layout:0010 */}
The macro [`offsetof`](/docs/cpp/library/utility/types/offsetof) is only guaranteed to be usable with standard-layout classes.

### Example

{/* source:cpp-types-is-standard-layout:0011 */}
```cpp
#include <type_traits>

struct A { int m; };
static_assert(std::is_standard_layout_v<A> == true);

class B: public A { int m; };
static_assert(std::is_standard_layout_v<B> == false);

struct C { virtual void foo(); };
static_assert(std::is_standard_layout_v<C> == false);

int main() {}
```
