{/* source:cpp-types-is-abstract:0001 */}
`std::is_abstract` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-abstract:0002 */}
If `T` is an [abstract class](/docs/cpp/language/classes/abstract_class) (that is, a non-union class that declares or inherits at least one pure virtual function), provides the member constant `value` equal to `true`. For any other type, `value` is `false`.

{/* source:cpp-types-is-abstract:0003 */}
If `T` is an incomplete non-union class type, the behavior is undefined.

{/* source:cpp-types-is-abstract:0004 */}
If the program adds specializations for `std::is_abstract` or `std::is_abstract_v`, the behavior is undefined.

### Example

{/* source:cpp-types-is-abstract:0008 */}
```cpp
#include <iostream>
#include <type_traits>
 
struct A { int m; };
static_assert(std::is_abstract_v<A> == false);
 
struct B { virtual void foo(); };
static_assert(std::is_abstract_v<B> == false);
 
struct C { virtual void foo() = 0; };
static_assert(std::is_abstract_v<C> == true);
 
struct D : C {};
static_assert(std::is_abstract_v<D> == true);
 
int main() {}
```
