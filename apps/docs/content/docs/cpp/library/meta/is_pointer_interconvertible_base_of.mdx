{/* source:cpp-types-is-pointer-interconvertible-base-of:0001 */}
If `Derived` is unambiguously derived from `Base` and every `Derived` object is [pointer-interconvertible](/docs/cpp/language/expressions/static_cast#pointer-interconvertible) with its `Base` subobject, or if both are the same non-union class (in both cases ignoring cv-qualification), provides the member constant `value` equal to `true`. Otherwise `value` is `false`.

{/* source:cpp-types-is-pointer-interconvertible-base-of:0002 */}
If both `Base` and `Derived` are non-union class types, and they are not the same type (ignoring cv-qualification), `Derived` shall be a [complete type](/docs/cpp/language/basic_concepts/incomplete_type); otherwise the behavior is undefined.

{/* source:cpp-types-is-pointer-interconvertible-base-of:0003 */}
If the program adds specializations for `std::is_pointer_interconvertible_base_of` or `std::is_pointer_interconvertible_base_of_v`, the behavior is undefined.

### Notes

{/* source:cpp-types-is-pointer-interconvertible-base-of:0006 */}
`std::is_pointer_interconvertible_base_of_v<T, U>` may be `true` even if `T` is a private or protected base class of `U`.

{/* source:cpp-types-is-pointer-interconvertible-base-of:0007 */}
Let

{/* source:cpp-types-is-pointer-interconvertible-base-of:0008 */}
- `U` be a complete object type,
- `T` be a complete object type with cv-qualification not less than `U`,
- `u` be any valid lvalue of `U`,

{/* source:cpp-types-is-pointer-interconvertible-base-of:0009 */}
`reinterpret_cast<T&>(u)` always has well-defined result if `std::is_pointer_interconvertible_base_of_v<T, U>` is `true`.

{/* source:cpp-types-is-pointer-interconvertible-base-of:0010 */}
If `T` and `U` are not the same type (ignoring cv-qualification) and `T` is a pointer-interconvertible base class of `U`, then both `std::is_standard_layout_v<T>` and `std::is_standard_layout_v<U>` are `true`.

{/* source:cpp-types-is-pointer-interconvertible-base-of:0011 */}
If `T` is standard layout class type, then all base classes of `T` (if any) are pointer-interconvertible base class of `T`.

### Example

{/* source:cpp-types-is-pointer-interconvertible-base-of:0013 */}
```cpp
#include <type_traits>

struct Foo {};

struct Bar {};

class Baz : Foo, public Bar { int x; };

class NonStdLayout : public Baz { int y; };

static_assert(std::is_pointer_interconvertible_base_of_v<Bar, Baz>);
static_assert(std::is_pointer_interconvertible_base_of_v<Foo, Baz>);
static_assert(not std::is_pointer_interconvertible_base_of_v<Baz, NonStdLayout>);
static_assert(std::is_pointer_interconvertible_base_of_v<NonStdLayout, NonStdLayout>);

int main() {}
```
