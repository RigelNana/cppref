{/* source:cpp-types-reference-converts-from-temporary:0001 */}
Let `V` be [`std::remove_cv_t<U>`](/docs/cpp/library/meta/remove_cv) if `U` is a scalar type or *cv* `void`, or `U` otherwise. If `T` is a reference type, and given a hypothetical expression `e` such that `decltype(e)` is `V`, the variable definition `T ref = e;` is well-formed and [binds a temporary object](/docs/cpp/language/initialization/reference_initialization#Lifetime_of_a_temporary) to `ref`, then provides the member constant `value` equal to `true`. Otherwise, `value` is `false`.

{/* source:cpp-types-reference-converts-from-temporary:0002 */}
If `T` is an lvalue reference type to a const- but not volatile-qualified object type or an rvalue reference type, both [`std::remove_reference_t<T>`](/docs/cpp/library/meta/remove_reference) and [`std::remove_reference_t<U>`](/docs/cpp/library/meta/remove_reference) shall be [complete types](/docs/cpp/language/basic_concepts/type-id#Incomplete_type), *cv* `void`, or an [arrays of unknown bound](/docs/cpp/language/declarations/array#Arrays_of_unknown_bound); otherwise the behavior is undefined.

{/* source:cpp-types-reference-converts-from-temporary:0003 */}
If an instantiation of a template above depends, directly or indirectly, on an incomplete type, and that instantiation could yield a different result if that type were hypothetically completed, the behavior is undefined.

{/* source:cpp-types-reference-converts-from-temporary:0004 */}
If the program adds specializations for `std::reference_converts_from_temporary` or `std::reference_converts_from_temporary_v`, the behavior is undefined.

### Notes

{/* source:cpp-types-reference-converts-from-temporary:0007 */}
`std::reference_converts_from_temporary` can be used for rejecting some cases that always produce dangling references.

### Example

{/* source:cpp-types-reference-converts-from-temporary:0008 */}
```cpp
#include <type_traits>
 
int main() {}
 
static_assert(
    std::reference_converts_from_temporary_v<int&&, int> == true &&
    std::reference_converts_from_temporary_v<const int&, int> == true &&
    std::reference_converts_from_temporary_v<int&&, int&&> == false &&
    std::reference_converts_from_temporary_v<const int&, int&&> == false &&
    std::reference_converts_from_temporary_v<int&&, long&&> == true &&
    std::reference_converts_from_temporary_v<int&&, long> == true);
```
