{/* source:cpp-meta:0000 */}
C++ provides metaprogramming facilities, such as type traits, compile-time rational arithmetic, and compile-time integer sequences.

{/* source:cpp-meta:0001 */}
The following types are collectively called *referenceable types*:

{/* source:cpp-meta:0002 */}
- [object types](/docs/cpp/language/basic_concepts/type-id#Object_type)
- [function types](/docs/cpp/language/functions/function#Function_type) without cv and ref
- [reference types](/docs/cpp/language/declarations/reference)

{/* source:cpp-meta:0003 */}
For any referenceable type `T`, a reference to it can be created<sup>[1]</sup>.

{/* source:cpp-meta:0004 */}
1. [↑](/docs/cpp/language/declarations/reference#Reference_collapsing) For reference types, this can be done via reference collapsing.

{/* source:cpp-meta:0005 */}
Type traits define compile-time template-based interfaces to query the properties of types.

{/* source:cpp-meta:0006 */}
Attempting to specialize a template defined in the [`<type_traits>`](/docs/cpp/library/headers/type_traits) header and listed in this page results in undefined behavior, except that [`std::common_type`](/docs/cpp/library/meta/common_type) <InlineRevision since="C++20">and [`std::basic_common_reference`](/docs/cpp/library/meta/common_reference)</InlineRevision> may be specialized as required in description.

{/* source:cpp-meta:0007 */}
A template defined in the [`<type_traits>`](/docs/cpp/library/headers/type_traits) header may be instantiated with an incomplete type unless otherwise specified, notwithstanding the general prohibition against instantiating standard library templates with incomplete types.

{/* source:cpp-meta:0008 */}
Most of non-transforming type traits need to be publicly and unambiguously derived from [`std::integral_constant`](/docs/cpp/library/meta/integral_constant) in order to satisfy the requirements of [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait) or [BinaryTypeTrait](/docs/cpp/library/named_req/BinaryTypeTrait).

{/* source:cpp-meta:0009 */}
Defined in header [`<type_traits>`](/docs/cpp/library/headers/type_traits)

{/* source:cpp-meta:0012 */}
Unary type traits can be used to query the boolean properties of a type at compile time.

{/* source:cpp-meta:0013 */}
All these type traits satisfy [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait), the base characteristic of each type trait is either [`std::true_type`](/docs/cpp/library/meta/integral_constant) or [`std::false_type`](/docs/cpp/library/meta/integral_constant), depending on whether the corresponding condition is met.
