{/* source:cpp-types-is-trivial:0001 */}
`std::is_trivial` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-trivial:0002 */}
If `T` is a [trivial type](/docs/cpp/library/named_req/TrivialType), provides the member constant `value` equal to `true`. For any other type, `value` is `false`.

{/* source:cpp-types-is-trivial:0003 */}
If `std::remove_all_extents_t<T>` is an incomplete type and not (possibly cv-qualified) `void`, the behavior is undefined.

{/* source:cpp-types-is-trivial:0004 */}
If the program adds specializations for `std::is_trivial` or `std::is_trivial_v`, the behavior is undefined.

### Example

{/* source:cpp-types-is-trivial:0008 */}
```cpp
#include <type_traits>

struct A { int m; };
static_assert(std::is_trivial_v<A> == true);

struct B { B() {} };
static_assert(std::is_trivial_v<B> == false);

// The following class shows why std::is_trivial(_v) may be a pitfall.
class C
{
private:
    C() = default;
};

static_assert(std::is_trivial_v<C> == true);
static_assert(std::is_trivially_default_constructible_v<C> == false);

int main() {}
```
