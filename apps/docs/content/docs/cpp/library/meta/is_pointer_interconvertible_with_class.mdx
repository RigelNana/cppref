  <Declaration id="1" language="cpp" since="C++20" code={`template< class S, class M >
constexpr bool is_pointer_interconvertible_with_class( M S::* mp ) noexcept;`} />

{/* source:cpp-types-is-pointer-interconvertible-with-class:0001 */}
Given an object `s` of type `S`, determines whether `s.*mp` refers to a subobject of `s` and `s` is [pointer-interconvertible](/docs/cpp/language/expressions/static_cast#pointer-interconvertible) with its subobject `s.*mp`. The program is ill-formed if `S` is not a [complete type](/docs/cpp/language/basic_concepts/type-id#Incomplete_type).

{/* source:cpp-types-is-pointer-interconvertible-with-class:0002 */}
If `S` is not a [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType), or `M` is not an object type, or `mp` is equal to `nullptr`, the result is always `false`.

### Parameters

{/* source:cpp-types-is-pointer-interconvertible-with-class:0003 */}
<ParameterList>
  <Parameter name="mp">a pointer-to-member to detect</Parameter>
</ParameterList>

### Return value

{/* source:cpp-types-is-pointer-interconvertible-with-class:0004 */}
`true` if `s.*mp` refers a subobject of `s` and `s` is pointer-interconvertible with its subobject `s.*mp`, otherwise `false`, where `s` is an object of type `S`.

### Notes

{/* source:cpp-types-is-pointer-interconvertible-with-class:0005 */}
The type of a pointer-to-member expression `&S::m` is not always `M S::*`, where `m` is of type `M`, because `m` may be a member inherited from a base class of `S`. The template arguments can be specified in order to avoid potentially surprising results.

{/* source:cpp-types-is-pointer-interconvertible-with-class:0006 */}
If there is a value `mp` of type `M S::*` such that `std::is_pointer_interconvertible_with_class(mp) == true`, then `reinterpret_cast<M&>(s)` has well-defined result and it refers the same subobject as `s.*mp`, where `s` is a valid lvalue of type `S`.

{/* source:cpp-types-is-pointer-interconvertible-with-class:0007 */}
On common platforms, the bit pattern of `mp` is all zero if `std::is_pointer_interconvertible_with_class(mp) == true`.

### Example

{/* source:cpp-types-is-pointer-interconvertible-with-class:0009 */}
```cpp
#include <type_traits>

struct Foo { int x; };
struct Bar { int y; };

struct Baz : Foo, Bar {}; // not standard-layout

static_assert( not std::is_same_v<decltype(&Baz::x), int Baz::*> );
static_assert( std::is_pointer_interconvertible_with_class(&Baz::x) );
static_assert( not std::is_pointer_interconvertible_with_class<Baz, int>(&Baz::x) );

int main() { }
```
