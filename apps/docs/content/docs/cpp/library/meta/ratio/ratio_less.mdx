{/* source:cpp-numeric-ratio-ratio-less:0001 */}
If the ratio `R1` is less than the ratio `R2`, provides the member constant `value` equal `true`. Otherwise, `value` is `false`.

### Helper variable template

{/* source:cpp-numeric-ratio-ratio-less:0002 */}
<DeclarationDoc>
  <Declaration language="cpp" since="C++17" code={`template< class R1, class R2 >
constexpr bool ratio_less_v = ratio_less<R1, R2>::value;`} />
</DeclarationDoc>

### Example

{/* source:cpp-numeric-ratio-ratio-less:0004 */}
```cpp
#include <iostream>
#include <ratio>

int main()
{
    using x = std::ratio<69, 90>;
    using y = std::ratio<70, 90>;

    if constexpr (std::ratio_less_v<x, y>)
        std::cout << x::num << '/' << x::den << " < "
                  << y::num << '/' << y::den << '\n';
}
```

Output:

```text
23/30 < 7/9
```
