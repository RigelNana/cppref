{/* source:cpp-types-is-trivially-copyable:0001 */}
`std::is_trivially_copyable` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-trivially-copyable:0002 */}
If `T` is a [trivially copyable](/docs/cpp/library/named_req/TriviallyCopyable) type, provides the member constant `value` equal to `true`. For any other type, `value` is `false`.

{/* source:cpp-types-is-trivially-copyable:0003 */}
If `std::remove_all_extents_t<T>` is an incomplete type and not (possibly cv-qualified) `void`, the behavior is undefined.

{/* source:cpp-types-is-trivially-copyable:0004 */}
If the program adds specializations for `std::is_trivially_copyable` or `std::is_trivially_copyable_v`, the behavior is undefined.

### Notes

{/* source:cpp-types-is-trivially-copyable:0008 */}
Objects of trivially-copyable types that are not potentially-overlapping subobjects are the only C++ objects that may be safely copied with [`std::memcpy`](/docs/cpp/library/text/byte/memcpy) or serialized to/from binary files with [`std::ofstream::write()`](/docs/cpp/library/io/basic_ostream/write) / [`std::ifstream::read()`](/docs/cpp/library/io/basic_istream/read).

### Example

{/* source:cpp-types-is-trivially-copyable:0009 */}
```cpp
#include <type_traits>

struct A { int m; };
static_assert(std::is_trivially_copyable_v<A> == true);

struct B { B(B const&) {} };
static_assert(std::is_trivially_copyable_v<B> == false);

struct C { virtual void foo(); };
static_assert(std::is_trivially_copyable_v<C> == false);

struct D
{
    int m;

    D(D const&) = default; // -> trivially copyable
    D(int x) : m(x + 1) {}
};
static_assert(std::is_trivially_copyable_v<D> == true);

int main() {}
```
