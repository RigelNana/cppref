{/* source:cpp-types-type-identity:0001 */}
Provides the member typedef `type` that names `T` (i.e., the identity transformation).

{/* source:cpp-types-type-identity:0002 */}
If the program adds specializations for `std::type_identity`, the behavior is undefined.

### Possible implementation

{/* source:cpp-types-type-identity:0005 */}
```cpp
template<class T>
struct type_identity { using type = T; };
```

### Notes

{/* source:cpp-types-type-identity:0006 */}
`std::type_identity` can be used to establish [non-deduced contexts](/docs/cpp/language/templates/template_argument_deduction#Non-deduced_contexts) in template argument deduction.

### Example

{/* source:cpp-types-type-identity:0008 */}
```cpp
#include <iostream>
#include <type_traits>
 
template<class T>
T foo(T a, T b) { return a + b; }
 
template<class T>
T bar(T a, std::type_identity_t<T> b) { return a + b; }
 
int main()
{
    // foo(4.2, 1); // error, deduced conflicting types for 'T'
    std::cout << bar(4.2, 1) << '\n';  // OK, calls bar<double>
}
```

Output:

```text
5.2
```
