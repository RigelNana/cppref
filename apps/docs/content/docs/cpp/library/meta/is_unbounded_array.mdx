`std::is_unbounded_array` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-unbounded-array:0002 */}
Checks whether `T` is an [arrays of unknown bound](/docs/cpp/language/declarations/array#Arrays_of_unknown_bound). Provides the member constant `value` which is equal to `true`, if `T` is an array type of unknown bound. Otherwise, `value` is equal to `false`.

{/* source:cpp-types-is-unbounded-array:0003 */}
If the program adds specializations for `std::is_unbounded_array` or `std::is_unbounded_array_v`, the behavior is undefined.

{/* source:cpp-types-is-unbounded-array:0009 */}
```cpp
#include <type_traits>

class A {};

(""
    && std::is_unbounded_array_v<A> == false
    && std::is_unbounded_array_v<A[]> == true
    && std::is_unbounded_array_v<A[3]> == false
    && std::is_unbounded_array_v<float> == false
    && std::is_unbounded_array_v<int> == false
    && std::is_unbounded_array_v<int[]> == true
    && std::is_unbounded_array_v<int[3]> == false
```
