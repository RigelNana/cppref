  <DeclarationDescription>
    {/* source:cpp-types-alignment-of:0001 */}
    Provides the member constant `value` equal to the [alignment requirement](/docs/cpp/language/basic_concepts/objects#Alignment) of the type `T`, as if obtained by an [alignof](/docs/cpp/language/expressions/alignof) expression. If `T` is an array type, returns the alignment requirements of the element type. If `T` is a reference type, returns the alignment requirements of the type referred to.

    {/* source:cpp-types-alignment-of:0002 */}
    If `alignof(T)` is not a valid expression, the behavior is undefined.

    {/* source:cpp-types-alignment-of:0003 */}
    If the program adds specializations for `std::alignment_of`<InlineRevision since="C++17"> or `std::alignment_of_v`</InlineRevision>, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

### Possible implementation

{/* source:cpp-types-alignment-of:0006 */}
```cpp
template<class T>
struct alignment_of : std::integral_constant<std::size_t, alignof(T)> {};
```

### Notes

{/* source:cpp-types-alignment-of:0007 */}
This type trait predates the [alignof](/docs/cpp/language/expressions/alignof) keyword, which can be used to obtain the same value with less verbosity.

### Example

{/* source:cpp-types-alignment-of:0008 */}
```cpp
#include <cstdint>
#include <iostream>
#include <type_traits>
 
struct A {};
struct B
{
    std::int8_t p;
    std::int16_t q;
};
 
int main()
{
    std::cout << std::alignment_of<A>::value << ' ';
    std::cout << std::alignment_of<B>::value << ' ';
    std::cout << std::alignment_of<int>() << ' '; // alt syntax
    std::cout << std::alignment_of_v<double> << '\n'; // c++17 alt syntax
}
```

Possible output:

```text
1 2 4 8
```
