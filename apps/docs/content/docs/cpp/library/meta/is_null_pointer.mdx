{/* source:cpp-types-is-null-pointer:0001 */}
`std::is_null_pointer` is a [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait).

{/* source:cpp-types-is-null-pointer:0002 */}
Checks whether `T` is the type [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t).

{/* source:cpp-types-is-null-pointer:0003 */}
Provides the member constant `value` that is equal to `true`, if `T` is the type [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t), `const std::nullptr_t`, `volatile std::nullptr_t`, or `const volatile std::nullptr_t`.

{/* source:cpp-types-is-null-pointer:0004 */}
Otherwise, `value` is equal to `false`.

{/* source:cpp-types-is-null-pointer:0005 */}
If the program adds specializations for `std::is_null_pointer` <InlineRevision since="C++17">or `std::is_null_pointer_v`</InlineRevision>, the behavior is undefined.

```cpp
template<class T>
struct is_null_pointer : std::is_same<std::nullptr_t, std::remove_cv_t<T>> {};
```

### Notes

{/* source:cpp-types-is-null-pointer:0010 */}
[`std::is_pointer`](/docs/cpp/library/meta/is_pointer) is `false` for [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t) because it is not a built-in pointer type.

{/* source:cpp-types-is-null-pointer:0011 */}
In libc++, `std::is_null_pointer` is not available in C++11 mode.

### Example

{/* source:cpp-types-is-null-pointer:0013 */}
```cpp
#include <type_traits>

static_assert(std::is_null_pointer_v<decltype(nullptr)>);
static_assert(!std::is_null_pointer_v<int*>);
static_assert(!std::is_pointer_v<decltype(nullptr)>);
static_assert(std::is_pointer_v<int*>);

int main()
{
}
```
