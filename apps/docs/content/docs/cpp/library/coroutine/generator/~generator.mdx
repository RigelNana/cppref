{/* source:cpp-coroutine-generator-generator:0001 */}
Destructs the `generator` object.

{/* source:cpp-coroutine-generator-generator:0002 */}
Given [`coroutine_`](/docs/cpp/library/ranges/generator#Data_members) as the underlying coroutine object, equivalent to:

{/* source:cpp-coroutine-generator-generator:0003 */}
```cpp
if (coroutine_)
    coroutine_.destroy();
```

{/* source:cpp-coroutine-generator-generator:0004 */}
Note, that destroying the root generator effectively destroys the entire stack of yielded generators, because the ownership of recursively yielded generators is held in awaitable objects in the coroutine frame of the yielding generator.
