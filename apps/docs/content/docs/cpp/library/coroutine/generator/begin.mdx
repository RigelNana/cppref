{/* source:cpp-coroutine-generator-begin:0001 */}
Pushes [`coroutine_`](/docs/cpp/library/ranges/generator#Data_members) into [`*active_`](/docs/cpp/library/ranges/generator#Data_members) stack, then evaluates `coroutine_.resume()`.

{/* source:cpp-coroutine-generator-begin:0002 */}
Before invocation of `begin()` the `coroutine_` must refer to a coroutine suspended at its [initial suspend point](/docs/cpp/language/functions/coroutines#co_await).

### Return value

{/* source:cpp-coroutine-generator-begin:0003 */}
An iterator whose `coroutine_` member refers to the same coroutine as `coroutine_` does.

### Notes

{/* source:cpp-coroutine-generator-begin:0004 */}
It is an undefined behavior to call `begin()` more than once on the same `generator` object.
