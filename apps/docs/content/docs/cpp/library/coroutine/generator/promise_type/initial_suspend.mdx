Informs that [`std::generator`](/docs/cpp/library/ranges/generator) always starts lazily (in suspended state).

{/* source:cpp-coroutine-generator-promise-type-initial-suspend:0002 */}
Equivalent to `return std::suspend_always{};`.

### Return value

{/* source:cpp-coroutine-generator-promise-type-initial-suspend:0003 */}
An [`awaitable`](/docs/cpp/library/utility/coroutine/suspend_always) object.
