{/* source:cpp-coroutine-generator-promise-type-operator-new:0001 */}
[Allocates](/docs/cpp/language/functions/coroutines#Dynamic_allocation) `size` bytes of uninitialized storage using default or user-provided allocator.

{/* source:cpp-coroutine-generator-promise-type-operator-new:0002 */}
Let `A` be

{/* source:cpp-coroutine-generator-promise-type-operator-new:0003 */}
- `Allocator`, if it is not `void`,
- `Alloc` for (2,3), or
- `std::allocator<void>` otherwise.

{/* source:cpp-coroutine-generator-promise-type-operator-new:0004 */}
Let `B` be `std::allocator_traits<A>::template rebind_alloc<U>` where `U` is an unspecified type whose size and alignment are both [`__STDCPP_DEFAULT_NEW_ALIGNMENT__`](/docs/cpp/language/preprocessor/replace#Predefined_macros).

{/* source:cpp-coroutine-generator-promise-type-operator-new:0005 */}
Initializes an allocator `b` of type `B` with:

{/* source:cpp-coroutine-generator-promise-type-operator-new:0006 */}
1. `A()`,

{/* source:cpp-coroutine-generator-promise-type-operator-new:0007 */}
2,3) `A(alloc)`.

{/* source:cpp-coroutine-generator-promise-type-operator-new:0008 */}
Uses `b` to allocate storage for the smallest array of `U` sufficient to provide storage for a [coroutine state](/docs/cpp/language/functions/coroutines#Execution) of size `size`, and unspecified additional state necessary to ensure that [`operator delete`](/docs/cpp/library/ranges/generator/promise_type/operator_delete) can later deallocate this memory block with an allocator equal to `b`.

{/* source:cpp-coroutine-generator-promise-type-operator-new:0009 */}
The program is ill-formed unless `std::allocator_traits<B>::pointer` is a pointer type and for overloads [(2,3)](/docs/cpp/library/ranges/generator/promise_type/operator_new#Version_2), `std::same_as<Allocator, void> || std::convertible_to<const Alloc&, Allocator>` is modeled.

### Parameters

{/* source:cpp-coroutine-generator-promise-type-operator-new:0010 */}
<ParameterList>
  <Parameter name="size">the size of the storage to allocate</Parameter>
  <Parameter name="alloc">a user provided allocator of type `Alloc`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-coroutine-generator-promise-type-operator-new:0011 */}
A pointer to the allocated storage.

### Exceptions

{/* source:cpp-coroutine-generator-promise-type-operator-new:0012 */}
1-3) May throw.
