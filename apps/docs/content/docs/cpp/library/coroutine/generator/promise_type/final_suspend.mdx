{/* source:cpp-coroutine-generator-promise-type-final-suspend:0001 */}
Let `x` be some [`generator`](/docs/cpp/library/ranges/generator) object. `final_suspend` does the following:

{/* source:cpp-coroutine-generator-promise-type-final-suspend:0002 */}
1. Pops the coroutine handle from the top of [`*active_`](/docs/cpp/library/ranges/generator#active).
2. If `*x.active_` is not empty, resumes execution of the coroutine referred to by `x.active_->top()`. If it is empty, control flow returns to the current coroutine caller or resumer.

{/* source:cpp-coroutine-generator-promise-type-final-suspend:0003 */}
A handle referring to the coroutine whose promise object is `*this` must be at the top of `*x.active_` of `x`. This function must be called by the coroutine upon reaching its final suspend point. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-coroutine-generator-promise-type-final-suspend:0004 */}
An [awaitable object](/docs/cpp/library/utility/coroutine#co_await) of unspecified type whose member functions are configured to suspend the calling coroutine.
