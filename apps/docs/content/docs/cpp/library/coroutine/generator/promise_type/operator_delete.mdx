  <Declaration language="cpp" since="C++23" code={`void operator delete( void* ptr, std::size_t n ) noexcept;`} />

{/* source:cpp-coroutine-generator-promise-type-operator-delete:0001 */}
Deallocates the storage pointed to by `ptr` using an allocator equivalent to that used to [`allocate`](/docs/cpp/library/ranges/generator/promise_type/operator_new) this memory.

{/* source:cpp-coroutine-generator-promise-type-operator-delete:0002 */}
The `ptr` passed to this function must be the one returned from an invocation of one of the `operator new` overloads with a size argument equal to `n`. Otherwise the behavior is undefined.

### Parameters

{/* source:cpp-coroutine-generator-promise-type-operator-delete:0003 */}
<ParameterList>
  <Parameter name="ptr">a pointer obtained from the previous call to [`operator new`](/docs/cpp/library/ranges/generator/promise_type/operator_new)</Parameter>
  <Parameter name="n">the size of the storage to be deallocated</Parameter>
</ParameterList>
