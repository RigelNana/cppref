Replaces the contents of the `generator` object. Equivalent to:

{/* source:cpp-coroutine-generator-operator:0002 */}
[`std::swap`](/docs/cpp/library/algorithm/swap)([`coroutine_`](/docs/cpp/library/ranges/generator#Data_members), `other.coroutine_`); [`std::swap`](/docs/cpp/library/algorithm/swap)([`active_`](/docs/cpp/library/ranges/generator#Data_members), `other.active_`);

### Notes

{/* source:cpp-coroutine-generator-operator:0006 */}
Iterators previously obtained from `other` are not invalidated – they become iterators into `*this`.

{/* source:cpp-coroutine-generator-operator:0007 */}
This assignment operator is technically a [copy assignment operator](/docs/cpp/language/classes/as_operator), although `std::generator` is only move assignable.
