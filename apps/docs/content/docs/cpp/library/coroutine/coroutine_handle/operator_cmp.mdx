{/* source:cpp-coroutine-coroutine-handle-operator-cmp:0001 */}
Compares two `std::coroutine_handle<>` values `x` and `y` according to their underlying addresses.

{/* source:cpp-coroutine-coroutine-handle-operator-cmp:0002 */}
The `\<`, `\<=`, `\>`, `\>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

### Parameters

{/* source:cpp-coroutine-coroutine-handle-operator-cmp:0003 */}
<ParameterList>
  <Parameter name="x, y">`std::coroutine_handle<>` values to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-coroutine-coroutine-handle-operator-cmp:0004 */}
1. `x.address() == y.address()`

{/* source:cpp-coroutine-coroutine-handle-operator-cmp:0005 */}
2. `std::compare_three_way{}(x.address(), y.address())`

### Notes

{/* source:cpp-coroutine-coroutine-handle-operator-cmp:0006 */}
Although these operators are only overloaded for `std::coroutine_handle<>`, other specializations of [`std::coroutine_handle`](/docs/cpp/library/utility/coroutine/coroutine_handle) are also equality comparable and three-way comparable, because they are implicitly convertible to `std::coroutine_handle<>`.
