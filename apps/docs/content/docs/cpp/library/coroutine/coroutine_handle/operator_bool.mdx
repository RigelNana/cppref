{/* source:cpp-coroutine-coroutine-handle-operator-bool:0001 */}
Checks whether `*this` is non-null, i.e. the value of `*this` is obtained from the promise object of some coroutine. Equivalent to `return bool(address());`.

{/* source:cpp-coroutine-coroutine-handle-operator-bool:0002 */}
If `Promise` is [`std::noop_coroutine_promise`](/docs/cpp/library/utility/coroutine/noop_coroutine_promise), this conversion function always returns `true`.

### Parameters

{/* source:cpp-coroutine-coroutine-handle-operator-bool:0003 */}
(none)

### Return value

{/* source:cpp-coroutine-coroutine-handle-operator-bool:0004 */}
`bool(address())`, or `true` if `Promise` is [`std::noop_coroutine_promise`](/docs/cpp/library/utility/coroutine/noop_coroutine_promise).
