The coroutine support library defines several types that provide compile and run-time support for [coroutines](/docs/cpp/language/functions/coroutines).

    <DescriptionBody>trait type for discovering coroutine promise types <br /> (class template)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
