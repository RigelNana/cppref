{/* source:cpp-concepts-strict-weak-order:0001 */}
The concept `strict_weak_order<R, T, U>` specifies that the [`relation`](/docs/cpp/library/concepts/relation) `R` imposes a strict weak ordering on its arguments.

### Semantic requirements

{/* source:cpp-concepts-strict-weak-order:0002 */}
A relation `r` is a strict weak ordering if

{/* source:cpp-concepts-strict-weak-order:0003 */}
- it is irreflexive: for all `x`, `r(x, x)` is `false`;
- it is transitive: for all `a`, `b` and `c`, if `r(a, b)` and `r(b, c)` are both `true` then `r(a, c)` is `true`;
- let `e(a, b)` be `!r(a, b) && !r(b, a)`, then `e` is transitive: `e(a, b) && e(b, c)` implies `e(a, c)`.

{/* source:cpp-concepts-strict-weak-order:0004 */}
Under these conditions, it can be shown that `e` is an equivalence relation, and `r` induces a strict total ordering on the equivalence classes determined by `e`.

### Notes

{/* source:cpp-concepts-strict-weak-order:0005 */}
The distinction between [`relation`](/docs/cpp/library/concepts/relation) and `strict_weak_order` is purely semantic.
