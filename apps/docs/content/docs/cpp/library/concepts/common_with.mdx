{/* source:cpp-concepts-common-with:0001 */}
The concept `common_with<T, U>` specifies that two types `T` and `U` share a common type (as computed by [`std::common_type_t`](/docs/cpp/library/meta/common_type)) to which both can be converted.

### Semantic requirements

{/* source:cpp-concepts-common-with:0002 */}
`T` and `U` model `std::common_with<T, U>` only if, given [equality-preserving](/docs/cpp/library/concepts#Equality_preservation) expressions `t1`, `t2`, `u1` and `u2` such that `decltype((t1))` and `decltype((t2))` are both `T` and `decltype((u1))` and `decltype((u2))` are both `U`,

{/* source:cpp-concepts-common-with:0003 */}
- `std::common_type_t<T, U>(t1)` equals `std::common_type_t<T, U>(t2)` if and only if `t1` equals `t2`; and
- `std::common_type_t<T, U>(u1)` equals `std::common_type_t<T, U>(u2)` if and only if `u1` equals `u2`.

{/* source:cpp-concepts-common-with:0004 */}
In other words, the conversion to the common type must [preserve equality](/docs/cpp/library/concepts#Equality_preservation).

### Equality preservation

{/* source:cpp-concepts-common-with:0005 */}
Expressions declared in [requires expressions](/docs/cpp/language/templates/requires) of the standard library concepts are required to be [equality-preserving](/docs/cpp/library/concepts#Equality_preservation) (except where stated otherwise).
