Defined in header [`<concepts>`](/docs/cpp/library/headers/concepts)

  <Declaration language="cpp" since="C++20" code={`template< class T >
concept copyable =
    std::copy_constructible<T> &&
    std::movable<T> &&
    std::assignable_from<T&, T&> &&
    std::assignable_from<T&, const T&> &&

    std::assignable_from<T&, const T>;`} />
</DeclarationDoc>

{/* source:cpp-concepts-copyable:0001 */}
The concept `copyable<T>` specifies that `T` is a [`movable`](/docs/cpp/library/concepts/movable) object type that can also be copied (that is, it supports copy construction and copy assignment).
