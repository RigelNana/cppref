{/* source:cpp-concepts-invocable:0001 */}
The `invocable` concept specifies that a callable type `F` can be called with a set of arguments `Args...` using the function template [`std::invoke`](/docs/cpp/library/utility/functional/invoke).

{/* source:cpp-concepts-invocable:0002 */}
The `regular_invocable` concept adds to the `invocable` concept by requiring the invoke expression to be [equality-preserving](/docs/cpp/library/concepts#Equality_preservation) and not modify either the function object or the arguments.

### Equality preservation

{/* source:cpp-concepts-invocable:0003 */}
Expressions declared in [requires expressions](/docs/cpp/language/templates/requires) of the standard library concepts are required to be [equality-preserving](/docs/cpp/library/concepts#Equality_preservation) (except where stated otherwise).

### Notes

{/* source:cpp-concepts-invocable:0004 */}
The distinction between `invocable` and `regular_invocable` is purely semantic.

{/* source:cpp-concepts-invocable:0005 */}
A random number generator may satisfy `invocable` but cannot satisfy `regular_invocable` ([comical ones](/docs/cpp/library/concepts/invocable#External_links) excluded).
