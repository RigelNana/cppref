{/* source:cpp-concepts-default-initializable:0001 */}
The `default_initializable` concept checks whether variables of type `T` can be

{/* source:cpp-concepts-default-initializable:0002 */}
- [value-initialized](/docs/cpp/language/initialization/value_initialization) (i.e., whether `T()` is well-formed);
- [direct-list-initialized](/docs/cpp/language/initialization/list_initialization) from an empty initializer list (i.e., whether `T{}` is well-formed); and
- [default-initialized](/docs/cpp/language/initialization/default_initialization) (i.e., whether `T t;` is well-formed).

{/* source:cpp-concepts-default-initializable:0003 */}
Access checking is performed as if in a context unrelated to `T`. Only the validity of the immediate context of the variable initialization is considered.

### Possible implementation

{/* source:cpp-concepts-default-initializable:0004 */}
```cpp
template<class T>
concept default_initializable =
    std::constructible_from<T> &&
    requires { T{}; ::new T; };
```
