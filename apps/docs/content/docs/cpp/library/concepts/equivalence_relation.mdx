{/* source:cpp-concepts-equivalence-relation:0001 */}
The concept `equivalence_relation<R, T, U>` specifies that the [`relation`](/docs/cpp/library/concepts/relation) `R` imposes an [equivalence relation](https://en.wikipedia.org/wiki/equivalence_relation) on its arguments.

### Semantic requirements

{/* source:cpp-concepts-equivalence-relation:0002 */}
A relation `r` is an equivalence relation if

{/* source:cpp-concepts-equivalence-relation:0003 */}
- it is reflexive: for all `x`, `r(x, x)` is `true`;
- it is symmetric: for all `a` and `b`, `r(a, b)` is `true` if and only if `r(b, a)` is `true`;
- it is transitive: `r(a, b) && r(b, c)` implies `r(a, c)`.

### Notes

{/* source:cpp-concepts-equivalence-relation:0004 */}
The distinction between [`relation`](/docs/cpp/library/concepts/relation) and `equivalence_relation` is purely semantic.
