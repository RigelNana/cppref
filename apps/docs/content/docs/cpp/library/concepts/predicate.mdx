{/* source:cpp-concepts-predicate:0001 */}
The concept `std::predicate<F, Args...>` specifies that `F` is a predicate that accepts arguments whose types and value categories are encoded by `Args...`, i.e., it can be invoked with these arguments to produce a [`boolean-testable`](/docs/cpp/library/concepts/boolean-testable) result.

{/* source:cpp-concepts-predicate:0002 */}
Note that [`regular_invocable`](/docs/cpp/library/concepts/invocable) requires the invocation to not modify either the callable object or the arguments and be [equality-preserving](/docs/cpp/library/concepts#Equality_preservation).

### Equality preservation

{/* source:cpp-concepts-predicate:0003 */}
Expressions declared in [requires expressions](/docs/cpp/language/templates/requires) of the standard library concepts are required to be [equality-preserving](/docs/cpp/library/concepts#Equality_preservation) (except where stated otherwise).
