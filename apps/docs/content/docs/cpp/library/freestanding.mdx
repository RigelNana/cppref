{/* source:cpp-freestanding:0000 */}
There are two kinds of implementations defined by the C++ standard: ***hosted*** and ***freestanding*** implementations. For *hosted* implementations, the set of standard library headers required by the C++ standard is much larger than for *freestanding* ones. In a *freestanding* implementation, execution may happen without an operating system.

{/* source:cpp-freestanding:0001 */}
The kind of the implementation is implementation-defined. <InlineRevision since="C++11">The macro `__STDC_HOSTED__` is predefined to `1` for hosted implementations and `0` for freestanding implementations.</InlineRevision>

{/* source:cpp-freestanding:0002 */}
<Revision since="C++11">
#### Requirements on [multi-threaded executions and data races](/docs/cpp/language/basic_concepts/memory_model)

| *freestanding* | *hosted* |
| --- | --- |
| Under a *freestanding* implementation, it is implementation-defined whether a program can have more than one [thread of execution](/docs/cpp/library/atomic). | Under a *hosted* implementation, a C++ program can have more than one [thread](/docs/cpp/library/atomic) running concurrently. |
</Revision>

### Requirements on the main function

{/* source:cpp-freestanding:0003 */}
| *freestanding* | *hosted* |
| --- | --- |
| In a *freestanding* implementation, it is implementation-defined whether a program is required to define a [`main`](/docs/cpp/language/basic_concepts/main_function) function. Start-up and termination is implementation-defined; start-up contains the execution of [constructors](/docs/cpp/language/classes/initializer_list) for objects of [namespace scope](/docs/cpp/language/basic_concepts/scope#Namespace_scope) with static storage duration; termination contains the execution of [destructors](/docs/cpp/language/classes/destructor) for objects with static [storage duration](/docs/cpp/language/declarations/storage_duration). | In a *hosted* implementation, a program must contain a global function called [`main`](/docs/cpp/language/basic_concepts/main_function). Executing a program starts a main [thread of execution](/docs/cpp/library/atomic) in which the main function is invoked, and in which variables of static [storage duration](/docs/cpp/language/declarations/storage_duration) might be initialized and destroyed. |

### Requirements on standard library headers

{/* source:cpp-freestanding:0004 */}
A *freestanding* implementation has an implementation-defined set of headers. This set includes at least the headers in the following table.

{/* source:cpp-freestanding:0005 */}
For partially freestanding headers, freestanding implementations only needs to provide part of the entities in the corresponding synopsis:

{/* source:cpp-freestanding:0006 */}
- If an entity is commented `// freestanding`, it is guaranteed to be provided.

{/* source:cpp-freestanding:0007 */}
<Revision since="C++26">
- If an entity (function or function template) is commented `// freestanding-deleted`, it is guaranteed to be either provided or deleted.
</Revision>

### Notes

{/* source:cpp-freestanding:0010 */}
Some compiler vendors may not fully support freestanding implementation. For example, GCC libstdc++ has had implementation and build issues before version 13, while LLVM libcxx and MSVC STL do not support freestanding.

{/* source:cpp-freestanding:0011 */}
In C++23, many features are made freestanding with partial headers. However, it is still up for discussion in WG21 whether some headers will be made freestanding in the future standards. Regardless, containers like [`vector`](/docs/cpp/library/container/vector), [`list`](/docs/cpp/library/container/list), [`deque`](/docs/cpp/library/container/deque), and [`map`](/docs/cpp/library/container/map) will never be freestanding due to their dependencies on exceptions and heap.

{/* source:cpp-freestanding:0012 */}
GCC 13 provides more headers, such as [`<optional>`](/docs/cpp/library/headers/optional), [`<span>`](/docs/cpp/library/headers/span), [`<array>`](/docs/cpp/library/headers/array), and [`<bitset>`](/docs/cpp/library/headers/bitset), for freestanding, although these headers may not be portable or provide the same capabilities as a hosted implementation. It is better to avoid using them in a freestanding environment, even if the toolchain provides them.
