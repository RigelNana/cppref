  <DeclarationDescription>
    {/* source:cpp-filesystem-last-write-time:0001 */}
    1,2) Returns the time of the last modification of `p`, determined as if by accessing the member `st_mtime` of the POSIX [`stat`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/stat.html) (symlinks are followed). The non-throwing overload returns `file_time_type::min()` on errors.

    {/* source:cpp-filesystem-last-write-time:0002 */}
    3,4) Changes the time of the last modification of `p`, as if by POSIX [`futimens`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/futimens.html) (symlinks are followed).
  </DeclarationDescription>
</DeclarationDoc>

### Return value

{/* source:cpp-filesystem-last-write-time:0004 */}
1,2) The time of the last modification of `p`.

{/* source:cpp-filesystem-last-write-time:0005 */}
3,4) (none)

### Exceptions

{/* source:cpp-filesystem-last-write-time:0006 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-last-write-time:0007 */}
1,3) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-last-write-time:0008 */}
2,4) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.

### Notes

{/* source:cpp-filesystem-last-write-time:0009 */}
It is not guaranteed that immediately after setting the write time, the value returned by (1,2) is the same as what was passed as the argument to (3,4) because the file system's time may be more granular than [`filesystem::file_time_type`](/docs/cpp/library/filesystem/file_time_type).

### Example

{/* source:cpp-filesystem-last-write-time:0010 */}
```cpp
#include <chrono>
#include <filesystem>
#include <format>
#include <fstream>
#include <iostream>
 
using namespace std::chrono_literals;
 
int main()
{
    auto p = std::filesystem::temp_directory_path() / "example.bin";
    std::ofstream{p.c_str()}.put('a'); // create file
 
    std::filesystem::file_time_type ftime = std::filesystem::last_write_time(p);
    std::cout << std::format("File write time is {}\n", ftime);
 
    // move file write time 1 hour to the future
    std::filesystem::last_write_time(p, ftime + 1h);
 
    // read back from the filesystem
    ftime = std::filesystem::last_write_time(p);
    std::cout << std::format("File write time is {}\n", ftime);
 
    std::filesystem::remove(p);
}
```

Possible output:

```text
File write time is 2023-09-04 19:33:24.702639224
File write time is 2023-09-04 20:33:24.702639224
```
