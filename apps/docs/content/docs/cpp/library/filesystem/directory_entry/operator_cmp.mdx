Compares the path with the directory entry `rhs`.

{/* source:cpp-filesystem-directory-entry-operator-cmp:0002 */}
<Revision since="C++20">
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Parameters

{/* source:cpp-filesystem-directory-entry-operator-cmp:0003 */}
<ParameterList>
  <Parameter name="rhs">directory_entry to compare</Parameter>
</ParameterList>

### Return value

1. {/* source:cpp-filesystem-directory-entry-operator-cmp:0004 */}1) `true` if `path() == rhs.path()`, `false` otherwise.
2. {/* source:cpp-filesystem-directory-entry-operator-cmp:0005 */}2) `true` if `path() != rhs.path()`, `false` otherwise.
3. {/* source:cpp-filesystem-directory-entry-operator-cmp:0006 */}3) `true` if `path() < rhs.path()`, `false` otherwise.
4. {/* source:cpp-filesystem-directory-entry-operator-cmp:0007 */}4) `true` if `path() <= rhs.path()`, `false` otherwise.
5. {/* source:cpp-filesystem-directory-entry-operator-cmp:0008 */}5) `true` if `path() > rhs.path()`, `false` otherwise.
6. {/* source:cpp-filesystem-directory-entry-operator-cmp:0009 */}6) `true` if `path() >= rhs.path()`, `false` otherwise.
7. {/* source:cpp-filesystem-directory-entry-operator-cmp:0010 */}7) The result of `path() <=> rhs.path()`.
