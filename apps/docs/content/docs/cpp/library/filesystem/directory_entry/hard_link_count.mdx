{/* source:cpp-filesystem-directory-entry-hard-link-count:0001 */}
If the number of hard links is cached in this [`directory_entry`](/docs/cpp/library/filesystem/directory_entry/directory_entry), returns the cached value. Otherwise, returns:

1. {/* source:cpp-filesystem-directory-entry-hard-link-count:0002 */}1) `std::filesystem::hard_link_count(path())`,
2. {/* source:cpp-filesystem-directory-entry-hard-link-count:0003 */}2) `std::filesystem::hard_link_count(path(), ec)`.

### Parameters

{/* source:cpp-filesystem-directory-entry-hard-link-count:0004 */}
<ParameterList>
  <Parameter name="ec">out-parameter for error reporting in the non-throwing overload</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-directory-entry-hard-link-count:0005 */}
The number of hard links for the referred-to filesystem object.

### Exceptions

{/* source:cpp-filesystem-directory-entry-hard-link-count:0006 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-directory-entry-hard-link-count:0007 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-directory-entry-hard-link-count:0008 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.
