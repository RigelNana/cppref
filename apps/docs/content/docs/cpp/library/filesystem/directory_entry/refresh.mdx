{/* source:cpp-filesystem-directory-entry-refresh:0001 */}
Examines the filesystem object referred to by this directory entry and stores its attributes for retrieval with [`status`](/docs/cpp/library/filesystem/directory_entry/status), [`exists`](/docs/cpp/library/filesystem/directory_entry/exists), [`is_regular_file`](/docs/cpp/library/filesystem/directory_entry/is_regular_file), and other status accessors.

{/* source:cpp-filesystem-directory-entry-refresh:0002 */}
If an error occurs, the value of any cached attributes is unspecified.

### Parameters

{/* source:cpp-filesystem-directory-entry-refresh:0003 */}
<ParameterList>
  <Parameter name="ec">out-parameter for error reporting in the non-throwing overload</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-directory-entry-refresh:0004 */}
(none)

### Exceptions

{/* source:cpp-filesystem-directory-entry-refresh:0005 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-directory-entry-refresh:0006 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-directory-entry-refresh:0007 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.

### Notes

{/* source:cpp-filesystem-directory-entry-refresh:0008 */}
Many low-level OS APIs for directory traversal retrieve file attributes along with the next directory entry. The constructors and the non-const member functions of [`std::filesystem::directory_iterator`](/docs/cpp/library/filesystem/directory_iterator) store these attributes, if any, in the pointed-to [`std::filesystem::directory_entry`](/docs/cpp/library/filesystem/directory_entry) without calling `directory_entry::refresh`, which makes it possible to examine the attributes of the directory entries as they are being iterated over, without making additional system calls.
