{/* source:cpp-filesystem-directory-entry-operator-ltlt:0001 */}
Performs stream output on the directory entry `d`. Equivalent to `return os << d.path();`.

{/* source:cpp-filesystem-directory-entry-operator-ltlt:0002 */}
This function template is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::filesystem::directory_entry` is an associated class of the arguments. This prevents undesirable conversions in the presence of a `using namespace std::filesystem;` [using-directive](/docs/cpp/language/declarations/namespace#Using-directives).

### Parameters

{/* source:cpp-filesystem-directory-entry-operator-ltlt:0003 */}
<ParameterList>
  <Parameter name="os">stream to perform output on</Parameter>
  <Parameter name="d">directory_entry to be inserted</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-directory-entry-operator-ltlt:0004 */}
`os`

### Exceptions

{/* source:cpp-filesystem-directory-entry-operator-ltlt:0005 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-filesystem-directory-entry-operator-ltlt:0006 */}
```cpp
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;
 
int main()
{
    const auto entries = {fs::directory_entry{fs::current_path()},
                          fs::directory_entry{fs::temp_directory_path()}};
 
    for (const fs::directory_entry& de : entries)
        std::cout << de << '\n';
}
```

Possible output:

```text
"/home/猫"
"/tmp"
```
