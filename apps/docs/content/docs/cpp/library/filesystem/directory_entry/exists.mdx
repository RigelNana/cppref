{/* source:cpp-filesystem-directory-entry-exists:0001 */}
Checks whether the pointed-to object exists. Effectively returns:

1. {/* source:cpp-filesystem-directory-entry-exists:0002 */}1) `std::filesystem::exists(status())`,
2. {/* source:cpp-filesystem-directory-entry-exists:0003 */}2) `std::filesystem::exists(status(ec))`.

{/* source:cpp-filesystem-directory-entry-exists:0004 */}
Note that [`status()`](/docs/cpp/library/filesystem/directory_entry/status) follows symlinks to their targets.

### Parameters

{/* source:cpp-filesystem-directory-entry-exists:0005 */}
<ParameterList>
  <Parameter name="ec">out-parameter for error reporting in the non-throwing overload</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-directory-entry-exists:0006 */}
`true` if the referred-to filesystem object exists.

### Exceptions

{/* source:cpp-filesystem-directory-entry-exists:0007 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-directory-entry-exists:0008 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-directory-entry-exists:0009 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.

### Example

{/* source:cpp-filesystem-directory-entry-exists:0010 */}
```cpp
#include <filesystem>
#include <iostream>
 
int main()
{
    for (auto const str:
    {
        "/usr/bin/cat",
        "/usr/bin/mouse",
        "/usr/bin/python",
        "/usr/bin/bison",
        "/usr/bin/yacc",
        "/usr/bin/c++",
    })
    {
        std::filesystem::directory_entry entry{str};
 
        std::cout << "directory entry " << entry
                  << (entry.exists() ? " exists\n" : " does not exist\n");
    }
}
```

Possible output:

```text
// Output on a POSIX system:
directory entry "/usr/bin/cat" exist
directory entry "/usr/bin/mouse" does not exist
directory entry "/usr/bin/python" exists
directory entry "/usr/bin/bison" exists
directory entry "/usr/bin/yacc" does not exist
directory entry "/usr/bin/c++" exists
```
