Constructs a new `directory_entry` object.

1. {/* source:cpp-filesystem-directory-entry-directory-entry:0002 */}1) Default constructor.
2. {/* source:cpp-filesystem-directory-entry-directory-entry:0003 */}2) Defaulted copy constructor.
3. {/* source:cpp-filesystem-directory-entry-directory-entry:0004 */}3) Defaulted move constructor.
4. {/* source:cpp-filesystem-directory-entry-directory-entry:0005 */}4,5) Initializes the directory entry with path `p` and calls [`refresh`](/docs/cpp/library/filesystem/directory_entry/refresh) to update the cached attributes. If an error occurs, the non-throwing overload leaves the `directory_entry` holding a default-constructed path.

### Parameters

{/* source:cpp-filesystem-directory-entry-directory-entry:0006 */}
<ParameterList>
  <Parameter name="p">path to the filesystem object to which the directory entry will refer</Parameter>
  <Parameter name="ec">out-parameter for error reporting in the non-throwing overload</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-filesystem-directory-entry-directory-entry:0007 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-directory-entry-directory-entry:0008 */}
1-4) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-directory-entry-directory-entry:0009 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.
