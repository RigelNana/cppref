{/* source:cpp-filesystem-directory-entry-is-regular-file:0001 */}
Checks whether the pointed-to object is a regular file. Effectively returns:

1. {/* source:cpp-filesystem-directory-entry-is-regular-file:0002 */}1) `std::filesystem::is_regular_file(status())`.
2. {/* source:cpp-filesystem-directory-entry-is-regular-file:0003 */}2) `std::filesystem::is_regular_file(status(ec))`.

### Parameters

{/* source:cpp-filesystem-directory-entry-is-regular-file:0004 */}
<ParameterList>
  <Parameter name="ec">out-parameter for error reporting in the non-throwing overload</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-directory-entry-is-regular-file:0005 */}
`true` if the referred-to filesystem object is a regular file, `false` otherwise.

### Exceptions

{/* source:cpp-filesystem-directory-entry-is-regular-file:0006 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-directory-entry-is-regular-file:0007 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-directory-entry-is-regular-file:0008 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.

### Example

{/* source:cpp-filesystem-directory-entry-is-regular-file:0009 */}
```cpp
#include <filesystem>
#include <iostream>
#include <string>
 
namespace fs = std::filesystem;
 
int main(int argc, const char* argv[])
{
    // Print out all regular files in a directory 'dir'.
    try
    {
        const auto dir{argc == 2 ? fs::path{argv[1]} : fs::current_path()};
 
        std::cout << "Current dir: " << dir << '\n'
                  << std::string(40, '-') << '\n';
 
        for (fs::directory_entry const& entry : fs::directory_iterator(dir))
            if (entry.is_regular_file())
                std::cout << entry.path().filename() << '\n';
    }
    catch(const fs::filesystem_error& e)
    {
        std::cout << e.what() << '\n';
    }
}
```

Possible output:

```text
Current dir: "/tmp/1588616534.9884143"
----------------------------------------
"main.cpp"
"a.out"
```
