### Parameters

{/* source:cpp-filesystem-temp-directory-path:0002 */}
(none)

### Return value

{/* source:cpp-filesystem-temp-directory-path:0003 */}
A directory suitable for temporary files. The path is guaranteed to exist and to be a directory. The overload that takes `error_code&` argument returns an empty path on error.

### Exceptions

{/* source:cpp-filesystem-temp-directory-path:0004 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-temp-directory-path:0005 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `path to be returned` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-temp-directory-path:0006 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.

### Notes

{/* source:cpp-filesystem-temp-directory-path:0007 */}
On POSIX systems, the path may be the one specified in the environment variables `TMPDIR`, `TMP`, `TEMP`, `TEMPDIR`, and, if none of them are specified, the path `"/tmp"` is returned.

{/* source:cpp-filesystem-temp-directory-path:0008 */}
On Windows systems, the path is typically the one returned by [`GetTempPath`](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-gettemppathw).

### Example

{/* source:cpp-filesystem-temp-directory-path:0009 */}
```cpp
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;
 
int main()
{
    std::cout << "Temp directory is " << fs::temp_directory_path() << '\n';
}
```

Possible output:

```text
Temp directory is "C:\Windows\TEMP\"
```
