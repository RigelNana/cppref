  <DeclarationDescription>
    {/* source:cpp-filesystem-copy-symlink:0001 */}
    Copies a symlink to another location.

    {/* source:cpp-filesystem-copy-symlink:0002 */}
    1) Effectively calls `f(read_symlink(from), to)` where `f` is [`create_symlink`](/docs/cpp/library/filesystem/create_symlink) or [`create_directory_symlink`](/docs/cpp/library/filesystem/create_symlink) depending on whether `from` resolves to a file or directory.

    {/* source:cpp-filesystem-copy-symlink:0003 */}
    2) Effectively calls `f(read_symlink(from, ec), to, ec)` where `f` is [`create_symlink`](/docs/cpp/library/filesystem/create_symlink) or [`create_directory_symlink`](/docs/cpp/library/filesystem/create_symlink) depending on whether `from` resolves to a file or directory.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-filesystem-copy-symlink:0004 */}
<ParameterList>
  <Parameter name="from">path to a symbolic link to copy</Parameter>
  <Parameter name="to">destination path of the new symlink</Parameter>
  <Parameter name="ec">out-parameter for error reporting in the non-throwing overload</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-copy-symlink:0005 */}
(none)

### Exceptions

{/* source:cpp-filesystem-copy-symlink:0006 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-copy-symlink:0007 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `from` as the first path argument, `to` as the second path argument, and the OS error code as the error code argument.

{/* source:cpp-filesystem-copy-symlink:0008 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.
