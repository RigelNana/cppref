{/* source:cpp-filesystem-file-status-operator:0001 */}
Checks if two `file_status` values are equal, i.e. types and permissions represented by them are same respectively.

{/* source:cpp-filesystem-file-status-operator:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::filesystem::file_status` is an associated class of the arguments.

{/* source:cpp-filesystem-file-status-operator:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Parameters

{/* source:cpp-filesystem-file-status-operator:0004 */}
<ParameterList>
  <Parameter name="lhs, rhs">`file_status` values to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-file-status-operator:0005 */}
`lhs.type() == rhs.type() && lhs.permissions() == rhs.permissions()`
