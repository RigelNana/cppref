    1. Returns `iter` unchanged.

    {/* source:cpp-filesystem-directory-iterator-begin:0002 */}

{/* source:cpp-filesystem-directory-iterator-begin:0003 */}
These non-member functions enable the use of `directory_iterators` with range-based for loops <InlineRevision since="C++20">and make `directory_iterator` a [`range`](/docs/cpp/library/ranges/range) type</InlineRevision>.

### Parameters

{/* source:cpp-filesystem-directory-iterator-begin:0004 */}
<ParameterList>
  <Parameter name="iter">a `directory_iterator`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-directory-iterator-begin:0005 */}
1) `iter` unchanged.

{/* source:cpp-filesystem-directory-iterator-begin:0006 */}
2) End iterator (default-constructed `directory_iterator`).

### Example

{/* source:cpp-filesystem-directory-iterator-begin:0007 */}
```cpp
#include <filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::filesystem;
 
int main()
{
    fs::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    std::ofstream("sandbox/file2.txt");
    for (auto& p : fs::directory_iterator("sandbox"))
        std::cout << p << '\n';
    fs::remove_all("sandbox");
}
```

Possible output:

```text
"sandbox/a"
"sandbox/file1.txt"
"sandbox/file2.txt"
```
