    {/* source:cpp-filesystem-directory-iterator-directory-iterator:0001 */}
    Constructs a new directory iterator.

    {/* source:cpp-filesystem-directory-iterator-directory-iterator:0002 */}
    1. Constructs the end iterator.

    {/* source:cpp-filesystem-directory-iterator-directory-iterator:0003 */}
    2. Constructs a directory iterator that refers to the first directory entry of a directory identified by `p`. If `p` refers to a non-existing file or not a directory, throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error).

    {/* source:cpp-filesystem-directory-iterator-directory-iterator:0004 */}
    3. Same as (2), but if [`std::filesystem::directory_options::skip_permission_denied`](/docs/cpp/library/filesystem/directory_options) is set in `options` and construction encounters a permissions denied error, constructs the end iterator and does not report an error.

    {/* source:cpp-filesystem-directory-iterator-directory-iterator:0005 */}
    4. Constructs a directory iterator that refers to the first directory entry of a directory identified by `p`. If `p` refers to a non-existing file or not a directory, returns the end iterator and sets `ec`.

    {/* source:cpp-filesystem-directory-iterator-directory-iterator:0006 */}
    5. Same as (4), but if [`std::filesystem::directory_options::skip_permission_denied`](/docs/cpp/library/filesystem/directory_options) is set in `options` and construction encounters a permissions denied error, constructs the end iterator and does not report an error.

    {/* source:cpp-filesystem-directory-iterator-directory-iterator:0007 */}
    6. Copy constructor.

    {/* source:cpp-filesystem-directory-iterator-directory-iterator:0008 */}
    7. Move constructor.

### Exceptions

{/* source:cpp-filesystem-directory-iterator-directory-iterator:0010 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-directory-iterator-directory-iterator:0011 */}
2,3) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-directory-iterator-directory-iterator:0012 */}
4,5) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec`. [`clear`](/docs/cpp/library/error/error_code/clear)() if no errors occur.

### Notes

{/* source:cpp-filesystem-directory-iterator-directory-iterator:0013 */}
To iterate over the current directory, construct the iterator as `directory_iterator(".")` instead of `directory_iterator("")`.
