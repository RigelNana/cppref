  <DeclarationDescription>
    {/* source:cpp-filesystem-is-other:0001 */}
    Checks if the given file status or path corresponds to a file of type other type. That is, the file exists, but is neither regular file, nor directory nor a symlink.

    {/* source:cpp-filesystem-is-other:0002 */}
    1) Equivalent to `exists(s) && !is_regular_file(s) && !is_directory(s) && !is_symlink(s)`.

    {/* source:cpp-filesystem-is-other:0003 */}
    2,3) Equivalent to `is_other(status(p))` or `is_other(status(p, ec))`, respectively.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-filesystem-is-other:0004 */}
<ParameterList>
  <Parameter name="s">file status to check</Parameter>
  <Parameter name="p">path to examine</Parameter>
  <Parameter name="ec">error code to store the error status to</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-is-other:0005 */}
`true` if the file indicated by `p` or if the type indicated `s` refers to a file that is not regular file, directory, or a symlink, `false` otherwise. The non-throwing overload returns `false` if an error occurs.

### Exceptions

{/* source:cpp-filesystem-is-other:0006 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-is-other:0007 */}
2,3) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.
