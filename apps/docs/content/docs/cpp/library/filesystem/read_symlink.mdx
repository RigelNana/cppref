                                    std::error_code& ec );`} />

  <DeclarationDescription>
    {/* source:cpp-filesystem-read-symlink:0001 */}
    If the path `p` refers to a symbolic link, returns a new path object which refers to the target of that symbolic link.

    {/* source:cpp-filesystem-read-symlink:0002 */}
    It is an error if `p` does not refer to a symbolic link.

    {/* source:cpp-filesystem-read-symlink:0003 */}
    The non-throwing overload returns an empty path on errors.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-filesystem-read-symlink:0004 */}
<ParameterList>
  <Parameter name="p">path to a symlink</Parameter>
  <Parameter name="ec">out-parameter for error reporting in the non-throwing overload</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-read-symlink:0005 */}
The target of the symlink (which may not necessarily exist).

### Exceptions

{/* source:cpp-filesystem-read-symlink:0006 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-read-symlink:0007 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-read-symlink:0008 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.

### Example

{/* source:cpp-filesystem-read-symlink:0009 */}
```cpp
#include <filesystem>
#include <iostream>
 
namespace fs = std::filesystem;
 
int main()
{
    for (fs::path p : {"/usr/bin/gcc", "/bin/cat", "/bin/mouse"})
    {
        std::cout << p;
        fs::exists(p) ?
            fs::is_symlink(p) ?
                std::cout << " -> " << fs::read_symlink(p) << '\n' :
                std::cout << " exists but it is not a symlink\n" :
            std::cout << " does not exist\n";
    }
}
```

Possible output:

```text
"/usr/bin/gcc" -> "gcc-5"
"/bin/cat" exists but it is not a symlink
"/bin/mouse" does not exist
```
