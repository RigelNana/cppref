{/* source:cpp-filesystem-directory-options:0001 */}
This type represents available options that control the behavior of the [`directory_iterator`](/docs/cpp/library/filesystem/directory_iterator) and [`recursive_directory_iterator`](/docs/cpp/library/filesystem/recursive_directory_iterator).

{/* source:cpp-filesystem-directory-options:0002 */}
`directory_options` satisfies the requirements of [*BitmaskType*](/docs/cpp/library/named_req/BitmaskType) (which means the bitwise operators `operator&`, `operator|`, `operator^`, `operator~`, `operator&=`, `operator|=`, and `operator^=` are defined for this type). `none` represents the empty bitmask; every other enumerator represents a distinct bitmask element.

### Member constants

{/* source:cpp-filesystem-directory-options:0003 */}
| Member constant | Meaning |
| --- | --- |
| `none` | (Default) Skip directory symlinks, permission denied is error. |
| `follow_directory_symlink` | Follow rather than skip directory symlinks. |
| `skip_permission_denied` | Skip directories that would otherwise result in permission denied errors. |
