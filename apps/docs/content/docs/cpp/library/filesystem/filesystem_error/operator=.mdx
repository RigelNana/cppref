{/* source:cpp-filesystem-filesystem-error-operator:0001 */}
Assigns the contents with those of `other`. If `*this` and `other` both have dynamic type `std::filesystem::filesystem_error` then `std::strcmp(what(), other.what()) == 0` after assignment.

### Parameters

{/* source:cpp-filesystem-filesystem-error-operator:0002 */}
<ParameterList>
  <Parameter name="other">another `filesystem_error` object to assign with</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-filesystem-error-operator:0003 */}
`*this`

### Notes

{/* source:cpp-filesystem-filesystem-error-operator:0004 */}
Typical implementations store path objects referenced by [`path1()`](/docs/cpp/library/filesystem/filesystem_error/path) and [`path2()`](/docs/cpp/library/filesystem/filesystem_error/path) in a reference-counted storage. As a result, `*this` and `other` usually share their path objects after assignment.
