  <Declaration id="1" language="cpp" since="C++17" code={`std::uintmax_t file_size( const std::filesystem::path& p );`} />
  <Declaration id="2" language="cpp" since="C++17" code={`std::uintmax_t file_size( const std::filesystem::path& p,
                          std::error_code& ec ) noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-filesystem-file-size:0001 */}
    If `p` does not exist, reports an error.

    {/* source:cpp-filesystem-file-size:0002 */}
    For a regular file `p`, returns the size determined as if by reading the `st_size` member of the structure obtained by POSIX [`stat`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/stat.html) (symlinks are followed).

    {/* source:cpp-filesystem-file-size:0003 */}
    The result of attempting to determine the size of a directory (as well as any other file that is not a regular file or a symlink) is implementation-defined.

    {/* source:cpp-filesystem-file-size:0004 */}
    The non-throwing overload returns `static_cast<std::uintmax_t>(-1)` on errors.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-filesystem-file-size:0005 */}
<ParameterList>
  <Parameter name="p">path to examine</Parameter>
  <Parameter name="ec">out-parameter for error reporting in the non-throwing overload</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-file-size:0006 */}
The size of the file, in bytes.

### Exceptions

{/* source:cpp-filesystem-file-size:0007 */}
Any overload not marked `noexcept` may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory allocation fails.

{/* source:cpp-filesystem-file-size:0008 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-file-size:0009 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec.`[`clear`](/docs/cpp/library/error/error_code/clear)`()` if no errors occur.

### Example

{/* source:cpp-filesystem-file-size:0010 */}
```cpp
#include <cmath>
#include <filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::filesystem;
 
struct HumanReadable
{
    std::uintmax_t size{};
 
private:
    friend std::ostream& operator<<(std::ostream& os, HumanReadable hr)
    {
        int o{};
        double mantissa = hr.size;
        for (; mantissa >= 1024.; mantissa /= 1024., ++o);
        os << std::ceil(mantissa * 10.) / 10. << "BKMGTPE"[o];
        return o ? os << "B (" << hr.size << ')' : os;
    }
};
 
int main(int, char const* argv[])
{
    fs::path example = "example.bin";
    fs::path p = fs::current_path() / example;
    std::ofstream(p).put('a'); // create file of size 1
    std::cout << example << " size = " << fs::file_size(p) << '\n';
    fs::remove(p);
 
    p = argv[0];
    std::cout << p << " size = " << HumanReadable{fs::file_size(p)} << '\n';
 
    try
    {
        std::cout << "Attempt to get size of a directory:\n";
        [[maybe_unused]] auto x_x = fs::file_size("/dev");
    }
    catch (fs::filesystem_error& e)
    {
        std::cout << e.what() << '\n';
    }
 
    for (std::error_code ec; fs::path bin : {"cat", "mouse"})
    {
        bin = "/bin"/bin;
        if (const std::uintmax_t size = fs::file_size(bin, ec); ec)
            std::cout << bin << " : " << ec.message() << '\n';
        else
            std::cout << bin << " size = " << HumanReadable{size} << '\n';
    }
}
```

Possible output:

```text
"example.bin" size = 1
"./a.out" size = 22KB (22512)
Attempt to get size of a directory:
filesystem error: cannot get file size: Is a directory [/dev]
"/bin/cat" size = 50.9KB (52080)
"/bin/mouse" : No such file or directory
```
