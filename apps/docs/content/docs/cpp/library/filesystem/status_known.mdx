### Return value

{/* source:cpp-filesystem-status-known:0003 */}
`true` if the given file status is a known file status.

### Notes

{/* source:cpp-filesystem-status-known:0004 */}
Despite the name, the function checks for the file status of [`file_type::none`](/docs/cpp/library/filesystem/file_type) (meaning an error occurred), not [`file_type::unknown`](/docs/cpp/library/filesystem/file_type) (meaning file exists, but its type cannot be determined).
