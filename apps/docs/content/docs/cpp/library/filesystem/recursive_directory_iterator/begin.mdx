{/* source:cpp-filesystem-recursive-directory-iterator-begin:0003 */}
These non-member functions enable the use of `recursive_directory_iterators` with range-based for loops <InlineRevision since="C++20">and make `recursive_directory_iterator` a [`range`](/docs/cpp/library/ranges/range) type</InlineRevision>.

### Parameters

{/* source:cpp-filesystem-recursive-directory-iterator-begin:0004 */}
<ParameterList>
  <Parameter name="iter">a `recursive_directory_iterator`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-recursive-directory-iterator-begin:0005 */}
1) `iter` unchanged.

{/* source:cpp-filesystem-recursive-directory-iterator-begin:0006 */}
2) End iterator (default-constructed `recursive_directory_iterator`).

### Example

{/* source:cpp-filesystem-recursive-directory-iterator-begin:0007 */}
```cpp
#include <cstdlib>
#include <filesystem>
#include <fstream>
#include <iostream>
namespace fs = std::filesystem;
 
int main()
{
    fs::current_path(fs::temp_directory_path());
    fs::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    fs::create_symlink("a", "sandbox/syma");
 
    std::cout << "Print dir structure using OS specific command 'tree':\n";
    std::system("tree --noreport sandbox");
 
    std::cout << "\nPrint dir structure using directory iterator:\n";
    for (auto& p : fs::recursive_directory_iterator("sandbox"))
        std::cout << p << '\n';
 
    fs::remove_all("sandbox");
}
```

Possible output:

```text
Print dir structure using OS specific command 'tree':
sandbox
├── a
│   └── b
├── file1.txt
└── syma -> a
 
Print dir structure using directory iterator:
"sandbox/syma"
"sandbox/file1.txt"
"sandbox/a"
"sandbox/a/b"
```
