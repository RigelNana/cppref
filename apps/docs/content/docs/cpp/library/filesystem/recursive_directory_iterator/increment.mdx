  <DeclarationDescription>
    {/* source:cpp-filesystem-recursive-directory-iterator-increment:0001 */}
    Advances the iterator to the next entry. Invalidates all copies of the previous value of `*this`.

    {/* source:cpp-filesystem-recursive-directory-iterator-increment:0002 */}
    If there are no more entries left in the currently iterated directory, the iteration is resumed over the parent directory. The process is repeated if the parent directory has no sibling entries that can to be iterated on. If the parent of the directory hierarchy that has been recursively iterated on is reached (there are no candidate entries at `depth() == 0)`, `*this` is set to an end iterator.

    {/* source:cpp-filesystem-recursive-directory-iterator-increment:0003 */}
    Otherwise, if `*this` refers to a directory, it is iterated into if the following conditions are met:

    {/* source:cpp-filesystem-recursive-directory-iterator-increment:0004 */}
    - [`disable_recursion_pending()`](/docs/cpp/library/filesystem/recursive_directory_iterator/disable_recursion_pending) has not been called before this increment, i.e. `recursion_pending() == true`.
    - The directory is not a symlink or following symlinks is enabled, i.e., at least one of the following is true:
      - `!is_symlink((*this)->symlink_status())`.
      - `(options() & directory_options::follow_directory_symlink) != directory_options::none)`
  </DeclarationDescription>
</DeclarationDoc>

### Exceptions

{/* source:cpp-filesystem-recursive-directory-iterator-increment:0007 */}

{/* source:cpp-filesystem-recursive-directory-iterator-increment:0008 */}
1) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with the OS error code as the error code argument.

{/* source:cpp-filesystem-recursive-directory-iterator-increment:0009 */}
2) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec`. [`clear`](/docs/cpp/library/error/error_code/clear)() if no errors occur.
