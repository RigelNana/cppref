{/* source:cpp-filesystem-recursive-directory-iterator-depth:0000 */}
<DeclarationDoc>
  <Declaration language="cpp" since="C++17" code={`int depth() const;`} />

  <DeclarationDescription>
    {/* source:cpp-filesystem-recursive-directory-iterator-depth:0001 */}
    Returns the number of directories from the starting directory to the currently iterated directory, i.e. the current depth of the directory hierarchy.

    {/* source:cpp-filesystem-recursive-directory-iterator-depth:0002 */}
    The starting directory has depth of 0, its subdirectories have depth 1, etc.

    {/* source:cpp-filesystem-recursive-directory-iterator-depth:0003 */}
    The behavior is undefined if `*this` is the end iterator.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-filesystem-recursive-directory-iterator-depth:0004 */}
(none)

### Return value

{/* source:cpp-filesystem-recursive-directory-iterator-depth:0005 */}
Current depth of the directory hierarchy.

### Exceptions

{/* source:cpp-filesystem-recursive-directory-iterator-depth:0006 */}
Throws nothing.

### Example

{/* source:cpp-filesystem-recursive-directory-iterator-depth:0007 */}
This example uses iteration depth to calculate the indentation of a directory tree printout.

```cpp
#include <filesystem>
#include <fstream>
#include <iostream>
#include <string>
namespace fs = std::filesystem;
 
int main()
{
    fs::current_path(fs::temp_directory_path());
    fs::create_directories("sandbox/a/b/c");
    fs::create_directories("sandbox/a/b/d/e");
    std::ofstream("sandbox/a/b/file1.txt");
    fs::create_symlink("a", "sandbox/syma");
    for (auto i = fs::recursive_directory_iterator("sandbox");
         i != fs::recursive_directory_iterator();
         ++i)
    {
        std::cout << std::string(i.depth() << 1, ' ') << *i;
        if (fs::is_symlink(i->symlink_status()))
            std::cout << " -> " << fs::read_symlink(*i);
        std::cout << '\n';
    }
    fs::remove_all("sandbox");
}
```

Output:

```text
"sandbox/syma" -> "a"
"sandbox/a"
  "sandbox/a/b"
    "sandbox/a/b/d"
      "sandbox/a/b/d/e"
    "sandbox/a/b/file1.txt"
    "sandbox/a/b/c"
```
