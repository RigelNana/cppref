{/* source:cpp-filesystem-recursive-directory-iterator:0001 */}
`recursive_directory_iterator` is a [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator) that iterates over the [`directory_entry`](/docs/cpp/library/filesystem/directory_entry) elements of a directory, and, recursively, over the entries of all subdirectories. The iteration order is unspecified, except that each directory entry is visited only once.

{/* source:cpp-filesystem-recursive-directory-iterator:0002 */}
By default, symlinks are not followed, but this can be enabled by specifying the directory option [`follow_directory_symlink`](/docs/cpp/library/filesystem/directory_options) at construction time.

{/* source:cpp-filesystem-recursive-directory-iterator:0003 */}
The special pathnames *dot* and *dot-dot* are skipped.

{/* source:cpp-filesystem-recursive-directory-iterator:0004 */}
If the `recursive_directory_iterator` reports an error or is advanced past the last directory entry of the top-level directory, it becomes equal to the default-constructed iterator, also known as the end iterator. Two end iterators are always equal, dereferencing or incrementing the end iterator is undefined behavior.

{/* source:cpp-filesystem-recursive-directory-iterator:0005 */}
If a file or a directory is deleted or added to the directory tree after the recursive directory iterator has been created, it is unspecified whether the change would be observed through the iterator.

{/* source:cpp-filesystem-recursive-directory-iterator:0006 */}
If the directory structure contains cycles, the end iterator may be unreachable.

### Notes

{/* source:cpp-filesystem-recursive-directory-iterator:0014 */}
A `recursive_directory_iterator` typically holds a reference-counted pointer (to satisfy shallow-copy semantics of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator)) to an implementation object, which holds:

{/* source:cpp-filesystem-recursive-directory-iterator:0015 */}
- a container (such as [`std::vector`](/docs/cpp/library/container/vector)) of non-recursive [`directory_iterator`](/docs/cpp/library/filesystem/directory_iterator)s that forms the recursion stack,
- the recursion depth counter (accessible with [`depth()`](/docs/cpp/library/filesystem/recursive_directory_iterator/depth)),
- the directory options used at construction (accessible with [`options()`](/docs/cpp/library/filesystem/recursive_directory_iterator/options)),
- the pending recursion flag (accessible with [`recursion_pending()`](/docs/cpp/library/filesystem/recursive_directory_iterator/recursion_pending), may be combined with the directory options to save space).

### Example

{/* source:cpp-filesystem-recursive-directory-iterator:0016 */}
```cpp
#include <filesystem>
#include <fstream>
#include <iostream>
#include <string>
namespace fs = std::filesystem;
 
int main()
{
    std::filesystem::current_path(std::filesystem::temp_directory_path());
    std::filesystem::create_directories("sandbox/a/b");
    std::ofstream("sandbox/file1.txt");
    std::filesystem::create_symlink("a", "sandbox/syma");
 
    // Iterate over the std::filesystem::directory_entry elements explicitly
    auto entry_length{3UZ};
    for (const fs::directory_entry& dir_entry :
            fs::recursive_directory_iterator("sandbox"))
    {
        std::cout << dir_entry << '\n';
        if (auto l{dir_entry.path().string().length()}; entry_length < l)
            entry_length = l;
    }
    std::cout << std::string(entry_length + 2, '-') << '\n';
 
    // Iterate over the std::filesystem::directory_entry elements using `auto`
    for (auto const& dir_entry : fs::recursive_directory_iterator("sandbox"))
        std::cout << dir_entry << '\n';
 
    std::filesystem::remove_all("sandbox");
}
```

Possible output:

```text
"sandbox/syma"
"sandbox/file1.txt"
"sandbox/a"
"sandbox/a/b"
-------------------
"sandbox/syma"
"sandbox/file1.txt"
"sandbox/a"
"sandbox/a/b"
```
