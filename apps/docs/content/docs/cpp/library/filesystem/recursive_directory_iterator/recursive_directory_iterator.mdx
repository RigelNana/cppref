### Exceptions

4,5) Throws [`std::filesystem::filesystem_error`](/docs/cpp/library/filesystem/filesystem_error) on underlying OS API errors, constructed with `p` as the first path argument and the OS error code as the error code argument.

{/* source:cpp-filesystem-recursive-directory-iterator-recursive-directory-iterator:0010 */}
6,7) Sets a `std::error_code&` parameter to the OS API error code if an OS API call fails, and executes `ec`. [`clear`](/docs/cpp/library/error/error_code/clear)() if no errors occur.

### Notes

{/* source:cpp-filesystem-recursive-directory-iterator-recursive-directory-iterator:0011 */}
Recursive directory iterators do not follow directory symlinks by default. To enable this behavior, specify [`directory_options::follow_directory_symlink`](/docs/cpp/library/filesystem/directory_options) among the `options` option set.
