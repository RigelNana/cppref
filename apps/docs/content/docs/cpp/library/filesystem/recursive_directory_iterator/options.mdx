  <DeclarationDescription>
    {/* source:cpp-filesystem-recursive-directory-iterator-options:0001 */}
    Returns the options that affect the directory iteration. The options can only be supplied when constructing the directory iterator.

    {/* source:cpp-filesystem-recursive-directory-iterator-options:0002 */}
    If the options argument was not supplied, returns [`std::filesystem::directory_options::none`](/docs/cpp/library/filesystem/directory_options).
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-filesystem-recursive-directory-iterator-options:0003 */}
(none)

### Return value

{/* source:cpp-filesystem-recursive-directory-iterator-options:0004 */}
The effective options that affect the directory iteration.

### Exceptions

{/* source:cpp-filesystem-recursive-directory-iterator-options:0005 */}
Throws nothing.
