{/* source:cpp-filesystem-recursive-directory-iterator-disable-recursion-pending:0000 */}
<DeclarationDoc>
  <Declaration language="cpp" since="C++17" code={`void disable_recursion_pending();`} />

  <DeclarationDescription>
    {/* source:cpp-filesystem-recursive-directory-iterator-disable-recursion-pending:0001 */}
    Disables recursion to the currently referred subdirectory, if any.

    {/* source:cpp-filesystem-recursive-directory-iterator-disable-recursion-pending:0002 */}
    The call modifies the pending recursion flag on the iterator in such a way that the next time [`increment`](/docs/cpp/library/filesystem/recursive_directory_iterator/increment) is called, the iterator will advance within the current directory even if it is currently referring to a subdirectory that hasn't been visited.

    {/* source:cpp-filesystem-recursive-directory-iterator-disable-recursion-pending:0003 */}
    The status of the pending recursion flag can be queried with [`recursion_pending()`](/docs/cpp/library/filesystem/recursive_directory_iterator/recursion_pending), which is `false` after this call. It is reset back to `true` after [`increment`](/docs/cpp/library/filesystem/recursive_directory_iterator/increment), and its initial value is also `true`.

    {/* source:cpp-filesystem-recursive-directory-iterator-disable-recursion-pending:0004 */}
    The behavior is undefined if `*this` is the end iterator.
  </DeclarationDescription>
</DeclarationDoc>

### Example

{/* source:cpp-filesystem-recursive-directory-iterator-disable-recursion-pending:0008 */}
```cpp
#include <cstdlib>
#include <filesystem>
#include <fstream>
#include <iostream>
#include <string>
namespace fs = std::filesystem;
 
int main()
{
    fs::current_path(fs::temp_directory_path());
    fs::create_directories("sandbox/a/b/c");
    fs::create_directories("sandbox/a/b/d/e");
    std::ofstream("sandbox/a/b/file1.txt");
    fs::create_symlink("a", "sandbox/syma");
    std::system("tree sandbox");
    for (auto i = fs::recursive_directory_iterator("sandbox");
         i != fs::recursive_directory_iterator();
         ++i)
    {
        std::cout << std::string(i.depth() * 2, ' ') << *i;
        if (fs::is_symlink(i->symlink_status()))
            std::cout << " -> " << fs::read_symlink(*i);
        std::cout << '\n';
 
        // do not descend into "b"
        if (i->path().filename() == "b")
            i.disable_recursion_pending();
    }
    fs::remove_all("sandbox");
}
```

Possible output:

```text
sandbox
├── a
│   └── b
│       ├── c
│       ├── d
│       │   └── e
│       └── file1.txt
└── syma -> a
 
"sandbox/a"
  "sandbox/a/b"
"sandbox/syma" -> "a"
```
