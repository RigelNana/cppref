{/* source:cpp-filesystem-path-compare:0001 */}
Compares the lexical representations of the path and another path.

{/* source:cpp-filesystem-path-compare:0002 */}
1. 1) If `root_name().native().compare(p.root_name().native())` is nonzero, returns that value.

{/* source:cpp-filesystem-path-compare:0003 */}
- Otherwise, if `has_root_directory() != p.has_root_directory()`, returns a value less than zero if [`has_root_directory()`](/docs/cpp/library/filesystem/path/has_path) is `false` and a value greater than zero otherwise.

{/* source:cpp-filesystem-path-compare:0004 */}
- Otherwise returns a value less than, equal to or greater than `0` if the relative portion of the path ([`relative_path()`](/docs/cpp/library/filesystem/path/relative_path)) is respectively lexicographically less than, equal to or greater than the relative portion of `p` (`p.relative_path()`). Comparison is performed element-wise, as if by iterating both paths from [`begin()`](/docs/cpp/library/filesystem/path/begin) to [`end()`](/docs/cpp/library/filesystem/path/begin) and comparing the result of [`native()`](/docs/cpp/library/filesystem/path/native) for each element.

{/* source:cpp-filesystem-path-compare:0005 */}
2. 2) Equivalent to `compare(path(str))`.

{/* source:cpp-filesystem-path-compare:0006 */}
3. 3) Equivalent to `compare(path(s))`.

### Parameters

{/* source:cpp-filesystem-path-compare:0007 */}
<ParameterList>
  <Parameter name="p">
    a path to compare to
  </Parameter>

    a string or string view representing path to compare to
  </Parameter>
  <Parameter name="s">
    a null-terminated string representing path to compare to
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-path-compare:0008 */}
A value less than `0` if the path is lexicographically less than the given path.

{/* source:cpp-filesystem-path-compare:0009 */}
A value equal to `0` if the path is lexicographically equal to the given path.

{/* source:cpp-filesystem-path-compare:0010 */}
A value greater than `0` if the path is lexicographically greater than the given path.

### Exceptions

{/* source:cpp-filesystem-path-compare:0011 */}
2,3. 2,3) May throw implementation-defined exceptions.

### Notes

{/* source:cpp-filesystem-path-compare:0012 */}
For two-way comparisons, [binary operators](/docs/cpp/library/filesystem/path/operator_cmp) may be more suitable.

### Example

{/* source:cpp-filesystem-path-compare:0013 */}
```cpp
#include <filesystem>
#include <iostream>
#include <string_view>
namespace fs = std::filesystem;
 
void demo(fs::path p1, fs::path p2, std::string_view msg)
{
    std::cout << p1;
    const int rc = p1.compare(p2); 
    if (rc < 0)
        std::cout << " < ";
    else if (rc > 0)
        std::cout << " > ";
    else
        std::cout << " == ";
    std::cout << p2 << " \t: " << msg << '\n';
}
 
int main()
{
    demo("/a/b/", "/a/b/", "simple");
    demo("/a/b/", "/a/b/c", "simple");
    demo("/a/b/../b", "/a/b", "no canonical conversion");
    demo("/a/b", "/a/b/.", "no canonical conversion");
    demo("/a/b/", "a/c", "absolute paths order after relative ones");
}
```

Output:

```text
"/a/b/" == "/a/b/"      : simple
"/a/b/" < "/a/b/c"	: simple
"/a/b/../b" > "/a/b"	: no canonical conversion
"/a/b" < "/a/b/."	: no canonical conversion
"/a/b/" > "a/c"	        : absolute paths order after relative ones
```
