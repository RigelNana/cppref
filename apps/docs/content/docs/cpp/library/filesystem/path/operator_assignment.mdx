<DeclarationDescription>

{/* source:cpp-filesystem-path-operator:0001 */}
1. 1) Replaces the contents of `*this` with a pathname whose both native and generic format representations equal those of `p`.

{/* source:cpp-filesystem-path-operator:0002 */}
2. 2) Replaces the contents of `*this` with a pathname whose both native and generic format representations equal those of `p`, possibly using move semantics: `p` is left in a valid, but unspecified state.

{/* source:cpp-filesystem-path-operator:0003 */}
3. 3) Replaces the contents of `*this` with a new path value constructed from detected-format `source`, which is left in valid, but unspecified state. Equivalent to `assign(std::move(source))`.

{/* source:cpp-filesystem-path-operator:0004 */}
4. 4) Replaces the contents of `*this` with a new path value constructed from detected-format `source` as if by overload (4) of the [path constructor](/docs/cpp/library/filesystem/path/path). Equivalent to `assign(source)`.

</DeclarationDescription>

{/* source:cpp-filesystem-path-operator:0005 */}
(4) participates in overload resolution only if `Source` and `path` are not the same type, and either:

{/* source:cpp-filesystem-path-operator:0006 */}
-  `Source` is a specialization of `[std::basic_string](/docs/cpp/library/string/basic_string)` or `[std::basic_string_view](/docs/cpp/library/string/basic_string_view)`, or

-  `std::iterator_traits<std::decay_t<Source>>::value_type` is valid and denotes a possibly const-qualified encoding character type (`char`, <InlineRevision since="C++20">`char8_t`, </InlineRevision>`char16_t`, `char32_t`, or `wchar_t`).

### Parameters

{/* source:cpp-filesystem-path-operator:0007 */}
<ParameterList>
  <Parameter name="p">
    a path to assign
  </Parameter>
  <Parameter name="source">
    a `[std::basic_string](/docs/cpp/library/string/basic_string)`, `[std::basic_string_view](/docs/cpp/library/string/basic_string_view)`, pointer to a null-terminated character/wide character string, or an input iterator that points to a null-terminated character/wide character sequence. The character type must be one of `char`, <InlineRevision since="C++20">`char8_t`, </InlineRevision>`char16_t`, `char32_t`, `wchar_t`
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-path-operator:0008 */}
`*this`

### Example

{/* source:cpp-filesystem-path-operator:0009 */}
```cpp
#include <filesystem>
namespace fs = std::filesystem;
 
int main()
{
    fs::path p = "C:/users/abcdef/AppData/Local";
    p = p / "Temp"; // move assignment
    const wchar_t* wstr = L"D:/猫.txt";
    p = wstr; // assignment from a source
}
```
