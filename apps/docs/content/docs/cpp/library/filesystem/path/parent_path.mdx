{/* source:cpp-filesystem-path-parent-path:0001 */}
Returns the path to the parent directory.

{/* source:cpp-filesystem-path-parent-path:0002 */}
If `has_relative_path()` returns false, the result is a copy of `*this`.
Otherwise, the result is a path whose generic format pathname is the longest prefix of the generic format pathname of `*this` that produces one fewer element in its iteration.

### Parameters

{/* source:cpp-filesystem-path-parent-path:0003 */}
(none)

### Return value

{/* source:cpp-filesystem-path-parent-path:0004 */}
The path to the parent directory, or a copy of `*this` if not `has_relative_path()`.

### Exceptions

{/* source:cpp-filesystem-path-parent-path:0005 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-filesystem-path-parent-path:0006 */}
```cpp
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;
 
int main()
{
    for (fs::path p : {"/var/tmp/example.txt", "/", "/var/tmp/."})
        std::cout << "The parent path of " << p
                  << " is " << p.parent_path() << '\n';
}
```

Possible output:

```text
The parent path of "/var/tmp/example.txt" is "/var/tmp"
The parent path of "/" is "/"
The parent path of "/var/tmp/." is "/var/tmp"
```
