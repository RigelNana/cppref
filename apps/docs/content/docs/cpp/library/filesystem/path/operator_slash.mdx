{/* source:cpp-filesystem-path-operator-slash:0001 */}
Concatenates two path components using the preferred directory separator if appropriate (see [`operator/=`](/docs/cpp/library/filesystem/path/append) for details).

{/* source:cpp-filesystem-path-operator-slash:0002 */}
Effectively returns `path(lhs) /= rhs`.

{/* source:cpp-filesystem-path-operator-slash:0003 */}
This function  is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when std::filesystem::path is an associated class of the arguments. This prevents undesirable conversions in the presence of a `using namespace std::filesystem;` *using-directive*.

### Parameters

{/* source:cpp-filesystem-path-operator-slash:0004 */}
<ParameterList>
  <Parameter name="lhs, rhs">
    paths to concatenate
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-filesystem-path-operator-slash:0005 */}
The result of path concatenation.

### Example

{/* source:cpp-filesystem-path-operator-slash:0006 */}
```cpp
#include <filesystem>
#include <iostream>
 
int main()
{
#   if defined(_WIN32) // see e.g. stackoverflow.com/questions/142508
 
    std::filesystem::path p = "C:";
 
    std::cout << "\"C:\" / \"Users\" / \"batman\" == " << p / "Users" / "batman" << '\n';
 
#   else // __linux__ etc
 
    std::filesystem::path p = "/home";
 
    std::cout << "\"/home\" / \"tux\" / \".fonts\" == " << p / "tux" / ".fonts" << '\n';
 
#   endif
}
```

Possible output:

```text
Windows specific output:
"C:" / "Users" / "batman" == "C:Users\\batman"
 
Linux etc specific output:
"/home" / "tux" / ".fonts" == "/home/tux/.fonts"
```
