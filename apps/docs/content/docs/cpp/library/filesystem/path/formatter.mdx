{/* source:cpp-filesystem-path-formatter:0001 */}
The template specialization of `[std::formatter](/docs/cpp/library/text/format/formatter)` for the `[std::filesystem::path](/docs/cpp/library/filesystem/path)` class allows users to convert a pathname to its textual representation using [formatting functions](/docs/cpp/library/text/format). This specialization is [*debug-enabled*](/docs/cpp/library/text/format/formatter#Basic_standard_specializations).

### Format specification

{/* source:cpp-filesystem-path-formatter:0002 */}
The syntax of format specifications *path-format-spec* is:

{/* source:cpp-filesystem-path-formatter:0003 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="fill-and-align ﻿(optional) width ﻿(optional) ?(optional) g(optional)" />
</DeclarationDoc>

{/* source:cpp-filesystem-path-formatter:0004 */}
*fill-and-align* and *width* have the same meaning as in [standard format specification](/docs/cpp/library/text/format/formatter#Standard_format_specification).

{/* source:cpp-filesystem-path-formatter:0005 */}
The `?` option is used to format the pathname as an [escaped string](/docs/cpp/library/text/format/spec#Formatting_escaped_characters_and_strings).

{/* source:cpp-filesystem-path-formatter:0006 */}
The `g` option is used to specify that the pathname is in [generic-format representation](/docs/cpp/library/filesystem/path/format).

{/* source:cpp-filesystem-path-formatter:0009 */}
#### std::formatter\<std::filesystem::path\>::parse

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr auto parse( std::basic_format_parse_context<CharT>& ctx ) 
    -> std::basic_format_parse_context<CharT>::iterator;`} />
</DeclarationDoc>

Parses the format specifiers as a *path-format-spec* and stores the parsed specifiers in the current object. Returns an iterator past the end of the *path-format-spec*.

{/* source:cpp-filesystem-path-formatter:0010 */}
#### std::formatter\<std::filesystem::path\>::format

<DeclarationDoc>
  <Declaration language="cpp" code={`template< class FormatContext >
auto format( const std::filesystem::path& p, FormatContext& ctx ) const 
    -> FormatContext::iterator;`} />
</DeclarationDoc>

Let `s` be `p.generic<std::filesystem::path::value_type>()` if the `g` option is used, otherwise `p.native()`. Writes `s` into `ctx.out()` as specified by *path-format-spec*. For character transcoding of the pathname: - The pathname is transcoded from the native encoding for wide character strings to UTF-8 with maximal subparts of ill-formed subsequences substituted with `U+FFFD` REPLACEMENT CHARACTER if - `std::is_same_v<CharT, char>` is `true`, - `std::is_same_v<typename path::value_type, wchar_t>` is `true`, and - [ordinary literal encoding](/docs/cpp/language/basic_concepts/charset#Code_unit_and_literal_encoding) is UTF-8. - Otherwise, no transcoding is performed if `std::is_same_v<typename path::value_type, CharT>` is `true`. - Otherwise, transcoding is implementation-defined. Returns an iterator past the end of the output range.
