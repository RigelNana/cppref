{/* source:cpp-filesystem-path-is-absrel:0001 */}
Checks whether the path is absolute or relative. An absolute path is a path that unambiguously identifies the location of a file without reference to an additional starting location. The first version returns `true` if the path, in native format, is absolute, `false` otherwise; the second version the other way round.

### Parameters

{/* source:cpp-filesystem-path-is-absrel:0002 */}
(none)

### Return value

{/* source:cpp-filesystem-path-is-absrel:0003 */}
1. 1) `true` if the path is absolute, `false` otherwise.

{/* source:cpp-filesystem-path-is-absrel:0004 */}
2. 2) `false` if the path is absolute, `true` otherwise.

### Exceptions

{/* source:cpp-filesystem-path-is-absrel:0005 */}
May throw implementation-defined exceptions.

### Notes

{/* source:cpp-filesystem-path-is-absrel:0006 */}
The path `"/"` is absolute on a POSIX OS, but is relative on Windows.
