{/* source:cpp-filesystem-path-assign:0001 */}
Replaces the contents to the `path` object by a new pathname constructed from the given character sequence.

{/* source:cpp-filesystem-path-assign:0002 */}
1. 1) Assigns the pathname identified by the detected-format string `source`, which is left in valid, but unspecified state.

{/* source:cpp-filesystem-path-assign:0003 */}
2. 2) Assigns the pathname identified by the detected-format character range `source`.

{/* source:cpp-filesystem-path-assign:0004 */}
3. 3) Assigns the pathname identified by detected-format character range `[first, last)`.

{/* source:cpp-filesystem-path-assign:0005 */}
(2) participates in overload resolution only if `Source` and `path` are not the same type, and either:

{/* source:cpp-filesystem-path-assign:0006 */}
-  `Source` is a specialization of `[std::basic_string](/docs/cpp/library/string/basic_string)` or `[std::basic_string_view](/docs/cpp/library/string/basic_string_view)`, or

-  `std::iterator_traits<std::decay_t<Source>>::value_type` is valid and denotes a possibly const-qualified encoding character type (`char`, <InlineRevision since="C++20">`char8_t`, </InlineRevision>`char16_t`, `char32_t`, or `wchar_t`).

### Parameters

{/* source:cpp-filesystem-path-assign:0007 */}
<ParameterList>
  <Parameter name="source">
    a character range to use, represented as `[std::string](/docs/cpp/library/string/basic_string)`, `[std::string_view](/docs/cpp/library/string/basic_string_view)`, pointer to a null-terminated multibyte string, or as an input iterator with char value type that points to a null-terminated multibyte string
  </Parameter>
  <Parameter name="first, last">
    a character range to use
  </Parameter>
</ParameterList>

Type requirements

- `InputIt` must meet the requirements of [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator).
- The value type of `InputIt` must be one of the encoded character types (`char`, `wchar_t`, `char16_t` and `char32_t`)

### Return value

{/* source:cpp-filesystem-path-assign:0008 */}
`*this`
