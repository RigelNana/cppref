{/* source:cpp-filesystem-path-operator-cmp:0001 */}
Compares two paths lexicographically.

{/* source:cpp-filesystem-path-operator-cmp:0002 */}
1. 1) Checks whether `lhs` and `rhs` are equal. Equivalent to `!(lhs < rhs) && !(rhs < lhs)`.

{/* source:cpp-filesystem-path-operator-cmp:0003 */}
2. 2) Checks whether `lhs` and `rhs` are not equal. Equivalent to `!(lhs == rhs)`.

{/* source:cpp-filesystem-path-operator-cmp:0004 */}
3. 3) Checks whether `lhs` is less than `rhs`. Equivalent to `lhs.compare(rhs) < 0`.

{/* source:cpp-filesystem-path-operator-cmp:0005 */}
4. 4) Checks whether `lhs` is less than or equal to `rhs`. Equivalent to `!(rhs < lhs)`.

{/* source:cpp-filesystem-path-operator-cmp:0006 */}
5. 5) Checks whether `lhs` is greater than `rhs`. Equivalent to `rhs < lhs`.

{/* source:cpp-filesystem-path-operator-cmp:0007 */}
6. 6) Checks whether `lhs` is greater than or equal to `rhs`. Equivalent to `!(lhs < rhs)`.

{/* source:cpp-filesystem-path-operator-cmp:0008 */}
7. 7) Obtains the three-way comparison result of `lhs` and `rhs`. Equivalent to `lhs.compare(rhs) <=> 0`.

{/* source:cpp-filesystem-path-operator-cmp:0009 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when std::filesystem::path is an associated class of the arguments. This prevents undesirable conversions in the presence of a `using namespace std::filesystem;` *using-directive*.

{/* source:cpp-filesystem-path-operator-cmp:0010 */}
<Revision since="C++20">
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Return value

{/* source:cpp-filesystem-path-operator-cmp:0012 */}
1-6. 1-6) `true` if the corresponding comparison yields, `false` otherwise.

{/* source:cpp-filesystem-path-operator-cmp:0013 */}
7. 7) `std::strong_ordering::less` if `lhs` is less than `rhs`, otherwise `std::strong_ordering::greater` if `rhs` is less than `lhs`, otherwise `std::strong_ordering::equal`.

### Notes

{/* source:cpp-filesystem-path-operator-cmp:0014 */}
Path equality and equivalence have different semantics.

{/* source:cpp-filesystem-path-operator-cmp:0015 */}
In the case of equality, as determined by `operator==`, only lexical representations are compared. Therefore, `path("a") == path("b")` is never `true`.

{/* source:cpp-filesystem-path-operator-cmp:0016 */}
In the case of equivalence, as determined by `[std::filesystem::equivalent()](/docs/cpp/library/filesystem/equivalent)`, it is checked whether two paths *resolve* to the same file system object. Thus `equivalent("a", "b")` will return `true` if the paths resolve to the same file.
