{/* source:cpp-filesystem-path-concat:0001 */}
Concatenates the current path and the argument

{/* source:cpp-filesystem-path-concat:0002 */}
1-3,6,7. 1-3,6,7) Appends `path(p).native()` to the pathname stored in `*this` in the native format. This directly manipulates the value of `native()` and may not be portable between operating systems.

{/* source:cpp-filesystem-path-concat:0003 */}
4,5. 4,5) Same as `return *this += std::basic_string_view(&x, 1);`.

{/* source:cpp-filesystem-path-concat:0004 */}
8. 8) Same as `return *this += path(first, last);`.

{/* source:cpp-filesystem-path-concat:0005 */}
(6) and (7) participate in overload resolution only if `Source` and `path` are not the same type, and either:

{/* source:cpp-filesystem-path-concat:0006 */}
-  `Source` is a specialization of `[std::basic_string](/docs/cpp/library/string/basic_string)` or `[std::basic_string_view](/docs/cpp/library/string/basic_string_view)`, or

-  `std::iterator_traits<std::decay_t<Source>>::value_type` is valid and denotes a possibly const-qualified encoding character type (`char`, <InlineRevision since="C++20">`char8_t`, </InlineRevision>`char16_t`, `char32_t`, or `wchar_t`).

Type requirements

- `InputIt` must meet the requirements of [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator).
- The value type of `InputIt` must be one of the encoded character types (`char`, `wchar_t`, `char16_t` and `char32_t`).
- `CharT` must be one of the encoded character types (`char`, `wchar_t`, `char16_t` and `char32_t`).

### Return value

{/* source:cpp-filesystem-path-concat:0008 */}
`*this`

### Exceptions

{/* source:cpp-filesystem-path-concat:0009 */}
May throw `std::bad_alloc` if memory allocation fails.

### Notes

{/* source:cpp-filesystem-path-concat:0010 */}
Unlike with `[append()](/docs/cpp/library/filesystem/path/append)` or `[operator/=](/docs/cpp/library/filesystem/path/append)`, additional directory separators are never introduced.

### Example

{/* source:cpp-filesystem-path-concat:0011 */}
```cpp
#include <filesystem>
#include <iostream>
#include <string>
 
int main()
{
    std::filesystem::path p1; // an empty path
    p1 += "var"; // does not insert a separator
    std::cout << R"("" + "var" --> )" << p1 << '\n';
    p1 += "lib"; // does not insert a separator
    std::cout << R"("var" + "lib" --> )" << p1 << '\n';
    auto str = std::string{"1234567"};
    p1.concat(std::begin(str) + 3, std::end(str) - 1);
    std::cout << "p1.concat --> " << p1 << '\n';
}
```

Output:

```text
"" + "var" --> "var"
"var" + "lib" --> "varlib"
p1.concat --> "varlib456"
```
