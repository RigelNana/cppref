Determines how string representations of pathnames are interpreted by the constructors of [`std::filesystem::path`](/docs/cpp/library/filesystem/path) that accept strings.

### Constants

{/* source:cpp-filesystem-path-format:0002 */}

  <DescriptionItem>

  </DescriptionItem>
</DescriptionList>

<DescriptionList>
  <DescriptionItem>

    <DescriptionBody>Generic pathname format</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`auto_format`</DescriptionTerm>
    <DescriptionBody>Implementation-defined pathname format, auto-detected where possible</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Notes

{/* source:cpp-filesystem-path-format:0003 */}
On POSIX systems, there is no difference between native and generic format.
