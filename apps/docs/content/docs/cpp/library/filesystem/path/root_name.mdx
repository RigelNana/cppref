{/* source:cpp-filesystem-path-root-name:0001 */}
Returns the root name of the generic-format path. If the path (in generic format) does not include root name, returns `path()`.

### Parameters

{/* source:cpp-filesystem-path-root-name:0002 */}
(none)

### Return value

{/* source:cpp-filesystem-path-root-name:0003 */}
The root name of the path.

### Exceptions

{/* source:cpp-filesystem-path-root-name:0004 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-filesystem-path-root-name:0005 */}
```cpp
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;
 
int main()
{
    std::cout << "Current root name is: " << fs::current_path().root_name() << '\n';
}
```

Possible output:

```text
Current root name is: "C:"
```
