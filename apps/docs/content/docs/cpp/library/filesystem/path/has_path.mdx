Checks whether the path contains the corresponding path element.

{/* source:cpp-filesystem-path-has-path:0002 */}
1. 1) Checks whether [`root_path()`](/docs/cpp/library/filesystem/path/root_path) is empty.

{/* source:cpp-filesystem-path-has-path:0003 */}
2. 2) Checks whether [`root_name()`](/docs/cpp/library/filesystem/path/root_name) is empty.

{/* source:cpp-filesystem-path-has-path:0004 */}
3. 3) Checks whether [`root_directory()`](/docs/cpp/library/filesystem/path/root_directory) is empty.

{/* source:cpp-filesystem-path-has-path:0005 */}
4. 4) Checks whether [`relative_path()`](/docs/cpp/library/filesystem/path/relative_path) is empty.

{/* source:cpp-filesystem-path-has-path:0006 */}
5. 5) Checks whether [`parent_path()`](/docs/cpp/library/filesystem/path/parent_path) is empty.

{/* source:cpp-filesystem-path-has-path:0007 */}
6. 6) Checks whether [`filename()`](/docs/cpp/library/filesystem/path/filename) is empty.

{/* source:cpp-filesystem-path-has-path:0008 */}
7. 7) Checks whether [`stem()`](/docs/cpp/library/filesystem/path/stem) is empty.

{/* source:cpp-filesystem-path-has-path:0009 */}
8. 8) Checks whether [`extension()`](/docs/cpp/library/filesystem/path/extension) is empty.

### Parameters

{/* source:cpp-filesystem-path-has-path:0010 */}
(none)

### Return value

{/* source:cpp-filesystem-path-has-path:0011 */}
`true` if the corresponding path component is not empty, `false` otherwise.

### Exceptions

{/* source:cpp-filesystem-path-has-path:0012 */}
