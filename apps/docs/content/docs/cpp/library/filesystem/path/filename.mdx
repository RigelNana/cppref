{/* source:cpp-filesystem-path-filename:0001 */}
Returns the generic-format filename component of the path.

{/* source:cpp-filesystem-path-filename:0002 */}
Equivalent to `relative_path().empty() ? path() : *--end()`.

### Parameters

{/* source:cpp-filesystem-path-filename:0003 */}
(none)

### Return value

{/* source:cpp-filesystem-path-filename:0004 */}
The filename identified by the path.

### Exceptions

{/* source:cpp-filesystem-path-filename:0005 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-filesystem-path-filename:0006 */}
```cpp
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;
 
int main()
{
    std::cout << fs::path("/foo/bar.txt").filename() << '\n'
              << fs::path("/foo/.bar").filename() << '\n'
              << fs::path("/foo/bar/").filename() << '\n'
              << fs::path("/foo/.").filename() << '\n'
              << fs::path("/foo/..").filename() << '\n'
              << fs::path(".").filename() << '\n'
              << fs::path("..").filename() << '\n'
              << fs::path("/").filename() << '\n'
              << fs::path("//host").filename() << '\n';
}
```

Output:

```text
"bar.txt"
".bar"
""
"."
".."
"."
".."
""
"host"
```
