{/* source:cpp-filesystem-path-operator-ltltgtgt:0001 */}
Performs stream input or output on the path `p`. `std::quoted` is used so that spaces do not cause truncation when later read by stream input operator.

{/* source:cpp-filesystem-path-operator-ltltgtgt:0002 */}
These function templates are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when std::filesystem::path is an associated class of the arguments. This prevents undesirable conversions in the presence of a `using namespace std::filesystem;` *using-directive*.

### Possible implementation

{/* source:cpp-filesystem-path-operator-ltltgtgt:0007 */}
[operator\<\<](/docs/cpp/library/filesystem/path/operator_ltltgtgt#Version_1)

```cpp
template<class CharT, class Traits>
friend std::basic_ostream<CharT,Traits>&
    operator<<(std::basic_ostream<CharT,Traits>& os, const path& p)
{
    os << std::quoted(p.string<CharT,Traits>());
    return os;
}
```

[operator\>\>](/docs/cpp/library/filesystem/path/operator_ltltgtgt#Version_2)

```cpp
template<class CharT, class Traits>
friend std::basic_istream<CharT,Traits>&
    operator>>(std::basic_istream<CharT,Traits>& is, path& p)
{
    std::basic_string<CharT, Traits> t;
    is >> std::quoted(t);
    p = t;
    return is;
}
```

### Example

{/* source:cpp-filesystem-path-operator-ltltgtgt:0008 */}
```cpp
#include <filesystem>
#include <iostream>
 
int main()
{
    std::cout << std::filesystem::current_path() << '\n';
    std::cout << std::filesystem::temp_directory_path() << '\n';
}
```

Possible output:

```text
"/home/user"
"/tmp"
```
