{/* source:cpp-filesystem-path-remove-filename:0001 */}
Removes a single generic-format filename component (as returned by [`filename`](/docs/cpp/library/filesystem/path/filename)) from the given generic-format path.

{/* source:cpp-filesystem-path-remove-filename:0002 */}
After this function completes, [`has_filename`](/docs/cpp/library/filesystem/path/has_path) returns `false`.

### Parameters

{/* source:cpp-filesystem-path-remove-filename:0003 */}
(none)

### Return value

{/* source:cpp-filesystem-path-remove-filename:0004 */}
`*this`

### Exceptions

{/* source:cpp-filesystem-path-remove-filename:0005 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-filesystem-path-remove-filename:0006 */}
```cpp
#include <filesystem>
#include <iostream>
namespace fs = std::filesystem;
 
int main()
{
    fs::path p;
    std::cout << std::boolalpha
              << (p = "foo/bar").remove_filename() << '\t' << p.has_filename() << '\n'
              << (p = "foo/").remove_filename() << '\t' << p.has_filename() << '\n'
              << (p = "/foo").remove_filename() << '\t' << p.has_filename() << '\n'
              << (p = "/").remove_filename() << '\t' << p.has_filename() << '\n'
              << (p = "").remove_filename() << '\t' << p.has_filename() << '\n';
}
```

Output:

```text
"foo/"  false
"foo/"  false
"/"     false
"/"     false
""      false
```
