{/* source:cpp-filesystem-path-empty:0001 */}
Checks if the path in generic format is empty.

### Parameters

{/* source:cpp-filesystem-path-empty:0002 */}
(none)

### Return value

{/* source:cpp-filesystem-path-empty:0003 */}
`true` if the path is empty, `false` otherwise.

### Notes

{/* source:cpp-filesystem-path-empty:0004 */}
An empty path can be obtained by calling [`clear`](/docs/cpp/library/filesystem/path/clear) and by default-constructing a `path`. It can also be returned by a path decomposition function (such as [`extension`](/docs/cpp/library/filesystem/path/extension)) if the corresponding component is not present in the path.

{/* source:cpp-filesystem-path-empty:0005 */}
An empty path is classified as a relative path.
