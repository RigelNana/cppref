Note: the standard doesn't define a named requirement with this name. This is a type category defined by the core language. It is included here as a named requirement only for consistency.

## Requirements

{/* source:cpp-named-req-scalartype:0001 */}
The following types are collectively called scalar types:

{/* source:cpp-named-req-scalartype:0002 */}
- [arithmetic types](/docs/cpp/language/basic_concepts/type-id)
- [enumeration types](/docs/cpp/language/declarations/enum)
- [pointer types](/docs/cpp/language/declarations/pointer)
- [pointer-to-member types](/docs/cpp/language/declarations/pointer#Pointers_to_members)

{/* source:cpp-named-req-scalartype:0003 */}
- [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t) <InlineRevision since="C++11" />

{/* source:cpp-named-req-scalartype:0004 */}
- cv-qualified versions of these types
