{/* source:cpp-named-req-booleantestable:0000 */}
Specifies that an expression of such a type and value category is convertible to `bool`, and for which the logical operators for the type or two different BooleanTestable types have the usual behavior (including [short-circuiting](https://en.wikipedia.org/wiki/Short-circuit_evaluation)).

### Requirements

{/* source:cpp-named-req-booleantestable:0001 */}
Let `e` be an expression of a certain type and value category. The type and value category meet the BooleanTestable requirements if:

{/* source:cpp-named-req-booleantestable:0002 */}
- `!e` is well-formed and does not modify the object denoted by `e`, if any<InlineRevision since="C++11">, except that if `e` is an xvalue, the denoted object can be left in a valid but unspecified state</InlineRevision>.
- Both `e` and `!e` are convertible to `bool` by both [implicit conversion](/docs/cpp/language/expressions/implicit_cast) and [static_cast](/docs/cpp/language/expressions/static_cast).
- Conversions in both manners produce equal results and do not modify the source object, if any<InlineRevision since="C++11">, except that if `e` or `!e` is an xvalue, the source object can be left in a valid but unspecified state</InlineRevision>.
- `bool(!e) == !bool(e)` holds.
- No viable non-member `operator&&` and `operator||` is visible by [argument-dependent lookup](/docs/cpp/language/functions/adl) for the type of `e` or `!e`.
- If `e` or `!e` is of a class type, the class does not define any member `operator&&` or `operator||`.

### Notes

{/* source:cpp-named-req-booleantestable:0003 */}
The standard does not define a named requirement with this name. It was originally proposed in an early resolution of [LWG2114](https://cplusplus.github.io/LWG/issue2114), but was superseded by the exposition-only concept [*boolean-testable*](/docs/cpp/library/concepts/boolean-testable) in the final resolution [P2167R3](https://wg21.link/P2167R3). Because implementations generally expect the provided types to model *boolean-testable* even in pre-C++20 modes, we intentedly treat P2167R3 as a defect report and transform the *boolean-testable* to legacy named requirements.

{/* source:cpp-named-req-booleantestable:0004 */}
When the `&&` and `||` operators are used with operands whose type and value category are BooleanTestable, built-in versions are selected and short-circuit evaluation is performed.

{/* source:cpp-named-req-booleantestable:0005 */}
<Revision since="C++20">The type and value category of an expression `e` meet the BooleanTestable requirements if and only if `decltype((e))` models [*boolean-testable*](/docs/cpp/library/concepts/boolean-testable).</Revision>

{/* source:cpp-named-req-booleantestable:0006 */}
Examples of BooleanTestable types (with any value category) include `bool`<InlineRevision since="C++11">, [`std::true_type`](/docs/cpp/library/meta/integral_constant)</InlineRevision>, `std::bitset<N>::`[`reference`](/docs/cpp/library/utility/bitset/reference), and `int*`.
