{/* source:cpp-named-req-equalitycomparable:0000 */}
The type must work with `==` operator and the result should have standard semantics.

### Requirements

{/* source:cpp-named-req-equalitycomparable:0001 */}
The type `T` satisfies *EqualityComparable* if given expressions `a`, `b` and `c` of type <InlineRevision since="C++11">`T` or </InlineRevision>`const T`, the following expression is valid and has its specified effects:

{/* source:cpp-named-req-equalitycomparable:0002 */}
| Expression | Type | Effects |
| --- | --- | --- |
| `a == b` | meets [*BooleanTestable*](/docs/cpp/library/named_req/BooleanTestable)<br /><InlineRevision until="C++20" /> | Establishes an [equivalence relation](https://en.wikipedia.org/wiki/Equivalence_relation), that is, it satisfies the following properties:<br />- For all values of `a`, `a == a` yields `true`.<br />- If `a == b`, then `b == a`.<br />- If `a == b` and `b == c`, then `a == c`. |
| `a == b` | models [`boolean-testable`](/docs/cpp/library/concepts/boolean-testable)<br /><InlineRevision since="C++20" /> | Establishes an [equivalence relation](https://en.wikipedia.org/wiki/Equivalence_relation), that is, it satisfies the following properties:<br />- For all values of `a`, `a == a` yields `true`.<br />- If `a == b`, then `b == a`.<br />- If `a == b` and `b == c`, then `a == c`. |

### Notes

{/* source:cpp-named-req-equalitycomparable:0003 */}
To satisfy this requirement, types that do not have built-in [comparison operators](/docs/cpp/language/expressions/operator_comparison) have to provide a [user-defined `operator==`](/docs/cpp/language/expressions/operators).

{/* source:cpp-named-req-equalitycomparable:0004 */}
For the types that are both *EqualityComparable* and [*LessThanComparable*](/docs/cpp/library/named_req/LessThanComparable), the C++ standard library makes a distinction between

{/* source:cpp-named-req-equalitycomparable:0005 */}
- *Equality*, which is the value of the expression `a == b` and
- *Equivalence*, which is the value of the expression `!(a < b) && !(b < a)`.
