{/* source:cpp-named-req-erasable:0000 */}
Specifies that an object of the type can be destroyed by a given [*Allocator*](/docs/cpp/library/named_req/Allocator).

### Requirements

{/* source:cpp-named-req-erasable:0001 */}
Given the following types, values and expressions:

{/* source:cpp-named-req-erasable:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`T`</DescriptionTerm>
    <DescriptionBody>an object type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`A`</DescriptionTerm>
    <DescriptionBody>an allocator type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`X`</DescriptionTerm>
    <DescriptionBody>a container type satisfying all following conditions:<br />`X::value_type` is the same as `T`.<br />`X::allocator_type` is the same as `std::allocator_traits<A>::rebind_alloc<T>`.</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`m`</DescriptionTerm>
    <DescriptionBody>an lvalue of type `A`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`p`</DescriptionTerm>
    <DescriptionBody>a pointer of type `T*`</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-named-req-erasable:0003 */}
If the expression `std::allocator_traits<A>::destroy(m, p)` is well-formed, `T` is *Erasable* from `X`.

### Notes

{/* source:cpp-named-req-erasable:0004 */}
All [standard library containers](/docs/cpp/library/container) require that their value types satisfy *Erasable*.

{/* source:cpp-named-req-erasable:0005 */}
<Revision until="C++20">
With the default allocator, this requirement is equivalent to the validity of `p->~T()`, which accepts class types with accessible destructors and all scalar types, but rejects array types, function types, reference types, and `void`.
</Revision>

<Revision since="C++20">
With the default allocator, this requirement is equivalent to the validity of `std::destroy_at(p)`, which accepts class types with accessible destructors and all scalar types, as well as arrays thereof.
</Revision>

{/* source:cpp-named-req-erasable:0006 */}
Although it is required that customized `destroy` is used when destroying elements of [`std::basic_string`](/docs/cpp/library/string/basic_string) until C++23, all implementations only used the default mechanism. The requirement is corrected by [P1072R10](https://wg21.link/P1072R10) to match existing practice.
