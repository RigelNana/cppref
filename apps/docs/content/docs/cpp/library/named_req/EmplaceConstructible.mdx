{/* source:cpp-named-req-emplaceconstructible:0000 */}
Specifies that an object of the type can be constructed from a given set of arguments in uninitialized storage by a given allocator.

### Requirements

{/* source:cpp-named-req-emplaceconstructible:0001 */}
The type `T` is *EmplaceConstructible* into the [*Container*](/docs/cpp/library/named_req/Container) `X` (whose `value_type` is identical to `T`) from the arguments `args` if, given

{/* source:cpp-named-req-emplaceconstructible:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`A`</DescriptionTerm>
    <DescriptionBody>an allocator type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`m`</DescriptionTerm>
    <DescriptionBody>an lvalue of type `A`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`p`</DescriptionTerm>
    <DescriptionBody>the pointer of type `T*` prepared by the container</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`args`</DescriptionTerm>
    <DescriptionBody>zero or more arguments</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-named-req-emplaceconstructible:0003 */}
where `X::allocator_type` is identical to `std::allocator_traits<A>::rebind_alloc<T>`,

{/* source:cpp-named-req-emplaceconstructible:0004 */}
the following expression is well-formed:

{/* source:cpp-named-req-emplaceconstructible:0005 */}
```cpp
std::allocator_traits<A>::construct(m, p, args);
```

{/* source:cpp-named-req-emplaceconstructible:0006 */}
If `X` is not allocator-aware or is a [`std::basic_string`](/docs/cpp/library/string/basic_string) specialization, the term is defined as if `A` were `std::allocator<T>`, except that no allocator object needs to be created, and user-defined specializations of [`std::allocator`](/docs/cpp/library/memory/allocator) are not instantiated.

### Notes

{/* source:cpp-named-req-emplaceconstructible:0007 */}
Although it is required that customized `construct` is used when constructing elements of [`std::basic_string`](/docs/cpp/library/string/basic_string) until C++23, all implementations only used the default mechanism. The requirement is corrected by [P1072R10](https://wg21.link/P1072R10) to match existing practice.
