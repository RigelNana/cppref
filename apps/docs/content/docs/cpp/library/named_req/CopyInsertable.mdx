{/* source:cpp-named-req-copyinsertable:0000 */}
Specifies that an object of the type can be copy-constructed in-place by a given allocator.

### Requirements

{/* source:cpp-named-req-copyinsertable:0001 */}
Given the following types, values and expressions:

{/* source:cpp-named-req-copyinsertable:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`T`</DescriptionTerm>
    <DescriptionBody>an object type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`A`</DescriptionTerm>
    <DescriptionBody>an allocator type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`X`</DescriptionTerm>
    <DescriptionBody>a container type satisfying all following conditions:<br />`X::value_type` is the same as `T`.<br />`X::allocator_type` is the same as `std::allocator_traits<A>::rebind_alloc<T>`.</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`m`</DescriptionTerm>
    <DescriptionBody>an lvalue of type `A`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`p`</DescriptionTerm>
    <DescriptionBody>a pointer of type `T*`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`v`</DescriptionTerm>
    <DescriptionBody>an expression denoting an lvalue of type `T` / `const T`, or an rvalue of type `const T`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`expr`</DescriptionTerm>
    <DescriptionBody>`std::allocator_traits<A>::construct(m, p, v)`</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-named-req-copyinsertable:0003 */}
`T` is *CopyInsertable* into `X` if all following conditions are satisfied:

{/* source:cpp-named-req-copyinsertable:0004 */}
- `T` is [*MoveInsertable*](/docs/cpp/library/named_req/MoveInsertable) into `X`.
- `expr` is well-formed.
- Evaluating `expr` does not change the value of `v`.
- Right after the evaluation of `expr`, the value of `v` is equivalent to `*p`.

### Notes

{/* source:cpp-named-req-copyinsertable:0005 */}
If `A` is `std::allocator<T>`, then this will call placement `new`, as by <InlineRevision until="C++20">`::new((void*)p) T(v)`</InlineRevision> <InlineRevision since="C++20">[`std::construct_at(p, v)`](/docs/cpp/library/memory/construct_at)</InlineRevision>.

{/* source:cpp-named-req-copyinsertable:0006 */}
Although it is required that customized `construct` is used when constructing elements of [`std::basic_string`](/docs/cpp/library/string/basic_string) until C++23, all implementations only used the default mechanism. The requirement is corrected by [P1072R10](https://wg21.link/P1072R10) to match existing practice.
