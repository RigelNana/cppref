{/* source:cpp-named-req-defaultconstructible:0000 */}
Specifies that an instance of the type can be default constructed.

### Requirements

{/* source:cpp-named-req-defaultconstructible:0001 */}
The type `T` satisfies *DefaultConstructible* if all following statements and expressions are valid and have their specified effects:

{/* source:cpp-named-req-defaultconstructible:0002 */}
<table>
<thead><tr><th>Expression/Statement</th><th>Postcondition</th></tr></thead>
<tbody>
<tr>
<td>`T u;`</td>
<td>The object `u` is [default-initialized](/docs/cpp/language/initialization/default_initialization).</td>
</tr>
<tr>
<td>`T u{};`</td>
<td>The object `u` is [value-initialized](/docs/cpp/language/initialization/value_initialization) or [aggregate-initialized](/docs/cpp/language/initialization/aggregate_initialization).</td>
</tr>
<tr>
<td>`T()`<br />`T{}`</td>
<td>A temporary object of type `T` is [value-initialized](/docs/cpp/language/initialization/value_initialization) or [aggregate-initialized](/docs/cpp/language/initialization/aggregate_initialization).</td>
</tr>
</tbody>
</table>

### Notes

{/* source:cpp-named-req-defaultconstructible:0003 */}
For objects of non-aggregate class type, a public [default constructor](/docs/cpp/language/classes/default_constructor) must be defined (either user-defined or implicitly defined) to satisfy *DefaultConstructible*.

{/* source:cpp-named-req-defaultconstructible:0004 */}
Non-const objects of [non-class object type](/docs/cpp/language/basic_concepts/type-id) are always *DefaultConstructible*.

{/* source:cpp-named-req-defaultconstructible:0005 */}
Const non-class types are not *DefaultConstructible*.

{/* source:cpp-named-req-defaultconstructible:0006 */}
Const aggregate types are not *DefaultConstructible* if any of their members is an object of non-class type.

{/* source:cpp-named-req-defaultconstructible:0007 */}
Non-object types (function types, reference types, and the (possibly cv-qualified) type `void`) as well as the const non-object types are never *DefaultConstructible*.
