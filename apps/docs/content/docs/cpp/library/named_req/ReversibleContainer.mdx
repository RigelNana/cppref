{/* source:cpp-named-req-reversiblecontainer:0000 */}
A ReversibleContainer is a [Container](/docs/cpp/library/named_req/Container) that has iterators that meet the requirements of either [LegacyBidirectionalIterator](/docs/cpp/library/named_req/BidirectionalIterator) or [LegacyRandomAccessIterator](/docs/cpp/library/named_req/RandomAccessIterator). Such iterators allow a ReversibleContainer to be iterated over in reverse.

## Requirements

{/* source:cpp-named-req-reversiblecontainer:0001 */}
A type satisfies ReversibleContainer if it satisfies [Container](/docs/cpp/library/named_req/Container), its iterator type belongs to the bidirectional or random access [iterator categories](/docs/cpp/library/iterator) and, given the following types and values, the semantic and complexity requirements in the tables below are satisfied:

{/* source:cpp-named-req-reversiblecontainer:0002 */}

  <DescriptionItem>

  </DescriptionItem>

  </DescriptionItem>
  <DescriptionItem>

    <DescriptionBody>a value of type `X`</DescriptionBody>

#### Types

{/* source:cpp-named-req-reversiblecontainer:0003 */}
| Name | Type | Requirements |
| --- | --- | --- |
| `typename X::reverse_iterator` | `std::reverse_iterator<X::iterator>` | an iterator type whose [value type](/docs/cpp/library/iterator) is `T` |
| `typename X::const_reverse_iterator` | `std::reverse_iterator<X::const_iterator>` | a constant iterator type whose [value type](/docs/cpp/library/iterator) is `T` |

#### Expressions

{/* source:cpp-named-req-reversiblecontainer:0004 */}
The types `reverse_iterator` and `const_reverse_iterator` in the following table denote `typename X::reverse_iterator` and `typename X::const_reverse_iterator` respectively.

{/* source:cpp-named-req-reversiblecontainer:0005 */}
| Expression | Type | Semantics | Complexity |
| --- | --- | --- | --- |
| `a.rbegin()` | `reverse_iterator`<br />`const_reverse_iterator` for constant `a` | `reverse_iterator(a.end())` | Constant |
| `a.rend()` | `reverse_iterator`<br />`const_reverse_iterator` for constant `a` | `reverse_iterator(a.begin())` | Constant |
| `a.crbegin()` | `const_reverse_iterator` | `const_cast<const X&>(a).rbegin()` | Constant |
| `a.crend()` | `const_reverse_iterator` | `const_cast<const X&>(a).rend()` | Constant |

## Example

{/* source:cpp-named-req-reversiblecontainer:0008 */}
The following example iterates over a [`vector`](/docs/cpp/library/container/vector) (which has [legacy random-access iterators](/docs/cpp/library/container/vector#Member_types)) in reverse.

```cpp
#include <iostream>
#include <vector>
 
int main()
{
    std::vector<int> v = {3, 1, 4, 1, 5, 9};
 
    for (std::vector<int>::const_reverse_iterator i{v.crbegin()}; i != v.crend(); ++i)
        std::cout << *i << ' ';
    std::cout << '\n';
}
```

Output:

```text
9 5 1 4 1 3
```
