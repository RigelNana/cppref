### Requirements

{/* source:cpp-named-req-unformattedinputfunction:0000 */}
An *UnformattedInputFunction* is a stream input function that performs the following:

{/* source:cpp-named-req-unformattedinputfunction:0001 */}
1. Constructs an object of type [`basic_istream::sentry`](/docs/cpp/library/io/basic_istream/sentry) with automatic storage duration and with the `noskipws` argument set to `true`, which performs the following:
   - If [`eofbit`](/docs/cpp/library/io/ios_base/iostate) or [`badbit`](/docs/cpp/library/io/ios_base/iostate) are set on the input stream, sets the [`failbit`](/docs/cpp/library/io/ios_base/iostate) as well, and if exceptions on `failbit` are enabled in this input stream's [`exception mask`](/docs/cpp/library/io/basic_ios/exceptions) (`(exceptions() & failbit) != 0`), throws [`ios_base::failure`](/docs/cpp/library/io/ios_base/failure).
   - Flushes the tie()'d output stream, if applicable.

{/* source:cpp-named-req-unformattedinputfunction:0002 */}
2. Checks the status of the sentry by calling `sentry::operator bool()`, which is equivalent to [`basic_ios::good`](/docs/cpp/library/io/basic_ios/good).
   - If the operator returns `false` or sentry's constructor throws an exception:
     - Sets the number of extracted characters (gcount) in the input stream to zero.
     - If the function was called to write to an array of `CharT`, writes `CharT()` (the null character) to the first location of the array.
   - If the operator returns `true`, performs the input as if by calling `rdbuf()->sbumpc()` or `rdbuf()->sgetc()`.
     - If the end of the stream is reached (the call to `rdbuf()->sbumpc()` or `rdbuf()->sgetc()` returns `Traits::eof()`), sets `eofbit`. If exceptions on `eofbit` are enabled in this stream's [`exception mask`](/docs/cpp/library/io/basic_ios/exceptions) (`(exceptions() & eofbit) != 0`), throws [`ios_base::failure`](/docs/cpp/library/io/ios_base/failure).
     - If an exception is thrown during input, sets `badbit` in the input stream. If exceptions on `badbit` are enabled in this stream's [`exception mask`](/docs/cpp/library/io/basic_ios/exceptions) (`(exceptions() & badbit) != 0`), the exception is also rethrown.
       - Exceptions thrown from [`basic_ios::clear`](/docs/cpp/library/io/basic_ios/clear) are not caught or rethrown.
     - If no exception was thrown during input, sets the number of extracted characters (gcount) in the input stream.

{/* source:cpp-named-req-unformattedinputfunction:0003 */}
3. In any event, whether terminating by exception or returning, the sentry's destructor is called before leaving this function.

### Standard library

{/* source:cpp-named-req-unformattedinputfunction:0004 */}
The following standard library functions are *UnformattedInputFunctions*.

{/* source:cpp-named-req-unformattedinputfunction:0005 */}
- [`std::getline`](/docs/cpp/library/string/basic_string/getline), except that it does not modify gcount.
- [`basic_istream::operator>>(basic_streambuf*)`](/docs/cpp/library/io/basic_istream/operator_gtgt)
- [`basic_istream::get`](/docs/cpp/library/io/basic_istream/get)
- [`basic_istream::getline`](/docs/cpp/library/io/basic_istream/getline)
- [`basic_istream::ignore`](/docs/cpp/library/io/basic_istream/ignore)
- [`basic_istream::peek`](/docs/cpp/library/io/basic_istream/peek)
- [`basic_istream::read`](/docs/cpp/library/io/basic_istream/read)
- [`basic_istream::readsome`](/docs/cpp/library/io/basic_istream/readsome)
- [`basic_istream::putback`](/docs/cpp/library/io/basic_istream/putback), except that it first clears `eofbit`
- [`basic_istream::unget`](/docs/cpp/library/io/basic_istream/unget), except that it first clears `eofbit`
- [`basic_istream::sync`](/docs/cpp/library/io/basic_istream/sync), except that it does not modify gcount
- [`basic_istream::tellg`](/docs/cpp/library/io/basic_istream/tellg), except that it does not modify gcount
- [`basic_istream::seekg`](/docs/cpp/library/io/basic_istream/seekg), except that it first clears `eofbit` and does not modify gcount
- [`std::ws`](/docs/cpp/library/io/manip/ws), except that it does not modify gcount

### Defect reports

{/* source:cpp-named-req-unformattedinputfunction:0006 */}
The following behavior-changing defect reports were applied retroactively to previously published C++ standards.

{/* source:cpp-named-req-unformattedinputfunction:0007 */}
<DefectReportList>
  <DefectReport kind="lwg" id={61} standard="C++98">
    <PublishedBehavior>it was unclear whether throwing an exception because of<br />setting `eofbit` and/or `failbit` will result in setting `badbit`</PublishedBehavior>
    <CorrectedBehavior>exceptions thrown from [`basic_ios::clear`](/docs/cpp/library/io/basic_ios/clear)<br />are not caught or rethrown</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={160} standard="C++98">
    <PublishedBehavior>the process of determining whether the exception caught<br />is rethrown mentioned a non-existing function `exception()`</PublishedBehavior>
    <CorrectedBehavior>corrected to [`exceptions()`](/docs/cpp/library/io/basic_ios/exceptions)</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={243} standard="C++98">
    <PublishedBehavior>the behavior when `sentry::operator bool()` returns `false`<br />or the sentry object fails to be constructed was not specified</PublishedBehavior>
    <CorrectedBehavior>specified</CorrectedBehavior>
  </DefectReport>
</DefectReportList>
