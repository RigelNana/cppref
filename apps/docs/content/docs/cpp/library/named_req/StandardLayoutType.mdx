{/* source:cpp-named-req-standardlayouttype:0000 */}
Specifies that a type is a standard layout type. Standard layout types are useful for communicating with code written in other programming languages.

{/* source:cpp-named-req-standardlayouttype:0001 */}
Note: the standard doesn't define a named requirement with this name. This is a type category defined by the core language. It is included here as a named requirement only for consistency.

### Requirements

{/* source:cpp-named-req-standardlayouttype:0002 */}
The following types are collectively called *standard-layout types*:

{/* source:cpp-named-req-standardlayouttype:0003 */}
- [`scalar types`](/docs/cpp/library/named_req/ScalarType)
- [`standard-layout class types`](/docs/cpp/language/classes#Standard-layout_class)
- arrays of such types
- cv-qualified versions of these types

### Properties

{/* source:cpp-named-req-standardlayouttype:0004 */}
See [`Standard-layout`](/docs/cpp/language/classes/data_members#Standard-layout).
