{/* source:cpp-named-req-moveassignable:0000 */}
Specifies that an instance of the type can be assigned from an [rvalue](/docs/cpp/language/expressions/value_category) argument.

## Requirements

{/* source:cpp-named-req-moveassignable:0001 */}
The type T satisfies MoveAssignable if

{/* source:cpp-named-req-moveassignable:0002 */}
Given

{/* source:cpp-named-req-moveassignable:0003 */}
- `t`, a modifiable [lvalue expression](/docs/cpp/language/expressions/value_category) of type `T`,
- `rv`, an [rvalue](/docs/cpp/language/expressions/value_category) expression of type `T`.

{/* source:cpp-named-req-moveassignable:0004 */}
The following expressions must be valid and have their specified effects.

{/* source:cpp-named-req-moveassignable:0005 */}
| Expression | Return type | Return value | Post-conditions |
| --- | --- | --- | --- |
| `t = rv` | `T&` | `t` | If `t` and `rv` do not refer to the same object, the value of `t` is equivalent to the value of `rv` before the assignment. The new value of `rv` is unspecified. |

## Notes

{/* source:cpp-named-req-moveassignable:0006 */}
The type does not have to implement [move assignment operator](/docs/cpp/language/classes/move_operator) in order to satisfy this type requirement: a [copy assignment operator](/docs/cpp/language/classes/as_operator) that takes its parameter by value or as a const Type&, will bind to rvalue argument.

{/* source:cpp-named-req-moveassignable:0007 */}
If a MoveAssignable class implements a move assignment operator, it may also implement [move semantics](/docs/cpp/library/utility/move) to take advantage of the fact that the value of rv after assignment is unspecified.
