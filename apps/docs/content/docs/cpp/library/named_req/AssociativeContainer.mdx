{/* source:cpp-named-req-associativecontainer:0000 */}
An AssociativeContainer is an ordered [Container](/docs/cpp/library/named_req/Container) that provides fast lookup of objects based on keys.

{/* source:cpp-named-req-associativecontainer:0001 */}
An associative container supports *unique keys* if it may contain at most one element for each key. Otherwise, it supports *equivalent keys*.

The type `X` satisfies AssociativeContainer if

{/* source:cpp-named-req-associativecontainer:0004 */}
- The type `X` satisfies <InlineRevision until="C++11">[Container](/docs/cpp/library/named_req/Container)</InlineRevision><InlineRevision since="C++11">[AllocatorAwareContainer](/docs/cpp/library/named_req/AllocatorAwareContainer)</InlineRevision>,
- Is parameterized on `Key` and an ordering relation `Compare` that induces a [strict weak ordering](/docs/cpp/library/named_req/Compare) on elements of `Key`, and
  - In addition, [`std::map`](/docs/cpp/library/container/map) and [`std::multimap`](/docs/cpp/library/container/multimap) associate an arbitrary *mapped type* `T` with the `Key`.
  - The object of type `Compare` is called the *comparison object* of a container of type `X`.
  - The following expressions must be valid and have their specified effects for all associative containers:

#### Iterators

{/* source:cpp-named-req-associativecontainer:0007 */}
Iterators of associative containers satisfy the requirements of [LegacyBidirectionalIterator](/docs/cpp/library/named_req/BidirectionalIterator).

{/* source:cpp-named-req-associativecontainer:0008 */}
For associative containers where `value_type` is the same as `key_type`, both `iterator` and `const_iterator` are constant iterators. It is unspecified whether or not `iterator` and `const_iterator` are the same type.

{/* source:cpp-named-req-associativecontainer:0009 */}
Iterators of associative containers iterate through the containers in the non-descending order of keys where non-descending is defined by the comparison that was used to construct the containers. That is, given

{/* source:cpp-named-req-associativecontainer:0010 */}
- `a`, an associative container
- `i` and `j`, dereferenceable iterators to `a`.

{/* source:cpp-named-req-associativecontainer:0011 */}
If the distance from `i` to `j` is positive, then `a.value_comp()(*j, *i) == false`. Additionally, if `a` is an associative container with unique keys, the stronger condition `a.value_comp()(*i, *j) != false` holds.
