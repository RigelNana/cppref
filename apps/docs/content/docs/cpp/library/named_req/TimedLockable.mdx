{/* source:cpp-named-req-timedlockable:0000 */}
The *TimedLockable* requirements describe the characteristics of types that provide timed exclusive blocking semantics for execution agents (threads, processes, tasks).

### Requirements

{/* source:cpp-named-req-timedlockable:0001 */}
- [`Lockable`](/docs/cpp/library/named_req/Lockable)

{/* source:cpp-named-req-timedlockable:0002 */}
For type `L` to be *TimedLockable*, given

{/* source:cpp-named-req-timedlockable:0003 */}
- `rel_time`, a value of a specialization of [`std::chrono::duration`](/docs/cpp/library/chrono/duration), and
- `abs_time`, a value of a specialization of [`std::chrono::time_point`](/docs/cpp/library/chrono/time_point),

{/* source:cpp-named-req-timedlockable:0004 */}
the following conditions have to be satisfied for an object `m` of type `L`:

{/* source:cpp-named-req-timedlockable:0005 */}
| Expression | Effects | Return value |
| --- | --- | --- |
| `m.try_lock_for(rel_time)` | Blocks for the provided duration `rel_time` or until a lock on `m` is acquired. | `true` if the lock was acquired, `false` otherwise. |
| `m.try_lock_until(abs_time)` | Blocks until the provided time point `abs_time` is reached or a lock on `m` is acquired. | `true` if the lock was acquired, `false` otherwise. |

### Notes

{/* source:cpp-named-req-timedlockable:0006 */}
The `try_lock_for` and `try_lock_until` member functions obtain a non-shared lock on `m` on success.

### Standard library

{/* source:cpp-named-req-timedlockable:0007 */}
The following standard library types satisfy *TimedLockable*:

{/* source:cpp-named-req-timedlockable:0008 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`timed_mutex`](/docs/cpp/library/atomic/timed_mutex) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>provides mutual exclusion facility which implements locking with a timeout (class)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`recursive_timed_mutex`](/docs/cpp/library/atomic/recursive_timed_mutex) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>provides mutual exclusion facility which can be locked recursively by the same thread and implements locking with a timeout (class)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`shared_timed_mutex`](/docs/cpp/library/atomic/shared_timed_mutex) <InlineRevision since="C++14" /></DescriptionTerm>
    <DescriptionBody>provides shared mutual exclusion facility and implements locking with a timeout (class)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
