{/* source:cpp-named-req-lockable:0000 */}
The Lockable requirements extends the [BasicLockable](/docs/cpp/library/named_req/BasicLockable) requirements to include attempted locking.

## Requirements

{/* source:cpp-named-req-lockable:0001 */}
- [BasicLockable](/docs/cpp/library/named_req/BasicLockable)

{/* source:cpp-named-req-lockable:0002 */}
For type L to be Lockable, it must meet the above condition as well as the following:

{/* source:cpp-named-req-lockable:0003 */}
| Expression | Effects | Return value |
| --- | --- | --- |
| `m.try_lock()` | Attempts to acquire the lock for the current execution agent (thread, process, task) without blocking. If an exception is thrown, no lock is obtained. | `true` if the lock was acquired, `false` otherwise |

## Notes

{/* source:cpp-named-req-lockable:0004 */}
The try_lock member functions obtains a non-shared lock on `m` on success.

## Standard library

{/* source:cpp-named-req-lockable:0005 */}
The following standard library types satisfy Lockable requirements:

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`mutex`](/docs/cpp/library/atomic/mutex) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>provides basic mutual exclusion facility (class)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`recursive_mutex`](/docs/cpp/library/atomic/recursive_mutex) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>provides mutual exclusion facility which can be locked recursively by the same thread (class)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`recursive_timed_mutex`](/docs/cpp/library/atomic/recursive_timed_mutex) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>provides mutual exclusion facility which can be locked recursively by the same thread and implements locking with a timeout (class)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`shared_mutex`](/docs/cpp/library/atomic/shared_mutex) <InlineRevision since="C++17" /></DescriptionTerm>
    <DescriptionBody>provides shared mutual exclusion facility (class)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`shared_timed_mutex`](/docs/cpp/library/atomic/shared_timed_mutex) <InlineRevision since="C++14" /></DescriptionTerm>
    <DescriptionBody>provides shared mutual exclusion facility and implements locking with a timeout (class)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`timed_mutex`](/docs/cpp/library/atomic/timed_mutex) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>provides mutual exclusion facility which implements locking with a timeout (class)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
