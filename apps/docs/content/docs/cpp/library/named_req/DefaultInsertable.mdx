{/* source:cpp-named-req-defaultinsertable:0000 */}
Specifies that an object of the type can be default-constructed in-place by a given allocator.

### Requirements

{/* source:cpp-named-req-defaultinsertable:0001 */}
Given the following types, values and expressions:

{/* source:cpp-named-req-defaultinsertable:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`T`</DescriptionTerm>
    <DescriptionBody>an object type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`A`</DescriptionTerm>
    <DescriptionBody>an allocator type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`X`</DescriptionTerm>
    <DescriptionBody>a container type satisfying all following conditions:<br />`X::value_type` is the same as `T`.<br />`X::allocator_type` is the same as `std::allocator_traits<A>::rebind_alloc<T>`.</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`m`</DescriptionTerm>
    <DescriptionBody>an lvalue of type `A`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`p`</DescriptionTerm>
    <DescriptionBody>a pointer of type `T*`</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-named-req-defaultinsertable:0003 */}
If the expression `std::allocator_traits<A>::construct(m, p)` is well-formed, `T` is *DefaultInsertable* into `X`.

### Notes

{/* source:cpp-named-req-defaultinsertable:0004 */}
By default, this will [value-initialize](/docs/cpp/language/initialization/value_initialization) the object, as by <InlineRevision until="C++20">`::new((void*)p) T()`</InlineRevision> <InlineRevision since="C++20">[`std::construct_at(p)`](/docs/cpp/library/memory/construct_at)</InlineRevision>.

{/* source:cpp-named-req-defaultinsertable:0005 */}
If value-initialization is undesirable, for example, if the object is of non-class type and zeroing out is not needed, it can be avoided by providing a [custom `Allocator::construct`](https://stackoverflow.com/a/21028912/273767).

{/* source:cpp-named-req-defaultinsertable:0006 */}
Although it is required that customized `construct` is used when constructing elements of [`std::basic_string`](/docs/cpp/library/string/basic_string) until C++23, all implementations only used the default mechanism. The requirement is corrected by [P1072R10](https://wg21.link/P1072R10) to match existing practice.
