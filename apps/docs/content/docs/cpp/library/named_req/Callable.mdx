{/* source:cpp-named-req-callable:0000 */}
A Callable type is a type for which the [*INVOKE*](/docs/cpp/library/utility/functional) and [*INVOKE\<R\>*](/docs/cpp/library/utility/functional) operations (used by, e.g., [`std::function`](/docs/cpp/library/utility/functional/function), [`std::bind`](/docs/cpp/library/utility/functional/bind), and [`std::thread::thread`](/docs/cpp/library/thread/thread/thread)) are applicable.

{/* source:cpp-named-req-callable:0001 */}
<Revision since="C++17">*INVOKE* can be performed explicitly using the library function [`std::invoke`](/docs/cpp/library/utility/functional/invoke).</Revision>

<Revision since="C++23">*INVOKE\<R\>* can be performed explicitly using the library function [`std::invoke_r`](/docs/cpp/library/utility/functional/invoke).</Revision>

### Requirements

{/* source:cpp-named-req-callable:0002 */}
The type `T` satisfies Callable if

{/* source:cpp-named-req-callable:0003 */}
Given

{/* source:cpp-named-req-callable:0004 */}
- `f`, an object of type `T`,
- `ArgTypes`, suitable list of argument types,
- `R`, suitable return type.

{/* source:cpp-named-req-callable:0005 */}
The following expressions must be valid:

{/* source:cpp-named-req-callable:0006 */}
| Expression | Requirements |
| --- | --- |
| [*INVOKE\<R\>*](/docs/cpp/library/utility/functional)`(f, std::declval<ArgTypes>()...)` | The expression is well-formed in unevaluated context. |

### Notes

{/* source:cpp-named-req-callable:0007 */}
[Pointers to data members](/docs/cpp/language/declarations/pointer#Pointers_to_data_members) are Callable, even though no function calls take place.
