{/* source:cpp-named-req-sequencecontainer:0000 */}
A *SequenceContainer* is a [`Container`](/docs/cpp/library/named_req/Container) that stores objects of the same type in a linear arrangement.

### Requirements

{/* source:cpp-named-req-sequencecontainer:0001 */}

`C` satisfies the requirements of *SequenceContainer* if all following conditions are satisfied:

{/* source:cpp-named-req-sequencecontainer:0004 */}

Notes

1. For an expression whose effect is equivalent to some other operations, the conditions of the expressions inside those operations are inherited on top of the conditions listed in the table.
2. [`std::array`](/docs/cpp/library/container/array) supports assignment from a [`brace-enclosed initializer list`](/docs/cpp/language/initialization), but not from an [`std::initializer_list`](/docs/cpp/library/utility/initializer_list).
3. All operations below <InlineRevision since="C++23">except `prepend_range` and `append_range`</InlineRevision> take amortized constant time.
4. In C++98, `tmp` was declared to have type `C::iterator`.
5. In C++98, `tmp` was declared to have type `C::const_iterator`.
6. ↑ 6.0 6.1 Insertion order, relative to order of elements in `rg`, is non-reversing.

Additionally, for every sequence container:

{/* source:cpp-named-req-sequencecontainer:0007 */}
- A constructor template that takes two input iterators and the member function template overloads of `insert`, `append`, `assign`, `replace` that take two input iterators do not participate in overload resolution if the corresponding template argument does not satisfy [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

{/* source:cpp-named-req-sequencecontainer:0008 */}
<Revision since="C++17">
- A deduction guide that has either a [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator) or an `Allocator` template parameter does not participate in overload resolution if the type that does not qualify as an input iterator or an allocator respectively is deduced for that parameter.
</Revision>

#### Usage notes

{/* source:cpp-named-req-sequencecontainer:0011 */}
| Container | Pros | Cons |
| --- | --- | --- |
| [`std::vector`](/docs/cpp/library/container/vector) | Fast access, contiguous storage | Mostly inefficient insertions/deletions |
| `std::inplace_vector` | Fast access, inplace contiguous storage | Fixed capacity and mostly inefficient insertions/deletions |
| [`std::array`](/docs/cpp/library/container/array) | Fast access, inplace contiguous storage | Fixed number of elements and no insertion/deletion |
| [`std::deque`](/docs/cpp/library/container/deque) | Fast access, efficient insertion/deletion at the beginning/end | Inefficient insertion/deletion in the middle of the sequence |
| [`std::list`](/docs/cpp/library/container/list) [`std::forward_list`](/docs/cpp/library/container/forward_list) | Efficient insertion/deletion in the middle of the sequence | Access is mostly linear-time |
