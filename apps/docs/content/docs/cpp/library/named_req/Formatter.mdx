{/* source:cpp-named-req-formatter:0000 */}
*Formatter* is a type that abstracts formatting operations for a given formatting argument type and character type. Specializations of [`std::formatter`](/docs/cpp/library/text/format/formatter) provided by the standard library are required to meet the requirements of *Formatter* except as noted otherwise.

{/* source:cpp-named-req-formatter:0001 */}
A *Formatter* is able to format both const and non-const arguments, typically by providing a `format` member function that takes a const reference.

### Requirements

{/* source:cpp-named-req-formatter:0002 */}
A type satisfies *Formatter* if it satisfies [*BasicFormatter*](/docs/cpp/library/named_req/BasicFormatter) and given the following types and values, the expressions shown in the table below are valid and have the indicated semantics:

{/* source:cpp-named-req-formatter:0003 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`CharT`</DescriptionTerm>
    <DescriptionBody>a character type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`Arg`</DescriptionTerm>
    <DescriptionBody>a formatting argument type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`Formatter`</DescriptionTerm>
    <DescriptionBody>a *Formatter* type for types `Arg` and `CharT`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`OutputIt`</DescriptionTerm>
    <DescriptionBody>a [*LegacyOutputIterator*](/docs/cpp/library/named_req/OutputIterator) type</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`ParseCtx`</DescriptionTerm>
    <DescriptionBody>`std::basic_format_parse_context<CharT>`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`FmtCtx`</DescriptionTerm>
    <DescriptionBody>`std::basic_format_context<OutputIt, CharT>`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`f`</DescriptionTerm>
    <DescriptionBody>a value of type (possibly const-qualified) `Formatter`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`arg`</DescriptionTerm>
    <DescriptionBody>an lvalue of type `Arg`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`t`</DescriptionTerm>
    <DescriptionBody>a value of type convertible to (possibly const-qualified) `Arg`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`parse_ctx`</DescriptionTerm>
    <DescriptionBody>an lvalue of type `ParseCtx` satisfying all following conditions:<br />`parse_ctx.begin()` points to the beginning of the *format-spec* of the replacement field being formatted in the [format string](/docs/cpp/library/text/format/basic_format_string#Format_specification).<br />If *format-spec* is not present or empty, then either `parse_ctx.begin() == parse_ctx.end()` or `*parse_ctx.begin() == '}'`.</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`fmt_ctx`</DescriptionTerm>
    <DescriptionBody>an lvalue of type `FmtCtx`</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
