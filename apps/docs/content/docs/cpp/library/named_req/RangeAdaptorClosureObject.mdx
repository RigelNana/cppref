{/* source:cpp-named-req-rangeadaptorclosureobject:0000 */}
Range adaptor closure objects are [FunctionObjects](/docs/cpp/library/named_req/FunctionObject) that are callable via the pipe operator: if `C` is a range adaptor closure object and `R` is a [range](/docs/cpp/library/ranges/range), these two expressions are [equivalent](/docs/cpp/language/expressions#Expression-equivalence):

{/* source:cpp-named-req-rangeadaptorclosureobject:0001 */}
```cpp
C(R)
R | C
```

{/* source:cpp-named-req-rangeadaptorclosureobject:0002 */}
Two range adaptor closure objects can be chained by `operator|` to produce another range adaptor closure object: if `C` and `D` are range adaptor closure objects, then `C | D` produces a range adaptor closure object `E` with the following properties:

{/* source:cpp-named-req-rangeadaptorclosureobject:0003 */}
- `E` stores a copy of `C` and `D`, direct-non-list-initialized from `std::forward<decltype((C))>(C)` and `std::forward<decltype((D))>(D)` respectively. If such initialization is invalid, `C | D` is also invalid. Let `c` and `d` be the stored copies (with the same constness and value category as `E`), and `R` be a [range](/docs/cpp/library/ranges/range) object, the following expressions are [equivalent](/docs/cpp/language/expressions#Expression-equivalence):

{/* source:cpp-named-req-rangeadaptorclosureobject:0004 */}
```cpp
d(c(R))
R | c | d
E(R)
R | E // R | (C | D)
```

{/* source:cpp-named-req-rangeadaptorclosureobject:0005 */}
Notes: `operator()` is unsupported for volatile-qualified or const-volatile-qualified version of range adaptor object closure types.

{/* source:cpp-named-req-rangeadaptorclosureobject:0006 */}
Objects whose type is the same as one of the following objects (ignoring cv-qualification) are range adaptor closure objects:

{/* source:cpp-named-req-rangeadaptorclosureobject:0007 */}
- unary range adaptor objects,

{/* source:cpp-named-req-rangeadaptorclosureobject:0008 */}
- objects of user-defined types that meet [the requirements of implementing a range adaptor closure object](/docs/cpp/library/ranges/range_adaptor_closure), <InlineRevision since="C++23" />

{/* source:cpp-named-req-rangeadaptorclosureobject:0009 */}
- the results of binding trailing arguments by range adaptor objects, and
- the results of chaining two range adaptor closure objects by `operator|`.
