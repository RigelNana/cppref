{/* source:cpp-named-req-bitmasktype:0000 */}
Defines a type that can be used to represent a set of constant values or any combination of those values. This trait is typically implemented by integer types, [`std::bitset`](/docs/cpp/library/utility/bitset), or enumerations (scoped and unscoped) with additional operator overloads.

### Requirements

{/* source:cpp-named-req-bitmasktype:0001 */}
The bitmask type supports a finite number of bitmask elements, which are distinct non-zero values of the bitmask type, such that, for any pair `Ci` and `Cj`, `Ci & Ci` is nonzero and `Ci & Cj` is zero. In addition, the value `0` is used to represent an empty bitmask, with no values set.

{/* source:cpp-named-req-bitmasktype:0002 */}
The bitwise operators `operator&`, `operator|`, `operator^`, `operator~`, `operator&=`, `operator|=`, and `operator^=` are defined for values of the bitmask type and have the same semantics as the corresponding built-in operators on unsigned integers would have if the bitmask elements were the distinct integer powers of two.

{/* source:cpp-named-req-bitmasktype:0003 */}
The following expressions are well-formed and have the following meaning for any BitmaskType:

{/* source:cpp-named-req-bitmasktype:0004 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`X |= Y`</DescriptionTerm>
    <DescriptionBody>sets the value `Y` in the object `X`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`X &= ~Y`</DescriptionTerm>
    <DescriptionBody>clears the value `Y` in the object `X`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`X & Y`</DescriptionTerm>
    <DescriptionBody>nonzero result indicates that the value `Y` is set in the object `X`</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-named-req-bitmasktype:0005 */}
Each representable bitmask element is defined as a<InlineRevision since="C++17">n `inline`</InlineRevision> `constexpr` value of the bitmask type.
