{/* source:cpp-named-req-copyassignable:0000 */}
Specifies that an instance of the type can be copy-assigned from an [lvalue expression](/docs/cpp/language/expressions/value_category).

### Requirements

{/* source:cpp-named-req-copyassignable:0001 */}
The type `T` satisfies CopyAssignable if

{/* source:cpp-named-req-copyassignable:0002 */}
- The type `T` satisfies [MoveAssignable](/docs/cpp/library/named_req/MoveAssignable), and

{/* source:cpp-named-req-copyassignable:0003 */}
Given

{/* source:cpp-named-req-copyassignable:0004 */}
- `t`, a modifiable [lvalue expression](/docs/cpp/language/expressions/value_category) of type `T`,
- `v`, an [lvalue](/docs/cpp/language/expressions/value_category) expression of type `T` or `const T` or an [rvalue](/docs/cpp/language/expressions/value_category) expression of type `const T`.

{/* source:cpp-named-req-copyassignable:0005 */}
The following expressions must be valid and have their specified effects.

{/* source:cpp-named-req-copyassignable:0006 */}
| Expression | Return type | Return value | Post-conditions |
| --- | --- | --- | --- |
| `t = v` | `T&` | `t` | The value of `t` is equivalent to the value of `v`. The value of `v` is unchanged. |
