{/* source:cpp-named-req-trivialclock:0000 */}
The *TrivialClock* requirements describe the requirements satisfied by several clocks in the [`chrono library`](/docs/cpp/library/chrono).

### Requirements

{/* source:cpp-named-req-trivialclock:0001 */}
For a type `TC`:

{/* source:cpp-named-req-trivialclock:0002 */}
- The type must meet [`Clock`](/docs/cpp/library/named_req/Clock) requirements.
- The types `TC::rep`, `TC::duration`, and `TC::time_point` satisfy the requirements of [`EqualityComparable`](/docs/cpp/library/named_req/EqualityComparable), [`LessThanComparable`](/docs/cpp/library/named_req/LessThanComparable), <InlineRevision until="C++17">, [`DefaultConstructible`](/docs/cpp/library/named_req/DefaultConstructible), [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible), [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable), [`Destructible`](/docs/cpp/library/named_req/Destructible)</InlineRevision>, [`Swappable`](/docs/cpp/library/named_req/Swappable), and [`NumericType`](/docs/cpp/library/named_req/NumericType).
- The function `TC::now()` does not throw exceptions.
- The type `TC::time_point::clock` meets the *TrivialClock* requirements, recursively.
