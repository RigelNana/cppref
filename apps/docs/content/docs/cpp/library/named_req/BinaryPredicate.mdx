{/* source:cpp-named-req-binarypredicate:0000 */}
BinaryPredicate is a set of requirements expected by some of the standard library facilities from the user-provided arguments.

{/* source:cpp-named-req-binarypredicate:0001 */}
Given a BinaryPredicate `bin_pred` and a pair of iterators `iter1` and `iter2` or an iterator `iter` and a (possibly `const`) value `value`, the type and value category of the expression `bin_pred(*iter1, *iter2)` or, respectively, `bin_pred(*iter, value)`, must meet the [BooleanTestable](/docs/cpp/library/named_req/BooleanTestable) requirements.

{/* source:cpp-named-req-binarypredicate:0002 */}
In addition, evaluation of that expression is not allowed to call non-const member functions of the dereferenced iterators; syntactically, the predicate must accept `const` object arguments, with the same behavior regardless of whether its arguments are `const` or non-`const`.

### Requirements

{/* source:cpp-named-req-binarypredicate:0003 */}
- [Predicate](/docs/cpp/library/named_req/Predicate)
- [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible) (unless otherwise specified)
