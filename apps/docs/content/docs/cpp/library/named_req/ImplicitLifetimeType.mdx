Note: the standard doesn't define a named requirement with this name. This is a type category defined by the core language. It is included here as a named requirement only for consistency.

### Requirements

{/* source:cpp-named-req-implicitlifetimetype:0001 */}
The following types are collectively called *implicit-lifetime types*:

{/* source:cpp-named-req-implicitlifetimetype:0002 */}
- [scalar types](/docs/cpp/library/named_req/ScalarType)
- [implicit-lifetime class types](/docs/cpp/language/classes#Implicit-lifetime_class)
- array types
- cv-qualified versions of these types

### Notes

{/* source:cpp-named-req-implicitlifetimetype:0003 */}
Certain operations may [implicitly create](/docs/cpp/language/basic_concepts/objects#Object_creation) and start the [lifetime](/docs/cpp/language/basic_concepts/lifetime) of objects of implicit-lifetime types, if doing so would prevent [undefined behavior](/docs/cpp/language/basic_concepts/ub). However, such operations do not start the lifetimes of subobjects of such objects that are not themselves of implicit-lifetime types.
