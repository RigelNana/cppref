{/* source:cpp-named-req-unarytypetrait:0000 */}
A *UnaryTypeTrait* is a class template that describes a property of its template type parameter with an [`std::integral_constant`](/docs/cpp/library/meta/integral_constant) (typically [`std::bool_constant`](/docs/cpp/library/meta/integral_constant)) specialization.

### Requirements

{/* source:cpp-named-req-unarytypetrait:0001 */}
- [`DefaultConstructible`](/docs/cpp/library/named_req/DefaultConstructible) and [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible).
- Takes one template type parameter (additional template parameters are optional and allowed).
- Publicly and unambiguously derived from a specialization of [`std::integral_constant`](/docs/cpp/library/meta/integral_constant), known as its *base characteristic*.
- The member names of the *base characteristic* are not hidden and are unambiguously available.

### Standard library

{/* source:cpp-named-req-unarytypetrait:0002 */}
The following [`type traits`](/docs/cpp/library/meta) all satisfy *UnaryTypeTrait*:

{/* source:cpp-named-req-unarytypetrait:0003 */}
- [`Primary type categories`](/docs/cpp/library/meta#Primary_type_categories)
- [`Composite type categories`](/docs/cpp/library/meta#Composite_type_categories)
- [`Type properties`](/docs/cpp/library/meta#Type_properties)
- [`Supported operations`](/docs/cpp/library/meta#Supported_operations)
- [`Property queries`](/docs/cpp/library/meta#Property_queries)
