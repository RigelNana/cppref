{/* source:cpp-named-req-numerictype:0000 */}
Specifies that the type can be used as the template argument of [`std::valarray`](/docs/cpp/library/numeric/valarray).

## Requirements

{/* source:cpp-named-req-numerictype:0001 */}
For a type T to be a NumericType, it must be a cv-unqualified object type that:

{/* source:cpp-named-req-numerictype:0002 */}
- Meets the [DefaultConstructible](/docs/cpp/library/named_req/DefaultConstructible), [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible), [CopyAssignable](/docs/cpp/library/named_req/CopyAssignable) and [Destructible](/docs/cpp/library/named_req/Destructible) requirements.
- No operation on T may throw exceptions.
