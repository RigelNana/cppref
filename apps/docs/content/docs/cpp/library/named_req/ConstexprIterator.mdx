{/* source:cpp-named-req-constexpriterator:0000 */}
A ConstexprIterator is a [LegacyIterator](/docs/cpp/library/named_req/Iterator) that can be used during constant expression evaluation.

### Requirements

{/* source:cpp-named-req-constexpriterator:0001 */}
The type `It` satisfies ConstexprIterator if

{/* source:cpp-named-req-constexpriterator:0002 */}
- The type `It` satisfies some iterator requirements MeowIterator

{/* source:cpp-named-req-constexpriterator:0003 */}
And, for every

{/* source:cpp-named-req-constexpriterator:0004 */}
- `purr`, an operation on `It` that is required to be supported by MeowIterator,
- `kittens...`, a set of arguments to `purr` that meets the requirements for that operation,

{/* source:cpp-named-req-constexpriterator:0005 */}
Then

{/* source:cpp-named-req-constexpriterator:0006 */}
- `purr(kittens...)` may be used in a constant expression if `kittens...` can also be used.

### Standard library

{/* source:cpp-named-req-constexpriterator:0007 */}
The following standard library types are ConstexprIterators.

{/* source:cpp-named-req-constexpriterator:0008 */}
- [`array::iterator`](/docs/cpp/library/container/array) and [`array::const_iterator`](/docs/cpp/library/container/array).
- [`basic_string_view::iterator`](/docs/cpp/library/string/basic_string_view).
- [`span::iterator`](/docs/cpp/library/container/span).
- [`vector::iterator`](/docs/cpp/library/container/vector) and [`vector::const_iterator`](/docs/cpp/library/container/vector).

{/* source:cpp-named-req-constexpriterator:0009 */}
<Revision since="C++26">
- [`optional::iterator`](/docs/cpp/library/utility/optional) and [`optional::const_iterator`](/docs/cpp/library/utility/optional)
</Revision>
