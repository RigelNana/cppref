{/* source:cpp-named-req-binarytypetrait:0000 */}
A BinaryTypeTrait is a class template that describes a relationship between its two template type parameters with a [`std::integral_constant`](/docs/cpp/library/meta/integral_constant) (typically [`std::bool_constant`](/docs/cpp/library/meta/integral_constant)) specialization.

### Requirements

{/* source:cpp-named-req-binarytypetrait:0001 */}
- [DefaultConstructible](/docs/cpp/library/named_req/DefaultConstructible) and [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible).
- Takes two template type parameters (additional template parameters are optional and allowed).
- Publicly and unambiguously derived from a specialization of [`std::integral_constant`](/docs/cpp/library/meta/integral_constant), known as its *base characteristic*.
- The member names of the *base characteristic* are not hidden and are unambiguously available.
