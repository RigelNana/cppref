{/* source:cpp-named-req-layoutmappingpolicy:0000 */}
*LayoutMappingPolicy* is a type used to specify layout policy of `std::mdspan`. It provides a member alias template whose specialization is a [*LayoutMapping*](/docs/cpp/library/named_req/LayoutMapping) type.

### Requirements

{/* source:cpp-named-req-layoutmappingpolicy:0001 */}
A type `MP` satisfies *LayoutMappingPolicy* if the type requirements shown below are valid:

#### Legend

{/* source:cpp-named-req-layoutmappingpolicy:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`MP`</DescriptionTerm>
    <DescriptionBody>a layout mapping policy class</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`M`</DescriptionTerm>
    <DescriptionBody>a layout mapping class</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`E`</DescriptionTerm>
    <DescriptionBody>a specialization of `std::extents`</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

#### Type requirements

{/* source:cpp-named-req-layoutmappingpolicy:0003 */}
- `MP::mapping<E>` is valid and denotes a type `M` that satisfies [*LayoutMapping*](/docs/cpp/library/named_req/LayoutMapping).
- `M::layout_type` is valid and denotes a type `MP`.
- `M::extents_type` is valid and denotes a type `E`.
