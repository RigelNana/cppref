{/* source:cpp-named-req-contiguousiterator:0000 */}
A LegacyContiguousIterator is a [LegacyIterator](/docs/cpp/library/named_req/Iterator) whose logically adjacent elements are also physically adjacent in memory.

{/* source:cpp-named-req-contiguousiterator:0001 */}
A pointer to an element of an array satisfies all requirements of LegacyContiguousIterator.

### Requirements

{/* source:cpp-named-req-contiguousiterator:0002 */}
The type `It` satisfies LegacyContiguousIterator if

{/* source:cpp-named-req-contiguousiterator:0003 */}
- The type `It` satisfies [LegacyIterator](/docs/cpp/library/named_req/Iterator)

{/* source:cpp-named-req-contiguousiterator:0004 */}
And, for every

{/* source:cpp-named-req-contiguousiterator:0005 */}
- `a`, a dereferenceable iterator of type `It`
- `n`, an integral value

{/* source:cpp-named-req-contiguousiterator:0006 */}
such that

{/* source:cpp-named-req-contiguousiterator:0007 */}
- `a + n` is a valid and dereferenceable iterator value

{/* source:cpp-named-req-contiguousiterator:0008 */}
then

{/* source:cpp-named-req-contiguousiterator:0009 */}
- `*(a + n)` is equivalent to `*(std::addressof(*a) + n)`.

### Standard library

{/* source:cpp-named-req-contiguousiterator:0010 */}
The following standard library types are LegacyContiguousIterators.

{/* source:cpp-named-req-contiguousiterator:0011 */}
- [`array::iterator`](/docs/cpp/library/container/array).
- [`basic_string_view::iterator`](/docs/cpp/library/string/basic_string_view).
- [`basic_string::iterator`](/docs/cpp/library/string/basic_string).
- [`vector::iterator`](/docs/cpp/library/container/vector) for `value_type` other than `bool`.
- The return type of [`begin(valarray)`](/docs/cpp/library/numeric/valarray/begin2) and [`end(valarray)`](/docs/cpp/library/numeric/valarray/end2).

### Notes

{/* source:cpp-named-req-contiguousiterator:0012 */}
[Fancy pointer](/docs/cpp/library/named_req/Allocator#Fancy_pointers) to object types are also required to satisfy LegacyContiguousIterator.

{/* source:cpp-named-req-contiguousiterator:0013 */}
<Revision since="C++20">LegacyContiguousIterator is replaced with the [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator) concept: iterator types in the standard library that are required to satisfy LegacyContiguousIterator in C++17 are required to model `contiguous_iterator` in C++20.</Revision>
