{/* source:cpp-named-req-compare:0000 */}
Compare is a set of requirements expected by some of the standard library facilities from the user-provided function object types.

{/* source:cpp-named-req-compare:0001 */}
The return value of the function call operation applied to an object of a type satisfying Compare, when [converted](/docs/cpp/language/expressions/implicit_cast) to `bool`, yields `true` if the first argument of the call appears before the second in the [strict weak ordering relation](https://en.wikipedia.org/wiki/Strict_weak_ordering) induced by this type, and `false` otherwise.

{/* source:cpp-named-req-compare:0002 */}
As with any [BinaryPredicate](/docs/cpp/library/named_req/BinaryPredicate), evaluation of that expression is not allowed to call non-const functions through the dereferenced iterators and, syntactically, the function call operation must accept `const` object arguments, with the same behavior regardless of whether the arguments are `const` or non-`const`.

### Requirements

{/* source:cpp-named-req-compare:0003 */}
The type `T` satisfies Compare if

{/* source:cpp-named-req-compare:0004 */}
- The type `T` satisfies [BinaryPredicate](/docs/cpp/library/named_req/BinaryPredicate), and

{/* source:cpp-named-req-compare:0005 */}
Given

{/* source:cpp-named-req-compare:0006 */}
- `comp`, an object of type `T`,
- `equiv(a, b)`, an [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `!comp(a, b) && !comp(b, a)`.

{/* source:cpp-named-req-compare:0007 */}
The following expressions must be valid and have their specified effects:

{/* source:cpp-named-req-compare:0008 */}
| Expression | Return type | Requirements |
| --- | --- | --- |
| `comp(a, b)` | meets [BooleanTestable](/docs/cpp/library/named_req/BooleanTestable) <InlineRevision until="C++20" />; models [*boolean-testable*](/docs/cpp/library/concepts/boolean-testable) <InlineRevision since="C++20" /> | Establishes [strict weak ordering](https://en.wikipedia.org/wiki/strict_weak_ordering) relation with the following properties: For all `a`, `comp(a, a) == false`; If `comp(a, b) == true` then `comp(b, a) == false`; if `comp(a, b) == true` and `comp(b, c) == true` then `comp(a, c) == true`. |
| `equiv(a, b)` | `bool` | Establishes [equivalence relationship](https://en.wikipedia.org/wiki/equivalence_relation) with the following properties: For all `a`, `equiv(a, a) == true`; If `equiv(a, b) == true`, then `equiv(b, a) == true`; If `equiv(a, b) == true` and `equiv(b, c) == true`, then `equiv(a, c) == true`. |

{/* source:cpp-named-req-compare:0009 */}
Note: `comp` induces a [strict total ordering](https://en.wikipedia.org/wiki/Total_order#Strict_and_non-strict_total_orders) on the equivalence classes determined by `equiv`.
