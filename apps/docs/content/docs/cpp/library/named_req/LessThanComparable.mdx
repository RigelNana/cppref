{/* source:cpp-named-req-lessthancomparable:0000 */}
The type must work with `\<` operator and the result should have standard semantics.

### Requirements

{/* source:cpp-named-req-lessthancomparable:0001 */}
The type `T` satisfies *LessThanComparable* if given expressions `a`, `b` and `c` of type `T`<InlineRevision since="C++11"> or `const T`</InlineRevision>, the following expression is valid and has its specified effects:

{/* source:cpp-named-req-lessthancomparable:0002 */}
| Expression | Type | Effects |
| --- | --- | --- |
| `a < b` | meets [*BooleanTestable*](/docs/cpp/library/named_req/BooleanTestable)<br /><InlineRevision until="C++20" /> | Establishes [strict weak ordering](https://en.wikipedia.org/wiki/strict_weak_ordering) relation with the following properties:<br />- For all `a`, `!(a < a)` yields `true`.<br />- If `a < b`, then `!(b < a)`.<br />- If `a < b` and `b < c`, then `a < c`.<br />- Defining `equiv(a, b)` as `!(a < b) && !(b < a)`, if `equiv(a, b)` and `equiv(b, c)`, then `equiv(a, c)`. |
| `a < b` | models [`boolean-testable`](/docs/cpp/library/concepts/boolean-testable)<br /><InlineRevision since="C++20" /> | Establishes [strict weak ordering](https://en.wikipedia.org/wiki/strict_weak_ordering) relation with the following properties:<br />- For all `a`, `!(a < a)` yields `true`.<br />- If `a < b`, then `!(b < a)`.<br />- If `a < b` and `b < c`, then `a < c`.<br />- Defining `equiv(a, b)` as `!(a < b) && !(b < a)`, if `equiv(a, b)` and `equiv(b, c)`, then `equiv(a, c)`. |

### Notes

{/* source:cpp-named-req-lessthancomparable:0003 */}
To satisfy this requirement, types that do not have built-in [comparison operators](/docs/cpp/language/expressions/operator_comparison) have to provide a [user-defined `operator<`](/docs/cpp/language/expressions/operators#Comparison_operators).

{/* source:cpp-named-req-lessthancomparable:0004 */}
For the types that are both [*EqualityComparable*](/docs/cpp/library/named_req/EqualityComparable) and *LessThanComparable*, the C++ standard library makes a distinction between

{/* source:cpp-named-req-lessthancomparable:0005 */}
- *Equality*, which is the value of the expression `a == b` and
- *Equivalence*, which is the value of the expression `!(a < b) && !(b < a)`.
