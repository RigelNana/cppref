{/* source:cpp-named-req-hash:0000 */}
A *Hash* is a function object for which the output depends only on the input and has a very low probability of yielding the same output given different input values.

### Requirements

{/* source:cpp-named-req-hash:0001 */}
The type `T` satisfies *Hash* if

{/* source:cpp-named-req-hash:0002 */}
- The type `T` satisfies [*FunctionObject*](/docs/cpp/library/named_req/FunctionObject), [*CopyConstructible*](/docs/cpp/library/named_req/CopyConstructible), [*Destructible*](/docs/cpp/library/named_req/Destructible), and

{/* source:cpp-named-req-hash:0003 */}
Given

{/* source:cpp-named-req-hash:0004 */}
- `h`, a value of type `T` or `const T`, whose argument type is `Key`,
- `k`, a value of type convertible to `Key` or `const Key`,
- `u`, an [lvalue](/docs/cpp/language/expressions/value_category) expression of type `Key`.

{/* source:cpp-named-req-hash:0005 */}
The following expressions must be valid and have their specified effects.

{/* source:cpp-named-req-hash:0006 */}
<table>
<thead><tr><th>Expression</th><th>Return type</th><th>Requirements</th></tr></thead>
<tbody>
<tr>
<td>`h(k)`</td>
<td>[`std::size_t`](/docs/cpp/library/utility/types/size_t)</td>
<td>The returned value depends only on the value of `k` for the duration of the program.<br />All evaluations of `h(k)` executed within a given execution of a program yield the same result for the same value of `k`.<br />The probability of `h(a) == h(b)` for `a != b` should approach `1.0 / std::numeric_limits<std::size_t>::max()`.</td>
</tr>
<tr>
<td>`h(u)`</td>
<td>[`std::size_t`](/docs/cpp/library/utility/types/size_t)</td>
<td>`u` is not modified.</td>
</tr>
</tbody>
</table>
