{/* source:cpp-named-req-contiguouscontainer:0000 */}
A ContiguousContainer is a [Container](/docs/cpp/library/named_req/Container) that stores objects in contiguous memory locations.

### Requirements

{/* source:cpp-named-req-contiguouscontainer:0001 */}
The type `X` satisfies ContiguousContainer if

{/* source:cpp-named-req-contiguouscontainer:0002 */}
- The type `X` satisfies [Container](/docs/cpp/library/named_req/Container)
- The type `X` supports [LegacyRandomAccessIterators](/docs/cpp/library/named_req/RandomAccessIterator)
- The member types `X::iterator` and `X::const_iterator` are <InlineRevision until="C++20">[LegacyContiguousIterators](/docs/cpp/library/named_req/ContiguousIterator)</InlineRevision><InlineRevision since="C++20">[`contiguous_iterators`](/docs/cpp/library/iterator/contiguous_iterator)</InlineRevision>

### Standard library

{/* source:cpp-named-req-contiguouscontainer:0003 */}
The following standard library string types and containers satisfy the ContiguousContainer requirements:
