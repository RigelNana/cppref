{/* source:cpp-named-req-uniformrandombitgenerator:0000 */}
A uniform random bit generator is a function object returning unsigned integer values such that each value in the range of possible results has (ideally) equal probability.

{/* source:cpp-named-req-uniformrandombitgenerator:0001 */}
Uniform random bit generators are not intended to be used as random number generators: they are used as the source of random bits (generated in bulk, for efficiency). Any uniform random bit generator may be plugged into any [`random number distribution`](/docs/cpp/library/numeric/random) in order to obtain a random number (formally, a random variate).

### Requirements

{/* source:cpp-named-req-uniformrandombitgenerator:0002 */}
The type `G` satisfies *UniformRandomBitGenerator* if

{/* source:cpp-named-req-uniformrandombitgenerator:0003 */}
<Revision until="C++20">
Given `g`, a value of type `G`, all following conditions are satisfied:

- `G::result_type` is valid, and denotes an unsigned integer type.
- The following expressions must be valid and have their specified effects:
</Revision>

{/* source:cpp-named-req-uniformrandombitgenerator:0004 */}
| Expression | Type | Requirements |
| --- | --- | --- |
| `G::min()` | `G::result_type` | Yields the smallest value that `G`'s `operator()` may return.<br />The result value is strictly less than `G::max()`.<br />The expression must be a constant expression. |
| `G::max()` | `G::result_type` | Yields the largest value that `G`'s `operator()` may return.<br />The result value is strictly greater than `G::min()`.<br />The expression must be a constant expression. |
| `g()` | `G::result_type` | Returns a value in the closed interval `[G::min(), G::max()]`.<br />Has amortized constant complexity. |

{/* source:cpp-named-req-uniformrandombitgenerator:0005 */}
<Revision since="C++20">
All following conditions are satisfied:

- `G` models [`uniform_random_bit_generator`](/docs/cpp/library/numeric/random/UniformRandomBitGenerator).
- `std::invoke_result_t<G&>` is an unsigned integer type.
- `G` provides a nested `typedef` name `result_type`, which denotes the same type as `std::invoke_result_t<G&>`.
</Revision>

### Notes

{/* source:cpp-named-req-uniformrandombitgenerator:0006 */}
All [`RandomNumberEngines`](/docs/cpp/library/named_req/RandomNumberEngine) satisfy this requirement.

### Standard library

{/* source:cpp-named-req-uniformrandombitgenerator:0007 */}
The following standard library facilities expect a *UniformRandomBitGenerator* type.

{/* source:cpp-named-req-uniformrandombitgenerator:0008 */}
|  |  |
| --- | --- |
| [`random_shuffle shuffle`](/docs/cpp/library/algorithm/random_shuffle) <InlineRevision until="C++17" /> <InlineRevision since="C++11" /> | randomly re-orders elements in a range (function template) |
| [`sample`](/docs/cpp/library/algorithm/sample) <InlineRevision since="C++17" /> | selects N random elements from a sequence (function template) |
| [`generate_canonical`](/docs/cpp/library/numeric/random/generate_canonical) <InlineRevision since="C++11" /> | evenly distributes real values of given precision across `[0, 1)` (function template) |
| [`uniform_int_distribution`](/docs/cpp/library/numeric/random/uniform_int_distribution) <InlineRevision since="C++11" /> | produces integer values evenly distributed across a range (class template) |
| [`uniform_real_distribution`](/docs/cpp/library/numeric/random/uniform_real_distribution) <InlineRevision since="C++11" /> | produces real values evenly distributed across a range (class template) |
| all other random number distributions |  |

{/* source:cpp-named-req-uniformrandombitgenerator:0013 */}
↑ The time complexity requirement for these expressions were “compile-time” before C++20. The wording is ambiguous, as “compile-time time complexity” can be interpreted as both “can be evaluated in compile-time” and “the time complexity can be determined in compile-time”.
