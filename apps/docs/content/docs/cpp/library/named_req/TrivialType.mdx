{/* source:cpp-named-req-trivialtype:0000 */}
Specifies that a type is a trivial type.

{/* source:cpp-named-req-trivialtype:0001 */}
Note: the standard doesn't define a named requirement with this name. This is a type category defined by the core language. It is included here as a named requirement only for consistency.

### Requirements

{/* source:cpp-named-req-trivialtype:0002 */}
The following types are collectively called *trivial types*:

{/* source:cpp-named-req-trivialtype:0003 */}
- [`scalar types`](/docs/cpp/library/named_req/ScalarType)
- [`trivial class types`](/docs/cpp/language/classes#Trivial_class)
- arrays of such types
- cv-qualified versions of these types

### Notes

{/* source:cpp-named-req-trivialtype:0004 */}
A trivial class may have a private or protected trivial default constructor, in which case an attempt to default-construct such a class object in contexts unrelated to the class makes the program ill-formed.
