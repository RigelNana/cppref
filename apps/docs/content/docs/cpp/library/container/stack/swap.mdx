Exchanges the contents of the container adaptor with those of `other`. Effectively calls

{/* source:cpp-container-stack-swap:0001 */}
```cpp
using std::swap;
swap(c, other.c);
```

### Parameters

{/* source:cpp-container-stack-swap:0002 */}
<ParameterList>
  <Parameter name="other">container adaptor to exchange the contents with</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-stack-swap:0003 */}
(none)

### Exceptions

{/* source:cpp-container-stack-swap:0004 */}
<Revision since="C++11" until="C++17">
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(noexcept(swap(c, other.c)))`

In the expression above, the identifier `swap` is looked up in the same manner as the one used by the C++17 [`std::is_nothrow_swappable`](/docs/cpp/library/meta/is_swappable) trait.
</Revision>
<Revision since="C++17">
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_swappable_v<Container>)`
</Revision>

### Complexity

{/* source:cpp-container-stack-swap:0005 */}
Same as underlying container (typically constant).

### Notes

{/* source:cpp-container-stack-swap:0006 */}
Some implementations (e.g. libc++) provide the `swap` member function as an extension to pre-C++11 modes.

### Example

{/* source:cpp-container-stack-swap:0007 */}
```cpp
#include <iostream>
#include <concepts>
#include <stack>
#include <string>
#include <string_view>
#include <vector>

template<typename Adaptor>
requires (std::ranges::input_range<typename Adaptor::container_type>)
void print(std::string_view name, const Adaptor& adaptor)
{
    struct Printer : Adaptor // to use protected Adaptor::Container c;
    {
        void print(std::string_view name) const
        {
            std::cout << name << " [" << std::size(this->c) << "]: ";
            for (auto const& elem : this->c)
                std::cout << elem << ' ';
            std::cout << '\n';
        }
    };

    static_cast<Printer const&>(adaptor).print(name);
}

int main()
{
    std::vector<std::string> v1{"1","2","3","4"},
                             v2{"Ɐ","B","Ɔ","D","Ǝ"};

    std::stack s1(std::move(v1));
    std::stack s2(std::move(v2));

    print("s1", s1);
    print("s2", s2);

    s1.swap(s2);

    print("s1", s1);
    print("s2", s2);
}
```

Output:

```text
s1 [4]: 4 3 2 1
s2 [5]: Ǝ D Ɔ B Ɐ
s1 [5]: Ǝ D Ɔ B Ɐ
s2 [4]: 4 3 2 1
```
