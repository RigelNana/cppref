{/* source:cpp-container-stack-pop:0001 */}
Removes the top element from the stack. Effectively calls `c.pop_back()`.

### Parameters

{/* source:cpp-container-stack-pop:0002 */}
(none)

### Return value

{/* source:cpp-container-stack-pop:0003 */}
(none)

### Complexity

{/* source:cpp-container-stack-pop:0004 */}
Equal to the complexity of `Container::pop_back`.
