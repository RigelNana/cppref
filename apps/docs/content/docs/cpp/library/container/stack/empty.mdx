{/* source:cpp-container-stack-empty:0001 */}
Checks if the underlying container has no elements. Equivalent to: `return` [`c`](/docs/cpp/library/container/stack#Member_objects)`.empty()`.

### Parameters

{/* source:cpp-container-stack-empty:0002 */}
(none)

### Return value

{/* source:cpp-container-stack-empty:0003 */}
`true` if the underlying container is empty, `false` otherwise.

### Complexity

{/* source:cpp-container-stack-empty:0004 */}
Constant.

### Example

{/* source:cpp-container-stack-empty:0005 */}
```cpp
#include <cassert>
#include <stack>

int main()
{
    std::stack<int> stack;
    assert(stack.empty());

    stack.push(42);
    assert(!stack.empty());

    stack.pop();
    assert(stack.empty());
}
```
