{/* source:cpp-container-stack-deduction-guides:0001 */}
These [deduction guides](/docs/cpp/language/templates/ctad) are provided for `stack` to allow deduction from underlying container type.

{/* source:cpp-container-stack-deduction-guides:0002 */}
1. Deduces underlying container type from the argument.

{/* source:cpp-container-stack-deduction-guides:0003 */}
2. Same as (1), except that the allocator is provided.

{/* source:cpp-container-stack-deduction-guides:0004 */}
3. Deduces the element type from the iterator, using `std::deque<typename std::iterator_traits<InputIt>::value_type>` as the underlying container type.

{/* source:cpp-container-stack-deduction-guides:0005 */}
4. Same as (3), except that the allocator is provided.

{/* source:cpp-container-stack-deduction-guides:0006 */}
5. Deduces the element type from a [`std::from_range_t`](/docs/cpp/library/ranges/from_range) tag and an [`input_range`](/docs/cpp/library/ranges/input_range).

{/* source:cpp-container-stack-deduction-guides:0007 */}
6. Same as (5), except that the allocator is provided.

{/* source:cpp-container-stack-deduction-guides:0008 */}
These overloads participate in overload resolution only if

{/* source:cpp-container-stack-deduction-guides:0009 */}
- `InputIt` (if exists) satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator),
- `Container` (if exists) does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator),
- for <InlineRevision until="C++23">(3)</InlineRevision><InlineRevision since="C++23">(4)</InlineRevision>, `Alloc` satisfies [`Allocator`](/docs/cpp/library/named_req/Allocator), and
- `std::uses_allocator_v<Container, Alloc>` is `true` if both `Container` and `Alloc` exist.

{/* source:cpp-container-stack-deduction-guides:0010 */}
Note: the extent to which the library determines that a type does not satisfy [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator) is unspecified, except that as a minimum integral types do not qualify as input iterators. Likewise, the extent to which it determines that a type does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator) is unspecified, except that as a minimum the member type `Alloc::value_type` must exist and the expression `std::declval<Alloc&>().allocate(std::size_t{})` must be well-formed when treated as an unevaluated operand.

### Example

{/* source:cpp-container-stack-deduction-guides:0012 */}
```cpp
#include <stack>
#include <vector>

int main()
{
    std::vector<int> v = {1, 2, 3, 4};
    std::stack s{v}; // guide #1 deduces std::stack<int, vector<int>>
}
```
