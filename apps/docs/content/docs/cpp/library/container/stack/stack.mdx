{/* source:cpp-container-stack-stack:0001 */}
Constructs new underlying container of the container adaptor from a variety of data sources.

{/* source:cpp-container-stack-stack:0002 */}
1. Default constructor. Value-initializes the container.

{/* source:cpp-container-stack-stack:0003 */}
2. Copy-constructs the underlying container `c` with the contents of `cont`. <InlineRevision until="C++11">This is also the default constructor.</InlineRevision>

{/* source:cpp-container-stack-stack:0004 */}
3. Move-constructs the underlying container `c` with `std::move(cont)`.

{/* source:cpp-container-stack-stack:0005 */}
4. (implicitly declared) [Copy constructor](/docs/cpp/language/classes/copy_constructor). The adaptor is copy-constructed with the contents of `other.c`.

{/* source:cpp-container-stack-stack:0006 */}
5. (implicitly declared) [Move constructor](/docs/cpp/language/classes/move_constructor). The adaptor is constructed with `std::move(other.c)`.

{/* source:cpp-container-stack-stack:0007 */}
6. Constructs the underlying container `c` with the contents of the range `[first, last)`. This overload participates in overload resolution only if `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

{/* source:cpp-container-stack-stack:0008 */}
7-12) These constructors participate in overload resolution only if `std::uses_allocator<Container, Alloc>::value` is `true`, that is, if the underlying container is an allocator-aware container (true for all standard library containers that can be used with `stack`).

{/* source:cpp-container-stack-stack:0009 */}
7. Constructs the underlying container using `alloc` as allocator, as if by `c(alloc)`.

{/* source:cpp-container-stack-stack:0010 */}
8. Constructs the underlying container with the contents of `cont` and using `alloc` as allocator, as if by `c(cont, alloc)`.

{/* source:cpp-container-stack-stack:0011 */}
9. Constructs the underlying container with the contents of `cont` using move semantics while utilizing `alloc` as allocator, as if by `c(std::move(cont), alloc)`.

{/* source:cpp-container-stack-stack:0012 */}
10. Constructs the adaptor with the contents of `other.c` and using `alloc` as allocator, as if by `c(other.c, alloc)`.

{/* source:cpp-container-stack-stack:0013 */}
11. Constructs the adaptor with the contents of `other` using move semantics while utilizing `alloc` as allocator, as if by `c(std::move(other.c), alloc)`.

{/* source:cpp-container-stack-stack:0014 */}
12. Constructs the underlying container with the contents of the range `[first, last)` using `alloc` as allocator, as if by `c(first, last, alloc)`. This overload participates in overload resolution only if `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

{/* source:cpp-container-stack-stack:0015 */}
13. Constructs the underlying container with `ranges::to<Container>(std::forward<R>(rg))`.

{/* source:cpp-container-stack-stack:0016 */}
14. Constructs the underlying container with `ranges::to<Container>(std::forward<R>(rg), alloc)`.

### Parameters

{/* source:cpp-container-stack-stack:0017 */}
<ParameterList>
  <Parameter name="alloc">allocator to use for all memory allocations of the underlying container</Parameter>
  <Parameter name="other">another container adaptor to be used as source to initialize the underlying container</Parameter>
  <Parameter name="cont">container to be used as source to initialize the underlying container</Parameter>
  <Parameter name="first, last">range of elements `[first, last)` to initialize with</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

Type requirements

- `Alloc` must meet the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator).
- `Container` must meet the requirements of [`Container`](/docs/cpp/library/named_req/Container). The constructors taking an allocator parameter participate in overload resolution only if `Container` meets the requirements of [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer).
- `InputIt` must meet the requirements of [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

### Complexity

{/* source:cpp-container-stack-stack:0018 */}
Same as the corresponding operation on the wrapped container.

### Example

{/* source:cpp-container-stack-stack:0020 */}
```cpp
#include <cassert>
#include <deque>
#include <iostream>
#include <memory>
#include <ranges>
#include <stack>

int main()
{
    std::stack<int> c1;
    c1.push(5);
    assert(c1.size() == 1);

    std::stack<int> c2(c1);
    assert(c2.size() == 1);

    std::deque<int> deq{3, 1, 4, 1, 5};
    std::stack<int> c3(deq); // overload (2)
    assert(c3.size() == 5);

# ifdef __cpp_lib_adaptor_iterator_pair_constructor
    const auto il = {2, 7, 1, 8, 2};
    std::stack<int> c4{il.begin(), il.end()}; // C++23, (6)
    assert(c4.size() == 5);
# endif

# if __cpp_lib_containers_ranges >= 202202L
    // C++23, overload (13)
    auto c5 = std::stack(std::from_range_t, std::ranges::iota(0, 42));
    assert(c5.size() == 42);

    // the same effect with pipe syntax, internally uses overload (13)
    auto c6 = std::ranges::iota(0, 42) | std::ranges::to<std::stack>();
    assert(c6.size() == 42);

    std::allocator<int> alloc;

    // C++23, overload (14)
    auto c7 = std::stack(std::from_range_t, std::ranges::iota(0, 42), alloc);
    assert(c7.size() == 42);

    // the same effect with pipe syntax, internally uses overload (14)
    auto c8 = std::ranges::iota(0, 42) | std::ranges::to<std::stack>(alloc);
    assert(c8.size() == 42);
# endif
}
```
