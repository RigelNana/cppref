  <Declaration language="cpp" code={`void clear();`} />

  <DeclarationDescription>
    {/* source:cpp-container-list-clear:0001 */}
    1. <InlineRevision since="C++11" /> Erases all elements from the container. After this call, [`size()`](/docs/cpp/library/container/list/size) returns zero.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-container-list-clear:0002 */}
Invalidates any references, pointers, and iterators referring to contained elements. Any past-the-end iterator remains valid.

### Parameters

{/* source:cpp-container-list-clear:0003 */}
(none)

### Return value

{/* source:cpp-container-list-clear:0004 */}
(none)

### Complexity

{/* source:cpp-container-list-clear:0005 */}
Linear in the size of the container, i.e., the number of elements.

### Example

{/* source:cpp-container-list-clear:0006 */}
```cpp
#include <iostream>
#include <string_view>
#include <list>

void print_info(std::string_view rem, const std::list<int>& v)
{
    std::cout << rem << "{ ";
    for (const auto& value : v)
        std::cout << value << ' ';
    std::cout << "}\n";
    std::cout << "Size=" << v.size() << '\n';
}

int main()
{
    std::list<int> container{1, 2, 3};
    print_info("Before clear: ", container);
    container.clear();
    print_info("After clear: ", container);
}
```

Output:

```text
Before clear: { 1 2 3 }
Size=3
After clear: { }
Size=0
```
