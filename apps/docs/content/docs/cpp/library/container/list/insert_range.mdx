<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++23" code={`template< container-compatible-range<T> R >
iterator insert_range( const_iterator pos, R&& rg );`} />

  <DeclarationDescription>
    {/* source:cpp-container-list-insert-range:0001 */}
    Inserts, in non-reversing order, copies of elements in `rg` before `pos`.

    {/* source:cpp-container-list-insert-range:0002 */}
    No iterators or references are invalidated.

    {/* source:cpp-container-list-insert-range:0003 */}
    Each iterator in the range `rg` is dereferenced exactly once.

    {/* source:cpp-container-list-insert-range:0004 */}
    `rg` must not overlap with the container. Otherwise, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-list-insert-range:0005 */}
<ParameterList>
  <Parameter name="pos">iterator before which the content will be inserted (`pos` may be the [`end()`](/docs/cpp/library/container/list/end) iterator)</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

**Type requirements**

- `T` must be [EmplaceConstructible](/docs/cpp/library/named_req/EmplaceConstructible) into `list` from `*ranges::begin(rg)`. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-list-insert-range:0006 */}
An [`iterator`](/docs/cpp/library/container/list#Member_types) that points at the copy of the first element inserted into `list` or at `pos` if `rg` is empty.

### Example

{/* source:cpp-container-list-insert-range:0008 */}
```cpp
#include <algorithm>
#include <cassert>
#include <iterator>
#include <list>
#include <vector>

int main()
{
    auto container = std::list{1, 2, 3, 4};
    auto pos = std::next(container.begin(), 2);
    assert(*pos == 3);
    const auto rg = std::vector{-1, -2, -3};

#ifdef __cpp_lib_containers_ranges
    container.insert_range(pos, rg);
#else
    container.insert(pos, rg.cbegin(), rg.cend());
#endif
    assert(std::ranges::equal(container, std::list{1, 2, -1, -2, -3, 3, 4}));
}
```
