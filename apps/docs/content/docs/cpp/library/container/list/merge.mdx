  <Declaration id="3" language="cpp" since="C++98" code={`template< class Compare > 
void merge( list& other, Compare comp );`} />
  <Declaration id="4" language="cpp" since="C++11" code={`template< class Compare > 
void merge( list&& other, Compare comp );`} />

  <DeclarationDescription>
    {/* source:cpp-container-list-merge:0001 */}
    The function does nothing if `other` refers to the same object as `*this`.

    {/* source:cpp-container-list-merge:0002 */}
    Otherwise, merges `other` into `*this`. Both lists should be sorted. No elements are copied, and the container `other` becomes empty after the merge. This operation is stable: for equivalent elements in the two lists, the elements from `*this` always precede the elements from `other`, and the order of equivalent elements of `*this` and `other` does not change.

    {/* source:cpp-container-list-merge:0003 */}
    No iterators or references become invalidated. The pointers and references to the elements moved from `*this`, as well as the iterators referring to these elements, will refer to the same elements of `*this`, instead of `other`.

    {/* source:cpp-container-list-merge:0004 */}
    1,2) Elements are compared using <InlineRevision until="C++14">`std::less<T>()`</InlineRevision> <InlineRevision since="C++14">`std::less<>()`</InlineRevision>.

    {/* source:cpp-container-list-merge:0005 */}
    3,4) Elements are compared using `comp`.

    {/* source:cpp-container-list-merge:0006 */}
    If `*this` or `other` is not sorted with respected to the corresponding comparator, or `get_allocator() != other.get_allocator()`, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-list-merge:0007 */}
<ParameterList>
  <Parameter name="other">another container to merge</Parameter>
  <Parameter name="comp">comparison function object (i.e. an object that satisfies the requirements of [Compare](/docs/cpp/library/named_req/Compare)) which returns `true` if the first argument is *less* than (i.e. is ordered *before*) the second.<br />The signature of the comparison function should be equivalent to the following: `bool cmp(const Type1& a, const Type2& b);`<br />While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>).<br />The types `Type1` and `Type2` must be such that an object of type `list<T, Allocator>::const_iterator` can be dereferenced and then implicitly converted to both of them.</Parameter>
</ParameterList>

**Type requirements**

- `Compare` must meet the requirements of [Compare](/docs/cpp/library/named_req/Compare).

### Return value

{/* source:cpp-container-list-merge:0008 */}
(none)

### Exceptions

{/* source:cpp-container-list-merge:0009 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)). Except if the exception comes from a comparison.

### Complexity

{/* source:cpp-container-list-merge:0010 */}
If `other` refers to the same object as `*this`, no comparisons are performed.

{/* source:cpp-container-list-merge:0011 */}
Otherwise, given `N` as `std::distance(begin(), end())` and `R` as `std::distance(other.begin(), other.end())`:

{/* source:cpp-container-list-merge:0012 */}
1,2) At most `N+R-1` comparisons using `operator<`.

{/* source:cpp-container-list-merge:0013 */}
3,4) At most `N+R-1` applications of the comparison function `comp`.

### Example

{/* source:cpp-container-list-merge:0014 */}
```cpp
#include <iostream>
#include <list>

std::ostream& operator<<(std::ostream& ostr, const std::list<int>& list)
{
    for (const int i : list)
        ostr << ' ' << i;
    return ostr;
}

int main()
{
    std::list<int> list1 = {5, 9, 1, 3, 3};
    std::list<int> list2 = {8, 7, 2, 3, 4, 4};

    list1.sort();
    list2.sort();
    std::cout << "list1: " << list1 << '\n';
    std::cout << "list2: " << list2 << '\n';

    list1.merge(list2);
    std::cout << "merged:" << list1 << '\n';
}
```

Output:

```text
list1:  1 3 3 5 9
list2:  2 3 4 4 7 8
merged: 1 2 3 3 3 4 4 5 7 8 9
```
