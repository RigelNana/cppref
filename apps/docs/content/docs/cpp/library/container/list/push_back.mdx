<DeclarationDoc>

  <Declaration id="2" language="cpp" since="C++11" code={`void push_back( T&& value );`} />
</DeclarationDoc>

{/* source:cpp-container-list-push-back:0001 */}
Appends the given element `value` to the end of the container.

{/* source:cpp-container-list-push-back:0002 */}
1) The new element is initialized as a copy of `value`.

{/* source:cpp-container-list-push-back:0003 */}
2) `value` is moved into the new element.

{/* source:cpp-container-list-push-back:0004 */}
No iterators or references are invalidated.

### Parameters

{/* source:cpp-container-list-push-back:0005 */}
<ParameterList>
  <Parameter name="value">the value of the element to append</Parameter>
</ParameterList>

Type requirements

- `T` must meet the requirements of [`CopyInsertable`](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (1).
- `T` must meet the requirements of [`MoveInsertable`](/docs/cpp/library/named_req/MoveInsertable) in order to use overload (2).

### Return value

{/* source:cpp-container-list-push-back:0006 */}
(none)

### Complexity

{/* source:cpp-container-list-push-back:0007 */}
Constant.

### Exceptions

{/* source:cpp-container-list-push-back:0008 */}
If an exception is thrown (which can be due to `Allocator::allocate()` or element copy/move constructor/assignment), this function has no effect ([strong exception guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-container-list-push-back:0009 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string>
#include <list>

int main()
{
    std::list<std::string> letters;

    letters.push_back("abc");
    std::string s{"def"};
    letters.push_back(std::move(s));

    std::cout << "std::list letters holds: ";
    for (auto&& e : letters)
        std::cout << std::quoted(e) << ' ';

    std::cout << "\nMoved-from string s holds: " << std::quoted(s) << '\n';
}
```

Possible output:

```text
std::list letters holds: "abc" "def"
Moved-from string s holds: ""
```
