    {/* source:cpp-container-list-list:0001 */}
    A [destructor](/docs/cpp/language/classes/destructor). Destructs the list. The destructors of the elements are called and the used storage is deallocated. Note, that if the elements are pointers, the pointed-to objects are not destroyed.
  </DeclarationDescription>
</DeclarationDoc>

### Complexity

{/* source:cpp-container-list-list:0002 */}
Linear in the size of the list.
