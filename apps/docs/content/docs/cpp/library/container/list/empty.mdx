{/* source:cpp-container-list-empty:0001 */}
<InlineRevision since="C++11" /> Checks if the container has no elements, i.e. whether `begin() == end()`.

## Parameters

{/* source:cpp-container-list-empty:0002 */}
(none)

## Return value

{/* source:cpp-container-list-empty:0003 */}
`true` if the container is empty, `false` otherwise.

## Complexity

{/* source:cpp-container-list-empty:0004 */}
Constant.

## Example

{/* source:cpp-container-list-empty:0005 */}
The following code uses `empty` to check if a `std::list<int>` contains any elements:

```cpp
#include <list>
#include <iostream>

int main()
{
    std::list<int> numbers;
    std::cout << std::boolalpha;
    std::cout << "Initially, numbers.empty(): " << numbers.empty() << '\n';

    numbers.push_back(42);
    numbers.push_back(13317); 
    std::cout << "After adding elements, numbers.empty(): " << numbers.empty() << '\n';
}
```

Output:

```text
Initially, numbers.empty(): true
After adding elements, numbers.empty(): false
```
