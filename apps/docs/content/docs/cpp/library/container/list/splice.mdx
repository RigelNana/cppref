{/* source:cpp-container-list-splice:0001 */}
Transfers elements from one list to another.

{/* source:cpp-container-list-splice:0002 */}
No elements are copied or moved, only the internal pointers of the list nodes are re-pointed. No iterators or references become invalidated, the iterators to moved elements remain valid, but now refer into `*this`, not into `other`.

{/* source:cpp-container-list-splice:0003 */}
1,2) Transfers all elements from `other` into `*this`. The elements are inserted before the element pointed to by `pos`. The container `other` becomes empty after the operation.

{/* source:cpp-container-list-splice:0004 */}
3,4) Transfers the element pointed to by `it` from `other` into `*this`. The element is inserted before the element pointed to by `pos`.

{/* source:cpp-container-list-splice:0005 */}
5,6) Transfers the elements in the range `[first, last)` from `other` into `*this`. The elements are inserted before the element pointed to by `pos`.

{/* source:cpp-container-list-splice:0006 */}
The behavior is undefined if

{/* source:cpp-container-list-splice:0007 */}
- `get_allocator() != other.get_allocator()`, for overloads (1,2), `*this` and `other` refer to the same object, for overloads (3,4), `it` is not a [dereferenceable iterator](/docs/cpp/library/iterator#Dereferenceability_and_validity) into `other`, or for overloads (5,6),

{/* source:cpp-container-list-splice:0008 */}
- `[first, last)` is not a valid [range](/docs/cpp/library/iterator#Ranges) in `other`, or `pos` is in `[first, last)`.

### Parameters

{/* source:cpp-container-list-splice:0009 */}
<ParameterList>
  <Parameter name="pos">element before which the content will be inserted</Parameter>
  <Parameter name="other">another container to transfer the content from</Parameter>
  <Parameter name="it">the element to transfer from `other` to `*this`</Parameter>
  <Parameter name="first, last">the range of elements to transfer from `other` to `*this`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-list-splice:0010 */}
(none)

### Exceptions

{/* source:cpp-container-list-splice:0011 */}
Throws nothing.

### Complexity

{/* source:cpp-container-list-splice:0012 */}
1-4) Constant.

{/* source:cpp-container-list-splice:0013 */}
5,6) Constant if `other` refers to the same object as `*this`, otherwise linear in `std::distance(first, last)`.

### Example

{/* source:cpp-container-list-splice:0014 */}
```cpp
#include <iostream>
#include <list>

std::ostream& operator<<(std::ostream& ostr, const std::list<int>& list)
{
    for (auto& i : list)
        ostr << ' ' << i;

    return ostr;
}

int main ()
{
    std::list<int> list1{1, 2, 3, 4, 5};
    std::list<int> list2{10, 20, 30, 40, 50};

    auto it = list1.begin();
    std::advance(it, 2);

    list1.splice(it, list2);

    std::cout << "list1:" << list1 << '\n';
    std::cout << "list2:" << list2 << '\n';

    list2.splice(list2.begin(), list1, it, list1.end());

    std::cout << "list1:" << list1 << '\n';
    std::cout << "list2:" << list2 << '\n';
}
```

Output:

```text
list1: 1 2 10 20 30 40 50 3 4 5
list2:
list1: 1 2 10 20 30 40 50
list2: 3 4 5
```
