<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`template< container-compatible-range<T> R >
void append_range( R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-list-append-range:0001 */}
Inserts copies of elements from the range `rg` before [`end()`](/docs/cpp/library/container/list/end), in non-reversing order.

{/* source:cpp-container-list-append-range:0002 */}
No iterators or references are invalidated.

{/* source:cpp-container-list-append-range:0003 */}
Each iterator in `rg` is dereferenced exactly once.

### Parameters

{/* source:cpp-container-list-append-range:0004 */}
<ParameterList>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

Type requirements

- `T` must be [`EmplaceConstructible`](/docs/cpp/library/named_req/EmplaceConstructible) into `list` from `*ranges::begin(rg)`. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-list-append-range:0005 */}
(none)

### Complexity

{/* source:cpp-container-list-append-range:0006 */}
Linear in size of `rg`. The number of calls to the constructor of `T` is exactly equal to the `std::ranges::size(rg))`.

### Exceptions

{/* source:cpp-container-list-append-range:0007 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Notes

{/* source:cpp-container-list-append-range:0008 */}
| [Feature-test](/docs/cpp/library/utility/feature_test) macro | Value | Std | Feature |
| --- | ---: | --- | --- |
| [`__cpp_lib_containers_ranges`](/docs/cpp/library/feature_test#cpp_lib_containers_ranges) | [`202202L`](/docs/cpp/library/compiler_support/23#cpp_lib_containers_ranges_202202L) | C++23 | [Ranges-aware](/docs/cpp/library/ranges/to#container_compatible_range) construction and insertion |

### Example

{/* source:cpp-container-list-append-range:0009 */}
```cpp
#include <cassert>
#include <list>
#include <vector>

int main()
{
    auto head = std::list{1, 2, 3, 4};
    const auto tail = std::vector{-5, -6, -7};
#ifdef __cpp_lib_containers_ranges
    head.append_range(tail);
#else
    head.insert(head.end(), tail.cbegin(), tail.cend());
#endif
    assert((head == std::list{1, 2, 3, 4, -5, -6, -7}));
}
```
