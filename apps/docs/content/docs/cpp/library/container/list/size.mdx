{/* source:cpp-container-list-size:0001 */}
Returns the number of elements in the container, i.e. `std::distance(begin(), end())`.

### Parameters

{/* source:cpp-container-list-size:0002 */}
(none)

### Return value

{/* source:cpp-container-list-size:0003 */}
The number of elements in the container.

### Complexity

{/* source:cpp-container-list-size:0004 */}
<Revision until="C++11">Constant or linear.</Revision>

<Revision since="C++11">Constant.</Revision>

### Example

{/* source:cpp-container-list-size:0005 */}
The following code uses `size` to display the number of elements in a [`std::list`](/docs/cpp/library/container/list):

```cpp
#include <iostream>
#include <list>

int main()
{ 
    std::list<int> nums{1, 3, 5, 7};

    std::cout << "nums contains " << nums.size() << " elements.\n";
}
```

Output:

```text
nums contains 4 elements.
```
