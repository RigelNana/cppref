  <DeclarationDescription>
    {/* source:cpp-container-list-list:0001 */}
    Constructs a new `list` from a variety of data sources, optionally using a user supplied allocator `alloc`.

    {/* source:cpp-container-list-list:0002 */}
    1) The default constructor since C++11. Constructs an empty list with a default-constructed allocator.

    {/* source:cpp-container-list-list:0003 */}
    If `Allocator` is not [DefaultConstructible](/docs/cpp/library/named_req/DefaultConstructible), the behavior is undefined.

    {/* source:cpp-container-list-list:0004 */}
    2) The default constructor until C++11. Constructs an empty list with the given allocator `alloc`.

    {/* source:cpp-container-list-list:0005 */}
    3) Constructs a list with `count` default-inserted objects of `T`. No copies are made.

    {/* source:cpp-container-list-list:0006 */}
    If `T` is not [DefaultInsertable](/docs/cpp/library/named_req/DefaultInsertable) into `std::list<T>`, the behavior is undefined.

    {/* source:cpp-container-list-list:0007 */}
    4) Constructs a `list` with `count` copies of elements with value `value`.

    <Revision since="C++11">
    If `T` is not [CopyInsertable](/docs/cpp/library/named_req/CopyInsertable) into `std::list<T>`, the behavior is undefined.
    </Revision>

    {/* source:cpp-container-list-list:0008 */}
    5) Constructs a `list` with the contents of the range [`first`, `last`). Each iterator in [`first`, `last`) is dereferenced exactly once.

    <Revision until="C++11">
    If `InputIt` does not satisfy the requirements of [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator), overload (4) is called instead with arguments `static_cast<size_type>(first)`, `last` and `alloc`.
    </Revision>

    <Revision since="C++11">
    This overload participates in overload resolution only if `InputIt` satisfies the requirements of [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator).

    If `T` is not [EmplaceConstructible](/docs/cpp/library/named_req/EmplaceConstructible) into `std::list<T>` from `*first`, the behavior is undefined.
    </Revision>

    {/* source:cpp-container-list-list:0009 */}
    6) Constructs a list with the contents of the range `rg`. Each iterator in `rg` is dereferenced exactly once.

    {/* source:cpp-container-list-list:0010 */}
    If `T` is not [EmplaceConstructible](/docs/cpp/library/named_req/EmplaceConstructible) into `std::list<T>` from `*ranges::begin(rg)`, the behavior is undefined.

    {/* source:cpp-container-list-list:0011 */}
    7-10) Constructs a list with the contents of `other`.

    {/* source:cpp-container-list-list:0012 */}
    7) The copy constructor.

    <Revision since="C++11">
    The allocator is obtained as if by calling `std::allocator_traits<Allocator>::select_on_container_copy_construction(other.get_allocator())`.
    </Revision>

    {/* source:cpp-container-list-list:0013 */}
    8) The move constructor. The allocator is obtained by move construction from `other.get_allocator()`.

    {/* source:cpp-container-list-list:0014 */}
    9) Same as the copy constructor, except that `alloc` is used as the allocator.

    {/* source:cpp-container-list-list:0015 */}
    If `T` is not [CopyInsertable](/docs/cpp/library/named_req/CopyInsertable) into `std::list<T>`, the behavior is undefined.

    {/* source:cpp-container-list-list:0016 */}
    10) Same as the move constructor, except that `alloc` is used as the allocator.

    {/* source:cpp-container-list-list:0017 */}
    If `T` is not [MoveInsertable](/docs/cpp/library/named_req/MoveInsertable) into `std::list<T>`, the behavior is undefined.

    {/* source:cpp-container-list-list:0018 */}
    11) Equivalent to `list(il.begin(), il.end(), alloc)`.
  </DeclarationDescription>
</DeclarationDoc>

### Complexity

{/* source:cpp-container-list-list:0020 */}
1,2) Constant.

{/* source:cpp-container-list-list:0021 */}
3,4) Linear in `count`.

{/* source:cpp-container-list-list:0022 */}
5) Linear in `std::distance(first, last)`.

{/* source:cpp-container-list-list:0023 */}
6) Linear in `ranges::distance(rg)`.

{/* source:cpp-container-list-list:0024 */}
7) Linear in `other.size()`.

{/* source:cpp-container-list-list:0025 */}
8) Constant.

{/* source:cpp-container-list-list:0026 */}
9) Linear in `other.size()`.

{/* source:cpp-container-list-list:0027 */}
10) Linear in `other.size()` if `alloc != other.get_allocator()`, otherwise constant.

{/* source:cpp-container-list-list:0028 */}
11) Linear in `init.size()`.

### Exceptions

{/* source:cpp-container-list-list:0029 */}
Calls to `Allocator::allocate` may throw.

### Notes

{/* source:cpp-container-list-list:0030 */}
After container move construction (overload (8)), references, pointers, and iterators (other than the end iterator) to `other` remain valid, but refer to elements that are now in `*this`. The current standard makes this guarantee via the blanket statement in [[container.reqmts]/67](https://eel.is/c++draft/container.reqmts#67), and a more direct guarantee is under consideration via [LWG issue 2321](https://cplusplus.github.io/LWG/issue2321).

### Example

{/* source:cpp-container-list-list:0032 */}
```cpp
#include <iostream>
#include <list>
#include <string>

template<typename T>
std::ostream& operator<<(std::ostream& s, const std::list<T>& v)
{
    s.put('{');
    for (char comma[]{'\0', ' ', '\0'}; const auto& e : v)
        s << comma << e, comma[0] = ',';
    return s << "}\n";
}

int main()
{
    // C++11 initializer list syntax:
    std::list<std::string> words1{"the", "frogurt", "is", "also", "cursed"};
    std::cout << "1: " << words1;

    // words2 == words1
    std::list<std::string> words2(words1.begin(), words1.end());
    std::cout << "2: " << words2;

    // words3 == words1
    std::list<std::string> words3(words1);
    std::cout << "3: " << words3;

    // words4 is {"Mo", "Mo", "Mo", "Mo", "Mo"}
    std::list<std::string> words4(5, "Mo");
    std::cout << "4: " << words4;

    const auto rg = {"cat", "cow", "crow"};
#ifdef __cpp_lib_containers_ranges
    std::list<std::string> words5(std::from_range, rg); // overload (6)
#else
    std::list<std::string> words5(rg.begin(), rg.end()); // overload (5)
#endif
    std::cout << "5: " << words5;
}
```

Output:

```text
1: {the, frogurt, is, also, cursed}
2: {the, frogurt, is, also, cursed}
3: {the, frogurt, is, also, cursed}
4: {Mo, Mo, Mo, Mo, Mo}
5: {cat, cow, crow}
```
