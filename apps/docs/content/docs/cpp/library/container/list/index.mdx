{/* source:cpp-container-list:0001 */}
`std::list` is a container that supports constant time insertion and removal of elements from anywhere in the container. Fast random access is not supported. It is usually implemented as a doubly-linked list. Compared to [`std::forward_list`](/docs/cpp/library/container/forward_list) this container provides bidirectional iteration capability while being less space efficient.

{/* source:cpp-container-list:0002 */}
Adding, removing and moving the elements within the list or across several lists does not invalidate the iterators or references. An iterator is invalidated only when the corresponding element is deleted.

{/* source:cpp-container-list:0003 */}
`std::list` meets the requirements of [`Container`](/docs/cpp/library/named_req/Container), [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer), [`SequenceContainer`](/docs/cpp/library/named_req/SequenceContainer) and [`ReversibleContainer`](/docs/cpp/library/named_req/ReversibleContainer).

### Example

{/* source:cpp-container-list:0010 */}
```cpp
#include <algorithm>
#include <iostream>
#include <list>
 
int main()
{
    // Create a list containing integers
    std::list<int> l = {7, 5, 16, 8};
 
    // Add an integer to the front of the list
    l.push_front(25);
    // Add an integer to the back of the list
    l.push_back(13);
 
    // Insert an integer before 16 by searching
    auto it = std::find(l.begin(), l.end(), 16);
    if (it != l.end())
        l.insert(it, 42);
 
    // Print out the list
    std::cout << "l = { ";
    for (int n : l)
        std::cout << n << ", ";
    std::cout << "};\n";
}```

Output:

```text
l = { 25, 7, 5, 42, 16, 8, 13, };```
