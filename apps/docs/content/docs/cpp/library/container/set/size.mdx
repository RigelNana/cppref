{/* source:cpp-container-set-size:0001 */}
<InlineRevision since="C++11" /> Returns the number of elements in the container, i.e. `std::distance(begin(), end())`.

## Parameters

{/* source:cpp-container-set-size:0002 */}
(none)

## Return value

{/* source:cpp-container-set-size:0003 */}
The number of elements in the container.

## Complexity

{/* source:cpp-container-set-size:0004 */}
Constant.

## Example

{/* source:cpp-container-set-size:0005 */}
```cpp
#include <cassert>
#include <set>

int main()
{
    std::set<int> nums{4, 2, 4, 2};
    assert(nums.size() == 2);
}
```
