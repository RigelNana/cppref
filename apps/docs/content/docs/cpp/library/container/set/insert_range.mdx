void insert_range( R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-set-insert-range:0001 */}
Inserts a copy of each element in the range `rg` if and only if there is no element with key equivalent to the key of that element in `*this`.

{/* source:cpp-container-set-insert-range:0002 */}
Each iterator in the range `rg` is dereferenced exactly once. The behavior is undefined if `rg` overlaps with the container.

{/* source:cpp-container-set-insert-range:0003 */}
No iterators or references are invalidated.

### Parameters

{/* source:cpp-container-set-insert-range:0004 */}
<ParameterList>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

**Type requirements**

- [`value_type`](/docs/cpp/library/container/set#Member_types) must be [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `set` from `*ranges::begin(rg)`. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-set-insert-range:0005 */}
(none)

### Complexity

{/* source:cpp-container-set-insert-range:0006 */}
`N·log(a.size() + N)`, where `N` is `ranges::distance(rg)`.

### Example

{/* source:cpp-container-set-insert-range:0008 */}
```cpp
#include <iostream>
#include <set>
 
void println(auto, auto const& container)
{
    for (const auto& elem : container)
        std::cout << elem << ' ';
    std::cout << '\n';
}
 
int main()
{
    auto container = std::set{1, 3, 2, 4};
    const auto rg = {-1, 3, -2};
#ifdef __cpp_lib_containers_ranges
    container.insert_range(rg);
#else
    container.insert(rg.begin(), rg.end());
#endif
    println("{}", container);
}
```

Output:

```text
-2 -1 1 2 3 4
```
