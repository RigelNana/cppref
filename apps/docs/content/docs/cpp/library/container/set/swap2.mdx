{/* source:cpp-container-set-swap2:0001 */}
Specializes the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::set`](/docs/cpp/library/container/set). Swaps the contents of `lhs` and `rhs`. Calls `lhs.swap(rhs)`.

### Parameters

{/* source:cpp-container-set-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">containers whose contents to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-set-swap2:0003 */}
(none)

### Complexity

{/* source:cpp-container-set-swap2:0004 */}
Constant.

### Exceptions

{/* source:cpp-container-set-swap2:0005 */}
<Revision since="C++17">
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(noexcept(lhs.swap(rhs)))`
</Revision>

### Example

{/* source:cpp-container-set-swap2:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <set>
 
int main()
{
    std::set<int> alice{1, 2, 3};
    std::set<int> bob{7, 8, 9, 10};
 
    auto print = [](const int& n) { std::cout << ' ' << n; };
 
    // Print state before swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';
 
    std::cout << "-- SWAP\n";
    std::swap(alice, bob);
 
    // Print state after swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';
}
```

Output:

```text
Alice: 1 2 3
Bobby: 7 8 9 10
-- SWAP
Alice: 7 8 9 10
Bobby: 1 2 3
```
