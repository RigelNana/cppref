{/* source:cpp-container-set-rbegin:0001 */}
<InlineRevision since="C++11" /> Returns a reverse iterator to the first element of the reversed `set`. It corresponds to the last element of the non-reversed `set`. If the `set` is empty, the returned iterator is equal to [`rend()`](/docs/cpp/library/container/set/rend).

### Parameters

{/* source:cpp-container-set-rbegin:0002 */}
(none)

### Return value

{/* source:cpp-container-set-rbegin:0003 */}
Reverse iterator to the first element.

### Complexity

{/* source:cpp-container-set-rbegin:0004 */}
Constant.

### Notes

{/* source:cpp-container-set-rbegin:0005 */}
Because both `iterator` and `const_iterator` are constant iterators (and may in fact be the same type), it is not possible to mutate the elements of the container through an iterator returned by any of these member functions.

{/* source:cpp-container-set-rbegin:0006 */}
The [underlying iterator](/docs/cpp/library/iterator/reverse_iterator/base) of the returned reverse iterator is the [end iterator](/docs/cpp/library/container/set/end). Hence the returned iterator is invalidated if and when the end iterator is invalidated.

{/* source:cpp-container-set-rbegin:0007 */}
libc++ backports `crbegin()` to C++98 mode.

### Example

{/* source:cpp-container-set-rbegin:0008 */}
```cpp
#include <iostream>
#include <set>
 
int main()
{
    std::set<unsigned> rep{1, 2, 3, 4, 1, 2, 3, 4};
 
    for (auto it = rep.crbegin(); it != rep.crend(); ++it)
    {
        for (auto n = *it; n > 0; --n)
            std::cout << "⏼" << ' ';
        std::cout << '\n';
    }
}
```

Output:

```text
⏼ ⏼ ⏼ ⏼
⏼ ⏼ ⏼
⏼ ⏼
⏼
```
