### Return value

{/* source:cpp-container-flat-multiset-operator-cmp:0003 */}
1. 1) `true` if the corresponding comparison yields `true`, `false` otherwise.

{/* source:cpp-container-flat-multiset-operator-cmp:0004 */}
2. 2) Result of three-way comparison on underlying containers.

### Complexity

{/* source:cpp-container-flat-multiset-operator-cmp:0005 */}
1. 1) Constant if `lhs` and `rhs` are of different size, otherwise linear in the size of the `flat_multiset`.

{/* source:cpp-container-flat-multiset-operator-cmp:0006 */}
2. 2) Linear in the size of the container.
