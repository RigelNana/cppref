{/* source:cpp-container-flat-multiset-rbegin:0001 */}
Returns a reverse iterator to the first element of the reversed `flat_multiset`. It corresponds to the last element of the non-reversed `flat_multiset`. If the `flat_multiset` is empty, the returned iterator is equal to `rend()`.

### Parameters

{/* source:cpp-container-flat-multiset-rbegin:0002 */}
(none)

### Return value

{/* source:cpp-container-flat-multiset-rbegin:0003 */}
Reverse iterator to the first element.

### Complexity

{/* source:cpp-container-flat-multiset-rbegin:0004 */}
Constant.

### Notes

{/* source:cpp-container-flat-multiset-rbegin:0005 */}
Because both `iterator` and `const_iterator` are constant iterators (and may in fact be the same type), it is not possible to mutate the elements of the container through an iterator returned by any of these member functions.

{/* source:cpp-container-flat-multiset-rbegin:0006 */}
The [underlying iterator](/docs/cpp/library/iterator/reverse_iterator/base) of the returned reverse iterator is the [end iterator](/docs/cpp/library/container/flat_multiset/end). Hence the returned iterator is invalidated if and when the end iterator is invalidated.

### Example

{/* source:cpp-container-flat-multiset-rbegin:0007 */}
```cpp
#include <iostream>
#include <flat_set>

int main()
{
    std::flat_multiset<unsigned> rep{1, 2, 3, 4, 1, 2, 3, 4};

    for (auto it = rep.crbegin(); it != rep.crend(); ++it)
    {
        for (auto n = *it; n > 0; --n)
            std::cout << "⏼" << ' ';
        std::cout << '\n';
    }
}
```

Output:

```text
⏼ ⏼ ⏼ ⏼
⏼ ⏼ ⏼ ⏼
⏼ ⏼ ⏼
⏼ ⏼ ⏼
⏼ ⏼
⏼ ⏼
⏼
⏼
```
