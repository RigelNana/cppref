{/* source:cpp-container-flat-multiset-flat-multiset:0001 */}
Constructs new container adaptor from a variety of data sources and optionally provided comparison function object `comp` and/or allocator `alloc`.

{/* source:cpp-container-flat-multiset-flat-multiset:0002 */}
1. 1) A default constructor. Constructs an empty container adaptor.

{/* source:cpp-container-flat-multiset-flat-multiset:0003 */}
2. 2) A [copy constructor](/docs/cpp/language/classes/copy_constructor). Constructs [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) with the copy of the contents of `other.c` and [`compare`](/docs/cpp/library/container/flat_multiset#Member_objects) with `other.compare`. See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0004 */}
3. 3) A [move constructor](/docs/cpp/language/classes/move_constructor). Constructs the container adaptor with the contents of `other` using move semantics. See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0005 */}
4. 4) Constructs the underlying container with the contents of the container `cont`. First, initializes [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) with `std::move(cont)` and [`compare`](/docs/cpp/library/container/flat_multiset#Member_objects) with `comp`. Then sorts the [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) with respect to `comp`.

{/* source:cpp-container-flat-multiset-flat-multiset:0006 */}
5. 5) Same as (4), equivalent to `flat_multiset(cont);`. See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0007 */}
6. 6) Same as (4), equivalent to `flat_multiset(cont, comp);`. See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0008 */}
7. 7) Constructs the underlying container with the contents of the other container `cont`. Initializes [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) with `std::move(cont)` and [`compare`](/docs/cpp/library/container/flat_multiset#Member_objects) with `comp`.

{/* source:cpp-container-flat-multiset-flat-multiset:0009 */}
8. 8) Same as (7), equivalent to `flat_multiset(s, cont);`. See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0010 */}
9. 9) Same as (7), equivalent to `flat_multiset(s, cont, comp);`. See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0011 */}
10. 10) Constructs an empty container adaptor.

{/* source:cpp-container-flat-multiset-flat-multiset:0012 */}
11. 11,12) Constructs an empty container adaptor. See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0013 */}
12. 13) Constructs the container adaptor with the contents of the range [`first`, `last`), equivalent to `insert(first, last);`.

{/* source:cpp-container-flat-multiset-flat-multiset:0014 */}
13. 14,15) Same as (13). See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0015 */}
14. 16) Constructs the container adaptor with the contents of the range `rg`. First, uses (10) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor). Then initializes [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) with the contents of `rg` as if by `insert_range(std::forward<R>(rg));`.

{/* source:cpp-container-flat-multiset-flat-multiset:0016 */}
15. 17) Same as (16) using it as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-multiset-flat-multiset:0017 */}
16. 18,19) Same as (16). See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0018 */}
17. 20) Constructs the underlying container with the contents of the range [`first`, `last`). Initializes [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) with `c(first, last)` and [`compare`](/docs/cpp/library/container/flat_multiset#Member_objects) with `compare(comp)`.

{/* source:cpp-container-flat-multiset-flat-multiset:0019 */}
18. 21,22) Same as (20). See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0020 */}
19. 23) An [initializer-list constructor](/docs/cpp/language/initialization/list_initialization). Constructs the underlying container with the contents of the initializer list `init`, using (13) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-multiset-flat-multiset:0021 */}
20. 24,25) Same as (23). See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0022 */}
21. 26) An [initializer-list constructor](/docs/cpp/language/initialization/list_initialization). Constructs the underlying container with the contents of the initializer list `init`, using (20) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-multiset-flat-multiset:0023 */}
22. 27,28) Save as (26). See [allocator usage note](/docs/cpp/library/container/flat_multiset/flat_multiset#Allocator_usage_note) below.

{/* source:cpp-container-flat-multiset-flat-multiset:0024 */}
Note for overloads (13-15,20-22): If [`first`, `last`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

##### Allocator usage note

{/* source:cpp-container-flat-multiset-flat-multiset:0025 */}
The constructors (2,3,5,6,8,9,11,12,14,15,17,19,21,22,24,25,27,28) are equivalent to the corresponding non-allocator constructors except that [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) is constructed with [uses-allocator construction](/docs/cpp/library/memory/uses_allocator#Uses-allocator_construction). These overloads participate in overload resolution only if `std::uses_allocator_v<container_type, Allocator>` is `true`.

### Parameters

{/* source:cpp-container-flat-multiset-flat-multiset:0026 */}
<ParameterList>
  <Parameter name="cont">a container to be used as source to initialize the underlying container</Parameter>
  <Parameter name="other">another `flat_multiset` to be used as source to initialize the elements of the underlying container with</Parameter>
  <Parameter name="alloc">an allocator to use for all memory allocations of the underlying container</Parameter>
  <Parameter name="comp">a function object to be used for all comparisons of keys</Parameter>
  <Parameter name="first, last">a range to copy the elements from</Parameter>
  <Parameter name="init">an initializer list to initialize the elements of the underlying container with</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range) (that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to [`value_type`](/docs/cpp/library/container/flat_multiset#Member_types)) to be used as source to initialize the underlying container</Parameter>
  <Parameter name="fr">a [disambiguation tag](/docs/cpp/library/ranges/from_range) that indicates that the contained member should be range constructed</Parameter>
  <Parameter name="s">a [disambiguation tag](/docs/cpp/library/container/sorted_equivalent) that indicates that the input sequence is sorted with respect to [`compare`](/docs/cpp/library/container/flat_multiset#Member_objects)</Parameter>
</ParameterList>

**Type requirements**

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `Compare` must meet the requirements of [*Compare*](/docs/cpp/library/named_req/Compare).
- `Allocator` must meet the requirements of [*Allocator*](/docs/cpp/library/named_req/Allocator).

### Complexity

{/* source:cpp-container-flat-multiset-flat-multiset:0027 */}
1. 1) Constant.

{/* source:cpp-container-flat-multiset-flat-multiset:0028 */}
2. 2) Linear in size of `other`.

{/* source:cpp-container-flat-multiset-flat-multiset:0029 */}
3. 3) Same as the corresponding move-constructor of the wrapped container, i.e. constant or linear in size of `cont`.

{/* source:cpp-container-flat-multiset-flat-multiset:0030 */}
4. 4-6) Linear in N if `cont` is sorted with respect to `compare`, otherwise 𝓞(N·log(N)), where N is the value of `cont.size()` before this call.

{/* source:cpp-container-flat-multiset-flat-multiset:0031 */}
5. 7-9) Same as the corresponding move-constructor of the wrapped container, i.e. constant or linear in size of `cont`.

{/* source:cpp-container-flat-multiset-flat-multiset:0032 */}
6. 10-12) Constant.

{/* source:cpp-container-flat-multiset-flat-multiset:0033 */}
7. 13-15) Linear in N if the input range [`first`, `last`) is sorted with respect to `compare`, otherwise 𝓞(N·log(N)), where N is the value of `cont.size()` before this call.

{/* source:cpp-container-flat-multiset-flat-multiset:0034 */}
8. 16-19) Linear in N if the input range `rg` is sorted with respect to `compare`, otherwise 𝓞(N·log(N)), where N is the value of `cont.size()` before this call.

{/* source:cpp-container-flat-multiset-flat-multiset:0035 */}
9. 20-22) Linear in size of [`first`, `last`).

{/* source:cpp-container-flat-multiset-flat-multiset:0036 */}
10. 23-25) Linear in N if the elements of `init` are sorted with respect to `compare`, otherwise 𝓞(N·log(N)), where N is the value of `cont.size()` before this call.

{/* source:cpp-container-flat-multiset-flat-multiset:0037 */}
11. 26-28) Linear in size of `init`.

### Exceptions

{/* source:cpp-container-flat-multiset-flat-multiset:0038 */}
Calls to `Allocator::allocate` may throw.

### Notes

{/* source:cpp-container-flat-multiset-flat-multiset:0039 */}
After container move construction (overload (3,16-19)), references, pointers, and iterators (other than the end iterator) to `other` remain valid, but refer to elements that are now in `*this`. The current standard makes this guarantee via the blanket statement in [[container.reqmts]/67](https://eel.is/c++draft/container.reqmts#67), and a more direct guarantee is under consideration via [LWG issue 2321](https://cplusplus.github.io/LWG/issue2321).
