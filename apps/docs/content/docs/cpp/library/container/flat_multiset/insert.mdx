{/* source:cpp-container-flat-multiset-insert:0001 */}
Inserts element(s) into the container. The order of the remaining equivalent elements is preserved.

{/* source:cpp-container-flat-multiset-insert:0002 */}
1. Inserts `value`. If the container has elements with equivalent key, inserts at the upper bound of that range. Equivalent to `return emplace(value);`.

{/* source:cpp-container-flat-multiset-insert:0003 */}
2. Inserts `value`. If the container has elements with equivalent key, inserts at the upper bound of that range. Equivalent to `return emplace(std::move(value));`.

{/* source:cpp-container-flat-multiset-insert:0004 */}
3. Inserts `value` in the position as close as possible to the position just prior to `pos`. Equivalent to `return emplace_hint(pos, value);`.

{/* source:cpp-container-flat-multiset-insert:0005 */}
4. Inserts `value` in the position as close as possible to the position just prior to `pos`. Equivalent to `return emplace_hint(pos, std::move(value));`.

{/* source:cpp-container-flat-multiset-insert:0006 */}
5. Inserts elements from range [`first`, `last`) as if performing the following operations sequentially:
   1. Adds elements to [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) as if by `c.insert(c.end(), first, last);`.
   2. Sorts the range of newly inserted elements with respect to [`compare`](/docs/cpp/library/container/flat_multiset#Member_objects).
   3. Merges the resulting sorted range and the sorted range of pre-existing elements into a single sorted range.

{/* source:cpp-container-flat-multiset-insert:0007 */}
May allocate memory during the in-place merge stage.

{/* source:cpp-container-flat-multiset-insert:0008 */}
6. Inserts elements from range [`first`, `last`). Equivalent to `insert(first, last);`.

{/* source:cpp-container-flat-multiset-insert:0009 */}
7. Inserts elements from initializer list `ilist`. Equivalent to `insert(ilist.begin(), ilist.end());`.

{/* source:cpp-container-flat-multiset-insert:0010 */}
8. Inserts elements from initializer list `ilist`. Equivalent to `insert(s, ilist.begin(), ilist.end());`.

{/* source:cpp-container-flat-multiset-insert:0011 */}
Information on iterator invalidation is copied from [here](/docs/Template:cpp/container/note-iterator-invalidation).

### Parameters

{/* source:cpp-container-flat-multiset-insert:0012 */}
<ParameterList>
  <Parameter name="pos">iterator to the position before which the new element will be inserted</Parameter>
  <Parameter name="value">element value to insert</Parameter>
  <Parameter name="first, last">range of elements to insert</Parameter>
  <Parameter name="ilist">initializer list to insert the values from</Parameter>
  <Parameter name="s">a disambiguation tag indicating that the input sequence is sorted (with respect to [`key_compare`](/docs/cpp/library/container/flat_multiset#Member_objects))</Parameter>
</ParameterList>

Type requirements: `InputIt` must meet the requirements of [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

### Return value

{/* source:cpp-container-flat-multiset-insert:0013 */}
1-4. An iterator to the inserted element.

{/* source:cpp-container-flat-multiset-insert:0014 */}
5-8. (none)

### Complexity

{/* source:cpp-container-flat-multiset-insert:0018 */}
1-4. Linear.

{/* source:cpp-container-flat-multiset-insert:0019 */}
5. `N + M·log(M)`, where `N` is the [`size()`](/docs/cpp/library/container/flat_multiset/size) before the operation and `M` is `std::distance(first, last)`.

{/* source:cpp-container-flat-multiset-insert:0020 */}
6. Linear.

{/* source:cpp-container-flat-multiset-insert:0021 */}
7. `N + M·log(M)`, where `N` is the [`size()`](/docs/cpp/library/container/flat_multiset/size) before the operation and `M` is `ilist.size()`.

{/* source:cpp-container-flat-multiset-insert:0022 */}
8. Linear.
