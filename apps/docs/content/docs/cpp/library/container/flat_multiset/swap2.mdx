Specializes the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for `std::flat_multiset`. Swaps the contents of `lhs` and `rhs`. Calls `lhs.swap(rhs)`.

### Parameters

{/* source:cpp-container-flat-multiset-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">containers whose contents to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-flat-multiset-swap2:0003 */}
(none)

### Complexity

{/* source:cpp-container-flat-multiset-swap2:0004 */}
Same as swapping the underlying containers.

### Example

{/* source:cpp-container-flat-multiset-swap2:0005 */}
```cpp
#include <algorithm>
#include <iostream>
#include <flat_set>

int main()
{
    std::flat_multiset<int> alice{1, 2, 3};
    std::flat_multiset<int> bob{7, 8, 9, 10};

    auto print = [](const int& n) { std::cout << ' ' << n; };

    // Print state before swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';

    std::cout << "-- SWAP\n";
    std::swap(alice, bob);

    // Print state after swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';
}
```

Output:

```text
Alice: 1 2 3
Bobby: 7 8 9 10
-- SWAP
Alice: 7 8 9 10
Bobby: 1 2 3
```
