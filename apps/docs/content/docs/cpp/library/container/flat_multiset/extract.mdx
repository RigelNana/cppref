{/* source:cpp-container-flat-multiset-extract:0001 */}
Extracts adapted container [`c`](/docs/cpp/library/container/flat_multiset#Member_objects). Equivalent to `return std::move(c);`.

{/* source:cpp-container-flat-multiset-extract:0002 */}
After this operation `*this` is empty, even if an exception is thrown.

### Parameters

{/* source:cpp-container-flat-multiset-extract:0003 */}
(none)

### Return value

{/* source:cpp-container-flat-multiset-extract:0004 */}
`std::move(c)`.

### Complexity

{/* source:cpp-container-flat-multiset-extract:0005 */}
Constant.

### Example

{/* source:cpp-container-flat-multiset-extract:0006 */}
```cpp
#include <cassert>
#include <flat_set>
#include <print>
#include <type_traits>
#include <vector>

int main()
{
    std::flat_multiset<int> set{1, 2, 3};
    const auto size = set.size();

    auto c = set.extract();
    assert(c.size() == size);
    assert(set.empty());
    assert(set.keys().empty());
    assert(set.values().empty());

    // The default keys container is std::vector:
    static_assert(std::is_same_v<decltype(c), std::vector<int>>);

    std::println("{}", c);
}
```

Output:

```text
[1, 2, 3]
```
