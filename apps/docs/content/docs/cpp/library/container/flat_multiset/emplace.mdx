{/* source:cpp-container-flat-multiset-emplace:0001 */}
Inserts a new element into the container constructed in-place with the given `args`.

{/* source:cpp-container-flat-multiset-emplace:0002 */}
```cpp
auto it = ranges::upper_bound(c, t, compare);
c.insert(it, std::move(t));
```

{/* source:cpp-container-flat-multiset-emplace:0003 */}
This overload participates in overload resolution only if `std::is_constructible_v<value_type, Args...>` is `true`.

{/* source:cpp-container-flat-multiset-emplace:0004 */}
Careful use of emplace allows the new element to be constructed while avoiding unnecessary copy or move operations.

{/* source:cpp-container-flat-multiset-emplace:0005 */}
Information on iterator invalidation is copied from [here](/docs/Template:cpp/container/note-iterator-invalidation).

### Exceptions

{/* source:cpp-container-flat-multiset-emplace:0008 */}

{/* source:cpp-container-flat-multiset-emplace:0009 */}
