<DeclarationDoc since="C++23">
  <Declaration language="cpp" code={`template< container-compatible-range<value_type> R >
void insert_range( R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-flat-multiset-insert-range:0001 */}
Inserts a copy of each element in the range `rg` into underlying container [`c`](/docs/cpp/library/container/flat_multiset#Member_objects) as if by:

{/* source:cpp-container-flat-multiset-insert-range:0002 */}
```cpp
for (const auto& e : rg)
    c.insert(c.end(), e);
```

{/* source:cpp-container-flat-multiset-insert-range:0003 */}
Then, sorts the range of newly inserted elements with respect to `compare`. Merges the resulting sorted range and the sorted range of pre-existing elements into a single sorted range.

{/* source:cpp-container-flat-multiset-insert-range:0004 */}
Each iterator in the range `rg` is dereferenced exactly once. The behavior is undefined if `rg` overlaps with the container.

{/* source:cpp-container-flat-multiset-insert-range:0005 */}
Information on iterator invalidation is copied from [here](/docs/Template:cpp/container/note-iterator-invalidation)

### Parameters

{/* source:cpp-container-flat-multiset-insert-range:0006 */}
<ParameterList>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-flat-multiset-insert-range:0007 */}
(none)

### Complexity

{/* source:cpp-container-flat-multiset-insert-range:0008 */}
`N + M·log(M)`, where N is `size()` before the operation and M is [`ranges::distance(rg)`](/docs/cpp/library/iterator/ranges/distance).

### Notes

{/* source:cpp-container-flat-multiset-insert-range:0009 */}
Since `insert_range` performs an in-place merge operation, that may allocate memory.

### Example

{/* source:cpp-container-flat-multiset-insert-range:0010 */}
```cpp
#include <iostream>
#include <flat_set>

void println(auto, auto const& container)
{
    for (const auto& elem : container)
        std::cout << elem << ' ';
    std::cout << '\n';
}

int main()
{
    auto container = std::flat_multiset{1, 3, 2, 4};
    const auto rg = {-1, 3, -2};

#ifdef __cpp_lib_containers_ranges
    container.insert_range(rg);
#else
    container.insert(rg.begin(), rg.end());
#endif
    println("{}", container);
}
```

Output:

```text
-2 -1 1 2 3 3 4
```
