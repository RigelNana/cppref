  <Declaration language="cpp" code={`void replace( container_type&& cont );`} />

{/* source:cpp-container-flat-multiset-replace:0001 */}
Replaces the underlying container [`c`](/docs/cpp/library/container/flat_multiset#Member_objects). Equivalent to: `c = std::move(cont);`.

{/* source:cpp-container-flat-multiset-replace:0002 */}
The elements of `cont` must be sorted with respect to [`compare`](/docs/cpp/library/container/flat_multiset#Member_objects). Otherwise, the behavior is undefined.

### Parameters

{/* source:cpp-container-flat-multiset-replace:0003 */}
<ParameterList>
  <Parameter name="cont">
    a sorted container of type `KeyContainer`, the contents of which will be moved into `*this`
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-flat-multiset-replace:0004 */}
(none)

### Complexity

{/* source:cpp-container-flat-multiset-replace:0005 */}
Equals to complexity of [`std::move`](/docs/cpp/library/utility/move) applied to adapted container.

### Example

{/* source:cpp-container-flat-multiset-replace:0006 */}
```cpp
#include <algorithm>
#include <cassert>
#include <flat_set>
#include <print>
#include <vector>

int main()
{
    std::vector<int> keys{1, 2, 3};
    assert(std::ranges::is_sorted(keys));

    std::flat_multiset<int> set;
    assert(set.empty());

    set.replace(keys);
    assert(set.size() == 3);
    assert(keys.empty());

    std::println("{}", set); // set.keys()
}
```

Output:

```text
[1, 2, 3]
```
