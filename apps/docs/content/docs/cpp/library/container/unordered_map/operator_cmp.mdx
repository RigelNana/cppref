{/* source:cpp-container-unordered-map-operator-cmp:0001 */}
Compares the contents of two unordered containers.

{/* source:cpp-container-unordered-map-operator-cmp:0002 */}
The contents of two unordered containers `lhs` and `rhs` are equal if the following conditions hold:

{/* source:cpp-container-unordered-map-operator-cmp:0003 */}
- `lhs.size() == rhs.size()`.
- each group of equivalent elements `[lhs_eq1, lhs_eq2)` obtained from `lhs.equal_range(lhs_eq1)` has a corresponding group of equivalent elements in the other container `[rhs_eq1, rhs_eq2)` obtained from `rhs.equal_range(rhs_eq1)`, that has the following properties:

  {/* source:cpp-container-unordered-map-operator-cmp:0004 */}
  - `std::distance(lhs_eq1, lhs_eq2) == std::distance(rhs_eq1, rhs_eq2)`.
  - `std::is_permutation(lhs_eq1, lhs_eq2, rhs_eq1) == true`.

{/* source:cpp-container-unordered-map-operator-cmp:0005 */}
The behavior is undefined if `Key` or `T` are not [EqualityComparable](/docs/cpp/library/named_req/EqualityComparable).

{/* source:cpp-container-unordered-map-operator-cmp:0006 */}
The behavior is also undefined if <InlineRevision until="C++20">`hash_function()` and `key_eq()` do</InlineRevision><InlineRevision since="C++20">`key_eq()` does</InlineRevision> not have the same behavior on `lhs` and `rhs` or if `operator==` for `Key` is not a refinement of the partition into equivalent-key groups introduced by `key_eq()` (that is, if two elements that compare equal using `operator==` fall into different partitions).

{/* source:cpp-container-unordered-map-operator-cmp:0007 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Return value

{/* source:cpp-container-unordered-map-operator-cmp:0009 */}
- 1) `true` if the contents of the containers are equal, `false` otherwise.

{/* source:cpp-container-unordered-map-operator-cmp:0010 */}
- 2) `true` if the contents of the containers are not equal, `false` otherwise.

### Complexity

{/* source:cpp-container-unordered-map-operator-cmp:0011 */}
Proportional to *N* calls to `operator==` on `value_type`, calls to the predicate returned by [`key_eq`](/docs/cpp/library/container/unordered_map/key_eq), and calls to the hasher returned by [`hash_function`](/docs/cpp/library/container/unordered_map/hash_function), in the average case, proportional to *N2* in the worst case where *N* is the size of the container.
