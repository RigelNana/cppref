{/* source:cpp-container-unordered-map-max-load-factor:0001 */}
Manages the maximum load factor (number of elements per bucket). The container automatically increases the number of buckets if the load factor exceeds this threshold.

{/* source:cpp-container-unordered-map-max-load-factor:0002 */}
- 1) Returns current maximum load factor.

{/* source:cpp-container-unordered-map-max-load-factor:0003 */}
- 2) Sets the maximum load factor to `ml`.

### Parameters

{/* source:cpp-container-unordered-map-max-load-factor:0004 */}
<ParameterList>
  <Parameter name="ml">new maximum load factor setting</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-unordered-map-max-load-factor:0005 */}
- 1) Current maximum load factor.

{/* source:cpp-container-unordered-map-max-load-factor:0006 */}
- 2) (none)
