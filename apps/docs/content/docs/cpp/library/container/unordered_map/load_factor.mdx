Returns the average number of elements per bucket, that is, [`size()`](/docs/cpp/library/container/unordered_map/size) divided by [`bucket_count()`](/docs/cpp/library/container/unordered_map/bucket_count).

### Parameters

{/* source:cpp-container-unordered-map-load-factor:0002 */}
(none)

### Return value

{/* source:cpp-container-unordered-map-load-factor:0003 */}
Average number of elements per bucket.

### Complexity

{/* source:cpp-container-unordered-map-load-factor:0004 */}
