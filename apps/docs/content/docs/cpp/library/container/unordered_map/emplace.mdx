{/* source:cpp-container-unordered-map-emplace:0001 */}
Inserts a new element into the container constructed in-place with the given `args`, if there is no element with the key in the container.

{/* source:cpp-container-unordered-map-emplace:0002 */}
The constructor of the new element (i.e. `std::pair<const Key, T>`) is called with exactly the same arguments as supplied to `emplace`, forwarded via `std::forward<Args>(args)...`. The element may be constructed even if there already is an element with the key in the container, in which case the newly constructed element will be destroyed immediately (see [`try_emplace()`](/docs/cpp/library/container/unordered_map/try_emplace) if this behavior is undesirable).

{/* source:cpp-container-unordered-map-emplace:0003 */}
Careful use of `emplace` allows the new element to be constructed while avoiding unnecessary copy or move operations.

{/* source:cpp-container-unordered-map-emplace:0004 */}
If after the operation the new number of elements is greater than old [`max_load_factor()`](/docs/cpp/library/container/unordered_map/max_load_factor) * [`bucket_count()`](/docs/cpp/library/container/unordered_map/bucket_count) a rehashing takes place.
If rehashing occurs (due to the insertion), all iterators are invalidated. Otherwise (no rehashing), iterators are not invalidated.

### Parameters

{/* source:cpp-container-unordered-map-emplace:0005 */}
<ParameterList>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-unordered-map-emplace:0006 */}
A pair consisting of an iterator to the inserted element (or to the element that prevented the insertion) and a `bool` value set to `true` if and only if the insertion took place.

### Exceptions

{/* source:cpp-container-unordered-map-emplace:0007 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-container-unordered-map-emplace:0008 */}
Amortized constant on average, worst case linear in the size of the container.

### Example

{/* source:cpp-container-unordered-map-emplace:0009 */}
```cpp
#include <iostream>
#include <string>
#include <utility>
#include <unordered_map>

int main()
{
    std::unordered_map<std::string, std::string> m;

    // uses pair's move constructor
    m.emplace(std::make_pair(std::string("a"), std::string("a")));

    // uses pair's converting move constructor
    m.emplace(std::make_pair("b", "abcd"));

    // uses pair's template constructor
    m.emplace("d", "ddd");

    // emplace with duplicate key has no effect
    m.emplace("d", "DDD");

    // uses pair's piecewise constructor
    m.emplace(std::piecewise_construct,
              std::forward_as_tuple("c"),
              std::forward_as_tuple(10, 'c'));
    // an alternative is: m.try_emplace("c", 10, 'c');

    for (const auto& p : m)
        std::cout << p.first << " => " << p.second << '\n';
}
```

Possible output:

```text
a => a
b => abcd
c => cccccccccc
d => ddd
```
