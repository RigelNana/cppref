{/* source:cpp-container-unordered-map-clear:0001 */}
Erases all elements from the container. After this call, [`size()`](/docs/cpp/library/container/unordered_map/size) returns zero.

{/* source:cpp-container-unordered-map-clear:0002 */}
Invalidates any references, pointers, and iterators referring to contained elements. May also invalidate past-the-end iterators.

### Parameters

{/* source:cpp-container-unordered-map-clear:0003 */}
(none)

### Return value

{/* source:cpp-container-unordered-map-clear:0004 */}
(none)

### Complexity

{/* source:cpp-container-unordered-map-clear:0005 */}
Linear in the size of the container, i.e., the number of elements.

### Example

{/* source:cpp-container-unordered-map-clear:0006 */}
```cpp
#include <iostream>
#include <string_view>
#include <unordered_map>

void print_info(std::string_view rem, const std::unordered_map<int, char>& v)
{
    std::cout << rem << "{ ";
    for (const auto& [key, value] : v)
        std::cout << '[' << key << "]:" << value << ' ';
    std::cout << "}\n";
    std::cout << "Size=" << v.size() << '\n';
}

int main()
{
    std::unordered_map<int, char> container{{1, 'x'}, {2, 'y'}, {3, 'z'}};
    print_info("Before clear: ", container);
    container.clear();
    print_info("After clear: ", container);
}
```

Possible output:

```text
Before clear: { [1]:x [2]:y [3]:z }
Size=3
After clear: { }
Size=0
```
