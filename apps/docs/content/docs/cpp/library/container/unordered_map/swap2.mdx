Specializes the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::unordered_map`](/docs/cpp/library/container/unordered_map). Swaps the contents of `lhs` and `rhs`. Calls `lhs.swap(rhs)`.

### Parameters

{/* source:cpp-container-unordered-map-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">containers whose contents to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-unordered-map-swap2:0003 */}
(none)

### Complexity

Constant.

### Example

{/* source:cpp-container-unordered-map-swap2:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <unordered_map>

int main()
{
    std::unordered_map<int, char> alice{{1, 'a'}, {2, 'b'}, {3, 'c'}};
    std::unordered_map<int, char> bob{{7, 'Z'}, {8, 'Y'}, {9, 'X'}, {10, 'W'}};

    auto print = [](std::pair<const int, char>& n)
    {
        std::cout << ' ' << n.first << ':' << n.second;
    };

    // Print state before swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';

    std::cout << "-- SWAP\n";
    std::swap(alice, bob);

    // Print state after swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';
}
```

Possible output:

```text
Alice: 1:a 2:b 3:c
Bobby: 7:Z 8:Y 9:X 10:W
-- SWAP
Alice: 7:Z 8:Y 9:X 10:W
Bobby: 1:a 2:b 3:c
```
