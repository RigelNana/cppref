{/* source:cpp-container-unordered-map-try-emplace:0001 */}
If a key equivalent to `k` already exists in the container, does nothing. Otherwise, inserts a new element into the container with key `k` and value constructed with `args`. In such case:

{/* source:cpp-container-unordered-map-try-emplace:0002 */}
- 1) Behaves like [`emplace`](/docs/cpp/library/container/unordered_map/emplace) except that the element is constructed as `value_type(std::piecewise_construct, std::forward_as_tuple(k), std::forward_as_tuple(std::forward<Args>(args)...))`.

{/* source:cpp-container-unordered-map-try-emplace:0003 */}
- 2) Behaves like [`emplace`](/docs/cpp/library/container/unordered_map/emplace) except that the element is constructed as `value_type(std::piecewise_construct, std::forward_as_tuple(std::move(k)), std::forward_as_tuple(std::forward<Args>(args)...))`.

{/* source:cpp-container-unordered-map-try-emplace:0004 */}
- 3) Behaves like [`emplace`](/docs/cpp/library/container/unordered_map/emplace) except that the element is constructed as `value_type(std::piecewise_construct, std::forward_as_tuple(std::forward<K>(k)), std::forward_as_tuple(std::forward<Args>(args)...))`.

{/* source:cpp-container-unordered-map-try-emplace:0005 */}
- 4) Behaves like [`emplace_hint`](/docs/cpp/library/container/unordered_map/emplace_hint) except that the element is constructed as `value_type(std::piecewise_construct, std::forward_as_tuple(k), std::forward_as_tuple(std::forward<Args>(args)...))`.

{/* source:cpp-container-unordered-map-try-emplace:0006 */}
- 5) Behaves like [`emplace_hint`](/docs/cpp/library/container/unordered_map/emplace_hint) except that the element is constructed as `value_type(std::piecewise_construct, std::forward_as_tuple(std::move(k)), std::forward_as_tuple(std::forward<Args>(args)...))`.

{/* source:cpp-container-unordered-map-try-emplace:0007 */}
- 6) Behaves like [`emplace_hint`](/docs/cpp/library/container/unordered_map/emplace_hint) except that the element is constructed as `value_type(std::piecewise_construct, std::forward_as_tuple(std::forward<K>(k)), std::forward_as_tuple(std::forward<Args>(args)...))`.

{/* source:cpp-container-unordered-map-try-emplace:0008 */}
- 1-6) If `value_type` is not [`EmplaceConstructible`](/docs/cpp/library/named_req/EmplaceConstructible) into `unordered_map` from the corresponding expression, the behavior is undefined.

{/* source:cpp-container-unordered-map-try-emplace:0009 */}
- 3) This overload participates in overload resolution only if all following conditions are satisfied: `std::is_convertible_v<K&&, const_iterator>` and `std::is_convertible_v<K&&, iterator>` are both `false`. `Hash::is_transparent` and `KeyEqual::is_transparent` are valid and each denotes a type.

{/* source:cpp-container-unordered-map-try-emplace:0010 */}
- If `hash_function()(u.first) != hash_function()(k) || contains(u.first)` is `true`, the behavior is undefined, where `u` is the new element to be inserted.

{/* source:cpp-container-unordered-map-try-emplace:0011 */}
- 6) This overload participates in overload resolution only if `Hash::is_transparent` and `KeyEqual::is_transparent` are both valid and each denotes a type.

{/* source:cpp-container-unordered-map-try-emplace:0012 */}
- If `hash_function()(u.first) != hash_function()(k) || contains(u.first)` is `true`, the behavior is undefined, where `u` is the new element to be inserted.

{/* source:cpp-container-unordered-map-try-emplace:0013 */}
If after the operation the new number of elements is greater than old [`max_load_factor()`](/docs/cpp/library/container/unordered_map/max_load_factor) `*` [`bucket_count()`](/docs/cpp/library/container/unordered_map/bucket_count) a rehashing takes place. If rehashing occurs (due to the insertion), all iterators are invalidated. Otherwise (no rehashing), iterators are not invalidated.

### Return value

{/* source:cpp-container-unordered-map-try-emplace:0015 */}
- 1-3) Same as for [`emplace`](/docs/cpp/library/container/unordered_map/emplace): A pair consisting of an iterator to the inserted element (or to the element that prevented the insertion) and a `bool` value set to `true` if and only if the insertion took place.

{/* source:cpp-container-unordered-map-try-emplace:0016 */}
- 4-6) Same as for [`emplace_hint`](/docs/cpp/library/container/unordered_map/emplace_hint): An iterator to the inserted element, or to the element that prevented the insertion.

### Complexity

{/* source:cpp-container-unordered-map-try-emplace:0017 */}
- 1-3) Same as for [`emplace`](/docs/cpp/library/container/unordered_map/emplace): Amortized constant on average, worst case linear in the size of the container.

{/* source:cpp-container-unordered-map-try-emplace:0018 */}
- 4-6) Same as for [`emplace_hint`](/docs/cpp/library/container/unordered_map/emplace_hint): Amortized constant on average, worst case linear in the size of the container.

### Notes

{/* source:cpp-container-unordered-map-try-emplace:0019 */}
Unlike [`insert`](/docs/cpp/library/container/unordered_map/insert) or [`emplace`](/docs/cpp/library/container/unordered_map/emplace), these functions do not move from rvalue arguments if the insertion does not happen, which makes it easy to manipulate maps whose values are move-only types, such as `std::unordered_map<std::string, std::unique_ptr<foo>>`. In addition, `try_emplace` treats the key and the arguments to the `mapped_type` separately, unlike [`emplace`](/docs/cpp/library/container/unordered_map/emplace), which requires the arguments to construct a `value_type` (that is, a [`std::pair`](/docs/cpp/library/utility/pair)).

{/* source:cpp-container-unordered-map-try-emplace:0020 */}
Overloads (3,6) can be called without constructing an object of type `Key`.

### Example

{/* source:cpp-container-unordered-map-try-emplace:0022 */}
```cpp
#include <iostream>
#include <string>
#include <unordered_map>
#include <utility>

void print_node(const auto& node)
{
    std::cout << '[' << node.first << "] = " << node.second << '\n';
}

void print_result(auto const& pair)
{
    std::cout << (pair.second ? "inserted: " : "ignored:  ");
    print_node(*pair.first);
}

int main()
{
    using namespace std::literals;
    std::unordered_map<std::string, std::string> m;

    print_result(m.try_emplace("a", "a"s));
    print_result(m.try_emplace("b", "abcd"));
    print_result(m.try_emplace("c", 10, 'c'));
    print_result(m.try_emplace("c", "Won't be inserted"));

    for (const auto& p : m)
        print_node(p);
}
```

Possible output:

```text
inserted: [a] = a
inserted: [b] = abcd
inserted: [c] = cccccccccc
ignored:  [c] = cccccccccc
[a] = a
[b] = abcd
[c] = cccccccccc
```
