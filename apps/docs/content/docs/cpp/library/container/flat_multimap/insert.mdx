Inserts element(s) into the container.

{/* source:cpp-container-flat-multimap-insert:0002 */}
- 1) Inserts `value`. Equivalent to `return emplace(value);`.

{/* source:cpp-container-flat-multimap-insert:0003 */}
- 2) Inserts `value`. Equivalent to `return emplace(std::move(value));`.

{/* source:cpp-container-flat-multimap-insert:0004 */}
- 3) Inserts `value` in the position as close as possible to the position just prior to `pos`. Equivalent to `return emplace_hint(pos, value);`.

{/* source:cpp-container-flat-multimap-insert:0005 */}
- 4) Inserts `value` in the position as close as possible to the position just prior to `pos`. Equivalent to `return emplace_hint(pos, std::move(value));`.

{/* source:cpp-container-flat-multimap-insert:0006 */}
- 5) Inserts `x` into `*this` as if by `emplace(std::forward<P>(x));`. This overload participates in overload resolution only if `std::is_constructible_v<pair<key_type, mapped_type>, P>` is `true`.

{/* source:cpp-container-flat-multimap-insert:0007 */}
- 6) Inserts `x` into `*this` in the position as close as possible to the position just prior to `pos`. Equivalent to `return emplace_hint(position, std::forward<P>(x));`. This overload participates in overload resolution only if `std::is_constructible_v<pair<key_type, mapped_type>, P>` is `true`.

{/* source:cpp-container-flat-multimap-insert:0008 */}
- 7) Inserts elements from range [`first`, `last`) as if performing the following operations sequentially:
  - Adds elements to [`c`](/docs/cpp/library/container/flat_multimap#Member_objects) as if by

    ```cpp
    for (; first != last; ++first)
    {
        value_type value = *first;
        c.keys.insert(c.keys.end(), std::move(value.first));
        c.values.insert(c.values.end(), std::move(value.second));
    }
    ```

  - Sorts the range of newly inserted elements with respect to [`value_comp`](/docs/cpp/library/container/flat_multimap/value_comp).
  - Merges the resulting sorted range and the sorted range of pre-existing elements into a single sorted range.

{/* source:cpp-container-flat-multimap-insert:0009 */}
- May allocate memory during the in-place merge operation.

{/* source:cpp-container-flat-multimap-insert:0010 */}
- 8) Inserts elements from range [`first`, `last`) as if performing the following operations sequentially:
  - Adds elements to [`c`](/docs/cpp/library/container/flat_multimap#Member_objects) as if by

    ```cpp
    for (; first != last; ++first)
    {
        value_type value = *first;
        c.keys.insert(c.keys.end(), std::move(value.first));
        c.values.insert(c.values.end(), std::move(value.second));
    }
    ```

  - Merges the sorted range of newly added elements and the sorted range of pre-existing elements into a single sorted range.

{/* source:cpp-container-flat-multimap-insert:0011 */}
- May allocate memory during the in-place merge operation.

{/* source:cpp-container-flat-multimap-insert:0012 */}
- 9) Inserts elements from initializer list `ilist`. Equivalent to `insert(ilist.begin(), ilist.end());`.

{/* source:cpp-container-flat-multimap-insert:0013 */}
- 10) Inserts elements from initializer list `ilist`. Equivalent to `insert(s, ilist.begin(), ilist.end());`.

{/* source:cpp-container-flat-multimap-insert:0014 */}
Information on iterator invalidation is copied from [here](/docs/Template:cpp/container/note-iterator-invalidation).

### Parameters

{/* source:cpp-container-flat-multimap-insert:0015 */}
<ParameterList>
  <Parameter name="pos">an iterator to the position before which the new element will be inserted</Parameter>
  <Parameter name="value">an element value to insert</Parameter>
  <Parameter name="first, last">a range of elements to insert</Parameter>
  <Parameter name="ilist">an initializer list to insert the values from</Parameter>
  <Parameter name="x">a value of any type that can be transparently compared with a key</Parameter>
  <Parameter name="s">a disambiguation tag indicating that the input sequence is sorted (with respect to [`value_comp()`](/docs/cpp/library/container/flat_multimap/value_comp))</Parameter>
</ParameterList>

Type requirements

- `InputIt` must meet the requirements of [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator).

### Return value

{/* source:cpp-container-flat-multimap-insert:0016 */}
- 1-6) An iterator to the inserted element.

{/* source:cpp-container-flat-multimap-insert:0017 */}
- 7-10) (none)

### Exceptions

{/* source:cpp-container-flat-multimap-insert:0018 */}
- 1-6) If an exception is thrown by any operation, the insertion has no effect.

{/* source:cpp-container-flat-multimap-insert:0019 */}
- 7-10) No exception safety guarantee. (?)

### Complexity

{/* source:cpp-container-flat-multimap-insert:0021 */}
- 1-6) Linear in [`size()`](/docs/cpp/library/container/flat_multimap/size).

{/* source:cpp-container-flat-multimap-insert:0022 */}
- 7) `N + M·log(M)`, where `N` is the [`size()`](/docs/cpp/library/container/flat_multimap/size) before the operation and `M` is `std::distance(first, last)`.

{/* source:cpp-container-flat-multimap-insert:0023 */}
- 8) Linear in [`size()`](/docs/cpp/library/container/flat_multimap/size).

{/* source:cpp-container-flat-multimap-insert:0024 */}
- 9) `N + M·log(M)`, where `N` is the [`size()`](/docs/cpp/library/container/flat_multimap/size) before the operation and `M` is `ilist.size()`.

{/* source:cpp-container-flat-multimap-insert:0025 */}
- 10) Linear in `N`, where `N` is [`size()`](/docs/cpp/library/container/flat_multimap/size) after the operation.
