{/* source:cpp-container-flat-multimap-rbegin:0001 */}
Returns a reverse iterator to the first element of the reversed `flat_multimap`. It corresponds to the last element of the non-reversed `flat_multimap`. If the `flat_multimap` is empty, the returned iterator is equal to `rend()`.

### Parameters

{/* source:cpp-container-flat-multimap-rbegin:0002 */}
(none)

### Return value

{/* source:cpp-container-flat-multimap-rbegin:0003 */}
Reverse iterator to the first element.

### Complexity

{/* source:cpp-container-flat-multimap-rbegin:0004 */}
Constant.

### Notes

{/* source:cpp-container-flat-multimap-rbegin:0005 */}
The [underlying iterator](/docs/cpp/library/iterator/reverse_iterator/base) of the returned reverse iterator is the [end iterator](/docs/cpp/library/container/flat_multimap/end). Hence the returned iterator is invalidated if and when the end iterator is invalidated.

### Example

{/* source:cpp-container-flat-multimap-rbegin:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <flat_map>

int main()
{
    std::flat_multimap<std::string, int> map
    {
        {"█", 1},
        {"▒", 5},
        {"░", 3},
        {"▓", 7},
        {"▓", 8},
        {"░", 4},
        {"▒", 6},
        {"█", 2}
    };

    std::cout << "Print out in reverse order using const reverse iterators:\n";
    std::for_each(map.crbegin(), map.crend(),
        [](std::pair<const std::string, int> const& e)
        {
            std::cout << "{ \"" << e.first << "\", " << e.second << " };\n";
        });

    map.rbegin()->second = 42; // OK: non-const value is modifiable
//  map.crbegin()->second = 42; // Error: cannot modify the const value
}
```

Possible output:

```text
Print out in reverse order using const reverse iterators:
{ "▓", 8 };
{ "▓", 7 };
{ "▒", 6 };
{ "▒", 5 };
{ "░", 4 };
{ "░", 3 };
{ "█", 2 };
{ "█", 1 };
```
