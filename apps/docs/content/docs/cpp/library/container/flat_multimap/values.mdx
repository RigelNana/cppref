{/* source:cpp-container-flat-multimap-values:0001 */}
Return a constant reference to the adapted values container. Equivalent to `return c.values;`.

### Parameters

{/* source:cpp-container-flat-multimap-values:0002 */}
(none)

### Return value

{/* source:cpp-container-flat-multimap-values:0003 */}
The underlying values container.

### Complexity

{/* source:cpp-container-flat-multimap-values:0004 */}
Constant.

### Example

{/* source:cpp-container-flat-multimap-values:0005 */}
```cpp
#include <flat_map>
#include <print>
#include <type_traits>
#include <vector>
 
int main()
{
    std::flat_multimap<int, double> map{{1, 1.1}, {2, 2.2}, {3, 3.3}};
 
    // The default values container is std::vector:
    static_assert(std::is_same_v<decltype(map.values()), const std::vector<int>&>);
 
    std::println("{}", map.values());
}
```

Output:

```text
[1.1, 2.2, 3.3]
```
