Returns an iterator to the element following the last element of the `flat_multimap`.

{/* source:cpp-container-flat-multimap-end:0002 */}
This element acts as a placeholder; attempting to access it results in undefined behavior.

### Parameters

{/* source:cpp-container-flat-multimap-end:0003 */}
(none)

### Return value

{/* source:cpp-container-flat-multimap-end:0004 */}
Iterator to the element following the last element.

### Complexity

{/* source:cpp-container-flat-multimap-end:0005 */}
Constant.

### Example

{/* source:cpp-container-flat-multimap-end:0006 */}
```cpp
#include <iostream>
#include <flat_map>

int main()
{
    std::flat_multimap<int, int> map{{4, 13}, {9, 94}, {1, 19}, {4, 42}};

    for (auto it = map.cbegin(); it != map.cend(); ++it)
        std::cout << '[' << it->first << "] = " << it->second << '\n';

    // Unlike std::multimap's bidirectional iterators, the std::flat_multimap
    // iterators are random-access, so they can be used with the operator[]:
    auto it = map.cbegin();
    assert(it[1] == 19);
    assert(it[4] == 13);
    assert(it[4] == 42);
    assert(it[9] == 94);
}
```

Output:

```text
[1] = 19
[4] = 13
[4] = 42
[9] = 94
```
