<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`template< container-compatible-range<value_type> R >
void insert_range( R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-flat-multimap-insert-range:0001 */}
Inserts a copy of each element in the range `rg` into underlying containers [`c`](/docs/cpp/library/container/flat_multimap#Member_objects) as if by:

{/* source:cpp-container-flat-multimap-insert-range:0002 */}
```cpp
for (const auto& e : rg)
{
    c.keys.insert(c.keys.end(), e.first);
    c.values.insert(c.values.end(), e.second);
}
```

{/* source:cpp-container-flat-multimap-insert-range:0003 */}
Then, sorts the range of newly inserted elements with respect to `value_comp()`. Merges the resulting sorted range and the sorted range of pre-existing elements into a single sorted range.

{/* source:cpp-container-flat-multimap-insert-range:0004 */}
Each iterator in the range `rg` is dereferenced exactly once. The behavior is undefined if `rg` overlaps with the container.

{/* source:cpp-container-flat-multimap-insert-range:0005 */}
Information on iterator invalidation is copied from [here](/docs/Template:cpp/container/note-iterator-invalidation)

### Parameters

{/* source:cpp-container-flat-multimap-insert-range:0006 */}
<ParameterList>
  <Parameter name="rg">
    a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to T
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-flat-multimap-insert-range:0007 */}
(none)

### Complexity

{/* source:cpp-container-flat-multimap-insert-range:0008 */}
`N + M·log(M)`, where N is `size()` before the operation and M is `ranges::distance(rg)`.

### Notes

{/* source:cpp-container-flat-multimap-insert-range:0009 */}
Since `insert_range` performs an in-place merge operation, that may allocate memory.

### Example

{/* source:cpp-container-flat-multimap-insert-range:0010 */}
```cpp
#include <iostream>
#include <flat_map>
#include <utility>

void println(auto, auto const& container)
{
    for (const auto& [key, value] : container)
        std::cout << '{' << key << ',' << value << '}' << ' ';
    std::cout << '\n';
}

int main()
{
    auto container = std::flat_multimap{std::pair{1, 11}, {3, 33}, {2, 22}, {4, 44}};
    const auto rg = {std::pair{-1, -11}, {3, -33}, {-2, -22}};
#ifdef __cpp_lib_containers_ranges
    container.insert_range(rg);
#else
    container.insert(rg.begin(), rg.end());
#endif
    println("{}", container);
}
```

Output:

```text
{-2,-22} {-1,-11} {1,11} {2,22} {3,33} {3,-33} {4,44}
```
