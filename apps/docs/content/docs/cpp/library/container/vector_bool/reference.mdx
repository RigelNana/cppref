The [`std::vector`](/docs/cpp/library/container/vector_bool)`<bool, Alloc>` specializations define `std::vector<bool, Alloc>::reference` as a publicly-accessible nested class. `std::vector<bool, Alloc>::reference` proxies the behavior of references to a single bit in `std::vector<bool, Alloc>`.

{/* source:cpp-container-vector-bool-reference:0002 */}
The primary use of `std::vector<bool, Alloc>::reference` is to provide an lvalue that can be returned from `operator[]`.

{/* source:cpp-container-vector-bool-reference:0003 */}
Any reads or writes to a vector that happen via a `std::vector<bool, Alloc>::reference` potentially read or write to the entire underlying vector.

## `std::formatter<std::vector<bool, Alloc>::reference>`

<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`template< class T, class CharT >
  requires /*is-vector-bool-reference*/<T>

struct formatter<T, CharT>;`} />
</DeclarationDoc>

Specializes the [`std::formatter`](/docs/cpp/library/text/format/formatter) for `std::vector<bool, Alloc>::reference`. The specialization uses `std::formatter<bool, CharT>` as its underlying formatter (denoted as `underlying_`) where the referenced bit is converted to `bool` to be formatted. The exposition-only constant `/*is-vector-bool-reference*/<T>` is `true` if and only if `T` denotes the type `std::vector<bool, Alloc>::reference` for some type `Alloc` and `std::vector<bool, Alloc>` is not a [`program-defined specialization`](/docs/cpp/language/basic_concepts/type-id#Program-defined_type).
