{/* source:cpp-container-vector-bool-flip:0001 */}
<InlineRevision since="C++20" /> Toggles each `bool` (replaces with its opposite value) in the [`vector`](/docs/cpp/library/container/vector_bool).

### Example

{/* source:cpp-container-vector-bool-flip:0002 */}
```cpp
#include <iostream>
#include <vector>
 
void print(const std::vector<bool>& vb)
{
    for (const bool b : vb)
        std::cout << b;
    std::cout << '\n';
}
 
int main()
{
    std::vector<bool> v{0, 1, 0, 1};
    print(v);
    v.flip();
    print(v);
}
```

Output:

```text
0101
1010
```
