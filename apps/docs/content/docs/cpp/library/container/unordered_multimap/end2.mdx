Returns an iterator to the element following the last element of the bucket with index `n`. This element acts as a placeholder, attempting to access it results in undefined behavior.

## Parameters

{/* source:cpp-container-unordered-multimap-end2:0002 */}
<ParameterList>
  <Parameter name="n">the index of the bucket to access</Parameter>
</ParameterList>

## Return value

{/* source:cpp-container-unordered-multimap-end2:0003 */}
Iterator to the element following the last element.

## Complexity

{/* source:cpp-container-unordered-multimap-end2:0004 */}
Constant.
