{/* source:cpp-container-unordered-multimap-emplace-hint:0001 */}
Inserts a new element into the container, using `hint` as a suggestion where the element should go.

{/* source:cpp-container-unordered-multimap-emplace-hint:0002 */}
The constructor of the element type (`value_type`, that is, `std::pair<const Key, T>`) is called with exactly the same arguments as supplied to the function, forwarded with `std::forward<Args>(args)...`.

{/* source:cpp-container-unordered-multimap-emplace-hint:0003 */}
If after the operation the new number of elements is greater than old [`max_load_factor()`](/docs/cpp/library/container/unordered_multimap/max_load_factor) * [`bucket_count()`](/docs/cpp/library/container/unordered_multimap/bucket_count) a rehashing takes place. If rehashing occurs (due to the insertion), all iterators are invalidated. Otherwise (no rehashing), iterators are not invalidated.

### Parameters

{/* source:cpp-container-unordered-multimap-emplace-hint:0004 */}
<ParameterList>
  <Parameter name="hint">iterator, used as a suggestion as to where to insert the new element</Parameter>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-unordered-multimap-emplace-hint:0005 */}
An iterator to the inserted element.

### Exceptions

{/* source:cpp-container-unordered-multimap-emplace-hint:0006 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-container-unordered-multimap-emplace-hint:0007 */}
Amortized constant on average, worst case linear in the size of the container.
