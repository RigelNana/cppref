{/* source:cpp-container-unordered-multimap-unordered-multimap:0001 */}
Constructs new container from a variety of data sources. Optionally uses user supplied `bucket_count` as a minimal number of buckets to create, `hash` as the hash function, `equal` as the function to compare keys and `alloc` as the allocator.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0002 */}
1-5) Constructs empty container. Sets [`max_load_factor()`](/docs/cpp/library/container/unordered_multimap/max_load_factor) to `1.0`. For the default constructor, the number of buckets is unspecified.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0003 */}
6-8) Constructs the container with the contents of the range [`first`, `last`). Sets [`max_load_factor()`](/docs/cpp/library/container/unordered_multimap/max_load_factor) to `1.0`.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0004 */}
9,10) Copy constructor. Constructs the container with the copy of the contents of `other`, copies the load factor, the predicate, and the hash function as well. If `alloc` is not provided, allocator is obtained by calling `std::allocator_traits<allocator_type>::select_on_container_copy_construction(other.get_allocator())`.

<Revision since="C++23">
The template parameter `Allocator` is only deduced from the first argument while used in [class template argument deduction](/docs/cpp/language/templates/ctad).
</Revision>

{/* source:cpp-container-unordered-multimap-unordered-multimap:0005 */}
11,12) [Move constructor](/docs/cpp/language/classes/move_constructor). Constructs the container with the contents of `other` using move semantics. If `alloc` is not provided, allocator is obtained by move-construction from the allocator belonging to `other`.

<Revision since="C++23">
The template parameter `Allocator` is only deduced from the first argument while used in [class template argument deduction](/docs/cpp/language/templates/ctad).
</Revision>

{/* source:cpp-container-unordered-multimap-unordered-multimap:0006 */}
13-15) [Initializer-list constructor](/docs/cpp/language/initialization/list_initialization). Constructs the container with the contents of the initializer list `init`, same as `unordered_multimap(init.begin(), init.end())`.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0007 */}
16-18) Constructs the container with the contents of `rg`.

## Parameters

{/* source:cpp-container-unordered-multimap-unordered-multimap:0008 */}
<ParameterList>
  <Parameter name="alloc">allocator to use for all memory allocations of this container</Parameter>
  <Parameter name="bucket_count">minimal number of buckets to use on initialization. If it is not specified, an unspecified default value is used</Parameter>
  <Parameter name="hash">hash function to use</Parameter>
  <Parameter name="equal">comparison function to use for all key comparisons of this container</Parameter>
  <Parameter name="first, last">the range [`first`, `last`) to copy the elements from</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to [`value_type`](/docs/cpp/library/container/unordered_multimap#Member_types)</Parameter>
  <Parameter name="other">another container to be used as source to initialize the elements of the container with</Parameter>
  <Parameter name="init">initializer list to initialize the elements of the container with</Parameter>
</ParameterList>

Type requirements

- `InputIt` must meet the requirements of [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

## Complexity

{/* source:cpp-container-unordered-multimap-unordered-multimap:0009 */}
1-5) Constant.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0010 */}
6-8) Average case linear (i.e. `O(N)`, where N is `std::distance(first, last)`), worst case quadratic, i.e. `O(N2)`.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0011 */}
9,10) Linear in size of `other`.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0012 */}
11,12) Constant. If `alloc` is given and `alloc != other.get_allocator()`, then linear.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0013 */}
13-15) Average case `O(N)` (N is `std::size(init)`), worst case `O(N2)`.

{/* source:cpp-container-unordered-multimap-unordered-multimap:0014 */}
16-18) Average case `O(N)` (N is `ranges::distance(rg)`), worst case `O(N2)`.

## Exceptions

{/* source:cpp-container-unordered-multimap-unordered-multimap:0015 */}
Calls to `Allocator::allocate` may throw.
