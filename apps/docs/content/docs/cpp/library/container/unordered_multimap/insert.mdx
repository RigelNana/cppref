{/* source:cpp-container-unordered-multimap-insert:0001 */}
Inserts element(s) into the container.

{/* source:cpp-container-unordered-multimap-insert:0002 */}
1-3) Inserts `value`.

{/* source:cpp-container-unordered-multimap-insert:0003 */}
Overload (3) is equivalent to `emplace(std::forward<P>(value))` and only participates in overload resolution if `std::is_constructible<value_type, P&&>::value == true`.

{/* source:cpp-container-unordered-multimap-insert:0004 */}
4-6) Inserts `value`, using `hint` as a non-binding suggestion to where the search should start.

{/* source:cpp-container-unordered-multimap-insert:0005 */}
Overload (6) is equivalent to `emplace_hint(hint, std::forward<P>(value))` and only participates in overload resolution if `std::is_constructible<value_type, P&&>::value == true`.

{/* source:cpp-container-unordered-multimap-insert:0006 */}
7) Inserts elements from range [`first`, `last`).

{/* source:cpp-container-unordered-multimap-insert:0007 */}
If [`first`, `last`) is not a [valid range](/docs/cpp/library/iterator#Ranges), or `first` and/or `last` are iterators into `*this`, the behavior is undefined.

{/* source:cpp-container-unordered-multimap-insert:0008 */}
8) Inserts elements from initializer list `ilist`.

{/* source:cpp-container-unordered-multimap-insert:0009 */}
9) If `nh` is an empty [node handle](/docs/cpp/library/container/node_handle), does nothing. Otherwise, inserts the element owned by `nh` into the container and returns an iterator pointing at the inserted element. The behavior is undefined if `nh` is not empty and `get_allocator() != nh.get_allocator()`.

{/* source:cpp-container-unordered-multimap-insert:0010 */}
10) If `nh` is an empty [node handle](/docs/cpp/library/container/node_handle), does nothing and returns the end iterator. Otherwise, inserts the element owned by `nh` into the container, and returns the iterator pointing to the element with key equivalent to `nh.key()`. `hint` is used as a non-binding suggestion to where the search should start. The behavior is undefined if `nh` is not empty and `get_allocator() != nh.get_allocator()`.

{/* source:cpp-container-unordered-multimap-insert:0011 */}
If after the operation the new number of elements is greater than old [`max_load_factor()`](/docs/cpp/library/container/unordered_multimap/max_load_factor) `*` [`bucket_count()`](/docs/cpp/library/container/unordered_multimap/bucket_count) a rehashing takes place.
If rehashing occurs (due to the insertion), all iterators are invalidated. Otherwise (no rehashing), iterators are not invalidated. <InlineRevision since="C++17">If the insertion is successful, pointers and references to the element obtained while it is held in the node handle are invalidated, and pointers and references obtained to that element before it was extracted become valid.</InlineRevision>

## Return value

{/* source:cpp-container-unordered-multimap-insert:0013 */}
1-6) An iterator to the inserted element.

{/* source:cpp-container-unordered-multimap-insert:0014 */}
7,8) (none)

{/* source:cpp-container-unordered-multimap-insert:0015 */}
9,10) End iterator if `nh` was empty, iterator pointing to the inserted element otherwise.

## Exceptions

{/* source:cpp-container-unordered-multimap-insert:0017 */}
7,8) No exception safety guarantee.

{/* source:cpp-container-unordered-multimap-insert:0018 */}

## Complexity

{/* source:cpp-container-unordered-multimap-insert:0019 */}
1-6) Average case: `O(1)`, worst case `O(size())`.

{/* source:cpp-container-unordered-multimap-insert:0020 */}
7,8) Average case: `O(N)`, where N is the number of elements to insert. Worst case: `O(N * size() + N)`.

{/* source:cpp-container-unordered-multimap-insert:0021 */}
9,10) Average case: `O(1)`, worst case `O(size())`.
