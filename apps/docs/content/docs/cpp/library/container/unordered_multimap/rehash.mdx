{/* source:cpp-container-unordered-multimap-rehash:0001 */}
Changes the number of buckets to a value `n` that is not less than `count` and satisfies `n >= size() / max_load_factor()`, then rehashes the container, i.e. puts the elements into appropriate buckets considering that total number of buckets has changed.

## Parameters

{/* source:cpp-container-unordered-multimap-rehash:0002 */}
<ParameterList>
  <Parameter name="count">lower bound for the new number of buckets</Parameter>
</ParameterList>

## Return value

{/* source:cpp-container-unordered-multimap-rehash:0003 */}
(none)

## Complexity

{/* source:cpp-container-unordered-multimap-rehash:0004 */}
Average case linear in the size of the container, worst case quadratic.

## Notes

{/* source:cpp-container-unordered-multimap-rehash:0005 */}
`rehash(0)` may be used to force an unconditional rehash, such as after suspension of automatic rehashing by temporarily increasing `max_load_factor()`.
