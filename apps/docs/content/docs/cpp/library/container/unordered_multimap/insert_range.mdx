  <Declaration language="cpp" since="C++23" code={`template< container-compatible-range<value_type> R >
void insert_range( R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-unordered-multimap-insert-range:0001 */}
Inserts a copy of each element in the range `rg`.

{/* source:cpp-container-unordered-multimap-insert-range:0002 */}
Each iterator in the range `rg` is dereferenced exactly once. The behavior is undefined if `rg` overlaps with the container.

{/* source:cpp-container-unordered-multimap-insert-range:0003 */}
If after the operation the new number of elements is greater than old [`max_load_factor()`](/docs/cpp/library/container/unordered_multimap/max_load_factor) * [`bucket_count()`](/docs/cpp/library/container/unordered_multimap/bucket_count) a rehashing takes place. If rehashing occurs (due to the insertion), all iterators are invalidated. Otherwise (no rehashing), iterators are not invalidated.

### Parameters

{/* source:cpp-container-unordered-multimap-insert-range:0004 */}
<ParameterList>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

Type requirements:

- [`value_type`](/docs/cpp/library/container/unordered_multimap#Member_types) must be [`EmplaceConstructible`](/docs/cpp/library/named_req/EmplaceConstructible) into `unordered_multimap` from `*ranges::begin(rg)`. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-unordered-multimap-insert-range:0005 */}
(none)

### Complexity

{/* source:cpp-container-unordered-multimap-insert-range:0006 */}
Average case O(N), where N is `ranges::distance(rg)`, worst case O(`N·(a.size() + 1)`).

### Example

{/* source:cpp-container-unordered-multimap-insert-range:0008 */}
```cpp
#include <iostream>
#include <unordered_map>
#include <utility>
 
void println(auto, auto const& container)
{
    for (const auto& [key, value] : container)
        std::cout << '{' << key << ',' << value << '}' << ' ';
    std::cout << '\n';
}
 
int main()
{
    auto container = std::unordered_multimap{std::pair{1, 11}, {3, 33}, {2, 22}, {4, 44}};
    const auto rg = {std::pair{-1, -11}, {3, -33}, {-2, -22}};
#ifdef __cpp_lib_containers_ranges
    container.insert_range(rg);
#else
    container.insert(rg.begin(), rg.end());
#endif
    println("{}", container);
}
```

Possible output:

```text
{1,11} {-2,-22} {3,-33} {3,33} {2,22} {-1,-11} {4,44}
```
