A [destructor](/docs/cpp/language/classes/destructor). Destructs the `unordered_multimap`. The destructors of the elements are called and the used storage is deallocated. Note, that if the elements are pointers, the pointed-to objects are not destroyed.

### Complexity

{/* source:cpp-container-unordered-multimap-unordered-multimap:0002 */}
Linear in the size of the `unordered_multimap`.
