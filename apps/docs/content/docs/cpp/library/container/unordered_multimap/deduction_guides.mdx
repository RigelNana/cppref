{/* source:cpp-container-unordered-multimap-deduction-guides:0001 */}
1-8) These [deduction guide](/docs/cpp/language/templates/ctad) are provided for `unordered_multimap` to allow deduction from an iterator range (overloads (1,3-5)) and [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) (overloads (2,6-8)).

{/* source:cpp-container-unordered-multimap-deduction-guides:0002 */}
9-12) These deduction guides are provided for `unordered_multimap` to allow deduction from a [`std::from_range_t`](/docs/cpp/library/ranges/from_range) tag and an [`input_range`](/docs/cpp/library/ranges/input_range).

{/* source:cpp-container-unordered-multimap-deduction-guides:0003 */}
These overloads participate in overload resolution only if `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator), `Alloc` satisfies [`Allocator`](/docs/cpp/library/named_req/Allocator), neither `Hash` nor `Pred` satisfy `Allocator`, and `Hash` is not an integral type.

{/* source:cpp-container-unordered-multimap-deduction-guides:0004 */}
Note: the extent to which the library determines that a type does not satisfy [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator) is unspecified, except that as a minimum integral types do not qualify as input iterators. Likewise, the extent to which it determines that a type does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator) is unspecified, except that as a minimum the member type `Alloc::value_type` must exist and the expression `std::declval<Alloc&>().allocate(std::size_t{})` must be well-formed when treated as an unevaluated operand.

{/* source:cpp-container-unordered-multimap-deduction-guides:0005 */}
The `size_type` parameter type in these guides in an refers to the `size_type` member type of the type deduced by the deduction guide.

### Example

{/* source:cpp-container-unordered-multimap-deduction-guides:0007 */}
```cpp
#include <unordered_map>
 
int main()
{
    // std::unordered_multimap m1 = {{"foo", 1}, {"bar", 2}};
        // Error: braced-init-list has no type cannot
        // deduce pair<Key, T> from {"foo", 1} or {"bar", 2}
 
    std::unordered_multimap m1 = {std::pair{"foo", 2}, {"bar", 3}}; // guide #2
    std::unordered_multimap m2(m1.begin(), m1.end()); // guide #1
}
```
