{/* source:cpp-container-unordered-multimap-size:0001 */}
Returns the number of elements in the container, i.e. `std::distance(begin(), end())`.

## Parameters

{/* source:cpp-container-unordered-multimap-size:0002 */}
(none)

## Return value

{/* source:cpp-container-unordered-multimap-size:0003 */}
The number of elements in the container.

## Complexity

{/* source:cpp-container-unordered-multimap-size:0004 */}
Constant.

## Example

{/* source:cpp-container-unordered-multimap-size:0005 */}
```cpp
#include <cassert>
#include <unordered_map>
 
int main()
{
    std::unordered_multimap<int, char> nums{{1, 'a'}, {1, 'b'}, {2, 'c'}, {2, 'd'}};
    assert(nums.size() == 4); 
}
```
