{/* source:cpp-container-span-rbegin:0001 */}
Returns a reverse iterator to the first element of the reversed `span`. It corresponds to the last element of the non-reversed `span`. If the `span` is empty, the returned iterator is equal to `rend()`.

## Parameters

{/* source:cpp-container-span-rbegin:0002 */}
(none)

## Return value

{/* source:cpp-container-span-rbegin:0003 */}
Reverse iterator to the first element.

## Complexity

{/* source:cpp-container-span-rbegin:0004 */}
Constant.

## Notes

{/* source:cpp-container-span-rbegin:0005 */}
The [underlying iterator](/docs/cpp/library/iterator/reverse_iterator/base) of the returned reverse iterator is the [end iterator](/docs/cpp/library/container/span/end). Hence the returned iterator is invalidated if and when the end iterator is invalidated.

## Example

{/* source:cpp-container-span-rbegin:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <span>

int main()
{
    constexpr std::span<const char> code{"@droNE_T0P_w$s@s#_SECRET_a,p^42!"};

    auto hack = [](const unsigned O) { return O - 0141 < 120; };

    std::copy_if(code.rbegin(), code.rend(),
        std::ostream_iterator<const char>(std::cout), hack);

    std::cout << '\n';
}
```

Output:

```text
password
```
