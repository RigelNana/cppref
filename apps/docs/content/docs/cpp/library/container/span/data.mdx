{/* source:cpp-container-span-data:0001 */}
Returns a pointer to the beginning of the sequence.

## Return value

{/* source:cpp-container-span-data:0002 */}
A pointer to the beginning of the sequence.

## Example

{/* source:cpp-container-span-data:0003 */}
```cpp
#include <iostream>
#include <span>

int main()
{
    constexpr char str[] = "ABCDEF\n";

    const std::span sp{str};

    for (auto n{sp.size()}; n != 2; --n)
        std::cout << sp.last(n).data();
}
```

Output:

```text
ABCDEF
BCDEF
CDEF
DEF
EF
F
```
