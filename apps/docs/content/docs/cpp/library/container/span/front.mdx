{/* source:cpp-container-span-front:0001 */}
Returns a reference to the first element in the span.

{/* source:cpp-container-span-front:0002 */}
Calling `front` on an empty span results in undefined behavior.

## Parameters

{/* source:cpp-container-span-front:0003 */}
(none)

## Return value

{/* source:cpp-container-span-front:0004 */}
A reference to the first element.

## Complexity

{/* source:cpp-container-span-front:0005 */}
Constant.

## Notes

{/* source:cpp-container-span-front:0006 */}
For a span `c`, the expression `c.front()` is equivalent to `*c.begin()`.

## Example

{/* source:cpp-container-span-front:0007 */}
```cpp
#include <iostream>
#include <span>

void print(std::span<const int> const data)
{
    for (auto offset{0U}; offset != data.size(); ++offset)
        std::cout << data.subspan(offset).front() << ' ';
    std::cout << '\n';
}

int main()
{
    constexpr int data[]{0, 1, 2, 3, 4, 5, 6};
    print({data, 4});
}
```

Output:

```text
0 1 2 3
```
