{/* source:cpp-container-span-at:0001 */}
Returns a reference to the element at specified location `pos`, with bounds checking.

{/* source:cpp-container-span-at:0002 */}
If `pos` is not within the range of the span, an exception of type [`std::out_of_range`](/docs/cpp/library/error/out_of_range) is thrown.

## Parameters

{/* source:cpp-container-span-at:0003 */}
<ParameterList>
  <Parameter name="pos">position of the element to return</Parameter>
</ParameterList>

## Return value

{/* source:cpp-container-span-at:0004 */}
Reference to the requested element

## Exceptions

{/* source:cpp-container-span-at:0005 */}
[`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos >= size()`.

## Complexity

{/* source:cpp-container-span-at:0006 */}
Constant.

## Example

{/* source:cpp-container-span-at:0008 */}
```cpp
#include <chrono>
#include <cstddef>
#include <iostream>
#include <span>
#include <stdexcept>

int main()
{
    int x[]{1, 2, 4, 5, 5, 6};
    std::span data(x);

    // Set element 1
    data.at(1) = 88;

    // Read element 2
    std::cout << "Element at index 2 has value " << data.at(2) << '\n';

    std::cout << "data size = " << data.size() << '\n';

    try
    {
        // Try to set an element at random position >= size()
        auto moon_phase = []
        {
            return std::chrono::system_clock::now().time_since_epoch().count() % 8;
        };
        data.at(data.size() + moon_phase()) = 13;
    }
    catch(const std::out_of_range& ex)
    {
        std::cout << ex.what() << '\n';
    }

    // Print final values
    std::cout << "data:";
    for (int elem : data)
        std::cout << ' ' << elem;
    std::cout << '\n';
}
```

Possible output:

```text
Element at index 2 has value 4
data size = 6
std::out_of_range: pos (which is 8) >= size() (which is 6)
data: 1 88 4 5 5 6
```
