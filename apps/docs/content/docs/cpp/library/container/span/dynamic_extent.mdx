{/* source:cpp-container-span-dynamic-extent:0001 */}
`std::dynamic_extent` is a constant of type [`std::size_t`](/docs/cpp/library/utility/types/size_t) that is generally used to indicate that any type using `std::dynamic_extent` will *dynamically* store its value (e.g., size) rather than having the value *statically* known in the type.

{/* source:cpp-container-span-dynamic-extent:0002 */}
It is being used in several contexts:

{/* source:cpp-container-span-dynamic-extent:0003 */}
- To differentiate [`std::span`](/docs/cpp/library/container/span) of static and dynamic extent.

{/* source:cpp-container-span-dynamic-extent:0004 */}
<Revision since="C++23">
- To indicate that the extent at a certain rank index will be stored dynamically in [`std::extents`](/docs/cpp/library/container/mdspan/extents).
</Revision>

{/* source:cpp-container-span-dynamic-extent:0005 */}
<Revision since="C++26">
- To indicate that the padded layouts for [`std::mdspan`](/docs/cpp/library/container/mdspan) will dynamically store its padding value.
</Revision>

## Note

{/* source:cpp-container-span-dynamic-extent:0006 */}
Since [`std::size_t`](/docs/cpp/library/utility/types/size_t) is an unsigned type, an equivalent definition is:

{/* source:cpp-container-span-dynamic-extent:0007 */}
```cpp
inline constexpr std::size_t dynamic_extent = -1;
```

{/* source:cpp-container-span-dynamic-extent:0008 */}
See [integral conversions](/docs/cpp/language/expressions/implicit_cast#Integral_conversions).

## Example

{/* source:cpp-container-span-dynamic-extent:0009 */}
```cpp
#include <array>
#include <cassert>
#include <cstddef>
#include <iostream>
#include <span>
#include <string_view>
#include <vector>

int main()
{
    auto print = [](std::string_view const name, std::size_t ex)
    {
        std::cout << name << ", ";
        if (std::dynamic_extent == ex)
            std::cout << "dynamic extent\n";
        else
            std::cout << "static extent = " << ex << '\n';
    };

    int a[]{1, 2, 3, 4, 5};

    std::span span1{a};
    print("span1", span1.extent);

    std::span<int, std::dynamic_extent> span2{a};
    print("span2", span2.extent);

    std::array ar{1, 2, 3, 4, 5};
    std::span span3{ar};
    print("span3", span3.extent);

    std::vector v{1, 2, 3, 4, 5};
    std::span span4{v};
    print("span4", span4.extent);
}
```

Output:

```text
span1, static extent = 5
span2, dynamic extent
span3, static extent = 5
span4, dynamic extent
```
