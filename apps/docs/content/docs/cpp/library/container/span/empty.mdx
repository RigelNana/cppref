{/* source:cpp-container-span-empty:0001 */}
Checks if the span is empty.

## Parameters

{/* source:cpp-container-span-empty:0002 */}
(none)

## Return value

{/* source:cpp-container-span-empty:0003 */}
`true` if the span is empty (i.e., `size() == 0`); `false` otherwise.

## Example

{/* source:cpp-container-span-empty:0004 */}
```cpp
#include <iomanip>
#include <iostream>
#include <span>

int main()
{
    std::span<const char> span{"ABCDEF"};

    while (!span.empty())
    {
        std::cout << std::quoted(span.data()) << '\n';
        span = span.last(span.size() - 1);
    }
}
```

Output:

```text
"ABCDEF"
"BCDEF"
"CDEF"
"DEF"
"EF"
"F"
""
```
