{/* source:cpp-container-span-operator-at:0001 */}
Returns a reference to the `idx`th element of the sequence. The behavior is undefined if `idx` is out of range (i.e., if it is greater than or equal to `size()`).

## Parameters

{/* source:cpp-container-span-operator-at:0002 */}
<ParameterList>
  <Parameter name="idx">the index of the element to access</Parameter>
</ParameterList>

## Return value

{/* source:cpp-container-span-operator-at:0003 */}
A reference to the `idx`th element of the sequence, i.e., `data()[idx]`.

## Exceptions

{/* source:cpp-container-span-operator-at:0004 */}
Throws nothing.

## Example

{/* source:cpp-container-span-operator-at:0005 */}
```cpp
#include <cstddef>
#include <iostream>
#include <span>
#include <utility>

void reverse(std::span<int> span)
{
    for (std::size_t i = 0, j = std::size(span); i < j; ++i)
    {
        --j;
        std::swap(span[i], span[j]);
    }
}

void print(std::span<const int> const span)
{
    for (int element : span)
        std::cout << element << ' ';
    std::cout << '\n';
}

int main()
{
    int data[]{1, 2, 3, 4, 5};
    print(data);
    reverse(data);
    print(data);
}
```

Output:

```text
1 2 3 4 5
5 4 3 2 1
```
