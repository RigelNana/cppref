Returns the size of the sequence in bytes.

## Parameters

{/* source:cpp-container-span-size-bytes:0002 */}
(none)

## Return value

{/* source:cpp-container-span-size-bytes:0003 */}
The size of the sequence in bytes, i.e., `size() * sizeof(element_type)`.

## Example

{/* source:cpp-container-span-size-bytes:0004 */}
```cpp
#include <cstdint>
#include <span>

int main()
{
    constexpr static std::int32_t a[]{1, 2, 3, 4, 5};
    constexpr static std::span s{a};

    static_assert
    (
        sizeof(int32_t) == 4 &&
        std::size(a) == 5 &&
        sizeof a == 20 &&
        s.size() == 5 &&
        s.size_bytes() == 20
    );
}
```
