{/* source:cpp-container-multimap-emplace-hint:0001 */}
Inserts a new element into the container as close as possible to the position just before `hint`.

{/* source:cpp-container-multimap-emplace-hint:0002 */}
The constructor of the element type (`value_type`, that is, `std::pair<const Key, T>`) is called with exactly the same arguments as supplied to the function, forwarded with `std::forward<Args>(args)...`.

{/* source:cpp-container-multimap-emplace-hint:0003 */}
No iterators or references are invalidated.

## Parameters

{/* source:cpp-container-multimap-emplace-hint:0004 */}
<ParameterList>
  <Parameter name="hint">iterator to the position before which the new element will be inserted</Parameter>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

## Return value

{/* source:cpp-container-multimap-emplace-hint:0005 */}
An iterator to the inserted element.

## Exceptions

{/* source:cpp-container-multimap-emplace-hint:0006 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

## Complexity

{/* source:cpp-container-multimap-emplace-hint:0007 */}
Logarithmic in the size of the container in general, but amortized constant if the new element is inserted just before `hint`.
