{/* source:cpp-container-multimap-emplace:0001 */}
Inserts a new element into the container constructed in-place with the given `args`.

{/* source:cpp-container-multimap-emplace:0002 */}
The constructor of the new element (i.e. `std::pair<const Key, T>`) is called with exactly the same arguments as supplied to emplace, forwarded via `std::forward<Args>(args)...`.

{/* source:cpp-container-multimap-emplace:0003 */}
Careful use of emplace allows the new element to be constructed while avoiding unnecessary copy or move operations.

{/* source:cpp-container-multimap-emplace:0004 */}
No iterators or references are invalidated.

### Parameters

{/* source:cpp-container-multimap-emplace:0005 */}
<ParameterList>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-multimap-emplace:0006 */}
An iterator to the inserted element.

### Exceptions

{/* source:cpp-container-multimap-emplace:0007 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-container-multimap-emplace:0008 */}
Logarithmic in the size of the container.

### Example

{/* source:cpp-container-multimap-emplace:0009 */}
```cpp
#include <iostream>
#include <string>
#include <utility>
#include <map>
 
int main()
{
    std::multimap<std::string, std::string> m;
 
    // uses pair's move constructor
    m.emplace(std::make_pair(std::string("a"), std::string("a")));
 
    // uses pair's converting move constructor
    m.emplace(std::make_pair("b", "abcd"));
 
    // uses pair's template constructor
    m.emplace("d", "ddd");
 
    // emplace with duplicate key 
    m.emplace("d", "DDD");
 
    // uses pair's piecewise constructor
    m.emplace(std::piecewise_construct,
              std::forward_as_tuple("c"),
              std::forward_as_tuple(10, 'c'));
 
    for (const auto& p : m)
        std::cout << p.first << " => " << p.second << '\n';
}
```

Output:

```text
a => a
b => abcd
c => cccccccccc
d => ddd
d => DDD
```
