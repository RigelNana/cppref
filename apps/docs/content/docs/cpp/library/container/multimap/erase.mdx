{/* source:cpp-container-multimap-erase:0001 */}
Removes specified elements from the container. The order of the remaining equivalent elements is preserved.

{/* source:cpp-container-multimap-erase:0002 */}
1. Removes the element at `pos`.

{/* source:cpp-container-multimap-erase:0003 */}
2. Removes the elements in the range `[first, last)`, which must be a valid range in `*this`.

{/* source:cpp-container-multimap-erase:0004 */}
3. Removes all elements with the key equivalent to `key`.

{/* source:cpp-container-multimap-erase:0005 */}
4. Removes all elements with key that compares equivalent to the value `x`. This overload participates in overload resolution only if the qualified-id `Compare::is_transparent` is valid and denotes a type, and neither `iterator` nor `const_iterator` is implicitly convertible from `K`. It allows calling this function without constructing an instance of `Key`.

{/* source:cpp-container-multimap-erase:0006 */}
References and iterators to the erased elements are invalidated. Other references and iterators are not affected.

{/* source:cpp-container-multimap-erase:0007 */}
The iterator `pos` must be valid and dereferenceable. Thus the [`end()`](/docs/cpp/library/container/multimap/end) iterator (which is valid, but is not dereferenceable) cannot be used as a value for `pos`.

### Parameters

{/* source:cpp-container-multimap-erase:0008 */}
<ParameterList>
  <Parameter name="pos">iterator to the element to remove</Parameter>
  <Parameter name="first, last">range of elements to remove</Parameter>
  <Parameter name="key">key value of the elements to remove</Parameter>
  <Parameter name="x">a value of any type that can be transparently compared with a key denoting the elements to remove</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-multimap-erase:0009 */}
1. Iterator following the last removed element.

{/* source:cpp-container-multimap-erase:0010 */}
2. Number of elements removed.

{/* source:cpp-container-multimap-erase:0011 */}
3. Number of elements removed.

### Exceptions

{/* source:cpp-container-multimap-erase:0012 */}
1. Throws nothing.

{/* source:cpp-container-multimap-erase:0013 */}
2. Any exceptions thrown by the `Compare` object.

### Complexity

{/* source:cpp-container-multimap-erase:0014 */}
Given an instance `c` of multimap:

{/* source:cpp-container-multimap-erase:0015 */}
1. Amortized constant

{/* source:cpp-container-multimap-erase:0016 */}
2. `log(c.size()) + std::distance(first, last)`

{/* source:cpp-container-multimap-erase:0017 */}
3. `log(c.size()) + c.count(key)`

{/* source:cpp-container-multimap-erase:0018 */}
4. `log(c.size()) + c.count(x)`

### Example

{/* source:cpp-container-multimap-erase:0020 */}
```cpp
#include <map>
#include <iostream>
 
int main()
{
    std::multimap<int, std::string> c =
    {
        {1, "one"}, {2, "two"}, {3, "three"},
        {4, "four"}, {5, "five"}, {6, "six"}
    };
 
    // erase all odd numbers from c
    for (auto it = c.begin(); it != c.end();)
    {
        if (it->first % 2 != 0)
            it = c.erase(it);
        else
            ++it;
    }
 
    for (auto& p : c)
        std::cout << p.second << ' ';
    std::cout << '\n';
}
```

Output:

```text
two four six
```
