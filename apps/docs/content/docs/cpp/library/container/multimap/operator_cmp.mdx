{/* source:cpp-container-multimap-operator-cmp:0001 */}
Compares the contents of two multimaps.

{/* source:cpp-container-multimap-operator-cmp:0002 */}
1. Checks if the contents of `lhs` and `rhs` are equal, that is, they have the same number of elements and each element in `lhs` compares equal with the element in `rhs` at the same position.

{/* source:cpp-container-multimap-operator-cmp:0003 */}
2. Compares the contents of `lhs` and `rhs` lexicographically. The comparison is performed by a function equivalent to [`std::lexicographical_compare`](/docs/cpp/library/algorithm/lexicographical_compare). This comparison ignores the multimap's ordering `Compare`.

{/* source:cpp-container-multimap-operator-cmp:0004 */}
3. Compares the contents of `lhs` and `rhs` lexicographically. The comparison is performed as if by calling `std::lexicographical_compare_three_way(lhs.begin(), lhs.end(), rhs.begin(), rhs.end(), synth-three-way)`. This comparison ignores the multimap's ordering `Compare`.

{/* source:cpp-container-multimap-operator-cmp:0005 */}
The return type is the return type of [`synth-three-way`](/docs/cpp/library/standard_library/synth-three-way) (i.e., [`synth-three-way-result`](/docs/cpp/library/standard_library/synth-three-way)`<T>`).

{/* source:cpp-container-multimap-operator-cmp:0006 */}
If none of the following conditions is satisfied, the behavior is undefined: `T` models [`three_way_comparable`](/docs/cpp/library/utility/compare/three_way_comparable). `<` is defined for values of type (possibly const-qualified) `T`, and `<` is a total ordering relationship.

{/* source:cpp-container-multimap-operator-cmp:0007 */}
<Revision since="C++20">
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Parameters

{/* source:cpp-container-multimap-operator-cmp:0008 */}
<ParameterList>
  <Parameter name="lhs, rhs">`multimap`s whose contents to compare</Parameter>
</ParameterList>

- `T, Key` must meet the requirements of [`EqualityComparable`](/docs/cpp/library/named_req/EqualityComparable) in order to use overloads (1,2).
- `Key` must meet the requirements of [`LessThanComparable`](/docs/cpp/library/named_req/LessThanComparable) in order to use overloads (3-6). The ordering relation must establish total order.

### Return value

{/* source:cpp-container-multimap-operator-cmp:0009 */}
1. `true` if the contents of the multimaps are equal, `false` otherwise.

{/* source:cpp-container-multimap-operator-cmp:0010 */}
2. `true` if the contents of the multimaps are not equal, `false` otherwise.

{/* source:cpp-container-multimap-operator-cmp:0011 */}
3. `true` if the contents of the `lhs` are lexicographically less than the contents of `rhs`, `false` otherwise.

{/* source:cpp-container-multimap-operator-cmp:0012 */}
4. `true` if the contents of the `lhs` are lexicographically less than or equal to the contents of `rhs`, `false` otherwise.

{/* source:cpp-container-multimap-operator-cmp:0013 */}
5. `true` if the contents of the `lhs` are lexicographically greater than the contents of `rhs`, `false` otherwise.

{/* source:cpp-container-multimap-operator-cmp:0014 */}
6. `true` if the contents of the `lhs` are lexicographically greater than or equal to the contents of `rhs`, `false` otherwise.

{/* source:cpp-container-multimap-operator-cmp:0015 */}
7. The relative order of the first pair of non-equivalent elements in `lhs` and `rhs` if there are such elements, `lhs.size() <=> rhs.size()` otherwise.

### Complexity

{/* source:cpp-container-multimap-operator-cmp:0016 */}
1. Constant if `lhs` and `rhs` are of different size, otherwise linear in the size of the multimap.

{/* source:cpp-container-multimap-operator-cmp:0017 */}
2. Linear in the size of the multimap.

### Notes

{/* source:cpp-container-multimap-operator-cmp:0018 */}
<Revision until="C++20">
The relational operators are defined in terms of the element type's `operator<`.
</Revision>
<Revision since="C++20">
The relational operators are defined in terms of [`synth-three-way`](/docs/cpp/library/standard_library/synth-three-way), which uses `operator<=>` if possible, or `operator<` otherwise. Notably, if the element does not itself provide `operator<=>`, but is implicitly convertible to a three-way comparable type, that conversion will be used instead of `operator<`.
</Revision>

### Example

{/* source:cpp-container-multimap-operator-cmp:0019 */}
```cpp
#include <cassert>
#include <compare>
#include <map>
 
int main()
{
    std::multimap<int, char> a{{1, 'a'}, {2, 'b'}, {3, 'c'}};
    std::multimap<int, char> b{{1, 'a'}, {2, 'b'}, {3, 'c'}};
    std::multimap<int, char> c{{7, 'Z'}, {8, 'Y'}, {9, 'X'}, {10, 'W'}};
 
    assert
    (""
        "Compare equal containers:" &&
        (a != b) == false &&
        (a == b) == true &&
        (a < b) == false &&
        (a <= b) == true &&
        (a > b) == false &&
        (a >= b) == true &&
        (a <=> b) != std::weak_ordering::less &&
        (a <=> b) != std::weak_ordering::greater &&
        (a <=> b) == std::weak_ordering::equivalent &&
        (a <=> b) >= 0 &&
        (a <=> b) <= 0 &&
        (a <=> b) == 0 &&
 
        "Compare non equal containers:" &&
        (a != c) == true &&
        (a == c) == false &&
        (a < c) == true &&
        (a <= c) == true &&
        (a > c) == false &&
        (a >= c) == false &&
        (a <=> c) == std::weak_ordering::less &&
        (a <=> c) != std::weak_ordering::equivalent &&
        (a <=> c) != std::weak_ordering::greater &&
        (a <=> c) < 0 &&
        (a <=> c) != 0 &&
        (a <=> c) <= 0 &&
    "");
}
```
