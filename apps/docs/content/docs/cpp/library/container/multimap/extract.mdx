{/* source:cpp-container-multimap-extract:0001 */}
- 1) Unlinks the node that contains the element pointed to by `position` and returns a [node handle](/docs/cpp/library/container/node_handle) that owns it.

{/* source:cpp-container-multimap-extract:0002 */}
- 2) If the container has an element with key equivalent to `k`, unlinks the node that contains the first such element from the container and returns a [node handle](/docs/cpp/library/container/node_handle) that owns it. Otherwise, returns an empty node handle.

{/* source:cpp-container-multimap-extract:0003 */}
- 3) Same as (2). This overload participates in overload resolution only if the qualified-id `Compare::is_transparent` is valid and denotes a type, and neither `iterator` nor `const_iterator` is implicitly convertible from `K`. It allows calling this function without constructing an instance of `Key`.

{/* source:cpp-container-multimap-extract:0004 */}
In either case, no elements are copied or moved, only the internal pointers of the container nodes are repointed (rebalancing may occur, as with [`erase()`](/docs/cpp/library/container/multimap/erase)).

{/* source:cpp-container-multimap-extract:0005 */}
Extracting a node invalidates only the iterators to the extracted element. Pointers and references to the extracted element remain valid, but cannot be used while element is owned by a node handle: they become usable if the element is inserted into a container.

### Parameters

{/* source:cpp-container-multimap-extract:0006 */}
<ParameterList>
  <Parameter name="position">
    a valid iterator into this container
  </Parameter>
  <Parameter name="k">
    a key to identify the node to be extracted
  </Parameter>
  <Parameter name="x">
    a value of any type that can be transparently compared with a key identifying the node to be extracted
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-multimap-extract:0007 */}
A [node handle](/docs/cpp/library/container/node_handle) that owns the extracted element, or empty node handle in case the element is not found in (2,3).

### Exceptions

{/* source:cpp-container-multimap-extract:0008 */}
- 1) Throws nothing.

{/* source:cpp-container-multimap-extract:0009 */}
- 2,3) Any exceptions thrown by the `Compare` object.

### Complexity

{/* source:cpp-container-multimap-extract:0010 */}
- 1) Amortized constant.

{/* source:cpp-container-multimap-extract:0011 */}
- 2,3) log([`size()`](/docs/cpp/library/container/multimap/size))

### Notes

{/* source:cpp-container-multimap-extract:0012 */}
`extract` is the only way to change a key of a map element without reallocation:

{/* source:cpp-container-multimap-extract:0013 */}
```cpp
std::map<int, std::string> m{{1, "mango"}, {2, "papaya"}, {3, "guava"}};
auto nh = m.extract(2);
nh.key() = 4;
m.insert(std::move(nh));
// m == {{1, "mango"}, {3, "guava"}, {4, "papaya"}}
```

### Example

{/* source:cpp-container-multimap-extract:0015 */}
```cpp
#include <algorithm>
#include <iostream>
#include <string_view>
#include <map>
 
void print(std::string_view comment, const auto& data)
{
    std::cout << comment;
    for (auto [k, v] : data)
        std::cout << ' ' << k << '(' << v << ')';
 
    std::cout << '\n';
}
 
int main()
{
    std::multimap<int, char> cont{{1, 'a'}, {2, 'b'}, {3, 'c'}};
 
    print("Start:", cont);
 
    // Extract node handle and change key
    auto nh = cont.extract(1);
    nh.key() = 4;
 
    print("After extract and before insert:", cont);
 
    // Insert node handle back
    cont.insert(std::move(nh));
 
    print("End:", cont);
}
```

Output:

```text
Start: 1(a) 2(b) 3(c)
After extract and before insert: 2(b) 3(c)
End: 2(b) 3(c) 4(a)
```
