{/* source:cpp-container-multimap:0001 */}
`std::multimap` is an associative container that contains a sorted list of key-value pairs, while permitting multiple entries with the same key. Sorting is done according to the comparison function `Compare`, applied to the keys. Search, insertion, and removal operations have logarithmic complexity.

{/* source:cpp-container-multimap:0002 */}
Iterators of `std::multimap` iterate in non-descending order of keys, where non-descending is defined by the comparison that was used for construction. That is, given

{/* source:cpp-container-multimap:0003 */}
- `m`, a `std::multimap`
- `it_l` and `it_r`, dereferenceable iterators to `m`, with `it_l < it_r`.

{/* source:cpp-container-multimap:0004 */}
`m.value_comp()(*it_r, *it_l) == false` (least to greatest if using the default comparison).

{/* source:cpp-container-multimap:0005 */}
<Revision since="C++11">
The order of the key-value pairs whose keys compare equivalent is the order of insertion and does not change.
</Revision>

{/* source:cpp-container-multimap:0006 */}
Everywhere the standard library uses the [`Compare`](/docs/cpp/library/named_req/Compare) requirements, equivalence is determined by using the equivalence relation as described on [`Compare`](/docs/cpp/library/named_req/Compare). In imprecise terms, two objects `a` and `b` are considered equivalent if neither compares less than the other: `!comp(a, b) && !comp(b, a)`.

{/* source:cpp-container-multimap:0007 */}
`std::multimap` meets the requirements of [`Container`](/docs/cpp/library/named_req/Container), [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer), [`AssociativeContainer`](/docs/cpp/library/named_req/AssociativeContainer) and [`ReversibleContainer`](/docs/cpp/library/named_req/ReversibleContainer).
