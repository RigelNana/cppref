<InlineRevision since="C++11" />
Returns the number of elements in the container, i.e. `std::distance(begin(), end())`.

### Parameters

{/* source:cpp-container-multimap-size:0002 */}
(none)

### Return value

{/* source:cpp-container-multimap-size:0003 */}
The number of elements in the container.

### Complexity

{/* source:cpp-container-multimap-size:0004 */}
Constant.

### Example

{/* source:cpp-container-multimap-size:0005 */}
```cpp
#include <cassert>
#include <map>
 
int main()
{
    std::multimap<int, char> nums{{1, 'a'}, {1, 'b'}, {2, 'c'}, {2, 'd'}};
    assert(nums.size() == 4); 
}
```
