{/* source:cpp-container-multimap-equal-range:0001 */}
Returns a range containing all elements with the given `key` in the container. The range is defined by two iterators, one pointing to the first element that is not less than `key` and another pointing to the first element greater than `key`. Alternatively, the first iterator may be obtained with [`lower_bound()`](/docs/cpp/library/container/multimap/lower_bound), and the second with [`upper_bound()`](/docs/cpp/library/container/multimap/upper_bound).

{/* source:cpp-container-multimap-equal-range:0002 */}
1. Compares the keys to `key`.

{/* source:cpp-container-multimap-equal-range:0003 */}
2. Compares the keys to the value `x`. This overload participates in overload resolution only if the qualified-id `Compare::is_transparent` is valid and denotes a type. It allows calling this function without constructing an instance of `Key`.

### Parameters

{/* source:cpp-container-multimap-equal-range:0004 */}
<ParameterList>
  <Parameter name="key">key value to compare the elements to</Parameter>
  <Parameter name="x">alternative value that can be compared to `Key`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-multimap-equal-range:0005 */}
[`std::pair`](/docs/cpp/library/utility/pair) containing a pair of iterators defining the wanted range: the first pointing to the first element that is not less than `key` and the second pointing to the first element greater than `key`.

{/* source:cpp-container-multimap-equal-range:0006 */}
If there are no elements not less than `key`, past-the-end (see [`end()`](/docs/cpp/library/container/multimap/end)) iterator is returned as the first element. Similarly if there are no elements greater than `key`, past-the-end iterator is returned as the second element.

{/* source:cpp-container-multimap-equal-range:0007 */}
<Revision since="C++11">
Since [`emplace`](/docs/cpp/library/container/multimap/emplace) and unhinted [`insert`](/docs/cpp/library/container/multimap/insert) always insert at the upper bound, the order of equivalent elements in the equal range is the order of insertion unless hinted [`insert`](/docs/cpp/library/container/multimap/insert) or [`emplace_hint`](/docs/cpp/library/container/multimap/emplace_hint) was used to insert an element at a different position.
</Revision>

### Complexity

{/* source:cpp-container-multimap-equal-range:0008 */}
Logarithmic in the size of the container.

### Example

{/* source:cpp-container-multimap-equal-range:0010 */}
```cpp
#include <iostream>
#include <map>
 
int main()
{
    std::multimap<int, char> dict
    {
        {1, 'A'},
        {2, 'B'},
        {2, 'C'},
        {2, 'D'},
        {4, 'E'},
        {3, 'F'}
    };
 
    auto range = dict.equal_range(2);
 
    for (auto i = range.first; i != range.second; ++i)
        std::cout << i->first << ": " << i->second << '\n';
}
```

Output:

```text
2: B
2: C
2: D
```
