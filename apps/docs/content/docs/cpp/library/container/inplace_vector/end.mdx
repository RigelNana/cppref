Returns an iterator to the element following the last element of the inplace_vector.

{/* source:cpp-container-inplace-vector-end:0002 */}
This element acts as a placeholder; attempting to access it results in undefined behavior.

### Parameters

{/* source:cpp-container-inplace-vector-end:0003 */}
(none)

### Return value

{/* source:cpp-container-inplace-vector-end:0004 */}
Iterator to the element following the last element.

### Complexity

{/* source:cpp-container-inplace-vector-end:0005 */}
Constant.
