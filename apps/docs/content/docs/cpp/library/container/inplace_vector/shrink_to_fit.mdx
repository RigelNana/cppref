Does nothing.

{/* source:cpp-container-inplace-vector-shrink-to-fit:0002 */}
Nominally, this function is a non-binding request to decrease capacity so that the internal storage contains only `size()` elements. However, such a request is always ignored by the fixed-capacity container `std::inplace_vector<T, N>`.

### Parameters

{/* source:cpp-container-inplace-vector-shrink-to-fit:0003 */}
(none)

### Return value

{/* source:cpp-container-inplace-vector-shrink-to-fit:0004 */}
(none)

### Complexity

{/* source:cpp-container-inplace-vector-shrink-to-fit:0005 */}
Constant.

### Notes

{/* source:cpp-container-inplace-vector-shrink-to-fit:0006 */}
This function exists for compatibility with vector-like interfaces.
