{/* source:cpp-container-inplace-vector-operator-at:0001 */}
Returns a reference to the element at specified location `pos`. No bounds checking is performed.

### Parameters

{/* source:cpp-container-inplace-vector-operator-at:0002 */}
<ParameterList>
  <Parameter name="pos">position of the element to return</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-inplace-vector-operator-at:0003 */}
Reference to the requested element.

### Complexity

{/* source:cpp-container-inplace-vector-operator-at:0004 */}
Constant.

### Notes

{/* source:cpp-container-inplace-vector-operator-at:0005 */}
Unlike [`std::map::operator[]`](/docs/cpp/library/container/map/operator_at), this operator never inserts a new element into the container. Accessing a nonexistent element through this operator is undefined behavior.

### Example

{/* source:cpp-container-inplace-vector-operator-at:0006 */}
The following code uses `operator[]` to read from and write to a `std::inplace_vector<int, N>`:

```cpp
#include <inplace_vector>
#include <iostream>

int main()
{
    std::inplace_vector<int, 4> numbers{2, 4, 6, 8};

    std::cout << "Second element: " << numbers[1] << '\n';

    numbers[0] = 5;

    std::cout << "All numbers:";
    for (auto i : numbers)
        std::cout << ' ' << i;
    std::cout << '\n';
}
```

Output:

```text
Second element: 4
All numbers: 5 4 6 8
```
