Specializes the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for `std::inplace_vector`. Swaps the contents of `lhs` and `rhs`. Calls `lhs.swap(rhs)`.

### Parameters

{/* source:cpp-container-inplace-vector-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">containers whose contents to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-inplace-vector-swap2:0003 */}
(none)

### Complexity

{/* source:cpp-container-inplace-vector-swap2:0004 */}
Linear in size of the containers.

### Exceptions

{/* source:cpp-container-inplace-vector-swap2:0005 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(N == 0 ||
         (std::is_nothrow_swappable_v<T> && std::is_nothrow_move_constructible_v<T>))
```

### Example

{/* source:cpp-container-inplace-vector-swap2:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <inplace_vector>

int main()
{
    std::inplace_vector<int, 4> alice{1, 2, 3};
    std::inplace_vector<int, 4> bob{7, 8, 9, 10};

    auto print = [](const int& n) { std::cout << ' ' << n; };

    // Print state before swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';

    std::cout << "-- SWAP\n";
    std::swap(alice, bob);

    // Print state after swap
    std::cout << "Alice:";
    std::for_each(alice.begin(), alice.end(), print);
    std::cout << "\nBobby:";
    std::for_each(bob.begin(), bob.end(), print);
    std::cout << '\n';
}
```

Output:

```text
Alice: 1 2 3
Bobby: 7 8 9 10
-- SWAP
Alice: 7 8 9 10
Bobby: 1 2 3
```
