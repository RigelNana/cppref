{/* source:cpp-container-inplace-vector:0001 */}
`inplace_vector` is a dynamically-resizable array with contiguous inplace storage. The elements of type `T` are stored and properly aligned within the object itself. The capacity of the internal storage is fixed at compile-time and is equal to `N`.

{/* source:cpp-container-inplace-vector:0002 */}
The elements are stored contiguously, which means that elements can be accessed not only through iterators or random-access `operator[]`, but also using offsets to regular pointers to elements. A pointer to an element of an `inplace_vector` may be passed to any function that expects a pointer to an element of a C-array.

{/* source:cpp-container-inplace-vector:0003 */}
The `inplace_vector` models [`Container`](/docs/cpp/library/named_req/Container), [`ReversibleContainer`](/docs/cpp/library/named_req/ReversibleContainer), [`ContiguousContainer`](/docs/cpp/library/named_req/ContiguousContainer), and [`SequenceContainer`](/docs/cpp/library/named_req/SequenceContainer), including most of the [optional sequence container requirements](/docs/cpp/library/named_req/SequenceContainer#Optional_operations), except that the `push_front`, `emplace_front`, `pop_front`, and `prepend_range` member functions are not provided.

{/* source:cpp-container-inplace-vector:0004 */}
For any positive `N`, `std::inplace_vector<T, N>::iterator` and `std::inplace_vector<T, N>::const_iterator` meet the [`ConstexprIterator`](/docs/cpp/library/named_req/ConstexprIterator) requirements.

{/* source:cpp-container-inplace-vector:0005 */}
For any positive `N`, if `T` is not [`TriviallyCopyable`](/docs/cpp/library/named_req/TriviallyCopyable) or `std::is_trivially_default_constructible_v<T>` is `false`, then member functions of `inplace_vector` are not [usable in constant expressions](/docs/cpp/language/expressions/constant_expression#Usable_in_constant_expressions).

{/* source:cpp-container-inplace-vector:0006 */}
The specialization `std::inplace_vector<T, 0>` is [`TriviallyCopyable`](/docs/cpp/library/named_req/TriviallyCopyable) and is empty. `std::is_trivially_default_constructible_v<std::inplace_vector<T, 0>>` is also `true`.

{/* source:cpp-container-inplace-vector:0007 */}
Any member function of `std::inplace_vector<T, N>` that would cause insertion beyond the capacity `N` throws [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc).

{/* source:cpp-container-inplace-vector:0008 */}
The complexity of common operations on `inplace_vector`s is as follows:

{/* source:cpp-container-inplace-vector:0009 */}
- Random access to an element via [`operator[]`](/docs/cpp/library/container/inplace_vector/operator_at) or [`at()`](/docs/cpp/library/container/inplace_vector/at) – constant: 𝓞(1).
- Insertion or removal of an element at the end – constant: 𝓞(1).
- Insertion or removal of elements at the end – linear in the number of elements inserted/removed: 𝓞(n).
- Insertion or removal of elements in the beginning or in the middle – linear in the number of elements inserted/removed plus the distance to the end of the vector: 𝓞(n).

### Iterator invalidation

{/* source:cpp-container-inplace-vector:0010 */}
`std::inplace_vector` iterator invalidation guarantees differ from [`std::vector`](/docs/cpp/library/container/vector):

{/* source:cpp-container-inplace-vector:0011 */}
- moving an `inplace_vector` invalidates all iterators;
- swapping two `inplace_vector`s invalidates all iterators (during swap, the iterator will continue to point to the same array element, and may thus change its value).

{/* source:cpp-container-inplace-vector:0012 */}
The following member functions potentially invalidate iterators: [`operator=`](/docs/cpp/library/container/inplace_vector/operator_assignment), [`assign`](/docs/cpp/library/container/inplace_vector/assign), [`assign_range`](/docs/cpp/library/container/inplace_vector/assign_range), [`clear`](/docs/cpp/library/container/inplace_vector/clear), [`emplace`](/docs/cpp/library/container/inplace_vector/emplace), [`erase`](/docs/cpp/library/container/inplace_vector/erase), [`insert`](/docs/cpp/library/container/inplace_vector/insert), [`insert_range`](/docs/cpp/library/container/inplace_vector/insert_range), [`pop_back`](/docs/cpp/library/container/inplace_vector/pop_back), [`resize`](/docs/cpp/library/container/inplace_vector/resize), and [`swap`](/docs/cpp/library/container/inplace_vector/swap).

{/* source:cpp-container-inplace-vector:0013 */}
The following member functions potentially invalidate [`end`](/docs/cpp/library/container/inplace_vector/end) iterator only: [`append_range`](/docs/cpp/library/container/inplace_vector/append_range), [`emplace_back`](/docs/cpp/library/container/inplace_vector/emplace_back), [`push_back`](/docs/cpp/library/container/inplace_vector/push_back), [`try_append_range`](/docs/cpp/library/container/inplace_vector/try_append_range), [`try_emplace_back`](/docs/cpp/library/container/inplace_vector/try_emplace_back), [`try_push_back`](/docs/cpp/library/container/inplace_vector/try_push_back), [`unchecked_emplace_back`](/docs/cpp/library/container/inplace_vector/unchecked_emplace_back), and [`unchecked_push_back`](/docs/cpp/library/container/inplace_vector/unchecked_push_back).

### Notes

{/* source:cpp-container-inplace-vector:0018 */}
The number of elements in a `inplace_vector` may vary dynamically up to a fixed capacity because elements are stored within the object itself similarly to [`std::array`](/docs/cpp/library/container/array). However, objects are initialized as they are inserted into `inplace_vector` unlike C arrays or [`std::array`](/docs/cpp/library/container/array), which must construct all elements on instantiation.

{/* source:cpp-container-inplace-vector:0019 */}
`inplace_vector` is useful in environments where dynamic memory allocations are undesired.

### Example

{/* source:cpp-container-inplace-vector:0021 */}
```cpp
#include <algorithm>
#include <array>
#include <cassert>
#include <inplace_vector>

int main()
{
    std::inplace_vector<int, 4> v1{0, 1, 2};
    assert(v1.max_size() == 4);
    assert(v1.capacity() == 4);
    assert(v1.size() == 3);
    assert(std::ranges::equal(v1, std::array{0, 1, 2}));
    assert(v1[0] == 0);
    assert(v1.at(0) == 0);
    assert(v1.front() == 0);
    assert(*v1.begin() == 0);
    assert(v1.back() == 2);
    v1.push_back(3);
    assert(v1.back() == 3);
    assert(std::ranges::equal(v1, std::array{0, 1, 2, 3}));
    v1.resize(3);
    assert(std::ranges::equal(v1, std::array{0, 1, 2}));
    assert(v1.try_push_back(3) != nullptr);
    assert(v1.back() == 3);
    assert(v1.size() == 4);
    assert(v1.try_push_back(13) == nullptr); // no place
    assert(v1.back() == 3);
    assert(v1.size() == 4);
    v1.clear();
    assert(v1.size() == 0);
    assert(v1.empty());
}
```
