constexpr reference unchecked_emplace_back( Args&&... args );`} />

{/* source:cpp-container-inplace-vector-unchecked-emplace-back:0001 */}
Appends a new element to the end of the container. Typically, the element is constructed using placement-`new` to construct the element in-place at the location provided by the container. The arguments `args...` are forwarded to the constructor as `std::forward<Args>(args)...`. Equivalent to `return *try_emplace_back(std::forward<Args>(args)...);`.

{/* source:cpp-container-inplace-vector-unchecked-emplace-back:0002 */}
Before the call to this function `size() < capacity()` must be `true`. Otherwise, the behavior is undefined.

{/* source:cpp-container-inplace-vector-unchecked-emplace-back:0003 */}
No iterators or references are invalidated, except [`end()`](/docs/cpp/library/container/inplace_vector/end), which is invalidated if the insertion occurs.

### Parameters

{/* source:cpp-container-inplace-vector-unchecked-emplace-back:0004 */}
<ParameterList>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

Type requirements

- `T` must be [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `inplace_vector` from `std::forward<Args>(args)...`.

### Return value

{/* source:cpp-container-inplace-vector-unchecked-emplace-back:0005 */}
[`back()`](/docs/cpp/library/container/inplace_vector/back), i.e. a reference to the inserted element.

### Complexity

{/* source:cpp-container-inplace-vector-unchecked-emplace-back:0006 */}
Constant.

### Exceptions

{/* source:cpp-container-inplace-vector-unchecked-emplace-back:0007 */}
Any exception thrown by initialization of inserted element. If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-container-inplace-vector-unchecked-emplace-back:0009 */}
```cpp
#include <inplace_vector>
#include <new>
#include <print>
#include <string>
#include <utility>
 
int main()
{
    std::inplace_vector<std::pair<std::string, std::string>, 2> fauna;
    std::string dog{"\N{DOG}"};
 
    fauna.unchecked_emplace_back("\N{CAT}", dog);
    fauna.unchecked_emplace_back("\N{CAT}", std::move(dog));
    std::println("fauna = {}", fauna);
 
    // fauna.unchecked_emplace_back("BUG", "BUG"); // undefined behavior: no space
}
```

Output:

```text
fauna = [("🐈", "🐕"), ("🐈", "🐕")]
```
