{/* source:cpp-container-inplace-vector-operator-cmp:0001 */}
Compares the contents of two std::inplace_vectors.

{/* source:cpp-container-inplace-vector-operator-cmp:0002 */}
1. Checks if the contents of `lhs` and `rhs` are equal, that is, they have the same number of elements and each element in `lhs` compares equal with the element in `rhs` at the same position.

{/* source:cpp-container-inplace-vector-operator-cmp:0003 */}
2. Compares the contents of `lhs` and `rhs` lexicographically. The comparison is performed as if by calling `std::lexicographical_compare_three_way(lhs.begin(), lhs.end(), rhs.begin(), rhs.end(), synth-three-way);`.

{/* source:cpp-container-inplace-vector-operator-cmp:0004 */}
The return type is the return type of [`synth-three-way`](/docs/cpp/library/standard_library/synth-three-way) (i.e., [`synth-three-way-result`](/docs/cpp/library/standard_library/synth-three-way)`<T>`).

{/* source:cpp-container-inplace-vector-operator-cmp:0005 */}
At least one of the following conditions must be satisfied:
- `T` models [`three_way_comparable`](/docs/cpp/library/utility/compare/three_way_comparable).
- `<` is defined for values of type (possibly const-qualified) `T`, and `<` is a total ordering relationship.

Otherwise, the behavior is undefined.

{/* source:cpp-container-inplace-vector-operator-cmp:0006 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

### Parameters

{/* source:cpp-container-inplace-vector-operator-cmp:0007 */}
<ParameterList>
  <Parameter name="lhs, rhs">std::inplace_vectors whose contents to compare</Parameter>
</ParameterList>

Type requirements: `T` must meet the requirements of [`EqualityComparable`](/docs/cpp/library/named_req/EqualityComparable) in order to use overloads (1).

### Return value

{/* source:cpp-container-inplace-vector-operator-cmp:0008 */}
1. `true` if the contents of the std::inplace_vectors are equal, `false` otherwise.

{/* source:cpp-container-inplace-vector-operator-cmp:0009 */}
2. The relative order of the first pair of non-equivalent elements in `lhs` and `rhs` if there are such elements, `lhs.size() <=> rhs.size()` otherwise.

### Complexity

{/* source:cpp-container-inplace-vector-operator-cmp:0010 */}
1. Constant if `lhs` and `rhs` are of different size, otherwise linear in the size of the std::inplace_vector.

{/* source:cpp-container-inplace-vector-operator-cmp:0011 */}
2. Linear in the size of the std::inplace_vector.

### Notes

{/* source:cpp-container-inplace-vector-operator-cmp:0012 */}
The relational operators are defined in terms of [`synth-three-way`](/docs/cpp/library/standard_library/synth-three-way), which uses `operator<=>` if possible, or `operator<` otherwise.

{/* source:cpp-container-inplace-vector-operator-cmp:0013 */}
Notably, if the element does not itself provide `operator<=>`, but is implicitly convertible to a three-way comparable type, that conversion will be used instead of `operator<`.

### Example

{/* source:cpp-container-inplace-vector-operator-cmp:0014 */}
```cpp
#include <inplace_vector>

int main()
{
    constexpr std::inplace_vector<int, 4>
        a{1, 2, 3},
        b{1, 2, 3},
        c{7, 8, 9, 10};

    static_assert
    (""
        "Compare equal containers:" &&
        (a != b) == false &&
        (a == b) == true &&
        (a < b) == false &&
        (a <= b) == true &&
        (a > b) == false &&
        (a >= b) == true &&
        (a <=> b) >= 0 &&
        (a <=> b) <= 0 &&
        (a <=> b) == 0 &&

        "Compare non equal containers:" &&
        (a != c) == true &&
        (a == c) == false &&
        (a < c) == true &&
        (a <= c) == true &&
        (a > c) == false &&
        (a >= c) == false &&
        (a <=> c) < 0 &&
        (a <=> c) != 0 &&
        (a <=> c) <= 0 &&
    "");
}
```
