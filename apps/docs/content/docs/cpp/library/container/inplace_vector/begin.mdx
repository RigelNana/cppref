{/* source:cpp-container-inplace-vector-begin:0001 */}
Returns an iterator to the first element of the `inplace_vector`.

{/* source:cpp-container-inplace-vector-begin:0002 */}
If the `inplace_vector` is empty, the returned iterator will be equal to `end()`.

### Parameters

{/* source:cpp-container-inplace-vector-begin:0003 */}
(none)

### Return value

{/* source:cpp-container-inplace-vector-begin:0004 */}
Iterator to the first element.

### Complexity

{/* source:cpp-container-inplace-vector-begin:0005 */}
Constant.
