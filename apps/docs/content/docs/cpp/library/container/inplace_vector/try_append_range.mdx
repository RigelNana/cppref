<DeclarationDoc since="C++26">
  <Declaration language="cpp" code={`template< container-compatible-range<T> R >
constexpr std::ranges::borrowed_iterator_t<R> try_append_range( R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-inplace-vector-try-append-range:0001 */}
Appends copies of initial elements in `rg` before [`end()`](/docs/cpp/library/container/inplace_vector/end), until all elements are inserted or the internal storage is exhausted (i.e. `size() == capacity()` is `true`).

{/* source:cpp-container-inplace-vector-try-append-range:0002 */}
All iterators and references remain valid. The [`end()`](/docs/cpp/library/container/inplace_vector/end) iterator is invalidated.

{/* source:cpp-container-inplace-vector-try-append-range:0003 */}
Each iterator in `rg` is dereferenced at most once.

### Parameters

{/* source:cpp-container-inplace-vector-try-append-range:0004 */}
<ParameterList>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

Type requirements: `T` must be [`EmplaceConstructible`](/docs/cpp/library/named_req/EmplaceConstructible) into `inplace_vector` from `*ranges::begin(rg)`. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-inplace-vector-try-append-range:0005 */}
An iterator pointing to the first element of `rg` that was not inserted into `*this`, or `ranges::end(rg)` if no such element exists.

### Complexity

{/* source:cpp-container-inplace-vector-try-append-range:0006 */}
Linear in the number of elements inserted.

### Exceptions

{/* source:cpp-container-inplace-vector-try-append-range:0007 */}
Any exception thrown by initialization of inserted element.

{/* source:cpp-container-inplace-vector-try-append-range:0008 */}
`inplace_vector` provides the basic exception safety guarantee, i.e., all elements of the container before the call are preserved, and all already inserted elements (before the exception, if any) are also preserved.

### Example

{/* source:cpp-container-inplace-vector-try-append-range:0010 */}
```cpp
#include <cassert>
#include <initializer_list>
#include <inplace_vector>

int main()
{
    using I = std::inplace_vector<int, 8>;
    auto nums = I{1, 2, 3};
    const auto rg = {-1, -2, -3};

    auto it = nums.try_append_range(rg);
    assert(nums.size() == 6);
    assert((nums == I{1, 2, 3, -1, -2, -3}));
    assert(it == rg.end());

    it = nums.try_append_range(rg);
    assert(nums.size() == 8);
    assert((nums == I{1, 2, 3, -1, -2, -3, -1, -2}));
    assert(it == rg.begin() + 2);
}
```
