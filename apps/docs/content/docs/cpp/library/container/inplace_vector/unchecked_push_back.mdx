{/* source:cpp-container-inplace-vector-unchecked-push-back:0001 */}
Appends the given element `value` to the end of the container.

{/* source:cpp-container-inplace-vector-unchecked-push-back:0002 */}
Equivalent to: `return *try_push_back(std::forward<decltype(value)>(value));`

{/* source:cpp-container-inplace-vector-unchecked-push-back:0003 */}
1. The new element is initialized as a copy of `value`.

{/* source:cpp-container-inplace-vector-unchecked-push-back:0004 */}
2. `value` is moved into the new element.

{/* source:cpp-container-inplace-vector-unchecked-push-back:0005 */}
Before the call to these functions `size() < capacity()` must be `true`. Otherwise, the behavior is undefined.

{/* source:cpp-container-inplace-vector-unchecked-push-back:0006 */}
No iterators or references are invalidated, except [`end()`](/docs/cpp/library/container/inplace_vector/end), which is invalidated if the insertion occurs.

### Parameters

{/* source:cpp-container-inplace-vector-unchecked-push-back:0007 */}
<ParameterList>
  <Parameter name="value">the value of the element to append</Parameter>
</ParameterList>

Type requirements

- `T` must meet the requirements of [`CopyInsertable`](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (1).
- `T` must meet the requirements of [`MoveInsertable`](/docs/cpp/library/named_req/MoveInsertable) in order to use overload (2).

### Return value

{/* source:cpp-container-inplace-vector-unchecked-push-back:0008 */}
[`back()`](/docs/cpp/library/container/inplace_vector/back), i.e. a reference to the inserted element.

### Complexity

{/* source:cpp-container-inplace-vector-unchecked-push-back:0009 */}
Constant.

### Exceptions

{/* source:cpp-container-inplace-vector-unchecked-push-back:0010 */}
Any exception thrown by initialization of inserted element.

{/* source:cpp-container-inplace-vector-unchecked-push-back:0011 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-container-inplace-vector-unchecked-push-back:0013 */}
```cpp
#include <cassert>
#include <inplace_vector>
#include <string>
 
int main()
{
    std::inplace_vector<std::string, 2> fauna;
    std::string dog{"dog"};
 
    auto& r1 = fauna.unchecked_push_back("cat"); // overload (1)
    assert(r1 == "cat" and fauna.size() == 1);
    auto& r2 = fauna.unchecked_push_back(std::move(dog)); // overload (2)
    assert(r2 == "dog" and fauna.size() == 2);
    assert(fauna[0] == "cat" and fauna[1] == "dog");
    // fauna.unchecked_push_back("bug"); // undefined behavior: there is no space
}
```
