{/* source:cpp-container-inplace-vector-max-size:0001 */}
Returns the maximum number of elements the container is able to hold.

### Parameters

{/* source:cpp-container-inplace-vector-max-size:0002 */}
(none)

### Return value

{/* source:cpp-container-inplace-vector-max-size:0003 */}
Maximum number of elements, i.e. `N`.

### Complexity

{/* source:cpp-container-inplace-vector-max-size:0004 */}
Constant.

### Notes

{/* source:cpp-container-inplace-vector-max-size:0005 */}
Because each [`std::inplace_vector<T, N>`](/docs/cpp/library/container/inplace_vector) is a fixed-capacity container, the value returned by `max_size` equals `N` (which is also the value returned by `capacity()`).

### Example

{/* source:cpp-container-inplace-vector-max-size:0006 */}
```cpp
#include <iostream>
#include <locale>
#include <inplace_vector>
 
int main()
{
    std::inplace_vector<char, 10> p;
    std::inplace_vector<long, 10> q;
 
    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << std::uppercase
              << "p.max_size() = " << std::dec << p.max_size() << " = 0x"
              << std::hex << p.max_size() << '\n'
              << "q.max_size() = " << std::dec << q.max_size() << " = 0x"
              << std::hex << q.max_size() << '\n';
}
```
Output:

```text
p.max_size() = 10 = 0xA
q.max_size() = 10 = 0xA
```
