{/* source:cpp-container-inplace-vector-push-back:0001 */}
Appends the given element `value` to the end of the container.

{/* source:cpp-container-inplace-vector-push-back:0002 */}
1. The new element is initialized as a copy of `value`.

{/* source:cpp-container-inplace-vector-push-back:0003 */}
2. `value` is moved into the new element.

{/* source:cpp-container-inplace-vector-push-back:0004 */}
No iterators or references are invalidated, except [`end()`](/docs/cpp/library/container/inplace_vector/end), which is invalidated if the insertion occurs.

### Parameters

{/* source:cpp-container-inplace-vector-push-back:0005 */}
<ParameterList>
  <Parameter name="value">the value of the element to append</Parameter>
</ParameterList>

Type requirements

- `T` must meet the requirements of [`CopyInsertable`](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (1).
- `T` must meet the requirements of [`MoveInsertable`](/docs/cpp/library/named_req/MoveInsertable) in order to use overload (2).

### Return value

{/* source:cpp-container-inplace-vector-push-back:0006 */}
[`back()`](/docs/cpp/library/container/inplace_vector/back), i.e. a reference to the inserted element.

### Complexity

{/* source:cpp-container-inplace-vector-push-back:0007 */}
Constant.

### Exceptions

{/* source:cpp-container-inplace-vector-push-back:0008 */}
- [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if `size() == capacity()` before invocation.
- Any exception thrown by initialization of inserted element.

{/* source:cpp-container-inplace-vector-push-back:0009 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-container-inplace-vector-push-back:0010 */}
```cpp
#include <inplace_vector>
#include <new>
#include <print>
#include <string>
 
int main()
{
    std::inplace_vector<std::string, 2> fauna;
    std::string dog{"\N{DOG}"};
 
    fauna.push_back("\N{CAT}"); // overload (1)
    fauna.push_back(std::move(dog)); // overload (2)
    std::println("fauna = {}", fauna);
 
    try
    {
        fauna.push_back("\N{BUG}"); // throws: there is no space
    }
    catch(const std::bad_alloc& ex)
    {
        std::println("{}", ex.what());
    }
    std::println("fauna = {}", fauna);
}
```

Possible output:

```text
fauna = ["🐈", "🐕"]
std::bad_alloc
fauna = ["🐈", "🐕"]
```
