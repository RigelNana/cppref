{/* source:cpp-container-inplace-vector-try-emplace-back:0001 */}
Conditionally appends an object of type `T` to the end of the container.

{/* source:cpp-container-inplace-vector-try-emplace-back:0002 */}
If `size() == capacity()` is `true`, there are no effects. Otherwise, appends direct-non-list-initialized with `std::forward<Args>(args)...` object of type `T`.

{/* source:cpp-container-inplace-vector-try-emplace-back:0003 */}
No iterators or references are invalidated, except [`end()`](/docs/cpp/library/container/inplace_vector/end), which is invalidated if the insertion occurs.

### Parameters

{/* source:cpp-container-inplace-vector-try-emplace-back:0004 */}
<ParameterList>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

Type requirements

- `T` must be [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `inplace_vector` from `std::forward<Args>(args)...`.

### Return value

{/* source:cpp-container-inplace-vector-try-emplace-back:0005 */}
`std::addressof(back())` if `size() < capacity()`, `nullptr` otherwise.

### Complexity

{/* source:cpp-container-inplace-vector-try-emplace-back:0006 */}
Constant.

### Exceptions

{/* source:cpp-container-inplace-vector-try-emplace-back:0007 */}
Any exception thrown by initialization of inserted element. If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-container-inplace-vector-try-emplace-back:0009 */}
```cpp
#include <cassert>
#include <complex>
#include <inplace_vector>
 
int main()
{
    using namespace std::complex_literals;
    using C = std::complex<double>;
    using I = std::inplace_vector<C, 3>;
    auto v = I{1.0 + 2.0i, 3.0 + 4.0i};
 
    C* c = v.try_emplace_back(5.0, 6.0);
    assert(*c == 5.0 + 6.0i);
    assert((v == I{1.0 + 2.0i, 3.0 + 4.0i, 5.0 + 6.0i}));
 
    c = v.try_emplace_back(7.0, 8.0); // no space => no insertion
    assert(c == nullptr);
    assert((v == I{1.0 + 2.0i, 3.0 + 4.0i, 5.0 + 6.0i}));
}
```
