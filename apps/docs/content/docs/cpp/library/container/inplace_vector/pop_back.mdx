{/* source:cpp-container-inplace-vector-pop-back:0001 */}
Removes the last element of the container.

{/* source:cpp-container-inplace-vector-pop-back:0002 */}
Calling `pop_back` on an empty container results in undefined behavior.

{/* source:cpp-container-inplace-vector-pop-back:0003 */}
Iterators and references to the last element are invalidated. The [`end()`](/docs/cpp/library/container/inplace_vector/end) iterator is also invalidated.

### Parameters

{/* source:cpp-container-inplace-vector-pop-back:0004 */}
(none)

### Return value

{/* source:cpp-container-inplace-vector-pop-back:0005 */}
(none)

### Complexity

{/* source:cpp-container-inplace-vector-pop-back:0006 */}
Constant.

### Exceptions

{/* source:cpp-container-inplace-vector-pop-back:0007 */}
Throws nothing.

### Example

{/* source:cpp-container-inplace-vector-pop-back:0008 */}
```cpp
#include <inplace_vector>
#include <print>
 
int main()
{
    std::inplace_vector<int, 4> numbers{1, 2, 3};
    for (; not numbers.empty(); numbers.pop_back())
        std::println("{}", numbers);
}
```

Output:

```text
[1, 2, 3]
[1, 2]
[1]
```
