{/* source:cpp-container-inplace-vector-reserve:0001 */}
Does nothing, except that may throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc). The request to increase the capacity (i.e., the internal storage size) is ignored because `std::inplace_vector<T, N>` is a fixed-capacity container.

### Parameters

{/* source:cpp-container-inplace-vector-reserve:0002 */}
<ParameterList>
  <Parameter name="new_cap">new capacity of the inplace_vector, in number of elements</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-inplace-vector-reserve:0003 */}
(none)

### Complexity

{/* source:cpp-container-inplace-vector-reserve:0004 */}
Constant.

### Exceptions

{/* source:cpp-container-inplace-vector-reserve:0005 */}
[`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if `new_cap > capacity()` is `true`.

### Notes

{/* source:cpp-container-inplace-vector-reserve:0006 */}
This function exists for compatibility with vector-like interfaces.

### Example

{/* source:cpp-container-inplace-vector-reserve:0007 */}
```cpp
#include <cassert>
#include <inplace_vector>
#include <iostream>

int main()
{
    std::inplace_vector<int, 4> v{1, 2, 3};
    assert(v.capacity() == 4 && v.size() == 3);

    v.reserve(2); // does nothing
    assert(v.capacity() == 4 && v.size() == 3);

    try
    {
        v.reserve(13); // throws, because requested capacity > N; v is left unchanged
    }
    catch(const std::bad_alloc& ex)
    {
        std::cout << ex.what() << '\n';
    }
    assert(v.capacity() == 4 && v.size() == 3);
}
```

Possible output:

```text
std::bad_alloc
```
