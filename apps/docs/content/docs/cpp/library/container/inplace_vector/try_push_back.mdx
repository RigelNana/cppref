{/* source:cpp-container-inplace-vector-try-push-back:0001 */}
Conditionally appends the given element `value` to the end of the container.

{/* source:cpp-container-inplace-vector-try-push-back:0002 */}
If `size() == capacity()` is `true`, there are no effects. Otherwise, appends an object of type `T`:

{/* source:cpp-container-inplace-vector-try-push-back:0003 */}
1. The new element is initialized as a copy of `value`.

{/* source:cpp-container-inplace-vector-try-push-back:0004 */}
2. `value` is moved into the new element.

{/* source:cpp-container-inplace-vector-try-push-back:0005 */}
No iterators or references are invalidated, except [`end()`](/docs/cpp/library/container/inplace_vector/end), which is invalidated if the insertion occurs.

### Parameters

{/* source:cpp-container-inplace-vector-try-push-back:0006 */}
<ParameterList>
  <Parameter name="value">the value of the element to append</Parameter>
</ParameterList>

Type requirements

- `T` must meet the requirements of [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible).

### Return value

{/* source:cpp-container-inplace-vector-try-push-back:0007 */}
`std::addressof(back())` if `size() < capacity()`, `nullptr` otherwise.

### Complexity

{/* source:cpp-container-inplace-vector-try-push-back:0008 */}
Constant.

### Exceptions

{/* source:cpp-container-inplace-vector-try-push-back:0009 */}
Any exception thrown by initialization of inserted element.

{/* source:cpp-container-inplace-vector-try-push-back:0010 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-container-inplace-vector-try-push-back:0012 */}
```cpp
#include <cassert>
#include <inplace_vector>
#include <string>
 
int main()
{
    std::inplace_vector<std::string, 2> pets;
    std::string dog{"dog"};
 
    std::string* p1 = pets.try_push_back("cat"); // overload (1)
    assert(*p1 == "cat" and pets.size() == 1);
 
    std::string* p2 = pets.try_push_back(std::move(dog)); // overload (2)
    assert(*p2 == "dog" and pets.size() == 2);
 
    assert(pets[0] == "cat" and pets[1] == "dog");
    assert(pets.size() == pets.capacity());
 
    std::string* p3 = pets.try_push_back("bug");
    assert(p3 == nullptr and pets.size() == 2);
}
```
