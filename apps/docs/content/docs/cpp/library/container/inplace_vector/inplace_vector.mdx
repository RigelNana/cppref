{/* source:cpp-container-inplace-vector-inplace-vector:0001 */}
Constructs a new `inplace_vector` from a variety of data sources.

{/* source:cpp-container-inplace-vector-inplace-vector:0002 */}
- 1) Constructs an empty `inplace_vector` whose `data() == nullptr` and `size() == 0`.

{/* source:cpp-container-inplace-vector-inplace-vector:0003 */}
- 2) Constructs an `inplace_vector` with `count` default-inserted elements.

{/* source:cpp-container-inplace-vector-inplace-vector:0004 */}
- 3) Constructs an `inplace_vector` with `count` copies of elements with value `value`.

{/* source:cpp-container-inplace-vector-inplace-vector:0005 */}
- 4) Constructs an `inplace_vector` with the contents of the range `[first, last)`.

{/* source:cpp-container-inplace-vector-inplace-vector:0006 */}
- 5) Constructs an `inplace_vector` with the contents of the range `rg`.

{/* source:cpp-container-inplace-vector-inplace-vector:0007 */}
For the definition of `/*container-compatible-range*/`, see [`ranges::to`](/docs/cpp/library/ranges/to).

{/* source:cpp-container-inplace-vector-inplace-vector:0008 */}
- 6) A [`copy constructor`](/docs/cpp/language/classes/copy_constructor). Constructs an `inplace_vector` with the copy of the contents of `other`.

{/* source:cpp-container-inplace-vector-inplace-vector:0009 */}
The constructor is a [`trivial copy constructor`](/docs/cpp/language/classes/copy_constructor#Trivial_copy_constructor) if `N > 0` and `std::is_trivially_copy_constructible_v<T>` are both `true`.

{/* source:cpp-container-inplace-vector-inplace-vector:0010 */}
- 7) A [`move constructor`](/docs/cpp/language/classes/move_constructor). Constructs an `inplace_vector` with the contents of `other` using move semantics.

{/* source:cpp-container-inplace-vector-inplace-vector:0011 */}
The constructor is a [`trivial move constructor`](/docs/cpp/language/classes/move_constructor#Trivial_move_constructor) if `N > 0` and `std::is_trivially_move_constructible_v<T>` are both `true`.

{/* source:cpp-container-inplace-vector-inplace-vector:0012 */}
- 8) Constructs an `inplace_vector` with the contents of the initializer list `init`.

### Parameters

{/* source:cpp-container-inplace-vector-inplace-vector:0013 */}
<ParameterList>
  <Parameter name="count">the size of the container</Parameter>
  <Parameter name="value">the value to initialize elements of the container with</Parameter>
  <Parameter name="first, last">the range `[first, last)` to copy the elements from</Parameter>
  <Parameter name="rg">the range of values to initialize elements of the container with</Parameter>
  <Parameter name="other">another `inplace_vector` to be used as source to initialize the elements of the container with</Parameter>
  <Parameter name="init">initializer list to initialize the elements of the container with</Parameter>
</ParameterList>

Type requirements

- `T` must meet the requirements of [`DefaultInsertable`](/docs/cpp/library/named_req/DefaultInsertable) in order to use overloads (2,3).

### Complexity

{/* source:cpp-container-inplace-vector-inplace-vector:0014 */}
- 1) Constant.

{/* source:cpp-container-inplace-vector-inplace-vector:0015 */}
- 2,3) Linear in `count`.

{/* source:cpp-container-inplace-vector-inplace-vector:0016 */}
- 4) Linear in `std::distance(first, last)`.

{/* source:cpp-container-inplace-vector-inplace-vector:0017 */}
- 5) Linear in `std::ranges::distance(rg)`.

{/* source:cpp-container-inplace-vector-inplace-vector:0018 */}
- 6,7) Linear in size of `other`.

{/* source:cpp-container-inplace-vector-inplace-vector:0019 */}
- 8) Linear in size of `init`.

### Exceptions

{/* source:cpp-container-inplace-vector-inplace-vector:0020 */}
- 2,3) Throws [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if `count > N`.

{/* source:cpp-container-inplace-vector-inplace-vector:0021 */}
- 5) Throws [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if `std::ranges::size(rg) > N`.

{/* source:cpp-container-inplace-vector-inplace-vector:0022 */}
- 8) Throws [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if `init.size() > N`.

### Example

{/* source:cpp-container-inplace-vector-inplace-vector:0023 */}
```cpp
#include <cassert>
#include <initializer_list>
#include <inplace_vector>
#include <new>
#include <print>
#include <ranges>
 
int main()
{
    std::inplace_vector<int, 4> v1; // overload (1)
    assert(v1.size() == 0 && v1.capacity() == 4);
 
    std::inplace_vector<int, 0> v2; // overload (1), N == 0 is allowed
    assert(v2.size() == 0 && v2.capacity() == 0);
 
    std::inplace_vector<int, 5> v3(3); // overload (2)
    assert(v3.size() == 3 && v3.capacity() == 5);
    std::println("v3 = {}", v3);
 
    try
    {
        std::inplace_vector<int, 3> v(4); // overload (2), throws: count > N
    }
    catch(const std::bad_alloc& ex1)
    {
        std::println("ex1.what(): {}", ex1.what());
    }
 
    std::inplace_vector<int, 5> v4(3, 8); // overload (3)
    assert(v4.size() == 3 && v4.capacity() == 5);
    std::println("v4 = {}", v4);
 
    try
    {
        std::inplace_vector<int, 3> v(4, 2); // overload (3), throws: count > N
    }
    catch(const std::bad_alloc& ex2)
    {
        std::println("ex2.what(): {}", ex2.what());
    }
 
    const auto init = {1, 2, 3};
 
    std::inplace_vector<int, 4> v5(init.begin(), init.end()); // overload (4)
    assert(v5.size() == 3 && v5.capacity() == 4);
    std::println("v5 = {}", v5);
 
    std::inplace_vector<int, 4> v6(std::from_range, init); // overload (5)
    assert(v6.size() == 3 && v6.capacity() == 4);
    std::println("v6 = {}", v6);
 
    std::inplace_vector<int, 4> v7(v6); // overload (6)
    assert(v7.size() == 3 && v7.capacity() == 4);
    std::println("v7 = {}", v7);
    assert(v6.size() == 3);
 
    std::inplace_vector<int, 4> v8(std::move(v6)); // overload (7)
    // Note that after the move v6 is left in valid but indeterminate state.
    assert(v8.size() == 3 && v8.capacity() == 4);
    std::println("v8 = {}", v8);
 
    std::inplace_vector<int, 4> v9(init); // overload (8)
    assert(v9.size() == 3 && v9.capacity() == 4);
    std::println("v9 = {}", v9);
 
    try
    {
        std::inplace_vector<int, 2> v(init); // overload (8), throws: init.size() > N
    }
    catch(const std::bad_alloc& ex3)
    {
        std::println("ex3.what(): {}", ex3.what());
    }
}
```
Possible output:

```text
v3 = [0, 0, 0]
ex1.what(): std::bad_alloc
v4 = [42, 42, 42]
ex2.what(): std::bad_alloc
v5 = [1, 2, 3]
v6 = [1, 2, 3]
v7 = [1, 2, 3]
v8 = [1, 2, 3]
v9 = [1, 2, 3]
ex3.what(): std::bad_alloc
```
