{/* source:cpp-container-inplace-vector-size:0001 */}
Returns the number of elements in the container, i.e. `std::distance(begin(), end())`.

### Parameters

{/* source:cpp-container-inplace-vector-size:0002 */}
(none)

### Return value

{/* source:cpp-container-inplace-vector-size:0003 */}
The number of elements in the container.

### Complexity

{/* source:cpp-container-inplace-vector-size:0004 */}
Constant.

### Example

{/* source:cpp-container-inplace-vector-size:0005 */}
```cpp
#include <cassert>
#include <inplace_vector>
 
int main()
{
    std::inplace_vector<int, 4> nums;
    assert(nums.size() == 0);
    nums = {1, 2, 3, 4};
    assert(nums.size() == 4);
}
```
