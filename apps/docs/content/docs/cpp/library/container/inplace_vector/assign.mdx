{/* source:cpp-container-inplace-vector-assign:0001 */}
Replaces the contents of the container.

{/* source:cpp-container-inplace-vector-assign:0002 */}
- 1) Replaces the contents with `count` copies of value `value`.

{/* source:cpp-container-inplace-vector-assign:0003 */}
- 2) Replaces the contents with copies of those in the range `[first, last)`.

{/* source:cpp-container-inplace-vector-assign:0004 */}
If either argument is an iterator into `*this`, the behavior is undefined. This overload participates in overload resolution only if `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

{/* source:cpp-container-inplace-vector-assign:0005 */}
- 3) Replaces the contents with the elements from `ilist`.

### Parameters

{/* source:cpp-container-inplace-vector-assign:0007 */}
<ParameterList>
  <Parameter name="count">the new size of the container</Parameter>
  <Parameter name="value">the value to initialize elements of the container with</Parameter>
  <Parameter name="first, last">the range to copy the elements from</Parameter>
  <Parameter name="ilist">[`std::initializer_list`](/docs/cpp/library/utility/initializer_list) to copy the values from</Parameter>
</ParameterList>

### Complexity

{/* source:cpp-container-inplace-vector-assign:0008 */}
- 1) Linear in `count`.

{/* source:cpp-container-inplace-vector-assign:0009 */}
- 2) Linear in distance between `first` and `last`.

{/* source:cpp-container-inplace-vector-assign:0010 */}
- 3) Linear in `ilist.size()`.

### Exceptions

{/* source:cpp-container-inplace-vector-assign:0011 */}
- 1) [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc), if `count > capacity()`.

{/* source:cpp-container-inplace-vector-assign:0012 */}
- 2) [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc), if `std::ranges::distance(first, last) > capacity()`.

{/* source:cpp-container-inplace-vector-assign:0013 */}
- 3) [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc), if `ilist.size() > capacity()`.

{/* source:cpp-container-inplace-vector-assign:0014 */}
- 1-3) Any exception thrown by initialization of inserted elements.

### Example

{/* source:cpp-container-inplace-vector-assign:0015 */}
The following code uses `assign` to add several characters to a `std::inplace_vector<char, 5>`:

```cpp
#include <inplace_vector>
#include <iterator>
#include <new>
#include <print>
 
int main()
{
    std::inplace_vector<char, 5> chars;
 
    chars.assign(4, 'a'); // overload (1)
    std::println("{}", chars);
 
    const char extra[3]{'a', 'b', 'c'};
    chars.assign(std::cbegin(extra), std::cend(extra)); // overload (2)
    std::println("{}", chars);
 
    chars.assign({'C', '+', '+', '2', '6'}); // overload (3)
    std::println("{}", chars);
 
    try
    {
        chars.assign(8, 'x'); // throws: count > chars.capacity()
    }
    catch(const std::bad_alloc&) { std::println("std::bad_alloc #1"); }
 
    try
    {
        const char bad[8]{'?'}; // ranges::distance(bad) > chars.capacity()
        chars.assign(std::cbegin(bad), std::cend(bad)); // throws
    }
    catch(const std::bad_alloc&) { std::println("std::bad_alloc #2"); }
 
    try
    {
        const auto l = {'1', '2', '3', '4', '5', '6'};
        chars.assign(l); // throws: l.size() > chars.capacity()
    }
    catch(const std::bad_alloc&) { std::println("std::bad_alloc #3"); }
}
```
Output:

```text
['a', 'a', 'a', 'a']
['a', 'b', 'c']
['C', '+', '+', '2', '6']
std::bad_alloc #1
std::bad_alloc #2
std::bad_alloc #3
```
