{/* source:cpp-container-inplace-vector-insert:0001 */}
Inserts elements at the specified location in the container.

{/* source:cpp-container-inplace-vector-insert:0002 */}
1. Inserts a copy of `value` before `pos`.

{/* source:cpp-container-inplace-vector-insert:0003 */}
2. Inserts `value` before `pos`, possibly using move semantics.

{/* source:cpp-container-inplace-vector-insert:0004 */}
3. Inserts `count` copies of the `value` before `pos`.

{/* source:cpp-container-inplace-vector-insert:0005 */}
4. Inserts elements from range `[first, last)` before `pos`. This overload participates in overload resolution only if `InputIt` is [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator) (to avoid ambiguity with the overload (3)).

{/* source:cpp-container-inplace-vector-insert:0006 */}
- Each iterator in `[first, last)` is dereferenced once.

{/* source:cpp-container-inplace-vector-insert:0007 */}
- If `first` and `last` are iterators into `*this`, the behavior is undefined.

{/* source:cpp-container-inplace-vector-insert:0008 */}
5. Inserts elements from initializer list `ilist` before `pos`. Equivalent to: `insert(pos, ilist.begin(), ilist.end());`.

### Parameters

{/* source:cpp-container-inplace-vector-insert:0009 */}
<ParameterList>
  <Parameter name="pos">iterator before which the content will be inserted (`pos` may be the [`end()`](/docs/cpp/library/container/inplace_vector/end) iterator)</Parameter>
  <Parameter name="value">element value to insert</Parameter>
  <Parameter name="count">number of elements to insert</Parameter>
  <Parameter name="first, last">the range of elements to insert</Parameter>
  <Parameter name="ilist">[`std::initializer_list`](/docs/cpp/library/utility/initializer_list) to insert the values from</Parameter>
</ParameterList>

Type requirements

- `T` must meet the requirements of [*CopyInsertable*](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (1).
- `T` must meet the requirements of [*MoveInsertable*](/docs/cpp/library/named_req/MoveInsertable) in order to use overload (2).
- `T` must meet the requirements of [*CopyAssignable*](/docs/cpp/library/named_req/CopyAssignable) and [*CopyInsertable*](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (3).
- `T` must meet the requirements of [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) in order to use overloads (4,5).

### Return value

{/* source:cpp-container-inplace-vector-insert:0010 */}
1,2. Iterator pointing to the inserted `value`.

{/* source:cpp-container-inplace-vector-insert:0011 */}
3. Iterator pointing to the first element inserted, or `pos` if `count == 0`.

{/* source:cpp-container-inplace-vector-insert:0012 */}
4. Iterator pointing to the first element inserted, or `pos` if `first == last`.

{/* source:cpp-container-inplace-vector-insert:0013 */}
5. Iterator pointing to the first element inserted, or `pos` if `ilist` is empty.

### Complexity

{/* source:cpp-container-inplace-vector-insert:0014 */}
Linear in the number of elements inserted plus the distance between `pos` and [`end()`](/docs/cpp/library/container/inplace_vector/end) of the container.

### Exceptions

{/* source:cpp-container-inplace-vector-insert:0015 */}
- Throws [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if before invocation `size() == capacity()`. The function has no effects ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).
- Any exception thrown by initialization of inserted element or by any [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator) operation. Elements in `[0, pos)` are not modified.

### Example

{/* source:cpp-container-inplace-vector-insert:0016 */}
```cpp
#include <initializer_list>
#include <inplace_vector>
#include <iterator>
#include <new>
#include <print>
 
int main()
{
    std::inplace_vector<int, 14> v(3, 100);
    std::println("1. {}", v);
 
    auto pos = v.begin();
    pos = v.insert(pos, 200); // overload (1)
    std::println("2. {}", v);
 
    v.insert(pos, 2, 300); // overload (3)
    std::println("3. {}", v);
 
    int arr[] = {501, 502, 503};
    v.insert(v.begin(), arr, arr + std::size(arr)); // overload (4)
    std::println("4. {}", v);
 
    v.insert(v.end(), {601, 602, 603}); // overload (5)
    std::println("5. {}", v);
 
    const auto list = {-13, -12, -11};
    try
    {
        v.insert(v.begin(), list); // throws: no space
    }
    catch(const std::bad_alloc&)
    {
        std::println("bad_alloc: v.capacity()={} < v.size()={} + list.size()={}",
                     v.capacity(), v.size(), list.size());
    }
}
```

Output:

```text
1. [100, 100, 100]
2. [200, 100, 100, 100]
3. [300, 300, 200, 100, 100, 100]
4. [501, 502, 503, 300, 300, 200, 100, 100, 100]
5. [501, 502, 503, 300, 300, 200, 100, 100, 100, 601, 602, 603]
bad_alloc: v.capacity()=14 < v.size()=12 + list.size()=3
```
