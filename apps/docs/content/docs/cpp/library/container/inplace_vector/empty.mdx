{/* source:cpp-container-inplace-vector-empty:0001 */}
Checks if the container has no elements, i.e. whether `begin() == end()`.

### Parameters

{/* source:cpp-container-inplace-vector-empty:0002 */}
(none)

### Return value

{/* source:cpp-container-inplace-vector-empty:0003 */}
`true` if the container is empty, `false` otherwise.

### Complexity

{/* source:cpp-container-inplace-vector-empty:0004 */}
Constant.

### Example

{/* source:cpp-container-inplace-vector-empty:0005 */}
```cpp
#include <cassert>
#include <inplace_vector>
 
int main()
{
    std::inplace_vector<char, 8> v;
    assert(v.empty());
 
    v.push_back('_');
    assert(not v.empty());
}
```
