{/* source:cpp-container-inplace-vector-back:0001 */}
Returns a reference to the last element in the container.

{/* source:cpp-container-inplace-vector-back:0002 */}
Calling `back` on an empty container causes [undefined behavior](/docs/cpp/language/basic_concepts/ub).

### Parameters

{/* source:cpp-container-inplace-vector-back:0003 */}
(none)

### Return value

{/* source:cpp-container-inplace-vector-back:0004 */}
Reference to the last element.

### Complexity

{/* source:cpp-container-inplace-vector-back:0005 */}
Constant.

### Notes

{/* source:cpp-container-inplace-vector-back:0006 */}
For a non-empty container `c`, the expression `c.back()` is equivalent to `*std::prev(c.end())`.

### Example

{/* source:cpp-container-inplace-vector-back:0007 */}
```cpp
#include <cassert>
#include <inplace_vector>

int main()
{
    std::inplace_vector<char, 4> letters{'a', 'b', 'c', 'd'};
    assert(letters.back() == 'd');
}
```
