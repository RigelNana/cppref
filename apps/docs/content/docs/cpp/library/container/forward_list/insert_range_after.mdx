<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`template< container-compatible-range<T> R >
iterator insert_range_after( const_iterator pos, R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-forward-list-insert-range-after:0001 */}
Inserts, in non-reversing order, the copies of elements in `rg` before `pos`. Each iterator in the range `rg` is dereferenced exactly once.

{/* source:cpp-container-forward-list-insert-range-after:0002 */}
`pos` must be any dereferenceable iterator in the range [`[`begin()`](/docs/cpp/library/container/forward_list/begin)`, `[`end()`](/docs/cpp/library/container/forward_list/end)`)` or the [`before_begin()`](/docs/cpp/library/container/forward_list/before_begin) iterator (thus, [`end()`](/docs/cpp/library/container/forward_list/end) is not a valid argument for `pos`).

{/* source:cpp-container-forward-list-insert-range-after:0003 */}
No iterators or references become invalidated.

{/* source:cpp-container-forward-list-insert-range-after:0004 */}
The behavior is undefined if `rg` overlaps with the container.

### Parameters

{/* source:cpp-container-forward-list-insert-range-after:0005 */}
<ParameterList>
  <Parameter name="pos">an iterator after which the content will be inserted</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

Type requirements

- `T` must be [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `forward_list` from `*ranges::begin(rg)`. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-forward-list-insert-range-after:0006 */}
An [`iterator`](/docs/cpp/library/container/forward_list#Member_types) that points at the copy of the last element inserted into `forward_list` or at `pos` if `rg` is empty.

### Complexity

{/* source:cpp-container-forward-list-insert-range-after:0007 */}
Linear in size of `rg`.

### Example

{/* source:cpp-container-forward-list-insert-range-after:0009 */}
```cpp
#include <algorithm>
#include <cassert>
#include <forward_list>
#include <iterator>
#include <vector>

int main()
{
    auto container = std::forward_list{1, 2, 3, 4};
    auto pos = std::next(container.cbegin());
    assert(*pos == 2);
    const auto rg = std::vector{-1, -2, -3};

#ifdef __cpp_lib_containers_ranges
    container.insert_range_after(pos, rg);
#else
    container.insert_after(pos, rg.cbegin(), rg.cend());
#endif

    assert(std::ranges::equal(container, std::vector{1, 2, -1, -2, -3, 3, 4}));
}
```
