{/* source:cpp-container-forward-list-erase-after:0001 */}
Removes specified elements from the container.

{/* source:cpp-container-forward-list-erase-after:0002 */}
1. Removes the element following `pos`.

{/* source:cpp-container-forward-list-erase-after:0003 */}
2. Removes the elements following `first` until `last`.

### Parameters

{/* source:cpp-container-forward-list-erase-after:0004 */}
<ParameterList>
  <Parameter name="pos">iterator to the element preceding the element to remove</Parameter>
  <Parameter name="first, last">range of elements to remove</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-forward-list-erase-after:0005 */}
1. Iterator to the element following the erased one, or [`end()`](/docs/cpp/library/container/forward_list/end) if no such element exists.

{/* source:cpp-container-forward-list-erase-after:0006 */}
2. `last`

### Complexity

{/* source:cpp-container-forward-list-erase-after:0007 */}
1. Constant.

{/* source:cpp-container-forward-list-erase-after:0008 */}
2. Linear in distance between `first` and `last`.

### Example

{/* source:cpp-container-forward-list-erase-after:0009 */}
```cpp
#include <forward_list>
#include <iostream>
#include <iterator>
 
int main()
{
    std::forward_list<int> l = {1, 2, 3, 4, 5, 6, 7, 8, 9};
 
//  l.erase(l.begin()); // Error: no function erase()
 
    l.erase_after(l.before_begin()); // Removes first element
 
    for (auto n : l)
        std::cout << n << ' ';
    std::cout << '\n';
 
    auto fi = std::next(l.begin());
    auto la = std::next(fi, 3);
 
    l.erase_after(fi, la);
 
    for (auto n : l)
        std::cout << n << ' ';
    std::cout << '\n';
}
```

Output:

```text
2 3 4 5 6 7 8 9
2 3 6 7 8 9
```
