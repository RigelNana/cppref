<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++11" code={`void resize( size_type count );`} />
  <Declaration id="2" language="cpp" since="C++11" code={`void resize( size_type count, const value_type& value );`} />
</DeclarationDoc>

{/* source:cpp-container-forward-list-resize:0001 */}
Resizes the container to contain `count` elements, does nothing if `count == std::distance(begin(), end())` (i.e. if `count` is equal to the current size).

{/* source:cpp-container-forward-list-resize:0002 */}
If the current size is greater than `count`, the container is reduced to its first `count` elements.

{/* source:cpp-container-forward-list-resize:0003 */}
If the current size is less than `count`, then:

{/* source:cpp-container-forward-list-resize:0004 */}
- 1) Additional [default-inserted](/docs/cpp/library/named_req/DefaultInsertable) elements are appended.

{/* source:cpp-container-forward-list-resize:0005 */}
- 2) Additional copies of `value` are appended.

### Parameters

{/* source:cpp-container-forward-list-resize:0006 */}
<ParameterList>
  <Parameter name="count">new size of the container</Parameter>
  <Parameter name="value">the value to initialize the new elements with</Parameter>
</ParameterList>

Type requirements

- `T` must meet the requirements of [*DefaultInsertable*](/docs/cpp/library/named_req/DefaultInsertable) in order to use overload (1).
- `T` must meet the requirements of [*CopyInsertable*](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (2).

### Complexity

{/* source:cpp-container-forward-list-resize:0007 */}
Linear in the difference between the current size and `count`. Additional complexity possible due to list traversal to reach the first element to erase/the end position to insert.

### Notes

{/* source:cpp-container-forward-list-resize:0008 */}
If value-initialization in overload ([1](/docs/cpp/library/container/forward_list/resize#Version_1)) is undesirable, for example, if the elements are of non-class type and zeroing out is not needed, it can be avoided by providing a [custom `Allocator::construct`](https://stackoverflow.com/a/21028912/273767).

### Example

{/* source:cpp-container-forward-list-resize:0009 */}
```cpp
#include <forward_list>
#include <iostream>

void print(auto rem, const std::forward_list<int>& c)
{
    for (std::cout << rem; const int el : c)
        std::cout << el << ' ';
    std::cout << '\n';
}

int main()
{
    std::forward_list<int> c = {1, 2, 3};
    print("The forward_list holds: ", c);

    c.resize(5);
    print("After resize up to 5: ", c);

    c.resize(2);
    print("After resize down to 2: ", c);

    c.resize(6, 4);
    print("After resize up to 6 (initializer = 4): ", c);
}
```

Output:

```text
The forward_list holds: 1 2 3
After resize up to 5: 1 2 3 0 0
After resize down to 2: 1 2
After resize up to 6 (initializer = 4): 1 2 4 4 4 4
```
