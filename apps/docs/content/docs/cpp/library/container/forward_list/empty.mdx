{/* source:cpp-container-forward-list-empty:0001 */}
Checks if the container has no elements, i.e. whether `begin() == end()`.

### Parameters

{/* source:cpp-container-forward-list-empty:0002 */}
(none)

### Return value

{/* source:cpp-container-forward-list-empty:0003 */}
`true` if the container is empty, `false` otherwise.

### Complexity

{/* source:cpp-container-forward-list-empty:0004 */}
Constant.

### Example

{/* source:cpp-container-forward-list-empty:0005 */}
The following code uses `empty` to check if a `std::forward_list<int>` contains any elements:

```cpp
#include <forward_list>
#include <iostream>

int main()
{
    std::forward_list<int> numbers;
    std::cout << std::boolalpha;
    std::cout << "Initially, numbers.empty(): " << numbers.empty() << '\n';

    numbers.push_front(42);
    numbers.push_front(13317); 
    std::cout << "After adding elements, numbers.empty(): " << numbers.empty() << '\n';
}
```

Output:

```text
Initially, numbers.empty(): true
After adding elements, numbers.empty(): false
```
