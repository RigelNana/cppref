{/* source:cpp-container-forward-list-insert-after:0001 */}
Inserts elements after the specified position in the container.

{/* source:cpp-container-forward-list-insert-after:0002 */}
1,2) Inserts `value` after the element pointed to by `pos`.

{/* source:cpp-container-forward-list-insert-after:0003 */}
3) Inserts `count` copies of the `value` after the element pointed to by `pos`.

{/* source:cpp-container-forward-list-insert-after:0004 */}
4) Inserts elements from range [`first`, `last`) after the element pointed to by `pos`. The behavior is undefined if `first` and `last` are iterators into `*this`.

{/* source:cpp-container-forward-list-insert-after:0005 */}
5) Inserts elements from initializer list `ilist`.

{/* source:cpp-container-forward-list-insert-after:0006 */}
No iterators or references are invalidated.

### Parameters

{/* source:cpp-container-forward-list-insert-after:0007 */}
<ParameterList>
  <Parameter name="pos">iterator after which the content will be inserted</Parameter>
  <Parameter name="value">element value to insert</Parameter>
  <Parameter name="count">number of copies to insert</Parameter>
  <Parameter name="first, last">the range of elements to insert</Parameter>
  <Parameter name="ilist">initializer list to insert the values from</Parameter>
</ParameterList>

**Type requirements**

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).

### Return value

{/* source:cpp-container-forward-list-insert-after:0008 */}
1,2) Iterator to the inserted element.

{/* source:cpp-container-forward-list-insert-after:0009 */}
3) Iterator to the last element inserted, or `pos` if `count == 0`.

{/* source:cpp-container-forward-list-insert-after:0010 */}
4) Iterator to the last element inserted, or `pos` if `first == last`.

{/* source:cpp-container-forward-list-insert-after:0011 */}
5) Iterator to the last element inserted, or `pos` if `ilist` is empty.

### Exceptions

{/* source:cpp-container-forward-list-insert-after:0012 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-container-forward-list-insert-after:0013 */}
1,2) Constant.

{/* source:cpp-container-forward-list-insert-after:0014 */}
3) Linear in `count`.

{/* source:cpp-container-forward-list-insert-after:0015 */}
4) Linear in `std::distance(first, last)`.

{/* source:cpp-container-forward-list-insert-after:0016 */}
5) Linear in `ilist.size()`.

### Example

{/* source:cpp-container-forward-list-insert-after:0017 */}
```cpp
#include <forward_list>
#include <iostream>
#include <string>
#include <vector>
 
void print(const std::forward_list<int>& list)
{
    std::cout << "list: {";
    for (char comma[3] = {'\0', ' ', '\0'}; int i : list)
    {
        std::cout << comma << i;
        comma[0] = ',';
    }
    std::cout << "}\n";
}
 
int main()
{
    std::forward_list<int> ints{1, 2, 3, 4, 5};
    print(ints);
 
    // insert_after (2)
    auto beginIt = ints.begin();
    ints.insert_after(beginIt, -6);
    print(ints);
 
    // insert_after (3)
    auto anotherIt = beginIt;
    ++anotherIt;
    anotherIt = ints.insert_after(anotherIt, 2, -7);
    print(ints);
 
    // insert_after (4)
    const std::vector<int> v = {-8, -9, -10};
    anotherIt = ints.insert_after(anotherIt, v.cbegin(), v.cend());
    print(ints);
 
    // insert_after (5)
    ints.insert_after(anotherIt, {-11, -12, -13, -14});
    print(ints);
}
```

Output:

```text
list: {1, 2, 3, 4, 5}
list: {1, -6, 2, 3, 4, 5}
list: {1, -6, -7, -7, 2, 3, 4, 5}
list: {1, -6, -7, -7, -8, -9, -10, 2, 3, 4, 5}
list: {1, -6, -7, -7, -8, -9, -10, -11, -12, -13, -14, 2, 3, 4, 5}
```
