  <Declaration language="cpp" since="C++23" code={`template< container-compatible-range<T> R >
void assign_range( R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-forward-list-assign-range:0001 */}
Replaces elements in the container with a copy of each element in `rg`.

{/* source:cpp-container-forward-list-assign-range:0002 */}
All iterators (including the [`end()`](/docs/cpp/library/container/forward_list/end) iterator) and all references to the elements are invalidated.

{/* source:cpp-container-forward-list-assign-range:0003 */}
Each iterator in the range `rg` is dereferenced exactly once.

{/* source:cpp-container-forward-list-assign-range:0004 */}
The behavior is undefined if `rg` overlaps with the container.

### Parameters

{/* source:cpp-container-forward-list-assign-range:0005 */}
<ParameterList>
  <Parameter name="rg">an [`input_range`](/docs/cpp/library/ranges/input_range) with reference type convertible to the element type of the container</Parameter>
</ParameterList>

**Type requirements**

- `std::assignable_from<T&, ranges::range_reference_t<R>>` must be modeled. Otherwise, the program is ill-formed.
- `T` must be [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into the container from `*ranges::begin(rg)`. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-forward-list-assign-range:0006 */}
(none)

{/* source:cpp-container-forward-list-assign-range:0007 */}

### Example

{/* source:cpp-container-forward-list-assign-range:0008 */}
```cpp
#include <algorithm>
#include <cassert>
#include <forward_list>
#include <list>
 
int main()
{
    const auto source = std::list{2, 7, 1};
    auto destination = std::forward_list{3, 1, 4};
#ifdef __cpp_lib_containers_ranges
    destination.assign_range(source);
#else
    destination.assign(source.cbegin(), source.cend());
#endif
    assert(std::ranges::equal(source, destination));
}
```
