{/* source:cpp-container-forward-list-front:0001 */}
Returns a reference to the first element in the container.

{/* source:cpp-container-forward-list-front:0002 */}
Calling `front` on an empty container causes undefined behavior.

### Parameters

{/* source:cpp-container-forward-list-front:0003 */}
(none)

### Return value

{/* source:cpp-container-forward-list-front:0004 */}
Reference to the first element.

### Complexity

{/* source:cpp-container-forward-list-front:0005 */}
Constant.

### Notes

{/* source:cpp-container-forward-list-front:0006 */}
For a container `c`, the expression `c.front()` is equivalent to `*c.begin()`.

### Example

{/* source:cpp-container-forward-list-front:0007 */}
The following code uses `front` to display the first element of a `std::forward_list<char>`:

```cpp
#include <cassert>
#include <forward_list>

int main()
{
    std::forward_list<char> letters{'a', 'b', 'c', 'd'};
    assert(letters.front() == 'a');
}
```
