{/* source:cpp-container-forward-list-splice-after:0001 */}
Moves elements from another `forward_list` to `*this`. The elements are inserted after the element pointed to by `pos`.

{/* source:cpp-container-forward-list-splice-after:0002 */}
No elements are copied. No iterators or references become invalidated. The iterators to the moved elements now refer into `*this`, not into `other`.

{/* source:cpp-container-forward-list-splice-after:0003 */}
- 1,2) Moves all elements from `other` into `*this`. The container `other` becomes empty after the operation.

{/* source:cpp-container-forward-list-splice-after:0004 */}
- 3,4) Moves the element pointed to by the iterator following `it` from `other` into `*this`. Has no effect if `pos == it` or if `pos == ++it`.

{/* source:cpp-container-forward-list-splice-after:0005 */}
- 5,6) Moves the elements in the range `(first, last)` from `other` into `*this`. The element pointed-to by `first` is not moved.

{/* source:cpp-container-forward-list-splice-after:0006 */}
The behavior is undefined if

{/* source:cpp-container-forward-list-splice-after:0007 */}
- `get_allocator() != other.get_allocator()`,
- `pos` is neither `before_begin()` nor a [dereferenceable iterator](/docs/cpp/library/iterator#Dereferenceability_and_validity) in `[begin(), end())`,
- for overloads (1,2), `*this` and `other` refer to the same object,
- for overloads (3,4), the iterator following `it` is not a [dereferenceable iterator](/docs/cpp/library/iterator#Dereferenceability_and_validity) into `other`, or
- for overloads (5,6),

{/* source:cpp-container-forward-list-splice-after:0008 */}
  - `(first, last)` is not a [valid range](/docs/cpp/library/iterator#Ranges) in `other`,
  - some iterators in `(first, last)` are not [dereferenceable](/docs/cpp/library/iterator#Dereferenceability_and_validity), or
  - `pos` is in `(first, last)`.

### Parameters

### Exceptions

{/* source:cpp-container-forward-list-splice-after:0010 */}
Throws nothing.

### Complexity

{/* source:cpp-container-forward-list-splice-after:0011 */}
- 1,2) Linear in the size of `other`.

{/* source:cpp-container-forward-list-splice-after:0012 */}
- 3,4) Constant.

{/* source:cpp-container-forward-list-splice-after:0013 */}
- 5,6) Linear in `std::distance(first, last)`.

### Example

{/* source:cpp-container-forward-list-splice-after:0014 */}
```cpp
#include <cassert>
#include <forward_list>

int main()
{
    using F = std::forward_list<int>;

    // Demonstrate the meaning of open range (first, last)
    // in overload (5): the first element of l1 is not moved.
    F l1 = {1, 2, 3, 4, 5};
    F l2 = {10, 11, 12};

    l2.splice_after(l2.cbegin(), l1, l1.cbegin(), l1.cend());
    // Not equivalent to l2.splice_after(l2.cbegin(), l1);
    // which is equivalent to
    // l2.splice_after(l2.cbegin(), l1, l1.cbefore_begin(), l1.end());

    assert((l1 == F{1}));
    assert((l2 == F{10, 2, 3, 4, 5, 11, 12}));

    // Overload (1)
    F x = {1, 2, 3, 4, 5};
    F y = {10, 11, 12};
    x.splice_after(x.cbegin(), y);
    assert((x == F{1, 10, 11, 12, 2, 3, 4, 5}));
    assert((y == F{}));

    // Overload (3)
    x = {1, 2, 3, 4, 5};
    y = {10, 11, 12};
    x.splice_after(x.cbegin(), y, y.cbegin());
    assert((x == F{1, 11, 2, 3, 4, 5}));
    assert((y == F{10, 12}));

    // Overload (5)
    x = {1, 2, 3, 4, 5};
    y = {10, 11, 12};
    x.splice_after(x.cbegin(), y, y.cbegin(), y.cend());
    assert((x == F{1, 11, 12, 2, 3, 4, 5}));
    assert((y == F{10}));
}
```
