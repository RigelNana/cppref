{/* source:cpp-container-forward-list:0001 */}
`std::forward_list` is a container that supports fast insertion and removal of elements from anywhere in the container. Fast random access is not supported. It is implemented as a singly-linked list. Compared to [`std::list`](/docs/cpp/library/container/list) this container provides more space efficient storage when bidirectional iteration is not needed.

{/* source:cpp-container-forward-list:0002 */}
Adding, removing and moving the elements within the list, or across several lists, does not invalidate the iterators currently referring to other elements in the list. However, an iterator or reference referring to an element is invalidated when the corresponding element is removed (via [`erase_after`](/docs/cpp/library/container/forward_list/erase_after)) from the list.

{/* source:cpp-container-forward-list:0003 */}
`std::forward_list` meets the requirements of [`Container`](/docs/cpp/library/named_req/Container) (except for the `size` member function and that `operator==`'s complexity is always linear), [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer) and [`SequenceContainer`](/docs/cpp/library/named_req/SequenceContainer).

    </Revision>
    <Revision since="C++17">
    The requirements that are imposed on the elements depend on the actual operations performed on the container. Generally, it is required that element type meets the requirements of [`Erasable`](/docs/cpp/library/named_req/Erasable), but many member functions impose stricter requirements. This container (but not its members) can be instantiated with an incomplete element type if the allocator satisfies the [allocator completeness requirements](/docs/cpp/library/named_req/Allocator#Allocator_completeness_requirements).
