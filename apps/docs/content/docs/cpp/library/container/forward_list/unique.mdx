{/* source:cpp-container-forward-list-unique:0001 */}
Removes all consecutive duplicate elements from the container. Only the first element in each group of equal elements is left. Invalidates only the iterators and references to the removed elements.

{/* source:cpp-container-forward-list-unique:0002 */}
1. Uses `operator==` to compare the elements.

{/* source:cpp-container-forward-list-unique:0003 */}
2. Uses `p` to compare the elements.

{/* source:cpp-container-forward-list-unique:0004 */}
The behavior is undefined if the corresponding comparator does not establish an equivalence relation.

### Parameters

{/* source:cpp-container-forward-list-unique:0005 */}
<ParameterList>
  <Parameter name="p">binary predicate which returns `true` if the elements should be treated as equal.
The signature of the predicate function should be equivalent to the following:
`bool pred(const Type1 &a, const Type2 &b);`
While the signature does not need to have `const&`, the function must not modify the objects passed to it and must be able to accept all values of type (possibly const) `Type1` and `Type2` regardless of [value category](/docs/cpp/language/expressions/value_category) (thus, `Type1&` is not allowed<InlineRevision since="C++11">, nor is `Type1` unless for `Type1` a move is equivalent to a copy</InlineRevision>).
The types `Type1` and `Type2` must be such that an object of type `forward_list<T,Allocator>::const_iterator` can be dereferenced and then implicitly converted to both of them.</Parameter>
</ParameterList>

**Type requirements**

- `BinaryPredicate` must meet the requirements of [*BinaryPredicate*](/docs/cpp/library/named_req/BinaryPredicate).

### Return value

{/* source:cpp-container-forward-list-unique:0006 */}
<Revision until="C++20">
(none)
</Revision>
<Revision since="C++20">
The number of elements removed.
</Revision>

### Complexity

{/* source:cpp-container-forward-list-unique:0007 */}
If [`empty()`](/docs/cpp/library/container/forward_list/empty) is `true`, no comparison is performed.

{/* source:cpp-container-forward-list-unique:0008 */}
Otherwise, given `N` as `std::distance(begin(), end())`:

{/* source:cpp-container-forward-list-unique:0009 */}
1. Exactly N-1 comparisons using `operator==`.

{/* source:cpp-container-forward-list-unique:0010 */}
2. Exactly N-1 applications of the predicate `p`.

### Example

{/* source:cpp-container-forward-list-unique:0012 */}
```cpp
#include <iostream>
#include <forward_list>
 
std::ostream& operator<< (std::ostream& os, std::forward_list<int> const& container)
{
    for (int val : container)
        os << val << ' ';
    return os << '\n';
}
 
int main()
{
    std::forward_list<int> c{1, 2, 2, 3, 3, 2, 1, 1, 2};
    std::cout << "Before unique(): " << c;
    const auto count1 = c.unique();
    std::cout << "After unique():  " << c
              << count1 << " elements were removed\n";
 
    c = {1, 2, 12, 23, 3, 2, 51, 1, 2, 2};
    std::cout << "\nBefore unique(pred): " << c;
 
    const auto count2 = c.unique([mod = 10](int x, int y)
    {
        return (x % mod) == (y % mod);
    });
 
    std::cout << "After unique(pred):  " << c
              << count2 << " elements were removed\n";
}
```

Output:

```text
Before unique(): 1 2 2 3 3 2 1 1 2
After unique():  1 2 3 2 1 2
3 elements were removed
 
Before unique(pred): 1 2 12 23 3 2 51 1 2 2
After unique(pred):  1 2 23 2 51 2
4 elements were removed
```
