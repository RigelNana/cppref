  <Declaration language="cpp" since="C++23" code={`template< container-compatible-range<T> R >
void prepend_range( R&& rg );`} />
</DeclarationDoc>

{/* source:cpp-container-forward-list-prepend-range:0001 */}
Inserts, in non-reversing order, copies of elements in `rg` before [`begin()`](/docs/cpp/library/container/forward_list/begin). Each iterator in the range `rg` is dereferenced exactly once.

{/* source:cpp-container-forward-list-prepend-range:0002 */}
No iterators or references are invalidated.

### Parameters

{/* source:cpp-container-forward-list-prepend-range:0003 */}
<ParameterList>
  <Parameter name="rg">a [`container compatible range`](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

**Type requirements**

- `T` must be [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `forward_list` from `*ranges::begin(rg)`. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-forward-list-prepend-range:0004 */}
(none)

### Complexity

{/* source:cpp-container-forward-list-prepend-range:0005 */}
Linear in size of `rg`.

### Notes

{/* source:cpp-container-forward-list-prepend-range:0006 */}
| [`Feature-test`](/docs/cpp/library/utility/feature_test) macro | Value | Std | Feature |
| --- | --- | --- | --- |
| [`__cpp_lib_containers_ranges`](/docs/cpp/library/feature_test#cpp_lib_containers_ranges) | [`202202L`](/docs/cpp/library/compiler_support/23#cpp_lib_containers_ranges_202202L) | (C++23) | [`Ranges-aware`](/docs/cpp/library/ranges/to#container_compatible_range) construction and insertion |

### Example

{/* source:cpp-container-forward-list-prepend-range:0007 */}
```cpp
#include <algorithm>
#include <cassert>
#include <forward_list>
#include <vector>
 
int main()
{
    auto container = std::forward_list{0, 1, 2, 3};
    const auto rg = std::vector{-3, -2, -1};
 
#if __cpp_lib_containers_ranges
    container.prepend_range(rg);
#else
    container.insert_after(container.before_begin(), rg.cbegin(), rg.cend());
#endif
    assert(std::ranges::equal(container, std::forward_list{-3, -2, -1, 0, 1, 2, 3}));
}
```
