{/* source:cpp-container-forward-list-remove:0001 */}
Removes all elements satisfying specific criteria. Invalidates only the iterators and references to the removed elements.

{/* source:cpp-container-forward-list-remove:0002 */}
1. Removes all elements that are equal to `value` (using `operator==`).

{/* source:cpp-container-forward-list-remove:0003 */}
2. Removes all elements for which predicate `p` returns `true`.

### Parameters

{/* source:cpp-container-forward-list-remove:0004 */}
<ParameterList>
  <Parameter name="value">value of the elements to remove</Parameter>
  <Parameter name="p">unary predicate which returns `true` if the element should be removed. The expression `p(v)` must be convertible to `bool` for every argument `v` of type (possibly const) `T`, regardless of [value category](/docs/cpp/language/expressions/value_category), and must not modify `v`. Thus, a parameter type of `T&`is not allowed<InlineRevision since="C++11">, nor is `T` unless for `T` a move is equivalent to a copy</InlineRevision>.</Parameter>
</ParameterList>

Type requirements

- `UnaryPredicate` must meet the requirements of [*Predicate*](/docs/cpp/library/named_req/Predicate).

### Return value

{/* source:cpp-container-forward-list-remove:0005 */}
<Revision until="C++20">(none)</Revision>

<Revision since="C++20">The number of elements removed.</Revision>

### Complexity

{/* source:cpp-container-forward-list-remove:0006 */}
Given N as `std::distance(begin(), end())`:

{/* source:cpp-container-forward-list-remove:0007 */}
1. Exactly N comparisons using `operator==`.

{/* source:cpp-container-forward-list-remove:0008 */}
2. Exactly N applications of the predicate `p`.

### Example

{/* source:cpp-container-forward-list-remove:0010 */}
```cpp
#include <forward_list>
#include <iostream>

int main()
{
    std::forward_list<int> l = {1, 100, 2, 3, 10, 1, 11, -1, 12};

    auto count1 = l.remove(1);
    std::cout << count1 << " elements equal to 1 were removed\n";

    auto count2 = l.remove_if([](int n){ return n > 10; });
    std::cout << count2 << " elements greater than 10 were removed\n";

    std::cout << "Finally, the list contains: ";
    for (int n : l)
        std::cout << n << ' ';
    std::cout << '\n';
}
```

Output:

```text
2 elements equal to 1 were removed
3 elements greater than 10 were removed
Finally, the list contains: 2 3 10 -1
```
