{/* source:cpp-container-forward-list-forward-list:0001 */}
Constructs a new `forward_list` from a variety of data sources, optionally using a user supplied allocator `alloc`.

{/* source:cpp-container-forward-list-forward-list:0002 */}
- 1) The default constructor. Constructs an empty `forward_list` with a default-constructed allocator.

{/* source:cpp-container-forward-list-forward-list:0003 */}
- If `Allocator` is not [*DefaultConstructible*](/docs/cpp/library/named_req/DefaultConstructible), the behavior is undefined.

{/* source:cpp-container-forward-list-forward-list:0004 */}
- 2) Constructs an empty `forward_list` with the given allocator `alloc`.

{/* source:cpp-container-forward-list-forward-list:0005 */}
- 3) Constructs a `forward_list` with `count` default-inserted objects of `T`. No copies are made.

{/* source:cpp-container-forward-list-forward-list:0006 */}
- If `T` is not [*DefaultInsertable*](/docs/cpp/library/named_req/DefaultInsertable) into `std::forward_list<T>`, the behavior is undefined.

{/* source:cpp-container-forward-list-forward-list:0007 */}
- 4) Constructs a `forward_list` with `count` copies of elements with value `value`.

{/* source:cpp-container-forward-list-forward-list:0008 */}
- If `T` is not [*CopyInsertable*](/docs/cpp/library/named_req/CopyInsertable) into `std::forward_list<T>`, the behavior is undefined.

{/* source:cpp-container-forward-list-forward-list:0009 */}
- 5) Constructs a `forward_list` with the contents of the range `[first, last)`. Each iterator in `[first, last)` is dereferenced exactly once.

{/* source:cpp-container-forward-list-forward-list:0010 */}
- This overload participates in overload resolution only if `InputIt` satisfies the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).

{/* source:cpp-container-forward-list-forward-list:0011 */}
- If `T` is not [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `std::forward_list<T>` from `*first`, the behavior is undefined.

{/* source:cpp-container-forward-list-forward-list:0012 */}
- 6) Constructs a `forward_list` with the contents of the range `rg`. Each iterator in `rg` is dereferenced exactly once.

{/* source:cpp-container-forward-list-forward-list:0013 */}
- If `T` is not [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `std::forward_list<T>` from `*ranges::begin(rg)`, the behavior is undefined.

{/* source:cpp-container-forward-list-forward-list:0014 */}
- 7-10) Constructs a `forward_list` with the contents of `other`.

{/* source:cpp-container-forward-list-forward-list:0015 */}
  - 7) The copy constructor. The allocator is obtained as if by calling `std::allocator_traits<Allocator>::select_on_container_copy_construction(other.get_allocator())`.

{/* source:cpp-container-forward-list-forward-list:0016 */}
  - 8) The move constructor. The allocator is obtained by move construction from `other.get_allocator()`.

{/* source:cpp-container-forward-list-forward-list:0017 */}
  - 9) Same as the copy constructor, except that `alloc` is used as the allocator.

{/* source:cpp-container-forward-list-forward-list:0018 */}
    - If `T` is not [*CopyInsertable*](/docs/cpp/library/named_req/CopyInsertable) into `std::forward_list<T>`, the behavior is undefined.

{/* source:cpp-container-forward-list-forward-list:0019 */}
  - 10) Same as the move constructor, except that `alloc` is used as the allocator.

{/* source:cpp-container-forward-list-forward-list:0020 */}
    - If `T` is not [*MoveInsertable*](/docs/cpp/library/named_req/MoveInsertable) into `std::forward_list<T>`, the behavior is undefined.

{/* source:cpp-container-forward-list-forward-list:0021 */}
- 11) Equivalent to `forward_list(il.begin(), il.end(), alloc)`.

### Complexity

{/* source:cpp-container-forward-list-forward-list:0023 */}
- 1,2) Constant.

{/* source:cpp-container-forward-list-forward-list:0024 */}
- 3,4) Linear in `count`.

{/* source:cpp-container-forward-list-forward-list:0025 */}
- 5) Linear in `std::distance(first, last)`.

{/* source:cpp-container-forward-list-forward-list:0026 */}
- 6) Linear in `ranges::distance(rg)`.

{/* source:cpp-container-forward-list-forward-list:0027 */}
- 7) Linear in `other.size()`.

{/* source:cpp-container-forward-list-forward-list:0028 */}
- 8) Constant.

{/* source:cpp-container-forward-list-forward-list:0029 */}
- 9) Linear in `other.size()`.

{/* source:cpp-container-forward-list-forward-list:0030 */}
- 10) Linear in `other.size()` if `alloc != other.get_allocator()`, otherwise constant.

{/* source:cpp-container-forward-list-forward-list:0031 */}
- 11) Linear in `init.size()`.

### Exceptions

{/* source:cpp-container-forward-list-forward-list:0032 */}
Calls to `Allocator::allocate` may throw.

### Notes

{/* source:cpp-container-forward-list-forward-list:0033 */}
After container move construction (overload (8)), references, pointers, and iterators (other than the end iterator) to `other` remain valid, but refer to elements that are now in `*this`. The current standard makes this guarantee via the blanket statement in [[container.reqmts]/67](https://eel.is/c++draft/container.reqmts#67), and a more direct guarantee is under consideration via [LWG issue 2321](https://cplusplus.github.io/LWG/issue2321).

### Example

{/* source:cpp-container-forward-list-forward-list:0035 */}
```cpp
#include <forward_list>
#include <iostream>
#include <string>

template<typename T>
std::ostream& operator<<(std::ostream& s, const std::forward_list<T>& v)
{
    s.put('{');
    for (char comma[]{'\0', ' ', '\0'}; const auto& e : v)
        s << comma << e, comma[0] = ',';
    return s << "}\n";
}

int main()
{
    // C++11 initializer list syntax:
    std::forward_list<std::string> words1{"the", "frogurt", "is", "also", "cursed"};
    std::cout << "1: " << words1;

    // words2 == words1
    std::forward_list<std::string> words2(words1.begin(), words1.end());
    std::cout << "2: " << words2;

    // words3 == words1
    std::forward_list<std::string> words3(words1);
    std::cout << "3: " << words3;

    // words4 is {"Mo", "Mo", "Mo", "Mo", "Mo"}
    std::forward_list<std::string> words4(5, "Mo");
    std::cout << "4: " << words4;

    const auto rg = {"cat", "cow", "crow"};
#ifdef __cpp_lib_containers_ranges
    std::forward_list<std::string> words5(std::from_range, rg); // overload (6)
#else
    std::forward_list<std::string> words5(rg.begin(), rg.end()); // overload (5)
#endif
    std::cout << "5: " << words5;
}
```

Output:

```text
1: {the, frogurt, is, also, cursed}
2: {the, frogurt, is, also, cursed}
3: {the, frogurt, is, also, cursed}
4: {Mo, Mo, Mo, Mo, Mo}
5: {cat, cow, crow}
```
