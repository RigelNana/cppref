{/* source:cpp-container-forward-list-assign:0001 */}
Replaces the contents of the container.

{/* source:cpp-container-forward-list-assign:0002 */}
- 1) Replaces the contents with `count` copies of value `value`.

{/* source:cpp-container-forward-list-assign:0003 */}
- 2) Replaces the contents with copies of those in the range `[first, last)`.

{/* source:cpp-container-forward-list-assign:0004 */}
- If either argument is an iterator into `*this`, the behavior is undefined.

  <Revision until="C++11">This overload has the same effect as overload (1) if `InputIt` is an integral type.</Revision>

  <Revision since="C++11">This overload participates in overload resolution only if `InputIt` satisfies [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).</Revision>

{/* source:cpp-container-forward-list-assign:0005 */}
- 3) Replaces the contents with the elements from `ilist`.

{/* source:cpp-container-forward-list-assign:0006 */}
All iterators, pointers and references to the elements of the container are invalidated.

### Parameters

{/* source:cpp-container-forward-list-assign:0007 */}
<ParameterList>
  <Parameter name="count">the new size of the container</Parameter>
  <Parameter name="value">the value to initialize elements of the container with</Parameter>
  <Parameter name="first, last">the range to copy the elements from</Parameter>
  <Parameter name="ilist">[`std::initializer_list`](/docs/cpp/library/utility/initializer_list) to copy the values from</Parameter>
</ParameterList>

### Complexity

{/* source:cpp-container-forward-list-assign:0008 */}
- 1) Linear in `count`.

{/* source:cpp-container-forward-list-assign:0009 */}
- 2) Linear in distance between `first` and `last`.

{/* source:cpp-container-forward-list-assign:0010 */}
- 3) Linear in `ilist.size()`.

### Example

{/* source:cpp-container-forward-list-assign:0011 */}
The following code uses `assign` to add several characters to a `std::forward_list<char>`:

```cpp
#include <forward_list>
#include <iostream>
#include <string>

int main()
{
    std::forward_list<char> characters;

    auto print_forward_list = [&]()
    {
        for (char c : characters)
            std::cout << c << ' ';
        std::cout << '\n';
    };

    characters.assign(5, 'a');
    print_forward_list();

    const std::string extra(6, 'b');
    characters.assign(extra.begin(), extra.end());
    print_forward_list();

    characters.assign({'C', '+', '+', '1', '1'});
    print_forward_list();
}
```

Output:

```text
a a a a a
b b b b b b
C + + 1 1
```
