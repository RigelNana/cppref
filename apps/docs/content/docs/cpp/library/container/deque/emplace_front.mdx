  <DeclarationDescription>
    {/* source:cpp-container-deque-emplace-front:0001 */}
    Inserts a new element to the beginning of the container. The element is constructed through [`std::allocator_traits::construct`](/docs/cpp/library/memory/allocator_traits/construct), which typically uses placement-new to construct the element in-place at the location provided by the container. The arguments `args...` are forwarded to the constructor as `std::forward<Args>(args)...`.

    {/* source:cpp-container-deque-emplace-front:0002 */}
    All iterators (including the [`end()`](/docs/cpp/library/container/deque/end) iterator) are invalidated. No references are invalidated.
  </DeclarationDescription>
</DeclarationDoc>
