{/* source:cpp-container-deque-push-front:0001 */}
Prepends the given element `value` to the beginning of the container.

{/* source:cpp-container-deque-push-front:0002 */}
All iterators (including the [`end()`](/docs/cpp/library/container/deque/end) iterator) are invalidated. No references are invalidated.

### Parameters

{/* source:cpp-container-deque-push-front:0003 */}
<ParameterList>
  <Parameter name="value">the value of the element to prepend</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-deque-push-front:0004 */}
(none)

### Complexity

{/* source:cpp-container-deque-push-front:0005 */}
Constant.

### Exceptions

{/* source:cpp-container-deque-push-front:0006 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-container-deque-push-front:0007 */}
```cpp
#include <deque>
#include <iomanip>
#include <iostream>
#include <string>

int main()
{
    std::deque<std::string> letters;

    letters.push_front("abc");
    std::string s{"def"};
    letters.push_front(std::move(s));

    std::cout << "std::deque letters holds: ";
    for (auto&& e : letters)
        std::cout << std::quoted(e) << ' ';

    std::cout << "\nMoved-from string s holds: " << std::quoted(s) << '\n';
}
```

Possible output:

```text
std::deque letters holds: "def" "abc"
Moved-from string s holds: ""
```
