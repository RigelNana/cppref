{/* source:cpp-container-deque-insert:0001 */}
Inserts elements at the specified location in the container.

{/* source:cpp-container-deque-insert:0002 */}
1. Inserts a copy of `value` before `pos`.

{/* source:cpp-container-deque-insert:0003 */}
2. Inserts `value` before `pos`, possibly using move semantics.

{/* source:cpp-container-deque-insert:0004 */}
3. Inserts `count` copies of the `value` before `pos`.

{/* source:cpp-container-deque-insert:0005 */}
4. Inserts elements from range `[first, last)` before `pos`.

<Revision until="C++11">
This overload has the same effect as overload (3) if `InputIt` is an integral type.
</Revision>

<Revision since="C++11">
This overload participates in overload resolution only if `InputIt` qualifies as [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator), to avoid ambiguity with the overload (3).
</Revision>

{/* source:cpp-container-deque-insert:0006 */}
If `first` and `last` are iterators into `*this`, the behavior is undefined.

{/* source:cpp-container-deque-insert:0007 */}
5. Inserts elements from initializer list `ilist` before `pos`.

{/* source:cpp-container-deque-insert:0008 */}
All iterators (including the [`end()`](/docs/cpp/library/container/deque/end) iterator) are invalidated. References are invalidated too, unless `pos ==` [`begin()`](/docs/cpp/library/container/deque/begin) or `pos ==` [`end()`](/docs/cpp/library/container/deque/end), in which case they are not invalidated.

### Parameters

{/* source:cpp-container-deque-insert:0009 */}
<ParameterList>
  <Parameter name="pos">iterator before which the content will be inserted (`pos` may be the [`end()`](/docs/cpp/library/container/deque/end) iterator)</Parameter>
  <Parameter name="value">element value to insert</Parameter>
  <Parameter name="count">number of elements to insert</Parameter>
  <Parameter name="first, last">the range of elements to insert, cannot be iterators into container for which insert is called</Parameter>
  <Parameter name="ilist">[`std::initializer_list`](/docs/cpp/library/utility/initializer_list) to insert the values from</Parameter>
</ParameterList>

Type requirements:

- `T` must meet the requirements of [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable) and [`CopyInsertable`](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (1).
- `T` must meet the requirements of [`MoveAssignable`](/docs/cpp/library/named_req/MoveAssignable) and [`MoveInsertable`](/docs/cpp/library/named_req/MoveInsertable) in order to use overload (2).
- `T` must meet the requirements of [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable) and [`CopyInsertable`](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (3).
- `T` must meet the requirements of [`EmplaceConstructible`](/docs/cpp/library/named_req/EmplaceConstructible) in order to use overloads (4,5).
- `T` must meet the requirements of [`Swappable`](/docs/cpp/library/named_req/Swappable), [`MoveAssignable`](/docs/cpp/library/named_req/MoveAssignable), [`MoveConstructible`](/docs/cpp/library/named_req/MoveConstructible) and [`MoveInsertable`](/docs/cpp/library/named_req/MoveInsertable) in order to use overloads (4,5). <InlineRevision since="C++17" />

### Return value

{/* source:cpp-container-deque-insert:0010 */}
1,2) Iterator pointing to the inserted `value`.

{/* source:cpp-container-deque-insert:0011 */}
3) Iterator pointing to the first element inserted, or `pos` if `count == 0`.

{/* source:cpp-container-deque-insert:0012 */}
4) Iterator pointing to the first element inserted, or `pos` if `first == last`.

{/* source:cpp-container-deque-insert:0013 */}
5) Iterator pointing to the first element inserted, or `pos` if `ilist` is empty.

### Complexity

{/* source:cpp-container-deque-insert:0014 */}
1,2) Constant plus linear in the lesser of the distances between `pos` and either of the ends of the container.

{/* source:cpp-container-deque-insert:0015 */}
3) Linear in `count` plus linear in the lesser of the distances between `pos` and either of the ends of the container.

{/* source:cpp-container-deque-insert:0016 */}
4) Linear in `std::distance(first, last)` plus linear in the lesser of the distances between `pos` and either of the ends of the container.

{/* source:cpp-container-deque-insert:0017 */}
5) Linear in `ilist.size()` plus linear in the lesser of the distances between `pos` and either of the ends of the container.

### Exceptions

{/* source:cpp-container-deque-insert:0018 */}
If an exception is thrown other than by

{/* source:cpp-container-deque-insert:0019 */}
- the copy constructor of `T`,

{/* source:cpp-container-deque-insert:0020 */}
- <InlineRevision since="C++11" /> the move constructor of `T`,

{/* source:cpp-container-deque-insert:0021 */}
- the copy assignment operator of `T`,

{/* source:cpp-container-deque-insert:0022 */}
- <InlineRevision since="C++11" /> the move assignment operator of `T`,

{/* source:cpp-container-deque-insert:0023 */}
this function has no effect (strong exception guarantee).

{/* source:cpp-container-deque-insert:0024 */}
<Revision since="C++11">If an exception is thrown when inserting a single element at either end, this function has no effect (strong exception guarantee). Otherwise, if an exception is thrown by the move constructor of a non-[`CopyInsertable`](/docs/cpp/library/named_req/CopyInsertable) `T`, the effects are unspecified.</Revision>

### Example

{/* source:cpp-container-deque-insert:0025 */}
```cpp
#include <iostream>
#include <iterator>
#include <string_view>
#include <deque>

namespace stq {
void println(std::string_view rem, const std::deque<int>& container)
{
    std::cout << rem.substr(0, rem.size() - 2) << '[';
    bool first{true};
    for (const int x : container)
        std::cout << (first ? first = false, "" : ", ") << x;
    std::cout << "]\n";
}
}

int main()
{
    std::deque<int> c1(3, 100);
    stq::println("1. {}", c1);

    auto pos = c1.begin();
    pos = c1.insert(pos, 200); // overload (1)
    stq::println("2. {}", c1);

    c1.insert(pos, 2, 300); // overload (3)
    stq::println("3. {}", c1);

    // reset pos to the begin:
    pos = c1.begin();

    std::deque<int> c2(2, 400);
    c1.insert(std::next(pos, 2), c2.begin(), c2.end()); // overload (4)
    stq::println("4. {}", c1);

    int arr[] = {501, 502, 503};
    c1.insert(c1.begin(), arr, arr + std::size(arr)); // overload (4)
    stq::println("5. {}", c1);

    c1.insert(c1.end(), {601, 602, 603}); // overload (5)
    stq::println("6. {}", c1);
}
```

Output:

```text
1. [100, 100, 100]
2. [200, 100, 100, 100]
3. [300, 300, 200, 100, 100, 100]
4. [300, 300, 400, 400, 200, 100, 100, 100]
5. [501, 502, 503, 300, 300, 400, 400, 200, 100, 100, 100]
6. [501, 502, 503, 300, 300, 400, 400, 200, 100, 100, 100, 601, 602, 603]
```
