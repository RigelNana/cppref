### Parameters

{/* source:cpp-container-deque-end:0003 */}
(none)

### Return value

{/* source:cpp-container-deque-end:0004 */}
Iterator to the element following the last element.

### Complexity

{/* source:cpp-container-deque-end:0005 */}
Constant.

### Notes

{/* source:cpp-container-deque-end:0006 */}
libc++ backports `cend()` to C++98 mode.

### Example

{/* source:cpp-container-deque-end:0007 */}
```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <deque>

int main()
{
    std::deque<int> nums{1, 2, 4, 8, 16};
    std::deque<std::string> fruits{"orange", "apple", "raspberry"};
    std::deque<char> empty;

    // Print deque.
    std::for_each(nums.begin(), nums.end(), [](const int n) { std::cout << n << ' '; });
    std::cout << '\n';

    // Sums all integers in the deque nums (if any), printing only the result.
    std::cout << "Sum of nums: "
              << std::accumulate(nums.begin(), nums.end(), 0) << '\n';

    // Prints the first fruit in the deque fruits, checking if there is any.
    if (!fruits.empty())
        std::cout << "First fruit: " << *fruits.begin() << '\n';

    if (empty.begin() == empty.end())
        std::cout << "deque 'empty' is indeed empty.\n";
}
```

Output:

```text
1 2 4 8 16
Sum of nums: 31
First fruit: orange
deque 'empty' is indeed empty.
```
