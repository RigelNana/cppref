<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++98" code={`void resize( size_type count );`} />
  <Declaration id="2" language="cpp" since="C++98" code={`void resize( size_type count, const value_type& value );`} />
</DeclarationDoc>

{/* source:cpp-container-deque-resize:0001 */}
Resizes the container to contain `count` elements, does nothing if `count == size()`.

{/* source:cpp-container-deque-resize:0002 */}
If the current size is greater than `count`, the container is reduced to its first `count` elements.

{/* source:cpp-container-deque-resize:0003 */}
If the current size is less than `count`, then:

{/* source:cpp-container-deque-resize:0004 */}
1. Additional [default-inserted](/docs/cpp/library/named_req/DefaultInsertable) elements are appended.

{/* source:cpp-container-deque-resize:0005 */}
2. Additional copies of `value` are appended.

### Parameters

{/* source:cpp-container-deque-resize:0006 */}
<ParameterList>
  <Parameter name="count">new size of the container</Parameter>
  <Parameter name="value">the value to initialize the new elements with</Parameter>
</ParameterList>

Type requirements:

- `T` must meet the requirements of [`MoveInsertable`](/docs/cpp/library/named_req/MoveInsertable) and [`DefaultInsertable`](/docs/cpp/library/named_req/DefaultInsertable) in order to use overload (1).
- `T` must meet the requirements of [`CopyInsertable`](/docs/cpp/library/named_req/CopyInsertable) in order to use overload (2).

### Complexity

{/* source:cpp-container-deque-resize:0007 */}
Linear in the difference between the current size and `count`.

### Notes

{/* source:cpp-container-deque-resize:0008 */}
If value-initialization in overload [`1`](/docs/cpp/library/container/deque/resize#Version_1) is undesirable, for example, if the elements are of non-class type and zeroing out is not needed, it can be avoided by providing a [custom `Allocator::construct`](https://stackoverflow.com/a/21028912/273767).

### Example

{/* source:cpp-container-deque-resize:0009 */}
```cpp
#include <deque>
#include <iostream>

void print(auto rem, const std::deque<int>& c)
{
    for (std::cout << rem; const int el : c)
        std::cout << el << ' ';
    std::cout << '\n';
}

int main()
{
    std::deque<int> c = {1, 2, 3};
    print("The deque holds: ", c);

    c.resize(5);
    print("After resize up to 5: ", c);

    c.resize(2);
    print("After resize down to 2: ", c);

    c.resize(6, 4);
    print("After resize up to 6 (initializer = 4): ", c);
}
```

Output:

```text
The deque holds: 1 2 3
After resize up to 5: 1 2 3 0 0
After resize down to 2: 1 2
After resize up to 6 (initializer = 4): 1 2 4 4 4 4
```

    <CorrectedBehavior>1. uses [`pop_back()`](/docs/cpp/library/container/deque/pop_back) 2. required</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={2066} standard="C++11">
    <PublishedBehavior>overload [`1`](/docs/cpp/library/container/deque/resize#Version_1) did not have the exception safety guarantee of overload [`2`](/docs/cpp/library/container/deque/resize#Version_2)</PublishedBehavior>
    <CorrectedBehavior>added</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={2160} standard="C++11">
    <PublishedBehavior>elements were removed by using [`pop_back()`](/docs/cpp/library/container/deque/pop_back)[2] due to the resolution of LWG 2033</PublishedBehavior>
    <CorrectedBehavior>does not specify the method of removing elements</CorrectedBehavior>
  </DefectReport>
</DefectReportList>

{/* source:cpp-container-deque-resize:0012 */}
1. ↑ [`erase()`](/docs/cpp/library/container/deque/erase) can remove elements in the middle of a `deque`, so the value type is required to be [`MoveAssignable`](/docs/cpp/library/named_req/MoveAssignable) so that the elements following the removed section can be moved forward to fill the gap. However, `resize()` can only remove elements at the end of the `deque`, making the `MoveAssignable` unnecessary.
2. ↑ Removing elements by using [`pop_back()`](/docs/cpp/library/container/deque/pop_back) implies that the elements are required to be removed from back to front.
