    A [destructor](/docs/cpp/language/classes/destructor). Destructs the deque. The destructors of the elements are called and the used storage is deallocated. Note, that if the elements are pointers, the pointed-to objects are not destroyed.
  </DeclarationDescription>

### Complexity

{/* source:cpp-container-deque-deque:0002 */}
Linear in the size of the deque.
