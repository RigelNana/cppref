  <DeclarationDescription>
    {/* source:cpp-container-deque-rbegin:0001 */}
    1. <InlineRevision since="C++11" /> Returns a reverse iterator to the first element of the reversed deque. It corresponds to the last element of the non-reversed deque. If the deque is empty, the returned iterator is equal to [`rend()`](/docs/cpp/library/container/deque/rend).
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-deque-rbegin:0002 */}
(none)

### Return value

{/* source:cpp-container-deque-rbegin:0003 */}
Reverse iterator to the first element.

### Complexity

{/* source:cpp-container-deque-rbegin:0004 */}
Constant.

### Notes

{/* source:cpp-container-deque-rbegin:0005 */}
The [underlying iterator](/docs/cpp/library/iterator/reverse_iterator/base) of the returned reverse iterator is the [end iterator](/docs/cpp/library/container/deque/end). Hence the returned iterator is invalidated if and when the end iterator is invalidated.

{/* source:cpp-container-deque-rbegin:0006 */}
`libc++` backports `crbegin()` to C++98 mode.

### Example

{/* source:cpp-container-deque-rbegin:0007 */}
```cpp
#include <algorithm>
#include <iostream>
#include <numeric>
#include <string>
#include <deque>

int main()
{
    std::deque<int> nums{1, 2, 4, 8, 16};
    std::deque<std::string> fruits{"orange", "apple", "raspberry"};
    std::deque<char> empty;

    // Print deque.
    std::for_each(nums.rbegin(), nums.rend(), [](const int n) { std::cout << n << ' '; });
    std::cout << '\n';

    // Sums all integers in the deque nums (if any), printing only the result.
    std::cout << "Sum of nums: "
              << std::accumulate(nums.rbegin(), nums.rend(), 0) << '\n';

    // Prints the first fruit in the deque fruits, checking if there is any.
    if (!fruits.empty())
        std::cout << "First fruit: " << *fruits.rbegin() << '\n';

    if (empty.rbegin() == empty.rend())
        std::cout << "deque 'empty' is indeed empty.\n";
}
```

Output:

```text
16 8 4 2 1
Sum of nums: 31
First fruit: raspberry
deque 'empty' is indeed empty.
```
