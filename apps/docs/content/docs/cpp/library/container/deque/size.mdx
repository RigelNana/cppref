### Parameters

{/* source:cpp-container-deque-size:0002 */}
(none)

### Return value

{/* source:cpp-container-deque-size:0003 */}
The number of elements in the container.

### Complexity

{/* source:cpp-container-deque-size:0004 */}
Constant.

### Example

{/* source:cpp-container-deque-size:0005 */}
The following code uses `size` to display the number of elements in a [`std::deque`](/docs/cpp/library/container/deque):

```cpp
#include <deque>
#include <iostream>

int main()
{ 
    std::deque<int> nums{1, 3, 5, 7};

    std::cout << "nums contains " << nums.size() << " elements.\n";
}
```

Output:

```text
nums contains 4 elements.
```
