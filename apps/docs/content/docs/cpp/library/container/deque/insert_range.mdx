<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++23" code={`template< container-compatible-range<T> R >
iterator insert_range( const_iterator pos, R&& rg );`} />

  <DeclarationDescription>
    {/* source:cpp-container-deque-insert-range:0001 */}
    Inserts, in non-reversing order, copies of elements in `rg` before `pos`.

    {/* source:cpp-container-deque-insert-range:0002 */}
    All iterators (including the [`end()`](/docs/cpp/library/container/deque/end) iterator) are invalidated. References are invalidated too, unless `pos ==` [`begin()`](/docs/cpp/library/container/deque/begin) or `pos ==` [`end()`](/docs/cpp/library/container/deque/end), in which case they are not invalidated.

    {/* source:cpp-container-deque-insert-range:0003 */}
    Each iterator in the range `rg` is dereferenced exactly once.

    {/* source:cpp-container-deque-insert-range:0004 */}
    `rg` must not overlap with the container. Otherwise, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-deque-insert-range:0005 */}
<ParameterList>
  <Parameter name="pos">iterator before which the content will be inserted (`pos` may be the [`end()`](/docs/cpp/library/container/deque/end) iterator)</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

**Type requirements**

- `T` must be [EmplaceConstructible](/docs/cpp/library/named_req/EmplaceConstructible) into `deque` from `*ranges::begin(rg)`. Also, `T` must be [MoveInsertable](/docs/cpp/library/named_req/MoveInsertable) into `deque` and `T` must satisfy [MoveConstructible](/docs/cpp/library/named_req/MoveConstructible), [MoveAssignable](/docs/cpp/library/named_req/MoveAssignable), and [Swappable](/docs/cpp/library/named_req/Swappable). Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-deque-insert-range:0006 */}
An [`iterator`](/docs/cpp/library/container/deque#Member_types) that points at the copy of the first element inserted into `deque` or at `pos` if `rg` is empty.

### Example

{/* source:cpp-container-deque-insert-range:0008 */}
```cpp
#include <algorithm>
#include <cassert>
#include <iterator>
#include <deque>
#include <list>

int main()
{
    auto container = std::deque{1, 2, 3, 4};
    auto pos = std::next(container.begin(), 2);
    assert(*pos == 3);
    const auto rg = std::list{-1, -2, -3};

#ifdef __cpp_lib_containers_ranges
    container.insert_range(pos, rg);
#else
    container.insert(pos, rg.cbegin(), rg.cend());
#endif
    assert(std::ranges::equal(container, std::deque{1, 2, -1, -2, -3, 3, 4}));
}
```
