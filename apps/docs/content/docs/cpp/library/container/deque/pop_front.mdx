{/* source:cpp-container-deque-pop-front:0001 */}
Removes the first element of the container. If there are no elements in the container, the behavior is undefined.

{/* source:cpp-container-deque-pop-front:0002 */}
Iterators and references to the erased element are invalidated. If the element is the last element in the container, the [`end()`](/docs/cpp/library/container/deque/end) iterator is also invalidated. Other references and iterators are not affected.

### Parameters

{/* source:cpp-container-deque-pop-front:0003 */}
(none)

### Return value

{/* source:cpp-container-deque-pop-front:0004 */}
(none)

### Complexity

{/* source:cpp-container-deque-pop-front:0005 */}
Constant.

### Exceptions

{/* source:cpp-container-deque-pop-front:0006 */}
Does not throw.

### Example

{/* source:cpp-container-deque-pop-front:0007 */}
```cpp
#include <deque>
#include <iostream>

int main()
{
    std::deque<char> chars{'A', 'B', 'C', 'D'};

    for (; !chars.empty(); chars.pop_front())
        std::cout << "chars.front(): '" << chars.front() << "'\n";
}
```

Output:

```text
chars.front(): 'A'
chars.front(): 'B'
chars.front(): 'C'
chars.front(): 'D'
```
