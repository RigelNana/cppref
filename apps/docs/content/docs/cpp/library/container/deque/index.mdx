{/* source:cpp-container-deque:0001 */}
`std::deque` (double-ended queue) is an indexed sequence container that allows fast insertion and deletion at both its beginning and its end. In addition, insertion and deletion at either end of a deque never invalidates pointers or references to the rest of the elements.

{/* source:cpp-container-deque:0002 */}
As opposed to [`std::vector`](/docs/cpp/library/container/vector), the elements of a deque are not stored contiguously: typical implementations use a sequence of individually allocated fixed-size arrays, with additional bookkeeping, which means indexed access to deque must perform two pointer dereferences, compared to vector's indexed access which performs only one.

{/* source:cpp-container-deque:0003 */}
The storage of a deque is automatically expanded and contracted as needed. Expansion of a deque is cheaper than the expansion of a [`std::vector`](/docs/cpp/library/container/vector) because it does not involve copying of the existing elements to a new memory location. On the other hand, deques typically have large minimal memory cost; a deque holding just one element has to allocate its full internal array (e.g. 8 times the object size on 64-bit libstdc++; 16 times the object size or 4096 bytes, whichever is larger, on 64-bit libc++).

{/* source:cpp-container-deque:0004 */}
The complexity (efficiency) of common operations on deques is as follows:

{/* source:cpp-container-deque:0005 */}
- Random access - constant `O(1)`.
- Insertion or removal of elements at the end or beginning - constant `O(1)`.
- Insertion or removal of elements - linear `O(n)`.

{/* source:cpp-container-deque:0006 */}
`std::deque` meets the requirements of [`Container`](/docs/cpp/library/named_req/Container), [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer), [`SequenceContainer`](/docs/cpp/library/named_req/SequenceContainer) and [`ReversibleContainer`](/docs/cpp/library/named_req/ReversibleContainer).

#### Invalidation notes

{/* source:cpp-container-deque:0010 */}
- When inserting at either end of the deque, references are not invalidated by [`insert`](/docs/cpp/library/container/deque/insert) and [`emplace`](/docs/cpp/library/container/deque/emplace).
- [`push_front`](/docs/cpp/library/container/deque/push_front), [`push_back`](/docs/cpp/library/container/deque/push_back), [`emplace_front`](/docs/cpp/library/container/deque/emplace_front) and [`emplace_back`](/docs/cpp/library/container/deque/emplace_back) do not invalidate any references to elements of the deque.
- When erasing at either end of the deque, references to non-erased elements are not invalidated by [`erase`](/docs/cpp/library/container/deque/erase), [`pop_front`](/docs/cpp/library/container/deque/pop_front) and [`pop_back`](/docs/cpp/library/container/deque/pop_back).
- A call to [`resize`](/docs/cpp/library/container/deque/resize) with a smaller size does not invalidate any references to non-erased elements.
- A call to [`resize`](/docs/cpp/library/container/deque/resize) with a bigger size does not invalidate any references to elements of the deque.

### Example

{/* source:cpp-container-deque:0016 */}
```cpp
#include <deque>
#include <iostream>
 
int main()
{
    // Create a deque containing integers
    std::deque<int> d = {7, 5, 16, 8};
 
    // Add an integer to the beginning and end of the deque
    d.push_front(13);
    d.push_back(25);
 
    // Iterate and print values of deque
    for (int n : d)
        std::cout << n << ' ';
    std::cout << '\n';
}```

Output:

```text
13 7 5 16 8 25```
