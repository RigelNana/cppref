{/* source:cpp-container-mdspan-layout-stride-mapping-required-span-size:0001 */}
Returns the required size of the mapping.

{/* source:cpp-container-mdspan-layout-stride-mapping-required-span-size:0002 */}
Let `s` be equal to:

{/* source:cpp-container-mdspan-layout-stride-mapping-required-span-size:0003 */}
- `1`, if `extents().rank() == 0` is `true`,
- otherwise, `0`, if the size of the multidimensional index space `extents()` is `0`,
- otherwise, `1` plus the sum of products of `extents().extent(r) - 1` and `extents_type::index-cast(strides_[r])` for all `r` in the range [`0`, `extents().rank()`).

{/* source:cpp-container-mdspan-layout-stride-mapping-required-span-size:0004 */}
A call is equivalent to `return s;`.

### Return value

{/* source:cpp-container-mdspan-layout-stride-mapping-required-span-size:0005 */}
The required size of the mapping.
