{/* source:cpp-container-mdspan-extents-rev-prod-of-extents:0001 */}
Returns the product of the sizes of extents with index greater than `i`. The behavior is undefined if `i < rank()` is `false`.

### Parameters

{/* source:cpp-container-mdspan-extents-rev-prod-of-extents:0002 */}
<ParameterList>
  <Parameter name="i">an index above which the sizes of corresponding extents will be multiplied together</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-extents-rev-prod-of-extents:0003 */}
If `i + 1 < rank()` is `true`, return the product of [`extent`](/docs/cpp/library/container/mdspan/extents/extent)`(k)` for all `k` in range `[i + 1, rank())`, otherwise `1`.
