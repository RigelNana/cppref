{/* source:cpp-container-mdspan-layout-right:0001 */}
`layout_right` is a [*LayoutMappingPolicy*](/docs/cpp/library/named_req/LayoutMappingPolicy) which provides a layout mapping where the rightmost extent has stride 1, and strides increase right-to-left as the product of extents.

{/* source:cpp-container-mdspan-layout-right:0002 */}
<Revision until="C++26">
`layout_right` is a [*TrivialType*](/docs/cpp/library/named_req/TrivialType).
</Revision>

<Revision since="C++26">
`layout_right` is [*TriviallyCopyable*](/docs/cpp/library/named_req/TriviallyCopyable), and `std::is_trivially_default_constructible_v<layout_right>` is `true`.
</Revision>

{/* source:cpp-container-mdspan-layout-right:0003 */}
It is the default layout mapping policy used by `std::mdspan` if no user-specified layout is provided.
