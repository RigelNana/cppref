{/* source:cpp-container-mdspan-layout-left-mapping-stride:0001 */}
Returns the stride of the mapping at a rank index `i`. Equivalent to `return extents().`*`fwd-prod-of-extents`*`(i);`.

{/* source:cpp-container-mdspan-layout-left-mapping-stride:0002 */}
This overload participates in overload resolution only if `extents_type::rank() > 0` is `true`.

{/* source:cpp-container-mdspan-layout-left-mapping-stride:0003 */}
The behavior is undefined if `i >= extents_type::rank()` is `true`.

### Parameters

{/* source:cpp-container-mdspan-layout-left-mapping-stride:0004 */}
<ParameterList>
  <Parameter name="i">a rank index in the range `[0, extents_type::rank())`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-layout-left-mapping-stride:0005 */}
The stride at a specified rank index.
