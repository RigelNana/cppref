    {/* source:cpp-container-mdspan-mdspan:0001 */}
    Constructs an `mdspan`, optionally using user-supplied data handle `p`, layout mapping `m`, and accessor `a`. If extents `exts` or `ext` are supplied, they are converted to `extents_type` and used to initialize the layout mapping.

    {/* source:cpp-container-mdspan-mdspan:0002 */}
    1) Constructs an empty `mdspan`. [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) [`ptr_`](/docs/cpp/library/container/mdspan#Data_members), [`map_`](/docs/cpp/library/container/mdspan#Data_members), and [`acc_`](/docs/cpp/library/container/mdspan#Data_members). The behavior is undefined if `[0, map_.required_span_size())` is not an accessible range of [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) for the values of [`map_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) after the invocation of this constructor. This overload participates in overload resolution only if `rank_dynamic() > 0` is `true`, `std::is_default_constructible_v<data_handle_type>` is `true`, `std::is_default_constructible_v<mapping_type>` is `true`, and `std::is_default_constructible_v<accessor_type>` is `true`.

    {/* source:cpp-container-mdspan-mdspan:0003 */}
    2) Constructs an `mdspan` over the underlying data referred by `p` with extents represented by `exts`.... [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) [`acc_`](/docs/cpp/library/container/mdspan#Data_members), [`direct-non-list-initializes`](/docs/cpp/language/initialization/direct_initialization) [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) with `std::move(p)` and [`map_`](/docs/cpp/library/container/mdspan#Data_members) with `extents_type(static_cast<index_type>(std::move(exts))...)`. The behavior is undefined if `[0, map_.required_span_size())` is not an accessible range of [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) for the values of [`map_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) after the invocation of this constructor. Let `N` be `sizeof...(OtherIndexTypes)`. This overload participates in overload resolution only if `(std::is_convertible_v<OtherIndexTypes, index_type> && ...)` is `true`, `(std::is_nothrow_constructible<index_type, OtherIndexTypes> && ...)` is `true`, `N == rank() || N == rank_dynamic()` is `true`, `std::is_constructible_v<mapping_type, extents_type>` is `true`, and `std::is_default_constructible_v<accessor_type>` is `true`.

    {/* source:cpp-container-mdspan-mdspan:0004 */}
    3,4) Constructs an `mdspan` over the underlying data referred by `p` with extents represented by pack `exts`. [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) [`acc_`](/docs/cpp/library/container/mdspan#Data_members), [`direct-non-list-initializes`](/docs/cpp/language/initialization/direct_initialization) [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) with `std::move(p)` and [`map_`](/docs/cpp/library/container/mdspan#Data_members) with `extents_type(exts)`. The behavior is undefined if `[0, map_.required_span_size())` is not an accessible range of [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) for the values of [`map_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) after the invocation of this constructor. This overload participates in overload resolution only if `std::is_convertible_v<const OtherIndexTypes&, index_type>` is `true`, `std::is_nothrow_constructible<index_type, const OtherIndexTypes&>` is `true`, `N == rank() || N == rank_dynamic()` is `true`, `std::is_constructible_v<mapping_type, extents_type>` is `true`, and `std::is_default_constructible_v<accessor_type>` is `true`.

    {/* source:cpp-container-mdspan-mdspan:0005 */}
    5) Constructs an `mdspan` over the underlying data referred by `p` with extents represented by `ext`. [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) [`acc_`](/docs/cpp/library/container/mdspan#Data_members), [`direct-non-list-initializes`](/docs/cpp/language/initialization/direct_initialization) [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) with `std::move(p)` and [`map_`](/docs/cpp/library/container/mdspan#Data_members) with `exts`. The behavior is undefined if `[0, map_.required_span_size())` is not an accessible range of `p` and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) for the values of [`map_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) after the invocation of this constructor. This overload participates in overload resolution only if `std::is_constructible_v<mapping_type, const mapping_type&>` is `true`, and `std::is_default_constructible_v<accessor_type>` is `true`.

    {/* source:cpp-container-mdspan-mdspan:0006 */}
    6) Constructs an `mdspan` over the underlying data referred by `p` with layout mapping `m`. [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) [`acc_`](/docs/cpp/library/container/mdspan#Data_members), [`direct-non-list-initializes`](/docs/cpp/language/initialization/direct_initialization) [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) with `std::move(p)` and [`map_`](/docs/cpp/library/container/mdspan#Data_members) with `m`. The behavior is undefined if `[0, m.required_span_size())` is not an accessible range of `p` and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) for the values of [`acc_`](/docs/cpp/library/container/mdspan#Data_members) after the invocation of this constructor. This overload participates in overload resolution only if `std::is_default_constructible_v<accessor_type>` is `true`.

    {/* source:cpp-container-mdspan-mdspan:0007 */}
    7) Constructs an `mdspan` over the underlying data referred by `p` with layout mapping `m` and accessor `a`. [`Direct-non-list-initializes`](/docs/cpp/language/initialization/direct_initialization) [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) with `std::move(p)`, [`map_`](/docs/cpp/library/container/mdspan#Data_members) with `m` and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) with `a`. The behavior is undefined if `[0, m.required_span_size())` is not an accessible range of `p` and `a` after the invocation of this constructor.

    {/* source:cpp-container-mdspan-mdspan:0008 */}
    8) Converting constructor from another `mdspan`. [`Direct-non-list-initializes`](/docs/cpp/language/initialization/direct_initialization) [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) with `other.ptr_`, [`map_`](/docs/cpp/library/container/mdspan#Data_members) with `other.map_` and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) with `other.acc_`. The behavior is undefined if: `[0, map_.required_span_size())` is not an accessible range of [`ptr_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) for the values of [`map_`](/docs/cpp/library/container/mdspan#Data_members) and [`acc_`](/docs/cpp/library/container/mdspan#Data_members) after the invocation of this constructor, or for each rank index `r` of `extents_type`, `extents_type::static_extent(r) == std::dynamic_extent` || `extents_type::static_extent(r) == other.extent(r)` is `false`. This overload participates in overload resolution only if `std::is_constructible_v<mapping_type, const OtherLayoutPolicy::template mapping<OtherExtents>&>` is `true`, and `std::is_constructible_v<accessor_type, const OtherAccessor&>` is `true`. The program is ill-formed if: `std::is_constructible_v<data_handle_type, const OtherAccessor::data_handle_type&>` is `false`, or `std::is_constructible_v<extents_type, OtherExtents>` is `false`. The expression inside `explicit` is equivalent to: `!std::is_convertible_v<const OtherLayoutPolicy::template mapping<OtherExtents>&, mapping_type>` || `!std::is_convertible_v<const OtherAccessor&, accessor_type>`.

    {/* source:cpp-container-mdspan-mdspan:0009 */}
