{/* source:cpp-container-mdspan-extent:0001 */}
Returns the extent of a `mdspan` at the rank index `r`. Equivalent to `return extents().extent(r);`.

## Parameters

{/* source:cpp-container-mdspan-extent:0002 */}
<ParameterList>
  <Parameter name="r">The rank index to get the extent size of</Parameter>
</ParameterList>

## Return value

{/* source:cpp-container-mdspan-extent:0003 */}
The extent at the given rank index.
