{/* source:cpp-container-mdspan-layout-right-padded:0001 */}
Every specialization of `layout_right_padded` is a [*LayoutMappingPolicy*](/docs/cpp/library/named_req/LayoutMappingPolicy) which provides a layout mapping that is similar to [`layout_right::mapping`](/docs/cpp/library/container/mdspan/layout_right/mapping) except that it has a *padding stride*.

{/* source:cpp-container-mdspan-layout-right-padded:0002 */}
Every specialization of `layout_right_padded` is [*TriviallyCopyable*](/docs/cpp/library/named_req/TriviallyCopyable), and `std::is_trivially_default_constructible_v<T>` is `true` for any such specialization `T`.

{/* source:cpp-container-mdspan-layout-right-padded:0003 */}
Let `m` be the instance of the mapping type [`layout_right_padded::mapping`](https://en.cppreference.com/mwiki/index.php?title=cpp/container/mdspan/layout_right_padded/mapping&action=edit&redlink=1). The padding stride of the mapping is the second to last stride `m.stride(rank() - 2)` which is guaranteed to be at least the last extent value `m.extent(rank() - 1)`, called *extent to pad*.
