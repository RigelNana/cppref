{/* source:cpp-container-mdspan-extents-rank:0001 */}
Returns the number of dimensions in [`extents`](/docs/cpp/library/container/mdspan/extents).

### Parameters

{/* source:cpp-container-mdspan-extents-rank:0002 */}
(none)

### Return value

{/* source:cpp-container-mdspan-extents-rank:0003 */}
The number of dimensions.

### Example

{/* source:cpp-container-mdspan-extents-rank:0004 */}
```cpp
#include <iostream>
#include <mdspan>

int main()
{
    std::extents<int, 1, 2> e1;
    std::extents<int, 3, 4, std::dynamic_extent> e2(5);
    std::cout << e1.rank() << ", " << e2.rank() << '\n';
}
```

Output:

```text
2, 3
```
