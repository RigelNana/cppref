{/* source:cpp-container-mdspan-layout-stride:0001 */}
`layout_stride` is a [*LayoutMappingPolicy*](/docs/cpp/library/named_req/LayoutMappingPolicy) which provides a layout mapping where the strides are user-defined.

{/* source:cpp-container-mdspan-layout-stride:0002 */}
<Revision until="C++26">
`layout_stride` is a [*TrivialType*](/docs/cpp/library/named_req/TrivialType).
</Revision>

<Revision since="C++26">
`layout_stride` is [*TriviallyCopyable*](/docs/cpp/library/named_req/TriviallyCopyable), and `std::is_trivially_default_constructible_v<layout_stride>` is `true`.
</Revision>
