  <DeclarationDescription>
    {/* source:cpp-container-mdspan-swap2:0001 */}
    1. Overloads the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::mdspan`](/docs/cpp/library/container/mdspan). Exchanges the state of `x` with that of `y`. Equivalent to:

    {/* source:cpp-container-mdspan-swap2:0002 */}
    `std::`[`swap`](/docs/cpp/library/algorithm/swap)`(x.`[`acc_`](/docs/cpp/library/container/mdspan#acc)`, y.`[`acc_`](/docs/cpp/library/container/mdspan#acc)`);` `std::`[`swap`](/docs/cpp/library/algorithm/swap)`(x.`[`map_`](/docs/cpp/library/container/mdspan#map)`, y.`[`map_`](/docs/cpp/library/container/mdspan#map)`);` `std::`[`swap`](/docs/cpp/library/algorithm/swap)`(x.`[`ptr_`](/docs/cpp/library/container/mdspan#ptr)`, y.`[`ptr_`](/docs/cpp/library/container/mdspan#ptr)`);`

    {/* source:cpp-container-mdspan-swap2:0003 */}
    This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::mdspan` is an associated class of the arguments.
  </DeclarationDescription>
</DeclarationDoc>
