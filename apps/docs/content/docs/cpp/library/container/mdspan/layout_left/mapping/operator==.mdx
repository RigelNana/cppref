{/* source:cpp-container-mdspan-layout-left-mapping-operator:0001 */}
Compares two layout mappings of the same layout type based on their underlying extents.

{/* source:cpp-container-mdspan-layout-left-mapping-operator:0002 */}
Layout mappings `lhs` and `rhs` compare equal if both `lhs.extents()` and `rhs.extents()` are equal.

{/* source:cpp-container-mdspan-layout-left-mapping-operator:0003 */}
This overload participates in overload resolution only if `extents_type::rank() == OtherExtents::rank()` is `true`.

### Parameters

{/* source:cpp-container-mdspan-layout-left-mapping-operator:0004 */}
<ParameterList>
  <Parameter name="lhs, rhs">layout mappings whose extents to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-layout-left-mapping-operator:0005 */}
`true` if `lhs.extents() == rhs.extents()` is `true`, `false` otherwise
