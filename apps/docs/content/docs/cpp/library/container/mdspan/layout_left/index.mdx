{/* source:cpp-container-mdspan-layout-left:0001 */}
`layout_left` is a [*LayoutMappingPolicy*](/docs/cpp/library/named_req/LayoutMappingPolicy) which provides a layout mapping where the leftmost extent has stride 1, and strides increase left-to-right as the product of extents.

{/* source:cpp-container-mdspan-layout-left:0002 */}
<Revision until="C++26">
`layout_left` is a [*TrivialType*](/docs/cpp/library/named_req/TrivialType).
</Revision>

<Revision since="C++26">
`layout_left` is [*TriviallyCopyable*](/docs/cpp/library/named_req/TriviallyCopyable), and `std::is_trivially_default_constructible_v<layout_left>` is `true`.
</Revision>
