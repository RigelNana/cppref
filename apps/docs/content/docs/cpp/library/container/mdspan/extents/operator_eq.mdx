{/* source:cpp-container-mdspan-extents-operator:0001 */}
Compares two `extents`. Returns `true` if `lhs.rank()` equals `rhs.rank()` and `lhs.extent(r)` equals `rhs.extent(r)` for every rank index `r` of `rhs`; otherwise returns `false`.

### Parameters

{/* source:cpp-container-mdspan-extents-operator:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">extents whose values to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-extents-operator:0003 */}
`true` if the extents represented by `lhs` and `rhs` are equal, `false` otherwise
