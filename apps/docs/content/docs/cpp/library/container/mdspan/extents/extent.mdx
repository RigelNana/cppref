Returns dynamic extent size of an [`extents`](/docs/cpp/library/container/mdspan/extents) at a certain rank index.

### Parameters

{/* source:cpp-container-mdspan-extents-extent:0002 */}
<ParameterList>
  <Parameter name="i">The rank index to get the extent size of</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-extents-extent:0003 */}
The dynamic extent size of an `extents` at a certain rank index.

### Example

{/* source:cpp-container-mdspan-extents-extent:0004 */}
```cpp
#include <iostream>
#include <mdspan>

int main()
{
    std::extents<int, 1, 2> e1;
    std::extents<int, 3, std::dynamic_extent, std::dynamic_extent> e2(4, 5);
    std::cout << e1.extent(0) << ", " << e1.extent(1) << '\n';
    std::cout << e2.extent(0) << ", " << e2.extent(1) << ", " << e2.extent(2) << '\n';
}
```

Output:

```text
1, 2
3, 4, 5
```
