{/* source:cpp-container-mdspan-extents-index-cast:0001 */}
Casts the index `i` of type `OtherIndexType` into a certain integral type.

{/* source:cpp-container-mdspan-extents-index-cast:0002 */}
It is equivalent to:

{/* source:cpp-container-mdspan-extents-index-cast:0003 */}
- `return i;`, if `OtherIndexType` is an integral type other than `bool` and
- `return static_cast<index_type>(i);` otherwise.

### Parameters

{/* source:cpp-container-mdspan-extents-index-cast:0004 */}
<ParameterList>
  <Parameter name="i">the index to be cast</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-extents-index-cast:0005 */}
Cast index.

### Notes

{/* source:cpp-container-mdspan-extents-index-cast:0006 */}
A call to this function will always return an integral type other than `bool`. [`Integer-class types`](/docs/cpp/library/iterator/is-integer-like#Integer-class_type) can use the `static_cast` branch without loss of precision because this function's call sites are already constrained on the convertibility of `OtherIndexType` to `index_type`.
