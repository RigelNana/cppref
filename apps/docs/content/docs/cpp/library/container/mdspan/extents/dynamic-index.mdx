{/* source:cpp-container-mdspan-extents-dynamic-index:0001 */}
Returns the number of dynamic extents below index `i`. If `i <= rank()` is `false`, the behavior is undefined.

### Parameters

{/* source:cpp-container-mdspan-extents-dynamic-index:0002 */}
<ParameterList>
  <Parameter name="i">the index</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-extents-dynamic-index:0003 */}
The number of `Er` with `r < i` for which `Er` is a dynamic extent.
