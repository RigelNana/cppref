{/* source:cpp-container-mdspan-layout-stride-mapping-mapping-traits:0001 */}
Every instance of every specialization of `mapping` is unique and strided.

{/* source:cpp-container-mdspan-layout-stride-mapping-mapping-traits:0002 */}
The mapping is exhaustive if one of the following conditions is `true`:

{/* source:cpp-container-mdspan-layout-stride-mapping-mapping-traits:0003 */}
- `rank_` is `0`, or
- there exists a permutation `p` of the integers in the range [`0`, `rank_`) such that:

{/* source:cpp-container-mdspan-layout-stride-mapping-mapping-traits:0004 */}
  - `stride(p[0])` equals `1` and
  - `stride(p[i])` equals `stride(p[i - 1]) * extents().extent(p[i - 1])` for all `i` in [`1`, `rank_`), where `p[i]` is the ith element of `p`.

{/* source:cpp-container-mdspan-layout-stride-mapping-mapping-traits:0005 */}
([`rank_`](/docs/cpp/library/container/mdspan/layout_stride/mapping#Member_constants) is an exposition-only static member constant defined in `std::layout_stride::mapping`.)

{/* source:cpp-container-mdspan-layout-stride-mapping-mapping-traits:0006 */}
See [`LayoutMapping`](/docs/cpp/library/named_req/LayoutMapping) for the semantics of these predicate mapping traits.
