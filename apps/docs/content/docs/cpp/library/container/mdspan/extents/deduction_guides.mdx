{/* source:cpp-container-mdspan-extents-deduction-guides:0001 */}
A [`deduction guide`](/docs/cpp/language/templates/ctad) is provided for `std::extents` to allow deduction from integral arguments.

The deduced type is equivalent to

{/* source:cpp-container-mdspan-extents-deduction-guides:0002 */}
<Revision until="C++26">
`std::dextents<std::size_t, sizeof...(Integrals)>`
</Revision>

<Revision since="C++26">
`std::extents<std::size_t, `[`maybe-static-ext`](/docs/cpp/library/headers/span#Synopsis)`<Integrals>...>`
</Revision>

{/* source:cpp-container-mdspan-extents-deduction-guides:0003 */}
This overload participates in overload resolution only if `(std::is_convertible_v<Integrals, std::size_t> && ...)` is `true`.
