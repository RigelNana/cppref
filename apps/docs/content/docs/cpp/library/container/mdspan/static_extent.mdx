{/* source:cpp-container-mdspan-static-extent:0001 */}
Statically determines the extent of a `mdspan` at the rank index `r`. If the rank index `r` corresponds to a dynamic extent, returns `std::dynamic_extent`. Equivalent to `return Extents::static_extent(r);`.

## Parameters

{/* source:cpp-container-mdspan-static-extent:0002 */}
<ParameterList>
  <Parameter name="r">The rank index to get the static extent size of</Parameter>
</ParameterList>

## Return value

{/* source:cpp-container-mdspan-static-extent:0003 */}
The static extent size, or `std::dynamic_extent`.
