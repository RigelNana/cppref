{/* source:cpp-container-mdspan-size:0001 */}
Returns the number of elements in [`mdspan`](/docs/cpp/library/container/mdspan/mdspan).

{/* source:cpp-container-mdspan-size:0002 */}
Equivalent to [`extents`](/docs/cpp/library/container/mdspan/extents)().[`fwd-prod-of-extents`](/docs/cpp/library/container/mdspan/extents/fwd-prod-of-extents)([`rank`](/docs/cpp/library/container/mdspan/extents/rank)()).

{/* source:cpp-container-mdspan-size:0003 */}
The size of the multidimensional index space [`extents()`](/docs/cpp/library/container/mdspan/extents) must be representable as a value of type [`size_type`](/docs/cpp/library/container/mdspan#Member_types). Otherwise, the behavior is undefined.

## Return value

{/* source:cpp-container-mdspan-size:0004 */}
The number of elements.
