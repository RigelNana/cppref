{/* source:cpp-container-mdspan-extents-static-extent:0001 */}
Returns static extent size of an [`extents`](/docs/cpp/library/container/mdspan/extents) at the rank index `i`. If the rank index `i` is a dynamic extent, returns `std::dynamic_extent`.

### Parameters

{/* source:cpp-container-mdspan-extents-static-extent:0002 */}
<ParameterList>
  <Parameter name="i">The rank index to get the static extent size of</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-extents-static-extent:0003 */}
The static extent size or `std::dynamic_extent` value.

### Example

{/* source:cpp-container-mdspan-extents-static-extent:0004 */}
```cpp
#include <iostream>
#include <mdspan>

int main()
{
    std::extents<int, 1, 2> e1;
    std::extents<int, 3, std::dynamic_extent, std::dynamic_extent> e2(4, 5);
    std::cout << e1.static_extent(0) << ", " << e1.static_extent(1) << '\n';
    std::cout << (e2.static_extent(0) == std::dynamic_extent) << ", "
              << (e2.static_extent(1) == std::dynamic_extent) << ", "
              << (e2.static_extent(2) == std::dynamic_extent) << '\n';
}
```

Output:

```text
1, 2
0, 1, 1
```
