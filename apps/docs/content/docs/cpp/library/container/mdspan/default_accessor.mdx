A specialization of `std::default_accessor` class template is the default [`AccessorPolicy`](/docs/cpp/library/named_req/AccessorPolicy) used by `std::mdspan` if no user-specified accessor policy is provided.

{/* source:cpp-container-mdspan-default-accessor:0002 */}
Each specialization of `default_accessor` models [`semiregular`](/docs/cpp/library/concepts/semiregular) and is [`TriviallyCopyable`](/docs/cpp/library/named_req/TriviallyCopyable).
