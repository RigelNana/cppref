{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0001 */}
Compares two layout mappings of possibly different layout types based on their underlying extents and strides.

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0002 */}
Layout mappings `lhs` and `rhs` compare equal if all of the following conditions are `true`:

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0003 */}
- both `lhs.extents()` and `rhs.extents()` are equal,
- `OFFSET(rhs)` is equal to `0`, and
- for every rank index `r` in the range [`0`, `lhs.extents().rank()`), `lhs.stride(r)` is equal to `rhs.stride(r)`

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0004 */}
Where `OFFSET(rhs)` is equal to:

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0005 */}
- `rhs()`, if `rhs.extents().rank()` is `0`,
- otherwise `0`, if the size of the multidimensional index space `rhs.extents()` is `0`,
- otherwise `rhs(z...)` for a pack of integers `z` that is a multidimensional index in `rhs.extents()` and each element of `z` is equal to `0`.

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0006 */}
This overload participates in overload resolution only if all of the following constraints are satisfied:

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0007 */}
- [`layout-mapping-alike`](/docs/cpp/library/named_req/LayoutMapping#layout-mapping-alike)`<OtherMapping>` is satisfied,
- `rank_ == OtherMapping::extents_type::rank()` is `true`, and
- `OtherMapping::is_always_strided()` is `true`

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0008 */}
([`rank_`](/docs/cpp/library/container/mdspan/layout_stride/mapping#Member_constants) is an exposition-only static member constant defined in `std::layout_stride::mapping`.)

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0009 */}
If `OtherMapping` does not meet the [`LayoutMapping`](/docs/cpp/library/named_req/LayoutMapping) requirements, the behavior is undefined.

### Parameters

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0010 */}
<ParameterList>
  <Parameter name="lhs, rhs">layout mappings whose extents and strides to compare</Parameter>

### Return value

{/* source:cpp-container-mdspan-layout-stride-mapping-operator:0011 */}
`true` if `lhs` and `rhs` are both equal as specified above, `false` otherwise
