Returns the stride of the mapping at a rank index `i`. Equivalent to `return strides_[i];`.

### Parameters

{/* source:cpp-container-mdspan-layout-stride-mapping-stride:0002 */}
<ParameterList>
  <Parameter name="i">a rank index in the range [`0`, `rank_`)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-layout-stride-mapping-stride:0003 */}
The stride at a specified rank index.
