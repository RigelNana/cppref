{/* source:cpp-container-mdspan-extents-fwd-prod-of-extents:0001 */}
Returns the product of the sizes of extents with index less than `i`. The behavior is undefined if `i <= rank()` is `false`.

### Parameters

{/* source:cpp-container-mdspan-extents-fwd-prod-of-extents:0002 */}
<ParameterList>
  <Parameter name="i">The end index of the range of extents to be multiplied together.</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-extents-fwd-prod-of-extents:0003 */}
If `i > 0` is `true`, return the product of [`extent`](/docs/cpp/library/container/mdspan/extents/extent)`(k)` for all `k` in range `[0, i)`, otherwise `1`.
