{/* source:cpp-container-mdspan-extents-dynamic-index-inv:0001 */}
Returns the number `r` such that in range [`0`, `r + 1`) there are exactly [`0`, `i + 1`) dynamic extents. If `i <= rank_dynamic()` is `false`, the behavior is undefined.

### Parameters

{/* source:cpp-container-mdspan-extents-dynamic-index-inv:0002 */}
<ParameterList>
  <Parameter name="i">the index</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-mdspan-extents-dynamic-index-inv:0003 */}
The minimum value of `r` such that [`dynamic-index`](/docs/cpp/library/container/mdspan/extents/dynamic-index)`(r + 1) == i + 1` is `true`.
