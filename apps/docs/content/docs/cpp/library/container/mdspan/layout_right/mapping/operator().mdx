{/* source:cpp-container-mdspan-layout-right-mapping-operator:0001 */}
Maps the multidimensional index `indices` into an offset value.

{/* source:cpp-container-mdspan-layout-right-mapping-operator:0002 */}
Equivalent to `return ((static_cast<index_type>(indices) * stride(P)) + ... + 0);` where `P` is a pack such that `std::is_same_v<std::index_sequence_for<Indices...>, std::index_sequence<P...>>` is `true`.

{/* source:cpp-container-mdspan-layout-right-mapping-operator:0003 */}
This overload participates in overload resolution only if:

{/* source:cpp-container-mdspan-layout-right-mapping-operator:0004 */}
- `sizeof...(Indices) == extents_type::rank()` is `true`,
- (`std::is_convertible_v<Indices, index_type>` && ...) is `true`, and
- (`std::is_nothrow_constructible_v<index_type, Indices>` && ...) is `true`.

{/* source:cpp-container-mdspan-layout-right-mapping-operator:0005 */}
If `extents_type::`[`index-cast`](/docs/cpp/library/container/mdspan/extents/index-cast)`(i)` is not a multidimensional index in `extents()`, the behavior is undefined.
