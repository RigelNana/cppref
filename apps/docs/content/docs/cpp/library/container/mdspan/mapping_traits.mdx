    {/* source:cpp-container-mdspan-mapping-traits:0001 */}
    Checks if (1-3) the underlying layout mapping [`map_`](/docs/cpp/library/container/mdspan#Data_member) or (4-6) its type `mapping_type` models the semantics of [`LayoutMapping`](/docs/cpp/library/named_req/LayoutMapping)'s predicate mapping traits.

    {/* source:cpp-container-mdspan-mapping-traits:0002 */}
    1-3. Let `func` be (1) `is_unique`, (2) `is_exhaustive`, or (3) `is_strided`, then it's equivalent to `return map_.func();`.

    {/* source:cpp-container-mdspan-mapping-traits:0003 */}
    4-6. Let `func` be (4) `is_always_unique`, (5) `is_always_exhaustive`, or (6) `is_always_strided`, then it's equivalent to `return mapping_type::func();`.
  </DeclarationDescription>
