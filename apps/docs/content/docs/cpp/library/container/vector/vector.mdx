  <DeclarationDescription>
    {/* source:cpp-container-vector-vector:0001 */}
    Constructs a new `vector` from a variety of data sources, optionally using a user supplied allocator `alloc`.

    {/* source:cpp-container-vector-vector:0002 */}
    1) <InlineRevision since="C++20" /> The default constructor since C++11. Constructs an empty vector with a default-constructed allocator.

    {/* source:cpp-container-vector-vector:0003 */}
    If `Allocator` is not [DefaultConstructible](/docs/cpp/library/named_req/DefaultConstructible), the behavior is undefined.

    {/* source:cpp-container-vector-vector:0004 */}
    2) <InlineRevision since="C++17" /> <InlineRevision since="C++20" /> The default constructor until C++11. Constructs an empty vector with the given allocator `alloc`.

    {/* source:cpp-container-vector-vector:0005 */}
    3) Constructs a vector with `count` default-inserted objects of `T`. No copies are made.

    {/* source:cpp-container-vector-vector:0006 */}
    If `T` is not [DefaultInsertable](/docs/cpp/library/named_req/DefaultInsertable) into `std::vector<T>`, the behavior is undefined.

    {/* source:cpp-container-vector-vector:0007 */}
    4) <InlineRevision since="C++20" /> Constructs a vector with `count` copies of elements with value `value`.

    <Revision since="C++11">
    If `T` is not [CopyInsertable](/docs/cpp/library/named_req/CopyInsertable) into `std::vector<T>`, the behavior is undefined.
    </Revision>

    {/* source:cpp-container-vector-vector:0008 */}
    5) <InlineRevision since="C++20" /> Constructs a vector with the contents of the range [`first`, `last`). Each iterator in [`first`, `last`) is dereferenced exactly once.

    <Revision until="C++11">
    If `InputIt` does not satisfy the requirements of [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator), overload (4) is called instead with arguments `static_cast<size_type>(first)`, `last` and `alloc`.
    </Revision>

    <Revision since="C++11">
    This overload participates in overload resolution only if `InputIt` satisfies the requirements of [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator).

    If any of the following conditions is satisfied, the behavior is undefined:

    - `T` is not [EmplaceConstructible](/docs/cpp/library/named_req/EmplaceConstructible) into `std::vector<T>` from `*first`.
    - `Iter` does not satisfy the requirements of [LegacyForwardIterator](/docs/cpp/library/named_req/ForwardIterator), and `T` is not [MoveInsertable](/docs/cpp/library/named_req/MoveInsertable) into `std::vector<T>`.
    </Revision>

    {/* source:cpp-container-vector-vector:0009 */}
    6) Constructs a vector with the contents of the range `rg`. Each iterator in `rg` is dereferenced exactly once.

    {/* source:cpp-container-vector-vector:0010 */}
    If any of the following conditions is satisfied, the behavior is undefined:

    - `T` is not [EmplaceConstructible](/docs/cpp/library/named_req/EmplaceConstructible) into `std::vector<T>` from `*ranges::begin(rg)`.
    - `R` models neither [`sized_range`](/docs/cpp/library/ranges/sized_range) nor [`forward_range`](/docs/cpp/library/ranges/forward_range), and `T` is not [MoveInsertable](/docs/cpp/library/named_req/MoveInsertable) into `std::vector<T>`.

    {/* source:cpp-container-vector-vector:0011 */}
    7-10) <InlineRevision since="C++17" /> <InlineRevision since="C++20" /> Constructs a vector with the contents of `other`.

    {/* source:cpp-container-vector-vector:0012 */}
    7) <InlineRevision since="C++20" /> The copy constructor.

    <Revision since="C++11">
    The allocator is obtained as if by calling `std::allocator_traits<Allocator>::select_on_container_copy_construction(other.get_allocator())`.
    </Revision>

    {/* source:cpp-container-vector-vector:0013 */}
    8) <InlineRevision since="C++17" /> <InlineRevision since="C++20" /> The move constructor. The allocator is obtained by move construction from `other.get_allocator()`.

    {/* source:cpp-container-vector-vector:0014 */}
    9) <InlineRevision since="C++20" /> Same as the copy constructor, except that `alloc` is used as the allocator.

    {/* source:cpp-container-vector-vector:0015 */}
    If `T` is not [CopyInsertable](/docs/cpp/library/named_req/CopyInsertable) into `std::vector<T>`, the behavior is undefined.

    {/* source:cpp-container-vector-vector:0016 */}
    10) Same as the move constructor, except that `alloc` is used as the allocator.

    {/* source:cpp-container-vector-vector:0017 */}
    If `T` is not [MoveInsertable](/docs/cpp/library/named_req/MoveInsertable) into `std::vector<T>`, the behavior is undefined.

    {/* source:cpp-container-vector-vector:0018 */}
    11) Equivalent to `vector(il.begin(), il.end(), alloc)`.
  </DeclarationDescription>

### Complexity

{/* source:cpp-container-vector-vector:0020 */}
- 1,2) Constant.

{/* source:cpp-container-vector-vector:0021 */}
- 3,4) Linear in `count`.

{/* source:cpp-container-vector-vector:0022 */}
- 5) Given `std::distance(first, last)` as N: If `first` and `last` are both forward, bidirectional or random-access iterators, The copy constructor of `T` is only called N times, and No reallocation occurs. Otherwise (`first` and `last` are just input iterators), The copy constructor of `T` is called O(N) times, and Reallocation occurs O(log N) times.

{/* source:cpp-container-vector-vector:0023 */}
- 6) Given `ranges::distance(rg)` as N: If `R` models `ranges::forward_range` or `ranges::sized_range`, Initializes exactly N elements from the result of dereferencing successive iterators of `rg`, and No reallocation occurs. Otherwise (`R` models input range), The copy or move constructor of `T` is called O(N) times, and Reallocation occurs O(log N) times.

{/* source:cpp-container-vector-vector:0024 */}
- 7) Linear in `other.size()`.

{/* source:cpp-container-vector-vector:0025 */}
- 8) Constant.

{/* source:cpp-container-vector-vector:0026 */}
- 9) Linear in `other.size()`.

{/* source:cpp-container-vector-vector:0027 */}
- 10) Linear in `other.size()` if `alloc != other.get_allocator()`, otherwise constant.

{/* source:cpp-container-vector-vector:0028 */}
- 11) Linear in `init.size()`.

### Exceptions

{/* source:cpp-container-vector-vector:0029 */}
Calls to `Allocator::allocate` may throw.

### Notes

{/* source:cpp-container-vector-vector:0030 */}
After container move construction (overload (8)), references, pointers, and iterators (other than the end iterator) to `other` remain valid, but refer to elements that are now in `*this`. The current standard makes this guarantee via the blanket statement in [[container.reqmts]/67](https://eel.is/c++draft/container.reqmts#67), and a more direct guarantee is under consideration via [LWG issue 2321](https://cplusplus.github.io/LWG/issue2321).

### Example

{/* source:cpp-container-vector-vector:0032 */}
```cpp
#include <iostream>
#include <string>
#include <vector>

template<typename T>
std::ostream& operator<<(std::ostream& s, const std::vector<T>& v)
{
    s.put('{');
    for (char comma[]{'\0', ' ', '\0'}; const auto& e : v)
        s << comma << e, comma[0] = ',';
    return s << "}\n";
}

int main()
{
    // C++11 initializer list syntax:
    std::vector<std::string> words1{"the", "frogurt", "is", "also", "cursed"};
    std::cout << "1: " << words1;

    // words2 == words1
    std::vector<std::string> words2(words1.begin(), words1.end());
    std::cout << "2: " << words2;

    // words3 == words1
    std::vector<std::string> words3(words1);
    std::cout << "3: " << words3;

    // words4 is {"Mo", "Mo", "Mo", "Mo", "Mo"}
    std::vector<std::string> words4(5, "Mo");
    std::cout << "4: " << words4;

    const auto rg = {"cat", "cow", "crow"};
#ifdef __cpp_lib_containers_ranges
    std::vector<std::string> words5(std::from_range, rg); // overload (6)
#else
    std::vector<std::string> words5(rg.begin(), rg.end()); // overload (5)
#endif
    std::cout << "5: " << words5;
}
```

Output:

```text
1: {the, frogurt, is, also, cursed}
2: {the, frogurt, is, also, cursed}
3: {the, frogurt, is, also, cursed}
4: {Mo, Mo, Mo, Mo, Mo}
5: {cat, cow, crow}
```
