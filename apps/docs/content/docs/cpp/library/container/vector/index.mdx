    1. `std::vector` is a sequence container that encapsulates dynamic size arrays.

    {/* source:cpp-container-vector:0002 */}
    2. `std::pmr::vector` is an alias template that uses a [polymorphic allocator](/docs/cpp/library/memory/polymorphic_allocator).
  </DeclarationDescription>

{/* source:cpp-container-vector:0003 */}
The elements are stored contiguously, which means that elements can be accessed not only through iterators, but also using offsets to regular pointers to elements. This means that a pointer to an element of a vector may be passed to any function that expects a pointer to an element of an array.

{/* source:cpp-container-vector:0004 */}
The storage of the vector is handled automatically, being expanded as needed. Vectors usually occupy more space than static arrays, because more memory is allocated to handle future growth. This way a vector does not need to reallocate each time an element is inserted, but only when the additional memory is exhausted. The total amount of allocated memory can be queried using [`capacity()`](/docs/cpp/library/container/vector/capacity) function. Extra memory can be returned to the system via a call to [`shrink_to_fit()`](/docs/cpp/library/container/vector/shrink_to_fit)[1].

{/* source:cpp-container-vector:0005 */}
Reallocations are usually costly operations in terms of performance. The [`reserve()`](/docs/cpp/library/container/vector/reserve) function can be used to eliminate reallocations if the number of elements is known beforehand.

{/* source:cpp-container-vector:0006 */}
The complexity (efficiency) of common operations on vectors is as follows:

{/* source:cpp-container-vector:0007 */}
- Random access - constant 𝓞(1).
- Insertion or removal of elements at the end - amortized constant 𝓞(1).
- Insertion or removal of elements - linear in the distance to the end of the vector 𝓞(n).

{/* source:cpp-container-vector:0008 */}
`std::vector` (for `T` other than `bool`) meets the requirements of [`Container`](/docs/cpp/library/named_req/Container)<InlineRevision since="C++11">, [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer)</InlineRevision>, [`SequenceContainer`](/docs/cpp/library/named_req/SequenceContainer)<InlineRevision since="C++17">, [`ContiguousContainer`](/docs/cpp/library/named_req/ContiguousContainer)</InlineRevision> and [`ReversibleContainer`](/docs/cpp/library/named_req/ReversibleContainer).

{/* source:cpp-container-vector:0009 */}
<Revision since="C++20">
Member functions of `std::vector` are `constexpr`: it is possible to create and use `std::vector` objects in the evaluation of a constant expression.

However, `std::vector` objects generally cannot be `constexpr`, because any dynamically allocated storage must be released in the same evaluation of constant expression.
</Revision>

{/* source:cpp-container-vector:0010 */}
↑ In libstdc++, `shrink_to_fit()` is [not available](https://gcc.gnu.org/onlinedocs/libstdc++/manual/strings.html#strings.string.shrink) in C++98 mode.

| Operations | Invalidated |
| --- | --- |
| All read only operations | Never. |
| [`swap`](/docs/cpp/library/container/vector/swap), [`std::swap`](/docs/cpp/library/algorithm/swap) | [`end()`](/docs/cpp/library/container/vector/end) |
| [`clear`](/docs/cpp/library/container/vector/clear), [`operator=`](/docs/cpp/container/vector/operator%3D), [`assign`](/docs/cpp/library/container/vector/assign) | Always. |
| [`reserve`](/docs/cpp/library/container/vector/reserve), [`shrink_to_fit`](/docs/cpp/library/container/vector/shrink_to_fit) | If the vector changed capacity, all of them. If not, none. |

### Example

{/* source:cpp-container-vector:0020 */}
```cpp
#include <iostream>
#include <vector>

int main()
{
    // Create a vector containing integers
    std::vector<int> v = {8, 4, 5, 9};

    // Add two more integers to vector
    v.push_back(6);
    v.push_back(9);

    // Overwrite element at position 2
    v[2] = -1;

    // Print out the vector
    for (int n : v)
        std::cout << n << ' ';
    std::cout << '\n';
}
```

Output:

```text
8 4 -1 9 6 9
```
