### Parameters

{/* source:cpp-container-vector-size:0002 */}
(none)

### Return value

{/* source:cpp-container-vector-size:0003 */}
The number of elements in the container.

### Complexity

{/* source:cpp-container-vector-size:0004 */}
Constant.

### Example

{/* source:cpp-container-vector-size:0005 */}
The following code uses `size` to display the number of elements in a `std::vector<int>`:

```cpp
#include <cassert>
#include <vector>

int main()
{
    std::vector<int> nums;
    assert(nums.size() == 0);
    nums = {1, 2, 3, 4};
    assert(nums.size() == 4);
}
```
