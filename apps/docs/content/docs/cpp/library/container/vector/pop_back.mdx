{/* source:cpp-container-vector-pop-back:0002 */}
Calling `pop_back` on an empty container results in undefined behavior.

{/* source:cpp-container-vector-pop-back:0003 */}
Iterators and references to the last element are invalidated. The [`end()`](/docs/cpp/library/container/vector/end) iterator is also invalidated.

### Parameters

{/* source:cpp-container-vector-pop-back:0004 */}
(none)

### Return value

{/* source:cpp-container-vector-pop-back:0005 */}
(none)

### Complexity

{/* source:cpp-container-vector-pop-back:0006 */}
Constant.

### Exceptions

{/* source:cpp-container-vector-pop-back:0007 */}
Throws nothing.

### Example

{/* source:cpp-container-vector-pop-back:0008 */}
```cpp
#include <vector>
#include <iostream>

namespace stq {
template<typename T>
void println(auto, const T& xz)
{
    std::cout << '[';
    bool first{true};
    for (auto const& x : xz)
        std::cout << (first ? first = false, "" : ", ") << x;
    std::cout << "]\n";
}
}

int main()
{
    std::vector<int> numbers{1, 2, 3};
    stq::println("{}", numbers);
    while (not numbers.empty())
    {
        numbers.pop_back();
        stq::println("{}", numbers);
    }
}
```

Output:

```text
[1, 2, 3]
[1, 2]
[1]
[]
```
