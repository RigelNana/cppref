### Parameters

{/* source:cpp-container-vector-max-size:0002 */}
(none)

### Return value

{/* source:cpp-container-vector-max-size:0003 */}
Maximum number of elements.

### Complexity

{/* source:cpp-container-vector-max-size:0004 */}
Constant.

### Notes

{/* source:cpp-container-vector-max-size:0005 */}
This value typically reflects the theoretical limit on the size of the container, at most `std::numeric_limits<difference_type>::max()`. At runtime, the size of the container may be limited to a value smaller than `max_size()` by the amount of RAM available.

### Example

{/* source:cpp-container-vector-max-size:0006 */}
```cpp
#include <iostream>
#include <locale>
#include <vector>

int main()
{
    std::vector<char> p;
    std::vector<long> q;

    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << std::uppercase
              << "p.max_size() = " << std::dec << p.max_size() << " = 0x"
              << std::hex << p.max_size() << '\n'
              << "q.max_size() = " << std::dec << q.max_size() << " = 0x"
              << std::hex << q.max_size() << '\n';
}
```

Possible output:

```text
p.max_size() = 9,223,372,036,854,775,807 = 0x7,FFF,FFF,FFF,FFF,FFF
q.max_size() = 1,152,921,504,606,846,975 = 0xFFF,FFF,FFF,FFF,FFF
```
