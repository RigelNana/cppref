{/* source:cpp-container-vector-assign-range:0000 */}
<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`template< container-compatible-range<T> R >
constexpr void assign_range( R&& rg );`} />

  <DeclarationDescription>
    {/* source:cpp-container-vector-assign-range:0001 */}
    1. Replaces elements in the container with a copy of each element in `rg`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-container-vector-assign-range:0002 */}
All iterators (including the [`end()`](/docs/cpp/library/container/vector/end) iterator) and all references to the elements are invalidated.

{/* source:cpp-container-vector-assign-range:0003 */}
Each iterator in the range `rg` is dereferenced exactly once.

{/* source:cpp-container-vector-assign-range:0004 */}
The behavior is undefined if `rg` overlaps with the container.

### Parameters

{/* source:cpp-container-vector-assign-range:0005 */}
<ParameterList>
  <Parameter name="rg">an [input_range](/docs/cpp/library/ranges/input_range) with reference type convertible to the element type of the container</Parameter>
</ParameterList>

Type requirements

- `std::assignable_from<T&, ranges::range_reference_t<R>>` must be modeled. Otherwise, the program is ill-formed.
- `T` must be [EmplaceConstructible](/docs/cpp/library/named_req/EmplaceConstructible) into the container from `*ranges::begin(rg)`. If `R` models neither [sized_range](/docs/cpp/library/ranges/sized_range) nor [forward_range](/docs/cpp/library/ranges/forward_range), `T` must be also [MoveInsertable](/docs/cpp/library/named_req/MoveInsertable) into the container. Otherwise, the behavior is undefined.

### Return value

{/* source:cpp-container-vector-assign-range:0006 */}
(none)

### Example

{/* source:cpp-container-vector-assign-range:0008 */}
```cpp
#include <algorithm>
#include <cassert>
#include <vector>
#include <list>

int main()
{
    const auto source = std::list{2, 7, 1};
    auto destination = std::vector{3, 1, 4};
#ifdef __cpp_lib_containers_ranges
    destination.assign_range(source);
#else
    destination.assign(source.cbegin(), source.cend());
#endif
    assert(std::ranges::equal(source, destination));
}
```
