{/* source:cpp-container-vector-shrink-to-fit:0002 */}
It is a non-binding request to reduce [`capacity()`](/docs/cpp/library/container/vector/capacity) to [`size()`](/docs/cpp/library/container/vector/size). It depends on the implementation whether the request is fulfilled.

{/* source:cpp-container-vector-shrink-to-fit:0003 */}
If reallocation occurs, all iterators (including the [`end()`](/docs/cpp/library/container/vector/end) iterator) and all references to the elements are invalidated. If no reallocation occurs, no iterators or references are invalidated.

{/* source:cpp-container-vector-shrink-to-fit:0004 */}
<Revision since="C++11">
If `T` is not [`MoveInsertable`](/docs/cpp/library/named_req/MoveInsertable) into `std::vector<T, Allocator>`, the behavior is undefined.
</Revision>

### Complexity

{/* source:cpp-container-vector-shrink-to-fit:0005 */}
At most linear in the size of the container.

{/* source:cpp-container-vector-shrink-to-fit:0006 */}
### Exceptions

<Revision since="C++11">
If an exception is thrown other than by the move constructor of a non-[`CopyInsertable`](/docs/cpp/library/named_req/CopyInsertable) `T`, there are no effects.
</Revision>

### Notes

{/* source:cpp-container-vector-shrink-to-fit:0007 */}
In libstdc++, `shrink_to_fit()` is [not available](https://gcc.gnu.org/onlinedocs/libstdc++/manual/strings.html#strings.string.shrink) in C++98 mode.

### Example

{/* source:cpp-container-vector-shrink-to-fit:0008 */}
```cpp
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> v;
    std::cout << "Default-constructed capacity is " << v.capacity() << '\n';
    v.resize(100);
    std::cout << "Capacity of a 100-element vector is " << v.capacity() << '\n';
    v.resize(50);
    std::cout << "Capacity after resize(50) is " << v.capacity() << '\n';
    v.shrink_to_fit();
    std::cout << "Capacity after shrink_to_fit() is " << v.capacity() << '\n';
    v.clear();
    std::cout << "Capacity after clear() is " << v.capacity() << '\n';
    v.shrink_to_fit();
    std::cout << "Capacity after shrink_to_fit() is " << v.capacity() << '\n';
    for (int i = 1000; i < 1300; ++i)
        v.push_back(i);
    std::cout << "Capacity after adding 300 elements is " << v.capacity() << '\n';
    v.shrink_to_fit();
    std::cout << "Capacity after shrink_to_fit() is " << v.capacity() << '\n';
}
```

Possible output:

```text
Default-constructed capacity is 0
Capacity of a 100-element vector is 100
Capacity after resize(50) is 100
Capacity after shrink_to_fit() is 50
Capacity after clear() is 50
Capacity after shrink_to_fit() is 0
Capacity after adding 300 elements is 512
Capacity after shrink_to_fit() is 300
```
