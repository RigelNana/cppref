<DeclarationDoc>
  <Declaration language="cpp" since="C++11" code={`template< class... Args >
iterator emplace( const_iterator pos, Args&&... args );`} />

  <DeclarationDescription>
    {/* source:cpp-container-vector-emplace:0001 */}
    1. <InlineRevision since="C++20" /> Inserts a new element into the container directly before `pos`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-container-vector-emplace:0002 */}
The element is constructed through [`std::allocator_traits::construct`](/docs/cpp/library/memory/allocator_traits/construct), which typically uses placement-new to construct the element in-place at a location provided by the container. However, if the required location has been occupied by an existing element, the inserted element is constructed at another location at first, and then move assigned into the required location.

{/* source:cpp-container-vector-emplace:0003 */}
The arguments `args...` are forwarded to the constructor as `std::forward<Args>(args)...`. `args...` may directly or indirectly refer to a value in the container.

{/* source:cpp-container-vector-emplace:0004 */}
If after the operation the new [`size()`](/docs/cpp/library/container/vector/size) is greater than old [`capacity()`](/docs/cpp/library/container/vector/capacity) a reallocation takes place, in which case all iterators (including the [`end()`](/docs/cpp/library/container/vector/end) iterator) and all references to the elements are invalidated. Otherwise, only the iterators and references before the insertion point remain valid.

### Parameters

{/* source:cpp-container-vector-emplace:0005 */}
<ParameterList>
  <Parameter name="pos">iterator before which the new element will be constructed</Parameter>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

Type requirements

- `T` (the container's element type) must meet the requirements of [MoveAssignable](/docs/cpp/library/named_req/MoveAssignable), [MoveInsertable](/docs/cpp/library/named_req/MoveInsertable) and [EmplaceConstructible](/docs/cpp/library/named_req/EmplaceConstructible).

### Return value

{/* source:cpp-container-vector-emplace:0006 */}
Iterator pointing to the emplaced element.

### Complexity

{/* source:cpp-container-vector-emplace:0007 */}
Linear in the distance between `pos` and end of the container.

### Exceptions

{/* source:cpp-container-vector-emplace:0008 */}
If an exception is thrown other than by the copy constructor, move constructor, assignment operator, or move assignment operator of `T`, or if an exception is thrown while `emplace` is used to insert a single element at the end and `T` is either [CopyInsertable](/docs/cpp/library/named_req/CopyInsertable) or nothrow move constructible, there are no effects ([strong exception guarantee](/docs/cpp/language/exceptions#Exception_safety)).

{/* source:cpp-container-vector-emplace:0009 */}
Otherwise, the effects are unspecified.

### Example

{/* source:cpp-container-vector-emplace:0010 */}
```cpp
#include <iostream>
#include <string>
#include <vector>

struct A
{
    std::string s;

    A(std::string str) : s(std::move(str)) { std::cout << " constructed\n"; }

    A(const A& o) : s(o.s) { std::cout << " copy constructed\n"; }

    A(A&& o) : s(std::move(o.s)) { std::cout << " move constructed\n"; }

    A& operator=(const A& other)
    {
        s = other.s;
        std::cout << " copy assigned\n";
        return *this;
    }

    A& operator=(A&& other)
    {
        s = std::move(other.s);
        std::cout << " move assigned\n";
        return *this;
    }
};

int main()
{
    std::vector<A> container;
    // reserve enough place so vector does not have to resize
    container.reserve(10);
    std::cout << "construct 2 times A:\n";
    A two{"two"};
    A three{"three"};

    std::cout << "emplace:\n";
    container.emplace(container.end(), "one");

    std::cout << "emplace with A&:\n";
    container.emplace(container.end(), two);

    std::cout << "emplace with A&&:\n";
    container.emplace(container.end(), std::move(three));

    std::cout << "content:\n";
    for (const auto& obj : container)
        std::cout << ' ' << obj.s;
    std::cout << '\n';
}
```

Output:

```text
construct 2 times A:
 constructed
 constructed
emplace:
 constructed
emplace with A&:
 copy constructed
emplace with A&&:
 move constructed
content:
 one two three
```
