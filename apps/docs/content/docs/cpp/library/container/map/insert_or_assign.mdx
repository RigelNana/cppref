{/* source:cpp-container-map-insert-or-assign:0001 */}
- 1,4) If a key equivalent to `k` already exists in the container, assigns `std::forward<M>(obj)` to the [`mapped_type`](/docs/cpp/library/container/map#Member_types) corresponding to the key `k`. If the key does not exist, inserts the new value as if by [`insert`](/docs/cpp/library/container/map/insert), constructing it from `value_type(k, std::forward<M>(obj))`.

{/* source:cpp-container-map-insert-or-assign:0002 */}
- 2,5) Same as (1,4), except the mapped value is constructed from `value_type(std::move(k), std::forward<M>(obj))`.

{/* source:cpp-container-map-insert-or-assign:0003 */}
- 3,6) If a key equivalent to `k` already exists in the container, assigns `std::forward<M>(obj)` to the [`mapped_type`](/docs/cpp/library/container/map#Member_types) corresponding to the key `k`. If the key does not exist, constructs an object `u` of `value_type` with `std::forward<K>(k), std::forward<M>(obj))`, then inserts `u` into `*this`. If `equal_range(u.first) == equal_range(k)` is `false`, the behavior is undefined. The `value_type` must be [`EmplaceConstructible`](/docs/cpp/library/named_req/EmplaceConstructible) into map from `std::forward<K>(k), std::forward<M>(obj)`. This overload participates in overload resolution only if the qualified-id `Compare::is_transparent` is valid and denotes a type. It allows calling this function without constructing an instance of `Key`.

{/* source:cpp-container-map-insert-or-assign:0004 */}
<InlineRevision until="C++20">The behavior is undefined</InlineRevision> <InlineRevision since="C++20">The program is ill-formed</InlineRevision> if `std::is_assignable_v<mapped_type&, M&&>` is `false`.

{/* source:cpp-container-map-insert-or-assign:0005 */}
No iterators or references are invalidated.

## Return value

{/* source:cpp-container-map-insert-or-assign:0007 */}
- 1-3) The `bool` component is `true` if the insertion took place and `false` if the assignment took place. The iterator component is pointing at the element that was inserted or updated.

{/* source:cpp-container-map-insert-or-assign:0008 */}
- 4-6) Iterator pointing at the element that was inserted or updated.

## Complexity

{/* source:cpp-container-map-insert-or-assign:0009 */}

{/* source:cpp-container-map-insert-or-assign:0010 */}
- 4-6) Same as for [`emplace_hint`](/docs/cpp/library/container/map/emplace_hint).

## Example

{/* source:cpp-container-map-insert-or-assign:0013 */}
```cpp
#include <iostream>
#include <string>
#include <map>

void print_node(const auto& node)
{
    std::cout << '[' << node.first << "] = " << node.second << '\n';
}

void print_result(auto const& pair)
{
    std::cout << (pair.second ? "inserted: " : "assigned: ");
    print_node(*pair.first);
}

int main()
{
    std::map<std::string, std::string> myMap;

    print_result(myMap.insert_or_assign("a", "apple"));
    print_result(myMap.insert_or_assign("b", "banana"));
    print_result(myMap.insert_or_assign("c", "cherry"));
    print_result(myMap.insert_or_assign("c", "clementine"));

    for (const auto& node : myMap)
        print_node(node);
}
```

Output:

```text
inserted: [a] = apple
inserted: [b] = banana
inserted: [c] = cherry
assigned: [c] = clementine
[a] = apple
[b] = banana
[c] = clementine
```
