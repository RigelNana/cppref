{/* source:cpp-container-map-map:0001 */}
Constructs new container from a variety of data sources and optionally using user supplied allocator `alloc` or comparison function object `comp`.

{/* source:cpp-container-map-map:0002 */}
1-3. Constructs an empty container.

{/* source:cpp-container-map-map:0003 */}
4,5. Constructs the container with the contents of the range `[`first`, `last`). If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

{/* source:cpp-container-map-map:0004 */}
If `[`first`, `last`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-container-map-map:0005 */}
6,7. [*Copy constructor*](/docs/cpp/language/classes/copy_constructor). Constructs the container with the copy of the contents of `other`.

<Revision since="C++11">
If `alloc` is not provided, allocator is obtained by calling `std::allocator_traits<allocator_type>::select_on_container_copy_construction(other.get_allocator())`.
</Revision>

<Revision since="C++23">
During [class template argument deduction](/docs/cpp/language/templates/ctad), only the first argument contributes to the deduction of the container's `Allocator` template parameter.
</Revision>

{/* source:cpp-container-map-map:0006 */}
8,9. [*Move constructor*](/docs/cpp/language/classes/move_constructor). Constructs the container with the contents of `other` using move semantics. If `alloc` is not provided, allocator is obtained by move-construction from the allocator belonging to `other`.

<Revision since="C++23">
During [class template argument deduction](/docs/cpp/language/templates/ctad), only the first argument contributes to the deduction of the container's `Allocator` template parameter.
</Revision>

{/* source:cpp-container-map-map:0007 */}
10,11. [*Initializer-list constructor*](/docs/cpp/language/initialization/list_initialization). Constructs the container with the contents of the initializer list `init`. If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

{/* source:cpp-container-map-map:0008 */}
12,13. Constructs the container with the contents of `rg`. If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

## Parameters

{/* source:cpp-container-map-map:0009 */}
<ParameterList>
  <Parameter name="alloc">allocator to use for all memory allocations of this container</Parameter>
  <Parameter name="comp">comparison function object to use for all comparisons of keys</Parameter>
  <Parameter name="first, last">the range to copy the elements from</Parameter>
  <Parameter name="other">another container to be used as source to initialize the elements of the container with</Parameter>
  <Parameter name="init">initializer list to initialize the elements of the container with</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to [`value_type`](/docs/cpp/library/container/map#Member_types)</Parameter>
</ParameterList>

**Type requirements**

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `Compare` must meet the requirements of [*Compare*](/docs/cpp/library/named_req/Compare).
- `Allocator` must meet the requirements of [*Allocator*](/docs/cpp/library/named_req/Allocator).

## Complexity

{/* source:cpp-container-map-map:0010 */}
1-3. Constant.

{/* source:cpp-container-map-map:0011 */}
4,5. `N·log(N)` where `N` is `std::distance(first, last)` in general, linear in `N` if `[`first`, `last`) is already sorted by `value_comp()`.

{/* source:cpp-container-map-map:0012 */}
6,7. Linear in size of `other`.

{/* source:cpp-container-map-map:0013 */}
8,9. Constant. If `alloc` is given and `alloc != other.get_allocator()`, then linear.

{/* source:cpp-container-map-map:0014 */}
10,11. `N·log(N)` where `N` is `init.size()` in general, linear in `N` if `init` is already sorted by `value_comp()`.

{/* source:cpp-container-map-map:0015 */}
12,13. `N·log(N)` where `N` is `ranges::distance(rg)` in general, linear in `N` if `rg` is already sorted by `value_comp()`.

## Exceptions

{/* source:cpp-container-map-map:0016 */}
Calls to `Allocator::allocate` may throw.

## Notes

{/* source:cpp-container-map-map:0017 */}
After container move construction (overload (8,9)), references, pointers, and iterators (other than the end iterator) to `other` remain valid, but refer to elements that are now in `*this`. The current standard makes this guarantee via the blanket statement in [[container.reqmts]/67](https://eel.is/c++draft/container.reqmts#67), and a more direct guarantee is under consideration via [LWG issue 2321](https://cplusplus.github.io/LWG/issue2321).

{/* source:cpp-container-map-map:0018 */}
Although not formally required until C++23, some implementations has already put the template parameter `Allocator` into [non-deduced contexts](/docs/cpp/language/templates/template_argument_deduction#Non-deduced_contexts) in earlier modes.

## Example

{/* source:cpp-container-map-map:0020 */}
```cpp
#include <iomanip>
#include <iostream>
#include <map>
#include <string>
 
template<typename Key, typename Value, typename Cmp>
std::ostream& operator<<(std::ostream& os, std::map<Key, Value, Cmp> const& map)
{
    os << "{ ";
    for (auto comma{map.size()}; auto const& p : map)
        os << '\'' << p.first << "' is " << p.second << (--comma ? ", " : " ");
    return os << "}\n";
}
 
struct Point
{
    double x, y;
 
    friend std::ostream& operator<<(std::ostream& os, Point pt)
    {
        return os << '(' << pt.x << ", " << pt.y << ')';
    }
};
 
struct PointCmp
{
    bool operator()(const Point& lhs, const Point& rhs) const
    {
        return lhs.x < rhs.x; // NB: y is intentionally ignored
    }
};
 
int main()
{
    // (1) Default constructor
    std::map<std::string, int> map1;
    map1["something"] = 69;
    map1["anything"] = 199;
    map1["that thing"] = 50;
    std::cout << "map1 = " << map1;
 
    // (4) Range constructor
    std::map<std::string, int> iter(map1.find("anything"), map1.end());
    std::cout << "\niter = " << iter;
    std::cout << "map1 = " << map1;
 
    // (6) Copy constructor
    std::map<std::string, int> copied(map1);
    std::cout << "\ncopied = " << copied;
    std::cout << "map1 = " << map1;
 
    // (8) Move constructor
    std::map<std::string, int> moved{std::move(map1)};
    std::cout << "\nmoved = " << moved;
    std::cout << "map1 = " << map1;
 
    // (10) Initializer list constructor
    const std::map<std::string, int> init
    {
        {"this", 100},
        {"can", 100},
        {"be", 100},
        {"const", 100}
    };
    std::cout << "\ninit = " << init;
 
    std::cout << "\nCustom Key class option 1:\n";
    // Use a comparison struct
    std::map<Point, double, PointCmp> mag =
    {
        {{5, -12}, 13},
        {{3, 4}, 5},
        {{-8, -15}, 17}
    };
    std::cout << "mag = " << mag << '\n';
 
    std::cout << "Custom Key class option 2:\n";
    // Use a comparison lambda
    // This lambda sorts points according to their magnitudes, where
    // these magnitudes are taken from the local variable mag.
    auto cmpLambda = [&mag](const Point& lhs, const Point& rhs)
    {
        return mag[lhs] < mag[rhs];
    };
 
    // You could also use a lambda that is not dependent on local variables, like this:
    // auto cmpLambda = [](const Point& lhs, const Point& rhs){ return lhs.y < rhs.y; };
    std::map<Point, double, decltype(cmpLambda)> magy(cmpLambda);
 
    // Various ways of inserting elements:
    magy.insert(std::pair<Point, double>({5, -12}, 13));
    magy.insert({{3, 4}, 5});
    magy.insert({Point{-8.0, -15.0}, 17});    
    std::cout << "magy = " << magy << '\n';
 
    std::cout << "Construction from a range:\n";
    using PS = std::pair<const std::string, int>;
    const auto rg = {PS{"one", 1}, {"one", 101}, {"two", 2}, {"three", 3}};
#if __cpp_lib_containers_ranges
    std::map<std::string, int> nums(std::from_range, rg); // overload (12)
#else
    std::map<std::string, int> nums(rg.begin(), rg.end()); // fallback to (4)
#endif
    std::cout << "nums = " << nums << '\n';
}
```

Output:

```text

iter = { 'anything' is 199, 'something' is 69, 'that thing' is 50 }
map1 = { 'anything' is 199, 'something' is 69, 'that thing' is 50 }
 
copied = { 'anything' is 199, 'something' is 69, 'that thing' is 50 }
map1 = { 'anything' is 199, 'something' is 69, 'that thing' is 50 }

map1 = { }
```
