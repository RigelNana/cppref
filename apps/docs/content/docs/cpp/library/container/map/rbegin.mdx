    {/* source:cpp-container-map-rbegin:0001 */}
    1. <InlineRevision since="C++11" /> Returns a reverse iterator to the first element of the reversed map. It corresponds to the last element of the non-reversed map. If the map is empty, the returned iterator is equal to [`rend()`](/docs/cpp/library/container/map/rend).
  </DeclarationDescription>
</DeclarationDoc>

## Parameters

{/* source:cpp-container-map-rbegin:0002 */}
(none)

## Return value

{/* source:cpp-container-map-rbegin:0003 */}
Reverse iterator to the first element.

## Complexity

{/* source:cpp-container-map-rbegin:0004 */}
Constant.

## Notes

{/* source:cpp-container-map-rbegin:0005 */}
The [underlying iterator](/docs/cpp/library/iterator/reverse_iterator/base) of the returned reverse iterator is the [end iterator](/docs/cpp/library/container/map/end). Hence the returned iterator is invalidated if and when the end iterator is invalidated.

{/* source:cpp-container-map-rbegin:0006 */}
libc++ backports `crbegin()` to C++98 mode.

## Example

{/* source:cpp-container-map-rbegin:0007 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string_view>
#include <map>
 
int main()
{
    const std::map<int, std::string_view> coins
    {
        {10, "dime"},
        {100, "dollar"},
        {50, "half dollar"},
        {5, "nickel"},
        {1, "penny"},
        {25, "quarter"}
    }; // initializer entries in name alphabetical order
 
    std::cout << "US coins in circulation, largest to smallest denomination:\n";
    for (auto it = coins.crbegin(); it != coins.crend(); ++it)
        std::cout << std::setw(11) << it->second << " = ¢" << it->first << '\n';
}
```

Output:

```text
US coins in circulation, largest to smallest denomination:
     dollar = ¢100
half dollar = ¢50
    quarter = ¢25
       dime = ¢10
     nickel = ¢5
      penny = ¢1
```
