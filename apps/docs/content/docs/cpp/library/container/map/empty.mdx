{/* source:cpp-container-map-empty:0001 */}
Checks if the container has no elements, i.e. whether `begin() == end()`.

## Parameters

{/* source:cpp-container-map-empty:0002 */}
(none)

## Return value

{/* source:cpp-container-map-empty:0003 */}
`true` if the container is empty, `false` otherwise.

## Complexity

{/* source:cpp-container-map-empty:0004 */}
Constant.

## Example

{/* source:cpp-container-map-empty:0005 */}
The following code uses `empty` to check if a `std::map<int, int>` contains any elements:

```cpp
#include <iostream>
#include <map>
#include <utility>

int main()
{
    std::map<int,int> numbers;
    std::cout << std::boolalpha;
    std::cout << "Initially, numbers.empty(): " << numbers.empty() << '\n';

    numbers.emplace(42, 13);
    numbers.insert(std::make_pair(13317, 123));
    std::cout << "After adding elements, numbers.empty(): " << numbers.empty() << '\n';
}
```

Output:

```text
Initially, numbers.empty(): true
After adding elements, numbers.empty(): false
```
