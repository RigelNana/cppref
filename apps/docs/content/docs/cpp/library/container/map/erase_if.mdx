{/* source:cpp-container-map-erase-if:0001 */}
Erases all elements that satisfy the predicate `pred` from `c`.

{/* source:cpp-container-map-erase-if:0002 */}
Equivalent to

{/* source:cpp-container-map-erase-if:0003 */}
```cpp
auto old_size = c.size();
for (auto first = c.begin(), last = c.end(); first != last;)
{
    if (pred(*first))
        first = c.erase(first);
    else
        ++first;
}
return old_size - c.size();
```

## Parameters

{/* source:cpp-container-map-erase-if:0004 */}
<ParameterList>
  <Parameter name="c">container from which to erase</Parameter>
  <Parameter name="pred">predicate that returns `true` if the element should be erased</Parameter>
</ParameterList>

## Return value

{/* source:cpp-container-map-erase-if:0005 */}
The number of erased elements.

## Complexity

{/* source:cpp-container-map-erase-if:0006 */}
Linear.

## Example

{/* source:cpp-container-map-erase-if:0007 */}
```cpp
#include <iostream>
#include <map>

void println(auto rem, auto const& container)
{
    std::cout << rem << '{';
    for (char sep[]{0, ' ', 0}; const auto& [key, value] : container)
        std::cout << sep << '{' << key << ", " << value << '}', *sep = ',';
    std::cout << "}\n";
}

int main()
{
    std::map<int, char> data
    {
        {1, 'a'}, {2, 'b'}, {3, 'c'}, {4, 'd'},
        {5, 'e'}, {4, 'f'}, {5, 'g'}, {5, 'g'},
    };
    println("Original:\n", data);

    const auto count = std::erase_if(data, [](const auto& item)
    {
        auto const& [key, value] = item;
        return (key & 1) == 1;
    });

    println("Erase items with odd keys:\n", data);
    std::cout << count << " items removed.\n";
}
```

Output:

```text
Original:
{{1, a}, {2, b}, {3, c}, {4, d}, {5, e}}
Erase items with odd keys:
{{2, b}, {4, d}}
3 items removed.
```
