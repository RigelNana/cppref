  </DeclarationDescription>

{/* source:cpp-container-unordered-set-end:0002 */}
This element acts as a placeholder; attempting to access it results in undefined behavior.

### Parameters

{/* source:cpp-container-unordered-set-end:0003 */}
(none)

### Return value

{/* source:cpp-container-unordered-set-end:0004 */}
Iterator to the element following the last element.

### Complexity

{/* source:cpp-container-unordered-set-end:0005 */}
Constant.

### Notes

{/* source:cpp-container-unordered-set-end:0006 */}
Because both `iterator` and `const_iterator` are constant iterators (and may in fact be the same type), it is not possible to mutate the elements of the container through an iterator returned by any of these member functions.

### Example

{/* source:cpp-container-unordered-set-end:0007 */}
```cpp
#include <iostream>
#include <unordered_set>
 
struct Point { double x, y; };
 
int main()
{
    Point pts[3] = {{1, 0}, {2, 0}, {3, 0}};
 
    // points is a set containing the addresses of points
    std::unordered_set<Point*> points = { pts, pts + 1, pts + 2 };
 
    // Change each y-coordinate of (i, 0) from 0 into i^2 and print the point
    for (auto iter = points.begin(); iter != points.end(); ++iter)
    {
        (*iter)->y = ((*iter)->x) * ((*iter)->x); // iter is a pointer-to-Point*
        std::cout << "(" << (*iter)->x << ", " << (*iter)->y << ") ";
    }
    std::cout << '\n';
 
    // Now using the range-based for loop, we increase each y-coordinate by 10
    for (Point* i : points)
    {
        i->y += 10;
        std::cout << "(" << i->x << ", " << i->y << ") ";
    }
}
```

Possible output:

```text
(3, 9) (1, 1) (2, 4) 
(3, 19) (1, 11) (2, 14)
```
