{/* source:cpp-container-unordered-set-emplace:0001 */}

Inserts a new element into the container constructed in-place with the given `args`, if there is no element with the key in the container.

{/* source:cpp-container-unordered-set-emplace:0002 */}

The constructor of the new element is called with exactly the same arguments as supplied to `emplace`, forwarded via `std::forward<Args>(args)...`. The element may be constructed even if there already is an element with the key in the container, in which case the newly constructed element will be destroyed immediately.

{/* source:cpp-container-unordered-set-emplace:0003 */}

Careful use of `emplace` allows the new element to be constructed while avoiding unnecessary copy or move operations.

{/* source:cpp-container-unordered-set-emplace:0004 */}

If after the operation the new number of elements is greater than old [`max_load_factor()`](/docs/cpp/library/container/unordered_set/max_load_factor) * [`bucket_count()`](/docs/cpp/library/container/unordered_set/bucket_count) a rehashing takes place. If rehashing occurs (due to the insertion), all iterators are invalidated. Otherwise (no rehashing), iterators are not invalidated.

### Parameters

{/* source:cpp-container-unordered-set-emplace:0005 */}

<ParameterList>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>

### Return value

{/* source:cpp-container-unordered-set-emplace:0006 */}

A pair consisting of an iterator to the inserted element (or to the element that prevented the insertion) and a `bool` value set to `true` if and only if the insertion took place.

### Exceptions

{/* source:cpp-container-unordered-set-emplace:0007 */}

If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-container-unordered-set-emplace:0008 */}

Amortized constant on average, worst case linear in the size of the container.
