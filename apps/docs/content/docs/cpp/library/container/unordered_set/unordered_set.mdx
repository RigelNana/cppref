{/* source:cpp-container-unordered-set-unordered-set:0001 */}
Constructs new container from a variety of data sources. Optionally uses user supplied `bucket_count` as a minimal number of buckets to create, `hash` as the hash function, `equal` as the function to compare keys and `alloc` as the allocator.

{/* source:cpp-container-unordered-set-unordered-set:0002 */}
1. Constructs empty container. Sets [`max_load_factor()`](/docs/cpp/library/container/unordered_set/max_load_factor) to `1.0`. For the default constructor, the number of buckets is unspecified.

{/* source:cpp-container-unordered-set-unordered-set:0003 */}
2. Constructs the container with the contents of the range `[first, last)`. Sets [`max_load_factor()`](/docs/cpp/library/container/unordered_set/max_load_factor) to `1.0`. If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [`LWG2844`](https://cplusplus.github.io/LWG/issue2844)).

{/* source:cpp-container-unordered-set-unordered-set:0004 */}
3. Copy constructor. Constructs the container with the copy of the contents of `other`, copies the load factor, the predicate, and the hash function as well. If `alloc` is not provided, allocator is obtained by calling `std::allocator_traits<allocator_type>::select_on_container_copy_construction(other.get_allocator())`. <Revision since="C++23">The template parameter `Allocator` is only deduced from the first argument while used in [`class template argument deduction`](/docs/cpp/language/templates/ctad).</Revision>

{/* source:cpp-container-unordered-set-unordered-set:0005 */}
4. [`Move constructor`](/docs/cpp/language/classes/move_constructor). Constructs the container with the contents of `other` using move semantics. If `alloc` is not provided, allocator is obtained by move-construction from the allocator belonging to `other`. <Revision since="C++23">The template parameter `Allocator` is only deduced from the first argument while used in [`class template argument deduction`](/docs/cpp/language/templates/ctad).</Revision>

{/* source:cpp-container-unordered-set-unordered-set:0006 */}
5. [`Initializer-list constructor`](/docs/cpp/language/initialization/list_initialization). Constructs the container with the contents of the initializer list `init`, same as `unordered_set(init.begin(), init.end())`.

{/* source:cpp-container-unordered-set-unordered-set:0007 */}
6. Constructs the container with the contents of `rg`. If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [`LWG2844`](https://cplusplus.github.io/LWG/issue2844)).

### Parameters

{/* source:cpp-container-unordered-set-unordered-set:0008 */}
<ParameterList>
  <Parameter name="alloc">allocator to use for all memory allocations of this container</Parameter>
  <Parameter name="bucket_count">minimal number of buckets to use on initialization. If it is not specified, an unspecified default value is used</Parameter>
  <Parameter name="hash">hash function to use</Parameter>
  <Parameter name="equal">comparison function to use for all key comparisons of this container</Parameter>
  <Parameter name="first, last">the range `[first, last)` to copy the elements from</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to [`value_type`](/docs/cpp/library/container/unordered_set#Member_types)</Parameter>
  <Parameter name="other">another container to be used as source to initialize the elements of the container with</Parameter>
  <Parameter name="init">initializer list to initialize the elements of the container with</Parameter>
</ParameterList>

### Complexity

{/* source:cpp-container-unordered-set-unordered-set:0009 */}
1. Constant.

{/* source:cpp-container-unordered-set-unordered-set:0010 */}
2. Average case linear (i.e. O(N), where N is `std::distance(first, last)`), worst case quadratic, i.e. O(N2).

{/* source:cpp-container-unordered-set-unordered-set:0011 */}
3. Linear in size of `other`.

{/* source:cpp-container-unordered-set-unordered-set:0012 */}
4. Constant. If `alloc` is given and `alloc != other.get_allocator()`, then linear.

{/* source:cpp-container-unordered-set-unordered-set:0013 */}
5. Average case O(N) (N is `std::size(init)`), worst case O(N2).

{/* source:cpp-container-unordered-set-unordered-set:0014 */}
6. Average case O(N) (N is `ranges::distance(rg)`), worst case O(N2).

### Exceptions

{/* source:cpp-container-unordered-set-unordered-set:0015 */}
Calls to `Allocator::allocate` may throw.
