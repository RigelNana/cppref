{/* source:cpp-container-unordered-set-find:0001 */}
1. Finds an element with key equivalent to `key`.

{/* source:cpp-container-unordered-set-find:0002 */}
2. Finds an element with key that compares equivalent to the value `x`. This overload participates in overload resolution only if `Hash::is_transparent` and `KeyEqual::is_transparent` are valid and each denotes a type. This assumes that such `Hash` is callable with both `K` and `Key` type, and that the `KeyEqual` is transparent, which, together, allows calling this function without constructing an instance of `Key`.

### Parameters

{/* source:cpp-container-unordered-set-find:0003 */}
<ParameterList>
  <Parameter name="key">key value of the element to search for</Parameter>
  <Parameter name="x">a value of any type that can be transparently compared with a key</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-unordered-set-find:0004 */}
An iterator to the requested element. If no such element is found, past-the-end (see [`end()`](/docs/cpp/library/container/unordered_set/end)) iterator is returned.

### Complexity

{/* source:cpp-container-unordered-set-find:0005 */}
Constant on average, worst case linear in the size of the container.

### Example

{/* source:cpp-container-unordered-set-find:0007 */}
```cpp
#include <cstddef>
#include <functional>
#include <iostream>
#include <source_location>
#include <string>
#include <string_view>
#include <unordered_set>

using namespace std::literals;

namespace logger { bool enabled{false}; }

inline void who(const std::source_location sloc = std::source_location::current())
{
    if (logger::enabled)
        std::cout << sloc.function_name() << '\n';
}

struct string_hash // C++20's transparent hashing
{
    using hash_type = std::hash<std::string_view>;
    using is_transparent = void;

    std::size_t operator()(const char* str) const
    {
        who();
        return hash_type{}(str);
    }
    std::size_t operator()(std::string_view str) const
    {
        who();
        return hash_type{}(str);
    }
    std::size_t operator()(std::string const& str) const
    {
        who();
        return hash_type{}(str);
    }
};

int main()
{
    std::unordered_set<int> example{1, 2, -10};

    std::cout << "Simple comparison demo:\n" << std::boolalpha;
    if (auto search = example.find(2); search != example.end())
        std::cout << "Found " << *search << '\n';
    else
        std::cout << "Not found\n";

    std::unordered_set<std::string, string_hash, std::equal_to<>> set{"one"s, "two"s};

    logger::enabled = true;
    std::cout << "Heterogeneous lookup for unordered containers (transparent hashing):\n"
              << (set.find("one")   != set.end()) << '\n'
              << (set.find("one"s)  != set.end()) << '\n'
              << (set.find("one"sv) != set.end()) << '\n';
}
```

```text

true

true

true
```
