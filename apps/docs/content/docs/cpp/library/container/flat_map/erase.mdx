{/* source:cpp-container-flat-map-erase:0001 */}
Removes specified elements from the container.

{/* source:cpp-container-flat-map-erase:0002 */}
- 1,2) Removes the element at `pos`.

{/* source:cpp-container-flat-map-erase:0003 */}
- 3) Removes the elements in the range `[first, last)`, which must be a valid range in `*this`.

{/* source:cpp-container-flat-map-erase:0004 */}
- 4) Removes the element (if one exists) with the key equivalent to `key`.

{/* source:cpp-container-flat-map-erase:0005 */}
- 5) Removes all elements with key that compares equivalent to the value `x`. This overload participates in overload resolution only if the qualified-id `Compare::is_transparent` is valid and denotes a type, and neither `iterator` nor `const_iterator` is implicitly convertible from `K`. It allows calling this function without constructing an instance of `Key`.

{/* source:cpp-container-flat-map-erase:0006 */}
Information on iterator invalidation is copied from [here](/docs/Template:cpp/container/note-iterator-invalidation)

{/* source:cpp-container-flat-map-erase:0007 */}
The iterator `pos` must be valid and dereferenceable. Thus the `end()` iterator (which is valid, but is not dereferenceable) cannot be used as a value for `pos`.

### Return value

{/* source:cpp-container-flat-map-erase:0009 */}
- 1-3) Iterator following the last removed element.

{/* source:cpp-container-flat-map-erase:0010 */}
- 4) Number of elements removed (0 or 1).

{/* source:cpp-container-flat-map-erase:0011 */}
- 5) Number of elements removed.

### Example

{/* source:cpp-container-flat-map-erase:0015 */}
```cpp
#include <flat_map>
#include <iostream>
 
int main()
{
    std::flat_map<int, std::string> c =
    {
        {1, "one"}, {2, "two"}, {3, "three"},
        {4, "four"}, {5, "five"}, {6, "six"}
    };
 
    // erase all odd numbers from c
    for (auto it = c.begin(); it != c.end();)
    {
        if (it->first % 2 != 0)
            it = c.erase(it);
        else
            ++it;
    }
 
    for (auto& p : c)
        std::cout << p.second << ' ';
    std::cout << '\n';
}
```

Output:

```text
two four six
```
