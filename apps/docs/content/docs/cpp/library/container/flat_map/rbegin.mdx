{/* source:cpp-container-flat-map-rbegin:0001 */}
Returns a reverse iterator to the first element of the reversed `flat_map`. It corresponds to the last element of the non-reversed `flat_map`. If the `flat_map` is empty, the returned iterator is equal to `rend()`.

### Parameters

{/* source:cpp-container-flat-map-rbegin:0002 */}
(none)

### Return value

{/* source:cpp-container-flat-map-rbegin:0003 */}
Reverse iterator to the first element.

### Complexity

{/* source:cpp-container-flat-map-rbegin:0004 */}
Constant.

### Notes

{/* source:cpp-container-flat-map-rbegin:0005 */}
The [`underlying iterator`](/docs/cpp/library/iterator/reverse_iterator/base) of the returned reverse iterator is the [`end iterator`](/docs/cpp/library/container/flat_map/end). Hence the returned iterator is invalidated if and when the end iterator is invalidated.

### Example

{/* source:cpp-container-flat-map-rbegin:0006 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string_view>
#include <flat_map>
 
int main()
{
    const std::flat_map<int, std::string_view> coins
    {
        {10, "dime"},
        {100, "dollar"},
        {50, "half dollar"},
        {5, "nickel"},
        {1, "penny"},
        {25, "quarter"}
    }; // initializer entries in name alphabetical order
 
    std::cout << "US coins in circulation, largest to smallest denomination:\n";
    for (auto it = coins.crbegin(); it != coins.crend(); ++it)
        std::cout << std::setw(11) << it->second << " = ¢" << it->first << '\n';
}
```

Output:

```text
US coins in circulation, largest to smallest denomination:
     dollar = ¢100
half dollar = ¢50
    quarter = ¢25
       dime = ¢10
     nickel = ¢5
      penny = ¢1
```
