{/* source:cpp-container-flat-map-size:0001 */}
Returns the number of elements in the container adaptor. Equivalent to: `return` [`c`](/docs/cpp/library/container/flat_map#Member_objects)`.keys.size()`.

### Parameters

{/* source:cpp-container-flat-map-size:0002 */}
(none)

### Return value

{/* source:cpp-container-flat-map-size:0003 */}
The number of elements in the container adaptor.

### Complexity

{/* source:cpp-container-flat-map-size:0004 */}
Constant.

### Example

{/* source:cpp-container-flat-map-size:0005 */}
```cpp
#include <cassert>
#include <flat_map>
 
int main()
{
    std::flat_map<int, char> nums{{1, 'a'}, {1, 'b'}, {2, 'c'}, {2, 'd'}};
    assert(nums.size() == 2); 
}
```
