{/* source:cpp-container-flat-map-keys:0001 */}
Return a constant reference to the adapted keys container. Equivalent to `return c.keys;`.

### Parameters

{/* source:cpp-container-flat-map-keys:0002 */}
(none)

### Return value

{/* source:cpp-container-flat-map-keys:0003 */}
The underlying keys container.

### Complexity

{/* source:cpp-container-flat-map-keys:0004 */}
Constant.

### Example

{/* source:cpp-container-flat-map-keys:0005 */}
```cpp
#include <flat_map>
#include <print>
#include <type_traits>
#include <vector>
 
int main()
{
    std::flat_map<int, double> adaptor{{1, 1.1}, {2, 2.2}, {3, 3.3}};
 
    // The default keys container is std::vector:
    static_assert(std::is_same_v<decltype(adaptor.keys()), const std::vector<int>&>);
 
    std::println("{}", adaptor.keys());
}
```

Output:

```text
[1, 2, 3]
```
