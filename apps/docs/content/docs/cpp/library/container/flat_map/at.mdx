  <DeclarationDescription>
    {/* source:cpp-container-flat-map-at:0001 */}
    Returns a reference to the mapped value of the element with specified `key`. If no such element exists, an exception of type [`std::out_of_range`](/docs/cpp/library/error/out_of_range) is thrown.

    {/* source:cpp-container-flat-map-at:0002 */}
    1,2) The key is equivalent to `key`.

    {/* source:cpp-container-flat-map-at:0003 */}
    3,4) The key compares equivalent to the value `x`. The reference to the mapped value is obtained as if by expression `this->find(x)->second`.

    {/* source:cpp-container-flat-map-at:0004 */}
    The expression `this->find(x)` must be well-formed and have well-defined behavior, otherwise the behavior is undefined.

    {/* source:cpp-container-flat-map-at:0005 */}
    These overloads participate in overload resolution only if the qualified-id `Compare::is_transparent` is valid and denotes a type. It allows calling this function without constructing an instance of `Key`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-flat-map-at:0006 */}
<ParameterList>
  <Parameter name="key">the key of the element to find</Parameter>
  <Parameter name="x">a value of any type that can be transparently compared with a key</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-flat-map-at:0007 */}
A reference to the mapped value of the requested element.

### Exceptions

{/* source:cpp-container-flat-map-at:0008 */}
1,2) [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if the container does not have an element with the specified `key`.

{/* source:cpp-container-flat-map-at:0009 */}
3,4) [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if the container does not have the specified element, that is, if `find(x) == end()` is `true`.

### Complexity

{/* source:cpp-container-flat-map-at:0010 */}
Logarithmic in the size of the container.

### Example

{/* source:cpp-container-flat-map-at:0011 */}
```cpp
#include <cassert>
#include <iostream>
#include <flat_map>

struct LightKey { int o; };
struct HeavyKey { int o[1000]; };

// The container must use std::less<> (or other transparent Comparator) to
// access overloads (3,4). This includes standard overloads, such as
// comparison between std::string and std::string_view.
bool operator<(const HeavyKey& x, const LightKey& y) { return x.o[0] < y.o; }
bool operator<(const LightKey& x, const HeavyKey& y) { return x.o < y.o[0]; }
bool operator<(const HeavyKey& x, const HeavyKey& y) { return x.o[0] < y.o[0]; }

int main()
{
    std::flat_map<int, char> map{{1, 'a'}, {2, 'b'}};
    assert(map.at(1) == 'a');
    assert(map.at(2) == 'b');
    try
    {
        map.at(13);
    }
    catch(const std::out_of_range& ex)
    {
        std::cout << "1) out_of_range::what(): " << ex.what() << '\n';
    }

#ifdef __cpp_lib_associative_heterogeneous_insertion
    // Transparent comparison demo.
    std::flat_map<HeavyKey, char, std::less<>> map2{{{1}, 'a'}, {{2}, 'b'}};
    assert(map2.at(LightKey{1}) == 'a');
    assert(map2.at(LightKey{2}) == 'b');
    try
    {
        map2.at(LightKey{13});
    }
    catch(const std::out_of_range& ex)
    {
        std::cout << "2) out_of_range::what(): " << ex.what() << '\n';
    }
#endif
}
```

Possible output:

```text
1) out_of_range::what(): map::at:  key not found
2) out_of_range::what(): map::at:  key not found
```
