  <Declaration language="cpp" since="C++23" code={`void replace( key_container_type&& key_cont, mapped_container_type&& mapped_cont );`} />

{/* source:cpp-container-flat-map-replace:0001 */}
Replaces the underlying containers [`c`](/docs/cpp/library/container/flat_map#Member_objects). Equivalent to:

{/* source:cpp-container-flat-map-replace:0002 */}
```cpp
c.keys = std::move(key_cont);
c.values = std::move(mapped_cont);
```

{/* source:cpp-container-flat-map-replace:0003 */}
The following conditions must be met:

{/* source:cpp-container-flat-map-replace:0004 */}
- The expression `key_cont.size() == mapped_cont.size()` is `true`,
- The elements of `key_cont` are sorted with respect to [`compare`](/docs/cpp/library/container/flat_map#Member_objects), and
- `key_cont` does not contain equal elements.

Otherwise, the behavior is undefined.

### Parameters

{/* source:cpp-container-flat-map-replace:0005 */}
<ParameterList>
  <Parameter name="keys_cont">a sorted keys container of type `KeyContainer`, the contents of which will be moved into `*this`</Parameter>
  <Parameter name="mapped_cont">a container of mapped values of type `MappedContainer`, the contents of which will be moved into `*this`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-flat-map-replace:0006 */}
(none)

### Complexity

{/* source:cpp-container-flat-map-replace:0007 */}
Equals to complexity of [`std::move`](/docs/cpp/library/utility/move) applied to adapted containers.

### Example

{/* source:cpp-container-flat-map-replace:0008 */}
```cpp
#include <algorithm>
#include <cassert>
#include <flat_map>
#include <print>
#include <vector>
 
int main()
{
    std::vector<int> keys{1, 2, 3};
    assert(std::ranges::is_sorted(keys));
    std::vector<double> values{2.2, 3.3, 1.1};
    assert(keys.size() == values.size());
 
    std::flat_map<int, double> map;
    assert(map.empty());
 
    map.replace(keys, values);
    assert(map.size() == 3);
    assert(map.keys() == 3);
    assert(map.values() == 3);
    assert(keys.empty());
    assert(values.empty());
 
    std::println("{}", map);
}
```

Output:

```text
{1: 2.2, 2: 3.3, 3: 1.1}
```
