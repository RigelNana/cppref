{/* source:cpp-container-flat-map-emplace:0001 */}
Inserts a new element into the container constructed in-place with the given `args`, if there is no element with the key in the container.

{/* source:cpp-container-flat-map-emplace:0002 */}
Initializes an object `t` of type `std::pair<key_type, mapped_type>` with `std::forward<Args>(args)...`; if the map already contains an element whose key is equivalent to `t.first`, `*this` is unchanged. Otherwise, equivalent to:

{/* source:cpp-container-flat-map-emplace:0003 */}
```cpp
auto key_it = ranges::upper_bound(c.keys, t.first, compare);
auto value_it = c.values.begin() + std::distance(c.keys.begin(), key_it);
c.keys.insert(key_it, std::move(t.first));
c.values.insert(value_it, std::move(t.second));
```

{/* source:cpp-container-flat-map-emplace:0004 */}
This overload participates in overload resolution only if `std::is_constructible_v<std::pair<key_type, mapped_type>, Args...>` is `true`.

{/* source:cpp-container-flat-map-emplace:0005 */}
Careful use of emplace allows the new element to be constructed while avoiding unnecessary copy or move operations.

{/* source:cpp-container-flat-map-emplace:0006 */}
Information on iterator invalidation is copied from [here](/docs/Template:cpp/container/note-iterator-invalidation)

### Parameters

{/* source:cpp-container-flat-map-emplace:0007 */}
<ParameterList>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-flat-map-emplace:0008 */}
A pair consisting of an iterator to the inserted element (or to the element that prevented the insertion) and a `bool` value set to `true` if and only if the insertion took place.

### Exceptions

{/* source:cpp-container-flat-map-emplace:0009 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-container-flat-map-emplace:0010 */}
If insertion occurs, linear in the size of the container, otherwise logarithmic in the size of the container

### Example

{/* source:cpp-container-flat-map-emplace:0011 */}
```cpp
#include <iostream>
#include <string>
#include <utility>
#include <flat_map>
 
int main()
{
    std::flat_map<std::string, std::string> m;
 
    // uses pair's move constructor
    m.emplace(std::make_pair(std::string("a"), std::string("a")));
 
    // uses pair's converting move constructor
    m.emplace(std::make_pair("b", "abcd"));
 
    // uses pair's template constructor
    m.emplace("d", "ddd");
 
    // emplace with duplicate key has no effect
    m.emplace("d", "DDD");
 
    // uses pair's piecewise constructor
    m.emplace(std::piecewise_construct,
              std::forward_as_tuple("c"),
              std::forward_as_tuple(10, 'c'));
    // an alternative is: m.try_emplace("c", 10, 'c');
 
    for (const auto& p : m)
        std::cout << p.first << " => " << p.second << '\n';
}
```

Output:

```text
a => a
b => abcd
c => cccccccccc
d => ddd
```
