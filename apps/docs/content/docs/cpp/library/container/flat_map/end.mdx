Returns an iterator to the element following the last element of the `flat_map`.

{/* source:cpp-container-flat-map-end:0002 */}
This element acts as a placeholder; attempting to access it results in undefined behavior.

### Parameters

{/* source:cpp-container-flat-map-end:0003 */}
(none)

### Return value

{/* source:cpp-container-flat-map-end:0004 */}
Iterator to the element following the last element.

### Complexity

{/* source:cpp-container-flat-map-end:0005 */}
Constant.

### Example

{/* source:cpp-container-flat-map-end:0006 */}
```cpp
#include <iostream>
#include <flat_map>
 
int main()
{
    std::flat_map<int, double> map{{4, 4.13}, {9, 9.24}, {1, 1.09}};
 
    for (auto it = map.cbegin(); it != map.cend(); ++it)
        std::cout << '[' << it->first << "] = " << it->second << '\n';
 
    // Unlike std::map's bidirectional iterators, the std::flat_map iterators
    // are random-access, so they can be used with the operator[]:
    auto it = map.cbegin();
    assert(it[0] == map[1]);
    assert(it[1] == map[4]);
    assert(it[2] == map[9]);
}
```

Output:

```text
[1] = 1.09
[4] = 4.13
[9] = 9.24
```
