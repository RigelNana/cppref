Constructs new container adaptor from a variety of data sources and optionally using user supplied comparison function object `comp` and/or allocator `alloc`.

{/* source:cpp-container-flat-map-flat-map:0002 */}
- 1) A default constructor. Constructs an empty container adaptor.

{/* source:cpp-container-flat-map-flat-map:0003 */}
- 2) A [copy constructor](/docs/cpp/language/classes/copy_constructor). Constructs [`c`](/docs/cpp/library/container/flat_map#Member_objects) with the copy of the contents of `other.c` and [`compare`](/docs/cpp/library/container/flat_map#Member_objects) with `other.compare`. See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0004 */}
- 3) A [move constructor](/docs/cpp/language/classes/move_constructor). Constructs the container adaptor with the contents of `other` using move semantics. See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0005 */}
- 4) First, initializes [`c.keys`](/docs/cpp/library/container/flat_map#Member_objects) with `std::move(key_cont)`, [`c.values`](/docs/cpp/library/container/flat_map#Member_objects) with `std::move(mapped_cont)`, and [`compare`](/docs/cpp/library/container/flat_map#Member_objects) with `comp`. Then sorts the underlying range [`begin()`, `end()`) with respect to `value_comp()`. Finally, erases the duplicate elements as if by:

```cpp
auto zv = views::zip(c.keys, c.values);
auto it = ranges::unique(zv, key_equiv(compare)).begin();
auto dist = distance(zv.begin(), it);
c.keys.erase(c.keys.begin() + dist, c.keys.end());
c.values.erase(c.values.begin() + dist, c.values.end());
```

{/* source:cpp-container-flat-map-flat-map:0006 */}
- 5) Same as (4), equivalent to `flat_map(key_cont, mapped_cont);`. See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0007 */}
- 6) Same as (4), equivalent to `flat_map(key_cont, mapped_cont, comp);`. See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0008 */}
- 7) Initializes [`c.keys`](/docs/cpp/library/container/flat_map#Member_objects) with `std::move(key_cont)`, [`c.values`](/docs/cpp/library/container/flat_map#Member_objects) with `std::move(mapped_cont)`, and [`compare`](/docs/cpp/library/container/flat_map#Member_objects) with `comp`.

{/* source:cpp-container-flat-map-flat-map:0009 */}
- 8) Same as (7), equivalent to `flat_map(s, key_cont, mapped_cont);`. See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0010 */}
- 9) Same as (7), equivalent to `flat_map(s, key_cont, mapped_cont, comp);`. See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0011 */}
- 10) Constructs an empty container adaptor.

{/* source:cpp-container-flat-map-flat-map:0012 */}
- 11,12) Constructs an empty container adaptor. See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0013 */}
- 13) Constructs the container adaptor with the contents of the range [`first`, `last`), equivalent to `insert(first, last);`.

{/* source:cpp-container-flat-map-flat-map:0014 */}
- 14,15) Same as (13). See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0015 */}
- 16) Constructs the container adaptor with the contents of the range `rg`. First, uses (10) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor). Then initializes [`c`](/docs/cpp/library/container/flat_map#Member_objects) with the contents of `rg` as if by `insert_range(std::forward<R>(rg));`.

{/* source:cpp-container-flat-map-flat-map:0016 */}
- 17) Same as (16) using it as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-map-flat-map:0017 */}
- 18,19) Same as (16). See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0018 */}
- 20) Constructs the underlying containers with the contents of the range [`first`, `last`) as if by `insert(first, last)`.

{/* source:cpp-container-flat-map-flat-map:0019 */}
- 21,22) Same as (20). See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0020 */}
- 23) An [initializer-list constructor](/docs/cpp/language/initialization/list_initialization). Constructs the underlying container with the contents of the initializer list `init`, using (13) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-map-flat-map:0021 */}
- 24,25) Same as (23). See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0022 */}
- 26) An [initializer-list constructor](/docs/cpp/language/initialization/list_initialization). Constructs the underlying container with the contents of the initializer list `init`, using (20) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-map-flat-map:0023 */}
- 27,28) Save as (26). See [allocator usage note](/docs/cpp/library/container/flat_map/flat_map#Allocator_usage_note) below.

{/* source:cpp-container-flat-map-flat-map:0024 */}
Note for overloads (13-15,20-22): If [`first`, `last`] is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-container-flat-map-flat-map:0025 */}
Note for overloads (4-6,13-19,23-25): If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

##### Allocator usage note

{/* source:cpp-container-flat-map-flat-map:0026 */}
The constructors (2,3,5,6,8,9,11,12,14,15,17,19,21,22,24,25,27,28) are equivalent to the corresponding non-allocator constructors except that the underlying containers [`c.keys`](/docs/cpp/library/container/flat_map#Member_objects) and [`c.values`](/docs/cpp/library/container/flat_map#Member_objects) are constructed with [uses-allocator construction](/docs/cpp/library/memory/uses_allocator#Uses-allocator_construction). These overloads participate in overload resolution only if `std::uses_allocator_v<container_type, Allocator>` is `true`.

### Parameters

{/* source:cpp-container-flat-map-flat-map:0027 */}
<ParameterList>
  <Parameter name="key_cont">a container to be used as source to initialize the underlying keys container</Parameter>
  <Parameter name="mapped_cont">a container to be used as source to initialize the underlying values container</Parameter>
  <Parameter name="other">another `flat_map` to be used as source to initialize the elements of the underlying containers with</Parameter>
  <Parameter name="alloc">an allocator to use for all memory allocations of the underlying containers</Parameter>
  <Parameter name="comp">a function object to be used for all comparisons of keys</Parameter>
  <Parameter name="first, last">a range to copy the elements from</Parameter>
  <Parameter name="init">an initializer list to initialize the elements of the underlying containers with</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range) (that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to [`value_type`](/docs/cpp/library/container/flat_map#Member_types)) to be used as source to initialize the underlying containers</Parameter>
  <Parameter name="fr">a [disambiguation tag](/docs/cpp/library/ranges/from_range) that indicates that the contained member should be range constructed</Parameter>
  <Parameter name="s">a [disambiguation tag](/docs/cpp/library/container/sorted_unique) that indicates that the input sequence is sorted with respect to `value_comp()` and all its elements are unique</Parameter>
</ParameterList>

**Type requirements**

- `InputIt` must meet the requirements of [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).
- `Compare` must meet the requirements of [`Compare`](/docs/cpp/library/named_req/Compare).
- `Allocator` must meet the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator).

### Complexity

{/* source:cpp-container-flat-map-flat-map:0028 */}
- 1) Constant.

{/* source:cpp-container-flat-map-flat-map:0029 */}
- 2) Linear in size of `other`.

{/* source:cpp-container-flat-map-flat-map:0030 */}
- 3) Same as the corresponding move-constructor of the wrapped container, i.e. constant or linear in size of `cont`.

{/* source:cpp-container-flat-map-flat-map:0031 */}
- 4-6) Linear in N if `cont` is sorted with respect to `value_comp()`, otherwise 𝓞(N·log(N)), where N is the value of `key_cont.size()` before this call.

{/* source:cpp-container-flat-map-flat-map:0032 */}
- 7-9) Same as the corresponding move-constructor of the wrapped container, i.e. constant or linear in size of `cont`.

{/* source:cpp-container-flat-map-flat-map:0033 */}
- 10-12) Constant.

{/* source:cpp-container-flat-map-flat-map:0034 */}
- 13-15) Linear in N if the input range [`first`, `last`) is sorted with respect to `value_comp()`, otherwise 𝓞(N·log(N)), where N is the value of `key_cont.size()` before this call.

{/* source:cpp-container-flat-map-flat-map:0035 */}
- 16-19) Linear in N if the input range `rg` is sorted with respect to `value_comp()`, otherwise 𝓞(N·log(N)), where N is the value of `key_cont.size()` before this call.

{/* source:cpp-container-flat-map-flat-map:0036 */}
- 20-22) Linear in size of [`first`, `last`).

{/* source:cpp-container-flat-map-flat-map:0037 */}
- 23-25) Linear in N if the elements of `init` are sorted with respect to `value_comp()`, otherwise 𝓞(N·log(N)), where N is the value of `key_cont.size()` before this call.

{/* source:cpp-container-flat-map-flat-map:0038 */}
- 26-28) Linear in size of `init`.

### Exceptions

{/* source:cpp-container-flat-map-flat-map:0039 */}
Calls to `Allocator::allocate` may throw.

### Notes

{/* source:cpp-container-flat-map-flat-map:0040 */}
After container move construction (overload (3)), references, pointers, and iterators (other than the end iterator) to `other` remain valid, but refer to elements that are now in `*this`. The current standard makes this guarantee via the blanket statement in [[container.reqmts]/67](https://eel.is/c++draft/container.reqmts#67), and a more direct guarantee is under consideration via [LWG issue 2321](https://cplusplus.github.io/LWG/issue2321).
