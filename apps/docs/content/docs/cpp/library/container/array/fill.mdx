    1. <InlineRevision since="C++20" /> Assigns the `value` to all elements in the container.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-array-fill:0002 */}
<ParameterList>
  <Parameter name="value">the value to assign to the elements</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-array-fill:0003 */}
(none)

### Complexity

{/* source:cpp-container-array-fill:0004 */}
Linear in the size of the container.

### Example

{/* source:cpp-container-array-fill:0005 */}
```cpp
#include <array>
#include <cstddef>
#include <iostream>
 
int main()
{
    constexpr std::size_t xy = 4;
 
    using Cell = std::array<unsigned char, 8>;
 
    std::array<Cell, xy * xy> board;
 
    board.fill({0xE2, 0x96, 0x84, 0xE2, 0x96, 0x80, 0, 0}); // "▄▀";
 
    for (std::size_t count{}; Cell c : board)
        std::cout << c.data() << ((++count % xy) ? "" : "\n");
}
```

Possible output:

```text
▄▀▄▀▄▀▄▀
▄▀▄▀▄▀▄▀
▄▀▄▀▄▀▄▀
▄▀▄▀▄▀▄▀
```
