    {/* source:cpp-container-array-get:0001 */}
    1. <InlineRevision since="C++14" /> Extracts the `I` th element from the array using [tuple-like](/docs/cpp/library/utility/tuple/tuple-like) interface.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-container-array-get:0002 */}
`I` must be an integer value in range `[0, N)`. This is enforced at compile time as opposed to [`at()`](/docs/cpp/library/container/array/at) or [`operator[]`](/docs/cpp/library/container/array/operator_at).

### Parameters

{/* source:cpp-container-array-get:0003 */}
<ParameterList>
  <Parameter name="a">array whose contents to extract</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-array-get:0004 */}
A reference to the `I` th element of `a`.

### Complexity

{/* source:cpp-container-array-get:0005 */}
Constant.

### Example

{/* source:cpp-container-array-get:0006 */}
```cpp
#include <array>
#include <iostream>
 
constexpr std::array v{1, 2, 3};
static_assert(get<0>(v) == 1 && get<1>(v) == 2 && get<2>(v) == 3);
 
int main()
{
    std::array<int, 3> a;
 
    // set values:
    get<0>(a) = 1, get<1>(a) = 2, get<2>(a) = 3;
 
    // get values:
    std::cout << '(' << get<0>(a) << ',' << get<1>(a) << ',' << get<2>(a) << ")\n";
}
```

Output:

```text
(1,2,3)
```
