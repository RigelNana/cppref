{/* source:cpp-container-array-front:0002 */}
Calling `front` on an empty container causes undefined behavior.

### Parameters

{/* source:cpp-container-array-front:0003 */}
(none)

### Return value

{/* source:cpp-container-array-front:0004 */}
Reference to the first element.

### Complexity

{/* source:cpp-container-array-front:0005 */}
Constant.

### Notes

{/* source:cpp-container-array-front:0006 */}
For a container `c`, the expression `c.front()` is equivalent to `*c.begin()`.

### Example

{/* source:cpp-container-array-front:0007 */}
The following code uses `front` to display the first element of a `std::array<char, 4>`:

```cpp
#include <cassert>
#include <array>
 
int main()
{
    std::array<char, 4> letters{'a', 'b', 'c', 'd'};
    assert(letters.front() == 'a');
}
```
