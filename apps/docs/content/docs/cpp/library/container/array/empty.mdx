  <DeclarationDescription>
    {/* source:cpp-container-array-empty:0001 */}
    1. Checks if the container has no elements, i.e. whether `begin() == end()`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-array-empty:0002 */}
(none)

### Return value

{/* source:cpp-container-array-empty:0003 */}
`true` if the container is empty, `false` otherwise.

### Complexity

{/* source:cpp-container-array-empty:0004 */}
Constant.

### Example

{/* source:cpp-container-array-empty:0005 */}
The following code uses `empty` to check if a [`std::array`](/docs/cpp/library/container/array) contains any elements:

```cpp
#include <array>
#include <iostream>
 
int main()
{
    std::array<int, 4> numbers{3, 1, 4, 1};
    std::array<int, 0> no_numbers;
 
    std::cout << std::boolalpha;
    std::cout << "numbers.empty(): " << numbers.empty() << '\n';
    std::cout << "no_numbers.empty(): " << no_numbers.empty() << '\n';
}
```

Output:

```text
numbers.empty(): false
no_numbers.empty(): true
```
