### Return value

{/* source:cpp-container-array-operator-at:0003 */}
Reference to the requested element.

### Complexity

{/* source:cpp-container-array-operator-at:0004 */}
Constant.

### Notes

{/* source:cpp-container-array-operator-at:0005 */}
Unlike [`std::map::operator[]`](/docs/cpp/library/container/map/operator_at), this operator never inserts a new element into the container. Accessing a nonexistent element through this operator is undefined behavior.

### Example

{/* source:cpp-container-array-operator-at:0006 */}
The following code uses `operator[]` to read from and write to a `std::array<int, N>`:

```cpp
#include <array>
#include <iostream>
 
int main()
{
    std::array<int, 4> numbers{2, 4, 6, 8};
 
    std::cout << "Second element: " << numbers[1] << '\n';
 
    numbers[0] = 5;
 
    std::cout << "All numbers:";
    for (auto i : numbers)
        std::cout << ' ' << i;
    std::cout << '\n';
}
```

Output:

```text
Second element: 4
All numbers: 5 4 6 8
```
