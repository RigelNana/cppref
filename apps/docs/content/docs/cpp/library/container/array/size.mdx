  <Declaration language="cpp" since="C++11" code={`constexpr size_type size() const noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-container-array-size:0001 */}
    1. Returns the number of elements in the container, i.e. `std::distance(begin(), end())`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-array-size:0002 */}
(none)

### Return value

{/* source:cpp-container-array-size:0003 */}
The number of elements in the container.

### Complexity

{/* source:cpp-container-array-size:0004 */}
Constant.

### Example

{/* source:cpp-container-array-size:0005 */}
The following code uses `size` to display the number of elements in a [`std::array`](/docs/cpp/library/container/array):

```cpp
#include <array>
#include <iostream>
 
int main()
{ 
    std::array<int, 4> nums{1, 3, 5, 7};
 
    std::cout << "nums contains " << nums.size() << " elements.\n";
}
```

Output:

```text
nums contains 4 elements.
```
