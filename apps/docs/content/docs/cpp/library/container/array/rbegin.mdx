  <DeclarationDescription>
    {/* source:cpp-container-array-rbegin:0001 */}
    1. <InlineRevision since="C++17" /> Returns a reverse iterator to the first element of the reversed array. It corresponds to the last element of the non-reversed array. If the array is empty, the returned iterator is equal to [`rend()`](/docs/cpp/library/container/array/rend).
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-container-array-rbegin:0002 */}
(none)

### Return value

{/* source:cpp-container-array-rbegin:0003 */}
Reverse iterator to the first element.

### Complexity

{/* source:cpp-container-array-rbegin:0004 */}
Constant.

### Notes

{/* source:cpp-container-array-rbegin:0005 */}
The [underlying iterator](/docs/cpp/library/iterator/reverse_iterator/base) of the returned reverse iterator is the [end iterator](/docs/cpp/library/container/array/end). Hence the returned iterator is invalidated if and when the end iterator is invalidated.

### Example

{/* source:cpp-container-array-rbegin:0006 */}
```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <string>
#include <string_view>
 
void print(const std::string_view s) { std::cout << s << ' '; }
 
int main()
{
    const std::array<std::string_view, 8> data
    {
        "▁", "▂", "▃", "▄", "▅", "▆", "▇", "█"
    };
    std::array<std::string, 8> arr;
 
    std::copy(data.cbegin(), data.cend(), arr.begin());
 
    print("Print 'arr' in direct order using [cbegin, cend):\t");
    std::for_each(arr.cbegin(), arr.cend(), print);
 
    print("\n\nPrint 'arr' in reverse order using [crbegin, crend):\t");
    std::for_each(arr.crbegin(), arr.crend(), print);
}
```

Output:

```text
Print 'arr' in direct order using [cbegin, cend):        ▁ ▂ ▃ ▄ ▅ ▆ ▇ █
 
Print 'arr' in reverse order using [crbegin, crend):     █ ▇ ▆ ▅ ▄ ▃ ▂ ▁
```
