{/* source:cpp-container-flat-set-erase-if:0001 */}
Erases all elements that satisfy the predicate `pred` from `c`.

{/* source:cpp-container-flat-set-erase-if:0002 */}
The predicate `pred` is satisfied if the expression `bool(pred(std::as_const(e)))` is `true`, where `e` is some element in `c`.

{/* source:cpp-container-flat-set-erase-if:0003 */}
`Key` must be [`MoveAssignable`](/docs/cpp/library/named_req/MoveAssignable). Otherwise, the behavior is undefined.

### Parameters

{/* source:cpp-container-flat-set-erase-if:0004 */}
<ParameterList>
  <Parameter name="c">
    container adaptor from which to erase
  </Parameter>
  <Parameter name="pred">
    predicate that returns `true` if the element should be erased
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-flat-set-erase-if:0005 */}
The number of erased elements.

### Complexity

{/* source:cpp-container-flat-set-erase-if:0006 */}
Exactly `c.size()` applications of the predicate `pred`.

### Exceptions

{/* source:cpp-container-flat-set-erase-if:0007 */}
If `erase_if` throws, `c` remains in valid but unspecified (maybe empty) state.

### Notes

{/* source:cpp-container-flat-set-erase-if:0008 */}
The algorithm is stable, that is, the order of elements that are not deleted remains unchanged.

### Example

{/* source:cpp-container-flat-set-erase-if:0009 */}
```cpp
#include <iostream>
#include <flat_set>
 
void println(auto rem, auto const& container)
{
    std::cout << rem << '{';
    for (char sep[]{0, ' ', 0}; const auto& item : container)
        std::cout << sep << item, *sep = ',';
    std::cout << "}\n";
}
 
int main()
{
    std::flat_set data{3, 3, 4, 5, 5, 6, 6, 7, 2, 1, 0};
    println("Original:\n", data);
 
    auto divisible_by_3 = [](auto const& x) { return (x % 3) == 0; };
 
    const auto count = std::erase_if(data, divisible_by_3);
 
    println("Erase all items divisible by 3:\n", data);
    std::cout << count << " items erased.\n";
}
```

Output:

```text
Original:
{0, 1, 2, 3, 4, 5, 6, 7}
Erase all items divisible by 3:
{1, 2, 4, 5, 7}
3 items erased.
```
