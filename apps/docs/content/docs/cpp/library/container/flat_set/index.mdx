{/* source:cpp-container-flat-set:0001 */}
The flat set is a [`container adaptor`](/docs/cpp/library/container#Container_adaptors) that gives the functionality of an associative container that stores a sorted set of unique objects of type `Key`. Sorting is done using the key comparison function `Compare`.

{/* source:cpp-container-flat-set:0002 */}
The class template `flat_set` acts as a wrapper to the underlying sorted container passed as object of type `KeyContainer`.

{/* source:cpp-container-flat-set:0003 */}
Everywhere the standard library uses the [`Compare`](/docs/cpp/library/named_req/Compare) requirements, uniqueness is determined by using the equivalence relation. Informally, two objects `a` and `b` are considered equivalent if neither compares less than the other: `!comp(a, b) && !comp(b, a)`.

{/* source:cpp-container-flat-set:0004 */}
`std::flat_set` meets the requirements of [`Container`](/docs/cpp/library/named_req/Container), [`ReversibleContainer`](/docs/cpp/library/named_req/ReversibleContainer), [`optional container requirements`](/docs/cpp/library/named_req/Container#Optional_container_requirements), and all requirements of [`AssociativeContainer`](/docs/cpp/library/named_req/AssociativeContainer) (including logarithmic search complexity), except that:

{/* source:cpp-container-flat-set:0005 */}
- requirements related to nodes are not applicable,
- iterator invalidation requirements differ,
- the complexity of insertion and erasure operations is linear.

{/* source:cpp-container-flat-set:0006 */}
A flat set supports most [`AssociativeContainer`](/docs/cpp/library/named_req/AssociativeContainer)'s operations that use unique keys.

### Notes

{/* source:cpp-container-flat-set:0015 */}
The member types `iterator` and `const_iterator` may be aliases to the same type. This means defining a pair of function overloads using the two types as parameter types may violate the [`One Definition Rule`](/docs/cpp/language/basic_concepts/definition#One_Definition_Rule). Since `iterator` is convertible to `const_iterator`, a single function with a `const_iterator` as parameter type will work instead.

{/* source:cpp-container-flat-set:0016 */}
Some advantages of flat set over other standard [`container adaptors`](/docs/cpp/library/container#Container_adaptors) are:

{/* source:cpp-container-flat-set:0017 */}
- Potentially faster lookup (even though search operations have logarithmic complexity).
- Much faster iteration: [`random access iterators`](/docs/cpp/library/iterator/random_access_iterator) instead of [`bidirectional iterators`](/docs/cpp/library/iterator/bidirectional_iterator).
- Less memory consumption for small objects (and for big objects if `KeyContainer::shrink_to_fit()` is available).
- Better cache performance (depending on `KeyContainer`, keys are stored in a contiguous block(s) of memory).

{/* source:cpp-container-flat-set:0018 */}
Some disadvantages of flat set are:

{/* source:cpp-container-flat-set:0019 */}
- Non-stable iterators (iterators are invalidated when inserting and erasing elements).
- Non-copyable and non-movable type values can not be stored.
- Weaker exception safety (copy/move constructors can throw when shifting values in erasures and insertions).
- Slower (i.e. linear) insertion and erasure, especially for non-movable types.
