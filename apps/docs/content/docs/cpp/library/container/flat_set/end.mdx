Returns an iterator to the element following the last element of the `flat_set`.

{/* source:cpp-container-flat-set-end:0002 */}
This element acts as a placeholder; attempting to access it results in undefined behavior.

### Parameters

{/* source:cpp-container-flat-set-end:0003 */}
(none)

### Return value

{/* source:cpp-container-flat-set-end:0004 */}
Iterator to the element following the last element.

### Complexity

{/* source:cpp-container-flat-set-end:0005 */}
Constant.

### Notes

{/* source:cpp-container-flat-set-end:0006 */}
Because both `iterator` and `const_iterator` are constant iterators (and may in fact be the same type), it is not possible to mutate the elements of the container through an iterator returned by any of these member functions.

### Example

{/* source:cpp-container-flat-set-end:0007 */}
```cpp
#include <algorithm>
#include <flat_set>
#include <iostream>
 
int main()
{
    std::flat_set<int> set{3, 1, 4, 1, 5, 9, 2, 6, 5};
    std::for_each(set.cbegin(), set.cend(), [](int x)
    {
        std::cout << x << ' ';
    });
    std::cout << '\n';
}
```

Output:

```text
1 2 3 4 5 6 9
```
