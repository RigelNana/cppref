{/* source:cpp-container-flat-set-flat-set:0001 */}
Constructs new container adaptor from a variety of data sources and optionally provided comparison function object `comp` and/or allocator `alloc`.

{/* source:cpp-container-flat-set-flat-set:0002 */}
- 1) A default constructor. Constructs an empty container adaptor.

{/* source:cpp-container-flat-set-flat-set:0003 */}
- 2) A [copy constructor](/docs/cpp/language/classes/copy_constructor). Constructs [`c`](/docs/cpp/library/container/flat_set#Member_objects) with the copy of the contents of `other.c` and [`compare`](/docs/cpp/library/container/flat_set#Member_objects) with `other.compare`. See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0004 */}
- 3) A [move constructor](/docs/cpp/language/classes/move_constructor). Constructs the container adaptor with the contents of `other` using move semantics. See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0005 */}
- 4) Constructs the underlying container with the contents of the container `cont`. First, initializes [`c`](/docs/cpp/library/container/flat_set#Member_objects) with `std::move(cont)` and [`compare`](/docs/cpp/library/container/flat_set#Member_objects) with `comp`. Then sorts the [`c`](/docs/cpp/library/container/flat_set#Member_objects) with respect to `comp`. Finally, makes elements unique, i.e. erases all but the first element from each group of consecutive equivalent elements.

{/* source:cpp-container-flat-set-flat-set:0006 */}
- 5) Same as (4), equivalent to `flat_set(cont);`. See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0007 */}
- 6) Same as (4), equivalent to `flat_set(cont, comp);`. See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0008 */}
- 7) Constructs the underlying container with the contents of the other container `cont`. Initializes [`c`](/docs/cpp/library/container/flat_set#Member_objects) with `std::move(cont)` and [`compare`](/docs/cpp/library/container/flat_set#Member_objects) with `comp`.

{/* source:cpp-container-flat-set-flat-set:0009 */}
- 8) Same as (7), equivalent to `flat_set(s, cont);`. See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0010 */}
- 9) Same as (7), equivalent to `flat_set(s, cont, comp);`. See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0011 */}
- 10) Constructs an empty container adaptor.

{/* source:cpp-container-flat-set-flat-set:0012 */}
- 11,12) Constructs an empty container adaptor. See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0013 */}
- 13) Constructs the container adaptor with the contents of the range [`first, last)`, equivalent to `insert(first, last);`.

{/* source:cpp-container-flat-set-flat-set:0014 */}
- 14,15) Same as (13). See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0015 */}
- 16) Constructs the container adaptor with the contents of the range `rg`. First, uses (10) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor). Then initializes [`c`](/docs/cpp/library/container/flat_set#Member_objects) with the contents of `rg` as if by `insert_range(std::forward<R>(rg));`.

{/* source:cpp-container-flat-set-flat-set:0016 */}
- 17) Same as (16) using it as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-set-flat-set:0017 */}
- 18,19) Same as (16). See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0018 */}
- 20) Constructs the underlying container with the contents of the range [`first, last)`. Initializes [`c`](/docs/cpp/library/container/flat_set#Member_objects) with `c(first, last)` and [`compare`](/docs/cpp/library/container/flat_set#Member_objects) with `compare(comp)`.

{/* source:cpp-container-flat-set-flat-set:0019 */}
- 21,22) Same as (20). See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0020 */}
- 23) An [initializer-list constructor](/docs/cpp/language/initialization/list_initialization). Constructs the underlying container with the contents of the initializer list `init`, using (13) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-set-flat-set:0021 */}
- 24,25) Same as (23). See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0022 */}
- 26) An [initializer-list constructor](/docs/cpp/language/initialization/list_initialization). Constructs the underlying container with the contents of the initializer list `init`, using (20) as [delegating constructor](/docs/cpp/language/classes/initializer_list#Delegating_constructor).

{/* source:cpp-container-flat-set-flat-set:0023 */}
- 27,28) Save as (26). See [allocator usage note](/docs/cpp/library/container/flat_set/flat_set#Allocator_usage_note) below.

{/* source:cpp-container-flat-set-flat-set:0024 */}
Note for overloads (13-15,20-22): If [`first, last)` is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-container-flat-set-flat-set:0025 */}
Note for overloads (4-6,13-19,23-25): If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

##### Allocator usage note

{/* source:cpp-container-flat-set-flat-set:0026 */}
The constructors (2,3,5,6,8,9,11,12,14,15,17,19,21,22,24,25,27,28) are equivalent to the corresponding non-allocator constructors except that [`c`](/docs/cpp/library/container/flat_set#Member_objects) is constructed with [uses-allocator construction](/docs/cpp/library/memory/uses_allocator#Uses-allocator_construction). These overloads participate in overload resolution only if `std::uses_allocator_v<container_type, Allocator>` is `true`.

### Complexity

{/* source:cpp-container-flat-set-flat-set:0028 */}
- 1) Constant.

{/* source:cpp-container-flat-set-flat-set:0029 */}
- 2) Linear in size of `other`.

{/* source:cpp-container-flat-set-flat-set:0030 */}
- 3) Same as the corresponding move-constructor of the wrapped container, i.e. constant or linear in size of `cont`.

{/* source:cpp-container-flat-set-flat-set:0031 */}
- 4-6) Linear in N if `cont` is sorted with respect to `compare`, otherwise 𝓞(N·log(N)), where N is the value of `cont.size()` before this call.

{/* source:cpp-container-flat-set-flat-set:0032 */}
- 7-9) Same as the corresponding move-constructor of the wrapped container, i.e. constant or linear in size of `cont`.

{/* source:cpp-container-flat-set-flat-set:0033 */}
- 10-12) Constant.

{/* source:cpp-container-flat-set-flat-set:0034 */}
- 13-15) Linear in N if the input range [`first, last)` is sorted with respect to `compare`, otherwise 𝓞(N·log(N)), where N is the value of `cont.size()` before this call.

{/* source:cpp-container-flat-set-flat-set:0035 */}
- 16-19) Linear in N if the input range `rg` is sorted with respect to `compare`, otherwise 𝓞(N·log(N)), where N is the value of `cont.size()` before this call.

{/* source:cpp-container-flat-set-flat-set:0036 */}
- 20-22) Linear in size of [`first, last)`.

{/* source:cpp-container-flat-set-flat-set:0037 */}
- 23-25) Linear in N if the elements of `init` are sorted with respect to `compare`, otherwise 𝓞(N·log(N)), where N is the value of `cont.size()` before this call.

{/* source:cpp-container-flat-set-flat-set:0038 */}
- 26-28) Linear in size of `init`.

### Exceptions

{/* source:cpp-container-flat-set-flat-set:0039 */}
Calls to `Allocator::allocate` may throw.

### Notes

{/* source:cpp-container-flat-set-flat-set:0040 */}
After container move construction (overload (3,16-19)), references, pointers, and iterators (other than the end iterator) to `other` remain valid, but refer to elements that are now in `*this`. The current standard makes this guarantee via the blanket statement in [[container.reqmts]/67](https://eel.is/c++draft/container.reqmts#67), and a more direct guarantee is under consideration via [LWG issue 2321](https://cplusplus.github.io/LWG/issue2321).
