Inserts element(s) into the container, if the container does not already contain an element with an equivalent key.

{/* source:cpp-container-flat-set-insert:0002 */}
1. 1) Inserts `value`. Equivalent to `return emplace(value);`.

{/* source:cpp-container-flat-set-insert:0003 */}
2. 2) Inserts `value`. Equivalent to `return emplace(std::move(value));`.

{/* source:cpp-container-flat-set-insert:0004 */}
3. 3) Inserts `value` in the position as close as possible to the position just prior to `pos`. Equivalent to `return emplace_hint(pos, value);`.

{/* source:cpp-container-flat-set-insert:0005 */}
4. 4) Inserts `value` in the position as close as possible to the position just prior to `pos`. Equivalent to `return emplace_hint(pos, std::move(value));`.

{/* source:cpp-container-flat-set-insert:0006 */}
5. 5,7) If `*this` already contains an element which transparently compares equivalent to `x`, does nothing. Otherwise, inserts a new element as if by: (5) `emplace(pos, std::forward<K>(x))` (in the position as close as possible to the position just prior to `pos`); (7) `emplace(std::forward<K>(x))`.

{/* source:cpp-container-flat-set-insert:0007 */}
6. The conversion from `x` into [`key_type`](/docs/cpp/library/container/flat_set#Member_types) must construct an object `u`, for which `find(k) == find(u)` is `true`. Otherwise, the behavior is undefined.

{/* source:cpp-container-flat-set-insert:0008 */}
7. These overloads participate in overload resolution only if The qualified-id `Compare::is_transparent` is valid and denotes a type, and `std::is_constructible_v<value_type, K>` is `true`, which together allows calling this function without constructing an instance of `Key`.

{/* source:cpp-container-flat-set-insert:0009 */}
8. 6) Equivalent to the sequence of operations: Inserts elements from range [`first`, `last`) as if by `c.insert(c.end(), first, last);`. Sorts the range of newly inserted elements with respect to [`compare`](/docs/cpp/library/container/flat_set#Member_objects). Merges the resulting sorted range and the sorted range of pre-existing elements into a single sorted range. (Note: the merge operation may allocate memory). Erases all but the first element from each group of consecutive equivalent elements.

{/* source:cpp-container-flat-set-insert:0010 */}
9. If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

{/* source:cpp-container-flat-set-insert:0011 */}
10. 8) Inserts elements from range [`first`, `last`). Equivalent to `insert(first, last);`.

{/* source:cpp-container-flat-set-insert:0012 */}
11. If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

{/* source:cpp-container-flat-set-insert:0013 */}
12. 9) Inserts elements from initializer list `ilist`. Equivalent to `insert(ilist.begin(), ilist.end());`.

{/* source:cpp-container-flat-set-insert:0014 */}
13. If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

{/* source:cpp-container-flat-set-insert:0015 */}
14. 10) Inserts elements from initializer list `ilist`. Equivalent to `insert(s, ilist.begin(), ilist.end());`.

{/* source:cpp-container-flat-set-insert:0016 */}
15. If multiple elements in the range have keys that compare equivalent, it is unspecified which element is inserted (pending [LWG2844](https://cplusplus.github.io/LWG/issue2844)).

{/* source:cpp-container-flat-set-insert:0017 */}

### Complexity

{/* source:cpp-container-flat-set-insert:0026 */}
1. 1-5) Linear in [`size()`](/docs/cpp/library/container/flat_set/size).

{/* source:cpp-container-flat-set-insert:0027 */}
2. 6) `N + M·log(M)`, where N is the [`size()`](/docs/cpp/library/container/flat_set/size) before the operation and M is `std::distance(first, last)`.

{/* source:cpp-container-flat-set-insert:0028 */}
3. 7) Linear in [`size()`](/docs/cpp/library/container/flat_set/size).

{/* source:cpp-container-flat-set-insert:0029 */}
4. 8) Linear in N, where N is [`size()`](/docs/cpp/library/container/flat_set/size) after the operation.

{/* source:cpp-container-flat-set-insert:0030 */}
5. 9) `N + M·log(M)`, where N is the [`size()`](/docs/cpp/library/container/flat_set/size) before the operation and M is `ilist.size()`.

{/* source:cpp-container-flat-set-insert:0031 */}
6. 10) Linear in N, where N is [`size()`](/docs/cpp/library/container/flat_set/size) after the operation.

### Notes

{/* source:cpp-container-flat-set-insert:0033 */}
The hinted insert (3-5) does not return a boolean in order to be signature-compatible with positional insert on sequential containers, such as [`std::vector::insert`](/docs/cpp/library/container/vector/insert). This makes it possible to create generic inserters such as [`std::inserter`](/docs/cpp/library/iterator/inserter). One way to check success of a hinted insert is to compare [`size()`](/docs/cpp/library/container/flat_set/size) before and after.

### Example

{/* source:cpp-container-flat-set-insert:0034 */}
```cpp
#include <cassert>
#include <flat_set>
#include <iostream>

int main()
{
    std::flat_set<int> set;

    auto result_1 = set.insert(3);
    assert(result_1.first != set.end()); // it is a valid iterator
    assert(*result_1.first == 3);
    if (result_1.second)
        std::cout << "insert done\n";

    auto result_2 = set.insert(3);
    assert(result_2.first == result_1.first); // the same iterator
    assert(*result_2.first == 3);
    if (!result_2.second)
        std::cout << "no insertion\n";
}
```

Output:

```text
insert done
no insertion
```
