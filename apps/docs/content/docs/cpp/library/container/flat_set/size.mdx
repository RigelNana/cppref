{/* source:cpp-container-flat-set-size:0001 */}
Returns the number of elements in the container adaptor. Equivalent to: `return` [`c`](/docs/cpp/library/container/flat_set#Member_objects)`.size()`.

### Parameters

{/* source:cpp-container-flat-set-size:0002 */}
(none)

### Return value

{/* source:cpp-container-flat-set-size:0003 */}
The number of elements in the container adaptor.

### Complexity

{/* source:cpp-container-flat-set-size:0004 */}
Constant.

### Example

{/* source:cpp-container-flat-set-size:0005 */}
```cpp
#include <cassert>
#include <flat_set>

int main()
{
    std::flat_set<int> nums{4, 2, 4, 2};
    assert(nums.size() == 2);
}
```
