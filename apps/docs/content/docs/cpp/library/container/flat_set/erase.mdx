{/* source:cpp-container-flat-set-erase:0001 */}
Removes specified elements from the container.

{/* source:cpp-container-flat-set-erase:0002 */}
1. 1,2) Removes the element at `pos`.

{/* source:cpp-container-flat-set-erase:0003 */}
2. 3) Removes the elements in the range [`first`, `last`), which must be a valid range in `*this`.

{/* source:cpp-container-flat-set-erase:0004 */}
3. 4) Removes the element (if one exists) with the key equivalent to `key`.

{/* source:cpp-container-flat-set-erase:0005 */}
4. 5) Removes all elements with key that compares equivalent to the value `x`. This overload participates in overload resolution only if the qualified-id `Compare::is_transparent` is valid and denotes a type, and neither `iterator` nor `const_iterator` is implicitly convertible from `K`. It allows calling this function without constructing an instance of `Key`.

{/* source:cpp-container-flat-set-erase:0006 */}
Information on iterator invalidation is copied from [here](/docs/Template:cpp/container/note-iterator-invalidation).

{/* source:cpp-container-flat-set-erase:0007 */}
The iterator `pos` must be valid and dereferenceable. Thus the `end()` iterator (which is valid, but is not dereferenceable) cannot be used as a value for `pos`.

### Return value

{/* source:cpp-container-flat-set-erase:0009 */}
1. 1-3) Iterator following the last removed element.

{/* source:cpp-container-flat-set-erase:0010 */}
2. 4) Number of elements removed (0 or 1).

{/* source:cpp-container-flat-set-erase:0011 */}
3. 5) Number of elements removed.

### Exceptions

{/* source:cpp-container-flat-set-erase:0012 */}
1. 1-3) Throws nothing.

{/* source:cpp-container-flat-set-erase:0013 */}
2. 4,5) Any exceptions thrown by the `Compare` object.

### Example

{/* source:cpp-container-flat-set-erase:0015 */}
```cpp
#include <flat_set>
#include <iostream>

int main()
{
    std::flat_set<int> c = {1, 2, 3, 4, 1, 2, 3, 4};

    auto print = [&c]
    {
        std::cout << "c = { ";
        for (int n : c)
            std::cout << n << ' ';
        std::cout << "}\n";
    };
    print();

    std::cout << "Erase all odd numbers:\n";
    for (auto it = c.begin(); it != c.end();)
    {
        if (*it % 2 != 0)
            it = c.erase(it);
        else
            ++it;
    }
    print();

    std::cout << "Erase 1, erased count: " << c.erase(1) << '\n';
    std::cout << "Erase 2, erased count: " << c.erase(2) << '\n';
    std::cout << "Erase 2, erased count: " << c.erase(2) << '\n';
    print();
}
```

Output:

```text
c = { 1 2 3 4 }
Erase all odd numbers:
c = { 2 4 }
Erase 1, erased count: 0
Erase 2, erased count: 1
Erase 2, erased count: 0
c = { 4 }
```
