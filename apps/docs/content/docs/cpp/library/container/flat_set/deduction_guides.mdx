{/* source:cpp-container-flat-set-deduction-guides:0001 */}
These [deduction guides](/docs/cpp/language/templates/ctad) are provided for to allow deduction from:

{/* source:cpp-container-flat-set-deduction-guides:0002 */}
- 1) A container and a comparator.

{/* source:cpp-container-flat-set-deduction-guides:0003 */}
- 2) A container and an allocator.

{/* source:cpp-container-flat-set-deduction-guides:0004 */}
- 3) A container, a comparator and an allocator.

{/* source:cpp-container-flat-set-deduction-guides:0005 */}
- 4) The `std::sorted_unique_t` tag, a container and a comparator.

{/* source:cpp-container-flat-set-deduction-guides:0006 */}
- 5) The `std::sorted_unique_t` tag, a container and an allocator.

{/* source:cpp-container-flat-set-deduction-guides:0007 */}
- 6) The `std::sorted_unique_t` tag, a container, a comparator and an allocator.

{/* source:cpp-container-flat-set-deduction-guides:0008 */}
- 7) An iterator range and a comparator.

{/* source:cpp-container-flat-set-deduction-guides:0009 */}
- 8) The `std::sorted_unique_t` tag, an iterator range and a comparator.

{/* source:cpp-container-flat-set-deduction-guides:0010 */}
- 9) The [`std::from_range_t`](/docs/cpp/library/ranges/from_range) tag, an [`input_range`](/docs/cpp/library/ranges/input_range) range, a comparator and an allocator.

{/* source:cpp-container-flat-set-deduction-guides:0011 */}
- 10) The [`std::from_range_t`](/docs/cpp/library/ranges/from_range) tag, an [`input_range`](/docs/cpp/library/ranges/input_range) range and an allocator.

{/* source:cpp-container-flat-set-deduction-guides:0012 */}
- 11) The [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) and a comparator.

{/* source:cpp-container-flat-set-deduction-guides:0013 */}
- 12) The `std::sorted_unique_t` tag, the [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) and a comparator.

{/* source:cpp-container-flat-set-deduction-guides:0014 */}
These overloads participate in overload resolution only if `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator), `Alloc` satisfies [`Allocator`](/docs/cpp/library/named_req/Allocator), and `Comp` does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator).

{/* source:cpp-container-flat-set-deduction-guides:0015 */}
Note: the extent to which the library determines that a type does not satisfy [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator) is unspecified, except that as a minimum integral types do not qualify as input iterators. Likewise, the extent to which it determines that a type does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator) is unspecified, except that as a minimum the member type `Alloc::value_type` must exist and the expression `std::declval<Alloc&>().allocate(std::size_t{})` must be well-formed when treated as an unevaluated operand.
