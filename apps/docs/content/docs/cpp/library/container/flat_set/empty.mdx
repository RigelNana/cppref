{/* source:cpp-container-flat-set-empty:0001 */}
Checks if the underlying container has no elements. Equivalent to: `return begin() == end();`.

### Parameters

{/* source:cpp-container-flat-set-empty:0002 */}
(none)

### Return value

{/* source:cpp-container-flat-set-empty:0003 */}
`true` if the underlying container is empty, `false` otherwise.

### Complexity

{/* source:cpp-container-flat-set-empty:0004 */}
Constant.

### Example

{/* source:cpp-container-flat-set-empty:0005 */}
The following code uses `empty` to check if a `std::flat_set<int>` contains any elements:

```cpp
#include <iostream>
#include <flat_set>

int main()
{
    std::flat_set<int> numbers;
    std::cout << std::boolalpha;
    std::cout << "Initially, numbers.empty(): " << numbers.empty() << '\n';

    numbers.insert(42);
    numbers.insert(19937);
    std::cout << "After adding elements, numbers.empty(): " << numbers.empty() << '\n';
}
```

Output:

```text
Initially, numbers.empty(): true
After adding elements, numbers.empty(): false
```
