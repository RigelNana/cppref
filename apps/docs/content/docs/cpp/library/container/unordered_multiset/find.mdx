{/* source:cpp-container-unordered-multiset-find:0001 */}
1,2) Finds an element with key equivalent to `key`. If there are several elements with the requested key in the container, any of them may be returned.

{/* source:cpp-container-unordered-multiset-find:0002 */}
3,4) Finds an element with key that compares equivalent to the value `x`. This overload participates in overload resolution only if `Hash::is_transparent` and `KeyEqual::is_transparent` are valid and each denotes a type. This assumes that such `Hash` is callable with both `K` and `Key` type, and that the `KeyEqual` is transparent, which, together, allows calling this function without constructing an instance of `Key`.

### Parameters

{/* source:cpp-container-unordered-multiset-find:0003 */}
<ParameterList>
  <Parameter name="key">key value of the element to search for</Parameter>
  <Parameter name="x">a value of any type that can be transparently compared with a key</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-unordered-multiset-find:0004 */}
An iterator to the requested element. If no such element is found, past-the-end (see [`end()`](/docs/cpp/library/container/unordered_multiset/end)) iterator is returned.

### Complexity

{/* source:cpp-container-unordered-multiset-find:0005 */}
Constant on average, worst case linear in the size of the container.

### Example

{/* source:cpp-container-unordered-multiset-find:0007 */}
```cpp
#include <iostream>
#include <unordered_set>
 
int main()
{
    // Simple comparison demo.
    std::unordered_multiset<int> example{1, 2, 3, 4};
 
    if (auto search = example.find(2); search != example.end())
        std::cout << "Found " << (*search) << '\n';
    else
        std::cout << "Not found\n";
}
```

Output:

```text
Found 2
```
