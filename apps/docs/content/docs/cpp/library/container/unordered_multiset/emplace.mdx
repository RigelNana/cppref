{/* source:cpp-container-unordered-multiset-emplace:0001 */}
Inserts a new element into the container constructed in-place with the given `args`.

{/* source:cpp-container-unordered-multiset-emplace:0002 */}
The constructor of the new element is called with exactly the same arguments as supplied to `emplace`, forwarded via `std::forward<Args>(args)...`.

{/* source:cpp-container-unordered-multiset-emplace:0003 */}
Careful use of `emplace` allows the new element to be constructed while avoiding unnecessary copy or move operations.

{/* source:cpp-container-unordered-multiset-emplace:0004 */}
If after the operation the new number of elements is greater than old [`max_load_factor()`](/docs/cpp/library/container/unordered_multiset/max_load_factor) * [`bucket_count()`](/docs/cpp/library/container/unordered_multiset/bucket_count) a rehashing takes place. If rehashing occurs (due to the insertion), all iterators are invalidated. Otherwise (no rehashing), iterators are not invalidated.

### Return value

### Exceptions

{/* source:cpp-container-unordered-multiset-emplace:0007 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-container-unordered-multiset-emplace:0008 */}
Amortized constant on average, worst case linear in the size of the container.
