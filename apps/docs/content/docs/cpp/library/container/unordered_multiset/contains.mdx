{/* source:cpp-container-unordered-multiset-contains:0001 */}
1. Checks if there is an element with key equivalent to `key` in the container.

{/* source:cpp-container-unordered-multiset-contains:0002 */}
2. Checks if there is an element with key that compares equivalent to the value `x`. This overload participates in overload resolution only if `Hash::is_transparent` and `KeyEqual::is_transparent` are valid and each denotes a type. This assumes that such `Hash` is callable with both `K` and `Key` type, and that the `KeyEqual` is transparent, which, together, allows calling this function without constructing an instance of `Key`.

### Parameters

{/* source:cpp-container-unordered-multiset-contains:0003 */}
<ParameterList>
  <Parameter name="key">key value of the element to search for</Parameter>
  <Parameter name="x">a value of any type that can be transparently compared with a key</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-unordered-multiset-contains:0004 */}
`true` if there is such an element, otherwise `false`.

### Complexity

{/* source:cpp-container-unordered-multiset-contains:0005 */}
Constant on average, worst case linear in the size of the container.

### Example

{/* source:cpp-container-unordered-multiset-contains:0006 */}
```cpp
#include <iostream>
#include <unordered_set>
 
int main()
{
    std::unordered_multiset<int> example{1, 2, 3, 4};
 
    for (int x : {2, 5})
        if (example.contains(x))
            std::cout << x << ": Found\n";
        else
            std::cout << x << ": Not found\n";
}
```

Output:

```text
2: Found
5: Not found
```
