{/* source:cpp-container-unordered-multiset-max-size:0001 */}
Returns the maximum number of elements the container is able to hold due to system or library implementation limitations, i.e. `std::distance(begin(), end())` for the largest container.

### Parameters

{/* source:cpp-container-unordered-multiset-max-size:0002 */}
(none)

### Return value

{/* source:cpp-container-unordered-multiset-max-size:0003 */}
Maximum number of elements.

### Complexity

{/* source:cpp-container-unordered-multiset-max-size:0004 */}
Constant.

### Notes

{/* source:cpp-container-unordered-multiset-max-size:0005 */}
This value typically reflects the theoretical limit on the size of the container, at most `std::numeric_limits<difference_type>::max()`. At runtime, the size of the container may be limited to a value smaller than `max_size()` by the amount of RAM available.

### Example

{/* source:cpp-container-unordered-multiset-max-size:0006 */}
```cpp
#include <iostream>
#include <locale>
#include <unordered_set>

int main()
{
    std::unordered_multiset<char> p;
    std::unordered_multiset<long> q;

    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << std::uppercase
              << "p.max_size() = " << std::dec << p.max_size() << " = 0x"
              << std::hex << p.max_size() << '\n'
              << "q.max_size() = " << std::dec << q.max_size() << " = 0x"
              << std::hex << q.max_size() << '\n';
}
```

Possible output:

```text
p.max_size() = 1,152,921,504,606,846,975 = 0xFFF,FFF,FFF,FFF,FFF
q.max_size() = 1,152,921,504,606,846,975 = 0xFFF,FFF,FFF,FFF,FFF
```
