{/* source:cpp-container-unordered-multiset-empty:0001 */}
Checks if the container has no elements, i.e. whether `begin() == end()`.

### Parameters

{/* source:cpp-container-unordered-multiset-empty:0002 */}
(none)

### Return value

{/* source:cpp-container-unordered-multiset-empty:0003 */}
`true` if the container is empty, `false` otherwise.

### Complexity

{/* source:cpp-container-unordered-multiset-empty:0004 */}
Constant.

### Example

{/* source:cpp-container-unordered-multiset-empty:0005 */}
The following code uses `empty` to check if a `std::unordered_multiset<int>` contains any elements:

```cpp
#include <iostream>
#include <unordered_set>
 
int main()
{
    std::unordered_multiset<int> numbers;
    std::cout << std::boolalpha;
    std::cout << "Initially, numbers.empty(): " << numbers.empty() << '\n';
 
    numbers.insert(42);
    numbers.insert(19937);
    std::cout << "After adding elements, numbers.empty(): " << numbers.empty() << '\n';
}
```

Output:

```text
Initially, numbers.empty(): true
After adding elements, numbers.empty(): false
```
