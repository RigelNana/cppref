{/* source:cpp-container-unordered-multiset-deduction-guides:0001 */}
- 1-6) These [deduction guides](/docs/cpp/language/templates/ctad) are provided for `unordered_multiset` to allow deduction from an iterator range (overloads (1,3,4)) and [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) (overloads (2,5,6)). This overload participates in overload resolution only if `InputIt` satisfies [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator), `Alloc` satisfies [Allocator](/docs/cpp/library/named_req/Allocator), neither `Hash` nor `Pred` satisfy [Allocator](/docs/cpp/library/named_req/Allocator), `Hash` is not an integral type.

{/* source:cpp-container-unordered-multiset-deduction-guides:0002 */}
- 7-10) These deduction guides are provided for `unordered_multiset` to allow deduction from a [`std::from_range_t`](/docs/cpp/library/ranges/from_range) tag and an [`input_range`](/docs/cpp/library/ranges/input_range).

{/* source:cpp-container-unordered-multiset-deduction-guides:0003 */}
Note: the extent to which the library determines that a type does not satisfy [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator) is unspecified, except that as a minimum integral types do not qualify as input iterators. Likewise, the extent to which it determines that a type does not satisfy [Allocator](/docs/cpp/library/named_req/Allocator) is unspecified, except that as a minimum the member type `Alloc::value_type` must exist and the expression `std::declval<Alloc&>().allocate(std::size_t{})` must be well-formed when treated as an unevaluated operand.

{/* source:cpp-container-unordered-multiset-deduction-guides:0004 */}
The `size_type` parameter type in these guides refers to the `size_type` member type of the type deduced by the deduction guide.

### Example

{/* source:cpp-container-unordered-multiset-deduction-guides:0006 */}
```cpp
#include <unordered_set>
 
int main()
{
    // guide #2 deduces std::unordered_multiset<int>
    std::unordered_multiset s = {1, 2, 3, 4};
 
    // guide #1 deduces std::unordered_multiset<int>
    std::unordered_multiset s2(s.begin(), s.end());
}
```
