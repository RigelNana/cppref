{/* source:cpp-container-unordered-multiset-insert:0001 */}
Inserts element(s) into the container.

{/* source:cpp-container-unordered-multiset-insert:0002 */}
1,2) Inserts `value`.

{/* source:cpp-container-unordered-multiset-insert:0003 */}
3,4) Inserts `value`, using `hint` as a non-binding suggestion to where the search should start.

{/* source:cpp-container-unordered-multiset-insert:0004 */}
5) Inserts elements from range `[first, last)`.

{/* source:cpp-container-unordered-multiset-insert:0005 */}
6) Inserts elements from initializer list `ilist`.

{/* source:cpp-container-unordered-multiset-insert:0006 */}
7) If `nh` is an empty [node handle](/docs/cpp/library/container/node_handle), does nothing. Otherwise, inserts the element owned by `nh` into the container and returns an iterator pointing at the inserted element. The behavior is undefined if `nh` is not empty and `get_allocator() != nh.get_allocator()`.

{/* source:cpp-container-unordered-multiset-insert:0007 */}
8) If `nh` is an empty [node handle](/docs/cpp/library/container/node_handle), does nothing and returns the end iterator. Otherwise, inserts the element owned by `nh` into the container, and returns the iterator pointing to the element with key equivalent to `nh.key()`. `hint` is used as a non-binding suggestion to where the search should start. The behavior is undefined if `nh` is not empty and `get_allocator() != nh.get_allocator()`.

{/* source:cpp-container-unordered-multiset-insert:0008 */}
If after the operation the new number of elements is greater than old [`max_load_factor()`](/docs/cpp/library/container/unordered_multiset/max_load_factor) `*` [`bucket_count()`](/docs/cpp/library/container/unordered_multiset/bucket_count) a rehashing takes place.
If rehashing occurs (due to the insertion), all iterators are invalidated. Otherwise (no rehashing), iterators are not invalidated. <InlineRevision since="C++17">If the insertion is successful, pointers and references to the element obtained while it is held in the node handle are invalidated, and pointers and references obtained to that element before it was extracted become valid.</InlineRevision>

Type requirements

- `InputIt` must meet the requirements of [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

### Return value

{/* source:cpp-container-unordered-multiset-insert:0010 */}
1-4) An iterator to the inserted element.

{/* source:cpp-container-unordered-multiset-insert:0011 */}
5,6) (none)

{/* source:cpp-container-unordered-multiset-insert:0012 */}
7,8) End iterator if `nh` was empty, iterator pointing to the inserted element otherwise.

### Exceptions

{/* source:cpp-container-unordered-multiset-insert:0013 */}
1-4) If an exception is thrown by any operation, the insertion has no effect.

### Complexity

{/* source:cpp-container-unordered-multiset-insert:0015 */}
1-4) Average case: `O(1)`, worst case `O(size())`.

{/* source:cpp-container-unordered-multiset-insert:0016 */}
5,6) Average case: `O(N)`, where N is the number of elements to insert. Worst case: `O(N * size() + N)`.

{/* source:cpp-container-unordered-multiset-insert:0017 */}
7,8) Average case: `O(1)`, worst case `O(size())`.
