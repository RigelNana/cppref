{/* source:cpp-container-unordered-multiset-size:0001 */}
Returns the number of elements in the container, i.e. `std::distance(begin(), end())`.

### Parameters

{/* source:cpp-container-unordered-multiset-size:0002 */}
(none)

### Return value

{/* source:cpp-container-unordered-multiset-size:0003 */}
The number of elements in the container.

### Complexity

{/* source:cpp-container-unordered-multiset-size:0004 */}
Constant.

### Example

{/* source:cpp-container-unordered-multiset-size:0005 */}
```cpp
#include <cassert>
#include <unordered_set>
 
int main()
{
    std::unordered_multiset<int> nums{4, 2, 4, 2};
    assert(nums.size() == 4);
}
```
