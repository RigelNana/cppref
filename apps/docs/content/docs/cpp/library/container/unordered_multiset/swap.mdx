{/* source:cpp-container-unordered-multiset-swap:0001 */}
Exchanges the contents of the container with those of `other`. Does not invoke any move, copy, or swap operations on individual elements.

{/* source:cpp-container-unordered-multiset-swap:0002 */}
All iterators and references remain valid. The [`end()`](/docs/cpp/library/container/unordered_multiset/end) iterator is invalidated.
The `Hash` and `KeyEqual` objects must be [Swappable](/docs/cpp/library/named_req/Swappable), and they are exchanged using unqualified calls to non-member `swap`.

{/* source:cpp-container-unordered-multiset-swap:0003 */}
<Revision since="C++11">
If `std::allocator_traits<allocator_type>::propagate_on_container_swap::value` is `true`, then the allocators are exchanged using an unqualified call to non-member `swap`. Otherwise, they are not swapped (and if `get_allocator() != other.get_allocator()`, the behavior is undefined).
</Revision>

### Exceptions

{/* source:cpp-container-unordered-multiset-swap:0005 */}
<Revision until="C++17">
Any exception thrown by the swap of the `Hash` or `KeyEqual` objects.
</Revision>

<Revision since="C++17">
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(std::allocator_traits<Allocator>::is_always_equal::value
&& std::is_nothrow_swappable<Hash>::value

&& std::is_nothrow_swappable<key_equal>::value)
```
</Revision>

### Complexity

{/* source:cpp-container-unordered-multiset-swap:0006 */}
Constant.

### Example

{/* source:cpp-container-unordered-multiset-swap:0007 */}
```cpp
#include <iostream>
#include <unordered_set>

template<class Os, class Co> Os& operator<<(Os& os, const Co& co)
{
    os << '{';
    for (auto const& i : co)
        os << ' ' << i;
    return os << " } ";
}

int main()
{
    std::unordered_multiset<int> a1{3, 1, 3, 2}, a2{5, 4, 5};

    auto it1 = std::next(a1.begin());
    auto it2 = std::next(a2.begin());

    const int& ref1 = *(a1.begin());
    const int& ref2 = *(a2.begin());

    std::cout << a1 << a2 << *it1 << ' ' << *it2 << ' ' << ref1 << ' ' << ref2 << '\n';
    a1.swap(a2);
    std::cout << a1 << a2 << *it1 << ' ' << *it2 << ' ' << ref1 << ' ' << ref2 << '\n';

    // Note that every iterator referring to an element in one container before the swap
    // refers to the same element in the other container after the swap. Same is true
    // for references.
}
```

Possible output:

```text
{ 2 3 3 1 } { 4 5 5 } 3 5 2 4
{ 4 5 5 } { 2 3 3 1 } 3 5 2 4
```
