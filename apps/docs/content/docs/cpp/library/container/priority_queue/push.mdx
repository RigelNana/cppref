{/* source:cpp-container-priority-queue-push:0001 */}
Pushes the given element `value` to the priority queue.

{/* source:cpp-container-priority-queue-push:0002 */}
- 1) Equivalent to: `c.push_back(value); std::push_heap(c.begin(), c.end(), comp);`.

{/* source:cpp-container-priority-queue-push:0003 */}
- 2) Equivalent to: `c.push_back(std::move(value)); std::push_heap(c.begin(), c.end(), comp);`.

### Parameters

{/* source:cpp-container-priority-queue-push:0004 */}
<ParameterList>
  <Parameter name="value">the value of the element to push</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-priority-queue-push:0005 */}
(none)

### Complexity

{/* source:cpp-container-priority-queue-push:0006 */}
Logarithmic number of comparisons plus the complexity of `Container::push_back`.

### Example

{/* source:cpp-container-priority-queue-push:0007 */}
```cpp
#include <iostream>
#include <queue>
 
struct Event
{
    int priority{};
    char data{' '};
 
    friend bool operator<(Event const& lhs, Event const& rhs)
    {
        return lhs.priority < rhs.priority;
    }
 
    friend std::ostream& operator<<(std::ostream& os, Event const& e)
    {
        return os << '{' << e.priority << ", '" << e.data << "'}";
    }
};
 
int main()
{
    std::priority_queue<Event> events;
 
    std::cout << "Fill the events queue:\t";
 
    for (auto const e : {Event{6,'L'}, {8,'I'}, {9,'S'}, {1,'T'}, {5,'E'}, {3,'N'}})
    {
        std::cout << e << ' ';
        events.push(e);
    }
 
    std::cout << "\nProcess events:\t\t";
 
    for (; !events.empty(); events.pop())
    {
        Event const& e = events.top();
        std::cout << e << ' ';
    }
 
    std::cout << '\n';
}
```
Output:

```text
Fill the events queue:  {6, 'L'} {8, 'I'} {9, 'S'} {1, 'T'} {5, 'E'} {3, 'N'}
Process events:         {9, 'S'} {8, 'I'} {6, 'L'} {5, 'E'} {3, 'N'} {1, 'T'}
```
