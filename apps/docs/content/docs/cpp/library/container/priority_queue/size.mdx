{/* source:cpp-container-priority-queue-size:0001 */}
Returns the number of elements in the container adaptor. Equivalent to: `return [`c`](/docs/cpp/library/container/priority_queue#Member_objects).size()`.

### Parameters

{/* source:cpp-container-priority-queue-size:0002 */}
(none)

### Return value

{/* source:cpp-container-priority-queue-size:0003 */}
The number of elements in the container adaptor.

### Complexity

{/* source:cpp-container-priority-queue-size:0004 */}
Constant.

### Example

{/* source:cpp-container-priority-queue-size:0005 */}
```cpp
#include <cassert>
#include <queue>
 
int main()
{
    std::priority_queue<int> queue;
    assert(queue.size() == 0);
 
    const int count = 8;
    for (int i = 0; i != count; ++i)
        queue.push(i);
    assert(queue.size() == count);
}
```
