{/* source:cpp-container-priority-queue-empty:0001 */}
Checks if the underlying container has no elements. Equivalent to: `return [`c`](/docs/cpp/library/container/priority_queue#Member_objects).empty()`.

### Parameters

{/* source:cpp-container-priority-queue-empty:0002 */}
(none)

### Return value

{/* source:cpp-container-priority-queue-empty:0003 */}
`true` if the underlying container is empty, `false` otherwise.

### Complexity

{/* source:cpp-container-priority-queue-empty:0004 */}
Constant.

### Example

{/* source:cpp-container-priority-queue-empty:0005 */}
```cpp
#include <cassert>
#include <queue>
 
int main()
{
    std::priority_queue<int> queue;
    assert(queue.empty());
 
    queue.push(42);
    assert(!queue.empty());
 
    queue.pop();
    assert(queue.empty());
}
```
