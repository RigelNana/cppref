{/* source:cpp-container-priority-queue-deduction-guides:0001 */}
The following [`deduction guides`](/docs/cpp/language/templates/ctad) are provided for [`std::priority_queue`](/docs/cpp/library/container/priority_queue):

{/* source:cpp-container-priority-queue-deduction-guides:0002 */}
- 1-6) Allow deduction from underlying container type and from an iterator range. `/*iter-value-type*/<It>` denotes `typename std::iterator_traits<It>::value_type` for any type `It`.

{/* source:cpp-container-priority-queue-deduction-guides:0003 */}
- 7-9) Allow deduction from a [`std::from_range_t`](/docs/cpp/library/ranges/from_range) tag and an [`input_range`](/docs/cpp/library/ranges/input_range).

{/* source:cpp-container-priority-queue-deduction-guides:0004 */}
These overloads participate in overload resolution only if

{/* source:cpp-container-priority-queue-deduction-guides:0005 */}
- `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator),
- `Comp` does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator),
- `Container` does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator),
- <InlineRevision since="C++23">for overloads (4,5),</InlineRevision> `Alloc` satisfies [`Allocator`](/docs/cpp/library/named_req/Allocator), and
- for overloads (3,6), `std::uses_allocator_v<Container, Alloc>` is `true`.

{/* source:cpp-container-priority-queue-deduction-guides:0006 */}
Note: the extent to which the library determines that a type does not satisfy [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator) is unspecified, except that as a minimum integral types do not qualify as input iterators. Likewise, the extent to which it determines that a type does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator) is unspecified, except that as a minimum the member type `Alloc::value_type` must exist and the expression `std::declval<Alloc&>().allocate(std::size_t{})` must be well-formed when treated as an unevaluated operand.

### Example

{/* source:cpp-container-priority-queue-deduction-guides:0008 */}
```cpp
#include <functional>
#include <iostream>
#include <queue>
#include <vector>
 
int main()
{
    const std::vector<int> v = {1, 2, 3, 4};
    std::priority_queue pq1{std::greater<int>{}, v}; // deduces std::priority_queue<
                                                     //     int, std::vector<int>,
                                                     //     std::greater<int>>
    for (; !pq1.empty(); pq1.pop())
        std::cout << pq1.top() << ' ';
    std::cout << '\n';
 
    std::priority_queue pq2{v.begin(), v.end()}; // deduces std::priority_queue<int>
 
    for (; !pq2.empty(); pq2.pop())
        std::cout << pq2.top() << ' ';
    std::cout << '\n';
}
```
Output:

```text
1 2 3 4
4 3 2 1
```
