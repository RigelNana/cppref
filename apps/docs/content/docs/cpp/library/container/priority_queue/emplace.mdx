{/* source:cpp-container-priority-queue-emplace:0001 */}
Pushes a new element to the priority queue. The element is constructed in-place, i.e. no copy or move operations are performed. The constructor of the element is called with exactly the same arguments as supplied to the function.

{/* source:cpp-container-priority-queue-emplace:0002 */}
Effectively calls

```cpp
c.emplace_back(std::forward<Args>(args)...);
std::push_heap(c.begin(), c.end(), comp);
```
### Parameters

{/* source:cpp-container-priority-queue-emplace:0003 */}
<ParameterList>
  <Parameter name="args">arguments to forward to the constructor of the element</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-priority-queue-emplace:0004 */}
(none)

### Complexity

{/* source:cpp-container-priority-queue-emplace:0005 */}
Logarithmic number of comparisons plus the complexity of `Container::emplace_back`.

### Example

{/* source:cpp-container-priority-queue-emplace:0006 */}
```cpp
#include <iostream>
#include <queue>
 
struct S
{
    int id;
 
    S(int i, double d, std::string s) : id{i}
    {
        std::cout << "S::S(" << i << ", " << d << ", \"" << s << "\");\n";
    }
    friend bool operator< (S const& x, S const& y) { return x.id < y.id; }
};
 
int main()
{
    std::priority_queue<S> queue;
    queue.emplace(42, 3.14, "C++");
    std::cout << "id: " << queue.top().id << '\n';
}
```
Output:

```text
S::S(42, 3.14, "C++")
id = 42
```
