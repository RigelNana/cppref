{/* source:cpp-container-priority-queue-priority-queue:0001 */}
Constructs new underlying container of the container adaptor from a variety of data sources.

{/* source:cpp-container-priority-queue-priority-queue:0002 */}
- 1) Default constructor. Value-initializes the comparator and the underlying container.

{/* source:cpp-container-priority-queue-priority-queue:0003 */}
- 2) Copy-constructs the comparison functor `comp` with the contents of `compare`. Value-initializes the underlying container `c`.

{/* source:cpp-container-priority-queue-priority-queue:0004 */}
- 3) Copy-constructs the underlying container `c` with the contents of `cont`. Copy-constructs the comparison functor `comp` with the contents of `compare`. Calls `std::make_heap(c.begin(), c.end(), comp)`. <InlineRevision until="C++11">This is also the default constructor.</InlineRevision>

{/* source:cpp-container-priority-queue-priority-queue:0005 */}
- 4) Move-constructs the underlying container `c` with `std::move(cont)`. Copy-constructs the comparison functor `comp` with `compare`. Calls `std::make_heap(c.begin(), c.end(), comp)`.

{/* source:cpp-container-priority-queue-priority-queue:0006 */}
- 5) [`Copy constructor`](/docs/cpp/language/classes/copy_constructor). The underlying container is copy-constructed with `other.c`. The comparison functor is copy-constructed with `other.comp`. (implicitly declared)

{/* source:cpp-container-priority-queue-priority-queue:0007 */}
- 6) [`Move constructor`](/docs/cpp/language/classes/move_constructor). The underlying container is constructed with `std::move(other.c)`. The comparison functor is constructed with `std::move(other.comp)`. (implicitly declared)

{/* source:cpp-container-priority-queue-priority-queue:0008 */}
- 7-9) Iterator-pair constructors. These overloads participate in overload resolution only if `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

{/* source:cpp-container-priority-queue-priority-queue:0009 */}
- 7) Constructs `c` as if by `c(first, last)` and `comp` from `compare`. Then calls `std::make_heap(c.begin(), c.end(), comp);`.

{/* source:cpp-container-priority-queue-priority-queue:0010 */}
- 8) Copy-constructs `c` from `cont` and `comp` from `compare`. Then calls `c.insert(c.end(), first, last);`, and then calls `std::make_heap(c.begin(), c.end(), comp);`.

{/* source:cpp-container-priority-queue-priority-queue:0011 */}
- 9) Move-constructs `c` from `std::move(cont)` and copy-constructs `comp` from `compare`. Then calls `c.insert(c.end(), first, last);`, and then calls `std::make_heap(c.begin(), c.end(), comp);`.

{/* source:cpp-container-priority-queue-priority-queue:0012 */}
- 10-15) Allocator-extended constructors. These overloads participate in overload resolution only if `std::uses_allocator<container_type, Alloc>::value` is `true`, that is, if the underlying container is an allocator-aware container (true for all standard library containers).

{/* source:cpp-container-priority-queue-priority-queue:0013 */}
- 10) Constructs the underlying container using `alloc` as allocator. Effectively calls `c(alloc)`. `comp` is value-initialized.

{/* source:cpp-container-priority-queue-priority-queue:0014 */}
- 11) Constructs the underlying container using `alloc` as allocator. Effectively calls `c(alloc)`. Copy-constructs `comp` from `compare`.

{/* source:cpp-container-priority-queue-priority-queue:0015 */}
- 12) Constructs the underlying container with the contents of `cont` and using `alloc` as allocator, as if by `c(cont, alloc)`. Copy-constructs `comp` from `compare`. Then calls `std::make_heap(c.begin(), c.end(), comp)`.

{/* source:cpp-container-priority-queue-priority-queue:0016 */}
- 13) Constructs the underlying container with the contents of `cont` using move semantics while using `alloc` as allocator, as if by `c(std::move(cont), alloc)`. Copy-constructs `comp` from `compare`. Then calls `std::make_heap(c.begin(), c.end(), comp)`.

{/* source:cpp-container-priority-queue-priority-queue:0017 */}
- 14) Constructs the underlying container with the contents of `other.c` and using `alloc` as allocator. Effectively calls `c(other.c, alloc)`. Copy-constructs `comp` from `other.comp`.

{/* source:cpp-container-priority-queue-priority-queue:0018 */}
- 15) Constructs the underlying container with the contents of `other` using move semantics while utilizing `alloc` as allocator. Effectively calls `c(std::move(other.c), alloc)`. Move-constructs `comp` from `other.comp`.

{/* source:cpp-container-priority-queue-priority-queue:0019 */}
- 16-19) Allocator-extended iterator-pair constructors. Same as (7-9), except that `alloc` is used for constructing the underlying container. These overloads participate in overload resolution only if `std::uses_allocator<container_type, Alloc>::value` is `true` and `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

{/* source:cpp-container-priority-queue-priority-queue:0020 */}
- 20) Initializes `comp` with `compare` and `c` with `ranges::to<Container>(std::forward<R>(rg))`. Then calls `std::make_heap(c.begin(), c.end(), comp)`.

{/* source:cpp-container-priority-queue-priority-queue:0021 */}
- 21) Initializes `comp` with `compare` and `c` with `ranges::to<Container>(std::forward<R>(rg), alloc)`. Then calls `std::make_heap(c.begin(), c.end(), comp)`.

{/* source:cpp-container-priority-queue-priority-queue:0022 */}
- 22) Initializes `c` with `ranges::to<Container>(std::forward<R>(rg), alloc)`. Then calls `std::make_heap(c.begin(), c.end(), comp)`.

{/* source:cpp-container-priority-queue-priority-queue:0023 */}
Note that how an implementation checks whether a type satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator) is unspecified, except that integral types are required to be rejected.

### Parameters

{/* source:cpp-container-priority-queue-priority-queue:0024 */}
<ParameterList>
  <Parameter name="alloc">allocator to use for all memory allocations of the underlying container</Parameter>
  <Parameter name="other">another container adaptor to be used as source to initialize the underlying container</Parameter>
  <Parameter name="cont">container to be used as source to initialize the underlying container</Parameter>
  <Parameter name="compare">the comparison function object to initialize the underlying comparison functor</Parameter>
  <Parameter name="first, last">a range `[first, last)` of elements to initialize with</Parameter>
  <Parameter name="rg">a [`container compatible range`](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to `T`</Parameter>
</ParameterList>

Type requirements

- `Alloc` must meet the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator).
- `Compare` must meet the requirements of [`Compare`](/docs/cpp/library/named_req/Compare).
- `Container` must meet the requirements of [`Container`](/docs/cpp/library/named_req/Container). The allocator-extended constructors are only defined if `Container` meets the requirements of [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer).
- `InputIt` must meet the requirements of [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

### Complexity

{/* source:cpp-container-priority-queue-priority-queue:0025 */}
- 1,2) Constant.

{/* source:cpp-container-priority-queue-priority-queue:0026 */}
- 3,5,12) O(N) comparisons and O(N) calls to the constructor of `value_type`, where N is `cont.size()`.

{/* source:cpp-container-priority-queue-priority-queue:0027 */}
- 4) O(N) comparisons, where N is `cont.size()`.

{/* source:cpp-container-priority-queue-priority-queue:0028 */}
- 6) Constant.

{/* source:cpp-container-priority-queue-priority-queue:0029 */}
- 7,16,17) O(M) comparisons, where M is `std::distance(first, last)`.

{/* source:cpp-container-priority-queue-priority-queue:0030 */}
- 8,18) O(N + M) comparisons and O(N) calls to the constructor of `value_type`, where N is `cont.size()` and M is `std::distance(first, last)`.

{/* source:cpp-container-priority-queue-priority-queue:0031 */}
- 9) O(N + M) comparisons, where N is `cont.size()` and M is `std::distance(first, last)`.

{/* source:cpp-container-priority-queue-priority-queue:0032 */}
- 10,11) Constant.

{/* source:cpp-container-priority-queue-priority-queue:0033 */}
- 13) O(N) comparisons, where N is `cont.size()`.

{/* source:cpp-container-priority-queue-priority-queue:0034 */}
- 14) Linear in size of `other`.

{/* source:cpp-container-priority-queue-priority-queue:0035 */}
- 15) Constant if `Alloc` compares equal to the allocator of `other`. Linear in size of `other` otherwise.

{/* source:cpp-container-priority-queue-priority-queue:0036 */}
- 19) O(N + M) comparisons and possibly O(N) calls to the constructor of `value_type` (present if `Alloc` does not compare equal to the allocator of `other`), where N is `cont.size()` and M is `std::distance(first, last)`.

{/* source:cpp-container-priority-queue-priority-queue:0037 */}
- 20) O(N) comparisons and O(N) calls to the constructor of `value_type`, where N is `ranges::distance(rg)`.

{/* source:cpp-container-priority-queue-priority-queue:0038 */}
- 21,22) This section is incomplete

### Example

{/* source:cpp-container-priority-queue-priority-queue:0040 */}
```cpp
#include <complex>
#include <functional>
#include <iostream>
#include <queue>
#include <vector>
 
int main()
{
    std::priority_queue<int> pq1;
    pq1.push(5);
    std::cout << "pq1.size() = " << pq1.size() << '\n';
 
    std::priority_queue<int> pq2 {pq1};
    std::cout << "pq2.size() = " << pq2.size() << '\n';
 
    std::vector<int> vec {3, 1, 4, 1, 5};
    std::priority_queue<int> pq3 {std::less<int>(), vec};
    std::cout << "pq3.size() = " << pq3.size() << '\n';
 
    for (std::cout << "pq3 : "; !pq3.empty(); pq3.pop())
        std::cout << pq3.top() << ' ';
    std::cout << '\n';
 
    // Demo With Custom Comparator:
 
    using my_value_t = std::complex<double>;
    using my_container_t = std::vector<my_value_t>;
 
    auto my_comp = [](const my_value_t& z1, const my_value_t& z2)
    {
        return z2.real() < z1.real();
    };
 
    std::priority_queue<my_value_t,
                        my_container_t,
                        decltype(my_comp)> pq4{my_comp};
 
    using namespace std::complex_literals;
    pq4.push(5.0 + 1i);
    pq4.push(3.0 + 2i);
    pq4.push(7.0 + 3i);
 
    for (; !pq4.empty(); pq4.pop())
    {
        const auto& z = pq4.top();
        std::cout << "pq4.top() = " << z << '\n';
    }
 
    // TODO: C++23 range-aware ctors
}
```
Output:

```text
pq1.size() = 1
pq2.size() = 1
pq3.size() = 5
pq3 : 5 4 3 1 1
pq4.top() = (3,2)
pq4.top() = (5,1)
pq4.top() = (7,3)
```
