{/* source:cpp-container-multiset-insert:0001 */}
Inserts element(s) into the container. The order of the remaining equivalent elements is preserved.

{/* source:cpp-container-multiset-insert:0002 */}
- 1,2) Inserts `value`. If the container has elements with equivalent key, inserts at the upper bound of that range.

{/* source:cpp-container-multiset-insert:0003 */}
- 3,4) Inserts `value` in the position as close as possible to the position just prior to `pos`.

{/* source:cpp-container-multiset-insert:0004 */}
- 5) Inserts elements from range `[first, last)`.

{/* source:cpp-container-multiset-insert:0005 */}
- 6) Inserts elements from initializer list `ilist`.

{/* source:cpp-container-multiset-insert:0006 */}
- 7) If `nh` is an empty [node handle](/docs/cpp/library/container/node_handle), does nothing. Otherwise, inserts the element owned by `nh` into the container and returns an iterator pointing at the inserted element. If a range containing elements with keys equivalent to `nh.key()` exists in the container, the element is inserted at the end of that range. The behavior is undefined if `nh` is not empty and `get_allocator() != nh.get_allocator()`.

{/* source:cpp-container-multiset-insert:0007 */}
- 8) If `nh` is an empty [node handle](/docs/cpp/library/container/node_handle), does nothing and returns the end iterator. Otherwise, inserts the element owned by `nh` into the container, and returns the iterator pointing to the element with key equivalent to `nh.key()`. The element is inserted as close as possible to the position just prior to `pos`. The behavior is undefined if `nh` is not empty and `get_allocator() != nh.get_allocator()`.

{/* source:cpp-container-multiset-insert:0008 */}
No iterators or references are invalidated. <InlineRevision since="C++17">If the insertion is successful, pointers and references to the element obtained while it is held in the node handle are invalidated, and pointers and references obtained to that element before it was extracted become valid.</InlineRevision>

Type requirements

- `InputIt` must meet the requirements of [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).

### Return value

{/* source:cpp-container-multiset-insert:0010 */}
- 1-4) An iterator to the inserted element.

{/* source:cpp-container-multiset-insert:0011 */}
- 5,6) (none)

{/* source:cpp-container-multiset-insert:0012 */}
- 7,8) End iterator if `nh` was empty, iterator pointing to the inserted element otherwise.

### Exceptions

{/* source:cpp-container-multiset-insert:0013 */}
- 1-4,7,8) If an exception is thrown by any operation, the insertion has no effect.

{/* source:cpp-container-multiset-insert:0014 */}
- 5,6) No exception safety guarantee.

### Complexity

{/* source:cpp-container-multiset-insert:0015 */}
- 1,2,7) `O(log(size()))`

{/* source:cpp-container-multiset-insert:0016 */}
- 3,4,8) Amortized constant if the insertion happens in the position just before `pos`, `O(log(size()))` otherwise.

{/* source:cpp-container-multiset-insert:0017 */}
- 5,6) `O(N·log(size() + N))`, where `N` is the number of elements to insert.
