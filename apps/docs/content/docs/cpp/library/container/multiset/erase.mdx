{/* source:cpp-container-multiset-erase:0001 */}
Removes specified elements from the container. The order of the remaining equivalent elements is preserved.

{/* source:cpp-container-multiset-erase:0002 */}
- 1,2) Removes the element at `pos`. <InlineRevision since="C++11">Only one overload is provided if `iterator` and `const_iterator` are the same type.</InlineRevision>

{/* source:cpp-container-multiset-erase:0003 */}
- 3) Removes the elements in the range `[first, last)`, which must be a valid range in `*this`.

{/* source:cpp-container-multiset-erase:0004 */}
- 4) Removes all elements with the key equivalent to `key`.

{/* source:cpp-container-multiset-erase:0005 */}
- 5) Removes all elements with key that compares *equivalent* to the value `x`. This overload participates in overload resolution only if the qualified-id `Compare::is_transparent` is valid and denotes a type, and neither `iterator` nor `const_iterator` is implicitly convertible from `K`. It allows calling this function without constructing an instance of `Key`.

{/* source:cpp-container-multiset-erase:0006 */}
References and iterators to the erased elements are invalidated. Other references and iterators are not affected.

{/* source:cpp-container-multiset-erase:0007 */}
The iterator `pos` must be valid and dereferenceable. Thus the [`end()`](/docs/cpp/library/container/multiset/end) iterator (which is valid, but is not dereferenceable) cannot be used as a value for `pos`.

### Parameters

{/* source:cpp-container-multiset-erase:0008 */}
<ParameterList>
  <Parameter name="pos">iterator to the element to remove</Parameter>
  <Parameter name="first, last">range of elements to remove</Parameter>
  <Parameter name="key">key value of the elements to remove</Parameter>
  <Parameter name="x">a value of any type that can be transparently compared with a key denoting the elements to remove</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-multiset-erase:0009 */}
- 1-3) Iterator following the last removed element.

{/* source:cpp-container-multiset-erase:0010 */}
- 4) Number of elements removed.

{/* source:cpp-container-multiset-erase:0011 */}
- 5) Number of elements removed.

### Exceptions

{/* source:cpp-container-multiset-erase:0012 */}
- 1-3) Throws nothing.

{/* source:cpp-container-multiset-erase:0013 */}
- 4,5) Any exceptions thrown by the `Compare` object.

### Complexity

{/* source:cpp-container-multiset-erase:0014 */}
Given an instance `c` of `multiset`:

{/* source:cpp-container-multiset-erase:0015 */}
- 1,2) Amortized constant

{/* source:cpp-container-multiset-erase:0016 */}
- 3) `log(c.size()) + std::distance(first, last)`

{/* source:cpp-container-multiset-erase:0017 */}
- 4) `log(c.size()) + c.count(key)`

{/* source:cpp-container-multiset-erase:0018 */}
- 5) `log(c.size()) + c.count(x)`

### Example

{/* source:cpp-container-multiset-erase:0020 */}
```cpp
#include <set>
#include <iostream>
 
int main()
{
    std::multiset<int> c = {1, 2, 3, 4, 1, 2, 3, 4};
 
    auto print = [&c]
    {
        std::cout << "c = { ";
        for (int n : c)
            std::cout << n << ' ';
        std::cout << "}\n";
    };
    print();
 
    std::cout << "Erase all odd numbers:\n";
    for (auto it = c.begin(); it != c.end();)
    {
        if (*it % 2 != 0)
            it = c.erase(it);
        else
            ++it;
    }
    print();
 
    std::cout << "Erase 1, erased count: " << c.erase(1) << '\n';
    std::cout << "Erase 2, erased count: " << c.erase(2) << '\n';
    std::cout << "Erase 2, erased count: " << c.erase(2) << '\n';
    print();
}
```

Output:

```text
c = { 1 1 2 2 3 3 4 4 }
Erase all odd numbers:
c = { 2 2 4 4 }
Erase 1, erased count: 0
Erase 2, erased count: 2
Erase 2, erased count: 0
c = { 4 4 }
```
