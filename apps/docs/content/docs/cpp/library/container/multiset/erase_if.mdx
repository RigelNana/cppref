{/* source:cpp-container-multiset-erase-if:0001 */}
Erases all elements that satisfy the predicate `pred` from `c`.

{/* source:cpp-container-multiset-erase-if:0002 */}
Equivalent to

{/* source:cpp-container-multiset-erase-if:0003 */}
```cpp
auto old_size = c.size();
for (auto first = c.begin(), last = c.end(); first != last;)
{
    if (pred(*first))
        first = c.erase(first);
    else
        ++first;
}
return old_size - c.size();
```

### Parameters

{/* source:cpp-container-multiset-erase-if:0004 */}
<ParameterList>
  <Parameter name="c">container from which to erase</Parameter>
  <Parameter name="pred">predicate that returns `true` if the element should be erased</Parameter>
</ParameterList>

### Return value

{/* source:cpp-container-multiset-erase-if:0005 */}
The number of erased elements.

### Complexity

{/* source:cpp-container-multiset-erase-if:0006 */}
Linear.

### Example

{/* source:cpp-container-multiset-erase-if:0007 */}
```cpp
#include <iostream>
#include <set>
 
void println(auto rem, auto const& container)
{
    std::cout << rem << '{';
    for (char sep[]{0, ' ', 0}; const auto& item : container)
        std::cout << sep << item, *sep = ',';
    std::cout << "}\n";
}
 
int main()
{
    std::multiset data{3, 3, 4, 5, 5, 6, 6, 7, 2, 1, 0};
    println("Original:\n", data);
 
    auto divisible_by_3 = [](auto const& x) { return (x % 3) == 0; };
 
    const auto count = std::erase_if(data, divisible_by_3);
 
    println("Erase all items divisible by 3:\n", data);
    std::cout << count << " items erased.\n";
}
```

Output:

```text
Original:
{0, 1, 2, 3, 3, 4, 5, 5, 6, 6, 7}
Erase all items divisible by 3:
{1, 2, 4, 5, 5, 7}
5 items erased.
```
