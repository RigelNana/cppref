### Parameters

{/* source:cpp-container-multiset-size:0002 */}
(none)

### Return value

{/* source:cpp-container-multiset-size:0003 */}
The number of elements in the container.

### Complexity

{/* source:cpp-container-multiset-size:0004 */}
Constant.

### Example

{/* source:cpp-container-multiset-size:0005 */}
```cpp
#include <cassert>
#include <set>
 
int main()
{
    std::multiset<int> nums{4, 2, 4, 2};
    assert(nums.size() == 4);
}
```
