{/* source:cpp-container-multiset-value-comp:0001 */}
Returns the function object that compares the values. It is the same as [`key_comp`](/docs/cpp/library/container/multiset/key_comp).

### Parameters

{/* source:cpp-container-multiset-value-comp:0002 */}
(none)

### Return value

{/* source:cpp-container-multiset-value-comp:0003 */}
The value comparison function object.

### Complexity

{/* source:cpp-container-multiset-value-comp:0004 */}
Constant.

### Example

{/* source:cpp-container-multiset-value-comp:0005 */}
```cpp
#include <iostream>
#include <set>
#include <utility>
 
// Example module 97 key compare function
struct ModCmp
{
    bool operator()(int lhs, int rhs) const
    {
        return (lhs % 97) < (rhs % 97);
    }
};
 
int main()
{
    std::multiset<int, ModCmp> cont{1, 2, 3, 4, 5};
 
    // Same behaviour as key_comp()
    auto comp_func = cont.value_comp();
 
    for (const int val{100}; const int key : cont)
    {
        const bool before = comp_func(key, val);
        const bool after = comp_func(val, key);
 
        std::cout << "Key (" << key << ") ";
        if (!before && !after)
            std::cout << "equivalent to key (" << val << ")\n";
        else if (before)
            std::cout << "goes before key (" << val << ")\n";
        else if (after)
            std::cout << "goes after key (" << val << ")\n";
        else
            std::unreachable();
    }
}
```

Output:

```text
Key (1) goes before key (100)
Key (2) goes before key (100)
Key (3) equivalent to key (100)
Key (4) goes after key (100)
Key (5) goes after key (100)
```
