{/* source:cpp-container-multiset-deduction-guides:0001 */}
1. 1-4) These [deduction guides](/docs/cpp/language/templates/ctad) are provided for `multiset` to allow deduction from an iterator range (overloads (1,3)) and [`std::initializer_list`](/docs/cpp/library/utility/initializer_list) (overloads (2,4)).

{/* source:cpp-container-multiset-deduction-guides:0002 */}
2. 5,6) These deduction guides are provided for `multiset` to allow deduction from a [`std::from_range_t`](/docs/cpp/library/ranges/from_range) tag and an [`input_range`](/docs/cpp/library/ranges/input_range).

{/* source:cpp-container-multiset-deduction-guides:0003 */}
These overloads participate in overload resolution only if `InputIt` satisfies [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator), `Alloc` satisfies [`Allocator`](/docs/cpp/library/named_req/Allocator), and `Comp` does not satisfy `Allocator`.

{/* source:cpp-container-multiset-deduction-guides:0004 */}
Note: the extent to which the library determines that a type does not satisfy [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator) is unspecified, except that as a minimum integral types do not qualify as input iterators. Likewise, the extent to which it determines that a type does not satisfy [`Allocator`](/docs/cpp/library/named_req/Allocator) is unspecified, except that as a minimum the member type `Alloc::value_type` must exist and the expression `std::declval<Alloc&>().allocate(std::size_t{})` must be well-formed when treated as an unevaluated operand.

#include <set>
 
int main()
{
