{/* source:cpp-container-multiset:0001 */}
`std::multiset` is an associative container that contains a sorted set of objects of type `Key`. Unlike `set`, multiple keys with equivalent values are allowed. Sorting is done using the key comparison function `Compare`. Search, insertion, and removal operations have logarithmic complexity.

{/* source:cpp-container-multiset:0002 */}
Everywhere the standard library uses the [`Compare`](/docs/cpp/library/named_req/Compare) requirements, equivalence is determined by using the equivalence relation as described on [`Compare`](/docs/cpp/library/named_req/Compare). In imprecise terms, two objects `a` and `b` are considered equivalent if neither compares less than the other: `!comp(a, b) && !comp(b, a)`.

{/* source:cpp-container-multiset:0003 */}
<Revision since="C++11">
The order of the elements that compare equivalent is the order of insertion and does not change.
</Revision>

{/* source:cpp-container-multiset:0004 */}
`std::multiset` meets the requirements of [`Container`](/docs/cpp/library/named_req/Container), [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer), [`AssociativeContainer`](/docs/cpp/library/named_req/AssociativeContainer) and [`ReversibleContainer`](/docs/cpp/library/named_req/ReversibleContainer).

### Notes

{/* source:cpp-container-multiset:0010 */}
The member types `iterator` and `const_iterator` may be aliases to the same type. This means defining a pair of function overloads using the two types as parameter types may violate the [`One Definition Rule`](/docs/cpp/language/basic_concepts/definition#One_Definition_Rule). Since `iterator` is convertible to `const_iterator`, a single function with a `const_iterator` as parameter type will work instead.
