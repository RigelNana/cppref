{/* source:cpp-container-multiset-multiset:0001 */}
Constructs new container from a variety of data sources and optionally using user supplied allocator `alloc` or comparison function object `comp`.

{/* source:cpp-container-multiset-multiset:0002 */}
1. 1-3) Constructs an empty container.

{/* source:cpp-container-multiset-multiset:0003 */}
2. 4,5) Constructs the container with the contents of the range [`first`, `last`).

{/* source:cpp-container-multiset-multiset:0004 */}
3. If [`first`, `last`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-container-multiset-multiset:0005 */}
4. 6,7) [Copy constructor](/docs/cpp/language/classes/copy_constructor). Constructs the container with the copy of the contents of `other`. If `alloc` is not provided, allocator is obtained by calling `std::allocator_traits<allocator_type>::select_on_container_copy_construction(other.get_allocator())`. During [class template argument deduction](/docs/cpp/language/templates/ctad), only the first argument contributes to the deduction of the container's `Allocator` template parameter.

{/* source:cpp-container-multiset-multiset:0006 */}
5. 8,9) [Move constructor](/docs/cpp/language/classes/move_constructor). Constructs the container with the contents of `other` using move semantics. If `alloc` is not provided, allocator is obtained by move-construction from the allocator belonging to `other`. During [class template argument deduction](/docs/cpp/language/templates/ctad), only the first argument contributes to the deduction of the container's `Allocator` template parameter.

{/* source:cpp-container-multiset-multiset:0007 */}
6. 10,11) [Initializer-list constructor](/docs/cpp/language/initialization/list_initialization). Constructs the container with the contents of the initializer list `init`.

{/* source:cpp-container-multiset-multiset:0008 */}
7. 12,13) Constructs the container with the contents of `rg`.

### Parameters

{/* source:cpp-container-multiset-multiset:0009 */}
<ParameterList>
  <Parameter name="alloc">allocator to use for all memory allocations of this container</Parameter>
  <Parameter name="comp">comparison function object to use for all comparisons of keys</Parameter>
  <Parameter name="first, last">the range to copy the elements from</Parameter>
  <Parameter name="other">another container to be used as source to initialize the elements of the container with</Parameter>
  <Parameter name="init">initializer list to initialize the elements of the container with</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range), that is, an [`input_range`](/docs/cpp/library/ranges/input_range) whose elements are convertible to [`value_type`](/docs/cpp/library/container/multiset#Member_types)</Parameter>
</ParameterList>

**Type requirements**

- `InputIt` must meet the requirements of [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator).
- `Compare` must meet the requirements of [`Compare`](/docs/cpp/library/named_req/Compare).
- `Allocator` must meet the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator).

### Complexity

{/* source:cpp-container-multiset-multiset:0010 */}
1. 1-3) Constant.

{/* source:cpp-container-multiset-multiset:0011 */}
2. 4,5) `N·log(N)` where `N` is `std::distance(first, last)` in general, linear in `N` if [`first`, `last`) is already sorted by `value_comp()`.

{/* source:cpp-container-multiset-multiset:0012 */}
3. 6,7) Linear in size of `other`.

{/* source:cpp-container-multiset-multiset:0013 */}
4. 8,9) Constant. If `alloc` is given and `alloc != other.get_allocator()`, then linear.

{/* source:cpp-container-multiset-multiset:0014 */}
5. 10,11) `N·log(N)` where `N` is `init.size()` in general, linear in `N` if `init` is already sorted by `value_comp()`.

{/* source:cpp-container-multiset-multiset:0015 */}
6. 12,13) `N·log(N)` where `N` is `ranges::distance(rg)` in general, linear in `N` if `rg` is already sorted by `value_comp()`.

### Exceptions

{/* source:cpp-container-multiset-multiset:0016 */}
Calls to `Allocator::allocate` may throw.

### Notes

{/* source:cpp-container-multiset-multiset:0017 */}
After container move construction (overload (8,9)), references, pointers, and iterators (other than the end iterator) to `other` remain valid, but refer to elements that are now in `*this`. The current standard makes this guarantee via the blanket statement in [[container.reqmts]/67](https://eel.is/c++draft/container.reqmts#67), and a more direct guarantee is under consideration via [LWG issue 2321](https://cplusplus.github.io/LWG/issue2321).

{/* source:cpp-container-multiset-multiset:0018 */}
Although not formally required until C++23, some implementations has already put the template parameter `Allocator` into [non-deduced contexts](/docs/cpp/language/templates/template_argument_deduction#Non-deduced_contexts) in earlier modes.

### Example

{/* source:cpp-container-multiset-multiset:0020 */}
```cpp
#include <iostream>
#include <set>
#include <string_view>
 
template <typename T>
void println(const std::string_view name, const std::multiset<T>& ms)
{
    std::cout << name << ": ";
    for (const auto& element : ms)
        std::cout << element << ' ';
    std::cout << '\n';
}
 
int main()
{
    // (1) Default constructor
    std::multiset<int> a;
    a.insert(4);
    a.insert(3);
    a.insert(2);
    a.insert(1);
    println("a", a);
 
    // (4) Range constructor
    std::multiset<int> b(a.begin(), a.find(3));
    println("b", b);
 
    // (6) Copy constructor
    std::multiset<int> c(a);
    println("c", c);
 
    // (8) Move constructor
    std::multiset<int> d(std::move(a));
    println("d", d);
 
    // (10) Initializer list constructor
    std::multiset<int> e{3, 2, 1, 2, 4, 7, 3};
    println("e", e);
 
    // (12) Range constructor
    const auto w = {"α", "β", "γ", "δ", "δ", "γ", "β", "α"};
#if __cpp_lib_containers_ranges
    std::multiset<std::string> f(std::from_range, w); // overload (12)
#else
    std::multiset<std::string> f(w.begin(), w.end()); // fallback to (4)
#endif
    println("f", f);
}
```

Output:

```text
a: 1 2 3 4
b: 1 2
c: 1 2 3 4
d: 1 2 3 4
e: 1 2 2 3 3 4 7
f: α α β β γ γ δ δ
```
