    1. <InlineRevision since="C++11" /> Returns an iterator to the element following the last element of the `multiset`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-container-multiset-end:0002 */}
This element acts as a placeholder; attempting to access it results in undefined behavior.

### Parameters

{/* source:cpp-container-multiset-end:0003 */}
(none)

### Return value

{/* source:cpp-container-multiset-end:0004 */}
Iterator to the element following the last element.

### Complexity

{/* source:cpp-container-multiset-end:0005 */}
Constant.

### Notes

{/* source:cpp-container-multiset-end:0006 */}
Because both `iterator` and `const_iterator` are constant iterators (and may in fact be the same type), it is not possible to mutate the elements of the container through an iterator returned by any of these member functions.

{/* source:cpp-container-multiset-end:0007 */}
`libc++` backports `cend()` to C++98 mode.

### Example

{/* source:cpp-container-multiset-end:0008 */}
```cpp
#include <iostream>
#include <iterator>
#include <set>
#include <string>

int main()
{
    const std::multiset<std::string> words =
    {
        "some", "not", "sorted", "words",
        "will", "come", "out", "sorted",
    };

    for (auto it = words.begin(); it != words.end(); )
    {
        auto count = words.count(*it);
        std::cout << *it << ":\t" << count << '\n';
        std::advance(it, count); // all count elements have equivalent keys
    }
}
```

Output:

```text
come:	1
not:	1
out:	1
some:	1
sorted:	2
will:	1
words:	1
```
