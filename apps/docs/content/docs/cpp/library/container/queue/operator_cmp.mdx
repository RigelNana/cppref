{/* source:cpp-container-queue-operator-cmp:0001 */}
Compares the contents of the underlying containers of two container adaptors. The comparison is done by applying the corresponding operator to the underlying containers.

### Parameters

{/* source:cpp-container-queue-operator-cmp:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">container adaptors whose contents to compare</Parameter>
</ParameterList>

- `T` must meet the requirements of [`EqualityComparable`](/docs/cpp/library/named_req/EqualityComparable).

### Return value

{/* source:cpp-container-queue-operator-cmp:0003 */}
1-6) `true` if the corresponding comparison yields `true`, `false` otherwise.

{/* source:cpp-container-queue-operator-cmp:0004 */}
7) Result of three-way comparison on underlying containers.

### Complexity

{/* source:cpp-container-queue-operator-cmp:0005 */}
Linear in the size of the container.
