{/* source:cpp-container-queue-back:0001 */}
Returns reference to the last element in the queue. This is the most recently pushed element. Effectively calls `c.back()`.

### Parameters

{/* source:cpp-container-queue-back:0002 */}
(none)

### Return value

{/* source:cpp-container-queue-back:0003 */}
Reference to the last element.

### Complexity

{/* source:cpp-container-queue-back:0004 */}
Constant.
