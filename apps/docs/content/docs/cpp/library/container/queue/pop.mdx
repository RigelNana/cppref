{/* source:cpp-container-queue-pop:0001 */}
Removes an element from the front of the queue. Effectively calls `c.pop_front()`.

### Parameters

{/* source:cpp-container-queue-pop:0002 */}
(none)

### Return value

{/* source:cpp-container-queue-pop:0003 */}
(none)

### Complexity

{/* source:cpp-container-queue-pop:0004 */}
Equal to the complexity of `Container::pop_front`.
