Returns reference to the first element in the queue. This element will be the first element to be removed on a call to [`pop()`](/docs/cpp/library/container/queue/pop). Effectively calls `c.front()`.

### Parameters

{/* source:cpp-container-queue-front:0002 */}
(none)

### Return value

{/* source:cpp-container-queue-front:0003 */}
Reference to the first element.

### Complexity

{/* source:cpp-container-queue-front:0004 */}
Constant.
