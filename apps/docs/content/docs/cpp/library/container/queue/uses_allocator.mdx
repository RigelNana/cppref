{/* source:cpp-container-queue-uses-allocator:0001 */}
Provides a transparent specialization of the [`std::uses_allocator`](/docs/cpp/library/memory/uses_allocator) type trait for `std::queue`: the container adaptor uses allocator if and only if the underlying container does.
