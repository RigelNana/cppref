{/* source:cpp-container-queue-formatter:0001 */}
The template specialization of [`std::formatter`](/docs/cpp/library/text/format/formatter) for the container adaptor type [`std::queue`](/docs/cpp/library/container/queue) allows users to convert the underlying container to its textual representation as a collection of elements using [formatting functions](/docs/cpp/library/text/format).

{/* source:cpp-container-queue-formatter:0002 */}
The specialization is enabled if `std::formattable<Container, CharT>` is `true`.
