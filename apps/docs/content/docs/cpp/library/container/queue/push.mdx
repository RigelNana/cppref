{/* source:cpp-container-queue-push:0001 */}
Pushes the given element `value` to the end of the queue.

{/* source:cpp-container-queue-push:0002 */}
1. Equivalent to: `c.push_back(value)`.

{/* source:cpp-container-queue-push:0003 */}
2. Equivalent to: `c.push_back(std::move(value))`.

### Parameters

{/* source:cpp-container-queue-push:0004 */}
<ParameterList>

</ParameterList>

### Return value

{/* source:cpp-container-queue-push:0005 */}
(none)

### Complexity

{/* source:cpp-container-queue-push:0006 */}
Equal to the complexity of `Container::push_back`.
