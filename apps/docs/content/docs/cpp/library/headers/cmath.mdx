## Synopsis

{/* source:cpp-header-cmath:0003 */}

For each function with at least one parameter of type `/* floating-point-type */`, an overload for each cv-unqualified floating-point type is provided where all uses of `/* floating-point-type */` in the function signature are replaced with that floating-point type.

{/* source:cpp-header-cmath:0004 */}

For each function with at least one parameter of type `/* floating-point-type */` other than `std::abs`, additional overloads are provided to ensure that, if every argument corresponding to a `/* floating-point-type */` parameter has arithmetic type, then every such argument is effectively cast to the floating-point type with the greatest [floating-point conversion rank](/docs/cpp/language/expressions/usual_arithmetic_conversions#Floating-point_conversion_rank) and greatest [floating-point conversion subrank](/docs/cpp/language/expressions/usual_arithmetic_conversions#Floating-point_conversion_subrank) among the types of all such arguments, where arguments of integer type are considered to have the same floating-point conversion rank as `double`. If no such floating-point type with the greatest rank and subrank exists, then overload resolution does not result in a usable candidate from the provided overloads.

{/* source:cpp-header-cmath:0005 */}
