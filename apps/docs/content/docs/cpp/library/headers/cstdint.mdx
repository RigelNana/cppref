This header was originally in the C standard library as [`<stdint.h>`](/docs/c/library/types/integer).

{/* source:cpp-header-cstdint:0001 */}
This header is part of the [`type support`](/docs/cpp/library/utility/types) library, providing [`fixed width integer types`](/docs/cpp/library/utility/types/integer) and part of [`C numeric limits interface`](/docs/cpp/library/utility/types/climits).
