This header was originally in the C standard library as [`<stdalign.h>`](/docs/c/library/types).

{/* source:cpp-header-cstdalign:0001 */}
C compatibility header. `alignas` and `alignof` are [`keywords`](/docs/cpp/language/keywords) in C++, but they were not keywords in C until C23.

{/* source:cpp-header-cstdalign:0002 */}

## Notes

`<cstdalign>` is deprecated in C++17 and removed in C++20. Corresponding [`<stdalign.h>`](/docs/c/library/types) is still available in C++20.
