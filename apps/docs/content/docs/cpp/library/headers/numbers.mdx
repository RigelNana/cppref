This header is part of the [`numeric`](/docs/cpp/library/numeric) library.

## Mathematical constants (since C++20)

{/* source:cpp-header-numbers:0001 */}
The header **`<numbers>`** provides several mathematical constants, such as [`std::numbers::pi`](/docs/cpp/library/numeric/constants) or [`std::numbers::sqrt2`](/docs/cpp/library/numeric/constants)
