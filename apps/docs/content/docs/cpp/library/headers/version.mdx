{/* source:cpp-header-version:0000 */}
This header is part of the [`language support`](/docs/cpp/library/utility#Language_support) library.

{/* source:cpp-header-version:0001 */}
This header supplies implementation-dependent information about the standard library (such as implementation-specific library version macros).

{/* source:cpp-header-version:0002 */}
Including `<version>` also defines all [`library feature-test macros`](/docs/cpp/library/feature_test#Library_features).

## Notes

{/* source:cpp-header-version:0003 */}
Prior to C++20, including [`<ciso646>`](/docs/cpp/library/headers/ciso646) is sometimes used for this purpose.
