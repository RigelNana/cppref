This header was originally in the C standard library as [`<wchar.h>`](/docs/c/library/string/wide).

{/* source:cpp-header-cwchar:0001 */}
This header is part of the null-terminated [`wide`](/docs/cpp/library/text/wide) and [`multibyte`](/docs/cpp/library/text/multibyte) strings libraries. It also provides some [`C-style I/O`](/docs/cpp/library/io/c) functions and conversion from [`C-style Date`](/docs/cpp/library/chrono/c).
