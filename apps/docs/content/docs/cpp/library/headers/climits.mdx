This header was originally in the C standard library as [`<limits.h>`](/docs/c/library/types/limits).

{/* source:cpp-header-climits:0001 */}

This header is part of the [type support](/docs/cpp/library/utility/types) library, in particular it's part of the [C numeric limits interface](/docs/cpp/library/utility/types/climits).
