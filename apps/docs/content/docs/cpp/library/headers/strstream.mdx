## Notes

{/* source:cpp-header-strstream:0002 */}
`<strstream>` is deprecated in C++98 and removed in C++26 (see [`P2867R1`](https://wg21.link/P2867R1)).

{/* source:cpp-header-strstream:0003 */}
The reason for removal is that C++20 and C++23 provide superior replacement facilities, such as the ability to move strings efficiently out of [`std::stringstreams`](/docs/cpp/library/io/basic_stringstream) (since C++20, see [`P0408R7`](https://wg21.link/P0408R7)), and the [`<spanstream>`](/docs/cpp/library/headers/spanstream) library (since C++23, see [`P0448R4`](https://wg21.link/P0448R4)).
