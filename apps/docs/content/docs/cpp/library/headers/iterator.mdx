## Concepts
#### Iterator concepts
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a type is indirectly readable by applying operator `*` (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_writable`](/docs/cpp/library/iterator/indirectly_writable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a value can be written to an iterator's referenced object (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`weakly_incrementable`](/docs/cpp/library/iterator/weakly_incrementable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a [`semiregular`](/docs/cpp/library/concepts/semiregular) type can be incremented with pre- and post-increment operators (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`incrementable`](/docs/cpp/library/iterator/incrementable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that the increment operation on a [`weakly_incrementable`](/docs/cpp/library/iterator/weakly_incrementable) type is [`equality-preserving`](/docs/cpp/library/concepts#Equality_preservation) and that the type is [`equality_comparable`](/docs/cpp/library/concepts/equality_comparable) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`input_or_output_iterator`](/docs/cpp/library/iterator/input_or_output_iterator) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that objects of a type can be incremented and dereferenced (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`sentinel_for`](/docs/cpp/library/iterator/sentinel_for) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies a type is a sentinel for an [`input_or_output_iterator`](/docs/cpp/library/iterator/input_or_output_iterator) type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`sized_sentinel_for`](/docs/cpp/library/iterator/sized_sentinel_for) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that the `-` operator can be applied to an iterator and a sentinel to calculate their difference in constant time (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`input_iterator`](/docs/cpp/library/iterator/input_iterator) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a type is an input iterator, that is, its referenced values can be read and it can be both pre- and post-incremented (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`output_iterator`](/docs/cpp/library/iterator/output_iterator) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a type is an output iterator for a given value type, that is, values of that type can be written to it and it can be both pre- and post-incremented (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`forward_iterator`](/docs/cpp/library/iterator/forward_iterator) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that an [`input_iterator`](/docs/cpp/library/iterator/input_iterator) is a forward iterator, supporting equality comparison and multi-pass (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`bidirectional_iterator`](/docs/cpp/library/iterator/bidirectional_iterator) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a [`forward_iterator`](/docs/cpp/library/iterator/forward_iterator) is a bidirectional iterator, supporting movement backwards (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`random_access_iterator`](/docs/cpp/library/iterator/random_access_iterator) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a [`bidirectional_iterator`](/docs/cpp/library/iterator/bidirectional_iterator) is a random-access iterator, supporting advancement in constant time and subscripting (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a [`random_access_iterator`](/docs/cpp/library/iterator/random_access_iterator) is a contiguous iterator, referring to elements that are contiguous in memory (concept)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
#### Indirect callable concepts
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_unary_invocable, indirectly_regular_unary_invocable`](/docs/cpp/library/iterator/indirectly_unary_invocable) <InlineRevision since="C++20" /><InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a callable type can be invoked with the result of dereferencing an [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirect_unary_predicate`](/docs/cpp/library/iterator/indirect_unary_predicate) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a callable type, when invoked with the result of dereferencing an [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) type, satisfies [`predicate`](/docs/cpp/library/concepts/predicate) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirect_binary_predicate`](/docs/cpp/library/iterator/indirect_binary_predicate) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a callable type, when invoked with the result of dereferencing two [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) types, satisfies [`predicate`](/docs/cpp/library/concepts/predicate) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirect_equivalence_relation`](/docs/cpp/library/iterator/indirect_equivalence_relation) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a callable type, when invoked with the result of dereferencing two [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) types, satisfies [`equivalence_relation`](/docs/cpp/library/concepts/equivalence_relation) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirect_strict_weak_order`](/docs/cpp/library/iterator/indirect_strict_weak_order) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that a callable type, when invoked with the result of dereferencing two [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) types, satisfies [`strict_weak_order`](/docs/cpp/library/concepts/strict_weak_order) (concept)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
#### Common algorithm requirements
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_movable`](/docs/cpp/library/iterator/indirectly_movable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that values may be moved from an [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) type to an [`indirectly_writable`](/docs/cpp/library/iterator/indirectly_writable) type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_movable_storable`](/docs/cpp/library/iterator/indirectly_movable_storable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that values may be moved from an [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) type to an [`indirectly_writable`](/docs/cpp/library/iterator/indirectly_writable) type and that the move may be performed via an intermediate object (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_copyable`](/docs/cpp/library/iterator/indirectly_copyable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that values may be copied from an [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) type to an [`indirectly_writable`](/docs/cpp/library/iterator/indirectly_writable) type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_copyable_storable`](/docs/cpp/library/iterator/indirectly_copyable_storable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that values may be copied from an [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) type to an [`indirectly_writable`](/docs/cpp/library/iterator/indirectly_writable) type and that the copy may be performed via an intermediate object (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_swappable`](/docs/cpp/library/iterator/indirectly_swappable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that the values referenced by two [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) types can be swapped (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`indirectly_comparable`](/docs/cpp/library/iterator/indirectly_comparable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies that the values referenced by two [`indirectly_readable`](/docs/cpp/library/iterator/indirectly_readable) types can be compared (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`permutable`](/docs/cpp/library/iterator/permutable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies the common requirements of algorithms that reorder elements in place (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`mergeable`](/docs/cpp/library/iterator/mergeable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies the requirements of algorithms that merge sorted sequences into an output sequence by copying elements (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`sortable`](/docs/cpp/library/iterator/sortable) <InlineRevision since="C++20" /></DescriptionTerm>
    <DescriptionBody>specifies the common requirements of algorithms that permute sequences into ordered sequences (concept)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
