{/* source:cpp-header-ciso646:0000 */}

This header was originally in the C standard library as [`<iso646.h>`](/docs/c/language/operator_alternative).

{/* source:cpp-header-ciso646:0001 */}

Compatibility header, in C defines [alternative operator representations](/docs/cpp/language/expressions/operator_alternative) which are keywords in C++.

{/* source:cpp-header-ciso646:0002 */}

This means that in a conforming implementation, including this header has no effect.

## Notes

{/* source:cpp-header-ciso646:0003 */}

In old or nonconforming compilers, using the [alternative operator representations](/docs/cpp/language/expressions/operator_alternative) may still require including this header.

{/* source:cpp-header-ciso646:0004 */}

`<ciso646>` is removed in C++20. Corresponding `<iso646.h>` is still available in C++20.

{/* source:cpp-header-ciso646:0005 */}

Prior to C++20, including `<ciso646>` was sometimes used as a technique for obtaining definitions of implementation-specific library version macros without causing other effects. As of C++20, the header [`<version>`](/docs/cpp/library/headers/version) was added for this purpose.

{/* source:cpp-header-ciso646:0006 */}

```cpp
#include <ciso646>
#ifdef _LIBCPP_VERSION
#error Using LLVM libc++
#elif __GLIBCXX__ // Note: only version 6.1 or newer define this in ciso646
#error Using GNU libstdc++
#elif _CPPLIB_VER // Note: used by Visual Studio
#error Using Microsoft STL
#else
#error Using an unknown standard library
#endif
```

Possible output:

```text
main.cpp:7:2: error: Using Microsoft STL
#error Using Microsoft STL
 ^
1 error generated.
```
