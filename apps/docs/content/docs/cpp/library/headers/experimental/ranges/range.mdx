### Range concepts

Defined in namespace `std::experimental::ranges`

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`Range`](/docs/cpp/library/experimental/ranges/range/Range)</DescriptionTerm>
    <DescriptionBody>specifies that a type is a range, that is, it provides a `begin` iterator and an `end` sentinel (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`SizedRange`](/docs/cpp/library/experimental/ranges/range/SizedRange)</DescriptionTerm>
    <DescriptionBody>specifies that a range knows its size in constant time (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`View`](/docs/cpp/library/experimental/ranges/range/View)</DescriptionTerm>
    <DescriptionBody>specifies that a range is a view, that is, it has constant time copy/move/assignment (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`BoundedRange`](/docs/cpp/library/experimental/ranges/range/BoundedRange)</DescriptionTerm>
    <DescriptionBody>specifies that a range has identical iterator and sentinel types (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`InputRange`](/docs/cpp/library/experimental/ranges/range/InputRange)</DescriptionTerm>
    <DescriptionBody>specifies a range whose iterator type satisfies [`InputIterator`](/docs/cpp/library/experimental/ranges/iterator/InputIterator) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`OutputRange`](/docs/cpp/library/experimental/ranges/range/OutputRange)</DescriptionTerm>
    <DescriptionBody>specifies a range whose iterator type satisfies [`OutputIterator`](/docs/cpp/library/experimental/ranges/iterator/OutputIterator) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`ForwardRange`](/docs/cpp/library/experimental/ranges/range/ForwardRange)</DescriptionTerm>
    <DescriptionBody>specifies a range whose iterator type satisfies [`ForwardIterator`](/docs/cpp/library/experimental/ranges/iterator/ForwardIterator) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`BidirectionalRange`](/docs/cpp/library/experimental/ranges/range/BidirectionalRange)</DescriptionTerm>
    <DescriptionBody>specifies a range whose iterator type satisfies [`BidirectionalIterator`](/docs/cpp/library/experimental/ranges/iterator/BidirectionalIterator) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`RandomAccessRange`](/docs/cpp/library/experimental/ranges/range/RandomAccessRange)</DescriptionTerm>
    <DescriptionBody>specifies a range whose iterator type satisfies [`RandomAccessIterator`](/docs/cpp/library/experimental/ranges/iterator/RandomAccessIterator) (concept)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Range access

Defined in namespace `std::experimental::ranges`

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`begin`, `cbegin`](https://en.cppreference.com/mwiki/index.php?title=cpp/experimental/ranges/range/begin&action=edit&redlink=1)</DescriptionTerm>
    <DescriptionBody>returns an iterator to the beginning of a range (customization point object)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`end`, `cend`](https://en.cppreference.com/mwiki/index.php?title=cpp/experimental/ranges/range/end&action=edit&redlink=1)</DescriptionTerm>
    <DescriptionBody>returns an iterator to the end of a range (customization point object)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`rbegin`, `crbegin`](https://en.cppreference.com/mwiki/index.php?title=cpp/experimental/ranges/range/rbegin&action=edit&redlink=1)</DescriptionTerm>
    <DescriptionBody>returns a reverse iterator to a range (customization point object)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`rend`, `crend`](https://en.cppreference.com/mwiki/index.php?title=cpp/experimental/ranges/range/rend&action=edit&redlink=1)</DescriptionTerm>
    <DescriptionBody>returns a reverse end iterator to a range (customization point object)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Range primitives

Defined in namespace `std::experimental::ranges`

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`size`](https://en.cppreference.com/mwiki/index.php?title=cpp/experimental/ranges/range/size&action=edit&redlink=1)</DescriptionTerm>

  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`empty`](https://en.cppreference.com/mwiki/index.php?title=cpp/experimental/ranges/range/empty&action=edit&redlink=1)</DescriptionTerm>

  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`data`, `cdata`](https://en.cppreference.com/mwiki/index.php?title=cpp/experimental/ranges/range/data&action=edit&redlink=1)</DescriptionTerm>
    <DescriptionBody>obtains a pointer to the beginning of a contiguous range (customization point object)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`iterator_t`, `sentinel_t`](/docs/cpp/library/experimental/ranges/range/iterator_t)</DescriptionTerm>
    <DescriptionBody>obtains the iterator and sentinel types of a range (alias template)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
