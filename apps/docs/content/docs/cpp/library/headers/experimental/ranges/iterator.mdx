#### Iterator concepts

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`Readable`](/docs/cpp/library/experimental/ranges/iterator/Readable)</DescriptionTerm>
    <DescriptionBody>specifies that a type is readable by applying operator `*` (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Writable`](/docs/cpp/library/experimental/ranges/iterator/Writable)</DescriptionTerm>
    <DescriptionBody>specifies that a value can be written to an iterator's referenced object (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`WeaklyIncrementable`](/docs/cpp/library/experimental/ranges/iterator/WeaklyIncrementable)</DescriptionTerm>
    <DescriptionBody>specifies that a [`Semiregular`](/docs/cpp/library/experimental/ranges/concepts/Semiregular) type can be incremented with pre- and post-increment operators (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Incrementable`](/docs/cpp/library/experimental/ranges/iterator/Incrementable)</DescriptionTerm>
    <DescriptionBody>specifies that the increment operation on a [`WeaklyIncrementable`](/docs/cpp/library/experimental/ranges/iterator/WeaklyIncrementable) type is equality-preserving and that the type is [`EqualityComparable`](/docs/cpp/library/experimental/ranges/concepts/EqualityComparable) (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Iterator`](/docs/cpp/library/experimental/ranges/iterator/Iterator)</DescriptionTerm>
    <DescriptionBody>specifies that objects of a type can be incremented and dereferenced (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Sentinel`](/docs/cpp/library/experimental/ranges/iterator/Sentinel)</DescriptionTerm>
    <DescriptionBody>specifies that objects of a type is a sentinel for an [`Iterator`](/docs/cpp/library/experimental/ranges/iterator/Iterator) type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`SizedSentinel`](/docs/cpp/library/experimental/ranges/iterator/SizedSentinel)</DescriptionTerm>
    <DescriptionBody>specifies that the `-` operator can be applied to an iterator and a sentinel to calculate their difference in constant time (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`InputIterator`](/docs/cpp/library/experimental/ranges/iterator/InputIterator)</DescriptionTerm>
    <DescriptionBody>specifies that a type is an input iterator, that is, its referenced values can be read and it can be both pre- and post-incremented (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`OutputIterator`](/docs/cpp/library/experimental/ranges/iterator/OutputIterator)</DescriptionTerm>
    <DescriptionBody>specifies that a type is an output iterator for a given value type, that is, values of that type can be written to it and it can be both pre- and post-incremented (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`ForwardIterator`](/docs/cpp/library/experimental/ranges/iterator/ForwardIterator)</DescriptionTerm>
    <DescriptionBody>specifies that an [`InputIterator`](/docs/cpp/library/experimental/ranges/iterator/InputIterator) is a forward iterator, supporting equality comparison and multi-pass (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`BidirectionalIterator`](/docs/cpp/library/experimental/ranges/iterator/BidirectionalIterator)</DescriptionTerm>
    <DescriptionBody>specifies that a [`ForwardIterator`](/docs/cpp/library/experimental/ranges/iterator/ForwardIterator) is a bidirectional iterator, supporting movement backwards (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`RandomAccessIterator`](/docs/cpp/library/experimental/ranges/iterator/RandomAccessIterator)</DescriptionTerm>
    <DescriptionBody>specifies that a [`BidirectionalIterator`](/docs/cpp/library/experimental/ranges/iterator/BidirectionalIterator) is a random-access iterator, supporting advancement in constant time and subscripting (concept)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
