### Core language concepts

Defined in namespace `std::experimental::ranges`

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`Same`](/docs/cpp/library/experimental/ranges/concepts/Same)</DescriptionTerm>
    <DescriptionBody>specifies that a type is the same as another type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`DerivedFrom`](/docs/cpp/library/experimental/ranges/concepts/DerivedFrom)</DescriptionTerm>
    <DescriptionBody>specifies that a type is derived from another type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`ConvertibleTo`](/docs/cpp/library/experimental/ranges/concepts/ConvertibleTo)</DescriptionTerm>
    <DescriptionBody>specifies that a type is implicitly convertible to another type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`CommonReference`](/docs/cpp/library/experimental/ranges/concepts/CommonReference)</DescriptionTerm>
    <DescriptionBody>specifies that two types share a common reference type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Common`](/docs/cpp/library/experimental/ranges/concepts/Common)</DescriptionTerm>
    <DescriptionBody>specifies that two types share a common type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Integral`](/docs/cpp/library/experimental/ranges/concepts/Integral)</DescriptionTerm>
    <DescriptionBody>specifies that a type is an integral type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`SignedIntegral`](/docs/cpp/library/experimental/ranges/concepts/SignedIntegral)</DescriptionTerm>

  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`UnsignedIntegral`](/docs/cpp/library/experimental/ranges/concepts/UnsignedIntegral)</DescriptionTerm>

  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Assignable`](/docs/cpp/library/experimental/ranges/concepts/Assignable)</DescriptionTerm>
    <DescriptionBody>specifies that a type is assignable from another type (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Swappable`, `SwappableWith`](/docs/cpp/library/experimental/ranges/concepts/Swappable)</DescriptionTerm>

  </DescriptionItem>

### Comparison concepts

Defined in namespace `std::experimental::ranges`

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`Boolean`](/docs/cpp/library/experimental/ranges/concepts/Boolean)</DescriptionTerm>
    <DescriptionBody>specifies that a type can be used in Boolean contexts (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`WeaklyEqualityComparableWith`](/docs/cpp/library/experimental/ranges/concepts/WeaklyEqualityComparableWith)</DescriptionTerm>
    <DescriptionBody>specifies that two types can be compared for equality using operators `==` and `!=` (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`EqualityComparable`, `EqualityComparableWith`](/docs/cpp/library/experimental/ranges/concepts/EqualityComparable)</DescriptionTerm>
    <DescriptionBody>specifies that operator `==` is an equivalence relation (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`StrictTotallyOrdered`, `StrictTotallyOrderedWith`](/docs/cpp/library/experimental/ranges/concepts/StrictTotallyOrdered)</DescriptionTerm>
    <DescriptionBody>specifies that the comparison operators on the type yield a total order (concept)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Object concepts

Defined in namespace `std::experimental::ranges`

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`Destructible`](/docs/cpp/library/experimental/ranges/concepts/Destructible)</DescriptionTerm>
    <DescriptionBody>specifies that an object of the type can be destroyed (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Constructible`](/docs/cpp/library/experimental/ranges/concepts/Constructible)</DescriptionTerm>
    <DescriptionBody>specifies that a variable of the type can be constructed from or bound to a set of argument types (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`DefaultConstructible`](/docs/cpp/library/experimental/ranges/concepts/DefaultConstructible)</DescriptionTerm>
    <DescriptionBody>specifies that an object of a type can be default constructed (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`MoveConstructible`](/docs/cpp/library/experimental/ranges/concepts/MoveConstructible)</DescriptionTerm>
    <DescriptionBody>specifies that an object of a type can be move constructed (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`CopyConstructible`](/docs/cpp/library/experimental/ranges/concepts/CopyConstructible)</DescriptionTerm>
    <DescriptionBody>specifies that an object of a type can be copy constructed and move constructed (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Movable`](/docs/cpp/library/experimental/ranges/concepts/Movable)</DescriptionTerm>
    <DescriptionBody>specifies that an object of a type can be moved and swapped (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Copyable`](/docs/cpp/library/experimental/ranges/concepts/Copyable)</DescriptionTerm>
    <DescriptionBody>specifies that an object of a type can be copied, moved, and swapped (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Semiregular`](/docs/cpp/library/experimental/ranges/concepts/Semiregular)</DescriptionTerm>
    <DescriptionBody>specifies that an object of a type can be copied, moved, swapped, and default constructed (concept)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`Regular`](/docs/cpp/library/experimental/ranges/concepts/Regular)</DescriptionTerm>
    <DescriptionBody>specifies that a type is regular, that is, it is both [`Semiregular`](/docs/cpp/library/experimental/ranges/concepts/Semiregular) and [`EqualityComparable`](/docs/cpp/library/experimental/ranges/concepts/EqualityComparable) (concept)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
