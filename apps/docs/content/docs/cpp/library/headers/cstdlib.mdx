This header was originally in the C standard library as [`<stdlib.h>`](/docs/c/library/program).

{/* source:cpp-header-cstdlib:0001 */}
This header provides miscellaneous utilities. Symbols defined here are used by several library components.

{/* source:cpp-header-cstdlib:0002 */}
