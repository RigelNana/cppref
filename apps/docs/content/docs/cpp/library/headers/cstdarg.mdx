This header was originally in the C standard library as [`<stdarg.h>`](/docs/c/library/variadic).

{/* source:cpp-header-cstdarg:0001 */}
This header provides support for [`C-style variadic functions`](/docs/cpp/library/utility/variadic), while the [`C definition`](/docs/c/language/expressions/conversion#Default_argument_promotions) of "default argument promotions" is replaced with the [`C++ definition`](/docs/cpp/language/functions/variadic_arguments#Default_conversions).

{/* source:cpp-header-cstdarg:0002 */}
