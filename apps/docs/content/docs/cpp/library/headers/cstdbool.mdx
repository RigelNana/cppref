This header was originally in the C standard library as [`<stdbool.h>`](/docs/c/library/types).

{/* source:cpp-header-cstdbool:0001 */}
Compatibility header. `true`, `false` and `bool` are [`keywords`](/docs/cpp/language/keywords) in C++, but they were not keywords in C until C23.

{/* source:cpp-header-cstdbool:0002 */}

  </DescriptionItem>
</DescriptionList>

{/* source:cpp-header-cstdbool:0003 */}
## Notes

`<cstdbool>` is deprecated in C++17 and removed in C++20. Corresponding `<stdbool.h>` is still available in C++20.
