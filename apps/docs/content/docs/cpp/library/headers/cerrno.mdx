## Notes

{/* source:cpp-header-cerrno:0003 */}

Although the header `<cerrno>` is based on the C standard library header [`<errno.h>`](/docs/c/library/error), the majority of the macros defined by `<cerrno>` were adopted by C++ from the POSIX standard, rather than the C standard library.
