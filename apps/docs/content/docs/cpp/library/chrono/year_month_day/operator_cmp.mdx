{/* source:cpp-chrono-year-month-day-operator-cmp:0001 */}
Compares the two `year_month_day` values `x` and `y`. This is a lexicographical comparison: the [`year()`](/docs/cpp/library/chrono/year_month_day/accessors) is compared first, then [`month()`](/docs/cpp/library/chrono/year_month_day/accessors), then [`day()`](/docs/cpp/library/chrono/year_month_day/accessors).

{/* source:cpp-chrono-year-month-day-operator-cmp:0002 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [`synthesized`](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-year-month-day-operator-cmp:0003 */}
1. `x.year() == y.year() && x.month() == y.month() && x.day() == y.day()`

{/* source:cpp-chrono-year-month-day-operator-cmp:0004 */}
2. If `x.year() <=> y.year != 0`, `x.year() <=> y.year`; otherwise if `x.month() <=> y.month() != 0`, `x.month() <=> y.month()`; otherwise `x.day() <=> y.day()`.

## Notes

{/* source:cpp-chrono-year-month-day-operator-cmp:0005 */}
If both `x` and `y` represent valid dates (`x.ok() && y.ok() == true`), the result of the lexicographical comparison is consistent with the calendar order.

## Example

{/* source:cpp-chrono-year-month-day-operator-cmp:0006 */}
```cpp
#include <chrono>

int main()
{
    constexpr auto ymd1{std::chrono::day(13)/7/1337};
    constexpr auto ymd2{std::chrono::year(1337)/7/13};
    static_assert(ymd1 == ymd2);
    static_assert(ymd1 <= ymd2);
    static_assert(ymd1 >= ymd2);
    static_assert(ymd1 <=> ymd2 == 0);
}
```
