{/* source:cpp-chrono-year-month-day-operator-ltlt:0001 */}
Outputs a textual representation of `ymd` into the stream `os`. This first forms a `std::basic_string<CharT> s` consisting of a textual representation of the date in the format `yyyy-mm-dd` (same as the one output by [`formatter`](/docs/cpp/library/chrono/year_month_day/formatter) with the `%F` specifier). Then, if `!ymd.ok()`, appends `" is not a valid date"` to `s`. Inserts `s` into `os`.

{/* source:cpp-chrono-year-month-day-operator-ltlt:0002 */}
Equivalent to

{/* source:cpp-chrono-year-month-day-operator-ltlt:0003 */}
```cpp
return os << (ymd.ok() ?
    std::format(STATICALLY_WIDEN<CharT>("{:%F}"), ymd) :
    std::format(STATICALLY_WIDEN<CharT>("{:%F} is not a valid date"), ymd));
```

{/* source:cpp-chrono-year-month-day-operator-ltlt:0004 */}
where `STATICALLY_WIDEN<CharT>("...")` is `"..."` if `CharT` is `char`, and `L"..."` if `CharT` is `wchar_t`.

## Return value

{/* source:cpp-chrono-year-month-day-operator-ltlt:0005 */}
`os`
