Constructs a `month_weekday` object that stores the [`month`](/docs/cpp/library/chrono/month) `m` and the [`weekday_indexed`](/docs/cpp/library/chrono/weekday_indexed) `wdi`.

## Notes

{/* source:cpp-chrono-month-weekday-month-weekday:0002 */}
A more convenient way to construct a `month_weekday` is with `operator/`, e.g., `std::chrono::April/std::chrono::Sunday[2]`.
