{/* source:cpp-chrono-month-weekday-operator-ltlt:0001 */}
Outputs a textual representation of `mwd` into `os`, as if by

{/* source:cpp-chrono-month-weekday-operator-ltlt:0002 */}
```cpp
os << std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{:L}/{:L}"),
                  mwd.month(), mwd.weekday_indexed());
```

{/* source:cpp-chrono-month-weekday-operator-ltlt:0003 */}
where `STATICALLY_WIDEN<CharT>("{:L}/{:L}")` is `"{:L}/{:L}"` if `CharT` is `char`, and `L"{:L}/{:L}"` if `CharT` is `wchar_t`.

## Return value

{/* source:cpp-chrono-month-weekday-operator-ltlt:0004 */}
`os`
