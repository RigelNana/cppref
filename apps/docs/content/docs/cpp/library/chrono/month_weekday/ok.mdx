{/* source:cpp-chrono-month-weekday-ok:0001 */}
Checks if the contained [`month`](/docs/cpp/library/chrono/month) and [`weekday_indexed`](/docs/cpp/library/chrono/weekday_indexed) objects are valid.

## Return value

{/* source:cpp-chrono-month-weekday-ok:0002 */}
`month().ok() && weekday_indexed().ok()`

## Example

{/* source:cpp-chrono-month-weekday-ok:0003 */}
```cpp
#include <cassert>
#include <chrono>

int main()
{
    auto mwdi{std::chrono::March/std::chrono::Friday[1]};
    assert(mwdi.ok());

    mwdi = {std::chrono::month(17)/std::chrono::Friday[1]};
    assert(not mwdi.ok());

    mwdi = {std::chrono::March/std::chrono::Friday[-4]};
    assert(not mwdi.ok());
}
```
