Compares the two `month_weekday` values `x` and `y`.

{/* source:cpp-chrono-month-weekday-operator-cmp:0002 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

## Return value

{/* source:cpp-chrono-month-weekday-operator-cmp:0003 */}
`x.month() == y.month() && x.weekday_indexed() == y.weekday_indexed()`

## Example

{/* source:cpp-chrono-month-weekday-operator-cmp:0004 */}
```cpp
#include <chrono>

int main()
{
    constexpr auto mwdi1{std::chrono::March/std::chrono::Friday[1]};

    constexpr auto mwdi2
    {
        std::chrono::month_weekday
        {
            std::chrono::month(3), std::chrono::weekday(5)[1]
        }
    };

    static_assert(mwdi1 == mwdi2);
}
```
