{/* source:cpp-chrono-month-operator-arith:0001 */}
Adds or subtracts `m.count()` from the month value, reducing the result modulo 12 to an integer in the range [`1`, `12`].

{/* source:cpp-chrono-month-operator-arith:0002 */}
1. Performs `*this = *this + m;`.

{/* source:cpp-chrono-month-operator-arith:0003 */}
2. Performs `*this = *this - m;`.

## Return value

{/* source:cpp-chrono-month-operator-arith:0004 */}
A reference to this month after modification.

## Notes

{/* source:cpp-chrono-month-operator-arith:0005 */}
After a call to one of these functions, [`ok()`](/docs/cpp/library/chrono/month/ok) is always `true` if no overflow occurred during the operation.

## Example

{/* source:cpp-chrono-month-operator-arith:0006 */}
```cpp
#include <chrono>
#include <iostream>
int main()
{
    std::cout << std::boolalpha;
    std::chrono::month m{6};
    m += std::chrono::months(2);
    std::cout << (m == std::chrono::month(8)) << ' '
              << (m == std::chrono::August) << ' ';
    m -= std::chrono::months(3);
    std::cout << (m == std::chrono::month(5)) << ' '
              << (m == std::chrono::May) << ' ';
    m = std::chrono::October;
    m += std::chrono::months{8}; // ((10 += 8 == 18) % 12) == 6;
    std::cout << (m == std::chrono::June) << ' ';
    m -= std::chrono::months{std::chrono::December - std::chrono::February}; // -= 10
    // (6 -= 10) == -4; -4 % 12 == (12 - 4) == 8
    std::cout << (m == std::chrono::August) << '\n';
}
```

Output:

```text
true true true true true true
```
