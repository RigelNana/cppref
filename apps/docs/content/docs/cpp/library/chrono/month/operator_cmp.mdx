{/* source:cpp-chrono-month-operator-cmp:0001 */}
Compare the two `std::chrono::month` `x` and `y`.

{/* source:cpp-chrono-month-operator-cmp:0002 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-month-operator-cmp:0003 */}
1. `unsigned(x) == unsigned(y)`

{/* source:cpp-chrono-month-operator-cmp:0004 */}
2. `unsigned(x) <=> unsigned(y)`

## Example

{/* source:cpp-chrono-month-operator-cmp:0005 */}
```cpp
#include <chrono>

int main()
{
    constexpr std::chrono::month m1{6}, m2{8};

    static_assert
    (
        m1 < m2 && m1 == m1 && m1 <= m2 &&
        m2 > m1 && m2 != m1 && m2 >= m1 &&
        m1 <=> m2 != 0
    );
}
```
