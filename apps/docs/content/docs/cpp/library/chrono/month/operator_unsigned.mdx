{/* source:cpp-chrono-month-operator-unsigned:0001 */}
Returns the month value stored in `*this`.

## Return value

{/* source:cpp-chrono-month-operator-unsigned:0002 */}
The month value stored in `*this`.

## Example

{/* source:cpp-chrono-month-operator-unsigned:0003 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    constexpr std::chrono::month m{6};
    constexpr unsigned p = static_cast<unsigned>(m);
    constexpr unsigned q = static_cast<unsigned>(std::chrono::September);
    std::cout << "The month is: " << p << '\n'
              << "September is: " << q << '\n'; 
}
```

Output:

```text
The month is: 6
September is: 9
```
