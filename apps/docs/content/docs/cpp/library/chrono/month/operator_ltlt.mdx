  <Declaration language="cpp" since="C++20" code={`template< class CharT, class Traits >
std::basic_ostream<CharT, Traits>&

    operator<<( std::basic_ostream<CharT, Traits>& os, const std::chrono::month& m );`} />
</DeclarationDoc>

{/* source:cpp-chrono-month-operator-ltlt:0001 */}
If `!m.ok()`, inserts `unsigned(m)` followed by `" is not a valid month"` to `os`. Otherwise, forms a `std::basic_string<CharT>` `s` consisting of the abbreviated month name for the month represented by `m`, determined using the locale associated with `os`, and inserts `s` into `os`.

{/* source:cpp-chrono-month-operator-ltlt:0002 */}
Equivalent to

{/* source:cpp-chrono-month-operator-ltlt:0003 */}
`return os << (m.ok() ? std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{:L%b}"), m) : std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{} is not a valid month"), unsigned(m)));`

{/* source:cpp-chrono-month-operator-ltlt:0004 */}
where `STATICALLY_WIDEN<CharT>("...")` is `"..."` if `CharT` is `char`, and `L"..."` if `CharT` is `wchar_t`.

## Return value

{/* source:cpp-chrono-month-operator-ltlt:0005 */}
`os`

## Notes

{/* source:cpp-chrono-month-operator-ltlt:0006 */}
This `operator<<` is primarily intended for debugging use. For control over formatting, use [`std::format`](/docs/cpp/library/text/format/format).
