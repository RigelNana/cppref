{/* source:cpp-chrono-weekday-encoding:0001 */}
1) Returns the weekday value stored in `*this`.

{/* source:cpp-chrono-weekday-encoding:0002 */}
2) Returns the weekday value stored in `*this`, except that Sunday (stored as `0`) is interpreted as `7` according to ISO 8601.

## Return value

{/* source:cpp-chrono-weekday-encoding:0003 */}
1) The weekday value stored in `*this`.

{/* source:cpp-chrono-weekday-encoding:0004 */}
2) `c_encoding() == 0u ? 7u : c_encoding()`

## Example

{/* source:cpp-chrono-weekday-encoding:0005 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    std::cout << "i: C: ISO: Weekday:\n";

    for (unsigned i{0}; i != 8; ++i)
    {
        const std::chrono::weekday w{i};
        std::cout << i << "  "
                  << w.c_encoding() << "  "
                  << w.iso_encoding() << "    "
                  << w << '\n';
    }
}
```

Output:

```text
i: C: ISO: Weekday:
0  0  7    Sun
1  1  1    Mon
2  2  2    Tue
3  3  3    Wed
4  4  4    Thu
5  5  5    Fri
6  6  6    Sat
7  0  7    Sun
```
