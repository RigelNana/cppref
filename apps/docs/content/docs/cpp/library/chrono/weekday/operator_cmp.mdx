{/* source:cpp-chrono-weekday-operator-cmp:0001 */}
Compare the two `std::chrono::weekday` `x` and `y`.

{/* source:cpp-chrono-weekday-operator-cmp:0002 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

## Return value

{/* source:cpp-chrono-weekday-operator-cmp:0003 */}
`x.c_encoding() == y.c_encoding()`

## Notes

{/* source:cpp-chrono-weekday-operator-cmp:0004 */}
`weekday` does not support the `<`, `<=`, `>` and `>=` operators because there is no universal consensus on which day is the first day of the week.

## Example

{/* source:cpp-chrono-weekday-operator-cmp:0005 */}
```cpp
#include <chrono>

int main()
{
    using namespace std::literals;

    constexpr std::chrono::weekday wd1{2};
    constexpr std::chrono::weekday wd2{std::chrono::Friday};
    static_assert(wd1 != wd2);

    // 13 January 1313 is a Friday
    constexpr std::chrono::weekday wd3{1313y/1/13d};
    static_assert(wd2 == wd3);
}
```
