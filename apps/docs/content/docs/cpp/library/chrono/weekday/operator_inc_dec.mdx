{/* source:cpp-chrono-weekday-operator-inc-dec:0001 */}
Adds or subtracts `1` from the weekday value, reducing the result modulo `7` to an integer in the range `[0, 6]`.

{/* source:cpp-chrono-weekday-operator-inc-dec:0002 */}
1,2) Performs `*this += std::chrono::days{1};`.

{/* source:cpp-chrono-weekday-operator-inc-dec:0003 */}
3,4) Performs `*this -= std::chrono::days{1};`.

## Parameters

{/* source:cpp-chrono-weekday-operator-inc-dec:0004 */}
(none)

## Return value

{/* source:cpp-chrono-weekday-operator-inc-dec:0005 */}
1,3) A reference to this `weekday` after modification.

{/* source:cpp-chrono-weekday-operator-inc-dec:0006 */}
2,4) A copy of the `weekday` made before modification.

## Notes

{/* source:cpp-chrono-weekday-operator-inc-dec:0007 */}
After a call to one of these functions, [`ok()`](/docs/cpp/library/chrono/weekday/ok) is always `true`.

## Example

{/* source:cpp-chrono-weekday-operator-inc-dec:0008 */}
```cpp
#include <cassert>
#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    std::chrono::weekday wd{0}; // Sunday is 0 or 7

    --wd;
    std::cout << (wd == std::chrono::Saturday) << ' ';

    ++wd;
    std::cout << (wd == std::chrono::Sunday) << '\n';

    wd = std::chrono::weekday{13};
    assert(!wd.ok());
    wd++;
    assert(wd.ok());
}
```

Output:

```text
true true
```
