{/* source:cpp-chrono-leap-second-operator-cmp:0001 */}
Compares the date and time represented by the objects `x` and `y`.

{/* source:cpp-chrono-leap-second-operator-cmp:0002 */}
Return type of (12) is deduced from `x.date() <=> y`, and hence the three-way comparison result type of [`std::chrono::seconds`](/docs/cpp/library/chrono/duration) and `Duration`.

{/* source:cpp-chrono-leap-second-operator-cmp:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

## Return value

{/* source:cpp-chrono-leap-second-operator-cmp:0004 */}
1. `x.date() == y.date()`

{/* source:cpp-chrono-leap-second-operator-cmp:0005 */}
2. `x.date() <=> y.date()`

{/* source:cpp-chrono-leap-second-operator-cmp:0006 */}
3. `x.date() == y`

{/* source:cpp-chrono-leap-second-operator-cmp:0007 */}
4. `x.date() < y`

{/* source:cpp-chrono-leap-second-operator-cmp:0008 */}
5. `x < y.date()`

{/* source:cpp-chrono-leap-second-operator-cmp:0009 */}
6. `x.date() > y`

{/* source:cpp-chrono-leap-second-operator-cmp:0010 */}
7. `x > y.date()`

{/* source:cpp-chrono-leap-second-operator-cmp:0011 */}
8. `x.date() <= y`

{/* source:cpp-chrono-leap-second-operator-cmp:0012 */}
9. `x <= y.date()`

{/* source:cpp-chrono-leap-second-operator-cmp:0013 */}
10. `x.date() >= y`

{/* source:cpp-chrono-leap-second-operator-cmp:0014 */}
11. `x >= y.date()`

{/* source:cpp-chrono-leap-second-operator-cmp:0015 */}
12. `x.date() <=> y`
