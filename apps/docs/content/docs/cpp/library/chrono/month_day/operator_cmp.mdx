Compares two `month_day` values.

{/* source:cpp-chrono-month-day-operator-cmp:0002 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-month-day-operator-cmp:0003 */}
1. `x.month() == y.month() && x.day() == y.day()`

{/* source:cpp-chrono-month-day-operator-cmp:0004 */}
2. `x.month() <=> y.month() != 0 ? x.month() <=> y.month() : x.day() <=> y.day()`

## Example

{/* source:cpp-chrono-month-day-operator-cmp:0005 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    constexpr auto md1{std::chrono::August/15};
    constexpr auto md2{std::chrono::month(8)/std::chrono::day(15)};
    std::cout << std::boolalpha << (md1 == md2) << '\n';

    static_assert(md1 <= md2);
}
```

Output:

```text
true
```
