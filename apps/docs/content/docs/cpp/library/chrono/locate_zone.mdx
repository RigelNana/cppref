{/* source:cpp-chrono-locate-zone:0001 */}
Convenience function for locating a time zone in the time zone database. Equivalent to `std::chrono::get_tzdb().locate_zone(tz_name)`.

## Exceptions

{/* source:cpp-chrono-locate-zone:0002 */}
[`std::runtime_error`](/docs/cpp/library/error/runtime_error) if the specified time zone cannot be found, or if this is the first reference to the time zone database and the time zone database cannot be initialized.

## Notes

{/* source:cpp-chrono-locate-zone:0003 */}
A call to this function that is the first reference to the time zone database will cause it to be initialized.
