Compares the two `month_day_last` values `x` and `y`.

{/* source:cpp-chrono-month-day-last-operator-cmp:0002 */}
The \<, \<=, \>, \>=, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-month-day-last-operator-cmp:0003 */}
1. `x.month() == y.month()`

{/* source:cpp-chrono-month-day-last-operator-cmp:0004 */}
2. `x.month() <=> y.month()`

## Example

{/* source:cpp-chrono-month-day-last-operator-cmp:0005 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    constexpr auto mdl1{std::chrono::February/std::chrono::last};
    constexpr std::chrono::month_day_last mdl2{std::chrono::month(2)};
    std::cout << std::boolalpha << (mdl1 == mdl2) << '\n';

    static_assert(mdl1 <= mdl2);
}
```

Output:

```text
true
```
