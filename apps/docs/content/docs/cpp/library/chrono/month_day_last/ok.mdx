Checks if the month object stored in `*this` is valid.

## Return value

{/* source:cpp-chrono-month-day-last-ok:0002 */}
`month().ok()`

## Example

{/* source:cpp-chrono-month-day-last-ok:0003 */}
```cpp
#include <cassert>
#include <chrono>

int main()
{
    auto mdl{std::chrono::February/std::chrono::last};
    assert(mdl.ok());
    mdl = {std::chrono::month(42)/std::chrono::last};
    assert(!mdl.ok());
}
```
