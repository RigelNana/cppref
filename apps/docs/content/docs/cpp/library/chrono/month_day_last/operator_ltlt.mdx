{/* source:cpp-chrono-month-day-last-operator-ltlt:0001 */}
Outputs a textual representation of `mdl` into `os`, as if by

{/* source:cpp-chrono-month-day-last-operator-ltlt:0002 */}
`os << std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{:L}/last"), mdl.month());`

{/* source:cpp-chrono-month-day-last-operator-ltlt:0003 */}
where `STATICALLY_WIDEN<CharT>("{:L}/last")` is `"{:L}/last"` if `CharT` is `char`, and `L"{:L}/last"` if `CharT` is `wchar_t`.

## Return value

{/* source:cpp-chrono-month-day-last-operator-ltlt:0004 */}
`os`
