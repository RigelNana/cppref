{/* source:cpp-chrono-day-operator-inc-dec:0001 */}
Adds or subtracts 1 from the day value.

{/* source:cpp-chrono-day-operator-inc-dec:0002 */}
1,2) Performs `*this += std::chrono::days{1};`.

{/* source:cpp-chrono-day-operator-inc-dec:0003 */}
3,4) Performs `*this -= std::chrono::days{1};`.

## Parameters

{/* source:cpp-chrono-day-operator-inc-dec:0004 */}
(none)

## Return value

{/* source:cpp-chrono-day-operator-inc-dec:0005 */}
1,3) A reference to this day after modification.

{/* source:cpp-chrono-day-operator-inc-dec:0006 */}
2,4) A copy of the day made before modification.

## Notes

{/* source:cpp-chrono-day-operator-inc-dec:0007 */}
If the result would be outside the range `[0, 255]`, the actual stored value is unspecified.

## Example

{/* source:cpp-chrono-day-operator-inc-dec:0008 */}
```cpp
#include <cassert>
#include <chrono>

int main()
{
    std::chrono::day d{15};

    ++d;
    assert(d == std::chrono::day(16));

    --d;
    assert(d == std::chrono::day(15));
}
```
