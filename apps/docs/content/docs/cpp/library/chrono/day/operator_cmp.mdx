{/* source:cpp-chrono-day-operator-cmp:0001 */}
Compare the two `std::chrono::day` `x` and `y`.

{/* source:cpp-chrono-day-operator-cmp:0002 */}
The `\<`, `\<=`, `\>`, `\>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-day-operator-cmp:0003 */}
1. `unsigned(x) == unsigned(y)`

{/* source:cpp-chrono-day-operator-cmp:0004 */}
2. `unsigned(x) <=> unsigned(y)`

## Example

{/* source:cpp-chrono-day-operator-cmp:0005 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    constexpr std::chrono::day x{13}, y{31};
    static_assert(x != y);

    if constexpr (constexpr auto res = x <=> y; res < 0)
        std::cout << "x is less than y\n";
    else if constexpr (res > 0)
        std::cout << "x is greater than y\n";
    else
        std::cout << "x and y are equal\n";

    using namespace std::literals::chrono_literals;

    static_assert
    (
        (6d < 9d) && (6d == 6d) && (6d <= 9d) &&
        (9d > 6d) && (9d != 6d) && (9d >= 6d)
    );
}
```

Output:

```text
x is less than y
```
