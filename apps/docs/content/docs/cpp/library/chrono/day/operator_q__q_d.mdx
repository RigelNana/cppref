Forms a [`std::chrono::day`](/docs/cpp/library/chrono/day) literal representing a day of the month in the calendar.

### Parameters

{/* source:cpp-chrono-operator-q-q-d:0002 */}
<ParameterList>
  <Parameter name="d">the day value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-chrono-operator-q-q-d:0003 */}
A [`std::chrono::day`](/docs/cpp/library/chrono/day) storing `d`. If `d > 255`, the stored value is unspecified.

### Possible implementation

{/* source:cpp-chrono-operator-q-q-d:0004 */}
```cpp
constexpr std::chrono::day operator ""d(unsigned long long d) noexcept
{
    return std::chrono::day(d);
}
```

### Notes

{/* source:cpp-chrono-operator-q-q-d:0005 */}
This operator is declared in the namespace `std::literals::chrono_literals`, where both `literals` and `chrono_literals` are [inline namespaces](/docs/cpp/language/declarations/namespace#Inline_namespaces). Access to this operator can be gained with:

{/* source:cpp-chrono-operator-q-q-d:0006 */}
- `using namespace std::literals`, `using namespace std::chrono_literals`, or `using namespace std::literals::chrono_literals`.

{/* source:cpp-chrono-operator-q-q-d:0007 */}
In addition, within the namespace `std::chrono`, the directive `using namespace literals::chrono_literals;` is provided by the [standard library](/docs/cpp/library/standard_library), so that if a programmer uses `using namespace std::chrono;` to gain access to the classes in the [chrono library](/docs/cpp/library/chrono), the corresponding literal operators become visible as well.

### Example

{/* source:cpp-chrono-operator-q-q-d:0008 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    using namespace std::literals::chrono_literals;

    std::cout << static_cast<unsigned>(42d) << '\t' << 42d << '\n'
              << static_cast<unsigned>(256d) << '\t' << 256d << '\n' // unspecified
              << static_cast<unsigned>(298d) << '\t' << 298d << '\n'; // unspecified
}
```

Possible output:

```text
42      42 is not a valid day
0       00 is not a valid day
42      42 is not a valid day
```
