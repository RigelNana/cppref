{/* source:cpp-chrono-day:0001 */}
The class `day` represents a day in a month. Its normal range is [`1, 31`], but it may hold any number in [`0, 255`].

{/* source:cpp-chrono-day:0002 */}
`day` is a [TriviallyCopyable](/docs/cpp/library/named_req/TriviallyCopyable) [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType).
