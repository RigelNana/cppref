    get_leap_second_info( const std::chrono::utc_time<Duration>& ut );`} />

{/* source:cpp-chrono-utc-clock-get-leap-second-info:0001 */}
Obtains a [`std::chrono::leap_second_info`](/docs/cpp/library/chrono/utc_clock/leap_second_info) whose `is_leap_second` and `elapsed` indicate whether `ut` is during a positive leap second insertion and the sum of leap seconds between 1 January 1970 and `ut`, respectively.

## Parameters

{/* source:cpp-chrono-utc-clock-get-leap-second-info:0002 */}
<ParameterList>
  <Parameter name="ut">UTC time to examine</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-utc-clock-get-leap-second-info:0003 */}
A `leap_second_info` value specified above.

## Exceptions

{/* source:cpp-chrono-utc-clock-get-leap-second-info:0004 */}
May throw implementation-defined exceptions.
