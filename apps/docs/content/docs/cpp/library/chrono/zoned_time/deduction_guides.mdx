{/* source:cpp-chrono-zoned-time-deduction-guides:0001 */}
These deduction guides normalize `Duration` to a minimum resolution of [`std::chrono::seconds`](/docs/cpp/library/chrono/duration), and provide correct handling for time zone names specified using types convertible to `std::string_view`.

{/* source:cpp-chrono-zoned-time-deduction-guides:0002 */}
3-6) If `std::is_convertible_v<TimeZonePtrOrName, std::string_view>` is `true`, the deduced second template argument is `const std::chrono::time_zone*`. Otherwise it is `std::remove_cvref_t<TimeZonePtrOrName>`.
