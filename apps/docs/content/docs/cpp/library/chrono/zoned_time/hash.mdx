{/* source:cpp-chrono-zoned-time-hash:0001 */}
The template specialization of [`std::hash`](/docs/cpp/library/utility/hash) for [`std::chrono::zoned_time`](/docs/cpp/library/chrono/zoned_time) allows users to obtain hashes of objects of type `std::chrono::zoned_time<Duration, TimeZonePtr>`. This specialization is [`enabled`](/docs/cpp/library/utility/hash) if and only if both `std::hash<Duration>` and `std::hash<TimeZonePtr>` are enabled.
