{/* source:cpp-chrono-zoned-time-operator-ltlt:0001 */}
Outputs `tp` to the stream `os`, as if by `std::format(os.getloc(), fmt, tp)`, where `fmt` is `"{:L%F %T %Z}"` if `CharT` is `char`, or `L"{:L%F %T %Z}"` if `CharT` is `wchar_t`.

</ParameterList>
