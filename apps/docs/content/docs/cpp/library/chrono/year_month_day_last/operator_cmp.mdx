{/* source:cpp-chrono-year-month-day-last-operator-cmp:0001 */}
Compares the two `year_month_day_last` values `x` and `y`. This is a lexicographical comparison: the [`year()`](/docs/cpp/library/chrono/year_month_day_last/accessors) is compared first, then [`month()`](/docs/cpp/library/chrono/year_month_day_last/accessors).

{/* source:cpp-chrono-year-month-day-last-operator-cmp:0002 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-year-month-day-last-operator-cmp:0003 */}
1. `x.year() == y.year() && x.month() == y.month()`

{/* source:cpp-chrono-year-month-day-last-operator-cmp:0004 */}
2. `x.year() <=> y.year() != 0 ? x.year() <=> y.year() : x.month() <=> y.month()`

## Notes

{/* source:cpp-chrono-year-month-day-last-operator-cmp:0005 */}
If both `x` and `y` represent valid dates (`x.ok() && y.ok() == true`), the result of the lexicographical comparison is consistent with the calendar order.

## Example

{/* source:cpp-chrono-year-month-day-last-operator-cmp:0006 */}
```cpp
#include <cassert>
#include <chrono>
#include <iostream>

int main()
{
    auto ymdl1{11/std::chrono::last/2020};
    auto mdl{std::chrono::last/std::chrono::November};
    auto ymdl2{mdl/2020};
    assert(ymdl1 == ymdl2);

    ymdl1 -= std::chrono::months{2};
    ymdl2 -= std::chrono::months{1};
    assert(ymdl1 < ymdl2);
}
```
