{/* source:cpp-chrono-year-month-day-last-operator-arith:0001 */}
Modifies the time point `*this` represents by the duration `dy` or `dm`.

{/* source:cpp-chrono-year-month-day-last-operator-arith:0002 */}
1) Equivalent to `*this = *this + dy;`.

{/* source:cpp-chrono-year-month-day-last-operator-arith:0003 */}
2) Equivalent to `*this = *this + dm;`.

{/* source:cpp-chrono-year-month-day-last-operator-arith:0004 */}
3) Equivalent to `*this = *this - dy;`.

{/* source:cpp-chrono-year-month-day-last-operator-arith:0005 */}
4) Equivalent to `*this = *this - dm;`.

{/* source:cpp-chrono-year-month-day-last-operator-arith:0006 */}
For durations that are convertible to both `std::chrono::years` and `std::chrono::months`, the years overloads (1,3) are preferred if the call would otherwise be ambiguous.

## Example

{/* source:cpp-chrono-year-month-day-last-operator-arith:0007 */}
```cpp
#include <cassert>
#include <chrono>

int main()
{
    auto ymdl{11/std::chrono::last/2020};

    ymdl += std::chrono::years(15);
    assert(ymdl.day() == std::chrono::day(30));
    assert(ymdl.month() == std::chrono::November);
    assert(ymdl.year() == std::chrono::year(2035));

    ymdl -= std::chrono::months(6);
    assert(ymdl.day() == std::chrono::day(31));
    assert(ymdl.month() == std::chrono::May);
    assert(ymdl.year() == std::chrono::year(2035));
}
```
