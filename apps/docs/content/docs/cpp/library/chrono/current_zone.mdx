{/* source:cpp-chrono-current-zone:0001 */}
Convenience function for obtaining local time zone from the time zone database. Equivalent to `std::chrono::get_tzdb().current_zone()`.

## Exceptions

{/* source:cpp-chrono-current-zone:0002 */}
[`std::runtime_error`](/docs/cpp/library/error/runtime_error) if this is the first reference to the time zone database and the time zone database cannot be initialized.

## Notes

{/* source:cpp-chrono-current-zone:0003 */}
A call to this function that is the first reference to the time zone database will cause it to be initialized.

## Example

{/* source:cpp-chrono-current-zone:0004 */}
```cpp
#include <chrono>
#include <iostream>

int main() {
    const std::chrono::zoned_time cur_time{ std::chrono::current_zone(),
                                            std::chrono::system_clock::now() };
    std::cout << cur_time << '\n';
}
```

Possible output:

```text
2021-09-13 19:46:42.249182012 MAGT
```
