{/* source:cpp-chrono-year-month-weekday-ok:0001 */}
Checks if this `year_month_weekday` object represents a valid date.

## Return value

{/* source:cpp-chrono-year-month-weekday-ok:0002 */}
`true` if this `year_month_weekday` object represents a valid date, that is, `year().ok() && month().ok() && weekday_indexed().ok()` is `true` and there are at least [`index()`](/docs/cpp/library/chrono/year_month_weekday/accessors) [`weekday()s`](/docs/cpp/library/chrono/year_month_weekday/accessors) in the specified year and month. Otherwise `false`.

## Example

{/* source:cpp-chrono-year-month-weekday-ok:0003 */}
```cpp
#include <cassert>
#include <chrono>

int main()
{
    auto ymwdi{std::chrono::Wednesday[1]/1/2021};
    assert(ymwdi.ok());
    ymwdi = std::chrono::year(2021)/std::chrono::month(1)/std::chrono::Wednesday[42];
    assert(!ymwdi.ok());
}
```
