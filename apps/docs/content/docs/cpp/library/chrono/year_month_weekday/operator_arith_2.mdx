{/* source:cpp-chrono-year-month-weekday-operator-arith-2:0001 */}
1,2) Adds `dm.count()` months to the date represented by `ymwd`. The result has the same [`year()`](/docs/cpp/library/chrono/year_month_weekday/accessors) and [`month()`](/docs/cpp/library/chrono/year_month_weekday/accessors) as `std::chrono::year_month(ymwd.year(), ymwd.month()) + dm` and the same [`weekday()`](/docs/cpp/library/chrono/year_month_weekday/accessors) and [`index()`](/docs/cpp/library/chrono/year_month_weekday/accessors) as `ymwd`.

{/* source:cpp-chrono-year-month-weekday-operator-arith-2:0002 */}
3,4) Adds `dy.count()` years to the date represented by `ymwd`. The result is equivalent to `std::chrono::year_month_weekday(ymwd.year() + dy, ymwd.month(), ymwd.weekday_indexed())`.

{/* source:cpp-chrono-year-month-weekday-operator-arith-2:0003 */}
5) Subtracts `dm.count()` months from the date represented by `ymwd`. Equivalent to `ymwd + -dm`.

{/* source:cpp-chrono-year-month-weekday-operator-arith-2:0004 */}
6) Subtracts `dy.count()` years from the date represented by `ymwd`. Equivalent to `ymwd + -dy`.

{/* source:cpp-chrono-year-month-weekday-operator-arith-2:0005 */}
For durations that are convertible to both `std::chrono::years` and `std::chrono::months`, the years overloads (3,4,6) are preferred if the call would otherwise be ambiguous.

## Notes

{/* source:cpp-chrono-year-month-weekday-operator-arith-2:0006 */}
Even if `ymwd.ok()` is `true`, the resulting `year_month_weekday` may not represent a valid date if `ymwd.index()` is 5.

## Example

{/* source:cpp-chrono-year-month-weekday-operator-arith-2:0007 */}
```cpp
#include <cassert>
#include <chrono>
#include <iostream>

int main()
{
    auto ymwdi{1/std::chrono::Wednesday[1]/2021};
    std::cout << ymwdi << '\n';

    ymwdi = std::chrono::years(5) + ymwdi;
    // First Wednesday in January, 2026
    std::cout << ymwdi << '\n';
    assert(static_cast<std::chrono::year_month_day>(ymwdi) ==
           std::chrono::January/7/2026);

    ymwdi = ymwdi - std::chrono::months(6);
    // First Wednesday in July, 2025
    std::cout << ymwdi << '\n';
    assert(static_cast<std::chrono::year_month_day>(ymwdi) ==
           std::chrono::July/2/2025);
}
```

Output:

```text
2021/Jan/Wed[1]
2026/Jan/Wed[1]
2025/Jul/Wed[1]
```
