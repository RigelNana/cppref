{/* source:cpp-chrono-year-month-weekday-operator-arith:0001 */}
Modifies the time point `*this` represents by the duration `dy` or `dm`.

{/* source:cpp-chrono-year-month-weekday-operator-arith:0002 */}
1. Equivalent to `*this = *this + dy;`.

{/* source:cpp-chrono-year-month-weekday-operator-arith:0003 */}
2. Equivalent to `*this = *this + dm;`.

{/* source:cpp-chrono-year-month-weekday-operator-arith:0004 */}
3. Equivalent to `*this = *this - dy;`.

{/* source:cpp-chrono-year-month-weekday-operator-arith:0005 */}
4. Equivalent to `*this = *this - dm;`.

{/* source:cpp-chrono-year-month-weekday-operator-arith:0006 */}
For durations that are convertible to both `std::chrono::years` and `std::chrono::months`, the years overloads (1,3) are preferred if the call would otherwise be ambiguous.

## Example

{/* source:cpp-chrono-year-month-weekday-operator-arith:0007 */}
```cpp
#include <cassert>
#include <chrono>
#include <iostream>

int main()
{
    auto ymwi{1/std::chrono::Wednesday[2]/2021};
    std::cout << ymwi << '\n';

    ymwi += std::chrono::years(5);
    std::cout << ymwi << '\n';
    assert(static_cast<std::chrono::year_month_day>(ymwi) ==
                       std::chrono::year(2026)/1/14);

    ymwi -= std::chrono::months(1);
    std::cout << ymwi << '\n';
    assert(static_cast<std::chrono::year_month_day>(ymwi) == 
                       std::chrono::day(10)/12/2025);
}
```

Output:

```text
2021/Jan/Wed[2]
2026/Jan/Wed[2]
2025/Dec/Wed[2]
```
