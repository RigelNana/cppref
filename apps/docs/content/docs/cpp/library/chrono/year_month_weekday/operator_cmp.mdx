Compares the two `year_month_weekday` values `x` and `y`.

{/* source:cpp-chrono-year-month-weekday-operator-cmp:0002 */}
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

## Return value

{/* source:cpp-chrono-year-month-weekday-operator-cmp:0003 */}
`x.year() == y.year() && x.month() == y.month() && x.weekday_indexed() == y.weekday_indexed()`

## Example

{/* source:cpp-chrono-year-month-weekday-operator-cmp:0004 */}
```cpp
#include <chrono>
#include <iostream>
using namespace std::chrono;

int main()
{
    constexpr auto ymwdi1{Wednesday[1]/January/2021};
    constexpr year_month_weekday ymwdi2{year(2021), month(1), weekday(3)[1]};
    std::cout << std::boolalpha << (ymwdi1 == ymwdi2) << '\n';
}
```

Output:

```text
true
```
