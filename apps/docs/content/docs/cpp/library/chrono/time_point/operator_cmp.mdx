{/* source:cpp-chrono-time-point-operator-cmp:0001 */}
Compares two time points. The comparison is done by comparing the results [`time_since_epoch()`](/docs/cpp/library/chrono/time_point/time_since_epoch) for the time points.

{/* source:cpp-chrono-time-point-operator-cmp:0002 */}
1,2) Checks if the time points `lhs` and `rhs` refer to the same time point for the given clock.

{/* source:cpp-chrono-time-point-operator-cmp:0003 */}
3-6) Compares the time points `lhs` and `rhs`.

{/* source:cpp-chrono-time-point-operator-cmp:0004 */}
7) Compares the time points `lhs` and `rhs`. The return type is deduced from `lhs.time_since_epoch() <=> rhs.time_since_epoch()`, and hence the three-way comparison result type of `Dur1` and `Dur2`.

{/* source:cpp-chrono-time-point-operator-cmp:0005 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

## Return value

{/* source:cpp-chrono-time-point-operator-cmp:0007 */}
1) `true` if the `lhs` and `rhs` refer to the same time point, `false` otherwise.

{/* source:cpp-chrono-time-point-operator-cmp:0008 */}
2) `true` if the `lhs` and `rhs` refer to different time points, `false` otherwise.

{/* source:cpp-chrono-time-point-operator-cmp:0009 */}
3) `true` if the `lhs` refers to time point before `rhs`, `false` otherwise.

{/* source:cpp-chrono-time-point-operator-cmp:0010 */}
4) `true` if the `lhs` refers to time point before `rhs`, or to the same time point as `rhs`, `false` otherwise.

{/* source:cpp-chrono-time-point-operator-cmp:0011 */}
5) `true` if the `lhs` refers to time point after `rhs`, `false` otherwise.

{/* source:cpp-chrono-time-point-operator-cmp:0012 */}
6) `true` if the `lhs` refers to time point after `rhs`, or to the same time point as `rhs`, `false` otherwise.

{/* source:cpp-chrono-time-point-operator-cmp:0013 */}
7) `lhs.time_since_epoch() <=> rhs.time_since_epoch()`.

## Exceptions

{/* source:cpp-chrono-time-point-operator-cmp:0014 */}
May throw implementation-defined exceptions.

## Notes

{/* source:cpp-chrono-time-point-operator-cmp:0015 */}
Two-way comparison operators of `time_point` were not `constexpr` in C++11, this was corrected in C++14.
