{/* source:cpp-chrono-time-point-operator-arith2:0001 */}
Performs add and subtract operations involving a `time_point`.

{/* source:cpp-chrono-time-point-operator-arith2:0002 */}
1,2) Applies the offset `d` to `pt`. Effectively returns `CT(pt.time_since_epoch() + d)`, where `CT` is the return type.

{/* source:cpp-chrono-time-point-operator-arith2:0003 */}
3) Applies the offset `d` to `pt` in negative direction. Effectively returns `CT(pt.time_since_epoch() - d)`, where `CT` is the return type.

{/* source:cpp-chrono-time-point-operator-arith2:0004 */}
4) Computes the difference between `pt_lhs` and `pt_rhs`.

## Parameters

{/* source:cpp-chrono-time-point-operator-arith2:0005 */}
<ParameterList>
  <Parameter name="pt">a time point to apply the offset to</Parameter>
  <Parameter name="d">a time offset</Parameter>
  <Parameter name="pt_lhs, pt_rhs">time points to extract difference from</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-time-point-operator-arith2:0006 */}
1-3) The time point that resulted from applying the offset `d`.

{/* source:cpp-chrono-time-point-operator-arith2:0007 */}
4) The duration between the time points.
