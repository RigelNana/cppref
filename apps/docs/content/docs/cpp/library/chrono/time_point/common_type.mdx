Exposes the type named `type`, which is the common type of two [`std::chrono::time_point`](/docs/cpp/library/chrono/time_point)s.

## Notes

{/* source:cpp-chrono-time-point-common-type:0003 */}
The common type of two [`std::chrono::time_point`](/docs/cpp/library/chrono/time_point) types is a [`std::chrono::time_point`](/docs/cpp/library/chrono/time_point) with the same clock as the two types and the [`std::common_type`](/docs/cpp/library/meta/common_type) of their durations.
