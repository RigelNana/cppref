{/* source:cpp-chrono-time-point-operator-inc-dec:0001 */}
Modifies the point in time `*this` represents by one tick of the duration.

{/* source:cpp-chrono-time-point-operator-inc-dec:0002 */}
If `d_` is a member variable holding the duration (i.e., time since epoch) of this `time_point` object,

{/* source:cpp-chrono-time-point-operator-inc-dec:0003 */}
1. Equivalent to `++d_; return *this;`.

{/* source:cpp-chrono-time-point-operator-inc-dec:0004 */}
2. Equivalent to `return time_point(d_++)`.

{/* source:cpp-chrono-time-point-operator-inc-dec:0005 */}
3. Equivalent to `--d_; return *this;`.

{/* source:cpp-chrono-time-point-operator-inc-dec:0006 */}
4. Equivalent to `return time_point(d_--);`.

## Parameters

{/* source:cpp-chrono-time-point-operator-inc-dec:0007 */}
(none)

## Return value

{/* source:cpp-chrono-time-point-operator-inc-dec:0008 */}
`1,3)` A reference to this time_point after modification.

{/* source:cpp-chrono-time-point-operator-inc-dec:0009 */}
`2,4)` A copy of the time_point made before modification.
