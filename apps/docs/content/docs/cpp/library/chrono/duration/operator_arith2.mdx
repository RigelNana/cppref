{/* source:cpp-chrono-duration-operator-arith2:0001 */}
Increments or decrements the number of ticks for this duration.

{/* source:cpp-chrono-duration-operator-arith2:0002 */}
If `rep_` is a member variable holding the number of ticks in a duration object,

{/* source:cpp-chrono-duration-operator-arith2:0003 */}
1. Equivalent to `++rep_; return *this;`.

{/* source:cpp-chrono-duration-operator-arith2:0004 */}
2. Equivalent to `return duration(rep_++)`.

{/* source:cpp-chrono-duration-operator-arith2:0005 */}
3. Equivalent to `--rep_; return *this;`.

{/* source:cpp-chrono-duration-operator-arith2:0006 */}
4. Equivalent to `return duration(rep_--);`.

## Parameters

{/* source:cpp-chrono-duration-operator-arith2:0007 */}
(none)

## Return value

{/* source:cpp-chrono-duration-operator-arith2:0008 */}
`1,3)` A reference to this duration after modification.

{/* source:cpp-chrono-duration-operator-arith2:0009 */}
`2,4)` A copy of the duration made before modification.

## Example

{/* source:cpp-chrono-duration-operator-arith2:0010 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    std::chrono::hours h(1);
    std::chrono::minutes m = ++h;
    m--;
    std::cout << m.count() << " minutes\n";
}
```

Output:

```text
119 minutes
```
