{/* source:cpp-chrono-duration-zero:0001 */}
Returns a zero-length duration.

{/* source:cpp-chrono-duration-zero:0002 */}
If the representation `rep` of the duration requires some other implementation to return a zero-length duration, [`std::chrono::duration_values`](/docs/cpp/library/chrono/duration/../duration_values) can be specialized to return the desired value.

## Parameters

{/* source:cpp-chrono-duration-zero:0003 */}
(none)

## Return value

{/* source:cpp-chrono-duration-zero:0004 */}
Returns `duration(std::chrono::duration_values<rep>::zero())`.

## Example

{/* source:cpp-chrono-duration-zero:0005 */}
```cpp
#include <chrono>
#include <ratio>

template<typename X, typename Y>
using dura = std::chrono::duration<X, Y>;

static_assert
(
    (std::chrono::hours::zero() == std::chrono::nanoseconds::zero()) &&
    (dura<short, std::nano>::zero() == dura<int, std::deci>::zero()) &&
    (dura<short, std::deca>::zero() == dura<long, std::exa>::zero()) &&
    (dura<long, std::atto>::zero().count() == dura<float, std::exa>::zero().count())
);

int main() {}
```
