{/* source:cpp-chrono-operator-q-q-ns:0001 */}
Forms a [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal representing nanoseconds.

{/* source:cpp-chrono-operator-q-q-ns:0002 */}
1. Integer literal, returns exactly `std::chrono::nanoseconds(nsec)`.

{/* source:cpp-chrono-operator-q-q-ns:0003 */}
2. Floating-point literal, returns a floating-point duration equivalent to [`std::chrono::nanoseconds`](/docs/cpp/library/chrono/duration).

## Parameters

{/* source:cpp-chrono-operator-q-q-ns:0004 */}
<ParameterList>
  <Parameter name="nsec">the number of nanoseconds</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-operator-q-q-ns:0005 */}
The [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal.

## Possible implementation

{/* source:cpp-chrono-operator-q-q-ns:0006 */}
```cpp
constexpr std::chrono::nanoseconds operator""ns(unsigned long long ns)
{
    return std::chrono::nanoseconds(ns);
}
constexpr std::chrono::duration<long double, std::nano> operator""ns(long double ns)
{
    return std::chrono::duration<long double, std::nano>(ns);
}
```

## Notes

{/* source:cpp-chrono-operator-q-q-ns:0007 */}
This operator is declared in the namespace `std::literals::chrono_literals`, where both `literals` and `chrono_literals` are [inline namespaces](/docs/cpp/language/declarations/namespace#Inline_namespaces). Access to this operator can be gained with:

{/* source:cpp-chrono-operator-q-q-ns:0008 */}
- `using namespace std::literals`
- `using namespace std::chrono_literals`
- or `using namespace std::literals::chrono_literals`.

{/* source:cpp-chrono-operator-q-q-ns:0009 */}
In addition, within the namespace `std::chrono`, the directive `using namespace literals::chrono_literals;` is provided by the [standard library](/docs/cpp/library/standard_library), so that if a programmer uses `using namespace std::chrono;` to gain access to the classes in the [chrono library](/docs/cpp/library/chrono), the corresponding literal operators become visible as well.

## Example

{/* source:cpp-chrono-operator-q-q-ns:0010 */}
```cpp
#include <chrono>
#include <iostream>
 
int main()
{
    using namespace std::chrono_literals;
    auto d1{250ns};
    std::chrono::nanoseconds d2{1us};
    std::cout << d1 << " = " << d1.count() << " nanoseconds\n"
              << d2 << " = " << d2.count() << " nanoseconds\n";
}
```

Output:

```text
250ns = 250 nanoseconds
1000ns = 1000 nanoseconds
```
