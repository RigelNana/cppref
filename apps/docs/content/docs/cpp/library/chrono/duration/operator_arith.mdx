{/* source:cpp-chrono-duration-operator-arith:0001 */}
Implements unary plus and unary minus for the durations.

{/* source:cpp-chrono-duration-operator-arith:0002 */}
If `rep_` is a member variable holding the number of ticks in a duration object, and `D` is the return type,

{/* source:cpp-chrono-duration-operator-arith:0003 */}
1. Equivalent to `return D(*this);`.

{/* source:cpp-chrono-duration-operator-arith:0004 */}
2. Equivalent to `return D(-rep_);`.

## Parameters

{/* source:cpp-chrono-duration-operator-arith:0005 */}
(none)

## Return value

{/* source:cpp-chrono-duration-operator-arith:0006 */}
1. A copy of this duration object.

{/* source:cpp-chrono-duration-operator-arith:0007 */}
2. A copy of this duration object, with the number of ticks negated.

## Example

{/* source:cpp-chrono-duration-operator-arith:0008 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    constexpr std::chrono::seconds s1(-052);
    constexpr std::chrono::seconds s2 = -s1;

    std::cout << "Negated " << s1 << " are " << s2 << '\n';
}
```

Output:

```text
Negated -42s are 42s
```
