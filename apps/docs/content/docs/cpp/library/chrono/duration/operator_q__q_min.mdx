{/* source:cpp-chrono-operator-q-q-min:0001 */}
Forms a [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal representing minutes.

{/* source:cpp-chrono-operator-q-q-min:0002 */}
1) Integer literal, returns exactly `std::chrono::minutes(mins)`.

{/* source:cpp-chrono-operator-q-q-min:0003 */}
2) Floating-point literal, returns a floating-point duration equivalent to [`std::chrono::minutes`](/docs/cpp/library/chrono/duration).

## Parameters

{/* source:cpp-chrono-operator-q-q-min:0004 */}
<ParameterList>
  <Parameter name="mins">the number of minutes</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-operator-q-q-min:0005 */}
The [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal.

## Possible implementation

{/* source:cpp-chrono-operator-q-q-min:0006 */}
```cpp
constexpr std::chrono::minutes operator""min(unsigned long long m)
{
    return std::chrono::minutes(m);
}
constexpr std::chrono::duration<long double,
                                std::ratio<60,1>> operator""min(long double m)
{
    return std::chrono::duration<long double, ratio<60,1>> (m);
}
```

## Notes

{/* source:cpp-chrono-operator-q-q-min:0007 */}
This operator is declared in the namespace `std::literals::chrono_literals`, where both `literals` and `chrono_literals` are [`inline namespaces`](/docs/cpp/language/declarations/namespace#Inline_namespaces). Access to this operator can be gained with:

{/* source:cpp-chrono-operator-q-q-min:0008 */}
- `using namespace std::literals`, `using namespace std::chrono_literals`, or `using namespace std::literals::chrono_literals`.

{/* source:cpp-chrono-operator-q-q-min:0009 */}
In addition, within the namespace `std::chrono`, the directive `using namespace literals::chrono_literals;` is provided by the [`standard library`](/docs/cpp/library/standard_library), so that if a programmer uses `using namespace std::chrono;` to gain access to the classes in the [`chrono library`](/docs/cpp/library/chrono), the corresponding literal operators become visible as well.

## Example

{/* source:cpp-chrono-operator-q-q-min:0010 */}
```cpp
#include <chrono>
#include <iostream>
int main()
{
    using namespace std::chrono_literals;
    auto lesson = 45min;
    auto halfmin = 0.5min;
    std::cout << "One lesson is " << lesson.count() << " minutes"
                 " (" << lesson << ")\n"
              << "Half a minute is " << halfmin.count() << " minutes"
                 " (" << halfmin << ")\n";
}
```

Output:

```text
One lesson is 45 minutes (45min)
Half a minute is 0.5 minutes (0.5min)
```
