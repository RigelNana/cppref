{/* source:cpp-chrono-duration-abs:0001 */}
Returns the absolute value of the duration `d`. Specifically, if `d >= d.zero()`, return `d`, otherwise return `-d`.

{/* source:cpp-chrono-duration-abs:0002 */}
The function does not participate in the overload resolution unless `std::numeric_limits<Rep>::is_signed` is `true`.

## Parameters

{/* source:cpp-chrono-duration-abs:0003 */}
<ParameterList>
  <Parameter name="d">duration</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-duration-abs:0004 */}
Absolute value of `d`.

## Possible implementation

{/* source:cpp-chrono-duration-abs:0005 */}
```cpp
template<class Rep, class Period,
    class = std::enable_if_t<std::numeric_limits<Rep>::is_signed>>
constexpr std::chrono::duration<Rep, Period> abs(std::chrono::duration<Rep, Period> d)
{
    return d >= d.zero() ? +d : -d;
}
```

## Example

{/* source:cpp-chrono-duration-abs:0006 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono;

    static_assert(abs(-42s) == std::chrono::abs(42s));

    std::cout << "abs(+3min) = " << abs(3min).count() << '\n'
              << "abs(-3min) = " << abs(-3min).count() << '\n';
}
```

Output:

```text
abs(+3min) = 3
abs(-3min) = 3
```
