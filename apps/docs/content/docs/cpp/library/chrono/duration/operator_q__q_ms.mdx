{/* source:cpp-chrono-operator-q-q-ms:0001 */}
Forms a [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal representing milliseconds.

{/* source:cpp-chrono-operator-q-q-ms:0002 */}
1) Integer literal, returns exactly `std::chrono::milliseconds(ms)`.

{/* source:cpp-chrono-operator-q-q-ms:0003 */}
2) Floating-point literal, returns a floating-point duration equivalent to [`std::chrono::milliseconds`](/docs/cpp/library/chrono/duration).

## Parameters

{/* source:cpp-chrono-operator-q-q-ms:0004 */}
<ParameterList>
  <Parameter name="ms">the number of milliseconds</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-operator-q-q-ms:0005 */}
The [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal.

## Possible implementation

{/* source:cpp-chrono-operator-q-q-ms:0006 */}
```cpp
constexpr std::chrono::milliseconds operator""ms(unsigned long long ms)
{
    return std::chrono::milliseconds(ms);
}
constexpr std::chrono::duration<long double, std::milli> operator""ms(long double ms)
{
    return std::chrono::duration<long double, std::milli>(ms);
}
```

## Notes

{/* source:cpp-chrono-operator-q-q-ms:0007 */}
This operator is declared in the namespace `std::literals::chrono_literals`, where both `literals` and `chrono_literals` are [inline namespaces](/docs/cpp/language/declarations/namespace#Inline_namespaces). Access to this operator can be gained with:

{/* source:cpp-chrono-operator-q-q-ms:0008 */}
- `using namespace std::literals`,
- `using namespace std::chrono_literals`, or
- `using namespace std::literals::chrono_literals`.

{/* source:cpp-chrono-operator-q-q-ms:0009 */}
In addition, within the namespace `std::chrono`, the directive `using namespace literals::chrono_literals;` is provided by the [standard library](/docs/cpp/library/standard_library), so that if a programmer uses `using namespace std::chrono;` to gain access to the classes in the [chrono library](/docs/cpp/library/chrono), the corresponding literal operators become visible as well.

## Example

{/* source:cpp-chrono-operator-q-q-ms:0010 */}
```cpp
#include <chrono>
#include <iostream>
 
int main()
{
    using namespace std::chrono_literals;
    constexpr auto d1{250ms};
    constexpr std::chrono::milliseconds d2{1s};
    std::cout << d1 << " = " << d1.count() << " milliseconds\n"
              << d2 << " = " << d2.count() << " milliseconds\n";
}
```

Output:

```text
250ms = 250 milliseconds
1000ms = 1000 milliseconds
```
