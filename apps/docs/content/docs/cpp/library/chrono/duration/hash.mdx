{/* source:cpp-chrono-duration-hash:0001 */}
The template specialization of [`std::hash`](/docs/cpp/library/utility/hash) for [`std::chrono::duration`](/docs/cpp/library/chrono/duration) allows users to obtain hashes of objects of type `std::chrono::duration<Rep, Period>`. This specialization is [`enabled`](/docs/cpp/library/utility/hash) if and only if both `std::hash<Rep>` and `std::hash<Period>` are enabled.
