Returns a duration with the lowest possible value.

{/* source:cpp-chrono-duration-min:0002 */}
If the representation `rep` of the duration requires some other implementation to return a minimum-length duration, [`std::chrono::duration_values`](/docs/cpp/library/chrono/duration/../duration_values) can be specialized to return the desired value.

## Parameters

{/* source:cpp-chrono-duration-min:0003 */}
(none)

## Return value

{/* source:cpp-chrono-duration-min:0004 */}
`duration(std::chrono::duration_values<rep>::min())`
