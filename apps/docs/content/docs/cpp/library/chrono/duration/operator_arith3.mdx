{/* source:cpp-chrono-duration-operator-arith3:0001 */}
Performs compound assignments between two durations with the same period or between a duration and a tick count value.

{/* source:cpp-chrono-duration-operator-arith3:0002 */}
If `rep_` is the member variable holding the number of ticks in this duration object,

{/* source:cpp-chrono-duration-operator-arith3:0003 */}
1. Equivalent to `rep_ += d.count(); return *this;`.

{/* source:cpp-chrono-duration-operator-arith3:0004 */}
2. Equivalent to `rep_ -= d.count(); return *this;`.

{/* source:cpp-chrono-duration-operator-arith3:0005 */}
3. Equivalent to `rep_ *= rhs; return *this;`.

{/* source:cpp-chrono-duration-operator-arith3:0006 */}
4. Equivalent to `rep_ /= rhs; return *this;`.

{/* source:cpp-chrono-duration-operator-arith3:0007 */}
5. Equivalent to `rep_ %= rhs; return *this;`.

{/* source:cpp-chrono-duration-operator-arith3:0008 */}
6. Equivalent to `rep_ %= d.count(); return *this;`.

## Parameters

{/* source:cpp-chrono-duration-operator-arith3:0009 */}
<ParameterList>
  <Parameter name="d">duration on the right-hand side of the operator</Parameter>
  <Parameter name="rhs">number of ticks on the right-hand side of the operator</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-duration-operator-arith3:0010 */}
A reference to this duration after modification.

## Example

{/* source:cpp-chrono-duration-operator-arith3:0011 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    std::chrono::minutes m(11);
    m *= 2;
    m += std::chrono::hours(10); // hours implicitly convert to minutes
    std::cout << m.count() << " minutes equals "
              << std::chrono::duration_cast<std::chrono::hours>(m).count() 
              << " hours and ";
    m %= std::chrono::hours(1);
    std::cout << m.count() << " minutes\n";
}
```

Output:

```text
622 minutes equals 10 hours and 22 minutes
```
