{/* source:cpp-chrono-operator-q-q-s:0001 */}
Forms a [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal representing seconds.

{/* source:cpp-chrono-operator-q-q-s:0002 */}
1) Integer literal, returns exactly `std::chrono::seconds(secs)`.

{/* source:cpp-chrono-operator-q-q-s:0003 */}
2) Floating-point literal, returns a floating-point duration equivalent to [`std::chrono::seconds`](/docs/cpp/library/chrono/duration).

## Parameters

{/* source:cpp-chrono-operator-q-q-s:0004 */}
<ParameterList>
  <Parameter name="secs">the number of seconds</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-operator-q-q-s:0005 */}
The [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal.

## Possible implementation

{/* source:cpp-chrono-operator-q-q-s:0006 */}
```cpp
constexpr std::chrono::seconds operator""s(unsigned long long s)
{
    return std::chrono::seconds(s);
}
constexpr std::chrono::duration<long double> operator""s(long double s)
{
    return std::chrono::duration<long double>(s);
}
```

## Notes

{/* source:cpp-chrono-operator-q-q-s:0007 */}
This operator is declared in the namespace `std::literals::chrono_literals`, where both `literals` and `chrono_literals` are [inline namespaces](/docs/cpp/language/declarations/namespace#Inline_namespaces). Access to this operator can be gained with:

{/* source:cpp-chrono-operator-q-q-s:0008 */}
- `using namespace std::literals`,
- `using namespace std::chrono_literals`, or
- `using namespace std::literals::chrono_literals`.

{/* source:cpp-chrono-operator-q-q-s:0009 */}
In addition, within the namespace `std::chrono`, the directive `using namespace literals::chrono_literals;` is provided by the [standard library](/docs/cpp/library/standard_library), so that if a programmer uses `using namespace std::chrono;` to gain access to the classes in the [chrono library](/docs/cpp/library/chrono), the corresponding literal operators become visible as well.

{/* source:cpp-chrono-operator-q-q-s:0010 */}
[`std::string`](/docs/cpp/library/string/basic_string) also defines `operator""s`, to represent literal objects of type `std::string`, but it is a string literal: `10s` is ten seconds, but `"10"s` is a two-character string.

## Example

{/* source:cpp-chrono-operator-q-q-s:0011 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono_literals;
    std::chrono::seconds halfmin = 30s;
    std::cout << "Half a minute is " << halfmin.count() << " seconds"
        " (" << halfmin << ").\n"
        "A minute and a second is " << (1min + 1s).count() << " seconds.\n";

    std::chrono::duration moment = 0.1s;
    std::cout << "A moment is " << moment.count() << " seconds"
        " (" << moment << ").\n"
        "And thrice as much is " << (moment + 0.2s).count() << " seconds.\n";
}
```

Output:

```text
Half a minute is 30 seconds (30s).
A minute and a second is 61 seconds.
A moment is 0.1 seconds (0.1s).
And thrice as much is 0.3 seconds.
```
