{/* source:cpp-chrono-operator-q-q-h:0001 */}
Forms a [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal representing hours.

{/* source:cpp-chrono-operator-q-q-h:0002 */}
1. Integer literal, returns exactly `std::chrono::hours(hrs)`.

{/* source:cpp-chrono-operator-q-q-h:0003 */}
2. Floating-point literal, returns a floating-point duration equivalent to [`std::chrono::hours`](/docs/cpp/library/chrono/duration).

## Parameters

{/* source:cpp-chrono-operator-q-q-h:0004 */}
<ParameterList>
  <Parameter name="hrs">the number of hours</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-operator-q-q-h:0005 */}
The [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal.

## Possible implementation

{/* source:cpp-chrono-operator-q-q-h:0006 */}
```cpp
constexpr std::chrono::hours operator""h(unsigned long long h)
{
    return std::chrono::hours(h);
}

constexpr std::chrono::duration<long double, ratio<3600,1>> operator""h(long double h)
{
    return std::chrono::duration<long double, std::ratio<3600,1>>(h);
}
```

## Notes

{/* source:cpp-chrono-operator-q-q-h:0007 */}
This operator is declared in the namespace `std::literals::chrono_literals`, where both `literals` and `chrono_literals` are [inline namespaces](/docs/cpp/language/declarations/namespace#Inline_namespaces). Access to this operator can be gained with:

{/* source:cpp-chrono-operator-q-q-h:0008 */}
- `using namespace std::literals`,
- `using namespace std::chrono_literals`, or
- `using namespace std::literals::chrono_literals`.

{/* source:cpp-chrono-operator-q-q-h:0009 */}
In addition, within the namespace `std::chrono`, the directive `using namespace literals::chrono_literals;` is provided by the [standard library](/docs/cpp/library/standard_library), so that if a programmer uses `using namespace std::chrono;` to gain access to the classes in the [chrono library](/docs/cpp/library/chrono), the corresponding literal operators become visible as well.

## Example

{/* source:cpp-chrono-operator-q-q-h:0010 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono_literals;
    auto day = 24h;
    auto halfhour = 0.5h;
    std::cout << "one day is " << day.count() << " hours (" << day << ")\n"
              << "half an hour is " << halfhour.count() << " hours ("
              << halfhour << ")\n";
}
```

Output:

```text
one day is 24 hours (24h)
half an hour is 0.5 hours (0.5h)
```
