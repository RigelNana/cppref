{/* source:cpp-chrono-operator-q-q-us:0001 */}
Forms a [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal representing microseconds.

{/* source:cpp-chrono-operator-q-q-us:0002 */}
1. Integer literal, returns exactly `std::chrono::microseconds(us)`.

{/* source:cpp-chrono-operator-q-q-us:0003 */}
2. Floating-point literal, returns a floating-point duration equivalent to [`std::chrono::microseconds`](/docs/cpp/library/chrono/duration).

### Parameters

{/* source:cpp-chrono-operator-q-q-us:0004 */}
<ParameterList>
  <Parameter name="us">the number of microseconds</Parameter>
</ParameterList>

### Return value

{/* source:cpp-chrono-operator-q-q-us:0005 */}
The [`std::chrono::duration`](/docs/cpp/library/chrono/duration) literal.

### Possible implementation

{/* source:cpp-chrono-operator-q-q-us:0006 */}
```cpp
constexpr std::chrono::microseconds operator""us(unsigned long long us)
{
    return std::chrono::microseconds(us);
}
constexpr std::chrono::duration<long double, std::micro> operator""us(long double us)
{
    return std::chrono::duration<long double, std::micro>(us);
}
```

### Notes

{/* source:cpp-chrono-operator-q-q-us:0007 */}
This operator is declared in the namespace `std::literals::chrono_literals`, where both `literals` and `chrono_literals` are [inline namespaces](/docs/cpp/language/declarations/namespace#Inline_namespaces). Access to this operator can be gained with:

{/* source:cpp-chrono-operator-q-q-us:0008 */}
- `using namespace std::literals`,
- `using namespace std::chrono_literals`, or
- `using namespace std::literals::chrono_literals`.

{/* source:cpp-chrono-operator-q-q-us:0009 */}
In addition, within the namespace `std::chrono`, the directive `using namespace literals::chrono_literals;` is provided by the [standard library](/docs/cpp/library/standard_library), so that if a programmer uses `using namespace std::chrono;` to gain access to the classes in the [`chrono library`](/docs/cpp/library/chrono), the corresponding literal operators become visible as well.

### Example

{/* source:cpp-chrono-operator-q-q-us:0010 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono_literals;
    auto d1 = 250us;
    std::chrono::microseconds d2 = 1ms;
    std::cout << d1 << " = " << d1.count() << " microseconds\n"
              << 1ms << " = " << d2.count() << " microseconds\n";
}
```

Output:

```text
250us = 250 microseconds
1ms = 1000 microseconds
```
