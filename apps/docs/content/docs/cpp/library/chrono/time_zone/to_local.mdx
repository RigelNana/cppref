{/* source:cpp-chrono-time-zone-to-local:0001 */}
Converts the `sys_time` `tp` to the corresponding `local_time` in this time zone.

## Return value

{/* source:cpp-chrono-time-zone-to-local:0002 */}
The `local_time` associated with `tp` and this time zone.

## Notes

{/* source:cpp-chrono-time-zone-to-local:0003 */}
The precision of the result is at least [`std::chrono::seconds`](/docs/cpp/library/chrono/duration), and will be finer if the argument has finer precision.
