Constructs a `month_weekday_last` object that stores the [`month`](/docs/cpp/library/chrono/month) `m` and the [`weekday_last`](/docs/cpp/library/chrono/weekday_last) `wdl`.

## Notes

{/* source:cpp-chrono-month-weekday-last-month-weekday-last:0002 */}
A more convenient way to construct a `month_weekday_last` is with `operator/`, e.g., `std::chrono::April/std::chrono::Sunday[std::chrono::last]`.
