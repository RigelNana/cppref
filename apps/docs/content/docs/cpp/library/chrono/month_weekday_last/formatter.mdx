Specialization of [`std::formatter`](/docs/cpp/library/text/format/formatter) that defines formatting rules for `std::chrono::month_weekday_last`.

{/* source:cpp-chrono-month-weekday-last-formatter:0002 */}
The [`std::formatter`](/docs/cpp/library/text/format/formatter) specialization is usually not directly accessed, but is used through [formatting functions](/docs/cpp/library/text/format).

## Format specification

{/* source:cpp-chrono-month-weekday-last-formatter:0003 */}
The format specification has the form

{/* source:cpp-chrono-month-weekday-last-formatter:0004 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="fill-and-align (optional) width (optional) precision (optional) L (optional) chrono-spec (optional)" />
</DeclarationDoc>

{/* source:cpp-chrono-month-weekday-last-formatter:0005 */}
fill-and-align, width, and precision have the same meaning as in [standard format specification](/docs/cpp/library/text/format/formatter#Standard_format_specification). precision is valid only for [`std::chrono::duration`](/docs/cpp/library/chrono/duration) types where the representation type `Rep` is a floating-point type, otherwise [`std::format_error`](/docs/cpp/library/text/format/format_error) is thrown.

{/* source:cpp-chrono-month-weekday-last-formatter:0006 */}
The locale used for formatting is determined as follows:

{/* source:cpp-chrono-month-weekday-last-formatter:0007 */}
- the default `"C"` locale if `L` is not present in the format specification,
- otherwise, the locale denoted by the [`std::locale`](/docs/cpp/library/text/locale/locale) passed to the formatting function, if any,
- otherwise (`L` is present but no [`std::locale`](/docs/cpp/library/text/locale/locale) is passed to the formatting function), the global locale.

{/* source:cpp-chrono-month-weekday-last-formatter:0008 */}
If the [(ordinary or wide) string literal encoding](/docs/cpp/language/basic_concepts/charset#Code_unit_and_literal_encoding) is a Unicode encoding form and the locale is among an implementation-defined set of locales, each replacement that depends on the locale is performed as if the replacement character sequence is converted to the literal encoding.

{/* source:cpp-chrono-month-weekday-last-formatter:0009 */}
The chrono-spec consists of one or more conversion specifiers and ordinary characters (other than `{`, `}`, and `%`). A chrono-spec must start with a conversion specifier. All ordinary characters are written to the output without modification. Each unmodified conversion specifier begins with a `%` character followed by a character that determines the behavior of the specifier. Some conversion specifiers have a modified form in which an `E` or `O` modifier character is inserted after the `%` character. Each conversion specifier is replaced by appropriate characters in the output as described below.

{/* source:cpp-chrono-month-weekday-last-formatter:0010 */}
If the chrono-spec is empty, the chrono object is formatted as if by [streaming](/docs/cpp/library/chrono/month_weekday_last/operator_ltlt) it to an object `os` of type `std::basic_ostringstream<CharT>` with the formatting locale (one of `std::locale::classic()`, the passed [`std::locale`](/docs/cpp/library/text/locale/locale) object, and `std::locale::global()`) [imbued](/docs/cpp/library/io/ios_base/imbue) and copying `os.str()` to the output buffer with additional padding and adjustments as per format specifiers.

{/* source:cpp-chrono-month-weekday-last-formatter:0011 */}
The following format specifiers are available:

{/* source:cpp-chrono-month-weekday-last-formatter:0012 */}
| Conversion specifier | Explanation |
| --- | --- |
| `%%` | Writes a literal `%` character. |
| `%n` | Writes a newline character. |
| `%t` | Writes a horizontal tab character. |
| Month |  |
| `%b` <br /> `%h` | Writes the locale's abbreviated month name. |
| `%B` | Writes the locale's full month name. |
| `%m` <br /> `%Om` | Writes the month as a decimal number (January is `01`). If the result is a single digit, it is prefixed with 0.<br />The modified command `%Om` writes the locale's alternative representation. |
| Day of the week |  |
| `%a` | Writes the locale's abbreviated weekday name. |
| `%A` | Writes the locale's full weekday name. |
| `%u` <br /> `%Ou` | Writes the ISO weekday as a decimal number (1-7), where Monday is `1`.<br />The modified command `%Ou` writes the locale's alternative representation. |
| `%w` <br /> `%Ow` | Writes the weekday as a decimal number (0-6), where Sunday is `0`.<br />The modified command `%Ow` writes the locale's alternative representation. |

| `%e` <br /> `%Oe` | Writes the day of month as a decimal number. If the result is a single decimal digit, it is prefixed with a space.<br />The modified command `%Oe` writes the locale's alternative representation. |

| `%V` <br /> `%OV` | Writes the ISO 8601 week of the year as a decimal number. If the result is a single digit, it is prefixed with 0.<br />The modified command `%OV` writes the locale's alternative representation. |
| Week/day of the year |  |

If the result is a single digit, it is prefixed with 0.<br />The modified command `%OU` writes the locale's alternative representation. |

If the result is a single digit, it is prefixed with 0.<br />The modified command `%OW` writes the locale's alternative representation. |
| Date |  |
| `%D` | Equivalent to `"%m/%d/%y"`. |
| `%F` | Equivalent to `"%Y-%m-%d"`. |
| `%x` <br /> `%Ex` | Writes the locale's date representation.<br />The modified command `%Ex` produces the locale's alternate date representation. |
| Time of day |  |
| `%H` <br /> `%OH` | Writes the hour (24-hour clock) as a decimal number. If the result is a single digit, it is prefixed with 0.<br />The modified command `%OH` writes the locale's alternative representation. |
| `%I` <br /> `%OI` | Writes the hour (12-hour clock) as a decimal number. If the result is a single digit, it is prefixed with 0.<br />The modified command `%OI` writes the locale's alternative representation. |
| `%M` <br /> `%OM` | Writes the minute as a decimal number. If the result is a single digit, it is prefixed with 0.<br />The modified command `%OM` writes the locale's alternative representation. |

If the number of seconds is less than 10, the result is prefixed with 0.<br />If the precision of the input cannot be exactly represented with seconds, then the format is a decimal floating-point number with a fixed format and a precision matching that of the precision of the input (or to a microseconds precision if the conversion to floating-point decimal seconds cannot be made within 18 fractional digits). The character for the decimal point is localized according to the locale.<br />The modified command `%OS` writes the locale's alternative representation. |
