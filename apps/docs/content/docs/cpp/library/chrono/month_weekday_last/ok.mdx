{/* source:cpp-chrono-month-weekday-last-ok:0001 */}
Checks if the contained [`month`](/docs/cpp/library/chrono/month) and [`weekday_last`](/docs/cpp/library/chrono/weekday_last) objects are valid.

## Return value

{/* source:cpp-chrono-month-weekday-last-ok:0002 */}
`month().ok() && weekday_last().ok()`

## Example

{/* source:cpp-chrono-month-weekday-last-ok:0003 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    auto mwdl{std::chrono::March/std::chrono::Wednesday[std::chrono::last]};
    std::cout << (mwdl.ok()) << ' ';
    mwdl = {std::chrono::month(3)/std::chrono::weekday(42)[std::chrono::last]}; 
    std::cout << (mwdl.ok()) << '\n';
}
```

Output:

```text
true false
```
