{/* source:cpp-chrono-tzdb-locate-zone:0001 */}
Obtains a pointer to a `std::chrono::time_zone` in this database that represents the time zone designated by `tz_name`. If `p` is the returned pointer, then either `p->name() == tz_name` or that there is a [`std::chrono::time_zone_link`](/docs/cpp/library/chrono/time_zone_link) `l` in this database such that `p->name() == l.target() && l.name() == tz_name`.

## Return value

{/* source:cpp-chrono-tzdb-locate-zone:0002 */}
A pointer to the `std::chrono::time_zone` in this database that represents the time zone designated by `tz_name`.

## Exceptions

{/* source:cpp-chrono-tzdb-locate-zone:0003 */}
Throws [`std::runtime_error`](/docs/cpp/library/error/runtime_error) if no such `time_zone` can be found.
