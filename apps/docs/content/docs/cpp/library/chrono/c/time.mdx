{/* source:cpp-chrono-c-time:0001 */}
Returns the current calendar time encoded as a [`std::time_t`](/docs/cpp/library/chrono/c/time_t) object, and also stores it in the object pointed to by `arg`, unless `arg` is a null pointer.

## Parameters

{/* source:cpp-chrono-c-time:0002 */}
<ParameterList>
  <Parameter name="arg">pointer to a [`std::time_t`](/docs/cpp/library/chrono/c/time_t) object to store the time, or a null pointer</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-c-time:0003 */}
Current calendar time encoded as `std::time_t` object on success, `(std::time_t)(-1)` on error. If `arg` is not null, the return value is also stored in the object pointed to by `arg`.

## Notes

{/* source:cpp-chrono-c-time:0004 */}
The encoding of calendar time in [`std::time_t`](/docs/cpp/library/chrono/c/time_t) is unspecified, but most systems conform to the [POSIX specification](https://pubs.opengroup.org/onlinepubs/9799919799/functions/time.html) and return a value of integral type holding `86400` times the number of calendar days since [the Epoch](https://pubs.opengroup.org/onlinepubs/9799919799/basedefs/V1_chap04.html#tag_04_16) plus the number of seconds that have passed since the last midnight UTC. Most notably, POSIX time does not (and can not) take leap seconds into account, so that this integral value is not equal to the number of [S.I. seconds](https://en.wikipedia.org/wiki/SI_base_unit#Definitions) that have passed since the epoch, but rather is reduced with the number of leap seconds that have occurred since the epoch. Implementations in which [`std::time_t`](/docs/cpp/library/chrono/c/time_t) is a 32-bit signed integer (many historical implementations) fail in the year [2038](https://en.wikipedia.org/wiki/Year_2038_problem).

## Example

{/* source:cpp-chrono-c-time:0005 */}
```cpp
#include <ctime>
#include <iostream>

int main()
{
    std::time_t result = std::time(nullptr);
    std::cout << std::asctime(std::localtime(&result))
              << result << " seconds since the Epoch\n";
}
```

Possible output:

```text
Wed Sep 21 10:27:52 2011
1316615272 seconds since the Epoch
```
