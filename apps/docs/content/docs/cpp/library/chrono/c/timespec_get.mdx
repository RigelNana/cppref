  <Declaration id="2" language="cpp" since="C++17" code={`#define TIME_UTC /* implementation-defined */`} />

{/* source:cpp-chrono-c-timespec-get:0001 */}
1. Modifies the [`std::timespec`](/docs/cpp/library/chrono/c/timespec) object pointed to by `ts` to hold the current calendar time in the time base `base`.

{/* source:cpp-chrono-c-timespec-get:0002 */}
2. Expands to a value suitable for use as the `base` argument of `std::timespec_get`.

{/* source:cpp-chrono-c-timespec-get:0003 */}
Other macro constants beginning with `TIME_` may be provided by the implementation to indicate additional time bases.

{/* source:cpp-chrono-c-timespec-get:0004 */}
If `base` is `TIME_UTC`, then

{/* source:cpp-chrono-c-timespec-get:0005 */}
- `ts->tv_sec` is set to the number of seconds since an implementation defined epoch, truncated to a whole value,
- `ts->tv_nsec` member is set to the integral number of nanoseconds, rounded to the resolution of the system clock.

## Parameters

{/* source:cpp-chrono-c-timespec-get:0006 */}
<ParameterList>
  <Parameter name="ts">pointer to an object of type [`std::timespec`](/docs/cpp/library/chrono/c/timespec)</Parameter>
  <Parameter name="base">`TIME_UTC` or another nonzero integer value indicating the time base</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-c-timespec-get:0007 */}
The value of `base` if successful, zero otherwise.

## Notes

{/* source:cpp-chrono-c-timespec-get:0008 */}
The POSIX function [`clock_gettime(CLOCK_REALTIME, ts)`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/clock_getres.html) may also be used to populate a `std::timespec` with the time since the Epoch.

## Example

{/* source:cpp-chrono-c-timespec-get:0009 */}
```cpp
#include <ctime>
#include <iostream>

int main()
{
    std::timespec ts;
    std::timespec_get(&ts, TIME_UTC);
    char buf[100];
    std::strftime(buf, sizeof buf, "%D %T", std::gmtime(&ts.tv_sec));
    std::cout << "Current time: " << buf << '.' << ts.tv_nsec << " UTC\n";
}
```

Possible output:

```text
Current time: 06/24/16 20:07:42.949494132 UTC
```
