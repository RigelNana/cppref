{/* source:cpp-chrono-c-ctime:0001 */}
Converts given time since epoch to a calendar local time and then to a textual representation, as if by calling `std::asctime(std::localtime(time))`. The resulting string has the following format:

{/* source:cpp-chrono-c-ctime:0002 */}
```text
Www Mmm dd hh:mm:ss yyyy\n
```

{/* source:cpp-chrono-c-ctime:0003 */}
- `Www` - the day of the week (one of `Mon`, `Tue`, `Wed`, `Thu`, `Fri`, `Sat`, `Sun`).
- `Mmm` - the month (one of `Jan`, `Feb`, `Mar`, `Apr`, `May`, `Jun`, `Jul`, `Aug`, `Sep`, `Oct`, `Nov`, `Dec`).
- `dd` - the day of the month.
- `hh` - hours.
- `mm` - minutes.
- `ss` - seconds.
- `yyyy` - years.

{/* source:cpp-chrono-c-ctime:0004 */}
The function does not support localization.

## Parameters

{/* source:cpp-chrono-c-ctime:0005 */}
<ParameterList>
  <Parameter name="time">pointer to a [`std::time_t`](/docs/cpp/library/chrono/c/time_t) object specifying the time to print</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-c-ctime:0006 */}
Pointer to a static null-terminated character string holding the textual representation of date and time. The string may be shared between [`std::asctime`](/docs/cpp/library/chrono/c/asctime) and `std::ctime`, and may be overwritten on each invocation of any of those functions.

## Notes

{/* source:cpp-chrono-c-ctime:0007 */}
This function returns a pointer to static data and is not thread-safe. In addition, it modifies the static [`std::tm`](/docs/cpp/library/chrono/c/tm) object which may be shared with [`std::gmtime`](/docs/cpp/library/chrono/c/gmtime) and [`std::localtime`](/docs/cpp/library/chrono/c/localtime). POSIX marks this function obsolete and recommends [`std::strftime`](/docs/cpp/library/chrono/c/strftime) instead.

{/* source:cpp-chrono-c-ctime:0008 */}
The behavior may be undefined for the values of [`std::time_t`](/docs/cpp/library/chrono/c/time_t) that result in the string longer than 25 characters (e.g. year 10000).

## Example

{/* source:cpp-chrono-c-ctime:0009 */}
```cpp
#include <cassert>
#include <cstring>
#include <ctime>
#include <iostream>
 
int main()
{
    std::time_t result = std::time(nullptr);
    std::cout << std::ctime(&result);
 
    char buffer[32];
    std::strncpy(buffer, std::ctime(&result), 26);
    assert('\n' == buffer[std::strlen(buffer) - 1]);
    std::cout << buffer;
}
```

Possible output:

```text
Mon Oct 11 17:10:55 2021
Mon Oct 11 17:10:55 2021
```
