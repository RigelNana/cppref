{/* source:cpp-chrono:0000 */}
C++ includes support for two types of time manipulation:

{/* source:cpp-chrono:0001 */}
- The chrono library, a flexible collection of types that track time with varying degrees of precision (e.g. [`std::chrono::time_point`](/docs/cpp/library/chrono/time_point)).
- C-style date and time library (e.g. [`std::time`](/docs/cpp/library/chrono/c/time)).

## Chrono library (since C++11)

{/* source:cpp-chrono:0002 */}
The chrono library defines <InlineRevision until="C++20">three</InlineRevision> <InlineRevision since="C++20">five</InlineRevision> main types as well as utility functions and common typedefs:

{/* source:cpp-chrono:0003 */}
- clocks
- time points
- durations

{/* source:cpp-chrono:0004 */}
<Revision since="C++20">
- calendar dates
- time zone information
</Revision>

### Duration

{/* source:cpp-chrono:0009 */}
A duration consists of a span of time, defined as some number of ticks of some time unit. For example, "42 seconds" could be represented by a duration consisting of 42 ticks of a 1-second time unit.

## C-style date and time library

{/* source:cpp-chrono:0018 */}
Also provided are the C-style date and time functions, such as [`std::time_t`](/docs/cpp/library/chrono/c/time_t), [`std::difftime`](/docs/cpp/library/chrono/c/difftime), and [`CLOCKS_PER_SEC`](/docs/cpp/library/chrono/c/CLOCKS_PER_SEC).

## Example

{/* source:cpp-chrono:0019 */}
Measures and displays an execution time of a function call.

```cpp
#include <chrono>
#include <iostream>

long Fibonacci(unsigned n)
{
    return n < 2 ? n : Fibonacci(n - 1) + Fibonacci(n - 2);
}

int main()
{
    const auto start{std::chrono::steady_clock::now()};
    const auto fb{Fibonacci(42)};
    const auto end{std::chrono::steady_clock::now()};
    const std::chrono::duration<double> elapsed_seconds{end - start};

    std::cout << "Fibonacci(42): " << fb << "\nElapsed time: ";
//  std::cout << elapsed_seconds.count() << "s\n"; // Before C++20
    std::cout << elapsed_seconds << '\n'; // C++20's chrono::duration operator<<
}
```

Possible output:

```text
Fibonacci(42): 267914296
Elapsed time: 0.791429s
```
