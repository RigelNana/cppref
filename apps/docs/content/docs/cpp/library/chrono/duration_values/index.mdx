{/* source:cpp-chrono-duration-values:0001 */}
The `std::chrono::duration_values` type defines three common durations:

{/* source:cpp-chrono-duration-values:0002 */}
- `std::chrono::duration_values::zero`
- `std::chrono::duration_values::min`
- `std::chrono::duration_values::max`

{/* source:cpp-chrono-duration-values:0003 */}
The [`zero`](/docs/cpp/library/chrono/duration/zero), [`min`](/docs/cpp/library/chrono/duration/min), and [`max`](/docs/cpp/library/chrono/duration/max) static member functions in [`std::chrono::duration`](/docs/cpp/library/chrono/duration) forward their work to these functions.

{/* source:cpp-chrono-duration-values:0004 */}
This type can be specialized if the representation `Rep` requires a specific implementation to return these duration objects.
