{/* source:cpp-chrono-year-month-weekday-last-operator-ltlt:0001 */}
Outputs a textual representation of `ymwdl` into `os`, as if by

{/* source:cpp-chrono-year-month-weekday-last-operator-ltlt:0002 */}
```cpp
os << std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{}/{:L}/{:L}"),
         ymwdl.year(), ymwdl.month(), ymwdl.weekday_last());
```

{/* source:cpp-chrono-year-month-weekday-last-operator-ltlt:0003 */}
where `STATICALLY_WIDEN<CharT>("{}/{:L}/{:L}")` is `"{}/{:L}/{:L}"` if `CharT` is `char`, and `L"..."` if `CharT` is `wchar_t`.

## Return value

{/* source:cpp-chrono-year-month-weekday-last-operator-ltlt:0004 */}
`os`
