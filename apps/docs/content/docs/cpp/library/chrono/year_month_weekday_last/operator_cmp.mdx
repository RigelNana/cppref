Compares the two `year_month_weekday_last` values `x` and `y`.

{/* source:cpp-chrono-year-month-weekday-last-operator-cmp:0002 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

## Return value

{/* source:cpp-chrono-year-month-weekday-last-operator-cmp:0003 */}
`x.year() == y.year() && x.month() == y.month() && x.weekday() == y.weekday()`

## Example

{/* source:cpp-chrono-year-month-weekday-last-operator-cmp:0004 */}
```cpp
#include <chrono>
#include <iostream>
using namespace std::chrono;

int main()
{
    constexpr auto ymwdl1{Tuesday[last]/11/2021};
    auto ymwdl2 = Tuesday[last]/11/2020;
    ymwdl2 += months(12);
    std::cout << std::boolalpha << (ymwdl1 == ymwdl2) << '\n';
}
```

Output:

```text
true
```
