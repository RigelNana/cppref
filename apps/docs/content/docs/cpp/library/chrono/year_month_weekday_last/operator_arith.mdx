{/* source:cpp-chrono-year-month-weekday-last-operator-arith:0001 */}
Modifies the time point `*this` represents by the duration `dy` or `dm`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith:0002 */}
1. Equivalent to `*this = *this + dy;`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith:0003 */}
2. Equivalent to `*this = *this + dm;`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith:0004 */}
3. Equivalent to `*this = *this - dy;`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith:0005 */}
4. Equivalent to `*this = *this - dm;`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith:0006 */}
For durations that are convertible to both `std::chrono::years` and `std::chrono::months`, the years overloads (1,3) are preferred if the call would otherwise be ambiguous.

## Example

{/* source:cpp-chrono-year-month-weekday-last-operator-arith:0007 */}
```cpp
#include <chrono>
#include <iostream>

using namespace std::chrono;

int main()
{
    auto ymwdl{August/Friday[last]/2022};
    std::cout << year_month_day{ymwdl} << '\n';
    ymwdl += months(2);
    std::cout << year_month_day{ymwdl} << '\n';
    ymwdl -= years(1);
    std::cout << year_month_day{ymwdl} << '\n';
}
```

Output:

```text
2022-08-26
2022-10-28
2021-10-29
```
