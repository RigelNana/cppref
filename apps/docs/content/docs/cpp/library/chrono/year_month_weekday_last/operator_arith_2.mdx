{/* source:cpp-chrono-year-month-weekday-last-operator-arith-2:0001 */}
1,2) Adds `dm.count()` months to the date represented by `ymwdl`. The result has the same [`year()`](/docs/cpp/library/chrono/year_month_weekday_last/accessors) and [`month()`](/docs/cpp/library/chrono/year_month_weekday_last/accessors) as `std::chrono::year_month(ymwdl.year(), ymwdl.month()) + dm` and the same [`weekday()`](/docs/cpp/library/chrono/year_month_weekday_last/accessors) as `ymwdl`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith-2:0002 */}
3,4) Adds `dy.count()` years to the date represented by `ymwdl`. The result is equivalent to `std::chrono::year_month_weekday_last(ymwdl.year() + dy, ymwdl.month(), ymwd.weekday_last())`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith-2:0003 */}
5) Subtracts `dm.count()` months from the date represented by `ymwdl`. Equivalent to `ymwdl + -dm`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith-2:0004 */}
6) Subtracts `dy.count()` years from the date represented by `ymwdl`. Equivalent to `ymwdl + -dy`.

{/* source:cpp-chrono-year-month-weekday-last-operator-arith-2:0005 */}
For durations that are convertible to both `std::chrono::years` and `std::chrono::months`, the years overloads (3,4,6) are preferred if the call would otherwise be ambiguous.

## Example

{/* source:cpp-chrono-year-month-weekday-last-operator-arith-2:0006 */}
```cpp
#include <cassert>
#include <chrono>
using namespace std::chrono;

int main()
{
    constexpr auto ymwdl1{Tuesday[last]/11/2021};
    auto ymwdl2 = ymwdl1;
    ymwdl2 = std::chrono::months(12) + ymwdl2;
    ymwdl2 = ymwdl2 - std::chrono::years(1);
    assert(ymwdl1 == ymwdl2);
}
```
