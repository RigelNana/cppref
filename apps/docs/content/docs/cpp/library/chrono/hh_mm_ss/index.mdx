The class template `hh_mm_ss` splits a [`std::chrono::duration`](/docs/cpp/library/chrono/duration) into a "broken down" time such as hours:minutes:seconds, with the precision of the split determined by the `Duration` template parameter. It is primarily a formatting tool.

{/* source:cpp-chrono-hh-mm-ss:0002 */}
`Duration` must be a specialization of [`std::chrono::duration`](/docs/cpp/library/chrono/duration), otherwise the program is ill-formed.
