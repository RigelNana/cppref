{/* source:cpp-chrono-system-clock-from-time-t:0001 */}
Converts `t` to a time point type, using the coarser precision of the two types.

{/* source:cpp-chrono-system-clock-from-time-t:0002 */}
If `time_point` has lower precision, it is implementation defined whether the value is rounded or truncated.

## Parameters

{/* source:cpp-chrono-system-clock-from-time-t:0003 */}
<ParameterList>
  <Parameter name="t">[`std::time_t`](/docs/cpp/library/chrono/c/time_t) value to convert</Parameter>
</ParameterList>

## Return value

{/* source:cpp-chrono-system-clock-from-time-t:0004 */}
A value of type [`std::chrono::system_clock::time_point`](/docs/cpp/library/chrono/system_clock#Member_types) representing `t`.

## Example

{/* source:cpp-chrono-system-clock-from-time-t:0005 */}
```cpp
#include <chrono>
#include <ctime>
#include <iostream>
#include <thread>
 
int main()
{
    using namespace std::chrono_literals;
 
    const std::time_t t = std::time(nullptr); // usually has "1 second" precision
 
    const auto from = std::chrono::system_clock::from_time_t(t);
 
    std::this_thread::sleep_for(500ms);
 
    const auto diff = std::chrono::system_clock::now() - from;
 
    std::cout << diff << " ("
              << std::chrono::round<std::chrono::milliseconds>(diff)
              << ")\n";
}
```

Possible output:

```text
987654321ns (987ms)
```
