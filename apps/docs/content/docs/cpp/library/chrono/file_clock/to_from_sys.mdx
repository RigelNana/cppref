{/* source:cpp-chrono-file-clock-to-from-sys:0001 */}
1. Converts the `file_time` `t` to a `sys_time` representing the same point in time.

{/* source:cpp-chrono-file-clock-to-from-sys:0002 */}
2. Converts the `sys_time` `t` to a `file_time` representing the same point in time.

{/* source:cpp-chrono-file-clock-to-from-sys:0003 */}
The duration of the return type is computed from `Duration` in an unspecified manner.

{/* source:cpp-chrono-file-clock-to-from-sys:0004 */}
These function templates are optional: an implementation may choose to instead provide [`to_utc()`](/docs/cpp/library/chrono/file_clock/to_from_utc) and [`from_utc()`](/docs/cpp/library/chrono/file_clock/to_from_utc).

## Return value

{/* source:cpp-chrono-file-clock-to-from-sys:0005 */}
1. A `sys_time` representing the same point in time as the argument.

{/* source:cpp-chrono-file-clock-to-from-sys:0006 */}
2. A `file_time` representing the same point in time as the argument.

## Notes

{/* source:cpp-chrono-file-clock-to-from-sys:0007 */}
User code should usually use `std::chrono::clock_cast`, which provides a generic interface to convert time points between clocks, rather than call these functions directly.
