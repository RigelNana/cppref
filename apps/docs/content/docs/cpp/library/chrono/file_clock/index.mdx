{/* source:cpp-chrono-file-clock:0001 */}
`std::chrono::file_clock` is an alias for the clock used for [`std::filesystem::file_time_type`](/docs/cpp/library/filesystem/file_time_type). Its epoch is unspecified.

{/* source:cpp-chrono-file-clock:0002 */}
`file_clock` meets the [`TrivialClock`](/docs/cpp/library/named_req/TrivialClock) requirements.

## Member functions
