Compares the two `weekday_last` values `x` and `y`.

{/* source:cpp-chrono-weekday-last-operator-cmp:0002 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

## Return value

{/* source:cpp-chrono-weekday-last-operator-cmp:0003 */}
`x.weekday() == y.weekday()`

## Example

{/* source:cpp-chrono-weekday-last-operator-cmp:0004 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    constexpr auto wdl1{std::chrono::Tuesday[std::chrono::last]};
    constexpr std::chrono::weekday_last wdl2{std::chrono::weekday(2)};
    std::cout << std::boolalpha
              << (wdl1 == wdl2) << ' '
              << (wdl1 == std::chrono::Wednesday[std::chrono::last]) << '\n';
}
```

Output:

```text
true false
```
