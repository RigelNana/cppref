Checks if the weekday object stored in `*this` is valid.

## Return value

{/* source:cpp-chrono-weekday-last-ok:0002 */}
`weekday().ok()`

## Example

{/* source:cpp-chrono-weekday-last-ok:0003 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    auto wdl{std::chrono::Tuesday[std::chrono::last]};
    std::cout << (wdl.ok()) << ' ';

    wdl = {std::chrono::weekday(42)[std::chrono::last]};
    std::cout << (wdl.ok()) << '\n';
}
```

Output:

```text
true false
```
