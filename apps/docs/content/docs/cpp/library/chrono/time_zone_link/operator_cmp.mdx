Compares the two `time_zone_link` values `x` and `y` by name.

{/* source:cpp-chrono-time-zone-link-operator-cmp:0002 */}
The \<, \<=, \>, and \>= operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-time-zone-link-operator-cmp:0003 */}
1. `x.name() == y.name()`

{/* source:cpp-chrono-time-zone-link-operator-cmp:0004 */}
2. `x.name() <=> y.name()`
