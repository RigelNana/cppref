{/* source:cpp-chrono-gps-clock:0001 */}
The clock `std::chrono::gps_clock` is a [Clock](/docs/cpp/library/named_req/Clock) that represents Global Positioning System (GPS) time. It measures time since 00:00:00, 6 January 1980 UTC.

{/* source:cpp-chrono-gps-clock:0002 */}
Leap seconds are not inserted into GPS. Thus, every time a leap second is inserted into UTC, UTC falls another second behind GPS. As of December 2017, UTC is 18 seconds behind GPS, reflecting the 18 leap seconds inserted between 1980 and 2017. Thus, 2018-01-01 00:00:00 UTC is equivalent to 2018-01-01 00:00:18 GPS. GPS is a constant 19 seconds behind [TAI](/docs/cpp/library/chrono/tai_clock).

{/* source:cpp-chrono-gps-clock:0003 */}
`gps_clock` meets the [Clock](/docs/cpp/library/named_req/Clock) requirements. It does not meet the [TrivialClock](/docs/cpp/library/named_req/TrivialClock) requirements unless the implementation can guarantee that [`now()`](/docs/cpp/library/chrono/gps_clock/now) does not throw an exception.
