{/* source:cpp-chrono-year-operator-inc-dec:0001 */}
Adds or subtracts 1 from the year value.

{/* source:cpp-chrono-year-operator-inc-dec:0002 */}
1,2) Performs `*this += std::chrono::years{1};`.

{/* source:cpp-chrono-year-operator-inc-dec:0003 */}
3,4) Performs `*this -= std::chrono::years{1};`.

## Parameters

{/* source:cpp-chrono-year-operator-inc-dec:0004 */}
(none)

## Return value

{/* source:cpp-chrono-year-operator-inc-dec:0005 */}
1,3) A reference to this year after modification.

{/* source:cpp-chrono-year-operator-inc-dec:0006 */}
2,4) A copy of the year made before modification.

## Notes

{/* source:cpp-chrono-year-operator-inc-dec:0007 */}
If the result would be outside the range `[-32767, 32767]`, the actual stored value is unspecified.

## Example

{/* source:cpp-chrono-year-operator-inc-dec:0008 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    std::cout << std::boolalpha;

    std::chrono::year y{2020};
    std::cout << (++y == std::chrono::year(2021)) << ' ';
    std::cout << (--y == std::chrono::year(2020)) << '\n';

    using namespace std::literals::chrono_literals;
    y = 32767y;
    y++; //← unspecified, see ↑ Notes ↑
    std::cout << static_cast<int>(y) << '\n';
}
```

Possible output:

```text
true true
-32768
```
