{/* source:cpp-chrono-year-operator-sign:0001 */}
Applies the unary operators to the year value.

{/* source:cpp-chrono-year-operator-sign:0002 */}
1) Returns a copy of `*this`.

{/* source:cpp-chrono-year-operator-sign:0003 */}
2) Returns a `year` whose year value is the negation of that of `*this`.

## Return value

{/* source:cpp-chrono-year-operator-sign:0004 */}
1) `*this`

{/* source:cpp-chrono-year-operator-sign:0005 */}
2) `std::chrono::year(-int(*this))`

## Example

{/* source:cpp-chrono-year-operator-sign:0006 */}
```cpp
#include <chrono>
#include <iostream>
 
int main()
{
    constexpr std::chrono::year y{2020};
    constexpr auto ny = -y;
    std::cout << "The year " << (int)y << " negated is " << (int)ny << '\n';
}
```

Output:

```text
The year 2020 negated is -2020
```
