{/* source:cpp-chrono-year-operator-cmp:0001 */}
Compare the two `std::chrono::year` `x` and `y`.

{/* source:cpp-chrono-year-operator-cmp:0002 */}
The `\<`, `\<=`, `\>`, `\>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-year-operator-cmp:0003 */}
1) `int(x) == int(y)`

{/* source:cpp-chrono-year-operator-cmp:0004 */}
2) `int(x) <=> int(y)`

## Example

{/* source:cpp-chrono-year-operator-cmp:0005 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono;

    constexpr year y1{2020};
    constexpr year y2{2021};

    std::cout << std::boolalpha << (y1 != y2) << '\n';

    static_assert((2020y < 2023y) && (2020y == 2020y) && (2020y <= 2023y) &&
                  (2023y > 2020y) && (2023y != 2020y) && (2023y >= 2020y));
}
```

Output:

```text
true
```
