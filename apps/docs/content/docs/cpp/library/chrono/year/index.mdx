{/* source:cpp-chrono-year:0001 */}
The class `year` represents a year in the [proleptic Gregorian calendar](https://en.wikipedia.org/wiki/proleptic_Gregorian_calendar). Its range is `[-32767, 32767]`.

{/* source:cpp-chrono-year:0002 */}
`year` is a [TriviallyCopyable](/docs/cpp/library/named_req/TriviallyCopyable) [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType).
