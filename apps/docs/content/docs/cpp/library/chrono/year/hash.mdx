The template specialization of [`std::hash`](/docs/cpp/library/utility/hash) for [`std::chrono::year`](/docs/cpp/library/chrono/year) allows users to obtain hashes of objects of type [`std::chrono::year`](/docs/cpp/library/chrono/year). This specialization is [`enabled`](/docs/cpp/library/utility/hash).

{/* source:cpp-chrono-year-hash:0002 */}
The `operator()` of this specialization is `noexcept`.
