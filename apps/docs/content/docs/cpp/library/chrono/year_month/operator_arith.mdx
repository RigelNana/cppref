{/* source:cpp-chrono-year-month-operator-arith:0001 */}
Modifies the time point `*this` represents by the duration `dy` or `dm`.

{/* source:cpp-chrono-year-month-operator-arith:0002 */}
1) Equivalent to `*this = *this + dy;`.

{/* source:cpp-chrono-year-month-operator-arith:0003 */}
2) Equivalent to `*this = *this + dm;`.

{/* source:cpp-chrono-year-month-operator-arith:0004 */}
3) Equivalent to `*this = *this - dy;`.

{/* source:cpp-chrono-year-month-operator-arith:0005 */}
4) Equivalent to `*this = *this - dm;`.

{/* source:cpp-chrono-year-month-operator-arith:0006 */}
For durations that are convertible to both `std::chrono::years` and `std::chrono::months`, the `years` overloads (1,3) are preferred if the call would otherwise be ambiguous.

## Example

{/* source:cpp-chrono-year-month-operator-arith:0007 */}
```cpp
#include <cassert>
#include <chrono>

int main()
{
    auto ym{std::chrono::day(1)/7/2023};

    ym -= std::chrono::years{2};
    assert(ym.month() == std::chrono::July);
    assert(ym.year() == std::chrono::year(2021));

    ym += std::chrono::months{7};
    assert(ym.month() == std::chrono::month(2));
    assert(ym.year() == std::chrono::year(2022));
}
```
