Compares the two `year_month` values `x` and `y`.

{/* source:cpp-chrono-year-month-operator-cmp:0002 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

## Return value

{/* source:cpp-chrono-year-month-operator-cmp:0003 */}
1. `x.year() == y.year() && x.month() == y.month()`

{/* source:cpp-chrono-year-month-operator-cmp:0004 */}
2. `x.year() <=> y.year() != 0 ? x.year() <=> y.year() : x.month() <=> y.month()`

## Example

{/* source:cpp-chrono-year-month-operator-cmp:0005 */}
```cpp
#include <chrono>
#include <iostream>

int main()
{
    using namespace std::chrono;

    constexpr year_month ym1{year(2021), month(7)};
    constexpr year_month ym2{year(2021)/7};
    static_assert(ym1 == ym2);
    std::cout << ym1 << '\n';

    static_assert((2020y/1 < 2020y/2) && (2020y/2 == 2020y/2) && (2020y/3 <= 2021y/3) &&
                  (2023y/1 > 2020y/2) && (3020y/2 != 2020y/2) && (2020y/3 >= 2020y/3));
}
```

Output:

```text
2021/Jul
```
