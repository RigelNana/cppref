   operator<<( std::basic_ostream<CharT, Traits>& os, const std::chrono::year_month& ym );`} />
</DeclarationDoc>

{/* source:cpp-chrono-year-month-operator-ltlt:0001 */}
Outputs a textual representation of `ym` into the stream `os`, as if by

{/* source:cpp-chrono-year-month-operator-ltlt:0002 */}
```cpp
os << std::format(os.getloc(), STATICALLY_WIDEN<CharT>("{}/{:L}"), ym.year(), ym.month())
```

{/* source:cpp-chrono-year-month-operator-ltlt:0003 */}
where `STATICALLY_WIDEN<CharT>("{}/{:L}")` is `"{}/{:L}"` if `CharT` is `char`, and `L"{}/{:L}"` if `CharT` is `wchar_t`.

## Return value

{/* source:cpp-chrono-year-month-operator-ltlt:0004 */}
`os`
