{/* source:cpp-chrono-year-month:0001 */}
The class `year_month` represents a specific month of a specific year, but with an unspecified day. It is a field-based time point, with a resolution of `std::chrono::months`.

{/* source:cpp-chrono-year-month:0002 */}
`year_month` is a [TriviallyCopyable](/docs/cpp/library/named_req/TriviallyCopyable) [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType).
