Compares the two `weekday_indexed` `x` and `y`.

{/* source:cpp-chrono-weekday-indexed-operator-cmp:0002 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

## Return value

{/* source:cpp-chrono-weekday-indexed-operator-cmp:0003 */}
`x.weekday() == y.weekday() && x.index() == y.index()`

## Example

{/* source:cpp-chrono-weekday-indexed-operator-cmp:0004 */}
```cpp
#include <chrono>

int main()
{
    constexpr std::chrono::weekday_indexed wdi1{std::chrono::Wednesday[2]};
    constexpr std::chrono::weekday_indexed wdi2{std::chrono::weekday(3), 2};
    static_assert(wdi1 == wdi2);
}
```
