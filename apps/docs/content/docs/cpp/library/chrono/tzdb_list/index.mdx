{/* source:cpp-chrono-tzdb-list:0001 */}
`tzdb_list` is a singleton list of `std::chrono::tzdb`s, each of which represents a copy of the IANA time zone database. Users cannot construct a `tzdb_list` and can only obtain access to one via the `std::chrono::get_tzdb_list` free function.
