{/* source:cpp-utility-initializer-list-initializer-list:0001 */}
Constructs an empty initializer list.

### Parameters

{/* source:cpp-utility-initializer-list-initializer-list:0002 */}
(none)

### Complexity

{/* source:cpp-utility-initializer-list-initializer-list:0003 */}
Constant

### Notes

{/* source:cpp-utility-initializer-list-initializer-list:0004 */}
Despite a lack of constructors, it is possible to create non-empty initializer lists. Instances of `std::initializer_list` are implicitly constructed when:

{/* source:cpp-utility-initializer-list-initializer-list:0005 */}
- a braced-init-list is used in [list-initialization](/docs/cpp/language/initialization/list_initialization), including function-call list initialization and assignment expressions (not to be confused with [constructor initializer lists](/docs/cpp/language/classes/initializer_list))
- a braced-init-list is bound to `auto`, including in a [ranged for loop](/docs/cpp/language/statements/range-for)

### Example

{/* source:cpp-utility-initializer-list-initializer-list:0006 */}
```cpp
#include <initializer_list>
#include <iostream>
 
int main()
{
    std::initializer_list<int> empty_list;
    std::cout << "empty_list.size(): " << empty_list.size() << '\n';
 
    // create initializer lists using list-initialization
    std::initializer_list<int> digits{1, 2, 3, 4, 5};
    std::cout << "digits.size(): " << digits.size() << '\n';
 
    // special rule for auto means 'fractions' has the
    // type std::initializer_list<double>
    auto fractions = {3.14159, 2.71828};
    std::cout << "fractions.size(): " << fractions.size() << '\n';
 
    // create constexpr initializer list (since C++14)
    static constexpr auto ab = {'a', 'b'};
    static_assert(ab.size() == 2 and *ab.begin() == 'a');
}
```

Output:

```text
empty_list.size(): 0
digits.size(): 5
fractions.size(): 2
```
