{/* source:cpp-utility-initializer-list-begin2:0001 */}
The overload of [`std::begin`](/docs/cpp/library/iterator/begin) for initializer_list returns a pointer to the first element of `il`.

### Parameters

{/* source:cpp-utility-initializer-list-begin2:0002 */}
<ParameterList>
  <Parameter name="il">an initializer_list</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-initializer-list-begin2:0003 */}
`il.begin()`

### Example

{/* source:cpp-utility-initializer-list-begin2:0004 */}
```cpp
#include <algorithm>
#include <initializer_list>
#include <iostream>
#include <iterator>
 
int main()
{
    std::initializer_list ϕ = {'1', '.', '6', '1', '8', '0'};
 
    std::copy(std::begin(ϕ),
              std::end(ϕ),
              std::ostream_iterator<char>(std::cout, ""));
 
    std::cout << '\n';
}
```

Output:

```text
1.6180
```
