Obtains a pointer to the first element in the initializer list.

{/* source:cpp-utility-initializer-list-begin:0002 */}
If the initializer list is empty, the values of `begin()` and [`end()`](/docs/cpp/library/utility/initializer_list/end) are unspecified, but will be identical.

### Parameters

{/* source:cpp-utility-initializer-list-begin:0003 */}
(none)

### Return value

{/* source:cpp-utility-initializer-list-begin:0004 */}
A pointer to the first element in the initializer list

### Complexity

{/* source:cpp-utility-initializer-list-begin:0005 */}
Constant

### Example

{/* source:cpp-utility-initializer-list-begin:0006 */}
```cpp
#include <initializer_list>
 
int main()
{
    static constexpr auto il = {42, 24};
    static_assert(*il.begin() == 0x2A);
    static_assert(il.begin()[1] == 030);
}
```
