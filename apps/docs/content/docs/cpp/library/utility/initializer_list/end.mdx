Obtains a pointer to one past the last element in the initializer list, i.e. [`begin()`](/docs/cpp/library/utility/initializer_list/begin) `+ size()`.

{/* source:cpp-utility-initializer-list-end:0002 */}
If the initializer list is empty, the values of [`begin()`](/docs/cpp/library/utility/initializer_list/begin) and `end()` are unspecified, but will be identical.

### Parameters

{/* source:cpp-utility-initializer-list-end:0003 */}
(none)

### Return value

{/* source:cpp-utility-initializer-list-end:0004 */}
A pointer to one past the last element in the initializer list

### Complexity

{/* source:cpp-utility-initializer-list-end:0005 */}
Constant

### Example

{/* source:cpp-utility-initializer-list-end:0006 */}
```cpp
#include <initializer_list>
#include <numeric>
 
int main()
{
    static constexpr auto l = {3, 13, 13};
    static_assert(std::accumulate(l.begin(), l.end(), 13) == 42);
}
```
