{/* source:cpp-utility-initializer-list-end2:0001 */}
The overload of [`std::end`](/docs/cpp/library/iterator/end) for initializer_list returns a pointer to one past the last element of `il`.

### Parameters

{/* source:cpp-utility-initializer-list-end2:0002 */}
<ParameterList>
  <Parameter name="il">an initializer_list</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-initializer-list-end2:0003 */}
`il.end()`

### Example

{/* source:cpp-utility-initializer-list-end2:0004 */}
```cpp
#include <cassert>
#include <initializer_list>
#include <iterator>
#include <numeric>
 
int main()
{
    std::initializer_list e = {2, 7, 1, 8, 2, 8, 1};
    assert(std::accumulate(std::begin(e), std::end(e), 13) == 42);
}
```
