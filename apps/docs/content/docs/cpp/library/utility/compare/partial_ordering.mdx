{/* source:cpp-utility-compare-partial-ordering:0001 */}
The class type `std::partial_ordering` is the result type of a [three-way comparison](/docs/cpp/language/expressions/operator_comparison#Three-way_comparison) that:

{/* source:cpp-utility-compare-partial-ordering:0002 */}
- Admits all six relational operators (`==`, `!=`, `<`, `<=`, `>`, `>=`).

{/* source:cpp-utility-compare-partial-ordering:0003 */}
- Does not imply substitutability: if `a` is equivalent to `b`, `f(a)` may not be equivalent to `f(b)`, where `f` denotes a function that reads only comparison-salient state that is accessible via the argument's public const members. In other words, equivalent values may be distinguishable.
- [Admits incomparable values](https://en.wikipedia.org/wiki/Connected_relation): `a < b`, `a == b`, and `a > b` may all be `false`.

### Conversions

{/* source:cpp-utility-compare-partial-ordering:0006 */}
`std::partial_ordering` cannot be implicitly converted to other comparison category types, while both `std::strong_ordering` and `std::weak_ordering` are implicitly-convertible to `partial_ordering`.

### Comparisons

{/* source:cpp-utility-compare-partial-ordering:0007 */}
Comparison operators are defined between values of this type and literal `0`. This supports the expressions `a <=> b == 0` or `a <=> b < 0` that can be used to convert the result of a three-way comparison operator to a boolean relationship; see [`std::is_eq`](/docs/cpp/library/utility/compare/named_comparison_functions), [`std::is_lt`](/docs/cpp/library/utility/compare/named_comparison_functions), etc.

{/* source:cpp-utility-compare-partial-ordering:0008 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::partial_ordering` is an associated class of the arguments.

{/* source:cpp-utility-compare-partial-ordering:0009 */}
The behavior of a program that attempts to compare a `partial_ordering` with anything other than the integer literal `0` is undefined.

### Notes

{/* source:cpp-utility-compare-partial-ordering:0017 */}
The [`built-in operator<=>`](/docs/cpp/language/expressions/operator_comparison#Three-way_comparison) between floating-point values uses this ordering: the positive zero and the negative zero compare equivalent, but can be distinguished, and NaN values compare unordered with any other value.
