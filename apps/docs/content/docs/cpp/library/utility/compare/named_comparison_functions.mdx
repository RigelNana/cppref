{/* source:cpp-utility-compare-named-comparison-functions:0001 */}
These functions take a result of 3-way comparison and convert it to the result of one of the six relational operators

{/* source:cpp-utility-compare-named-comparison-functions:0002 */}
Specifically, these functions return

{/* source:cpp-utility-compare-named-comparison-functions:0003 */}
1. 1) `cmp == 0`

{/* source:cpp-utility-compare-named-comparison-functions:0004 */}
2. 2) `cmp != 0`

{/* source:cpp-utility-compare-named-comparison-functions:0005 */}
3. 3) `cmp < 0`

{/* source:cpp-utility-compare-named-comparison-functions:0006 */}
4. 4) `cmp <= 0`

{/* source:cpp-utility-compare-named-comparison-functions:0007 */}
5. 5) `cmp > 0`

{/* source:cpp-utility-compare-named-comparison-functions:0008 */}
6. 6) `cmp >= 0`

### Parameters

{/* source:cpp-utility-compare-named-comparison-functions:0009 */}
<ParameterList>
  <Parameter name="cmp">result of 3-way comparison</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-compare-named-comparison-functions:0010 */}
`bool` result of the corresponding relational operation
