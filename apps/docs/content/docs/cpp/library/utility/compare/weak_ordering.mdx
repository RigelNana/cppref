{/* source:cpp-utility-compare-weak-ordering:0001 */}
The class type `std::weak_ordering` is the result type of a [three-way comparison](/docs/cpp/language/expressions/operator_comparison#Three-way_comparison) that:

{/* source:cpp-utility-compare-weak-ordering:0002 */}
- Admits all six relational operators (`==`, `!=`, `<`, `<=`, `>`, `>=`).

{/* source:cpp-utility-compare-weak-ordering:0003 */}
- Does not imply substitutability: if `a` is equivalent to `b`, `f(a)` may not be equivalent to `f(b)`, where `f` denotes a function that reads only comparison-salient state that is accessible via the argument's public const members. In other words, equivalent values may be distinguishable.
- [Does not allow incomparable values](https://en.wikipedia.org/wiki/Connected_relation): exactly one of `a < b`, `a == b`, or `a > b` must be `true`.

### Return value

`std::partial_ordering::less` if `v` is `less`,

`std::partial_ordering::equivalent` if `v` is `equivalent`.

### Comparisons

{/* source:cpp-utility-compare-weak-ordering:0009 */}
Comparison operators are defined between values of this type and literal `0`. This supports the expressions `a <=> b == 0` or `a <=> b < 0` that can be used to convert the result of a three-way comparison operator to a boolean relationship; see [`std::is_eq`](/docs/cpp/library/utility/compare/named_comparison_functions), [`std::is_lt`](/docs/cpp/library/utility/compare/named_comparison_functions), etc.

{/* source:cpp-utility-compare-weak-ordering:0010 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::weak_ordering` is an associated class of the arguments.

{/* source:cpp-utility-compare-weak-ordering:0011 */}
The behavior of a program that attempts to compare a `weak_ordering` with anything other than the integer literal `0` is undefined.
