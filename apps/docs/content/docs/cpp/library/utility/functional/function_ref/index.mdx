{/* source:cpp-utility-functional-function-ref:0001 */}
Class template `std::function_ref` is a non-owning function wrapper. `std::function_ref` objects can store and invoke reference to [*Callable*](/docs/cpp/library/named_req/Callable) *target* - functions, [lambda expressions](/docs/cpp/language/functions/lambda), [bind expressions](/docs/cpp/library/utility/functional/bind), or other function objects, but not pointers to member functions and pointers to member objects. `std::nontype` can be used to construct `std::function_ref` by passing function pointers, pointers to member functions, and pointers to member objects.

{/* source:cpp-utility-functional-function-ref:0002 */}
`std::function_refs` supports every possible combination of [cv-qualifiers](/docs/cpp/language/classes/member_functions#Member_functions_with_cv-qualifiers) (excluding `volatile`), and [noexcept-specifiers](/docs/cpp/language/exceptions/noexcept_spec) provided in its template parameter.

{/* source:cpp-utility-functional-function-ref:0003 */}
Every specialization of `std::function_ref` is a [*TriviallyCopyable*](/docs/cpp/library/named_req/TriviallyCopyable) type that satisfies [`copyable`](/docs/cpp/library/concepts/copyable).
