## std::plus\<void\>::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`template< class T, class U >
constexpr auto operator()( T&& lhs, U&& rhs ) const

    -> decltype(std::forward<T>(lhs) + std::forward<U>(rhs));`} />
</DeclarationDoc>

Returns the sum of `lhs` and `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to sum</Parameter>
</ParameterList>

### Return value

`std::forward<T>(lhs) + std::forward<U>(rhs)`.

### Example

{/* source:cpp-utility-functional-plus-void:0005 */}
```cpp
#include <functional>
#include <iostream>
 
int main()
{
    auto string_plus = std::plus<void>{}; // “void” can be omitted
    std::string a = "Hello ";
    const char* b = "world";
    std::cout << string_plus(a, b) << '\n';
}
```

Output:

```text
Hello world
```
