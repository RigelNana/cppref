{/* source:cpp-utility-functional-mem-fun-ref:0001 */}
Creates a member function wrapper object, deducing the target type from the template arguments. The wrapper object expects a reference to an object of type `T` as the first parameter to its `operator()`.

{/* source:cpp-utility-functional-mem-fun-ref:0002 */}
1. 1) Effectively calls `std::mem_fun_ref_t<S,T>(f)` or `std::const_mem_fun_ref_t<S,T>(f)`.

{/* source:cpp-utility-functional-mem-fun-ref:0003 */}
2. 2) Effectively calls `std::mem_fun1_ref_t<S,T>(f)` or `std::const_mem_fun1_ref_t<S,T>(f)`.

{/* source:cpp-utility-functional-mem-fun-ref:0004 */}
This function and the related types were deprecated in C++11 and removed in C++17 in favor of the more general [`std::mem_fn`](/docs/cpp/library/utility/functional/mem_fn) and [`std::bind`](/docs/cpp/library/utility/functional/bind), both of which create callable adaptor-compatible function objects from member functions.

### Parameters

{/* source:cpp-utility-functional-mem-fun-ref:0005 */}
<ParameterList>
  <Parameter name="f">pointer to a member function to create a wrapper for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-mem-fun-ref:0006 */}
A function object wrapping `f`.

### Exceptions

{/* source:cpp-utility-functional-mem-fun-ref:0007 */}
May throw implementation-defined exceptions.

### Notes

{/* source:cpp-utility-functional-mem-fun-ref:0008 */}
The difference between `std::mem_fun` and `std::mem_fun_ref` is that the former produces a function wrapper that expects a pointer to an object, whereas the latter — a reference.

### Example

{/* source:cpp-utility-functional-mem-fun-ref:0009 */}
Uses `std::mem_fun_ref` to bind [`std::string`](/docs/cpp/library/string/basic_string)'s member function [`size()`](/docs/cpp/library/string/basic_string/size).

```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <iterator>
#include <string>
#include <vector>
 
int main()
{
    std::vector<std::string> v = {"once", "upon", "a", "time"};
    std::transform(v.cbegin(), v.cend(),
                   std::ostream_iterator<std::size_t>(std::cout, " "),
                   std::mem_fun_ref(&std::string::size));
}
```

Output:

```text
4 4 1 4
```
