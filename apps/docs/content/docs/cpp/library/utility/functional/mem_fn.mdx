{/* source:cpp-utility-functional-mem-fn:0001 */}
Function template `std::mem_fn` generates wrapper objects for pointers to members, which can store, copy, and invoke a [pointer to member](/docs/cpp/language/declarations/pointer#Pointers_to_members). Both references and pointers (including smart pointers) to an object can be used when invoking a `std::mem_fn`.

### Parameters

{/* source:cpp-utility-functional-mem-fn:0002 */}
<ParameterList>
  <Parameter name="pm">pointer to member that will be wrapped</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-mem-fn:0003 */}
`std::mem_fn` returns a call wrapper `fn` of unspecified type that has the following members:

### Member function

<DeclarationDoc>
  <Declaration language="cpp" since="C++20" code={`template< class... Args >
/* see below */ operator()(Args&&... args) /* cvref-qualifiers */

    noexcept(/* see below */);`} />
  <InlineRevision since="C++20">constexpr</InlineRevision>
</DeclarationDoc>

The expression `fn(args)` is equivalent to [`INVOKE`](/docs/cpp/library/utility/functional)`(pmd, args)`, where `pmd` is the [*Callable*](/docs/cpp/library/named_req/Callable) object held by `fn`, it is of type `M T::*` and is direct-non-list-initialized with `pm`.

Thus, the return type of `operator()` is `std::result_of<decltype(pm)(Args&&...)>::type` <InlineRevision since="C++17">or equivalently `std::invoke_result_t<decltype(pm), Args&&...>`, and the value in `noexcept` specifier is equal to `std::is_nothrow_invocable_v<decltype(pm), Args&&...>`)</InlineRevision>.

Each argument in `args` is perfectly forwarded, as if by `std::forward<Args>(args)....`

### Example

{/* source:cpp-utility-functional-mem-fn:0005 */}
Use `std::mem_fn` to store and execute a member function and a member object:

```cpp
#include <functional>
#include <iostream>
#include <memory>
 
struct Foo
{
    void display_greeting()
    {
        std::cout << "Hello, world.\n";
    }
 
    void display_number(int i)
    {
        std::cout << "number: " << i << '\n';
    }
 
    int add_xy(int x, int y)
    {
        return data + x + y;
    }
 
    template<typename... Args> int add_many(Args... args)
    {
        return data + (args + ...);
    }
 
    auto add_them(auto... args) // C++20 required
    {
        return data + (args + ...);
    }
 
    int data = 7;
};
 
int main()
{
    auto f = Foo{};
 
    auto greet = std::mem_fn(&Foo::display_greeting);
    greet(f);
 
    auto print_num = std::mem_fn(&Foo::display_number);
    print_num(f, 42);
 
    auto access_data = std::mem_fn(&Foo::data);
    std::cout << "data: " << access_data(f) << '\n';
 
    auto add_xy = std::mem_fn(&Foo::add_xy);
    std::cout << "add_xy: " << add_xy(f, 1, 2) << '\n';
 
    auto u = std::make_unique<Foo>();
    std::cout << "access_data(u): " << access_data(u) << '\n';
    std::cout << "add_xy(u, 1, 2): " << add_xy(u, 1, 2) << '\n';
 
    auto add_many = std::mem_fn(&Foo::add_many<short, int, long>);
    std::cout << "add_many(u, ...): " << add_many(u, 1, 2, 3) << '\n';
 
    auto add_them = std::mem_fn(&Foo::add_them<short, int, float, double>);
    std::cout << "add_them(u, ...): " << add_them(u, 5, 7, 10.0f, 13.0) << '\n';
}
```

Output:

```text
Hello, world.
number: 42
data: 7
add_xy: 10
access_data(u): 7
add_xy(u, 1, 2): 10
add_many(u, ...): 13
add_them(u, ...): 42
```
