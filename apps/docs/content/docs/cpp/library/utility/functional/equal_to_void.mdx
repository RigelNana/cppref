## std::equal_to\<void\>::operator()

<DeclarationDoc>

</DeclarationDoc>

Returns the result of equality comparison between `lhs` and `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to compare</Parameter>
</ParameterList>

### Return value

`std::forward<T>(lhs) == std::forward<U>(rhs)`.

### Example

{/* source:cpp-utility-functional-equal-to-void:0005 */}
```cpp
#include <functional>
 
int main()
{
    constexpr int a = 0, b = 8;
    std::equal_to<> equal{};
    static_assert(equal(a, a));
    static_assert(!equal(a, b));
}
```
