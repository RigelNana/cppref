{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0001 */}
Performs comparison operations on `reference_wrapper` objects.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0002 */}
1. 1,2) Compares two `reference_wrapper` objects. The objects compare equal if and only if `lhs.get()` and `rhs.get()` are equal.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0003 */}
2. 1) This overload participates in overload resolution only if the expression `lhs.get() == rhs.get()` is well-formed and its result is convertible to `bool`.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0004 */}
3. 2) This overload participates in overload resolution only if all following conditions are satisfied:

- `std::is_const_v<T>` is `false`.
- The expression `lhs.get() == rhs.get()` is well-formed and its result is convertible to `bool`.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0005 */}
4. 3) Compares `reference_wrapper` object with a reference. The parameters compare equal if and only if `lhs.get()` is equal to `ref`.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0006 */}
5. This overload participates in overload resolution only if the expression `lhs.get() == ref` is well-formed and its result is convertible to `bool`.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0007 */}
6. 4,5) Compares two `reference_wrapper` objects using [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way).

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0008 */}
7. 4) This overload participates in overload resolution only if the expression [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way)`(lhs.get(), rhs.get())` is well-formed.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0009 */}
8. 5) This overload participates in overload resolution only if all following conditions are satisfied:

- `std::is_const_v<T>` is `false`.
- The expression [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way)`(lhs.get(), rhs.get())` is well-formed.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0010 */}
9. 6) Compares `reference_wrapper` object with a reference using [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way).

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0011 */}
10. This overload participates in overload resolution only if the expression [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way)`(lhs.get(), ref)` is well-formed.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0012 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

### Return value

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0014 */}
1. 1,2) `lhs.get() == rhs.get()`.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0015 */}
2. 3) `lhs.get() == ref`.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0016 */}
3. 4,5) [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way)`(lhs.get(), rhs.get())`.

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0017 */}
4. 6) [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way)`(lhs.get(), ref)`.

### Notes

{/* source:cpp-utility-functional-reference-wrapper-operator-cmp:0019 */}
The return types of `operator<=>` are [deduced](/docs/cpp/language/templates/template_argument_deduction#auto-returning_functions) from `return` statements to avoid hard error when instantiating a `std::reference_wrapper<T>` with [*synth-three-way-result*](/docs/cpp/library/standard_library/synth-three-way)`<T>` being ill-formed.
