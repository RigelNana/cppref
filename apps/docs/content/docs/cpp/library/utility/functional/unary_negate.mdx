`std::unary_negate` is a wrapper function object returning the complement of the unary predicate it holds.

{/* source:cpp-utility-functional-unary-negate:0002 */}
The unary predicate type must define a member type, `argument_type`, that is convertible to the predicate's parameter type. The unary function objects obtained from [`std::ref`](/docs/cpp/library/utility/functional/ref), [`std::cref`](/docs/cpp/library/utility/functional/ref), [`std::negate`](/docs/cpp/library/utility/functional/negate), [`std::logical_not`](/docs/cpp/library/utility/functional/logical_not), [`std::mem_fn`](/docs/cpp/library/utility/functional/mem_fn), [`std::function`](/docs/cpp/library/utility/functional/function), [`std::hash`](/docs/cpp/library/utility/hash), or from another call to [`std::not1`](/docs/cpp/library/utility/functional/not1) have this type defined, as are function objects derived from the deprecated [`std::unary_function`](/docs/cpp/library/utility/functional/unary_function).

{/* source:cpp-utility-functional-unary-negate:0003 */}
`std::unary_negate` objects are easily constructed with helper function [`std::not1`](/docs/cpp/library/utility/functional/not1).

### Example

{/* source:cpp-utility-functional-unary-negate:0008 */}
```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <vector>
 
struct less_than_7 : std::unary_function<int, bool>
{
    bool operator()(int i) const { return i < 7; }
};
 
int main()
{
    std::vector<int> v(7, 7);
    v[0] = v[1] = v[2] = 6;
 
    std::unary_negate<less_than_7> not_less_than_7((less_than_7()));
    // C++11 solution:
    // Use std::function<bool (int)>
    // std::function<bool (int)> not_less_than_7 =
    //     [](int x)->bool { return !less_than_7()(x); };
 
    std::cout << std::count_if(v.begin(), v.end(), not_less_than_7);
}
```

Output:

```text
4
```
