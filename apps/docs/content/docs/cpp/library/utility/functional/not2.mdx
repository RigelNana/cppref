{/* source:cpp-utility-functional-not2:0001 */}
`std::not2` is a helper function to create a function object that returns the complement of the binary predicate function passed. The function object created is of type `std::binary_negate<Predicate>`.

{/* source:cpp-utility-functional-not2:0002 */}
The binary predicate type must define two member types, `first_argument_type` and `second_argument_type`, that are convertible to the predicate's parameter types. The function objects obtained from [`std::owner_less`](/docs/cpp/library/memory/owner_less), [`std::ref`](/docs/cpp/library/utility/functional/ref), [`std::cref`](/docs/cpp/library/utility/functional/ref), [`std::plus`](/docs/cpp/library/utility/functional/plus), [`std::minus`](/docs/cpp/library/utility/functional/minus), [`std::multiplies`](/docs/cpp/library/utility/functional/multiplies), [`std::divides`](/docs/cpp/library/utility/functional/divides), [`std::modulus`](/docs/cpp/library/utility/functional/modulus), [`std::equal_to`](/docs/cpp/library/utility/functional/equal_to), [`std::not_equal_to`](/docs/cpp/library/utility/functional/not_equal_to), [`std::greater`](/docs/cpp/library/utility/functional/greater), [`std::less`](/docs/cpp/library/utility/functional/less), [`std::greater_equal`](/docs/cpp/library/utility/functional/greater_equal), [`std::less_equal`](/docs/cpp/library/utility/functional/less_equal), [`std::logical_not`](/docs/cpp/library/utility/functional/logical_not), [`std::logical_or`](/docs/cpp/library/utility/functional/logical_or), [`std::bit_and`](/docs/cpp/library/utility/functional/bit_and), [`std::bit_or`](/docs/cpp/library/utility/functional/bit_or), [`std::bit_xor`](/docs/cpp/library/utility/functional/bit_xor), [`std::mem_fn`](/docs/cpp/library/utility/functional/mem_fn), [`std::map::value_comp`](/docs/cpp/library/container/map/value_comp), [`std::multimap::value_comp`](/docs/cpp/library/container/multimap/value_comp), [`std::function`](/docs/cpp/library/utility/functional/function), or from another call to `std::not2` have these types defined, as are function objects derived from the deprecated `std::binary_function`.

### Parameters

{/* source:cpp-utility-functional-not2:0003 */}
<ParameterList>
  <Parameter name="pred">binary predicate</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-not2:0004 */}
`std::not2` returns an object of type `std::binary_negate<Predicate>`, constructed with `pred`.

### Exceptions

{/* source:cpp-utility-functional-not2:0005 */}
(none)

### Example

{/* source:cpp-utility-functional-not2:0006 */}
```cpp
#include <algorithm>
#include <cstddef>
#include <functional>
#include <iostream>
#include <vector>
 
struct old_same : std::binary_function<int, int, bool>
{
    bool operator()(int a, int b) const { return a == b; }
};
 
struct new_same
{
    bool operator()(int a, int b) const { return a == b; }
};
 
bool same_fn(int a, int b)
{
    return a == b;
}
 
int main()
{
    std::vector<int> v1{0, 1, 2};
    std::vector<int> v2{2, 1, 0};
    std::vector<bool> v3(v1.size());
 
    std::cout << "negating a binary_function:\n";
    std::transform(v1.begin(), v1.end(), v2.begin(), v3.begin(),
                   std::not2(old_same()));
 
    std::cout << std::boolalpha;
    for (std::size_t i = 0; i < v1.size(); ++i)
        std::cout << v1[i] << ' ' << v2[i] << ' ' << v3[i] << '\n';
 
    std::cout << "negating a standard functor:\n";
    std::transform(v1.begin(), v1.end(), v2.begin(), v3.begin(),
                   std::not2(std::equal_to<int>()));
 
    for (std::size_t i = 0; i < v1.size(); ++i)
        std::cout << v1[i] << ' ' << v2[i] << ' ' << v3[i] << '\n';
 
    std::cout << "negating a std::function:\n";
    std::transform(v1.begin(), v1.end(), v2.begin(), v3.begin(),
                   std::not2(std::function<bool(int, int)>(new_same())));
 
    for (std::size_t i = 0; i < v1.size(); ++i)
        std::cout << v1[i] << ' ' << v2[i] << ' ' << v3[i] << '\n';
 
    std::cout << "negating a std::reference_wrapper:\n";
    std::transform(v1.begin(), v1.end(), v2.begin(), v3.begin(),
                   std::not2(std::ref(same_fn)));
 
    for (std::size_t i = 0; i < v1.size(); ++i)
        std::cout << v1[i] << ' ' << v2[i] << ' ' << v3[i] << '\n';
}
```

Output:

```text
negating a binary_function:
0 2 true
1 1 false
2 0 true
negating a standard functor:
0 2 true
1 1 false
2 0 true
negating a std::function:
0 2 true
1 1 false
2 0 true
negating a std::reference_wrapper:
0 2 true
1 1 false
2 0 true
```
