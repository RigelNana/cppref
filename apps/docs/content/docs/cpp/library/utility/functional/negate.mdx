Function object for performing negation. Effectively calls `operator-` on an instance of type `T`.

{/* source:cpp-utility-functional-negate:0002 */}
<Revision since="C++14">
### Specializations

The standard library provides a specialization of `std::negate` when `T` is not specified, which leaves the parameter types and return type to be deduced.

#### std::negate::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`T operator()( const T& arg ) const;`} />
  (constexpr since C++14)
</DeclarationDoc>

Returns the negation of `arg`.

##### Parameters

<ParameterList>
  <Parameter name="arg">value to compute negation of</Parameter>
</ParameterList>

##### Return value

The result of `-arg`.

##### Exceptions

May throw implementation-defined exceptions.

##### Possible implementation

```cpp
constexpr T operator()(const T& arg) const 
{
    return -arg;
}
```
