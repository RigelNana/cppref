{/* source:cpp-utility-functional-function-operator-cmp:0001 */}
Compares a `std::function` with a null pointer. Empty functions (that is, functions without a callable target) compare equal, non-empty functions compare non-equal.

{/* source:cpp-utility-functional-function-operator-cmp:0002 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Return value

{/* source:cpp-utility-functional-function-operator-cmp:0004 */}
1. 1,2) `!f`

{/* source:cpp-utility-functional-function-operator-cmp:0005 */}
2. 3,4) `(bool) f`

### Example

{/* source:cpp-utility-functional-function-operator-cmp:0006 */}
```cpp
#include <functional>
#include <iostream>
 
using SomeVoidFunc = std::function<void(int)>;
 
class C
{
public:
    C(SomeVoidFunc void_func = nullptr) : void_func_(void_func)
    {
        if (void_func_ == nullptr) // specialized compare with nullptr
            void_func_ = std::bind(&C::default_func, this, std::placeholders::_1);
        void_func_(7);
    }
 
    void default_func(int i) { std::cout << i << '\n'; };
 
private:
    SomeVoidFunc void_func_;
};
 
void user_func(int i)
{
    std::cout << (i + 1) << '\n';
}
 
int main()
{
    C c1;
    C c2(user_func);
}
```

Output:

```text
7
8
```
