Function object for computing remainders of divisions. Implements `operator%` for type `T`.

### Specializations

{/* source:cpp-utility-functional-modulus:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::modulus` when `T` is not specified, which leaves the parameter types and return type to be deduced.

## std::modulus::operator()

<DeclarationDoc>
  <Declaration language="cpp" since="C++14" code={`T operator()( const T& lhs, const T& rhs ) const;`} />
  <InlineRevision since="C++14">constexpr</InlineRevision>
</DeclarationDoc>

Returns the remainder of the division of `lhs` by `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to divide one by another</Parameter>
</ParameterList>

### Return value

The result of `lhs % rhs`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr T operator()(const T& lhs, const T& rhs) const 
{
    return lhs % rhs;
}
```
