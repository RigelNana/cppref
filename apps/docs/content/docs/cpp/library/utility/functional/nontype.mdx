constexpr std::nontype_t<V> nontype {};`} />

  <DeclarationDescription>
    {/* source:cpp-utility-nontype:0001 */}
    1) The class template `std::nontype_t` can be used in the constructor's parameter list to match the intended tag.

    {/* source:cpp-utility-nontype:0002 */}
    2) The corresponding `std::nontype` instance of (1) is a disambiguation argument tag that can be passed to the constructors of [`std::function_ref`](/docs/cpp/library/utility/functional/function_ref) to indicate that the contained object should be constructed with the value of the non-type template parameter `V`.
  </DeclarationDescription>
</DeclarationDoc>
