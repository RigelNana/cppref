Function object for performing logical AND (logical conjunction). Effectively calls `operator&&` on type `T`.

### Specializations

{/* source:cpp-utility-functional-logical-and:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::logical_and` when `T` is not specified, which leaves the parameter types and return type to be deduced.

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`logical_and<void>`](/docs/cpp/library/utility/functional/logical_and_void) <InlineRevision since="C++14" /></DescriptionTerm>
    <DescriptionBody>function object implementing `x && y` deducing parameter and return types (class template specialization)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
</Revision>

## std::logical_and::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`bool operator()( const T& lhs, const T& rhs ) const;`} />
  (constexpr since C++14)
</DeclarationDoc>

Returns the logical AND of `lhs` and `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to compute logical AND of</Parameter>
</ParameterList>

### Return value

The result of `lhs && rhs`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr bool operator()(const T& lhs, const T& rhs) const 
{
    return lhs && rhs;
}
```
