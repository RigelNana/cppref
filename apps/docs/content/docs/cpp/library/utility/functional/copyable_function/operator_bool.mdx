Checks whether `*this` stores a callable target, i.e. is not empty.

### Parameters

{/* source:cpp-utility-functional-copyable-function-operator-bool:0002 */}
(none)

### Return value

{/* source:cpp-utility-functional-copyable-function-operator-bool:0003 */}
`true` if `*this` stores a callable target, `false` otherwise.
