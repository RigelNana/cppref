{/* source:cpp-utility-functional-function-target-type:0001 */}
Returns the type of the stored function.

### Parameters

{/* source:cpp-utility-functional-function-target-type:0002 */}
(none)

### Return value

{/* source:cpp-utility-functional-function-target-type:0003 */}
`typeid(T)` if the stored function has type `T`, otherwise `typeid(void)`

### Example

{/* source:cpp-utility-functional-function-target-type:0004 */}
```cpp
#include <functional>
#include <iostream>
 
int f(int a) { return -a; }
void g(double) {}
int main()
{
    // fn1 and fn2 have the same type, but their targets do not
    std::function<int(int)> fn1(f),
                            fn2([](int a) {return -a;});
    std::cout << fn1.target_type().name() << '\n'
              << fn2.target_type().name() << '\n';
 
    // since C++17 deduction guides (CTAD) can avail
    std::cout << std::function{g}.target_type().name() << '\n';
}
```

Possible output:

```text
PFiiE
Z4mainEUliE_
PFvdE
```
