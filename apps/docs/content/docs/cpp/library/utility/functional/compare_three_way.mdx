## std::compare_three_way::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`template< class T, class U >
constexpr auto operator()( T&& t, U&& u ) const;`} />
</DeclarationDoc>

Given the expression `std::forward<T>(t) <=> std::forward<U>(u)` as `expr`:

- If `expr` results in a call to [built-in](/docs/cpp/language/expressions/operator_comparison#Built-in_pointer_equality_comparison) `operator<=>` comparing pointers, given the [composite pointer type](/docs/cpp/language/declarations/pointer#Composite_pointer_type) of `t` and `u` as `P`:
  - Compares the two converted pointers (of type `P`) in the [implementation-defined strict total order over pointers](/docs/cpp/language/expressions/operator_comparison#Pointer_total_order):
    - If `t` precedes `u`, returns [`std::strong_ordering::less`](/docs/cpp/library/utility/compare/strong_ordering).
    - If `u` precedes `t`, returns [`std::strong_ordering::greater`](/docs/cpp/library/utility/compare/strong_ordering).
    - Otherwise, returns [`std::strong_ordering::equal`](/docs/cpp/library/utility/compare/strong_ordering).
  - If the conversion sequence from `T` to `P` or the conversion sequence from `U` to `P` is not [equality-preserving](/docs/cpp/library/concepts#Equality_preservation), the behavior is undefined.
- Otherwise:
  - Returns the result of `expr`.
  - If `std::three_way_comparable_with<T, U>` is not modeled, the behavior is undefined.

This overload participates in overload resolution only if `std::three_way_comparable_with<T, U>` is satisfied.

### Example

{/* source:cpp-utility-compare-compare-three-way:0005 */}
```cpp
#include <compare>
#include <iostream>
 
struct Rational
{
    int num;
    int den; // > 0
 
    // Although the comparison X <=> Y will work, a direct call
    // to std::compare_three_way{}(X, Y) requires the operator==
    // be defined, to satisfy the std::three_way_comparable_with.
    constexpr bool operator==(Rational const&) const = default;
};
 
constexpr std::weak_ordering operator<=>(Rational lhs, Rational rhs)
{
    return lhs.num * rhs.den <=> rhs.num * lhs.den;
}
 
void print(std::weak_ordering value)
{
    value < 0 ? std::cout << "less\n" :
    value > 0 ? std::cout << "greater\n" :
                std::cout << "equal\n";
}
 
int main()
{
    Rational a{6, 5};
    Rational b{8, 7};
    print(a <=> b);
    print(std::compare_three_way{}(a, b));
}
```

Output:

```text
greater
greater
```
