{/* source:cpp-utility-functional-move-only-function-operator:0001 */}
Checks whether the wrapper `f` has a callable target by formally comparing it with [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t). Empty wrappers (that is, wrappers without a target) compare equal, non-empty functions compare non-equal.

{/* source:cpp-utility-functional-move-only-function-operator:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::move_only_function<FunctionType>` is an associated class of the arguments.

{/* source:cpp-utility-functional-move-only-function-operator:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Parameters

{/* source:cpp-utility-functional-move-only-function-operator:0004 */}
<ParameterList>
  <Parameter name="f">`std::move_only_function` to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-move-only-function-operator:0005 */}
`!f`.

### Example

{/* source:cpp-utility-functional-move-only-function-operator:0006 */}
```cpp
#include <functional>
#include <iostream>
#include <utility>
 
using SomeVoidFunc = std::move_only_function<void(int) const>;
 
class C {
public:
    C() = default;
    C(SomeVoidFunc func) : void_func_(std::move(func)) {}
 
    void default_func(int i) const { std::cout << i << '\n'; };
 
    void operator()() const
    {
        if (void_func_ == nullptr) // specialized compare with nullptr
            default_func(7);
        else
            void_func_(7);
    }
 
private:
    SomeVoidFunc void_func_{};
};
 
void user_func(int i)
{
    std::cout << (i + 1) << '\n';
}
 
int main()
{
    C c1;
    C c2(user_func);
    c1();
    c2();
}
```

Output:

```text
7
8
```
