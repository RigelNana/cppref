{/* source:cpp-utility-functional-function-ref-operator:0001 */}
Invokes the stored [`thunk-ptr`](/docs/cpp/library/utility/functional/function_ref#thunk-ptr) with [`bound-entity`](/docs/cpp/library/utility/functional/function_ref#bound-entity) as its first parameter and the rest of the parameters `args`. The `/*noex*/` part of `operator()` is identical to those of the template parameter of `std::function_ref`.

{/* source:cpp-utility-functional-function-ref-operator:0002 */}
Equivalent to `return` [`thunk-ptr`](/docs/cpp/library/utility/functional/function_ref#thunk-ptr)([`bound-entity`](/docs/cpp/library/utility/functional/function_ref#bound-entity)`, std::forward<Args>(args)...);`.

### Parameters

{/* source:cpp-utility-functional-function-ref-operator:0003 */}
<ParameterList>
  <Parameter name="args">rest parameters to pass to the stored [`thunk-ptr`](/docs/cpp/library/utility/functional/function_ref#thunk-ptr)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-function-ref-operator:0004 */}
[`thunk-ptr`](/docs/cpp/library/utility/functional/function_ref#thunk-ptr)([`bound-entity`](/docs/cpp/library/utility/functional/function_ref#bound-entity)`, std::forward<Args>(args)...)`.

### Exceptions

{/* source:cpp-utility-functional-function-ref-operator:0005 */}
Propagates the exception thrown by the underlying function call.
