Function object for performing logical OR (logical disjunction). Effectively calls `operator||` on type `T`.

### Specializations

{/* source:cpp-utility-functional-logical-or:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::logical_or` when `T` is not specified, which leaves the parameter types and return type to be deduced.

  <DescriptionItem>
    <DescriptionTerm>[`logical_or<void>`](/docs/cpp/library/utility/functional/logical_or_void)</DescriptionTerm>

</DescriptionList>
</Revision>

## std::logical_or::operator()

<DeclarationDoc>
  <Declaration language="cpp" since="C++14" code={`bool operator()( const T& lhs, const T& rhs ) const;`} />
  <InlineRevision since="C++14">constexpr</InlineRevision>
</DeclarationDoc>

Returns the logical OR of `lhs` and `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to compute logical OR of</Parameter>
</ParameterList>

### Return value

The result of `lhs || rhs`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr bool operator()(const T& lhs, const T& rhs) const 
{
    return lhs || rhs;
}
```
