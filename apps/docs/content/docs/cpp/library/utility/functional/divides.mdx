Function object for performing division. Effectively calls `operator/` on two instances of type `T`.

### Specializations

{/* source:cpp-utility-functional-divides:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::divides` when `T` is not specified, which leaves the parameter types and return type to be deduced.

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`divides<void>`](/docs/cpp/library/utility/functional/divides_void)</DescriptionTerm>
    <DescriptionBody>function object implementing `x / y` deducing parameter and return types (class template specialization)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
</Revision>

## std::divides::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`T operator()( const T& lhs, const T& rhs ) const;`} />
  <InlineRevision since="C++14">constexpr</InlineRevision>
</DeclarationDoc>

Returns the result of division of `lhs` by `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to divide one by other</Parameter>
</ParameterList>

### Return value

The result of `lhs / rhs`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr T operator()(const T& lhs, const T& rhs) const 
{
    return lhs / rhs;
}
```
