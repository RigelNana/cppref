`std::binary_negate` is a wrapper function object returning the complement of the binary predicate it holds.

{/* source:cpp-utility-functional-binary-negate:0002 */}
The binary predicate type must define two member types, `first_argument_type` and `second_argument_type`, that are convertible to the predicate's parameter types. The function objects obtained from [`std::owner_less`](/docs/cpp/library/memory/owner_less), [`std::ref`](/docs/cpp/library/utility/functional/ref), [`std::cref`](/docs/cpp/library/utility/functional/ref), [`std::plus`](/docs/cpp/library/utility/functional/plus), [`std::minus`](/docs/cpp/library/utility/functional/minus), [`std::multiplies`](/docs/cpp/library/utility/functional/multiplies), [`std::divides`](/docs/cpp/library/utility/functional/divides), [`std::modulus`](/docs/cpp/library/utility/functional/modulus), [`std::equal_to`](/docs/cpp/library/utility/functional/equal_to), [`std::not_equal_to`](/docs/cpp/library/utility/functional/not_equal_to), [`std::greater`](/docs/cpp/library/utility/functional/greater), [`std::less`](/docs/cpp/library/utility/functional/less), [`std::greater_equal`](/docs/cpp/library/utility/functional/greater_equal), [`std::less_equal`](/docs/cpp/library/utility/functional/less_equal), [`std::logical_not`](/docs/cpp/library/utility/functional/logical_not), [`std::logical_or`](/docs/cpp/library/utility/functional/logical_or), [`std::bit_and`](/docs/cpp/library/utility/functional/bit_and), [`std::bit_or`](/docs/cpp/library/utility/functional/bit_or), `std::bit_xor`, [`std::mem_fn`](/docs/cpp/library/utility/functional/mem_fn), [`std::map::value_comp`](/docs/cpp/library/container/map/value_comp), [`std::multimap::value_comp`](/docs/cpp/library/container/multimap/value_comp), [`std::function`](/docs/cpp/library/utility/functional/function), or from a call to [`std::not2`](/docs/cpp/library/utility/functional/not2) have these types defined, as are function objects derived from the deprecated `std::binary_function`.

{/* source:cpp-utility-functional-binary-negate:0003 */}
`std::binary_negate` objects are easily constructed with helper function [`std::not2`](/docs/cpp/library/utility/functional/not2).

### Example

{/* source:cpp-utility-functional-binary-negate:0008 */}
```cpp
#include <algorithm>
#include <cstddef>
#include <functional>
#include <iostream>
#include <vector>
 
struct same : std::binary_function<int, int, bool>
{
    bool operator()(int a, int b) const { return a == b; }
};
 
int main()
{
    std::vector<int> v1;
    for (int i = 0; i < 7; ++i)
        v1.push_back(i);
 
    std::vector<int> v2(v1.size());
    std::reverse_copy(v1.begin(), v1.end(), v2.begin());
 
    std::vector<bool> v3(v1.size());
 
    std::binary_negate<same> not_same((same()));
 
    // C++11 solution:
    // std::function<bool (int, int)> not_same =
    //     [](int x, int y) -> bool { return !same()(x, y); };
 
    std::transform(v1.begin(), v1.end(), v2.begin(), v3.begin(), not_same);
 
    std::cout.setf(std::ios_base::boolalpha);
    for (std::size_t i = 0; i != v1.size(); ++i)
        std::cout << v1[i] << " != " << v2[i] << " : " << v3[i] << '\n';
}
```

Output:

```text
0 != 6 : true
1 != 5 : true
2 != 4 : true
3 != 3 : false
4 != 2 : true
5 != 1 : true
6 != 0 : true
```
