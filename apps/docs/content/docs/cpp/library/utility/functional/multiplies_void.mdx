#### std::multiplies\<void\>::operator()

Returns the product of `lhs` and `rhs`.

##### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to multiply</Parameter>
</ParameterList>

##### Return value

`std::forward<T>(lhs) * std::forward<U>(rhs)`.

### Example

{/* source:cpp-utility-functional-multiplies-void:0005 */}
```cpp
#include <complex>
#include <functional>
#include <iostream>
 
int main()
{
    auto complex_multiplies = std::multiplies<void>{}; // “void” can be omitted
    constexpr std::complex z1{1.0, 2.0}, z2{3.0, 4.0};
 
    std::cout << std::showpos
              << complex_multiplies(z1, z2) << ' ' << z1 * z2 << '\n'
              << complex_multiplies(z1, 5.) << ' ' << z1 * 5. << '\n'
              << complex_multiplies(5., z1) << ' ' << 5. * z1 << '\n';
}
```

Output:

```text
(-5,+10) (-5,+10)
(+5,+10) (+5,+10)
(+5,+10) (+5,+10)
```
