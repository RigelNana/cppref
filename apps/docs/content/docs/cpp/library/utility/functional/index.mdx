{/* source:cpp-utility-functional:0000 */}
A function object is any object for which the function call operator is defined. C++ provides many built-in function objects as well as support for creation and manipulation of new function objects.

### Function invocation

{/* source:cpp-utility-functional:0001 */}
<Revision since="C++11">
The exposition-only operation `INVOKE`(f, arg_0, arg_1, arg_2, ..., arg_N) is defined as follows:

Let type `Obj` be the unqualified type of `arg_0` (i.e., `std::remove_cv<std::remove_reference<decltype(arg_0)>::type>::type`)

- If `f` is a [pointer to member function](/docs/cpp/language/declarations/pointer#Pointers_to_member_functions) of class `C`, then `INVOKE`(f, obj, arg_1, arg_2, ..., arg_N) is equivalent to:

  - If `std::is_same<C, Obj>::value || std::is_base_of<C, Obj>::value` is `true`

    - `(obj.*f)(arg_1, arg_2, ..., arg_N)` (invoke the member function on the object).
  - If `Obj` is a specialization of [`std::reference_wrapper`](/docs/cpp/library/utility/functional/reference_wrapper)

    - `(obj.get().*f)(arg_1, arg_2, ..., arg_N)` (invoke the member function on the specially referred object).
  - Otherwise

    - `((*obj).*f)(arg_1, arg_2, ..., arg_N)` (invoke the member function on the dereferenced object).

- Otherwise, if `N == 0` and `f` is a [pointer to data member](/docs/cpp/language/declarations/pointer#Pointers_to_data_members) of class `C`, then `INVOKE`(mptr, obj) is equivalent to:

  - If `std::is_same<C, Obj>::value || std::is_base_of<C, Obj>::value` is `true`

    - `obj.*mptr` (access the data member of the object).
  - If `Obj` is a specialization of `std::reference_wrapper`

    - `obj.get().*mptr` (access the data member of the specially referred object).
  - Otherwise

    - `(*obj).*mptr` (access the data member of the dereferenced object).

- Otherwise

  - `INVOKE`(f, arg_0, arg_1, arg_2, ..., arg_N) is equivalent to `f(arg_0, arg_1, arg_2, ..., arg_N)` (invoke the callable).

The exposition-only operation `INVOKE<R>`(f, arg_0, arg_1, arg_2, ..., arg_N) is defined as follows:

- If `R` is (possibly cv-qualified) `void`

  - `static_cast<void>(`INVOKE`(f, arg_0, arg_1, arg_2, ..., arg_N))`.
- Otherwise

  - `INVOKE`(f, arg_0, arg_1, arg_2, ..., arg_N) implicitly converted to `R`.

<Revision since="C++23">
Let type `Actual` be `decltype(`INVOKE`(f, arg_0, arg_1, arg_2, ..., arg_N))`

- If [`std::reference_converts_from_temporary_v`](/docs/cpp/library/meta/reference_converts_from_temporary)`<R, Actual>` is `true`

  - `INVOKE<R>`(f, arg_0, arg_1, arg_2, ..., arg_N) is ill-formed.
</Revision>
</Revision>

### Constrained comparison function objects

The following comparison function objects are [constrained](/docs/cpp/language/templates/constraints).

- The equality operators (`ranges::equal_to` and `ranges::not_equal_to`) require the types of the arguments to satisfy [`equality_comparable_with`](/docs/cpp/library/concepts/equality_comparable).
- The relational operators (`ranges::less`, `ranges::greater`, `ranges::less_equal`, and `ranges::greater_equal`) require the types of the arguments to satisfy [`totally_ordered_with`](/docs/cpp/library/concepts/totally_ordered).
- The three-way comparison operator (`compare_three_way`) requires the type to model [`three_way_comparable_with`](/docs/cpp/library/utility/compare/three_way_comparable).

All these function objects are [transparent](/docs/cpp/library/utility/functional#Transparent_function_objects).
