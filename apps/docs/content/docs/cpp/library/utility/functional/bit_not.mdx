Function object for performing bitwise NOT. Effectively calls `operator~` on type `T`.

### Specializations

{/* source:cpp-utility-functional-bit-not:0002 */}
The standard library provides a specialization of `std::bit_not` when `T` is not specified, which leaves the parameter types and return type to be deduced.

## std::bit_not::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr T operator()( const T& arg ) const;`} />
  (since C++14)
</DeclarationDoc>

Returns the result of bitwise NOT of `arg`.

### Parameters

<ParameterList>
  <Parameter name="arg">value to compute bitwise NOT of</Parameter>
</ParameterList>

### Return value

The result of `~arg`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr T operator()(const T& arg) const
{
    return ~arg;
}
```

### Notes

{/* source:cpp-utility-functional-bit-not:0007 */}
Although `std::bit_not` is added via post-C++11 proposal [N3421](https://wg21.link/N3421), it is treated as a part of the resolution for [LWG issue 660](https://cplusplus.github.io/LWG/issue660) (except for its transparent specialization [`std::bit_not<>`](/docs/cpp/library/utility/functional/bit_not_void)) by common implementations, and thus available in their C++98/03 mode.
