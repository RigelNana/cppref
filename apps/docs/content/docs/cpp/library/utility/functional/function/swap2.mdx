{/* source:cpp-utility-functional-function-swap2:0001 */}
Overloads the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::function`](/docs/cpp/library/utility/functional/function). Exchanges the state of `lhs` with that of `rhs`. Effectively calls `lhs.swap(rhs)`.

### Parameters

{/* source:cpp-utility-functional-function-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">polymorphic function wrappers whose states to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-function-swap2:0003 */}
(none)

### Example

{/* source:cpp-utility-functional-function-swap2:0004 */}
```cpp
#include <functional>
#include <iostream>
 
void foo(const char* str, int x)
{
    std::cout << "foo(\"" << str << "\", " << x << ")\n";
}
 
void bar(const char* str, int x)
{
    std::cout << "bar(\"" << str << "\", " << x << ")\n";
}
 
int main()
{
    std::function<void(const char*, int)> f1{foo};
    std::function<void(const char*, int)> f2{bar};
 
    f1("f1", 1);
    f2("f2", 2);
 
    std::cout << "std::swap(f1, f2);\n";
    std::swap(f1, f2);
 
    f1("f1", 1);
    f2("f2", 2);
}
```

Output:

```text
foo("f1", 1)
bar("f2", 2)
std::swap(f1, f2);
bar("f1", 1)
foo("f2", 2)
```
