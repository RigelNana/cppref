Function object for performing comparisons. Unless specialised, invokes `operator!=` on type `T`.

### Specializations

{/* source:cpp-utility-functional-not-equal-to:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::not_equal_to` when `T` is not specified, which leaves the parameter types and return type to be deduced.

</Revision>

## std::not_equal_to::operator()

<DeclarationDoc>
  <Declaration language="cpp" since="C++14" code={`bool operator()( const T& lhs, const T& rhs ) const;`} />
</DeclarationDoc>

Checks whether `lhs` is *not equal* to `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to compare</Parameter>
</ParameterList>

### Return value

`true` if `lhs != rhs`, `false` otherwise.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr bool operator()(const T& lhs, const T& rhs) const 
{
    return lhs != rhs;
}
```
