{/* source:cpp-utility-functional-move-only-function-swap2:0001 */}
Overloads the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for `std::move_only_function`. Exchanges the state of `lhs` with that of `rhs`. Effectively calls `lhs.swap(rhs)`.

{/* source:cpp-utility-functional-move-only-function-swap2:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::move_only_function<FunctionType>` is an associated class of the arguments.

### Parameters

{/* source:cpp-utility-functional-move-only-function-swap2:0003 */}
<ParameterList>
  <Parameter name="lhs, rhs">`std::move_only_function` objects whose states to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-move-only-function-swap2:0004 */}
(none)

### Example

{/* source:cpp-utility-functional-move-only-function-swap2:0005 */}
```cpp
#include <concepts>
#include <functional>
#include <iostream>
 
void foo(const char* str, int x)
{
    std::cout << "foo(\"" << str << "\", " << x << ")\n";
}
 
void bar(const char* str, int x)
{
    std::cout << "bar(\"" << str << "\", " << x << ")\n";
}
 
int main()
{
    std::move_only_function<void(const char*, int) const> f1{foo};
    std::move_only_function<void(const char*, int) const> f2{bar};
 
    f1("f1", 1);
    f2("f2", 2);
 
    std::cout << "std::ranges::swap(f1, f2);\n";
    std::ranges::swap(f1, f2); // finds the hidden friend
 
    f1("f1", 1);
    f2("f2", 2);
}
```

Output:

```text
foo("f1", 1)
bar("f2", 2)
std::ranges::swap(f1, f2);
bar("f1", 1)
foo("f2", 2)
```
