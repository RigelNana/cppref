{/* source:cpp-utility-functional-copyable-function-operator:0001 */}
Checks whether the wrapper `f` has a callable target by formally comparing it with [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t). Empty wrappers (that is, wrappers without a target) compare equal, non-empty functions compare non-equal.

{/* source:cpp-utility-functional-copyable-function-operator:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::copyable_function<FunctionType>` is an associated class of the arguments.

{/* source:cpp-utility-functional-copyable-function-operator:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
