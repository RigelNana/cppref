</DeclarationDoc>

{/* source:cpp-utility-functional-function-operator:0001 */}
Invokes the stored callable function target with the parameters `args`.

{/* source:cpp-utility-functional-function-operator:0002 */}
Effectively does [`INVOKE<R>`](/docs/cpp/library/utility/functional)`(f, std::forward<Args>(args)...)`, where `f` is the [target object](/docs/cpp/library/utility/functional/function) of `*this`.

### Parameters

{/* source:cpp-utility-functional-function-operator:0003 */}
<ParameterList>
  <Parameter name="args">parameters to pass to the stored callable function target</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-function-operator:0004 */}
None if `R` is `void`. Otherwise the return value of the invocation of the stored callable object.

### Exceptions

{/* source:cpp-utility-functional-function-operator:0005 */}
Throws [`std::bad_function_call`](/docs/cpp/library/utility/functional/bad_function_call) if `*this` does not store a callable function target, i.e. `!*this == true`.

### Example

{/* source:cpp-utility-functional-function-operator:0006 */}
The following example shows how [`std::function`](/docs/cpp/library/utility/functional/function) can be passed to other functions by value. Also, it shows how [`std::function`](/docs/cpp/library/utility/functional/function) can store lambdas.

```cpp
#include <functional>
#include <iostream>
 
void call(std::function<int()> f) // can be passed by value
{ 
    std::cout << f() << '\n';
}
 
int normal_function()
{
    return 42;
}
 
int main()
{
    int n = 1;
    std::function<int()> f;
    try
    {
        call(f);
    }
    catch (const std::bad_function_call& ex)
    {
        std::cout << ex.what() << '\n';
    }
 
    f = [&n](){ return n; };
    call(f);
 
    n = 2;
    call(f);
 
    f = normal_function;
    call(f);
 
    std::function<void(std::string, int)> g;
    g = [](std::string str, int i) { std::cout << str << ' ' << i << '\n'; };
    g("Hi", 052);
}
```

Possible output:

```text
bad_function_call
1
2
42
Hi 42
```
