{/* source:cpp-utility-functional-move-only-function-move-only-function:0001 */}
Creates a new `std::move_only_function`.

{/* source:cpp-utility-functional-move-only-function-move-only-function:0002 */}
1,2) Default constructor and the constructor taking `nullptr` construct an empty `std::move_only_function`.

{/* source:cpp-utility-functional-move-only-function-move-only-function:0003 */}
3) Move constructor constructs a `std::move_only_function` whose target is that of `other`. `other` is in a valid but unspecified state after move construction.

{/* source:cpp-utility-functional-move-only-function-move-only-function:0004 */}
4) Copy constructor is deleted. `std::move_only_function` does not satisfy [*CopyConstructible*](/docs/cpp/library/named_req/CopyConstructible).

{/* source:cpp-utility-functional-move-only-function-move-only-function:0005 */}
5) Let `VT` be `std::decay_t<F>`. If `f` is a null function pointer, a null pointer to member value, or an empty `std::move_only_function` (may be any other specialization), then constructs an empty `std::move_only_function`. Otherwise, constructs a `std::move_only_function` whose target is of type `VT` and direct-non-list-initialized with `std::forward<F>(f)`. This overload participates in overload resolution only if `VT` is neither same as `move_only_function` nor a specialization of [`std::in_place_type_t`](/docs/cpp/library/utility/in_place), and `/*is-callable-from*/<VT>` (see below) is `true`. The program is ill-formed if `std::is_constructible_v<VT, F>` is not true.

{/* source:cpp-utility-functional-move-only-function-move-only-function:0006 */}
6) Let `VT` be `std::decay_t<T>`. Constructs a `std::move_only_function` whose target is of type `VT` and direct-non-list-initialized with `std::forward<CArgs>(args)....`. This overload participates in overload resolution only if both `std::is_constructible_v<VT, CArgs...>` and `/*is-callable-from*/<VT>` (see below) are `true`. The program is ill-formed if `VT` is not the same type as `T`.

{/* source:cpp-utility-functional-move-only-function-move-only-function:0007 */}
7) Let `VT` be `std::decay_t<T>`. Constructs a `std::move_only_function` whose target is of type `VT` and direct-non-list-initialized with `il, std::forward<CArgs>(args)....`. This overload participates in overload resolution only if both `std::is_constructible_v<VT, std::initializer_list<U>&, CArgs...>` and `/*is-callable-from*/<VT>` (see below) are `true`. The program is ill-formed if `VT` is not the same type as `T`.

{/* source:cpp-utility-functional-move-only-function-move-only-function:0008 */}
For constructors (5-7), the behavior is undefined if `VT` does not satisfy the [*Destructible*](/docs/cpp/library/named_req/Destructible) requirements, or `std::is_move_constructible_v<VT>` is `true` but `VT` does not satisfy the [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible) requirements.

{/* source:cpp-utility-functional-move-only-function-move-only-function:0009 */}
The constant `/*is-callable-from*/<VT>` is dependent on `cv`, `ref`, and `noex` in the template parameter of `std::move_only_function` as below:

{/* source:cpp-utility-functional-move-only-function-move-only-function:0010 */}
| cv ref noexcept(noex) | `/*is-callable-from*/<VT>` |
| --- | --- |
| `noexcept(false)` | `std::is_invocable_r_v<R, VT, Args...> && std::is_invocable_r_v<R, VT&, Args...>` |
| `noexcept(true)` | `std::is_nothrow_invocable_r_v<R, VT, Args...> && std::is_nothrow_invocable_r_v<R, VT&, Args...>` |
| `const noexcept(false)` | `std::is_invocable_r_v<R, const VT, Args...> && std::is_invocable_r_v<R, const VT&, Args...>` |
| `const noexcept(true)` | `std::is_nothrow_invocable_r_v<R, const VT, Args...> && std::is_nothrow_invocable_r_v<R, const VT&, Args...>` |
| `& noexcept(false)` | `std::is_invocable_r_v<R, VT&, Args...>` |
| `& noexcept(true)` | `std::is_nothrow_invocable_r_v<R, VT&, Args...>` |
| `const & noexcept(false)` | `std::is_invocable_r_v<R, const VT&, Args...>` |
| `const & noexcept(true)` | `std::is_nothrow_invocable_r_v<R, const VT&, Args...>` |
| `&& noexcept(false)` | `std::is_invocable_r_v<R, VT, Args...>` |
| `&& noexcept(true)` | `std::is_nothrow_invocable_r_v<R, VT, Args...>` |
| `const && noexcept(false)` | `std::is_invocable_r_v<R, const VT, Args...>` |
| `const && noexcept(true)` | `std::is_nothrow_invocable_r_v<R, const VT, Args...>` |

### Exceptions

{/* source:cpp-utility-functional-move-only-function-move-only-function:0012 */}
5-7) May throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) on allocation failure or propagate the exception thrown by the initialization of the target. No exception is thrown if `VT` is a function pointer type or a specialization of [`std::reference_wrapper`](/docs/cpp/library/utility/functional/reference_wrapper).
