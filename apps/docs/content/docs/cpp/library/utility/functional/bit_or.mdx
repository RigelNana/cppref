Function object for performing bitwise OR. Effectively calls `operator|` on type `T`.

{/* source:cpp-utility-functional-bit-or:0002 */}
<Revision since="C++14">

### Specializations

The standard library provides a specialization of `std::bit_or` when `T` is not specified, which leaves the parameter types and return type to be deduced.

## std::bit_or::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`T operator()( const T& lhs, const T& rhs ) const;`} />
  (constexpr since C++14)
</DeclarationDoc>

Returns the result of bitwise OR of `lhs` and `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to compute bitwise OR of</Parameter>
</ParameterList>

### Return value

The result of `lhs | rhs`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr T operator()(const T& lhs, const T& rhs) const
{
    return lhs | rhs;
}
```
