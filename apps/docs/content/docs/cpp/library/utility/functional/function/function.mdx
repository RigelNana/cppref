  <DeclarationDescription>
    {/* source:cpp-utility-functional-function-function:0001 */}
    Constructs a `std::function` from a variety of sources.

    {/* source:cpp-utility-functional-function-function:0002 */}
    1,2) Creates an [empty](/docs/cpp/library/utility/functional/function) `std::function`.

    {/* source:cpp-utility-functional-function-function:0003 */}
    3) Copies the [target](/docs/cpp/library/utility/functional/function) of `other` to the target of `*this`.

    {/* source:cpp-utility-functional-function-function:0004 */}
    If `other` is empty, `*this` will be empty right after the call too.

    {/* source:cpp-utility-functional-function-function:0005 */}
    4) Moves the target of `other` to the target of `*this`.

    {/* source:cpp-utility-functional-function-function:0006 */}
    If `other` is empty, `*this` will be empty right after the call too.

    {/* source:cpp-utility-functional-function-function:0007 */}
    `other` is in a valid but unspecified state right after the call.

    {/* source:cpp-utility-functional-function-function:0008 */}
    5) Initializes the target with `std::forward<F>(f)`. The target is of type `std::decay<F>::type`.

    {/* source:cpp-utility-functional-function-function:0009 */}
    If `f` is a null pointer to function, a null pointer to member, or an empty value of some `std::function` specialization, `*this` will be empty right after the call.

    {/* source:cpp-utility-functional-function-function:0010 */}
    This overload participates in overload resolution only if all following conditions are satisfied:

    <Revision since="C++23">
    - `std::is_same_v<std::remove_cvref_t<F>, std::function<R(Args...)>` is `false`.
    </Revision>

    - An lvalue of type `std::decay<F>::type` is callable for argument types `Args...` and return type `R`.

    <Revision since="C++23">
    - If `std::is_copy_constructible_v<std::decay_t<F>>` or `std::is_constructible_v<std::decay_t<F>, F>` is `false`, the program is ill-formed.
    </Revision>

    {/* source:cpp-utility-functional-function-function:0011 */}
    If `F` is not [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible), the behavior is undefined.

    {/* source:cpp-utility-functional-function-function:0012 */}
    6-10) Same as (1-5) except that `alloc` is used to allocate memory for any internal data structures that the `std::function` might use.

    {/* source:cpp-utility-functional-function-function:0013 */}
    When the target is a function pointer or a [`std::reference_wrapper`](/docs/cpp/library/utility/functional/reference_wrapper), small object optimization is guaranteed, that is, these targets are always directly stored inside the [`std::function`](/docs/cpp/library/utility/functional/function) object, no dynamic allocation takes place. Other large objects may be constructed in dynamic allocated storage and accessed by the [`std::function`](/docs/cpp/library/utility/functional/function) object through a pointer.
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-utility-functional-function-function:0018 */}
`std::function`'s allocator support was poorly specified and inconsistently implemented. Some implementations do not provide overloads ([`6-10`](/docs/cpp/library/utility/functional/function/function#Version_6)) at all, some provide the overloads but ignore the supplied allocator argument, and some provide the overloads and use the supplied allocator for construction but not when the `std::function` is reassigned. As a result, allocator support was removed in C++17.

### Example

{/* source:cpp-utility-functional-function-function:0019 */}
```cpp
#include <functional>
#include <iostream>
#include <utility>
 
void print_num(int i) { std::cout << "print_num(" << i << ")\n"; }
 
int main()
{
    std::function<void(int)> func1; // (1) empty constructor
    try
    {
        func1(333 << 1);
    }
    catch (const std::bad_function_call& ex)
    {
        std::cout << "1) " << ex.what() << '\n';
    }
 
    std::function<void(int)> func2{nullptr}; // (2) empty constructor
    try
    {
        func1(222 * 3);
    }
    catch (const std::bad_function_call& ex)
    {
        std::cout << "2) " << ex.what() << '\n';
    }
 
    func1 = print_num; // initializes func1 using assignment operator
 
    std::function<void(int)> func3{func1}; // (3) copy constructor
    func3(33);
 
    std::function<void(int)> func4{std::move(func3)}; // (4) move constructor,
                                                      // func3 in unspecified state
    func4(44);
 
    std::function<void(int)> func5{print_num}; // (5) constructor with function
    func5(55);
 
    // (5) constructor with lambda
    std::function<void(int)> func6([](int i) { std::cout << "lambda(" << i << ")\n"; });
    func6(66);
}
```

Possible output:

```text
1) bad_function_call
2) bad_function_call
print_num(33)
print_num(44)
print_num(55)
lambda(66)
```
