Function object for performing multiplication. Effectively calls `operator*` on two instances of type `T`.

{/* source:cpp-utility-functional-multiplies:0002 */}
<Revision since="C++14">
### Specializations

The standard library provides a specialization of `std::multiplies` when `T` is not specified, which leaves the parameter types and return type to be deduced.

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`multiplies<void>`](/docs/cpp/library/utility/functional/multiplies_void)</DescriptionTerm>
    <DescriptionBody>function object implementing `x * y` deducing parameter and return types (class template specialization)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
</Revision>

#### std::multiplies::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`T operator()( const T& lhs, const T& rhs ) const;`} />
  (constexpr since C++14)
</DeclarationDoc>

Returns the product of `lhs` and `rhs`.

##### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to multiply</Parameter>
</ParameterList>

##### Return value

The result of `lhs * rhs`.

##### Exceptions

May throw implementation-defined exceptions.

##### Possible implementation

```cpp
constexpr T operator()(const T& lhs, const T& rhs) const 
{
    return lhs * rhs;
}
```
