## std::less::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`bool operator()( const T& lhs, const T& rhs ) const;`} />
  (constexpr since C++14)
</DeclarationDoc>

Checks whether `lhs` is less than `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to compare</Parameter>
</ParameterList>

### Return value

`lhs < rhs`.

If `T` is a pointer type, the result is consistent with the [implementation-defined strict total order over pointers](/docs/cpp/language/expressions/operator_comparison#Pointer_total_order).

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr bool operator()(const T& lhs, const T& rhs) const 
{
    return lhs < rhs; // assumes that the implementation handles pointer total order
}
```

### Example

{/* source:cpp-utility-functional-less:0007 */}
```cpp
#include <functional>
 
template<typename A, typename B, typename C = std::less<>>
constexpr bool fun(A a, B b, C cmp = C{})
{
    return cmp(a, b);
}
 
static_assert(fun(1, 2) == true);
static_assert(fun(1.0, 1) == false);
static_assert(fun(1, 2.0) == true);
static_assert(std::less<int>{}(5, 5.6) == false);   // 5 < 5 (warn: implicit conversion)
static_assert(std::less<double>{}(5, 5.6) == true); // 5.0 < 5.6
static_assert(std::less<int>{}(5.6, 5.7) == false); // 5 < 5 (warn: implicit conversion)
static_assert(std::less{}(5, 5.6) == true);         // less<void>: 5.0 < 5.6
 
int main() {}
```
