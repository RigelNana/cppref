## std::ranges::not_equal_to::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`template< class T, class U >
constexpr bool operator()( T&& t, U&& u ) const;`} />
</DeclarationDoc>

Equivalent to `return !ranges::equal_to{}(std::forward<T>(t), std::forward<U>(u));`.

This overload participates in overload resolution only if `std::equality_comparable_with<T, U>` is satisfied.

### Notes

{/* source:cpp-utility-functional-ranges-not-equal-to:0005 */}
Unlike [`std::not_equal_to`](/docs/cpp/library/utility/functional/not_equal_to), `std::ranges::not_equal_to` requires both `==` and `!=` to be valid (via the [`equality_comparable_with`](/docs/cpp/library/concepts/equality_comparable) constraint), and is entirely defined in terms of `std::ranges::equal_to`.
