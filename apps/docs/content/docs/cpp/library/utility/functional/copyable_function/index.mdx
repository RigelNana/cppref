{/* source:cpp-utility-functional-copyable-function:0001 */}
Class template `std::copyable_function` is a general-purpose polymorphic function wrapper. `std::copyable_function` objects can store and invoke any [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible) [Callable](/docs/cpp/library/named_req/Callable) *target* — functions, [lambda expressions](/docs/cpp/language/functions/lambda), [bind expressions](/docs/cpp/library/utility/functional/bind), or other function objects, as well as pointers to member functions and pointers to member objects.

{/* source:cpp-utility-functional-copyable-function:0002 */}
The stored callable object is called the *target* of `std::copyable_function`. If a `std::copyable_function` contains no target, it is called *empty*. Unlike [`std::function`](/docs/cpp/library/utility/functional/function), invoking an *empty* `std::copyable_function` results in undefined behavior.

{/* source:cpp-utility-functional-copyable-function:0003 */}
`std::copyable_function`s supports every possible combination of [cv-qualifiers](/docs/cpp/language/classes/member_functions#Member_functions_with_cv-qualifiers) (not including `volatile`), [ref-qualifiers](/docs/cpp/language/classes/member_functions#Member_functions_with_ref-qualifier), and [noexcept-specifiers](/docs/cpp/language/exceptions/noexcept_spec)  provided in its template parameter. These qualifiers and specifier (if any) are added to its [`operator()`](/docs/cpp/library/utility/functional/copyable_function/operator()).

{/* source:cpp-utility-functional-copyable-function:0004 */}
`std::copyable_function` satisfies the requirements of [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible) and [CopyAssignable](/docs/cpp/library/named_req/CopyAssignable).

### Notes

{/* source:cpp-utility-functional-copyable-function:0008 */}
Implementations may store a callable object of small size within the `std::copyable_function` object. Such small object optimization is effectively required for function pointers and [`std::reference_wrapper`](/docs/cpp/library/utility/functional/reference_wrapper) specializations, and can only be applied to types `T` for which `std::is_nothrow_move_constructible_v<T>` is `true`.
