Function object for performing addition. Effectively calls `operator+` on two instances of type `T`.

### Specializations

{/* source:cpp-utility-functional-plus:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::plus` when `T` is not specified, which leaves the parameter types and return type to be deduced.

  <DescriptionItem>
    <DescriptionTerm>[`plus<void>`](/docs/cpp/library/utility/functional/plus_void) <InlineRevision since="C++14" /></DescriptionTerm>

## std::plus::operator()

<DeclarationDoc>
  <Declaration language="cpp" since="C++14" code={`T operator()( const T& lhs, const T& rhs ) const;`} />
</DeclarationDoc>

Returns the sum of `lhs` and `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to sum</Parameter>
</ParameterList>

### Return value

The result of `lhs + rhs`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr T operator()(const T& lhs, const T& rhs) const 
{
    return lhs + rhs;
}
```
