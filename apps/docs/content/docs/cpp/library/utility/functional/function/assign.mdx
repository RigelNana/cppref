{/* source:cpp-utility-functional-function-assign:0001 */}
Initializes the target with `f`. The `alloc` is used to allocate memory for any internal data structures that the `function` might use.

{/* source:cpp-utility-functional-function-assign:0002 */}
Equivalent to `function(std::allocator_arg, alloc, std::forward<F>(f)).swap(*this);`.

### Parameters

{/* source:cpp-utility-functional-function-assign:0003 */}
<ParameterList>
  <Parameter name="f">callable function to initialize the target with</Parameter>
  <Parameter name="alloc">allocator to use to allocate memory for the internal data structures</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-function-assign:0004 */}
(none)

### Exceptions

{/* source:cpp-utility-functional-function-assign:0005 */}
May throw implementation-defined exceptions.
