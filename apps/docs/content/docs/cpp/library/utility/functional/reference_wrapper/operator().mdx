{/* source:cpp-utility-functional-reference-wrapper-operator:0001 */}
Calls the [*Callable*](/docs/cpp/library/named_req/Callable) object, reference to which is stored, as if by [`INVOKE`](/docs/cpp/library/utility/functional)`(`[`get()`](/docs/cpp/library/utility/functional/reference_wrapper/get)`, std::forward<ArgTypes>(args)...)`. This function is available only if the stored reference points to a [*Callable*](/docs/cpp/library/named_req/Callable) object.

{/* source:cpp-utility-functional-reference-wrapper-operator:0002 */}
`T` must be a complete type.

### Parameters

{/* source:cpp-utility-functional-reference-wrapper-operator:0003 */}
<ParameterList>
  <Parameter name="args">arguments to pass to the called function</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-reference-wrapper-operator:0004 */}
The return value of the called function.

### Exceptions

{/* source:cpp-utility-functional-reference-wrapper-operator:0005 */}
<Revision since="C++11" until="C++17">
May throw implementation-defined exceptions.
</Revision>
<Revision since="C++17">
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_invocable_v<T&, ArgTypes...>)`
</Revision>

### Example

{/* source:cpp-utility-functional-reference-wrapper-operator:0006 */}
```cpp
#include <functional>
#include <iostream>
 
void f1()
{
    std::cout << "reference to function called\n";
}
 
void f2(int n)
{
    std::cout << "bind expression called with " << n << " as the argument\n";
}
 
int main()
{
    std::reference_wrapper<void()> ref1 = std::ref(f1);
    ref1();
 
    auto b = std::bind(f2, std::placeholders::_1);
    auto ref2 = std::ref(b);
    ref2(7);
 
    auto c = []{ std::cout << "lambda function called\n"; };
    auto ref3 = std::ref(c);
    ref3();
}
```

Output:

```text
reference to function called
bind expression called with 7 as the argument
lambda function called
```
