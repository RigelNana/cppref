{/* source:cpp-utility-functional-move-only-function:0001 */}
Class template `std::move_only_function` is a general-purpose polymorphic function wrapper. `std::move_only_function` objects can store and invoke any constructible (not required to be move constructible) [*Callable*](/docs/cpp/library/named_req/Callable) *target* — functions, [lambda expressions](/docs/cpp/language/functions/lambda), [bind expressions](/docs/cpp/library/utility/functional/bind), or other function objects, as well as pointers to member functions and pointers to member objects.

{/* source:cpp-utility-functional-move-only-function:0002 */}
The stored callable object is called the *target* of `std::move_only_function`. If a `std::move_only_function` contains no target, it is called *empty*. Unlike [`std::function`](/docs/cpp/library/utility/functional/function), invoking an *empty* `std::move_only_function` results in undefined behavior.

{/* source:cpp-utility-functional-move-only-function:0003 */}
`std::move_only_function`s supports every possible combination of [cv-qualifiers](/docs/cpp/language/classes/member_functions#Member_functions_with_cv-qualifiers) (not including `volatile`), [ref-qualifiers](/docs/cpp/language/classes/member_functions#Member_functions_with_ref-qualifier), and [noexcept-specifiers](/docs/cpp/language/exceptions/noexcept_spec) provided in its template parameter. These qualifiers and specifier (if any) are added to its [`operator()`](/docs/cpp/library/utility/functional/move_only_function/operator()).

{/* source:cpp-utility-functional-move-only-function:0004 */}
`std::move_only_function` satisfies the requirements of [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible) and [*MoveAssignable*](/docs/cpp/library/named_req/MoveAssignable), but does not satisfy [*CopyConstructible*](/docs/cpp/library/named_req/CopyConstructible) or [*CopyAssignable*](/docs/cpp/library/named_req/CopyAssignable).

### Notes

{/* source:cpp-utility-functional-move-only-function:0008 */}
Implementations may store a callable object of small size within the `std::move_only_function` object. Such small object optimization is effectively required for function pointers and [`std::reference_wrapper`](/docs/cpp/library/utility/functional/reference_wrapper) specializations, and can only be applied to types `T` for which `std::is_nothrow_move_constructible_v<T>` is `true`.

{/* source:cpp-utility-functional-move-only-function:0009 */}
If a `std::move_only_function` returning a reference is initialized from a function or function object returning a prvalue (including a lambda expression without a trailing-return-type), the program is ill-formed because binding the returned reference to a temporary object is forbidden. See also [`std::function`](/docs/cpp/library/utility/functional/function#Notes) Notes.

### Example

{/* source:cpp-utility-functional-move-only-function:0011 */}
```cpp
#include <functional>
#include <future>
#include <iostream>
 
int main()
{
    std::packaged_task<double()> packaged_task([](){ return 3.14159; });
 
    std::future<double> future = packaged_task.get_future();
 
    auto lambda = [task = std::move(packaged_task)]() mutable { task(); };
 
//  std::function<void()> function = std::move(lambda); // Error
    std::move_only_function<void()> function = std::move(lambda); // OK
 
    function();
 
    std::cout << future.get();
}
```

Output:

```text
3.14159
```
