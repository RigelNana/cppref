## std::greater_equal\<void\>::operator()

<DeclarationDoc>
  <Declaration language="cpp" code={`template< class T, class U >
constexpr auto operator()( T&& lhs, U&& rhs ) const

    -> decltype(std::forward<T>(lhs) >= std::forward<U>(rhs));`} />
</DeclarationDoc>

Returns the result of `std::forward<T>(lhs) >= std::forward<U>(rhs)`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to compare</Parameter>
</ParameterList>

### Return value

`std::forward<T>(lhs) >= std::forward<U>(rhs)`.

If a built-in operator comparing pointers is called, the result is consistent with the [implementation-defined strict total order over pointers](/docs/cpp/language/expressions/operator_comparison#Pointer_total_order).

### Exceptions

May throw implementation-defined exceptions.

### Example

{/* source:cpp-utility-functional-greater-equal-void:0005 */}
```cpp
#include <algorithm>
#include <functional>
#include <initializer_list>
 
constexpr bool strictly_not_negative(int lhs)
{
    return std::greater_equal<>()(lhs, 0);
}
 
int main()
{
    constexpr int low = 0, high = 8;
    std::greater_equal<> greater_equal{};
    static_assert(greater_equal(high, low));
    static_assert(greater_equal(low, low));
 
    static constexpr auto arr = {-1, 0, 1, 2, 3, 4};
    static_assert(!std::all_of(arr.begin(), arr.end(), strictly_not_negative));
    static_assert(std::all_of(arr.begin() + 1, arr.end(), strictly_not_negative));
}
```
