Function object for performing subtraction. Effectively calls `operator-` on two instances of type `T`.

### Specializations

{/* source:cpp-utility-functional-minus:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::minus` when `T` is not specified, which leaves the parameter types and return type to be deduced.

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`minus<void>`](/docs/cpp/library/utility/functional/minus_void)</DescriptionTerm>
    <DescriptionBody>function object implementing `x - y` deducing parameter and return types (class template specialization)</DescriptionBody>

</DescriptionList>

## std::minus::operator()

<DeclarationDoc>
  <Declaration language="cpp" since="C++14" code={`T operator()( const T& lhs, const T& rhs ) const;`} />
  <InlineRevision since="C++14">constexpr</InlineRevision>
</DeclarationDoc>

Returns the difference between `lhs` and `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to subtract from one another</Parameter>
</ParameterList>

### Return value

The result of `lhs - rhs`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr T operator()(const T& lhs, const T& rhs) const 
{
    return lhs - rhs;
}
```
