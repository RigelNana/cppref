Wrapper around a member function pointer. The class instance whose member function to call is passed as a pointer to the `operator()`.

{/* source:cpp-utility-functional-mem-fun-t:0002 */}
1. 1) Wraps a non-const member function with no parameters.

{/* source:cpp-utility-functional-mem-fun-t:0003 */}
2. 2) Wraps a const member function with no parameters.

{/* source:cpp-utility-functional-mem-fun-t:0004 */}
3. 3) Wraps a non-const member function with a single parameter.

{/* source:cpp-utility-functional-mem-fun-t:0005 */}
4. 4) Wraps a const member function with a single parameter.
