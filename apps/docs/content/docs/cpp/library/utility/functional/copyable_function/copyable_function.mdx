{/* source:cpp-utility-functional-copyable-function-copyable-function:0001 */}
Creates a new `std::copyable_function`.

{/* source:cpp-utility-functional-copyable-function-copyable-function:0002 */}
1. 1,2) Default constructor and the constructor taking `nullptr` construct an empty `std::copyable_function`.

{/* source:cpp-utility-functional-copyable-function-copyable-function:0003 */}
2. 3) Copy constructor constructs a `std::copyable_function` whose target is a copy of the target of `other`. Otherwise, constructs an empty `std::copyable_function` if `other` is empty.

{/* source:cpp-utility-functional-copyable-function-copyable-function:0004 */}
3. 4) Move constructor constructs a `std::copyable_function` whose target is that of `other`. `other` is in a valid but unspecified state after move construction.

{/* source:cpp-utility-functional-copyable-function-copyable-function:0005 */}
4. 5) Let `VT` be `std::decay_t<F>`. If `f` is a null function pointer, a null pointer to member value, or an empty `std::copyable_function` (may be any other specialization), then constructs an empty `std::copyable_function`. Otherwise, constructs a `std::copyable_function` whose target is of type `VT` and direct-non-list-initialized with `std::forward<F>(f)`.

   - This overload participates in overload resolution only if `VT` is neither same as `copyable_function` nor a specialization of [`std::in_place_type_t`](/docs/cpp/library/utility/in_place), and `/*is-callable-from*/<VT>` (see below) is `true`.
   - The program is ill-formed if `std::is_constructible_v<VT, F>` or `std::is_copy_constructible_v<VT>` is not `true`.

{/* source:cpp-utility-functional-copyable-function-copyable-function:0006 */}
5. 6) Let `VT` be `std::decay_t<T>`. Constructs a `std::copyable_function` whose target is of type `VT` and direct-non-list-initialized with `std::forward<CArgs>(args)...`.

   - This overload participates in overload resolution only if both `std::is_constructible_v<VT, CArgs...>` and `/*is-callable-from*/<VT>` (see below) are `true`.
   - The program is ill-formed if `VT` is not the same type as `T` or `std::is_copy_constructible_v<VT>` is not `true`.

{/* source:cpp-utility-functional-copyable-function-copyable-function:0007 */}
6. 7) Let `VT` be `std::decay_t<T>`. Constructs a `std::copyable_function` whose target is of type `VT` and direct-non-list-initialized with `il, std::forward<CArgs>(args)...`.

   - This overload participates in overload resolution only if both `std::is_constructible_v<VT, std::initializer_list<U>&, CArgs...>` and `/*is-callable-from*/<VT>` (see below) are `true`.
   - The program is ill-formed if `VT` is not the same type as `T` or `std::is_copy_constructible_v<VT>` is not `true`.

{/* source:cpp-utility-functional-copyable-function-copyable-function:0008 */}
For constructors (5-7), the behavior is undefined unless `VT` satisfies both [Destructible](/docs/cpp/library/named_req/Destructible) and [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible) requirements.

{/* source:cpp-utility-functional-copyable-function-copyable-function:0009 */}
The constant `/*is-callable-from*/<VT>` is dependent on `cv`, `ref`, and `noex` in the template parameter of `std::copyable_function` as below:

{/* source:cpp-utility-functional-copyable-function-copyable-function:0010 */}
| `cv` `ref` `noexcept(` `noex` `)` | `/*is-callable-from*/<VT>` |
| --- | --- |
| `noexcept(false)` | `std::is_invocable_r_v<R, VT, Args...> && std::is_invocable_r_v<R, VT&, Args...>` |
| `noexcept(true)` | `std::is_nothrow_invocable_r_v<R, VT, Args...> && std::is_nothrow_invocable_r_v<R, VT&, Args...>` |
| `const noexcept(false)` | `std::is_invocable_r_v<R, const VT, Args...> && std::is_invocable_r_v<R, const VT&, Args...>` |
| `const noexcept(true)` | `std::is_nothrow_invocable_r_v<R, const VT, Args...> && std::is_nothrow_invocable_r_v<R, const VT&, Args...>` |
| `& noexcept(false)` | `std::is_invocable_r_v<R, VT&, Args...>` |
| `& noexcept(true)` | `std::is_nothrow_invocable_r_v<R, VT&, Args...>` |
| `const & noexcept(false)` | `std::is_invocable_r_v<R, const VT&, Args...>` |
| `const & noexcept(true)` | `std::is_nothrow_invocable_r_v<R, const VT&, Args...>` |
| `&& noexcept(false)` | `std::is_invocable_r_v<R, VT, Args...>` |
| `&& noexcept(true)` | `std::is_nothrow_invocable_r_v<R, VT, Args...>` |
| `const && noexcept(false)` | `std::is_invocable_r_v<R, const VT, Args...>` |
| `const && noexcept(true)` | `std::is_nothrow_invocable_r_v<R, const VT, Args...>` |
