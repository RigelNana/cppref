Function object for performing bitwise AND. Effectively calls `operator&` on type T.

### Specializations

{/* source:cpp-utility-functional-bit-and:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::bit_and` when `T` is not specified, which leaves the parameter types and return type to be deduced.

## std::bit_and::operator()

{/* source:cpp-utility-functional-bit-and:0006 */}
<DeclarationDoc>
  <Declaration language="cpp" code={`T operator()( const T& lhs, const T& rhs ) const;`} />
  (constexpr since C++14)
</DeclarationDoc>

Returns the result of bitwise AND of `lhs` and `rhs`.

### Parameters

<ParameterList>
  <Parameter name="lhs, rhs">values to compute bitwise AND of</Parameter>
</ParameterList>

### Return value

The result of `lhs & rhs`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr T operator()(const T& lhs, const T& rhs) const
{
    return lhs & rhs;
}
```
