{/* source:cpp-utility-functional-reference-wrapper-reference-wrapper:0001 */}
Constructs a new reference wrapper.

{/* source:cpp-utility-functional-reference-wrapper-reference-wrapper:0002 */}
1. 1) Converts `x` to `T&` as if by `T& t = std::forward<U>(x);`, then stores a reference to `t`. This overload participates in overload resolution only if `typename std::decay<U>::type` is not the same type as `reference_wrapper` and the expression `FUN(std::declval<U>())` is well-formed, where `FUN` names the set of imaginary functions

```cpp
void FUN(T&) noexcept;
void FUN(T&&) = delete;
```

{/* source:cpp-utility-functional-reference-wrapper-reference-wrapper:0003 */}
2. 2) Copy constructor. Stores a reference to `other.get()`.
