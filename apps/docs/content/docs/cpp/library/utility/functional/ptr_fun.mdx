{/* source:cpp-utility-functional-ptr-fun:0001 */}
Creates a function wrapper object (either `std::pointer_to_unary_function` or `std::pointer_to_binary_function`), deducing the target type from the template arguments.

{/* source:cpp-utility-functional-ptr-fun:0002 */}
1. 1) Effectively calls `std::pointer_to_unary_function<Arg,Result>(f)`.

{/* source:cpp-utility-functional-ptr-fun:0003 */}
2. 2) Effectively calls `std::pointer_to_binary_function<Arg1,Arg2,Result>(f)`.

{/* source:cpp-utility-functional-ptr-fun:0004 */}
This function and the related types are deprecated as of C++11 in favor of the more general [`std::function`](/docs/cpp/library/utility/functional/function) and [`std::ref`](/docs/cpp/library/utility/functional/ref), both of which create callable adaptor-compatible function objects from plain functions.

### Parameters

{/* source:cpp-utility-functional-ptr-fun:0005 */}
<ParameterList>
  <Parameter name="f">pointer to a function to create a wrapper for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-functional-ptr-fun:0006 */}
A function object wrapping `f`.

### Exceptions

{/* source:cpp-utility-functional-ptr-fun:0007 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-utility-functional-ptr-fun:0008 */}
```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <string_view>
 
constexpr bool is_vowel(char c)
{
    return std::string_view{"aeoiuAEIOU"}.find(c) != std::string_view::npos;
}
 
int main()
{
    std::string_view s = "Hello, world!";
    std::ranges::copy_if(s, std::ostreambuf_iterator<char>(std::cout),
        std::not1(std::ptr_fun(is_vowel)));
#if 0
// C++11 alternatives:
        std::not1(std::cref(is_vowel)));
        std::not1(std::function<bool(char)>(is_vowel)));
        [](char c) { return !is_vowel(c); });
// C++17 alternatives:
        std::not_fn(is_vowel));
#endif
}
```

Output:

```text
Hll, wrld!
```
