Function object for performing logical NOT (logical negation). Effectively calls `operator!` for type `T`.

### Specializations

{/* source:cpp-utility-functional-logical-not:0002 */}
<Revision since="C++14">
The standard library provides a specialization of `std::logical_not` when `T` is not specified, which leaves the parameter types and return type to be deduced.

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`logical_not<void>`](/docs/cpp/library/utility/functional/logical_not_void)</DescriptionTerm>
    <DescriptionBody>function object implementing `!x` deducing parameter and return types (class template specialization)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
</Revision>

## std::logical_not::operator()

<DeclarationDoc>
  <Declaration language="cpp" since="C++14" code={`bool operator()( const T& arg ) const;`} />
  <InlineRevision since="C++14">constexpr</InlineRevision>
</DeclarationDoc>

Returns the logical NOT of `arg`.

### Parameters

<ParameterList>
  <Parameter name="arg">value to compute logical NOT of</Parameter>
</ParameterList>

### Return value

The result of `!arg`.

### Exceptions

May throw implementation-defined exceptions.

### Possible implementation

```cpp
constexpr // since C++14
bool operator()(const T& arg) const 
{
    return !arg;
}
```
