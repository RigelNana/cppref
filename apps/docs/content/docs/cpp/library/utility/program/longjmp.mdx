{/* source:cpp-utility-program-longjmp:0001 */}
Loads the execution context `env` saved by a previous call to [`setjmp`](/docs/cpp/library/utility/program/setjmp). This function does not return. Control is transferred to the call site of the macro [`setjmp`](/docs/cpp/library/utility/program/setjmp) that set up `env`. That [`setjmp`](/docs/cpp/library/utility/program/setjmp) then returns the value, passed as the `status`.

{/* source:cpp-utility-program-longjmp:0002 */}
If the function that called [`setjmp`](/docs/cpp/library/utility/program/setjmp) has exited, the behavior is undefined (in other words, only long jumps up the call stack are allowed).

### Extra restrictions in C++

{/* source:cpp-utility-program-longjmp:0003 */}
On top of C [`longjmp`](/docs/c/library/program/longjmp), C++ `std::longjmp` has more restricted behavior.

{/* source:cpp-utility-program-longjmp:0004 */}
If replacing `std::longjmp` with `throw` and [`setjmp`](/docs/cpp/library/utility/program/setjmp) with `catch` would invoke a [non-trivial destructor](/docs/cpp/language/classes/destructor#Trivial_destructor) for any automatic object, the behavior of such `std::longjmp` is undefined.

{/* source:cpp-utility-program-longjmp:0005 */}
<Revision since="C++20">
The behavior is undefined if `std::longjmp` is called in a [coroutine](/docs/cpp/language/functions/coroutines) in a place where the `co_await` operator may be used.
</Revision>

{/* source:cpp-utility-program-longjmp:0007 */}
(none)

### Notes

{/* source:cpp-utility-program-longjmp:0008 */}
`std::longjmp` is the mechanism used in C to handle unexpected error conditions where the function cannot return meaningfully. C++ generally uses [exception handling](/docs/cpp/language/exceptions) for this purpose.

### Example

{/* source:cpp-utility-program-longjmp:0009 */}
```cpp
#include <array>
#include <cmath>
#include <csetjmp>
#include <cstdlib>
#include <format>
#include <iostream>
 
std::jmp_buf solver_error_handler;
 
std::array<double, 2> solve_quadratic_equation(double a, double b, double c)
{
    const double discriminant = b * b - 4.0 * a * c;
    if (discriminant < 0)
        std::longjmp(solver_error_handler, true); // Go to error handler
 
    const double delta = std::sqrt(discriminant) / (2.0 * a);
    const double argmin = -b / (2.0 * a);
    return {argmin - delta, argmin + delta};
}
 
void show_quadratic_equation_solution(double a, double b, double c)
{
    std::cout << std::format("Solving {}x² + {}x + {} = 0...\n", a, b, c);
    auto [x_0, x_1] = solve_quadratic_equation(a, b, c);
    std::cout << std::format("x₁ = {}, x₂ = {}\n\n", x_0, x_1);
}
 
int main()
{
    if (setjmp(solver_error_handler))
    {
        // Error handler for solver
        std::cout << "No real solution\n";
        return EXIT_FAILURE;
    }
 
    for (auto [a, b, c] : {std::array{1, -3, 2}, {2, -3, -2}, {1, 2, 3}})
        show_quadratic_equation_solution(a, b, c);
 
    return EXIT_SUCCESS;
}
```

Output:

```text
Solving 1x² + -3x + 2 = 0...
x₁ = 1, x₂ = 2
 
Solving 2x² + -3x + -2 = 0...
x₁ = -0.5, x₂ = 2
 
Solving 1x² + 2x + 3 = 0...
No real solution
```
