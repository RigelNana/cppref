### Program termination

{/* source:cpp-utility-program:0000 */}
The following functions manage program termination and resource cleanup.

{/* source:cpp-utility-program:0001 */}
Defined in header [`<cstdlib>`](/docs/cpp/library/headers/cstdlib)

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`abort`](/docs/cpp/library/utility/program/abort)</DescriptionTerm>
    <DescriptionBody>causes abnormal program termination (without cleaning up) (function)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`exit`](/docs/cpp/library/utility/program/exit)</DescriptionTerm>
    <DescriptionBody>causes normal program termination with cleaning up (function)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`quick_exit`](/docs/cpp/library/utility/program/quick_exit) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>causes quick program termination without completely cleaning up (function)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`_Exit`](/docs/cpp/library/utility/program/_Exit) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>causes normal program termination without cleaning up (function)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`atexit`](/docs/cpp/library/utility/program/atexit)</DescriptionTerm>
    <DescriptionBody>registers a function to be called on [`std::exit()`](/docs/cpp/library/utility/program/exit) invocation (function)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`at_quick_exit`](/docs/cpp/library/utility/program/at_quick_exit) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>registers a function to be called on [`std::quick_exit`](/docs/cpp/library/utility/program/quick_exit) invocation (function)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`EXIT_SUCCESS`, `EXIT_FAILURE`](/docs/cpp/library/utility/program/EXIT_status)</DescriptionTerm>
    <DescriptionBody>indicates program execution status (macro constant)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
