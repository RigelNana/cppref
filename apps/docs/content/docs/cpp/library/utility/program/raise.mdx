  <Declaration language="cpp" code={`int raise( int sig );`} />

{/* source:cpp-utility-program-raise:0001 */}
Sends signal `sig` to the program. The signal handler (specified using the [`std::signal()`](/docs/cpp/library/utility/program/signal) function) is invoked.

{/* source:cpp-utility-program-raise:0002 */}
If the user-defined signal handling strategy is not set using [`std::signal()`](/docs/cpp/library/utility/program/signal) yet, it is implementation-defined whether the signal will be ignored or default handler will be invoked.

### Parameters

{/* source:cpp-utility-program-raise:0003 */}
<ParameterList>
  <Parameter name="sig">
    the signal to be sent. It can be an implementation-defined value or one of the following values:

    <DescriptionList>
      <DescriptionItem>
        <DescriptionTerm>[`SIGABRT SIGFPE SIGILL SIGINT SIGSEGV SIGTERM`](/docs/cpp/library/utility/program/SIG_types)</DescriptionTerm>
        <DescriptionBody>defines signal types (macro constant)</DescriptionBody>
      </DescriptionItem>
    </DescriptionList>
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-program-raise:0004 */}
`0` upon success, non-zero value on failure.

### Example

{/* source:cpp-utility-program-raise:0005 */}
```cpp
#include <csignal>
#include <iostream>
 
void signal_handler(int signal)
{
    std::cout << "Received signal " << signal << '\n';
}
 
int main()
{
    // Install a signal handler
    std::signal(SIGTERM, signal_handler);
 
    std::cout << "Sending signal " << SIGTERM << '\n';
    std::raise(SIGTERM);
}
```

Possible output:

```text
Sending signal 15
Received signal 15
```
