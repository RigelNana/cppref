Each of the above macro constants expands to an integer constant expression with distinct values, which represent different signals sent to the program.

{/* source:cpp-utility-program-sig-types:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`SIGTERM`</DescriptionTerm>
    <DescriptionBody>termination request, sent to the program</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`SIGSEGV`</DescriptionTerm>
    <DescriptionBody>invalid memory access (segmentation fault)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`SIGINT`</DescriptionTerm>
    <DescriptionBody>external interrupt, usually initiated by the user</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`SIGILL`</DescriptionTerm>
    <DescriptionBody>invalid program image, such as invalid instruction</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`SIGABRT`</DescriptionTerm>
    <DescriptionBody>abnormal termination condition, as is e.g. initiated by [`std::abort()`](/docs/cpp/library/utility/program/abort)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`SIGFPE`</DescriptionTerm>
    <DescriptionBody>erroneous arithmetic operation such as divide by zero</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Notes

{/* source:cpp-utility-program-sig-types:0003 */}
Additional signal names [are specified by POSIX](https://pubs.opengroup.org/onlinepubs/9699919799/basedefs/signal.h.html).
