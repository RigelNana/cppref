{/* source:cpp-utility-program-exit-status:0001 */}
The `EXIT_SUCCESS` and `EXIT_FAILURE` macros expand into integral constant expressions that can be used as arguments to the [`std::exit`](/docs/cpp/library/utility/program/exit) function (and, therefore, as the values to return from the [main function](/docs/cpp/language/basic_concepts/main_function)), and indicate program execution status.

{/* source:cpp-utility-program-exit-status:0002 */}
<Revision since="C++23">
A freestanding implementation is required to provide `EXIT_SUCCESS` and `EXIT_FAILURE`.
</Revision>

{/* source:cpp-utility-program-exit-status:0003 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`EXIT_SUCCESS`</DescriptionTerm>
    <DescriptionBody>successful execution of a program</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`EXIT_FAILURE`</DescriptionTerm>
    <DescriptionBody>unsuccessful execution of a program</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Notes

{/* source:cpp-utility-program-exit-status:0004 */}
Both `EXIT_SUCCESS` and the value zero indicate successful program execution status (see [`std::exit`](/docs/cpp/library/utility/program/exit)), although it is not required that `EXIT_SUCCESS` equals zero.

{/* source:cpp-utility-program-exit-status:0005 */}
Although `EXIT_SUCCESS` and `EXIT_FAILURE` are required to be freestanding since C++23, they are not required to be available in a freestanding C implementation.

### Example

{/* source:cpp-utility-program-exit-status:0006 */}
```cpp
#include <cstdlib>
#include <iostream>
 
int main(int argc, char* argv[])
{
    if (argc <= 1)
    {
        std::cout << "At least one command-line argument required\n";
        return EXIT_FAILURE;
    }
 
    std::cout << argv[1] << '\n';
    return EXIT_SUCCESS;
}
```

Possible output:

```text
The quick brown fox jumps over the lazy cat
```
