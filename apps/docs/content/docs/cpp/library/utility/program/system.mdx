{/* source:cpp-utility-program-system:0001 */}
Calls the host environment's command processor (e.g. `/bin/sh`, `cmd.exe`) with the parameter `command`. Returns an implementation-defined value (usually the value that the invoked program returns).

{/* source:cpp-utility-program-system:0002 */}
If `command` is a null pointer, checks if the host environment has a command processor and returns a nonzero value if and only if the command processor exists.

### Parameters

{/* source:cpp-utility-program-system:0003 */}
<ParameterList>
  <Parameter name="command">character string identifying the command to be run in the command processor. If a null pointer is given, command processor is checked for existence</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-program-system:0004 */}
Implementation-defined value. If `command` is a null pointer, returns a nonzero value if and only if the command processor exists.

### Notes

{/* source:cpp-utility-program-system:0005 */}
On POSIX systems, the return value can be decomposed using [WEXITSTATUS and WSTOPSIG](https://pubs.opengroup.org/onlinepubs/9699919799/functions/wait.html).

{/* source:cpp-utility-program-system:0006 */}
The related POSIX function [popen](https://pubs.opengroup.org/onlinepubs/9699919799/functions/popen.html) makes the output generated by `command` available to the caller.

{/* source:cpp-utility-program-system:0007 */}
An explicit flush of [`std::cout`](/docs/cpp/library/io/basic_ostream/cout) is also necessary before a call to `std::system`, if the spawned process performs any screen I/O.

### Example

{/* source:cpp-utility-program-system:0008 */}
```cpp
#include <cstdlib>
#include <fstream>
#include <iostream>
 
int main()
{
    std::system("ls -l >test.txt"); // executes the UNIX command "ls -l >test.txt"
    std::cout << std::ifstream("test.txt").rdbuf();
}
```

Possible output:

```text
total 16
-rwxr-xr-x 1 2001 2000 8859 Sep 30 20:52 a.out
-rw-rw-rw- 1 2001 2000  161 Sep 30 20:52 main.cpp
-rw-r--r-- 1 2001 2000    0 Sep 30 20:52 test.txt
```
