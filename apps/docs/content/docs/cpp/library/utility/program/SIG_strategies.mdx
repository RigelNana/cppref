The `SIG_DFL` and `SIG_IGN` macros expand into integral expressions that are not equal to an address of any function. The macros define signal handling strategies for `std::signal()` function.

{/* source:cpp-utility-program-sig-strategies:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`SIG_DFL`</DescriptionTerm>
    <DescriptionBody>default signal handling</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`SIG_IGN`</DescriptionTerm>
    <DescriptionBody>signal is ignored</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
