Provides access to the number of alternatives in a possibly cv-qualified variant as a compile-time constant expression.

{/* source:cpp-utility-variant-variant-size:0002 */}
Formally,

{/* source:cpp-utility-variant-variant-size:0003 */}
2) meets the [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait) requirements with a base characteristic of `std::integral_constant<std::size_t, sizeof...(Types)>`

{/* source:cpp-utility-variant-variant-size:0004 */}
3-5) meets the [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait) requirements with a base characteristic of `std::integral_constant<std::size_t, std::variant_size<T>::value>`

### Notes

{/* source:cpp-utility-variant-variant-size:0007 */}
All specializations of `std::variant_size` satisfy [UnaryTypeTrait](/docs/cpp/library/named_req/UnaryTypeTrait) with base characteristic `std::integral_constant<std::size_t, N>` for some `N`.

### Example

{/* source:cpp-utility-variant-variant-size:0008 */}
```cpp
#include <any>
#include <variant>
 
static_assert(std::variant_size_v<std::variant<>> == 0);
static_assert(std::variant_size_v<std::variant<int>> == 1);
static_assert(std::variant_size_v<std::variant<int, int>> == 2);
static_assert(std::variant_size_v<std::variant<int, int, int>> == 3);
static_assert(std::variant_size_v<std::variant<int, float, double>> == 3);
static_assert(std::variant_size_v<std::variant<std::monostate, void>> == 2);
static_assert(std::variant_size_v<std::variant<const int, const float>> == 2);
static_assert(std::variant_size_v<std::variant<std::variant<std::any>>> == 1);
 
int main() {}
```
