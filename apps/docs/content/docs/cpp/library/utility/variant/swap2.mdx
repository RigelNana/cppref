{/* source:cpp-utility-variant-swap2:0001 */}
Overloads the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::variant`](/docs/cpp/library/utility/variant). Effectively calls `lhs.swap(rhs)`.

{/* source:cpp-utility-variant-swap2:0002 */}
This overload participates in overload resolution only if `std::is_move_constructible_v<T_i>` and `std::is_swappable_v<T_i>` are both `true` for all `T_i` in `Types...`.

### Parameters

{/* source:cpp-utility-variant-swap2:0003 */}
<ParameterList>
  <Parameter name="lhs, rhs">variant objects whose values to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-variant-swap2:0004 */}
(none)

### Exceptions

{/* source:cpp-utility-variant-swap2:0005 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(noexcept(lhs.swap(rhs)))`

### Example

{/* source:cpp-utility-variant-swap2:0007 */}
```cpp
#include <iostream>
#include <string>
#include <variant>
 
void print(auto const& v, char term = '\n')
{
    std::visit([](auto&& o) { std::cout << o; }, v);
    std::cout << term;
}
 
int main()
{
    std::variant<int, std::string> v1{123}, v2{"XYZ"};
    print(v1, ' ');
    print(v2);
 
    std::swap(v1, v2);
    print(v1, ' ');
    print(v2);
 
    std::variant<double, std::string> v3{3.14};
    // std::swap(v1, v3); // ERROR: ~ inconsistent parameter packs
}
```

Output:

```text
123 XYZ
XYZ 123
```
