{/* source:cpp-utility-variant:0001 */}
Returns the zero-based index of the alternative that is currently held by the variant.

{/* source:cpp-utility-variant:0002 */}
If the variant is [valueless_by_exception](/docs/cpp/utility/valueless-by-exception), returns [variant_npos](/docs/cpp/utility/variant-npos).

### Example

{/* source:cpp-utility-variant:0003 */}
```cpp
#include <iostream>
#include <string>
#include <variant>
 
int main()
{
    std::variant<int, std::string> v = "abc";
    std::cout << "v.index = " << v.index() << '\n';
    v = {};
    std::cout << "v.index = " << v.index() << '\n';
}
```
Output:

```text
v.index = 1
v.index = 0
```
