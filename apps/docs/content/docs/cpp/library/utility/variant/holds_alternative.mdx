  <Declaration language="cpp" since="C++17" code={`template< class T, class... Types >
constexpr bool holds_alternative( const std::variant<Types...>& v ) noexcept;`} />
</DeclarationDoc>

{/* source:cpp-utility-variant-holds-alternative:0001 */}
Checks if the variant `v` holds the alternative `T`. The call is ill-formed if `T` does not appear exactly once in `Types...`

### Parameters

{/* source:cpp-utility-variant-holds-alternative:0002 */}
<ParameterList>
  <Parameter name="v">variant to examine</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-variant-holds-alternative:0003 */}
`true` if the variant currently holds the alternative `T`, `false` otherwise.

### Example

{/* source:cpp-utility-variant-holds-alternative:0004 */}
```cpp
#include <cassert>
#include <string>
#include <variant>
 
int main()
{
    std::variant<int, std::string> v = "abc";
    assert(not std::holds_alternative<int>(v));
    assert(std::holds_alternative<std::string>(v));
}
```
