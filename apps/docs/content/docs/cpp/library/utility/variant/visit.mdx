{/* source:cpp-utility-variant-visit:0001 */}
Applies the visitor `vis` (a [Callable](/docs/cpp/library/named_req/Callable) that can be called with any combination of types from the variant) to the variant held by `self`.

{/* source:cpp-utility-variant-visit:0002 */}
Given type `V` as `decltype(std::forward_like<Self>(std::declval<variant>()))`, the equivalent call is:

{/* source:cpp-utility-variant-visit:0003 */}
1. 1) `return std::visit(std::forward<Visitor>(vis), (V) self);`.

{/* source:cpp-utility-variant-visit:0004 */}
2. 2) `return std::visit<R>(std::forward<Visitor>(vis), (V) self);`.

### Parameters

{/* source:cpp-utility-variant-visit:0005 */}
<ParameterList>
  <Parameter name="vis">a [Callable](/docs/cpp/library/named_req/Callable) that accepts every possible alternative from the variant</Parameter>
  <Parameter name="self">variant to pass to the visitor</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-variant-visit:0006 */}
1. 1) The result of the `std::visit` invocation.

{/* source:cpp-utility-variant-visit:0007 */}
2. 2) Nothing if `R` is (possibly cv-qualified) `void`; otherwise the result of the `std::visit<R>` invocation.

### Exceptions

{/* source:cpp-utility-variant-visit:0008 */}
Only throws if the call to `std::visit` throws.

### Notes

### Example

{/* source:cpp-utility-variant-visit:0010 */}
```cpp
#include <print>
#include <string>
#include <string_view>
#include <variant>
 
struct Base {};
struct Derived : Base {};
 
// helper type for the visitor
template<class... Ts>
struct overloads : Ts... { using Ts::operator()...; };
 
// the variant to visit
using var_t = std::variant<int, std::string, Derived>;
 
int main()
{
    const auto visitor = overloads
    {
        [](int i){ std::print("int = {}\n", i); },
        [](std::string_view s){ std::println("string = “{}”", s); },
        [](const Base&){ std::println("base"); }
    };
 
    const var_t var1 = 42, var2 = "abc", var3 = Derived();
 
#if (__cpp_lib_variant >= 202306L)
    var1.visit(visitor);
    var2.visit(visitor);
    var3.visit(visitor);
#else
    std::visit(visitor, var1);
    std::visit(visitor, var2);
    std::visit(visitor, var3);
#endif
}
```

Output:

```text
int = 42
string = “abc”
base
```
