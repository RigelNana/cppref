{/* source:cpp-utility-variant-bad-variant-access:0001 */}
`std::bad_variant_access` is the type of the exception thrown in the following situations:

{/* source:cpp-utility-variant-bad-variant-access:0002 */}
- [`std::get(std::variant)`](/docs/cpp/library/utility/variant/get) called with an index or type that does not match the currently active alternative.
- [`std::visit`](/docs/cpp/library/utility/variant/visit2) called to visit a variant that is [valueless_by_exception](/docs/cpp/library/utility/variant/valueless_by_exception).

{/* source:cpp-utility-variant-bad-variant-access:0003 */}
<Revision since="C++26">
[`std::variant::visit`](/docs/cpp/library/utility/variant/visit) called to visit a variant that is [valueless_by_exception](/docs/cpp/library/utility/variant/valueless_by_exception).
</Revision>

#### `std::bad_variant_access::bad_variant_access`

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++17" code={`bad_variant_access() noexcept;`} />
  <Declaration id="2" language="cpp" since="C++17" code={`bad_variant_access( const bad_variant_access& other ) noexcept;`} />
</DeclarationDoc>

Constructs a new `bad_variant_access` object with an implementation-defined null-terminated byte string which is accessible through [`what()`](/docs/cpp/library/error/exception/what).

1. Default constructor.
2. Copy constructor. If `*this` and `other` both have dynamic type `std::bad_variant_access` then `std::strcmp(what(), other.what()) == 0`.

#### `std::bad_variant_access::what`

<DeclarationDoc>
  <Declaration language="cpp" since="C++17" code={`virtual const char* what() const noexcept;`} />
</DeclarationDoc>

Returns the explanatory string.

##### Return value

Pointer to an implementation-defined null-terminated string with explanatory information. The string is suitable for conversion and display as a [`std::wstring`](/docs/cpp/library/string/basic_string). The pointer is guaranteed to be valid at least until the exception object from which it is obtained is destroyed, or until a non-const member function (e.g. copy assignment operator) on the exception object is called.

<Revision since="C++26">
The returned string is encoded with the ordinary literal encoding during constant evaluation.
</Revision>

##### Notes

Implementations are allowed but not required to override `what()`.

### Example

{/* source:cpp-utility-variant-bad-variant-access:0009 */}
```cpp
#include <iostream>
#include <variant>
 
int main()
{
    std::variant<int, float> v;
    v = 12;
    try
    {
        std::get<float>(v);
    }
    catch (const std::bad_variant_access& e)
    {
        std::cout << e.what() << '\n';
    }
}
```
Possible output:

```text
bad_variant_access
```
