{/* source:cpp-utility-variant-visit2:0001 */}
Applies the visitor `v` (a [Callable](/docs/cpp/library/named_req/Callable) that can be called with any combination of types from `Variants`) to the `Variants` values.

{/* source:cpp-utility-variant-visit2:0002 */}
Given `VariantBases` as `decltype(as-variant(std::forward<Variants>(values))...)` (a pack of `sizeof...(Variants)` types):

{/* source:cpp-utility-variant-visit2:0003 */}
1. 1) Invokes `v` as if by [`INVOKE`](/docs/cpp/library/utility/functional)`(std::forward<Visitor>(v),`<br />`std::get<indices>(std::forward<VariantBases>(values))...)`, where `indices` is `as-variant(values).index()...`.

{/* source:cpp-utility-variant-visit2:0004 */}
2. 2) Invokes `v` as if by [`INVOKE<R>`](/docs/cpp/library/utility/functional)`(std::forward<Visitor>(v),`<br />`std::get<indices>(std::forward<VariantBases>(values))...)`, where `indices` is `as-variant(values).index()...`.

{/* source:cpp-utility-variant-visit2:0005 */}
These overloads participate in overload resolution only if every type in `VariantBases` is a valid type. If the expression denoted by [`INVOKE`](/docs/cpp/library/utility/functional) <InlineRevision since="C++20">or [`INVOKE<R>`](/docs/cpp/library/utility/functional)</InlineRevision> is invalid, or the results of [`INVOKE`](/docs/cpp/library/utility/functional) <InlineRevision since="C++20">or [`INVOKE<R>`](/docs/cpp/library/utility/functional)</InlineRevision> have different types or value categories for different `indices`, the program is ill-formed.

{/* source:cpp-utility-variant-visit2:0006 */}
3-6) The exposition-only `as-variant` function templates accept a value whose type can be [deduced](/docs/cpp/language/templates/template_argument_deduction) for `std::variant<Ts...>` (i.e., either `std::variant<Ts...>` or a type derived from [`std::variant`](/docs/cpp/library/utility/variant)), and return the `std::variant` value with the same const-qualification and value category.

{/* source:cpp-utility-variant-visit2:0007 */}
3,4) Returns `value`.

{/* source:cpp-utility-variant-visit2:0008 */}
5,6) Returns `std::move(value)`.

### Parameters

  <Parameter name="v">a [Callable](/docs/cpp/library/named_req/Callable) that accepts every possible alternative from every variant in `Variants`</Parameter>
  <Parameter name="values">list of variants to pass to the visitor</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-variant-visit2:0010 */}
1. 1) The result of the [`INVOKE`](/docs/cpp/library/utility/functional) operation. The return type is the type obtained from applying [decltype](/docs/cpp/language/declarations/decltype) to the result.

{/* source:cpp-utility-variant-visit2:0011 */}
2. 2) Nothing if `R` is (possibly cv-qualified) `void`; otherwise the result of the [`INVOKE<R>`](/docs/cpp/library/utility/functional) operation.

{/* source:cpp-utility-variant-visit2:0012 */}
3. 3-6) A `std::variant` value converted from `value`.

### Exceptions

{/* source:cpp-utility-variant-visit2:0013 */}
Throws [`std::bad_variant_access`](/docs/cpp/library/utility/variant/bad_variant_access) if `as-variant(value_i).valueless_by_exception()` is `true` for any variant `value_i` in `values`.

### Complexity

{/* source:cpp-utility-variant-visit2:0014 */}
When the number of variants is zero or one, the invocation of the callable object is implemented in constant time; i.e., it does not depend on the number of types can be stored in the variant.

{/* source:cpp-utility-variant-visit2:0015 */}
If the number of variants is larger than one, the invocation of the callable object has no complexity requirements.

### Notes

{/* source:cpp-utility-variant-visit2:0016 */}
Let `n` be `(1 * ... * std::variant_size_v<std::remove_reference_t<VariantBases>>)`, implementations usually generate a table equivalent to an (possibly multidimensional) array of `n` function pointers for every specialization of `std::visit`, which is similar to the implementation of [virtual functions](/docs/cpp/language/classes/virtual).

{/* source:cpp-utility-variant-visit2:0017 */}
Implementations may also generate a [switch statement](/docs/cpp/language/statements/switch) with `n` branches for `std::visit` (e.g., the MSVC STL implementation uses a switch statement when `n` is not greater than 256).

{/* source:cpp-utility-variant-visit2:0018 */}
On typical implementations, the time complexity of the invocation of `v` can be considered equal to that of access to an element in an (possibly multidimensional) array or execution of a switch statement.

### Example

{/* source:cpp-utility-variant-visit2:0020 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string>
#include <type_traits>
#include <variant>
#include <vector>
 
// the variant to visit
using value_t = std::variant<int, long, double, std::string>;
 
// helper type for the visitor #4
template<class... Ts>
struct overloaded : Ts... { using Ts::operator()...; };
// explicit deduction guide (not needed as of C++20)
template<class... Ts>
overloaded(Ts...) -> overloaded<Ts...>;
 
int main()
{
    std::vector<value_t> vec = {10, 15l, 1.5, "hello"};
 
    for (auto& v: vec)
    {
        // 1. void visitor, only called for side-effects (here, for I/O)
        std::visit([](auto&& arg){ std::cout << arg; }, v);
 
        // 2. value-returning visitor, demonstrates the idiom of returning another variant
        value_t w = std::visit([](auto&& arg) -> value_t { return arg + arg; }, v);
 
        // 3. type-matching visitor: a lambda that handles each type differently
        std::cout << ". After doubling, variant holds ";
        std::visit([](auto&& arg)
        {
            using T = std::decay_t<decltype(arg)>;
            if constexpr (std::is_same_v<T, int>)
                std::cout << "int with value " << arg << '\n';
            else if constexpr (std::is_same_v<T, long>)
                std::cout << "long with value " << arg << '\n';
            else if constexpr (std::is_same_v<T, double>)
                std::cout << "double with value " << arg << '\n';
            else if constexpr (std::is_same_v<T, std::string>)
                std::cout << "std::string with value " << std::quoted(arg) << '\n';
            else
                static_assert(false, "non-exhaustive visitor!");
        }, w);
    }
 
    for (auto& v: vec)
    {
        // 4. another type-matching visitor: a class with 3 overloaded operator()'s
        // Note: The `(auto arg)` template operator() will bind to `int` and `long`
        //       in this case, but in its absence the `(double arg)` operator()
        //       *will also* bind to `int` and `long` because both are implicitly
        //       convertible to double. When using this form, care has to be taken
        //       that implicit conversions are handled correctly.
        std::visit(overloaded{
            [](auto arg) { std::cout << arg << ' '; },
            [](double arg) { std::cout << std::fixed << arg << ' '; },
            [](const std::string& arg) { std::cout << std::quoted(arg) << ' '; }
        }, v);
    }
}
```

Output:

```text
10. After doubling, variant holds int with value 20
15. After doubling, variant holds long with value 30
1.5. After doubling, variant holds double with value 3
hello. After doubling, variant holds std::string with value "hellohello"
10 15 1.500000 "hello"
```
