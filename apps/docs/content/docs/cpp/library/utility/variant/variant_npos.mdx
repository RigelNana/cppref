{/* source:cpp-utility-variant-variant-npos:0001 */}
This is a special value equal to the largest value representable by the type `std::size_t`, used as the return value of [`index()`](/docs/cpp/library/utility/variant) when [`valueless_by_exception()`](/docs/cpp/library/utility/variant/valueless_by_exception) is `true`.

{/* source:cpp-utility-variant-variant-npos:0002 */}
```cpp
#include <iostream>
#include <stdexcept>
#include <string>
#include <variant>
 
struct Demon
{
    Demon(int) {}
    Demon(const Demon&) { throw std::domain_error("copy ctor"); }
    Demon& operator= (const Demon&) = default;
};
 
int main()
{
    std::variant<int, Demon> var{42};
    std::cout
        << std::boolalpha
        << "index == npos: " << (var.index() == std::variant_npos) << '\n';
 
    try { var = Demon{666}; } catch (const std::domain_error& ex)
    {
        std::cout
            << "Exception: " << ex.what() << '\n'
            << "index == npos: " << (var.index() == std::variant_npos) << '\n'
            << "valueless: " << var.valueless_by_exception() << '\n';
    }
}
```

Possible output:

```text
index == npos: false
Exception: copy ctor
index == npos: true
valueless: true
```
