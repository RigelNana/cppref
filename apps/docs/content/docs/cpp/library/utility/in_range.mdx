{/* source:cpp-utility-in-range:0001 */}
Returns `true` if the value of `t` is in the range of values that can be represented in `R`, that is, if `t` can be converted to `R` in a value-preserving manner.

{/* source:cpp-utility-in-range:0002 */}
It is a compile-time error if either `T` or `U` is a non-[integer](/docs/cpp/language/basic_concepts/types#Integer_types) type, a character type, or `bool`.

### Parameters

{/* source:cpp-utility-in-range:0003 */}
<ParameterList>
  <Parameter name="t">value to test</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-in-range:0004 */}
`true` if the value of `t` is representable in `R`, `false` otherwise.

### Possible implementation

{/* source:cpp-utility-in-range:0005 */}
```cpp
template<class R, class T>
constexpr bool in_range(T t) noexcept
{
    return std::cmp_greater_equal(t, std::numeric_limits<R>::min()) &&
        std::cmp_less_equal(t, std::numeric_limits<R>::max());
}
```

### Notes

{/* source:cpp-utility-in-range:0006 */}
This function cannot be used with [enums](/docs/cpp/language/declarations/enum) (including [`std::byte`](/docs/cpp/library/utility/types/byte)), `char`, `char8_t`, `char16_t`, `char32_t`, `wchar_t` and `bool`.

### Example

{/* source:cpp-utility-in-range:0008 */}
```cpp
#include <iostream>
#include <utility>
 
int main()
{
    std::cout << std::boolalpha;
 
    std::cout << std::in_range<std::size_t>(-1) << '\n';
    std::cout << std::in_range<std::size_t>(42) << '\n';
}
```

Output:

```text
false
true
```
