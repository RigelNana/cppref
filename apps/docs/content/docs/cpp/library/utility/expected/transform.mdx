{/* source:cpp-utility-expected-transform:0001 */}
If `*this` represents an expected value, invokes `f` and returns a `std::expected` object that contains an expected value, which is initialized with its result (or value-initialized if the result type is `void`). Otherwise, returns a `std::expected` object that contains an unexpected value, which is initialized with the unexpected value of `*this`.

{/* source:cpp-utility-expected-transform:0002 */}
1-4) `f` is invoked with the expected value [`val`](/docs/cpp/library/utility/expected#Data_members) of `*this` as the argument.

{/* source:cpp-utility-expected-transform:0003 */}
5-8) `f` is invoked without any argument.

{/* source:cpp-utility-expected-transform:0004 */}
Given type `U` as:

{/* source:cpp-utility-expected-transform:0005 */}
1,2) `std::remove_cv_t<std::invoke_result_t<F, decltype((`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`))>>`

{/* source:cpp-utility-expected-transform:0006 */}
3,4) `std::remove_cv_t<std::invoke_result_t<F, decltype(std::move(`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`))>>`

{/* source:cpp-utility-expected-transform:0007 */}
5-8) `std::remove_cv_t<std::invoke_result_t<F>>`

{/* source:cpp-utility-expected-transform:0008 */}
If any of the following conditions is satisfied, the program is ill-formed:

{/* source:cpp-utility-expected-transform:0009 */}
- `U` is not a valid value type for `std::expected`.
- `std::is_void_v<U>` is `false`, and the following corresponding declaration is ill-formed:

{/* source:cpp-utility-expected-transform:0010 */}
1,2) `U u(std::invoke(std::forward<F>(f),`[`val`](/docs/cpp/library/utility/expected#Data_members)`));`

{/* source:cpp-utility-expected-transform:0011 */}
3,4) `U u(std::invoke(std::forward<F>(f), std::move(`[`val`](/docs/cpp/library/utility/expected#Data_members)`)));`

{/* source:cpp-utility-expected-transform:0012 */}
5-8) `U u(std::invoke(std::forward<F>(f)));`

{/* source:cpp-utility-expected-transform:0013 */}
1,2) These overloads participate in overload resolution only if `std::is_constructible_v<E, decltype(error())>` is `true`.

{/* source:cpp-utility-expected-transform:0014 */}
3,4) These overloads participate in overload resolution only if `std::is_constructible_v<E, decltype(std::move(error()))>` is `true`.

{/* source:cpp-utility-expected-transform:0015 */}
5,6) These overloads participate in overload resolution only if `std::is_constructible_v<E, decltype(error())>` is `true`.

{/* source:cpp-utility-expected-transform:0016 */}
7,8) These overloads participate in overload resolution only if `std::is_constructible_v<E, decltype(std::move(error()))>` is `true`.

### Return value

{/* source:cpp-utility-expected-transform:0018 */}
Given expression `expr` as:

{/* source:cpp-utility-expected-transform:0019 */}
1,2) `std::invoke(std::forward<F>(f),`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`

{/* source:cpp-utility-expected-transform:0020 */}
3,4) `std::invoke(std::forward<F>(f),std::move(`[`val`](/docs/cpp/library/utility/expected#Data_members)`))`

{/* source:cpp-utility-expected-transform:0021 */}
5-8) `std::invoke(std::forward<F>(f))`

{/* source:cpp-utility-expected-transform:0022 */}
The return values are defined as follows:

{/* source:cpp-utility-expected-transform:0023 */}
| Overload | Value of [`has_value()`](/docs/cpp/library/utility/expected/operator_bool) |  |
| --- | --- | --- |
|  | `true` | `false` |
| ([`1,2`](/docs/cpp/library/utility/expected/transform#Version_1)) | If `std::is_void_v<U>` is `false`, returns `std::expected<U, E>` `(std::in_place, expr)`. Otherwise, returns `std::expected<U, E>()` (but still evaluates `expr`). | `std::expected<U, E>(std::unexpect, error())` |
| ([`3,4`](/docs/cpp/library/utility/expected/transform#Version_3)) |  | `std::expected<U, E>` `(std::unexpect, std::move(error()))` |
| ([`5,6`](/docs/cpp/library/utility/expected/transform#Version_5)) |  | `std::expected<U, E>(std::unexpect, error())` |
| ([`7,8`](/docs/cpp/library/utility/expected/transform#Version_7)) |  | `std::expected<U, E>` `(std::unexpect, std::move(error()))` |
