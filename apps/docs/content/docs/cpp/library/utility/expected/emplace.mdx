{/* source:cpp-utility-expected-emplace:0001 */}
Constructs an expected value in-place. After the call, [`has_value()`](/docs/cpp/library/utility/expected/operator_bool) returns `true`.

{/* source:cpp-utility-expected-emplace:0002 */}
1. 1) Destroys the contained value, then [direct-initializes](/docs/cpp/language/initialization/direct_initialization) the expected value contained in `*this` with `std::forward<Args>(args)...`.

{/* source:cpp-utility-expected-emplace:0003 */}
This overload participates in overload resolution only if `std::is_nothrow_constructible_v<T, Args...>` is `true`.

{/* source:cpp-utility-expected-emplace:0004 */}
2. 2) Destroys the contained value, then [direct-initializes](/docs/cpp/language/initialization/direct_initialization) the expected value contained in `*this` with `il` and `std::forward<Args>(args)...`.

{/* source:cpp-utility-expected-emplace:0005 */}
This overload participates in overload resolution only if `std::is_nothrow_constructible_v<T, std::initializer_list<U>&, Args...>` is `true`.

{/* source:cpp-utility-expected-emplace:0006 */}
3. 3) If `*this` contains an unexpected value, destroys that value.

{/* source:cpp-utility-expected-emplace:0010 */}
If the construction of `T` is potentially-throwing, [`operator=`](/docs/cpp/library/utility/expected/operator_assignment) can be used instead.
