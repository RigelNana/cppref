{/* source:cpp-utility-expected-operator-star:0001 */}
Accesses the expected value contained in `*this`.

{/* source:cpp-utility-expected-operator-star:0002 */}
1,2) Returns a pointer to the expected value.

{/* source:cpp-utility-expected-operator-star:0003 */}
3-6) Returns a reference to the expected value.

{/* source:cpp-utility-expected-operator-star:0004 */}
7) Returns nothing.

{/* source:cpp-utility-expected-operator-star:0005 */}
If [`has_value()`](/docs/cpp/library/utility/expected/operator_bool) is `false`, the behavior is undefined.

### Return value

{/* source:cpp-utility-expected-operator-star:0006 */}
1,2) `std::addressof(`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`

{/* source:cpp-utility-expected-operator-star:0007 */}
3,4) [`val`](/docs/cpp/library/utility/expected#Data_members)

{/* source:cpp-utility-expected-operator-star:0008 */}
5,6) [`std::move`](/docs/cpp/library/utility/move)`(`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`

### Notes

{/* source:cpp-utility-expected-operator-star:0009 */}
These operators do not check whether the optional represents an expected value! You can do so manually by using [`has_value()`](/docs/cpp/library/utility/expected/operator_bool) or simply [`operator bool()`](/docs/cpp/library/utility/expected/operator_bool). Alternatively, if checked access is needed, [`value()`](/docs/cpp/library/utility/expected/value) or [`value_or()`](/docs/cpp/library/utility/expected/value_or) may be used.

### Example

{/* source:cpp-utility-expected-operator-star:0010 */}
```cpp
#include <cassert>
#include <expected>
#include <iomanip>
#include <iostream>
#include <string>
 
int main()
{
    using namespace std::string_literals;
 
    std::expected<int, std::string> ex1 = 6;
    assert(*ex1 == 6);
 
    *ex1 = 9;
    assert(*ex1 == 9);
 
    // *ex1 = "error"s; // error, ex1 contains an expected value of type int
    ex1 = std::unexpected("error"s);
    // *ex1 = 13; // UB, ex1 contains an unexpected value
    assert(ex1.value_or(42) == 42);
 
    std::expected<std::string, bool> ex2 = "Moon"s;
    std::cout << "ex2: " << std::quoted(*ex2) << ", size: " << ex2->size() << '\n';
 
    // You can "take" the expected value by calling operator* on an std::expected rvalue
 
    auto taken = *std::move(ex2);
    std::cout << "taken " << std::quoted(taken) << "\n"
                 "ex2: " << std::quoted(*ex2) << ", size: " << ex2->size() << '\n';
}
```

Possible output:

```text
ex2: "Moon", size: 4
taken "Moon"
ex2: "", size: 0
```
