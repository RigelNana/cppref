{/* source:cpp-utility-expected-value:0001 */}
If `*this` contains an expected value, returns a reference to the contained value. Returns nothing for `void` partial specialization.

{/* source:cpp-utility-expected-value:0002 */}
Otherwise, throws an exception of type `std::bad_expected_access<std::decay_t<E>>` that contains a copy of [`error()`](/docs/cpp/library/utility/expected/error).

{/* source:cpp-utility-expected-value:0003 */}
1,2) If `std::is_copy_constructible_v<E>` is `false`, the program is ill-formed.

{/* source:cpp-utility-expected-value:0004 */}
3,4) If `std::is_copy_constructible_v<E>` or `std::is_constructible_v<E, decltype(std::move(error()))>` is `false`, the program is ill-formed.

{/* source:cpp-utility-expected-value:0005 */}
5) If `std::is_copy_constructible_v<E>` is `false`, the program is ill-formed.

{/* source:cpp-utility-expected-value:0006 */}
6) If `std::is_move_constructible_v<E>` is `false`, the program is ill-formed.

### Return value

{/* source:cpp-utility-expected-value:0007 */}
1,2) [`val`](/docs/cpp/library/utility/expected#Data_members)

{/* source:cpp-utility-expected-value:0008 */}
3,4) `std::move(`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`

### Exceptions

{/* source:cpp-utility-expected-value:0009 */}
1,2,5) Throws `std::bad_expected_access(std::as_const(error()))` if `*this` contains an unexpected value.

{/* source:cpp-utility-expected-value:0010 */}
3,4,6) Throws `std::bad_expected_access(std::move(error()))` if `*this` contains an unexpected value.
