{/* source:cpp-utility-expected-transform-error:0001 */}
If `*this` contains an unexpected value, invokes `f` with the unexpected value of `*this` as the argument and returns a `std::expected` object that contains an unexpected value, which is initialized with the result of `f`. Otherwise, returns a `std::expected` object that represents an expected value.

{/* source:cpp-utility-expected-transform-error:0002 */}
1-4) The expected value is initialized with the expected value [`val`](/docs/cpp/library/utility/expected#Data_members) of `*this`.

{/* source:cpp-utility-expected-transform-error:0003 */}
Given type `G` as:

{/* source:cpp-utility-expected-transform-error:0004 */}
1,2) `std::remove_cv_t<std::invoke_result_t<F, decltype(error())>>`

{/* source:cpp-utility-expected-transform-error:0005 */}
3,4) `std::remove_cv_t<std::invoke_result_t<F, decltype(std::move(error()))>>`

{/* source:cpp-utility-expected-transform-error:0006 */}
5,6) `std::remove_cv_t<std::invoke_result_t<F, decltype(error())>>`

{/* source:cpp-utility-expected-transform-error:0007 */}
7,8) `std::remove_cv_t<std::invoke_result_t<F, decltype(std::move(error()))>>`

{/* source:cpp-utility-expected-transform-error:0008 */}
If any of the following conditions is satisfied, the program is ill-formed:

{/* source:cpp-utility-expected-transform-error:0009 */}
- `G` is not a valid template argument for [`std::unexpected`](/docs/cpp/library/utility/expected/unexpected).
- The following corresponding declaration is ill-formed:

{/* source:cpp-utility-expected-transform-error:0010 */}
1,2) `G g(std::invoke(std::forward<F>(f), error()));`

{/* source:cpp-utility-expected-transform-error:0011 */}
3,4) `G g(std::invoke(std::forward<F>(f), std::move(error()));`

{/* source:cpp-utility-expected-transform-error:0012 */}
5,6) `G g(std::invoke(std::forward<F>(f), error()));`

{/* source:cpp-utility-expected-transform-error:0013 */}
7,8) `G g(std::invoke(std::forward<F>(f), std::move(error()));`

{/* source:cpp-utility-expected-transform-error:0014 */}
1,2) This overload participates in overload resolution only if `std::is_constructible_v<T, decltype((`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`))>` is `true`.

{/* source:cpp-utility-expected-transform-error:0015 */}
3,4) This overload participates in overload resolution only if `std::is_constructible_v<T, decltype(std::move(`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`))>` is `true`.
