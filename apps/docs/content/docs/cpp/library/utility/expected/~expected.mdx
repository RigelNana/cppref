### Main template destructor

{/* source:cpp-utility-expected-expected:0001 */}
Destroys the contained value:

{/* source:cpp-utility-expected-expected:0002 */}
- If [`has_value()`](/docs/cpp/library/utility/expected/operator_bool) is `true`, destroys the expected value.
- Otherwise, destroys the unexpected value.

{/* source:cpp-utility-expected-expected:0003 */}
This destructor is trivial if `std::is_trivially_destructible_v<T>` and `std::is_trivially_destructible_v<E>` are both `true`.

### void partial specialization destructor

{/* source:cpp-utility-expected-expected:0004 */}
If [`has_value()`](/docs/cpp/library/utility/expected/operator_bool) is `false`, destroys the unexpected value.

{/* source:cpp-utility-expected-expected:0005 */}
This destructor is trivial if `std::is_trivially_destructible_v<E>` is `true`.
