{/* source:cpp-utility-expected-and-then:0001 */}
If `*this` represents an expected value, invokes `f` and returns its result. Otherwise, returns a `std::expected` object that contains an unexpected value, which is initialized with the unexpected value of `*this`.

{/* source:cpp-utility-expected-and-then:0002 */}
1. 1-4) `f` is invoked with the expected value [`val`](/docs/cpp/library/utility/expected#Data_members) as the argument.

{/* source:cpp-utility-expected-and-then:0003 */}
2. 5-8) `f` is invoked without any argument.

{/* source:cpp-utility-expected-and-then:0004 */}
Given type `U` as:

{/* source:cpp-utility-expected-and-then:0005 */}
1. 1,2) `std::remove_cvref_t<std::invoke_result_t<F, decltype((val))>>`

{/* source:cpp-utility-expected-and-then:0006 */}
2. 3,4) `std::remove_cvref_t<std::invoke_result_t<F, decltype(std::move(val))>>`

{/* source:cpp-utility-expected-and-then:0007 */}
3. 5-8) `std::remove_cvref_t<std::invoke_result_t<F>>`

{/* source:cpp-utility-expected-and-then:0008 */}
If `U` is not a specialization of `std::expected`, or `std::is_same_v<U::error_type, E>` is `false`, the program is ill-formed.

{/* source:cpp-utility-expected-and-then:0009 */}
1. 1,2) These overloads participate in overload resolution only if `std::is_constructible_v<E, decltype(error())>` is `true`.

{/* source:cpp-utility-expected-and-then:0010 */}
2. 3,4) These overloads participate in overload resolution only if `std::is_constructible_v<E, decltype(std::move(error()))>` is `true`.

{/* source:cpp-utility-expected-and-then:0011 */}
3. 5,6) These overloads participate in overload resolution only if `std::is_constructible_v<E, decltype(error())>` is `true`.

{/* source:cpp-utility-expected-and-then:0012 */}
4. 7,8) These overloads participate in overload resolution only if `std::is_constructible_v<E, decltype(std::move(error()))>` is `true`.
