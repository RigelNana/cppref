Checks whether `*this` represents an expected value.

### Return value

{/* source:cpp-utility-expected-operator-bool:0002 */}
[`has_val`](/docs/cpp/library/utility/expected#Data_members)

### Notes

{/* source:cpp-utility-expected-operator-bool:0003 */}
A `std::expected` object is never valueless. If `has_value()` returns `true`, [`operator*()`](/docs/cpp/library/utility/expected/operator_star_) can be used to access the expected value; otherwise, [`error()`](/docs/cpp/library/utility/expected/error) can be used to access the unexpected value.
