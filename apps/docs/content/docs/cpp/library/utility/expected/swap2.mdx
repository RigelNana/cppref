Overloads the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for `std::expected`. Exchanges the state of `lhs` with that of `rhs`. Effectively calls `lhs.swap(rhs)`.

{/* source:cpp-utility-expected-swap2:0002 */}
This overload participates in overload resolution only if `lhs.swap(rhs)` is valid.

{/* source:cpp-utility-expected-swap2:0003 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::expected<T, E>` is an associated class of the arguments.

### Parameters

{/* source:cpp-utility-expected-swap2:0004 */}
<ParameterList>
  <Parameter name="lhs, rhs">expected objects whose states to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-expected-swap2:0005 */}
(none)

### Exceptions

{/* source:cpp-utility-expected-swap2:0006 */}
noexcept specification: [`noexcept(noexcept(lhs.swap(rhs)))`](/docs/cpp/language/exceptions/noexcept_spec)

### Example

{/* source:cpp-utility-expected-swap2:0007 */}
```cpp
#include <expected>
#include <iostream>
#include <string>
 
using Ex = std::expected<std::string, int>;
 
void show(const Ex& ex1, const Ex& ex2)
{
    for (int i{}; i < 2; ++i)
    {
        std::cout << (i ? "ex2" : "ex1");
        if (const Ex& ex = (i ? ex2 : ex1); ex.has_value())
            std::cout << ".has_value() = " << *ex << '\n';
        else
            std::cout << ".error() = " << ex.error() << '\n';
    }
}
 
int main()
{
    Ex ex1("\N{DOG FACE}");
    Ex ex2{"\N{BONE}"};
    show(ex1, ex2);
    swap(ex1, ex2);
    std::cout << "swap(ex1, ex2);\n";
    show(ex1, ex2);
    std::cout << '\n';
 
    ex2 = std::unexpected(13);
    show(ex1, ex2);
    swap(ex1, ex2);
    std::cout << "swap(ex1, ex2);\n";
    show(ex1, ex2);
    std::cout << '\n';
 
    ex2 = std::unexpected(19937);
    show(ex1, ex2);
    swap(ex1, ex2);
    std::cout << "swap(ex1, ex2);\n";
    show(ex1, ex2);
    std::cout << '\n';
}
```
