{/* source:cpp-utility-expected-error-or:0001 */}
Returns the unexpected value if it exists, otherwise returns `default_value`.

{/* source:cpp-utility-expected-error-or:0002 */}
1) If `std::is_copy_constructible_v<E>` or `std::is_convertible_v<G, E>` is `false`, the program is ill-formed.

{/* source:cpp-utility-expected-error-or:0003 */}
2) If `std::is_move_constructible_v<E>` or `std::is_convertible_v<G, E>` is `false`, the program is ill-formed.

### Parameters

{/* source:cpp-utility-expected-error-or:0004 */}
<ParameterList>
  <Parameter name="default_value">the value to use in case `*this` does not contain an unexpected value</Parameter>
</ParameterList>

Type requirements

### Return value

{/* source:cpp-utility-expected-error-or:0005 */}
1) `has_value() ? std::forward<G>(default_value) : error()`

{/* source:cpp-utility-expected-error-or:0006 */}
2) `has_value() ? std::forward<G>(default_value) : std::move(error())`
