{/* source:cpp-utility-expected-or-else:0001 */}
If `*this` contains an unexpected value, invokes `f` with the unexpected value of `*this` as the argument and returns its result. Otherwise, returns a `std::expected` object that represents an expected value.

{/* source:cpp-utility-expected-or-else:0002 */}
1-4) The expected value is initialized with the expected value [`val`](/docs/cpp/library/utility/expected#Data_members) of `*this`.

{/* source:cpp-utility-expected-or-else:0003 */}
Given type `G` as:

{/* source:cpp-utility-expected-or-else:0004 */}
1,2) `std::remove_cvref_t<std::invoke_result_t<F, decltype(error())>>`

{/* source:cpp-utility-expected-or-else:0005 */}
3,4) `std::remove_cvref_t<std::invoke_result_t<F, decltype(std::move(error()))>>`

{/* source:cpp-utility-expected-or-else:0006 */}
5,6) `std::remove_cvref_t<std::invoke_result_t<F, decltype(error())>>`

{/* source:cpp-utility-expected-or-else:0007 */}
7,8) `std::remove_cvref_t<std::invoke_result_t<F, decltype(std::move(error()))>>`

{/* source:cpp-utility-expected-or-else:0008 */}
If `G` is not a specialization of `std::expected`, or `std::is_same_v<G::value_type, T>` is `false`, the program is ill-formed.

{/* source:cpp-utility-expected-or-else:0009 */}
1,2) These overloads participate in overload resolution only if `std::is_constructible_v<T, decltype((`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`))>` is `true`.

{/* source:cpp-utility-expected-or-else:0010 */}
3,4) These overloads participate in overload resolution only if `std::is_constructible_v<T, decltype(std::move(`[`val`](/docs/cpp/library/utility/expected#Data_members)`)`))>` is `true`.
