Accesses the unexpected value contained in `*this`.

{/* source:cpp-utility-expected-error:0002 */}
If [`has_value()`](/docs/cpp/library/utility/expected/operator_bool) is `true`, the behavior is undefined.

### Return value

{/* source:cpp-utility-expected-error:0003 */}
1. 1,2) [`unex`](/docs/cpp/library/utility/expected#Data_members)

{/* source:cpp-utility-expected-error:0004 */}
2. 3,4) `std::move(unex)`
