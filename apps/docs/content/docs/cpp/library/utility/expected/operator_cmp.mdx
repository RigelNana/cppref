{/* source:cpp-utility-expected-operator-cmp:0001 */}
Performs comparison operations on `std::expected` objects.

{/* source:cpp-utility-expected-operator-cmp:0002 */}
1) Compares two `std::expected` objects. The objects compare equal if and only if both `lhs` and `rhs` contain expected values that are equal, or both contain unexpected values that are equal.

<Revision until="C++26">
If any of the following expressions is ill-formed, or its result is not convertible to `bool`, the program is ill-formed:
</Revision>

<Revision since="C++26">
This overload participates in overload resolution only if all following expressions is well-formed, and their results are convertible to `bool`:
</Revision>

- `*lhs == *rhs`
- `lhs.error() == rhs.error()`

{/* source:cpp-utility-expected-operator-cmp:0003 */}
2) Compares `std::expected` object with an [`std::unexpected`](/docs/cpp/library/error/unexpected) object. The objects compare equal if and only if `lhs` contains an unexpected value that is equal to `unex.error()`.

<Revision until="C++26">
If the expression `lhs.error() == unex.error()` is ill-formed, or its result is not convertible to `bool`, the program is ill-formed.
</Revision>

<Revision since="C++26">
This overload participates in overload resolution only if the expression `lhs.error() == unex.error()` is well-formed, and its result is convertible to `bool`.
</Revision>

{/* source:cpp-utility-expected-operator-cmp:0004 */}
3) Compares `std::expected` object with an expected value. The objects compare equal if and only if `lhs` contains an expected value that is equal to `val`.

<Revision until="C++26">
If the expression `*lhs == val` is ill-formed, or its result is not convertible to `bool`, the program is ill-formed.
</Revision>

<Revision since="C++26">
This overload participates in overload resolution only if all following conditions are satisfied:

- `T2` is not a specialization of `std::expected`.
- The expression `*lhs == val` is well-formed, and its result is convertible to `bool`.
</Revision>

{/* source:cpp-utility-expected-operator-cmp:0005 */}
4) Compares two `std::expected` objects. The objects compare equal if and only if `lhs` and `rhs` both represent expected values, or both contain unexpected values that are equal.

<Revision until="C++26">
If the expression `lhs.error() == rhs.error()` is ill-formed, or its result is not convertible to `bool`, the program is ill-formed.
</Revision>

<Revision since="C++26">
This overload participates in overload resolution only if the expression `lhs.error() == rhs.error()` is well-formed, and its result is convertible to `bool`.
</Revision>

{/* source:cpp-utility-expected-operator-cmp:0006 */}
5) Compares `std::expected` object with an [`std::unexpected`](/docs/cpp/library/error/unexpected) object. The objects compare equal if and only if `lhs` contains an unexpected value that is equal to `unex.error()`.

<Revision until="C++26">
If the expression `lhs.error() == unex.error()` is ill-formed, or its result is not convertible to `bool`, the program is ill-formed.
</Revision>

<Revision since="C++26">
This overload participates in overload resolution only if the expression `lhs.error() == unex.error()` is well-formed, and its result is convertible to `bool`.
</Revision>

{/* source:cpp-utility-expected-operator-cmp:0007 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::expected<T, E>` is an associated class of the arguments.

{/* source:cpp-utility-expected-operator-cmp:0008 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Parameters

### Return value

{/* source:cpp-utility-expected-operator-cmp:0010 */}
1) `lhs.has_value() != rhs.has_value() ? false :`<br />`  (lhs.has_value() ? *lhs == *rhs : lhs.error() == rhs.error())`

{/* source:cpp-utility-expected-operator-cmp:0011 */}
2) `!lhs.has_value() && static_cast<bool>(lhs.error() == unex.error())`

{/* source:cpp-utility-expected-operator-cmp:0012 */}
3) `lhs.has_value() && static_cast<bool>(*lhs == val)`

{/* source:cpp-utility-expected-operator-cmp:0013 */}
4) `lhs.has_value() != rhs.has_value() ? false :`<br />`  lhs.has_value() || static_cast<bool>(lhs.error() == rhs.error())`

{/* source:cpp-utility-expected-operator-cmp:0014 */}
5) `!lhs.has_value() && static_cast<bool>(lhs.error() == unex.error())`

### Exceptions

{/* source:cpp-utility-expected-operator-cmp:0015 */}
Throws when and what the comparison throws.

### Example

{/* source:cpp-utility-expected-operator-cmp:0017 */}
```cpp
#include <expected>
#include <iostream>
#include <string_view>
 
using namespace std::string_view_literals;
 
int main()
{
    auto x1{"\N{GREEN HEART}"sv};
    auto x2{"\N{CROSS MARK}"sv};
    std::expected<std::string_view, int> e1{x1}, e2{x1}, e3{x2};
    std::unexpected u1{13};
 
    std::cout << "Overload (1):\n"
              << e1.value() << (e1 == e2 ? " == " : " != ") << *e2 << '\n'
              << e1.value() << (e1 != e3 ? " != " : " == ") << *e3 << "\n\n";
 
    std::cout << "Overload (2):\n"
              << e1.value() << (e1 == u1 ? " == " : " != ") << u1.error() << '\n';
    e1 = std::unexpected{13};
    std::cout << e1.error() << (e1 == u1 ? " == " : " != ") << u1.error() << '\n';
    e1 = std::unexpected{31};
    std::cout << e1.error() << (e1 != u1 ? " != " : " == ") << u1.error() << '\n';
 
    std::cout << "Overload (3):\n"
              << *e1 << (e1 == x1 ? " == " : " != ") << x1 << '\n'
              << *e1 << (e1 != x2 ? " != " : " == ") << x2 << "\n\n";
}
```

Output:

```text
Overload (1):
💚 == 💚
💚 != ❌
 
Overload (2):
💚 != 13
13 == 13
31 != 13
 
Overload (3):
💚 == 💚
💚 != ❌
```
