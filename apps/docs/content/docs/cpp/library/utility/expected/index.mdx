{/* source:cpp-utility-expected:0001 */}
The class template `std::expected` provides a way to represent either of two values: an expected value of type `T`, or an unexpected value of type `E`. `std::expected` is never valueless.

{/* source:cpp-utility-expected:0002 */}
1. 1) The main template. Contains the expected or unexpected value within its own storage. No dynamic memory allocation takes place.

{/* source:cpp-utility-expected:0003 */}
2. 2) The `void` partial specialization. Represents an expected `void` value or contains the unexpected value within its own storage. No dynamic memory allocation takes place.

{/* source:cpp-utility-expected:0004 */}
A program is ill-formed if it instantiates an `expected` with a reference type, a function type, or a specialization of [`std::unexpected`](/docs/cpp/library/utility/expected/unexpected). In addition, `T` must not be [`std::in_place_t`](/docs/cpp/library/utility/in_place) or [`std::unexpect_t`](/docs/cpp/library/utility/expected/unexpect_t).

### Template parameters

{/* source:cpp-utility-expected:0005 */}
<ParameterList>
  <Parameter name="T">the type of the expected value. The type must either be (possibly cv-qualified) `void`, or meet the [*Destructible*](/docs/cpp/library/named_req/Destructible) requirements (in particular, array and reference types are not allowed).</Parameter>
  <Parameter name="E">the type of the unexpected value. The type must meet the [*Destructible*](/docs/cpp/library/named_req/Destructible) requirements, and must be a valid template argument for [`std::unexpected`](/docs/cpp/library/utility/expected/unexpected) (in particular, arrays, non-object types, and cv-qualified types are not allowed).</Parameter>
</ParameterList>

### Example

{/* source:cpp-utility-expected:0014 */}
```cpp
#include <cmath>
#include <expected>
#include <iomanip>
#include <iostream>
#include <string_view>
 
enum class parse_error
{
    invalid_input,
    overflow
};
 
auto parse_number(std::string_view& str) -> std::expected<double, parse_error>
{
    const char* begin = str.data();
    char* end;
    double retval = std::strtod(begin, &end);
 
    if (begin == end)
        return std::unexpected(parse_error::invalid_input);
    else if (std::isinf(retval))
        return std::unexpected(parse_error::overflow);
 
    str.remove_prefix(end - begin);
    return retval;
}
 
int main()
{
    auto process = [](std::string_view str)
    {
        std::cout << "str: " << std::quoted(str) << ", ";
        if (const auto num = parse_number(str); num.has_value())
            std::cout << "value: " << *num << '\n';
            // If num did not have a value, dereferencing num
            // would cause an undefined behavior, and
            // num.value() would throw std::bad_expected_access.
            // num.value_or(123) uses specified default value 123.
        else if (num.error() == parse_error::invalid_input)
            std::cout << "error: invalid input\n";
        else if (num.error() == parse_error::overflow)
            std::cout << "error: overflow\n";
        else
            std::cout << "unexpected!\n"; // or invoke std::unreachable();
    };
 
    for (auto src : {"42", "42abc", "meow", "inf"})
        process(src);
}
```

Output:

```text
str: "42", value: 42
str: "42abc", value: 42
str: "meow", error: invalid input
str: "inf", error: overflow
```
