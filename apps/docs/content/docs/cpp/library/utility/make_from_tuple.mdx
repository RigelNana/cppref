{/* source:cpp-utility-make-from-tuple:0001 */}
Construct an object of type `T`, using the elements of the tuple `t` as the arguments to the constructor.

{/* source:cpp-utility-make-from-tuple:0002 */}
Given the exposition-only function `/*make-from-tuple-impl*/` defined as follows:

```cpp
template<class T, tuple-like Tuple, std::size_t... I> // no constraint on Tuple before C++23
constexpr T /*make-from-tuple-impl*/(Tuple&& t, std::index_sequence<I...>)
{
    return T(std::get<I>(std::forward<Tuple>(t))...);
}
```

{/* source:cpp-utility-make-from-tuple:0003 */}
The effect is equivalent to:

```cpp
return /*make-from-tuple-impl*/<T>(
    std::forward<Tuple>(t),
    std::make_index_sequence<std::tuple_size_v<std::remove_reference_t<Tuple>>>{}
);
```

{/* source:cpp-utility-make-from-tuple:0004 */}
If

{/* source:cpp-utility-make-from-tuple:0005 */}
<Revision since="C++23">
- `std::tuple_size_v<std::remove_reference_t<Tuple>>` is `1` and `std::reference_constructs_from_temporary_v<`<br />`    T, decltype(std::get<0>(std::declval<Tuple>()))>` is `true`, or
</Revision>

{/* source:cpp-utility-make-from-tuple:0006 */}
- `std::is_constructible_v<T, decltype(std::get<I>(std::declval<Tuple>()))...>` is `false`,

{/* source:cpp-utility-make-from-tuple:0007 */}
the program is ill-formed.

### Parameters

{/* source:cpp-utility-make-from-tuple:0008 */}
<ParameterList>
  <Parameter name="t">tuple whose elements to be used as arguments to the constructor of `T`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-make-from-tuple:0009 */}
The constructed `T` object or reference.

### Notes

{/* source:cpp-utility-make-from-tuple:0010 */}
<Revision until="C++23">
`Tuple` need not be [`std::tuple`](/docs/cpp/library/utility/tuple), and instead may be anything that supports [`std::get`](/docs/cpp/library/utility/tuple/get) and [`std::tuple_size`](/docs/cpp/library/utility/tuple_size); in particular, [`std::array`](/docs/cpp/library/container/array) and [`std::pair`](/docs/cpp/library/utility/pair) may be used.
</Revision>

<Revision since="C++23">
`Tuple` is constrained to be tuple-like, i.e. each type therein is required to be a specialization of [`std::tuple`](/docs/cpp/library/utility/tuple) or another type (such as [`std::array`](/docs/cpp/library/container/array) and [`std::pair`](/docs/cpp/library/utility/pair)) that models [`tuple-like`](/docs/cpp/library/utility/tuple/tuple-like).
</Revision>

{/* source:cpp-utility-make-from-tuple:0011 */}
Due to [guaranteed copy elision](/docs/cpp/language/initialization/copy_elision), `T` need not be movable.

### Example

{/* source:cpp-utility-make-from-tuple:0013 */}
```cpp
#include <iostream>
#include <tuple>
 
struct Foo
{
    Foo(int first, float second, int third)
    {
        std::cout << first << ", " << second << ", " << third << '\n';
    }
};
 
int main()
{
    auto tuple = std::make_tuple(42, 3.14f, 0);
    std::make_from_tuple<Foo>(std::move(tuple));
}
```

Output:

```text
42, 3.14, 0
```
