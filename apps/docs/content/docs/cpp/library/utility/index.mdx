{/* source:cpp-utility:0000 */}
C++ includes a variety of utility libraries that provide functionality ranging from [bit-counting](/docs/cpp/library/utility/bitset) to [partial function application](/docs/cpp/library/utility/functional/bind). These libraries can be broadly divided into two groups:

{/* source:cpp-utility:0001 */}
- language support libraries, and general-purpose libraries.

## Language support

{/* source:cpp-utility:0002 */}
Language support libraries provide classes and functions that interact closely with language features and support common language idioms.

### Type support

{/* source:cpp-utility:0003 */}
Basic types (e.g. [`std::size_t`](/docs/cpp/library/utility/types/size_t), [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t)), RTTI (e.g. [`std::type_info`](/docs/cpp/library/utility/types/type_info))

### Metaprogramming (since C++11)

{/* source:cpp-utility:0004 */}
Type traits (e.g. [`std::is_integral`](/docs/cpp/library/meta/is_integral), [`std::rank`](/docs/cpp/library/meta/rank)), compile-time constants (e.g. [`std::integer_sequence`](/docs/cpp/library/meta/integer_sequence), [`std::ratio`](/docs/cpp/library/meta/ratio/ratio))

### Implementation properties (since C++20)

{/* source:cpp-utility:0006 */}
The header [`<version>`](/docs/cpp/library/headers/version) supplies implementation-dependent information about the C++ standard library (such as the version number and release date). It also defines the [library feature-test macros](/docs/cpp/library/utility/feature_test).

### Program utilities

{/* source:cpp-utility:0007 */}
Termination (e.g. [`std::abort`](/docs/cpp/library/utility/program/abort), [`std::atexit`](/docs/cpp/library/utility/program/atexit)), environment (e.g. [`std::system`](/docs/cpp/library/utility/program/system)), signals (e.g. [`std::raise`](/docs/cpp/library/utility/program/raise))

### Dynamic memory management

{/* source:cpp-utility:0008 */}
Smart pointers (e.g. [`std::shared_ptr`](/docs/cpp/library/memory/shared_ptr)), allocators (e.g. [`std::allocator`](/docs/cpp/library/memory/allocator) or [`std::pmr::memory_resource`](/docs/cpp/library/memory/memory_resource)), C-style memory management (e.g. [`std::malloc`](/docs/cpp/library/memory/c/malloc))

### Error handling

{/* source:cpp-utility:0009 */}
Exceptions (e.g. [`std::exception`](/docs/cpp/library/error/exception), [`std::terminate`](/docs/cpp/library/error/terminate)), assertions (e.g. [`assert`](/docs/cpp/library/error/assert))

### Bit manipulation (since C++20)

{/* source:cpp-utility:0023 */}
The header [`<bit>`](/docs/cpp/library/headers/bit) provides several function templates to access, manipulate, and process individual bits and bit sequences. The byte ordering ([endianness](/docs/cpp/library/utility/bit/endian)) of scalar types can be inspected via `std::endian` facility.

### Function objects (since C++11)

{/* source:cpp-utility:0024 */}
Partial function application (e.g. [`std::bind`](/docs/cpp/library/utility/functional/bind)) and related utilities: utilities for binding such as [`std::ref`](/docs/cpp/library/utility/functional/ref) and [`std::placeholders`](/docs/cpp/library/utility/functional/placeholders), polymorphic function wrappers: [`std::function`](/docs/cpp/library/utility/functional/function), predefined functors (e.g. [`std::plus`](/docs/cpp/library/utility/functional/plus), [`std::equal_to`](/docs/cpp/library/utility/functional/equal_to)), pointer-to-member to function converters [`std::mem_fn`](/docs/cpp/library/utility/functional/mem_fn).
