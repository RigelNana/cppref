{/* source:cpp-coroutine-coroutine-handle-from-promise:0001 */}
Creates a `coroutine_handle` from the promise object of a coroutine. The created `coroutine_handle` refers the coroutine, and [`promise()`](/docs/cpp/library/utility/coroutine/coroutine_handle/promise) returns a reference to `p`.

{/* source:cpp-coroutine-coroutine-handle-from-promise:0002 */}
The behavior is undefined if `p` is not a reference to a promise object. This function is only provided for the primary template, i.e. specializations `std::coroutine_handle<>` and `std::coroutine_handle<std::noop_coroutine_promise>` do not have this function.

### Parameters

{/* source:cpp-coroutine-coroutine-handle-from-promise:0003 */}
<ParameterList>
  <Parameter name="p">promise object of a coroutine to refer</Parameter>
</ParameterList>

### Return value

{/* source:cpp-coroutine-coroutine-handle-from-promise:0004 */}
A `coroutine_handle` referring the given coroutine.
