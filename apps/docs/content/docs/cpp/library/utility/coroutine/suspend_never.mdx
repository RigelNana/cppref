{/* source:cpp-coroutine-suspend-never:0001 */}
`suspend_never` is an empty class which can be used to indicate that an [await expression](/docs/cpp/language/functions/coroutines#co_await) never suspends and does not produce a value.

### Member functions

{/* source:cpp-coroutine-suspend-never:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`await_ready`</DescriptionTerm>
    <DescriptionBody>indicates that an await expression never suspends (public member function)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`await_suspend`</DescriptionTerm>
    <DescriptionBody>no-op (public member function)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`await_resume`</DescriptionTerm>
    <DescriptionBody>no-op (public member function)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-coroutine-suspend-never:0003 */}
#### await_ready

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr bool await_ready() const noexcept { return true; }`} />
</DeclarationDoc>

Always returns `true`, indicating that an await expression never suspends.

{/* source:cpp-coroutine-suspend-never:0004 */}
#### await_suspend

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr void await_suspend( std::coroutine_handle<> ) const noexcept {}`} />
</DeclarationDoc>

Does nothing.

{/* source:cpp-coroutine-suspend-never:0005 */}
#### await_resume

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr void await_resume() const noexcept {}`} />
</DeclarationDoc>

Does nothing. An await expression does not produce a value if `suspend_never` is used.
