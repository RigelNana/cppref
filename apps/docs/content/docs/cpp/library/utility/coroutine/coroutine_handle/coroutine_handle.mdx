    {/* source:cpp-coroutine-coroutine-handle-coroutine-handle:0001 */}
    Creates a `coroutine_handle` that does not refer a coroutine, or copies a `coroutine_handle`.

    {/* source:cpp-coroutine-coroutine-handle-coroutine-handle:0002 */}
    1,2) Initializes the underlying address [`ptr`](/docs/cpp/library/utility/coroutine/coroutine_handle#Data_members) to `nullptr`. After construction, [`address()`](/docs/cpp/library/utility/coroutine/coroutine_handle/address) returns `nullptr`, and the `coroutine_handle` does not refer a coroutine. These constructors are not declared for the specialization `std::coroutine_handle<std::noop_coroutine_promise>`.

    {/* source:cpp-coroutine-coroutine-handle-coroutine-handle:0003 */}
    3,4) Copies the underlying address. The copy constructor and move constructor are equivalent to implicitly declared ones.
  </DeclarationDescription>

### Notes

{/* source:cpp-coroutine-coroutine-handle-coroutine-handle:0005 */}
`std::coroutine_handle<std::noop_coroutine_promise>` is neither default constructible nor constructible from [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t). [`std::noop_coroutine`](/docs/cpp/library/utility/coroutine/noop_coroutine) can be used to create a new `std::coroutine_handle<std::noop_coroutine_promise>`.

{/* source:cpp-coroutine-coroutine-handle-coroutine-handle:0006 */}
Static member functions `from_promise` and `from_address` can also create a `coroutine_handle`.
