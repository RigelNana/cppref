Destroys the contained object, if any, as if by a call to [`reset()`](/docs/cpp/library/utility/any/reset).

### Example

{/* source:cpp-utility-any-any:0002 */}
```cpp
#include <any>
#include <cstdio>
 
struct X
{
    X() { std::puts("X::X()"); }
    X(const X&) { std::puts("X::X(const X&)"); }
    ~X() { std::puts("X::~X()"); }
};
 
int main()
{
    std::any a{X{}};
    std::puts("Leaving main()...");
}
```

Output:

```text
X::X()
X::X(const X&)
X::~X()
Leaving main()...
X::~X()
```
