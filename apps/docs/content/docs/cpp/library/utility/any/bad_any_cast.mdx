#### `std::bad_any_cast::bad_any_cast`

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++17" code={`bad_any_cast() noexcept;`} />
  <Declaration id="2" language="cpp" since="C++17" code={`bad_any_cast( const bad_any_cast& other ) noexcept;`} />
</DeclarationDoc>

Constructs a new `bad_any_cast` object with an implementation-defined null-terminated byte string which is accessible through [`what()`](/docs/cpp/library/error/exception/what).

1. 1) Default constructor.
2. 2) Copy constructor. If `*this` and `other` both have dynamic type `std::bad_any_cast` then `std::strcmp(what(), other.what()) == 0`.

#### `std::bad_any_cast::what`

<DeclarationDoc>
  <Declaration language="cpp" since="C++17" code={`virtual const char* what() const noexcept;`} />
</DeclarationDoc>

Returns the explanatory string.

##### Return value

Pointer to an implementation-defined null-terminated string with explanatory information. The string is suitable for conversion and display as a [`std::wstring`](/docs/cpp/library/string/basic_string). The pointer is guaranteed to be valid at least until the exception object from which it is obtained is destroyed, or until a non-const member function (e.g. copy assignment operator) on the exception object is called.

<Revision since="C++26">
The returned string is encoded with the ordinary literal encoding during constant evaluation.
</Revision>

##### Notes

Implementations are allowed but not required to override `what()`.

### Example

{/* source:cpp-utility-any-bad-any-cast:0008 */}
```cpp
#include <any>
#include <cassert>
#include <print>
 
int main()
{
    auto x = std::any(42);
    assert(std::any_cast<int>(x) == 42); // OK
 
    try
    {
        [[maybe_unused]] auto s = std::any_cast<std::string>(x); // throws
    }
    catch (const std::bad_any_cast& ex)
    {
        std::println("{}", ex.what());
    }
}
```

Possible output:

```text
bad any_cast
```
