Overloads the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::any`](/docs/cpp/library/utility/any). Swaps the content of two `any` objects by calling `lhs.swap(rhs)`.

### Parameters

{/* source:cpp-utility-any-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">objects to swap</Parameter>
</ParameterList>

### Example

{/* source:cpp-utility-any-swap2:0003 */}
```cpp
#include <any>
#include <print>
#include <string>
 
int main()
{
    std::any p = 42, q = std::string{"Bishop"};
    std::println("p: {}, q: {}", std::any_cast<int>(p), std::any_cast<std::string&>(q));
    std::println("swap(p, q)");
    std::swap(p, q);
    std::println("p: {}, q: {}", std::any_cast<std::string&>(p), std::any_cast<int>(q));
}
```

Output:

```text
p: 42, q: Bishop
swap(p, q)
p: Bishop, q: 42
```
