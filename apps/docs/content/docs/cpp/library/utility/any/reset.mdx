{/* source:cpp-utility-any-reset:0001 */}
If `*this` contains a value, destroys the contained value.

{/* source:cpp-utility-any-reset:0002 */}
`*this` does not contain a value after this call.

### Parameters

{/* source:cpp-utility-any-reset:0003 */}
(none)

### Return value

{/* source:cpp-utility-any-reset:0004 */}
(none)

### Example

{/* source:cpp-utility-any-reset:0005 */}
```cpp
#include <any>
#include <cassert>
 
int main()
{
    std::any a{42};
    assert(a.has_value());
    a.reset();
    assert(not a.has_value());
}
```
