{/* source:cpp-utility-variadic:0000 */}
Variadic functions are functions (e.g. [`std::printf`](/docs/cpp/library/io/c/printf)) which take a [variable number of arguments](/docs/cpp/language/functions/variadic_arguments).

{/* source:cpp-utility-variadic:0001 */}
To declare a variadic function, an ellipsis appears after the list of parameters, e.g. `int printf(const char* format...);`, which may be preceded by an optional comma. See [Variadic arguments](/docs/cpp/language/functions/variadic_arguments) for additional detail on the syntax, automatic argument conversions and the alternatives.

{/* source:cpp-utility-variadic:0002 */}
To access the variadic arguments from the function body, the following library facilities are provided:

{/* source:cpp-utility-variadic:0003 */}
Defined in header [`<cstdarg>`](/docs/cpp/library/headers/cstdarg)

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`va_start`](/docs/cpp/library/utility/variadic/va_start)</DescriptionTerm>
    <DescriptionBody>enables access to variadic function arguments (function macro)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`va_arg`](/docs/cpp/library/utility/variadic/va_arg)</DescriptionTerm>
    <DescriptionBody>accesses the next variadic function argument (function macro)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`va_copy`](/docs/cpp/library/utility/variadic/va_copy) <InlineRevision since="C++11" /></DescriptionTerm>
    <DescriptionBody>makes a copy of the variadic function arguments (function macro)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`va_end`](/docs/cpp/library/utility/variadic/va_end)</DescriptionTerm>
    <DescriptionBody>ends traversal of the variadic function arguments (function macro)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`va_list`](/docs/cpp/library/utility/variadic/va_list)</DescriptionTerm>
    <DescriptionBody>holds the information needed by [`va_start`](/docs/cpp/library/utility/variadic/va_start), [`va_arg`](/docs/cpp/library/utility/variadic/va_arg), [`va_end`](/docs/cpp/library/utility/variadic/va_end), and [`va_copy`](/docs/cpp/library/utility/variadic/va_copy) (typedef)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Example

{/* source:cpp-utility-variadic:0004 */}
```cpp
#include <cstdarg>
#include <iostream>
 
void simple_printf(const char* fmt...) // C-style "const char* fmt, ..." is also valid
{
    va_list args;
    va_start(args, fmt);
 
    while (*fmt != '\0')
    {
        if (*fmt == 'd')
        {
            int i = va_arg(args, int);
            std::cout << i << '\n';
        }
        else if (*fmt == 'c')
        {
            // note automatic conversion to integral type
            int c = va_arg(args, int);
            std::cout << static_cast<char>(c) << '\n';
        }
        else if (*fmt == 'f')
        {
            double d = va_arg(args, double);
            std::cout << d << '\n';
        }
        ++fmt;
    }
 
    va_end(args);
}
 
int main()
{
    simple_printf("dcff", 3, 'a', 1.999, 42.5); 
}
```

Output:

```text
3
a
1.999
42.5
```
