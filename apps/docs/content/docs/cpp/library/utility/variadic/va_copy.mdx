  <Declaration language="cpp" since="C++11" code={`void va_copy( std::va_list dest, std::va_list src );`} />
</DeclarationDoc>

{/* source:cpp-utility-variadic-va-copy:0001 */}
The `va_copy` macro copies `src` to `dest`.

{/* source:cpp-utility-variadic-va-copy:0002 */}
[`va_end`](/docs/cpp/library/utility/variadic/va_end) should be called on `dest` before the function returns or any subsequent re-initialization of `dest` (via calls to [`va_start`](/docs/cpp/library/utility/variadic/va_start) or `va_copy`).

### Parameters

{/* source:cpp-utility-variadic-va-copy:0003 */}
<ParameterList>
  <Parameter name="dest">an instance of the [`va_list`](/docs/cpp/library/utility/variadic/va_list) type to initialize</Parameter>
  <Parameter name="src">the source [`va_list`](/docs/cpp/library/utility/variadic/va_list) that will be used to initialize `dest`</Parameter>
</ParameterList>

### Expanded value

{/* source:cpp-utility-variadic-va-copy:0004 */}
(none)

### Example

{/* source:cpp-utility-variadic-va-copy:0005 */}
```cpp
#include <cmath>
#include <cstdarg>
#include <iostream>
 
double sample_stddev(int count, ...) 
{
    double sum = 0;
    std::va_list args1;
    va_start(args1, count);
    std::va_list args2;
    va_copy(args2, args1);
    for (int i = 0; i < count; ++i)
    {
        double num = va_arg(args1, double);
        sum += num;
    }
    va_end(args1);
    double mean = sum / count;
 
    double sum_sq_diff = 0;
    for (int i = 0; i < count; ++i)
    {
        double num = va_arg(args2, double);
        sum_sq_diff += (num - mean) * (num - mean);
    }
    va_end(args2);
    return std::sqrt(sum_sq_diff / count);
}
 
int main() 
{
    std::cout << sample_stddev(4, 25.0, 27.3, 26.9, 25.7) << '\n';
}
```

Output:

```text
0.920258
```
