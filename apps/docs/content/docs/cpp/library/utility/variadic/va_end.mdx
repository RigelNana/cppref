{/* source:cpp-utility-variadic-va-end:0001 */}
The `va_end` macro performs cleanup for an `ap` object initialized by a call to [`va_start`](/docs/cpp/library/utility/variadic/va_start) or [`va_copy`](/docs/cpp/library/utility/variadic/va_copy). `va_end` may modify `ap` so that it is no longer usable.

{/* source:cpp-utility-variadic-va-end:0002 */}
If there is no corresponding call to [`va_start`](/docs/cpp/library/utility/variadic/va_start) or [`va_copy`](/docs/cpp/library/utility/variadic/va_copy), or if `va_end` is not called before a function that calls [`va_start`](/docs/cpp/library/utility/variadic/va_start) or [`va_copy`](/docs/cpp/library/utility/variadic/va_copy) returns, the behavior is undefined.
