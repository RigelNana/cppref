{/* source:cpp-utility-variadic-va-start:0001 */}
The `va_start` macro enables access to the variable arguments following the named argument `parm_n`.

{/* source:cpp-utility-variadic-va-start:0002 */}
`va_start` should be invoked with an instance to a valid [`va_list`](/docs/cpp/library/utility/variadic/va_list) object `ap` before any calls to [`va_arg`](/docs/cpp/library/utility/variadic/va_arg).

{/* source:cpp-utility-variadic-va-start:0003 */}
<Revision since="C++11">
If the `parm_n` is a [pack expansion](/docs/cpp/language/templates/parameter_pack#Pack_expansion) or an entity resulting from a [lambda capture](/docs/cpp/language/functions/lambda#Lambda_capture), the program is ill-formed, no diagnostic required.
</Revision>

{/* source:cpp-utility-variadic-va-start:0004 */}
If `parm_n` is of reference type, or of a type not compatible with the type that results from [default argument promotions](/docs/cpp/language/functions/variadic_arguments#Default_conversions), the behavior is undefined.

### Parameters

{/* source:cpp-utility-variadic-va-start:0005 */}
<ParameterList>
  <Parameter name="ap">an object of the [`va_list`](/docs/cpp/library/utility/variadic/va_list) type</Parameter>
  <Parameter name="parm_n">the named parameter preceding the first variable parameter</Parameter>
</ParameterList>

### Expanded value

{/* source:cpp-utility-variadic-va-start:0006 */}
(none)

### Notes

{/* source:cpp-utility-variadic-va-start:0007 */}
`va_start` is required to support `parm_n` with overloaded `operator&`.

### Example

{/* source:cpp-utility-variadic-va-start:0008 */}
```cpp
#include <cstdarg>
#include <iostream>
 
int add_nums(int count...)
{
    int result = 0;
    std::va_list args;
    va_start(args, count);
    for (int i = 0; i < count; ++i)
        result += va_arg(args, int);
    va_end(args);
    return result;
}
 
int main()
{
    std::cout << add_nums(4, 25, 25, 50, 50) << '\n';
}
```
Output:

```text
150
```
