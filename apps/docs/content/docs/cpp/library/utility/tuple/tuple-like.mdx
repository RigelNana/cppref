{/* source:cpp-utility-tuple-tuple-like:0001 */}
1. 1) A type `T` models and satisfies the concept *tuple-like* if `std::remove_cvref_t<T>` is a specialization of
- [`std::array`](/docs/cpp/library/container/array),
- <InlineRevision since="C++26">[`std::complex`](/docs/cpp/library/numeric/complex)</InlineRevision>,
- [`std::pair`](/docs/cpp/library/utility/pair),
- [`std::tuple`](/docs/cpp/library/utility/tuple), or
- [`std::ranges::subrange`](/docs/cpp/library/ranges/subrange).

{/* source:cpp-utility-tuple-tuple-like:0002 */}
2. 2) *pair-like* objects are *tuple-like* objects with exactly 2 elements.

### Notes

{/* source:cpp-utility-tuple-tuple-like:0003 */}
*tuple-like* types implement the tuple protocol, i.e., such types can be used with [`std::get`](/docs/cpp/library/utility/tuple/get), [`std::tuple_element`](/docs/cpp/library/utility/tuple_element) and [`std::tuple_size`](/docs/cpp/library/utility/tuple_size).

{/* source:cpp-utility-tuple-tuple-like:0004 */}
Elements of *tuple-like* types can be bound with [structured binding](/docs/cpp/language/declarations/structured_binding#Case_2:_binding_a_tuple-like_type).
