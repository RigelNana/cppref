These [deduction guides](/docs/cpp/language/templates/ctad) are provided for [`std::tuple`](/docs/cpp/library/utility/tuple) to account for the edge cases missed by the implicit deduction guides, in particular, non-copyable arguments and array to pointer conversion.

### Example

{/* source:cpp-utility-tuple-deduction-guides:0002 */}
```cpp
#include <tuple>
int main()
{
    int a[2], b[3], c[4];
    std::tuple t1{a, b, c}; // explicit deduction guide is used in this case
}
```
