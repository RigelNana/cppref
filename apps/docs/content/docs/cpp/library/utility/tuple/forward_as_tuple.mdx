  <Declaration language="cpp" since="C++11" code={`template< class... Types >
std::tuple<Types&&...> forward_as_tuple( Types&&... args ) noexcept;`} />
  <InlineRevision since="C++14">constexpr</InlineRevision>

{/* source:cpp-utility-tuple-forward-as-tuple:0001 */}
Constructs a tuple of references to the arguments in `args` suitable for forwarding as an argument to a function. The tuple has rvalue reference data members when rvalues are used as arguments, and otherwise has lvalue reference data members.

### Parameters

{/* source:cpp-utility-tuple-forward-as-tuple:0002 */}
<ParameterList>
  <Parameter name="args">zero or more arguments to construct the tuple from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-tuple-forward-as-tuple:0003 */}
A [`std::tuple`](/docs/cpp/library/utility/tuple) object created as if by `std::tuple<Types&&...>(std::forward<Types>(args)...)`

### Notes

{/* source:cpp-utility-tuple-forward-as-tuple:0004 */}
If the arguments are temporaries, `forward_as_tuple` does not extend their lifetime; they have to be used before the end of the full expression.

### Example

{/* source:cpp-utility-tuple-forward-as-tuple:0005 */}
```cpp
#include <iostream>
#include <map>
#include <string>
#include <tuple>
 
int main()
{
    std::map<int, std::string> m;
 
    m.emplace(std::piecewise_construct,
              std::forward_as_tuple(6),
              std::forward_as_tuple(9, 'g'));
    std::cout << "m[6] = " << m[6] << '\n';
 
    // The following is an error: it produces a
    // std::tuple<int&&, char&&> holding two dangling references.
    //
    // auto t = std::forward_as_tuple(20, 'a');
    // m.emplace(std::piecewise_construct, std::forward_as_tuple(10), t);
}
```

Output:

```text
m[6] = ggggggggg
```
