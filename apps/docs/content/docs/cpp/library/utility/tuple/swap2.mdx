{/* source:cpp-utility-tuple-swap2:0001 */}
Swaps the contents of `lhs` and `rhs`. Equivalent to `lhs.swap(rhs)`.

{/* source:cpp-utility-tuple-swap2:0002 */}
<Revision since="C++17">
1. 1) This overload participates in overload resolution only if `std::is_swappable_v<Ti>` is `true` for all i from 0 to `sizeof...(Types)`.
2. 2) This overload participates in overload resolution only if `std::is_swappable_v<const Ti>` is `true` for all i from 0 to `sizeof...(Types)`.
</Revision>

### Return value

{/* source:cpp-utility-tuple-swap2:0004 */}

[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(noexcept(lhs.swap(rhs)))`

### Example

{/* source:cpp-utility-tuple-swap2:0006 */}
```cpp
#include <iostream>
#include <string>
#include <tuple>
 
int main()
{
    std::tuple<int, std::string, float> p1{42, "ABCD", 2.71}, p2;
    p2 = std::make_tuple(10, "1234", 3.14);
 
    auto print_p1_p2 = [&](auto rem)
    {
        std::cout << rem
                  << "p1 = {" << std::get<0>(p1)
                  << ", "     << std::get<1>(p1)
                  << ", "     << std::get<2>(p1) << "}, "
                  << "p2 = {" << std::get<0>(p2)
                  << ", "     << std::get<1>(p2)
                  << ", "     << std::get<2>(p2) << "}\n";
    };
 
    print_p1_p2("Before p1.swap(p2): ");
    p1.swap(p2);
    print_p1_p2("After  p1.swap(p2): ");
    swap(p1, p2);
    print_p1_p2("After swap(p1, p2): ");
}
```

Output:

```text
Before p1.swap(p2): p1 = {42, ABCD, 2.71}, p2 = {10, 1234, 3.14}
After  p1.swap(p2): p1 = {10, 1234, 3.14}, p2 = {42, ABCD, 2.71}
After swap(p1, p2): p1 = {42, ABCD, 2.71}, p2 = {10, 1234, 3.14}
```
