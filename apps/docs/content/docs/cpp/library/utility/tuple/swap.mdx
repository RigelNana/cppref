{/* source:cpp-utility-tuple-swap:0001 */}
Calls `swap` (which might be [`std::swap`](/docs/cpp/library/algorithm/swap), or might be found via [ADL](/docs/cpp/language/functions/adl)) for each element in `*this` and its corresponding element in `other`.

{/* source:cpp-utility-tuple-swap:0002 */}
<Revision until="C++23">
If any selected `swap` function call is ill-formed, or does not swap the corresponding elements of both tuples, the behavior is undefined.
</Revision>

<Revision since="C++23">
If any selected `swap` function call does not swap the corresponding elements of both tuples, the behavior is undefined.

1. 1) The program is ill-formed if `(std::is_swappable_v<Types> && ...)` is not `true`.
2. 2) The program is ill-formed if `(std::is_swappable_v<const Types> && ...)` is not `true`.
</Revision>

### Exceptions

{/* source:cpp-utility-tuple-swap:0005 */}
<Revision until="C++17">
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification:

```cpp
noexcept(
    noexcept(swap(std::declval<T0&>>(), std::declval<T0&>())) &&
    noexcept(swap(std::declval<T1&>>(), std::declval<T1&>())) &&
    noexcept(swap(std::declval<T2&>>(), std::declval<T2&>())) &&
    ...

)
```

In the expression above, the identifier `swap` is looked up in the same manner as the one used by the C++17 [`std::is_nothrow_swappable`](/docs/cpp/library/meta/is_swappable) trait.
</Revision>

<Revision since="C++17">
1. 1) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept((std::is_nothrow_swappable_v<Types> && ...))`
2. 2) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept((std::is_nothrow_swappable_v<const Types> && ...))`
</Revision>

### Example

{/* source:cpp-utility-tuple-swap:0006 */}
```cpp
#include <iostream>
#include <string>
#include <tuple>
 
int main()
{
    std::tuple<int, std::string, float> p1{42, "ABCD", 2.71}, p2;
    p2 = std::make_tuple(10, "1234", 3.14);
 
    auto print_p1_p2 = [&](auto rem)
    {
        std::cout << rem
                  << "p1 = {" << std::get<0>(p1)
                  << ", "     << std::get<1>(p1)
                  << ", "     << std::get<2>(p1) << "}, "
                  << "p2 = {" << std::get<0>(p2)
                  << ", "     << std::get<1>(p2)
                  << ", "     << std::get<2>(p2) << "}\n";
    };
 
    print_p1_p2("Before p1.swap(p2): ");
    p1.swap(p2);
    print_p1_p2("After  p1.swap(p2): ");
    swap(p1, p2);
    print_p1_p2("After swap(p1, p2): ");
}
```

Output:

```text
Before p1.swap(p2): p1 = {42, ABCD, 2.71}, p2 = {10, 1234, 3.14}
After  p1.swap(p2): p1 = {10, 1234, 3.14}, p2 = {42, ABCD, 2.71}
After swap(p1, p2): p1 = {42, ABCD, 2.71}, p2 = {10, 1234, 3.14}
```
