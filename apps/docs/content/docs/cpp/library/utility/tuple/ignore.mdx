{/* source:cpp-utility-tuple-ignore:0001 */}
1. 1) An object such that any value can be assigned to it with no effect.

{/* source:cpp-utility-tuple-ignore:0002 */}
2. 2) The type of `std::ignore`.

### Notes

{/* source:cpp-utility-tuple-ignore:0003 */}
A `void` expression or a volatile bit-field value cannot be assigned to `std::ignore`.

{/* source:cpp-utility-tuple-ignore:0004 */}
`std::ignore` is intended for use with [`std::tie`](/docs/cpp/library/utility/tuple/tie) when unpacking a [`std::tuple`](/docs/cpp/library/utility/tuple), as a placeholder for the arguments that are not used, but can be used for any unwanted assignment.

{/* source:cpp-utility-tuple-ignore:0005 */}
Some code guides recommend using `std::ignore` to avoid warnings from unused return values of [`[[nodiscard]]`](/docs/cpp/language/declarations/attributes/nodiscard) functions, even though an assignment isn't required.

{/* source:cpp-utility-tuple-ignore:0006 */}
For ignoring values not requiring assignment, one may cast to `void`. For variables that have names, but whose value is unused, one may cast those to `void` or declare those variables with [`[[maybe_unused]]`](/docs/cpp/language/declarations/attributes/maybe_unused).

### Example

{/* source:cpp-utility-tuple-ignore:0007 */}
1. Demonstrates the use of `std::ignore` together with a [`[[nodiscard]]`](/docs/cpp/language/declarations/attributes/nodiscard) function.
2. Unpacks a `std::pair<iterator, bool>` returned by [`std::set::insert()`](/docs/cpp/library/container/set/insert), but only saves the boolean.

{/* source:cpp-utility-tuple-ignore:0008 */}
```cpp
#include <iostream>
#include <set>
#include <string>
#include <tuple>
 
[[nodiscard]] int dontIgnoreMe()
{
    return 42;
}
 
int main()
{
    std::ignore = dontIgnoreMe();
 
    std::set<std::string> set_of_str;
    if (bool inserted{false};
        std::tie(std::ignore, inserted) = set_of_str.insert("Test"),
        inserted)
        std::cout << "Value was inserted successfully.\n";
}
```

Output:

```text
Value was inserted successfully.
```
