{/* source:cpp-utility-bitset-to-string:0001 */}
Converts the contents of the bitset to a string. Uses `zero` to represent bits with value of `false` and `one` to represent bits with value of `true`.

{/* source:cpp-utility-bitset-to-string:0002 */}
The resulting string contains `N` characters with the first character corresponds to the last (`N-1` th) bit and the last character corresponding to the first bit.

{/* source:cpp-utility-bitset-to-string:0003 */}
<Revision until="C++11">
All template type arguments need to be provided because function templates cannot have default template arguments. Overloads (2-4) are provided to simplify the invocations of `to_string`:

2. 2) Uses the default allocator [`std::allocator`](/docs/cpp/library/memory/allocator).
3. 3) Uses the default character trait [`std::char_traits`](/docs/cpp/library/string/char_traits) and the default allocator [`std::allocator`](/docs/cpp/library/memory/allocator).
4. 4) Uses the default character type `char`, the default character trait [`std::char_traits`](/docs/cpp/library/string/char_traits) and the default allocator [`std::allocator`](/docs/cpp/library/memory/allocator).

</Revision>

### Parameters

{/* source:cpp-utility-bitset-to-string:0004 */}
<ParameterList>
  <Parameter name="zero">character to use to represent `false`</Parameter>
  <Parameter name="one">character to use to represent `true`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-to-string:0005 */}
1. 1) The converted string.

{/* source:cpp-utility-bitset-to-string:0006 */}
2. 2) `to_string<CharT, Traits, std::allocator<CharT>>(zero, one)`.

{/* source:cpp-utility-bitset-to-string:0007 */}
3. 3) `to_string<CharT, std::char_traits<CharT>, std::allocator<CharT>>(zero, one)`.

{/* source:cpp-utility-bitset-to-string:0008 */}
4. 4) `to_string<char, std::char_traits<char>, std::allocator<char>>(zero, one)`.

### Exceptions

{/* source:cpp-utility-bitset-to-string:0009 */}
May throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) from the [`std::basic_string`](/docs/cpp/library/string/basic_string) constructor.

### Notes

{/* source:cpp-utility-bitset-to-string:0010 */}
Since C++11, functions templates can have default template arguments. [LWG issue 1113](https://cplusplus.github.io/LWG/issue1113) removed the helper overloads ([`2-4`](/docs/cpp/library/utility/bitset/to_string#Version_2)) and added the corresponding default template arguments in ([`1`](/docs/cpp/library/utility/bitset/to_string#Version_1)).

### Example

{/* source:cpp-utility-bitset-to-string:0011 */}
```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::bitset<8> b{42};
    std::cout << b.to_string() << '\n'
              << b.to_string('*') << '\n'
              << b.to_string('O', 'X') << '\n';
}
```

Output:

```text
00101010
**1*1*1*
OOXOXOXO
```
