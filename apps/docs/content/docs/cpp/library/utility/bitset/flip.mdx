{/* source:cpp-utility-bitset-flip:0001 */}
Flips bits, i.e. changes `true` values to `false` and `false` values to `true`. Equivalent to a logical NOT operation on part or all of the bitset.

{/* source:cpp-utility-bitset-flip:0002 */}
1. 1) Flips all bits (like [`operator~`](/docs/cpp/library/utility/bitset/operator_logic), but in-place).

{/* source:cpp-utility-bitset-flip:0003 */}
2. 2) Flips the bit at the position `pos`.

### Parameters

{/* source:cpp-utility-bitset-flip:0004 */}
<ParameterList>
  <Parameter name="pos">the position of the bit to flip</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-flip:0005 */}
`*this`

### Exceptions

{/* source:cpp-utility-bitset-flip:0006 */}
2) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos` does not correspond to a valid bit position.

### Example

{/* source:cpp-utility-bitset-flip:0007 */}
```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::bitset<4> flops;
 
    std::cout << flops << '\n'
              << flops.flip(0) << '\n'
              << flops.flip(2) << '\n'
              << flops.flip() << '\n';
}
```

Output:

```text
0000
0001
0101
1010
```
