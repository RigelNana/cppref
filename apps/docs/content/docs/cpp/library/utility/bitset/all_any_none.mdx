{/* source:cpp-utility-bitset-all-any-none:0001 */}
1. 1) Checks if all bits are set to `true`.

{/* source:cpp-utility-bitset-all-any-none:0002 */}
2. 2) Checks if any bits are set to `true`.

{/* source:cpp-utility-bitset-all-any-none:0003 */}
3. 3) Checks if none of the bits are set to `true`.

### Parameters

{/* source:cpp-utility-bitset-all-any-none:0004 */}
(none)

### Return value

{/* source:cpp-utility-bitset-all-any-none:0005 */}
1. 1) `true` if all bits are set to `true`, otherwise `false`.

{/* source:cpp-utility-bitset-all-any-none:0006 */}
2. 2) `true` if any of the bits are set to `true`, otherwise `false`.

{/* source:cpp-utility-bitset-all-any-none:0007 */}
3. 3) `true` if none of the bits are set to `true`, otherwise `false`.

### Example

{/* source:cpp-utility-bitset-all-any-none:0008 */}
```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::bitset<4> b1("0000");
    std::bitset<4> b2("0101");
    std::bitset<4> b3("1111");
 
    std::cout
        << "bitset\t" << "all\t" << "any\t" << "none\n"
        << b1 << '\t' << b1.all() << '\t' << b1.any() << '\t' << b1.none() << '\n'
        << b2 << '\t' << b2.all() << '\t' << b2.any() << '\t' << b2.none() << '\n'
        << b3 << '\t' << b3.all() << '\t' << b3.any() << '\t' << b3.none() << '\n';
}
```

Output:

```text
bitset  all any none
0000    0   0   1
0101    0   1   0
1111    1   1   0
```
