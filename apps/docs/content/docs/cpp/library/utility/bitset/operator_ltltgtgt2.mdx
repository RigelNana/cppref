{/* source:cpp-utility-bitset-operator-ltltgtgt2:0001 */}
Inserts or extracts a bitset from a character stream.

{/* source:cpp-utility-bitset-operator-ltltgtgt2:0002 */}
1. 1) Writes the bitset `x` to the character stream `os` as if by first converting it to a `std::basic_string<CharT, Traits>` using [`to_string()`](/docs/cpp/library/utility/bitset/to_string), and then writing it into `os` using the [`operator<<`](/docs/cpp/library/string/basic_string/operator_ltltgtgt) (which is a [FormattedOutputFunction](/docs/cpp/library/named_req/FormattedOutputFunction) for strings). The characters to use for ones and zeroes are obtained from the currently-imbued locale by calling `std::use_facet<std::ctype<CharT>>(os.getloc()).widen()` with `'1'` and `'0'` as arguments.

{/* source:cpp-utility-bitset-operator-ltltgtgt2:0003 */}
2. 2) Behaves as a [FormattedInputFunction](/docs/cpp/library/named_req/FormattedInputFunction). After constructing and checking the sentry object, which may skip leading whitespace, extracts up to `N` characters from `is` and stores the characters in the bitset `x`. Characters are extracted until either `N` characters have been read, end-of-file occurs in `is`, or the next character is neither `is.widen('0')` nor `is.widen('1')`. If `N > 0` and no characters are extracted, `is.setstate(ios_base::failbit)` is called.

### Example

{/* source:cpp-utility-bitset-operator-ltltgtgt2:0007 */}
```cpp
#include <bitset>
#include <iostream>
#include <sstream>
 
int main()
{
    std::string bit_string = "001101";
    std::istringstream bit_stream(bit_string);
 
    std::bitset<3> b1;
    bit_stream >> b1; // reads "001", stream still holds "101"
    std::cout << b1 << '\n';
 
    std::bitset<8> b2;
    bit_stream >> b2; // reads "101", populates the 8-bit set as "00000101"
    std::cout << b2 << '\n';
}
```

Output:

```text
001
00000101
```
