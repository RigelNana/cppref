{/* source:cpp-utility-bitset-set:0001 */}
Sets all bits to `true` or sets one bit to specified value.

{/* source:cpp-utility-bitset-set:0002 */}
1. 1) Sets all bits to `true`.

{/* source:cpp-utility-bitset-set:0003 */}
2. 2) Sets the bit at position `pos` to the value `value`.

### Parameters

{/* source:cpp-utility-bitset-set:0004 */}
<ParameterList>
  <Parameter name="pos">the position (counting from `0`, i.e. from least significant to most significant) of the bit to set</Parameter>
  <Parameter name="value">the value to set the bit to</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-set:0005 */}
`*this`

### Exceptions

{/* source:cpp-utility-bitset-set:0006 */}
2. 2) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos` does not correspond to a valid bit position.

### Example

{/* source:cpp-utility-bitset-set:0007 */}
```cpp
#include <bitset>
#include <cstddef>
#include <iostream>
 
int main()
{
    std::bitset<8> b;
    std::cout << b << '\n';
    std::cout << b.set() << '\n';
    std::cout << b.reset() << '\n';
 
    for (std::size_t i = 1; i < b.size(); i += 2)
        b.set(i);
 
    std::cout << b << '\n';
}
```

Output:

```text
00000000
11111111
00000000
10101010
```
