{/* source:cpp-utility-bitset-reset:0001 */}
Sets bits to `false`.

{/* source:cpp-utility-bitset-reset:0002 */}
1. 1) Sets all bits to `false`

{/* source:cpp-utility-bitset-reset:0003 */}
2. 2) Sets the bit at position `pos` to `false`.

### Parameters

{/* source:cpp-utility-bitset-reset:0004 */}
<ParameterList>
  <Parameter name="pos">the position of the bit to set</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-reset:0005 */}
`*this`

### Exceptions

{/* source:cpp-utility-bitset-reset:0006 */}
2. 2) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos` does not correspond to a valid bit position.

### Example

{/* source:cpp-utility-bitset-reset:0007 */}
```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::bitset<8> b(42);
    std::cout << "Bitset is         " << b << '\n';
    b.reset(1);
    std::cout << "After b.reset(1): " << b << '\n';
    b.reset();
    std::cout << "After b.reset():  " << b << '\n';
}
```

Output:

```text
Bitset is         00101010
After b.reset(1): 00101000
After b.reset():  00000000
```
