<DeclarationDoc>
  <Declaration id="1" language="cpp" code={`bool operator==( const bitset& rhs ) const;`} />
  (noexcept since C++11)
  (constexpr since C++23)

  <Declaration id="2" language="cpp" until="C++20" code={`bool operator!=( const bitset& rhs ) const;`} />
  (noexcept since C++11)
</DeclarationDoc>

{/* source:cpp-utility-bitset-operator-cmp:0001 */}
1. 1) Returns `true` if all of the bits in `*this` and `rhs` are equal.

{/* source:cpp-utility-bitset-operator-cmp:0002 */}
2. 2) Returns `true` if any of the bits in `*this` and `rhs` are not equal.

{/* source:cpp-utility-bitset-operator-cmp:0003 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Parameters

{/* source:cpp-utility-bitset-operator-cmp:0004 */}
<ParameterList>
  <Parameter name="rhs">bitset to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-operator-cmp:0005 */}
1. 1) `true` if the value of each bit in `*this` equals the value of the corresponding bit in `rhs`, otherwise `false`.

{/* source:cpp-utility-bitset-operator-cmp:0006 */}
2. 2) `true` if `!(*this == rhs)`, otherwise `false`.

### Example

{/* source:cpp-utility-bitset-operator-cmp:0007 */}
Compare given bitsets to determine if they are identical:

```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::bitset<4> b1(0b0011);
    std::bitset<4> b2(b1);
    std::bitset<4> b3(0b0100);
 
    std::cout << std::boolalpha;
    std::cout << "b1 == b2: " << (b1 == b2) << '\n';
    std::cout << "b1 == b3: " << (b1 == b3) << '\n';
    std::cout << "b1 != b3: " << (b1 != b3) << '\n';
 
//  b1 == std::bitset<3>{}; // compile-time error: incompatible types
}
```

Output:

```text
b1 == b2: true
b1 == b3: false
b1 != b3: true
```
