{/* source:cpp-utility-bitset-operator-at:0001 */}
Accesses the bit at position `pos`. The first version returns the value of the bit, the second version returns an object of type [`std::bitset::reference`](/docs/cpp/library/utility/bitset/reference) that allows modification of the value.

{/* source:cpp-utility-bitset-operator-at:0002 */}
Unlike [`test()`](/docs/cpp/library/utility/bitset/test), does not throw exceptions: the behavior is undefined if `pos` is out of bounds.

### Parameters

{/* source:cpp-utility-bitset-operator-at:0003 */}
<ParameterList>
  <Parameter name="pos">position of the bit to return</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-operator-at:0004 */}
1. 1) The value of the requested bit.

{/* source:cpp-utility-bitset-operator-at:0005 */}
2. 2) An object of type [`std::bitset::reference`](/docs/cpp/library/utility/bitset/reference), which allows writing to the requested bit.

### Exceptions

{/* source:cpp-utility-bitset-operator-at:0006 */}
(none)

### Example

{/* source:cpp-utility-bitset-operator-at:0007 */}
```cpp
#include <bitset>
#include <cstddef>
#include <iostream>
 
int main()
{
    std::bitset<8> b1{0b00101010}; // binary literal for 42
 
    for (std::size_t i = 0; i < b1.size(); ++i)
        std::cout << "b1[" << i << "]: " << b1[i] << '\n';
    b1[0] = true; // modifies the first bit through bitset::reference
 
    std::cout << "After setting bit 0, b1 holds " << b1 << '\n';
}
```

Output:

```text
b1[0]: 0
b1[1]: 1
b1[2]: 0
b1[3]: 1
b1[4]: 0
b1[5]: 1
b1[6]: 0
b1[7]: 0
After setting bit 0, b1 holds 00101011
```
