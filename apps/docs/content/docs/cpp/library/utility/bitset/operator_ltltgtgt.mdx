{/* source:cpp-utility-bitset-operator-ltltgtgt:0001 */}
Performs binary shift left (towards higher index positions) and binary shift right (towards lower index positions). Zeroes are shifted in, and bits that would go to an index out of range are dropped (ignored).

{/* source:cpp-utility-bitset-operator-ltltgtgt:0002 */}
1,2) Performs binary shift left. The (2) version is destructive, i.e. performs the shift to the current object.

{/* source:cpp-utility-bitset-operator-ltltgtgt:0003 */}
3,4) Performs binary shift right. The (4) version is destructive, i.e. performs the shift to the current object.

### Parameters

{/* source:cpp-utility-bitset-operator-ltltgtgt:0004 */}
<ParameterList>
  <Parameter name="pos">number of positions to shift the bits</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-operator-ltltgtgt:0005 */}
1,3) New bitset object containing the shifted bits.

{/* source:cpp-utility-bitset-operator-ltltgtgt:0006 */}
2,4) `*this`

### Example

{/* source:cpp-utility-bitset-operator-ltltgtgt:0007 */}
```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::bitset<8> b{0b01110010};
    std::cout << b << " (initial value)\n";
 
    for (; b.any(); b >>= 1)
    {
        while (!b.test(0))
            b >>= 1;
        std::cout << b << '\n';
    }
 
    std::cout << b << " (final value)\n";
}
```

Output:

```text
01110010 (initial value)
00111001
00000111
00000011
00000001
00000000 (final value)
```
