{/* source:cpp-utility-bitset-test:0001 */}
Returns the value of the bit at the position `pos` (counting from 0).

{/* source:cpp-utility-bitset-test:0002 */}
Unlike [`operator[]`](/docs/cpp/library/utility/bitset/operator_at), it performs a bounds check.

### Parameters

{/* source:cpp-utility-bitset-test:0003 */}
<ParameterList>
  <Parameter name="pos">position of the bit to return (counting from 0)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-test:0004 */}
`true` if the requested bit is set, `false` otherwise.

### Exceptions

{/* source:cpp-utility-bitset-test:0005 */}
Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos` does not correspond to a valid bit position.

### Example

{/* source:cpp-utility-bitset-test:0006 */}
```cpp
#include <bit>
#include <bitset>
#include <cassert>
#include <iostream>
#include <stdexcept>
 
int main()
{
    std::bitset<10> b1("1111010000");
 
    std::size_t idx = 0;
    while (idx < b1.size() && !b1.test(idx))
        ++idx;
 
    assert(static_cast<int>(idx) == std::countr_zero(b1.to_ulong()));
 
    if (idx < b1.size())
        std::cout << "The first set bit is at index " << idx << '\n';
    else
        std::cout << "no set bits\n";
 
    try
    {
        std::bitset<0B10'1001'1010> bad;
        if (bad.test(bad.size()))
            std::cout << "Expect unexpected!\n";
    }
    catch (std::out_of_range const& ex)
    {
        std::cout << "Exception: " << ex.what() << '\n';
    }
}
```

Possible output:

```text
The first set bit is at index 4
Exception: bitset::test: __position (which is 666) >= _Nb (which is 666)
```
