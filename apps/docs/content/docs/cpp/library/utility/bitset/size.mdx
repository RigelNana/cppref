Returns the number of bits that the bitset holds.

### Parameters

{/* source:cpp-utility-bitset-size:0002 */}
(none)

### Return value

{/* source:cpp-utility-bitset-size:0003 */}
number of bits that the bitset holds, i.e. the template parameter `N`.

### Example

{/* source:cpp-utility-bitset-size:0004 */}
```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::cout << std::bitset<0x400>().size() << '\n';
}
```

Output:

```text
1024
```
