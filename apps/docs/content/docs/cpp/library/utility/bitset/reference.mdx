{/* source:cpp-utility-bitset-reference:0001 */}
The [`std::bitset`](/docs/cpp/library/utility/bitset) class includes `std::bitset::reference` as a publicly-accessible nested class. This class is used as a proxy object to allow users to interact with individual bits of a bitset, since standard C++ types (like references and pointers) are not built with enough precision to specify individual bits.

{/* source:cpp-utility-bitset-reference:0002 */}
The primary use of `std::bitset::reference` is to provide an lvalue that can be returned from [`operator[]`](/docs/cpp/library/utility/bitset/operator_at).

{/* source:cpp-utility-bitset-reference:0003 */}
Any reads or writes to a bitset that happen via a `std::bitset::reference` potentially read or write to the entire underlying bitset.

### Example

{/* source:cpp-utility-bitset-reference:0010 */}
```cpp
#include <bitset>
#include <iostream>
 
int main()
{
    std::bitset<4> bs{0b1110};
    std::bitset<4>::reference ref = bs[2];
 
    auto info = [&](int id)
    {
        std::cout << id << ") bs: " << bs << "; ref bit: " << ref << '\n';
    };
 
    info(1);
    ref = false;
    info(2);
    ref = true;
    info(3);
    ref.flip();
    info(4);
    ref = bs[1]; // operator=( const reference& x )
    info(5);
 
    std::cout << "6) ~ref bit: " << ~ref << '\n';
}
```

Output:

```text
1) bs: 1110; ref bit: 1
2) bs: 1010; ref bit: 0
3) bs: 1110; ref bit: 1
4) bs: 1010; ref bit: 0
5) bs: 1110; ref bit: 1
6) ~ref bit: 0
```
