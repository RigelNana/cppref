{/* source:cpp-utility-bitset-operator-logic:0001 */}
Performs binary AND, OR, XOR and NOT.

{/* source:cpp-utility-bitset-operator-logic:0002 */}
1. 1) Sets the bits to the result of binary AND on corresponding pairs of bits of `*this` and `other`.

{/* source:cpp-utility-bitset-operator-logic:0003 */}
2. 2) Sets the bits to the result of binary OR on corresponding pairs of bits of `*this` and `other`.

{/* source:cpp-utility-bitset-operator-logic:0004 */}
3. 3) Sets the bits to the result of binary XOR on corresponding pairs of bits of `*this` and `other`.

{/* source:cpp-utility-bitset-operator-logic:0005 */}
4. 4) Returns a temporary copy of `*this` with all bits flipped (binary NOT).

{/* source:cpp-utility-bitset-operator-logic:0006 */}
Note that `&=`, `|=`, and `^=` are only defined for bitsets of the same size `N`.

### Parameters

{/* source:cpp-utility-bitset-operator-logic:0007 */}
<ParameterList>
  <Parameter name="other">another bitset</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-bitset-operator-logic:0008 */}
1-3) `*this`

{/* source:cpp-utility-bitset-operator-logic:0009 */}
4) `std::bitset<N>(*this).flip()`

### Example

{/* source:cpp-utility-bitset-operator-logic:0010 */}
```cpp
#include <bitset>
#include <cstddef>
#include <iostream>
#include <string>
 
int main()
{
    const std::string pattern_str{"1001"};
    std::bitset<16> pattern{pattern_str}, dest;
 
    for (std::size_t i = dest.size() / pattern_str.size(); i != 0; --i)
    {
        dest <<= pattern_str.size();
        dest |= pattern;
        std::cout << dest << " (i = " << i << ")\n";
    }
 
    std::cout << ~dest << " (~dest)\n";
}
```

Output:

```text
0000000000001001 (i = 4)
0000000010011001 (i = 3)
0000100110011001 (i = 2)
1001100110011001 (i = 1)
0110011001100110 (~dest)
```
