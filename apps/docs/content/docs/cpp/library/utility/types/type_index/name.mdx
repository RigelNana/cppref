{/* source:cpp-types-type-index-name:0001 */}
Returns the name of the associated [`std::type_info`](/docs/cpp/library/utility/types/type_info) object. Equivalent to calling [`std::type_info::name()`](/docs/cpp/library/utility/types/type_info/name) directly.

### Parameters

{/* source:cpp-types-type-index-name:0002 */}
(none)

### Return value

{/* source:cpp-types-type-index-name:0003 */}
The name of the associated [`std::type_info`](/docs/cpp/library/utility/types/type_info) object.

### Example

{/* source:cpp-types-type-index-name:0004 */}
```cpp
#include <iostream>
#include <typeindex>
int main() {
    std::cout << std::type_index(typeid(std::cout)).name();
}
```

Possible output:



```text
NSt3__113basic_ostreamIcNS_11char_traitsIcEEEE
```
