{/* source:cpp-types-type-index-operator-cmp:0001 */}
Compares the underlying [`std::type_info`](/docs/cpp/library/utility/types/type_info) objects.

{/* source:cpp-types-type-index-operator-cmp:0002 */}
1,2) Checks whether the underlying [`std::type_info`](/docs/cpp/library/utility/types/type_info) objects refer to the same type.

{/* source:cpp-types-type-index-operator-cmp:0003 */}
3-7) Compares the underlying [`std::type_info`](/docs/cpp/library/utility/types/type_info) objects as defined by an implementation-defined ordering. The comparison is done by [`type_info::before`](/docs/cpp/library/utility/types/type_info/before).

{/* source:cpp-types-type-index-operator-cmp:0004 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Return value

{/* source:cpp-types-type-index-operator-cmp:0006 */}
1. `true` if the underlying [`std::type_info`](/docs/cpp/library/utility/types/type_info) objects refer to the same type, `false` otherwise.

{/* source:cpp-types-type-index-operator-cmp:0007 */}
2. `true` if the underlying [`std::type_info`](/docs/cpp/library/utility/types/type_info) objects refer not to the same type, `false` otherwise.

{/* source:cpp-types-type-index-operator-cmp:0008 */}
3-6) `true` if the types referred by the underlying [`std::type_info`](/docs/cpp/library/utility/types/type_info) objects are ordered by corresponding order, `false` otherwise.

{/* source:cpp-types-type-index-operator-cmp:0009 */}
7. `std::strong_ordering::equal` if the underlying [`std::type_info`](/docs/cpp/library/utility/types/type_info) objects refer to the same type, otherwise `std::strong_ordering::less` if `*this`'s underlying [`std::type_info`](/docs/cpp/library/utility/types/type_info) object precedes `rhs`'s in the implementation-defined ordering, otherwise `std::strong_ordering::greater`.
