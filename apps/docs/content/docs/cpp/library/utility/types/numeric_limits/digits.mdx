The value of `std::numeric_limits<T>::digits` is the number of digits in base-[radix](/docs/cpp/library/utility/types/numeric_limits/radix) that can be represented by the type `T` without change. For integer types, this is the number of bits not counting the sign bit and the padding bits (if any). For floating-point types, this is the digits of the mantissa (for [IEC 559/IEEE 754](/docs/cpp/library/utility/types/numeric_limits/is_iec559) implementations, this is the number of digits stored for the mantissa plus one, because the mantissa has an implicit leading 1 and binary point).
