{/* source:cpp-types-max-align-t:0001 */}
`std::max_align_t` is a [standard-layout](/docs/cpp/library/named_req/StandardLayoutType) <InlineRevision until="C++26">[*TrivialType*](/docs/cpp/library/named_req/TrivialType)</InlineRevision> <InlineRevision since="C++26">[*TriviallyCopyable*](/docs/cpp/library/named_req/TriviallyCopyable) type</InlineRevision> whose [alignment requirement](/docs/cpp/language/basic_concepts/objects#Alignment) is at least as strict (as large) as that of every scalar type.

{/* source:cpp-types-max-align-t:0002 */}
`std::is_trivially_default_constructible_v<std::max_align_t>` is `true`.

### Notes

{/* source:cpp-types-max-align-t:0003 */}
Pointers returned by allocation functions such as [`std::malloc`](/docs/cpp/library/memory/c/malloc) are suitably aligned for any object, which means they are aligned at least as strictly as `std::max_align_t`.

### Example

{/* source:cpp-types-max-align-t:0004 */}
```cpp
#include <cstddef>
#include <iostream>
 
int main()
{
    std::cout << alignof(std::max_align_t) << '\n';
}
```

Possible output:



```text
16
```
