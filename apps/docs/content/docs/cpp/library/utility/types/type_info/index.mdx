{/* source:cpp-types-type-info:0001 */}
The class `type_info` holds implementation-specific information about a type, including the name of the type and means to compare two types for equality or collating order. This is the class returned by the [`typeid`](/docs/cpp/language/expressions/typeid) operator.

{/* source:cpp-types-type-info:0002 */}
The `type_info` class is neither [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible) nor [CopyAssignable](/docs/cpp/library/named_req/CopyAssignable).
