Destructs an object of type [`std::type_info`](/docs/cpp/library/utility/types/type_info). This destructor is public virtual, making the [`std::type_info`](/docs/cpp/library/utility/types/type_info) a polymorphic class.

### Notes

{/* source:cpp-types-type-info-type-info:0002 */}
The dynamic type of a [`std::type_info`](/docs/cpp/library/utility/types/type_info) subobject may be examined by the [`typeid`](/docs/cpp/language/expressions/typeid) operator.

{/* source:cpp-types-type-info-type-info:0003 */}
It is unspecified whether the implementation calls this destructor for any [`std::type_info`](/docs/cpp/library/utility/types/type_info) object at the end of the program.
