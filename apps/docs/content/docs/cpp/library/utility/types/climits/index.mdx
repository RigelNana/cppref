{/* source:cpp-types-climits:0002 */}
The types of these constants, other than `CHAR_BIT` and `MB_LEN_MAX`, are required to match the results of the [integral promotions](/docs/cpp/language/expressions/implicit_cast#Integral_promotion) as applied to objects of the types they describe: `CHAR_MAX` may have type `int` or `unsigned int`, but never `char`. Similarly `USHRT_MAX` may not be of an unsigned type: its type may be `int`.

{/* source:cpp-types-climits:0003 */}
A [freestanding](/docs/cpp/library/freestanding) implementation may lack [`std::sig_atomic_t`](/docs/cpp/library/utility/program/sig_atomic_t) and/or [`std::wint_t`](/docs/cpp/library/text/wide#Types) typedef names, in which case the `SIG_ATOMIC_*` and/or `WINT_*` macros are correspondingly absent.

```cpp
#include <climits>
#include <cstdint>
#include <iomanip>
#include <iostream>
 
int main()
{
    constexpr int w = 14;
    std::cout << std::left;
#   define COUT(x) std::cout << std::setw(w) << #x << " = " << x << '\n'
 
    COUT( CHAR_BIT       );
    COUT( MB_LEN_MAX     );
    COUT( CHAR_MIN       );
    COUT( CHAR_MAX       );
    COUT( SCHAR_MIN      );
    COUT( SHRT_MIN       );
    COUT( INT_MIN        );
    COUT( LONG_MIN       );
    COUT( LLONG_MIN      );
    COUT( SCHAR_MAX      );
    COUT( SHRT_MAX       );
    COUT( INT_MAX        );
    COUT( LONG_MAX       );
    COUT( LLONG_MAX      );
    COUT( UCHAR_MAX      );
    COUT( USHRT_MAX      );
```
