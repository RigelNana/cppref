{/* source:cpp-types-numeric-limits-is-bounded:0001 */}
The value of `std::numeric_limits<T>::is_bounded` is `true` for all arithmetic types `T` that represent a finite set of values. While all fundamental types are bounded, this constant would be `false` in a specialization of [`std::numeric_limits`](/docs/cpp/library/utility/types/numeric_limits) for a library-provided arbitrary precision arithmetic type.
