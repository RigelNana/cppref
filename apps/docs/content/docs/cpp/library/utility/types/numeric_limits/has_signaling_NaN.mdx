{/* source:cpp-types-numeric-limits-has-signaling-nan:0001 */}
The value of `std::numeric_limits<T>::has_signaling_NaN` is `true` for all types `T` capable of representing the special value "Signaling [Not-A-Number](https://en.wikipedia.org/wiki/NaN)". This constant is meaningful for all floating-point types and is guaranteed to be `true` if `std::numeric_limits<T>::is_iec559 == true`.
