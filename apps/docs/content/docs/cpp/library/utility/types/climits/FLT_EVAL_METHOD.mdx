### Notes

{/* source:cpp-types-climits-flt-eval-method:0003 */}
Regardless of the value of `FLT_EVAL_METHOD`, any floating-point expression may be contracted, that is, calculated as if all intermediate results have infinite range and precision (unless [`#pragma`](/docs/cpp/language/preprocessor/impl) `STDC FP_CONTRACT` is off).

{/* source:cpp-types-climits-flt-eval-method:0004 */}
Cast and assignment strip away any extraneous range and precision: this models the action of storing a value from an extended-precision FPU register into a standard-sized memory location.
