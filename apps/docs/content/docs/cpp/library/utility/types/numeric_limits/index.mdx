{/* source:cpp-types-numeric-limits:0001 */}
The `std::numeric_limits` class template provides a standardized way to query various properties of arithmetic types (e.g. the largest possible value for type `int` is `std::numeric_limits<int>::max()`).

{/* source:cpp-types-numeric-limits:0002 */}
This information is provided via specializations of the `std::numeric_limits` template. The [standard library](/docs/cpp/library/standard_library) makes available specializations for all arithmetic types (only lists the specializations for cv-unqualified arithmetic types):

{/* source:cpp-types-numeric-limits:0004 */}
The value of each member of a specialization of `std::numeric_limits` on a cv-qualified type *cv* `T` is equal to the value of the corresponding member of the specialization on the unqualified type `T`. For example, `std::numeric_limits<int>::digits` is equal to `std::numeric_limits<const int>::digits`.

{/* source:cpp-types-numeric-limits:0005 */}
Aliases of arithmetic types (such as [`std::size_t`](/docs/cpp/library/utility/types/size_t) or [`std::streamsize`](/docs/cpp/library/io/streamsize)) may also be examined with the `std::numeric_limits` type traits.

{/* source:cpp-types-numeric-limits:0006 */}
Non-arithmetic standard types, such as `std::complex<T>` or [`std::nullptr_t`](/docs/cpp/library/utility/types/nullptr_t), do not have specializations.

{/* source:cpp-types-numeric-limits:0007 */}
<Revision since="C++20">

If the implementation defines any [integer-class types](/docs/cpp/library/iterator/weakly_incrementable#Integer-like_types), specializations of `std::numeric_limits` must also be provided for them.

</Revision>

{/* source:cpp-types-numeric-limits:0008 */}
Implementations may provide specializations of `std::numeric_limits` for implementation-specific types: e.g. GCC provides `std::numeric_limits<__int128>`. Non-standard libraries may [add specializations](/docs/cpp/language/extending_std) for library-provided types, e.g. [OpenEXR](http://openexr.com/) provides `std::numeric_limits<half>` for a 16-bit floating-point type.
