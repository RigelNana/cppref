Specifies the current rounding direction of floating-point arithmetic operations.

{/* source:cpp-types-climits-flt-rounds:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>Value</DescriptionTerm>
    <DescriptionBody>Explanation</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`-1`</DescriptionTerm>
    <DescriptionBody>the default rounding direction is not known</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`0`</DescriptionTerm>
    <DescriptionBody>toward zero; same meaning as [`FE_TOWARDZERO`](/docs/cpp/library/numeric/fenv/FE_round)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`1`</DescriptionTerm>
    <DescriptionBody>to nearest; same meaning as [`FE_TONEAREST`](/docs/cpp/library/numeric/fenv/FE_round)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`2`</DescriptionTerm>
    <DescriptionBody>towards positive infinity; same meaning as [`FE_UPWARD`](/docs/cpp/library/numeric/fenv/FE_round)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`3`</DescriptionTerm>
    <DescriptionBody>towards negative infinity; same meaning as [`FE_DOWNWARD`](/docs/cpp/library/numeric/fenv/FE_round)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>other values</DescriptionTerm>
    <DescriptionBody>implementation-defined behavior</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Notes

{/* source:cpp-types-climits-flt-rounds:0003 */}
The rounding mode can be changed with [`std::fesetround`](/docs/cpp/library/numeric/fenv/feround) and FLT_ROUNDS reflects that change.

{/* source:cpp-types-climits-flt-rounds:0004 */}
The possible values of FLT_ROUNDS match the possible values of [`std::float_round_style`](/docs/cpp/library/utility/types/numeric_limits/float_round_style), returned by [`std::numeric_limits::round_style`](/docs/cpp/library/utility/types/numeric_limits/round_style).
