{/* source:cpp-utility-rel-ops-operator-cmp:0001 */}
Given a user-defined `operator==` and `operator<` for objects of type `T`, implements the usual semantics of other comparison operators.

{/* source:cpp-utility-rel-ops-operator-cmp:0002 */}
1. 1) Implements `operator!=` in terms of `operator==`.

{/* source:cpp-utility-rel-ops-operator-cmp:0003 */}
2. 2) Implements `operator>` in terms of `operator<`.

{/* source:cpp-utility-rel-ops-operator-cmp:0004 */}
3. 3) Implements `operator<=` in terms of `operator<`.

{/* source:cpp-utility-rel-ops-operator-cmp:0005 */}
4. 4) Implements `operator>=` in terms of `operator<`.

### Parameters

{/* source:cpp-utility-rel-ops-operator-cmp:0006 */}
<ParameterList>
  <Parameter name="lhs">left-hand argument</Parameter>
  <Parameter name="rhs">right-hand argument</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-rel-ops-operator-cmp:0007 */}
1. 1) Returns `true` if `lhs` is not equal to `rhs`.

{/* source:cpp-utility-rel-ops-operator-cmp:0008 */}
2. 2) Returns `true` if `lhs` is greater than `rhs`.

{/* source:cpp-utility-rel-ops-operator-cmp:0009 */}
3. 3) Returns `true` if `lhs` is less or equal to `rhs`.

{/* source:cpp-utility-rel-ops-operator-cmp:0010 */}
4. 4) Returns `true` if `lhs` is greater or equal to `rhs`.

### Possible implementation

{/* source:cpp-utility-rel-ops-operator-cmp:0011 */}
[(1) `operator!=`](/docs/cpp/library/utility/rel_ops/operator_cmp#Version_1)

```cpp
namespace rel_ops
{
    template<class T>
    bool operator!=(const T& lhs, const T& rhs)
    {
        return !(lhs == rhs);
    }
}
```

[(2) `operator>`](/docs/cpp/library/utility/rel_ops/operator_cmp#Version_2)

```cpp
namespace rel_ops
{
    template<class T>
    bool operator>(const T& lhs, const T& rhs)
    {
        return rhs < lhs;
    }
}
```

[(3) `operator<=`](/docs/cpp/library/utility/rel_ops/operator_cmp#Version_3)

```cpp
namespace rel_ops
{
    template<class T>
    bool operator<=(const T& lhs, const T& rhs)
    {
        return !(rhs < lhs);
    }
}
```

[(4) `operator>=`](/docs/cpp/library/utility/rel_ops/operator_cmp#Version_4)

```cpp
namespace rel_ops
{
    template<class T>
    bool operator>=(const T& lhs, const T& rhs)
    {
        return !(lhs < rhs);
    }
}
```

### Notes

{/* source:cpp-utility-rel-ops-operator-cmp:0012 */}
[Boost.operators](https://www.boost.org/doc/libs/release/libs/utility/operators.htm) provides a more versatile alternative to `std::rel_ops`.

{/* source:cpp-utility-rel-ops-operator-cmp:0013 */}
As of C++20, `std::rel_ops` are deprecated in favor of [`operator<=>`](/docs/cpp/language/expressions/default_comparisons).

### Example

{/* source:cpp-utility-rel-ops-operator-cmp:0014 */}
```cpp
#include <iostream>
#include <utility>
 
struct Foo
{
    int n;
};
 
bool operator==(const Foo& lhs, const Foo& rhs)
{
    return lhs.n == rhs.n;
}
 
bool operator<(const Foo& lhs, const Foo& rhs)
{
    return lhs.n < rhs.n;
}
 
int main()
{
    Foo f1 = {1};
    Foo f2 = {2};
    using namespace std::rel_ops;
 
    std::cout << std::boolalpha
              << "{1} != {2} : " << (f1 != f2) << '\n'
              << "{1} >  {2} : " << (f1 >  f2) << '\n'
              << "{1} <= {2} : " << (f1 <= f2) << '\n'
              << "{1} >= {2} : " << (f1 >= f2) << '\n';
}
```

Output:

```text
{1} != {2} : true
{1} >  {2} : false
{1} <= {2} : true
{1} >= {2} : false
```
