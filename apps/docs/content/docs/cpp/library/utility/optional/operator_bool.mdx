{/* source:cpp-utility-optional-operator-bool:0001 */}
Checks whether `*this` contains a value.

### Parameters

{/* source:cpp-utility-optional-operator-bool:0002 */}
(none)

### Return value

{/* source:cpp-utility-optional-operator-bool:0003 */}
`true` if `*this` contains a value, `false` if `*this` does not contain a value.

### Example

{/* source:cpp-utility-optional-operator-bool:0004 */}
```cpp
#include <optional>
#include <iostream>
 
int main()
{
    std::cout << std::boolalpha;
 
    std::optional<int> opt;
    std::cout << opt.has_value() << '\n';
 
    opt = 43;
    if (opt)
        std::cout << "value set to " << opt.value() << '\n';
    else
        std::cout << "value not set\n";
 
    opt.reset();
    if (opt.has_value())
        std::cout << "value still set to " << opt.value() << '\n';
    else
        std::cout << "value no longer set\n";
}
```

Output:

```text
false
value set to 43
value no longer set
```
