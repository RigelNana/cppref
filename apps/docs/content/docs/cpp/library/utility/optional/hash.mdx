{/* source:cpp-utility-optional-hash:0001 */}
The template specialization of [`std::hash`](/docs/cpp/library/utility/hash) for the [`std::optional`](/docs/cpp/library/utility/optional) class allows users to obtain hashes of the values contained in optional objects.

{/* source:cpp-utility-optional-hash:0002 */}
The specialization `std::hash<std::optional<T>>` is enabled (see [`std::hash`](/docs/cpp/library/utility/hash)) if `std::hash<std::remove_const_t<T>>` is enabled, and is disabled otherwise.

{/* source:cpp-utility-optional-hash:0003 */}
When enabled, for an object `o` of type `std::optional<T>` that contains a value, `std::hash<std::optional<T>>()(o)` evaluates to the same value as `std::hash<std::remove_const_t<T>>()(*o)`. For an optional that does not contain a value, the hash is unspecified.

{/* source:cpp-utility-optional-hash:0004 */}
The member functions of this specialization are not guaranteed to be `noexcept` because the hash of the underlying type might throw.

### Template parameters

{/* source:cpp-utility-optional-hash:0005 */}
<ParameterList>
  <Parameter name="T">the type of the value contained in optional object</Parameter>
</ParameterList>

### Example

{/* source:cpp-utility-optional-hash:0006 */}
```cpp
#include <iostream>
#include <optional>
#include <string>
#include <unordered_set>
 
using namespace std::literals;
 
int main()
{
    using OptStr = std::optional<std::string>;
 
    // hash<optional> makes it possible to use unordered_set
    std::unordered_set<OptStr> s =
    {
        "ABC"s, "abc"s, std::nullopt, "def"s
    };
 
    for (const auto& o : s)
        std::cout << o.value_or("(null)") << '\t' << std::hash<OptStr>{}(o) << '\n';
}
```

Possible output:

```text
def     11697390762615875584
(null)  18446744073709548283
abc     3663726644998027833
ABC     11746482041453314842
```
