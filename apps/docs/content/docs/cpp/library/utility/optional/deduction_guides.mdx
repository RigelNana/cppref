One [deduction guide](/docs/cpp/language/templates/ctad) is provided for [`std::optional`](/docs/cpp/library/utility/optional) to account for the edge cases missed by the implicit deduction guides, in particular, non-copyable arguments and array to pointer conversion.

### Example

{/* source:cpp-utility-optional-deduction-guides:0002 */}
```cpp
#include <optional>
#include <type_traits>
 
int main()
{
    int a[2];
    std::optional oa{a}; // uses explicit deduction guide
    static_assert(std::is_same_v<decltype(oa), std::optional<int*>> == true);
}
```
