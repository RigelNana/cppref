{/* source:cpp-utility-optional-nullopt-t:0001 */}
`std::nullopt_t` is an empty class type used to indicate that an [`std::optional`](/docs/cpp/library/utility/optional) does not contain a value.

{/* source:cpp-utility-optional-nullopt-t:0002 */}
`std::nullopt_t` is a non-aggregate [*LiteralType*](/docs/cpp/library/named_req/LiteralType) that has no default constructor, no initializer-list constructor, but does have a `constexpr` constructor that takes an implementation-defined literal type.

### Notes

{/* source:cpp-utility-optional-nullopt-t:0003 */}
The constraints on `nullopt_t`'s constructors exist to support both `op = {};` and `op = nullopt;` as the syntax for disengaging an optional object.

{/* source:cpp-utility-optional-nullopt-t:0004 */}
A possible implementation of this class is

{/* source:cpp-utility-optional-nullopt-t:0005 */}
```cpp
struct nullopt_t {
    constexpr explicit nullopt_t(int) {}
};
```
