{/* source:cpp-utility-optional-value:0001 */}
If `*this` contains a value, returns a reference to the contained value.

{/* source:cpp-utility-optional-value:0002 */}
Otherwise, throws a [`std::bad_optional_access`](/docs/cpp/library/utility/optional/bad_optional_access) exception.

### Parameters

{/* source:cpp-utility-optional-value:0003 */}
(none)

### Return value

{/* source:cpp-utility-optional-value:0004 */}
A reference to the contained value.

### Exceptions

{/* source:cpp-utility-optional-value:0005 */}
[`std::bad_optional_access`](/docs/cpp/library/utility/optional/bad_optional_access) if `*this` does not contain a value.

### Notes

{/* source:cpp-utility-optional-value:0006 */}
The dereference operator [`operator*()`](/docs/cpp/library/utility/optional/operator_star_) does not check if this optional contains a value, which may be more efficient than `value()`.

### Example

{/* source:cpp-utility-optional-value:0007 */}
```cpp
#include <iostream>
#include <optional>
 
int main()
{
    std::optional<int> opt = {};
 
    try
    {
        [[maybe_unused]] int n = opt.value();
    }
    catch(const std::bad_optional_access& e)
    {
        std::cout << e.what() << '\n';
    }
 
    try
    {
        opt.value() = 42;
    }
    catch(const std::bad_optional_access& e)
    {
        std::cout << e.what() << '\n';
    }
 
    opt = 43;
    std::cout << *opt << '\n';
 
    opt.value() = 44;
    std::cout << opt.value() << '\n';
}
```

Output:

```text
bad optional access
bad optional access
43
44
```
