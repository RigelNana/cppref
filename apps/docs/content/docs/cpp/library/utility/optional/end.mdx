{/* source:cpp-utility-optional-end:0001 */}
Returns a past-the-end iterator. Equivalent to `return begin() + has_value();`.

### Parameters

{/* source:cpp-utility-optional-end:0002 */}
(none)

### Return value

{/* source:cpp-utility-optional-end:0003 */}
Past-the-end iterator

### Complexity

{/* source:cpp-utility-optional-end:0004 */}
Constant.

### Notes

{/* source:cpp-utility-optional-end:0005 */}

| --- | --- | --- | --- |
| [`__cpp_lib_optional_range_support`](/docs/cpp/library/feature_test#cpp_lib_optional_range_support) | [`202406L`](/docs/cpp/library/compiler_support/26#cpp_lib_optional_range_support_202406L) | (C++26) | Range support for `std::optional` |

### Example

{/* source:cpp-utility-optional-end:0006 */}
```cpp
#include <optional>
#include <print>
 
int main()
{
    constexpr std::optional<int> none = std::nullopt; // optional @1
    constexpr std::optional<int> some = 42;           // optional @2
 
    static_assert(none.begin() == none.end());
    static_assert(some.begin() != some.end());
 
    // ranged-for loop support
    for (int i : none)
        std::println("Optional @1 has a value of {}", i);
 
    for (int i : some)
        std::println("Optional @2 has a value of {}", i);
}
```

Output:

```text
Optional @2 has a value of 42
```
