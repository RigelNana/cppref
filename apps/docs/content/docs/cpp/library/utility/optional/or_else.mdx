{/* source:cpp-utility-optional-or-else:0001 */}
Returns `*this` if it contains a value. Otherwise, returns the result of `f`.

{/* source:cpp-utility-optional-or-else:0002 */}
The program is ill-formed if `std::remove_cvref_t<std::invoke_result_t<F>>` is not same as `std::optional<T>`.

{/* source:cpp-utility-optional-or-else:0003 */}
1. 1) Equivalent to `return *this ? *this : std::forward<F>(f)();`. This overload participates in overload resolution only if both `std::copy_constructible<T>` and `std::invocable<F>` are modeled.

{/* source:cpp-utility-optional-or-else:0004 */}
2. 2) Equivalent to `return *this ? std::move(*this) : std::forward<F>(f)();`. This overload participates in overload resolution only if both `std::move_constructible<T>` and `std::invocable<F>` are modeled.

### Parameters

{/* source:cpp-utility-optional-or-else:0005 */}
<ParameterList>
  <Parameter name="f">a function or [*Callable*](/docs/cpp/library/named_req/Callable) object that returns an `std::optional<T>`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-optional-or-else:0006 */}
`*this` or the result of `f`, as described above.

### Example

{/* source:cpp-utility-optional-or-else:0008 */}
```cpp
#include <iostream>
#include <optional>
#include <string>
 
int main()
{
    using maybe_int = std::optional<int>;
 
    auto valueless = []
    {
        std::cout << "Valueless: ";
        return maybe_int{0};
    };
 
    maybe_int x;
    std::cout << x.or_else(valueless).value() << '\n';
 
    x = 42;
    std::cout << "Has value: ";
    std::cout << x.or_else(valueless).value() << '\n';
 
    x.reset();
    std::cout << x.or_else(valueless).value() << '\n';
}
```

Output:

```text
Valueless: 0
Has value: 42
Valueless: 0
```
