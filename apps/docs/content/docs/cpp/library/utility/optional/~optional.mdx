{/* source:cpp-utility-optional-optional:0001 */}
If the object contains a value and the type `T` is not trivially destructible (see [`std::is_trivially_destructible`](/docs/cpp/library/meta/is_destructible)), destroys the contained value by calling its destructor, as if by `value().T::~T()`.

{/* source:cpp-utility-optional-optional:0002 */}
Otherwise, does nothing.

### Notes

{/* source:cpp-utility-optional-optional:0003 */}
If `T` is trivially-destructible, then this destructor is also trivial, so `std::optional<T>` is also trivially-destructible.
