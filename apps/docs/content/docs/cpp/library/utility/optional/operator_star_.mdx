{/* source:cpp-utility-optional-operator-star:0001 */}
Accesses the contained value.

{/* source:cpp-utility-optional-operator-star:0002 */}
1. 1) Returns a pointer to the contained value.

{/* source:cpp-utility-optional-operator-star:0003 */}
2. 2) Returns a reference to the contained value.

{/* source:cpp-utility-optional-operator-star:0004 */}
The behavior is undefined if `*this` does not contain a value.

### Parameters

{/* source:cpp-utility-optional-operator-star:0005 */}
(none)

### Return value

{/* source:cpp-utility-optional-operator-star:0006 */}
Pointer or reference to the contained value.

### Notes

{/* source:cpp-utility-optional-operator-star:0007 */}
This operator does not check whether the optional contains a value! You can do so manually by using [`has_value()`](/docs/cpp/library/utility/optional/operator_bool) or simply [`operator bool()`](/docs/cpp/library/utility/optional/operator_bool). Alternatively, if checked access is needed, [`value()`](/docs/cpp/library/utility/optional/value) or [`value_or()`](/docs/cpp/library/utility/optional/value_or) may be used.

### Example

{/* source:cpp-utility-optional-operator-star:0008 */}
```cpp
#include <iomanip>
#include <iostream>
#include <optional>
#include <string>
 
int main()
{
    using namespace std::string_literals;
 
    std::optional<int> opt1 = 1;
    std::cout << "opt1: " << *opt1 << '\n';
 
    *opt1 = 2;
    std::cout << "opt1: " << *opt1 << '\n';
 
    std::optional<std::string> opt2 = "abc"s;
    std::cout << "opt2: " << std::quoted(*opt2) << ", size: " << opt2->size() << '\n';
 
    // You can "take" the contained value by calling operator* on an rvalue to optional
 
    auto taken = *std::move(opt2);
    std::cout << "taken: " << std::quoted(taken) << "\n"
                 "opt2: " << std::quoted(*opt2) << ", size: " << opt2->size()  << '\n';
}
```

Output:

```text
opt1: 1
opt1: 2
opt2: "abc", size: 3
taken: "abc"
opt2: "", size: 0
```
