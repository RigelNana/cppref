{/* source:cpp-utility-optional:0001 */}
The class template `std::optional` manages an optional contained value, i.e. a value that may or may not be present.

{/* source:cpp-utility-optional:0002 */}
A common use case for `optional` is the return value of a function that may fail. As opposed to other approaches, such as `std::pair<T, bool>`, `optional` handles expensive-to-construct objects well and is more readable, as the intent is expressed explicitly.

{/* source:cpp-utility-optional:0003 */}
Any instance of `optional<T>` at any given point in time either contains a value or does not contain a value.

{/* source:cpp-utility-optional:0004 */}
If an `optional<T>` contains a value, the value is guaranteed to be [nested within](/docs/cpp/language/basic_concepts/objects#Address) the optional object, which means that no dynamic memory allocation ever takes place. Thus, an optional object models an object, not a pointer, even though [`operator*()`](/docs/cpp/library/utility/optional/operator_star_) and [`operator->()`](/docs/cpp/library/utility/optional/operator_star_) are defined.

{/* source:cpp-utility-optional:0005 */}
When an object of type `optional<T>` is [contextually converted to bool](/docs/cpp/language/expressions/implicit_cast#Contextual_conversions), the conversion returns `true` if the object contains a value and `false` if it does not contain a value.

{/* source:cpp-utility-optional:0006 */}
The optional object contains a value in the following conditions:

{/* source:cpp-utility-optional:0007 */}
- The object is initialized with/assigned from a value of type `T` or another `optional` that contains a value.

{/* source:cpp-utility-optional:0008 */}
The object does not contain a value in the following conditions:

{/* source:cpp-utility-optional:0009 */}
- The object is default-initialized.
- The object is initialized with/assigned from a value of type [`std::nullopt_t`](/docs/cpp/library/utility/optional/nullopt_t) or an `optional` object that does not contain a value.
- The member function [`reset()`](/docs/cpp/library/utility/optional/reset) is called.

{/* source:cpp-utility-optional:0010 */}
<Revision since="C++26">
The optional object is a [view](/docs/cpp/library/ranges/view) that contains either one element if it contains a value, or otherwise zero elements if it does not contain a value. The lifetime of the contained element is bound to the object.
</Revision>

{/* source:cpp-utility-optional:0011 */}
There are no optional references, functions, arrays, or cv `void`; a program is ill-formed if it instantiates an optional with such a type. In addition, a program is ill-formed if it instantiates an optional with the (possibly cv-qualified) tag types [`std::nullopt_t`](/docs/cpp/library/utility/optional/nullopt_t) or [`std::in_place_t`](/docs/cpp/library/utility/in_place).

### Example

{/* source:cpp-utility-optional:0024 */}
```cpp
#include <iostream>
#include <optional>
#include <string>
 
// optional can be used as the return type of a factory that may fail
std::optional<std::string> create(bool b)
{
    if (b)
        return "Godzilla";
    return {};
}
 
// std::nullopt can be used to create any (empty) std::optional
auto create2(bool b)
{
    return b ? std::optional<std::string>{"Godzilla"} : std::nullopt;
}
 
int main()
{
    std::cout << "create(false) returned "
              << create(false).value_or("empty") << '\n';
 
    // optional-returning factory functions are usable as conditions of while and if
    if (auto str = create2(true))
        std::cout << "create2(true) returned " << *str << '\n';
}
```

Output:

```text
create(false) returned empty
create2(true) returned Godzilla
```
