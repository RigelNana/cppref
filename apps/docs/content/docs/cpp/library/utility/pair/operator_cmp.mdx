{/* source:cpp-utility-pair-operator-cmp:0001 */}
1,2) Tests if both elements of `lhs` and `rhs` are equal, that is, compares `lhs.first` with `rhs.first` and `lhs.second` with `rhs.second`.

<Revision until="C++26">
The behavior is undefined if the type and value category of either `lhs.first == rhs.first` or `lhs.second == rhs.second` do not meet the [BooleanTestable](/docs/cpp/library/named_req/BooleanTestable) requirements.
</Revision>

<Revision since="C++26">
This overload participates in overload resolution only if both `decltype(lhs.first == rhs.first)` and `decltype(lhs.second == rhs.second)` model [*boolean-testable*](/docs/cpp/library/concepts/boolean-testable).
</Revision>

{/* source:cpp-utility-pair-operator-cmp:0002 */}
3-6) Compares `lhs` and `rhs` lexicographically by `operator<`, that is, compares the first elements and only if they are equivalent, compares the second elements. The behavior is undefined if the type and value category of any of `lhs.first < rhs.first`, `rhs.first < lhs.first`, or `lhs.second < rhs.second` do not meet the [BooleanTestable](/docs/cpp/library/named_req/BooleanTestable) requirements.

{/* source:cpp-utility-pair-operator-cmp:0003 */}
7) Compares `lhs` and `rhs` lexicographically by [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way), that is, compares the first elements and only if they are equivalent, compares the second elements. [*synth-three-way-result*](/docs/cpp/library/standard_library/synth-three-way) is the return type of *synth-three-way*.

{/* source:cpp-utility-pair-operator-cmp:0004 */}
<Revision since="C++20">
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Return value

{/* source:cpp-utility-pair-operator-cmp:0006 */}
1) `true` if both `lhs.first == rhs.first` and `lhs.second == rhs.second`, otherwise `false`.

{/* source:cpp-utility-pair-operator-cmp:0007 */}
2) `!(lhs == rhs)`

{/* source:cpp-utility-pair-operator-cmp:0008 */}
3) If `lhs.first < rhs.first`, returns `true`. Otherwise, if `rhs.first < lhs.first`, returns `false`. Otherwise, if `lhs.second < rhs.second`, returns `true`. Otherwise, returns `false`.

{/* source:cpp-utility-pair-operator-cmp:0009 */}
4) `!(rhs < lhs)`

{/* source:cpp-utility-pair-operator-cmp:0010 */}
5) `rhs < lhs`

{/* source:cpp-utility-pair-operator-cmp:0011 */}
6) `!(lhs < rhs)`

{/* source:cpp-utility-pair-operator-cmp:0012 */}
7) [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way)(`lhs.first`, `rhs.first`) if it is not equal to `0`, otherwise [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way)(`lhs.second`, `rhs.second`).

### Notes

{/* source:cpp-utility-pair-operator-cmp:0013 */}
<Revision until="C++20">
The relational operators are defined in terms of each element's `operator<`.
</Revision>

<Revision since="C++20">
The relational operators are defined in terms of [*synth-three-way*](/docs/cpp/library/standard_library/synth-three-way), which uses `operator<=>` if possible, or `operator<` otherwise.

Notably, if an element type does not itself provide `operator<=>`, but is implicitly convertible to a three-way comparable type, that conversion will be used instead of `operator<`.
</Revision>

### Example

{/* source:cpp-utility-pair-operator-cmp:0015 */}
Because `operator<` is defined for pairs, containers of pairs can be sorted.

```cpp
#include <algorithm>
#include <iomanip>
#include <iostream>
#include <string>
#include <utility>
#include <vector>
 
int main()
{
    std::vector<std::pair<int, std::string>> v = {{2, "baz"}, {2, "bar"}, {1, "foo"}};
    std::sort(v.begin(), v.end());
 
    for (auto p : v)
        std::cout << '{' << p.first << ", " << std::quoted(p.second) << "}\n";
}
```

Output:

```text
{1, "foo"}
{2, "bar"}
{2, "baz"}
```
