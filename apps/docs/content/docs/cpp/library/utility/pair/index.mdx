{/* source:cpp-utility-pair:0001 */}
`std::pair` is a class template that provides a way to store two heterogeneous objects as a single unit. A pair is a specific case of a [`std::tuple`](/docs/cpp/library/utility/tuple) with two elements.

{/* source:cpp-utility-pair:0002 */}
If neither `T1` nor `T2` is a possibly cv-qualified class type with non-trivial destructor, or array thereof, the destructor of `pair` is trivial.
