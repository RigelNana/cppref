One [deduction guide](/docs/cpp/language/templates/ctad) is provided for [`std::pair`](/docs/cpp/library/utility/pair) to account for the edge cases missed by the implicit deduction guides, in particular, non-copyable arguments and array to pointer conversion.

### Example

{/* source:cpp-utility-pair-deduction-guides:0002 */}
```cpp
#include <utility>
 
int main()
{
    int a[2], b[3];
    std::pair p{a, b}; // explicit deduction guide is used in this case
}
```
