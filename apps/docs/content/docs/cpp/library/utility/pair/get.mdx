{/* source:cpp-utility-pair-get:0001 */}
Extracts an element from the pair using [tuple-like](/docs/cpp/library/utility/tuple/tuple-like) interface.

{/* source:cpp-utility-pair-get:0002 */}
1-4) The index-based overloads fail to compile if the index `I` is neither `0` nor `1`.

{/* source:cpp-utility-pair-get:0003 */}
5-12) The type-based overloads fail to compile if the types `T` and `U` are the same.

### Parameters

{/* source:cpp-utility-pair-get:0004 */}
<ParameterList>
  <Parameter name="p">pair whose contents to extract</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-pair-get:0005 */}
1-4) Returns a reference to `p.first` if `I == 0` and a reference to `p.second` if `I == 1`.

{/* source:cpp-utility-pair-get:0006 */}
5-8) Returns a reference to `p.first`.

{/* source:cpp-utility-pair-get:0007 */}
9-12) Returns a reference to `p.second`.

### Example

{/* source:cpp-utility-pair-get:0008 */}
```cpp
#include <iostream>
#include <utility>
 
int main()
{
    auto p = std::make_pair(1, 3.14);
    std::cout << '(' << std::get<0>(p) << ", " << std::get<1>(p) << ")\n";
    std::cout << '(' << std::get<int>(p) << ", " << std::get<double>(p) << ")\n";
}
```

Output:

```text
(1, 3.14)
(1, 3.14)
```
