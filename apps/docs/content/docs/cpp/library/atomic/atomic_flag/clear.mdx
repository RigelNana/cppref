{/* source:cpp-atomic-atomic-flag-clear:0001 */}
Atomically changes the state of a [`std::atomic_flag`](/docs/cpp/library/atomic/atomic_flag) to clear (`false`).

{/* source:cpp-atomic-atomic-flag-clear:0002 */}
If `order` is one of `std::memory_order_consume`, `std::memory_order_acquire` and `std::memory_order_acq_rel`, the behavior is undefined.
