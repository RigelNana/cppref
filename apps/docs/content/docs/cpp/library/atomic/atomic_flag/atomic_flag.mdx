    <Revision until="C++20">

    1. Initializes `std::atomic_flag` to clear state.
    </Revision>

    {/* source:cpp-atomic-atomic-flag-atomic-flag:0003 */}
    2. The copy constructor is deleted; `std::atomic_flag` is not copyable.
  </DeclarationDescription>

{/* source:cpp-atomic-atomic-flag-atomic-flag:0004 */}
In addition, `std::atomic_flag` can be value-initialized to clear state with the expression [`ATOMIC_FLAG_INIT`](/docs/cpp/library/atomic/ATOMIC_FLAG_INIT). For an `atomic_flag` with static [storage duration](/docs/cpp/language/declarations/storage_duration#Storage_duration), this guarantees [static initialization](/docs/cpp/language/initialization#Static_initialization): the flag can be used in constructors of static objects.
