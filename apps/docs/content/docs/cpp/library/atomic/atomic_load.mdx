                        std::memory_order order ) noexcept;`} />

T atomic_load_explicit( const volatile std::atomic<T>* obj,

                        std::memory_order order ) noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-atomic-atomic-load:0001 */}
    1,2) Atomically obtains the value pointed to by `obj` as if by `obj->load()`.

    {/* source:cpp-atomic-atomic-load:0002 */}
    3,4) Atomically obtains the value pointed to by `obj` as if by `obj->load(order)`.

    {/* source:cpp-atomic-atomic-load:0003 */}
    If `order` is one of `std::memory_order_release` and `std::memory_order_acq_rel`, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-atomic-atomic-load:0004 */}
<ParameterList>
  <Parameter name="obj">pointer to the atomic object to modify</Parameter>
  <Parameter name="order">the memory synchronization ordering for this operation</Parameter>
</ParameterList>

### Return value

{/* source:cpp-atomic-atomic-load:0005 */}
The value that is held by the atomic object pointed to by `obj`.
