{/* source:cpp-atomic-atomic-fetch-xor:0001 */}
Atomically replaces the value pointed by `obj` with the result of bitwise XOR between the old value of `obj` and `arg`. Returns the value `obj` held previously.

{/* source:cpp-atomic-atomic-fetch-xor:0002 */}
The operation is performed as if the following is executed:

{/* source:cpp-atomic-atomic-fetch-xor:0003 */}
1,2) `obj->fetch_xor(arg)`

{/* source:cpp-atomic-atomic-fetch-xor:0004 */}
3,4) `obj->fetch_xor(arg, order)`

{/* source:cpp-atomic-atomic-fetch-xor:0005 */}
If `std::atomic<T>` has no `fetch_xor` member (this member is only provided for [integral types](/docs/cpp/library/atomic/atomic#Specializations_for_integral_types) except `bool`), the program is ill-formed.

### Parameters

{/* source:cpp-atomic-atomic-fetch-xor:0006 */}
<ParameterList>
  <Parameter name="obj">pointer to the atomic object to modify</Parameter>
  <Parameter name="arg">the value to bitwise XOR to the value stored in the atomic object</Parameter>
  <Parameter name="order">the memory synchronization ordering</Parameter>
</ParameterList>

### Return value

{/* source:cpp-atomic-atomic-fetch-xor:0007 */}
The value immediately preceding the effects of this function in the [modification order](/docs/cpp/library/atomic/memory_order#Modification_order) of `*obj`.
