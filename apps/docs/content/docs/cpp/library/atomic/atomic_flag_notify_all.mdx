{/* source:cpp-atomic-atomic-flag-notify-all:0001 */}
Performs atomic notifying operations.

{/* source:cpp-atomic-atomic-flag-notify-all:0002 */}
Unblocks all threads blocked in atomic waiting operations (i.e. [`std::atomic_flag_wait()`](/docs/cpp/library/atomic/atomic_flag_wait), [`std::atomic_flag_wait_explicit()`](/docs/cpp/library/atomic/atomic_flag_wait), or [`std::atomic_flag::wait()`](/docs/cpp/library/atomic/atomic_flag/wait)) on `*object`, if there are any; otherwise does nothing.

{/* source:cpp-atomic-atomic-flag-notify-all:0003 */}
Equivalent to `object->notify_all()`.

### Parameters

{/* source:cpp-atomic-atomic-flag-notify-all:0004 */}
<ParameterList>
  <Parameter name="object">pointer to the `atomic_flag` object to notify</Parameter>
</ParameterList>

### Return value

{/* source:cpp-atomic-atomic-flag-notify-all:0005 */}
(none)

### Notes

{/* source:cpp-atomic-atomic-flag-notify-all:0006 */}
This form of change-detection is often more efficient than simple polling or pure spinlocks.
