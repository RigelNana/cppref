{/* source:cpp-atomic-atomic-init:0001 */}
Initializes the default-constructed atomic object `obj` with the value `desired`. The function is not atomic: concurrent access from another thread, even through an atomic operation, is a data race.

{/* source:cpp-atomic-atomic-init:0002 */}
If `obj` was not default-constructed, or this function is called twice on the same `obj`, the behavior is undefined.

### Parameters

{/* source:cpp-atomic-atomic-init:0003 */}
<ParameterList>
  <Parameter name="obj">pointer to an atomic object to initialize</Parameter>
  <Parameter name="desired">the value to initialize atomic object with</Parameter>
</ParameterList>

### Return value

{/* source:cpp-atomic-atomic-init:0004 */}
(none)

### Notes

{/* source:cpp-atomic-atomic-init:0005 */}
This function is provided for compatibility with C. If the compatibility is not required, [`std::atomic`](/docs/cpp/library/atomic/atomic) may be initialized through their non-default constructors.
