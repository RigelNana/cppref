{/* source:cpp-atomic-atomic-notify-one:0001 */}
Performs atomic notifying operations.

{/* source:cpp-atomic-atomic-notify-one:0002 */}
If there is a thread blocked in atomic waiting operation (i.e. [`std::atomic_wait()`](/docs/cpp/library/atomic/atomic_wait), [`std::atomic_wait_explicit()`](/docs/cpp/library/atomic/atomic_wait), or [`std::atomic::wait()`](/docs/cpp/library/atomic/atomic/wait)) on `*object`, then unblocks at least one such thread; otherwise does nothing.

{/* source:cpp-atomic-atomic-notify-one:0003 */}
Equivalent to `object->notify_one()`.

{/* source:cpp-atomic-atomic-notify-one:0004 */}
<ParameterList>
  <Parameter name="object">pointer to the atomic object to notify</Parameter>

### Return value

{/* source:cpp-atomic-atomic-notify-one:0005 */}
(none)

### Notes

{/* source:cpp-atomic-atomic-notify-one:0006 */}
This form of change-detection is often more efficient than simple polling or pure spinlocks.
