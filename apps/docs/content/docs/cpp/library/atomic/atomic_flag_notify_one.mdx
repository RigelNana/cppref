{/* source:cpp-atomic-atomic-flag-notify-one:0001 */}
Performs atomic notifying operations.

{/* source:cpp-atomic-atomic-flag-notify-one:0002 */}
If there is a thread blocked in an atomic waiting operation (i.e. [`std::atomic_flag_wait()`](/docs/cpp/library/atomic/atomic_flag_wait), [`std::atomic_flag_wait_explicit()`](/docs/cpp/library/atomic/atomic_flag_wait), or [`std::atomic_flag::wait()`](/docs/cpp/library/atomic/atomic_flag/wait)) on `*object`, then unblocks at least one such thread; otherwise does nothing.

{/* source:cpp-atomic-atomic-flag-notify-one:0003 */}
Equivalent to `object->notify_one()`.

### Return value

{/* source:cpp-atomic-atomic-flag-notify-one:0005 */}
(none)

### Notes

{/* source:cpp-atomic-atomic-flag-notify-one:0006 */}
This form of change-detection is often more efficient than simple polling or pure spinlocks.
