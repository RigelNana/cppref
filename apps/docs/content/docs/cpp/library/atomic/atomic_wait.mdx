{/* source:cpp-atomic-atomic-wait:0001 */}
Performs atomic waiting operations. Behaves as if it repeatedly performs the following steps:

{/* source:cpp-atomic-atomic-wait:0002 */}
- Compare the [value representation](/docs/cpp/language/basic_concepts/objects) of `object->load()` (for overloads (1,2)) or `object->load(order)` (for overloads (3,4)) with that of `old`. If those are bitwise equal, then blocks until `*object` is notified by `std::atomic::notify_one()` or `std::atomic::notify_all()`, or the thread is unblocked spuriously. Otherwise, returns.

{/* source:cpp-atomic-atomic-wait:0003 */}
These functions are guaranteed to return only if `value` has changed, even if the underlying implementation unblocks spuriously.

{/* source:cpp-atomic-atomic-wait:0004 */}
1,2) Equivalent to `object->wait(old)`.

{/* source:cpp-atomic-atomic-wait:0005 */}
3,4) Equivalent to `object->wait(old, order)`.

{/* source:cpp-atomic-atomic-wait:0006 */}
If `order` is one of `std::memory_order::release` and `std::memory_order::acq_rel`, the behavior is undefined.

### Parameters

{/* source:cpp-atomic-atomic-wait:0007 */}
<ParameterList>
  <Parameter name="object">pointer to the atomic object to check and wait on</Parameter>
  <Parameter name="old">the value to check the atomic object no longer contains</Parameter>
  <Parameter name="order">the memory synchronization ordering</Parameter>
</ParameterList>

### Return value

{/* source:cpp-atomic-atomic-wait:0008 */}
(none)

### Notes

{/* source:cpp-atomic-atomic-wait:0009 */}
This form of change-detection is often more efficient than simple polling or pure spinlocks.

{/* source:cpp-atomic-atomic-wait:0010 */}
Due to the [ABA problem](https://en.wikipedia.org/wiki/ABA_problem), transient changes from `old` to another value and back to `old` might be missed, and not unblock.

{/* source:cpp-atomic-atomic-wait:0011 */}
The comparison is bitwise (similar to [`std::memcmp`](/docs/cpp/library/text/byte/memcmp)); no comparison operator is used. Padding bits that never participate in an object's value representation are ignored.
