{/* source:cpp-atomic-atomic-operator:0001 */}
1,2) Atomically assigns `desired` to the atomic variable. Equivalent to `store(desired)`.

<Revision since="C++20">
It is deprecated if `std::atomic<T>::is_always_lock_free` is `false` and overload (2) participates in overload resolution.
</Revision>

{/* source:cpp-atomic-atomic-operator:0002 */}
3,4) Atomic variables are not [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable).

### Parameters

{/* source:cpp-atomic-atomic-operator:0003 */}
<ParameterList>
  <Parameter name="desired">value to assign</Parameter>
</ParameterList>

### Return value

{/* source:cpp-atomic-atomic-operator:0004 */}
1,2) `desired`

### Notes

{/* source:cpp-atomic-atomic-operator:0005 */}
Unlike most assignment operators, the assignment operators for atomic types do not return a reference to their left-hand arguments. They return a copy of the stored value instead.
