{/* source:cpp-atomic-atomic-is-always-lock-free:0001 */}
Equals `true` if this atomic type is always lock-free and `false` if it is never or sometimes lock-free.

{/* source:cpp-atomic-atomic-is-always-lock-free:0002 */}
The value of this constant is consistent with both the macro `ATOMIC_xxx_LOCK_FREE`, where defined, with the member function [`is_lock_free`](/docs/cpp/library/atomic/atomic/is_lock_free) and non-member function [`std::atomic_is_lock_free`](/docs/cpp/library/atomic/atomic_is_lock_free).

### Notes

{/* source:cpp-atomic-atomic-is-always-lock-free:0003 */}
There is no non-member function equivalent of this static member constant because non-member functions take pointers to atomic types, and therefore aren't as useful in [constant expressions](/docs/cpp/language/expressions/constant_expression).
