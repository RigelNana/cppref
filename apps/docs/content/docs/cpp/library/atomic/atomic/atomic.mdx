  <DeclarationDescription>
    {/* source:cpp-atomic-atomic-atomic:0001 */}
    Constructs a new atomic variable.

    {/* source:cpp-atomic-atomic-atomic:0002 */}
    <Revision until="C++20">
    1. The default constructor is trivial: no initialization takes place other than [zero initialization](/docs/cpp/language/initialization/zero_initialization) of static and thread-local objects. [`std::atomic_init`](/docs/cpp/library/atomic/atomic_init) may be used to complete initialization.
    </Revision>
    <Revision since="C++20">
    1. Value-initializes the underlying object (i.e. with `T()`). The initialization is not atomic. This overload participates in overload resolution only if `std::is_default_constructible_v<T>` is `true`.
    </Revision>

    {/* source:cpp-atomic-atomic-atomic:0003 */}
    2. Initializes the underlying object with `desired`. The initialization is not atomic.

    {/* source:cpp-atomic-atomic-atomic:0004 */}
    3. Atomic variables are not [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible).
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-atomic-atomic-atomic:0006 */}
<Revision until="C++20">
The default-initialized `std::atomic<T>` does not contain a `T` object, and its only valid uses are destruction and initialization by [`std::atomic_init`](/docs/cpp/library/atomic/atomic_init), see [LWG issue 2334](https://cplusplus.github.io/LWG/issue2334).
</Revision>
