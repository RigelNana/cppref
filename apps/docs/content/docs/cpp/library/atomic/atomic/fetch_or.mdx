{/* source:cpp-atomic-atomic-fetch-or:0001 */}
Atomically replaces the current value with the result of bitwise OR of the value and `arg`. The operation is read-modify-write operation. Memory is affected according to the value of `order`.

{/* source:cpp-atomic-atomic-fetch-or:0002 */}
<Revision since="C++20">
It is deprecated if `std::atomic<T>::is_always_lock_free` is `false` and overload (2) participates in overload resolution.
</Revision>

### Parameters

{/* source:cpp-atomic-atomic-fetch-or:0003 */}
<ParameterList>
  <Parameter name="arg">the other argument of bitwise OR</Parameter>
  <Parameter name="order">memory order constraints to enforce</Parameter>
</ParameterList>

### Return value

{/* source:cpp-atomic-atomic-fetch-or:0004 */}
The value immediately preceding the effects of this function in the [modification order](/docs/cpp/library/atomic/memory_order) of `*this`.
