{/* source:cpp-atomic-atomic-notify-all:0001 */}
Performs atomic notifying operations.

{/* source:cpp-atomic-atomic-notify-all:0002 */}
Unblocks all threads blocked in atomic waiting operations (i.e. `wait()`) on `*this`, if there are any; otherwise does nothing.

### Notes

{/* source:cpp-atomic-atomic-notify-all:0003 */}
This form of change-detection is often more efficient than simple polling or pure spinlocks.
