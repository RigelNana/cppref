<DeclarationDoc>
Defined in header [`<atomic>`](/docs/cpp/library/headers/atomic)

  <Declaration language="cpp" since="C++11" code={`#define ATOMIC_FLAG_INIT /* implementation-defined */`} />
</DeclarationDoc>

{/* source:cpp-atomic-atomic-flag-init:0001 */}
Defines the initializer which can be used to initialize [`std::atomic_flag`](/docs/cpp/library/atomic/atomic_flag) to clear (false) state in the form `std::atomic_flag v = ATOMIC_FLAG_INIT;`. It is unspecified if it can be used with other initialization contexts.

{/* source:cpp-atomic-atomic-flag-init:0002 */}
If the flag has is a [complete object](/docs/cpp/language/basic_concepts/objects#Subobjects) with [static storage duration](/docs/cpp/language/declarations/storage_duration#Static_storage_duration), this [initialization is static](/docs/cpp/language/initialization#Static_initialization).

{/* source:cpp-atomic-atomic-flag-init:0003 */}
<Revision until="C++20">
This is the only way to initialize [`std::atomic_flag`](/docs/cpp/library/atomic/atomic_flag) to a definite value: the value held after any other initialization is unspecified.
</Revision>
<Revision since="C++20">
This macro is no longer needed since default constructor of [`std::atomic_flag`](/docs/cpp/library/atomic/atomic_flag) initializes it to clear state. It is kept for the compatibility with C.
</Revision>

### Example

{/* source:cpp-atomic-atomic-flag-init:0004 */}
```cpp
#include <atomic>

std::atomic_flag static_flag = ATOMIC_FLAG_INIT; // static initialization,
// guaranteed to be available during dynamic initialization of static objects.

int main()
{
    std::atomic_flag automatic_flag = ATOMIC_FLAG_INIT; // guaranteed to work
//    std::atomic_flag another_flag(ATOMIC_FLAG_INIT); // unspecified
}
```
