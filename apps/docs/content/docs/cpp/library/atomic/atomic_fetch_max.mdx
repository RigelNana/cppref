{/* source:cpp-atomic-atomic-fetch-max:0001 */}
Atomically replaces the value pointed by `obj` with the result of [`std::max`](/docs/cpp/library/algorithm/max) between the old value of `obj` and `arg`. Returns the value `obj` held previously. The operation is performed as if the following was executed:

{/* source:cpp-atomic-atomic-fetch-max:0002 */}
1,2) `obj->fetch_max(arg)`

{/* source:cpp-atomic-atomic-fetch-max:0003 */}
3,4) `obj->fetch_max(arg, order)`

{/* source:cpp-atomic-atomic-fetch-max:0004 */}
If `std::atomic<T>` has no `fetch_max` member (this member is only provided for [integral](/docs/cpp/library/atomic/atomic#Specializations_for_integral_types) and [pointer](/docs/cpp/library/atomic/atomic#Partial_specializations) types except `bool`), the program is ill-formed.

### Parameters

{/* source:cpp-atomic-atomic-fetch-max:0005 */}
<ParameterList>
  <Parameter name="obj">pointer to the atomic object to modify</Parameter>
  <Parameter name="arg">the value to [`std::max`](/docs/cpp/library/algorithm/max) with the value stored in the atomic object</Parameter>
  <Parameter name="order">the memory synchronization ordering</Parameter>
</ParameterList>

### Return value

{/* source:cpp-atomic-atomic-fetch-max:0006 */}
The value immediately preceding the effects of this function in the [modification order](/docs/cpp/library/atomic/memory_order#Modification_order) of `*obj`.
