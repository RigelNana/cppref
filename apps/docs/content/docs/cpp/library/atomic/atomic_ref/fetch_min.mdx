Provided only when `T` is an integral type other than *cv* `bool` or a pointer-to-object type
  <Declaration language="cpp" since="C++26" code={`value_type fetch_min( value_type arg,
                      std::memory_order order =
                          std::memory_order_seq_cst ) const noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-atomic-atomic-ref-fetch-min:0001 */}
    Atomically replaces the current value of the referenced object with the result of [`std::min`](/docs/cpp/library/algorithm/min) of the value and `arg`. That is, it performs atomic minimum operation. The operation is a read-modify-write operation. Memory is affected according to the value of `order`.

    {/* source:cpp-atomic-atomic-ref-fetch-min:0002 */}
    If `T` is a pointer type and the pointers point to different complete objects (or subobjects thereof), [pointer comparison](/docs/cpp/language/expressions/operator_comparison#Built-in_pointer_relational_comparison) does not establish a [strict weak ordering](https://en.wikipedia.org/wiki/strict_weak_ordering).

    {/* source:cpp-atomic-atomic-ref-fetch-min:0003 */}
    This overload participates in overload resolution only if `std::is_const_v<T>` is `false`.
  </DeclarationDescription>
</DeclarationDoc>
