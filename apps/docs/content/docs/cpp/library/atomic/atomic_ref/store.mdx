<DeclarationDoc>
  <Declaration language="cpp" code={`void store( value_type desired,
            std::memory_order order =
                std::memory_order_seq_cst ) const noexcept;`} /> (constexpr since C++26)

  <DeclarationDescription>
    {/* source:cpp-atomic-atomic-ref-store:0001 */}
    Atomically replaces the current value of the referenced object with `desired`. Memory is affected according to the value of `order`.

    {/* source:cpp-atomic-atomic-ref-store:0002 */}
    This overload participates in overload resolution only if `std::is_const_v<T>` is `false`.

    {/* source:cpp-atomic-atomic-ref-store:0003 */}
    If `order` is not `std::memory_order_relaxed`, `std::memory_order_release` or `std::memory_order_seq_cst`, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>


### Parameters


{/* source:cpp-atomic-atomic-ref-store:0004 */}
<ParameterList>
  <Parameter name="desired">the value to store into the referenced object</Parameter>
  <Parameter name="order">memory order constraints to enforce</Parameter>
</ParameterList>
