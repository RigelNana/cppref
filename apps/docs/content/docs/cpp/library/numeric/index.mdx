{/* source:cpp-numeric:0000 */}
The C++ numerics library includes common mathematical functions and types, as well as optimized numeric arrays and support for random number generation.

{/* source:cpp-numeric:0001 */}
The header [`<cmath>`](/docs/cpp/library/headers/cmath) provides [standard C library mathematical functions](/docs/cpp/library/numeric/math) such as [`std::fabs`](/docs/cpp/library/numeric/math/fabs), [`std::sqrt`](/docs/cpp/library/numeric/math/sqrt), and [`std::sin`](/docs/cpp/library/numeric/math/sin).

{/* source:cpp-numeric:0002 */}
The header [`<cmath>`](/docs/cpp/library/headers/cmath) also provides several mathematical special functions such as [`std::beta`](/docs/cpp/library/numeric/special_functions/beta), [`std::hermite`](/docs/cpp/library/numeric/special_functions/hermite), and [`std::cyl_bessel_i`](/docs/cpp/library/numeric/special_functions/cyl_bessel_i).

{/* source:cpp-numeric:0003 */}
The header [`<numbers>`](/docs/cpp/library/headers/numbers) provides several mathematical constants, such as [`std::numbers::pi`](/docs/cpp/library/numeric/constants) or [`std::numbers::sqrt2`](/docs/cpp/library/numeric/constants)

{/* source:cpp-numeric:0004 */}
The header [`<linalg>`](/docs/cpp/library/headers/linalg) provides basic linear algebra algorithms which are based on BLAS.

{/* source:cpp-numeric:0005 */}
The header [`<simd>`](/docs/cpp/library/headers/simd) provides portable types for explicitly stating data-parallelism and structuring data for more efficient SIMD access.

{/* source:cpp-numeric:0013 */}
The header [`<random>`](/docs/cpp/library/headers/random) defines [pseudo-random number generators and numerical distributions](/docs/cpp/library/numeric/random). The header [`<cstdlib>`](/docs/cpp/library/headers/cstdlib) also includes C-style random number generation via [`std::srand`](/docs/cpp/library/numeric/random/srand) and [`std::rand`](/docs/cpp/library/numeric/random/rand).

{/* source:cpp-numeric:0014 */}
The header [`<cfenv>`](/docs/cpp/library/headers/cfenv) defines [flags and functions related to exceptional floating-point state](/docs/cpp/library/numeric/fenv), such as overflow and division by zero.

{/* source:cpp-numeric:0015 */}
The header [`<bit>`](/docs/cpp/library/headers/bit) provides several function templates to access, manipulate, and process individual bits and bit sequences. The byte ordering ([endianness](/docs/cpp/library/utility/bit/endian)) of scalar types can be inspected via `std::endian` facility.
