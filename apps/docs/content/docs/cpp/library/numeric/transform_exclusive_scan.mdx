{/* source:cpp-algorithm-transform-exclusive-scan:0001 */}
1. 1) Computes the exclusive prefix sum using `op`.

{/* source:cpp-algorithm-transform-exclusive-scan:0002 */}
2. For each integer `i` in [`0`, `std::distance(first, last)`), performs the following operations in order:
   - Creates a sequence which is formed by `init` followed by the values transformed from the elements of [`first`, `iter`) in order by `unary_op`, where `iter` is the next `i`th iterator of `first`.
   - Computes the generalized noncommutative sum of the sequence over `binary_op`.
   - Assigns the result to `*dest`, where `dest` is the next `i`th iterator of `d_first`.

{/* source:cpp-algorithm-transform-exclusive-scan:0003 */}
3. 2) Same as (1), but executed according to `policy`.

{/* source:cpp-algorithm-transform-exclusive-scan:0004 */}
4. This overload participates in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

{/* source:cpp-algorithm-transform-exclusive-scan:0005 */}
The generalized noncommutative sum of a sequence of elements over a binary operation `binary_op` is defined as follows:

{/* source:cpp-algorithm-transform-exclusive-scan:0006 */}
- If the sequence only has one element, the sum is the value of the element. Otherwise, performs the following operations in order:

{/* source:cpp-algorithm-transform-exclusive-scan:0007 */}
1. Selects any two adjacent elements `elem1` and `elem2` from the sequence.
2. Calculates `binary_op(elem1, elem2)` and replaces the two elements in the sequence with the result.
3. Repeats steps 1 and 2 until there is only one element in the sequence.

{/* source:cpp-algorithm-transform-exclusive-scan:0008 */}
The result is non-deterministic if the `binary_op` is not associative (such as floating-point addition).

{/* source:cpp-algorithm-transform-exclusive-scan:0009 */}
If any of the following values is not convertible to `T`, the program is ill-formed:

{/* source:cpp-algorithm-transform-exclusive-scan:0010 */}
- `binary_op(init, init)`
- `binary_op(init, unary_op(*first))`
- `binary_op(unary_op(*first), unary_op(*first))`

{/* source:cpp-algorithm-transform-exclusive-scan:0011 */}
If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-transform-exclusive-scan:0012 */}
- `T` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
- `unary_op` or `binary_op` modifies any element of [`first`, `last`).
- `unary_op` or `binary_op` invalidates any iterator or subrange of [`first`, `last`].

### Parameters

{/* source:cpp-algorithm-transform-exclusive-scan:0013 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to sum</Parameter>
  <Parameter name="d_first">the beginning of the destination range, may be equal to `first`</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="init">the initial value</Parameter>
  <Parameter name="unary_op">unary [FunctionObject](/docs/cpp/library/named_req/FunctionObject) that will be applied to each element of the input range. The return type must be acceptable as input to `binary_op`.</Parameter>
  <Parameter name="binary_op">binary [FunctionObject](/docs/cpp/library/named_req/FunctionObject) that will be applied in to the result of `unary_op`, the results of other `binary_op`, and `init`.</Parameter>
</ParameterList>

Type requirements

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `OutputIt` must meet the requirements of [*LegacyOutputIterator*](/docs/cpp/library/named_req/OutputIterator).
- `ForwardIt1, ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-algorithm-transform-exclusive-scan:0014 */}
Iterator to the element past the last element written.

### Complexity

{/* source:cpp-algorithm-transform-exclusive-scan:0015 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-transform-exclusive-scan:0016 */}
1. 1,2) `O(N)` applications of `unary_op` and `binary_op` respectively.

### Exceptions

{/* source:cpp-algorithm-transform-exclusive-scan:0017 */}
The overload with a template parameter named `ExecutionPolicy` reports errors as follows:

{/* source:cpp-algorithm-transform-exclusive-scan:0018 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Notes

{/* source:cpp-algorithm-transform-exclusive-scan:0019 */}
`unary_op` is never applied to `init`.

### Example

{/* source:cpp-algorithm-transform-exclusive-scan:0020 */}
```cpp
#include <functional>
#include <iostream>
#include <iterator>
#include <numeric>
#include <vector>
 
int main()
{
    std::vector data{3, 1, 4, 1, 5, 9, 2, 6};
 
    auto times_10 = [](int x) { return x * 10; };
 
    std::cout << "10 times exclusive sum: ";
    std::transform_exclusive_scan(data.begin(), data.end(),
                                  std::ostream_iterator<int>(std::cout, " "),
                                  0, std::plus<int>{}, times_10);
    std::cout << "\n10 times inclusive sum: ";
    std::transform_inclusive_scan(data.begin(), data.end(),
                                  std::ostream_iterator<int>(std::cout, " "),
                                  std::plus<int>{}, times_10);
    std::cout << '\n';
}
```

Output:

```text
10 times exclusive sum: 0 30 40 80 90 140 230 250 
10 times inclusive sum: 30 40 80 90 140 230 250 310
```
