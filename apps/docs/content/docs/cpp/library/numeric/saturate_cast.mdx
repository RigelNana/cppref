{/* source:cpp-numeric-saturate-cast:0001 */}
Converts the value `x` to a value of type `T`, clamping `x` between the minimum and maximum values of type `T`.

{/* source:cpp-numeric-saturate-cast:0002 */}
The program is ill-formed if either `T` or `U` is not a signed or unsigned [integer type](/docs/cpp/language/basic_concepts/types#Integer_types) (including [standard integer type](/docs/cpp/language/basic_concepts/types#Standard_integer_types) and [extended integer type](/docs/cpp/language/basic_concepts/types#Extended_integer_types_.28since_C.2B.2B11.29)).

### Parameters

{/* source:cpp-numeric-saturate-cast:0003 */}
<ParameterList>
  <Parameter name="x">an integer value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-saturate-cast:0004 */}
- `x`, if `x` is representable as a value of type `T`. Otherwise, either the largest or smallest representable value of type `T`, whichever is closer to the value of `x`.

### Example

{/* source:cpp-numeric-saturate-cast:0007 */}
Can be previewed on [Compiler Explorer](https://godbolt.org/z/5P149Y377).

```cpp
#include <cstdint>
#include <limits>
#include <numeric>
 
int main()
{
    constexpr std::int16_t x1{696};
 
    constexpr std::int8_t x2 = std::saturate_cast<std::int8_t>(x1);
    static_assert(x2 == std::numeric_limits<std::int8_t>::max());
 
    constexpr std::uint8_t x3 = std::saturate_cast<std::uint8_t>(x1);
    static_assert(x3 == std::numeric_limits<std::uint8_t>::max());
 
    constexpr std::int16_t y1{-696};
 
    constexpr std::int8_t y2 = std::saturate_cast<std::int8_t>(y1);
    static_assert(y2 == std::numeric_limits<std::int8_t>::min());
 
    constexpr std::uint8_t y3 = std::saturate_cast<std::uint8_t>(y1);
    static_assert(y3 == 0);
}
```
