  <DeclarationDescription>
    {/* source:cpp-numeric-complex-operator-cmp:0001 */}
    Compares two complex numbers. Scalar arguments are treated as complex numbers with the real part equal to the argument and the imaginary part set to zero.

    {/* source:cpp-numeric-complex-operator-cmp:0002 */}
    1-3) Compares `lhs` and `rhs` for equality.

    {/* source:cpp-numeric-complex-operator-cmp:0003 */}
    4-6) Compares `lhs` and `rhs` for inequality.

    {/* source:cpp-numeric-complex-operator-cmp:0004 */}
    <Revision since="C++20">
    The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
    </Revision>
  </DeclarationDescription>
</DeclarationDoc>

## Parameters

{/* source:cpp-numeric-complex-operator-cmp:0005 */}
<ParameterList>
  <Parameter name="lhs, rhs">the arguments to compare: either both complex numbers or one complex and one scalar of matching type (`float`, `double`, `long double`)</Parameter>
</ParameterList>

## Return value

{/* source:cpp-numeric-complex-operator-cmp:0006 */}
1-3) `true` if respective parts of `lhs` are equal to `rhs`, `false` otherwise.

{/* source:cpp-numeric-complex-operator-cmp:0007 */}
4-6) `!(lhs == rhs)`

## Example

{/* source:cpp-numeric-complex-operator-cmp:0008 */}
```cpp
#include <complex>
 
int main()
{
    using std::operator""i; // or: using namespace std::complex_literals;
 
    static_assert(1.0i == 1.0i);
    static_assert(2.0i != 1.0i);
 
    constexpr std::complex z(1.0, 0.0);
    static_assert(z == 1.0);
    static_assert(1.0 == z);
    static_assert(2.0 != z);
    static_assert(z != 2.0);
}
```
