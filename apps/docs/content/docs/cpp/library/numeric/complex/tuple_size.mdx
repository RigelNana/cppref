{/* source:cpp-numeric-complex-tuple-size:0001 */}
The partial specialization of [`std::tuple_size`](/docs/cpp/library/utility/tuple_size) for [`std::complex`](/docs/cpp/library/numeric/complex) provides a compile-time way to obtain the number of components of a complex, which is always `2`, using tuple-like syntax. It is provided for structured binding support.

## Example

{/* source:cpp-numeric-complex-tuple-size:0004 */}
```cpp
#include <complex>
 
static_assert(std::tuple_size_v<std::complex<float>> == 2);
 
static_assert([]
{
    using namespace std::literals;
    auto [re, im] = -1.5 + 2.5i;
    return re == -1.5 && im == 2.5;
}());
 
static_assert([]
{
    using namespace std::literals;
    auto z = std::complex<double>{};
    auto& [re, im] = z;
    re = 1.0;
    im = 2.0;
    return z == 1.0 + 2.0i;
}());
 
int main() {}
```
