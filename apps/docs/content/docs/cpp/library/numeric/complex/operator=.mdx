  <DeclarationDescription>
    {/* source:cpp-numeric-complex-operator:0001 */}
    Assigns new values to the contents.

    {/* source:cpp-numeric-complex-operator:0002 */}
    1,2) Assigns [`cx.real()`](/docs/cpp/library/numeric/complex/real) and [`cx.imag()`](/docs/cpp/library/numeric/complex/imag) to the real and the imaginary parts of the complex number respectively. <InlineRevision since="C++23">The copy assignment operator (1) is [trivial](/docs/cpp/language/classes/as_operator#Trivial_copy_assignment_operator) when `T` is a floating-point type.</InlineRevision>

    {/* source:cpp-numeric-complex-operator:0003 */}
    3) Assigns `x` to the real part of the complex number. Imaginary part is set to zero.
  </DeclarationDescription>
</DeclarationDoc>

## Notes

{/* source:cpp-numeric-complex-operator:0006 */}
The copy assignment operator is required to be [trivial](/docs/cpp/language/classes/as_operator#Trivial_copy_assignment_operator) since C++23, but implementations generally make it trivial in all modes.
