## Return value

{/* source:cpp-numeric-complex-real2:0004 */}
1. The real part of `z`.

{/* source:cpp-numeric-complex-real2:0005 */}
A) `f`.

{/* source:cpp-numeric-complex-real2:0006 */}
B) `static_cast<double>(i)`.

## Notes

{/* source:cpp-numeric-complex-real2:0007 */}
The additional overloads are not required to be provided exactly as (A,B). They only need to be sufficient to ensure that for their argument `num`:

{/* source:cpp-numeric-complex-real2:0008 */}
- If `num` has a <InlineRevision until="C++23">standard</InlineRevision> floating-point type `T`, then `std::real(num)` has the same effect as `std::real(std::complex<T>(num))`. Otherwise, if `num` has an integer type, then `std::real(num)` has the same effect as `std::real(std::complex<double>(num))`.
