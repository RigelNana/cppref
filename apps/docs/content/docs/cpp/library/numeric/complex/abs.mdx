  <Declaration language="cpp" code={`template< class T > 
T abs( const complex<T>& z );`} />
</DeclarationDoc>

{/* source:cpp-numeric-complex-abs:0001 */}
Returns the magnitude of the complex number `z`.

## Parameters

{/* source:cpp-numeric-complex-abs:0002 */}
<ParameterList>
  <Parameter name="z">complex value</Parameter>
</ParameterList>

## Return value

{/* source:cpp-numeric-complex-abs:0003 */}
If no errors occur, returns the absolute value (also known as norm, modulus, or magnitude) of `z`.

{/* source:cpp-numeric-complex-abs:0004 */}
Errors and special cases are handled as if the function is implemented as `std::hypot(std::real(z), std::imag(z))`.

## Example

{/* source:cpp-numeric-complex-abs:0005 */}
```cpp
#include <complex>
#include <iostream>
 
int main()
{
    std::complex<double> z(1, 1);
    std::cout << z << " cartesian is rho = " << std::abs(z)
              << " theta = " << std::arg(z) << " polar\n";
}
```

Output:

```text
(1,1) cartesian is rho = 1.41421 theta = 0.785398 polar
```
