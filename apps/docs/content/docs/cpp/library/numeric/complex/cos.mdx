{/* source:cpp-numeric-complex-cos:0001 */}
Computes complex cosine of a complex value `z`.

## Parameters

{/* source:cpp-numeric-complex-cos:0002 */}
<ParameterList>
  <Parameter name="z">complex value</Parameter>
</ParameterList>

## Return value

{/* source:cpp-numeric-complex-cos:0003 */}
If no errors occur, the complex cosine of `z` is returned.

{/* source:cpp-numeric-complex-cos:0004 */}
Errors and special cases are handled as if the operation is implemented by [`std::cosh`](/docs/cpp/library/numeric/complex/cosh)`(i * z)`, where `i` is the imaginary unit.

## Notes

{/* source:cpp-numeric-complex-cos:0005 */}
The cosine is an entire function on the complex plane, and has no branch cuts.

{/* source:cpp-numeric-complex-cos:0006 */}
Mathematical definition of the cosine is `cos z = (eiz + e-iz) / 2`.

## Example

{/* source:cpp-numeric-complex-cos:0007 */}
```cpp
#include <cmath>
#include <complex>
#include <iostream>
 
int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1.0, 0.0); // behaves like real cosine along the real line
    std::cout << "cos" << z << " = " << std::cos(z)
              << " ( cos(1) = " << std::cos(1) << ")\n";
 
    std::complex<double> z2(0.0, 1.0); // behaves like real cosh along the imaginary line
    std::cout << "cos" << z2 << " = " << std::cos(z2)
              << " (cosh(1) = " << std::cosh(1) << ")\n";
}
```

Output:

```text
cos(1.000000,0.000000) = (0.540302,-0.000000) ( cos(1) = 0.540302)
cos(0.000000,1.000000) = (1.543081,-0.000000) (cosh(1) = 1.543081)
```
