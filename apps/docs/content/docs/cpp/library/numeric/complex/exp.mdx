{/* source:cpp-numeric-complex-exp:0001 */}
Compute base-e exponential of `z`, that is `e` (Euler's number, 2.7182818) raised to the `z` power.

## Parameters

{/* source:cpp-numeric-complex-exp:0002 */}
<ParameterList>
  <Parameter name="z">complex value</Parameter>
</ParameterList>

## Return value

{/* source:cpp-numeric-complex-exp:0003 */}
If no errors occur, `e` raised to the power of `z`, `ez`, is returned.

## Error handling and special values

{/* source:cpp-numeric-complex-exp:0004 */}
Errors are reported consistent with [`math_errhandling`](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-complex-exp:0005 */}
If the implementation supports IEEE floating-point arithmetic,

{/* source:cpp-numeric-complex-exp:0006 */}
- `std::exp(std::conj(z)) == std::conj(std::exp(z))`
- If `z` is (±0,+0), the result is (1,+0)
- If `z` is (x,+∞) (for any finite x), the result is (NaN,NaN) and [`FE_INVALID`](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised.
- If `z` is (x,NaN) (for any finite x), the result is (NaN,NaN) and [`FE_INVALID`](/docs/cpp/library/numeric/fenv/FE_exceptions) may be raised.
- If `z` is (+∞,+0), the result is (+∞,+0)
- If `z` is (-∞,y) (for any finite y), the result is +0cis(y)
- If `z` is (+∞,y) (for any finite nonzero y), the result is +∞cis(y)
- If `z` is (-∞,+∞), the result is (±0,±0) (signs are unspecified)
- If `z` is (+∞,+∞), the result is (±∞,NaN) and [`FE_INVALID`](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised (the sign of the real part is unspecified)
- If `z` is (-∞,NaN), the result is (±0,±0) (signs are unspecified)
- If `z` is (+∞,NaN), the result is (±∞,NaN) (the sign of the real part is unspecified)
- If `z` is (NaN,+0), the result is (NaN,+0)
- If `z` is (NaN,y) (for any nonzero y), the result is (NaN,NaN) and [`FE_INVALID`](/docs/cpp/library/numeric/fenv/FE_exceptions) may be raised
- If `z` is (NaN,NaN), the result is (NaN,NaN)

{/* source:cpp-numeric-complex-exp:0007 */}
where `cis(y)` is `cos(y) + i sin(y)`.

## Notes

{/* source:cpp-numeric-complex-exp:0008 */}
The complex exponential function `ez` for `z = x+iy` equals `ex cis(y)`, or, `ex (cos(y) + i sin(y))`.

{/* source:cpp-numeric-complex-exp:0009 */}
The exponential function is an entire function in the complex plane and has no branch cuts.

{/* source:cpp-numeric-complex-exp:0010 */}
The following have equivalent results when the real part is 0:

{/* source:cpp-numeric-complex-exp:0011 */}
- `std::exp(std::complex<float>(0, theta))`
- `std::complex<float>(cosf(theta), sinf(theta))`
- `std::polar(1.f, theta)`

{/* source:cpp-numeric-complex-exp:0012 */}
In this case `exp` can be about 4.5x slower. One of the other forms should be used instead of calling `exp` with an argument whose real part is literal 0. There is no benefit in trying to avoid `exp` with a runtime check of `z.real() == 0` though.

## Example

{/* source:cpp-numeric-complex-exp:0013 */}
```cpp
#include <cmath>
#include <complex>
#include <iostream>
 
int main()
{
   const double pi = std::acos(-1.0);
   const std::complex<double> i(0.0, 1.0);
 
   std::cout << std::fixed << " exp(i * pi) = " << std::exp(i * pi) << '\n';
}
```

Output:

```text
exp(i * pi) = (-1.000000,0.000000)
```
