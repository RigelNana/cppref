{/* source:cpp-numeric-complex-tuple-element:0001 */}
The partial specializations of [`std::tuple_element`](/docs/cpp/library/utility/tuple_element) for [`std::complex`](/docs/cpp/library/numeric/complex) provide compile-time access to the underlying real and imaginary number type of a complex, using tuple-like syntax. They are provided for structured binding support. The program is ill-formed if `I >= 2`.

## Example

{/* source:cpp-numeric-complex-tuple-element:0004 */}
```cpp
#include <complex>
#include <type_traits>
 
static_assert([z = std::complex<float>()]
{
    using T = decltype(z);
    return
#if __cpp_lib_tuple_like >= 202311L
        std::is_same_v<std::tuple_element_t<0, T>, float> &&
        std::is_same_v<std::tuple_element_t<1, T>, float> &&
#endif
        std::is_same_v<T::value_type, float>;
}());
 
int main() {}
```
