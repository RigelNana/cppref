{/* source:cpp-numeric-complex-sin:0001 */}
Computes complex sine of a complex value `z`.

## Parameters

{/* source:cpp-numeric-complex-sin:0002 */}
<ParameterList>
  <Parameter name="z">complex value</Parameter>
</ParameterList>

## Return value

{/* source:cpp-numeric-complex-sin:0003 */}
If no errors occur, the complex sine of `z` is returned.

{/* source:cpp-numeric-complex-sin:0004 */}
Errors and special cases are handled as if the operation is implemented by `-i *` [`std::sinh`](/docs/cpp/library/numeric/complex/sinh)`(i * z)`, where `i` is the imaginary unit.

## Notes

{/* source:cpp-numeric-complex-sin:0005 */}
The sine is an entire function on the complex plane, and has no branch cuts.

{/* source:cpp-numeric-complex-sin:0006 */}
Mathematical definition of the sine is `sin z = (eiz - e-iz) / (2i)`.

## Example

{/* source:cpp-numeric-complex-sin:0007 */}
```cpp
#include <cmath>
#include <complex>
#include <iostream>
 
int main()
{
    std::cout << std::fixed;
    std::complex<double> z(1.0, 0.0); // behaves like real sine along the real line
    std::cout << "sin" << z << " = " << std::sin(z)
              << " ( sin(1) = " << std::sin(1) << ")\n";
 
    std::complex<double> z2(0.0, 1.0); // behaves like sinh along the imaginary line
    std::cout << "sin" << z2 << " = " << std::sin(z2)
              << " (sinh(1) = " << std::sinh(1) << ")\n";
}
```

Output:

```text
sin(1.000000,0.000000) = (0.841471,0.000000) ( sin(1) = 0.841471)
sin(0.000000,1.000000) = (0.000000,1.175201) (sinh(1) = 1.175201)
```
