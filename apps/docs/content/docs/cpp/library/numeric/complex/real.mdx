Accesses the real part of the complex number.

{/* source:cpp-numeric-complex-real:0002 */}
1) Returns the real part.

{/* source:cpp-numeric-complex-real:0003 */}
2) Sets the real part to `value`.

## Parameters

{/* source:cpp-numeric-complex-real:0004 */}
<ParameterList>
  <Parameter name="value">the value to set the real part to</Parameter>
</ParameterList>

## Return value

{/* source:cpp-numeric-complex-real:0005 */}
1) The real part of `*this`.

{/* source:cpp-numeric-complex-real:0006 */}
2) (none)

## Notes

{/* source:cpp-numeric-complex-real:0007 */}
In C++11, overload (1) in [`std::complex`](/docs/cpp/library/numeric/complex) specializations used to be specified without `const` qualifier. However, in C++11, a [`constexpr`](/docs/cpp/language/declarations/constexpr) specifier used in a non-static member function implies `const`, and thus the behavior is as if `const` is specified.
