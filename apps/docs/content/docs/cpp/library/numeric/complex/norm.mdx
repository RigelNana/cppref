## Return value

{/* source:cpp-numeric-complex-norm:0004 */}
1. The squared magnitude of `z`.

{/* source:cpp-numeric-complex-norm:0005 */}
A) The square of `f`.

{/* source:cpp-numeric-complex-norm:0006 */}
B) The square of `i`.

## Notes

{/* source:cpp-numeric-complex-norm:0007 */}
The norm calculated by this function is also known as [field norm](https://en.wikipedia.org/wiki/Field_norm) or [absolute square](https://mathworld.wolfram.com/AbsoluteSquare.html).

{/* source:cpp-numeric-complex-norm:0008 */}
The [Euclidean norm](https://en.wikipedia.org/wiki/Euclidean_space#Euclidean_norm) of a complex number is provided by [`std::abs`](/docs/cpp/library/numeric/complex/abs), which is more costly to compute. In some situations, it may be replaced by `std::norm`, for example, if `abs(z1) > abs(z2)` then `norm(z1) > norm(z2)`.

{/* source:cpp-numeric-complex-norm:0009 */}
The additional overloads are not required to be provided exactly as (A,B). They only need to be sufficient to ensure that for their argument `num`:

{/* source:cpp-numeric-complex-norm:0010 */}
- If `num` has a <InlineRevision until="C++23">standard</InlineRevision> floating-point type `T`, then `std::norm(num)` has the same effect as `std::norm(std::complex<T>(num))`. Otherwise, if `num` has an integer type, then `std::norm(num)` has the same effect as `std::norm(std::complex<double>(num))`.

## Example

{/* source:cpp-numeric-complex-norm:0011 */}
```cpp
#include <cassert>
#include <complex>
#include <iostream>
 
int main()
{
    constexpr std::complex<double> z {3.0, 4.0};
    static_assert(std::norm(z) == (z.real() * z.real() + z.imag() * z.imag()));
    static_assert(std::norm(z) == (z * std::conj(z)));
           assert(std::norm(z) == (std::abs(z) * std::abs(z)));
    std::cout << "std::norm(" << z << ") = " << std::norm(z) << '\n';
}
```

Output:

```text
std::norm((3,4)) = 25
```
