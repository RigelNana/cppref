{/* source:cpp-algorithm-reduce:0001 */}
1. 1) Equivalent to `reduce(first, last, typename std::iterator_traits<InputIt>::value_type{})`.

{/* source:cpp-algorithm-reduce:0002 */}
2. 3) Equivalent to `reduce(first, last, init, std::plus<>())`.

{/* source:cpp-algorithm-reduce:0003 */}
3. 5) Reduces the range [`first`, `last`), possibly permuted and aggregated in unspecified manner, along with the initial value `init` over `op`.

{/* source:cpp-algorithm-reduce:0004 */}
4. 2,4,6) Same as (1,3,5), but executed according to `policy`.

{/* source:cpp-algorithm-reduce:0005 */}
5. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

{/* source:cpp-algorithm-reduce:0006 */}
Given `binary_op` as the actual binary operation:

{/* source:cpp-algorithm-reduce:0007 */}
- The result is non-deterministic if the `binary_op` is not associative or not commutative (such as floating-point addition).

{/* source:cpp-algorithm-reduce:0008 */}
- If any of the following values is not convertible to `T`, the program is ill-formed:

{/* source:cpp-algorithm-reduce:0009 */}
  - `binary_op(init, *first)`
  - `binary_op(*first, init)`
  - `binary_op(init, init)`
  - `binary_op(*first, *first)`

{/* source:cpp-algorithm-reduce:0010 */}
- If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-reduce:0011 */}
  - `T` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
  - `binary_op` modifies any element of [`first`, `last`).
  - `binary_op` invalidates any iterator or subrange of [`first`, `last`].

### Parameters

{/* source:cpp-algorithm-reduce:0012 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to apply the algorithm to</Parameter>
  <Parameter name="init">the initial value of the generalized sum</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="op">binary [FunctionObject](/docs/cpp/library/named_req/FunctionObject) that will be applied in unspecified order to the result of dereferencing the input iterators, the results of other `op` and `init`.</Parameter>
</ParameterList>

Type requirements

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-algorithm-reduce:0013 */}
1. 1-4) The generalized sum of `init` and the elements of [`first`, `last`) over `std::plus<>()`.

{/* source:cpp-algorithm-reduce:0014 */}
2. 5,6) The generalized sum of `init` and the elements of [`first`, `last`) over `op`.

{/* source:cpp-algorithm-reduce:0015 */}
The generalized sum of a group of elements over an binary operation `binary_op` is defined as follows:

{/* source:cpp-algorithm-reduce:0016 */}
- If the group only has one element, the sum is the value of the element. Otherwise, performs the following operations in order:

{/* source:cpp-algorithm-reduce:0017 */}
1. Takes any two elements `elem1` and `elem2` from the group.
2. Calculates `binary_op(elem1, elem2)` and puts the result back to the group.
3. Repeats steps 1 and 2 until there is only one element in the group.

### Complexity

{/* source:cpp-algorithm-reduce:0018 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-reduce:0019 */}
1. 1-4) `O(N)` applications of `std::plus<>()`.

{/* source:cpp-algorithm-reduce:0020 */}
2. 5,6) `O(N)` applications of `op`.

### Exceptions

{/* source:cpp-algorithm-reduce:0021 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-reduce:0022 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Notes

{/* source:cpp-algorithm-reduce:0023 */}
`std::reduce` behaves like [`std::accumulate`](/docs/cpp/library/numeric/accumulate) except the elements of the range may be grouped and rearranged in arbitrary order.

### Example

{/* source:cpp-algorithm-reduce:0024 */}
Side-by-side comparison between `std::reduce` and [`std::accumulate`](/docs/cpp/library/numeric/accumulate):

```cpp
#if PARALLEL
#include <execution>
#define SEQ std::execution::seq,
#define PAR std::execution::par,
#else
#define SEQ
#define PAR
#endif
 
#include <chrono>
#include <iomanip>
#include <iostream>
#include <locale>
#include <numeric>
#include <utility>
#include <vector>
 
int main()
{
    std::cout.imbue(std::locale("en_US.UTF-8"));
    std::cout << std::fixed << std::setprecision(1);
 
    auto eval = [](auto fun)
    {
        const auto t1 = std::chrono::high_resolution_clock::now();
        const auto [name, result] = fun();
        const auto t2 = std::chrono::high_resolution_clock::now();
        const std::chrono::duration<double, std::milli> ms = t2 - t1;
        std::cout << std::setw(28) << std::left << name << "sum: "
                  << result << '\t' << "time: " << ms.count() << " ms\n";
    };
 
    {
        const std::vector<double> v(100'000'007, 0.1);
 
        eval([&v]{ return std::pair{"std::accumulate (double)",
            std::accumulate(v.cbegin(), v.cend(), 0.0)}; });
        eval([&v]{ return std::pair{"std::reduce (seq, double)",
            std::reduce(SEQ v.cbegin(), v.cend())}; });
        eval([&v]{ return std::pair{"std::reduce (par, double)",
            std::reduce(PAR v.cbegin(), v.cend())}; });
    }
 
    {
        const std::vector<long> v(100'000'007, 1);
 
        eval([&v]{ return std::pair{"std::accumulate (long)",
            std::accumulate(v.cbegin(), v.cend(), 0l)}; });
        eval([&v]{ return std::pair{"std::reduce (seq, long)",
            std::reduce(SEQ v.cbegin(), v.cend())}; });
        eval([&v]{ return std::pair{"std::reduce (par, long)",
            std::reduce(PAR v.cbegin(), v.cend())}; });
    }
}
```
