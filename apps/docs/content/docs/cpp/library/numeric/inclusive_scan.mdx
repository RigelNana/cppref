{/* source:cpp-algorithm-inclusive-scan:0001 */}
1. 1) Equivalent to `inclusive_scan(first, last, d_first, std::plus<>()`. 

{/* source:cpp-algorithm-inclusive-scan:0002 */}
2. 3) Computes the inclusive prefix sum using `op`.

{/* source:cpp-algorithm-inclusive-scan:0003 */}
3. For each integer `i` in [`0`, `std::distance(first, last)`), performs the following operations in order:
   - Creates a sequence which is formed by the elements of [`first`, `iter`] in order, where `iter` is the next `i`th iterator of `first`.
   - Computes the generalized noncommutative sum of the sequence over `op`.
   - Assigns the result to `*dest`, where `dest` is the next `i`th iterator of `d_first`.

{/* source:cpp-algorithm-inclusive-scan:0004 */}
4. 5) Same as (3), but each sequence created is formed by `init` followed by the elements of [`first`, `iter`] in order.

{/* source:cpp-algorithm-inclusive-scan:0005 */}
5. 2,4,6) Same as (1,3,5), but executed according to `policy`.

{/* source:cpp-algorithm-inclusive-scan:0006 */}
6. These overloads participate in overload resolution only if all following conditions are satisfied:

   <Revision until="C++20">`std::is_execution_policy_v<std::decay_t<ExecutionPolicy>>` is `true`.</Revision>

   <Revision since="C++20">`std::is_execution_policy_v<std::remove_cvref_t<ExecutionPolicy>>` is `true`.</Revision>

{/* source:cpp-algorithm-inclusive-scan:0007 */}
The generalized, noncommutative sum of a sequence of elements over a binary operation `binary_op` is defined as follows:

{/* source:cpp-algorithm-inclusive-scan:0008 */}
- If the sequence only has one element, the sum is the value of the element. Otherwise, performs the following operations in order:

{/* source:cpp-algorithm-inclusive-scan:0009 */}
1. Selects any two adjacent elements `elem1` and `elem2` from the sequence.
2. Calculates `binary_op(elem1, elem2)` and replaces the two elements in the sequence with the result.
3. Repeats steps 1 and 2 until there is only one element in the sequence.

{/* source:cpp-algorithm-inclusive-scan:0010 */}
Given `binary_op` as the actual binary operation:

{/* source:cpp-algorithm-inclusive-scan:0011 */}
- The result is non-deterministic if the `binary_op` is not associative (such as floating-point addition).

{/* source:cpp-algorithm-inclusive-scan:0012 */}
- For overloads (1-4), if `binary_op(*first, *first)` is not convertible to the [value type](/docs/cpp/library/iterator#Types_and_writability) of `decltype(first)`, the program is ill-formed.

{/* source:cpp-algorithm-inclusive-scan:0013 */}
- For overloads (5,6), if any of the following values is not convertible to `T`, the program is ill-formed:

{/* source:cpp-algorithm-inclusive-scan:0014 */}
  - `binary_op(init, *first)`
  - `binary_op(init, init)`
  - `binary_op(*first, *first)`

{/* source:cpp-algorithm-inclusive-scan:0015 */}
- If any of the following conditions is satisfied, the behavior is undefined:

{/* source:cpp-algorithm-inclusive-scan:0016 */}
  - For overloads (1-4), the value type of `decltype(first)` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
  - For overloads (5,6), `T` is not [*MoveConstructible*](/docs/cpp/library/named_req/MoveConstructible).
  - `binary_op` modifies any element of [`first`, `last`).
  - `binary_op` invalidates any iterator or subrange of [`first`, `last`].

### Parameters

{/* source:cpp-algorithm-inclusive-scan:0017 */}
<ParameterList>
  <Parameter name="first, last">the range of elements to sum</Parameter>
  <Parameter name="d_first">the beginning of the destination range; may be equal to `first`</Parameter>
  <Parameter name="policy">the [execution policy](/docs/cpp/library/algorithm/execution_policy_tag_t) to use</Parameter>
  <Parameter name="init">the initial value</Parameter>
  <Parameter name="op">binary [FunctionObject](/docs/cpp/library/named_req/FunctionObject) that will be applied in to the result of dereferencing the input iterators, the results of other `op`, and `init` (if provided)</Parameter>
</ParameterList>

Type requirements

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
- `OutputIt` must meet the requirements of [*LegacyOutputIterator*](/docs/cpp/library/named_req/OutputIterator).
- `ForwardIt1, ForwardIt2` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-algorithm-inclusive-scan:0018 */}
Iterator to the element past the last element written.

### Complexity

{/* source:cpp-algorithm-inclusive-scan:0019 */}
Given `N` as `std::distance(first, last)`:

{/* source:cpp-algorithm-inclusive-scan:0020 */}
1. 1,2) `O(N)` applications of `std::plus<>()`.

{/* source:cpp-algorithm-inclusive-scan:0021 */}
2. 3-6) `O(N)` applications of `op`.

### Exceptions

{/* source:cpp-algorithm-inclusive-scan:0022 */}
The overloads with a template parameter named `ExecutionPolicy` report errors as follows:

{/* source:cpp-algorithm-inclusive-scan:0023 */}
- If execution of a function invoked as part of the algorithm throws an exception and `ExecutionPolicy` is one of the [standard policies](/docs/cpp/library/algorithm/execution_policy_tag_t), [`std::terminate`](/docs/cpp/library/error/terminate) is called. For any other `ExecutionPolicy`, the behavior is implementation-defined.
- If the algorithm fails to allocate memory, [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) is thrown.

### Example

{/* source:cpp-algorithm-inclusive-scan:0024 */}
```cpp
#include <functional>
#include <iostream>
#include <iterator>
#include <numeric>
#include <vector>
 
int main()
{
    std::vector data{3, 1, 4, 1, 5, 9, 2, 6};
 
    std::cout << "Exclusive sum: ";
    std::exclusive_scan(data.begin(), data.end(),
                        std::ostream_iterator<int>(std::cout, " "),
                        0);
 
    std::cout << "\nInclusive sum: ";
    std::inclusive_scan(data.begin(), data.end(),
                        std::ostream_iterator<int>(std::cout, " "));
 
    std::cout << "\n\nExclusive product: ";
    std::exclusive_scan(data.begin(), data.end(),
                        std::ostream_iterator<int>(std::cout, " "),
                        1, std::multiplies<>{});
 
    std::cout << "\nInclusive product: ";
    std::inclusive_scan(data.begin(), data.end(),
                        std::ostream_iterator<int>(std::cout, " "),
                        std::multiplies<>{});
}
```

Output:

```text
Exclusive sum: 0 3 4 8 9 14 23 25
Inclusive sum: 3 4 8 9 14 23 25 31
 
Exclusive product: 1 3 3 12 12 60 540 1080
Inclusive product: 3 3 12 12 60 540 1080 6480
```
