{/* source:cpp-numeric-gcd:0001 */}
Computes the [greatest common divisor](https://en.wikipedia.org/wiki/greatest_common_divisor) of the integers `m` and `n`.

{/* source:cpp-numeric-gcd:0002 */}
If either `M` or `N` is not an integer type, or if either is (possibly cv-qualified) `bool`, the program is ill-formed.

{/* source:cpp-numeric-gcd:0003 */}
If either `|m|` or `|n|` is not representable as a value of type `std::common_type_t<M, N>`, the behavior is undefined.

### Parameters

{/* source:cpp-numeric-gcd:0004 */}
<ParameterList>
  <Parameter name="m">integer values</Parameter>
  <Parameter name="n">integer values</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-gcd:0005 */}
If both `m` and `n` are zero, returns zero. Otherwise, returns the greatest common divisor of `|m|` and `|n|`.

### Exceptions

{/* source:cpp-numeric-gcd:0006 */}
Throws no exceptions.

### Example

{/* source:cpp-numeric-gcd:0008 */}
```cpp
#include <numeric>
 
int main()
{
    constexpr int p{2 * 2 * 3};
    constexpr int q{2 * 3 * 3};
    static_assert(2 * 3 == std::gcd(p, q));
 
    static_assert(std::gcd( 6,  10) == 2);
    static_assert(std::gcd( 6, -10) == 2);
    static_assert(std::gcd(-6, -10) == 2);
 
    static_assert(std::gcd( 24, 0) == 24);
    static_assert(std::gcd(-24, 0) == 24);
}
```
