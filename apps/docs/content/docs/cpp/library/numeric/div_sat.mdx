{/* source:cpp-numeric-div-sat:0001 */}
Computes the [saturating](https://en.wikipedia.org/wiki/Saturation_arithmetic) division `x / y`. If `T` is a signed integer type, `x` is the smallest (most negative) value of `T`, and `y == -1`, returns the greatest value of `T`; otherwise, returns `x / y`.

{/* source:cpp-numeric-div-sat:0002 */}
`y` must not be `0`, otherwise the behavior is undefined. The function call is not a [core constant expression](/docs/cpp/language/expressions/constant_expression#Core_constant_expressions) if undefined behavior happens.

{/* source:cpp-numeric-div-sat:0003 */}
This overload participates in overload resolution only if `T` is an [integer type](/docs/cpp/language/basic_concepts/types#Integer_types), that is: `signed char`, `short`, `int`, `long`, `long long`, an extended signed integer type, or an unsigned version of such types. In particular, `T` must not be (possibly cv-qualified) `bool`, `char`, `wchar_t`, `char8_t`, `char16_t`, and `char32_t`, as these types are not intended for arithmetic.

### Return value

### Notes

{/* source:cpp-numeric-div-sat:0006 */}
Unlike the built-in arithmetic operators on integers, the [integral promotion](/docs/cpp/language/expressions/implicit_cast#Integral_promotion) does not apply to the `x` and `y` arguments.

{/* source:cpp-numeric-div-sat:0007 */}
If two arguments of different type are passed, the call fails to compile, i.e. the behavior relative to [template argument deduction](/docs/cpp/language/templates/template_argument_deduction) is the same as for [`std::min`](/docs/cpp/library/algorithm/min) or [`std::max`](/docs/cpp/library/algorithm/max).

{/* source:cpp-numeric-div-sat:0008 */}
Most modern hardware architectures have efficient support for saturation arithmetic on SIMD vectors, including SSE2 for x86 and NEON for ARM.

### Possible implementation

{/* source:cpp-numeric-div-sat:0010 */}
```cpp
namespace detail {
template<class T>
concept standard_or_extended_integral =
     std::is_integral_v<T> &&
    !std::is_same_v<std::remove_cv_t<T>, bool> &&
    !std::is_same_v<std::remove_cv_t<T>, char> &&
    !std::is_same_v<std::remove_cv_t<T>, char8_t> &&
    !std::is_same_v<std::remove_cv_t<T>, char16_t> &&
    !std::is_same_v<std::remove_cv_t<T>, char32_t> &&
    !std::is_same_v<std::remove_cv_t<T>, wchar_t>;
} // namespace detail
 
template<detail::standard_or_extended_integral T>
constexpr T div_sat( T x, T y ) noexcept
{
    if constexpr (std::is_signed_v<T>)
        if (x == std::numeric_limits<T>::min() && y == -1)
            return std::numeric_limits<T>::max();
    return x / y;
}
```

### Example

{/* source:cpp-numeric-div-sat:0011 */}
Can be previewed on [Compiler Explorer](https://godbolt.org/z/vvsTa6e3j).

```cpp
#include <climits>
#include <numeric>
 
static_assert
(""
    && (std::div_sat<int>(6, 3) == 2) // not saturated
    && (std::div_sat<int>(INT_MIN, -1) == INT_MAX) // saturated
    && (std::div_sat<unsigned>(6, 3) == 2) // not saturated
);
 
int main() {}
```
