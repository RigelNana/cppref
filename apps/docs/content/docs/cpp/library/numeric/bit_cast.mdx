{/* source:cpp-numeric-bit-cast:0001 */}
Obtain a value of type `To` by reinterpreting the object representation of `From`. Every bit in the [value representation](/docs/cpp/language/basic_concepts/objects#Object_representation_and_value_representation) of the returned `To` object is equal to the corresponding bit in the [object](/docs/cpp/language/basic_concepts/objects#Object_representation_and_value_representation) representation of `from`. The values of padding bits in the returned `To` object are unspecified.

{/* source:cpp-numeric-bit-cast:0002 */}
If there is no value of type `To` corresponding to the value representation produced, the behavior is undefined. If there are multiple such values, which value is produced is unspecified.

{/* source:cpp-numeric-bit-cast:0003 */}
A bit in the value representation of the result is indeterminate if it

{/* source:cpp-numeric-bit-cast:0004 */}
- does not correspond to a bit in the value representation of `From` (i.e. it corresponds to a padding bit), or
- corresponds to a bit <InlineRevision until="C++26">of an object that</InlineRevision><InlineRevision since="C++26">for which the smallest enclosing object</InlineRevision> is not within its [lifetime](/docs/cpp/language/basic_concepts/lifetime), or
- has an [indeterminate value](/docs/cpp/language/initialization/default_initialization#Indeterminate_and_erroneous_values).

{/* source:cpp-numeric-bit-cast:0005 */}
<Revision since="C++26">
A bit in the value representation of the result is *erroneous* if it corresponds to a bit for which the smallest enclosing object has an [erroneous value](/docs/cpp/language/initialization/default_initialization#Indeterminate_and_erroneous_values).
</Revision>

{/* source:cpp-numeric-bit-cast:0006 */}
The result does not otherwise contain any indeterminate or erroneous values.

{/* source:cpp-numeric-bit-cast:0007 */}
<Revision until="C++26">
For each bit in the value representation of the result that is indeterminate, the smallest object containing that bit has an indeterminate value; the behavior is undefined unless that object is of an [uninitialized-friendly type](/docs/cpp/language/initialization/default_initialization#Special_cases).

The result does not otherwise contain any indeterminate values.
</Revision>
<Revision since="C++26">
For each bit `b` in the value representation of the result that is indeterminate or erroneous, let `u` be the smallest object enclosing `b`:

- If `u` is of [uninitialized-friendly type](/docs/cpp/language/initialization/default_initialization#Special_cases), `u` has an indeterminate value if any of the bits in its value representation are indeterminate, or otherwise has an erroneous value.
- Otherwise, if `b` is indeterminate, the behavior is undefined.
- Otherwise, the behavior is [erroneous](/docs/cpp/language/basic_concepts/ub), and the result is as specified above.
</Revision>

{/* source:cpp-numeric-bit-cast:0008 */}
This overload participates in overload resolution only if `sizeof(To) == sizeof(From)` and both `To` and `From` are [TriviallyCopyable](/docs/cpp/library/named_req/TriviallyCopyable) types.

{/* source:cpp-numeric-bit-cast:0009 */}
This function template is `constexpr` if and only if each of `To`, `From` and the types of all subobjects of `To` and `From`:

{/* source:cpp-numeric-bit-cast:0010 */}
- is not a union type;
- is not a pointer type;
- is not a pointer to member type;
- is not a volatile-qualified type; and
- has no non-static data member of reference type.

### Return value

{/* source:cpp-numeric-bit-cast:0012 */}
An object of type `To` whose value representation is as described above.

### Possible implementation

{/* source:cpp-numeric-bit-cast:0013 */}
To implement `std::bit_cast`, ignoring the fact that it's [constexpr](/docs/cpp/language/declarations/constexpr), [`std::memcpy`](/docs/cpp/library/text/byte/memcpy) can be used, when it is needed, to interpret the object representation as one of another type:

{/* source:cpp-numeric-bit-cast:0014 */}
```cpp
template<class To, class From>
std::enable_if_t<
    sizeof(To) == sizeof(From) &&
    std::is_trivially_copyable_v<From> &&
    std::is_trivially_copyable_v<To>,
    To>
// constexpr support needs compiler magic
bit_cast(const From& src) noexcept
{
    static_assert(std::is_trivially_constructible_v<To>,
        "This implementation additionally requires "
        "destination type to be trivially constructible");
 
    To dst;
    std::memcpy(&dst, &src, sizeof(To));
    return dst;
}
```

### Notes

{/* source:cpp-numeric-bit-cast:0015 */}
[reinterpret_cast](/docs/cpp/language/expressions/reinterpret_cast) (or equivalent [explicit cast](/docs/cpp/language/expressions/explicit_cast)) between pointer or reference types shall not be used to reinterpret object representation in most cases because of the [type aliasing rule](/docs/cpp/language/expressions/reinterpret_cast#Type_aliasing).

### Example

{/* source:cpp-numeric-bit-cast:0017 */}
```cpp
#include <bit>
#include <cstdint>
#include <iostream>
 
constexpr double f64v = 19880124.0; 
constexpr auto u64v = std::bit_cast<std::uint64_t>(f64v);
static_assert(std::bit_cast<double>(u64v) == f64v); // round-trip
 
constexpr std::uint64_t u64v2 = 0x3fe9000000000000ull;
constexpr auto f64v2 = std::bit_cast<double>(u64v2);
static_assert(std::bit_cast<std::uint64_t>(f64v2) == u64v2); // round-trip
 
int main()
{
    std::cout
        << "std::bit_cast<std::uint64_t>(" << std::fixed << f64v << ") == 0x"
        << std::hex << u64v << '\n'
        << "std::bit_cast<double>(0x" << std::hex << u64v2 << ") == "
        << std::fixed << f64v2 << '\n';
}
```

Possible output:

```text
std::bit_cast<std::uint64_t>(19880124.000000) == 0x4172f58bc0000000
std::bit_cast<double>(0x3fe9000000000000) == 0.781250
```
