{/* source:cpp-numeric-random:0000 */}
The random number library provides classes that generate random and pseudo-random numbers. These classes include:

{/* source:cpp-numeric-random:0001 */}
-  Uniform random bit generators (URBGs), which include both random number engines, which are pseudo-random number generators that generate integer sequences with a uniform distribution, and true random number generators (if available).

-  Random number distributions (e.g. [uniform](/docs/cpp/library/numeric/random/uniform_int_distribution), [normal](/docs/cpp/library/numeric/random/normal_distribution), or [poisson distributions](/docs/cpp/library/numeric/random/poisson_distribution)) which convert the output of URBGs into various statistical distributions.

{/* source:cpp-numeric-random:0002 */}
URBGs and distributions are designed to be used together to produce random values. All of the random number engines may be specifically seeded, serialized, and de-serialized for use with repeatable simulators.

### Uniform random bit generators

{/* source:cpp-numeric-random:0003 */}
A <i>uniform random bit generator</i> is a function object returning unsigned integer values such that each value in the range of possible results has (ideally) equal probability of being returned.

{/* source:cpp-numeric-random:0004 */}
All uniform random bit generators meet the [*UniformRandomBitGenerator*](/docs/cpp/library/named_req/UniformRandomBitGenerator) requirements.
C++20 also defines a [`uniform_random_bit_generator`](/docs/cpp/library/numeric/random/UniformRandomBitGenerator) concept.

### Random number engines

{/* source:cpp-numeric-random:0006 */}
A <i>random number engine</i> (commonly shortened to <i>engine</i> ) is a uniform random bit generator which generates pseudo-random numbers using seed data as entropy source.

{/* source:cpp-numeric-random:0007 */}
At any given time, an engine `e` of type `E` has a state `ei` for some non-negative integer `i`. Upon construction, `e` has an initial state `e0`, which is determined by engine parameters and an initial seed (or seed sequence).

{/* source:cpp-numeric-random:0008 */}
The following properties are always defined for any engine type `E`:

{/* source:cpp-numeric-random:0009 */}
-  The <i>size</i> of `E`’s state in multiples of the size of `E::result_type` (i.e. `(sizeof ei) / sizeof(E::result_type)`).

-  The <i>transition algorithm</i> `TA` by which `e`’s state `ei` is advanced to its successor state `ei+1` (i.e. `TA(ei) == ei+1`).

-  The <i>generation algorithm</i> `GA` by which `e`’s state is mapped to a value of type `E::result_type`, the result is a pseudo-random number.

{/* source:cpp-numeric-random:0010 */}
A pseudo-random number sequence can be generated by calling `TA` and `GA` alternatively.

{/* source:cpp-numeric-random:0011 */}
The standard library provides the implementations of three different classes of pseudo-random number generation algorithms as class templates, so that the algorithms can be customized. The choice of which engine to use involves a number of trade-offs:

{/* source:cpp-numeric-random:0012 */}
-  The [linear congruential engine](/docs/cpp/library/numeric/random/linear_congruential_engine) is moderately fast and has a very small storage requirement for state.

-  The [Mersenne twister engine](/docs/cpp/library/numeric/random/mersenne_twister_engine) is slower and has greater state storage requirements but with the right parameters has the longest non-repeating sequence with the most desirable spectral characteristics (for a given definition of desirable).

-  The [subtract with carry engine](/docs/cpp/library/numeric/random/subtract_with_carry_engine) is very fast even on processors without advanced arithmetic instruction sets, at the expense of greater state storage and sometimes less desirable spectral characteristics.

{/* source:cpp-numeric-random:0013 */}
<Revision since="C++26">

-  The [Philox engine](/docs/cpp/library/numeric/random/philox_engine) is a [counter-based random number generator](https://en.wikipedia.org/wiki/counter-based_random_number_generator). It has a small state and a long period (not less than 2^130) and is intended for use in Monte-Carlo simulations which require massively parallel random number generation. It is easily vectorized and parallelized and is implemented in GPU-optimized libraries.

</Revision>

{/* source:cpp-numeric-random:0014 */}
None of these random number engines are [cryptographically secure](https://en.wikipedia.org/wiki/Cryptographically_secure_pseudorandom_number_generator). As with any secure operation, a crypto library should be used for the purpose (e.g. [OpenSSL `RAND_bytes`](https://www.openssl.org/docs/manmaster/man3/RAND_bytes.html)).

### Random number engine adaptors

{/* source:cpp-numeric-random:0017 */}

### Example

{/* source:cpp-numeric-random:0030 */}
```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>
 
int main()
{
    // Seed with a real random value, if available
    std::random_device r;
 
    // Choose a random mean between 1 and 6
    std::default_random_engine e1(r());
    std::uniform_int_distribution<int> uniform_dist(1, 6);
    int mean = uniform_dist(e1);
    std::cout << "Randomly-chosen mean: " << mean << '\n';
 
    // Generate a normal distribution around that mean
    std::seed_seq seed2{r(), r(), r(), r(), r(), r(), r(), r()};
    std::mt19937 e2(seed2);
    std::normal_distribution<> normal_dist(mean, 2);
 
    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[std::round(normal_dist(e2))];
 
    std::cout << "Normal distribution around " << mean << ":\n"
              << std::fixed << std::setprecision(1);
    for (auto [x, y] : hist)
        std::cout << std::setw(2) << x << ' ' << std::string(y / 200, '*') << '\n';
}
```
