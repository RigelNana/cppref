Returns the parameters the distribution was constructed with.

{/* source:cpp-numeric-random-normal-distribution-params:0002 */}
1. Returns the mean μ distribution parameter. The mean specifies the location of the peak. The default value is `0.0`.

{/* source:cpp-numeric-random-normal-distribution-params:0003 */}
2. Returns the deviation σ distribution parameter. The default value is `1.0`.

  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-numeric-random-normal-distribution-params:0004 */}
(none)

### Return value

{/* source:cpp-numeric-random-normal-distribution-params:0005 */}
1. The mean μ distribution parameter.

{/* source:cpp-numeric-random-normal-distribution-params:0006 */}
2. The deviation σ distribution parameter.
