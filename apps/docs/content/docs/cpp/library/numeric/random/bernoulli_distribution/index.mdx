Produces random boolean values, according to the discrete probability function. The probability of `true` is

{/* source:cpp-numeric-random-bernoulli-distribution:0002 */}
P(b|p) = ⎧ ⎨ ⎩ p, if b is true 1 − p, if b is false

{/* source:cpp-numeric-random-bernoulli-distribution:0003 */}
`std::bernoulli_distribution` satisfies [*RandomNumberDistribution*](/docs/cpp/library/named_req/RandomNumberDistribution).

### Example

{/* source:cpp-numeric-random-bernoulli-distribution:0007 */}
```cpp
#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>
 
int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    // give "true" 1/4 of the time
    // give "false" 3/4 of the time
    std::bernoulli_distribution d(0.25);
 
    std::map<bool, int> hist;
    for (int n = 0; n < 10000; ++n)
        ++hist[d(gen)];
 
    std::cout << std::boolalpha;
    for (auto const& [key, value] : hist)
        std::cout << std::setw(5) << key << ' '
                  << std::string(value / 500, '*') << '\n';
}
```

Possible output:

```text
false ***************
 true ****
```
