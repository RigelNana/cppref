Resets the internal state of the distribution object.  After a call to this function, the next call to [`operator()`](/docs/cpp/library/numeric/random/exponential_distribution/operator()) on the distribution object will not be dependent on previous calls to [`operator()`](/docs/cpp/library/numeric/random/exponential_distribution/operator()).
