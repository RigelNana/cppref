    Returns the parameters the distribution has been constructed with.

    {/* source:cpp-numeric-random-uniform-int-distribution-params:0002 */}
    1. Returns the <i>a</i> distribution parameter. It defines the minimum possibly generated value. The default value is `0`.

    {/* source:cpp-numeric-random-uniform-int-distribution-params:0003 */}
    2. Returns the <i>b</i> distribution parameter. It defines the maximum possibly generated value. The default value is `std::numeric_limits<IntType>::max()`.

  </DeclarationDescription>
</DeclarationDoc>
