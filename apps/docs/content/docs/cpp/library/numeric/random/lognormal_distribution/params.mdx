Returns the parameters the distribution was constructed with.

{/* source:cpp-numeric-random-lognormal-distribution-params:0002 */}
1. Returns the log-mean m distribution parameter. It defines the location of the peak. The default value is `0.0`.

{/* source:cpp-numeric-random-lognormal-distribution-params:0003 */}
2. Returns the log-deviation s distribution parameter. The default value is `1.0`.

  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-numeric-random-lognormal-distribution-params:0004 */}
(none)

### Return value

{/* source:cpp-numeric-random-lognormal-distribution-params:0005 */}
1. The log-mean m distribution parameter.

{/* source:cpp-numeric-random-lognormal-distribution-params:0006 */}
2. The log-deviation s distribution parameter.
