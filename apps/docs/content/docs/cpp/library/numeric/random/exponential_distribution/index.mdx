{/* source:cpp-numeric-random-exponential-distribution:0001 */}
Produces random non-negative floating-point values x, distributed according to probability density function:

{/* source:cpp-numeric-random-exponential-distribution:0002 */}
P(x|λ) = λe-λx

{/* source:cpp-numeric-random-exponential-distribution:0003 */}
The value obtained is the time/distance until the next random event if random events occur at constant rate λ per unit of time/distance. For example, this distribution describes the time between the clicks of a Geiger counter or the distance between point mutations in a DNA strand.

{/* source:cpp-numeric-random-exponential-distribution:0004 */}
This is the continuous counterpart of [`std::geometric_distribution`](/docs/cpp/library/numeric/random/geometric_distribution).

{/* source:cpp-numeric-random-exponential-distribution:0005 */}
`std::exponential_distribution` satisfies [*RandomNumberDistribution*](/docs/cpp/library/named_req/RandomNumberDistribution).

### Notes

{/* source:cpp-numeric-random-exponential-distribution:0010 */}
Some implementations may occasionally return infinity if `RealType` is `float`. This is [LWG issue 2524](https://cplusplus.github.io/LWG/issue2524).

### Example

{/* source:cpp-numeric-random-exponential-distribution:0011 */}
```cpp
#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>
 
int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
 
    // if particles decay once per second on average,
    // how much time, in seconds, until the next one?
    std::exponential_distribution<> d(1);
 
    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[2 * d(gen)];
 
    for (auto const& [x, y] : hist)
        std::cout << std::fixed << std::setprecision(1)
                  << x / 2.0 << '-' << (x + 1) / 2.0 << ' '
                  << std::string(y / 200, '*') << '\n';
}
```

Possible output:

```text
0.0-0.5 *******************
0.5-1.0 ***********
1.0-1.5 *******
1.5-2.0 ****
2.0-2.5 **
2.5-3.0 *
3.0-3.5
3.5-4.0
```
