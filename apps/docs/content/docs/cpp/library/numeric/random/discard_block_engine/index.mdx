`discard_block_engine` is a pseudo-random number engine adaptor that discards a certain amount of data produced by the base engine. From each block of size `P` generated by the base engine, the adaptor keeps only `R` numbers, discarding the rest.

### Template parameters

{/* source:cpp-numeric-random-discard-block-engine:0002 */}
<ParameterList>
  <Parameter name="Engine">the type of the wrapped engine.</Parameter>
  <Parameter name="P">the size of a block. Expected that P \> 0.</Parameter>
  <Parameter name="R">the number of used numbers per block. Expected that 0 \< R ≤ P.</Parameter>
</ParameterList>

Type requirements
- `Engine` must meet the requirements of [*RandomNumberEngine*](/docs/cpp/library/named_req/RandomNumberEngine).
