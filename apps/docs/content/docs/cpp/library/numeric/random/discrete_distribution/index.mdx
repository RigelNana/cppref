{/* source:cpp-numeric-random-discrete-distribution:0001 */}
`std::discrete_distribution` produces random integers on the interval `[``0``,``n``)`, where the probability of each individual integer `i` is defined as wi/S, that is the <i>weight</i> of the `i`th integer divided by the sum of all `n` weights.

{/* source:cpp-numeric-random-discrete-distribution:0002 */}
`std::discrete_distribution` satisfies all requirements of [*RandomNumberDistribution*](/docs/cpp/library/named_req/RandomNumberDistribution).

### Example

{/* source:cpp-numeric-random-discrete-distribution:0007 */}
```cpp
#include <iomanip>
#include <iostream>
#include <map>
#include <random>
 
int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    std::discrete_distribution<> d({40, 10, 10, 40});
    std::map<int, int> map;
 
    for (int n = 0; n < 1e4; ++n)
        ++map[d(gen)];
 
    for (const auto& [num, count] : map)
        std::cout << num << " generated " << std::setw(4) << count << " times\n";
}
```

Possible output:

```text
0 generated 4037 times
1 generated  962 times
2 generated 1030 times
3 generated 3971 times
```
