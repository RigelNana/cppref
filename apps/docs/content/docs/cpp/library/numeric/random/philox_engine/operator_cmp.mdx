{/* source:cpp-numeric-random-philox-engine-operator-cmp:0001 */}
Compares two pseudo-random number engines. Two engines are equal, if their internal states are equivalent, that is, if they would generate equivalent values for any number of calls of `operator()`.

{/* source:cpp-numeric-random-philox-engine-operator-cmp:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `decltype(*this)` is an associated class of the arguments.

{/* source:cpp-numeric-random-philox-engine-operator-cmp:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Parameters

{/* source:cpp-numeric-random-philox-engine-operator-cmp:0004 */}
<ParameterList>
  <Parameter name="lhs, rhs">engines to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-random-philox-engine-operator-cmp:0005 */}
`true` if the engines are equal, `false` otherwise.
