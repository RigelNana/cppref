{/* source:cpp-numeric-random-mersenne-twister-engine-operator-cmp:0001 */}
Compares two pseudo-random number engines. Two engines are equal, if their internal states are equivalent, that is, if they would generate equivalent values for any number of calls of `operator()`.

{/* source:cpp-numeric-random-mersenne-twister-engine-operator-cmp:0002 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when std::mersenne_twister_engine\<UIntType, w, n, m, r, a, u, d, s, b, t, c, l, f\> is an associated class of the arguments.

{/* source:cpp-numeric-random-mersenne-twister-engine-operator-cmp:0003 */}
<Revision since="C++20">

The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

</Revision>

### Return value

{/* source:cpp-numeric-random-mersenne-twister-engine-operator-cmp:0005 */}
1. `true` if the engines are equal, `false` otherwise.

{/* source:cpp-numeric-random-mersenne-twister-engine-operator-cmp:0006 */}
2. `true` if the engines are not equal, `false` otherwise.
