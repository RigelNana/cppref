{/* source:cpp-numeric-random-independent-bits-engine-operator-cmp:0001 */}
Compares two pseudo-random number engine adaptors. Two engine adaptors are equal, if their underlying engines are equal and their internal state (if any) is equal, that is, if they would generate equivalent values for any number of calls of `operator()`.

{/* source:cpp-numeric-random-independent-bits-engine-operator-cmp:0002 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when std::independent_bits_engine\<Engine, w, UIntType\> is an associated class of the arguments.

{/* source:cpp-numeric-random-independent-bits-engine-operator-cmp:0003 */}
<Revision since="C++20">

The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

</Revision>

### Parameters

{/* source:cpp-numeric-random-independent-bits-engine-operator-cmp:0004 */}
<ParameterList>
  <Parameter name="lhs, rhs">engine adaptors to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-random-independent-bits-engine-operator-cmp:0005 */}
1. `true` if the engine adaptors are equivalent, `false` otherwise.

{/* source:cpp-numeric-random-independent-bits-engine-operator-cmp:0006 */}
2. `true` if the engine adaptors are not equivalent, `false` otherwise.

### Exceptions

{/* source:cpp-numeric-random-independent-bits-engine-operator-cmp:0007 */}
Throws nothing.
