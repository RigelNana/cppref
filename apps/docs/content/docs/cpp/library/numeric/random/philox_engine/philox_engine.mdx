{/* source:cpp-numeric-random-philox-engine-philox-engine:0001 */}
Constructs the pseudo-random number engine.

{/* source:cpp-numeric-random-philox-engine-philox-engine:0002 */}
1. The default constructor. If the default-constructed engine is of type `std::philox4x32`, the 10000th consecutive invocation of it produces the value `1955073260`. If the default-constructed engine is of type `std::philox4x64`, the 10000th consecutive invocation of it produces the value `3409172418970261260`.

{/* source:cpp-numeric-random-philox-engine-philox-engine:0003 */}
2. Constructs the engine with a seed value `value`. The engine's initial [state](/docs/cpp/library/numeric/random/philox_engine#Generator_properties) is determined as follows: [[1]](/docs/cpp/numeric/random/philox_engine/philox_engine#cite_note-y-1) All elements of the sequence `X` are set to zero. The first element of the sequence `K` is set to value mod 2w , the remaining elements are set to zero. The value of `j` is set to `n - 1`.

{/* source:cpp-numeric-random-philox-engine-philox-engine:0004 */}
3. Constructs the engine with a seed sequence `seq`. The engine's initial [state](/docs/cpp/library/numeric/random/philox_engine#Generator_properties) is determined as follows: [[1]](/docs/cpp/numeric/random/philox_engine/philox_engine#cite_note-y-1) All elements of the sequence `X` are set to zero. Given `(w - 1) / 32 + 1` as `p`, the elements of the sequence `K` are set by the following steps: Creates an invented array object `a` of length `n / 2 * p`. Calls `seq.generate(a + 0, a + n / 2 * p)`. For each integer `k` in [`0`, `n / 2``)`, sets Kk to (∑p-1 i=0 ak·p+i·232i ) mod 2w . The value of `j` is set to `n - 1`.

{/* source:cpp-numeric-random-philox-engine-philox-engine:0005 */}
This overload participates in overload resolution only if `SeedSeq` meets the requirements of [*SeedSequence*](/docs/cpp/library/named_req/SeedSequence).

{/* source:cpp-numeric-random-philox-engine-philox-engine:0006 */}
4. The copy constructor. Upon construction, `*this == other` is `true`.

1. [1.1](/docs/cpp/numeric/random/philox_engine/philox_engine#cite_ref-y_1-1) The buffer `Y` is intentionally not being set. As `j` is being set to `n - 1`, the next state transition always generates new random values and stores them in `Y`.
