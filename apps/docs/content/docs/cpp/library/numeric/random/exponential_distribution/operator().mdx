Generates random numbers that are distributed according to the associated probability function. The entropy is acquired by calling `g.operator()`. 

{/* source:cpp-numeric-random-exponential-distribution-operator:0002 */}
The first version uses the associated parameter set, the second version uses `params`. The associated parameter set is not modified.

### Parameters

{/* source:cpp-numeric-random-exponential-distribution-operator:0003 */}
<ParameterList>
  <Parameter name="g">a uniform random bit generator object</Parameter>
  <Parameter name="params">distribution parameter set to use instead of the associated one</Parameter>
</ParameterList>

Type requirements
- `Generator` must meet the requirements of [*UniformRandomBitGenerator*](/docs/cpp/library/named_req/UniformRandomBitGenerator).

### Return value

{/* source:cpp-numeric-random-exponential-distribution-operator:0004 */}
The generated random number.

### Complexity

{/* source:cpp-numeric-random-exponential-distribution-operator:0005 */}
Amortized constant number of invocations of `g.operator()`.
