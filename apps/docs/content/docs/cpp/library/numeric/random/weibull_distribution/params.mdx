    Returns the parameters the distribution was constructed with.

    {/* source:cpp-numeric-random-weibull-distribution-params:0002 */}
    1. Returns the a parameter. It defines the shape of the distribution. The default value is `1.0`.

    {/* source:cpp-numeric-random-weibull-distribution-params:0003 */}
    2. Returns the b parameter. It defines the scale of the distribution. The default value is `1.0`.

  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-numeric-random-weibull-distribution-params:0006 */}
