    {/* source:cpp-numeric-random-piecewise-linear-distribution-piecewise-linear-distribution:0001 */}
    Constructs new piecewise linear distribution object.

    {/* source:cpp-numeric-random-piecewise-linear-distribution-piecewise-linear-distribution:0002 */}
    1. Constructs a distribution object with <i>n</i> = 1, <i>ρ0</i> = 1, <i>b0</i> = 0, and <i>b1</i> = 1.

    {/* source:cpp-numeric-random-piecewise-linear-distribution-piecewise-linear-distribution:0003 */}
    2. Constructs a distribution object from iterators over the interval sequence `[first_i, last_i)` and a matching weight sequence starting at `first_w`.

    {/* source:cpp-numeric-random-piecewise-linear-distribution-piecewise-linear-distribution:0004 */}
    3. Constructs a distribution object where the intervals are taken from the initializer list `ilist` and the weights generated by the function `fw`.

    {/* source:cpp-numeric-random-piecewise-linear-distribution-piecewise-linear-distribution:0005 */}
    4. Constructs a distribution object with the `fw` intervals distributed uniformly over `[xmin, xmax]`.

    {/* source:cpp-numeric-random-piecewise-linear-distribution-piecewise-linear-distribution:0006 */}
    5. Constructs a distribution object initialized with the parameters `param`.

  </DeclarationDescription>
