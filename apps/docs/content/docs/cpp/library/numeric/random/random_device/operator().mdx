### Parameters

{/* source:cpp-numeric-random-random-device-operator:0002 */}
(none)

### Return value

{/* source:cpp-numeric-random-random-device-operator:0003 */}
A random number uniformly distributed in \[`min()`, `max()`\].

### Exceptions

{/* source:cpp-numeric-random-random-device-operator:0004 */}
Throws an implementation-defined exception derived from [`std::exception`](/docs/cpp/library/error/exception) if a random number could not be generated.
