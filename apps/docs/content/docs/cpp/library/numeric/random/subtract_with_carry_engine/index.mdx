### Generator properties

{/* source:cpp-numeric-random-subtract-with-carry-engine:0004 */}
The [size](/docs/cpp/library/numeric/random#Random_number_engines) of the states of `subtract_with_carry_engine` is O(r), each of them consists of two parts:

{/* source:cpp-numeric-random-subtract-with-carry-engine:0005 */}
- A sequence `X` of `r` integer values, where each value is in `[0, 2w )`.
- An integer `c` (known as the <i>carry</i>), whose value is either `0` or `1`.

{/* source:cpp-numeric-random-subtract-with-carry-engine:0006 */}
Given that Xj stands for the j mod rth value (starting from 0) of `X`, the [transition algorithm](/docs/cpp/library/numeric/random#Random_number_engines) of `subtract_with_carry_engine` (TA(xi)) is defined as follows:

{/* source:cpp-numeric-random-subtract-with-carry-engine:0007 */}
1. Let `Y` be Xi-s-Xi-r-c.
2. Let `y` be Y mod 2w , and set Xi to `y`.
3. If `Y` is negative, set `c` to `1`, otherwise set `c` to `0`.

{/* source:cpp-numeric-random-subtract-with-carry-engine:0008 */}
The [generation algorithm](/docs/cpp/library/numeric/random#Random_number_engines) of `subtract_with_carry_engine` is GA(xi) = y, where `y` is the value produced in step 2 of the transition algorithm.
