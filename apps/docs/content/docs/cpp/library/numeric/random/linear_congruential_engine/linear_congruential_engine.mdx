{/* source:cpp-numeric-random-linear-congruential-engine-linear-congruential-engine:0001 */}
Constructs the pseudo-random number engine.

{/* source:cpp-numeric-random-linear-congruential-engine-linear-congruential-engine:0002 */}
1. The default constructor. If the default-constructed engine is of type `std::minstd_rand0`, the 10000th consecutive invocation of it produces the value `1043618065`. If the default-constructed engine is of type `std::minstd_rand`, the 10000th consecutive invocation of it produces the value `399268537`.

{/* source:cpp-numeric-random-linear-congruential-engine-linear-congruential-engine:0003 */}
2. Constructs the engine with a seed value `value`. The engine's initial [state](/docs/cpp/library/numeric/random/linear_congruential_engine#Generator_properties) is determined as follows: If `c % m == 0` and `value % m == 0` are both `true`, the state is `1`. Otherwise, the state is `value % m`.

{/* source:cpp-numeric-random-linear-congruential-engine-linear-congruential-engine:0004 */}
3. Constructs the engine with a seed sequence `seq`. Given std::size_t(std::log2(m) / 32) + 1 as `k`, the engine's initial [state](/docs/cpp/library/numeric/random/linear_congruential_engine#Generator_properties) is determined as follows: Creates an invented array object `a` of length `k + 3`. Calls `seq.generate(a + 0, a + k + 3)`. Let `S` be (∑k-1 j=0 aj+3·232j ) mod m. If both `c % m == 0` and `S == 0` are `true`, sets the engine's state to `1`. Otherwise, sets the engine’s state to `S`.

{/* source:cpp-numeric-random-linear-congruential-engine-linear-congruential-engine:0005 */}
This overload participates in overload resolution only if `SeedSeq` meets the requirements of [*SeedSequence*](/docs/cpp/library/named_req/SeedSequence).

{/* source:cpp-numeric-random-linear-congruential-engine-linear-congruential-engine:0006 */}
4. The copy constructor. Upon construction, `*this == other` is `true`.
