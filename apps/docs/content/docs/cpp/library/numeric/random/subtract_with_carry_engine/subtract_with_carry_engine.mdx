    {/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0001 */}
    Constructs the pseudo-random number engine.

    {/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0002 */}
    1. The default constructor.
       - If the default-constructed engine is of type `std::ranlux24_base`, the 10000th consecutive invocation of it produces the value `7937952`.
       - If the default-constructed engine is of type `std::ranlux48_base`, the 10000th consecutive invocation of it produces the value `61839128582725`.

    {/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0003 */}
    2. Constructs the engine with a seed value `value`. The sequence `X` of the engine's initial [state](/docs/cpp/library/numeric/random/subtract_with_carry_engine#Generator_properties) is determined as follows: Constructs a `std::linear_congruential_engine<std::uint_least32_t, 40014u, 0u, 2147483563u>` object `e` with argument `value == 0u ? default_seed : static_cast<std::uint_least32_t>(value % 2147483563u)`. Let `n` be `std::size_t(w / 32) + 1`. Sets the values of X-r, ..., X-1, in that order. Each value Xi is set as specified below: Successively calls `e` for `n` times, the return values are denoted as z0 ... zn-1. Sets Xi to (∑n-1 j=0 zj·232j ) mod m.

    {/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0004 */}
    If X-1 is `0`, sets the carry value `c` of the engine's initial state to `1`. Otherwise, sets `c` to `0`.

    {/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0005 */}
    3. Constructs the engine with a seed sequence `seq`. Given `std::size_t(w / 32) + 1` as `k`, the sequence `X` of the engine's initial [state](/docs/cpp/library/numeric/random/subtract_with_carry_engine#Generator_properties) is determined as follows: Creates an invented array object `a` of length `r * k`. Calls `seq.generate(a + 0, a + r * k)`. For each integer `i` in `[-r, -1]`, sets Xi to (∑k-1 j=0 ak(i+r)+j·232j ) mod m.

    {/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0006 */}
    If X-1 is `0`, sets the carry value `c` of the engine's initial state to `1`. Otherwise, sets `c` to `0`.

    {/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0007 */}
    This overload participates in overload resolution only if `SeedSeq` meets the requirements of [*SeedSequence*](/docs/cpp/library/named_req/SeedSequence).

    {/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0008 */}
    4. The copy constructor. Upon construction, `*this == other` is `true`.

### Complexity

{/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0010 */}
`(std::size_t(w / 32) + 1) * r` invocations of `e`.

{/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0011 */}
3. Same as the complexity of the `seq.generate` call.

{/* source:cpp-numeric-random-subtract-with-carry-engine-subtract-with-carry-engine:0012 */}
4. O(r).

### Example

```cpp
#include <cassert>
#include <random>
 
int main()
{
    std::ranlux24_base gen24; // overload (1)
    std::ranlux48_base gen48; // overload (1)
    gen24.discard(10000 - 1);
    gen48.discard(10000 - 1);
    assert(gen24() == 7'937'952);
    assert(gen48() == 61'839'128'582'725);
}
```
