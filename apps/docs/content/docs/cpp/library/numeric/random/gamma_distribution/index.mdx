{/* source:cpp-numeric-random-gamma-distribution:0001 */}
Produces random positive floating-point values x, distributed according to probability density function:

{/* source:cpp-numeric-random-gamma-distribution:0002 */}
P(x|α,β) = e-x/β βα · Γ(α) · xα-1

{/* source:cpp-numeric-random-gamma-distribution:0003 */}
where α is known as the <i>shape</i> parameter and β is known as the <i>scale</i> parameter. The shape parameter is sometimes denoted by the letter k and the scale parameter is sometimes denoted by the letter θ.

{/* source:cpp-numeric-random-gamma-distribution:0004 */}
For floating-point α, the value obtained is the sum of α independent exponentially distributed random variables, each of which has a mean of β.

{/* source:cpp-numeric-random-gamma-distribution:0005 */}
`std::gamma_distribution` satisfies [*RandomNumberDistribution*](/docs/cpp/library/named_req/RandomNumberDistribution).

### Example

{/* source:cpp-numeric-random-gamma-distribution:0010 */}
```cpp
#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>
 
int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
 
    // A gamma distribution with alpha = 1, and beta = 2
    // approximates an exponential distribution.
    std::gamma_distribution<> d(1, 2);
 
    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[2 * d(gen)];
 
    for (auto const& [x, y] : hist)
        if (y / 100.0 > 0.5)
            std::cout << std::fixed << std::setprecision(1)
                      << x / 2.0 << '-' << (x + 1) / 2.0 << ' '
                      << std::string(y / 100, '*') << '\n';
}
```
