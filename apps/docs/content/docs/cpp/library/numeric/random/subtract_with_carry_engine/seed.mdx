    {/* source:cpp-numeric-random-subtract-with-carry-engine-seed:0002 */}

    {/* source:cpp-numeric-random-subtract-with-carry-engine-seed:0003 */}
    2. Right after the state is set, `*this == std::subtract_with_carry_engine(seq)` is `true`.

  </DeclarationDescription>
