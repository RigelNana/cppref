{/* source:cpp-numeric-random-linear-congruential-engine-discard:0001 */}
Advances the internal state by `z` times.

### Parameters

{/* source:cpp-numeric-random-linear-congruential-engine-discard:0002 */}
<ParameterList>
  <Parameter name="z">integer value specifying the number of times to advance the state by</Parameter>
</ParameterList>

### Complexity

{/* source:cpp-numeric-random-linear-congruential-engine-discard:0003 */}
No worse than the complexity of `z` consecutive calls to [`operator()`](/docs/cpp/library/numeric/random/linear_congruential_engine/operator()).

### Notes

{/* source:cpp-numeric-random-linear-congruential-engine-discard:0004 */}
This function can use “fast jump” algorithms which advance the state by many steps (order of millions) without calculating intermediate state transitions can be used instead of naive loops that calls [`operator()`](/docs/cpp/library/numeric/random/linear_congruential_engine/operator()) `z` times and discarding the result.
