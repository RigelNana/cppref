{/* source:cpp-numeric-random-philox-engine:0001 */}
`std::philox_engine` is a counter-based random number engine.

### Template parameters

{/* source:cpp-numeric-random-philox-engine:0002 */}
<ParameterList>
  <Parameter name="UIntType">The result type generated by the generator. The effect is undefined if this is not one of `unsigned short`, `unsigned int`, `unsigned long`, or `unsigned long long`.</Parameter>
  <Parameter name="w">the word size in bits</Parameter>
  <Parameter name="n">the word count</Parameter>
  <Parameter name="r">the round count</Parameter>
  <Parameter name="consts">the sequence of multipliers and round constants used for generating random numbers</Parameter>
</ParameterList>

{/* source:cpp-numeric-random-philox-engine:0003 */}
If any of the following values is not `true`, the program is ill-formed:

{/* source:cpp-numeric-random-philox-engine:0004 */}
- `sizeof...(consts) == n`
- `n == 2 || n == 4 || n == 8 || n == 16`
- `0 < r`
- 0 \< w && w \<= std::numeric_limits\<UIntType\>::digits

### Generator properties

{/* source:cpp-numeric-random-philox-engine:0005 */}
In the following description, let Qi denote the ith element of sequence `Q`, where the subscript starts from zero.

{/* source:cpp-numeric-random-philox-engine:0006 */}
The [size](/docs/cpp/library/numeric/random#Random_number_engines) of the states of `philox_engine` is O(n), each of them consists of four parts:

{/* source:cpp-numeric-random-philox-engine:0007 */}
- A sequence `X` of `n` integer values, where each value is in [`0`, `2w``)`.

{/* source:cpp-numeric-random-philox-engine:0008 */}
- This sequence represents a large unsigned integer counter value Z=∑n-1 j=0X⋅2wj  of n⋅w bits.

{/* source:cpp-numeric-random-philox-engine:0009 */}
- A sequence `K` of `n / 2` keys of type `UIntType`.
- A buffer `Y` of `n` produced values of type `UIntType`.
- An index `j` in `Y` buffer.

{/* source:cpp-numeric-random-philox-engine:0010 */}
The [transition algorithm](/docs/cpp/library/numeric/random#Random_number_engines) of `philox_engine` ( TA(Xi)) is defined as follows:

{/* source:cpp-numeric-random-philox-engine:0011 */}
- If `j` is not `n - 1`, increments `j` by `1`.[[1]](/docs/cpp/numeric/random/philox_engine#cite_note-1)
- If `j` is `n - 1`, performs the following operations:[[2]](/docs/cpp/numeric/random/philox_engine#cite_note-2)

{/* source:cpp-numeric-random-philox-engine:0012 */}
1. Generates a new sequence of `n` random values (see below) and stores them in `Y`.
1. Increments the counter `Z` by `1`.
1. Resets `j` to `0`.

{/* source:cpp-numeric-random-philox-engine:0013 */}
The [generation algorithm](/docs/cpp/library/numeric/random#Random_number_engines) of `philox_engine` is GA(Xi)=Yj.

{/* source:cpp-numeric-random-philox-engine:0014 */}
1. [↑](/docs/cpp/numeric/random/philox_engine#cite_ref-1) In this case, the next generation algorithm call returns the next generated value in the buffer.
2. [↑](/docs/cpp/numeric/random/philox_engine#cite_ref-2) In this case, the buffer is refreshed, and the next generation algorithm call returns the first value in the new buffer.

#### Generating random values

{/* source:cpp-numeric-random-philox-engine:0015 */}
Random values are generated from the following parameters:

{/* source:cpp-numeric-random-philox-engine:0016 */}
- the number of rounds `r`
- the current counter sequence `X`
- the key sequence `K`
- the multiplier sequence `M`
- the round constant sequence `C`

{/* source:cpp-numeric-random-philox-engine:0017 */}
The sequences `M` and `C` are formed from the values from template parameter pack `consts`, which represents the Mk and Ck constants as [ M0, C0, M1, C1,... , ..., Mn/2-1, Cn/2-1].

{/* source:cpp-numeric-random-philox-engine:0018 */}
Random numbers are generated by the following process:

{/* source:cpp-numeric-random-philox-engine:0019 */}
1. Initializes the output sequence `S` with the elements of `X`.
1. Updates the elements of `S` for `r` rounds.
1. Replaces the values in the buffer `Y` with the values in `S`.

#### Updating the output sequence

{/* source:cpp-numeric-random-philox-engine:0020 */}
For each round of update, an intermediate sequence `V` is initialized with the elements of `S` in a specified order:

{/* source:cpp-numeric-random-philox-engine:0021 */}
| `n` | V0 | V1 | V2 | V3 | V4 | V5 | V6 | V7 | V8 | V9 | V10 | V11 | V12 | V13 | V14 | V15 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `2` | S0 | S1 | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A |
| `4` | S0 | S3 | S2 | S1 | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A |
| `8` | S2 | S1 | S4 | S7 | S6 | S5 | S0 | S3 | N/A | N/A | N/A | N/A | N/A | N/A | N/A | N/A |
| `16` | S0 | S9 | S2 | S13 | S6 | S11 | S4 | S15 | S10 | S7 | S12 | S3 | S14 | S5 | S8 | S1 |

{/* source:cpp-numeric-random-philox-engine:0022 */}
Given the following operation notations:

{/* source:cpp-numeric-random-philox-engine:0023 */}
- xor, built-in [bitwise XOR](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_logic_operators).
- mullo, it calcuates the low half of modular multiplication and is defined as mullo(a,b,w)=(a⋅b) mod 2w .
- mulhi, it calcuates the high half of multiplication and is defined as mulhi(a,b,w)=⌊(a⋅b)/2w ⌋.

{/* source:cpp-numeric-random-philox-engine:0024 */}
Let `q` be the current round number (starting from zero), for each integer `k` in [`0`, `n / 2``)`, the elements of the output sequence `S` are updated as follows:

{/* source:cpp-numeric-random-philox-engine:0025 */}
- X2⋅k=mullo(V2⋅k+1,Mk,w)
- X2⋅k+1=mulhi(V2⋅k+1,Mk,w) xor ((Kk+q⋅Ck) mod 2w ) xor V2⋅k
