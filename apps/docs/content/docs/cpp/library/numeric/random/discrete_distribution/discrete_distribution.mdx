{/* source:cpp-numeric-random-discrete-distribution-discrete-distribution:0001 */}
Constructs a new distribution object. 

{/* source:cpp-numeric-random-discrete-distribution-discrete-distribution:0002 */}
1. Default constructor. Constructs the distribution with a single weight p = \{1\}. This distribution will always generate `0`.

{/* source:cpp-numeric-random-discrete-distribution-discrete-distribution:0003 */}
2. Constructs the distribution with weights in the range `[``first``,``last``)`. If `first == last`, the effects are the same as of the default constructor.

{/* source:cpp-numeric-random-discrete-distribution-discrete-distribution:0004 */}
3. Constructs the distribution with weights in `weights`. Effectively calls `discrete_distribution(weights.begin(), weights.end())`.

{/* source:cpp-numeric-random-discrete-distribution-discrete-distribution:0005 */}
4. Constructs the distribution with `count` weights that are generated using function `unary_op`. Each of the weights is equal to wi = unary_op(xmin + δ(i + 0.5)), where δ = (xmax − xmin)count and i ∈ \{0, ..., count − 1\}. `xmin` and `xmax` must be such that δ \> 0. If `count == 0` the effects are the same as of the default constructor.

{/* source:cpp-numeric-random-discrete-distribution-discrete-distribution:0006 */}
5. Constructs the distribution with `params` as the distribution parameters.

### Parameters

{/* source:cpp-numeric-random-discrete-distribution-discrete-distribution:0007 */}
<ParameterList>
  <Parameter name="first, last">the range of elements defining the numbers to use as weights. The type of the elements referred by `InputIterator` must be convertible to `double`</Parameter>
  <Parameter name="weights">initializer list containing the weights</Parameter>
  <Parameter name="unary_op">unary operation function object that will be applied. <br /> The signature of the function should be equivalent to the following: `Ret fun(const Type &a);` The signature does not need to have `const &`. <br />The type `Type` must be such that an object of type `double` can be dereferenced and then implicitly converted to `Type`. The type `Ret` must be such that an object of type `double` can be dereferenced and assigned a value of type `Ret`.</Parameter>
  <Parameter name="params">the distribution parameter set</Parameter>
</ParameterList>

Type requirements
