{/* source:cpp-numeric-random-mersenne-twister-engine:0001 */}
`mersenne_twister_engine` is a random number engine based on [Mersenne Twister](https://en.wikipedia.org/wiki/Mersenne_Twister) algorithm. It produces high quality, but not cryptographically secure, unsigned integer random numbers of type `UIntType` on the interval [0, 2w ).

### Template parameters

{/* source:cpp-numeric-random-mersenne-twister-engine:0002 */}
<ParameterList>
  <Parameter name="UIntType">The result type generated by the generator. The effect is undefined if this is not one of `unsigned short`, `unsigned int`, `unsigned long`, or `unsigned long long`.</Parameter>
  <Parameter name="w">the power of two that determines the range of values generated by the engine</Parameter>
  <Parameter name="n">the degree of recurrence</Parameter>
  <Parameter name="m">the middle word, an offset used in the recurrence relation defining the state</Parameter>
  <Parameter name="r">the number of bits of the lower bit-mask, also known as the twist value</Parameter>
  <Parameter name="a">the conditional xor-mask, i.e. the coefficients of the rational normal form twist matrix</Parameter>
  <Parameter name="u, d, s, b, t, c, l">the 1st to 7th components of the bit-scrambling (tempering) matrix</Parameter>
  <Parameter name="f">the initialization multiplier</Parameter>
</ParameterList>

{/* source:cpp-numeric-random-mersenne-twister-engine:0003 */}
If any of the following restrictions is violated, the program is ill-formed:

{/* source:cpp-numeric-random-mersenne-twister-engine:0004 */}
- `m` is in [`1`, `n``]`.
- The following expressions are all `true`:

{/* source:cpp-numeric-random-mersenne-twister-engine:0005 */}
- `w >= 3`
- `w >= r`
- `w >= u`
- `w >= s`
- `w >= t`
- `w >= l`
- w \<= std::numeric_limits\<UIntType\>::digits

{/* source:cpp-numeric-random-mersenne-twister-engine:0006 */}
- Given `(1u << w) - 1u` as `w1`, the following expressions are all `true`:

{/* source:cpp-numeric-random-mersenne-twister-engine:0007 */}
- `a <= w1`
- `b <= w1`
- `c <= w1`
- `d <= w1`
- `f <= w1`

### Generator properties

{/* source:cpp-numeric-random-mersenne-twister-engine:0008 */}
The [size](/docs/cpp/library/numeric/random#Random_number_engines) of the states of `mersenne_twister_engine` is `n`, each of them consists of a sequence `X` of `n` values of type `result_type`. Xj stands for the j mod nth value (starting from 0) of `X`.

{/* source:cpp-numeric-random-mersenne-twister-engine:0009 */}
Given the following bitwise operation notations:

{/* source:cpp-numeric-random-mersenne-twister-engine:0010 */}
- bitand, built-in [bitwise AND](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_logic_operators).
- xor, built-in [bitwise XOR](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_logic_operators).
- lshift, built-in [bitwise left-shift](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_shift_operators).
- rshift, built-in [bitwise right-shift](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_shift_operators).

{/* source:cpp-numeric-random-mersenne-twister-engine:0011 */}
The [transition algorithm](/docs/cpp/library/numeric/random#Random_number_engines) of `mersenne_twister_engine` ( TA(xi)) is defined as follows:

{/* source:cpp-numeric-random-mersenne-twister-engine:0012 */}
1. Concatenate the upper `w - r` bits of Xi-n with the lower `r` bits of Xi+1-n to obtain an unsigned integer value `Y`.
1. Let `y` be a·(Y bitand 1), and set Xi to Xi+m−n xor (Y rshift 1) xor y.

{/* source:cpp-numeric-random-mersenne-twister-engine:0013 */}
The [generation algorithm](/docs/cpp/library/numeric/random#Random_number_engines) of `mersenne_twister_engine` ( GA(xi)) is defined as follows:

{/* source:cpp-numeric-random-mersenne-twister-engine:0014 */}
1. Let z1 be Xi xor ((Xi rshift u) bitand d).
1. Let z2 be Xi xor (((Xi lshift s) mod 2w ) bitand b).
1. Let z3 be Xi xor (((Xi lshift t) mod 2w ) bitand c).
1. Let z4 be z3 xor (z3 rshift l).
1. Deliver z4 as the result (i.e. GA(xi)=z4).
