### Notes

{/* source:cpp-numeric-random-negative-binomial-distribution-negative-binomial-distribution:0005 */}
Requires that 0 \< p ≤ 1 and 0 \< k.

{/* source:cpp-numeric-random-negative-binomial-distribution-negative-binomial-distribution:0006 */}
If `p == 1`, subsequent calls to the [operator()](/docs/cpp/library/numeric/random/negative_binomial_distribution/operator()) overload that does not accept a `param_type` object will cause undefined behavior.

{/* source:cpp-numeric-random-negative-binomial-distribution-negative-binomial-distribution:0007 */}
The default-constructed `std::negative_binomial_distribution` is equivalent to the default-constructed [`std::geometric_distribution`](/docs/cpp/library/numeric/random/geometric_distribution).
