{/* source:cpp-numeric-random-piecewise-constant-distribution:0001 */}
`std::piecewise_constant_distribution` produces random floating-point numbers, which are uniformly distributed within each of the several subintervals [bi, bi+1), each with its own weight wi. The set of interval boundaries and the set of weights are the parameters of this distribution.

{/* source:cpp-numeric-random-piecewise-constant-distribution:0002 */}
wi S (bi+1 - bi)

{/* source:cpp-numeric-random-piecewise-constant-distribution:0003 */}
[`std::piecewise_constant_distribution`](/docs/cpp/library/numeric/random/piecewise_constant_distribution#top) satisfies all requirements of [*RandomNumberDistribution*](/docs/cpp/library/named_req/RandomNumberDistribution).

### Example

{/* source:cpp-numeric-random-piecewise-constant-distribution:0008 */}
```cpp
#include <iostream>
#include <map>
#include <random>
#include <string>
 
int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    // 50% of the time, generate a random number between 0 and 1
    // 50% of the time, generate a random number between 10 and 15
    std::vector<double> i {0, 1, 10, 15};
    std::vector<double> w {1, 0, 1};
    std::piecewise_constant_distribution<> d(i.begin(), i.end(), w.begin());
 
    std::map<int, int> hist;
    for (int n {}; n < 1e4; ++n)
        ++hist[d(gen)];
 
    for (std::cout << std::hex << std::uppercase; auto [x, y] : hist)
        std::cout << x << ' ' << std::string(y / 100, '*') << '\n';
}
```

Possible output:

```text
0 **************************************************
A **********
B *********
C *********
D **********
E *********
```
