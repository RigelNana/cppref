{/* source:cpp-numeric-random-linear-congruential-engine:0001 */}
`linear_congruential_engine` is a random number engine based on [Linear congruential generator](https://en.wikipedia.org/wiki/Linear_congruential_generator) (LCG).

### Template parameters

{/* source:cpp-numeric-random-linear-congruential-engine:0002 */}
<ParameterList>
  <Parameter name="UIntType">The result type generated by the generator. The effect is undefined if this is not one of `unsigned short`, `unsigned int`, `unsigned long`, or `unsigned long long`.</Parameter>
  <Parameter name="a">the multiplier term</Parameter>
  <Parameter name="c">the increment term</Parameter>
  <Parameter name="m">the modulus term</Parameter>
</ParameterList>

{/* source:cpp-numeric-random-linear-congruential-engine:0003 */}
When `m` is not zero, if `a >= m` or `c >= m` is `true`, the program is ill-formed.

### Generator properties

{/* source:cpp-numeric-random-linear-congruential-engine:0004 */}
The [size](/docs/cpp/library/numeric/random#Random_number_engines) of the states of `linear_congruential_engine` is `1`, each of them consists of a single integer.

{/* source:cpp-numeric-random-linear-congruential-engine:0005 */}
The actual modulus m0 is defined as follows:

{/* source:cpp-numeric-random-linear-congruential-engine:0006 */}
- If `m` is not zero, m0 is `m`.
- If `m` is zero, m0 is the value of std::numeric_limits\<result_type\>::max() plus `1` (which means m0 need not be representable as `result_type`).

{/* source:cpp-numeric-random-linear-congruential-engine:0007 */}
The [transition algorithm](/docs/cpp/library/numeric/random#Random_number_engines) of `linear_congruential_engine` is TA(xi) = (a·xi+c) mod m0.

{/* source:cpp-numeric-random-linear-congruential-engine:0008 */}
The [generation algorithm](/docs/cpp/library/numeric/random#Random_number_engines) of `linear_congruential_engine` is GA(xi) = (a·xi+c) mod m0.

{/* source:cpp-numeric-random-linear-congruential-engine:0009 */}
The pseudo-random number generated with the current state is also the successor state.
