{/* source:cpp-numeric-random-philox-engine-set-counter:0001 */}
Sets the [counter](/docs/cpp/library/numeric/random/philox_engine#Generator_properties) of the random-number engine.

{/* source:cpp-numeric-random-philox-engine-set-counter:0002 */}
- For each integer `k` in [`0`, `n``)`, sets Xk to cn-1-k mod 2w .
- The value of `j` is set to `n - 1`.[[1]](/docs/cpp/numeric/random/philox_engine/set_counter#cite_note-1)

{/* source:cpp-numeric-random-philox-engine-set-counter:0003 */}
1. [↑](/docs/cpp/numeric/random/philox_engine/set_counter#cite_ref-1) As `j` is being set to `n - 1`, the next state transition always generates new random values.
