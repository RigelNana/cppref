{/* source:cpp-numeric-random-independent-bits-engine-discard:0001 */}
Advances the internal state by `z` times. Equivalent to calling [`operator()`](/docs/cpp/library/numeric/random/independent_bits_engine/operator()) `z` times and discarding the result. The state of the underlying engine may be advanced by more than `z` times.

### Parameters

{/* source:cpp-numeric-random-independent-bits-engine-discard:0002 */}
<ParameterList>
  <Parameter name="z">integer value specifying the number of times to advance the state by</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-random-independent-bits-engine-discard:0003 */}
(none)

### Exceptions

{/* source:cpp-numeric-random-independent-bits-engine-discard:0004 */}
Throws nothing.
