### Notes

{/* source:cpp-numeric-random-uniform-real-distribution-uniform-real-distribution:0005 */}
Requires that `a ≤ b` and `b - a ≤ std::numeric_limits<RealType>::max()`.

{/* source:cpp-numeric-random-uniform-real-distribution-uniform-real-distribution:0006 */}
If `a == b`, subsequent calls to the [operator()](/docs/cpp/library/numeric/random/uniform_real_distribution/operator()) overload that does not accept a `param_type` object will cause undefined behavior.

{/* source:cpp-numeric-random-uniform-real-distribution-uniform-real-distribution:0007 */}
To create a distribution over the closed interval \[a,b\], `std::nextafter(b, std::numeric_limits<RealType>::max())` may be used as the second parameter.
