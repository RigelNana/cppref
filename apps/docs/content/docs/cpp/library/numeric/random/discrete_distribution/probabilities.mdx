Obtains a `std::vector<double>` containing the individual probabilities of each integer that is generated by this distribution.

### Parameters

{/* source:cpp-numeric-random-discrete-distribution-probabilities:0002 */}
(none)

### Return value

{/* source:cpp-numeric-random-discrete-distribution-probabilities:0003 */}
An object of type `std::vector<double>`.

### Example

{/* source:cpp-numeric-random-discrete-distribution-probabilities:0004 */}
```cpp
#include <iostream>
#include <random>
#include <vector>
 
int main()
{
    std::discrete_distribution<> d({40, 10, 10, 40});
    std::vector<double> p = d.probabilities();
    for (auto n : p)
        std::cout << n << ' ';
    std::cout << '\n';
}
```

Output:

```text
0.4 0.1 0.1 0.4
```
