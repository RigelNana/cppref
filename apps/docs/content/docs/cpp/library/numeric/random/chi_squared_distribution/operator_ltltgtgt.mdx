Performs stream input and output operations on pseudo-random number distribution `d`.

{/* source:cpp-numeric-random-chi-squared-distribution-operator-ltltgtgt:0002 */}
1. Writes a textual representation of the distribution parameters and internal state to `ost` as textual representation. The formatting flags and fill character of `ost` are unchanged.

{/* source:cpp-numeric-random-chi-squared-distribution-operator-ltltgtgt:0003 */}
2. Restores the distribution parameters and internal state with data read from `ist`. The formatting flags of `ist` are unchanged. The data must have been written using a stream with the same locale, `CharT` and `Traits` template parameters, otherwise the behavior is undefined. If bad input is encountered, `ist.setstate(std::ios::failbit)` is called, which may throw [`std::ios_base::failure`](/docs/cpp/library/io/ios_base/failure). `d` is unchanged in that case.
  </DeclarationDescription>
</DeclarationDoc>
