{/* source:cpp-numeric-random-lognormal-distribution:0001 */}
The lognormal_distribution random number distribution produces random numbers x \> 0 according to a [Log-normal distribution](https://en.wikipedia.org/wiki/Log-normal_distribution):

{/* source:cpp-numeric-random-lognormal-distribution:0002 */}
f(x; m,s) = 1 sx √ 2 π exp ⎛ ⎜ ⎝ - (ln x - m)2 2s2 ⎞ ⎟ ⎠

{/* source:cpp-numeric-random-lognormal-distribution:0003 */}
The parameters m and s are, respectively, the mean and standard deviation of the natural logarithm of x.

{/* source:cpp-numeric-random-lognormal-distribution:0004 */}
[`std::lognormal_distribution`](/docs/cpp/library/numeric/random/lognormal_distribution#top) satisfies all requirements of [*RandomNumberDistribution*](/docs/cpp/library/named_req/RandomNumberDistribution).

### Example

{/* source:cpp-numeric-random-lognormal-distribution:0009 */}
```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>
 
int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
 
    std::lognormal_distribution<> d(1.6, 0.25);
 
    std::map<int, int> hist;
    for (int n = 0; n < 1e4; ++n)
        ++hist[std::round(d(gen))];
 
    for (std::cout << std::fixed << std::setprecision(1); auto [x, y] : hist)
        std::cout << std::hex << x << ' ' << std::string(y / 200, '*') << '\n';
}
```

```text
4 *************
5 ***************
6 *********

9
a
b
c
```
