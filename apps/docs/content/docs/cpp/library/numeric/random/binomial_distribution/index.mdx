Produces random non-negative integer values i, distributed according to discrete probability function:

{/* source:cpp-numeric-random-binomial-distribution:0002 */}
P(i|t,p) =⎛ ⎜ ⎝ t i ⎞ ⎟ ⎠ · pi · (1 − p)t−i

{/* source:cpp-numeric-random-binomial-distribution:0003 */}
The value obtained is the number of successes in a sequence of t yes/no experiments, each of which succeeds with probability p.

{/* source:cpp-numeric-random-binomial-distribution:0004 */}
`std::binomial_distribution` satisfies [*RandomNumberDistribution*](/docs/cpp/library/named_req/RandomNumberDistribution).

### Example

{/* source:cpp-numeric-random-binomial-distribution:0009 */}
Plot of binomial distribution with probability of success of each trial exactly 0.5, illustrating the relationship with the pascal triangle (the probabilities that none, 1, 2, 3, or all four of the 4 trials will be successful in this case are 1:4:6:4:1).

```cpp
#include <iomanip>
#include <iostream>
#include <map>
#include <random>
#include <string>
 
int main()
{
    std::random_device rd;
    std::mt19937 gen(rd());
    // perform 4 trials, each succeeds 1 in 2 times
    std::binomial_distribution<> d(4, 0.5);
 
    std::map<int, int> hist;
    for (int n = 0; n != 10000; ++n)
        ++hist[d(gen)];
 
    for (auto const& [x, y] : hist)
        std::cout << x << ' ' << std::string(y / 100, '*') << '\n';
}
```

Possible output:

```text
0 ******
1 ************************
2 *************************************
3 *************************
4 ******
```
