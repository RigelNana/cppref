{/* source:cpp-numeric-random-discard-block-engine-discard-block-engine:0001 */}
Constructs new pseudo-random engine adaptor.

{/* source:cpp-numeric-random-discard-block-engine-discard-block-engine:0002 */}
1. Default constructor. The underlying engine is also default-constructed.

{/* source:cpp-numeric-random-discard-block-engine-discard-block-engine:0003 */}
2. Constructs the underlying engine with `s`.

{/* source:cpp-numeric-random-discard-block-engine-discard-block-engine:0004 */}
3. Constructs the underlying engine with seed sequence `seq`.

{/* source:cpp-numeric-random-discard-block-engine-discard-block-engine:0005 */}
 This overload participates in overload resolution only if `Sseq` satisfies the requirements of [*SeedSequence*](/docs/cpp/library/named_req/SeedSequence).

{/* source:cpp-numeric-random-discard-block-engine-discard-block-engine:0006 */}
4. Constructs the underlying engine with a copy of `e`.

{/* source:cpp-numeric-random-discard-block-engine-discard-block-engine:0007 */}
5. Move-constructs the underlying engine with `e`. `e` holds unspecified, but valid state afterwards.
