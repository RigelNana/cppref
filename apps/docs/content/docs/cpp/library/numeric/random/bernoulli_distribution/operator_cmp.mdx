Compares two distribution objects. Two distribution objects are equal when parameter values and internal state is the same.

{/* source:cpp-numeric-random-bernoulli-distribution-operator-cmp:0002 */}
1. Compares two distribution objects for equality.

{/* source:cpp-numeric-random-bernoulli-distribution-operator-cmp:0003 */}
2. Compares two distribution objects for inequality.
  </DeclarationDescription>

These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when std::bernoulli_distribution is an associated class of the arguments.

### Return value

{/* source:cpp-numeric-random-bernoulli-distribution-operator-cmp:0007 */}
1. `true` if the distribution objects are equal, `false` otherwise.

{/* source:cpp-numeric-random-bernoulli-distribution-operator-cmp:0008 */}
2. `true` if the distribution objects are not equal, `false` otherwise.
