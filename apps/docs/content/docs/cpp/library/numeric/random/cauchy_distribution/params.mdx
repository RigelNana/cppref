{/* source:cpp-numeric-random-cauchy-distribution-params:0001 */}
Returns the distribution parameters with which the distribution was constructed.

{/* source:cpp-numeric-random-cauchy-distribution-params:0002 */}
1. Returns the <i>a</i> parameter. It specifies the location of the peak and is also called location parameter. The default value is `0.0`.

{/* source:cpp-numeric-random-cauchy-distribution-params:0003 */}
2. Returns the <i>b</i> parameter. It represents the half-width at half-maximum (HWHM) and is also called scale parameter. The default value is `1.0`.

{/* source:cpp-numeric-random-cauchy-distribution-params:0004 */}
(none)

{/* source:cpp-numeric-random-cauchy-distribution-params:0005 */}

{/* source:cpp-numeric-random-cauchy-distribution-params:0006 */}
