Advances the state of the engine, and generates a pseudo-random value from the new state.

### Return value

{/* source:cpp-numeric-random-philox-engine-operator:0002 */}
A pseudo-random number in [`min()`, `max()``]`.

### Complexity

{/* source:cpp-numeric-random-philox-engine-operator:0003 */}
Amortized constant.
