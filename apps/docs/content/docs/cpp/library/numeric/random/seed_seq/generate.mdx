<DeclarationDoc>

void generate( RandomIt begin, RandomIt end );`} />

  <DeclarationDescription>
    {/* source:cpp-numeric-random-seed-seq-generate:0001 */}
    Generate unbiased seeds by filling the output range `[begin, end)` with 32-bit unsigned integer values, based on the (possibly biased) seeds stored in <i>[`v`](/docs/cpp/library/numeric/random/seed_seq#v)</i>.

  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-numeric-random-seed-seq-generate:0002 */}
- If `begin == end` is `true`, does nothing.
- Otherwise, generates seeds by the generation algorithm described below.

{/* source:cpp-numeric-random-seed-seq-generate:0003 */}
If `std::iterator_traits<RandomIt>::value_type` is not an unsigned integer type, or its width is less than 32, the program is ill-formed.

{/* source:cpp-numeric-random-seed-seq-generate:0004 */}
If `RandomIt` does not meet the requirements of [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator), or it is not [mutable](/docs/cpp/library/iterator), the behavior is undefined.

### Generation algorithm

{/* source:cpp-numeric-random-seed-seq-generate:0005 */}
Given the following values and operations:

{/* source:cpp-numeric-random-seed-seq-generate:0006 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`z`</DescriptionTerm>
    <DescriptionBody><i>[`v`](/docs/cpp/library/numeric/random/seed_seq#v)</i>`.size()`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`n`</DescriptionTerm>
    <DescriptionBody>`end - begin`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`m`</DescriptionTerm>
    <DescriptionBody>`std::max(z + 1, n)`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`t`</DescriptionTerm>
    <DescriptionBody>`(n >= 623) ? 11 : (n >= 68) ? 7 : (n >= 39) ? 5 : (n >= 7) ? 3 : (n - 1) / 2`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`p`</DescriptionTerm>
    <DescriptionBody>`(n - t) / 2`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`q`</DescriptionTerm>
    <DescriptionBody>`p + t`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>xor</DescriptionTerm>
    <DescriptionBody>built-in [bitwise XOR](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_logic_operators)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>rshift</DescriptionTerm>
    <DescriptionBody>built-in [bitwise right-shift](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_shift_operators)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>T(x)</DescriptionTerm>
    <DescriptionBody>x xor (x rshift 27)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-numeric-random-seed-seq-generate:0007 */}
The generation algorithm consists of the following steps, where Si denotes `begin[i % n]`, Vi denotes <i>[`v`](/docs/cpp/library/numeric/random/seed_seq#v)</i>`[i]`:

{/* source:cpp-numeric-random-seed-seq-generate:0008 */}
1. Set each element of the output range to the value `0x8b8b8b8b`.

{/* source:cpp-numeric-random-seed-seq-generate:0009 */}
2. For each integer `k` in `[0, m)`, performs the following operations in order:

{/* source:cpp-numeric-random-seed-seq-generate:0010 */}
   1. Let r1 be 1664525·T(Sk xor Sk+p xor Sk-1).

{/* source:cpp-numeric-random-seed-seq-generate:0011 */}
   2. Let r2 be r1+j, where j is:
      - z, if k=0
      - (k mod n)+Vk-1, if 0\<k⩽z
      - k mod n, if z\<k

{/* source:cpp-numeric-random-seed-seq-generate:0012 */}
   3. Set Sk+p to (Sk+p+r1) mod 232 .

{/* source:cpp-numeric-random-seed-seq-generate:0013 */}
   4. Set Sk+q to (Sk+q+r2) mod 232 .

{/* source:cpp-numeric-random-seed-seq-generate:0014 */}
   5. Set Sk to r2 mod 232 .

{/* source:cpp-numeric-random-seed-seq-generate:0015 */}
3. For each integer `k` in `[m, m + n)`, performs the following operations in order:

{/* source:cpp-numeric-random-seed-seq-generate:0016 */}
   1. Let r3 be 1566083941·T(Sk+Sk+p+Sk-1).

{/* source:cpp-numeric-random-seed-seq-generate:0017 */}
   2. Let r4 be r3-(k mod n).

{/* source:cpp-numeric-random-seed-seq-generate:0018 */}
   3. Set Sk+p to (Sk+p xor r3) mod 232 .

{/* source:cpp-numeric-random-seed-seq-generate:0019 */}
   4. Set Sk+q to (Sk+q xor r4) mod 232 .

{/* source:cpp-numeric-random-seed-seq-generate:0020 */}
   5. Set Sk to r4 mod 232 .

### Parameters

{/* source:cpp-numeric-random-seed-seq-generate:0021 */}
<ParameterList>
  <Parameter name="begin, end">the iterators denoting the output range</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-numeric-random-seed-seq-generate:0022 */}
Only throws the exceptions thrown by the `RandomIt` operations on `begin` and `end`.

### Notes

{/* source:cpp-numeric-random-seed-seq-generate:0023 */}
The generation algorithm is adapted from the initialization sequence of the Mersenne Twister generator by [Makoto Matsumoto and Takuji Nishimura](http://www.math.sci.hiroshima-u.ac.jp/~m-mat/MT/emt.html), incorporating the improvements made by [Mutsuo Saito in 2007](http://www.math.sci.hiroshima-u.ac.jp/~m-mat/MT/SFMT/M062821.pdf).

### Example

{/* source:cpp-numeric-random-seed-seq-generate:0024 */}
```cpp
#include <algorithm>
#include <cassert>
#include <cstdint>
#include <iostream>
#include <random>
 
// Prototyping the main part of std::seed_seq...
struct seed_seq
{
    std::vector<std::uint32_t> v;
 
    seed_seq(std::initializer_list<std::uint32_t> const il) : v{il} {}
 
    template<typename RandomIt>
    void generate(RandomIt first, RandomIt last)
    {
        if (first == last)
            return;
        //
        // Assuming v = {1, 2, 3, 4, 5} and distance(first, last) == 10.
        //
        // Step 1: fill with 0x8b8b8b8b
        // seeds = {2341178251, 2341178251, 2341178251, 2341178251, 2341178251,
        //          2341178251, 2341178251, 2341178251, 2341178251, 2341178251}
        //
        std::fill(first, last, 0x8b8b8b8b);
        //
        // Step 2:
        // n = 10, s = 5, t = 3, p = 3, q = 6, m = 10
        //
        const std::uint32_t n = last - first;
        const std::uint32_t s = v.size();
        const std::uint32_t t = (n < 7) ? (n - 1) / 2
                              : (n < 39) ? 3
                              : (n < 68) ? 5
                              : (n < 623) ? 7
                              : 11;
        const std::uint32_t p = (n - t) / 2;
        const std::uint32_t q = p + t;
        const std::uint32_t m = std::max(s + 1, n);
        //
        // First iteration, k = 0; r1 = 1371501266, r2 = 1371501271
        //
        // seeds = {1371501271, 2341178251, 2341178251, 3712679517, 2341178251,
        //          2341178251, 3712679522, 2341178251, 2341178251, 2341178251}
        //
        // Iterations from k = 1 to k = 5 (r2 = r1 + k % n + v[k - 1])
        //
        // r1 = 2786190137, 3204727651, 4173325571, 1979226628, 401983366
        // r2 = 2786190139, 3204727655, 4173325577, 1979226636, 401983376
        //
        // seeds = {3350727907, 3188173515, 3204727655, 4173325577, 1979226636,
        //           401983376, 3591037797, 2811627722, 1652921976, 2219536532}
        //
        // Iterations from k = 6 to k = 9 (r2 = r1 + k % n)
        //
        // r1 = 2718637909, 1378394210, 2297813071, 1608643617
        // r2 = 2718637915, 1378394217, 2297813079, 1608643626
        //
        // seeds = { 434154821, 1191019290, 3237041891, 1256752498, 4277039715,
        //          2010627002, 2718637915, 1378394217, 2297813079, 1608643626}
        //
        auto begin_mod = [first, n](std::uint32_t u) -> decltype(*first)&
        {
            return first[u % n]; // i.e. begin[x] is taken modulo n
        };
        auto T = [](std::uint32_t x) { return x ^ (x >> 27); };
 
        for (std::uint32_t k = 0, r1, r2; k < m; ++k)
        {
            r1 = 1664525 * T(begin_mod(k) ^ begin_mod(k + p) ^ begin_mod(k - 1));
            r2 = (k == 0) ? r1 + s
               : (k <= s) ? r1 + k % n + v[k - 1]
               :            r1 + k % n;
            begin_mod(k + p) += r1;
            begin_mod(k + q) += r2;
            begin_mod(k) = r2;
        }
        //
        // Step 3
        // iterations from k = 10 to k = 19, using ^= to modify the output
        //
        // r1 = 1615303485, 3210438310, 893477041, 2884072672, 1918321961,
        // r2 = 1615303485, 3210438309, 893477039, 2884072669, 1918321957
        //
        // seeds = { 303093272, 3210438309,  893477039, 2884072669, 1918321957,
        //          1117182731, 1772877958, 2669970405, 3182737656, 4094066935}
        //
        // r1 =  423054846, 46783064, 3904109085, 1534123446, 1495905687
        // r2 =  423054841, 46783058, 3904109078, 1534123438, 1495905678
        //
        // seeds = { 4204997637, 4246533866, 1856049002, 1129615051, 690460811,
        //           1075771511,   46783058, 3904109078, 1534123438, 1495905678}
        //
        for (std::uint32_t k = m, r3, r4; k < m + n; ++k)
        {
            r3 = 1566083941 * T(begin_mod(k) + begin_mod(k + p) + begin_mod(k - 1));
            r4 = r3 - k % n;
            begin_mod(k+p) ^= r3;
            begin_mod(k+q) ^= r4;
            begin_mod(k) = r4;
        }
    }
};
 
int main()
{
    const auto input = std::initializer_list<std::uint32_t>{1, 2, 3, 4, 5};
    const auto output_size = 10;
 
    // using std version of seed_seq
    std::seed_seq seq(input);
    std::vector<std::uint32_t> seeds(output_size);
    seq.generate(seeds.begin(), seeds.end());
    for (const std::uint32_t n : seeds)
        std::cout << n << '\n';
 
    // using custom version of seed_seq
    seed_seq seq2(input);
    std::vector<std::uint32_t> seeds2(output_size);
    seq2.generate(seeds2.begin(), seeds2.end());
 
    assert(seeds == seeds2);
}
```
