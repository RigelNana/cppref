Returns the parameters the distribution was constructed with.

{/* source:cpp-numeric-random-binomial-distribution-params:0002 */}
1. Returns the p distribution parameter. It defines the probability of a trial generating `true`. The default value is `0.5`.

{/* source:cpp-numeric-random-binomial-distribution-params:0003 */}
2. Returns the t distribution parameter. It identifies the number of trials. The default value is `1`.

{/* source:cpp-numeric-random-binomial-distribution-params:0004 */}
(none)

{/* source:cpp-numeric-random-binomial-distribution-params:0005 */}
