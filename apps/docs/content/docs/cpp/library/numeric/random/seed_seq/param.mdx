<DeclarationDoc>
  <Declaration language="cpp" since="C++11" code={`template< class OutputIt >
void param( OutputIt dest ) const;`} />

  <DeclarationDescription>
    {/* source:cpp-numeric-random-seed-seq-param:0001 */}
    Copies the stored seeds to the range beginning with `dest`. Equivalent to `std::copy(`<i>[`v`](/docs/cpp/library/numeric/random/seed_seq#v)</i>`.begin(), `<i>[`v`](/docs/cpp/library/numeric/random/seed_seq#v)</i>`.end(), dest);`.

    {/* source:cpp-numeric-random-seed-seq-param:0002 */}
    If values of type `result_type` are not [writable](/docs/cpp/library/iterator#Types_and_writability) to `dest`, the program is ill-formed.

    {/* source:cpp-numeric-random-seed-seq-param:0003 */}
    If `OutputIt` does not satisfy the requirements of [*LegacyOutputIterator*](/docs/cpp/library/named_req/OutputIterator), the behavior is undefined.

  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-numeric-random-seed-seq-param:0004 */}
<ParameterList>
  <Parameter name="dest">the beginning iterator of the output range</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-numeric-random-seed-seq-param:0005 */}
Only throws the exceptions thrown by the operations on `dest`.

### Example

{/* source:cpp-numeric-random-seed-seq-param:0006 */}
```cpp
#include <iostream>
#include <iterator>
#include <random>
 
int main()
{
    std::seed_seq s1 = {-1, 0, 1};
    s1.param(std::ostream_iterator<int>(std::cout, " "));
}
```

Output:

```text
-1 0 1
```
