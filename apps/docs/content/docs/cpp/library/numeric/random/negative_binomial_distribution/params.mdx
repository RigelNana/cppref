Returns the parameters the distribution was constructed with.

{/* source:cpp-numeric-random-negative-binomial-distribution-params:0002 */}
1. Returns the p distribution parameter. It defines the probability of a trial generating `true`. The default value is `0.5`.

{/* source:cpp-numeric-random-negative-binomial-distribution-params:0003 */}
2. Returns the k distribution parameter. It defines the number of desired outcomes. The default value is `1`.

  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-numeric-random-negative-binomial-distribution-params:0004 */}
(none)

### Return value

{/* source:cpp-numeric-random-negative-binomial-distribution-params:0005 */}
1. The p distribution parameter.

{/* source:cpp-numeric-random-negative-binomial-distribution-params:0006 */}
2. The k distribution parameter.
