{/* source:cpp-numeric-random-mersenne-twister-engine-mersenne-twister-engine:0001 */}
Constructs the pseudo-random number engine.

{/* source:cpp-numeric-random-mersenne-twister-engine-mersenne-twister-engine:0002 */}
1. The default constructor. If the default-constructed engine is of type `std::mt19937`, the 10000th consecutive invocation of it produces the value `4123659995`. If the default-constructed engine is of type `std::mt19937_64`, the 10000th consecutive invocation of it produces the value `9981545732273789042`.

{/* source:cpp-numeric-random-mersenne-twister-engine-mersenne-twister-engine:0003 */}
2. Constructs the engine with a seed value `value`. Given 2w as `p`, the engine's initial [state](/docs/cpp/library/numeric/random/mersenne_twister_engine#Generator_properties) is determined as follows: Sets X-n to `value % p`. For each integer `i` in [`i - n``, ``-1``]`, sets Xi to [f·(Xi-1 xor (Xi-1 rshift (w-2)))+i mod n] mod p, where xor and rshift stand for built-in [bitwise XOR](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_logic_operators) and [bitwise right-shift](/docs/cpp/language/expressions/operator_arithmetic#Bitwise_shift_operators) respectively.

{/* source:cpp-numeric-random-mersenne-twister-engine-mersenne-twister-engine:0004 */}
3. Constructs the engine with a seed sequence `seq`. Given std::size_t(w / 32) + 1 as `k`, the engine's initial [state](/docs/cpp/library/numeric/random/mersenne_twister_engine#Generator_properties) is determined as follows: Creates an invented array object `a` of length `n * k`. Calls `seq.generate(a + 0, a + n * k)`. For each integer `i` in `[``-n``, ``-1``]`, sets Xi to (∑k-1 j=0 ak(i+n)+j·232j ) mod 2w . If the most significant `w − r` bits of X-n are zero, and if each of the other resulting Xi is `0`, changes X-n to 2w-1 .

{/* source:cpp-numeric-random-mersenne-twister-engine-mersenne-twister-engine:0005 */}
This overload participates in overload resolution only if `SeedSeq` meets the requirements of [*SeedSequence*](/docs/cpp/library/named_req/SeedSequence).

{/* source:cpp-numeric-random-mersenne-twister-engine-mersenne-twister-engine:0006 */}
4. The copy constructor. Upon construction, `*this == other` is `true`.

#include <cassert>

int main()

    std::mt19937 gen32; // overload (1)

    gen64.discard(10000 - 1);
