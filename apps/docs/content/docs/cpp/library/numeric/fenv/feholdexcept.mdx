{/* source:cpp-numeric-fenv-feholdexcept:0001 */}
First, saves the current floating-point environment to the object pointed to by `envp` (similar to [`std::fegetenv`](/docs/cpp/library/numeric/fenv/feenv)), then clears all floating-point status flags, and then installs the non-stop mode: future floating-point exceptions will not interrupt execution (will not trap), until the floating-point environment is restored by [`std::feupdateenv`](/docs/cpp/library/numeric/fenv/feupdateenv) or [`std::fesetenv`](/docs/cpp/library/numeric/fenv/feenv).

{/* source:cpp-numeric-fenv-feholdexcept:0002 */}
This function may be used in the beginning of a subroutine that must hide the floating-point exceptions it may raise from the caller. If only some exceptions must be suppressed, while others must be reported, the non-stop mode is usually ended with a call to [`std::feupdateenv`](/docs/cpp/library/numeric/fenv/feupdateenv) after clearing the unwanted exceptions.

### Parameters

{/* source:cpp-numeric-fenv-feholdexcept:0003 */}
<ParameterList>
  <Parameter name="envp">pointer to the object of type `std::fenv_t` where the floating-point environment will be stored</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-fenv-feholdexcept:0004 */}
`0` on success, non-zero otherwise.
