{/* source:cpp-numeric-fenv-feupdateenv:0001 */}
First, remembers the currently raised floating-point exceptions, then restores the floating-point environment from the object pointed to by `envp` (similar to [`std::fesetenv`](/docs/cpp/library/numeric/fenv/feenv)), then raises the floating-point exceptions that were saved.

{/* source:cpp-numeric-fenv-feupdateenv:0002 */}
This function may be used to end the non-stop mode established by an earlier call to [`std::feholdexcept`](/docs/cpp/library/numeric/fenv/feholdexcept).

### Parameters

{/* source:cpp-numeric-fenv-feupdateenv:0003 */}
<ParameterList>
  <Parameter name="envp">pointer to the object of type `std::fenv_t` set by an earlier call to [`std::feholdexcept`](/docs/cpp/library/numeric/fenv/feholdexcept) or `std::fegetenv` or equal to [`FE_DFL_ENV`](/docs/cpp/library/numeric/fenv/FE_DFL_ENV)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-fenv-feupdateenv:0004 */}
`0` on success, non-zero otherwise.
