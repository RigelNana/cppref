  <Declaration id="1" language="cpp" since="C++11" code={`int fesetround( int round )`} />
  <Declaration id="2" language="cpp" since="C++11" code={`int fegetround()`} />

  <DeclarationDescription>
    {/* source:cpp-numeric-fenv-feround:0001 */}
    Manages the floating-point rounding direction.

    {/* source:cpp-numeric-fenv-feround:0002 */}
    1. Attempts to establish the floating-point rounding direction equal to the argument `round`, which is expected to be one of the [floating point rounding macros](/docs/cpp/library/numeric/fenv/FE_round).

    {/* source:cpp-numeric-fenv-feround:0003 */}
    2. Returns the value of the [floating point rounding macro](/docs/cpp/library/numeric/fenv/FE_round) that corresponds to the current rounding direction.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-numeric-fenv-feround:0004 */}
<ParameterList>
  <Parameter name="round">rounding direction, one of [floating point rounding macros](/docs/cpp/library/numeric/fenv/FE_round)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-fenv-feround:0005 */}
1. `0` on success, non-zero otherwise.

{/* source:cpp-numeric-fenv-feround:0006 */}
2. The [floating point rounding macro](/docs/cpp/library/numeric/fenv/FE_round) describing the current rounding direction or a negative value if the direction cannot be determined.

### Notes

{/* source:cpp-numeric-fenv-feround:0007 */}
The current rounding mode, reflecting the effects of the most recent `fesetround`, can also be queried with [`FLT_ROUNDS`](/docs/cpp/library/utility/types/climits/FLT_ROUNDS).

{/* source:cpp-numeric-fenv-feround:0008 */}
See [floating-point rounding macros](/docs/cpp/library/numeric/fenv/FE_round) for the effects of rounding.

### Example

{/* source:cpp-numeric-fenv-feround:0009 */}
```cpp
#include <cfenv>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <utility>
// #pragma STDC FENV_ACCESS ON
 
int main()
{
    static constexpr std::pair<const char*, const double> samples[]
    {
        {" 12.0", 12.0},  {" 12.1", 12.1}, {"-12.1", -12.1}, {" 12.5", 12.5},
        {"-12.5", -12.5}, {" 12.9", 12.9}, {"-12.9", -12.9}, {" 13.0", 13.0}
    };
 
    std::cout <<
        "│ sample │  FE_DOWNWARD  │   FE_UPWARD   │ FE_TONEAREST  │ FE_TOWARDZERO │\n";
 
    for (const auto& [str, fp] : samples)
    {
        std::cout << "│ " << std::setw(6) << str << " │  ";
        for (const int dir : {FE_DOWNWARD, FE_UPWARD, FE_TONEAREST, FE_TOWARDZERO})
        {
            std::fesetround(dir);
            std::cout << std::setw(10) << std::fixed << std::nearbyint(fp) << "   │  ";
        }
        std::cout << '\n';
    }
}
```
