  <DeclarationDescription>
    {/* source:cpp-numeric-fenv-feenv:0001 */}
    Manages the status of the floating-point environment.

    {/* source:cpp-numeric-fenv-feenv:0002 */}
    1. Attempts to store the status of the floating-point environment in the object pointed to by `envp`.

    {/* source:cpp-numeric-fenv-feenv:0003 */}
    2. Attempts to establish the floating-point environment from the object pointed to by `envp`. The value of that object must be previously obtained by a call to [`std::feholdexcept`](/docs/cpp/library/numeric/fenv/feholdexcept) or `std::fegetenv` or be a floating-point macro constant. If any of the floating-point status flags are set in `envp`, they become set in the environment (and are then testable with [`std::fetestexcept`](/docs/cpp/library/numeric/fenv/fetestexcept)), but the corresponding floating-point exceptions are not raised (execution continues uninterrupted)
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-numeric-fenv-feenv:0004 */}
<ParameterList>
  <Parameter name="envp">pointer to the object of type `std::fenv_t` which holds the status of the floating-point environment</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-fenv-feenv:0005 */}
`0` on success, non-zero otherwise.
