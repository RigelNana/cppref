{/* source:cpp-numeric-countl-zero:0001 */}
Returns the number of consecutive `0` bits in the value of `x`, starting from the most significant bit ("left").

{/* source:cpp-numeric-countl-zero:0002 */}
This overload participates in overload resolution only if `T` is an unsigned integer type (that is, `unsigned char`, `unsigned short`, `unsigned int`, `unsigned long`, `unsigned long long`, or an extended unsigned integer type).

### Parameters

{/* source:cpp-numeric-countl-zero:0003 */}
<ParameterList>
  <Parameter name="x">value of unsigned integer type</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-countl-zero:0004 */}
The number of consecutive `0` bits in the value of `x`, starting from the most significant bit.

### Example

{/* source:cpp-numeric-countl-zero:0006 */}
```cpp
#include <bit>
#include <bitset>
#include <cstdint>
#include <iostream>
 
int main()
{
    for (const std::uint8_t i : {0, 0b11111111, 0b11110000, 0b00011110})
        std::cout << "countl_zero( " << std::bitset<8>(i) << " ) = "
                  << std::countl_zero(i) << '\n';
}
```

Output:

```text
countl_zero( 00000000 ) = 8
countl_zero( 11111111 ) = 0
countl_zero( 11110000 ) = 0
countl_zero( 00011110 ) = 3
```
