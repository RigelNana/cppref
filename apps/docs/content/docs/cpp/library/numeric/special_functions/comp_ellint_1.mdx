### Return value

{/* source:cpp-numeric-special-functions-comp-ellint-1:0004 */}
If no errors occur, value of the complete elliptic integral of the first kind of `k`, that is `std::ellint_1(k, π/2)`, is returned.

### Error handling

{/* source:cpp-numeric-special-functions-comp-ellint-1:0005 */}
Errors may be reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-special-functions-comp-ellint-1:0006 */}
- If the argument is NaN, NaN is returned and domain error is not reported.
- If |k|\>1, a domain error may occur.

### Notes

{/* source:cpp-numeric-special-functions-comp-ellint-1:0007 */}
Implementations that do not support C++17, but support [ISO 29124:2010](/docs/cpp/library/experimental/special_math), provide this function if `__STDCPP_MATH_SPEC_FUNCS__` is defined by the implementation to a value at least `201003L` and if the user defines `__STDCPP_WANT_MATH_SPEC_FUNCS__` before including any standard library headers.

{/* source:cpp-numeric-special-functions-comp-ellint-1:0008 */}
Implementations that do not support ISO 29124:2010 but support TR 19768:2007 (TR1), provide this function in the header `tr1/cmath` and namespace `std::tr1`.

{/* source:cpp-numeric-special-functions-comp-ellint-1:0009 */}
An implementation of this function is also [available in boost.math](https://www.boost.org/doc/libs/release/libs/math/doc/html/math_toolkit/ellint/ellint_1.html).

{/* source:cpp-numeric-special-functions-comp-ellint-1:0010 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::comp_ellint_1(num)` has the same effect as `std::comp_ellint_1(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-special-functions-comp-ellint-1:0011 */}
The [period of a pendulum](https://en.wikipedia.org/wiki/Pendulum_(mechanics)#Arbitrary-amplitude_period) of length l, given acceleration due to gravity g, and initial angle θ equals 4⋅√ l/g⋅K(sin(θ/2)), where K is std::comp_ellint_1.

```cpp
#include <cmath>
#include <iostream>
#include <numbers>
 
int main()
{
    constexpr double π{std::numbers::pi};
 
    std::cout << "K(0) ≈ " << std::comp_ellint_1(0) << '\n'
              << "π/2 ≈ " << π / 2 << '\n'
              << "K(0.5) ≈ " << std::comp_ellint_1(0.5) << '\n'
              << "F(0.5, π/2) ≈ " << std::ellint_1(0.5, π / 2) << '\n'
              << "The period of a pendulum length 1m at 10° initial angle ≈ "
              << 4 * std::sqrt(1 / 9.80665) * std::comp_ellint_1(std::sin(π / 18 / 2))
              << "s,\n" "whereas the linear approximation gives ≈ "
              << 2 * π * std::sqrt(1 / 9.80665) << '\n';
}
```

Output:

```text
K(0) ≈ 1.5708
π/2 ≈ 1.5708
K(0.5) ≈ 1.68575
F(0.5, π/2) ≈ 1.68575
The period of a pendulum length 1 m at 10° initial angle ≈ 2.01024s,
whereas the linear approximation gives ≈ 2.00641
```
