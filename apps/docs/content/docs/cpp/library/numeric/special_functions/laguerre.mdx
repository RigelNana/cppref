### Error handling

{/* source:cpp-numeric-special-functions-laguerre:0006 */}
Errors may be reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling)

{/* source:cpp-numeric-special-functions-laguerre:0007 */}
- If the argument is NaN, NaN is returned and domain error is not reported
- If `x` is negative, a domain error may occur
- If `n` is greater or equal than 128, the behavior is implementation-defined

### Notes

{/* source:cpp-numeric-special-functions-laguerre:0008 */}
Implementations that do not support C++17, but support [ISO 29124:2010](/docs/cpp/library/experimental/special_math), provide this function if `__STDCPP_MATH_SPEC_FUNCS__` is defined by the implementation to a value at least `201003L` and if the user defines `__STDCPP_WANT_MATH_SPEC_FUNCS__` before including any standard library headers.

{/* source:cpp-numeric-special-functions-laguerre:0009 */}
Implementations that do not support ISO 29124:2010 but support TR 19768:2007 (TR1), provide this function in the header `tr1/cmath` and namespace `std::tr1`.

{/* source:cpp-numeric-special-functions-laguerre:0010 */}
An implementation of this function is also [available in boost.math](https://www.boost.org/doc/libs/release/libs/math/doc/html/math_toolkit/sf_poly/laguerre.html).

{/* source:cpp-numeric-special-functions-laguerre:0011 */}
The Laguerre polynomials are the polynomial solutions of the equation .

{/* source:cpp-numeric-special-functions-laguerre:0012 */}
The first few are:

{/* source:cpp-numeric-special-functions-laguerre:0013 */}
| Function | Polynomial |
| --- | --- |
| `laguerre(0, x)` | 1 |
| `laguerre(1, x)` | -x + 1 |
| `laguerre(2, x)` | 1 2(x2 - 4x + 2) |
| `laguerre(3, x)` | 1 6(-x3 - 9x2 - 18x + 6) |

{/* source:cpp-numeric-special-functions-laguerre:0014 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::laguerre(int_num, num)` has the same effect as `std::laguerre(int_num, static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-special-functions-laguerre:0015 */}
```cpp
#include <cmath>
#include <iostream>
 
double L1(double x)
{
    return -x + 1;
}
 
double L2(double x)
{
    return 0.5 * (x * x - 4 * x + 2);
}
 
int main()
{
    // spot-checks
    std::cout << std::laguerre(1, 0.5) << '=' << L1(0.5) << '\n'
              << std::laguerre(2, 0.5) << '=' << L2(0.5) << '\n'
              << std::laguerre(3, 0.0) << '=' << 1.0 << '\n';
}
```

Output:

```text
0.5=0.5
0.125=0.125
1=1
```
