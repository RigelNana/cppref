### Parameters

{/* source:cpp-numeric-special-functions-comp-ellint-3:0003 */}
<ParameterList>
  <Parameter name="k">elliptic modulus or eccentricity (a floating-point or integer value)</Parameter>
  <Parameter name="nu">elliptic characteristic (a floating-point or integer value)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-special-functions-comp-ellint-3:0004 */}
If no errors occur, value of the complete elliptic integral of the third kind of `k` and `nu`, that is `std::ellint_3(k, nu, π/2)`, is returned.

### Error handling

{/* source:cpp-numeric-special-functions-comp-ellint-3:0005 */}
Errors may be reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-special-functions-comp-ellint-3:0006 */}
- If the argument is NaN, NaN is returned and domain error is not reported
- If |k|\>1, a domain error may occur

### Notes

{/* source:cpp-numeric-special-functions-comp-ellint-3:0007 */}
Implementations that do not support C++17, but support [ISO 29124:2010](/docs/cpp/library/experimental/special_math), provide this function if `__STDCPP_MATH_SPEC_FUNCS__` is defined by the implementation to a value at least `201003L` and if the user defines `__STDCPP_WANT_MATH_SPEC_FUNCS__` before including any standard library headers.

{/* source:cpp-numeric-special-functions-comp-ellint-3:0008 */}
Implementations that do not support ISO 29124:2010 but support TR 19768:2007 (TR1), provide this function in the header `tr1/cmath` and namespace `std::tr1`.

{/* source:cpp-numeric-special-functions-comp-ellint-3:0009 */}
An implementation of this function is also available in [boost.math](https://www.boost.org/doc/libs/release/libs/math/doc/html/math_toolkit/ellint/ellint_3.html).

{/* source:cpp-numeric-special-functions-comp-ellint-3:0010 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their first argument `num1` and second argument `num2`:

{/* source:cpp-numeric-special-functions-comp-ellint-3:0011 */}
<Revision until="C++23">
- If `num1` or `num2` has type `long double`, then `std::comp_ellint_3(num1, num2)` has the same effect as `std::comp_ellint_3(static_cast<long double>(num1),` `                   static_cast<long double>(num2))`.
- Otherwise, if `num1` and/or `num2` has type `double` or an integer type, then `std::comp_ellint_3(num1, num2)` has the same effect as `std::comp_ellint_3(static_cast<double>(num1),` `                   static_cast<double>(num2))`.
- Otherwise, if `num1` or `num2` has type `float`, then `std::comp_ellint_3(num1, num2)` has the same effect as `std::comp_ellint_3(static_cast<float>(num1),` `                   static_cast<float>(num2))`.
</Revision>
<Revision since="C++23">
If `num1` and `num2` have arithmetic types, then `std::comp_ellint_3(num1, num2)` has the same effect as `std::comp_ellint_3(static_cast</* common-floating-point-type */>(num1),` `                   static_cast</* common-floating-point-type */>(num2))`, where `/* common-floating-point-type */` is the floating-point type with the greatest [floating-point conversion rank](/docs/cpp/language/expressions/usual_arithmetic_conversions#Floating-point_conversion_rank) and greatest [floating-point conversion subrank](/docs/cpp/language/expressions/usual_arithmetic_conversions#Floating-point_conversion_subrank) between the types of `num1` and `num2`, arguments of integer type are considered to have the same floating-point conversion rank as `double`.
If no such floating-point type with the greatest rank and subrank exists, then [overload resolution](/docs/cpp/language/functions/overload_resolution) does not result in a usable candidate from the overloads provided.
</Revision>

### Example

{/* source:cpp-numeric-special-functions-comp-ellint-3:0012 */}
```cpp
#include <cmath>
#include <iostream>
 
int main()
{
    std::cout << std::fixed
              << "Π(0.5,0) = " << std::comp_ellint_3(0.5, 0) << '\n'
              << "K(0.5)   = " << std::comp_ellint_1(0.5) << '\n'
              << "Π(0,0)   = " << std::comp_ellint_3(0, 0) << '\n'
              << "π/2      = " << std::acos(-1) / 2 << '\n'
              << "Π(0.5,1) = " << std::comp_ellint_3(0.5, 1) << '\n';
}
```

Output:

```text
Π(0.5,0) = 1.685750
K(0.5)   = 1.685750
Π(0,0)   = 1.570796
π/2      = 1.570796
Π(0.5,1) = inf
```
