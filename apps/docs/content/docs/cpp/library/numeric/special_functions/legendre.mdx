### Error handling

{/* source:cpp-numeric-special-functions-legendre:0006 */}
Errors may be reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-special-functions-legendre:0007 */}
- If the argument is NaN, NaN is returned and domain error is not reported
- The function is not required to be defined for |x|\>1
- If `n` is greater or equal than 128, the behavior is implementation-defined

### Notes

{/* source:cpp-numeric-special-functions-legendre:0008 */}
Implementations that do not support C++17, but support [ISO 29124:2010](/docs/cpp/library/experimental/special_math), provide this function if `__STDCPP_MATH_SPEC_FUNCS__` is defined by the implementation to a value at least `201003L` and if the user defines `__STDCPP_WANT_MATH_SPEC_FUNCS__` before including any standard library headers.

{/* source:cpp-numeric-special-functions-legendre:0009 */}
Implementations that do not support ISO 29124:2010 but support TR 19768:2007 (TR1), provide this function in the header `tr1/cmath` and namespace `std::tr1`.

{/* source:cpp-numeric-special-functions-legendre:0010 */}
An implementation of this function is also [available in boost.math](https://www.boost.org/doc/libs/release/libs/math/doc/html/math_toolkit/sf_poly/legendre.html).

{/* source:cpp-numeric-special-functions-legendre:0011 */}
The first few Legendre polynomials are:

{/* source:cpp-numeric-special-functions-legendre:0012 */}
| Function | Polynomial |
| --- | --- |
| `legendre(0, x)` | 1 |
| `legendre(1, x)` | x |
| `legendre(2, x)` | 1 2(3x2 - 1) |
| `legendre(3, x)` | 1 2(5x3 - 3x) |
| `legendre(4, x)` | 1 8(35x4 - 30x2 + 3) |

{/* source:cpp-numeric-special-functions-legendre:0013 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::legendre(int_num, num)` has the same effect as `std::legendre(int_num, static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-special-functions-legendre:0014 */}
```cpp
#include <cmath>
#include <iostream>
 
double P3(double x)
{
    return 0.5 * (5 * std::pow(x, 3) - 3 * x);
}
 
double P4(double x)
{
    return 0.125 * (35 * std::pow(x, 4) - 30 * x * x + 3);
}
 
int main()
{
    // spot-checks
    std::cout << std::legendre(3, 0.25) << '=' << P3(0.25) << '\n'
              << std::legendre(4, 0.25) << '=' << P4(0.25) << '\n';
}
```

Output:

```text
-0.335938=-0.335938
0.157715=0.157715
```
