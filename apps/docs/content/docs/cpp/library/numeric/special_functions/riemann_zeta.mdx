### Return value

{/* source:cpp-numeric-special-functions-riemann-zeta:0004 */}
If no errors occur, value of the Riemann zeta function of `num`, ζ(`num`), defined for the entire real axis:

{/* source:cpp-numeric-special-functions-riemann-zeta:0005 */}
- For num\>1, Σ∞ n=1n-num
- For 0≤num≤1, 1 21-num -1Σ∞ n=1 (-1)n n-num
- For num\<0, 2num πnum-1 sin(πnum 2)Γ(1−num)ζ(1−num)

### Error handling

{/* source:cpp-numeric-special-functions-riemann-zeta:0006 */}
Errors may be reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-special-functions-riemann-zeta:0007 */}
- If the argument is NaN, NaN is returned and domain error is not reported

### Notes

{/* source:cpp-numeric-special-functions-riemann-zeta:0008 */}
Implementations that do not support C++17, but support [ISO 29124:2010](/docs/cpp/library/experimental/special_math), provide this function if `__STDCPP_MATH_SPEC_FUNCS__` is defined by the implementation to a value at least `201003L` and if the user defines `__STDCPP_WANT_MATH_SPEC_FUNCS__` before including any standard library headers.

{/* source:cpp-numeric-special-functions-riemann-zeta:0009 */}
Implementations that do not support ISO 29124:2010 but support TR 19768:2007 (TR1), provide this function in the header `tr1/cmath` and namespace `std::tr1`.

{/* source:cpp-numeric-special-functions-riemann-zeta:0010 */}
An implementation of this function is also [available in boost.math](https://www.boost.org/doc/libs/release/libs/math/doc/html/math_toolkit/zetas/zeta.html).

{/* source:cpp-numeric-special-functions-riemann-zeta:0011 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::riemann_zeta(num)` has the same effect as `std::riemann_zeta(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-special-functions-riemann-zeta:0012 */}
```cpp
#include <cmath>
#include <format>
#include <iostream>
#include <numbers>
 
int main()
{
    constexpr auto π = std::numbers::pi;
 
    // spot checks for well-known values
    for (const double x : {-1.0, 0.0, 1.0, 0.5, 2.0})
        std::cout << std::format("ζ({})\t= {:+.5f}\n", x, std::riemann_zeta(x));
    std::cout << std::format("π²/6\t= {:+.5f}\n", π * π / 6);
}
```

Output:

```text
ζ(-1)   = -0.08333
ζ(0)    = -0.50000
ζ(1)    = +inf
ζ(0.5)  = -1.46035
ζ(2)    = +1.64493
π²/6    = +1.64493
```
