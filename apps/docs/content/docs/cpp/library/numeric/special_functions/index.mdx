See [Mathematical special functions](/docs/cpp/library/experimental/special_math) for the ISO/IEC 29124:2010 version of this library.

### Notes

{/* source:cpp-numeric-special-functions:0003 */}
The `float` and `long double` overloads for math special functions without the "f" or "l" suffix are present in the final draft of ISO/IEC 29124:2010 ([N3060](https://wg21.link/N3060)), but absent in the published C++17/20 standard (see [LWG issue 3234](https://cplusplus.github.io/LWG/issue3234)). These overloads were not provided by MSVC STL until VS 2022 17.3.

{/* source:cpp-numeric-special-functions:0004 */}
These functions are unrelated to [special member functions](/docs/cpp/language/classes/member_functions#Special_member_functions) of class types.
