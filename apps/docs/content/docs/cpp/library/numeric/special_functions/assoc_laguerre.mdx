### Error handling

{/* source:cpp-numeric-special-functions-assoc-laguerre:0005 */}
Errors may be reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling)

{/* source:cpp-numeric-special-functions-assoc-laguerre:0006 */}
- If the argument is NaN, NaN is returned and domain error is not reported
- If `x` is negative, a domain error may occur
- If `n` or `m` is greater or equal to 128, the behavior is implementation-defined

### Notes

{/* source:cpp-numeric-special-functions-assoc-laguerre:0007 */}
Implementations that do not support C++17, but support [ISO 29124:2010](/docs/cpp/library/experimental/special_math), provide this function if `__STDCPP_MATH_SPEC_FUNCS__` is defined by the implementation to a value at least `201003L` and if the user defines `__STDCPP_WANT_MATH_SPEC_FUNCS__` before including any standard library headers.

{/* source:cpp-numeric-special-functions-assoc-laguerre:0008 */}
Implementations that do not support ISO 29124:2010 but support TR 19768:2007 (TR1), provide this function in the header `tr1/cmath` and namespace `std::tr1`.

{/* source:cpp-numeric-special-functions-assoc-laguerre:0009 */}
An implementation of this function is also [available in boost.math](https://www.boost.org/doc/libs/release/libs/math/doc/html/math_toolkit/sf_poly/laguerre.html).

{/* source:cpp-numeric-special-functions-assoc-laguerre:0010 */}
The associated Laguerre polynomials are the polynomial solutions of the equation xy,, +(m+1-x)y, +ny = 0.

{/* source:cpp-numeric-special-functions-assoc-laguerre:0011 */}
The first few are:

{/* source:cpp-numeric-special-functions-assoc-laguerre:0012 */}
| Function | Polynomial |
| --- | --- |
| `assoc_laguerre(0, m, x)` | 1 |
| `assoc_laguerre(1, m, x)` | -x + m + 1 |
| `assoc_laguerre(2, m, x)` | 1 2[x2 - 2(m + 2)x + (m + 1)(m + 2)] |
| `assoc_laguerre(3, m, x)` | 1 6[-x3 - 3(m + 3)x2 - 3(m + 2)(m + 3)x + (m + 1)(m + 2)(m + 3)] |

{/* source:cpp-numeric-special-functions-assoc-laguerre:0013 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::assoc_laguerre(int_num1, int_num2, num)` has the same effect as `std::assoc_laguerre(int_num1, int_num2, static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-special-functions-assoc-laguerre:0014 */}
```cpp
#include <cmath>
#include <iostream>
 
double L1(unsigned m, double x)
{
    return -x + m + 1;
}
 
double L2(unsigned m, double x)
{
    return 0.5 * (x * x - 2 * (m + 2) * x + (m + 1) * (m + 2));
}
 
int main()
{
    // spot-checks
    std::cout << std::assoc_laguerre(1, 10, 0.5) << '=' << L1(10, 0.5) << '\n'
              << std::assoc_laguerre(2, 10, 0.5) << '=' << L2(10, 0.5) << '\n';
}
```

Output:

```text
10.5=10.5
60.125=60.125
```
