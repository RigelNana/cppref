### Return value

{/* source:cpp-numeric-special-functions-sph-neumann:0004 */}
If no errors occur, returns the value of the spherical Bessel function of the second kind (spherical Neumann function) of `n` and `x`, that is nn(`x`) = (π/2x)1/2 Nn+1/2(`x`) where Nn(`x`) is `std::cyl_neumann(n, x)` and `x`≥0.

### Error handling

{/* source:cpp-numeric-special-functions-sph-neumann:0005 */}
Errors may be reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling)

{/* source:cpp-numeric-special-functions-sph-neumann:0006 */}
- If the argument is NaN, NaN is returned and domain error is not reported
- If n≥128, the behavior is implementation-defined

### Notes

{/* source:cpp-numeric-special-functions-sph-neumann:0007 */}
Implementations that do not support C++17, but support [ISO 29124:2010](/docs/cpp/library/experimental/special_math), provide this function if `__STDCPP_MATH_SPEC_FUNCS__` is defined by the implementation to a value at least `201003L` and if the user defines `__STDCPP_WANT_MATH_SPEC_FUNCS__` before including any standard library headers.

{/* source:cpp-numeric-special-functions-sph-neumann:0008 */}
Implementations that do not support ISO 29124:2010 but support TR 19768:2007 (TR1), provide this function in the header `tr1/cmath` and namespace `std::tr1`.

{/* source:cpp-numeric-special-functions-sph-neumann:0009 */}
An implementation of this function is also available in [boost.math](https://www.boost.org/doc/libs/release/libs/math/doc/html/math_toolkit/bessel/sph_bessel.html).

{/* source:cpp-numeric-special-functions-sph-neumann:0010 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::sph_neumann(int_num, num)` has the same effect as `std::sph_neumann(int_num, static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-special-functions-sph-neumann:0011 */}
```cpp
#include <cmath>
#include <iostream>
 
int main()
{
    // spot check for n == 1
    double x = 1.2345;
    std::cout << "n_1(" << x << ") = " << std::sph_neumann(1, x) << '\n';
 
    // exact solution for n_1
    std::cout << "-cos(x)/x² - sin(x)/x = "
              << -std::cos(x) / (x * x) - std::sin(x) / x << '\n';
}
```

Output:

```text
n_1(1.2345) = -0.981201
-cos(x)/x² - sin(x)/x = -0.981201
```
