{/* source:cpp-numeric-valarray-operator-cmp:0001 */}
Compares each value within the numeric array with another value.

{/* source:cpp-numeric-valarray-operator-cmp:0002 */}
1) Returns a numeric array of `bool` containing elements each of which is obtained by applying the indicated comparison operator to the corresponding values of `lhs` and `rhs`.

{/* source:cpp-numeric-valarray-operator-cmp:0003 */}
The behavior is undefined if `size() != v.size()`.

{/* source:cpp-numeric-valarray-operator-cmp:0004 */}
2) Returns a numeric array of `bool` containing elements each of which is obtained by applying the indicated comparison operator to `lhsv` and the corresponding value of `rhs`.

{/* source:cpp-numeric-valarray-operator-cmp:0005 */}
3) Returns a numeric array of `bool` containing elements each of which is obtained by applying the indicated comparison operator to the corresponding value of `lhs` and `rhsv`.

### Parameters

{/* source:cpp-numeric-valarray-operator-cmp:0006 */}
<ParameterList>
  <Parameter name="lhs, rhs">numeric arrays to compare</Parameter>
  <Parameter name="lhsv, rhsv">values to compare to each element within a numeric array</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-valarray-operator-cmp:0007 */}
A numeric array of `bool` containing comparison results of corresponding elements.

### Exceptions

{/* source:cpp-numeric-valarray-operator-cmp:0008 */}
May throw implementation-defined exceptions.

### Notes

{/* source:cpp-numeric-valarray-operator-cmp:0009 */}
Each of the operators can only be instantiated if the following requirements are met:

{/* source:cpp-numeric-valarray-operator-cmp:0010 */}
- The indicated operator can be applied to type `T`.
- The result value can be unambiguously converted to `bool`.

{/* source:cpp-numeric-valarray-operator-cmp:0011 */}
The function can be implemented with the return type different from [`std::valarray`](/docs/cpp/library/numeric/valarray). In this case, the replacement type has the following properties:

{/* source:cpp-numeric-valarray-operator-cmp:0012 */}
- All const member functions of [`std::valarray`](/docs/cpp/library/numeric/valarray) are provided.
- [`std::valarray`](/docs/cpp/library/numeric/valarray), [`std::slice_array`](/docs/cpp/library/numeric/valarray/slice_array), [`std::gslice_array`](/docs/cpp/library/numeric/valarray/gslice_array), [`std::mask_array`](/docs/cpp/library/numeric/valarray/mask_array) and [`std::indirect_array`](/docs/cpp/library/numeric/valarray/indirect_array) can be constructed from the replacement type.
- For every function taking a const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) <InlineRevision since="C++11">except [`begin()`](/docs/cpp/library/numeric/valarray/begin2) and [`end()`](/docs/cpp/library/numeric/valarray/end2)</InlineRevision>, identical functions taking the replacement types shall be added;
- For every function taking two const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) arguments, identical functions taking every combination of const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) and replacement types shall be added.
- The return type does not add more than two levels of template nesting over the most deeply-nested argument type.

### Example

{/* source:cpp-numeric-valarray-operator-cmp:0013 */}
Output:
```cpp
#include <iostream>
#include <valarray>
 
int main()
{
    // zero all negatives in a valarray
    std::valarray<int> v = {1, -1, 0, -3, 10, -1, -2};
    std::cout << "Before: ";
    for (auto n : v)
        std::cout << n << ' ';
    std::cout << '\n';
    v[v < 0] = 0;
    std::cout << "After: ";
    for (auto n : v)
        std::cout << n << ' ';
    std::cout << '\n';
 
    // convert the valarray<bool> result of == to a single bool
    std::valarray<int> a = {1, 2, 3};
    std::valarray<int> b = {2, 4, 6};
 
    std::cout << "2*a == b is " << std::boolalpha
              << (2 * a == b).min() << '\n';
}
```
Output:
```text
Before: 1 -1 0 -3 10 -1 -2
After: 1 0 0 0 10 0 0
2*a == b is true
```
