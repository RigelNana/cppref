{/* source:cpp-numeric-valarray-min:0001 */}
Computes the minimum value of the elements.

{/* source:cpp-numeric-valarray-min:0002 */}
If there are no elements, the behavior is undefined.

{/* source:cpp-numeric-valarray-min:0003 */}
The function can be used only if `operator<` is defined for type `T`.

### Parameters

{/* source:cpp-numeric-valarray-min:0004 */}
(none)

### Return value

{/* source:cpp-numeric-valarray-min:0005 */}
The minimum of the elements.

### Example

{/* source:cpp-numeric-valarray-min:0006 */}
Output:
```cpp
#include <valarray>
#include <iostream>
 
int main()
{
    std::valarray<double> a{1, 2, 3, 4, 5, 6, 7, 8};
    std::cout << "Minimum value : " << a.min() << "\n";
}
```
Output:
```text
Minimum value : 1
```
