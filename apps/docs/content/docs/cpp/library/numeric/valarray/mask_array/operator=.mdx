{/* source:cpp-numeric-valarray-mask-array-operator:0001 */}
Assigns values to all referred elements.

{/* source:cpp-numeric-valarray-mask-array-operator:0002 */}
1) Assigns `value` to all of the elements.

{/* source:cpp-numeric-valarray-mask-array-operator:0003 */}
2) Assigns the elements of `val_arr` to the referred to elements of `*this`.

{/* source:cpp-numeric-valarray-mask-array-operator:0004 */}
3) Assigns the selected elements from `other_arr` to the referred to elements of `*this`.

### Parameters

{/* source:cpp-numeric-valarray-mask-array-operator:0005 */}
<ParameterList>
  <Parameter name="value">a value to assign to all of the referred elements</Parameter>
  <Parameter name="val_arr">[`std::valarray`](/docs/cpp/library/numeric/valarray) to assign</Parameter>
  <Parameter name="other_arr">[`std::mask_array`](/docs/cpp/library/numeric/valarray/mask_array) to assign</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-valarray-mask-array-operator:0006 */}
1,2) (none)

{/* source:cpp-numeric-valarray-mask-array-operator:0007 */}
3) `*this`

### Example

{/* source:cpp-numeric-valarray-mask-array-operator:0008 */}
Output:
```cpp
#include <iomanip>
#include <iostream>
#include <valarray>
 
void print(std::valarray<int> const& v)
{
    for (int e : v)
        std::cout << std::setw(2) << e << ' ';
    std::cout << '\n';
}
 
int main()
{
    const auto init = {1, 2, 3, 4, 5, 6, 7, 8};
    std::valarray<int> v;
 
    v = init;
    v[(v % 2) == 0] = 0; // (1)
    print(v);
 
    v = init;
    v[(v % 2) == 1] = std::valarray<int>{-1, -2, -3, -4}; // (2)
    print(v);
 
    v = init;
    v[(v % 2) == 0] = v[(v % 2) == 1]; // (3)
    print(v);
}
```
Output:
```text
 1  0  3  0  5  0  7  0 
-1  2 -2  4 -3  6 -4  8 
 1  1  3  3  5  5  7  7
```
