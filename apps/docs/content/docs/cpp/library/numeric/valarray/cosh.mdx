{/* source:cpp-numeric-valarray-cosh:0001 */}
For each element in `va` computes hyperbolic cosine of the value of the element.

### Parameters

{/* source:cpp-numeric-valarray-cosh:0002 */}
<ParameterList>
  <Parameter name="va">value array to apply the operation to</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-valarray-cosh:0003 */}
Value array containing hyperbolic cosine of the values in `va`.

### Notes

{/* source:cpp-numeric-valarray-cosh:0004 */}
Unqualified function (`cosh`) is used to perform the computation. If such function is not available, [`std::cosh`](/docs/cpp/library/numeric/math/cosh) is used due to [argument-dependent lookup](/docs/cpp/language/functions/adl).

{/* source:cpp-numeric-valarray-cosh:0005 */}
The function can be implemented with the return type different from [`std::valarray`](/docs/cpp/library/numeric/valarray). In this case, the replacement type has the following properties:

{/* source:cpp-numeric-valarray-cosh:0006 */}
- All const member functions of [`std::valarray`](/docs/cpp/library/numeric/valarray) are provided.
- [`std::valarray`](/docs/cpp/library/numeric/valarray), [`std::slice_array`](/docs/cpp/library/numeric/valarray/slice_array), [`std::gslice_array`](/docs/cpp/library/numeric/valarray/gslice_array), [`std::mask_array`](/docs/cpp/library/numeric/valarray/mask_array) and [`std::indirect_array`](/docs/cpp/library/numeric/valarray/indirect_array) can be constructed from the replacement type.
- For every function taking a const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) <InlineRevision since="C++11">except [`begin()`](/docs/cpp/library/numeric/valarray/begin2) and [`end()`](/docs/cpp/library/numeric/valarray/end2)</InlineRevision>, identical functions taking the replacement types shall be added;
- For every function taking two const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) arguments, identical functions taking every combination of const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) and replacement types shall be added.
- The return type does not add more than two levels of template nesting over the most deeply-nested argument type.

### Possible implementation

{/* source:cpp-numeric-valarray-cosh:0007 */}
```cpp
template<class T>
valarray<T> cosh(const valarray<T>& va)
{
    valarray<T> other = va;
    for (T& i : other)
        i = cosh(i);
 
    return other; // proxy object may be returned
}
```

### Example

{/* source:cpp-numeric-valarray-cosh:0008 */}
Output:
```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
#include <valarray>
 
void show(const char* title, const std::valarray<float>& data)
{
    const int w{9};
    std::cout << std::setw(w) << title << " | ";
    for (float x : data)
        std::cout << std::setw(w) << x << " | ";
    std::cout << '\n';
}
 
int main()
{
    const std::valarray<float> x{.1, .2, .3, .4};
    const auto sinh = std::sinh(x);
    const auto cosh = std::cosh(x);
    const auto z = (cosh * cosh) - (sinh * sinh);
 
    show("x", x);
    show("sinh(x)", sinh);
    show("cosh(x)", cosh);
    show("z", z);
}
```
Output:
```text
        x |       0.1 |       0.2 |       0.3 |       0.4 | 
  sinh(x) |  0.100167 |  0.201336 |   0.30452 |  0.410752 | 
  cosh(x) |     1.005 |   1.02007 |   1.04534 |   1.08107 | 
        z |         1 |         1 |         1 |         1 |
```
