{/* source:cpp-numeric-valarray-slice:0001 */}
`std::slice` is the selector class that identifies a subset of [`std::valarray`](/docs/cpp/library/numeric/valarray) similar to [BLAS](https://en.wikipedia.org/wiki/BLAS) slice. An object of type `std::slice` holds three values: the starting index, the stride, and the total number of values in the subset. Objects of type `std::slice` can be used as indices with valarray's operator[].

#### std::slice::slice
<DeclarationDoc>
  <Declaration id="1" language="cpp" code={` slice()`} />
  <Declaration id="2" language="cpp" code={` slice( std::size_t start, std::size_t size, std::size_t stride );`} />
  <Declaration id="3" language="cpp" code={` slice( const slice& other );`} />

  <DeclarationDescription>
    Constructs a new slice.
    1. Default constructor. Equivalent to `slice(0, 0, 0)`. This constructor exists only to allow construction of arrays of slices.
    2. Constructs a new slice with parameters `start`, `size`, `stride`. This slice will refer to `size` number of elements, each with the position:
       - `start + 0 * stride`
       - `start + 1 * stride`
       - `...`
       - `start + (size - 1) * stride`
    3. Constructs a copy of `other`.
  </DeclarationDescription>
</DeclarationDoc>

  <Parameter name="stride">the number of positions between successive elements in the slice</Parameter>
  <Parameter name="other">another slice to copy</Parameter>

    This function  is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when std::slice is an associated class of the arguments.

### Example

{/* source:cpp-numeric-valarray-slice:0007 */}
Barebones valarray-backed Matrix class with a [trace](https://en.wikipedia.org/wiki/Trace_(linear_algebra)) calculating function.
```cpp
#include <iostream>
#include <valarray>
 
class Matrix
{
    std::valarray<int> data;
    int dim;
public:
    Matrix(int r, int c) : data(r*c), dim(c) {}
    int& operator()(int r, int c) { return data[r * dim + c]; }
    int trace() const { return data[std::slice(0, dim, dim + 1)].sum(); }
};
 
int main()
{
    Matrix m(3, 3);
    int n = 0;
    for (int r = 0; r < 3; ++r)
       for (int c = 0; c < 3; ++c)
           m(r, c) = ++n;
    std::cout << "Trace of the matrix (1,2,3) (4,5,6) (7,8,9) is " << m.trace() << '\n';
}
```
Output:
```text
Trace of the matrix (1,2,3) (4,5,6) (7,8,9) is 15
```
