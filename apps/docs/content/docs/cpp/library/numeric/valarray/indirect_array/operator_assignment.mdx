{/* source:cpp-numeric-valarray-indirect-array-operator:0001 */}
Assigns values to all referred elements.

{/* source:cpp-numeric-valarray-indirect-array-operator:0002 */}
1) Assigns `value` to all of the elements.

{/* source:cpp-numeric-valarray-indirect-array-operator:0003 */}
2) Assigns the elements of `val_arr` to the referred to elements of `*this`.

{/* source:cpp-numeric-valarray-indirect-array-operator:0004 */}
3) Assigns the selected elements from `other_arr` to the referred to elements of `*this`.

### Parameters

{/* source:cpp-numeric-valarray-indirect-array-operator:0005 */}
<ParameterList>
  <Parameter name="value">a value to assign to all of the referred elements</Parameter>
  <Parameter name="val_arr">[`std::valarray`](/docs/cpp/library/numeric/valarray) to assign</Parameter>
  <Parameter name="other_arr">[`std::indirect_array`](/docs/cpp/library/numeric/valarray/indirect_array) to assign</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-valarray-indirect-array-operator:0006 */}
1,2) (none)

{/* source:cpp-numeric-valarray-indirect-array-operator:0007 */}
3) `*this`

### Example

{/* source:cpp-numeric-valarray-indirect-array-operator:0008 */}
Output:
```cpp
#include <iomanip>
#include <iostream>
#include <numeric>
#include <valarray>
 
void print(int n, std::valarray<int> const& v)
{
    std::cout << n << ':';
    for (int e : v)
        std::cout << std::setw(3) << e;
    std::cout << '\n';
}
 
int main()
{
    std::valarray<int> v(8);
    std::iota(std::begin(v), std::end(v), 0);
    print(1, v);
 
    std::valarray<std::size_t> idx{1, 3, 5, 7};
    const std::indirect_array<int> ia = v[idx];
    // 'ia' refers to v[1], v[3], v[5], v[7]
    ia = -1; // (1), effectively:
             // v[1] = v[3] = v[5] = v[7] = -1;
    print(2, v);
 
    ia = /*std::valarray<int>*/{-1, -2, -3, -4}; // (2),
        // effectively: v[1] = -1, v[3] = -2, v[5] = -3, v[7] = -4;
    print(3, v);
 
    std::valarray<std::size_t> idx2{0, 2, 4, 6};
    const std::indirect_array<int> ia2 = v[idx2];
    // 'ia2' refers to v[0], v[2], v[4], v[6]
    ia = ia2; // (3), effectively:
              // v[1] = v[0], v[3] = v[2], v[5] = v[4], v[7] = v[6];
    print(4, v);
}
```
Output:
```text
1:  0  1  2  3  4  5  6  7
2:  0 -1  2 -1  4 -1  6 -1
3:  0 -1  2 -2  4 -3  6 -4
4:  0  0  2  2  4  4  6  6
```
