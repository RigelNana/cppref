{/* source:cpp-numeric-valarray-valarray:0001 */}
Constructs new numeric array from various sources.

{/* source:cpp-numeric-valarray-valarray:0002 */}
1) Default constructor. Constructs an empty numeric array.

{/* source:cpp-numeric-valarray-valarray:0003 */}
2) Constructs a numeric array with `count` copies of [value-initialized](/docs/cpp/language/initialization/value_initialization) elements.

{/* source:cpp-numeric-valarray-valarray:0004 */}
3) Constructs a numeric array with `count` copies of `val`.

{/* source:cpp-numeric-valarray-valarray:0005 */}
4) Constructs a numeric array with copies of `count` values from an array pointed to by `vals`. If this array contains less than `count` values, the behavior is undefined.

{/* source:cpp-numeric-valarray-valarray:0006 */}
5) Copy constructor. Constructs the numeric array with the copy of the contents of `other`.

{/* source:cpp-numeric-valarray-valarray:0007 */}
6) Move constructor. Constructs the container with the contents of `other` using move semantics.

{/* source:cpp-numeric-valarray-valarray:0008 */}
7-10) [Converting constructor](/docs/cpp/language/classes/converting_constructor). Convert the corresponding data structure to a `valarray`.

{/* source:cpp-numeric-valarray-valarray:0009 */}
11) Constructs the numeric array with the contents of the initializer list `il`.

### Parameters

{/* source:cpp-numeric-valarray-valarray:0010 */}
<ParameterList>
  <Parameter name="count">the number of elements to construct</Parameter>
  <Parameter name="val">the value to initialize the elements with</Parameter>
  <Parameter name="vals">pointer to a C array to use as source to initialize the contents</Parameter>
  <Parameter name="other">another numeric array to use as source to initialize the contents</Parameter>
  <Parameter name="sa">slice array to initialize the elements with</Parameter>
  <Parameter name="gsa">generic slice array to initialize the elements with</Parameter>
  <Parameter name="ma">mask array to initialize the elements with</Parameter>
  <Parameter name="ia">indirect array to initialize the elements with</Parameter>
  <Parameter name="il">initializer list to initialize the elements with</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-numeric-valarray-valarray:0011 */}
1-5, 7-11) May throw implementation-defined exceptions.
