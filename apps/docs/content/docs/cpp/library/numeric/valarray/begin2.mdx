{/* source:cpp-numeric-valarray-begin2:0001 */}
The overload of [`std::begin`](/docs/cpp/library/iterator/begin) for `valarray` returns an iterator of unspecified type referring to the first element in the numeric array.

{/* source:cpp-numeric-valarray-begin2:0002 */}
1) The return type must
- meet the requirements of [mutable](/docs/cpp/library/iterator) [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator),
<Revision since="C++20">
- model [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator),
</Revision>
- have a member type `value_type`, which is `T`, and
- have a member type `reference`, which is `T&`.

{/* source:cpp-numeric-valarray-begin2:0003 */}
2) The return type must
- meet the requirements of [constant](/docs/cpp/library/iterator) [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator),
<Revision since="C++20">
- model [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator),
</Revision>
- have a member type `value_type`, which is `T`, and
- have a member type `reference`, which is `const T&`.

{/* source:cpp-numeric-valarray-begin2:0004 */}
The iterator returned from this function is invalidated when the member function [`resize()`](/docs/cpp/library/numeric/valarray/resize) is called on `v` or when the lifetime of `v` ends, whichever comes first.

### Parameters

{/* source:cpp-numeric-valarray-begin2:0005 */}
<ParameterList>
  <Parameter name="v">a numeric array</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-valarray-begin2:0006 */}
Iterator to the first value in the numeric array.

### Exceptions

{/* source:cpp-numeric-valarray-begin2:0007 */}
May throw implementation-defined exceptions.

### Notes

{/* source:cpp-numeric-valarray-begin2:0008 */}
Unlike other functions that take `std::valarray` arguments, `begin()` cannot accept the replacement types (such as the types produced by expression templates) that may be returned from expressions involving valarrays: [`std::begin(v1 + v2)`](/docs/cpp/library/iterator/begin) is not portable, `std::begin(std::valarray<T>(v1 + v2))`[std::begin](/docs/cpp/library/iterator/begin)[std::valarray](/docs/cpp/library/numeric/valarray) has to be used instead.

{/* source:cpp-numeric-valarray-begin2:0009 */}
The intent of this function is to allow [range for loops](/docs/cpp/language/statements/range-for) to work with valarrays, not to provide container semantics.

### Example

{/* source:cpp-numeric-valarray-begin2:0010 */}
Output:
```cpp
#include <algorithm>
#include <iostream>
#include <valarray>
 
void show(const std::valarray<int>& v)
{
    std::for_each(std::begin(v), std::end(v), [](int c)
    {
        std::cout << c << ' ';
    });
    std::cout << '\n';
};
 
int main()
{
    const std::valarray<int> x{47, 70, 37, 52, 90, 23, 17, 33, 22, 16, 21, 4};
    const std::valarray<int> y{25, 31, 71, 56, 21, 21, 15, 34, 21, 27, 12, 6};
 
    show(x); 
    show(y); 
 
    const std::valarray<int> z{x + y};
 
    for (char c : z)
        std::cout << c;
}
```
Output:
```text
47 70 37 52 90 23 17 33 22 16 21 4 
25 31 71 56 21 21 15 34 21 27 12 6 
Hello, C++!
```
