{/* source:cpp-numeric-valarray-max:0001 */}
Computes the maximum value of the elements.

{/* source:cpp-numeric-valarray-max:0002 */}
If there are no elements, the behavior is undefined.

{/* source:cpp-numeric-valarray-max:0003 */}
The function can be used only if `operator<` is defined for type `T`.

### Parameters

{/* source:cpp-numeric-valarray-max:0004 */}
(none)

### Return value

{/* source:cpp-numeric-valarray-max:0005 */}
The maximum of the elements.

### Example

{/* source:cpp-numeric-valarray-max:0006 */}
Output:
```cpp
#include <valarray>
#include <iostream>
 
int main()
{
    std::valarray<double> a{1, 2, 3, 4, 5, 6, 7, 8};
    std::cout << "Maximum value : " << a.max() << "\n";
}
```
Output:
```text
Maximum value : 8
```
