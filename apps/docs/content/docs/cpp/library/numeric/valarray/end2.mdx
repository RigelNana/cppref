{/* source:cpp-numeric-valarray-end2:0001 */}
The overload of [`std::end`](/docs/cpp/library/iterator/end) for `valarray` returns an iterator of unspecified type referring to the one past the last element in the numeric array.

{/* source:cpp-numeric-valarray-end2:0002 */}
1) The return type must
- meet the requirements of [mutable](/docs/cpp/library/iterator) [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator),
<Revision since="C++20">
- model [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator),
</Revision>
- have a member type `value_type`, which is `T`, and
- have a member type `reference`, which is `T&`.

{/* source:cpp-numeric-valarray-end2:0003 */}
2) The return type must
- meet the requirements of [constant](/docs/cpp/library/iterator) [*LegacyRandomAccessIterator*](/docs/cpp/library/named_req/RandomAccessIterator),
<Revision since="C++20">
- model [`contiguous_iterator`](/docs/cpp/library/iterator/contiguous_iterator),
</Revision>
- have a member type `value_type`, which is `T`, and
- have a member type `reference`, which is `const T&`.

{/* source:cpp-numeric-valarray-end2:0004 */}
The iterator returned from this function is invalidated when the member function [`resize()`](/docs/cpp/library/numeric/valarray/resize) is called on `v` or when the lifetime of `v` ends, whichever comes first.

### Parameters

{/* source:cpp-numeric-valarray-end2:0005 */}
<ParameterList>
  <Parameter name="v">a numeric array</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-valarray-end2:0006 */}
Iterator to one past the last value in the numeric array.

### Exceptions

{/* source:cpp-numeric-valarray-end2:0007 */}
May throw implementation-defined exceptions.

### Notes

{/* source:cpp-numeric-valarray-end2:0008 */}
Unlike other functions that take `std::valarray` arguments, `end()` cannot accept the replacement types (such as the types produced by expression templates) that may be returned from expressions involving valarrays: [`std::end(v1 + v2)`](/docs/cpp/library/iterator/end) is not portable, `std::end(std::valarray<T>(v1 + v2))`[std::end](/docs/cpp/library/iterator/end)[std::valarray](/docs/cpp/library/numeric/valarray) has to be used instead.

{/* source:cpp-numeric-valarray-end2:0009 */}
The intent of this function is to allow [range for loops](/docs/cpp/language/statements/range-for) to work with valarrays, not to provide container semantics.

### Example

{/* source:cpp-numeric-valarray-end2:0010 */}
Output:
```cpp
#include <algorithm>
#include <iostream>
#include <valarray>
 
int main()
{
    const std::valarray<char> va
    {
        'H', 'e', 'l', 'l', 'o', 
        ',', ' ', 
        'C', '+', '+', '!', '\n'
    };
 
    std::for_each(std::begin(va), std::end(va),
                  [](char c){ std::cout << c; });
}
```
Output:
```text
Hello, C++!
```
