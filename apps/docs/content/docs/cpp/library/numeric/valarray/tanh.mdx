{/* source:cpp-numeric-valarray-tanh:0001 */}
For each element in `va` computes hyperbolic tangent of the value of the element.

### Parameters

{/* source:cpp-numeric-valarray-tanh:0002 */}
<ParameterList>
  <Parameter name="va">value array to apply the operation to</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-valarray-tanh:0003 */}
Value array containing hyperbolic tangent of the values in `va`.

### Notes

{/* source:cpp-numeric-valarray-tanh:0004 */}
Unqualified function (`tanh`) is used to perform the computation. If such function is not available, [`std::tanh`](/docs/cpp/library/numeric/math/tanh) is used due to [argument-dependent lookup](/docs/cpp/language/functions/adl).

{/* source:cpp-numeric-valarray-tanh:0005 */}
The function can be implemented with the return type different from [`std::valarray`](/docs/cpp/library/numeric/valarray). In this case, the replacement type has the following properties:

{/* source:cpp-numeric-valarray-tanh:0006 */}
- All const member functions of [`std::valarray`](/docs/cpp/library/numeric/valarray) are provided.
- [`std::valarray`](/docs/cpp/library/numeric/valarray), [`std::slice_array`](/docs/cpp/library/numeric/valarray/slice_array), [`std::gslice_array`](/docs/cpp/library/numeric/valarray/gslice_array), [`std::mask_array`](/docs/cpp/library/numeric/valarray/mask_array) and [`std::indirect_array`](/docs/cpp/library/numeric/valarray/indirect_array) can be constructed from the replacement type.
- For every function taking a const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) <InlineRevision since="C++11">except [`begin()`](/docs/cpp/library/numeric/valarray/begin2) and [`end()`](/docs/cpp/library/numeric/valarray/end2)</InlineRevision>, identical functions taking the replacement types shall be added;
- For every function taking two const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) arguments, identical functions taking every combination of const [`std::valarray<T>&`](/docs/cpp/library/numeric/valarray) and replacement types shall be added.
- The return type does not add more than two levels of template nesting over the most deeply-nested argument type.

### Possible implementation

{/* source:cpp-numeric-valarray-tanh:0007 */}
```cpp
template<class T>
valarray<T> tanh(const valarray<T>& va)
{
    valarray<T> other = va;
    for (T& i : other)
        i = tanh(i);
 
    return other; // proxy object may be returned
}
```

### Example

{/* source:cpp-numeric-valarray-tanh:0008 */}
Output:
```cpp
#include <cmath>
#include <iostream>
#include <valarray>
 
auto show = [](char const* title, const std::valarray<double>& va)
{
    std::cout << title << " :";
    for (auto x : va)
        std::cout << "  " << std::fixed << x;
    std::cout << '\n';
};
 
int main()
{
    const std::valarray<double> x = {.0, .1, .2, .3};
    const std::valarray<double> sinh = std::sinh(x);
    const std::valarray<double> cosh = std::cosh(x);
    const std::valarray<double> tanh = std::tanh(x);
    const std::valarray<double> tanh_by_def = sinh / cosh;
    const std::valarray<double> tanh_2x = std::tanh(2.0 * x);
    const std::valarray<double> tanh_2x_by_def = 
        (2.0 * tanh) / (1.0 + std::pow(tanh, 2.0));
 
    show("x              ", x);
    show("tanh(x)        ", tanh);
    show("tanh(x) (def)  ", tanh_by_def);
    show("tanh(2*x)      ", tanh_2x);
    show("tanh(2*x) (def)", tanh_2x_by_def);
}
```
Output:
```text
x               :  0.000000  0.100000  0.200000  0.300000
tanh(x)         :  0.000000  0.099668  0.197375  0.291313
tanh(x) (def)   :  0.000000  0.099668  0.197375  0.291313
tanh(2*x)       :  0.000000  0.197375  0.379949  0.537050
tanh(2*x) (def) :  0.000000  0.197375  0.379949  0.537050
```
