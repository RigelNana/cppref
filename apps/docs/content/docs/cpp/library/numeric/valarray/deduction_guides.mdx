This [deduction guide](/docs/cpp/language/templates/ctad) is provided for [`std::valarray`](/docs/cpp/library/numeric/valarray) to allow deduction from array and size (note that deduction from pointer and size is covered by the implicit guides).

### Example

{/* source:cpp-numeric-valarray-deduction-guides:0002 */}
Output:
```cpp
#include <iostream>
#include <valarray>
 
int main()
{
    int a[] = {1, 2, 3, 4};
    std::valarray va(a, 3); // uses explicit deduction guide
    for (int x : va)
        std::cout << x << ' ';
    std::cout << '\n';
}
```
Output:
```text
1 2 3
```
