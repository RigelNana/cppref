{/* source:cpp-numeric-mul-sat:0001 */}
Computes the [saturating](https://en.wikipedia.org/wiki/Saturation_arithmetic) multiplication `x × y`. This operation (unlike built-in [arithmetic operations on integers](/docs/cpp/language/expressions/operator_arithmetic#Overflows)) behaves as-if it is a mathematical operation with an infinite range. Let `q` denote the result of such operation. Returns:

{/* source:cpp-numeric-mul-sat:0002 */}
- `q`, if `q` is representable as a value of type `T`. Otherwise, the largest or smallest value of type `T`, whichever is closer to the `q`.

{/* source:cpp-numeric-mul-sat:0003 */}
This overload participates in overload resolution only if `T` is an [integer type](/docs/cpp/language/basic_concepts/types#Integer_types), that is: `signed char`, `short`, `int`, `long`, `long long`, an extended signed integer type, or an unsigned version of such types. In particular, `T` must not be (possibly cv-qualified) `bool`, `char`, `wchar_t`, `char8_t`, `char16_t`, and `char32_t`, as these types are not intended for arithmetic.

### Return value

{/* source:cpp-numeric-mul-sat:0005 */}
Saturated `x × y`.

### Notes

{/* source:cpp-numeric-mul-sat:0006 */}
Unlike the built-in arithmetic operators on integers, the [integral promotion](/docs/cpp/language/expressions/implicit_cast#Integral_promotion) does not apply to the `x` and `y` arguments.

{/* source:cpp-numeric-mul-sat:0007 */}
If two arguments of different type are passed, the call fails to compile, i.e. the behavior relative to [template argument deduction](/docs/cpp/language/templates/template_argument_deduction) is the same as for [`std::min`](/docs/cpp/library/algorithm/min) or [`std::max`](/docs/cpp/library/algorithm/max).

{/* source:cpp-numeric-mul-sat:0008 */}
Most modern hardware architectures have efficient support for saturation arithmetic on SIMD vectors, including SSE2 for x86 and NEON for ARM.

### Example

{/* source:cpp-numeric-mul-sat:0011 */}
Can be previewed on [Compiler Explorer](https://godbolt.org/z/T58GEKPM6).

```cpp
#include <climits>
#include <numeric>
 
static_assert
(""
    && (std::mul_sat<int>(2, 3) == 6) // not saturated
    && (std::mul_sat<int>(INT_MAX / 2, 3) == INT_MAX) // saturated
    && (std::mul_sat<int>(-2, 3) == -6) // not saturated
    && (std::mul_sat<int>(INT_MIN / -2, -3) == INT_MIN) // saturated
    && (std::mul_sat<unsigned>(2, 3) == 6) // not saturated
    && (std::mul_sat<unsigned>(UINT_MAX / 2, 3) == UINT_MAX) // saturated
);
 
int main() {}
```
