  <DeclarationDescription>
    {/* source:cpp-numeric-simd-basic-simd:0001 */}
    1) `std::basic_simd` specialization is a data-parallel type. The default ABI tag is determined by the implementation at compile-time.

    {/* source:cpp-numeric-simd-basic-simd:0002 */}
    2) `std::simd` is an alias template that allows users to specify the width to a certain size. The default width is determined by the implementation at compile-time.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-numeric-simd-basic-simd:0003 */}
Every specialization of `basic_simd` is a complete type. The specialization is

{/* source:cpp-numeric-simd-basic-simd:0004 */}
- enabled, if `T` is a [vectorizable type](/docs/cpp/library/numeric/simd#vectorizable_types), and there exists value `M` in the range [`1`, `64`] such that `Abi` is [`deduce-abi-t`](/docs/cpp/library/numeric/simd#deduce-abi-t)`<T, M>`,
- otherwise disabled, if `T` is not a vectorizable type,
- otherwise, it is implementation-defined if such specialization is enabled.

{/* source:cpp-numeric-simd-basic-simd:0005 */}
If `basic_simd<T, Abi>` is disabled, the specialization has all deleted default constructor, destructor, copy constructor, and copy assignment. In addition, only the member types below are present.

{/* source:cpp-numeric-simd-basic-simd:0006 */}
If `basic_simd<T, Abi>` is enabled, `basic_simd<T, Abi>` is [TriviallyCopyable](/docs/cpp/library/named_req/TriviallyCopyable).

### Deduction guide

{/* source:cpp-numeric-simd-basic-simd:0012 */}
<DeclarationDoc>
  <Declaration language="cpp" since="C++26" code={`template< class R, class... Ts >
basic_simd( R&& r, Ts... ) -> /* see below */;`} />
</DeclarationDoc>

{/* source:cpp-numeric-simd-basic-simd:0013 */}
The deduction guide is present only if:

{/* source:cpp-numeric-simd-basic-simd:0014 */}
- `R` models [contiguous_range](/docs/cpp/library/ranges/contiguous_range) and [sized_range](/docs/cpp/library/ranges/sized_range), and `ranges::size(r)` is a [constant expression](/docs/cpp/language/expressions/constant_expression).

{/* source:cpp-numeric-simd-basic-simd:0015 */}
The deduced type is equivalent to `std::simd<ranges::range_value_t<R>, ranges::size(r)>`.

### Notes

{/* source:cpp-numeric-simd-basic-simd:0016 */}
Implementations are recommended to support explicit conversions between enabled specializations of `basic_simd` and appropriate implementation-defined types. These appropriate types are non-standard vector types which are available in the implementation.
