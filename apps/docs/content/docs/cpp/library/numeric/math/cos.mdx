### Parameters

{/* source:cpp-numeric-math-cos:0004 */}
<ParameterList>
  <Parameter name="num">floating-point or integer value representing angle in radians</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-math-cos:0005 */}
If no errors occur, the cosine of `num` (`cos(num)`) in the range `[-1.0, +1.0]`, is returned.

{/* source:cpp-numeric-math-cos:0006 */}
<Revision until="C++11">
The result may have little or no significance if the magnitude of `num` is large.
</Revision>

{/* source:cpp-numeric-math-cos:0007 */}
If a domain error occurs, an implementation-defined value is returned (NaN where supported).

{/* source:cpp-numeric-math-cos:0008 */}
If a range error occurs due to underflow, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-cos:0009 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-cos:0010 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-cos:0011 */}
- if the argument is ±0, the result is `1.0`.
- if the argument is ±∞, NaN is returned and [FE_INVALID](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised.
- if the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-cos:0012 */}
The case where the argument is infinite is not specified to be a domain error in C, but it is defined as a [domain error in POSIX](https://pubs.opengroup.org/onlinepubs/9699919799/functions/cos.html).

{/* source:cpp-numeric-math-cos:0013 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::cos(num)` has the same effect as `std::cos(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-cos:0014 */}
```cpp
#include <cerrno>
#include <cfenv>
#include <cmath>
#include <iomanip>
#include <iostream>
#include <numbers>
 
// #pragma STDC FENV_ACCESS ON
 
constexpr double pi = std::numbers::pi; // or std::acos(-1) before C++20
 
constexpr double your_cos(double x)
{
    double cos{1}, pow{x};
    for (auto fac{1ull}, n{1ull}; n != 19; fac *= ++n, pow *= x)
        if ((n & 1) == 0)
            cos += (n & 2 ? -pow : pow) / fac;
    return cos;
}
 
int main()
{
    std::cout << std::setprecision(10) << std::showpos
              << "Typical usage:\n"
              << "std::cos(pi/3) = " << std::cos(pi / 3) << '\n'
              << "your cos(pi/3) = " << your_cos(pi / 3) << '\n'
              << "std::cos(pi/2) = " << std::cos(pi / 2) << '\n'
              << "your cos(pi/2) = " << your_cos(pi / 2) << '\n'
              << "std::cos(-3*pi/4) = " << std::cos(-3 * pi / 4) << '\n'
              << "your cos(-3*pi/4) = " << your_cos(-3 * pi / 4) << '\n'
              << "Special values:\n"
              << "std::cos(+0) = " << std::cos(0.0) << '\n'
              << "std::cos(-0) = " << std::cos(-0.0) << '\n';
 
    // error handling
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "cos(INFINITY) = " << std::cos(INFINITY) << '\n';
    if (std::fetestexcept(FE_INVALID))
        std::cout << "    FE_INVALID raised\n";
}
```

Possible output:

```text
Typical usage:
std::cos(pi/3) = +0.5
your cos(pi/3) = +0.5
std::cos(pi/2) = +6.123233996e-17
your cos(pi/2) = -3.373452105e-15
std::cos(-3*pi/4) = -0.7071067812
your cos(-3*pi/4) = -0.7071067812
Special values:
std::cos(+0) = +1
std::cos(-0) = +1
cos(INFINITY) = -nan
    FE_INVALID raised
```
