### Return value

{/* source:cpp-numeric-math-sinh:0005 */}
enum -e-num 2

{/* source:cpp-numeric-math-sinh:0006 */}
If a range error due to overflow occurs, [±HUGE_VAL](/docs/cpp/library/numeric/math/HUGE_VAL), `±HUGE_VALF`, or `±HUGE_VALL` is returned.

{/* source:cpp-numeric-math-sinh:0007 */}
If a range error occurs due to underflow, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-sinh:0008 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-sinh:0009 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-sinh:0010 */}
- if the argument is ±0 or ±∞, it is returned unmodified.
- if the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-sinh:0011 */}
[POSIX specifies](https://pubs.opengroup.org/onlinepubs/9699919799/functions/sinh.html) that in case of underflow, `num` is returned unmodified, and if that is not supported, and implementation-defined value no greater than [DBL_MIN](/docs/cpp/library/utility/types/climits), [FLT_MIN](/docs/cpp/library/utility/types/climits), and [LDBL_MIN](/docs/cpp/library/utility/types/climits) is returned.

{/* source:cpp-numeric-math-sinh:0012 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::sinh(num)` has the same effect as `std::sinh(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-sinh:0013 */}
```cpp
#include <cerrno>
#include <cfenv>
#include <cmath>
#include <cstring>
#include <iostream>
// #pragma STDC FENV_ACCESS ON
 
int main()
{
    const double x = 42;
 
    std::cout << "sinh(1) = " << std::sinh(1) << '\n'
              << "sinh(-1) = " << std::sinh(-1) << '\n'
              << "log(sinh(" << x << ")+cosh(" << x << ")) = "
              << std::log(std::sinh(x) + std::cosh(x)) << '\n';
 
    // special values
    std::cout << "sinh(+0) = " << std::sinh(0.0) << '\n'
              << "sinh(-0) = " << std::sinh(-0.0) << '\n';
 
    // error handling
    errno = 0;
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "sinh(710.5) = " << std::sinh(710.5) << '\n';
 
    if (errno == ERANGE)
        std::cout << "    errno == ERANGE: " << std::strerror(errno) << '\n';
    if (std::fetestexcept(FE_OVERFLOW))
        std::cout << "    FE_OVERFLOW raised\n";
}
```

Output:

```text
sinh(1) = 1.1752
sinh(-1) = -1.1752
log(sinh(42)+cosh(42)) = 42
sinh(+0) = 0
sinh(-0) = -0
sinh(710.5) = inf
    errno == ERANGE: Numerical result out of range
    FE_OVERFLOW raised
```
