### Parameters

{/* source:cpp-numeric-math-nearbyint:0004 */}
<ParameterList>
  <Parameter name="num">floating-point or integer value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-math-nearbyint:0005 */}
The nearest integer value to `num`, according to the [current rounding mode](/docs/cpp/library/numeric/fenv/FE_round), is returned.

### Error handling

{/* source:cpp-numeric-math-nearbyint:0006 */}
This function is not subject to any of the errors specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-nearbyint:0007 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-nearbyint:0008 */}
- [FE_INEXACT](/docs/cpp/library/numeric/fenv/FE_exceptions) is never raised.
- If `num` is ±∞, it is returned, unmodified.
- If `num` is ±0, it is returned, unmodified.
- If `num` is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-nearbyint:0009 */}
The only difference between `std::nearbyint` and [std::rint](/docs/cpp/library/numeric/math/rint) is that `std::nearbyint` never raises [FE_INEXACT](/docs/cpp/library/numeric/fenv/FE_exceptions).

{/* source:cpp-numeric-math-nearbyint:0010 */}
The largest representable floating-point values are exact integers in all standard floating-point formats, so `std::nearbyint` never overflows on its own; however the result may overflow any integer type (including [std::intmax_t](/docs/cpp/library/utility/types/integer)), when stored in an integer variable.

{/* source:cpp-numeric-math-nearbyint:0011 */}
If the current rounding mode is [FE_TONEAREST](/docs/cpp/library/numeric/fenv/FE_round), this function rounds to even in halfway cases (like [std::rint](/docs/cpp/library/numeric/math/rint), but unlike [std::round](/docs/cpp/library/numeric/math/round)).

{/* source:cpp-numeric-math-nearbyint:0012 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::nearbyint(num)` has the same effect as `std::nearbyint(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-nearbyint:0013 */}
```cpp
#include <cfenv>
#include <cmath>
#include <iostream>
#pragma STDC FENV_ACCESS ON
 
int main()
{
    std::fesetround(FE_TONEAREST);
    std::cout << "rounding to nearest: \n"
              << "nearbyint(+2.3) = " << std::nearbyint(2.3)
              << "  nearbyint(+2.5) = " << std::nearbyint(2.5)
              << "  nearbyint(+3.5) = " << std::nearbyint(3.5) << '\n'
              << "nearbyint(-2.3) = " << std::nearbyint(-2.3)
              << "  nearbyint(-2.5) = " << std::nearbyint(-2.5)
              << "  nearbyint(-3.5) = " << std::nearbyint(-3.5) << '\n';
 
    std::fesetround(FE_DOWNWARD);
    std::cout << "rounding down:\n"
              << "nearbyint(+2.3) = " << std::nearbyint(2.3)
              << "  nearbyint(+2.5) = " << std::nearbyint(2.5)
              << "  nearbyint(+3.5) = " << std::nearbyint(3.5) << '\n'
              << "nearbyint(-2.3) = " << std::nearbyint(-2.3)
              << "  nearbyint(-2.5) = " << std::nearbyint(-2.5)
              << "  nearbyint(-3.5) = " << std::nearbyint(-3.5) << '\n';
 
    std::cout << "nearbyint(-0.0) = " << std::nearbyint(-0.0)  << '\n'
              << "nearbyint(-Inf) = " << std::nearbyint(-INFINITY) << '\n';
}
```

Output:

```text
rounding to nearest: 
nearbyint(+2.3) = 2  nearbyint(+2.5) = 2  nearbyint(+3.5) = 4
nearbyint(-2.3) = -2  nearbyint(-2.5) = -2  nearbyint(-3.5) = -4
rounding down:
nearbyint(+2.3) = 2  nearbyint(+2.5) = 2  nearbyint(+3.5) = 3
nearbyint(-2.3) = -3  nearbyint(-2.5) = -3  nearbyint(-3.5) = -4
nearbyint(-0.0) = -0
nearbyint(-Inf) = -inf
```
