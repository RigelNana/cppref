  <DeclarationDescription>
    {/* source:cpp-numeric-math-fpclassify:0001 */}
    1) Categorizes floating point value `num` into the following categories: zero, subnormal, normal, infinite, NAN, or implementation-defined category.<InlineRevision since="C++23"> The library provides overloads of `std::fpclassify` for all cv-unqualified floating-point types as the type of the parameter `num`.</InlineRevision>

    {/* source:cpp-numeric-math-fpclassify:0002 */}
    A) Additional overloads are provided for all integer types, which are treated as `double`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-numeric-math-fpclassify:0003 */}
<ParameterList>
  <Parameter name="num">floating-point or integer value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-math-fpclassify:0004 */}
one of [FP_INFINITE](/docs/cpp/library/numeric/math/FP_categories), [FP_NAN](/docs/cpp/library/numeric/math/FP_categories), [FP_NORMAL](/docs/cpp/library/numeric/math/FP_categories), [FP_SUBNORMAL](/docs/cpp/library/numeric/math/FP_categories), [FP_ZERO](/docs/cpp/library/numeric/math/FP_categories) or implementation-defined type, specifying the category of `num`.

### Notes

{/* source:cpp-numeric-math-fpclassify:0005 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::fpclassify(num)` has the same effect as `std::fpclassify(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-fpclassify:0006 */}
```cpp
#include <cfloat>
#include <cmath>
#include <iostream>
 
auto show_classification(double x)
{
    switch (std::fpclassify(x))
    {
        case FP_INFINITE:
            return "Inf";
        case FP_NAN:
            return "NaN";
        case FP_NORMAL:
            return "normal";
        case FP_SUBNORMAL:
            return "subnormal";
        case FP_ZERO:
            return "zero";
        default:
            return "unknown";
    }
}
 
int main()
{
    std::cout << "1.0/0.0 is " << show_classification(1 / 0.0) << '\n'
              << "0.0/0.0 is " << show_classification(0.0 / 0.0) << '\n'
              << "DBL_MIN/2 is " << show_classification(DBL_MIN / 2) << '\n'
              << "-0.0 is " << show_classification(-0.0) << '\n'
              << "1.0 is " << show_classification(1.0) << '\n';
}
```

Output:

```text
1.0/0.0 is Inf
0.0/0.0 is NaN
DBL_MIN/2 is subnormal
-0.0 is zero
1.0 is normal
```
