### Return value

{/* source:cpp-numeric-math-atan:0005 */}
π 2

{/* source:cpp-numeric-math-atan:0006 */}
π 2

{/* source:cpp-numeric-math-atan:0007 */}
If a range error occurs due to underflow, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-atan:0008 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-atan:0009 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-atan:0010 */}
- If the argument is ±0, it is returned unmodified.
- If the argument is +∞, +π/2 is returned.
- If the argument is -∞, -π/2 is returned.
- If the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-atan:0011 */}
[POSIX specifies](https://pubs.opengroup.org/onlinepubs/9699919799/functions/atan.html) that in case of underflow, `num` is returned unmodified, and if that is not supported, an implementation-defined value no greater than [`DBL_MIN`](/docs/cpp/library/utility/types/climits#Limits_of_floating-point_types), [FLT_MIN](/docs/cpp/library/utility/types/climits), and [LDBL_MIN](/docs/cpp/library/utility/types/climits) is returned.

{/* source:cpp-numeric-math-atan:0012 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::atan(num)` has the same effect as `std::atan(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-atan:0013 */}
```cpp
#include <cmath>
#include <iostream>
 
int main()
{
    std::cout << "atan(1) = " << std::atan(1) << '\n'
              << "4*atan(1) = " << 4 * std::atan(1) << '\n';
 
    // special values
    std::cout << "atan(Inf) = " << std::atan(INFINITY) << '\n'
              << "2*atan(Inf) = " << 2 * std::atan(INFINITY) << '\n'
              << "atan(-0.0) = " << std::atan(-0.0) << '\n'
              << "atan(+0.0) = " << std::atan(0) << '\n';
}
```

Output:

```text
atan(1) = 0.785398
4*atan(1) = 3.14159
atan(Inf) = 1.5708
2*atan(Inf) = 3.14159
atan(-0.0) = -0
atan(+0.0) = 0
```
