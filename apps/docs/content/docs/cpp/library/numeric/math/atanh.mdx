### Return value

{/* source:cpp-numeric-math-atanh:0005 */}
If no errors occur, the inverse hyperbolic tangent of `num` (`tanh-1 (num)`, or `artanh(num)`), is returned.

{/* source:cpp-numeric-math-atanh:0006 */}
If a domain error occurs, an implementation-defined value is returned (NaN where supported).

{/* source:cpp-numeric-math-atanh:0007 */}
If a pole error occurs, [±HUGE_VAL](/docs/cpp/library/numeric/math/HUGE_VAL), `±HUGE_VALF`, or `±HUGE_VALL` is returned (with the correct sign).

{/* source:cpp-numeric-math-atanh:0008 */}
If a range error occurs due to underflow, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-atanh:0009 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-atanh:0010 */}
If the argument is not on the interval `[-1, +1]`, a range error occurs.

{/* source:cpp-numeric-math-atanh:0011 */}
If the argument is ±1, a pole error occurs.

{/* source:cpp-numeric-math-atanh:0012 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-atanh:0013 */}
- if the argument is ±0, it is returned unmodified.
- if the argument is ±1, ±∞ is returned and [FE_DIVBYZERO](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised.
- if `|num|>1`, NaN is returned and [FE_INVALID](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised.
- if the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-atanh:0014 */}
Although the C standard (to which C++ refers for this function) names this function "arc hyperbolic tangent", the inverse functions of the hyperbolic functions are the area functions. Their argument is the area of a hyperbolic sector, not an arc. The correct name is "inverse hyperbolic tangent" (used by POSIX) or "area hyperbolic tangent".

{/* source:cpp-numeric-math-atanh:0015 */}
[POSIX specifies](https://pubs.opengroup.org/onlinepubs/9699919799/functions/atanh.html) that in case of underflow, `num` is returned unmodified, and if that is not supported, an implementation-defined value no greater than [DBL_MIN](/docs/cpp/library/utility/types/climits), [FLT_MIN](/docs/cpp/library/utility/types/climits), and [LDBL_MIN](/docs/cpp/library/utility/types/climits) is returned.

{/* source:cpp-numeric-math-atanh:0016 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::atanh(num)` has the same effect as `std::atanh(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-atanh:0017 */}
```cpp
#include <cerrno>
#include <cfenv>
#include <cfloat>
#include <cmath>
#include <cstring>
#include <iostream>
// #pragma STDC FENV_ACCESS ON
 
int main()
{
    std::cout << "atanh(0) = " << std::atanh(0) << '\n'
              << "atanh(-0) = " << std::atanh(-0.0) << '\n'
              << "atanh(0.9) = " << std::atanh(0.9) << '\n';
 
    // error handling
    errno = 0;
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "atanh(-1) = " << std::atanh(-1) << '\n';
 
    if (errno == ERANGE)
        std::cout << "    errno == ERANGE: " << std::strerror(errno) << '\n';
    if (std::fetestexcept(FE_DIVBYZERO))
        std::cout << "    FE_DIVBYZERO raised\n";
}
```

Possible output:

```text
atanh(0) = 0
atanh(-0) = -0
atanh(0.9) = 1.47222
atanh(-1) = -inf
    errno == ERANGE: Numerical result out of range
    FE_DIVBYZERO raised
```
