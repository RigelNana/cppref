### Return value

{/* source:cpp-numeric-math-rint:0005 */}
If no errors occur, the nearest integer value to `num`, according to the [current rounding mode](/docs/cpp/library/numeric/fenv/FE_round), is returned.

### Error handling

{/* source:cpp-numeric-math-rint:0006 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-rint:0007 */}
If the result of `std::lrint` or `std::llrint` is outside the range representable by the return type, a domain error or a range error may occur.

{/* source:cpp-numeric-math-rint:0008 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-rint:0009 */}
For the
`std::rint`
function:

{/* source:cpp-numeric-math-rint:0010 */}
- If `num` is ±∞, it is returned, unmodified.
- If `num` is ±0, it is returned, unmodified.
- If `num` is NaN, NaN is returned.

{/* source:cpp-numeric-math-rint:0011 */}
For
`std::lrint`
and
`std::llrint`
functions:

{/* source:cpp-numeric-math-rint:0012 */}
- If `num` is ±∞, [FE_INVALID](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised and an implementation-defined value is returned.
- If the result of the rounding is outside the range of the return type, [FE_INVALID](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised and an implementation-defined value is returned.
- If `num` is NaN, [FE_INVALID](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised and an implementation-defined value is returned.

### Notes

{/* source:cpp-numeric-math-rint:0013 */}
[POSIX specifies](https://pubs.opengroup.org/onlinepubs/9699919799/functions/lrint.html) that all cases where `std::lrint` or `std::llrint` raise [FE_INEXACT](/docs/cpp/library/numeric/fenv/FE_exceptions) are domain errors.

{/* source:cpp-numeric-math-rint:0014 */}
As specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling), [FE_INEXACT](/docs/cpp/library/numeric/fenv/FE_exceptions) may be (but isn't required to be on non-IEEE floating-point platforms) raised by `std::rint` when rounding a non-integer finite value.

{/* source:cpp-numeric-math-rint:0015 */}
The only difference between `std::rint` and [std::nearbyint](/docs/cpp/library/numeric/math/nearbyint) is that [std::nearbyint](/docs/cpp/library/numeric/math/nearbyint) never raises [FE_INEXACT](/docs/cpp/library/numeric/fenv/FE_exceptions).

{/* source:cpp-numeric-math-rint:0016 */}
The largest representable floating-point values are exact integers in all standard floating-point formats, so `std::rint` never overflows on its own; however the result may overflow any integer type (including [std::intmax_t](/docs/cpp/library/utility/types/integer)), when stored in an integer variable.

{/* source:cpp-numeric-math-rint:0017 */}
If the current rounding mode is:

{/* source:cpp-numeric-math-rint:0018 */}
- [FE_DOWNWARD](/docs/cpp/library/numeric/fenv/FE_round), then `std::rint` is equivalent to [std::floor](/docs/cpp/library/numeric/math/floor).
- [FE_UPWARD](/docs/cpp/library/numeric/fenv/FE_round), then `std::rint` is equivalent to [std::ceil](/docs/cpp/library/numeric/math/ceil).
- [FE_TOWARDZERO](/docs/cpp/library/numeric/fenv/FE_round), then `std::rint` is equivalent to [std::trunc](/docs/cpp/library/numeric/math/trunc).
- [FE_TONEAREST](/docs/cpp/library/numeric/fenv/FE_round), then `std::rint` differs from [std::round](/docs/cpp/library/numeric/math/round) in that halfway cases are rounded to even rather than away from zero.

{/* source:cpp-numeric-math-rint:0019 */}
The additional overloads are not required to be provided exactly as (A-C). They only need to be sufficient to ensure that for their argument `num` of integer type:

{/* source:cpp-numeric-math-rint:0020 */}
- `std::rint(num)` has the same effect as `std::rint(static_cast<double>(num))`.
- `std::lrint(num)` has the same effect as `std::lrint(static_cast<double>(num))`.
- `std::llrint(num)` has the same effect as `std::llrint(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-rint:0021 */}
```cpp
#include <cfenv>
#include <climits>
#include <cmath>
#include <iostream>
// #pragma STDC FENV_ACCESS ON
 
int main()
{
    std::fesetround(FE_TONEAREST);
    std::cout << "Rounding to nearest (halfway cases to even):\n"
              << "  rint(+2.3) = " << std::rint(2.3) << '\n'
              << "  rint(+2.5) = " << std::rint(2.5) << '\n'
              << "  rint(+3.5) = " << std::rint(3.5) << '\n'
              << "  rint(-2.3) = " << std::rint(-2.3) << '\n'
              << "  rint(-2.5) = " << std::rint(-2.5) << '\n'
              << "  rint(-3.5) = " << std::rint(-3.5) << '\n';
 
    std::fesetround(FE_DOWNWARD);
    std::cout << "Rounding down:\n"
              << "  rint(+2.3) = " << std::rint(2.3) << '\n'
              << "  rint(+2.5) = " << std::rint(2.5) << '\n'
              << "  rint(+3.5) = " << std::rint(3.5) << '\n'
              << "  rint(-2.3) = " << std::rint(-2.3) << '\n'
              << "  rint(-2.5) = " << std::rint(-2.5) << '\n'
              << "  rint(-3.5) = " << std::rint(-3.5) << '\n'
              << "Rounding down with lrint:\n"
              << "  lrint(+2.3) = " << std::lrint(2.3) << '\n'
              << "  lrint(+2.5) = " << std::lrint(2.5) << '\n'
              << "  lrint(+3.5) = " << std::lrint(3.5) << '\n'
              << "  lrint(-2.3) = " << std::lrint(-2.3) << '\n'
              << "  lrint(-2.5) = " << std::lrint(-2.5) << '\n'
              << "  lrint(-3.5) = " << std::lrint(-3.5) << '\n'
              << "Special values:\n"
              << "  lrint(-0.0) = " << std::lrint(-0.0) << '\n'
              << std::hex << std::showbase
              << "  lrint(-Inf) = " << std::lrint(-INFINITY) << '\n';
 
    // error handling
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "std::rint(0.1) = " << std::rint(.1) << '\n';
    if (std::fetestexcept(FE_INEXACT))
        std::cout << "  FE_INEXACT was raised\n";
 
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "std::lrint(LONG_MIN-2048.0) = "
              << std::lrint(LONG_MIN - 2048.0) << '\n';
    if (std::fetestexcept(FE_INVALID))
        std::cout << "  FE_INVALID was raised\n";
}
```
