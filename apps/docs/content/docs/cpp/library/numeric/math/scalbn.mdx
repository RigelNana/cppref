### Return value

{/* source:cpp-numeric-math-scalbn:0004 */}
If no errors occur, `num` multiplied by [FLT_RADIX](/docs/cpp/library/utility/types/climits) to the power of `exp` (`num×FLT_RADIXexp`) is returned.

{/* source:cpp-numeric-math-scalbn:0005 */}
If a range error due to overflow occurs, [±HUGE_VAL](/docs/cpp/library/numeric/math/HUGE_VAL), `±HUGE_VALF`, or `±HUGE_VALL` is returned.

{/* source:cpp-numeric-math-scalbn:0006 */}
If a range error due to underflow occurs, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-scalbn:0007 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-scalbn:0008 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-scalbn:0009 */}
- Unless a range error occurs, [FE_INEXACT](/docs/cpp/library/numeric/fenv/FE_exceptions) is never raised (the result is exact).
- Unless a range error occurs, [the current rounding mode](/docs/cpp/library/numeric/fenv/FE_round) is ignored.
- If `num` is ±0, it is returned, unmodified.
- If `num` is ±∞, it is returned, unmodified.
- If `exp` is 0, then `num` is returned, unmodified.
- If `num` is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-scalbn:0010 */}
On binary systems (where [FLT_RADIX](/docs/cpp/library/utility/types/climits) is `2`), `std::scalbn` is equivalent to [std::ldexp](/docs/cpp/library/numeric/math/ldexp).

{/* source:cpp-numeric-math-scalbn:0011 */}
Although `std::scalbn` and `std::scalbln` are specified to perform the operation efficiently, on many implementations they are less efficient than multiplication or division by a power of two using arithmetic operators.

{/* source:cpp-numeric-math-scalbn:0012 */}
The function name stands for "new scalb", where `scalb` was an older non-standard function whose second argument had floating-point type.

{/* source:cpp-numeric-math-scalbn:0013 */}
The `std::scalbln` function is provided because the factor required to scale from the smallest positive floating-point value to the largest finite one may be greater than 32767, the standard-guaranteed [INT_MAX](/docs/cpp/library/utility/types/climits). In particular, for the 80-bit `long double`, the factor is 32828.

{/* source:cpp-numeric-math-scalbn:0014 */}
The GNU implementation does not set `errno` regardless of `math_errhandling`.

{/* source:cpp-numeric-math-scalbn:0015 */}
The additional overloads are not required to be provided exactly as (A,B). They only need to be sufficient to ensure that for their argument `num` of integer type:

{/* source:cpp-numeric-math-scalbn:0016 */}
- `std::scalbn(num, exp)` has the same effect as `std::scalbn(static_cast<double>(num), exp)`.
- `std::scalbln(num, exp)` has the same effect as `std::scalbln(static_cast<double>(num), exp)`.

### Example

{/* source:cpp-numeric-math-scalbn:0017 */}
```cpp
#include <cerrno>
#include <cfenv>
#include <cmath>
#include <cstring>
#include <iostream>
// #pragma STDC FENV_ACCESS ON
 
int main()
{
    std::cout << "scalbn(7, -4) = " << std::scalbn(7, -4) << '\n'
              << "scalbn(1, -1074) = " << std::scalbn(1, -1074)
              << " (minimum positive subnormal double)\n"
              << "scalbn(nextafter(1,0), 1024) = "
              << std::scalbn(std::nextafter(1,0), 1024)
              << " (largest finite double)\n";
 
    // special values
    std::cout << "scalbn(-0, 10) = " << std::scalbn(-0.0, 10) << '\n'
              << "scalbn(-Inf, -1) = " << std::scalbn(-INFINITY, -1) << '\n';
 
    // error handling
    errno = 0;
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "scalbn(1, 1024) = " << std::scalbn(1, 1024) << '\n';
 
    if (errno == ERANGE)
        std::cout << "    errno == ERANGE: " << std::strerror(errno) << '\n';
    if (std::fetestexcept(FE_OVERFLOW))
        std::cout << "    FE_OVERFLOW raised\n";
}
```

Possible output:

```text
scalbn(7, -4) = 0.4375
scalbn(1, -1074) = 4.94066e-324 (minimum positive subnormal double)
scalbn(nextafter(1,0), 1024) = 1.79769e+308 (largest finite double)
scalbn(-0, 10) = -0
scalbn(-Inf, -1) = -inf
scalbn(1, 1024) = inf
    errno == ERANGE: Numerical result out of range
    FE_OVERFLOW raised
```
