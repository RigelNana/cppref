### Return value

{/* source:cpp-numeric-math-erfc:0005 */}
2 √ π

{/* source:cpp-numeric-math-erfc:0006 */}
If a range error occurs due to underflow, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-erfc:0007 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-erfc:0008 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-erfc:0009 */}
- If the argument is +∞, +0 is returned.
- If the argument is -∞, 2 is returned.
- If the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-erfc:0010 */}
For the IEEE-compatible type `double`, underflow is guaranteed if `num > 26.55`.

{/* source:cpp-numeric-math-erfc:0011 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::erfc(num)` has the same effect as `std::erfc(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-erfc:0012 */}
```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
 
double normalCDF(double x) // Phi(-∞, x) aka N(x)
{
    return std::erfc(-x / std::sqrt(2)) / 2;
}
 
int main()
{
    std::cout << "normal cumulative distribution function:\n"
              << std::fixed << std::setprecision(2);
    for (double n = 0; n < 1; n += 0.1)
        std::cout << "normalCDF(" << n << ") = " << 100 * normalCDF(n) << "%\n";
 
    std::cout << "special values:\n"
              << "erfc(-Inf) = " << std::erfc(-INFINITY) << '\n'
              << "erfc(Inf) = " << std::erfc(INFINITY) << '\n';
}
```
