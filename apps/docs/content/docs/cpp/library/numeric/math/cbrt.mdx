### Return value

{/* source:cpp-numeric-math-cbrt:0005 */}
If no errors occur, the cube root of `num` (`3√num`), is returned.

{/* source:cpp-numeric-math-cbrt:0006 */}
If a range error occurs due to underflow, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-cbrt:0007 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-cbrt:0008 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-cbrt:0009 */}
- if the argument is ±0 or ±∞, it is returned, unchanged.
- if the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-cbrt:0010 */}
1 3

{/* source:cpp-numeric-math-cbrt:0011 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::cbrt(num)` has the same effect as `std::cbrt(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-cbrt:0012 */}
```cpp
#include <cmath>
#include <iomanip>
#include <iostream>
#include <limits>
 
int main()
{
    std::cout
        << "Normal use:\n"
        << "cbrt(729)       = " << std::cbrt(729) << '\n'
        << "cbrt(-0.125)    = " << std::cbrt(-0.125) << '\n'
        << "Special values:\n"
        << "cbrt(-0)        = " << std::cbrt(-0.0) << '\n'
        << "cbrt(+inf)      = " << std::cbrt(INFINITY) << '\n'
        << "Accuracy and comparison with `pow`:\n"
        << std::setprecision(std::numeric_limits<double>::max_digits10)
        << "cbrt(343)       = " << std::cbrt(343) << '\n'
        << "pow(343,1.0/3)  = " << std::pow(343, 1.0 / 3) << '\n'
        << "cbrt(-343)      = " << std::cbrt(-343) << '\n'
        << "pow(-343,1.0/3) = " << std::pow(-343, 1.0 / 3) << '\n';
}
```

Possible output:

```text
Normal use:
cbrt(729)       = 9
cbrt(-0.125)    = -0.5
Special values:
cbrt(-0)        = -0
cbrt(+inf)      = inf
Accuracy and comparison with `pow`:
cbrt(343)       = 7
pow(343,1.0/3)  = 6.9999999999999991
cbrt(-343)      = -7
pow(-343,1.0/3) = -nan
```
