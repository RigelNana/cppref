### Parameters

<ParameterList>
  <Parameter name="num">floating-point or integer value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-math-sqrt:0005 */}
If no errors occur, square root of `num` (`√num`), is returned.

{/* source:cpp-numeric-math-sqrt:0006 */}
If a domain error occurs, an implementation-defined value is returned (NaN where supported).

{/* source:cpp-numeric-math-sqrt:0007 */}
If a range error occurs due to underflow, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-sqrt:0008 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-sqrt:0009 */}
Domain error occurs if `num` is less than zero.

{/* source:cpp-numeric-math-sqrt:0010 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-sqrt:0011 */}
- If the argument is less than -0, [FE_INVALID](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised and NaN is returned.
- If the argument is +∞ or ±0, it is returned, unmodified.
- If the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-sqrt:0012 */}
`std::sqrt` is required by the IEEE standard to be correctly rounded from the infinitely precise result. In particular, the exact result is produced if it can be represented in the floating-point type. The only other operations which require this are the [arithmetic operators](/docs/cpp/language/expressions/operator_arithmetic) and the function [std::fma](/docs/cpp/library/numeric/math/fma). Other functions, including [std::pow](/docs/cpp/library/numeric/math/pow), are not so constrained.

{/* source:cpp-numeric-math-sqrt:0013 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::sqrt(num)` has the same effect as `std::sqrt(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-sqrt:0014 */}
```cpp
#include <cerrno>
#include <cfenv>
#include <cmath>
#include <cstring>
#include <iostream>
// #pragma STDC FENV_ACCESS ON
 
int main()
{
    // normal use
    std::cout << "sqrt(100) = " << std::sqrt(100) << '\n'
              << "sqrt(2) = " << std::sqrt(2) << '\n'
              << "golden ratio = " << (1 + std::sqrt(5)) / 2 << '\n';
 
    // special values
    std::cout << "sqrt(-0) = " << std::sqrt(-0.0) << '\n';
 
    // error handling
    errno = 0;
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "sqrt(-1.0) = " << std::sqrt(-1) << '\n';
    if (errno == EDOM)
        std::cout << "    errno = EDOM " << std::strerror(errno) << '\n';
    if (std::fetestexcept(FE_INVALID))
        std::cout << "    FE_INVALID raised\n";
}
```

Possible output:

```text
sqrt(100) = 10
sqrt(2) = 1.41421
golden ratio = 1.61803
sqrt(-0) = -0
sqrt(-1.0) = -nan
    errno = EDOM Numerical argument out of domain
    FE_INVALID raised
```
