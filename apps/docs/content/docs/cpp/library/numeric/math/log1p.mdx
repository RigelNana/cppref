### Return value

{/* source:cpp-numeric-math-log1p:0005 */}
If no errors occur `ln(1+num)` is returned.

{/* source:cpp-numeric-math-log1p:0006 */}
If a domain error occurs, an implementation-defined value is returned (NaN where supported).

{/* source:cpp-numeric-math-log1p:0007 */}
If a pole error occurs, [-HUGE_VAL](/docs/cpp/library/numeric/math/HUGE_VAL), `-HUGE_VALF`, or `-HUGE_VALL` is returned.

{/* source:cpp-numeric-math-log1p:0008 */}
If a range error occurs due to underflow, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-log1p:0009 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-log1p:0010 */}
Domain error occurs if `num` is less than `-1`.

{/* source:cpp-numeric-math-log1p:0011 */}
Pole error may occur if `num` is `-1`.

{/* source:cpp-numeric-math-log1p:0012 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-log1p:0013 */}
- If the argument is ±0, it is returned unmodified.
- If the argument is -1, -∞ is returned and [FE_DIVBYZERO](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised.
- If the argument is less than -1, NaN is returned and [FE_INVALID](/docs/cpp/library/numeric/fenv/FE_exceptions) is raised.
- If the argument is +∞, +∞ is returned.
- If the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-log1p:0014 */}
The functions [std::expm1](/docs/cpp/library/numeric/math/expm1) and `std::log1p` are useful for financial calculations, for example, when calculating small daily interest rates: `(1 + x)n - 1` can be expressed as `std::expm1(n * std::log1p(x))`. These functions also simplify writing accurate inverse hyperbolic functions.

{/* source:cpp-numeric-math-log1p:0015 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::log1p(num)` has the same effect as `std::log1p(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-log1p:0016 */}
```cpp
#include <cerrno>
#include <cfenv>
#include <cmath>
#include <cstring>
#include <iostream>
// #pragma STDC FENV_ACCESS ON
 
int main()
{
    std::cout << "log1p(0) = " << log1p(0) << '\n'
              << "Interest earned in 2 days on $100, compounded daily at 1%\n"
              << "    on a 30/360 calendar = "
              << 100 * expm1(2 * log1p(0.01 / 360)) << '\n'
              << "log(1+1e-16) = " << std::log(1 + 1e-16)
              << ", but log1p(1e-16) = " << std::log1p(1e-16) << '\n';
 
    // special values
    std::cout << "log1p(-0) = " << std::log1p(-0.0) << '\n'
              << "log1p(+Inf) = " << std::log1p(INFINITY) << '\n';
 
    // error handling
    errno = 0;
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "log1p(-1) = " << std::log1p(-1) << '\n';
 
    if (errno == ERANGE)
        std::cout << "    errno == ERANGE: " << std::strerror(errno) << '\n';
    if (std::fetestexcept(FE_DIVBYZERO))
        std::cout << "    FE_DIVBYZERO raised\n";
}
```

Possible output:

```text
log1p(0) = 0
Interest earned in 2 days on $100, compounded daily at 1%
    on a 30/360 calendar = 0.00555563
log(1+1e-16) = 0, but log1p(1e-16) = 1e-16
log1p(-0) = -0
log1p(+Inf) = inf
log1p(-1) = -inf
    errno == ERANGE: Result too large
    FE_DIVBYZERO raised
```
