{/* source:cpp-numeric-math-fabs:0002 */}
<Revision since="C++11">
A) Additional overloads are provided for all integer types, which are treated as `double`.
</Revision>

{/* source:cpp-numeric-math-fabs:0003 */}
For integral arguments, [the integral overloads of `std::abs`](/docs/cpp/library/numeric/math/abs) are likely better matches. If `std::abs` is called with an unsigned integral argument that cannot be converted to `int` by [integral promotion](/docs/cpp/language/expressions/implicit_cast#Integral_promotion), the program is ill-formed.

<ParameterList>
  <Parameter name="num">floating-point or integer value</Parameter>

### Return value

{/* source:cpp-numeric-math-fabs:0005 */}
If successful, returns the absolute value of `arg` (`|arg|`). The value returned is exact and does not depend on any rounding modes.

### Error handling

{/* source:cpp-numeric-math-fabs:0006 */}
This function is not subject to any of the error conditions specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-fabs:0007 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-fabs:0008 */}
- If the argument is ±0, +0 is returned.
- If the argument is ±∞, +∞ is returned.
- If the argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-fabs:0009 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::fabs(num)` has the same effect as `std::fabs(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-fabs:0010 */}
```cpp
#include <cmath>
#include <iostream>
 
int main()
{
    std::cout << "abs(+3.0) = " << std::abs(+3.0) << '\n'
              << "abs(-3.0) = " << std::abs(-3.0) << '\n';
 
    // special values
    std::cout << "abs(-0.0) = " << std::abs(-0.0) << '\n'
              << "abs(-Inf) = " << std::abs(-INFINITY) << '\n'
              << "abs(-NaN) = " << std::abs(-NAN) << '\n';
}
```

Possible output:

```text
abs(+3.0) = 3
abs(-3.0) = 3
abs(-0.0) = 0
abs(-Inf) = inf
abs(-NaN) = nan
```
