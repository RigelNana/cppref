### Parameters

{/* source:cpp-numeric-math-trunc:0004 */}
<ParameterList>
  <Parameter name="num">floating-point or integer value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-math-trunc:0005 */}
If no errors occur, the nearest integer value not greater in magnitude than `num` (in other words, `num` rounded towards zero) is returned.

{/* source:cpp-numeric-math-trunc:0006 */}
Return value · `num`

### Error handling

{/* source:cpp-numeric-math-trunc:0007 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-trunc:0008 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-trunc:0009 */}
- The current [rounding mode](/docs/cpp/library/numeric/fenv/FE_round) has no effect.
- If `num` is ±∞, it is returned, unmodified.
- If `num` is ±0, it is returned, unmodified.
- If `num` is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-trunc:0010 */}
[FE_INEXACT](/docs/cpp/library/numeric/fenv/FE_exceptions) may be (but isn't required to be) raised when truncating a non-integer finite value.

{/* source:cpp-numeric-math-trunc:0011 */}
The largest representable floating-point values are exact integers in all standard floating-point formats, so this function never overflows on its own; however the result may overflow any integer type (including [std::intmax_t](/docs/cpp/library/utility/types/integer)), when stored in an integer variable.

{/* source:cpp-numeric-math-trunc:0012 */}
The [implicit conversion](/docs/cpp/language/expressions/implicit_cast) from floating-point to integral types also rounds towards zero, but is limited to the values that can be represented by the target type.

{/* source:cpp-numeric-math-trunc:0013 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::trunc(num)` has the same effect as `std::trunc(static_cast<double>(num))`.

### Example

{/* source:cpp-numeric-math-trunc:0014 */}
```cpp
#include <cmath>
#include <initializer_list>
#include <iostream>
 
int main()
{
    const auto data = std::initializer_list<double>
    {
        +2.7, -2.9, +0.7, -0.9, +0.0, 0.0, -INFINITY, +INFINITY, -NAN, +NAN
    };
 
    std::cout << std::showpos;
    for (double const x : data)
        std::cout << "trunc(" << x << ") == " << std::trunc(x) << '\n';
}
```

Possible output:

```text
trunc(+2.7) == +2
trunc(-2.9) == -2
trunc(+0.7) == +0
trunc(-0.9) == -0
trunc(+0) == +0
trunc(+0) == +0
trunc(-inf) == -inf
trunc(+inf) == +inf
trunc(-nan) == -nan
trunc(+nan) == +nan
```
