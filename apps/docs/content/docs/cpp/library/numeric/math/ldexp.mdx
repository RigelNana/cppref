### Return value

{/* source:cpp-numeric-math-ldexp:0004 */}
If no errors occur, `num` multiplied by 2 to the power of `exp` (`num×2exp`) is returned.

{/* source:cpp-numeric-math-ldexp:0005 */}
If a range error due to overflow occurs, [±HUGE_VAL](/docs/cpp/library/numeric/math/HUGE_VAL), `±HUGE_VALF`, or `±HUGE_VALL` is returned.

{/* source:cpp-numeric-math-ldexp:0006 */}
If a range error due to underflow occurs, the correct result (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-ldexp:0007 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-ldexp:0008 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-ldexp:0009 */}
- Unless a range error occurs, [FE_INEXACT](/docs/cpp/library/numeric/fenv/FE_exceptions) is never raised (the result is exact).
- Unless a range error occurs, [the current rounding mode](/docs/cpp/library/numeric/fenv/FE_round) is ignored.
- If `num` is ±0, it is returned, unmodified.
- If `num` is ±∞, it is returned, unmodified.
- If `exp` is 0, then `num` is returned, unmodified.
- If `num` is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-ldexp:0010 */}
On binary systems (where [FLT_RADIX](/docs/cpp/library/utility/types/climits) is `2`), `std::ldexp` is equivalent to [std::scalbn](/docs/cpp/library/numeric/math/scalbn).

{/* source:cpp-numeric-math-ldexp:0011 */}
The function `std::ldexp` ("load exponent"), together with its dual, [std::frexp](/docs/cpp/library/numeric/math/frexp), can be used to manipulate the representation of a floating-point number without direct bit manipulations.

{/* source:cpp-numeric-math-ldexp:0012 */}
On many implementations, `std::ldexp` is less efficient than multiplication or division by a power of two using arithmetic operators.

{/* source:cpp-numeric-math-ldexp:0013 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their argument `num` of integer type, `std::ldexp(num, exp)` has the same effect as `std::ldexp(static_cast<double>(num), exp)`.

{/* source:cpp-numeric-math-ldexp:0014 */}
For exponentiation of 2 by a floating point exponent, [std::exp2](/docs/cpp/library/numeric/math/exp2) can be used.

### Example

{/* source:cpp-numeric-math-ldexp:0015 */}
```cpp
#include <cerrno>
#include <cfenv>
#include <cmath>
#include <cstring>
#include <iostream>
// #pragma STDC FENV_ACCESS ON
 
int main()
{
    std::cout
        << "ldexp(5, 3) = 5 * 8 = " << std::ldexp(5, 3) << '\n'
        << "ldexp(7, -4) = 7 / 16 = " << std::ldexp(7, -4) << '\n'
        << "ldexp(1, -1074) = " << std::ldexp(1, -1074)
        << " (minimum positive subnormal float64_t)\n"
        << "ldexp(nextafter(1,0), 1024) = "
        << std::ldexp(std::nextafter(1,0), 1024)
        << " (largest finite float64_t)\n";
 
    // special values
    std::cout << "ldexp(-0, 10) = " << std::ldexp(-0.0, 10) << '\n'
              << "ldexp(-Inf, -1) = " << std::ldexp(-INFINITY, -1) << '\n';
 
    // error handling
    std::feclearexcept(FE_ALL_EXCEPT);
    errno = 0;
    const double inf = std::ldexp(1, 1024);
    const bool is_range_error = errno == ERANGE;
 
    std::cout << "ldexp(1, 1024) = " << inf << '\n';
    if (is_range_error)
        std::cout << "    errno == ERANGE: " << std::strerror(ERANGE) << '\n';
    if (std::fetestexcept(FE_OVERFLOW))
        std::cout << "    FE_OVERFLOW raised\n";
}
```

Possible output:

```text
ldexp(5, 3) = 5 * 8 = 40
ldexp(7, -4) = 7 / 16 = 0.4375
ldexp(1, -1074) = 4.94066e-324 (minimum positive subnormal float64_t)
ldexp(nextafter(1,0), 1024) = 1.79769e+308 (largest finite float64_t)
ldexp(-0, 10) = -0
ldexp(-Inf, -1) = -inf
ldexp(1, 1024) = inf
    errno == ERANGE: Numerical result out of range
    FE_OVERFLOW raised
```
