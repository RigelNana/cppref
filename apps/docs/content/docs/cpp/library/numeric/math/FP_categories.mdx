{/* source:cpp-numeric-math-fp-categories:0001 */}
The `FP_NORMAL`, `FP_SUBNORMAL`, `FP_ZERO`, `FP_INFINITE`, `FP_NAN` macros each represent a distinct category of floating-point numbers. They all expand to an integer constant expression.

{/* source:cpp-numeric-math-fp-categories:0002 */}
Constant
 Explanation

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`FP_NORMAL`</DescriptionTerm>
    <DescriptionBody>indicates that the value is *normal*, i.e. not an infinity, subnormal, not-a-number or zero</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`FP_SUBNORMAL`</DescriptionTerm>
    <DescriptionBody>indicates that the value is *subnormal*</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`FP_ZERO`</DescriptionTerm>
    <DescriptionBody>indicates that the value is positive or negative zero</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`FP_INFINITE`</DescriptionTerm>
    <DescriptionBody>indicates that the value is not representable by the underlying type (positive or negative infinity)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`FP_NAN`</DescriptionTerm>
    <DescriptionBody>indicates that the value is not-a-number (NaN)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Example

{/* source:cpp-numeric-math-fp-categories:0003 */}
```cpp
#include <cfloat>
#include <cmath>
#include <iostream>
 
auto show_classification(double x)
{
    switch (std::fpclassify(x))
    {
        case FP_INFINITE:
            return "Inf";
        case FP_NAN:
            return "NaN";
        case FP_NORMAL:
            return "normal";
        case FP_SUBNORMAL:
            return "subnormal";
        case FP_ZERO:
            return "zero";
        default:
            return "unknown";
    }
}
 
int main()
{
    std::cout << "1.0/0.0 is " << show_classification(1 / 0.0) << '\n'
              << "0.0/0.0 is " << show_classification(0.0 / 0.0) << '\n'
              << "DBL_MIN/2 is " << show_classification(DBL_MIN / 2) << '\n'
              << "-0.0 is " << show_classification(-0.0) << '\n'
              << "1.0 is " << show_classification(1.0) << '\n';
}
```

Output:

```text
1.0/0.0 is Inf
0.0/0.0 is NaN
DBL_MIN/2 is subnormal
-0.0 is zero
1.0 is normal
```
