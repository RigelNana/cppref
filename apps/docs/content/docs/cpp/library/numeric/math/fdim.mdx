### Return value

{/* source:cpp-numeric-math-fdim:0005 */}
If successful, returns the positive difference between `x` and `y`.

{/* source:cpp-numeric-math-fdim:0006 */}
If a range error due to overflow occurs, [+HUGE_VAL](/docs/cpp/library/numeric/math/HUGE_VAL), `+HUGE_VALF`, or `+HUGE_VALL` is returned.

{/* source:cpp-numeric-math-fdim:0007 */}
If a range error due to underflow occurs, the correct value (after rounding) is returned.

### Error handling

{/* source:cpp-numeric-math-fdim:0008 */}
Errors are reported as specified in [math_errhandling](/docs/cpp/library/numeric/math/math_errhandling).

{/* source:cpp-numeric-math-fdim:0009 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559),

{/* source:cpp-numeric-math-fdim:0010 */}
- If either argument is NaN, NaN is returned.

### Notes

{/* source:cpp-numeric-math-fdim:0011 */}
Equivalent to `std::fmax(x - y, 0)`, except for the NaN handling requirements.

{/* source:cpp-numeric-math-fdim:0012 */}
The additional overloads are not required to be provided exactly as (A). They only need to be sufficient to ensure that for their first argument `num1` and second argument `num2`:

{/* source:cpp-numeric-math-fdim:0013 */}
<Revision until="C++23">
If `num1` or `num2` has type `long double`, then `std::fdim(num1, num2)` has the same effect as `std::fdim(static_cast<long double>(num1), static_cast<long double>(num2))`. Otherwise, if `num1` and/or `num2` has type `double` or an integer type, then `std::fdim(num1, num2)` has the same effect as `std::fdim(static_cast<double>(num1), static_cast<double>(num2))`. Otherwise, if `num1` or `num2` has type `float`, then `std::fdim(num1, num2)` has the same effect as `std::fdim(static_cast<float>(num1), static_cast<float>(num2))`.
</Revision>
<Revision since="C++23">
If `num1` and `num2` have arithmetic types, then `std::fdim(num1, num2)` has the same effect as `std::fdim(static_cast</*common-floating-point-type*/>(num1), static_cast</*common-floating-point-type*/>(num2))`, where `/*common-floating-point-type*/` is the floating-point type with the greatest [floating-point conversion rank](/docs/cpp/language/expressions/usual_arithmetic_conversions#Floating-point_conversion_rank) and greatest [floating-point conversion subrank](/docs/cpp/language/expressions/usual_arithmetic_conversions#Floating-point_conversion_subrank) between the types of `num1` and `num2`, arguments of integer type are considered to have the same floating-point conversion rank as `double`.
If no such floating-point type with the greatest rank and subrank exists, then [overload resolution](/docs/cpp/language/functions/overload_resolution) does not result in a usable candidate from the overloads provided.
</Revision>

### Example

{/* source:cpp-numeric-math-fdim:0014 */}
```cpp
#include <cerrno>
#include <cfenv>
#include <cmath>
#include <cstring>
#include <iostream>
 
#ifndef __GNUC__
#pragma STDC FENV_ACCESS ON
#endif
 
int main()
{
    std::cout << "fdim(4, 1) = " << std::fdim(4, 1) << '\n'
              << "fdim(1, 4) = " << std::fdim(1, 4) << '\n'
              << "fdim(4,-1) = " << std::fdim(4, -1) << '\n'
              << "fdim(1,-4) = " << std::fdim(1, -4) << '\n';
 
    // error handling 
    errno = 0;
    std::feclearexcept(FE_ALL_EXCEPT);
 
    std::cout << "fdim(1e308, -1e308) = " << std::fdim(1e308, -1e308) << '\n';
 
    if (errno == ERANGE)
        std::cout << "    errno == ERANGE: " << std::strerror(errno) << '\n';
    if (std::fetestexcept(FE_OVERFLOW))
        std::cout << "    FE_OVERFLOW raised\n";
}
```

Output:

```text
fdim(4, 1) = 3
fdim(1, 4) = 0
fdim(4,-1) = 5
fdim(1,-4) = 5
fdim(1e308, -1e308) = inf
    errno == ERANGE: Numerical result out of range
    FE_OVERFLOW raised
```
