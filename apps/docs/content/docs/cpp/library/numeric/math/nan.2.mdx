{/* source:cpp-numeric-math-nan-2:0001 */}
Converts the character string `arg` into the corresponding quiet NaN value, as if by calling [std::strtof](/docs/cpp/library/text/byte/strtof), [std::strtod](/docs/cpp/library/text/byte/strtof), or [std::strtold](/docs/cpp/library/text/byte/strtof), respectively.

{/* source:cpp-numeric-math-nan-2:0002 */}
1) The call `std::nanf("n-char-sequence")`, where *n-char-sequence* is a sequence of digits, ASCII letters, and underscores, is equivalent to the call `std::strtof("NAN(n-char-sequence)", (char**)nullptr);`.

{/* source:cpp-numeric-math-nan-2:0003 */}
The call `std::nanf("")` is equivalent to the call `std::strtof("NAN()", (char**)nullptr);`.

{/* source:cpp-numeric-math-nan-2:0004 */}
The call `std::nanf("string")`, where *string* is neither an *n-char-sequence* nor an empty string, is equivalent to the call `std::strtof("NAN", (char**)nullptr);`.

{/* source:cpp-numeric-math-nan-2:0005 */}
2) Same as (1), but calls [std::strtod](/docs/cpp/library/text/byte/strtof) instead of [std::strtof](/docs/cpp/library/text/byte/strtof).

{/* source:cpp-numeric-math-nan-2:0006 */}
3) Same as (1), but calls [std::strtold](/docs/cpp/library/text/byte/strtof) instead of [std::strtof](/docs/cpp/library/text/byte/strtof).

### Parameters

{/* source:cpp-numeric-math-nan-2:0007 */}
<ParameterList>
  <Parameter name="arg">narrow character string identifying the contents of a NaN</Parameter>
</ParameterList>

### Return value

{/* source:cpp-numeric-math-nan-2:0008 */}
The quiet NaN value that corresponds to the identifying string `arg` or zero if the implementation does not support quiet NaNs.

{/* source:cpp-numeric-math-nan-2:0009 */}
If the implementation supports IEEE floating-point arithmetic (IEC 60559), it also supports quiet NaNs.

### Error handling

{/* source:cpp-numeric-math-nan-2:0010 */}
This function is not subject to any of the error conditions specified in [`math_errhandling`](/docs/cpp/library/numeric/math/math_errhandling).

### Example

{/* source:cpp-numeric-math-nan-2:0011 */}
```cpp
#include <cmath>
#include <cstdint>
#include <cstring>
#include <iostream>
 
int main()
{
    double f1 = std::nan("1");
    std::uint64_t f1n; std::memcpy(&f1n, &f1, sizeof f1);
    std::cout << "nan(\"1\") = " << f1 << " (" << std::hex << f1n << ")\n";
 
    double f2 = std::nan("2");
    std::uint64_t f2n; std::memcpy(&f2n, &f2, sizeof f2);
    std::cout << "nan(\"2\") = " << f2 << " (" << std::hex << f2n << ")\n";
}
```

Possible output:

```text
nan("1") = nan (7ff0000000000001)
nan("2") = nan (7ff0000000000002)
```
