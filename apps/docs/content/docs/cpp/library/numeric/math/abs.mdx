{/* source:cpp-numeric-math-abs:0001 */}
Computes the absolute value of the integer number `num`. The behavior is undefined if the result cannot be represented by the return type.

{/* source:cpp-numeric-math-abs:0002 */}
If `std::abs` is called with an unsigned integral argument that cannot be converted to `int` by [integral promotion](/docs/cpp/language/expressions/implicit_cast#Integral_promotion), the program is ill-formed.

{/* source:cpp-numeric-math-abs:0003 */}
<Revision since="C++11">
Overload (6) of `std::abs` for [std::intmax_t](/docs/cpp/library/utility/types/integer) is provided in [`<cinttypes>`](/docs/cpp/library/headers/cinttypes) if and only if [std::intmax_t](/docs/cpp/library/utility/types/integer) is an [extended integer type](/docs/cpp/language/basic_concepts/types#Extended_integer_types).
</Revision>

### Return value

{/* source:cpp-numeric-math-abs:0005 */}
The absolute value of `num` (i.e. `|num|`), if it is representable.

### Notes

{/* source:cpp-numeric-math-abs:0006 */}
In [2's complement](/docs/cpp/language/basic_concepts/types#Range_of_values) systems, the absolute value of the most-negative value is out of range, e.g. for 32-bit 2's complement type `int`, [INT_MIN](/docs/cpp/library/utility/types/climits) is `-2147483648`, but the would-be result `2147483648` is greater than [INT_MAX](/docs/cpp/library/utility/types/climits), which is `2147483647`.

### Example

{/* source:cpp-numeric-math-abs:0007 */}
```cpp
#include <climits>
#include <cstdlib>
#include <iostream>
 
int main()
{
    std::cout << std::showpos
              << "abs(+3) = " << std::abs(3) << '\n'
              << "abs(-3) = " << std::abs(-3) << '\n';
 
//  std::cout << std::abs(INT_MIN); // undefined behavior on 2's complement systems
}
```

Output:

```text
abs(+3) = +3
abs(-3) = +3
```
