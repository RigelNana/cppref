### Characters

{/* source:cpp-string:0000 */}
In the C++ standard library, a *character* is an object which, when treated sequentially, can represent text.

{/* source:cpp-string:0001 */}
The term means not only objects of [character types](/docs/cpp/language/basic_concepts/type-id), but also any value that can be represented by a type that provides the definitions specified in the strings library and following libraries:

{/* source:cpp-string:0002 */}
- [localization library](/docs/cpp/library/text/locale)
- [input/output library](/docs/cpp/library/io)

{/* source:cpp-string:0003 */}
<Revision since="C++11">
- [regular expressions library](/docs/cpp/library/text/regex)
</Revision>

{/* source:cpp-string:0004 */}
In the strings library <InlineRevision since="C++11">and regular expressions library</InlineRevision>, a character can be of only *char-like types*, i.e. those non-array types that satisfy the requirements of [PODType](/docs/cpp/library/named_req/PODType) <InlineRevision until="C++20" />, [TrivialType](/docs/cpp/library/named_req/TrivialType) and [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType) <InlineRevision since="C++20" until="C++26" />, [TriviallyCopyable](/docs/cpp/library/named_req/TriviallyCopyable) and [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType) <InlineRevision since="C++26" />.

{/* source:cpp-string:0005 */}
<Revision since="C++26">
For any char-like type `T`, `std::is_trivially_default_constructible_v<T>` is `true`.
</Revision>

{/* source:cpp-string:0006 */}
Therefore, characters are also referred as *char-like objects* in the strings library <InlineRevision since="C++11">and regular expressions library</InlineRevision>.

{/* source:cpp-string:0007 */}
Some standard library components accept *character container types*. They, too, are types used to represent individual characters. Such types are used for one of the template arguments of [`std::char_traits`](/docs/cpp/library/string/char_traits) and the class templates which use [`std::char_traits`](/docs/cpp/library/string/char_traits).

### Library components

{/* source:cpp-string:0008 */}
The C++ strings library includes the following components:

#### Character traits

{/* source:cpp-string:0009 */}
Many character-related class templates (such as [`std::basic_string`](/docs/cpp/library/string/basic_string)) need a set of related types and functions to complete the definition of their semantics. These types and functions are provided as a set of member `typedef` names and functions in the template parameter `Traits` used by each such template. The classes which are able to complete those semantics are [CharTraits](/docs/cpp/library/named_req/CharTraits).

{/* source:cpp-string:0010 */}
The string library provides the class template [`std::char_traits`](/docs/cpp/library/string/char_traits) that defines types and functions for [`std::basic_string`](/docs/cpp/library/string/basic_string) <InlineRevision since="C++17">and [`std::basic_string_view`](/docs/cpp/library/string/basic_string_view)</InlineRevision>.

{/* source:cpp-string:0011 */}
The following specializations are defined, all of them satisfy the [CharTraits](/docs/cpp/library/named_req/CharTraits) requirements:

{/* source:cpp-string:0012 */}
Defined in header [`<string>`](/docs/cpp/library/headers/string)

{/* source:cpp-string:0013 */}
When a user-defined character container type for [`std::basic_string`](/docs/cpp/library/string/basic_string) <InlineRevision since="C++17">and [`std::basic_string_view`](/docs/cpp/library/string/basic_string_view)</InlineRevision> is used, it is also necessary to provide a corresponding character trait class (which can be a specialization of [`std::char_traits`](/docs/cpp/library/string/char_traits)).

#### String classes (`std::string` etc.)

{/* source:cpp-string:0014 */}
The class template [`std::basic_string`](/docs/cpp/library/string/basic_string) generalizes how sequences of characters are manipulated and stored. String creation, manipulation, and destruction are all handled by a convenient set of class methods and related functions.

### Relevant libraries

{/* source:cpp-string:0020 */}
The [text processing library](/docs/cpp/library/text) provides support for localizations, string conversions (e.g. [`std::toupper`](/docs/cpp/library/text/locale/toupper)), character classification functions (e.g. [`std::isspace`](/docs/cpp/library/text/locale/isspace)), and text encoding recognition ([`std::text_encoding`](/docs/cpp/library/text/text_encoding)).
