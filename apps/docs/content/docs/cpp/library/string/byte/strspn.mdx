{/* source:cpp-string-byte-strspn:0001 */}
Returns the length of the maximum initial segment (span) of the byte string pointed to by `dest`, that consists of only the characters found in byte string pointed to by `src`.

### Parameters

{/* source:cpp-string-byte-strspn:0002 */}
<ParameterList>
  <Parameter name="dest">pointer to the null-terminated byte string to be analyzed</Parameter>
  <Parameter name="src">pointer to the null-terminated byte string that contains the characters to search for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-strspn:0003 */}
The length of the maximum initial segment that contains only characters from byte string pointed to by `src`.

### Example

{/* source:cpp-string-byte-strspn:0004 */}
```cpp
#include <cstring>
#include <iostream>
#include <string>
 
const char* low_alpha = "qwertyuiopasdfghjklzxcvbnm";
 
int main()
{
    std::string s = "abcde312$#@";
 
    std::size_t spnsz = std::strspn(s.c_str(), low_alpha);
    std::cout << "After skipping initial lowercase letters from '" << s
              << "'\nThe remainder is '" << s.substr(spnsz) << "'\n";
}
```
Output:
```text
After skipping initial lowercase letters from 'abcde312$#@'
The remainder is '312$#@'
```
