{/* source:cpp-string-byte-isblank:0001 */}
Checks if the given character is a blank character as classified by the currently installed C locale. Blank characters are whitespace characters used to separate words within a sentence. In the default C locale, only space (`0x20`) and horizontal tab (`0x09`) are classified as blank characters.

{/* source:cpp-string-byte-isblank:0002 */}
The behavior is undefined if the value of `ch` is not representable as `unsigned char` and is not equal to [`EOF`](/docs/cpp/library/io/c).

### Parameters

{/* source:cpp-string-byte-isblank:0003 */}
<ParameterList>
  <Parameter name="ch">character to classify</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-isblank:0004 */}
Non-zero value if the character is a blank character, zero otherwise.

### Notes

{/* source:cpp-string-byte-isblank:0005 */}
Like all other functions from [`<cctype>`](/docs/cpp/library/headers/cctype), the behavior of `std::isblank` is undefined if the argument's value is neither representable as `unsigned char` nor equal to [`EOF`](/docs/cpp/library/io/c). To use these functions safely with plain `chars` (or `signed chars`), the argument should first be converted to `unsigned char`:

{/* source:cpp-string-byte-isblank:0006 */}
```cpp
bool my_isblank(char ch)
{
    return std::isblank(static_cast<unsigned char>(ch));
}
```

{/* source:cpp-string-byte-isblank:0007 */}
Similarly, they should not be directly used with standard algorithms when the iterator's value type is `char` or `signed char`. Instead, convert the value to `unsigned char` first:

{/* source:cpp-string-byte-isblank:0008 */}
```cpp
int count_blanks(const std::string& s)
{
    return std::count_if(s.begin(), s.end(),
                      // static_cast<int(*)(int)>(std::isblank)         // wrong
                      // [](int c){ return std::isblank(c); }           // wrong
                      // [](char c){ return std::isblank(c); }          // wrong
                         [](unsigned char c){ return std::isblank(c); } // correct
                        );
}
```
