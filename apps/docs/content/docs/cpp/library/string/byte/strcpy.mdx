{/* source:cpp-string-byte-strcpy:0001 */}
Copies the character string pointed to by `src`, including the null terminator, to the character array whose first element is pointed to by `dest`.

{/* source:cpp-string-byte-strcpy:0002 */}
The behavior is undefined if the `dest` array is not large enough. The behavior is undefined if the strings overlap.

### Parameters

{/* source:cpp-string-byte-strcpy:0003 */}
<ParameterList>
  <Parameter name="dest">pointer to the character array to write to</Parameter>
  <Parameter name="src">pointer to the null-terminated byte string to copy from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-strcpy:0004 */}
`dest`

### Example

{/* source:cpp-string-byte-strcpy:0005 */}
```cpp
#include <cstring>
#include <iostream>
#include <memory>
 
int main()
{
    const char* src = "Take the test.";
//  src[0] = 'M'; // can't modify string literal
    auto dst = std::make_unique<char[]>(std::strlen(src) + 1); // +1 for null terminator
    std::strcpy(dst.get(), src);
    dst[0] = 'M';
    std::cout << src << '\n' << dst.get() << '\n';
}
```
Output:
```text
Take the test.
Make the test.
```
