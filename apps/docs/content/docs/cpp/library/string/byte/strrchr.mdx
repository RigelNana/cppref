{/* source:cpp-string-byte-strrchr:0001 */}
Finds the last occurrence of `ch` (after conversion to `char`) in the byte string pointed to by `str`. The terminating null character is considered to be a part of the string and can be found if searching for `'\0'`.

### Parameters

{/* source:cpp-string-byte-strrchr:0002 */}
<ParameterList>
  <Parameter name="str">pointer to the null-terminated byte string to be analyzed</Parameter>
  <Parameter name="ch">character to search for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-strrchr:0003 */}
Pointer to the found character in `str`, or null pointer if no such character is found.

### Example

{/* source:cpp-string-byte-strrchr:0004 */}
```cpp
#include <cstring>
#include <iostream>
 
int main()
{
    char input[] = "/home/user/hello.c";
    char* output = std::strrchr(input, '/');
    if (output)
        std::cout << output + 1 << '\n';
}
```
Output:
```text
hello.c
```
