<DeclarationDoc>
Defined in header [`<cstring>`](/docs/cpp/library/headers/cstring)
  <Declaration language="cpp" code={`void* memcpy( void* dest, const void* src, std::size_t count );`} />
</DeclarationDoc>

{/* source:cpp-string-byte-memcpy:0001 */}
Copies `count` bytes from the object pointed to by `src` to the object pointed to by `dest`. Both objects are reinterpreted as arrays of `unsigned char`.

{/* source:cpp-string-byte-memcpy:0002 */}
If the objects overlap, the behavior is undefined.

{/* source:cpp-string-byte-memcpy:0003 */}
If either `dest` or `src` is an [invalid or null pointer](/docs/cpp/language/declarations/pointer#Pointers), the behavior is undefined, even if `count` is zero.

{/* source:cpp-string-byte-memcpy:0004 */}
If the objects are [potentially-overlapping](/docs/cpp/language/basic_concepts/objects#Subobjects) or not [`TriviallyCopyable`](/docs/cpp/library/named_req/TriviallyCopyable), the behavior of `memcpy` is not specified and [may be undefined](https://stackoverflow.com/questions/29777492).

### Parameters

{/* source:cpp-string-byte-memcpy:0005 */}
<ParameterList>
  <Parameter name="dest">pointer to the memory location to copy to</Parameter>
  <Parameter name="src">pointer to the memory location to copy from</Parameter>
  <Parameter name="count">number of bytes to copy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-memcpy:0006 */}
`dest`

### Notes

{/* source:cpp-string-byte-memcpy:0007 */}
`std::memcpy` may be used to [implicitly create](/docs/cpp/language/basic_concepts/objects#Object_creation) objects in the destination buffer.

{/* source:cpp-string-byte-memcpy:0008 */}
`std::memcpy` is meant to be the fastest library routine for memory-to-memory copy. It is usually more efficient than [`std::strcpy`](/docs/cpp/library/text/byte/strcpy), which must scan the data it copies or [`std::memmove`](/docs/cpp/library/text/byte/memmove), which must take precautions to handle overlapping inputs.

{/* source:cpp-string-byte-memcpy:0009 */}
Several C++ compilers transform suitable memory-copying loops to `std::memcpy` calls.

{/* source:cpp-string-byte-memcpy:0010 */}
Where [strict aliasing](/docs/cpp/language/basic_concepts/objects#Strict_aliasing) prohibits examining the same memory as values of two different types, `std::memcpy` may be used to convert the values.

### Example

{/* source:cpp-string-byte-memcpy:0011 */}
```cpp
#include <cstdint>
#include <cstring>
#include <iostream>
 
int main()
{
    // simple usage
    char source[] = "once upon a daydream...", dest[4];
    std::memcpy(dest, source, sizeof dest);
    std::cout << "dest[4] = {";
    for (int n{}; char c : dest)
        std::cout << (n++ ? ", " : "") << '\'' << c << "'";
    std::cout << "};\n";
 
    // reinterpreting
    double d = 0.1;
//  std::int64_t n = *reinterpret_cast<std::int64_t*>(&d); // aliasing violation
    std::int64_t n;
    std::memcpy(&n, &d, sizeof d); // OK
 
    std::cout << std::hexfloat << d << " is " << std::hex << n
              << " as a std::int64_t\n" << std::dec;
 
    // object creation in destination buffer
    struct S
    {
        int x{42};
        void print() const { std::cout << '{' << x << "}\n"; }
    } s;
    alignas(S) char buf[sizeof(S)];
    S* ps = new (buf) S; // placement new
    std::memcpy(ps, &s, sizeof s);
    ps->print();
}
```
Output:
```text
dest[4] = {'o', 'n', 'c', 'e'};
0x1.999999999999ap-4 is 3fb999999999999a as a std::int64_t
{42}
```
