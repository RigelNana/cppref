{/* source:cpp-string-byte-isgraph:0001 */}
Checks if the given character is graphic (has a graphical representation) as classified by the currently installed C locale. In the default C locale, the following characters are graphic:

{/* source:cpp-string-byte-isgraph:0002 */}
- digits (`0123456789`)
- uppercase letters (`ABCDEFGHIJKLMNOPQRSTUVWXYZ`)
- lowercase letters (`abcdefghijklmnopqrstuvwxyz`)
- punctuation characters (!"#$%&'()*+,-./:;\<=\>?@[\\]^_\`\{|\}~)

{/* source:cpp-string-byte-isgraph:0003 */}
The behavior is undefined if the value of `ch` is not representable as `unsigned char` and is not equal to [`EOF`](/docs/cpp/library/io/c).

### Parameters

{/* source:cpp-string-byte-isgraph:0004 */}
<ParameterList>
  <Parameter name="ch">character to classify</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-isgraph:0005 */}
Non-zero value if the character has a graphical representation character, zero otherwise.

### Notes

{/* source:cpp-string-byte-isgraph:0006 */}
Like all other functions from [`<cctype>`](/docs/cpp/library/headers/cctype), the behavior of `std::isgraph` is undefined if the argument's value is neither representable as `unsigned char` nor equal to [`EOF`](/docs/cpp/library/io/c). To use these functions safely with plain `chars` (or `signed chars`), the argument should first be converted to `unsigned char`:

{/* source:cpp-string-byte-isgraph:0007 */}
```cpp
bool my_isgraph(char ch)
{
    return std::isgraph(static_cast<unsigned char>(ch));
}
```

{/* source:cpp-string-byte-isgraph:0008 */}
Similarly, they should not be directly used with standard algorithms when the iterator's value type is `char` or `signed char`. Instead, convert the value to `unsigned char` first:

{/* source:cpp-string-byte-isgraph:0009 */}
```cpp
int count_graphs(const std::string& s)
{
    return std::count_if(s.begin(), s.end(),
                      // static_cast<int(*)(int)>(std::isgraph)         // wrong
                      // [](int c){ return std::isgraph(c); }           // wrong
                      // [](char c){ return std::isgraph(c); }          // wrong
                         [](unsigned char c){ return std::isgraph(c); } // correct
                        );
}
```

### Example

{/* source:cpp-string-byte-isgraph:0010 */}
```cpp
#include <cctype>
#include <clocale>
#include <iostream>
 
int main()
{
    unsigned char c = '\xb6'; // the character ¶ in ISO-8859-1
 
    std::cout << "isgraph(\'\\xb6\', default C locale) returned "
              << std::boolalpha << (std::isgraph(c) != 0) << '\n';
 
    std::setlocale(LC_ALL, "en_GB.iso88591");
    std::cout << "isgraph(\'\\xb6\', ISO-8859-1 locale) returned "
              << std::boolalpha << (std::isgraph(c) != 0) << '\n';
}
```
Possible output:
```text
isgraph('\xb6', default C locale) returned false
isgraph('\xb6', ISO-8859-1 locale) returned true
```
