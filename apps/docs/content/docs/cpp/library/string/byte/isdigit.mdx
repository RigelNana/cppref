{/* source:cpp-string-byte-isdigit:0001 */}
Checks if the given character is one of the 10 decimal digits: (`0123456789`).

{/* source:cpp-string-byte-isdigit:0002 */}
The behavior is undefined if the value of `ch` is not representable as `unsigned char` and is not equal to [`EOF`](/docs/cpp/library/io/c).

### Parameters

{/* source:cpp-string-byte-isdigit:0003 */}
<ParameterList>
  <Parameter name="ch">character to classify</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-isdigit:0004 */}
Non-zero value if the character is a numeric character, zero otherwise.

### Notes

{/* source:cpp-string-byte-isdigit:0005 */}
`isdigit` and `isxdigit` are the only standard narrow character classification functions that are not affected by the currently installed C locale. although some implementations (e.g. Microsoft in [1252 codepage](https://en.wikipedia.org/wiki/Windows-1252)) may classify additional single-byte characters as digits.

{/* source:cpp-string-byte-isdigit:0006 */}
Like all other functions from [`<cctype>`](/docs/cpp/library/headers/cctype), the behavior of `std::isdigit` is undefined if the argument's value is neither representable as `unsigned char` nor equal to [`EOF`](/docs/cpp/library/io/c). To use these functions safely with plain `chars` (or `signed chars`), the argument should first be converted to `unsigned char`:

{/* source:cpp-string-byte-isdigit:0007 */}
```cpp
bool my_isdigit(char ch)
{
    return std::isdigit(static_cast<unsigned char>(ch));
}
```

{/* source:cpp-string-byte-isdigit:0008 */}
Similarly, they should not be directly used with standard algorithms when the iterator's value type is `char` or `signed char`. Instead, convert the value to `unsigned char` first:

{/* source:cpp-string-byte-isdigit:0009 */}
```cpp
int count_digits(const std::string& s)
{
    return std::count_if(s.begin(), s.end(),
                      // static_cast<int(*)(int)>(std::isdigit)         // wrong
                      // [](int c){ return std::isdigit(c); }           // wrong
                      // [](char c){ return std::isdigit(c); }          // wrong
                         [](unsigned char c){ return std::isdigit(c); } // correct
                        );
}
```

### Example

{/* source:cpp-string-byte-isdigit:0010 */}
```cpp
#include <cctype>
#include <climits>
#include <iostream>
 
int main(void)
{
    for (int i = 0; i <= UCHAR_MAX; ++i)
        if (std::isdigit(i))
            std::cout << static_cast<unsigned char>(i);
    std::cout << '\n';
}
```
Output:
```text
0123456789
```
