{/* source:cpp-string-byte-isalpha:0001 */}
Checks if the given character is an alphabetic character as classified by the currently installed C locale. In the default locale, the following characters are alphabetic:

{/* source:cpp-string-byte-isalpha:0002 */}
- uppercase letters `ABCDEFGHIJKLMNOPQRSTUVWXYZ`
- lowercase letters `abcdefghijklmnopqrstuvwxyz`

{/* source:cpp-string-byte-isalpha:0003 */}
In locales other than `"C"`, an alphabetic character is a character for which `std::isupper()` or `std::islower()` returns non-zero or any other character considered alphabetic by the locale. In any case, `std::iscntrl()`, `std::isdigit()`, `std::ispunct()` and `std::isspace()` will return zero for this character.

{/* source:cpp-string-byte-isalpha:0004 */}
The behavior is undefined if the value of `ch` is not representable as `unsigned char` and is not equal to [`EOF`](/docs/cpp/library/io/c).

### Parameters

{/* source:cpp-string-byte-isalpha:0005 */}
<ParameterList>
  <Parameter name="ch">character to classify</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-isalpha:0006 */}
Non-zero value if the character is an alphabetic character, zero otherwise.

### Notes

{/* source:cpp-string-byte-isalpha:0007 */}
Like all other functions from [`<cctype>`](/docs/cpp/library/headers/cctype), the behavior of `std::isalpha` is undefined if the argument's value is neither representable as `unsigned char` nor equal to [`EOF`](/docs/cpp/library/io/c). To use these functions safely with plain `chars` (or `signed chars`), the argument should first be converted to `unsigned char`:

{/* source:cpp-string-byte-isalpha:0008 */}
```cpp
bool my_isalpha(char ch)
{
    return std::isalpha(static_cast<unsigned char>(ch));
}
```

{/* source:cpp-string-byte-isalpha:0009 */}
Similarly, they should not be directly used with standard algorithms when the iterator's value type is `char` or `signed char`. Instead, convert the value to `unsigned char` first:

{/* source:cpp-string-byte-isalpha:0010 */}
```cpp
int count_alphas(const std::string& s)
{
    return std::count_if(s.begin(), s.end(),
                      // static_cast<int(*)(int)>(std::isalpha)         // wrong
                      // [](int c){ return std::isalpha(c); }           // wrong
                      // [](char c){ return std::isalpha(c); }          // wrong
                         [](unsigned char c){ return std::isalpha(c); } // correct
                        );
}
```

### Example

{/* source:cpp-string-byte-isalpha:0011 */}
Demonstrates the use of `std::isalpha` with different locales (OS-specific).
```cpp
#include <cctype>
#include <clocale>
#include <iostream>
 
int main()
{
    unsigned char c = '\xdf'; // German letter ß in ISO-8859-1
 
    std::cout << "isalpha(\'\\xdf\', default C locale) returned "
              << std::boolalpha << !!std::isalpha(c) << '\n';
 
    std::setlocale(LC_ALL, "de_DE.iso88591");
    std::cout << "isalpha(\'\\xdf\', ISO-8859-1 locale) returned "
              << static_cast<bool>(std::isalpha(c)) << '\n';
 
}
```
Possible output:
```text
isalpha('\xdf', default C locale) returned false
isalpha('\xdf', ISO-8859-1 locale) returned true
```
