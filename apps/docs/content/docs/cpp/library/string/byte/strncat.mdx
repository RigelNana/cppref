  <Declaration language="cpp" code={`char* strncat( char* dest, const char* src, std::size_t count );`} />
</DeclarationDoc>

{/* source:cpp-string-byte-strncat:0001 */}
Appends a byte string pointed to by `src` to a byte string pointed to by `dest`. At most `count` characters are copied. The resulting byte string is null-terminated.

{/* source:cpp-string-byte-strncat:0002 */}
The destination byte string must have enough space for the contents of both `dest` and `src` plus the terminating null character, except that the size of `src` is limited to `count`.

{/* source:cpp-string-byte-strncat:0003 */}
The behavior is undefined if the strings overlap.

### Parameters

{/* source:cpp-string-byte-strncat:0004 */}
<ParameterList>
  <Parameter name="dest">pointer to the null-terminated byte string to append to</Parameter>
  <Parameter name="src">pointer to the null-terminated byte string to copy from</Parameter>
  <Parameter name="count">maximum number of characters to copy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-strncat:0005 */}
`dest`

### Notes

{/* source:cpp-string-byte-strncat:0006 */}
Because `std::strncat` needs to seek to the end of `dest` on each call, it is inefficient to concatenate many strings into one using `std::strncat`.

### Example

{/* source:cpp-string-byte-strncat:0007 */}
```cpp
#include <cstdio>
#include <cstring>
 
int main() 
{
    char str[50] = "Hello ";
    const char str2[50] = "World!";
    std::strcat(str, str2);
    std::strncat(str, " Goodbye World!", 3); // may issue "truncated output" warning
    std::puts(str);
}
```
Output:
```text
Hello World! Go
```
