{/* source:cpp-string-byte-strcat:0001 */}
Appends a copy of the character string pointed to by `src` to the end of the character string pointed to by `dest`. The character `src[0]` replaces the null terminator at the end of `dest`. The resulting byte string is null-terminated.

{/* source:cpp-string-byte-strcat:0002 */}
The behavior is undefined if the destination array is not large enough for the contents of both `src` and `dest` and the terminating null character.

{/* source:cpp-string-byte-strcat:0003 */}
The behavior is undefined if the strings overlap.

### Parameters

{/* source:cpp-string-byte-strcat:0004 */}
<ParameterList>
  <Parameter name="dest">pointer to the null-terminated byte string to append to</Parameter>
  <Parameter name="src">pointer to the null-terminated byte string to copy from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-strcat:0005 */}
`dest`

### Notes

{/* source:cpp-string-byte-strcat:0006 */}
Because `strcat` needs to seek to the end of `dest` on each call, it is inefficient to concatenate many strings into one using `strcat`.

### Example

{/* source:cpp-string-byte-strcat:0007 */}
```cpp
#include <cstdio>
#include <cstring>
 
int main() 
{
    char str[50] = "Hello ";
    char str2[50] = "World!";
    std::strcat(str, str2);
    std::strcat(str, " Goodbye World!");
    std::puts(str);
}
```
Output:
```text
Hello World! Goodbye World!
```
