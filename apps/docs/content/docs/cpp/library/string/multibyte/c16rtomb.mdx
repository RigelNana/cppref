Converts a single code point from variable-length 16-bit character representation (typically, UTF-16) to a narrow multibyte character representation.


{/* source:cpp-string-multibyte-c16rtomb:0002 */}

If `s` is not a null pointer and `c16` is the last 16-bit code unit in a valid variable-length encoding of a code point, the function determines the number of bytes necessary to store the multibyte character representation of that code point (including any shift sequences, and taking into account the current multibyte conversion state `*ps`), and stores the multibyte character representation in the character array whose first element is pointed to by `s`, updating `*ps` as necessary. At most `MB_CUR_MAX` bytes can be written by this function.


{/* source:cpp-string-multibyte-c16rtomb:0003 */}

If `s` is a null pointer, the call is equivalent to `std::c16rtomb(buf, u'\0', ps)` for some internal buffer `buf`.


{/* source:cpp-string-multibyte-c16rtomb:0004 */}

If `c16` is not the final code unit in a 16-bit representation of a wide character, it does not write to the array pointed to by `s`, only `*ps` is updated.


{/* source:cpp-string-multibyte-c16rtomb:0005 */}

If `c16` is the null wide character `u'\0'`, a null byte is stored, preceded by any shift sequence necessary to restore the initial shift state and the conversion state parameter `*ps` is updated to represent the initial shift state.


{/* source:cpp-string-multibyte-c16rtomb:0006 */}

The multibyte encoding used by this function is specified by the currently active C locale.


### Parameters

{/* source:cpp-string-multibyte-c16rtomb:0007 */}

<ParameterList>
  <Parameter name="s">pointer to narrow character array where the multibyte character will be stored</Parameter>
  <Parameter name="c16">the 16-bit character to convert</Parameter>
  <Parameter name="ps">pointer to the conversion state object used when interpreting the multibyte string</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-multibyte-c16rtomb:0008 */}

On success, returns the number of bytes (including any shift sequences) written to the character array whose first element is pointed to by `s`. This value may be `​0​`, e.g. when processing the first char16_t in a surrogate pair.


{/* source:cpp-string-multibyte-c16rtomb:0009 */}

On failure (if `c16` is not a valid 16-bit character), returns `-1`, stores [`EILSEQ`](/docs/cpp/library/error/errno_macros) in [`errno`](/docs/cpp/library/error/errno), and leaves `*ps` in unspecified state.


### Notes

{/* source:cpp-string-multibyte-c16rtomb:0010 */}

The C++ standard defers to the C standard for the semantics of this function. In C11 as published, unlike [`std::mbrtoc16`](/docs/cpp/library/text/multibyte/mbrtoc16), which converts variable-width multibyte (such as UTF-8) to variable-width 16-bit (such as UTF-16) encoding, this function can only convert single-unit 16-bit encoding, meaning it cannot convert UTF-16 to UTF-8 despite that being the original intent of this function. This was corrected by the post-C11 defect report [DR488](https://open-std.org/JTC1/SC22/WG14/www/docs/n2059.htm#dr_488).


### Example

{/* source:cpp-string-multibyte-c16rtomb:0011 */}

The example assumes that the fix for the [defect report 488](https://open-std.org/JTC1/SC22/WG14/www/docs/n2059.htm#dr_488) is applied.

```cpp
#include <climits>
#include <clocale>
#include <cuchar>
#include <iomanip>
#include <iostream>
#include <string_view>
 
int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    std::u16string_view strv = u"zß水🍌"; // or z\u00df\u6c34\U0001F34C
    std::cout << "Processing " << strv.size() << " UTF-16 code units: [ ";
    for (char16_t c : strv)
        std::cout << std::showbase << std::hex << static_cast<int>(c) << ' ';
    std::cout << "]\n";
 
    std::mbstate_t state{};
    char out[MB_LEN_MAX]{};
    for (char16_t c : strv)
    {
        std::size_t rc = std::c16rtomb(out, c, &state);
        std::cout << static_cast<int>(c) << " converted to [ ";
        if (rc != (std::size_t) - 1)
            for (unsigned char c8 : std::string_view{out, rc})
                std::cout << +c8 << ' ';
        std::cout << "]\n";
    }
}
```

Output:

```text
Processing 5 UTF-16 code units: [ 0x7a 0xdf 0x6c34 0xd83c 0xdf4c ]
0x7a converted to [ 0x7a ]
0xdf converted to [ 0xc3 0x9f ]
0x6c34 converted to [ 0xe6 0xb0 0xb4 ]
0xd83c converted to [ ]
0xdf4c converted to [ 0xf0 0x9f 0x8d 0x8c ]
```
