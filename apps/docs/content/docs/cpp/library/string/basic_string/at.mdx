{/* source:cpp-string-basic-string-at:0001 */}
Returns a reference to the character at specified location `pos`. Bounds checking is performed, exception of type [`std::out_of_range`](/docs/cpp/library/error/out_of_range) will be thrown on invalid access.

### Parameters

{/* source:cpp-string-basic-string-at:0002 */}
<ParameterList>
  <Parameter name="pos">position of the character to return</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-at:0003 */}
Reference to the requested character.

### Exceptions

{/* source:cpp-string-basic-string-at:0004 */}
Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos >= size()`.

{/* source:cpp-string-basic-string-at:0005 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-string-basic-string-at:0006 */}
Constant.

### Example

{/* source:cpp-string-basic-string-at:0007 */}
```cpp
#include <iostream>
#include <stdexcept>
#include <string>
 
int main()
{
    std::string s("message"); // for capacity
 
    s = "abc";
    s.at(2) = 'x'; // OK
    std::cout << s << '\n';
 
    std::cout << "string size = " << s.size() << '\n';
    std::cout << "string capacity = " << s.capacity() << '\n';
 
    try
    {
        // This will throw since the requested offset is greater than the current size.
        s.at(3) = 'x';
    }
    catch (std::out_of_range const& exc)
    {
        std::cout << exc.what() << '\n';
    }
}
```

Possible output:

```text
abx
string size = 3
string capacity = 7
basic_string::at
```
