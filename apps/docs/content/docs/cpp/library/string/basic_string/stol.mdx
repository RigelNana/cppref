{/* source:cpp-string-basic-string-stol:0001 */}
Interprets a signed integer value in the string `str`.

{/* source:cpp-string-basic-string-stol:0002 */}
Let `ptr` be an internal (to the conversion functions) pointer of type `char*` (1,3,5) or `wchar_t*` (2,4,6), accordingly.

{/* source:cpp-string-basic-string-stol:0003 */}
1. 1) Calls `std::strtol(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stol:0004 */}
2. 2) Calls `std::wcstol(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stol:0005 */}
3. 3) Calls `std::strtol(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stol:0006 */}
4. 4) Calls `std::wcstol(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stol:0007 */}
5. 5) Calls `std::strtoll(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stol:0008 */}
6. 6) Calls `std::wcstoll(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stol:0009 */}
Discards any whitespace characters (as identified by calling [`std::isspace`](/docs/cpp/library/text/byte/isspace)) until the first non-whitespace character is found, then takes as many characters as possible to form a valid base-n (where n=`base`) integer number representation and converts them to an integer value. The valid integer value consists of the following parts:

{/* source:cpp-string-basic-string-stol:0010 */}
- (optional) plus or minus sign
- (optional) prefix (`0`) indicating octal base (applies only when the base is `8` or `​0​`)
- (optional) prefix (`0x` or `0X`) indicating hexadecimal base (applies only when the base is `16` or `​0​`)
- a sequence of digits

{/* source:cpp-string-basic-string-stol:0011 */}
The set of valid values for `base` is \{0, 2, 3, ..., 36\}. The set of valid digits for base-2 integers is \{0, 1\}, for base-3 integers is \{0, 1, 2\}, and so on. For bases larger than 10, valid digits include alphabetic characters, starting from `Aa` for base-11 integer, to `Zz` for base-36 integer. The case of the characters is ignored.

{/* source:cpp-string-basic-string-stol:0012 */}
Additional numeric formats may be accepted by the currently installed C [locale](/docs/cpp/library/text/locale/setlocale).

{/* source:cpp-string-basic-string-stol:0013 */}
If the value of `base` is `​0​`, the numeric base is auto-detected: if the prefix is `0`, the base is octal, if the prefix is `0x` or `0X`, the base is hexadecimal, otherwise the base is decimal.

{/* source:cpp-string-basic-string-stol:0014 */}
If the minus sign was part of the input sequence, the numeric value calculated from the sequence of digits is negated as if by [unary minus](/docs/cpp/language/expressions/operator_arithmetic#Unary_arithmetic_operators) in the result type.

{/* source:cpp-string-basic-string-stol:0015 */}
If `pos` is not a null pointer, then `ptr` will receive an address of the first unconverted character in `str.c_str()`, and the index of that character will be calculated and stored in `*pos`, giving the number of characters that were processed by the conversion.

### Parameters

{/* source:cpp-string-basic-string-stol:0016 */}

### Return value

{/* source:cpp-string-basic-string-stol:0017 */}
Integer value corresponding to the content of `str`.

### Exceptions

{/* source:cpp-string-basic-string-stol:0018 */}
- [`std::invalid_argument`](/docs/cpp/library/error/invalid_argument) if no conversion could be performed.
- [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if the converted value would fall out of the range of the result type or if the underlying function ([`std::strtol`](/docs/cpp/library/text/byte/strtol) or [`std::strtoll`](/docs/cpp/library/text/byte/strtol)) sets [`errno`](/docs/cpp/library/error/errno) to [`ERANGE`](/docs/cpp/library/error/errno_macros).

### Example

{/* source:cpp-string-basic-string-stol:0019 */}
```cpp
#include <iomanip>
#include <iostream>
#include <stdexcept>
#include <string>
#include <utility>
 
int main()
{
    const auto data =
    {
        "45",
        "+45",
        " -45",
        "3.14159",
        "31337 with words",
        "words and 2",
        "12345678901",
    };
 
    for (const std::string s : data)
    {
        std::size_t pos{};
        try
        {
            std::cout << "std::stoi(" << std::quoted(s) << "): ";
            const int i{std::stoi(s, &pos)};
            std::cout << i << "; pos: " << pos << '\n';
        }
        catch (std::invalid_argument const& ex)
        {
            std::cout << "std::invalid_argument::what(): " << ex.what() << '\n';
        }
        catch (std::out_of_range const& ex)
        {
            std::cout << "std::out_of_range::what(): " << ex.what() << '\n';
            const long long ll{std::stoll(s, &pos)};
            std::cout << "std::stoll(" << std::quoted(s) << "): " << ll
                      << "; pos: " << pos << '\n';
        }
    }
 
    std::cout << "\nCalling with different radixes:\n";
    for (const auto& [s, base] : {std::pair<const char*, int>
        {"11",  2}, {"22",  3}, {"33",  4}, {"77",  8},
        {"99", 10}, {"FF", 16}, {"jJ", 20}, {"Zz", 36}})
    {
        const int i{std::stoi(s, nullptr, base)};
        std::cout << "std::stoi(" << std::quoted(s)
                  << ", nullptr, " << base << "): " << i << '\n';
    }
}
```

Possible output:

```text
std::stoi("45"): 45; pos: 2
std::stoi("+45"): 45; pos: 3
std::stoi(" -45"): -45; pos: 4
std::stoi("3.14159"): 3; pos: 1
std::stoi("31337 with words"): 31337; pos: 5
std::stoi("words and 2"): std::invalid_argument::what(): stoi
std::stoi("12345678901"): std::out_of_range::what(): stoi
std::stoll("12345678901"): 12345678901; pos: 11
 
Calling with different radixes:
std::stoi("11", nullptr, 2): 3
std::stoi("22", nullptr, 3): 8
std::stoi("33", nullptr, 4): 15
std::stoi("77", nullptr, 8): 63
std::stoi("99", nullptr, 10): 99
std::stoi("FF", nullptr, 16): 255
std::stoi("jJ", nullptr, 20): 399
std::stoi("Zz", nullptr, 36): 1295
```
