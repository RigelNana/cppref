{/* source:cpp-string-basic-string-operator-q-q-s:0001 */}
Forms a string literal of the desired type.

{/* source:cpp-string-basic-string-operator-q-q-s:0002 */}
1) Returns `std::string{str, len}`.

{/* source:cpp-string-basic-string-operator-q-q-s:0003 */}
2) Returns `std::u8string{str, len}`.

{/* source:cpp-string-basic-string-operator-q-q-s:0004 */}
3) Returns `std::u16string{str, len}`.

{/* source:cpp-string-basic-string-operator-q-q-s:0005 */}
4) Returns `std::u32string{str, len}`.

{/* source:cpp-string-basic-string-operator-q-q-s:0006 */}
5) Returns `std::wstring{str, len}`.

### Parameters

{/* source:cpp-string-basic-string-operator-q-q-s:0007 */}

  <Parameter name="str">pointer to the beginning of the raw character array literal</Parameter>
  <Parameter name="len">length of the raw character array literal</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-operator-q-q-s:0008 */}
The string literal.

### Notes

{/* source:cpp-string-basic-string-operator-q-q-s:0009 */}
These operators are declared in the namespace `std::literals::string_literals`, where both `literals` and `string_literals` are inline namespaces. Access to these operators can be gained with any of the following `using` directives:

{/* source:cpp-string-basic-string-operator-q-q-s:0010 */}
- `using namespace std::literals`,
- `using namespace std::string_literals`, or
- `using namespace std::literals::string_literals`.

{/* source:cpp-string-basic-string-operator-q-q-s:0011 */}
[`std::chrono::duration`](/docs/cpp/library/chrono/duration) also defines [`operator""s`](/docs/cpp/library/chrono/duration/operator_q__q_s) to represent literal seconds, but it is an arithmetic literal: `10.0s` and `10s` are ten seconds, but `"10"s` is a string.

### Example

{/* source:cpp-string-basic-string-operator-q-q-s:0013 */}
```cpp
#include <iostream>
#include <string>
 
void print_with_zeros(const auto note, const std::string& s)
{
    std::cout << note;
    for (const char c : s)
        c ? std::cout << c : std::cout << "₀";
    std::cout << " (size = " << s.size() << ")\n";
}
 
int main()
{
    using namespace std::string_literals;
 
    std::string s1 = "abc\0\0def";
    std::string s2 = "abc\0\0def"s;
    print_with_zeros("s1: ", s1);
    print_with_zeros("s2: ", s2);
 
    std::cout << "abcdef"s.substr(1,4) << '\n';
}
```

Output:

```text
s1: abc (size = 3)
s2: abc₀₀def (size = 8)
bcde
```
