{/* source:cpp-string-basic-string-stoul:0001 */}
Interprets an unsigned integer value in the string `str`.

{/* source:cpp-string-basic-string-stoul:0002 */}
Let `ptr` be an internal (to the conversion functions) pointer of type `char*` (1,3) or `wchar_t*` (2,4), accordingly.

{/* source:cpp-string-basic-string-stoul:0003 */}
1. 1) Calls `std::strtoul(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stoul:0004 */}
2. 2) Calls `std::wcstoul(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stoul:0005 */}
3. 3) Calls `std::strtoull(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stoul:0006 */}
4. 4) Calls `std::wcstoull(str.c_str(), &ptr, base)`.

{/* source:cpp-string-basic-string-stoul:0007 */}
Discards any whitespace characters (as identified by calling [`std::isspace`](/docs/cpp/library/text/byte/isspace)) until the first non-whitespace character is found, then takes as many characters as possible to form a valid base-n (where n=`base`) unsigned integer number representation and converts them to an integer value. The valid unsigned integer value consists of the following parts:

{/* source:cpp-string-basic-string-stoul:0008 */}
- (optional) plus or minus sign
- (optional) prefix (`0`) indicating octal base (applies only when the base is `8` or `​0​`)
- (optional) prefix (`0x` or `0X`) indicating hexadecimal base (applies only when the base is `16` or `​0​`)
- a sequence of digits

{/* source:cpp-string-basic-string-stoul:0009 */}
The set of valid values for `base` is \{0, 2, 3, ..., 36\}. The set of valid digits for base-2 integers is \{0, 1\}, for base-3 integers is \{0, 1, 2\}, and so on. For bases larger than 10, valid digits include alphabetic characters, starting from `Aa` for base-11 integer, to `Zz` for base-36 integer. The case of the characters is ignored.

{/* source:cpp-string-basic-string-stoul:0010 */}
Additional numeric formats may be accepted by the currently installed C [locale](/docs/cpp/library/text/locale/setlocale).

{/* source:cpp-string-basic-string-stoul:0011 */}
If the value of `base` is `​0​`, the numeric base is auto-detected: if the prefix is `0`, the base is octal, if the prefix is `0x` or `0X`, the base is hexadecimal, otherwise the base is decimal.

{/* source:cpp-string-basic-string-stoul:0012 */}
If the minus sign was part of the input sequence, the numeric value calculated from the sequence of digits is negated as if by [unary minus](/docs/cpp/language/expressions/operator_arithmetic#Unary_arithmetic_operators) in the result type, which applies unsigned integer wraparound rules.

{/* source:cpp-string-basic-string-stoul:0013 */}
If `pos` is not a null pointer, then `ptr` will receive the address of the first unconverted character in `str.c_str()`, and the index of that character will be calculated and stored in `*pos`, giving the number of characters that were processed by the conversion.

### Return value

{/* source:cpp-string-basic-string-stoul:0015 */}
The string converted to the specified unsigned integer type.

### Exceptions

{/* source:cpp-string-basic-string-stoul:0016 */}
- [`std::invalid_argument`](/docs/cpp/library/error/invalid_argument) if no conversion could be performed.
- [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if the converted value would fall out of the range of the result type or if the underlying function ([`std::strtoul`](/docs/cpp/library/text/byte/strtoul) or [`std::strtoull`](/docs/cpp/library/text/byte/strtoul)) sets [`errno`](/docs/cpp/library/error/errno) to [`ERANGE`](/docs/cpp/library/error/errno_macros).
