{/* source:cpp-string-basic-string-assign-range:0001 */}
Replaces the contents of the string with the values in the range `rg`.

{/* source:cpp-string-basic-string-assign-range:0002 */}
Equivalent to

{/* source:cpp-string-basic-string-assign-range:0003 */}
```cpp
return assign(
    std::basic_string(
        std::from_range,
        std​::​forward<R>(rg),
        get_allocator())
);
```

### Parameters

{/* source:cpp-string-basic-string-assign-range:0004 */}
<ParameterList>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-assign-range:0005 */}
`*this`

### Complexity

{/* source:cpp-string-basic-string-assign-range:0006 */}
Linear in size of `rg`.

### Exceptions

{/* source:cpp-string-basic-string-assign-range:0007 */}
If the operation would cause [`size()`](/docs/cpp/library/string/basic_string/size) to exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size), throws [`std::length_error`](/docs/cpp/library/error/length_error).

{/* source:cpp-string-basic-string-assign-range:0008 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-assign-range:0010 */}
```cpp
#include <cassert>
#include <string>
 
int main()
{
    const auto source = {'s', 'o', 'u', 'r', 'c', 'e'};
    std::string destination{"destination"};
 
#ifdef __cpp_lib_containers_ranges
    destination.assign_range(source);
#else
    destination.assign(source.begin(), source.end());
#endif
 
    assert(destination == "source");
}
```
