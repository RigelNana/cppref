{/* source:cpp-string-basic-string-c-str:0001 */}
Returns a pointer to a null-terminated character array with data equivalent to those stored in the string.

{/* source:cpp-string-basic-string-c-str:0002 */}
The pointer is such that the range [`c_str()`, `c_str() + size()`] is valid and the values in it correspond to the values stored in the string with an additional null character after the last position.

{/* source:cpp-string-basic-string-c-str:0003 */}
The pointer obtained from `c_str()` may be invalidated by:

{/* source:cpp-string-basic-string-c-str:0004 */}
- Passing a non-const reference to the string to any standard library function, or
- Calling non-const member functions on the string, <InlineRevision since="C++11">excluding [`operator[]`](/docs/cpp/library/string/basic_string/operator_at), [`at()`](/docs/cpp/library/string/basic_string/at), [`front()`](/docs/cpp/library/string/basic_string/front), [`back()`](/docs/cpp/library/string/basic_string/back), [`begin()`](/docs/cpp/library/string/basic_string/begin), [`rbegin()`](/docs/cpp/library/string/basic_string/rbegin), [`end()`](/docs/cpp/library/string/basic_string/end) and [`rend()`](/docs/cpp/library/string/basic_string/rend)</InlineRevision>.

{/* source:cpp-string-basic-string-c-str:0005 */}
Writing to the character array accessed through `c_str()` is undefined behavior.

{/* source:cpp-string-basic-string-c-str:0006 */}
<Revision since="C++11">
`c_str()` and [`data()`](/docs/cpp/library/string/basic_string/data) perform the same function.
</Revision>

### Parameters

{/* source:cpp-string-basic-string-c-str:0007 */}
(none)

### Return value

{/* source:cpp-string-basic-string-c-str:0008 */}
Pointer to the underlying character storage.

{/* source:cpp-string-basic-string-c-str:0009 */}
<Revision until="C++11">
`c_str()[i] == operator[](i)` for every `i` in [`0`, `size()`).
</Revision>

<Revision since="C++11">
`c_str() + i == std::addressof(operator[](i))` for every `i` in [`0`, `size()`].
</Revision>

### Complexity

{/* source:cpp-string-basic-string-c-str:0010 */}
Constant.

### Notes

{/* source:cpp-string-basic-string-c-str:0011 */}
The pointer obtained from `c_str()` may only be treated as a pointer to a null-terminated character string if the string object does not contain other null characters.

### Example

{/* source:cpp-string-basic-string-c-str:0012 */}
```cpp
#include <algorithm>
#include <cassert>
#include <cstring>
#include <string>
 
extern "C" void c_func(const char* c_str)
{
    printf("c_func called with '%s'\n", c_str);
}
 
int main()
{
    std::string const s("Emplary");
    const char* p = s.c_str();
    assert(s.size() == std::strlen(p));
    assert(std::equal(s.begin(), s.end(), p));
    assert(std::equal(p, p + s.size(), s.begin()));
    assert('\0' == *(p + s.size()));
 
    c_func(s.c_str());
}
```

Output:

```text
c_func called with 'Emplary'
```
