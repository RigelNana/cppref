{/* source:cpp-string-basic-string-empty:0001 */}
Checks if the string has no characters, i.e. whether `begin() == end()`.

### Parameters

{/* source:cpp-string-basic-string-empty:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-empty:0003 */}
`true` if the string is empty, `false` otherwise

### Complexity

{/* source:cpp-string-basic-string-empty:0004 */}
Constant.

### Example

{/* source:cpp-string-basic-string-empty:0005 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    std::string s;
    std::boolalpha(std::cout);
    std::cout << "s.empty():" << s.empty() << "\t s:'" << s << "'\n";
 
    s = "Exemplar";
    std::cout << "s.empty():" << s.empty() << "\t s:'" << s << "'\n";
 
    s = "";
    std::cout << "s.empty():" << s.empty() << "\t s:'" << s << "'\n";
}
```

Output:

```text
s.empty():true   s:''
s.empty():false  s:'Exemplar'
s.empty():true   s:''
```
