{/* source:cpp-string-basic-string-back:0001 */}
Returns reference to the last character in the string. The behavior is undefined if [`empty()`](/docs/cpp/library/string/basic_string/empty) is `true`.

### Parameters

{/* source:cpp-string-basic-string-back:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-back:0003 */}
Reference to the last character, equivalent to `operator[](size() - 1)`.

### Complexity

{/* source:cpp-string-basic-string-back:0004 */}
Constant.

### Notes

{/* source:cpp-string-basic-string-back:0005 */}
In libstdc++, `back()` is [not available](https://gcc.gnu.org/onlinedocs/libstdc++/manual/strings.html#strings.string.shrink) in C++98 mode.

### Example

{/* source:cpp-string-basic-string-back:0006 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    std::string s("Exemplary");
    char& back1 = s.back();
    back1 = 's';
    std::cout << s << '\n'; // "Exemplars"
 
    std::string const c("Exemplary");
    char const& back2 = c.back();
    std::cout << back2 << '\n'; // 'y'
}
```

Output:

```text
Exemplars
y
```
