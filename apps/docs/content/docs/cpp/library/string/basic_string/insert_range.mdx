constexpr iterator insert_range( const_iterator pos, R&& rg );`} />

{/* source:cpp-string-basic-string-insert-range:0001 */}
Inserts characters from the range `rg` before the element (if any) pointed by `pos`.

{/* source:cpp-string-basic-string-insert-range:0002 */}
Equivalent to

{/* source:cpp-string-basic-string-insert-range:0003 */}
```cpp
return insert(pos - begin(),
    std::basic_string(
        std::from_range,
        std​::​forward<R>(rg),
        get_allocator())
);
```

{/* source:cpp-string-basic-string-insert-range:0004 */}
If `pos` is not a valid iterator on `*this`, the behavior is undefined.

{/* source:cpp-string-basic-string-insert-range:0005 */}
### Parameters

<ParameterList>
  <Parameter name="pos">iterator before which the characters will be inserted</Parameter>
  <Parameter name="rg">a [container compatible range](/docs/cpp/library/ranges/to#container_compatible_range)</Parameter>
</ParameterList>

{/* source:cpp-string-basic-string-insert-range:0006 */}
### Return value

An iterator which refers to the first inserted character, or `pos` if no characters were inserted because `rg` was empty.

{/* source:cpp-string-basic-string-insert-range:0007 */}
### Complexity

Linear in size of `rg`.

{/* source:cpp-string-basic-string-insert-range:0008 */}
### Exceptions

If `std::allocator_traits<Allocator>::allocate` throws an exception, it is rethrown.

{/* source:cpp-string-basic-string-insert-range:0009 */}
If the operation would cause [`size()`](/docs/cpp/library/string/basic_string/size) to exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size), throws [`std::length_error`](/docs/cpp/library/error/length_error).

{/* source:cpp-string-basic-string-insert-range:0010 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

{/* source:cpp-string-basic-string-insert-range:0011 */}

### Example

```cpp
#include <cassert>
#include <iterator>
#include <string>
 
int main()
{
    const auto source = {'l', 'i', 'b', '_'};
    std::string target{"__cpp_containers_ranges"};
    //                        ^insertion will occur
    //                         before this position
 
    const auto pos = target.find("container");
    assert(pos != target.npos);
    auto iter = std::next(target.begin(), pos);
 
#ifdef __cpp_lib_containers_ranges
    target.insert_range(iter, source);
#else
    target.insert(iter, source.begin(), source.end());
#endif
 
    assert(target == "__cpp_lib_containers_ranges");
    //                      ^^^^
}
```
