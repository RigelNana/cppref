{/* source:cpp-string-basic-string-compare:0001 */}
Compares two character sequences.

1. {/* source:cpp-string-basic-string-compare:0002 */}1) Compares this string to `str`.
2. {/* source:cpp-string-basic-string-compare:0003 */}2) Compares a [`pos1`, `pos1 + count1`) substring of this string to `str`. If `count1 > size() - pos1`, the substring is [`pos1`, `size()`).
3. {/* source:cpp-string-basic-string-compare:0004 */}3) Compares a [`pos1`, `pos1 + count1`) substring of this string to a substring [`pos2`, `pos2 + count2`) of `str`. If `count1 > size() - pos1`, the first substring is [`pos1`, `size()`). If `count2 > str.size() - pos2`, the second substring is [`pos2`, `str.size()`).
4. {/* source:cpp-string-basic-string-compare:0005 */}4) Compares this string to the null-terminated character sequence beginning at the character pointed to by `s` with length `Traits::length(s)`.
5. {/* source:cpp-string-basic-string-compare:0006 */}5) Compares a [`pos1`, `pos1 + count1`) substring of this string to the null-terminated character sequence beginning at the character pointed to by `s` with length `Traits::length(s)`. If `count1 > size() - pos1`, the substring is [`pos1`, `size()`).
6. {/* source:cpp-string-basic-string-compare:0007 */}6) Compares a [`pos1`, `pos1 + count1`) substring of this string to the characters in the range [`s`, `s + count2`). The characters in [`s`, `s + count2`) may include null characters. If `count1 > size() - pos1`, the substring is [`pos1`, `size()`).
7. {/* source:cpp-string-basic-string-compare:0008 */}7-9) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then
8. {/* source:cpp-string-basic-string-compare:0009 */}7) compares this string to `sv`;
9. {/* source:cpp-string-basic-string-compare:0010 */}8) compares a [`pos1`, `pos1 + count1`) substring of this string to `sv`, as if by `std::basic_string_view<CharT, Traits>(*this).substr(pos1, count1).compare(sv)`;
10. {/* source:cpp-string-basic-string-compare:0011 */}9) compares a [`pos1`, `pos1 + count1`) substring of this string to a substring [`pos2`, `pos2 + count2`) of `sv`, as if by `std::basic_string_view<CharT, Traits>(*this)`<br />`.substr(pos1, count1).compare(sv.substr(pos2, count2))`.
11. {/* source:cpp-string-basic-string-compare:0012 */}These overloads participate in overload resolution only if `std::is_convertible_v<const StringViewLike&,` `std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`..

{/* source:cpp-string-basic-string-compare:0013 */}
A character sequence consisting of `count1` characters starting at `data1` is compared to a character sequence consisting of `count2` characters starting at `data2` as follows:

{/* source:cpp-string-basic-string-compare:0014 */}
- First, calculate the number of characters to compare, as if by `size_type rlen = std::min(count1, count2)`. Then compare the sequences by calling `Traits::compare(data1, data2, rlen)`. For standard strings this function performs character-by-character lexicographical comparison. If the result is zero (the character sequences are equal so far), then their sizes are compared as follows:

{/* source:cpp-string-basic-string-compare:0015 */}
| Condition | Result | Return value |
| --- | --- | --- |
| `Traits::compare(data1, data2, rlen) < 0` | `data1` is *less* than `data2` | `< 0` |
| `Traits::compare(data1, data2, rlen) == 0` | `size1 < size2` | `data1` is *less* than `data2` | `< 0` |
| | `size1 == size2` | `data1` is *equal* to `data2` | `0` |
| | `size1 > size2` | `data1` is *greater* than `data2` | `> 0` |
| `Traits::compare(data1, data2, rlen) > 0` | `data1` is *greater* than `data2` | `> 0` |

### Return value

{/* source:cpp-string-basic-string-compare:0017 */}
- Negative value if `*this` appears before the character sequence specified by the arguments, in lexicographical order.
- Zero if both character sequences compare equivalent.
- Positive value if `*this` appears after the character sequence specified by the arguments, in lexicographical order.

### Exceptions

{/* source:cpp-string-basic-string-compare:0018 */}
The overloads taking parameters named `pos1` or `pos2` throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if the argument is out of range.

1. {/* source:cpp-string-basic-string-compare:0019 */}7) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_convertible_v<const T&, std::basic_string_view<CharT, Traits>>)`
2. {/* source:cpp-string-basic-string-compare:0020 */}8,9) Throws anything thrown by the conversion to [`std::basic_string_view`](/docs/cpp/library/string/basic_string_view).

{/* source:cpp-string-basic-string-compare:0021 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Possible implementation

{/* source:cpp-string-basic-string-compare:0022 */}
[overload (1)](/docs/cpp/library/string/basic_string/compare#Version_1)

```cpp
template<class CharT, class Traits, class Alloc>
int std::basic_string<CharT, Traits, Alloc>::compare
    (const std::basic_string& s) const noexcept
{
    size_type lhs_sz = size();
    size_type rhs_sz = s.size();
    int result = traits_type::compare(data(), s.data(), std::min(lhs_sz, rhs_sz));
    if (result != 0)
        return result;
    if (lhs_sz < rhs_sz)
        return -1;
    if (lhs_sz > rhs_sz)
        return 1;
    return 0;
}
```

### Notes

{/* source:cpp-string-basic-string-compare:0023 */}
For the situations when three-way comparison is not required, [`std::basic_string`](/docs/cpp/library/string/basic_string) provides the usual [relational operators](/docs/cpp/library/string/basic_string/operator_cmp) `(<, <=, ==, >, etc)`.

{/* source:cpp-string-basic-string-compare:0024 */}
By default (with the default [`std::char_traits`](/docs/cpp/library/string/char_traits)), this function is not locale-sensitive. See [`std::collate::compare`](/docs/cpp/library/text/locale/collate/compare) for locale-aware three-way string comparison.

### Example

{/* source:cpp-string-basic-string-compare:0025 */}
```cpp
#include <cassert>
#include <iomanip>
#include <iostream>
#include <string>
#include <string_view>
 
void print_compare_result(std::string_view str1,
                          std::string_view str2,
                          int compare_result)
{
    if (compare_result < 0)
        std::cout << std::quoted(str1) << " comes before "
                  << std::quoted(str2) << ".\n";
    else if (compare_result > 0)
        std::cout << std::quoted(str2) << " comes before "
                  << std::quoted(str1) << ".\n";
    else
        std::cout << std::quoted(str1) << " and "
                  << std::quoted(str2) << " are the same.\n";
}
 
int main()
{
    std::string batman{"Batman"};
    std::string superman{"Superman"};
    int compare_result{0};
 
    // 1) Compare with other string
    compare_result = batman.compare(superman);
    std::cout << "1) ";
    print_compare_result("Batman", "Superman", compare_result);
 
    // 2) Compare substring with other string
    compare_result = batman.compare(3, 3, superman);
    std::cout << "2) ";
    print_compare_result("man", "Superman", compare_result);
 
    // 3) Compare substring with other substring
    compare_result = batman.compare(3, 3, superman, 5, 3);
    std::cout << "3) ";
    print_compare_result("man", "man", compare_result);
 
    // Compare substring with other substring
    // defaulting to end of other string
    assert(compare_result == batman.compare(3, 3, superman, 5));
 
    // 4) Compare with char pointer
    compare_result = batman.compare("Superman");
    std::cout << "4) ";
    print_compare_result("Batman", "Superman", compare_result);
 
    // 5) Compare substring with char pointer
    compare_result = batman.compare(3, 3, "Superman");
    std::cout << "5) ";
    print_compare_result("man", "Superman", compare_result);
 
    // 6) Compare substring with char pointer substring
    compare_result = batman.compare(0, 3, "Superman", 5);
    std::cout << "6) ";
    print_compare_result("Bat", "Super", compare_result);
}
```

Output:

```text
1) "Batman" comes before "Superman".
2) "Superman" comes before "man".
3) "man" and "man" are the same.
4) "Batman" comes before "Superman".
5) "Superman" comes before "man".
6) "Bat" comes before "Super".
```
