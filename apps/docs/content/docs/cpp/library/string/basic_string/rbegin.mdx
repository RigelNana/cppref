{/* source:cpp-string-basic-string-rbegin:0001 */}
Returns a reverse iterator to the first character of the reversed string. It corresponds to the last character of the non-reversed string.

### Parameters

{/* source:cpp-string-basic-string-rbegin:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-rbegin:0003 */}
Reverse iterator to the first character.

### Complexity

{/* source:cpp-string-basic-string-rbegin:0004 */}
Constant.

### Notes

{/* source:cpp-string-basic-string-rbegin:0005 */}
libc++ backports `crbegin()` to C++98 mode.

### Example

{/* source:cpp-string-basic-string-rbegin:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <string>
 
int main()
{
    std::string s("Exemplar!");
    *s.rbegin() = 'y';
    std::cout << s << '\n'; // "Exemplary"
 
    std::string c;
    std::copy(s.crbegin(), s.crend(), std::back_inserter(c));
    std::cout << c << '\n'; // "yralpmexE"
}
```

Output:

```text
Exemplary
yralpmexE
```
