{/* source:cpp-string-basic-string-rfind:0001 */}
Finds the last substring that is equal to the given character sequence. The search begins at `pos` and proceeds from right to left (thus, the found substring, if any, cannot begin in a position following `pos`). If [`npos`](/docs/cpp/library/string/basic_string/npos) or any value not smaller than [`size()`](/docs/cpp/library/string/basic_string/size) - 1 is passed as `pos`, the whole string will be searched.

{/* source:cpp-string-basic-string-rfind:0002 */}
1) Finds the last substring equal to `str`.

{/* source:cpp-string-basic-string-rfind:0003 */}
2) Finds the last substring equal to the range [`s`, `s + count`). This range can include null characters.

{/* source:cpp-string-basic-string-rfind:0004 */}
If [`s`, `s + count`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-rfind:0005 */}
3) Finds the last substring equal to the character string pointed to by `s`. The length of the string is determined by the first null character using `Traits::length(s)`.

{/* source:cpp-string-basic-string-rfind:0006 */}
If [`s`, `s + Traits::length(s)`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-rfind:0007 */}
4) Finds the last character equal to `ch`.

{/* source:cpp-string-basic-string-rfind:0008 */}
5) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then finds the last substring equal to the contents of `sv`.

{/* source:cpp-string-basic-string-rfind:0009 */}
This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-rfind:0010 */}
In all cases, equality is checked by calling [`Traits::eq`](/docs/cpp/library/string/char_traits/cmp).

### Return value

{/* source:cpp-string-basic-string-rfind:0012 */}
Position of the first character of the found substring or [`npos`](/docs/cpp/library/string/basic_string/npos) if no such substring is found. Note that this is an offset from the start of the string, not the end.

{/* source:cpp-string-basic-string-rfind:0013 */}
If searching for an empty string (i.e., `str.size()`, `count`, or `Traits::length(s)` is zero), the empty string is found immediately and `rfind` returns:

{/* source:cpp-string-basic-string-rfind:0014 */}
- `pos`, if `pos < size()`;
- `size()` otherwise, including the case where `pos == npos`.

{/* source:cpp-string-basic-string-rfind:0015 */}
Otherwise, if [`size()`](/docs/cpp/library/string/basic_string/size) is zero, [`npos`](/docs/cpp/library/string/basic_string/npos) is always returned.

### Exceptions

{/* source:cpp-string-basic-string-rfind:0016 */}
1,4) Throws nothing.

{/* source:cpp-string-basic-string-rfind:0017 */}
5) noexcept specification: [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) `noexcept(std::is_nothrow_convertible_v<const T&, std::basic_string_view<CharT, Traits>>)`

{/* source:cpp-string-basic-string-rfind:0018 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-rfind:0019 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string>
 
void print(std::string::size_type n,
           std::string::size_type len,
           std::string const &s)
{
    if (n == std::string::npos)
        std::cout << "not found\n";
    else
        std::cout << "found: " << std::quoted(s.substr(n, len)) << " at " << n << '\n';
}
 
int main()
{
    std::string::size_type n;
    std::string const s = "This is a string";
 
    // search backwards from end of string
    n = s.rfind("is");
    print(n, 2, s);
 
    // search backwards from position 4
    n = s.rfind("is", 4);
    print(n, 2, s);
 
    // find a single character
    n = s.rfind('s');
    print(n, 1, s);
 
    // find a single character
    n = s.rfind('q');
    print(n, 1, s);
 
    // find the prefix (see also s.starts_with("This"))
    n = s.rfind("This", 0);
    print(n, 4, s);
}
```

Output:

```text
found: "is" at 5
found: "is" at 2
found: "s" at 10
not found
found: "This" at 0
```
