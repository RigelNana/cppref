{/* source:cpp-string-basic-string-find-last-of:0001 */}
Finds the last character equal to one of characters in the given character sequence. The exact search algorithm is not specified. The search considers only the range [`0`, `pos`]. If none of the characters in the given character sequence is present in the range, [`npos`](/docs/cpp/library/string/basic_string/npos) will be returned.

{/* source:cpp-string-basic-string-find-last-of:0002 */}
1) Finds the last character equal to one of characters in `str`.

{/* source:cpp-string-basic-string-find-last-of:0003 */}
2) Finds the last character equal to one of characters in range [`s`, `s + count`). This range can include null characters.

{/* source:cpp-string-basic-string-find-last-of:0004 */}
If [`s`, `s + count`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find-last-of:0005 */}
3) Finds the last character equal to one of characters in character string pointed to by `s`. The length of the string is determined by the first null character using `Traits::length(s)`.

{/* source:cpp-string-basic-string-find-last-of:0006 */}
If [`s`, `s + Traits::length(s)`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find-last-of:0007 */}
4) Finds the last character equal to `ch`.

{/* source:cpp-string-basic-string-find-last-of:0008 */}
5) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then finds the last character equal to one of characters in `sv`.

{/* source:cpp-string-basic-string-find-last-of:0009 */}
This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-find-last-of:0010 */}
In all cases, equality is checked by calling [`Traits::eq`](/docs/cpp/library/string/char_traits/cmp).

### Return value

{/* source:cpp-string-basic-string-find-last-of:0012 */}
Position of the found character or [`npos`](/docs/cpp/library/string/basic_string/npos) if no such character is found.

### Exceptions

{/* source:cpp-string-basic-string-find-last-of:0013 */}
1,4) Throws nothing.

{/* source:cpp-string-basic-string-find-last-of:0014 */}
5) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_convertible_v<const T&, std::basic_string_view<CharT, Traits>>)`

{/* source:cpp-string-basic-string-find-last-of:0015 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-find-last-of:0016 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    const std::string path = "/root/config";
    auto const pos = path.find_last_of('/');
    const auto leaf = path.substr(pos + 1);
 
    std::cout << leaf << '\n';
}
```

Output:

```text
config
```
