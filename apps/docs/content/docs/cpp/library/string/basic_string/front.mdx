{/* source:cpp-string-basic-string-front:0001 */}
Returns reference to the first character in the string. The behavior is undefined if [`empty()`](/docs/cpp/library/string/basic_string/empty) is `true`.

### Parameters

{/* source:cpp-string-basic-string-front:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-front:0003 */}
Reference to the first character, equivalent to `operator[](0)`.

### Complexity

{/* source:cpp-string-basic-string-front:0004 */}
Constant.

### Notes

{/* source:cpp-string-basic-string-front:0005 */}
In libstdc++, `front()` is [not available](https://gcc.gnu.org/onlinedocs/libstdc++/manual/strings.html#strings.string.shrink) in C++98 mode.

### Example

{/* source:cpp-string-basic-string-front:0006 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    std::string s("Exemplary");
    char& f1 = s.front();
    f1 = 'e';
    std::cout << s << '\n'; // "exemplary"
 
    std::string const c("Exemplary");
    char const& f2 = c.front();
    std::cout << &f2 << '\n'; // "Exemplary"
}
```

Output:

```text
exemplary
Exemplary
```
