{/* source:cpp-string-basic-string-ends-with:0001 */}
Checks if the string ends with the given suffix. The suffix may be one of the following:

{/* source:cpp-string-basic-string-ends-with:0002 */}
1) A string view `sv` (which may be a result of implicit conversion from another `std::basic_string`).

{/* source:cpp-string-basic-string-ends-with:0003 */}
2) A single character `ch`.

{/* source:cpp-string-basic-string-ends-with:0004 */}
3) A null-terminated character string `s`.

{/* source:cpp-string-basic-string-ends-with:0005 */}
All three overloads effectively return `std::basic_string_view<CharT, Traits>(data(), size()).ends_with(x)`, where `x` is the parameter.

### Parameters

{/* source:cpp-string-basic-string-ends-with:0006 */}
<ParameterList>
  <Parameter name="sv">a string view which may be a result of implicit conversion from another `std::basic_string`</Parameter>
  <Parameter name="ch">a single character</Parameter>
  <Parameter name="s">a null-terminated character string</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-ends-with:0007 */}
`true` if the string ends with the provided suffix, `false` otherwise.

### Example

{/* source:cpp-string-basic-string-ends-with:0009 */}
```cpp
#include <cassert>
#include <string>
#include <string_view>
 
int main()
{
    using namespace std::literals;
 
    const auto str = "Hello, C++20!"s;
 
    assert
    (""
        && str.ends_with("C++20!"sv)  // (1)
        && !str.ends_with("c++20!"sv) // (1)
        && str.ends_with("C++20!"s)   // (1) implicit conversion string to string_view
        && !str.ends_with("c++20!"s)  // (1) implicit conversion string to string_view
        && str.ends_with('!')         // (2)
        && !str.ends_with('?')        // (2)
        && str.ends_with("C++20!")    // (3)
        && !str.ends_with("c++20!")   // (3)
    );
}
```
