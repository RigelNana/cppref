{/* source:cpp-string-basic-string-end:0001 */}
Returns an iterator to the character following the last character of the string. This character acts as a placeholder, attempting to access it results in undefined behavior.

### Parameters

{/* source:cpp-string-basic-string-end:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-end:0003 */}
Iterator to the character following the last character.

### Complexity

{/* source:cpp-string-basic-string-end:0004 */}
Constant.

### Notes

{/* source:cpp-string-basic-string-end:0005 */}
libc++ backports `cend()` to C++98 mode.

### Example

{/* source:cpp-string-basic-string-end:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <string>
 
int main()
{
    std::string s("Exemparl");
    std::next_permutation(s.begin(), s.end());
 
    std::string c;
    std::copy(s.cbegin(), s.cend(), std::back_inserter(c));
    std::cout << c << '\n'; // "Exemplar"
}
```

Output:

```text
Exemplar
```
