{/* source:cpp-string-basic-string-insert:0001 */}
Inserts characters into the string.

{/* source:cpp-string-basic-string-insert:0002 */}
1. 1) Inserts `count` copies of character `ch` at the position `index`.

{/* source:cpp-string-basic-string-insert:0003 */}
2. 2) Inserts null-terminated character string pointed to by `s` at the position `index`. The length of the string is determined by the first null character using `Traits::length(s)`.

{/* source:cpp-string-basic-string-insert:0004 */}
3. 3) Inserts the characters in the range [`s`, `s + count`) at the position `index`. The range can contain null characters.

{/* source:cpp-string-basic-string-insert:0005 */}
4. 4) Inserts string `str` at the position `index`.

{/* source:cpp-string-basic-string-insert:0006 */}
5. 5) Inserts a string, obtained by `str.substr(s_index, count)` at the position `index`.

{/* source:cpp-string-basic-string-insert:0007 */}
6. 6) Inserts character `ch` before the character pointed by `pos`.

{/* source:cpp-string-basic-string-insert:0008 */}
7. 7) Inserts `count` copies of character `ch` before the element (if any) pointed by `pos`.

{/* source:cpp-string-basic-string-insert:0009 */}
8. 8) Inserts characters from the range [`first`, `last`) before the element (if any) pointed by `pos`, as if by `insert(pos - begin(), basic_string(first, last, get_allocator()))`.

   <Revision since="C++11">
   This overload does not participate in overload resolution if `InputIt` does not satisfy [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
   </Revision>

{/* source:cpp-string-basic-string-insert:0010 */}
9. 9) Inserts elements from initializer list `ilist` before the element (if any) pointed by `pos`.

{/* source:cpp-string-basic-string-insert:0011 */}
10. 10) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then inserts the elements from `sv` before the element (if any) pointed by `index`, as if by `insert(index, sv.data(), sv.size())`.

{/* source:cpp-string-basic-string-insert:0012 */}
11. This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-insert:0013 */}
12. 11) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then inserts, before the element (if any) pointed by `index`, the characters from the subview [`t_index`, `t_index + count`) of `sv`. If the requested subview lasts past the end of `sv`, or if `count == npos`, the resulting subview is [`t_index`, `sv.size()`). If `t_index > sv.size()`, or if `index > size()`, [`std::out_of_range`](/docs/cpp/library/error/out_of_range) is thrown.

{/* source:cpp-string-basic-string-insert:0014 */}
13. This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-insert:0015 */}
14. If `pos` is not a valid iterator on `*this`, the behavior is undefined.

{/* source:cpp-string-basic-string-insert:0016 */}

Type requirements

- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).

{/* source:cpp-string-basic-string-insert:0017 */}
### Return value

1. 1-5) `*this`

{/* source:cpp-string-basic-string-insert:0018 */}
2. 6-9) An iterator which refers to the copy of the first inserted character or `pos` if no characters were inserted (`count == 0` or `first == last` or `ilist.size() == 0`)

{/* source:cpp-string-basic-string-insert:0019 */}
3. 10,11) `*this`

{/* source:cpp-string-basic-string-insert:0020 */}
### Exceptions

1. 1-4,10) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `index > size()`.

{/* source:cpp-string-basic-string-insert:0021 */}
2. 5) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `index > size()` or if `s_index > str.size()`.

{/* source:cpp-string-basic-string-insert:0022 */}
3. 11) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `index > size()` or if `t_index > sv.size()`.

{/* source:cpp-string-basic-string-insert:0023 */}
4. In all cases, throws [`std::length_error`](/docs/cpp/library/error/length_error) if `size() + ins_count > max_size()` where `ins_count` is the number of characters that will be inserted.

{/* source:cpp-string-basic-string-insert:0024 */}
<Revision since="C++20">
In all cases, if `std::allocator_traits<Allocator>::allocate` throws an exception, it is rethrown.
</Revision>

{/* source:cpp-string-basic-string-insert:0025 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

{/* source:cpp-string-basic-string-insert:0026 */}
### Example

```cpp
#include <cassert>
#include <iterator>
#include <string>
 
using namespace std::string_literals;
 
int main()
{
    std::string s = "xmplr";
 
    // insert(size_type index, size_type count, char ch)
    s.insert(0, 1, 'E');
    assert("Exmplr" == s);
 
    // insert(size_type index, const char* s)
    s.insert(2, "e");
    assert("Exemplr" == s);
 
    // insert(size_type index, string const& str)
    s.insert(6, "a"s);
    assert("Exemplar" == s);
 
    // insert(size_type index, string const& str,
    //        size_type s_index, size_type count)
    s.insert(8, " is an example string."s, 0, 14);
    assert("Exemplar is an example" == s);
 
    // insert(const_iterator pos, char ch)
    s.insert(s.cbegin() + s.find_first_of('n') + 1, ':');
    assert("Exemplar is an: example" == s);
 
    // insert(const_iterator pos, size_type count, char ch)
    s.insert(s.cbegin() + s.find_first_of(':') + 1, 2, '=');
    assert("Exemplar is an:== example" == s);
 
    // insert(const_iterator pos, InputIt first, InputIt last)
    {
        std::string seq = " string";
        s.insert(s.begin() + s.find_last_of('e') + 1,
            std::begin(seq), std::end(seq));
        assert("Exemplar is an:== example string" == s);
    }
 
    // insert(const_iterator pos, std::initializer_list<char>)
    s.insert(s.cbegin() + s.find_first_of('g') + 1, {'.'});
    assert("Exemplar is an:== example string." == s);
}
```
