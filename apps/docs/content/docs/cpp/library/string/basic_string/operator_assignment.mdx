Replaces the contents of the string.

{/* source:cpp-string-basic-string-operator:0002 */}
1. 1) Replaces the contents with a copy of `str`. If `*this` and `str` are the same object, this function has no effect.

{/* source:cpp-string-basic-string-operator:0003 */}
2. 2) Replaces the contents with those of `str` using [*SequenceContainer*](/docs/cpp/library/named_req/SequenceContainer)'s move assignment semantics.

{/* source:cpp-string-basic-string-operator:0004 */}
3. Unlike other sequence container move assignments, references, pointers, and iterators to elements of `str` may be invalidated.

{/* source:cpp-string-basic-string-operator:0005 */}
4. 3) Replaces the contents with those of null-terminated character string pointed to by `s` as if by `assign(s, Traits::length(s))`.

{/* source:cpp-string-basic-string-operator:0006 */}
5. 4) Replaces the contents with character `ch` as if by `assign(std::addressof(ch), 1)`.

{/* source:cpp-string-basic-string-operator:0007 */}
6. 5) Replaces the contents with those of the initializer list `ilist` as if by `assign(ilist.begin(), ilist.size())`.

{/* source:cpp-string-basic-string-operator:0008 */}
7. 6) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then replaces the contents with those of the `sv` as if by `assign(sv)`.

{/* source:cpp-string-basic-string-operator:0009 */}
8. This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-operator:0010 */}
9. 7) `std::basic_string` cannot be assigned from `nullptr`.

{/* source:cpp-string-basic-string-operator:0011 */}

### Return value

`*this`

{/* source:cpp-string-basic-string-operator:0013 */}
### Complexity

1. 1) Linear in size of `str`.

{/* source:cpp-string-basic-string-operator:0014 */}
2. 2) Linear in the size of `*this` (formally, each `CharT` has to be destroyed). If allocators do not compare equal and do not propagate, then also linear in the size of `str` (copy must be made).

{/* source:cpp-string-basic-string-operator:0015 */}
3. 3) Linear in size of `s`.

{/* source:cpp-string-basic-string-operator:0016 */}
4. 4) Constant.

{/* source:cpp-string-basic-string-operator:0017 */}
5. 5) Linear in size of `ilist`.

{/* source:cpp-string-basic-string-operator:0018 */}
6. 6) Linear in size of `t`.

{/* source:cpp-string-basic-string-operator:0019 */}
### Exceptions

1. 2) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification:

   ```cpp
   noexcept(std::allocator_traits<Allocator>::
                propagate_on_container_move_assignment::value ||
   
            std::allocator_traits<Allocator>::is_always_equal::value)
   ```

{/* source:cpp-string-basic-string-operator:0020 */}
If the operation would cause [`size()`](/docs/cpp/library/string/basic_string/size) to exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size), throws [`std::length_error`](/docs/cpp/library/error/length_error).

{/* source:cpp-string-basic-string-operator:0021 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

{/* source:cpp-string-basic-string-operator:0022 */}
### Example

```cpp
#include <iomanip>
#include <iostream>
#include <string>
 
int main()
{
    std::string str1;
    std::string str2{"alpha"};
 
    // (1) operator=(const basic_string&);
    str1 = str2;
    std::cout << std::quoted(str1) << ' '   // "alpha"
              << std::quoted(str2) << '\n'; // "alpha"
 
    // (2) operator=(basic_string&&);
    str1 = std::move(str2);
    std::cout << std::quoted(str1) << ' '   // "alpha"
              << std::quoted(str2) << '\n'; // "" or "alpha" (unspecified)
 
    // (3) operator=(const CharT*);
    str1 = "beta";
    std::cout << std::quoted(str1) << '\n'; // "beta"
 
    // (4) operator=(CharT);
    str1 = '!'; 
    std::cout << std::quoted(str1) << '\n'; // "!"
 
    // (5) operator=(std::initializer_list<CharT>);
    str1 = {'g', 'a', 'm', 'm', 'a'};
    std::cout << std::quoted(str1) << '\n'; // "gamma"
 
    // (6) operator=(const T&);
    str1 = 35U; // equivalent to str1 = static_cast<char>(35U);
    std::cout << std::quoted(str1) << '\n'; // "#" (ASCII = 35)
}
```

Output:

Possible output:

```text
"alpha" "alpha"
"alpha" ""
"beta"
"!"
"gamma"
"#"
```
