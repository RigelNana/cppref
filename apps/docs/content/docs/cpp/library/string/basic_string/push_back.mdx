{/* source:cpp-string-basic-string-push-back:0001 */}
Appends the given character `ch` to the end of the string.

### Parameters

{/* source:cpp-string-basic-string-push-back:0002 */}
<ParameterList>
  <Parameter name="ch">the character to append</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-push-back:0003 */}
(none)

### Complexity

{/* source:cpp-string-basic-string-push-back:0004 */}
Amortized constant.

### Exceptions

{/* source:cpp-string-basic-string-push-back:0005 */}
If the operation would cause [`size()`](/docs/cpp/library/string/basic_string/size) to exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size), throws [`std::length_error`](/docs/cpp/library/error/length_error).

{/* source:cpp-string-basic-string-push-back:0006 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-push-back:0007 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string>
 
int main()
{
    std::string str{"Short string"};
    std::cout << "1) " << std::quoted(str) << ", size: " << str.size() << '\n';
 
    str.push_back('!');
    std::cout << "2) " << std::quoted(str) << ", size: " << str.size() << '\n';
}
```

Output:

```text
1) "Short string", size: 12
2) "Short string!", size: 13
```
