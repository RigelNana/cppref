{/* source:cpp-string-basic-string-basic-string:0001 */}
Constructs new string from a variety of data sources and optionally using user supplied allocator `alloc`.

1. {/* source:cpp-string-basic-string-basic-string:0002 */}1) The default constructor since C++11. Constructs an empty string with a default-constructed allocator.
2. {/* source:cpp-string-basic-string-basic-string:0003 */}If `Allocator` is not [*DefaultConstructible*](/docs/cpp/library/named_req/DefaultConstructible), the behavior is undefined.
3. {/* source:cpp-string-basic-string-basic-string:0004 */}2) The default constructor until C++11. Constructs an empty string with the given allocator `alloc`.
4. {/* source:cpp-string-basic-string-basic-string:0005 */}3) Constructs a string with `count` copies of character `ch`.

   <Revision since="C++11">
   If `CharT` is not [*CopyInsertable*](/docs/cpp/library/named_req/CopyInsertable) into `std::basic_string<CharT>`, the behavior is undefined.
   </Revision>

   <Revision since="C++17">
   This overload participates in overload resolution only if `Allocator` satisfies the requirements of [*Allocator*](/docs/cpp/library/named_req/Allocator).
   </Revision>

5. {/* source:cpp-string-basic-string-basic-string:0006 */}4) Constructs a string with the contents of the range [`first`, `last`). Each iterator in [`first`, `last`) is dereferenced exactly once.

   <Revision until="C++11">
   If `InputIt` does not satisfy the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator), overload (3) is called instead with arguments `static_cast<size_type>(first)`, `last` and `alloc`.
   </Revision>

   <Revision since="C++11">
   This overload participates in overload resolution only if `InputIt` satisfies the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).

   If `CharT` is not [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `std::basic_string<CharT>` from `*first`, the behavior is undefined.
   </Revision>

6. {/* source:cpp-string-basic-string-basic-string:0007 */}5) Constructs a string with the contents of the range `rg`. Each iterator in `rg` is dereferenced exactly once.
7. {/* source:cpp-string-basic-string-basic-string:0008 */}If `CharT` is not [*EmplaceConstructible*](/docs/cpp/library/named_req/EmplaceConstructible) into `std::basic_string<CharT>` from `*ranges::begin(rg)`, the behavior is undefined.
8. {/* source:cpp-string-basic-string-basic-string:0009 */}6) Constructs a string with the contents of the range [`s`, `s + count`).
9. {/* source:cpp-string-basic-string-basic-string:0010 */}If [`s`, `s + count`) is not a valid range, the behavior is undefined.
10. {/* source:cpp-string-basic-string-basic-string:0011 */}7) Equivalent to `basic_string(s, Traits::length(s), alloc)`.

    <Revision since="C++17">
    This overload participates in overload resolution only if `Allocator` satisfies the requirements of [*Allocator*](/docs/cpp/library/named_req/Allocator).
    </Revision>

11. {/* source:cpp-string-basic-string-basic-string:0012 */}8) `std::basic_string` cannot be constructed from `nullptr`.
12. {/* source:cpp-string-basic-string-basic-string:0013 */}9) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then constructs a string as if by `basic_string(sv.data(), sv.size(), alloc)`.
13. {/* source:cpp-string-basic-string-basic-string:0014 */}This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.
14. {/* source:cpp-string-basic-string-basic-string:0015 */}10) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then constructs a string as if by `basic_string(sv.substr(pos, n), alloc)`.
15. {/* source:cpp-string-basic-string-basic-string:0016 */}This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true`.
16. {/* source:cpp-string-basic-string-basic-string:0017 */}11-18) Constructs a string with (part of) the contents of `other`. If the type of `other` is `basic_string&&`, when the construction finishes, `other` is in a valid but unspecified state.
17. {/* source:cpp-string-basic-string-basic-string:0018 */}11) The copy constructor.

    <Revision since="C++11">
    The allocator is obtained as if by calling [`std::allocator_traits<Allocator>::`](/docs/cpp/library/memory/allocator_traits) `select_on_container_copy_construction` `(other.get_allocator())`.
    </Revision>

18. {/* source:cpp-string-basic-string-basic-string:0019 */}12) The move constructor. The allocator is obtained by move construction from `other.get_allocator()`.
19. {/* source:cpp-string-basic-string-basic-string:0020 */}13) Same as the copy constructor, except that `alloc` is used as the allocator.
20. {/* source:cpp-string-basic-string-basic-string:0021 */}If `CharT` is not [*CopyInsertable*](/docs/cpp/library/named_req/CopyInsertable) into `std::basic_string<CharT>`, the behavior is undefined.
21. {/* source:cpp-string-basic-string-basic-string:0022 */}14) Same as the move constructor, except that `alloc` is used as the allocator.
22. {/* source:cpp-string-basic-string-basic-string:0023 */}If `CharT` is not [*MoveInsertable*](/docs/cpp/library/named_req/MoveInsertable) into `std::basic_string<CharT>`, the behavior is undefined.
23. {/* source:cpp-string-basic-string-basic-string:0024 */}15,16) Constructs a string with the contents of the range [`other.data() + pos`, `other.data() + other.size()`).
24. {/* source:cpp-string-basic-string-basic-string:0025 */}17,18) Constructs a string with the contents of the range [`other.data() + pos`, `other.data() + (pos + std::min(count, other.size() - pos))`).
25. {/* source:cpp-string-basic-string-basic-string:0026 */}19) Equivalent to `basic_string(ilist.begin(), ilist.end())`.

### Complexity

1. {/* source:cpp-string-basic-string-basic-string:0028 */}1,2) Constant.
2. {/* source:cpp-string-basic-string-basic-string:0029 */}3-7) Linear in the size of the string.
3. {/* source:cpp-string-basic-string-basic-string:0030 */}9-11) Linear in the size of the string.
4. {/* source:cpp-string-basic-string-basic-string:0031 */}12) Constant.
5. {/* source:cpp-string-basic-string-basic-string:0032 */}13) Linear in the size of the string.
6. {/* source:cpp-string-basic-string-basic-string:0033 */}14) Linear in the size of the string if `alloc != other.get_allocator()` is `true`, otherwise constant.
7. {/* source:cpp-string-basic-string-basic-string:0034 */}15-19) Linear in the size of the string.

### Exceptions

1. {/* source:cpp-string-basic-string-basic-string:0035 */}10) [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos` is out of range.
2. {/* source:cpp-string-basic-string-basic-string:0036 */}14) Throws nothing if `alloc == str.get_allocator()` is `true`.
3. {/* source:cpp-string-basic-string-basic-string:0037 */}15-18) [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos > other.size()` is `true`.

{/* source:cpp-string-basic-string-basic-string:0038 */}
Throws [`std::length_error`](/docs/cpp/library/error/length_error) if the length of the constructed string would exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size) (for example, if `count > max_size()` for (3)). Calls to `Allocator::allocate` may throw.

{/* source:cpp-string-basic-string-basic-string:0039 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Notes

{/* source:cpp-string-basic-string-basic-string:0040 */}
Initialization with a [string literal](/docs/cpp/language/expressions/string_literal) that contains embedded `'\0'` characters uses the overload (7), which stops at the first null character. This can be avoided by specifying a different constructor or by using [`operator""s`](/docs/cpp/library/string/basic_string/operator_q__q_s):

{/* source:cpp-string-basic-string-basic-string:0041 */}
```cpp
std::string s1 = "ab\0\0cd";   // s1 contains "ab"
std::string s2{"ab\0\0cd", 6}; // s2 contains "ab\0\0cd"
std::string s3 = "ab\0\0cd"s;  // s3 contains "ab\0\0cd"
```

### Example

{/* source:cpp-string-basic-string-basic-string:0043 */}
```cpp
#include <cassert>
#include <cctype>
#include <iomanip>
#include <iostream>
#include <iterator>
#include <string>
 
int main()
{
    std::cout << "1)  string(); ";
    std::string s1;
    assert(s1.empty() && (s1.length() == 0) && (s1.size() == 0));
    std::cout << "s1.capacity(): " << s1.capacity() << '\n'; // unspecified
 
    std::cout << "3)  string(size_type count, CharT ch): ";
    std::string s2(4, '=');
    std::cout << std::quoted(s2) << '\n'; // "===="
 
    std::cout << "4)  string(InputIt first, InputIt last): ";
    char mutable_c_str[] = "another C-style string";
    std::string s4(std::begin(mutable_c_str) + 8, std::end(mutable_c_str) - 1);
    std::cout << std::quoted(s4) << '\n'; // "C-style string"
 
    std::cout << "6)  string(CharT const* s, size_type count): ";
    std::string s6("C-style string", 7);
    std::cout << std::quoted(s6) << '\n'; // "C-style", i.e. [0, 7)
 
    std::cout << "7)  string(CharT const* s): ";
    std::string s7("C-style\0string");
    std::cout << std::quoted(s7) << '\n'; // "C-style"
 
    std::cout << "11) string(string&): ";
    std::string const other11("Exemplar");
    std::string s11(other11);
    std::cout << std::quoted(s11) << '\n'; // "Exemplar"
 
    std::cout << "12) string(string&&): ";
    std::string s12(std::string("C++ by ") + std::string("example"));
    std::cout << std::quoted(s12) << '\n'; // "C++ by example"
 
    std::cout << "15) string(const string& other, size_type pos): ";
    std::string const other15("Mutatis Mutandis");
    std::string s15(other15, 8);
    std::cout << std::quoted(s15) << '\n'; // "Mutandis", i.e. [8, 16)
 
    std::cout << "17) string(const string& other, size_type pos, size_type count): ";
    std::string const other17("Exemplary");
    std::string s17(other17, 0, other17.length() - 1);
    std::cout << std::quoted(s17) << '\n'; // "Exemplar"
 
    std::cout << "19) string(std::initializer_list<CharT>): ";
    std::string s19({'C', '-', 's', 't', 'y', 'l', 'e'});
    std::cout << std::quoted(s19) << '\n'; // "C-style"
}
```

Possible output:

```text
1)  string(); s1.capacity(): 15
3)  string(size_type count, CharT ch): "===="
4)  string(InputIt first, InputIt last): "C-style string"
6)  string(CharT const* s, size_type count): "C-style"
7)  string(CharT const* s): "C-style"
11) string(string&): "Exemplar"
12) string(string&&): "C++ by example"
15) string(const string& other, size_type pos): "Mutandis"
17) string(const string& other, size_type pos, size_type count): "Exemplar"
19) string(std::initializer_list<CharT>): "C-style"
```
