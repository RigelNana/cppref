{/* source:cpp-string-basic-string-size:0001 */}
Returns the number of `CharT` elements in the string, i.e. `std::distance(begin(), end())`.

### Parameters

{/* source:cpp-string-basic-string-size:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-size:0003 */}
The number of `CharT` elements in the string.

### Complexity

{/* source:cpp-string-basic-string-size:0004 */}
<Revision until="C++11">Unspecified</Revision>

<Revision since="C++11">Constant</Revision>

### Notes

{/* source:cpp-string-basic-string-size:0005 */}
For [`std::string`](/docs/cpp/library/string/basic_string), the elements are bytes (objects of type `char`), which are not the same as characters if a multibyte encoding such as UTF-8 is used.

### Example

{/* source:cpp-string-basic-string-size:0006 */}
```cpp
#include <cassert>
#include <iterator>
#include <string>
 
int main()
{
    std::string s("Exemplar");
    assert(8 == s.size());
    assert(s.size() == s.length());
    assert(s.size() == static_cast<std::string::size_type>(
        std::distance(s.begin(), s.end())));
 
    std::u32string a(U"ハロー・ワールド"); // 8 code points
    assert(8 == a.size()); // 8 code units in UTF-32
 
    std::u16string b(u"ハロー・ワールド"); // 8 code points
    assert(8 == b.size()); // 8 code units in UTF-16
 
    std::string c("ハロー・ワールド"); // 8 code points
    assert(24 == c.size()); // 24 code units in UTF-8
 
    #if __cpp_lib_char8_t >= 201907L
    std::u8string d(u8"ハロー・ワールド"); // 8 code points
    assert(24 == d.size()); // 24 code units in UTF-8
    #endif
}
```
