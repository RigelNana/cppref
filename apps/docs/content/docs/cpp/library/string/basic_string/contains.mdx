{/* source:cpp-string-basic-string-contains:0001 */}
Checks if the string contains the given substring. The substring may be one of the following:

1. {/* source:cpp-string-basic-string-contains:0002 */}1) A string view `sv` (which may be a result of implicit conversion from another `std::basic_string`).
2. {/* source:cpp-string-basic-string-contains:0003 */}2) A single character `ch`.
3. {/* source:cpp-string-basic-string-contains:0004 */}3) A null-terminated character string `s`.

{/* source:cpp-string-basic-string-contains:0005 */}
All three overloads are equivalent to `return find(x) != npos;`, where `x` is the parameter.

### Parameters

{/* source:cpp-string-basic-string-contains:0006 */}
<ParameterList>
  <Parameter name="sv">a string view which may be a result of implicit conversion from another `std::basic_string`</Parameter>
  <Parameter name="ch">a single character</Parameter>
  <Parameter name="s">a null-terminated character string</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-contains:0007 */}
`true` if the string contains the provided substring, `false` otherwise.

### Example

{/* source:cpp-string-basic-string-contains:0009 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string>
#include <string_view>
#include <type_traits>
 
template<typename SubstrType>
void test_substring(const std::string& str, SubstrType subs)
{
    constexpr char delim = std::is_scalar_v<SubstrType> ? '\'' : '\"';
    std::cout << std::quoted(str)
              << (str.contains(subs) ? " contains "
                                     : " does not contain ")
              << std::quoted(std::string{subs}, delim) << '\n';
}
 
int main()
{
    using namespace std::literals;
 
    auto helloWorld = "hello world"s;
 
    test_substring(helloWorld, "hello"sv);
    test_substring(helloWorld, "goodbye"sv);
    test_substring(helloWorld, 'w');
    test_substring(helloWorld, 'x');
}
```

Output:

```text
"hello world" contains "hello"
"hello world" does not contain "goodbye"
"hello world" contains 'w'
"hello world" does not contain 'x'
```
