{/* source:cpp-string-basic-string-erase2:0001 */}
1) Erases all elements that compare equal to `value` from the container. Equivalent to

```cpp
auto it = std::remove(c.begin(), c.end(), value);
auto r = c.end() - it;
c.erase(it, c.end());
return r;
```

{/* source:cpp-string-basic-string-erase2:0002 */}
2) Erases all elements that satisfy the predicate `pred` from the container. Equivalent to

```cpp
auto it = std::remove_if(c.begin(), c.end(), pred);
auto r = c.end() - it;
c.erase(it, c.end());
return r;
```

### Parameters

{/* source:cpp-string-basic-string-erase2:0003 */}
<ParameterList>
  <Parameter name="c">container from which to erase</Parameter>
  <Parameter name="value">value to be removed</Parameter>
  <Parameter name="pred">unary predicate which returns `true` if the element should be erased.<br />
The expression `pred(v)` must be convertible to `bool` for every argument `v` of type (possibly const) `CharT`, regardless of [value category](/docs/cpp/language/expressions/value_category), and must not modify `v`. Thus, a parameter type of `CharT&`is not allowed<InlineRevision since="C++11">, nor is `CharT` unless for `CharT` a move is equivalent to a copy</InlineRevision>.</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-erase2:0004 */}
The number of erased elements.

### Complexity

{/* source:cpp-string-basic-string-erase2:0005 */}
Linear.

### Example

{/* source:cpp-string-basic-string-erase2:0007 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string>
 
int main()
{
    std::string word{"startling"};
    std::cout << "Initially, word = " << std::quoted(word) << '\n';
 
    std::erase(word, 'l');
    std::cout << "After erase 'l': " << std::quoted(word) << '\n';
 
    auto erased = std::erase_if(word, [](char x)
    {
        return x == 'a' or x == 'r' or x == 't';
    });
 
    std::cout << "After erase all 'a', 'r', and 't': " << std::quoted(word) << '\n';
    std::cout << "Erased symbols count: " << erased << '\n';
 
#if __cpp_lib_algorithm_default_value_type
    std::erase(word, {'g'});
    std::cout << "After erase {'g'}: " << std::quoted(word) << '\n';
#endif
}
```

Possible output:

```text
Initially, word = "startling"
After erase 'l', word = "starting"
After erase all 'a', 'r', and 't': "sing"
Erased symbols count: 4
After erase {'g'}: "sin"
```
