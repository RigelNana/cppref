{/* source:cpp-string-basic-string-operator-at:0001 */}
Returns a reference to the character at specified location `pos` if `pos < size()`, or a reference to `CharT()` if `pos == size()`. No bounds checking is performed.

{/* source:cpp-string-basic-string-operator-at:0002 */}
If `pos > size()`, the behavior is undefined.

{/* source:cpp-string-basic-string-operator-at:0003 */}
For overload (1), if `pos == size()`, the behavior is undefined <InlineRevision since="C++11">if the object referred by the returned reference is modified to any value other than `CharT()`</InlineRevision>.

{/* source:cpp-string-basic-string-operator-at:0004 */}
### Parameters

<ParameterList>
  <Parameter name="pos">position of the character to return</Parameter>
</ParameterList>

{/* source:cpp-string-basic-string-operator-at:0005 */}
### Return value

Reference to the requested element if `pos < size()`, or a reference to `CharT()` if `pos == size()`.

{/* source:cpp-string-basic-string-operator-at:0006 */}
### Complexity

Constant.

{/* source:cpp-string-basic-string-operator-at:0007 */}
### Example

```cpp
#include <iostream>
#include <string>
 
int main()
{
    const std::string e("Exemplar");
    for (unsigned i = e.length() - 1; i != 0; i /= 2)
        std::cout << e[i];
    std::cout << '\n';
 
    const char* c = &e[0];
    std::cout << c << '\n'; // print as a C string
 
    // Change the last character of s into a 'y'
    std::string s("Exemplar ");
    s[s.size() - 1] = 'y'; // equivalent to s.back() = 'y';
    std::cout << s << '\n';
}
```

Output:

```text
rmx
Exemplar
Exemplary
```

### Defect reports

The following behavior-changing defect reports were applied retroactively to previously published C++ standards.

{/* source:cpp-string-basic-string-operator-at:0009 */}
<DefectReportList>
  <DefectReport kind="lwg" id={259} standard="C++98">
    <PublishedBehavior>non-const overload could return const lvalue `data()[pos]`, which was ill-formed</PublishedBehavior>
    <CorrectedBehavior>changed to return<br />`*(begin() + pos)`</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={2475} standard="C++11">
    <PublishedBehavior>if `pos == size()`, the behavior of modifying the object referred by the returned reference was undefined</PublishedBehavior>
    <CorrectedBehavior>well-defined if<br />modified to `CharT()`</CorrectedBehavior>
  </DefectReport>
</DefectReportList>
