{/* source:cpp-string-basic-string-begin:0001 */}
Returns an iterator to the first character of the string.

{/* source:cpp-string-basic-string-begin:0002 */}
`begin()` returns a [mutable](/docs/cpp/library/iterator) or [constant](/docs/cpp/library/iterator) iterator, depending on the constness of `*this`.

{/* source:cpp-string-basic-string-begin:0003 */}
`cbegin()` always returns a [constant](/docs/cpp/library/iterator) iterator. It is equivalent to `const_cast<const basic_string&>(*this).begin()`.

### Parameters

{/* source:cpp-string-basic-string-begin:0004 */}
(none)

### Return value

{/* source:cpp-string-basic-string-begin:0005 */}
Iterator to the first character.

### Complexity

{/* source:cpp-string-basic-string-begin:0006 */}
Constant.

### Notes

{/* source:cpp-string-basic-string-begin:0007 */}
libc++ backports `cbegin()` to C++98 mode.

### Example

{/* source:cpp-string-basic-string-begin:0008 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    std::string s("Exemplar");
    *s.begin() = 'e';
    std::cout << s << '\n';
 
    auto i = s.cbegin();
    std::cout << *i << '\n';
//  *i = 'E'; // error: i is a constant iterator
}
```

Output:

```text
exemplar
e
```
