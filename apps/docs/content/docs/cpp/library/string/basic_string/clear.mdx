{/* source:cpp-string-basic-string-clear:0001 */}
Removes all characters from the string as if by executing `erase(begin(), end())`.

{/* source:cpp-string-basic-string-clear:0002 */}
All pointers, references, and iterators are invalidated.

### Parameters

{/* source:cpp-string-basic-string-clear:0003 */}
(none)

### Return value

{/* source:cpp-string-basic-string-clear:0004 */}
(none)

### Notes

{/* source:cpp-string-basic-string-clear:0005 */}
Unlike for [`std::vector::clear`](/docs/cpp/library/container/vector/clear), the C++ standard does not explicitly require that [capacity](/docs/cpp/library/string/basic_string/capacity) is unchanged by this function, but existing implementations do not change capacity. This means that they do not release the allocated memory (see also [`shrink_to_fit`](/docs/cpp/library/string/basic_string/shrink_to_fit)).

### Complexity

{/* source:cpp-string-basic-string-clear:0006 */}
Linear in the size of the string, although existing implementations operate in constant time.

### Example

{/* source:cpp-string-basic-string-clear:0007 */}
```cpp
#include <cassert>
#include <iostream>
#include <string>
 
int main()
{
    std::string s{"Exemplar"};
    std::string::size_type const capacity = s.capacity();
 
    s.clear();
    assert(s.empty());
    assert(s.size() == 0);
    std::cout << std::boolalpha << (s.capacity() == capacity) << '\n';
}
```

Possible output:

```text
true
```
