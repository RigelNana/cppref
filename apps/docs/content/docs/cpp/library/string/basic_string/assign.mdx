{/* source:cpp-string-basic-string-assign:0001 */}
Replaces the contents of the string.

1. {/* source:cpp-string-basic-string-assign:0002 */}1) Equivalent to `return *this = str;`.
2. {/* source:cpp-string-basic-string-assign:0003 */}2) Equivalent to `return *this = std::move(str);`.
3. {/* source:cpp-string-basic-string-assign:0004 */}3) Replaces the contents with `count` copies of character `ch`.
4. {/* source:cpp-string-basic-string-assign:0005 */}Equivalent to `clear(); resize(n, c); return *this;`.
5. {/* source:cpp-string-basic-string-assign:0006 */}4) Replaces the contents with copies of the characters in the range [`s`, `s + count`).
6. {/* source:cpp-string-basic-string-assign:0007 */}If [`s`, `s + count`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.
7. {/* source:cpp-string-basic-string-assign:0008 */}5) Equivalent to `return assign(s, Traits::length(s));`.
8. {/* source:cpp-string-basic-string-assign:0009 */}6,7) Replaces the contents with characters in a string view `sv` constructed from `t`. If only `t` is provided, replaces the contents with all characters in `sv`. If `pos` is also provided: If `count` is [`npos`](/docs/cpp/library/string/basic_string#Data_members), replaces the contents with all characters in `sv` starting from `pos`. Otherwise, replaces the contents with the `std::min(count, sv.size() - pos)` characters in `sv` starting from `pos`.
9. {/* source:cpp-string-basic-string-assign:0010 */}These overloads participate in overload resolution only if all following conditions are satisfied: `std::is_convertible_v<const SV&, std::basic_string_view<CharT, Traits>>` is `true`. `std::is_convertible_v<const SV&, const CharT*>` is `false`.
10. {/* source:cpp-string-basic-string-assign:0011 */}6) Equivalent to `std::basic_string_view<CharT, Traits> sv = t;` `return assign(sv.data(), sv.size());`.
11. {/* source:cpp-string-basic-string-assign:0012 */}7) Equivalent to `std::basic_string_view<CharT, Traits> sv = t;` `return assign(sv.substr(pos, count));`.
12. {/* source:cpp-string-basic-string-assign:0013 */}8) Replaces the contents with characters in `str`. If `count` is [`npos`](/docs/cpp/library/string/basic_string#Data_members), replaces the contents with all characters in `str` starting from `pos`. Otherwise, replaces the contents with the `std::min(count, str.size() - pos)` characters in `str` starting from `pos`.

    {/* source:cpp-string-basic-string-assign:0014 */}
    <Revision since="C++20">
    Equivalent to `return assign(std::basic_string_view<CharT, Traits>`<br />`(str).substr(pos, count));`.
    </Revision>

13. {/* source:cpp-string-basic-string-assign:0015 */}9) Equivalent to `return assign(basic_string(first, last, get_allocator()));`.

    <Revision since="C++11">
    This overload participates in overload resolution only if `InputIt` satisfies the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
    </Revision>

14. {/* source:cpp-string-basic-string-assign:0016 */}10) Equivalent to `return assign(ilist.begin(), ilist.size());`.

### Exceptions

1. {/* source:cpp-string-basic-string-assign:0019 */}2) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::allocator_traits<Allocator>::propagate_on_container_move_assignment::value || std::allocator_traits<Allocator>::is_always_equal::value)`

{/* source:cpp-string-basic-string-assign:0020 */}
If the operation would cause [`size()`](/docs/cpp/library/string/basic_string/size) to exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size), throws [`std::length_error`](/docs/cpp/library/error/length_error).

2. {/* source:cpp-string-basic-string-assign:0021 */}7) If `pos > sv.size()` is `true`, throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range).
3. {/* source:cpp-string-basic-string-assign:0022 */}8) If `pos > str.size()` is `true`, throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range).

{/* source:cpp-string-basic-string-assign:0023 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-assign:0024 */}
```cpp
#include <iostream>
#include <iterator>
#include <string>
 
int main()
{
    std::string s;
    // assign(size_type count, CharT ch)
    s.assign(4, '=');
    std::cout << s << '\n'; // "===="
 
    std::string const c("Exemplary");
    // assign(const basic_string& str)
    s.assign(c);
    std::cout << c << " == " << s << '\n'; // "Exemplary == Exemplary"
 
    // assign(const basic_string& str, size_type pos, size_type count)
    s.assign(c, 0, c.length() - 1);
    std::cout << s << '\n'; // "Exemplar";
 
    // assign(basic_string&& str)
    s.assign(std::string("C++ by ") + "example");
    std::cout << s << '\n'; // "C++ by example"
 
    // assign(const CharT* s, size_type count)
    s.assign("C-style string", 7);
    std::cout << s << '\n'; // "C-style"
 
    // assign(const CharT* s)
    s.assign("C-style\0string");
    std::cout << s << '\n'; // "C-style"
 
    char mutable_c_str[] = "C-style string";
    // assign(InputIt first, InputIt last)
    s.assign(std::begin(mutable_c_str), std::end(mutable_c_str) - 1);
    std::cout << s << '\n'; // "C-style string"
 
    // assign(std::initializer_list<CharT> ilist)
    s.assign({'C', '-', 's', 't', 'y', 'l', 'e'});
    std::cout << s << '\n'; // "C-style"
}
```

Output:

```text
====
Exemplary == Exemplary
Exemplar
C++ by example
C-style
C-style
C-style string
C-style
```
