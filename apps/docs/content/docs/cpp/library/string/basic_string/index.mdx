{/* source:cpp-string-basic-string:0001 */}
The class template `basic_string` stores and manipulates sequences of [character](/docs/cpp/language/basic_concepts/types#Character_types)-like objects, which are non-array objects of [*TrivialType*](/docs/cpp/library/named_req/TrivialType) and [*StandardLayoutType*](/docs/cpp/library/named_req/StandardLayoutType). The class is dependent neither on the character type nor on the nature of operations on that type. The definitions of the operations are supplied via the `Traits` template parameter - a specialization of [`std::char_traits`](/docs/cpp/library/string/char_traits) or a compatible traits class.

{/* source:cpp-string-basic-string:0002 */}
The elements of a `basic_string` are stored contiguously, that is, for a `basic_string` `s`, `&*(s.begin() + n) == &*s.begin() + n` for any `n` in [`0`, `s.size()`), <InlineRevision since="C++11">, and `*(s.begin() + s.size())` has value `CharT()` (a null terminator)</InlineRevision>; or, equivalently, a pointer to `s[0]` can be passed to functions that expect a pointer to the first element of <InlineRevision until="C++11">an array</InlineRevision><InlineRevision since="C++11">a null-terminated array</InlineRevision> of `CharT`.

{/* source:cpp-string-basic-string:0003 */}
`std::basic_string` satisfies the requirements of [*AllocatorAwareContainer*](/docs/cpp/library/named_req/AllocatorAwareContainer) (except that customized construct/destroy are not used for construction/destruction of elements), [*SequenceContainer*](/docs/cpp/library/named_req/SequenceContainer) and <InlineRevision since="C++17">[*ContiguousContainer*](/docs/cpp/library/named_req/ContiguousContainer)</InlineRevision>.

{/* source:cpp-string-basic-string:0004 */}
If any of `Traits::char_type` and `Allocator::char_type` is different from `CharT`, the program is ill-formed.

{/* source:cpp-string-basic-string:0005 */}
<Revision since="C++20">
Member functions of `std::basic_string` are constexpr: it is possible to create and use `std::string` objects in the evaluation of a constant expression. However, `std::string` objects generally cannot be constexpr, because any dynamically allocated storage must be released in the same evaluation of constant expression.
</Revision>

References, pointers, and iterators referring to the elements of a `basic_string` may be invalidated by any standard library function taking a reference to non-const `basic_string` as an argument, such as [`std::getline`](/docs/cpp/library/string/basic_string/getline), [`std::swap`](/docs/cpp/library/algorithm/swap), or [`operator>>`](/docs/cpp/library/string/basic_string/operator_ltltgtgt), and by calling non-const member functions, except [`operator[]`](/docs/cpp/library/string/basic_string/operator_at), [`at`](/docs/cpp/library/string/basic_string/at), [`data`](/docs/cpp/library/string/basic_string/data), [`front`](/docs/cpp/library/string/basic_string/front), [`back`](/docs/cpp/library/string/basic_string/back), [`begin`](/docs/cpp/library/string/basic_string/begin), [`rbegin`](/docs/cpp/library/string/basic_string/rbegin), [`end`](/docs/cpp/library/string/basic_string/end), and [`rend`](/docs/cpp/library/string/basic_string/rend).

### Notes

{/* source:cpp-string-basic-string:0016 */}
Although it is required that customized construct or destroy is used when constructing or destroying elements of `std::basic_string` until C++23, all implementations only used the default mechanism. The requirement is corrected by [P1072R10](https://wg21.link/P1072R10) to match existing practice.

### Example

{/* source:cpp-string-basic-string:0018 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    using namespace std::literals;
 
    // Creating a string from const char*
    std::string str1 = "hello";
 
    // Creating a string using string literal
    auto str2 = "world"s;
 
    // Concatenating strings
    std::string str3 = str1 + " " + str2;
 
    // Print out the result
    std::cout << str3 << '\n';
 
    std::string::size_type pos = str3.find(" ");
    str1 = str3.substr(pos + 1); // the part after the space
    str2 = str3.substr(0, pos);  // the part till the space
 
    std::cout << str1 << ' ' << str2 << '\n';
 
    // Accessing an element using subscript operator[]
    std::cout << str1[0] << '\n';
    str1[0] = 'W';
    std::cout << str1 << '\n';
}
```

Output:

```text
hello world
world hello
w
World
```
