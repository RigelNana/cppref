{/* source:cpp-string-basic-string-data:0001 */}
Returns a pointer to the underlying array serving as character storage. The pointer is such that the range

{/* source:cpp-string-basic-string-data:0002 */}
<Revision until="C++11">[`data()`, `data() + size()`)</Revision>

<Revision since="C++11">[`data()`, `data() + size()`]</Revision>

{/* source:cpp-string-basic-string-data:0003 */}
is valid and the values in it correspond to the values stored in the string.

{/* source:cpp-string-basic-string-data:0004 */}
<Revision until="C++11">
The returned array is not required to be null-terminated.

If [`empty()`](/docs/cpp/library/string/basic_string/empty) returns `true`, the pointer is a non-null pointer that should not be dereferenced.
</Revision>

<Revision since="C++11">
The returned array is null-terminated, that is, `data()` and [`c_str()`](/docs/cpp/library/string/basic_string/c_str) perform the same function.

If [`empty()`](/docs/cpp/library/string/basic_string/empty) returns `true`, the pointer points to a single null character.
</Revision>

{/* source:cpp-string-basic-string-data:0005 */}
The pointer obtained from `data()` may be invalidated by:

{/* source:cpp-string-basic-string-data:0006 */}
- Passing a non-const reference to the string to any standard library function, or
- Calling non-const member functions on the string, excluding [`operator[]()`](/docs/cpp/library/string/basic_string/operator_at), [`at()`](/docs/cpp/library/string/basic_string/at), [`front()`](/docs/cpp/library/string/basic_string/front), [`back()`](/docs/cpp/library/string/basic_string/back), [`begin()`](/docs/cpp/library/string/basic_string/begin), [`end()`](/docs/cpp/library/string/basic_string/end), [`rbegin()`](/docs/cpp/library/string/basic_string/rbegin), [`rend()`](/docs/cpp/library/string/basic_string/rend).

{/* source:cpp-string-basic-string-data:0007 */}
1) Modifying the character array accessed through the const overload of `data` has undefined behavior.

{/* source:cpp-string-basic-string-data:0008 */}
2) Modifying the past-the-end null terminator stored at `data() + `[`size()`](/docs/cpp/library/string/basic_string/size) to any value other than `CharT()` has undefined behavior.

### Parameters

{/* source:cpp-string-basic-string-data:0009 */}
(none)

### Return value

{/* source:cpp-string-basic-string-data:0010 */}
A pointer to the underlying character storage.

{/* source:cpp-string-basic-string-data:0011 */}
<Revision until="C++11">`data()[i] == operator[](i)` for every `i` in [`0`, `size()`).</Revision>

<Revision since="C++11">`data() + i == std::addressof(operator[](i))` for every `i` in [`0`, `size()`].</Revision>

### Complexity

{/* source:cpp-string-basic-string-data:0012 */}
Constant.

### Example

{/* source:cpp-string-basic-string-data:0013 */}
```cpp
#include <algorithm>
#include <cassert>
#include <cstring>
#include <string>
 
int main()
{
    std::string const s("Emplary");
    assert(s.size() == std::strlen(s.data()));
    assert(std::equal(s.begin(), s.end(), s.data()));
    assert(std::equal(s.data(), s.data() + s.size(), s.begin()));
    assert('\0' == *(s.data() + s.size()));
}
```
