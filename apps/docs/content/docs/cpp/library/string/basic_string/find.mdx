{/* source:cpp-string-basic-string-find:0001 */}
Finds the first substring equal to the given character sequence. Search begins at `pos`, i.e. the found substring must not begin in a position preceding `pos`.

{/* source:cpp-string-basic-string-find:0002 */}
1) Finds the first substring equal to `str`.

{/* source:cpp-string-basic-string-find:0003 */}
2) Finds the first substring equal to the range [`s`, `s + count`). This range may contain null characters.

{/* source:cpp-string-basic-string-find:0004 */}
If [`s`, `s + count`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find:0005 */}
3) Finds the first substring equal to the character string pointed to by `s`. The length of the string is determined by the first null character using `Traits::length(s)`.

{/* source:cpp-string-basic-string-find:0006 */}
If [`s`, `s + Traits::length(s)`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find:0007 */}
4) Finds the first character `ch` (treated as a single-character substring by the formal rules below).

{/* source:cpp-string-basic-string-find:0008 */}
5) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then finds the first substring equal to `sv`.

{/* source:cpp-string-basic-string-find:0009 */}
This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-find:0010 */}
Formally, a substring `str` is said to be *found* at position `xpos` if all of the following are `true`:

{/* source:cpp-string-basic-string-find:0011 */}
- `xpos >= pos`
- `xpos + str.size() <= size()`
- for all positions `n` in `str`, `Traits::eq(at(xpos + n), str.at(n))`.

{/* source:cpp-string-basic-string-find:0012 */}
In particular, this implies that

{/* source:cpp-string-basic-string-find:0013 */}
- a substring can be found only if `pos <= size() - str.size()`
- an empty substring is found at `pos` if and only if `pos <= size()`
- for a non-empty substring, if `pos >= size()`, the function always returns [`npos`](/docs/cpp/library/string/basic_string/npos).

### Return value

{/* source:cpp-string-basic-string-find:0015 */}
Position of the first character of the found substring or [`npos`](/docs/cpp/library/string/basic_string/npos) if no such substring is found.

### Exceptions

{/* source:cpp-string-basic-string-find:0016 */}
1,4) Throws nothing.

{/* source:cpp-string-basic-string-find:0017 */}
5) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_convertible_v<const T&, std::basic_string_view<CharT, Traits>>)`

{/* source:cpp-string-basic-string-find:0018 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-find:0019 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string>
 
void print(int id, std::string::size_type n, std::string const& s)
{
    std::cout << id << ") ";
    if (std::string::npos == n)
        std::cout << "not found! n == npos\n";
    else
        std::cout << "found @ n = " << n << ", substr(" << n << ") = "
                  << std::quoted(s.substr(n)) << '\n';
}
 
int main()
{
    std::string::size_type n;
    std::string const s = "This is a string"; /*
                             ^  ^  ^
                             1  2  3          */
 
    // search from beginning of string
    n = s.find("is");
    print(1, n, s);
 
    // search from position 5
    n = s.find("is", 5);
    print(2, n, s);
 
    // find a single character
    n = s.find('a');
    print(3, n, s);
 
    // find a single character
    n = s.find('q');
    print(4, n, s);
}
```

Output:

```text
1) found @ n = 2, substr(2) = "is is a string"
2) found @ n = 5, substr(5) = "is a string"
3) found @ n = 8, substr(8) = "a string"
4) not found! n == npos
```
