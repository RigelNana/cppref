{/* source:cpp-string-basic-string-pop-back:0001 */}
Removes the last character from the string.

{/* source:cpp-string-basic-string-pop-back:0002 */}
Equivalent to `erase(end() - 1)`. The behavior is undefined if the string is empty.

### Parameters

{/* source:cpp-string-basic-string-pop-back:0003 */}
(none)

### Return value

{/* source:cpp-string-basic-string-pop-back:0004 */}
(none)

### Complexity

{/* source:cpp-string-basic-string-pop-back:0005 */}
Constant.

### Exceptions

{/* source:cpp-string-basic-string-pop-back:0006 */}
Throws nothing.

### Notes

{/* source:cpp-string-basic-string-pop-back:0007 */}
In libstdc++, `pop_back()` is [not available](https://gcc.gnu.org/onlinedocs/libstdc++/manual/strings.html#strings.string.shrink) in C++98 mode.

### Example

{/* source:cpp-string-basic-string-pop-back:0008 */}
```cpp
#include <cassert>
#include <iomanip>
#include <iostream>
#include <string>
 
int main()
{
    std::string str("Short string!");
    std::cout << "Before: " << std::quoted(str) << '\n';
    assert(str.size() == 13);
 
    str.pop_back();
    std::cout << "After:  " << std::quoted(str) << '\n';
    assert(str.size() == 12);
 
    str.clear();
//  str.pop_back(); // undefined behavior
}
```

Output:

```text
Before: "Short string!"
After:  "Short string"
```
