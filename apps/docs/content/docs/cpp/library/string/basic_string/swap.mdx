{/* source:cpp-string-basic-string-swap:0001 */}
Exchanges the contents of the string with those of `other`. All iterators and references may be invalidated.

{/* source:cpp-string-basic-string-swap:0002 */}
<Revision since="C++11">
If `std::allocator_traits<Allocator>::propagate_on_container_swap::value && get_allocator() == s.get_allocator()` is `false`, the behavior is undefined.
</Revision>

### Parameters

{/* source:cpp-string-basic-string-swap:0003 */}
<ParameterList>
  <Parameter name="other">string to exchange the contents with</Parameter>
</ParameterList>

### Complexity

{/* source:cpp-string-basic-string-swap:0004 */}
Constant.

### Exceptions

{/* source:cpp-string-basic-string-swap:0005 */}
<Revision until="C++11">
No exception is thrown.
</Revision>

<Revision since="C++11">
No exception is thrown, unless the behavior is undefined.

If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).
</Revision>

{/* source:cpp-string-basic-string-swap:0006 */}
<Revision since="C++17">
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::allocator_traits<Allocator>::propagate_on_container_swap::value ||
         std::allocator_traits<Allocator>::is_always_equal::value)`
</Revision>

### Example

{/* source:cpp-string-basic-string-swap:0007 */}
```cpp
#include <iostream>
#include <string>
 
int main() 
{
    std::string a = "AAA";
    std::string b = "BBBB";
 
    std::cout << "Before swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << "\n\n";
 
    a.swap(b);
 
    std::cout << "After swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << '\n';
}
```

Output:

```text
Before swap:
a = AAA
b = BBBB
 
After swap:
a = BBBB
b = AAA
```
