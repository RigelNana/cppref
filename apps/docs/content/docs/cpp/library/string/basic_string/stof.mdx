{/* source:cpp-string-basic-string-stof:0001 */}
Interprets a floating point value in a string `str`.

{/* source:cpp-string-basic-string-stof:0002 */}
Let `ptr` be an internal (to the conversion functions) pointer of type `char*` (1,3,5) or `wchar_t*` (2,4,6), accordingly.

{/* source:cpp-string-basic-string-stof:0003 */}
1. 1) Calls `std::strtof(str.c_str(), &ptr)`.

{/* source:cpp-string-basic-string-stof:0004 */}
2. 2) Calls `std::wcstof(str.c_str(), &ptr)`.

{/* source:cpp-string-basic-string-stof:0005 */}
3. 3) Calls `std::strtod(str.c_str(), &ptr)`.

{/* source:cpp-string-basic-string-stof:0006 */}
4. 4) Calls `std::wcstod(str.c_str(), &ptr)`.

{/* source:cpp-string-basic-string-stof:0007 */}
5. 5) Calls `std::strtold(str.c_str(), &ptr)`.

{/* source:cpp-string-basic-string-stof:0008 */}
6. 6) Calls `std::wcstold(str.c_str(), &ptr)`.

{/* source:cpp-string-basic-string-stof:0009 */}
Function discards any whitespace characters (as determined by `std::isspace`) until first non-whitespace character is found. Then it takes as many characters as possible to form a valid floating-point representation and converts them to a floating-point value. The valid floating-point value can be one of the following:

{/* source:cpp-string-basic-string-stof:0010 */}
- decimal floating-point expression. It consists of the following parts:
  {/* source:cpp-string-basic-string-stof:0011 */}
  - (optional) plus or minus sign
  - nonempty sequence of decimal digits optionally containing decimal-point character (as determined by the current C [locale](/docs/cpp/library/text/locale/setlocale)) (defines significand)
  - (optional) `e` or `E` followed with optional minus or plus sign and nonempty sequence of decimal digits (defines exponent to base 10)

{/* source:cpp-string-basic-string-stof:0012 */}
- hexadecimal floating-point expression. It consists of the following parts:
  {/* source:cpp-string-basic-string-stof:0013 */}
  - (optional) plus or minus sign
  - `0x` or `0X` nonempty sequence of hexadecimal digits optionally containing a decimal-point character (as determined by the current C [locale](/docs/cpp/library/text/locale/setlocale)) (defines significand)
  - (optional) `p` or `P` followed with optional minus or plus sign and nonempty sequence of decimal digits (defines exponent to base 2)

{/* source:cpp-string-basic-string-stof:0014 */}
- infinity expression. It consists of the following parts:
  {/* source:cpp-string-basic-string-stof:0015 */}
  - (optional) plus or minus sign
  - `INF` or `INFINITY` ignoring case

{/* source:cpp-string-basic-string-stof:0016 */}
- not-a-number expression. It consists of the following parts:
  {/* source:cpp-string-basic-string-stof:0017 */}
  - (optional) plus or minus sign
  - `NAN` or `NAN( char_sequence )` ignoring case of the `NAN` part. `char_sequence` can only contain digits, Latin letters, and underscores. The result is a quiet NaN floating-point value.

{/* source:cpp-string-basic-string-stof:0018 */}
- any other expression that may be accepted by the currently installed C [locale](/docs/cpp/library/text/locale/setlocale)

{/* source:cpp-string-basic-string-stof:0019 */}
If `pos` is not a null pointer, then `ptr` will receive the address of the first unconverted character in `str.c_str()`, and the index of that character will be calculated and stored in `*pos`, giving the number of characters that were processed by the conversion.

### Parameters

{/* source:cpp-string-basic-string-stof:0020 */}
<ParameterList>
  <Parameter name="str">the string to convert</Parameter>

### Return value

{/* source:cpp-string-basic-string-stof:0021 */}
The string converted to the specified floating point type.

### Exceptions

{/* source:cpp-string-basic-string-stof:0022 */}
[`std::invalid_argument`](/docs/cpp/library/error/invalid_argument) if no conversion could be performed.

{/* source:cpp-string-basic-string-stof:0023 */}
[`std::out_of_range`](/docs/cpp/library/error/out_of_range) if the converted value would fall out of the range of the result type or if the underlying function ([`std::strtof`](/docs/cpp/library/text/byte/strtof), [`std::strtod`](/docs/cpp/library/text/byte/strtof) or [`std::strtold`](/docs/cpp/library/text/byte/strtof)) sets [`errno`](/docs/cpp/library/error/errno) to [`ERANGE`](/docs/cpp/library/error/errno_macros).
