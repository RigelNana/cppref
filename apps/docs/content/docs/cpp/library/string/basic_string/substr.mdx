{/* source:cpp-string-basic-string-substr:0001 */}
Returns a substring `[pos, pos + count)`. If the requested substring extends past the end of the string, i.e. the `count` is greater than `size() - pos` (e.g. if `count == npos`), the returned substring is `[pos, size())`.

{/* source:cpp-string-basic-string-substr:0002 */}
1. 1) Equivalent to `return basic_string(*this, pos, count);`.

{/* source:cpp-string-basic-string-substr:0003 */}
2. 2) Equivalent to `return basic_string(std::move(*this), pos, count);`.

### Parameters

{/* source:cpp-string-basic-string-substr:0004 */}
<ParameterList>
  <Parameter name="pos">position of the first character to include</Parameter>
  <Parameter name="count">length of the substring</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-substr:0005 */}
String containing the substring `[pos, pos + count)` or `[pos, size())`.

### Exceptions

{/* source:cpp-string-basic-string-substr:0006 */}
[`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos > size()`.

{/* source:cpp-string-basic-string-substr:0007 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-string-basic-string-substr:0008 */}
Linear in `count`.

### Notes

{/* source:cpp-string-basic-string-substr:0009 */}
The allocator of the returned string is default-constructed: the new allocator might not be a copy of [`get_allocator()`](/docs/cpp/library/string/basic_string/get_allocator).

### Example

{/* source:cpp-string-basic-string-substr:0010 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    std::string a = "0123456789abcdefghij";
 
    // count is npos, returns [pos, size())
    std::string sub1 = a.substr(10);
    std::cout << sub1 << '\n';
 
    // both pos and pos + count are within bounds, returns [pos, pos + count)
    std::string sub2 = a.substr(5, 3);
    std::cout << sub2 << '\n';
 
    // pos is within bounds, pos + count is not, returns [pos, size())
    std::string sub4 = a.substr(a.size() - 3, 50);
    // this is effectively equivalent to
    // std::string sub4 = a.substr(17, 3);
    // since a.size() == 20, pos == a.size() - 3 == 17, and a.size() - pos == 3
 
    std::cout << sub4 << '\n';
 
    try
    {
        // pos is out of bounds, throws
        std::string sub5 = a.substr(a.size() + 3, 50);
        std::cout << sub5 << '\n';
    }
    catch (const std::out_of_range& ex)
    {
        std::cout << ex.what() << '\n';
    }
}
```

Possible output:

```text
abcdefghij
567
hij
basic_string::substr: __pos (which is 23) > this->size() (which is 20)
```
