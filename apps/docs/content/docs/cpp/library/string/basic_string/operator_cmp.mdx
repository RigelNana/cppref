Compares the contents of a string with another string or a null-terminated array of `CharT`.

{/* source:cpp-string-basic-string-operator-cmp:0002 */}
All comparisons are done via the [`compare()`](/docs/cpp/library/string/basic_string/compare) member function (which itself is defined in terms of `Traits::compare()`):

{/* source:cpp-string-basic-string-operator-cmp:0003 */}
- Two strings are equal if both the size of `lhs` and `rhs` are equal and each character in `lhs` has equivalent character in `rhs` at the same position.

{/* source:cpp-string-basic-string-operator-cmp:0004 */}
- The ordering comparisons are done lexicographically – the comparison is performed by a function equivalent to [`std::lexicographical_compare`](/docs/cpp/library/algorithm/lexicographical_compare) <InlineRevision since="C++20">or [`std::lexicographical_compare_three_way`](/docs/cpp/library/algorithm/lexicographical_compare_three_way)</InlineRevision>.

{/* source:cpp-string-basic-string-operator-cmp:0005 */}
1. 1-7) Compares two `basic_string` objects.

{/* source:cpp-string-basic-string-operator-cmp:0006 */}
2. 8-20) Compares a `basic_string` object and a null-terminated array of `CharT`.

{/* source:cpp-string-basic-string-operator-cmp:0007 */}
<Revision since="C++20">
The return type of three-way comparison operators (`/*comp-cat*/`) is `Traits::comparison_category` if that qualified-id exists and denotes a type, `std::weak_ordering` otherwise. If `/*comp-cat*/` is not a comparison category type, the program is ill-formed. The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Return value

1. 1-6,8-19) `true` if the corresponding comparison holds, `false` otherwise.

{/* source:cpp-string-basic-string-operator-cmp:0010 */}
2. 7,20) `static_cast</*comp-cat*/>(lhs.compare(rhs) <=> 0)`.

{/* source:cpp-string-basic-string-operator-cmp:0011 */}
### Complexity

Linear in the size of the strings.

{/* source:cpp-string-basic-string-operator-cmp:0012 */}
### Notes

<Revision since="C++20">
If at least one parameter is of type [`std::string`](/docs/cpp/library/string/basic_string), [`std::wstring`](/docs/cpp/library/string/basic_string), [`std::u8string`](/docs/cpp/library/string/basic_string), [`std::u16string`](/docs/cpp/library/string/basic_string), or [`std::u32string`](/docs/cpp/library/string/basic_string), the return type of `operator<=>` is `std::strong_ordering`.
</Revision>
