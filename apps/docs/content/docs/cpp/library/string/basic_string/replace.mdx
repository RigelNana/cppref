{/* source:cpp-string-basic-string-replace:0001 */}
Replaces the characters in the range [`begin() + pos`, `begin() + std::min(pos + count, size())`) or [`first`, `last`) with given characters.

{/* source:cpp-string-basic-string-replace:0002 */}
1. 1,2) Those characters are replaced with `str`.

{/* source:cpp-string-basic-string-replace:0003 */}
2. 3) Those characters are replaced with a substring [`pos2`, `std::min(pos2 + count2, str.size())`) of `str`.

{/* source:cpp-string-basic-string-replace:0004 */}
3. 4,5) Those characters are replaced with the characters in the range [`cstr`, `cstr + count2`).

{/* source:cpp-string-basic-string-replace:0005 */}
4. If [`cstr`, `cstr + count2`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-replace:0006 */}
5. 6,7) Those characters are replaced with the characters in the range [`cstr`, `cstr + Traits::length(cstr)`).

{/* source:cpp-string-basic-string-replace:0007 */}
6. 8,9) Those characters are replaced with `count2` copies of `ch`.

{/* source:cpp-string-basic-string-replace:0008 */}
7. 10) Those characters are replaced with the characters in the range [`first2`, `last2`) as if by `replace(first, last, basic_string(first2, last2, get_allocator()))`.

{/* source:cpp-string-basic-string-replace:0009 */}
8. 11) Those characters are replaced with the characters in `ilist`.

{/* source:cpp-string-basic-string-replace:0010 */}
9. 12,13) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then those characters are replaced with the characters from `sv`.

{/* source:cpp-string-basic-string-replace:0011 */}
10. These overloads participate in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-replace:0012 */}
11. 14) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then those characters are replaced with the characters from the subview `sv.substr(pos2, count2)`.

{/* source:cpp-string-basic-string-replace:0013 */}
12. This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-replace:0014 */}
13. If [`begin()`, `first`) or [`first`, `last`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

### Return value

{/* source:cpp-string-basic-string-replace:0016 */}
`*this`.

### Exceptions

{/* source:cpp-string-basic-string-replace:0017 */}
1) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos > size()`.

{/* source:cpp-string-basic-string-replace:0018 */}
3) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos > size()` or `pos2 > str.size()`.

{/* source:cpp-string-basic-string-replace:0019 */}
4,6,8) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos > size()`.

{/* source:cpp-string-basic-string-replace:0020 */}
12,14) Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos > size()`.

{/* source:cpp-string-basic-string-replace:0021 */}
If the operation would cause [`size()`](/docs/cpp/library/string/basic_string/size) to exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size), throws [`std::length_error`](/docs/cpp/library/error/length_error).

{/* source:cpp-string-basic-string-replace:0022 */}
If an exception is thrown for any reason, these functions have no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).
