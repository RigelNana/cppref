  (constexpr since C++20)

{/* source:cpp-string-basic-string-copy:0001 */}
Copies a substring [`pos`, `pos + count`) to character string pointed to by `dest`. If the requested substring lasts past the end of the string, or if `count == npos`, the copied substring is [`pos`, [`size()`](/docs/cpp/library/string/basic_string/size)).

{/* source:cpp-string-basic-string-copy:0002 */}
The resulting character string is not null-terminated.

### Parameters

{/* source:cpp-string-basic-string-copy:0003 */}
<ParameterList>
  <Parameter name="dest">pointer to the destination character string</Parameter>
  <Parameter name="count">length of the substring</Parameter>
  <Parameter name="pos">position of the first character to include</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-copy:0004 */}
Number of characters copied.

### Exceptions

{/* source:cpp-string-basic-string-copy:0005 */}
[`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos > size()`.

{/* source:cpp-string-basic-string-copy:0006 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Complexity

{/* source:cpp-string-basic-string-copy:0007 */}
Linear in `count`.

### Example

{/* source:cpp-string-basic-string-copy:0008 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    std::string foo("WINE");
 
    // brace-initialization initializes all characters to 0,
    // providing a null-terminator
    char bar[4]{};
 
    // do not copy the last char, to guarantee null-termination
    foo.copy(bar, sizeof bar - 1);
 
    std::cout << bar << '\n'; // requires bar to be null-terminated
}
```

Output:

```text
WIN
```
