{/* source:cpp-string-basic-string-append:0001 */}
Appends additional characters to the string.

1. {/* source:cpp-string-basic-string-append:0002 */}1) Appends `count` copies of character `ch`.
2. {/* source:cpp-string-basic-string-append:0003 */}2) Appends characters in the range [`s`, `s + count`).
3. {/* source:cpp-string-basic-string-append:0004 */}If [`s`, `s + count`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.
4. {/* source:cpp-string-basic-string-append:0005 */}3) Equivalent to `return append(s, Traits::length(s));`.
5. {/* source:cpp-string-basic-string-append:0006 */}4,5) Appends characters in a string view `sv` constructed from `t`. If only `t` is provided, all characters in `sv` are appended. If `pos` is also provided: If `count` is [`npos`](/docs/cpp/library/string/basic_string#Data_members), all characters in `sv` starting from `pos` are appended. Otherwise, the `std::min(count, sv.size() - pos)` characters in `sv` starting from `pos` are appended.
6. {/* source:cpp-string-basic-string-append:0007 */}These overloads participate in overload resolution only if all following conditions are satisfied: `std::is_convertible_v<const SV&, std::basic_string_view<CharT, Traits>>` is `true`. `std::is_convertible_v<const SV&, const CharT*>` is `false`.
7. {/* source:cpp-string-basic-string-append:0008 */}4) Equivalent to `std::basic_string_view<CharT, Traits> sv = t;` `return append(sv.data(), sv.size());`.
8. {/* source:cpp-string-basic-string-append:0009 */}5) Equivalent to `std::basic_string_view<CharT, Traits> sv = t;` `return append(sv.substr(pos, count));`.
9. {/* source:cpp-string-basic-string-append:0010 */}6,7) Appends characters in another string `str`. If only `str` is provided, all characters in it are appended. If `pos` is also provided: If `count` is [`npos`](/docs/cpp/library/string/basic_string#Data_members), all characters in `str` starting from `pos` are appended. Otherwise, the `std::min(count, str.size() - pos)` characters in `str` starting from `pos` are appended.
10. {/* source:cpp-string-basic-string-append:0011 */}6) Equivalent to `return append(str.data(), str.size());`.

    {/* source:cpp-string-basic-string-append:0012 */}
    <Revision since="C++20">
    7) Equivalent to `return append(std::basic_string_view<CharT, Traits>`<br />`(str).substr(pos, count));`.
    </Revision>

11. {/* source:cpp-string-basic-string-append:0013 */}8) Equivalent to `return append(basic_string(first, last, get_allocator()));`.

    <Revision until="C++11">
    This overload has the same effect as overload (1) if `InputIt` is an integral type.
    </Revision>

    <Revision since="C++11">
    This overload participates in overload resolution only if `InputIt` satisfies the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).
    </Revision>

12. {/* source:cpp-string-basic-string-append:0014 */}9) Equivalent to `return append(ilist.begin(), ilist.size());`.

### Return value

{/* source:cpp-string-basic-string-append:0016 */}
`*this`

### Complexity

{/* source:cpp-string-basic-string-append:0017 */}
There are no standard complexity guarantees, typical implementations behave similar to [`std::vector::insert()`](/docs/cpp/library/container/vector/insert).

### Exceptions

{/* source:cpp-string-basic-string-append:0018 */}
If the operation would cause [`size()`](/docs/cpp/library/string/basic_string/size) to exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size), throws [`std::length_error`](/docs/cpp/library/error/length_error).

1. {/* source:cpp-string-basic-string-append:0019 */}5) If `pos > sv.size()` is `true`, throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range).
2. {/* source:cpp-string-basic-string-append:0020 */}7) If `pos > str.size()` is `true`, throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range).

{/* source:cpp-string-basic-string-append:0021 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-append:0022 */}
```cpp
#include <cassert>
#include <string>
 
int main()
{
    std::string str = "std::string";
    const char* cptr = "C-string";
    const char carr[] = "range";
 
    std::string result;
 
    // 1) Append a char 3 times.
    // Note: This is the only overload accepting “CharT”s.
    result.append(3, '*');
    assert(result == "***");
 
    // 2) Append a fixed-length C-string
    result.append(cptr, 5);
    assert(result == "***C-str");
 
    // 3) Append a null-terminated C-string
    // Note: Because “append” returns *this, we can chain calls together.
    result.append(1, ' ').append(cptr);
    assert(result == "***C-str C-string");
 
    // 6) Append a whole string
    result.append(1, ' ').append(str);
    assert(result == "***C-str C-string std::string");
 
    // 7) Append part of a string
    result.append(str, 3, 2);
    assert(result == "***C-str C-string std::string::");
 
    // 8) Append range
    result.append(&carr[2], &carr[3]);
    assert(result == "***C-str C-string std::string::n");
 
    // 9) Append initializer list
    result.append({'p', 'o', 's'});
    assert(result == "***C-str C-string std::string::npos");
}
```
