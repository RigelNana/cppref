The template specializations of [`std::hash`](/docs/cpp/library/utility/hash) for the various string classes allow users to obtain hashes of strings.

{/* source:cpp-string-basic-string-hash:0002 */}
<Revision since="C++17">
These hashes equal the hashes of corresponding [`std::basic_string_view`](/docs/cpp/library/string/basic_string_view) classes: If `S` is one of these string types, `SV` is the corresponding string view type, and `s` is an object of type `S`, then `std::hash<S>()(s) == std::hash<SV>()(SV(s))`.
</Revision>

{/* source:cpp-string-basic-string-hash:0003 */}
### Example

The following code shows one possible output of a hash function used on a string:

```cpp
#include <functional>
#include <iostream>
#include <memory_resource>
#include <string>
#include <string_view>
using namespace std::literals;
 
int main()
{
    auto sv = "Stand back! I've got jimmies!"sv;
    std::string s(sv);
    std::pmr::string pmrs(sv); // use default allocator
 
    std::cout << std::hash<std::string_view>{}(sv) << '\n';
    std::cout << std::hash<std::string>{}(s) << '\n';
    std::cout << std::hash<std::pmr::string>{}(pmrs) << '\n';
}
```

Possible output:

```text
3544599705012401047
3544599705012401047
3544599705012401047
```
