Appends additional characters to the string.

{/* source:cpp-string-basic-string-operator:0002 */}
1. 1) Appends string `str`.

{/* source:cpp-string-basic-string-operator:0003 */}
2. 2) Appends character `ch`.

{/* source:cpp-string-basic-string-operator:0004 */}
3. 3) Appends the null-terminated character string pointed to by `s`.

{/* source:cpp-string-basic-string-operator:0005 */}
4. 4) Appends characters in the initializer list `ilist`.

{/* source:cpp-string-basic-string-operator:0006 */}
5. 5) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then appends characters in the string view `sv` as if by `append(sv)`.

{/* source:cpp-string-basic-string-operator:0007 */}
6. This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-operator:0008 */}

### Return value

`*this`

{/* source:cpp-string-basic-string-operator:0010 */}
### Complexity

There are no standard complexity guarantees, typical implementations behave similar to [`std::vector::insert()`](/docs/cpp/library/container/vector/insert).

{/* source:cpp-string-basic-string-operator:0011 */}
### Exceptions

If the operation would cause [`size()`](/docs/cpp/library/string/basic_string/size) to exceed [`max_size()`](/docs/cpp/library/string/basic_string/max_size), throws [`std::length_error`](/docs/cpp/library/error/length_error).

{/* source:cpp-string-basic-string-operator:0012 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

{/* source:cpp-string-basic-string-operator:0013 */}
### Notes

Overload (2) can accept any types that are implicitly convertible to `CharT`. For `std::string`, where `CharT` is `char`, the set of acceptable types includes all arithmetic types. This may have unintended effects.

{/* source:cpp-string-basic-string-operator:0014 */}
### Example

```cpp
#include <iomanip>
#include <iostream>
#include <string>
 
int main()
{
    std::string str;
 
    // reserve sufficient storage space to avoid memory reallocation
    str.reserve(50);
 
    std::cout << std::quoted(str) << '\n'; // empty string
 
    str += "This";
    std::cout << std::quoted(str) << '\n';
 
    str += std::string(" is ");
    std::cout << std::quoted(str) << '\n';
 
    str += 'a';
    std::cout << std::quoted(str) << '\n';
 
    str += {' ', 's', 't', 'r', 'i', 'n', 'g', '.'};
    std::cout << std::quoted(str) << '\n';
 
    str += 69.96; // Equivalent to str += static_cast<char>(69.96);
                  // 'E' (ASCII code 69) is appended by overload (2),
                  // which might not be the intent.
 
    // To add a numeric value, consider std::to_string():
    str += std::to_string(1729);
 
    std::cout << std::quoted(str) << '\n';
}
```

Output:

```text
""
"This"
"This is "
"This is a"
"This is a string."
"This is a string.E1729"
```
