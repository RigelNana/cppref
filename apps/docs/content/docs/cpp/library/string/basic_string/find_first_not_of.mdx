{/* source:cpp-string-basic-string-find-first-not-of:0001 */}
Finds the first character equal to none of the characters in the given character sequence. The search considers only the range [`pos`, [`size()`](/docs/cpp/library/string/basic_string/size)). If all characters in the range can be found in the given character sequence, [`npos`](/docs/cpp/library/string/basic_string/npos) will be returned.

{/* source:cpp-string-basic-string-find-first-not-of:0002 */}
1) Finds the first character equal to none of characters in `str`.

{/* source:cpp-string-basic-string-find-first-not-of:0003 */}
2) Finds the first character equal to none of characters in range [`s`, `s + count`). This range can include null characters.

{/* source:cpp-string-basic-string-find-first-not-of:0004 */}
If [`s`, `s + count`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find-first-not-of:0005 */}
3) Finds the first character equal to none of characters in character string pointed to by `s`. The length of the string is determined by the first null character using `Traits::length(s)`.

{/* source:cpp-string-basic-string-find-first-not-of:0006 */}
If [`s`, `s + Traits::length(s)`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find-first-not-of:0007 */}
4) Finds the first character not equal to `ch`.

{/* source:cpp-string-basic-string-find-first-not-of:0008 */}
5) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then finds the first character equal to none of characters in `sv`.

{/* source:cpp-string-basic-string-find-first-not-of:0009 */}
This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-find-first-not-of:0010 */}
In all cases, equality is checked by calling [`Traits::eq`](/docs/cpp/library/string/char_traits/cmp).

### Return value

{/* source:cpp-string-basic-string-find-first-not-of:0012 */}
Position of the found character or [`std::string::npos`](/docs/cpp/library/string/basic_string/npos) if no such character is found.

### Exceptions

{/* source:cpp-string-basic-string-find-first-not-of:0013 */}
1,4) Throws nothing.

{/* source:cpp-string-basic-string-find-first-not-of:0014 */}
5) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_convertible_v<const T&, std::basic_string_view<CharT, Traits>>)`

{/* source:cpp-string-basic-string-find-first-not-of:0015 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-find-first-not-of:0016 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    // Permit uppercase letters, lowercase letters and numbers in macro names
    const char* pattern = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
                          "abcdefghijklmnopqrstuvwxyz"
                          "0123456789";
 
    std::string data = "1) %FIX, 2) %HACK, and 3) %TODO";
    const std::string replacement = "%DONE%";
 
    std::cout << "Before: " << data << '\n';
 
    for (std::string::size_type first{}, last{};
        (first = data.find('%', first)) != std::string::npos;
        first += replacement.size())
    {
        last = data.find_first_not_of(pattern, first + 1);
        if (last == std::string::npos)
            last = data.length();
 
        // Now first at '%' and last is one past end of the found substring
        data.replace(first, last - first, replacement);
    }
 
    std::cout << "After: " << data << '\n';
}
```

Output:

```text
Before: 1) %FIX, 2) %HACK, and 3) %TODO
After: 1) %DONE%, 2) %DONE%, and 3) %DONE%
```
