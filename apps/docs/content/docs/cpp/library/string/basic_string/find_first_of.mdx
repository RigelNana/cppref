{/* source:cpp-string-basic-string-find-first-of:0001 */}
Finds the first character equal to one of the characters in the given character sequence. The search considers only the range [`pos`, [`size()`](/docs/cpp/library/string/basic_string/size)). If none of the characters in the given character sequence is present in the range, [`npos`](/docs/cpp/library/string/basic_string/npos) will be returned.

{/* source:cpp-string-basic-string-find-first-of:0002 */}
1) Finds the first character equal to one of the characters in `str`.

{/* source:cpp-string-basic-string-find-first-of:0003 */}
2) Finds the first character equal to one of the characters in the range [`s`, `s + count`). This range can include null characters.

{/* source:cpp-string-basic-string-find-first-of:0004 */}
If [`s`, `s + count`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find-first-of:0005 */}
3) Finds the first character equal to one of the characters in character string pointed to by `s`. The length of the string is determined by the first null character using `Traits::length(s)`.

{/* source:cpp-string-basic-string-find-first-of:0006 */}
If [`s`, `s + Traits::length(s)`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find-first-of:0007 */}
4) Finds the first character equal to `ch`.

{/* source:cpp-string-basic-string-find-first-of:0008 */}
5) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then finds the first character equal to one of the characters in `sv`.

{/* source:cpp-string-basic-string-find-first-of:0009 */}
This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

### Return value

{/* source:cpp-string-basic-string-find-first-of:0011 */}
Position of the found character or [`npos`](/docs/cpp/library/string/basic_string/npos) if no such character is found.

### Exceptions

{/* source:cpp-string-basic-string-find-first-of:0012 */}
1,4) Throws nothing.

{/* source:cpp-string-basic-string-find-first-of:0013 */}
5) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_convertible_v<const T&, std::basic_string_view<CharT, Traits>>)`

{/* source:cpp-string-basic-string-find-first-of:0014 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Notes

{/* source:cpp-string-basic-string-find-first-of:0015 */}
`Traits::eq()` is used to perform the comparison.

### Example

{/* source:cpp-string-basic-string-find-first-of:0016 */}
```cpp
#include <cassert>
#include <iostream>
#include <string>
#include <string_view>
 
int main()
{
    using namespace std::literals;
    std::string::size_type sz;
 
    // (1)
    sz = "alignas"s.find_first_of("klmn"s);
    //     └────────────────────────┘
    assert(sz == 1);
 
    sz = "alignof"s.find_first_of("wxyz"s);
    // no match
    assert(sz == std::string::npos);
 
    // (2)
    sz = "consteval"s.find_first_of("xyzabc", 0, 3);
    // no match (× are not targets)     ×××
    assert(sz == std::string::npos);
 
    sz = "consteval"s.find_first_of("xyzabc", 0, 6);
    //    └───────────────────────────────┘
    assert(sz == 0);
 
    // (3)
    sz = "decltype"s.find_first_of("xyzabc");
    //      └────────────────────────────┘
    assert(sz == 2);
 
    // (4)
    sz = "co_await"s.find_first_of('a');
    //       └──────────────────────┘
    assert(sz == 3);
 
    // (5)
    sz = "constinit"s.find_first_of("int"sv);
    //      └─────────────────────────┘
    assert(sz == 2);
 
    std::cout << "All tests passed.\n";
}
```

Output:

```text
All tests passed.
```
