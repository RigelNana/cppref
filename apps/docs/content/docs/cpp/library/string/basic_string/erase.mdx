{/* source:cpp-string-basic-string-erase:0001 */}
Removes specified characters from the string.

{/* source:cpp-string-basic-string-erase:0002 */}
1) Removes `std::min(count, size() - index)` characters starting at `index`.

{/* source:cpp-string-basic-string-erase:0003 */}
2) Removes the character at `position`.

{/* source:cpp-string-basic-string-erase:0004 */}
If `position` is not a [dereferenceable iterator](/docs/cpp/library/iterator#Dereferenceability_and_validity) on `*this`, the behavior is undefined.

{/* source:cpp-string-basic-string-erase:0005 */}
3) Removes the characters in the range [`first`, `last`).

{/* source:cpp-string-basic-string-erase:0006 */}
If `first` or `last` is not a [valid iterator](/docs/cpp/library/iterator#Dereferenceability_and_validity) on `*this`, or [`first`, `last`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

### Parameters

{/* source:cpp-string-basic-string-erase:0007 */}
<ParameterList>
  <Parameter name="index">first character to remove</Parameter>
  <Parameter name="count">number of characters to remove</Parameter>
  <Parameter name="position">iterator to the character to remove</Parameter>
  <Parameter name="first, last">range of the characters to remove</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-erase:0008 */}
1) `*this`

{/* source:cpp-string-basic-string-erase:0009 */}
2) Iterator pointing to the character immediately following the character erased, or [`end()`](/docs/cpp/library/string/basic_string/end) if no such character exists.

{/* source:cpp-string-basic-string-erase:0010 */}
3) Iterator pointing to the character `last` pointed to before the erase, or [`end()`](/docs/cpp/library/string/basic_string/end) if no such character exists.

### Exceptions

{/* source:cpp-string-basic-string-erase:0011 */}
1) [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `index > size()`.

{/* source:cpp-string-basic-string-erase:0012 */}
2,3) Throws nothing.

{/* source:cpp-string-basic-string-erase:0013 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-erase:0014 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <string>
 
int main()
{
    std::string s = "This Is An Example";
    std::cout << "1) " << s << '\n';
 
    s.erase(7, 3); // erases " An" using overload (1)
    std::cout << "2) " << s << '\n';
 
    s.erase(std::find(s.begin(), s.end(), ' ')); // erases first ' '; overload (2)
    std::cout << "3) " << s << '\n';
 
    s.erase(s.find(' ')); // trims from ' ' to the end of the string; overload (1)
    std::cout << "4) " << s << '\n';
 
    auto it = std::next(s.begin(), s.find('s')); // obtains iterator to the first 's'
    s.erase(it, std::next(it, 2)); // erases "sI"; overload (3)
    std::cout << "5) " << s << '\n';
}
```

Output:

```text
1) This Is An Example
2) This Is Example
3) ThisIs Example
4) ThisIs
5) This
```
