Specializes the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::basic_string`](/docs/cpp/library/string/basic_string). Swaps the contents of `lhs` and `rhs`.

{/* source:cpp-string-basic-string-swap2:0002 */}
Equivalent to `lhs.swap(rhs)`.

### Parameters

{/* source:cpp-string-basic-string-swap2:0003 */}
<ParameterList>
  <Parameter name="lhs, rhs">strings whose contents to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-swap2:0004 */}
(none)

### Complexity

{/* source:cpp-string-basic-string-swap2:0005 */}
Constant.

### Exceptions

{/* source:cpp-string-basic-string-swap2:0006 */}
<Revision since="C++17">
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(noexcept(lhs.swap(rhs)))`
</Revision>

### Example

{/* source:cpp-string-basic-string-swap2:0007 */}
```cpp
#include <iostream>
#include <string>
 
int main()
{
    std::string a = "AAA";
    std::string b = "BBBB";
 
    std::cout << "Before swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << "\n\n";
 
    std::swap(a, b);
 
    std::cout << "After swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << '\n';
}
```

Output:

```text
Before swap:
a = AAA
b = BBBB
 
After swap:
a = BBBB
b = AAA
```
