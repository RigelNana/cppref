{/* source:cpp-string-basic-string-find-last-not-of:0001 */}
Finds the last character equal to none of the characters in the given character sequence. The search considers only the range [`0`, `pos`]. If all characters in the range can be found in the given character sequence, [`npos`](/docs/cpp/library/string/basic_string/npos) will be returned.

{/* source:cpp-string-basic-string-find-last-not-of:0002 */}
1) Finds the last character equal to none of characters in `str`.

{/* source:cpp-string-basic-string-find-last-not-of:0003 */}
2) Finds the last character equal to none of characters in the range [`s`, `s + count`). This range can include null characters.

{/* source:cpp-string-basic-string-find-last-not-of:0004 */}
If [`s`, `s + count`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find-last-not-of:0005 */}
3) Finds the last character equal to none of characters in character string pointed to by `s`. The length of the string is determined by the first null character using `Traits::length(s)`.

{/* source:cpp-string-basic-string-find-last-not-of:0006 */}
If [`s`, `s + Traits::length(s)`) is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-string-basic-string-find-last-not-of:0007 */}
4) Finds the last character not equal to `ch`.

{/* source:cpp-string-basic-string-find-last-not-of:0008 */}
5) Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then finds the last character equal to none of characters in `sv`.

{/* source:cpp-string-basic-string-find-last-not-of:0009 */}
This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true` and `std::is_convertible_v<const StringViewLike&, const CharT*>` is `false`.

{/* source:cpp-string-basic-string-find-last-not-of:0010 */}
In all cases, equality is checked by calling [`Traits::eq`](/docs/cpp/library/string/char_traits/cmp).

### Return value

{/* source:cpp-string-basic-string-find-last-not-of:0012 */}
Position of the found character or [`npos`](/docs/cpp/library/string/basic_string/npos) if no such character is found.

### Exceptions

{/* source:cpp-string-basic-string-find-last-not-of:0013 */}
1,4) Throws nothing.

{/* source:cpp-string-basic-string-find-last-not-of:0014 */}
5) [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_convertible_v<
    const T&, std::basic_string_view<CharT, Traits>>)`

{/* source:cpp-string-basic-string-find-last-not-of:0015 */}
If an exception is thrown for any reason, this function has no effect ([strong exception safety guarantee](/docs/cpp/language/exceptions#Exception_safety)).

### Example

{/* source:cpp-string-basic-string-find-last-not-of:0016 */}
```cpp
#include <iostream>
#include <string>
 
void show_pos(const std::string& str, std::string::size_type found)
{
    if (found != std::string::npos)
        std::cout << '[' << found << "] = \'" << str[found] << "\'\n";
    else
        std::cout << "not found\n";
}
 
int main()
{
    std::string str{"abc_123"};
    char const* skip_set{"0123456789"};
    std::string::size_type str_last_pos{std::string::npos};
 
    show_pos(str, str.find_last_not_of(skip_set)); // [3] = '_'
 
    str_last_pos = 2;
    show_pos(str, str.find_last_not_of(skip_set, str_last_pos)); // [2] = 'c'
 
    str_last_pos = 2;
    show_pos(str, str.find_last_not_of('c', str_last_pos)); // [1] = 'b'
 
    const char arr[]{'3', '4', '5'};
    show_pos(str, str.find_last_not_of(arr)); // [5] = '2'
 
    str_last_pos = 2;
    std::string::size_type skip_set_size{4};
    show_pos(str, str.find_last_not_of(skip_set,
                                       str_last_pos,
                                       skip_set_size)); // [2] = 'c'
 
    show_pos(str, str.find_last_not_of("abc")); // [6] = '3'
 
    str_last_pos = 2;
    show_pos(str, str.find_last_not_of("abc", str_last_pos)); // not found
}
```

Output:

```text
[3] = '_'
[2] = 'c'
[1] = 'b'
[5] = '2'
[2] = 'c'
[6] = '3'
not found
```
