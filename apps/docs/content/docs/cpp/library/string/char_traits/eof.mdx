{/* source:cpp-string-char-traits-eof:0001 */}
Returns a value not equivalent to any valid value of type `char_type`.

{/* source:cpp-string-char-traits-eof:0002 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::eof`.

### Parameters

{/* source:cpp-string-char-traits-eof:0003 */}
(none)

### Return value

{/* source:cpp-string-char-traits-eof:0004 */}
| `char_type` | `eof()` |
| --- | --- |
| `char` | [`EOF`](/docs/cpp/library/io/c) |
| `wchar_t` | `WEOF` |
| `char8_t` | an implementation-defined constant that cannot appear as a valid UTF-8 code unit |
| `char16_t` | an implementation-defined constant that cannot appear as a valid UTF-16 code unit |
| `char32_t` | an implementation-defined constant that cannot appear as a Unicode code point |

### Complexity

{/* source:cpp-string-char-traits-eof:0005 */}
Constant.
