{/* source:cpp-string-char-traits-find:0001 */}
Searches for character `ch` within the first `count` characters of the sequence pointed to by `ptr`.

{/* source:cpp-string-char-traits-find:0002 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::find`.

### Parameters

{/* source:cpp-string-char-traits-find:0003 */}
<ParameterList>
  <Parameter name="ptr">pointer to a character string to search</Parameter>
  <Parameter name="count">the number of characters to analyze</Parameter>
  <Parameter name="ch">the character to search for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-find:0004 */}
A pointer to the first character in the range specified by [`ptr`, `ptr + count`) that compares equal to `ch`, or a null pointer if not found.

### Complexity

{/* source:cpp-string-char-traits-find:0005 */}
Linear in `count`.
