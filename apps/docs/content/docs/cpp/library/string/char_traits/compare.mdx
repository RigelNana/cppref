{/* source:cpp-string-char-traits-compare:0001 */}
Compares the first `count` characters of the character strings `s1` and `s2`. The comparison is done lexicographically.

{/* source:cpp-string-char-traits-compare:0002 */}
If `count` is zero, strings are considered equal.

{/* source:cpp-string-char-traits-compare:0003 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::compare`.

### Parameters

{/* source:cpp-string-char-traits-compare:0004 */}
<ParameterList>
  <Parameter name="s1, s2">pointers to character strings to compare</Parameter>
  <Parameter name="count">the number of characters to compare from each character string</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-compare:0005 */}
Negative value if `s1` is less than `s2`.

{/* source:cpp-string-char-traits-compare:0006 */}
`0` if `s1` is equal to `s2`.

{/* source:cpp-string-char-traits-compare:0007 */}
Positive value if `s1` is greater than `s2`.

### Complexity

{/* source:cpp-string-char-traits-compare:0008 */}
Linear in `count`.
