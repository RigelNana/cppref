    move( char_type* dest, const char_type* src, std::size_t count );`} />

{/* source:cpp-string-char-traits-move:0001 */}
Copies `count` characters from the character string pointed to by `src` to the character string pointed to by `dest`.

{/* source:cpp-string-char-traits-move:0002 */}
Performs correctly even if the ranges [`src`, `src + count`) and [`dest`, `dest + count`) overlap.

{/* source:cpp-string-char-traits-move:0003 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::move`.

### Parameters

{/* source:cpp-string-char-traits-move:0004 */}
<ParameterList>
  <Parameter name="dest">pointer to a character string to copy to</Parameter>
  <Parameter name="src">pointer to a character string to copy from</Parameter>
  <Parameter name="count">the number of characters to copy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-move:0005 */}
`dest`

### Exceptions

{/* source:cpp-string-char-traits-move:0006 */}
Throws nothing.

### Complexity

{/* source:cpp-string-char-traits-move:0007 */}
Linear in `count`.
