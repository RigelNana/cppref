{/* source:cpp-string-char-traits-to-char-type:0001 */}
Converts `c` to `char_type`. If there is no equivalent `char_type` value (such as when `c` is a copy of the [`eof()`](/docs/cpp/library/string/char_traits/eof) value), the result is unspecified.

{/* source:cpp-string-char-traits-to-char-type:0002 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::to_char_type`.

### Parameters

{/* source:cpp-string-char-traits-to-char-type:0003 */}
<ParameterList>
  <Parameter name="c">value to convert</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-to-char-type:0004 */}
A value equivalent to `c`.

### Complexity

{/* source:cpp-string-char-traits-to-char-type:0005 */}
Constant.
