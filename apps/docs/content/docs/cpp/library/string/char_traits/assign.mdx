<DeclarationDoc>
  <Declaration id="1" language="cpp" code={`static void assign( char_type& c1, const char_type& c2 );`} />
  (noexcept since C++11)
  (constexpr since C++17)

  <Declaration id="2" language="cpp" code={`static char_type* assign( char_type* ptr, std::size_t count, char_type c2 );`} />
  (constexpr since C++20)
</DeclarationDoc>

{/* source:cpp-string-char-traits-assign:0001 */}
1. 1) Assigns `c2` to `c1`, behaves identically to `c1 = c2`.

{/* source:cpp-string-char-traits-assign:0002 */}
2. 2) Assigns `c2` to each character in `count` characters in the character sequence pointed to by `ptr`.

{/* source:cpp-string-char-traits-assign:0003 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::assign`.

### Parameters

{/* source:cpp-string-char-traits-assign:0004 */}
<ParameterList>
  <Parameter name="c1">character to assign to</Parameter>
  <Parameter name="c2">character value to assign</Parameter>
  <Parameter name="ptr">pointer to a character sequence to assign to</Parameter>
  <Parameter name="count">the length of the character sequence</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-assign:0005 */}
1. 1) (none)

{/* source:cpp-string-char-traits-assign:0006 */}
2. 2) `ptr`

### Complexity

{/* source:cpp-string-char-traits-assign:0007 */}
1. 1) Constant.

{/* source:cpp-string-char-traits-assign:0008 */}
2. 2) Linear in `count`.
