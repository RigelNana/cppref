{/* source:cpp-string-char-traits-not-eof:0001 */}
Given `e`, produces a suitable value that is not equivalent to `eof`.

{/* source:cpp-string-char-traits-not-eof:0002 */}
This function is typically used when a value other than `eof` needs to be returned, such as in implementations of [`std::basic_streambuf::overflow()`](/docs/cpp/library/io/basic_streambuf/overflow).

{/* source:cpp-string-char-traits-not-eof:0003 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::not_eof`.

### Parameters

{/* source:cpp-string-char-traits-not-eof:0004 */}
<ParameterList>
  <Parameter name="e">value to analyze</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-not-eof:0005 */}
`e` if `e` and `eof` value are not equivalent, or some other non-eof value otherwise.

### Complexity

{/* source:cpp-string-char-traits-not-eof:0006 */}
Constant.
