{/* source:cpp-string-char-traits-to-int-type:0001 */}
Converts `c` to `int_type`.

{/* source:cpp-string-char-traits-to-int-type:0002 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::to_int_type`.

### Parameters

{/* source:cpp-string-char-traits-to-int-type:0003 */}
<ParameterList>
  <Parameter name="c">value to convert</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-to-int-type:0004 */}
A value equivalent to `c`.

### Complexity

{/* source:cpp-string-char-traits-to-int-type:0005 */}
Constant.

### Notes

{/* source:cpp-string-char-traits-to-int-type:0006 */}
For every valid value of `char_type`, there must be a unique value of `int_type` distinct from [`eof()`](/docs/cpp/library/string/char_traits/eof).
