{/* source:cpp-string-char-traits-length:0001 */}
Returns the length of the character sequence pointed to by `s`, that is, the position of the terminating null character (`char_type()`).

{/* source:cpp-string-char-traits-length:0002 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::length`.

### Parameters

{/* source:cpp-string-char-traits-length:0003 */}
<ParameterList>
  <Parameter name="s">pointer to a character sequence to return length of</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-length:0004 */}
The length of character sequence pointed to by `s`.

### Complexity

{/* source:cpp-string-char-traits-length:0005 */}
Linear.

### Example

{/* source:cpp-string-char-traits-length:0006 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string>
 
void print(const char* str)
{
    std::cout << std::quoted(str) << " has length = "
              << std::char_traits<char>::length(str) << '\n';
}
 
int main()
{
    print("foo");
 
    std::string s{"booo"};
    print(s.c_str());
}
```

Output:

```text
"foo" has length = 3
"booo" has length = 4
```
