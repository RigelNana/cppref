{/* source:cpp-string-char-traits-cmp:0001 */}
Compares two characters.

{/* source:cpp-string-char-traits-cmp:0002 */}
1. 1) Compares `a` and `b` for equality, behaves identically to `static_cast<unsigned char>(a) == static_cast<unsigned char>(b)`, if `char_type` is `char`, `a == b` otherwise.

{/* source:cpp-string-char-traits-cmp:0003 */}
2. 2) Compares `a` and `b` in such a way that they are totally ordered, behaves identically to `static_cast<unsigned char>(a) < static_cast<unsigned char>(b)`, if `char_type` is `char`, `a < b` otherwise.

{/* source:cpp-string-char-traits-cmp:0004 */}
See [CharTraits](/docs/cpp/library/named_req/CharTraits) for the general requirements on character traits for `X::eq` and `X::lt`.

### Parameters

{/* source:cpp-string-char-traits-cmp:0005 */}
<ParameterList>
  <Parameter name="a, b">character values to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-char-traits-cmp:0006 */}
1. 1) `true` if `a` and `b` are equal, `false` otherwise.

{/* source:cpp-string-char-traits-cmp:0007 */}
2. 2) `true` if `a` is less than `b`, `false` otherwise.

### Complexity

{/* source:cpp-string-char-traits-cmp:0008 */}
Constant.

↑ Most implementations call [`std::memcmp()`](/docs/cpp/library/text/byte/memcmp) for efficiency, which interprets the data as arrays of `unsigned char`. If `char` is [signed](/docs/cpp/language/basic_concepts/types#Character_types) on such implementations, `std::char_traits<char>` fails to satisfy the requirements of [CharTraits](/docs/cpp/library/named_req/CharTraits).
