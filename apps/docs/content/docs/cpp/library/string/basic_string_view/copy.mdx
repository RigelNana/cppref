{/* source:cpp-string-basic-string-view-copy:0001 */}
Copies the substring [`pos`, `pos + rcount`) to the character array pointed to by `dest`, where `rcount` is the smaller of `count` and `size() - pos`.

{/* source:cpp-string-basic-string-view-copy:0002 */}
Equivalent to `Traits::copy(dest, data() + pos, rcount)`.

### Parameters

{/* source:cpp-string-basic-string-view-copy:0003 */}
<ParameterList>
  <Parameter name="dest">pointer to the destination character string</Parameter>
  <Parameter name="count">requested substring length</Parameter>
  <Parameter name="pos">position of the first character</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-copy:0004 */}
Number of characters copied.

### Exceptions

{/* source:cpp-string-basic-string-view-copy:0005 */}
[`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos > size()`.

### Complexity

{/* source:cpp-string-basic-string-view-copy:0006 */}
Linear in `rcount`.

### Example

{/* source:cpp-string-basic-string-view-copy:0007 */}
```cpp
#include <array>
#include <cstddef>
#include <iostream>
#include <stdexcept>
#include <string_view>
 
int main()
{
    constexpr std::basic_string_view<char> source{"ABCDEF"};
    std::array<char, 8> dest;
    std::size_t count{}, pos{};
 
    dest.fill('\0');
    source.copy(dest.data(), count = 4); // pos = 0
    std::cout << dest.data() << '\n'; // ABCD
 
    dest.fill('\0');
    source.copy(dest.data(), count = 4, pos = 1);
    std::cout << dest.data() << '\n'; // BCDE
 
    dest.fill('\0');
    source.copy(dest.data(), count = 42, pos = 2); // ok, count -> 4
    std::cout << dest.data() << '\n'; // CDEF
 
    try
    {
        source.copy(dest.data(), count = 1, pos = 666); // throws: pos > size()
    }
    catch (std::out_of_range const& ex)
    {
        std::cout << ex.what() << '\n';
    }
}
```

Output:

```text
ABCD
BCDE
CDEF
basic_string_view::copy: __pos (which is 666) > __size (which is 6)
```
