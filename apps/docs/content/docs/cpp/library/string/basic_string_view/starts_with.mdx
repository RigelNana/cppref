{/* source:cpp-string-basic-string-view-starts-with:0001 */}
Checks if the string view begins with the given prefix, where

{/* source:cpp-string-basic-string-view-starts-with:0002 */}
1. 1) the prefix is a string view. Effectively returns `basic_string_view(data(), std::min(size(), sv.size())) == sv`.

{/* source:cpp-string-basic-string-view-starts-with:0003 */}
2. 2) the prefix is a single character. Effectively returns `!empty() && Traits::eq(front(), ch)`.

{/* source:cpp-string-basic-string-view-starts-with:0004 */}
3. 3) the prefix is a null-terminated character string. Effectively returns `starts_with(basic_string_view(s))`.

### Parameters

{/* source:cpp-string-basic-string-view-starts-with:0005 */}
<ParameterList>
  <Parameter name="sv">a string view which may be a result of implicit conversion from `std::basic_string`</Parameter>
  <Parameter name="ch">a single character</Parameter>
  <Parameter name="s">a null-terminated character string</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-starts-with:0006 */}
`true` if the string view begins with the provided prefix, `false` otherwise.

### Example

{/* source:cpp-string-basic-string-view-starts-with:0008 */}
```cpp
#include <cassert>
#include <string_view>
 
int main()
{
    using namespace std::literals;
 
    assert
    (""
        // (1) starts_with( basic_string_view )
        && "https://cppreference.com"sv.starts_with("http"sv) == true
        && "https://cppreference.com"sv.starts_with("ftp"sv) == false
 
        // (2) starts_with( CharT )
        && "C++20"sv.starts_with('C') == true
        && "C++20"sv.starts_with('J') == false
 
        // (3) starts_with( const CharT* )
        && std::string_view("string_view").starts_with("string") == true
        && std::string_view("string_view").starts_with("String") == false
    );
}
```
