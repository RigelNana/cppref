{/* source:cpp-string-basic-string-view-find:0001 */}
Finds the first substring equal to the given character sequence.

{/* source:cpp-string-basic-string-view-find:0002 */}
1. 1) Finds the first occurence of `v` in this view, starting at position `pos`.

{/* source:cpp-string-basic-string-view-find:0003 */}
2. 2) Equivalent to `find(basic_string_view(std::addressof(ch), 1), pos)`.

{/* source:cpp-string-basic-string-view-find:0004 */}
3. 3) Equivalent to `find(basic_string_view(s, count), pos)`.

{/* source:cpp-string-basic-string-view-find:0005 */}
4. 4) Equivalent to `find(basic_string_view(s), pos)`.

### Parameters

{/* source:cpp-string-basic-string-view-find:0006 */}
<ParameterList>
  <Parameter name="v">view to search for</Parameter>
  <Parameter name="pos">position at which to start the search</Parameter>
  <Parameter name="count">length of substring to search for</Parameter>
  <Parameter name="s">pointer to a character string to search for</Parameter>
  <Parameter name="ch">character to search for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-find:0007 */}
Position of the first character of the found substring, or [`npos`](/docs/cpp/library/string/basic_string_view/npos) if no such substring is found.

### Complexity

{/* source:cpp-string-basic-string-view-find:0008 */}
O([`size()`](/docs/cpp/library/string/basic_string_view/size) * [`v.size()`](/docs/cpp/library/string/basic_string_view/size)) at worst.

### Example

{/* source:cpp-string-basic-string-view-find:0009 */}
```cpp
#include <string_view>
 
int main()
{
    using namespace std::literals;
 
    constexpr auto str{" long long int;"sv};
 
    static_assert(
        1 == str.find("long"sv)            && "<- find(v , pos = 0)" &&
        6 == str.find("long"sv, 2)         && "<- find(v , pos = 2)" &&
        0 == str.find(' ')                 && "<- find(ch, pos = 0)" &&
        2 == str.find('o', 1)              && "<- find(ch, pos = 1)" &&
        2 == str.find("on")                && "<- find(s , pos = 0)" &&
        6 == str.find("long double", 5, 4) && "<- find(s , pos = 5, count = 4)"
    );
 
    static_assert(str.npos == str.find("float"));
}
```
