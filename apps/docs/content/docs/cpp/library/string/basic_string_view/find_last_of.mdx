{/* source:cpp-string-basic-string-view-find-last-of:0001 */}
Finds the last character equal to one of characters in the given character sequence. Exact search algorithm is not specified. The search considers only the interval [`0`, `pos`]. If the character is not present in the interval, [`npos`](/docs/cpp/library/string/basic_string_view/npos) will be returned.

{/* source:cpp-string-basic-string-view-find-last-of:0002 */}
1. 1) Finds the last occurence of any of the characters of `v` in this view, ending at position `pos`.

{/* source:cpp-string-basic-string-view-find-last-of:0003 */}
2. 2) Equivalent to `find_last_of(basic_string_view(std::addressof(ch), 1), pos)`.

{/* source:cpp-string-basic-string-view-find-last-of:0004 */}
3. 3) Equivalent to `find_last_of(basic_string_view(s, count), pos)`.

{/* source:cpp-string-basic-string-view-find-last-of:0005 */}
4. 4) Equivalent to `find_last_of(basic_string_view(s), pos)`.

### Parameters

{/* source:cpp-string-basic-string-view-find-last-of:0006 */}
<ParameterList>
  <Parameter name="v">view to search for</Parameter>
  <Parameter name="pos">position at which the search is to finish</Parameter>
  <Parameter name="count">length of the string of characters to search for</Parameter>
  <Parameter name="s">pointer to a string of characters to search for</Parameter>
  <Parameter name="ch">character to search for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-find-last-of:0007 */}
Position of the last occurrence of any character of the substring, or [`npos`](/docs/cpp/library/string/basic_string_view/npos) if no such character is found.

### Complexity

{/* source:cpp-string-basic-string-view-find-last-of:0008 */}
O([`size()`](/docs/cpp/library/string/basic_string_view/size) * [`v.size()`](/docs/cpp/library/string/basic_string_view/size)) at worst.

### Example

{/* source:cpp-string-basic-string-view-find-last-of:0009 */}
```cpp
#include <string_view>
 
using namespace std::literals;
constexpr auto N = std::string_view::npos;
 
static_assert(
    5 == "delete"sv.find_last_of("cdef"sv) &&
      //       └────────────────────┘
    N == "double"sv.find_last_of("fghi"sv) &&
      //
    0 == "else"sv.find_last_of("bcde"sv, 2 /* pos [0..2]: "els" */) &&
      //  └────────────────────────┘
    N == "explicit"sv.find_last_of("abcd"sv, 4 /* pos [0..4]: "expli" */) &&
      //
    3 == "extern"sv.find_last_of('e') &&
      //     └────────────────────┘
    N == "false"sv.find_last_of('x') &&
      //
    0 == "inline"sv.find_last_of('i', 2 /* pos [0..2]: "inl" */) &&
      //  └───────────────────────┘
    N == "mutable"sv.find_last_of('a', 2 /* pos [0..2]: "mut" */) &&
      //
    3 == "namespace"sv.find_last_of("cdef", 3 /* pos [0..3]: "name" */, 3 /* "cde" */) &&
      //     └─────────────────────────┘
    N == "namespace"sv.find_last_of("cdef", 3 /* pos [0..3]: "name" */, 2 /* "cd" */)
);
 
int main() {}
```
