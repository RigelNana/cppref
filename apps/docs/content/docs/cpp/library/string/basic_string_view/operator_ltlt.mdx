{/* source:cpp-string-basic-string-view-operator-ltlt:0001 */}
Behaves as a [FormattedOutputFunction](/docs/cpp/library/named_req/FormattedOutputFunction). After constructing and checking the sentry object, [determines the output format padding](/docs/cpp/library/named_req/FormattedOutputFunction#Padding).

{/* source:cpp-string-basic-string-view-operator-ltlt:0002 */}
Then stores each character from the resulting sequence `seq` (the contents of `v` with padding) to the output stream `os` as if by calling `os.rdbuf()->sputn(seq, n)`, where `n` is `std::max(os.width(), str.size())`.

{/* source:cpp-string-basic-string-view-operator-ltlt:0003 */}
Finally, calls `os.width(0)` to cancel the effects of [`std::setw`](/docs/cpp/library/io/manip/setw), if any.

### Exceptions

{/* source:cpp-string-basic-string-view-operator-ltlt:0004 */}
May throw [`std::ios_base::failure`](/docs/cpp/library/io/ios_base/failure) if an exception is thrown during output.

### Parameters

{/* source:cpp-string-basic-string-view-operator-ltlt:0005 */}
<ParameterList>
  <Parameter name="os">a character output stream</Parameter>
  <Parameter name="v">the view to be inserted</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-operator-ltlt:0006 */}
`os`

### Example

{/* source:cpp-string-basic-string-view-operator-ltlt:0007 */}
```cpp
#include <iomanip>
#include <iostream>
#include <string_view>
 
int main()
{
    constexpr std::string_view s{"abc"};
    constexpr int width{5};
 
    // fill/left/right properties are kept until changed
    std::cout << std::setfill('-');
    std::cout << std::left;
 
    std::cout << '[' << std::setw(width) << s << "]\n";
    std::cout << '[' << std::setw(width) << s << "]\n";
 
    std::cout << std::right;
    std::cout << '[' << std::setw(width) << s << "]\n";
 
    // width is reset after each call
    std::cout << '[' << s << "]\n";
}
```

Output:

```text
[abc--]
[abc--]
[--abc]
[abc]
```
