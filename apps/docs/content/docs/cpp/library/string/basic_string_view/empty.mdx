Checks if the view has no characters, i.e. whether [`size()`](/docs/cpp/library/string/basic_string_view/size) == `0`.

### Parameters

{/* source:cpp-string-basic-string-view-empty:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-view-empty:0003 */}
`true` if the view is empty, `false` otherwise.

### Complexity

{/* source:cpp-string-basic-string-view-empty:0004 */}
Constant.

### Example

{/* source:cpp-string-basic-string-view-empty:0005 */}
```cpp
#include <iostream>
#include <string_view>
 
// Print a string surrounded by single quotes, its
// length and whether it is considered empty.
void check_string(std::string_view ref)
{
    std::cout << std::boolalpha
              << "'" << ref << "' has " << ref.size()
              << " character(s); emptiness: " << ref.empty() << '\n';
}
 
int main(int argc, char **argv)
{
    // An empty string
    check_string("");
 
    // Almost always not empty: argv[0]
    if (argc > 0)
        check_string(argv[0]);
}
```

Possible output:

```text
'' has 0 character(s); emptiness: true
'./a.out' has 7 character(s); emptiness: false
```
