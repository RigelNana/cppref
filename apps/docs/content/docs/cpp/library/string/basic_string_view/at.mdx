{/* source:cpp-string-basic-string-view-at:0001 */}
Returns a const reference to the character at specified location `pos`. Bounds checking is performed, exception of type [`std::out_of_range`](/docs/cpp/library/error/out_of_range) will be thrown on invalid access.

### Parameters

{/* source:cpp-string-basic-string-view-at:0002 */}
<ParameterList>
  <Parameter name="pos">position of the character to return</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-at:0003 */}
Const reference to the requested character.

### Exceptions

{/* source:cpp-string-basic-string-view-at:0004 */}
Throws [`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos >= size()`.

### Complexity

{/* source:cpp-string-basic-string-view-at:0005 */}
Constant.

### Example

{/* source:cpp-string-basic-string-view-at:0006 */}
```cpp
#include <iostream>
#include <stdexcept>
#include <string_view>
 
int main()
{
    std::string_view str_view("abcdef");
 
    try
    {
        for (std::size_t i = 0; true; ++i)
            std::cout << i << ": " << str_view.at(i) << '\n';
    }
    catch (const std::out_of_range& e)
    {
        std::cout << "Whooops. Index is out of range.\n";
        std::cout << e.what() << '\n';
    }
}
```

Possible output:

```text
0: a
1: b
2: c
3: d
4: e
5: f
6: Whooops. Index is out of range.
basic_string_view::at: __pos (which is 6) >= this->size() (which is 6)
```
