{/* source:cpp-string-basic-string-view-rfind:0001 */}
Finds the last substring that is equal to the given character sequence. The search begins at `pos` and proceeds from right to left (thus, the found substring, if any, cannot begin in a position following `pos`). If [`npos`](/docs/cpp/library/string/basic_string_view/npos) or any value not smaller than [`size()`](/docs/cpp/library/string/basic_string_view/size) ` - 1` is passed as `pos`, the whole string will be searched.

{/* source:cpp-string-basic-string-view-rfind:0002 */}
1) Finds the last occurrence of `v` in this view, starting at position `pos`.

{/* source:cpp-string-basic-string-view-rfind:0003 */}
2) Equivalent to `rfind(basic_string_view(std::addressof(ch), 1), pos)`.

{/* source:cpp-string-basic-string-view-rfind:0004 */}
3) Equivalent to `rfind(basic_string_view(s, count), pos)`.

{/* source:cpp-string-basic-string-view-rfind:0005 */}
4) Equivalent to `rfind(basic_string_view(s), pos)`.

### Parameters

{/* source:cpp-string-basic-string-view-rfind:0006 */}
<ParameterList>
  <Parameter name="v">view to search for</Parameter>
  <Parameter name="pos">position at which to start the search</Parameter>
  <Parameter name="count">length of substring to search for</Parameter>
  <Parameter name="s">pointer to a character string to search for</Parameter>
  <Parameter name="ch">character to search for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-rfind:0007 */}
Position of the first character of the found substring or [`npos`](/docs/cpp/library/string/basic_string_view/npos) if no such substring is found.

### Complexity

{/* source:cpp-string-basic-string-view-rfind:0008 */}
O([`size()`](/docs/cpp/library/string/basic_string_view/size) * v.[`size()`](/docs/cpp/library/string/basic_string_view/size)) at worst.

### Example

{/* source:cpp-string-basic-string-view-rfind:0009 */}
```cpp
#include <string_view>
 
int main()
{
    using namespace std::literals;
    constexpr auto N = std::string_view::npos;
 
    static_assert(true
        && (6 == "AB AB AB"sv.rfind("AB"))
        && (6 == "AB AB AB"sv.rfind("ABCD", N, 2))
        && (3 == "AB AB AB"sv.rfind("AB", 5))
        && (0 == "AB CD EF"sv.rfind("AB", 0))
        && (2 == "B AB AB "sv.rfind("AB", 2))
        && (N == "B AB AB "sv.rfind("AB", 1))
        && (5 == "B AB AB "sv.rfind('A'))
        && (4 == "AB AB AB"sv.rfind('B', 4))
        && (N == "AB AB AB"sv.rfind('C'))
    );
}
```
