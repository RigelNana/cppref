{/* source:cpp-string-basic-string-view-contains:0001 */}
Checks if the string view contains the given substring, where

{/* source:cpp-string-basic-string-view-contains:0002 */}
1. 1) the substring is a string view.

{/* source:cpp-string-basic-string-view-contains:0003 */}
2. 2) the substring is a single character.

{/* source:cpp-string-basic-string-view-contains:0004 */}
3. 3) the substring is a null-terminated character string.

{/* source:cpp-string-basic-string-view-contains:0005 */}
All three overloads are equivalent to `return find(x) != npos;`, where `x` is the parameter.

### Parameters

{/* source:cpp-string-basic-string-view-contains:0006 */}
<ParameterList>
  <Parameter name="sv">a string view</Parameter>
  <Parameter name="c">a single character</Parameter>
  <Parameter name="s">a null-terminated character string</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-contains:0007 */}
`true` if the string view contains the provided substring, `false` otherwise.

### Example

{/* source:cpp-string-basic-string-view-contains:0009 */}
```cpp
#include <string_view>
using namespace std::literals;
 
static_assert
(
    // bool contains(basic_string_view x) const noexcept;
    "https://cppreference.com"sv.contains("cpp"sv) == true and
    "https://cppreference.com"sv.contains("php"sv) == false and
 
    // bool contains(CharT x) const noexcept;
    "C++23"sv.contains('+') == true and
    "C++23"sv.contains('-') == false and
 
    // bool contains(const CharT* x) const;
    std::string_view("basic_string_view").contains("string") == true and
    std::string_view("basic_string_view").contains("String") == false
);
 
int main() {}
```
