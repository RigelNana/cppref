Returns reference to the last character in the view. The behavior is undefined if `empty() == true`.

### Parameters

{/* source:cpp-string-basic-string-view-back:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-view-back:0003 */}
Reference to the last character, equivalent to `operator[](size() - 1)`.

### Complexity

{/* source:cpp-string-basic-string-view-back:0004 */}
Constant.

### Example

{/* source:cpp-string-basic-string-view-back:0005 */}
```cpp
#include <iostream>
#include <string_view>
 
int main()
{
    for (std::string_view str{"ABCDEF"}; !str.empty(); str.remove_suffix(1))
        std::cout << str.back() << ' ' << str << '\n';
}
```

Output:

```text
F ABCDEF
E ABCDE
D ABCD
C ABC
B AB
A A
```
