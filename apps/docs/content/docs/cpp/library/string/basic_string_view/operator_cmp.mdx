{/* source:cpp-string-basic-string-view-operator-cmp:0001 */}
Compares two views.

{/* source:cpp-string-basic-string-view-operator-cmp:0002 */}
All comparisons are done via the [`compare()`](/docs/cpp/library/string/basic_string_view/compare) member function (which itself is defined in terms of `Traits::compare()`):

{/* source:cpp-string-basic-string-view-operator-cmp:0003 */}
- Two views are equal if both the size of `lhs` and `rhs` are equal and each character in `lhs` has an equivalent character in `rhs` at the same position.

{/* source:cpp-string-basic-string-view-operator-cmp:0004 */}
- The ordering comparisons are done lexicographically – the comparison is performed by a function equivalent to [`std::lexicographical_compare`](/docs/cpp/library/algorithm/lexicographical_compare).

{/* source:cpp-string-basic-string-view-operator-cmp:0005 */}
<Revision until="C++20">
The implementation provides sufficient additional `constexpr` and `noexcept` overloads of these functions so that a `basic_string_view<CharT,Traits>` object `sv` may be compared to another object `t` with an implicit conversion to `basic_string_view<CharT,Traits>`, with semantics identical to comparing `sv` and `basic_string_view<CharT,Traits>(t)`.
</Revision>

<Revision since="C++20">
The return type of three-way comparison operators (`/*comp-cat*/`) is `Traits::comparison_category` if that qualified-id denotes a type, `std::weak_ordering` otherwise. If `/*comp-cat*/` is not a comparison category type, the program is ill-formed.

The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Return value

{/* source:cpp-string-basic-string-view-operator-cmp:0007 */}
1-6) `true` if the corresponding comparison holds, `false` otherwise.

{/* source:cpp-string-basic-string-view-operator-cmp:0008 */}
7) `static_cast</*comp-cat*/>(lhs.compare(rhs) <=> 0)`

### Complexity

{/* source:cpp-string-basic-string-view-operator-cmp:0009 */}
Linear in the size of the views.

### Notes

{/* source:cpp-string-basic-string-view-operator-cmp:0010 */}
<Revision until="C++20">
Sufficient additional overloads can be implemented through non-deduced context in one parameter type.
</Revision>

<Revision since="C++20">
Three-way comparison result type of [`std::string_view`](/docs/cpp/library/string/basic_string_view), [`std::wstring_view`](/docs/cpp/library/string/basic_string_view), [`std::u8string_view`](/docs/cpp/library/string/basic_string_view), [`std::u16string_view`](/docs/cpp/library/string/basic_string_view) and [`std::u32string_view`](/docs/cpp/library/string/basic_string_view) is `std::strong_ordering`.

`std::type_identity_t` is used for non-deduced context, which makes arguments that implicitly convertible to the string view type comparable with the string view.
</Revision>
