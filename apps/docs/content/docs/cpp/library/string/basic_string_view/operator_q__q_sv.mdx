{/* source:cpp-string-basic-string-view-operator-q-q-sv:0001 */}
Forms a string view of a character literal.

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0002 */}
1) Returns `std::string_view{str, len}`.

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0003 */}
2) Returns `std::u8string_view{str, len}`.

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0004 */}
3) Returns `std::u16string_view{str, len}`.

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0005 */}
4) Returns `std::u32string_view{str, len}`.

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0006 */}
5) Returns `std::wstring_view{str, len}`.

### Parameters

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0007 */}
<ParameterList>
  <Parameter name="str">pointer to the beginning of the raw character array literal</Parameter>
  <Parameter name="len">length of the raw character array literal</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0008 */}
The [`std::basic_string_view`](/docs/cpp/library/string/basic_string_view) literal.

### Notes

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0009 */}
These operators are declared in the namespace `std::literals::string_view_literals`, where both `literals` and `string_view_literals` are inline namespaces. Access to these operators can be gained with any of:

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0010 */}
- `using namespace std::literals`,
- `using namespace std::string_view_literals`, or
- `using namespace std::literals::string_view_literals`.

### Example

{/* source:cpp-string-basic-string-view-operator-q-q-sv:0011 */}
```cpp
#include <iostream>
#include <string_view>
#include <typeinfo>
 
void print_each_character(const std::string_view sw)
{
    for (char c : sw)
        std::cout << (c == '\0' ? '@' : c);
    std::cout << '\n';
}
 
int main()
{
    using namespace std::literals;
 
    std::string_view s1 = "abc\0\0def";
    std::string_view s2 = "abc\0\0def"sv;
 
    std::cout << "s1.size(): " << s1.size() << "; s1: ";
    print_each_character(s1);
    std::cout << "s2.size(): " << s2.size() << "; s2: ";
    print_each_character(s2);
 
    std::cout << "substr(1, 4): " << "abcdef"sv.substr(1, 4) << '\n';
 
    auto value_type_info = []<typename T>(T)
    {
        using V = typename T::value_type;
        std::cout << "sizeof " << typeid(V).name() << ": " << sizeof(V) << '\n';
    };
 
    value_type_info("char A"sv);
    value_type_info(L"wchar_t ∀"sv);
    value_type_info(u8"char8_t ∆"sv);
    value_type_info(u"char16_t ∇"sv);
    value_type_info(U"char32_t ∃"sv);
    value_type_info(LR"(raw ⊞)"sv);
}
```

Possible output:

```text
s1.size(): 3; s1: abc
s2.size(): 8; s2: abc@@def
substr(1, 4): bcde
sizeof char: 1
sizeof wchar_t: 4
sizeof char8_t: 1
sizeof char16_t: 2
sizeof char32_t: 4
sizeof wchar_t: 4
```
