{/* source:cpp-string-basic-string-view-operator:0001 */}
Replaces the view with that of `view`.

### Parameters

{/* source:cpp-string-basic-string-view-operator:0002 */}
<ParameterList>
  <Parameter name="view">view to copy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-operator:0003 */}
`*this`

### Complexity

{/* source:cpp-string-basic-string-view-operator:0004 */}
Constant.

### Example

{/* source:cpp-string-basic-string-view-operator:0005 */}
```cpp
#include <iostream>
#include <string_view>
 
int main()
{
    std::string_view v = "Hello, world";
    v = v.substr(7);
    std::cout << v << '\n';
}
```

Output:

```text
world
```
