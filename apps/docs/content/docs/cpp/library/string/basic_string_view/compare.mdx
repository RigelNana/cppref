{/* source:cpp-string-basic-string-view-compare:0001 */}
Compares two character sequences.

{/* source:cpp-string-basic-string-view-compare:0002 */}
1. 1) The length `rlen` of the sequences to compare is the smaller of `size()` and `v.size()`. The function compares the two views by calling `traits::compare(data(), v.data(), rlen)`, and returns a value according to the following table:

{/* source:cpp-string-basic-string-view-compare:0003 */}
| Condition | Result | Return value |
| --- | --- | --- |
| `Traits::compare(data(), v.data(), rlen) < 0` | `this` is *less* than `v` | `< 0` |
| `Traits::compare(data(), v.data(), rlen) == 0`, `size() < v.size()` | `this` is *less* than `v` | `< 0` |
| `Traits::compare(data(), v.data(), rlen) == 0`, `size() == v.size()` | `this` is *equal* to `v` | `0` |
| `Traits::compare(data(), v.data(), rlen) == 0`, `size() > v.size()` | `this` is *greater* than `v` | `> 0` |
| `Traits::compare(data(), v.data(), rlen) > 0` | `this` is *greater* than `v` | `> 0` |

{/* source:cpp-string-basic-string-view-compare:0004 */}
2. 2) Equivalent to `substr(pos1, count1).compare(v)`.

{/* source:cpp-string-basic-string-view-compare:0005 */}
3. 3) Equivalent to `substr(pos1, count1).compare(v.substr(pos2, count2))`.

{/* source:cpp-string-basic-string-view-compare:0006 */}
4. 4) Equivalent to `compare(basic_string_view(s))`.

{/* source:cpp-string-basic-string-view-compare:0007 */}
5. 5) Equivalent to `substr(pos1, count1).compare(basic_string_view(s))`.

{/* source:cpp-string-basic-string-view-compare:0008 */}
6. 6) Equivalent to `substr(pos1, count1).compare(basic_string_view(s, count2))`.

### Return value

{/* source:cpp-string-basic-string-view-compare:0010 */}
Negative value if this view is less than the other character sequence, zero if the both character sequences are equal, positive value if this view is greater than the other character sequence.

### Complexity

{/* source:cpp-string-basic-string-view-compare:0011 */}
1) Linear in the number of characters compared.

### Example

{/* source:cpp-string-basic-string-view-compare:0012 */}
```cpp
#include <string_view>
 
int main()
{
    using std::operator""sv;
    static_assert("abc"sv.compare("abcd"sv) < 0);
    static_assert("abcd"sv.compare("abc"sv) > 0);
    static_assert("abc"sv.compare("abc"sv) == 0);
    static_assert(""sv.compare(""sv) == 0);
}
```
