{/* source:cpp-string-basic-string-view-remove-suffix:0001 */}
Moves the end of the view back by `n` characters.

{/* source:cpp-string-basic-string-view-remove-suffix:0002 */}
The behavior is undefined if `n > size()`.

### Parameters

{/* source:cpp-string-basic-string-view-remove-suffix:0003 */}
<ParameterList>
  <Parameter name="n">number of characters to remove from the end of the view</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-remove-suffix:0004 */}
(none)

### Complexity

{/* source:cpp-string-basic-string-view-remove-suffix:0005 */}
Constant.

### Example

{/* source:cpp-string-basic-string-view-remove-suffix:0006 */}
```cpp
#include <iostream>
#include <string_view>
 
int main()
{
    char arr[] = {'a', 'b', 'c', 'd', '\0', '\0', '\0'};
    std::string_view v(arr, sizeof arr);
    auto trim_pos = v.find('\0');
    if (trim_pos != v.npos)
        v.remove_suffix(v.size() - trim_pos);
    std::cout << "Array: '" << arr << "', size=" << sizeof arr << '\n'
              << "View : '" << v << "', size=" << v.size() << '\n';
}
```

Output:

```text
Array: 'abcd', size=7
View : 'abcd', size=4
```
