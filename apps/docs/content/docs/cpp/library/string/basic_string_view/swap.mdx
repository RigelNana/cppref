{/* source:cpp-string-basic-string-view-swap:0001 */}
Exchanges the view with that of `v`.

### Parameters

{/* source:cpp-string-basic-string-view-swap:0002 */}
<ParameterList>
  <Parameter name="v">view to swap with</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-swap:0003 */}
(none)

### Complexity

{/* source:cpp-string-basic-string-view-swap:0004 */}
Constant.

### Example

{/* source:cpp-string-basic-string-view-swap:0005 */}
```cpp
#include <iostream>
#include <string_view>
 
int main() 
{
    std::string_view a = "AAA";
    std::string_view b = "BBBB";
 
    std::cout << "Before swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << "\n\n";
 
    a.swap(b);
 
    std::cout << "After swap:\n"
                 "a = " << a << "\n"
                 "b = " << b << '\n';
}
```

Output:

```text
Before swap:
a = AAA
b = BBBB
 
After swap:
a = BBBB
b = AAA
```
