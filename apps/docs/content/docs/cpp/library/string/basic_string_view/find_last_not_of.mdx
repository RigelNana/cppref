{/* source:cpp-string-basic-string-view-find-last-not-of:0001 */}
Finds the last character not equal to any of the characters in the given character sequence. The search considers only the interval [`0`, `pos`].

{/* source:cpp-string-basic-string-view-find-last-not-of:0002 */}
1. 1) Finds the last character not equal to any of the characters of `v` in this view, starting at position `pos`.

{/* source:cpp-string-basic-string-view-find-last-not-of:0003 */}
2. 2) Equivalent to `find_last_not_of(basic_string_view(std::addressof(ch), 1), pos)`.

{/* source:cpp-string-basic-string-view-find-last-not-of:0004 */}
3. 3) Equivalent to `find_last_not_of(basic_string_view(s, count), pos)`.

{/* source:cpp-string-basic-string-view-find-last-not-of:0005 */}
4. 4) Equivalent to `find_last_not_of(basic_string_view(s), pos)`.

### Parameters

{/* source:cpp-string-basic-string-view-find-last-not-of:0006 */}
<ParameterList>
  <Parameter name="v">view to search for</Parameter>
  <Parameter name="pos">position at which to start the search</Parameter>
  <Parameter name="count">length of the string of characters to compare</Parameter>
  <Parameter name="s">pointer to a string of characters to compare</Parameter>
  <Parameter name="ch">character to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-basic-string-view-find-last-not-of:0007 */}
Position of the last character not equal to any of the characters in the given string, or [`npos`](/docs/cpp/library/string/basic_string_view/npos) if no such character is found.

### Complexity

{/* source:cpp-string-basic-string-view-find-last-not-of:0008 */}
O([`size()`](/docs/cpp/library/string/basic_string_view/size) * [`v.size()`](/docs/cpp/library/string/basic_string_view/size)) at worst.

### Example

{/* source:cpp-string-basic-string-view-find-last-not-of:0009 */}
```cpp
#include <string_view>
using std::operator""sv;
 
int main()
{
    static_assert(1 == "BCDEF"sv.find_last_not_of("DEF"));
                    //   ^
    static_assert(2 == "BCDEFG"sv.find_last_not_of("EFG", 3));
                    //    ^
    static_assert(2 == "ABBA"sv.find_last_not_of('A'));
                    //    ^
    static_assert(1 == "ABBA"sv.find_last_not_of('A', 1));
                    //   ^
}
```
