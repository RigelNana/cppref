{/* source:cpp-string-basic-string-view-front:0001 */}
Returns reference to the first character in the view. The behavior is undefined if `empty() == true`.

### Parameters

{/* source:cpp-string-basic-string-view-front:0002 */}
(none)

### Return value

{/* source:cpp-string-basic-string-view-front:0003 */}
Reference to the first character, equivalent to `operator[](0)`.

### Complexity

{/* source:cpp-string-basic-string-view-front:0004 */}
Constant.

### Example

{/* source:cpp-string-basic-string-view-front:0005 */}
```cpp
#include <iostream>
#include <string_view>
 
int main()
{
    for (std::string_view str{"ABCDEF"}; !str.empty(); str.remove_prefix(1))
        std::cout << str.front() << ' ' << str << '\n';
}
```

Output:

```text
A ABCDEF
B BCDEF
C CDEF
D DEF
E EF
F F
```
