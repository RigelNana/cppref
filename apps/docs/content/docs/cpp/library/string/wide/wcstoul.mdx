{/* source:cpp-string-wide-wcstoul:0001 */}

Interprets an unsigned integer value in a wide string pointed to by `str`.

{/* source:cpp-string-wide-wcstoul:0002 */}

Discards any whitespace characters (as identified by calling [`std::iswspace`](/docs/cpp/library/text/wide/iswspace)) until the first non-whitespace character is found, then takes as many characters as possible to form a valid *base-n* (where n=`base`) unsigned integer number representation and converts them to an integer value. The valid unsigned integer value consists of the following parts:

{/* source:cpp-string-wide-wcstoul:0003 */}

- (optional) plus or minus sign
- (optional) prefix (`0`) indicating octal base (applies only when the base is `8` or `0`)
- (optional) prefix (`0x` or `0X`) indicating hexadecimal base (applies only when the base is `16` or `0`)
- a sequence of digits

{/* source:cpp-string-wide-wcstoul:0004 */}

The set of valid values for base is `{0, 2, 3, ..., 36}`. The set of valid digits for base-`2` integers is `{0, 1}`, for base-`3` integers is `{0, 1, 2}`, and so on. For bases larger than `10`, valid digits include alphabetic characters, starting from `Aa` for base-`11` integer, to `Zz` for base-`36` integer. The case of the characters is ignored.

{/* source:cpp-string-wide-wcstoul:0005 */}

Additional numeric formats may be accepted by the currently installed C [locale](/docs/cpp/library/text/locale/setlocale).

{/* source:cpp-string-wide-wcstoul:0006 */}

If the value of `base` is `0`, the numeric base is auto-detected: if the prefix is `0`, the base is octal, if the prefix is `0x` or `0X`, the base is hexadecimal, otherwise the base is decimal.

{/* source:cpp-string-wide-wcstoul:0007 */}

If the minus sign was part of the input sequence, the numeric value calculated from the sequence of digits is negated as if by [unary minus](/docs/cpp/language/expressions/operator_arithmetic#Unary_arithmetic_operators) in the result type, which applies unsigned integer wraparound rules.

{/* source:cpp-string-wide-wcstoul:0008 */}

The functions sets the pointer pointed to by `str_end` to point to the wide character past the last character interpreted. If `str_end` is a null pointer, it is ignored.

### Parameters

{/* source:cpp-string-wide-wcstoul:0009 */}

<ParameterList>
  <Parameter name="str">pointer to the null-terminated wide string to be interpreted</Parameter>
  <Parameter name="str_end">pointer to a pointer to a wide character</Parameter>
  <Parameter name="base">*base* of the interpreted integer value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wcstoul:0010 */}

Integer value corresponding to the contents of `str` on success. If the converted value falls out of range of corresponding return type, range error occurs and [`ULONG_MAX`](/docs/cpp/library/utility/types/climits) or [`ULLONG_MAX`](/docs/cpp/library/utility/types/climits) is returned. If no conversion can be performed, `0` is returned.

### Example

{/* source:cpp-string-wide-wcstoul:0011 */}

```cpp
#include <cwchar>
#include <errno.h>
#include <iostream>
#include <string>
 
int main()
{
    const wchar_t* p = L"10 200000000000000000000000000000 30 40";
    wchar_t* end;
    std::wcout << "Parsing L'" << p << "':\n";
    for (unsigned long i = std::wcstoul(p, &end, 10);
         p != end;
         i = std::wcstoul(p, &end, 10))
    {
        std::wcout << '\'' << std::wstring(p, end - p) << "' -> ";
        p = end;
        if (errno == ERANGE)
        {
            std::wcout << "range error, got ";
            errno = 0;
        }
        std::wcout << i << '\n';
    }
}
```

Possible output:

```text
Parsing L'10 200000000000000000000000000000 30 40':
'10' -> 10
' 200000000000000000000000000000' -> range error, got 18446744073709551615
' 30' -> 30
' 40' -> 40
```
