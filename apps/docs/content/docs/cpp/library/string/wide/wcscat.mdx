{/* source:cpp-string-wide-wcscat:0001 */}

Appends a copy of the wide string pointed to by `src` to the end of the wide string pointed to by `dest`. The wide character `src[0]` replaces the null terminator at the end of `dest`. The resulting wide string is null-terminated.

{/* source:cpp-string-wide-wcscat:0002 */}

The behavior is undefined if the destination array is not large enough for the contents of both `src` and `dest` and the terminating null wide character.

{/* source:cpp-string-wide-wcscat:0003 */}

The behavior is undefined if the strings overlap.

### Parameters

{/* source:cpp-string-wide-wcscat:0004 */}

<ParameterList>
  <Parameter name="dest">pointer to the null-terminated wide string to append to</Parameter>
  <Parameter name="src">pointer to the null-terminated wide string to copy from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wcscat:0005 */}

Returns a copy of `dest`.

### Example

{/* source:cpp-string-wide-wcscat:0006 */}

```cpp
#include <clocale>
#include <cwchar> 
#include <iostream>
 
int main(void) 
{
    wchar_t str[50] = L"Земля, прощай.";
    std::wcscat(str, L" ");
    std::wcscat(str, L"В добрый путь.");
 
    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale("en_US.utf8"));
    std::wcout << str << '\n';
}
```

Possible output:

```text
Земля, прощай. В добрый путь.
```
