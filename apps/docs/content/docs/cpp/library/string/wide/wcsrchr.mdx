{/* source:cpp-string-wide-wcsrchr:0001 */}

Finds the last occurrence of the wide character `ch` in the wide string pointed to by `str`.

### Parameters

{/* source:cpp-string-wide-wcsrchr:0002 */}

<ParameterList>
  <Parameter name="str">pointer to the null-terminated wide string to be analyzed</Parameter>
  <Parameter name="ch">wide character to search for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wcsrchr:0003 */}

Pointer to the found character in `str`, or a null pointer if no such character is found.

### Example

{/* source:cpp-string-wide-wcsrchr:0004 */}

```cpp
#include <cwchar>
#include <iostream>
#include <locale>
 
int main()
{
    const wchar_t arr[] = L"白猫 黒猫 кошки";
    const wchar_t* cat = std::wcsrchr(arr, L'猫');
    const wchar_t* dog = std::wcsrchr(arr, L'犬');
 
    std::cout.imbue(std::locale("en_US.utf8"));
 
    if (cat)
        std::cout << "The character 猫 found at position " << cat - arr << '\n';
    else
        std::cout << "The character 猫 not found\n";
 
    if (dog)
        std::cout << "The character 犬 found at position " << dog - arr << '\n';
    else
        std::cout << "The character 犬 not found\n";
}
```

Output:

```text
The character 猫 found at position 4
The character 犬 not found
```
