{/* source:cpp-string-wide-wctype:0001 */}

Constructs a value of type `std::wctype_t` that describes a [`LC_CTYPE`](/docs/cpp/library/text/locale/LC_categories) category of wide character classification. It may be one of the standard classification categories, or a locale-specific category, such as `"jkanji"`.

### Parameters

{/* source:cpp-string-wide-wctype:0002 */}

<ParameterList>
  <Parameter name="str">C string holding the name of the desired category</Parameter>
</ParameterList>

{/* source:cpp-string-wide-wctype:0003 */}

The following values of `str` are supported in all C locales:

{/* source:cpp-string-wide-wctype:0004 */}

| value of `str` | effect |
| --- | --- |
| `"alnum"` | identifies the category used by [`std::iswalnum`](/docs/cpp/library/text/wide/iswalnum) |
| `"alpha"` | identifies the category used by [`std::iswalpha`](/docs/cpp/library/text/wide/iswalpha) |
| `"blank"` | identifies the category used by [`std::iswblank`](/docs/cpp/library/text/wide/iswblank) <InlineRevision since="C++11" /> |
| `"cntrl"` | identifies the category used by [`std::iswcntrl`](/docs/cpp/library/text/wide/iswcntrl) |
| `"digit"` | identifies the category used by [`std::iswdigit`](/docs/cpp/library/text/wide/iswdigit) |
| `"graph"` | identifies the category used by [`std::iswgraph`](/docs/cpp/library/text/wide/iswgraph) |
| `"lower"` | identifies the category used by [`std::iswlower`](/docs/cpp/library/text/wide/iswlower) |
| `"print"` | identifies the category used by [`std::iswprint`](/docs/cpp/library/text/wide/iswprint) |
| `"space"` | identifies the category used by [`std::iswspace`](/docs/cpp/library/text/wide/iswspace) |
| `"upper"` | identifies the category used by [`std::iswupper`](/docs/cpp/library/text/wide/iswupper) |
| `"xdigit"` | identifies the category used by [`std::iswxdigit`](/docs/cpp/library/text/wide/iswxdigit) |

### Return value

{/* source:cpp-string-wide-wctype:0005 */}

`std::wctype_t` object suitable for use with [`std::iswctype`](/docs/cpp/library/text/wide/iswctype) to classify wide characters according to the named category of the current C locale or zero if `str` does not name a category supported by the current C locale.
