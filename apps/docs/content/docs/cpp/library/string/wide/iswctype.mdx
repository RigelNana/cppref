{/* source:cpp-string-wide-iswctype:0001 */}

Classifies the wide character `wc` using the current C locale's [`LC_CTYPE`](/docs/cpp/library/text/locale/LC_categories) category identified by `desc`.

{/* source:cpp-string-wide-iswctype:0002 */}

If the value of `wc` is neither representable as a `wchar_t` nor equal to the value of the macro `WEOF`, the behavior is undefined.

### Parameters

{/* source:cpp-string-wide-iswctype:0003 */}

<ParameterList>
  <Parameter name="wc">the wide character to classify</Parameter>
  <Parameter name="desc">the [`LC_CTYPE`](/docs/cpp/library/text/locale/LC_categories) category, obtained from a call to [`std::wctype`](/docs/cpp/library/text/wide/wctype)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-iswctype:0004 */}

Non-zero if the character `wc` has the property identified by `desc` in [`LC_CTYPE`](/docs/cpp/library/text/locale/LC_categories) facet of the current C locale, zero otherwise.

### Example

{/* source:cpp-string-wide-iswctype:0005 */}

```cpp
#include <clocale>
#include <cwctype>
#include <iostream>
 
bool classify(wchar_t wc, const std::string& cat)
{
    return std::iswctype(wc, std::wctype(cat.c_str()));
}
 
int main()
{
    std::setlocale(LC_ALL, "ja_JP.UTF-8");
    std::cout << "The character \u6c34 is...\n";
    for (std::string s : {"digit", "alpha", "space", "cntrl", "jkanji"})
        std::cout << s << "? " << std::boolalpha << classify(L'\u6c34', s) << '\n';
}
```

Output:

```text
The character 水 is...
digit? false
alpha? true
space? false
cntrl? false
jkanji? true
```
