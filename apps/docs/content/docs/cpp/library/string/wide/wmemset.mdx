Defined in header [`<cwchar>`](/docs/cpp/library/headers/cwchar)

  <Declaration language="cpp" code={
`wchar_t* wmemset( wchar_t* dest, wchar_t ch, std::size_t count );`
  } />
</DeclarationDoc>

{/* source:cpp-string-wide-wmemset:0001 */}

Copies the wide character `ch` into each of the first `count` wide characters of the wide character array pointed to by `dest`.

{/* source:cpp-string-wide-wmemset:0002 */}

If overflow occurs, the behavior is undefined.

{/* source:cpp-string-wide-wmemset:0003 */}

If `count` is zero, the function does nothing.

### Parameters

{/* source:cpp-string-wide-wmemset:0004 */}

<ParameterList>
  <Parameter name="dest">pointer to the wide character array to fill</Parameter>
  <Parameter name="ch">fill wide character</Parameter>
  <Parameter name="count">number of wide characters to fill</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wmemset:0005 */}

Returns a copy of `dest`.

### Notes

{/* source:cpp-string-wide-wmemset:0006 */}

This function is not locale-sensitive and pays no attention to the values of the `wchar_t` objects it writes: nulls as well as invalid wide characters are written too.

### Example

{/* source:cpp-string-wide-wmemset:0007 */}

```cpp
#include <clocale>
#include <cwchar>
#include <iostream>
#include <locale>
 
int main()
{
    wchar_t ar[4] = {L'1', L'2', L'3', L'4'};
    std::wmemset(ar, L'\U0001f34c', 2); // replaces [12] with the 🍌 bananas
    std::wmemset(ar + 2, L'蕉', 2); // replaces [34] with the 蕉 bananas
 
    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale("en_US.utf8"));
    std::wcout << std::wstring(ar, 4) << '\n';
}
```

Possible output:

```text
🍌🍌蕉蕉
```
