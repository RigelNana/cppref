  <Declaration language="cpp" code={
`wchar_t* wmemmove( wchar_t* dest, const wchar_t* src, std::size_t count );`
  } />
</DeclarationDoc>

{/* source:cpp-string-wide-wmemmove:0001 */}

Copies exactly `count` successive wide characters from the wide character array pointed to by `src` to the wide character array pointed to by `dest`.

{/* source:cpp-string-wide-wmemmove:0002 */}

If `count` is zero, the function does nothing.

{/* source:cpp-string-wide-wmemmove:0003 */}

The arrays may overlap: copying takes place as if the wide characters were copied to a temporary wide character array and then copied from the temporary array to `dest`.

### Parameters

{/* source:cpp-string-wide-wmemmove:0004 */}

<ParameterList>
  <Parameter name="dest">pointer to the wide character array to copy to</Parameter>
  <Parameter name="src">pointer to the wide character array to copy from</Parameter>
  <Parameter name="count">number of wide characters to copy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wmemmove:0005 */}

Returns a copy of `dest`.

### Notes

{/* source:cpp-string-wide-wmemmove:0006 */}

This function is not locale-sensitive and pays no attention to the values of the `wchar_t` objects it copies: nulls as well as invalid characters are copied too.

### Example

{/* source:cpp-string-wide-wmemmove:0007 */}

```cpp
#include <clocale>
#include <cwchar>
#include <iostream>
#include <locale>
 
int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale("en_US.utf8"));
 
    wchar_t str[] = L"αβγδεζηθικλμνξοπρστυφχψω";
    std::wcout << str << '\n';
    std::wmemmove(str + 4, str + 3, 3); // copy from [δεζ] to [εζη]
    std::wcout << str << '\n';
}
```

Possible output:

```text
αβγδεζηθικλμνξοπρστυφχψω
αβγδδεζθικλμνξοπρστυφχψω
```
