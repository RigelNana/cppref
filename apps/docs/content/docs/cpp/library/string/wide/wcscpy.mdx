{/* source:cpp-string-wide-wcscpy:0001 */}

Copies the wide string pointed to by `src` (including the terminating null wide character) to wide character array pointed to by `dest`.

{/* source:cpp-string-wide-wcscpy:0002 */}

If the strings overlap, the behavior is undefined.

### Parameters

{/* source:cpp-string-wide-wcscpy:0003 */}

<ParameterList>
  <Parameter name="dest">pointer to the wide character array to copy to</Parameter>
  <Parameter name="src">pointer to the null-terminated wide string to copy from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wcscpy:0004 */}

`dest`

### Example

{/* source:cpp-string-wide-wcscpy:0005 */}

```cpp
#include <clocale>
#include <cwchar>
#include <iostream>
#include <memory>
 
int main()
{
    const wchar_t* src = L"犬 means dog";
//  src[0] = L'狗'; // can't modify string literal
    auto dst = std::make_unique<wchar_t[]>(std::wcslen(src) + 1); // +1 for the null
    std::wcscpy(dst.get(), src);
    dst[0] = L'狗';
    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale(""));
    std::wcout << src << '\n' << dst.get() << '\n';
}
```

Output:

```text
犬 means dog
狗 means dog
```
