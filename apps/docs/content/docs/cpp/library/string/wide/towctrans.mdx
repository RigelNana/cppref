{/* source:cpp-string-wide-towctrans:0001 */}

Maps the wide character `ch` using the current C locale's [`LC_CTYPE`](/docs/cpp/library/text/locale/LC_categories) mapping category identified by `desc`.

{/* source:cpp-string-wide-towctrans:0002 */}

If the value of `ch` is neither representable as a `wchar_t` nor equal to the value of the macro `WEOF`, the behavior is undefined.

### Parameters

{/* source:cpp-string-wide-towctrans:0003 */}

<ParameterList>
  <Parameter name="ch">the wide character to map</Parameter>
  <Parameter name="desc">the [`LC_CTYPE`](/docs/cpp/library/text/locale/LC_categories) mapping, obtained from a call to [`std::wctrans`](/docs/cpp/library/text/wide/wctrans)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-towctrans:0004 */}

The mapped value of `ch` using the mapping identified by `desc` in [`LC_CTYPE`](/docs/cpp/library/text/locale/LC_categories) facet of the current C locale.

### Example

{/* source:cpp-string-wide-towctrans:0005 */}

The following example demonstrates katakana to hiragana character mapping.
```cpp
#include <algorithm>
#include <clocale>
#include <cwctype>
#include <iostream>
 
std::wstring tohira(std::wstring str)
{
    std::transform(str.begin(), str.end(), str.begin(), [](wchar_t c)
    {
         return std::towctrans(c, std::wctrans("tojhira"));
    });
    return str;
}
 
int main()
{
    std::setlocale(LC_ALL, "ja_JP.UTF-8");
    std::wstring kana = L"ヒラガナ";
    std::wcout << "katakana characters " << kana
               << " are " << tohira(kana) << " in hiragana\n";
}
```

Output:

```text
katakana characters ヒラガナ are ひらがな in hiragana
```
