{/* source:cpp-ranges-transform-view-iterator-operator-arith2:0001 */}
1. 1,2) Returns the iterator `i` incremented by `n`.

{/* source:cpp-ranges-transform-view-iterator-operator-arith2:0002 */}
2. 3) Returns the iterator `i` decremented by `n`.

{/* source:cpp-ranges-transform-view-iterator-operator-arith2:0003 */}
3. 4) Returns the distance between `x` and `y`.

{/* source:cpp-ranges-transform-view-iterator-operator-arith2:0004 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `transform_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-transform-view-iterator-operator-arith2:0006 */}
Let `parent_` denote the pointer to the parent `transform_view`, `current_` denote the underlying iterator.

{/* source:cpp-ranges-transform-view-iterator-operator-arith2:0007 */}
1. 1,2) `/*iterator*/{*i.parent_, i.current_ + n}`

{/* source:cpp-ranges-transform-view-iterator-operator-arith2:0008 */}
2. 3) `/*iterator*/{*i.parent_, i.current_ - n}`

{/* source:cpp-ranges-transform-view-iterator-operator-arith2:0009 */}
3. 4) `x.current_ - y.current_`
