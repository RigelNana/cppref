{/* source:cpp-ranges-transform-view-sentinel-operator:0001 */}
Computes the distance between the underlying iterator of `x` and the underlying sentinel of `y`.

{/* source:cpp-ranges-transform-view-sentinel-operator:0002 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `transform_view::sentinel<Const>` is an associated class of the arguments.

### Parameters

{/* source:cpp-ranges-transform-view-sentinel-operator:0003 */}
<ParameterList>
  <Parameter name="x">an [`iterator`](/docs/cpp/library/ranges/transform_view/iterator)</Parameter>
  <Parameter name="y">a sentinel</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-transform-view-sentinel-operator:0004 */}
Let `current_` denote the underlying iterator, `end_` denote the underlying sentinel.

{/* source:cpp-ranges-transform-view-sentinel-operator:0005 */}
1. 1) `x.current_ - y.end_`

{/* source:cpp-ranges-transform-view-sentinel-operator:0006 */}
2. 2) `y.end_ - x.current_`
