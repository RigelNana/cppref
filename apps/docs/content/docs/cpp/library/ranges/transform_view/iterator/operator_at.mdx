Returns the element at specified relative location, after transformation.

{/* source:cpp-ranges-transform-view-iterator-operator-at:0002 */}
Effectively returns `std::invoke(*parent_->fun_, current_[n])`, where `*parent_->fun_` is the transformation function stored in the parent `transform_view`, and `current_` is the underlying iterator into `V`.

### Parameters

{/* source:cpp-ranges-transform-view-iterator-operator-at:0003 */}
<ParameterList>
  <Parameter name="n">position relative to current location.</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-transform-view-iterator-operator-at:0004 */}
the transformed element
