{/* source:cpp-ranges-transform-view-end:0001 */}
Returns a [`sentinel`](/docs/cpp/library/ranges/transform_view/sentinel) or an [`iterator`](/docs/cpp/library/ranges/transform_view/iterator) representing the end of the `transform_view`.

{/* source:cpp-ranges-transform-view-end:0002 */}
Let [`base_`](/docs/cpp/library/ranges/transform_view#Data_members) be the underlying view. Equivalent to:

{/* source:cpp-ranges-transform-view-end:0003 */}
1. 1) `return /*sentinel*/<false>{ranges::end(base_)};`.

{/* source:cpp-ranges-transform-view-end:0004 */}
2. 2) `return /*iterator*/<false>{*this, ranges::end(base_)};`.

{/* source:cpp-ranges-transform-view-end:0005 */}
3. 3) `return /*sentinel*/<true>{ranges::end(base_)};`.

{/* source:cpp-ranges-transform-view-end:0006 */}
4. 4) `return /*iterator*/<true>{*this, ranges::end(base_)};`.

### Parameters

{/* source:cpp-ranges-transform-view-end:0007 */}
(none)

### Return value

{/* source:cpp-ranges-transform-view-end:0008 */}
1. 1,3) sentinel which compares equal to the end iterator

{/* source:cpp-ranges-transform-view-end:0009 */}
2. 2,4) iterator to the element following the last element

### Notes

{/* source:cpp-ranges-transform-view-end:0010 */}
`end()` returns an iterator if and only if the underlying view is a [`common_range`](/docs/cpp/library/ranges/common_range): `transform_view<V,F>` models [`common_range`](/docs/cpp/library/ranges/common_range) whenever `V` does.
