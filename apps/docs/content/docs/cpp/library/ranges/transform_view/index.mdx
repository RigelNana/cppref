{/* source:cpp-ranges-transform-view:0001 */}
1) A range adaptor that represents [`view`](/docs/cpp/library/ranges/view) of an underlying sequence after applying a transformation function to each element.

{/* source:cpp-ranges-transform-view:0002 */}
2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::transform(e, f)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `transform_view(e, f)` for any suitable subexpressions `e` and `f`.

{/* source:cpp-ranges-transform-view:0003 */}
`transform_view` models the concepts [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`input_range`](/docs/cpp/library/ranges/input_range), [`common_range`](/docs/cpp/library/ranges/common_range), and [`sized_range`](/docs/cpp/library/ranges/sized_range) when the underlying view `V` models respective concepts.

### Example

{/* source:cpp-ranges-transform-view:0007 */}
```cpp
#include <algorithm>
#include <cstdio>
#include <iterator>
#include <ranges>
#include <string>
 
char rot13a(const char x, const char a)
{
    return a + (x - a + 13) % 26;
}
 
char rot13(const char x)
{
    if ('Z' >= x and x >= 'A')
        return rot13a(x, 'A');
 
    if ('z' >= x and x >= 'a')
        return rot13a(x, 'a');
 
    return x;
}
 
int main()
{
    auto show = [](const unsigned char x) { std::putchar(x); };
 
    std::string in{"cppreference.com\n"};
    std::ranges::for_each(in, show);
    std::ranges::for_each(in | std::views::transform(rot13), show);
 
    std::string out;
    std::ranges::copy(std::views::transform(in, rot13), std::back_inserter(out));
    std::ranges::for_each(out, show);
    std::ranges::for_each(out | std::views::transform(rot13), show);
}
```

Output:

```text
cppreference.com
pccersrerapr.pbz
pccersrerapr.pbz
cppreference.com
```
