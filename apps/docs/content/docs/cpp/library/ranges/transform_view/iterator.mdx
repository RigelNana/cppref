{/* source:cpp-ranges-transform-view-iterator:0001 */}
The return type of [`transform_view::begin`](/docs/cpp/library/ranges/transform_view/begin), and of [`transform_view::end`](/docs/cpp/library/ranges/transform_view/end) when the underlying view is a [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-transform-view-iterator:0002 */}
The type `/*iterator*/<true>` is returned by the const-qualified overloads. The type `/*iterator*/<false>` is returned by the non-const-qualified overloads.
