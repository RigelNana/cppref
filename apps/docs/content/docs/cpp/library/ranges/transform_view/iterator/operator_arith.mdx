{/* source:cpp-ranges-transform-view-iterator-operator-arith:0001 */}
Increments or decrements the iterator.

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0002 */}
Let `current_` be the underlying iterator.

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0003 */}
1. 1) Equivalent to `++current_; return *this;`

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0004 */}
2. 2) Equivalent to `++current_;`

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0005 */}
3. 3) Equivalent to `auto tmp = *this; ++*this; return tmp;`

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0006 */}
4. 4) Equivalent to `--current_; return *this;`

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0007 */}
5. 5) Equivalent to `auto tmp = *this; --*this; return tmp;`

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0008 */}
6. 6) Equivalent to `current_ += n; return *this;`

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0009 */}
7. 7) Equivalent to `current_ -= n; return *this;`

### Return value

{/* source:cpp-ranges-transform-view-iterator-operator-arith:0011 */}
1. 1,4,6,7) `*this`

2. 3,5) a copy of `*this` that was made before the change
