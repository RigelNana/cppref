{/* source:cpp-ranges-transform-view-iterator-iter-move:0001 */}
If `*i` is an lvalue reference, returns [`std::move`](/docs/cpp/library/utility/move)`(*i)`; otherwise returns `*i`.

{/* source:cpp-ranges-transform-view-iterator-iter-move:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `transform_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-transform-view-iterator-iter-move:0004 */}
`std::move(*i)` if `*i` is an lvalue reference, otherwise `*i`
