Returns an [`iterator`](/docs/cpp/library/ranges/transform_view/iterator) to the first element of the `transform_view`.

{/* source:cpp-ranges-transform-view-begin:0002 */}
1. 1) Equivalent to `return /*iterator*/<false>{*this, ranges::begin(base_)};`, where [`base_`](/docs/cpp/library/ranges/transform_view#Data_members) is the underlying view.

{/* source:cpp-ranges-transform-view-begin:0003 */}
2. 2) Equivalent to `return /*iterator*/<true>{*this, ranges::begin(base_)};`, where `base_` is the underlying view.

### Parameters

{/* source:cpp-ranges-transform-view-begin:0004 */}
(none)

{/* source:cpp-ranges-transform-view-begin:0005 */}
