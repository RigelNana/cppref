Returns the number of elements.

{/* source:cpp-ranges-transform-view-size:0002 */}
Returns `ranges::size(base_)`, where [`base_`](/docs/cpp/library/ranges/transform_view#Data_members) is the underlying view.

### Parameters

{/* source:cpp-ranges-transform-view-size:0003 */}
(none)

### Return value

{/* source:cpp-ranges-transform-view-size:0004 */}
The number of elements.

### Notes

{/* source:cpp-ranges-transform-view-size:0005 */}
If `V` does not model [`forward_range`](/docs/cpp/library/ranges/forward_range), `size()` might not be well-defined after a call to [`begin()`](/docs/cpp/library/ranges/transform_view/begin).

### Example

{/* source:cpp-ranges-transform-view-size:0006 */}
```cpp
#include <cassert>
#include <cctype>
#include <iostream>
#include <ranges>
#include <string>
 
int main()
{
    std::string s{"The length of this string is 42 characters"};
    auto to_upper = [](unsigned char c) -> char { return std::toupper(c); };
    auto tv = std::ranges::transform_view{s, to_upper};
    assert(tv.size() == 42);
    for (auto x : tv)
        std::cout << x;
}
```

Output:

```text
THE LENGTH OF THIS STRING IS 42 CHARACTERS
```
