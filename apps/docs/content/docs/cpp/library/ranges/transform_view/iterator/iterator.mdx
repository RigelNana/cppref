Construct an iterator.

{/* source:cpp-ranges-transform-view-iterator-iterator:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying iterator, and initializes the pointer to parent `transform_view` with `nullptr`.

{/* source:cpp-ranges-transform-view-iterator-iterator:0003 */}
2. 2) Initializes the underlying iterator with `std::move(current)`, and the pointer to parent with `std::addressof(parent)`.

{/* source:cpp-ranges-transform-view-iterator-iterator:0004 */}
3. 3) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Move constructs corresponding members.
