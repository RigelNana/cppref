{/* source:cpp-ranges-as-rvalue-view:0001 */}
1) A range adaptor that represents a view of underlying [`view`](/docs/cpp/library/ranges/view) whose elements are rvalues.

{/* source:cpp-ranges-as-rvalue-view:0002 */}
2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). Let `e` be a subexpression and let `T` be `decltype((e))`. Then the expression `views::as_rvalue(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

- `views::all(e)`, if it is a well-formed expression, `T` models [`input_range`](/docs/cpp/library/ranges/input_range), and `std::same_as<ranges::range_rvalue_reference_t<T>, ranges::range_reference_t<T>>` is `true`;
- `as_rvalue_view{e}` otherwise.

### Example

{/* source:cpp-ranges-as-rvalue-view:0014 */}
```cpp
#include <algorithm>
#include <iostream>
#include <ranges>
#include <string>
#include <vector>
 
int main()
{
    std::vector<std::string> words =
        {"the", "quick", "brown", "\N{FOX FACE}", "ate", "an", "archeopteryx"};
    std::vector<std::string> new_words;
 
    std::ranges::copy(
        words | std::views::as_rvalue,
        std::back_inserter(new_words)); // move string from words into new_words
 
    auto quoted = std::views::transform([](auto&& s) { return "“" + s + "”"; });
 
    std::cout << "Words: ";
    for (auto&& word : words | std::views::as_rvalue | quoted)
        std::cout << word << ' ';
 
    std::cout << "\nNew words: ";
    for (auto&& word : new_words | std::views::as_rvalue | quoted)
        std::cout << word << ' ';
}
```

Possible output:

```text
Words: “” “” “” “” “” “” “” 
New words: “the” “quick” “brown” “🦊” “ate” “an” “archeopteryx”
```
