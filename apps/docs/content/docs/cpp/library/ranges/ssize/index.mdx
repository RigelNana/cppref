{/* source:cpp-ranges-ssize:0001 */}
Calculates the number of elements in `t` in constant time, and converts the result to a signed type.

{/* source:cpp-ranges-ssize:0002 */}
Given the [subexpression](/docs/cpp/language/expressions#Full-expressions) of which `t` denotes the (possibly [materialized](/docs/cpp/language/expressions/implicit_cast#Temporary_materialization)) result object as `E`:

{/* source:cpp-ranges-ssize:0003 */}
- If `ranges::size(t)` is ill-formed, `ranges::ssize(E)` is also ill-formed.
- Otherwise, let `Signed` be [`make-signed-like-t`](/docs/cpp/library/ranges#make-signed-like-t)`<decltype(ranges::size(t))>`:
  - If [`std::ptrdiff_t`](/docs/cpp/library/utility/types/ptrdiff_t) is wider than `Signed`, `ranges::ssize(E)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `static_cast<std::ptrdiff_t>(ranges::size(t))`.
  - Otherwise, `ranges::ssize(E)` is expression-equivalent to `static_cast<Signed>(ranges::size(t))`.

### Customization point objects

{/* source:cpp-ranges-ssize:0004 */}
The name `ranges::ssize` denotes a *customization point object*, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as `__ssize_fn`.

{/* source:cpp-ranges-ssize:0005 */}
All instances of `__ssize_fn` are equal. The effects of invoking different instances of type `__ssize_fn` on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `ranges::ssize` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-ssize:0006 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `ranges::ssize` above, `__ssize_fn` models

{/* source:cpp-ranges-ssize:0007 */}
- `std::invocable<__ssize_fn, Args...>`,
- `std::invocable<const __ssize_fn, Args...>`,
- `std::invocable<__ssize_fn&, Args...>`, and
- `std::invocable<const __ssize_fn&, Args...>`.

{/* source:cpp-ranges-ssize:0008 */}
Otherwise, no function call operator of `__ssize_fn` participates in overload resolution.

### Notes

{/* source:cpp-ranges-ssize:0009 */}
If `ranges::ssize(e)` is valid for an expression `e`, the return type is a [signed-integer-like type](/docs/cpp/library/iterator/is-integer-like).

### Example

{/* source:cpp-ranges-ssize:0010 */}
```cpp
#include <array>
#include <iostream>
#include <ranges>
#include <type_traits>
 
int main()
{
    std::array arr{1, 2, 3, 4, 5};
    auto s = std::ranges::ssize(arr);
 
    std::cout << "ranges::ssize(arr) = " << s << '\n'
              << "ranges::ssize is "
              << (std::is_signed_v<decltype(s)> ? "signed" : "unsigned")
              << '\n';
 
    std::cout << "reversed arr: ";
 
    for (--s; s >= 0; --s)
        std::cout << arr[s] << ' ';
 
    std::cout << "\n" "s = " << s << '\n';
}
```

Output:

```text
ranges::ssize(arr) = 5
ranges::ssize is signed
reversed arr: 5 4 3 2 1
s = -1
```
