{/* source:cpp-ranges-all-view:0001 */}
1) A [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject) (also a [*RangeAdaptorClosureObject*](/docs/cpp/library/named_req/RangeAdaptorClosureObject)) that returns a [`view`](/docs/cpp/library/ranges/view) that includes all elements of its [`range`](/docs/cpp/library/ranges/range) argument.

{/* source:cpp-ranges-all-view:0002 */}
Given an expression `e` of type `R`, the expression `views::all(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

- Implicitly converting `e` to a `std::decay_t<R>` prvalue, if `std::decay_t<R>` models [`view`](/docs/cpp/library/ranges/view).
- Otherwise, `std::ranges::ref_view{e}` if that expression is well-formed.
- Otherwise, `std::ranges::owning_view{e}`.

{/* source:cpp-ranges-all-view:0003 */}
2) Calculates the suitable [`view`](/docs/cpp/library/ranges/view) type of a [`viewable_range`](/docs/cpp/library/ranges/viewable_range) type.

### Example

{/* source:cpp-ranges-all-view:0004 */}
```cpp
#include <iostream>
#include <ranges>
#include <type_traits>
#include <vector>
 
int main()
{
    std::vector<int> v{0, 1, 2, 3, 4, 5};
    for (int n : std::views::all(v) | std::views::take(2))
        std::cout << n << ' ';
    std::cout << '\n';
 
    static_assert(std::is_same<
        decltype(std::views::single(42)),
        std::ranges::single_view<int>
        >{});
 
    static_assert(std::is_same<
        decltype(std::views::all(v)),
        std::ranges::ref_view<std::vector<int, std::allocator<int>>>
        >{});
 
    int a[]{1, 2, 3, 4};
    static_assert(std::is_same<
        decltype(std::views::all(a)),
        std::ranges::ref_view<int[4]>
        >{});
 
    static_assert(std::is_same<
        decltype(std::ranges::subrange{std::begin(a) + 1, std::end(a) - 1}),
        std::ranges::subrange<int*, int*, std::ranges::subrange_kind(1)>
        >{});
}
```

Output:

```text
0 1
```
