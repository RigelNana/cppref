{/* source:cpp-ranges-iota-view-iterator:0001 */}
1. 1) `ranges::iota_view<W, Bound>::iterator` is the type of the iterators returned by [`begin()`](/docs/cpp/library/ranges/iota_view/begin) and [`end()`](/docs/cpp/library/ranges/iota_view/end) of `ranges::iota_view<W, Bound>`.

{/* source:cpp-ranges-iota-view-iterator:0002 */}
2. 2) Calculates the difference type for both iterator types and [integer-like types](/docs/cpp/library/iterator/is-integer-like).
   - If `I` is not an integral type, or if it is an integral type and `sizeof(std::iter_difference_t<I>)` is greater than `sizeof(I)`, then `/*iota-diff-t*/<I>` is `std::iter_difference_t<I>`.
   - Otherwise, `/*iota-diff-t*/<I>` is a signed integer type of width greater than the width of `I` if such a type exists.
   - Otherwise, `I` is one of the widest integral types, and `/*iota-diff-t*/<I>` is an unspecified [signed-integer-like type](/docs/cpp/library/iterator/is-integer-like) of width not less than the width of `I`. It is unspecified whether `/*iota-diff-t*/<I>` models [`weakly_incrementable`](/docs/cpp/library/iterator/weakly_incrementable) in this case.

{/* source:cpp-ranges-iota-view-iterator:0003 */}
3. 3) Specifies that a type is [`incrementable`](/docs/cpp/library/iterator/incrementable), and pre- and post- `operator--` for the type have common meaning.

{/* source:cpp-ranges-iota-view-iterator:0004 */}
4. 4) Specifies that a type is both [`decrementable`](/docs/cpp/library/ranges/iota_view/iterator#decrementable) and [`totally_ordered`](/docs/cpp/library/concepts/totally_ordered), and `operator+=`, `operator-=`, `operator+`, and `operator-` among the type and its different type have common meaning.

{/* source:cpp-ranges-iota-view-iterator:0005 */}
`/*iterator*/` models

{/* source:cpp-ranges-iota-view-iterator:0006 */}
- [`random_access_iterator`](/docs/cpp/library/iterator/random_access_iterator) if `W` models [`advanceable`](/docs/cpp/library/ranges/iota_view/iterator#advanceable) (4),
- [`bidirectional_iterator`](/docs/cpp/library/iterator/bidirectional_iterator) if `W` models [`decrementable`](/docs/cpp/library/ranges/iota_view/iterator#decrementable) (3),
- [`forward_iterator`](/docs/cpp/library/iterator/forward_iterator) if `W` models [`incrementable`](/docs/cpp/library/iterator/incrementable), and
- [`input_iterator`](/docs/cpp/library/iterator/input_iterator) otherwise.

{/* source:cpp-ranges-iota-view-iterator:0007 */}
However, it only satisfies [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator) if `W` models [`incrementable`](/docs/cpp/library/iterator/incrementable), and does not satisfy [LegacyInputIterator](/docs/cpp/library/named_req/InputIterator) otherwise.

### Semantic requirements

{/* source:cpp-ranges-iota-view-iterator:0008 */}
3. 3) Type `I` models `decrementable` only if `I` satisfies `decrementable` and all concepts it subsumes are modeled, and given equal objects `a` and `b` of type `I`:
   - If `a` and `b` are in the domain of both pre- and post- `operator--` (i.e. they are decrementable), then the following are all `true`:
     - `std::addressof(--a) == std::addressof(a)`,
     - `bool(a-- == b)`,
     - `bool(((void)a--, a) == --b)`,
     - `bool(++(--a) == b)`.
   - If `a` and `b` are in the domain of both pre- and post- `operator++` (i.e. they are incrementable), then `bool(--(++a) == b)` is `true`.

{/* source:cpp-ranges-iota-view-iterator:0009 */}
4. 4) Let `D` denote `/*iota-diff-t*/<I>`. Type `I` models [`advanceable`](/docs/cpp/library/ranges/iota_view/iterator#advanceable) only if `I` satisfies [`advanceable`](/docs/cpp/library/ranges/iota_view/iterator#advanceable) and all concepts it subsumes are modeled, and given
   - objects `a` and `b` of type `I` and
   - value `n` of type `D`,

   such that `b` is reachable from `a` after `n` applications of `++a`, all following conditions are satisfied:
   - `(a += n)` is equal to `b`.
   - `std::addressof(a += n)` is equal to `std::addressof(a)`.
   - `I(a + n)` is equal to `(a += n)`.
   - For any two positive values `x` and `y` of type `D`, if `I(a + D(x + y))` is well-defined, then `I(a + D(x + y))` is equal to `I(I(a + x) + y)`.
   - `I(a + D(0))` is equal to `a`.
   - If `I(a + D(n - 1))` is well-defined, then `I(a + n)` is equal to `[](I c) { return ++c; }(I(a + D(n - 1)))`.
   - `(b += -n)` is equal to `a`.
   - `(b -= n)` is equal to `a`.
   - `std::addressof(b -= n)` is equal to `std::addressof(b)`.
   - `I(b - n)` is equal to `(b -= n)`.
   - `D(b - a)` is equal to `n`.
   - `D(a - b)` is equal to `D(-n)`.
   - `bool(a <= b)` is `true`.

#### Determining the iterator concept

{/* source:cpp-ranges-iota-view-iterator:0011 */}
`iterator_concept` is defined as follows:

{/* source:cpp-ranges-iota-view-iterator:0012 */}
- If `W` models [`advanceable`](/docs/cpp/library/ranges/iota_view/iterator#advanceable), `iterator_concept` denotes [`std::random_access_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).
- Otherwise, if `W` models [`decrementable`](/docs/cpp/library/ranges/iota_view/iterator#decrementable), `iterator_concept` denotes [`std::bidirectional_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).
- Otherwise, if `W` models [`incrementable`](/docs/cpp/library/iterator/incrementable), `iterator_concept` denotes [`std::forward_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).
- Otherwise, `iterator_concept` denotes [`std::input_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).

Updates [`value_`](/docs/cpp/library/ranges/iota_view/iterator#value) and returns `*this`:
- If `W` is an [unsigned-integer-like type](/docs/cpp/library/iterator/is-integer-like):
  - If `n` is non-negative, performs [`value_`](/docs/cpp/library/ranges/iota_view/iterator#value) `+= static_cast<W>(n)`.
  - Otherwise, performs [`value_`](/docs/cpp/library/ranges/iota_view/iterator#value) `-= static_cast<W>(-n)`.
- Otherwise, performs [`value_`](/docs/cpp/library/ranges/iota_view/iterator#value) `+= n`.
