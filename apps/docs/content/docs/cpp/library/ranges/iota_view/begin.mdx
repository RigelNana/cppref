Obtains an [`iterator`](/docs/cpp/library/ranges/iota_view/iterator) to the beginning value.

### Return value

{/* source:cpp-ranges-iota-view-begin:0002 */}
[`iterator`](/docs/cpp/library/ranges/iota_view/iterator)\{[`value_`](/docs/cpp/library/ranges/iota_view#value)\}

### Example

{/* source:cpp-ranges-iota-view-begin:0003 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    auto iota{std::views::iota(2, 6)};
    auto iter{iota.begin()};
    while (iter != iota.end())
        std::cout << *iter++ << ' ';
    std::cout << '\n';
}
```

Output:

```text
2 3 4 5
```
