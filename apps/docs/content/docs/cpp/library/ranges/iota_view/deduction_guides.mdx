This [deduction guide](/docs/cpp/language/templates/ctad) is provided for [`iota_view`](/docs/cpp/library/ranges/iota_view) to allow deduction from an initial value and a bounding value.

{/* source:cpp-ranges-iota-view-deduction-guides:0002 */}
For the definitions of `/*is-integer-like*/` and `/*is-signed-integer-like*/`, see [is-integer-like](/docs/cpp/library/iterator/is-integer-like).

{/* source:cpp-ranges-iota-view-deduction-guides:0003 */}
Note that the guide protects itself against bugs arising from sign mismatch, like `views::iota(0, v.size())`, where `​0​` is signed and `v.size()` is unsigned.

### Example

{/* source:cpp-ranges-iota-view-deduction-guides:0004 */}
```cpp
#include <cassert>
#include <ranges>
 
int main()
{
    auto io = std::ranges::iota_view(1L, 7L); // deduces W and Bound as “long”
    assert(io.front() == 1L and io.back() == 6L);
}
```
