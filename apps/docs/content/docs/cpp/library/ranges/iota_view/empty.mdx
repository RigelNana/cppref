{/* source:cpp-ranges-iota-view-empty:0001 */}
Checks whether the range is empty (i.e. whether the beginning value is the same as the sentinel value).

### Return value

{/* source:cpp-ranges-iota-view-empty:0002 */}
[`value_`](/docs/cpp/library/ranges/iota_view#value) `==` [`bound_`](/docs/cpp/library/ranges/iota_view#bound)

### Example

{/* source:cpp-ranges-iota-view-empty:0003 */}
```cpp
#include <cassert>
#include <ranges>
 
int main()
{
    auto a = std::ranges::iota_view<int, int>();
    assert(a.empty());
 
    auto b = std::ranges::iota_view(4);
    assert(!b.empty());
 
    auto c = std::ranges::iota_view(4, 8);
    assert(!c.empty());
}
```
