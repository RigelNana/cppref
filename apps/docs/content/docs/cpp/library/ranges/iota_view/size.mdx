{/* source:cpp-ranges-iota-view-size:0001 */}
Returns the size of the view if the view is bounded.

{/* source:cpp-ranges-iota-view-size:0002 */}
For the definitions of `/*advanceable*/` and `/*is-integer-like*/`, see [advanceable](/docs/cpp/library/ranges/iota_view/iterator#advanceable) and [is-integer-like](/docs/cpp/library/iterator/is-integer-like) respectively.

### Return value

{/* source:cpp-ranges-iota-view-size:0003 */}
If any of `W` and `Bound` is not a [integer-like type](/docs/cpp/library/iterator/is-integer-like), returns [`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)([`bound_`](/docs/cpp/library/ranges/iota_view#bound) `-` [`value_`](/docs/cpp/library/ranges/iota_view#value)).

{/* source:cpp-ranges-iota-view-size:0004 */}
Otherwise, returns `(`[`value_`](/docs/cpp/library/ranges/iota_view#value) `< 0) ?` `(`[`bound_`](/docs/cpp/library/ranges/iota_view#bound) `< 0) ?` [`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(-`[`value_`](/docs/cpp/library/ranges/iota_view#value)`) - `[`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(-`[`bound_`](/docs/cpp/library/ranges/iota_view#bound)`) : `[`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(`[`bound_`](/docs/cpp/library/ranges/iota_view#bound)`) + `[`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(-`[`value_`](/docs/cpp/library/ranges/iota_view#value)`)) : `[`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(`[`bound_`](/docs/cpp/library/ranges/iota_view#bound)`) - `[`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(`[`value_`](/docs/cpp/library/ranges/iota_view#value)`).

### Example

{/* source:cpp-ranges-iota-view-size:0005 */}
```cpp
#include <cassert>
#include <ranges>
 
int main()
{
    unsigned initial_value{1}, bound{5};
    auto i{std::views::iota(initial_value, bound)};
    assert(i.size() == bound - initial_value and i.size() == 4);
 
    auto u{std::views::iota(8)};
    // assert(u.size()); // Error: size() is not present since “u” is unbounded
}
```
