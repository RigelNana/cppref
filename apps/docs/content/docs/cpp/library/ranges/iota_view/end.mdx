{/* source:cpp-ranges-iota-view-end:0001 */}
1. 1) Obtains a [sentinel](/docs/cpp/library/ranges/iota_view/sentinel) representing the sentinel value:
   - If `Bound` is [`std::unreachable_sentinel_t`](/docs/cpp/library/iterator/unreachable_sentinel_t), returns `std::unreachable_sentinel`.
   - Otherwise, returns [`sentinel`](/docs/cpp/library/ranges/iota_view/sentinel)\{[`bound_`](/docs/cpp/library/ranges/iota_view#bound)\}.

{/* source:cpp-ranges-iota-view-end:0002 */}
2. 2) Obtains an [`iterator`](/docs/cpp/library/ranges/iota_view/iterator) to the sentinel value.

### Return value

{/* source:cpp-ranges-iota-view-end:0003 */}
1. 1) As specified above.

{/* source:cpp-ranges-iota-view-end:0004 */}
2. 2) [`iterator`](/docs/cpp/library/ranges/iota_view/iterator)\{[`bound_`](/docs/cpp/library/ranges/iota_view#bound)\}

### Example

{/* source:cpp-ranges-iota-view-end:0005 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    auto iota{std::views::iota(2, 6)};
    auto end{iota.end()};
    for (auto iter{iota.begin()}; iter != end; ++iter)
        std::cout << *iter << ' ';
    std::cout << '\n';
}
```

Output:

```text
2 3 4 5
```
