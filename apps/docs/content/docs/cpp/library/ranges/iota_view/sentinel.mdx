`ranges::iota_view<W, Bound>::sentinel` is the type of the reachable sentinels returned by [`end()`](/docs/cpp/library/ranges/iota_view/end) of `ranges::iota_view<W, Bound>`.

**operator==(std::ranges::iota_view::iterator, std::ranges::iota_view::sentinel)**

<DeclarationDoc>

Returns `x.`[`value_`](/docs/cpp/library/ranges/iota_view/iterator#value)` == y.`[`bound_`](/docs/cpp/library/ranges/iota_view/sentinel#bound).

The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `sentinel` is an associated class of the arguments.
