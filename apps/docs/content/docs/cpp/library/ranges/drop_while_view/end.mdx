Returns a sentinel or an iterator representing the end of the `drop_while_view`.

{/* source:cpp-ranges-drop-while-view-end:0002 */}
Effectively returns `ranges::end(base_)`, where [`base_`](/docs/cpp/library/ranges/drop_while_view#Data_members) is the underlying view.

### Parameters

{/* source:cpp-ranges-drop-while-view-end:0003 */}
(none)

### Return value

{/* source:cpp-ranges-drop-while-view-end:0004 */}
A sentinel or an iterator representing the end of the view.

### Example

{/* source:cpp-ranges-drop-while-view-end:0005 */}
```cpp
#include <cassert>
#include <iostream>
#include <ranges>
 
int main()
{
    static constexpr auto data = {0, -1, -2, 3, 1, 4, 1, 5}; 
    auto view = std::ranges::drop_while_view{data, [](int x) { return x <= 0; }};
    assert(view.end()[-1] == 5);
}
```
