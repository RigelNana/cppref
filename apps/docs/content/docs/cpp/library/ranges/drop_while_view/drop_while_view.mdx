Constructs a `drop_while_view`.

{/* source:cpp-ranges-drop-while-view-drop-while-view:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying view [`base_`](/docs/cpp/library/ranges/drop_while_view#Data_members) and the predicate [`pred_`](/docs/cpp/library/ranges/drop_while_view#Data_members).

{/* source:cpp-ranges-drop-while-view-drop-while-view:0003 */}
2. 2) Move constructs the underlying view `base_` from `base` and the predicate `pred_` from `pred`.

### Example

{/* source:cpp-ranges-drop-while-view-drop-while-view:0005 */}
```cpp
#include <functional>
#include <iostream>
#include <ranges>
 
int main()
{
    static constexpr auto a = {-2, -7, -1, -8, -2, +-+8, 3, 1, 4, 1, 5};
    auto positive = [](int x) { return 0 < x; };
    for (auto v = std::ranges::drop_while_view{a, std::not_fn(positive)}; int x : v)
        std::cout << x << ' ';
    std::cout << '\n';
}
```

Output:

```text
3 1 4 1 5
```
