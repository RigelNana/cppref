{/* source:cpp-ranges-drop-while-view-begin:0001 */}
Returns an iterator to the first element of the view.

{/* source:cpp-ranges-drop-while-view-begin:0002 */}
Effectively returns `ranges::find_if_not(base_, std::cref(pred()))`, where [`base_`](/docs/cpp/library/ranges/drop_while_view#Data_members) is the underlying view. The behavior is undefined if `*this` does not store a predicate.

{/* source:cpp-ranges-drop-while-view-begin:0003 */}
In order to provide the amortized constant time complexity required by the [`range`](/docs/cpp/library/ranges/range) concept, this function caches the result within the `drop_while_view` object for use on subsequent calls.

### Parameters

{/* source:cpp-ranges-drop-while-view-begin:0004 */}
(none)

### Return value

{/* source:cpp-ranges-drop-while-view-begin:0005 */}
Iterator to the first element of the view.

### Example

{/* source:cpp-ranges-drop-while-view-begin:0006 */}
```cpp
#include <cassert>
#include <ranges>
 
int main()
{
    static constexpr auto data = {0, -1, -2, 3, 1, 4, 1, 5};
    auto view = std::ranges::drop_while_view{data, [](int x){ return x <= 0; }};
    assert(view.begin()[0] == 3);
}
```
