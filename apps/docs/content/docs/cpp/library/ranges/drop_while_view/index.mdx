{/* source:cpp-ranges-drop-while-view:0001 */}
1. 1) A range adaptor that represents [`view`](/docs/cpp/library/ranges/view) of elements from an underlying sequence, beginning at the first element for which the predicate returns `false`.

{/* source:cpp-ranges-drop-while-view:0002 */}
2. 2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::drop_while(e, f)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `drop_while_view(e, f)` for any suitable subexpressions `e` and `f`.

{/* source:cpp-ranges-drop-while-view:0003 */}
`drop_while_view` models the concepts [`contiguous_range`](/docs/cpp/library/ranges/contiguous_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`input_range`](/docs/cpp/library/ranges/input_range), and [`common_range`](/docs/cpp/library/ranges/common_range) when the underlying view `V` models respective concepts. It also models [`sized_range`](/docs/cpp/library/ranges/sized_range) if `ranges::forward_range<V>` and `std::sized_sentinel_for<ranges::sentinel_t<V>, ranges::iterator_t<V>>` are modeled.

This specialization of `std::ranges::enable_borrowed_range` makes `drop_while_view` satisfy [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range) when the underlying view satisfies it.

### Notes

{/* source:cpp-ranges-drop-while-view:0008 */}
In order to provide the amortized constant time complexity required by the [`range`](/docs/cpp/library/ranges/range) concept, the result of [`begin`](/docs/cpp/library/ranges/drop_while_view/begin) is cached within the `drop_while_view` object. If the underlying range is modified after the first call to `begin()`, subsequent uses of the `drop_while_view` object might have unintuitive behavior.

### Example

{/* source:cpp-ranges-drop-while-view:0009 */}
```cpp
#include <iostream>
#include <ranges>
#include <string>
#include <string_view>
 
using std::operator""sv;
 
[[nodiscard]]
constexpr bool is_space(char p) noexcept
{
    auto ne = [p](auto q) { return p != q; };
    return !!(" \t\n\v\r\f" | std::views::drop_while(ne));
};
 
[[nodiscard("trims the output")]]
constexpr std::string_view trim_left(std::string_view const in) noexcept
{
    auto view = in | std::views::drop_while(is_space);
    return {view.begin(), view.end()};
}
 
[[nodiscard("trims the output")]]
constexpr std::string trim(std::string_view const in)
{
    auto view = in
              | std::views::drop_while(is_space)
              | std::views::reverse
              | std::views::drop_while(is_space)
              | std::views::reverse
              ;
    return {view.begin(), view.end()};
}
 
int main()
{
    static_assert(trim_left(" \n C++23") == "C++23"sv);
 
    constexpr auto src{" \f\n\t\r\vHello, C++20!\f\n\t\r\v "sv};
    static_assert(trim(src) == "Hello, C++20!");
 
    static constexpr auto v = {0, 1, 2, 3, 4, 5};
    for (int n : v | std::views::drop_while([](int i) { return i < 3; }))
        std::cout << n << ' ';
    std::cout << '\n';
}
```

Output:

```text
3 4 5
```
