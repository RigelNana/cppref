{/* source:cpp-ranges-drop-while-view-base:0001 */}
Returns a copy of the underlying view.

{/* source:cpp-ranges-drop-while-view-base:0002 */}
1. 1) Copy constructs the result from the underlying view [`base_`](/docs/cpp/library/ranges/drop_while_view#Data_members).

{/* source:cpp-ranges-drop-while-view-base:0003 */}
2. 2) Move constructs the result from the underlying view *`base_`*.

### Parameters

{/* source:cpp-ranges-drop-while-view-base:0004 */}
(none)

### Return value

{/* source:cpp-ranges-drop-while-view-base:0005 */}
A copy of the underlying view.

### Example

{/* source:cpp-ranges-drop-while-view-base:0006 */}
```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <ranges>
 
void print(auto first, auto last)
{
    for (; first != last; ++first)
        std::cout << *first << ' ';
    std::cout << '\n';
}
 
int main()
{
    std::array data{1, 2, 3, 4, 5};
    print(data.cbegin(), data.cend());
 
    auto func = [](int x) { return x < 3; };
    auto view = std::ranges::drop_while_view{data, func};
    print(view.begin(), view.end());
 
    auto base = view.base(); // `base` refers to the `data`
    std::ranges::reverse(base); //< changes `data` indirectly
    print(data.cbegin(), data.cend());
}
```

Output:

```text
1 2 3 4 5
3 4 5
5 4 3 2 1
```
