{/* source:cpp-ranges-zip-transform-view-iterator-operator-cmp:0001 */}
Compares the underlying iterators. Let [`inner_`](/docs/cpp/library/ranges/zip_transform_view/iterator#Data_members) denote the underlying iterator.

{/* source:cpp-ranges-zip-transform-view-iterator-operator-cmp:0002 */}
Equivalent to:

{/* source:cpp-ranges-zip-transform-view-iterator-operator-cmp:0003 */}
1) `return x.inner_ == y.inner_;`

{/* source:cpp-ranges-zip-transform-view-iterator-operator-cmp:0004 */}
2) `return x.inner_ <=> y.inner_;`

{/* source:cpp-ranges-zip-transform-view-iterator-operator-cmp:0005 */}
These functions are not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::ranges::zip_transform_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-zip-transform-view-iterator-operator-cmp:0006 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [`synthesized`](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
