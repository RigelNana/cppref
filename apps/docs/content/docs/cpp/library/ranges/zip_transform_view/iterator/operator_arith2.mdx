{/* source:cpp-ranges-zip-transform-view-iterator-operator-arith2:0001 */}
Let [`inner_`](/docs/cpp/library/ranges/zip_transform_view/iterator#Data_members) denote the underlying iterator.

{/* source:cpp-ranges-zip-transform-view-iterator-operator-arith2:0002 */}
1,2) Returns the iterator `i` incremented by `n`. Equivalent to: `return /*iterator*/(*i.parent_, i.inner_ + n);`.

{/* source:cpp-ranges-zip-transform-view-iterator-operator-arith2:0003 */}
3) Returns the iterator `i` decremented by `n`. Equivalent to: `return /*iterator*/(*i.parent_, i.inner_ - n);`.

{/* source:cpp-ranges-zip-transform-view-iterator-operator-arith2:0004 */}
4) Calculates the *distance* between `i` and `j`. Equivalent to `return i.inner_ - j.inner_;`.

{/* source:cpp-ranges-zip-transform-view-iterator-operator-arith2:0005 */}
This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `zip_transform_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-zip-transform-view-iterator-operator-arith2:0007 */}

{/* source:cpp-ranges-zip-transform-view-iterator-operator-arith2:0008 */}
3) `/*iterator*/{ inner_ - n }`

{/* source:cpp-ranges-zip-transform-view-iterator-operator-arith2:0009 */}
4) `i.inner_ - j.inner_`
