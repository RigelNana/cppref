Compares the underlying iterator of `x` with the underlying sentinel of `y`.

{/* source:cpp-ranges-zip-transform-view-sentinel-operator-cmp:0002 */}
This function template is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `zip_transform_view::sentinel` is an associated class of the arguments.

{/* source:cpp-ranges-zip-transform-view-sentinel-operator-cmp:0003 */}
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Return value

{/* source:cpp-ranges-zip-transform-view-sentinel-operator-cmp:0005 */}
`x.inner_ == y.inner_`, where `inner_` denotes the underlying iterator or sentinel respectively.
