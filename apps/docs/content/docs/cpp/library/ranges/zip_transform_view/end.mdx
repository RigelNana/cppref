{/* source:cpp-ranges-zip-transform-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/zip_transform_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/zip_transform_view/sentinel) that compares equal to the end iterator of the [`zip_transform_view`](/docs/cpp/library/ranges/zip_transform_view).

{/* source:cpp-ranges-zip-transform-view-end:0002 */}
Let `zip_` denote the underlying tuple of views:

{/* source:cpp-ranges-zip-transform-view-end:0003 */}
1) Equivalent to:

```cpp
if constexpr (ranges::common_range</*InnerView*/>)
    return /*iterator*/<false>(*this, zip_.end());
else

    return /*sentinel*/<false>(zip_.end());
```

{/* source:cpp-ranges-zip-transform-view-end:0004 */}
2) Equivalent to:

```cpp
if constexpr (ranges::common_range<const /*InnerView*/>)
    return /*iterator*/<true>(*this, zip_.end());
else

    return /*sentinel*/<true>(zip_.end());
```

### Parameters

{/* source:cpp-ranges-zip-transform-view-end:0005 */}
(none)

### Return value

{/* source:cpp-ranges-zip-transform-view-end:0006 */}
An iterator or sentinel representing the end of the `zip_transform_view`, as described above.
