Obtains the beginning iterator of `zip_transform_view`.

{/* source:cpp-ranges-zip-transform-view-begin:0002 */}
1) Equivalent to `return /*iterator*/<false>(*this, zip_.begin());`.

{/* source:cpp-ranges-zip-transform-view-begin:0003 */}
2) Equivalent to `return /*iterator*/<true>(*this, zip_.begin());`.

### Parameters

{/* source:cpp-ranges-zip-transform-view-begin:0004 */}
(none)

### Return value

{/* source:cpp-ranges-zip-transform-view-begin:0005 */}
[`Iterator`](/docs/cpp/library/ranges/zip_transform_view/iterator) to the first element.

### Notes

{/* source:cpp-ranges-zip-transform-view-begin:0006 */}
`ranges::range<const ranges::zip_view<Views...>>` is modeled if and only if for every type `Vi` in `Views...`, `const Vi` models [`range`](/docs/cpp/library/ranges/range).
