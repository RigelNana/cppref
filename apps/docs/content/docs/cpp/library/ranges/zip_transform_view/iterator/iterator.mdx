{/* source:cpp-ranges-zip-transform-view-iterator-iterator:0001 */}
Construct an iterator.

{/* source:cpp-ranges-zip-transform-view-iterator-iterator:0002 */}
1) Default constructor. [`Default-initializes`](/docs/cpp/language/initialization/default_initialization) the underlying iterators, and [`value-initializes`](/docs/cpp/language/initialization/value_initialization) the pointer to parent `ranges::zip_transform_view` with `nullptr`.

{/* source:cpp-ranges-zip-transform-view-iterator-iterator:0003 */}
2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Move constructs the underlying pointer to parent [`parent_`](/docs/cpp/library/ranges/zip_transform_view/iterator#Data_members) with `i.parent_` and [`inner_`](/docs/cpp/library/ranges/zip_transform_view/iterator#Data_members) with `std::move(i.inner_)`.

{/* source:cpp-ranges-zip-transform-view-iterator-iterator:0004 */}
3) Initializes the pointer to parent `parent_` with `std::addressof(parent)`, and the underlying `inner_` iterator with `std::move(inner)`. This constructor is not accessible to users.
