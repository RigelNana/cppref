{/* source:cpp-ranges-zip-transform-view-zip-transform-view:0001 */}
1) Default constructor. [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) the stored invocable object and all adapted [`view`](/docs/cpp/library/ranges/view) objects.

The default constructor is deleted if `F` does not satisfy [`default_initializable`](/docs/cpp/library/concepts/default_initializable), or [`std::is_default_constructible_v`](/docs/cpp/library/meta/is_default_constructible) is `false` for at least one type in `Views...`.

{/* source:cpp-ranges-zip-transform-view-zip-transform-view:0002 */}
2) Move constructs the stored invocable object from `fun` and every adapted [`view`](/docs/cpp/library/ranges/view) object from the corresponding view in `views...`.
