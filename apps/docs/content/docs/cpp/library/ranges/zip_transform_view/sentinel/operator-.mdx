{/* source:cpp-ranges-zip-transform-view-sentinel-operator:0001 */}
Computes the distance between the underlying iterator of `x` and the underlying sentinel of `y`.

{/* source:cpp-ranges-zip-transform-view-sentinel-operator:0002 */}
These function templates are not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `zip_transform_view::sentinel` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-zip-transform-view-sentinel-operator:0004 */}
Let `inner_` denote the underlying iterator or sentinel respectively.

{/* source:cpp-ranges-zip-transform-view-sentinel-operator:0005 */}
1) `x.inner_ - y.inner_`

{/* source:cpp-ranges-zip-transform-view-sentinel-operator:0006 */}
