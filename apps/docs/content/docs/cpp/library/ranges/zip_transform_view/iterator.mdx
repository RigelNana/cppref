{/* source:cpp-ranges-zip-transform-view-iterator:0001 */}
The iterator type of a possibly const-qualified `zip_transform_view`, returned by [`zip_transform_view::begin`](/docs/cpp/library/ranges/zip_transform_view/begin) and in certain cases by [`zip_transform_view::end`](/docs/cpp/library/ranges/zip_transform_view/end).

{/* source:cpp-ranges-zip-transform-view-iterator:0002 */}
The type `/*iterator*/<true>` or `/*iterator*/<false>` treats the underlying views as const-qualified or non-const-qualified respectively.

    Let `/*maybe-const*/<Const, F>&` denote `const F&` if `Const` is `true`, `F&` otherwise. Let `/*maybe-const*/<Const, Views>` denote `const Views` if `Const` is `true`, `Views` otherwise. Let `/*POT*/` denote the pack of types `std::iterator_traits<std::iterator_t<    /*maybe-const*/<Const, Views>>>::iterator_category...`. If `/*Base*/` models [`forward_range`](/docs/cpp/library/ranges/forward_range), then `iterator_category` denotes:

    - [`std::input_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `std::invoke_result_t</*maybe-const*/<Const, F>&,    ranges::range_reference_t</*maybe-const*/<Const, Views>>...>` is not a reference.
    - Otherwise, [`std::random_access_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `(std::derived_from</*POT*/, std::random_access_iterator_tag> && ...)` is true.
    - Otherwise, [`std::bidirectional_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `(std::derived_from</*POT*/, std::bidirectional_iterator_tag> && ...)` is true.
    - Otherwise, [`std::forward_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `(std::derived_from</*POT*/, std::forward_iterator_tag> && ...)` is true.
    - Otherwise, [`std::input_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).

    Not present if `/*Base*/` does not model [`forward_range`](/docs/cpp/library/ranges/forward_range).

</DescriptionBody>
