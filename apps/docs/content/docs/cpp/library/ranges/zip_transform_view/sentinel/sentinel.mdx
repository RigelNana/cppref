Constructs a sentinel.

{/* source:cpp-ranges-zip-transform-view-sentinel-sentinel:0002 */}
1) Default constructor. [`Default-initializes`](/docs/cpp/language/initialization/default_initialization) the underlying sentinel object [`inner_`](/docs/cpp/library/ranges/zip_transform_view/sentinel#Data_members).

{/* source:cpp-ranges-zip-transform-view-sentinel-sentinel:0003 */}
2) Conversion from `/*sentinel*/<false>` to `/*sentinel*/<true>`. Move constructs the underlying object `inner_` with `std::move(i.inner_)`.

{/* source:cpp-ranges-zip-transform-view-sentinel-sentinel:0004 */}
3) [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) the underlying object `inner_` with `inner`. This constructor is not accessible to users.
