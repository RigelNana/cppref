{/* source:cpp-ranges-zip-transform-view:0001 */}
1) `zip_transform_view` is a range adaptor that takes an invocable object and one or more [`view`](/docs/cpp/library/ranges/view)s, and produces a [`view`](/docs/cpp/library/ranges/view) whose `i`th element is the result of applying the invocable object to the `i`th elements of all views.

A type `T` models the exposition-only concept `/*can-reference*/` if and only if `T&` is a valid type.

{/* source:cpp-ranges-zip-transform-view:0002 */}
2) `views::zip_transform` is a customization point object.

When calling with one argument `f`, let `FD` be `std::decay_t<decltype(f)>`, if:

- `FD` models [`copy_constructible`](/docs/cpp/library/concepts/copy_constructible),
- `FD&` models [`regular_invocable`](/docs/cpp/library/concepts/invocable), and
- `std::invoke_result_t<FD&>` is an object type,

then `views::zip_transform(f)` is [`expression-equivalent`](/docs/cpp/language/expressions#Expression-equivalence) to `((void)f, auto(views::empty<std::decay_t<std::invoke_result_t<FD&>>>))`. Otherwise, the call to `views::zip_transform` is ill-formed.

When calling with more than one arguments `f` and `rs...`, `views::zip_transform(f, rs...)` is [`expression-equivalent`](/docs/cpp/language/expressions#Expression-equivalence) to `ranges::zip_transform_view(f, rs...)`.

{/* source:cpp-ranges-zip-transform-view:0003 */}
`zip_transform_view` models the concepts [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`input_range`](/docs/cpp/library/ranges/input_range), [`common_range`](/docs/cpp/library/ranges/common_range), and [`sized_range`](/docs/cpp/library/ranges/sized_range) when the underlying `ranges::zip_view<Views...>` models respective concepts.

### Customization point objects

{/* source:cpp-ranges-zip-transform-view:0004 */}
The name `views::zip_transform` denotes a *customization point object*, which is a const [`function object`](/docs/cpp/library/named_req/FunctionObject) of a [`literal`](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as `__zip_transform_fn`.

{/* source:cpp-ranges-zip-transform-view:0005 */}
All instances of `__zip_transform_fn` are equal. The effects of invoking different instances of type `__zip_transform_fn` on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `views::zip_transform` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-zip-transform-view:0006 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `views::zip_transform` above, `__zip_transform_fn` models

{/* source:cpp-ranges-zip-transform-view:0007 */}
- `std::invocable<__zip_transform_fn, Args...>`,
- `std::invocable<const __zip_transform_fn, Args...>`,
- `std::invocable<__zip_transform_fn&, Args...>`, and
- `std::invocable<const __zip_transform_fn&, Args...>`.

{/* source:cpp-ranges-zip-transform-view:0008 */}
Otherwise, no function call operator of `__zip_transform_fn` participates in overload resolution.

### Example

{/* source:cpp-ranges-zip-transform-view:0014 */}
```cpp
#include <array>
#include <iostream>
#include <list>
#include <ranges>
#include <vector>
 
void print(auto const rem, auto const& r)
{
    std::cout << rem << '{'; 
    for (char o[]{0,' ',0}; auto const& e : r)
        std::cout << o << e, *o = ',';
    std::cout << "}\n";
}
 
int main()
{
    auto v1 = std::vector<float>{1, 2, 3};
    auto v2 = std::list<short>{1, 2, 3, 4};
    auto v3 = std::to_array({1, 2, 3, 4, 5});
 
    auto add = [](auto a, auto b, auto c) { return a + b + c; };
 
    auto sum = std::views::zip_transform(add, v1, v2, v3);
 
    print("v1:  ", v1);
    print("v2:  ", v2);
    print("v3:  ", v3);
    print("sum: ", sum);
}
```

Output:

```text
v1:  {1, 2, 3}
v2:  {1, 2, 3, 4}
v3:  {1, 2, 3, 4, 5}
sum: {3, 6, 9}
```
