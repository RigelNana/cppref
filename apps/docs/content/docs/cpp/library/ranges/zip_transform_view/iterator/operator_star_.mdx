{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0001 */}
Returns the transformed element obtained by application of the invocable object of type `F` to the underlying poined-to elements.

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0002 */}
Equivalent to

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0003 */}
```cpp
return
    std::apply
    (
        [&](auto const&... iters) -> decltype(auto)
        {
            return std::invoke(*parent_->fun_, *iters...);
        },
        inner_.current_
    );
```

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0004 */}
where `*parent_->fun_` is the transformation function stored in the parent `ranges::zip_transform_view`, and `current_` is the underlying tuple of iterators into `Views...`.

### Parameters

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0005 */}
(none)

### Return value

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0006 */}
The element which is the result of transformation (mapping).

### Exceptions

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0007 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::invoke(*parent_->fun_, *std::get<INTS>(inner_.current_)...))`

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0008 */}
where `INTS` is the pack of integers `0, 1, ..., (sizeof...(Views)-1)`.

### Notes

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0009 */}
`operator->` is not provided.

{/* source:cpp-ranges-zip-transform-view-iterator-operator-star:0010 */}
The behavior is undefined if the `parent_` pointer to parent `ranges::zip_transform_view` is null (e.g. if `*this` is default constructed).
