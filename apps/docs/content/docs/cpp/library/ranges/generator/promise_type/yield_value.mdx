  <DeclarationDescription>
    {/* source:cpp-coroutine-generator-promise-type-yield-value:0001 */}
    An implementation of coroutine interface functions used internally to support `operator co_yield`.

    {/* source:cpp-coroutine-generator-promise-type-yield-value:0002 */}
    (`[`yielded`](/docs/cpp/library/ranges/generator#Member_types)` is a reference type defined in [`std::generator`](/docs/cpp/library/ranges/generator).)

    {/* source:cpp-coroutine-generator-promise-type-yield-value:0003 */}
    1. Assigns `std::addressof(val)` to [`value_`](/docs/cpp/library/ranges/generator/promise_type#value). Returns `{}`.

    {/* source:cpp-coroutine-generator-promise-type-yield-value:0004 */}
    2. Returns an awaitable object `x` of an unspecified type that stores an object of type `std::remove_cvref_t<`[`yielded`](/docs/cpp/library/ranges/generator#yielded)`>`. `x` is [direct-non-list-initialized](/docs/cpp/language/initialization/direct_initialization) with `lval`, whose member functions are configured so that [`value_`](/docs/cpp/library/ranges/generator/promise_type#value) points to that stored object. Then suspends the coroutine.

    {/* source:cpp-coroutine-generator-promise-type-yield-value:0005 */}
    3, 4) Let `x` be some [`generator`](/docs/cpp/library/ranges/generator) object. Returns an awaitable object of an unspecified type into which `g.range` is moved, whose member `await_ready` returns `false`, whose member `await_suspend` pushes `g.range.coroutine_` into [`*x.active_`](/docs/cpp/library/ranges/generator#active) and resumes execution of the coroutine referred to by `g.range.coroutine_`, and whose member `await_resume` evaluates `std::rethrow_exception(except_)` if `bool(except_)` is `true`. If `bool(except_)` is `false`, the `await_resume` member has no effects.

    {/* source:cpp-coroutine-generator-promise-type-yield-value:0006 */}
    The coroutine referred to by `g.range.coroutine_` must be suspended at its initial suspend point. Otherwise the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-coroutine-generator-promise-type-yield-value:0007 */}
5. Equivalent to:

```cpp
auto nested = [](std::allocator_arg_t, Alloc, ranges::iterator_t<R> i,
                 ranges::sentinel_t<R> s) ->
    std::generator<yielded, void, Alloc>
{
    for (; i != s; ++i)
        co_yield static_cast<yielded>(*i);
};
 
return yield_value(ranges::elements_of(nested(
    allocator_arg, r.allocator, ranges::begin(r.range), ranges::end(r.range))));
```

{/* source:cpp-coroutine-generator-promise-type-yield-value:0008 */}
2,3) A handle referring to the coroutine whose promise object is `*this` must be at the top of [`*active_`](/docs/cpp/library/ranges/generator#active) of some generator object. Otherwise, the behavior is undefined.

{/* source:cpp-coroutine-generator-promise-type-yield-value:0009 */}
2-5) A [yield-expression](/docs/cpp/language/functions/coroutines#co_yield) that calls these overload has the type `void`.
