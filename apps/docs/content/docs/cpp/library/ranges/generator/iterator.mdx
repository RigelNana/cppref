#### iterator

<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`/*iterator*/( /*iterator*/&& other ) noexcept;`} />

{/* source:cpp-coroutine-generator-iterator:0006 */}
#### operator=

<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`/*iterator*/& operator=( /*iterator*/&& other ) noexcept;`} />
</DeclarationDoc>

Equivalent to `coroutine_ = std::exchange(other.coroutine_, {});`. Returns: `*this`.

{/* source:cpp-coroutine-generator-iterator:0007 */}
#### operator*

<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`reference operator*() const
    noexcept( std::is_nothrow_copy_constructible_v<reference> );`} />
</DeclarationDoc>

Let [`reference`](/docs/cpp/library/ranges/generator#Member_types) be the [`std::generator`](/docs/cpp/library/ranges/generator)'s underlying type. Let for some generator object `x` its [`coroutine_`](/docs/cpp/library/ranges/generator/iterator#coroutine) be in the stack `*x.active_`. Let `x.active_->top()` refer to a suspended coroutine with promise object `p`. Equivalent to `return static_cast<reference>(*p.value_);`.

#### operator==

<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`friend bool operator==( const /*iterator*/& i, std::default_sentinel_t );`} />
</DeclarationDoc>

Equivalent to `return i.coroutine_.done();`. The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`. This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::generator::iterator` is an associated class of the arguments.
