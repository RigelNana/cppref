{/* source:cpp-coroutine-generator-promise-type-unhandled-exception:0001 */}
Let `x` be some [`generator`](/docs/cpp/library/ranges/generator) object.

{/* source:cpp-coroutine-generator-promise-type-unhandled-exception:0002 */}
If a [`handle`](/docs/cpp/library/ranges/generator#Data_members) referring to the coroutine whose [`promise object`](/docs/cpp/library/ranges/generator/promise_type) is `*this` is at the top of [`*active_`](/docs/cpp/library/ranges/generator#active) of `x`:

{/* source:cpp-coroutine-generator-promise-type-unhandled-exception:0003 */}
- If the handle referring to the coroutine whose promise object is `*this` is the only element of `*x.active_`, equivalent to `throw;`.
- Otherwise, assigns [`std::current_exception()`](/docs/cpp/library/error/current_exception) to [`except_`](/docs/cpp/library/ranges/generator/promise_type#except).

{/* source:cpp-coroutine-generator-promise-type-unhandled-exception:0004 */}
Otherwise, the behavior is undefined.

### Exceptions

{/* source:cpp-coroutine-generator-promise-type-unhandled-exception:0005 */}
May throw.
