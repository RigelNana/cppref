<DeclarationDoc>
Defined in header [`<ranges>`](/docs/cpp/library/headers/ranges)

  <Declaration id="1" language="cpp" since="C++20" code={`template< class T >
using iterator_t = decltype(ranges::begin(std::declval<T&>()));`} />
  <Declaration id="2" language="cpp" since="C++23" code={`template< ranges::range R >
using const_iterator_t = decltype(ranges::cbegin(std::declval<R&>()));`} />
  <Declaration id="3" language="cpp" since="C++20" code={`template< ranges::range R >
using sentinel_t = decltype(ranges::end(std::declval<R&>()));`} />
  <Declaration id="4" language="cpp" since="C++23" code={`template< ranges::range R >
using const_sentinel_t = decltype(ranges::cend(std::declval<R&>()));`} />
</DeclarationDoc>

{/* source:cpp-ranges-iterator-t:0001 */}
1. 1) Used to obtain the iterator type of the type `T`.

{/* source:cpp-ranges-iterator-t:0002 */}
2. 2) Used to obtain the constant iterator type of the [`range`](/docs/cpp/library/ranges/range) type `R`.

{/* source:cpp-ranges-iterator-t:0003 */}
3. 3) Used to obtain the sentinel type of the range type `R`.

{/* source:cpp-ranges-iterator-t:0004 */}
4. 4) Used to obtain the constant sentinel type of the range type `R`.

### Template parameters

{/* source:cpp-ranges-iterator-t:0005 */}
<ParameterList>
  <Parameter name="T">a type that can be used in [`std::ranges::begin`](/docs/cpp/library/ranges/begin)</Parameter>
  <Parameter name="R">a [`range`](/docs/cpp/library/ranges/range) type or a [`sized_range`](/docs/cpp/library/ranges/sized_range) type</Parameter>
</ParameterList>

### Notes

{/* source:cpp-ranges-iterator-t:0006 */}
`iterator_t` can be applied to non-range types, e.g. arrays with unknown bound.
