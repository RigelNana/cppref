{/* source:cpp-ranges-as-const-view:0001 */}
1) A range adaptor that represents a view of underlying [`view`](/docs/cpp/library/ranges/view) that is also a [`constant_range`](/docs/cpp/library/ranges/constant_range). An `as_const_view` always has read-only elements (if not empty).

{/* source:cpp-ranges-as-const-view:0002 */}
2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). Let `e` be a subexpression, let `T` be `decltype((e))`, and let `U` be `std::remove_cvref_t<T>`. Then the expression `views::as_const(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

- `views::all(e)`, if it is a well-formed expression and `views::all_t<T>` models [`constant_range`](/docs/cpp/library/ranges/constant_range);
- otherwise, `std::span<const X, Extent>(e)` for some type `X` and some extent `Extent` if `U` denotes `std::span<X, Extent>`;
- otherwise, `ranges::ref_view(static_cast<const X&>(e.base()))` if `U` denotes `ranges::ref_view<X>` for some type `X` and `const X` models [`constant_range`](/docs/cpp/library/ranges/constant_range);
- otherwise, `ranges::ref_view(static_cast<const U&>(e))` if `e` is an lvalue, `const U` models [`constant_range`](/docs/cpp/library/ranges/constant_range), and `U` does not model [`view`](/docs/cpp/library/ranges/view);
- otherwise, `as_const_view{e}`.

{/* source:cpp-ranges-as-const-view:0003 */}
`as_const_view` always models [`constant_range`](/docs/cpp/library/ranges/constant_range), and it models the [`contiguous_range`](/docs/cpp/library/ranges/contiguous_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range), [`common_range`](/docs/cpp/library/ranges/common_range), and [`sized_range`](/docs/cpp/library/ranges/sized_range) when the underlying view `V` models respective concepts.

### Example

{/* source:cpp-ranges-as-const-view:0015 */}
```cpp
#include <cassert>
#include <ranges>
 
int main()
{
    int x[]{1, 2, 3, 4, 5};
 
    auto v1 = x | std::views::drop(2);
    assert(v1.back() == 5);
    v1[0]++; // OK, can modify non-const element
 
    auto v2 = x | std::views::drop(2) | std::views::as_const;
    assert(v2.back() == 5);
    // v2[0]++; // Compile-time error, cannot modify read-only element
}
```
