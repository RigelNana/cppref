{/* source:cpp-ranges-range-size-t:0001 */}
1. 1) Used to obtain the size type of the [`sized_range`](/docs/cpp/library/ranges/sized_range) type `R`.

{/* source:cpp-ranges-range-size-t:0002 */}
2. 2) Used to obtain the difference type of the iterator type of range type `R`.

{/* source:cpp-ranges-range-size-t:0003 */}
3. 3) Used to obtain the value type of the iterator type of range type `R`.
