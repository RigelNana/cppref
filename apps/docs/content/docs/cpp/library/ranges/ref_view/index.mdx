{/* source:cpp-ranges-ref-view:0001 */}
`ref_view` is a [`view`](/docs/cpp/library/ranges/view) of the elements of some other [`range`](/docs/cpp/library/ranges/range). It wraps a reference to that `range`.

#### `std::ranges::ref_view::ref_view`

<DeclarationDoc>
  <Declaration language="cpp" since="C++20" code={`template< /*different-from*/<ref_view> T >
    requires std::convertible_to<T, R&> && requires { _FUN(std::declval<T>()); }

constexpr ref_view( T&& t );`} />
</DeclarationDoc>

Initializes `r_` with `std::addressof(static_cast<R&>(std::forward<T>(t)))`.

`/*different-from*/<T, U>` is satisfied if and only if `std::remove_cvref_t<T>` and `std::remove_cvref_t<U>` are not the same type, and overloads of `_FUN` are declared as `void _FUN(R&); void _FUN(R&&) = delete;`.

### Example

{/* source:cpp-ranges-ref-view:0014 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    const std::string s{"cosmos"};
 
    const std::ranges::take_view tv{s, 3};
    const std::ranges::ref_view rv{tv};
 
    std::cout
        << std::boolalpha
        << "call empty() : " << rv.empty() << '\n'
        << "call size()  : " << rv.size() << '\n'
        << "call begin() : " << *rv.begin() << '\n'
        << "call end()   : " << *(rv.end() - 1) << '\n'
        << "call data()  : " << rv.data() << '\n'
        << "call base()  : " << rv.base().size() << '\n' // ~> tv.size()
        << "range-for    : ";
 
    for (const auto c : rv)
        std::cout << c;
    std::cout << '\n';
}
```

Output:

```text
call empty() : false
call size()  : 3
call begin() : c
call end()   : s
call data()  : cosmos
call base()  : 3
range-for    : cos
```
