{/* source:cpp-ranges-join-with-view-iterator:0001 */}
`ranges::join_with_view<V, Pattern>::iterator` is the type of the iterators returned by [`begin()`](/docs/cpp/library/ranges/join_with_view/begin) and [`end()`](/docs/cpp/library/ranges/join_with_view/end) of `ranges::join_with_view<V, Pattern>`.

{/* source:cpp-ranges-join-with-view-iterator:0002 */}
The state of an iterator of this class is managed as if there are two nested iterators:

{/* source:cpp-ranges-join-with-view-iterator:0003 */}
- an *outer iterator* into the parent range `*`[`parent_`](/docs/cpp/library/ranges/join_with_view/iterator#parent)

{/* source:cpp-ranges-join-with-view-iterator:0004 */}
  - If `Base` models [`forward_range`](/docs/cpp/library/ranges/forward_range), it is [`outer_it_`](/docs/cpp/library/ranges/join_with_view/iterator#outer_it).
  - Otherwise, it is [`parent_`](/docs/cpp/library/ranges/join_with_view/iterator#parent)`->`[`outer_it_`](/docs/cpp/library/ranges/join_with_view#outer_it).

{/* source:cpp-ranges-join-with-view-iterator:0005 */}
- an *inner iterator* [`inner_it_`](/docs/cpp/library/ranges/join_with_view/iterator#inner_it) into the pattern range [`parent_`](/docs/cpp/library/ranges/join_with_view/iterator#parent)`->`[`pattern_`](/docs/cpp/library/ranges/join_with_view#pattern) or into a child range of the parent range

{/* source:cpp-ranges-join-with-view-iterator:0006 */}
This iterator class has the invariant that the inner iterator is always dereferenceable unless the outer iterator is not dereferenceable. When an iterator is constructed, incremented or decremented, its outer iterator might be adjusted to hold the invariant.

### Determining the iterator concept

{/* source:cpp-ranges-join-with-view-iterator:0009 */}
`iterator_concept` is defined as follows:

{/* source:cpp-ranges-join-with-view-iterator:0010 */}
- If all following conditions are satisfied, `iterator_concept` denotes [`std::bidirectional_iterator_tag`](/docs/cpp/library/iterator/iterator_tags):

  - `std::is_reference_v<InnerBase>` is `true`.
  - `Base` models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range).
  - `InnerBase` and `PatternBase` each model [`common_range`](/docs/cpp/library/ranges/common_range).

- Otherwise, if all following conditions are satisfied, `iterator_concept` denotes [`std::forward_iterator_tag`](/docs/cpp/library/iterator/iterator_tags):

  - `std::is_reference_v<InnerBase>` is `true`.
  - `Base` and `InnerBase` each model [`forward_range`](/docs/cpp/library/ranges/forward_range).

- Otherwise, `iterator_concept` denotes [`std::input_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).

### Determining the iterator category

{/* source:cpp-ranges-join-with-view-iterator:0011 */}
Given the following types:

{/* source:cpp-ranges-join-with-view-iterator:0012 */}
- Let `OuterC` be `std::iterator_traits<OuterIter>::iterator_category`.
- Let `InnerC` be `std::iterator_traits<InnerIter>::iterator_category`.
- Let `PatternC` be `std::iterator_traits<PatternIter>::iterator_category`.

{/* source:cpp-ranges-join-with-view-iterator:0013 */}
`iterator_category` is defined if and only if `std::is_reference_v<InnerBase>` is `true`, and `Base` and `InnerBase` each model [`forward_range`](/docs/cpp/library/ranges/forward_range). In this case, it is defined as follows:

{/* source:cpp-ranges-join-with-view-iterator:0014 */}
- If `std::is_reference_v<std::common_reference_t<ranges::range_reference_t<InnerBase>, ranges::range_reference_t<PatternBase>>>` is `false`, `iterator_category` denotes [`std::input_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).
- Otherwise, if all following conditions are satisfied, `iterator_category` denotes [`std::bidirectional_iterator_tag`](/docs/cpp/library/iterator/iterator_tags):

  - `OuterC`, `InnerC`, and `PatternC` each model `std::derived_from<std::bidirectional_iterator_tag>`.
  - `InnerBase` and `PatternBase` each model [`common_range`](/docs/cpp/library/ranges/common_range).

- Otherwise, if `OuterC`, `InnerC`, and `PatternC` each model `std::derived_from<std::forward_iterator_tag>`, `iterator_category` denotes [`std::forward_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).
- Otherwise, `iterator_category` denotes [`std::input_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).
