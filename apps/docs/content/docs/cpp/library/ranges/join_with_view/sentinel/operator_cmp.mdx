{/* source:cpp-ranges-join-with-view-sentinel-operator-cmp:0001 */}
Compares the underlying iterator of `x` with the underlying sentinel of `y`. The comparison returns `true` if the underlying outer iterator stored in `x` is the end iterator.

{/* source:cpp-ranges-join-with-view-sentinel-operator-cmp:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `join_with_view::sentinel<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-join-with-view-sentinel-operator-cmp:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Parameters

{/* source:cpp-ranges-join-with-view-sentinel-operator-cmp:0004 */}
<ParameterList>
  <Parameter name="x">[`iterator`](/docs/cpp/library/ranges/join_with_view/iterator) to compare</Parameter>

</ParameterList>

### Return value

{/* source:cpp-ranges-join-with-view-sentinel-operator-cmp:0005 */}
`x.outer_it_ == y.end_`, where `outer_it_` denotes the underlying outer iterator, `end_` denotes the underlying sentinel.
