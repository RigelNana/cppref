Returns an [`iterator`](/docs/cpp/library/ranges/join_with_view/iterator) to the beginning of the [`join_with_view`](/docs/cpp/library/ranges/join_with_view).

{/* source:cpp-ranges-join-with-view-begin:0002 */}
1) Returns a mutable iterator or const iterator.

- If `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range), equivalent to `constexpr bool use_const = `[`simple-view`](/docs/cpp/library/ranges#simple-view)`<V> && std::is_reference_v<`[`InnerRng`](/docs/cpp/library/ranges/join_with_view#InnerRng)`> && `[`simple-view`](/docs/cpp/library/ranges#simple-view)`<Pattern>;` `return `[`iterator`](/docs/cpp/library/ranges/join_with_view/iterator)`<use_const>{*this, ranges::begin(`[`base_`](/docs/cpp/library/ranges/join_with_view#base)`)};`.
- Otherwise, equivalent to [`outer_it_`](/docs/cpp/library/ranges/join_with_view#outer_it)` = ranges::begin(`[`base_`](/docs/cpp/library/ranges/join_with_view#base)`);` `return `[`iterator`](/docs/cpp/library/ranges/join_with_view/iterator)`<false>{*this};`.

{/* source:cpp-ranges-join-with-view-begin:0003 */}
2) Returns a const iterator.

{/* source:cpp-ranges-join-with-view-begin:0004 */}
For the definition of [`concatable`](/docs/cpp/library/ranges/concat_view#concatable), see [`std::ranges::concat_view`](/docs/cpp/library/ranges/concat_view).

### Return value

{/* source:cpp-ranges-join-with-view-begin:0005 */}
1) As described above.

{/* source:cpp-ranges-join-with-view-begin:0006 */}
2) [`iterator`](/docs/cpp/library/ranges/join_with_view/iterator)`<true>{*this, ranges::begin(`[`base_`](/docs/cpp/library/ranges/join_with_view#base)`)}`
