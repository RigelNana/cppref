{/* source:cpp-ranges-join-with-view-iterator-operator-cmp:0001 */}
Compares whether the iterators `x` and `y` are equal. They only compare equal if their [outer iterators](/docs/cpp/library/ranges/join_with_view/iterator) and [inner iterators](/docs/cpp/library/ranges/join_with_view/iterator) compare equal respectively.

{/* source:cpp-ranges-join-with-view-iterator-operator-cmp:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::join_with_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-join-with-view-iterator-operator-cmp:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
