Returns the result of applying [`ranges::iter_move`](/docs/cpp/library/iterator/ranges/iter_move) to the [*inner iterator*](/docs/cpp/library/ranges/join_with_view/iterator).

{/* source:cpp-ranges-join-with-view-iterator-iter-move:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `join_with_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-join-with-view-iterator-iter-move:0004 */}
`std::visit<rvalue_reference>(ranges::iter_move, x.`[`inner_it_`](/docs/cpp/library/ranges/join_with_view/iterator#inner_it)`)`, where `rvalue_reference` is `std::common_reference_t<ranges::range_rvalue_reference_t<`[`InnerBase`](/docs/cpp/library/ranges/join_with_view/iterator#InnerBase)`>, ranges::range_rvalue_reference_t<`[`PatternBase`](/docs/cpp/library/ranges/join_with_view/iterator#PatternBase)`>>`.
