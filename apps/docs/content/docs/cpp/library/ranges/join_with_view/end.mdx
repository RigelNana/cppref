{/* source:cpp-ranges-join-with-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/join_with_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/join_with_view/sentinel) that compares equal to the past-the-end iterator of the [`join_with_view`](/docs/cpp/library/ranges/join_with_view).

{/* source:cpp-ranges-join-with-view-end:0002 */}
1) Returns a mutable iterator/sentinel or const iterator/sentinel.

- If all following conditions are satisfied, returns an iterator:

  - `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range) and [`common_range`](/docs/cpp/library/ranges/common_range).
  - `std::is_reference_v<`[`InnerRng`](/docs/cpp/library/ranges/join_with_view#InnerRng)`>` is `true`.
  - [`InnerRng`](/docs/cpp/library/ranges/join_with_view#InnerRng) models [`forward_range`](/docs/cpp/library/ranges/forward_range) and [`common_range`](/docs/cpp/library/ranges/common_range).

- Otherwise, returns a sentinel.

{/* source:cpp-ranges-join-with-view-end:0003 */}
2) Returns a const iterator/sentinel.

- If all following conditions are satisfied, returns an iterator:

  - `const V` models [`common_range`](/docs/cpp/library/ranges/common_range).
  - `ranges::range_reference_t<const V>` models [`forward_range`](/docs/cpp/library/ranges/forward_range) and [`common_range`](/docs/cpp/library/ranges/common_range).

- Otherwise, returns a sentinel.

{/* source:cpp-ranges-join-with-view-end:0004 */}
For the definition of `/*concatable*/`, see [`std::ranges::concat_view`](/docs/cpp/library/ranges/concat_view).
