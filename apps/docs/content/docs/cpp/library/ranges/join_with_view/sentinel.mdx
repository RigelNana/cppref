{/* source:cpp-ranges-join-with-view-sentinel:0001 */}
`ranges::join_with_view<V, Pattern>::sentinel` is the type of the sentinels returned by [`end()`](/docs/cpp/library/ranges/join_with_view/end) of `ranges::join_with_view<V, Pattern>`.

{/* source:cpp-ranges-join-with-view-sentinel:0002 */}
If an iterator compares equal with a sentinel, the iterator is a past-the-end iterator.
