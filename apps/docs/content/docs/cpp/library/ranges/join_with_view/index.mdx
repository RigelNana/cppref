{/* source:cpp-ranges-join-with-view:0001 */}
1) A range adaptor that represents [`view`](/docs/cpp/library/ranges/view) consisting of the sequence obtained from flattening a view of ranges, with every element of the delimiter inserted in between elements of the view. The delimiter can be a single element or a view of elements.

{/* source:cpp-ranges-join-with-view:0002 */}
For the definition of `/*concatable*/`, see [`std::ranges::concat_view`](/docs/cpp/library/ranges/concat_view).

{/* source:cpp-ranges-join-with-view:0003 */}
2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::join_with(e, f)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `join_with_view(e, f)` for any suitable subexpressions `e` and `f`.

{/* source:cpp-ranges-join-with-view:0004 */}
`join_with_view` models [`input_range`](/docs/cpp/library/ranges/input_range).

{/* source:cpp-ranges-join-with-view:0005 */}
`join_with_view` models [`forward_range`](/docs/cpp/library/ranges/forward_range) when:

{/* source:cpp-ranges-join-with-view:0006 */}
- `ranges::range_reference_t<V>` is a reference, and
- `V` and `ranges::range_reference_t<V>` each model [`forward_range`](/docs/cpp/library/ranges/forward_range).

{/* source:cpp-ranges-join-with-view:0007 */}
`join_with_view` models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range) when:

{/* source:cpp-ranges-join-with-view:0008 */}
- `ranges::range_reference_t<V>` is a reference,
- `V`, `ranges::range_reference_t<V>`, and `Pattern` each models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), and
- `ranges::range_reference_t<V>` and `Pattern` each model [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-join-with-view:0009 */}
`join_with_view` models [`common_range`](/docs/cpp/library/ranges/common_range) when:

{/* source:cpp-ranges-join-with-view:0010 */}
- `ranges::range_reference_t<V>` is a reference, and
- `V` and `ranges::range_reference_t<V>` each model [`forward_range`](/docs/cpp/library/ranges/forward_range) and [`common_range`](/docs/cpp/library/ranges/common_range).

### Example

{/* source:cpp-ranges-join-with-view:0016 */}
```cpp
#include <iostream>
#include <ranges>
#include <string_view>
#include <vector>

int main()
{
    using namespace std::literals;

    std::vector v{"This"sv, "is"sv, "a"sv, "test."sv};
    auto joined = v | std::views::join_with(' ');

    for (auto c : joined)
        std::cout << c;
    std::cout << '\n';
}
```

Output:

```text
This is a test.
```
