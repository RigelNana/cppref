{/* source:cpp-ranges-cbegin:0001 */}
<Revision until="C++23">
Returns an iterator to the first element of the const-qualified argument.
</Revision>
<Revision since="C++23">
Returns a constant iterator to the first element of the argument.
</Revision>

{/* source:cpp-ranges-cbegin:0002 */}
<Revision until="C++23">
Let `CT` be

- `const std::remove_reference_t<T>&` if the argument is an lvalue (i.e. `T` is an lvalue reference type),
- `const T` otherwise.

A call to `ranges::cbegin` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `ranges::begin(static_cast<CT&&>(t))`.
</Revision>
<Revision since="C++23">
If the argument is an lvalue or `ranges::enable_borrowed_range<std::remove_cv_t<T>>` is `true`, then a call to `ranges::cbegin` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

- `std::const_iterator<decltype(U)>(U)` for some expression `U` equivalent to `ranges::begin(`[`possibly-const-range`](/docs/cpp/library/ranges#possibly-const-range)`(t)`.

In all other cases, a call to `ranges::cbegin` is ill-formed, which can result in [substitution failure](/docs/cpp/language/templates/sfinae) when the call appears in the immediate context of a template instantiation.
</Revision>

{/* source:cpp-ranges-cbegin:0003 */}
The return type models [`std::input_or_output_iterator`](/docs/cpp/library/iterator/input_or_output_iterator) <InlineRevision since="C++23">and [`constant-iterator`](/docs/cpp/library/ranges/constant_range)</InlineRevision> in all cases.

### Customization point objects

{/* source:cpp-ranges-cbegin:0004 */}
The name `ranges::cbegin` denotes a *customization point object*, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as `__cbegin_fn`.

{/* source:cpp-ranges-cbegin:0005 */}
All instances of `__cbegin_fn` are equal. The effects of invoking different instances of type `__cbegin_fn` on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `ranges::cbegin` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-cbegin:0006 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `ranges::cbegin` above, `__cbegin_fn` models

{/* source:cpp-ranges-cbegin:0007 */}
- `std::invocable<__cbegin_fn, Args...>`,
- `std::invocable<const __cbegin_fn, Args...>`,
- `std::invocable<__cbegin_fn&, Args...>`, and
- `std::invocable<const __cbegin_fn&, Args...>`.

{/* source:cpp-ranges-cbegin:0008 */}
Otherwise, no function call operator of `__cbegin_fn` participates in overload resolution.

### Notes

{/* source:cpp-ranges-cbegin:0009 */}
For an lvalue range `e` of type `T`, `ranges::cbegin(e)` is equivalent to

{/* source:cpp-ranges-cbegin:0010 */}
<Revision until="C++23">
`ranges::begin(std::as_const(e))`.
</Revision>
<Revision since="C++23">
- `ranges::begin(e)` if `T` models [`constant_range`](/docs/cpp/library/ranges/constant_range).
- Otherwise, `ranges::begin(std::as_const(e))` if `const T` models [`constant_range`](/docs/cpp/library/ranges/constant_range).
- Otherwise, `std::basic_const_iterator(ranges::begin(e))`.
</Revision>

### Example

{/* source:cpp-ranges-cbegin:0011 */}
```cpp
#include <cassert>
#include <ranges>
#include <vector>
 
int main()
{
    std::vector v{3, 1, 4};
    auto vi = std::ranges::cbegin(v);
    assert(3 == *vi);
    ++vi; // OK, constant-iterator object is mutable
    assert(1 == *vi);
    // *vi = 13; // Error: constant-iterator points to an immutable element
 
    int a[]{3, 1, 4};
    auto ai = std::ranges::cbegin(a); // cbegin works with C-arrays as well
    assert(3 == *ai and *(ai + 1) == 1);
    // *ai = 13; // Error: read-only variable is not assignable
}
```
