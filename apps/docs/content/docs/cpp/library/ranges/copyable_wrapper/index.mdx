{/* source:cpp-ranges-copyable-wrapper:0001 */}
[`ranges::single_view`](/docs/cpp/library/ranges/single_view)<InlineRevision since="C++23">, [`ranges::repeat_view`](/docs/cpp/library/ranges/repeat_view),</InlineRevision> and range adaptors that store an invocable object are specified in terms of an exposition-only class template <InlineRevision until="C++23">`copyable-box`</InlineRevision><InlineRevision since="C++23">`movable-box`</InlineRevision>. The name shown here is for exposition purposes only.

{/* source:cpp-ranges-copyable-wrapper:0002 */}
The wrapper behaves exactly like [`std::optional<T>`](/docs/cpp/library/utility/optional), except that the default constructor, copy assignment operator, and move assignment operator are (conditionally) different from those of [`std::optional`](/docs/cpp/library/utility/optional), which augments `T` with assignability when needed and makes it always satisfy [`copyable`](/docs/cpp/library/concepts/copyable)<InlineRevision since="C++23"> or [`movable`](/docs/cpp/library/concepts/movable)</InlineRevision>.

{/* source:cpp-ranges-copyable-wrapper:0003 */}
<Revision until="C++23">
If `T` is already [`copyable`](/docs/cpp/library/concepts/copyable), or both `std::is_nothrow_move_constructible_v<T>` and `std::is_nothrow_copy_constructible_v<T>` are `true`, `/*copyable-box*/<T>` may store only a `T` object, because it always contains a value.
</Revision>

<Revision since="C++23">
If `T`

- is already [`copyable`](/docs/cpp/library/concepts/copyable), or
- is [`copy_constructible`](/docs/cpp/library/concepts/copy_constructible) and both `std::is_nothrow_move_constructible_v<T>` and `std::is_nothrow_copy_constructible_v<T>` are `true`, or
- does not satisfy [`copy_constructible`](/docs/cpp/library/concepts/copy_constructible) but satisfies [`movable`](/docs/cpp/library/concepts/movable), or
- does not satisfy [`copy_constructible`](/docs/cpp/library/concepts/copy_constructible) but `std::is_nothrow_move_constructible_v<T>` is `true`,

`/*movable-box*/<T>` may store only a `T` object, because it always contains a value.
</Revision>

## Default constructor

{/* source:cpp-ranges-copyable-wrapper:0005 */}
<DeclarationDoc>
  <Declaration language="cpp" since="C++20" until="C++23" code={`constexpr /*copyable-box*/() noexcept(std::is_nothrow_default_constructible_v<T>)
    requires std::default_initializable<T>

    : /*copyable-box*/(std::in_place) { }`} />
  <Declaration language="cpp" since="C++23" code={`constexpr /*movable-box*/() noexcept(std::is_nothrow_default_constructible_v<T>)
    requires std::default_initializable<T>

    : /*movable-box*/(std::in_place) { }`} />
</DeclarationDoc>

The default constructor is provided if and only if `T` models [`default_initializable`](/docs/cpp/library/concepts/default_initializable).

A default-constructed wrapper contains a value-initialized `T` object.

## Assignment operators

{/* source:cpp-ranges-copyable-wrapper:0006 */}
<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++20" until="C++23" code={`constexpr /*copyable-box*/& operator=(const /*copyable-box*/& other);
    noexcept(/* see below */);`} />
  <Declaration id="1" language="cpp" since="C++23" code={`constexpr /*movable-box*/& operator=(const /*movable-box*/& other);
    noexcept(/* see below */) requires std::copy_constructible<T>;`} />
  <Declaration id="2" language="cpp" since="C++20" until="C++23" code={`constexpr /*copyable-box*/& operator=(/*copyable-box*/&& other)
    noexcept(std::is_nothrow_move_constructible_v<T>);`} />
  <Declaration id="2" language="cpp" since="C++23" code={`constexpr /*movable-box*/& operator=(/*movable-box*/&& other)
    noexcept(std::is_nothrow_move_constructible_v<T>);`} />
</DeclarationDoc>

1) If `std::copyable<T>` is not modeled, the copy assignment operator is equivalently defined as:

<Revision until="C++23">
```cpp
constexpr /*copyable-box*/& operator=(const /*copyable-box*/& other)
    noexcept(std::is_nothrow_copy_constructible_v<T>)
{
    if (this != std::addressof(other))
        if (other)
            emplace(*other);
        else
            reset();

    return *this;
}
```
</Revision>

<Revision since="C++23">
```cpp
constexpr /*movable-box*/& operator=(const /*movable-box*/& other)
    noexcept(std::is_nothrow_copy_constructible_v<T>)
    requires std::copy_constructible<T>
{
    if (this != std::addressof(other))
        if (other)
            emplace(*other);
        else
            reset();

    return *this;
}
```
</Revision>

Otherwise, it is identical to [the copy assignment operator of `std::optional`](/docs/cpp/library/utility/optional/operator_assignment).

2) If `std::movable<T>` is not modeled, the move assignment operator is equivalently defined as:

<Revision until="C++23">
```cpp
constexpr /*copyable-box*/& operator=(/*copyable-box*/&& other)
    noexcept(std::is_nothrow_move_constructible_v<T>)
{
    if (this != std::addressof(other))
        if (other)
            emplace(std::move(*other));
        else
            reset();

    return *this;
}
```
</Revision>

<Revision since="C++23">
```cpp
constexpr /*movable-box*/& operator=(/*movable-box*/&& other)
    noexcept(std::is_nothrow_move_constructible_v<T>)
{
    if (this != std::addressof(other))
        if (other)
            emplace(std::move(*other));
        else
            reset();

    return *this;
}
```
</Revision>

Otherwise, it is identical to [the move assignment operator of `std::optional`](/docs/cpp/library/utility/optional/operator_assignment).

### Notes

{/* source:cpp-ranges-copyable-wrapper:0008 */}
A <InlineRevision until="C++23">`copyable-box`</InlineRevision><InlineRevision since="C++23">`movable-box`</InlineRevision> does not contain a value only if

{/* source:cpp-ranges-copyable-wrapper:0009 */}
- `T` does not model [`movable`](/docs/cpp/library/concepts/movable) or [`copyable`](/docs/cpp/library/concepts/copyable), and an exception is thrown on move assignment or copy assignment respectively, or
- it is initialized/assigned from another valueless wrapper.

{/* source:cpp-ranges-copyable-wrapper:0010 */}
Before [P2325R3](https://wg21.link/P2325R3), the wrapper was called `semiregular-box` in the standard and always satisfied [`semiregular`](/docs/cpp/library/concepts/semiregular), as the default constructor was always provided (which might construct a valueless wrapper).
