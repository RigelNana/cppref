Construct an iterator.

{/* source:cpp-ranges-adjacent-view-iterator-iterator:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying array of iterators [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members) to [`Base`](/docs/cpp/library/ranges/adjacent_view/iterator#Member_types), as if by `std::array<ranges::iterator_t<Base>, N>()`.

{/* source:cpp-ranges-adjacent-view-iterator-iterator:0003 */}
2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Move constructs the underlying [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members) member.

{/* source:cpp-ranges-adjacent-view-iterator-iterator:0004 */}
This iterator also has two private constructors which is used by `ranges::adjacent_view::begin` and `ranges::adjacent_view::end`. These constructors are not accessible to users.
