{/* source:cpp-ranges-adjacent-view-sentinel-operator:0001 */}
Computes the distance between the underlying iterator of `x` and the underlying sentinel of `y`.

{/* source:cpp-ranges-adjacent-view-sentinel-operator:0002 */}
Let [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members) denote the underlying array of iterators in `x`, and [`end_`](/docs/cpp/library/ranges/adjacent_view/sentinel#Data_members) denote the underlying sentinel in `y`.

{/* source:cpp-ranges-adjacent-view-sentinel-operator:0003 */}
1) Equivalent to: `return x.current_.back() - y.end_;`

{/* source:cpp-ranges-adjacent-view-sentinel-operator:0004 */}
2) Equivalent to: `return y.end_ - x.current_.back();`

{/* source:cpp-ranges-adjacent-view-sentinel-operator:0005 */}
These function templates are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `adjacent_view::sentinel` is an associated class of the arguments.
