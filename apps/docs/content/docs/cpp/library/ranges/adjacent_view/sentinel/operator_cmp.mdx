{/* source:cpp-ranges-adjacent-view-sentinel-operator-cmp:0001 */}
Compares the underlying iterator of `x` with the underlying sentinel of `y`.

{/* source:cpp-ranges-adjacent-view-sentinel-operator-cmp:0002 */}
Equivalent to: `return x.current_.back() == y.end_`, where [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members) is underlying array of iterators in `x`, and [`end_`](/docs/cpp/library/ranges/adjacent_view/sentinel#Data_members) is the underlying sentinel in `y`.

{/* source:cpp-ranges-adjacent-view-sentinel-operator-cmp:0003 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `adjacent_view::sentinel<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-adjacent-view-sentinel-operator-cmp:0004 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

{/* source:cpp-ranges-adjacent-view-sentinel-operator-cmp:0006 */}
