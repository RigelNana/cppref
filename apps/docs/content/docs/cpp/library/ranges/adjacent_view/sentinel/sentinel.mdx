Constructs a sentinel.

{/* source:cpp-ranges-adjacent-view-sentinel-sentinel:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying sentinel (denoted as [`end_`](/docs/cpp/library/ranges/adjacent_view/sentinel#Data_members)) with `ranges::sentinel_t<Base>()`.

{/* source:cpp-ranges-adjacent-view-sentinel-sentinel:0003 */}
2) Conversion from `/*sentinel*/<false>` to `/*sentinel*/<true>`. Move constructs the underlying sentinel [`end_`](/docs/cpp/library/ranges/adjacent_view/sentinel#Data_members) with the corresponding member of `i`.

{/* source:cpp-ranges-adjacent-view-sentinel-sentinel:0004 */}
This type also has a private constructor which is used by `adjacent_view::end`. This constructor is not accessible to users.
