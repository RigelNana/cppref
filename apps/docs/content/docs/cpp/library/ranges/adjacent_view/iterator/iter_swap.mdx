{/* source:cpp-ranges-adjacent-view-iterator-iter-swap:0001 */}
Swaps the objects pointed to by two underlying arrays of iterators (denoted as [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members)).

{/* source:cpp-ranges-adjacent-view-iterator-iter-swap:0002 */}
Equivalent to:

{/* source:cpp-ranges-adjacent-view-iterator-iter-swap:0003 */}
```cpp
for (std::size_t i{}; i != N; ++i)
{
    std::ranges::iter_swap(x.current_[i], y.current_[i]);
}
```

{/* source:cpp-ranges-adjacent-view-iterator-iter-swap:0004 */}
The behavior is undefined if before the operation none of the iterators in `x.current_` is equal to an iterator in `y.current_`.

{/* source:cpp-ranges-adjacent-view-iterator-iter-swap:0005 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `adjacent_view::iterator<Const>` is an associated class of the arguments.
