{/* source:cpp-ranges-adjacent-view-iterator-operator-star:0001 */}
Returns the elements into `V` the underlying array of iterators points to.

{/* source:cpp-ranges-adjacent-view-iterator-operator-star:0002 */}
Let [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members) be an underlying array of iterators.

{/* source:cpp-ranges-adjacent-view-iterator-operator-star:0003 */}
Equivalent to:

{/* source:cpp-ranges-adjacent-view-iterator-operator-star:0004 */}
```cpp
return /*tuple-transform*/([](auto& i) -> decltype(auto) { return *i; }, current_);
```

### Parameters

{/* source:cpp-ranges-adjacent-view-iterator-operator-star:0005 */}
(none)

### Return value

{/* source:cpp-ranges-adjacent-view-iterator-operator-star:0006 */}
The current element, which is a [`std::tuple`](/docs/cpp/library/utility/tuple) of references to underlying elements.

### Notes

{/* source:cpp-ranges-adjacent-view-iterator-operator-star:0007 */}
`operator->` is not provided.

### Example

{/* source:cpp-ranges-adjacent-view-iterator-operator-star:0008 */}
```cpp
#include <ranges>
#include <tuple>
 
int main()
{
    constexpr static auto v = {0, 1, 2, 3, 4, 5};
    //                               └──┬──┘
    //                                  └─────────────────┐
    constexpr auto view {v | std::views::adjacent<3>}; // │
    constexpr auto iter {view.begin() + 2};            // │
    //              ┌────────────────────┬────────────────┘
    //              │                 ┌──┴──┐
    static_assert(*iter == std::tuple{2, 3, 4});
}
```
