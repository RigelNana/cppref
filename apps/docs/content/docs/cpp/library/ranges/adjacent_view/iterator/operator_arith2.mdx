{/* source:cpp-ranges-adjacent-view-iterator-operator-arith2:0001 */}
Let [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members) be the underlying array of iterators, and [`Base`](/docs/cpp/library/ranges/adjacent_view/iterator#Member_types) be the type (possibly const-qualified) of underlying view.

{/* source:cpp-ranges-adjacent-view-iterator-operator-arith2:0002 */}
1,2) Returns the iterator `i` incremented by `n`. Equivalent to: `auto r = i; r += n; return r;`

{/* source:cpp-ranges-adjacent-view-iterator-operator-arith2:0003 */}
3) Returns the iterator `i` decremented by `n`. Equivalent to: `auto r = i; r -= n; return r;`

{/* source:cpp-ranges-adjacent-view-iterator-operator-arith2:0004 */}
4) Returns the distance between `i` and `j`. Equivalent to: `return i.current_.back() - j.current_.back();`

{/* source:cpp-ranges-adjacent-view-iterator-operator-arith2:0005 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `adjacent_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-adjacent-view-iterator-operator-arith2:0007 */}
1,2) An incremented iterator.

{/* source:cpp-ranges-adjacent-view-iterator-operator-arith2:0008 */}
3) A decremented iterator.

{/* source:cpp-ranges-adjacent-view-iterator-operator-arith2:0009 */}
4) A distance between given iterators.
