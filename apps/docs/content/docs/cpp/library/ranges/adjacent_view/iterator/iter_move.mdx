{/* source:cpp-ranges-adjacent-view-iterator-iter-move:0001 */}
Returns the result of applying [`ranges::iter_move`](/docs/cpp/library/iterator/ranges/iter_move) to the underlying iterators.

{/* source:cpp-ranges-adjacent-view-iterator-iter-move:0002 */}
Equivalent to: `return /*tuple-transform*/(ranges::iter_move, i.current_);`, where [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members) is an underlying array of iterators.

{/* source:cpp-ranges-adjacent-view-iterator-iter-move:0003 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `adjacent_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-adjacent-view-iterator-iter-move:0005 */}
