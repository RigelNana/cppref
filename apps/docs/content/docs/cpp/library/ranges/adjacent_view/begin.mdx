{/* source:cpp-ranges-adjacent-view-begin:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/adjacent_view/iterator) to the first element of the [`adjacent_view`](/docs/cpp/library/ranges/adjacent_view).

{/* source:cpp-ranges-adjacent-view-begin:0002 */}
Let [`base_`](/docs/cpp/library/ranges/adjacent_view#Data_members) be the underlying view.

{/* source:cpp-ranges-adjacent-view-begin:0003 */}
1) Equivalent to `return /*iterator*/<false>(ranges::begin(base_), ranges::end(base_));`

{/* source:cpp-ranges-adjacent-view-begin:0004 */}
2) Equivalent to `return /*iterator*/<true>(ranges::begin(base_), ranges::end(base_));`

### Parameters

{/* source:cpp-ranges-adjacent-view-begin:0005 */}
(none)

### Return value

{/* source:cpp-ranges-adjacent-view-begin:0006 */}
Iterator to the first element.

### Example

{/* source:cpp-ranges-adjacent-view-begin:0007 */}
```cpp
#include <ranges>
#include <tuple>
#include <type_traits>
 
int main()
{
    constexpr static auto v = {'A', 'B', 'C', 'D', 'E'};
 
    constexpr auto view = std::views::adjacent<3>(v);
 
    constexpr auto tuple = *view.begin();
 
    static_assert
    (
        std::is_same_v
        <
            decltype(tuple),
            const std::tuple<char const&, char const&, char const&>
        >
    );
 
    static_assert
    (
        std::get<0>(tuple) == 'A' &&
        std::get<1>(tuple) == 'B' &&
        std::get<2>(tuple) == 'C'
    );
}
```
