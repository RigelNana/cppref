{/* source:cpp-ranges-adjacent-view-sentinel:0001 */}
The return type of [`adjacent_view::end`](/docs/cpp/library/ranges/adjacent_view/end) when the underlying view is not a [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-adjacent-view-sentinel:0002 */}
The type `/*sentinel*/<true>` is returned by the const-qualified overload. The type `/*sentinel*/<false>` is returned by the non-const-qualified overload.
