{/* source:cpp-ranges-adjacent-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/adjacent_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/adjacent_view/sentinel) representing the end of the [`adjacent_view`](/docs/cpp/library/ranges/adjacent_view).

{/* source:cpp-ranges-adjacent-view-end:0002 */}
Let [`base_`](/docs/cpp/library/ranges/adjacent_view#Data_members) be the underlying view.

{/* source:cpp-ranges-adjacent-view-end:0003 */}
1) Equivalent to:

```cpp
if constexpr (ranges::common_range<V>)
    return /*iterator*/<false>(__as_sentinel{}, ranges::begin(base_), ranges::end(base_));
else
    return /*sentinel*/<false>(ranges::end(base_));
```

{/* source:cpp-ranges-adjacent-view-end:0004 */}
2) Equivalent to:

```cpp
if constexpr (ranges::common_range<const V>)
    return /*iterator*/<true>(__as_sentinel{}, ranges::begin(base_), ranges::end(base_));
else
    return /*sentinel*/<true>(ranges::end(base_));
```

### Parameters

{/* source:cpp-ranges-adjacent-view-end:0005 */}
(none)

### Return value

{/* source:cpp-ranges-adjacent-view-end:0006 */}
An [`iterator`](/docs/cpp/library/ranges/adjacent_view/iterator) to the element following the last element, if the underlying view `V` models [`common_range`](/docs/cpp/library/ranges/common_range). Otherwise, a [`sentinel`](/docs/cpp/library/ranges/adjacent_view/sentinel) which compares equal to the end iterator.

### Notes

{/* source:cpp-ranges-adjacent-view-end:0007 */}
`ranges::adjacent_view<V,N>` models [`common_range`](/docs/cpp/library/ranges/common_range) whenever the underlying view `V` does.
