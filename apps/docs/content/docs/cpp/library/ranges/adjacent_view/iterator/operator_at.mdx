{/* source:cpp-ranges-adjacent-view-iterator-operator-at:0001 */}
Returns an element at specified relative location.

{/* source:cpp-ranges-adjacent-view-iterator-operator-at:0002 */}
Let [`current_`](/docs/cpp/library/ranges/adjacent_view/iterator#Data_members) be an underlying array of iterators.

{/* source:cpp-ranges-adjacent-view-iterator-operator-at:0003 */}
Equivalent to:

{/* source:cpp-ranges-adjacent-view-iterator-operator-at:0004 */}
```cpp
return /*tuple-transform*/([&](auto& i) -> decltype(auto) { return i[n]; }, current_);
```

### Parameters

{/* source:cpp-ranges-adjacent-view-iterator-operator-at:0005 */}
<ParameterList>
  <Parameter name="n">position relative to current location</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-adjacent-view-iterator-operator-at:0006 */}
The element at displacement `n` relative to the current location.

### Example

{/* source:cpp-ranges-adjacent-view-iterator-operator-at:0007 */}
```cpp
#include <ranges>
#include <tuple>
 
int main()
{
    constexpr static auto v = {0, 1, 2, 3, 4, 5};
    //                               └──┬──┘  
    //                                  └─────────────────┐
    constexpr auto view = v | std::views::adjacent<3>; // │
    //                 ┌───────────────────┬──────────────┘ 
    //                 │                ┌──┴──┐
    static_assert(view[2] == std::tuple{2, 3, 4});
}
```
