{/* source:cpp-ranges-adjacent-view:0001 */}
1) `adjacent_view` is a range adaptor that takes a [`view`](/docs/cpp/library/ranges/view), and produces a [`view`](/docs/cpp/library/ranges/view) whose `i`-th element (a "window") is a [`std::tuple`](/docs/cpp/library/utility/tuple) that holds `N` references to the elements of the original view, from `i`-th up to `i + N - 1`-th inclusively.

{/* source:cpp-ranges-adjacent-view:0002 */}
Let `S` be the size of the original view. Then the size of produced view is:

- `S - N + 1`, if `S >= N`,
- `0` otherwise, and the resulting view is empty.

{/* source:cpp-ranges-adjacent-view:0003 */}
2) The name `views::adjacent<N>` denotes a [RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject). Given a subexpression `e` and a constant expression `N`, the expression `views::adjacent<N>(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `((void)e, auto(views::empty<tuple<>>))` if `N` is equal to `0` and `decltype((e))` models [`forward_range`](/docs/cpp/library/ranges/forward_range), `adjacent_view<views::all_t<decltype((e))>, N>(e)` otherwise.

{/* source:cpp-ranges-adjacent-view:0004 */}
3) The name `views::pairwise` denotes a [RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject) that behaves exactly as `views::adjacent<2>`.

{/* source:cpp-ranges-adjacent-view:0005 */}
`adjacent_view` always models [`forward_range`](/docs/cpp/library/ranges/forward_range), and models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), or [`sized_range`](/docs/cpp/library/ranges/sized_range) if adapted [`view`](/docs/cpp/library/ranges/view) type models the corresponding concept.

### Notes

{/* source:cpp-ranges-adjacent-view:0012 */}
`views::adjacent` only accepts forward ranges even when `N` is `0`.

{/* source:cpp-ranges-adjacent-view:0013 */}
There are similarities between `ranges::adjacent_view` and `ranges::slide_view`:

{/* source:cpp-ranges-adjacent-view:0014 */}
- Both create a "sliding window" of size `N`.
- Both have the same size `S - N + 1`, where `S` is the size of an adapted [`view`](/docs/cpp/library/ranges/view) such that `S >= N > 0`.

{/* source:cpp-ranges-adjacent-view:0015 */}
The following table shows the differences between these adaptors:

{/* source:cpp-ranges-adjacent-view:0016 */}
| View adaptor | `value_type` | The window size `N` |
| --- | --- | --- |
| `ranges::adjacent_view` | [`std::tuple`](/docs/cpp/library/utility/tuple) | A template parameter |
| [`ranges::slide_view`](/docs/cpp/library/ranges/slide_view) | [`ranges::range`](/docs/cpp/library/ranges/range) | A runtime argument |

{/* source:cpp-ranges-adjacent-view:0017 */}
| [`Feature-test`](/docs/cpp/library/utility/feature_test) macro | Value | Std | Feature |
| --- | --- | --- | --- |
| [`__cpp_lib_ranges_zip`](/docs/cpp/library/feature_test#cpp_lib_ranges_zip) | [`202110L`](/docs/cpp/library/compiler_support/23#cpp_lib_ranges_zip_202110L) | (C++23) | [`ranges::zip_view`](/docs/cpp/library/ranges/zip_view), [`ranges::zip_transform_view`](/docs/cpp/library/ranges/zip_transform_view), `ranges::adjacent_view`, [`ranges::adjacent_transform_view`](/docs/cpp/library/ranges/adjacent_transform_view) |

### Example

{/* source:cpp-ranges-adjacent-view:0018 */}
```cpp
#include <array>
#include <format>
#include <iostream>
#include <ranges>
#include <tuple>
 
int main()
{
    constexpr std::array v{1, 2, 3, 4, 5, 6};
    std::cout << "v = [1 2 3 4 5 6]\n";
 
    for (int i{}; std::tuple t : v | std::views::adjacent<3>)
    {
        auto [t0, t1, t2] = t;
        std::cout << std::format("e = {:<{}}[{} {} {}]\n", "", 2 * i++, t0, t1, t2);
    }
}
```

Output:

```text
v = [1 2 3 4 5 6]
e = [1 2 3]
e =   [2 3 4]
e =     [3 4 5]
e =       [4 5 6]
```
