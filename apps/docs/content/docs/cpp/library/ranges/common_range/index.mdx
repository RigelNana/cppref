{/* source:cpp-ranges-common-range:0001 */}
The `common_range` concept is a refinement of [`range`](/docs/cpp/library/ranges/range) for which [`std::ranges::begin()`](/docs/cpp/library/ranges/begin) and [`std::ranges::end()`](/docs/cpp/library/ranges/end) return the same type (e.g. all standard library containers).

### Example

{/* source:cpp-ranges-common-range:0002 */}
```cpp
#include <ranges>
 
struct A
{
    char* begin();
    char* end();
};
static_assert( std::ranges::common_range<A> );
 
struct B
{
    char* begin();
    bool end();
};  // not a common_range: begin/end have different types
static_assert( not std::ranges::common_range<B> );
 
struct C
{
    char* begin();
};  // not a common_range, not even a range: has no end()
static_assert( not std::ranges::common_range<C> );
 
int main() {}
```
