{/* source:cpp-ranges-join-view-sentinel:0001 */}
The return type of [`join_view::end`](/docs/cpp/library/ranges/join_view/end) when either of the underlying ranges (`V` or `ranges::range_reference_t<V>`) is not a [`common_range`](/docs/cpp/library/ranges/common_range), or when the parent `join_view` is not a [`forward_range`](/docs/cpp/library/ranges/forward_range).

{/* source:cpp-ranges-join-view-sentinel:0002 */}
If `V` is not a [simple view](/docs/cpp/library/ranges#Helper_concepts), `Const` is `true` for sentinels returned from the const overloads, and `false` otherwise. If `V` is a simple view, `Const` is `true`.
