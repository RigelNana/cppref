Constructs a sentinel.

{/* source:cpp-ranges-join-view-sentinel-sentinel:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying sentinel.

{/* source:cpp-ranges-join-view-sentinel-sentinel:0003 */}
2. 2) Initializes the underlying sentinel `end_` with `ranges::end(parent.base_)`.

{/* source:cpp-ranges-join-view-sentinel-sentinel:0004 */}
3. 3) Conversion from `/*sentinel*/<false>` to `/*sentinel*/<true>`. Move constructs the underlying sentinel `end_` with `std::move(i.end_)`.
