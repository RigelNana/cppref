{/* source:cpp-ranges-join-view-end:0001 */}
Returns a [`sentinel`](/docs/cpp/library/ranges/join_view/sentinel) or an [`iterator`](/docs/cpp/library/ranges/join_view/iterator) representing the end of the `join_view`.

{/* source:cpp-ranges-join-view-end:0002 */}
Let `base_` be the underlying view:

{/* source:cpp-ranges-join-view-end:0003 */}
1. 1) Equivalent to

```cpp
if constexpr (ranges::forward_range<V> &&
              std::is_reference_v<ranges::range_reference_t<V>> &&
              ranges::forward_range<ranges::range_reference_t<V>> &&
              ranges::common_range<V> &&
              ranges::common_range<ranges::range_reference_t<V>>)
    return /*iterator*/</*simple-view*/<V>>{*this, ranges::end(base_)};
else
    return /*sentinel*/</*simple-view*/<V>>{*this};
```

{/* source:cpp-ranges-join-view-end:0004 */}
2. 2) Equivalent to

```cpp
if constexpr (ranges::forward_range<const V> &&
              std::is_reference_v<ranges::range_reference_t<const V>> &&
              ranges::forward_range<ranges::range_reference_t<const V>> &&
              ranges::common_range<const V> &&
              ranges::common_range<ranges::range_reference_t<const V>>)
    return /*iterator*/<true>{*this, ranges::end(base_)};
else
    return /*sentinel*/<true>{*this};
```

### Parameters

{/* source:cpp-ranges-join-view-end:0005 */}
(none)

### Return value

{/* source:cpp-ranges-join-view-end:0006 */}
1. 1) sentinel which compares equal to the end iterator.

{/* source:cpp-ranges-join-view-end:0007 */}
2. 2) iterator to the element following the last element.
