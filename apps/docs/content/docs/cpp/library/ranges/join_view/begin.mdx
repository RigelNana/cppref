{/* source:cpp-ranges-join-view-begin:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/join_view/iterator) to the first element of the `join_view`. Given `base_` is the underlying view,

{/* source:cpp-ranges-join-view-begin:0002 */}
1. 1) Equivalent to `return /*iterator*/<true>{*this, ranges::begin(base_)};` if `/*simple-view*/<V>` is satisfied and `ranges::range_reference_t<V>` is reference type. Otherwise, `return /*iterator*/<false>{*this, ranges::begin(base_)};`.

{/* source:cpp-ranges-join-view-begin:0003 */}
2. 2) Equivalent to `return /*iterator*/<true>{*this, ranges::begin(base_)};`.

### Parameters

{/* source:cpp-ranges-join-view-begin:0004 */}
(none)

### Return value

{/* source:cpp-ranges-join-view-begin:0005 */}
Iterator to the first element.

### Notes

{/* source:cpp-ranges-join-view-begin:0006 */}
When `ranges::range_reference_t<V>` is not a reference type, that is, deferencing an iterator of V returns a prvalue temporary, the `join_view` is only an [`input_range`](/docs/cpp/library/ranges/input_range), in which case only single-pass iteration is supported, and repeated calls to `begin()` may not give meaningful results.
