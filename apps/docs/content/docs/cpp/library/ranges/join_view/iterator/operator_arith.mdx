{/* source:cpp-ranges-join-view-iterator-operator-arith:0001 */}
Increments or decrements the underlying iterator.

{/* source:cpp-ranges-join-view-iterator-operator-arith:0002 */}
Let [`inner_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) and [`outer_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) be the underlying iterators, and [`parent_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) be the pointer to parent [`ranges::join_view`](/docs/cpp/library/ranges/join_view), the constant `/*ref-is-glvalue*/` be `std::is_reference_v<ranges::range_reference_t<Base>>`.

{/* source:cpp-ranges-join-view-iterator-operator-arith:0003 */}
1. 1) Let `/*inner-range*/` be: `*outer_`, if `/*ref-is-glvalue*/ == true`; `*parent_->inner_` otherwise. Equivalent to:

```cpp
auto&& inner_rng = /*inner-range*/;
if (++inner_ == ranges::end(inner_rng))
{
    ++outer_;
    satisfy();
}
return *this;
```

{/* source:cpp-ranges-join-view-iterator-operator-arith:0004 */}
2. 2) Equivalent to: `++*this`.

{/* source:cpp-ranges-join-view-iterator-operator-arith:0005 */}
3. 3) Equivalent to:

```cpp
auto tmp = *this;
++*this;
return tmp;
```

{/* source:cpp-ranges-join-view-iterator-operator-arith:0006 */}
4. 4) Equivalent to:

```cpp
if (outer_ == ranges::end(parent_->base_))
    inner_ = ranges::end(*--outer_);
while (inner_ == ranges::begin(*outer_))
    inner_ = ranges::end(*--outer_);
--inner_;
return *this;
```

{/* source:cpp-ranges-join-view-iterator-operator-arith:0007 */}
5. 5) Equivalent to:

```cpp
auto tmp = *this;
--*this;
return tmp;
```
