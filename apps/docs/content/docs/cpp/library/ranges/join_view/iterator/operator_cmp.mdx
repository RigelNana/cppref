{/* source:cpp-ranges-join-view-iterator-operator-cmp:0001 */}
Compares the underlying iterators.

{/* source:cpp-ranges-join-view-iterator-operator-cmp:0002 */}
Equivalent to: `return (x.outer_ == y.outer_) and (x.inner_ == y.inner_);`, where [`outer_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) and [`inner_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) are the underlying iterators. The constant `/*ref-is-glvalue*/` in the requires-clause is equal to `std::is_reference_v<ranges::range_reference_t<Base>>`.

{/* source:cpp-ranges-join-view-iterator-operator-cmp:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

{/* source:cpp-ranges-join-view-iterator-operator-cmp:0004 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::join_view::iterator<Const>` is an associated class of the arguments.
