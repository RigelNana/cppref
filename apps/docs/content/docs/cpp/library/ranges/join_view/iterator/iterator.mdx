Constructs an iterator.

{/* source:cpp-ranges-join-view-iterator-iterator:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying iterators, and initializes the pointer to parent [`ranges::join_view`](/docs/cpp/library/ranges/join_view) with `nullptr`.

{/* source:cpp-ranges-join-view-iterator-iterator:0003 */}
2. 2) Initializes the underlying [`outer_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) iterator with `std::move(outer)`, and the pointer to parent [`parent_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) with `std::addressof(parent)`; then calls [`satisfy()`](/docs/cpp/library/ranges/join_view/iterator/satisfy).

{/* source:cpp-ranges-join-view-iterator-iterator:0004 */}
3. 3) Converts `/*iterator*/<false>` to `/*iterator*/<true>`. Move constructs the underlying iterators [`outer_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) with `std::move(i.outer_)`, [`inner_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) with `std::move(i.inner_)`, and underlying pointer to parent [`parent_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) with `i.parent_`.
