{/* source:cpp-ranges-join-view:0001 */}
1) A range adaptor that represents [`view`](/docs/cpp/library/ranges/view) consisting of the sequence obtained from flattening a view of ranges.

{/* source:cpp-ranges-join-view:0002 */}
2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject) (and also [*RangeAdaptorClosureObject*](/docs/cpp/library/named_req/RangeAdaptorClosureObject)). The expression `views::join(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `join_view<views::all_t<decltype((e))>>{e}` for any suitable subexpressions `e`.

{/* source:cpp-ranges-join-view:0003 */}
`join_view` models [`input_range`](/docs/cpp/library/ranges/input_range).

{/* source:cpp-ranges-join-view:0004 */}
`join_view` models [`forward_range`](/docs/cpp/library/ranges/forward_range) when:

{/* source:cpp-ranges-join-view:0005 */}
- `ranges::range_reference_t<V>` is a reference type, and
- `V` and `ranges::range_reference_t<V>` each model [`forward_range`](/docs/cpp/library/ranges/forward_range).

{/* source:cpp-ranges-join-view:0006 */}
`join_view` models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range) when:

{/* source:cpp-ranges-join-view:0007 */}
- `ranges::range_reference_t<V>` is a reference type,
- `V` models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), and
- `ranges::range_reference_t<V>` models both [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range) and [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-join-view:0008 */}
`join_view` models [`common_range`](/docs/cpp/library/ranges/common_range) when:

{/* source:cpp-ranges-join-view:0009 */}
- `ranges::range_reference_t<V>` is a reference type, and
- `V` and `ranges::range_reference_t<V>` each model [`forward_range`](/docs/cpp/library/ranges/forward_range) and [`common_range`](/docs/cpp/library/ranges/common_range).

### Notes

{/* source:cpp-ranges-join-view:0012 */}
Before [P2328R1](https://wg21.link/P2328R1) was adopted, the inner range type (`ranges::range_reference_t<V>`) cannot be a container type (but can be reference to container). For example, it was not allowed to join a [`transform_view`](/docs/cpp/library/ranges/transform_view) of [`std::string`](/docs/cpp/library/string/basic_string) prvalue.

{/* source:cpp-ranges-join-view:0013 */}
```cpp
struct Person { int age; std::string name; };
 
auto f(std::vector<Person>& v) {
//  return v | std::views::transform([](auto& p){ return p.name; })
//           | std::views::join; // error before P2328R1
    return v | std::views::transform([](auto& p) -> std::string& { return p.name; })
             | std::views::join; // OK
}
```

### Example

{/* source:cpp-ranges-join-view:0014 */}
```cpp
#include <iostream>
#include <ranges>
#include <string_view>
#include <vector>
 
int main()
{
    using namespace std::literals;
 
    const auto bits = {"https:"sv, "//"sv, "cppreference"sv, "."sv, "com"sv};
    for (char const c : bits | std::views::join)
        std::cout << c;
    std::cout << '\n';
 
    const std::vector<std::vector<int>> v{{1, 2}, {3, 4, 5}, {6}, {7, 8, 9}};
    auto jv = std::ranges::join_view(v);
    for (int const e : jv)
        std::cout << e << ' ';
    std::cout << '\n';
}
```

Output:

```text
https://cppreference.com
1 2 3 4 5 6 7 8 9
```
