{/* source:cpp-ranges-join-view-iterator-iter-move:0001 */}
Casts the result of dereferencing the underlying iterator `i.`[`inner_`](/docs/cpp/library/ranges/join_view/iterator#Data_members) to its associated rvalue reference type.

{/* source:cpp-ranges-join-view-iterator-iter-move:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `join_view::iterator<Const>` is an associated class of the arguments.

</ParameterList>

### Return value

{/* source:cpp-ranges-join-view-iterator-iter-move:0004 */}
Equivalent to: `ranges::iter_move(i.inner_)`.
