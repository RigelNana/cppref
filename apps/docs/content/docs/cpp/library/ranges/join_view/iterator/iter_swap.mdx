{/* source:cpp-ranges-join-view-iterator-iter-swap:0001 */}
Swaps the objects pointed to by two underlying iterators (denoted as [`inner_`](/docs/cpp/library/ranges/join_view/iterator#Data_members)).

{/* source:cpp-ranges-join-view-iterator-iter-swap:0002 */}
Equivalent to: `ranges::iter_swap(x.inner_, y.inner_);`.

{/* source:cpp-ranges-join-view-iterator-iter-swap:0003 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `join_view::iterator<Const>` is an associated class of the arguments.
