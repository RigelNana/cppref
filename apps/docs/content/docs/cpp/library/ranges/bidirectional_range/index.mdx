{/* source:cpp-ranges-bidirectional-range:0001 */}
The `bidirectional_range` concept is a refinement of [`range`](/docs/cpp/library/ranges/range) for which `ranges::begin` returns a model of [`bidirectional_iterator`](/docs/cpp/library/iterator/bidirectional_iterator).

### Example

{/* source:cpp-ranges-bidirectional-range:0002 */}
```cpp
#include <forward_list>
#include <list>
#include <ranges>
#include <set>
#include <unordered_set>
 
int main()
{
    static_assert(
            std::ranges::bidirectional_range<std::set<int>> and
        not std::ranges::bidirectional_range<std::unordered_set<int>> and
            std::ranges::bidirectional_range<std::list<int>> and
        not std::ranges::bidirectional_range<std::forward_list<int>>
    );
}
```
