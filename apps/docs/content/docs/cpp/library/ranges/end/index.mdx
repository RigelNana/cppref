Returns a sentinel indicating the end of a range.

{/* source:cpp-ranges-end:0002 */}
If the argument is an lvalue or `ranges::enable_borrowed_range<std::remove_cv_t<T>>` is `true`, then a call to `ranges::end` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

{/* source:cpp-ranges-end:0003 */}
1. `t + std::extent_v<T>` if `t` has an array type of known bound.
   - If `std::remove_all_extents_t<std::remove_reference_t<T>>` is incomplete, then the call to `ranges::end` is ill-formed, [no diagnostic required](/docs/cpp/language/ndr).
2. Otherwise, <InlineRevision until="C++23">[`decay-copy`](/docs/cpp/library/standard_library/decay-copy) `(t.end())`</InlineRevision><InlineRevision since="C++23">`auto(t.end())`</InlineRevision>, if that expression is valid, and its type models `std::sentinel_for<ranges::iterator_t<T>>`.
3. Otherwise, <InlineRevision until="C++23">[`decay-copy`](/docs/cpp/library/standard_library/decay-copy) `(end(t))`</InlineRevision><InlineRevision since="C++23">`auto(end(t))`</InlineRevision>, if `T` is a class or enumeration type, that expression is valid and its converted type models `std::sentinel_for<ranges::iterator_t<T>>`, where the meaning of `end` is established as if by performing [argument-dependent lookup](/docs/cpp/language/functions/adl) only.

{/* source:cpp-ranges-end:0004 */}
In all other cases, a call to `ranges::end` is ill-formed, which can result in [substitution failure](/docs/cpp/language/templates/sfinae) when the call to `ranges::end` appears in the immediate context of a template instantiation.

### Customization point objects

{/* source:cpp-ranges-end:0005 */}
The name `ranges::end` denotes a *customization point object*, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as `__end_fn`.

{/* source:cpp-ranges-end:0006 */}
All instances of `__end_fn` are equal. The effects of invoking different instances of type `__end_fn` on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `ranges::end` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-end:0007 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `ranges::end` above, `__end_fn` models

{/* source:cpp-ranges-end:0008 */}
- `std::invocable<__end_fn, Args...>`,
- `std::invocable<const __end_fn, Args...>`,
- `std::invocable<__end_fn&, Args...>`, and
- `std::invocable<const __end_fn&, Args...>`.

{/* source:cpp-ranges-end:0009 */}
Otherwise, no function call operator of `__end_fn` participates in overload resolution.

### Notes

{/* source:cpp-ranges-end:0010 */}
If the argument is an rvalue (i.e. `T` is an object type) and `ranges::enable_borrowed_range<std::remove_cv_t<T>>` is `false`, or if it is of an array type of unknown bound, the call to `ranges::end` is ill-formed, which also results in substitution failure.

{/* source:cpp-ranges-end:0011 */}
If `ranges::end(std::forward<T>(t))` is valid, then `decltype(ranges::end(std::forward<T>(t)))` and `decltype(ranges::begin(std::forward<T>(t)))` model [`std::sentinel_for`](/docs/cpp/library/iterator/sentinel_for) in all cases, while `T` models [`std::ranges::range`](/docs/cpp/library/ranges/range).

{/* source:cpp-ranges-end:0012 */}
The C++20 standard requires that if the underlying `end` function call returns a prvalue, the return value is move-constructed from the materialized temporary object. All implementations directly return the prvalue instead. The requirement is corrected by the post-C++20 proposal [P0849R8](https://wg21.link/P0849R8) to match the implementations.

### Example

{/* source:cpp-ranges-end:0013 */}
```cpp
#include <algorithm>
#include <iostream>
#include <ranges>
#include <vector>
 
int main()
{
    std::vector<int> vec{3, 1, 4};
    if (std::ranges::find(vec, 5) != std::ranges::end(vec))
        std::cout << "found a 5 in vector vec!\n";
 
    int arr[]{5, 10, 15};
    if (std::ranges::find(arr, 5) != std::ranges::end(arr))
        std::cout << "found a 5 in array arr!\n";
}
```

Output:

```text
found a 5 in array arr!
```
