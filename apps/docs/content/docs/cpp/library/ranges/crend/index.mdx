{/* source:cpp-ranges-crend:0001 */}
Returns a sentinel <InlineRevision since="C++23">for the constant iterator</InlineRevision> indicating the end of a <InlineRevision until="C++23">const-qualified</InlineRevision> range that is treated as a reversed sequence.

{/* source:cpp-ranges-crend:0002 */}
<Revision until="C++23">
Let `CT` be

- `const std::remove_reference_t<T>&` if the argument is an lvalue (i.e. `T` is an lvalue reference type),
- `const T` otherwise.

A call to `ranges::crend` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `ranges::rend(static_cast<CT&&>(t))`.
</Revision>
<Revision since="C++23">
If the argument is an lvalue or `ranges::enable_borrowed_range<std::remove_cv_t<T>>` is `true`, then a call to `ranges::crend` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

- `std::const_sentinel<decltype(U)>(U)` for some expression `U` equivalent to `ranges::rend(`[`possibly-const-range`](/docs/cpp/library/ranges#possibly-const-range)`(t))`.

In all other cases, a call to `ranges::crend` is ill-formed, which can result in [substitution failure](/docs/cpp/language/templates/sfinae) when the call appears in the immediate context of a template instantiation.
</Revision>

{/* source:cpp-ranges-crend:0003 */}
If `ranges::crend(e)` is valid for an expression `e`, where `decltype((e))` is `T`, then <InlineRevision until="C++23">`CT` models [`std::ranges::range`](/docs/cpp/library/ranges/range), and</InlineRevision> `std::sentinel_for<S, I>` is `true` in all cases, where `S` is `decltype(ranges::crend(e))`, and `I` is `decltype(ranges::crbegin(e))`. <InlineRevision since="C++23">Additionally, `S` models [`constant-iterator`](/docs/cpp/library/ranges/constant_range) if it models [`input_iterator`](/docs/cpp/library/iterator/input_iterator).</InlineRevision>

### Customization point objects

{/* source:cpp-ranges-crend:0004 */}
The name `ranges::crend` denotes a *customization point object*, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as `__crend_fn`.

{/* source:cpp-ranges-crend:0005 */}
All instances of `__crend_fn` are equal. The effects of invoking different instances of type `__crend_fn` on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `ranges::crend` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-crend:0006 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `ranges::crend` above, `__crend_fn` models

{/* source:cpp-ranges-crend:0007 */}
- `std::invocable<__crend_fn, Args...>`,
- `std::invocable<const __crend_fn, Args...>`,
- `std::invocable<__crend_fn&, Args...>`, and
- `std::invocable<const __crend_fn&, Args...>`.

{/* source:cpp-ranges-crend:0008 */}
Otherwise, no function call operator of `__crend_fn` participates in overload resolution.

### Example

{/* source:cpp-ranges-crend:0009 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <vector>
 
int main()
{
    int a[]{4, 6, -3, 9, 10};
    std::cout << "Array backwards: ";
    namespace ranges = std::ranges;
    ranges::copy(ranges::rbegin(a), ranges::rend(a),
                 std::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';
 
    std::cout << "Vector backwards: ";
    std::vector v{4, 6, -3, 9, 10};
    ranges::copy(ranges::rbegin(v), ranges::rend(v),
                 std::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';
}
```

Output:

```text
Array backwards: 10 9 -3 6 4
Vector backwards: 10 9 -3 6 4
```
