{/* source:cpp-ranges-elements-of:0001 */}
Encapsulates a [`range`](/docs/cpp/library/ranges/range). Specializations of `elements_of` act as a tag in overload sets to disambiguate when a range should be treated as a sequence rather than a single value.

### Template parameters

{/* source:cpp-ranges-elements-of:0002 */}
<ParameterList>
  <Parameter name="R">a type that satisfies [`range`](/docs/cpp/library/ranges/range)</Parameter>
  <Parameter name="Allocator">an allocator type that meets the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator)</Parameter>
</ParameterList>

### Data members

{/* source:cpp-ranges-elements-of:0003 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`range`</DescriptionTerm>
    <DescriptionBody>a range of type `R` (public member object)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`allocator`</DescriptionTerm>
    <DescriptionBody>an allocator of type `Allocator`. It has default member initializer that value initializes itself (public member object)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-ranges-elements-of:0004 */}
All these members are declared with [`[[no_unique_address]]`](/docs/cpp/language/declarations/attributes/no_unique_address) attribute.

### Example

{/* source:cpp-ranges-elements-of:0006 */}
```cpp
#include <any>
#include <generator>
#include <iostream>
#include <ranges>
#include <string_view>
 
template<bool Elementwise>
std::generator<std::any> gen(std::ranges::input_range auto&& r)
{
    if constexpr (Elementwise)
        co_yield std::ranges::elements_of(r); // yield each element of r
    else
        co_yield r;                           // yield r as a single value
}
 
int main()
{
    auto test = std::string_view{"test"};
 
    for (std::any a : gen<true>(test))
        std::cout << '[' << std::any_cast<char>(a) << "] ";
    std::cout << '\n';
 
    for (std::any a : gen<false>(test))
        std::cout << '[' << std::any_cast<std::string_view>(a) << "] ";
    std::cout << '\n';
}
```

Output:

```text
[t] [e] [s] [t] 
[test]
```
