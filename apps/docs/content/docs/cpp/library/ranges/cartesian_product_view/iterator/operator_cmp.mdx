Compares two [`iterators`](/docs/cpp/library/ranges/cartesian_product_view/iterator) or an iterator and a sentinel.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-cmp:0002 */}
Let *[`current_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* denote the underlying tuple of iterators.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-cmp:0003 */}
1. 1) Equivalent to: `return x.current_ == y.current_;`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-cmp:0004 */}
2. 2) Returns `true` if `std::get<i>(x.current_) == ranges::end(std::get<i>(x.parent_->bases_))` is `true` for any integer `0 ≤ i ≤ sizeof...(Vs)`. Otherwise, returns `false`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-cmp:0005 */}
3. 3) Equivalent to: `return x.current_ <=> y.current_;`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-cmp:0006 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::cartesian_product_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-cmp:0007 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
