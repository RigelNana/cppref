Let *[`current_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* be the underlying tuple of iterators.

{/* source:cpp-ranges-cartesian-product-view-iterator-iter-move:0002 */}
Equivalent to: `return /*tuple-transform*/(ranges::iter_move, i.current_);`

{/* source:cpp-ranges-cartesian-product-view-iterator-iter-move:0003 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `cartesian_product_view::iterator<Const>` is an associated class of the arguments.

### Parameters

{/* source:cpp-ranges-cartesian-product-view-iterator-iter-move:0004 */}
<ParameterList>
  <Parameter name="i">iterator</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-cartesian-product-view-iterator-iter-move:0005 */}
A tuple that contains the result of applying `ranges::iter_move` to the stored underlying iterators converted to the return type, as described above.

### Exceptions

{/* source:cpp-ranges-cartesian-product-view-iterator-iter-move:0006 */}
The exception specification is equivalent to the logical AND of the following expressions:

{/* source:cpp-ranges-cartesian-product-view-iterator-iter-move:0007 */}
- `noexcept(ranges::iter_move(std::get<N>(i.current_)))` for every integer `0 ≤ N ≤ sizeof...(Vs)`,
- `std::is_nothrow_move_constructible_v<ranges::range_rvalue_reference_t</*maybe-const*/<Const, T>>>` for every type `T` in `First`, `Vs...`.
