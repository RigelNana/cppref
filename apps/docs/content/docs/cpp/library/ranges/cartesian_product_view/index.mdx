{/* source:cpp-ranges-cartesian-product-view:0001 */}
1) `cartesian_product_view` is a range adaptor that takes *n* [`view`](/docs/cpp/library/ranges/view)s, where *n > 0*, and produces a [`view`](/docs/cpp/library/ranges/view) of tuples calculated by the [n-ary cartesian product](https://en.wikipedia.org/wiki/Cartesian_product#n-ary_Cartesian_product) of the provided ranges. The size of produced view is a multiple of sizes of provided ranges, while each element is a tuple (of references) of the size *n*.

{/* source:cpp-ranges-cartesian-product-view:0002 */}
2) `views::cartesian_product` is a customization point object.

- When calling with no argument, `views::cartesian_product()` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `views::single(std::tuple())`.
- Otherwise, `views::cartesian_product(rs...)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `ranges::cartesian_product_view<views::all_t<decltype((rs))>...>(rs...)`.

{/* source:cpp-ranges-cartesian-product-view:0003 */}
3) Determines if `cartesian_product` is a random access range (see also [`random_access_range`](/docs/cpp/library/ranges/random_access_range)).

{/* source:cpp-ranges-cartesian-product-view:0004 */}
4) Determines if `cartesian_product` is a common range (see also [`common_range`](/docs/cpp/library/ranges/common_range)).

{/* source:cpp-ranges-cartesian-product-view:0005 */}
5) Determines if `cartesian_product` is a bidirectional range (see also [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range)).

{/* source:cpp-ranges-cartesian-product-view:0006 */}
6) Determines if `cartesian_product` satisfies the helper concept `/*cartesian-product-is-common*/` (see also [`common_range`](/docs/cpp/library/ranges/common_range)).

{/* source:cpp-ranges-cartesian-product-view:0007 */}
7) Determines if `cartesian_product` is a sized range (see also [`sized_range`](/docs/cpp/library/ranges/sized_range)).

{/* source:cpp-ranges-cartesian-product-view:0008 */}
8) Determines if `cartesian_product` uses sized sentinel.

{/* source:cpp-ranges-cartesian-product-view:0009 */}
9) Returns the end of the produced [`view`](/docs/cpp/library/ranges/view). Participates in overload resolution only if `cartesian_product` satisfies the helper concept `/*cartesian-product-common-arg*/`.

{/* source:cpp-ranges-cartesian-product-view:0010 */}
The `First` [`range`](/docs/cpp/library/ranges/range) passed to `cartesian_product_view` is treated specially, since it is only passed through a single time. As a result, several constrains are relaxed on it:

{/* source:cpp-ranges-cartesian-product-view:0011 */}
- `First` is an [`input_range`](/docs/cpp/library/ranges/input_range) instead of [`forward_range`](/docs/cpp/library/ranges/forward_range);
- `First` does not have to be a [`sized_range`](/docs/cpp/library/ranges/sized_range) in order for the `cartesian_product_view` to be [`random_access_range`](/docs/cpp/library/ranges/random_access_range) or [`common_range`](/docs/cpp/library/ranges/common_range);
- `First` does not have to be [`common_range`](/docs/cpp/library/ranges/common_range) in order for the `cartesian_product_view` to be [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range).

### Customization point objects

{/* source:cpp-ranges-cartesian-product-view:0012 */}
The name `views::cartesian_product` denotes a *customization point object*, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as *`__cartesian_product_fn`*.

{/* source:cpp-ranges-cartesian-product-view:0013 */}
All instances of *`__cartesian_product_fn`* are equal. The effects of invoking different instances of type *`__cartesian_product_fn`* on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `views::cartesian_product` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-cartesian-product-view:0014 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `views::cartesian_product` above, *`__cartesian_product_fn`* models

{/* source:cpp-ranges-cartesian-product-view:0015 */}
- `std::invocable<__cartesian_product_fn, Args...>`,
- `std::invocable<const __cartesian_product_fn, Args...>`,
- `std::invocable<__cartesian_product_fn&, Args...>`, and
- `std::invocable<const __cartesian_product_fn&, Args...>`.

{/* source:cpp-ranges-cartesian-product-view:0016 */}
Otherwise, no function call operator of *`__cartesian_product_fn`* participates in overload resolution.

### Example

{/* source:cpp-ranges-cartesian-product-view:0021 */}
```cpp
#include <array>
#include <iostream>
#include <list>
#include <ranges>
#include <string>
#include <vector>
 
void print(std::tuple<char const&, int const&, std::string const&> t, int pos)
{
    const auto& [a, b, c] = t;
    std::cout << '(' << a << ' ' << b << ' ' << c << ')' << (pos % 4 ? " " : "\n");
}
 
int main()
{
    const auto x = std::array{'A', 'B'};
    const auto y = std::vector{1, 2, 3};
    const auto z = std::list<std::string>{"α", "β", "γ", "δ"};
 
    for (int i{1}; auto const& tuple : std::views::cartesian_product(x, y, z))
        print(tuple, i++);
}
```

Output:

```text
(A 1 α) (A 1 β) (A 1 γ) (A 1 δ)
(A 2 α) (A 2 β) (A 2 γ) (A 2 δ)
(A 3 α) (A 3 β) (A 3 γ) (A 3 δ)
(B 1 α) (B 1 β) (B 1 γ) (B 1 δ)
(B 2 α) (B 2 β) (B 2 γ) (B 2 δ)
(B 3 α) (B 3 β) (B 3 γ) (B 3 δ)
```
