{/* source:cpp-ranges-cartesian-product-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/cartesian_product_view/iterator) or a sentinel representing the end of the [`cartesian_product_view`](/docs/cpp/library/ranges/cartesian_product_view).

{/* source:cpp-ranges-cartesian-product-view-end:0002 */}
Let *[`bases_`](/docs/cpp/library/ranges/cartesian_product_view#Data_members)* be the underlying tuple of views.

{/* source:cpp-ranges-cartesian-product-view-end:0003 */}
1,2) Equivalent to

{/* source:cpp-ranges-cartesian-product-view-end:0004 */}
```cpp
auto check = [](auto& rng) { return __begin_or_first_end(rng); };
return iterator<__is_const>(/*tuple-transform*/(check, bases_));
```

{/* source:cpp-ranges-cartesian-product-view-end:0005 */}
where:

- `__is_const` is `true` for the *const-qualified* overload, and `false` otherwise.
- `__is_empty` is `true` if the expression `ranges::empty(rng)` is `true` for any `rng` among the underlying ranges except the first one and `false` otherwise.
- `__begin_or_first_end(rng)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `__is_empty ? ranges::begin(rng) : /*cartesian-common-arg-end*/(rng)` if `rng` is the first underlying range and `ranges::begin(rng)` otherwise.

{/* source:cpp-ranges-cartesian-product-view-end:0006 */}
3. 3) Equivalent to: `return std::default_sentinel;`.

### Parameters

{/* source:cpp-ranges-cartesian-product-view-end:0007 */}
(none)

### Return value

{/* source:cpp-ranges-cartesian-product-view-end:0008 */}
An [`iterator`](/docs/cpp/library/ranges/cartesian_product_view/iterator) to the element following the last element, or a sentinel which compares equal to the end iterator.

### Example

{/* source:cpp-ranges-cartesian-product-view-end:0009 */}
```cpp
#include <array>
#include <format>
#include <iostream>
#include <ranges>
#include <string_view>
#include <tuple>
using namespace std::literals;
 
int main()
{
    constexpr auto a = std::array{ "bool"sv, "goto"sv, "extern"sv, "long"sv }; /*
                                       ^         ^           ^         ^        */
    constexpr auto v = std::ranges::cartesian_product_view(a[0], a[1], a[2], a[3]);
 
    constexpr std::tuple<char const&,
                         char const&,
                         char const&,
                         char const&> last{*(v.end() - 1)};
 
    std::cout << std::format("{}{}{}{}{}",
                             std::get<0>(last),
                             std::get<1>(last),
                             std::get<2>(last),
                             std::get<3>(last), '\n');
}
```

Output:

```text
long
```
