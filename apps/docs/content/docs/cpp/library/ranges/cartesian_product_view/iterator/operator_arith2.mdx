{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0001 */}
Performs [`iterator`](/docs/cpp/library/ranges/cartesian_product_view/iterator) arithmetic or calculates the distance.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0002 */}
Let *[`current_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* denote the underlying tuple of iterators and *[`parent_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* denote the underlying pointer to `cartesian_product_view`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0003 */}
1. 1) Equivalent to: `return /*iterator*/(i) += n;`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0004 */}
2. 2) Equivalent to: `return i + n;`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0005 */}
3. 3) Equivalent to: `return /*iterator*/(i) -= n;`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0006 */}
4. 4) Equivalent to: `return i.`[`distance_from`](/docs/cpp/library/ranges/cartesian_product_view/iterator/helpers#distance_from)`(j.current_);`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0007 */}
5. 5) Let `/*end-tuple*/` be an object of a type that is a specialization of [`tuple`](/docs/cpp/library/utility/tuple), such that:

- `std::get<0>(/*end-tuple*/)` has the same value as `ranges::end(std::get<0>(i.parent_->bases_));`
- `std::get<N>(/*end-tuple*/)` has the same value as `ranges::begin(std::get<N>(i.parent_->bases_))` for every integer `1 ≤ N ≤ sizeof...(Vs)`.

Equivalent to: `return i.`[`distance_from`](/docs/cpp/library/ranges/cartesian_product_view/iterator/helpers#distance_from)`(/*end-tuple*/);`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0008 */}
6. 6) Equivalent to: `return -(i - s);`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0009 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `cartesian_product_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0011 */}
1,2) An incremented iterator.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0012 */}
3. 3) A decremented iterator.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0013 */}
4. 4) A distance between given iterators.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith2:0014 */}
5,6) A distance between given iterator and sentinel.
