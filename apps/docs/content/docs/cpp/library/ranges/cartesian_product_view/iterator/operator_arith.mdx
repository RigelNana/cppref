{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0001 */}
Increments or decrements the [`iterator`](/docs/cpp/library/ranges/cartesian_product_view/iterator/iterator).

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0002 */}
Let *[`current_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* denote the underlying tuple of iterators and *[`parent_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* denote the underlying pointer to `cartesian_product_view`.

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0003 */}
1. 1) Equivalent to [`next`](/docs/cpp/library/ranges/cartesian_product_view/iterator/helpers#next)`(); return *this;`

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0004 */}
2. 2) Equivalent to `++*this;`

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0005 */}
3. 3) Equivalent to `auto tmp = *this; ++*this; return tmp;`

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0006 */}
4. 4) Equivalent to [`prev`](/docs/cpp/library/ranges/cartesian_product_view/iterator/helpers#prev)`(); return *this;`

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0007 */}
5. 5) Equivalent to `auto tmp = *this; --*this; return tmp;`

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0008 */}
6. 6) Sets the value of `*this` to `ret`, where `ret` is: if `n > 0`, the value of `*this` provided that [`next`](/docs/cpp/library/ranges/cartesian_product_view/iterator/helpers#next) been called `n` times. Otherwise, if `n < 0`, the value of `*this` provided that [`prev`](/docs/cpp/library/ranges/cartesian_product_view/iterator/helpers#prev) been called `-n` times. Otherwise, the value of `*this` before the call. The behavior is undefined if `n` is not in the range [`ranges::distance(*this, ranges::begin(*parent_))`, `ranges::distance(*this, ranges::end(*parent_))`).

{/* source:cpp-ranges-cartesian-product-view-iterator-operator-arith:0009 */}
7. 7) Equivalent to `*this += -n; return *this;`.
