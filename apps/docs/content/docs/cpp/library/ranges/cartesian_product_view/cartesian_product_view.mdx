Constructs an [`cartesian_product_view`](/docs/cpp/library/ranges/cartesian_product_view).

{/* source:cpp-ranges-cartesian-product-view-cartesian-product-view:0002 */}
1. 1) Default constructor. [Default-initializes](/docs/cpp/language/initialization/default_initialization) the underlying data member *[`base_`](/docs/cpp/library/ranges/cartesian_product_view#Data_members)*.

{/* source:cpp-ranges-cartesian-product-view-cartesian-product-view:0003 */}
2. 2) Move constructs the underlying *[`base_`](/docs/cpp/library/ranges/cartesian_product_view#Data_members)* by initializing it with `std::move(first_base), std::move(bases)...`.

### Parameters

{/* source:cpp-ranges-cartesian-product-view-cartesian-product-view:0004 */}
<ParameterList>
  <Parameter name="first_base">the first view object to adapt</Parameter>
  <Parameter name="bases">the pack of views objects to adapt</Parameter>
</ParameterList>

### Example

{/* source:cpp-ranges-cartesian-product-view-cartesian-product-view:0005 */}
```cpp
#include <array>
#include <format>
#include <iostream>
#include <ranges>
#include <vector>
 
int main()
{
    auto x = std::array{'A', 'B'};
    auto y = std::vector{1, 2, 3};
    auto z = std::vector{-1, -2, -3};
 
    auto v = std::ranges::cartesian_product_view(x, y, z); // overload (2)
 
    for (int i{1}; auto const& [rx, ry, rz] : v)
        std::cout << std::format("({} {} {}){}", rx, ry, rz, (i++ % 3) ? ' ' : '\n');
}
```

Output:

```text
(A 1 -1) (A 1 -2) (A 1 -3)
(A 2 -1) (A 2 -2) (A 2 -3)
(A 3 -1) (A 3 -2) (A 3 -3)
(B 1 -1) (B 1 -2) (B 1 -3)
(B 2 -1) (B 2 -2) (B 2 -3)
(B 3 -1) (B 3 -2) (B 3 -3)
```
