Construct an iterator.

{/* source:cpp-ranges-cartesian-product-view-iterator-iterator:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the *[`parent_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* with `nullptr` and [default-initializes](/docs/cpp/language/initialization/default_initialization) the *[`current_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)*.

{/* source:cpp-ranges-cartesian-product-view-iterator-iterator:0003 */}
2. 2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Initializes *[`parent_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* with `i`. *[`parent_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* and *[`current_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* with `std::move(i.current_)`.

{/* source:cpp-ranges-cartesian-product-view-iterator-iterator:0004 */}
3. 3) A private constructor which is used by `cartesian_product_view::begin` and `cartesian_product_view::end`. This constructor is not accessible to users. Initializes *[`parent_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* with `std::addressof(parent)` and *[`current_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* with `std::move(current)`.
