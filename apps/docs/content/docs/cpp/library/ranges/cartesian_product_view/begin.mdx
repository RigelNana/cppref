{/* source:cpp-ranges-cartesian-product-view-begin:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/cartesian_product_view/iterator) to the first element of the [`cartesian_product_view`](/docs/cpp/library/ranges/cartesian_product_view).

{/* source:cpp-ranges-cartesian-product-view-begin:0002 */}
Let *[`bases_`](/docs/cpp/library/ranges/cartesian_product_view#Data_members)* be the tuple of underlying views.

{/* source:cpp-ranges-cartesian-product-view-begin:0003 */}
1. 1) Equivalent to `return /*iterator*/<false>(`[`tuple-transform`](/docs/cpp/library/ranges#tuple-transform)`(ranges::begin, bases_));`.

{/* source:cpp-ranges-cartesian-product-view-begin:0004 */}
2. 2) Equivalent to `return /*iterator*/<true>(`[`tuple-transform`](/docs/cpp/library/ranges#tuple-transform)`(ranges::begin, bases_));`.

### Parameters

{/* source:cpp-ranges-cartesian-product-view-begin:0005 */}
(none)

### Return value

{/* source:cpp-ranges-cartesian-product-view-begin:0006 */}
An [`iterator`](/docs/cpp/library/ranges/cartesian_product_view/iterator) to the first element.

### Example

{/* source:cpp-ranges-cartesian-product-view-begin:0007 */}
```cpp
#include <array>
#include <format>
#include <iostream>
#include <ranges>
#include <string_view>
#include <tuple>
using namespace std::literals;
 
int main()
{
    constexpr auto a = std::array{"Curiously"sv, "Recurring"sv, "Template"sv, "Pattern"sv};
 
    constexpr auto v = std::ranges::cartesian_product_view(a[0], a[1], a[2], a[3]);
 
    constexpr std::tuple<char const&,
                         char const&,
                         char const&,
                         char const&> first{*v.begin()};
 
    std::cout << std::format("{}{}{}{}{}",
                             std::get<0>(first),
                             std::get<1>(first),
                             std::get<2>(first),
                             std::get<3>(first),
                             '\n');
}
```

Output:

```text
CRTP
```
