{/* source:cpp-ranges-cartesian-product-view-iterator-iter-swap:0001 */}
Applies `ranges::iter_swap` to the stored underlying iterators. Formally, for every integer `0 ≤ i ≤ sizeof...(Vs)`, performs `ranges::iter_swap(std::get<i>(x.current_), std::get<i>(y.current_))`, where *[`current_`](/docs/cpp/library/ranges/cartesian_product_view/iterator#Data_members)* is the underlying tuple of iterators.

{/* source:cpp-ranges-cartesian-product-view-iterator-iter-swap:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `cartesian_product_view::iterator<Const>` is an associated class of the arguments.

### Exceptions

{/* source:cpp-ranges-cartesian-product-view-iterator-iter-swap:0005 */}
The exception specification is equivalent to the logical AND of the expression `noexcept(ranges::iter_swap(std::get<i>(x.current_), std::get<i>(y.current_)))` for every integer `0 ≤ i ≤ sizeof...(Vs)`.
