{/* source:cpp-ranges-slide-view-iterator-operator-arith:0001 */}
Advances or decrements the [`iterator`](/docs/cpp/library/ranges/slide_view/iterator/iterator).

{/* source:cpp-ranges-slide-view-iterator-operator-arith:0002 */}
Let [`current_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) and [`last_ele_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) be the underlying iterators to the begin and end of the sliding window.

{/* source:cpp-ranges-slide-view-iterator-operator-arith:0003 */}
1) Equivalent to:

```cpp
current_ = ranges::next(current_);
last_ele_ = ranges::next(last_ele_); // if last_ele_ is present
return *this;
```

Before the invocation, the `current_` and `last_ele_` (if present) must be incrementable.

{/* source:cpp-ranges-slide-view-iterator-operator-arith:0004 */}
2) Equivalent to: `auto tmp = *this; ++*this; return tmp;`

{/* source:cpp-ranges-slide-view-iterator-operator-arith:0005 */}
3) Equivalent to:

```cpp
current_ = ranges::prev(current_);
last_ele_ = ranges::prev(last_ele_); // if last_ele_ is present
return *this;
```

Before the invocation, the `current_` and `last_ele_` (if present) must be decrementable.

{/* source:cpp-ranges-slide-view-iterator-operator-arith:0006 */}
4) Equivalent to: `auto tmp = *this; --*this; return tmp;`

{/* source:cpp-ranges-slide-view-iterator-operator-arith:0007 */}
5) Equivalent to:

```cpp
current_ = current_ + n;
last_ele_ = last_ele_ + n; // if last_ele_ is present
return *this;
```

Before the invocation, the expressions `current_ + n` and `last_ele_ + n` (if `last_ele_` is present) must have well-defined behavior.

{/* source:cpp-ranges-slide-view-iterator-operator-arith:0008 */}
6) Equivalent to:

```cpp
current_ = current_ - n;
last_ele_ = last_ele_ - n; // if last_ele_ is present
return *this;
```

Before the invocation, the expressions `current_ - n` and `last_ele_ - n` (if `last_ele_` is present) must have well-defined behavior.
