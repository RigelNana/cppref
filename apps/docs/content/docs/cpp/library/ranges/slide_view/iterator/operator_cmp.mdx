{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0001 */}
Compares the underlying iterators.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0002 */}
Let [`current_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) and [`last_ele_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) be the underlying iterators to the begin and end of the sliding window, respectively.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0003 */}
1) Equivalent to: `return x.last_ele_ == y.last_ele_;`, if `last_ele_` is present. Otherwise, `return x.current_ == y.current_;`.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0004 */}
2) Equivalent to `return x.current_ < y.current_;`.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0005 */}
3) Equivalent to `return y < x;`.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0006 */}
4) Equivalent to `return !(y < x);`.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0007 */}
5) Equivalent to `return !(x < y);`.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0008 */}
6) Equivalent to `return x.current_ <=> y.current_;`.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0009 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::slide_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-slide-view-iterator-operator-cmp:0010 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
