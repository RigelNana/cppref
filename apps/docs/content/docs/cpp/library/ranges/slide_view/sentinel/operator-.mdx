{/* source:cpp-ranges-slide-view-sentinel-operator:0001 */}
Computes the distance between the underlying [`iterator`](/docs/cpp/library/ranges/slide_view/iterator) of `x` and the underlying [`sentinel`](/docs/cpp/library/ranges/slide_view/sentinel) of `y`.

{/* source:cpp-ranges-slide-view-sentinel-operator:0002 */}
Let [`last_ele_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) denote the underlying iterator of `x` and [`end_`](/docs/cpp/library/ranges/slide_view/sentinel#Data_members) denote the underlying sentinel of `y`.

{/* source:cpp-ranges-slide-view-sentinel-operator:0003 */}
1) Equivalent to: `return x.last_ele_ - y.end_;`.

{/* source:cpp-ranges-slide-view-sentinel-operator:0004 */}
2) Equivalent to: `return y.end_ - x.last_ele_;`.

{/* source:cpp-ranges-slide-view-sentinel-operator:0005 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `slide_view::sentinel` is an associated class of the arguments.

</ParameterList>

### Return value

{/* source:cpp-ranges-slide-view-sentinel-operator:0007 */}
The distance between the iterator and the sentinel.
