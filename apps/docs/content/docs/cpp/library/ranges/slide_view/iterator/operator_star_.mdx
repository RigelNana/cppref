Returns the current element in the `slide_view`.

{/* source:cpp-ranges-slide-view-iterator-operator-star:0002 */}
Let [`current_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) and [`n_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) be the underlying data members. Equivalent to: `return views::counted(current_, n_)`.

### Parameters

{/* source:cpp-ranges-slide-view-iterator-operator-star:0003 */}
(none)

### Return value

{/* source:cpp-ranges-slide-view-iterator-operator-star:0004 */}
The current element, which is an object of [`value_type`](/docs/cpp/library/ranges/slide_view/iterator#Member_types).
