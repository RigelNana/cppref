{/* source:cpp-ranges-slide-view-sentinel:0001 */}
The return type of [`slide_view::end`](/docs/cpp/library/ranges/slide_view/end) when the underlying view is not a [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-slide-view-sentinel:0002 */}
The `/*sentinel*/` is used only when `/*slide-caches-first*/<V>` is `true`.
