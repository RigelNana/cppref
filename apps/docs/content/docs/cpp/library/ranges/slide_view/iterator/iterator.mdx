{/* source:cpp-ranges-slide-view-iterator-iterator:0001 */}
Construct an iterator.

{/* source:cpp-ranges-slide-view-iterator-iterator:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying data members: [`current_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `ranges::iterator_t<Base>()`, [`last_ele_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `ranges::iterator_t<Base>()` (note that this member may not be present), [`n_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `0`.

{/* source:cpp-ranges-slide-view-iterator-iterator:0003 */}
2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Initializes the underlying data members:

- [`current_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `std::`[`move`](/docs/cpp/library/utility/move)`(i.current_)`,
- [`n_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `i.n_`.

Note that `/*iterator*/<true>` can only be formed when [`Base`](/docs/cpp/library/ranges/slide_view/iterator#Member_types) models `/*slide-caches-nothing*/`, in which case [`last_ele_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) is not present.

{/* source:cpp-ranges-slide-view-iterator-iterator:0004 */}
3) A private constructor which is used by `ranges::slide_view::begin` and `ranges::slide_view::end`. This constructor is not accessible to users. Initializes the underlying data members: [`current_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `current`, [`n_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `n`. Note that this overload can only be present if [`last_ele_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) is not present.

{/* source:cpp-ranges-slide-view-iterator-iterator:0005 */}
4) A private constructor which is used by `ranges::slide_view::begin` and `ranges::slide_view::end`. This constructor is not accessible to users. Initializes the underlying data members: [`current_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `current`, [`last_ele_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `last_ele` (note that this data member is present due to `/*slide-caches-first*/<Base>` requirement), [`n_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) with `n`.
