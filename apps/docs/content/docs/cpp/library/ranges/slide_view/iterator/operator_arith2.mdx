{/* source:cpp-ranges-slide-view-iterator-operator-arith2:0001 */}
Performs iterator arithmetic.

{/* source:cpp-ranges-slide-view-iterator-operator-arith2:0002 */}
1,2) Equivalent to: `auto r = i; r += n; return r;`.

{/* source:cpp-ranges-slide-view-iterator-operator-arith2:0003 */}
3) Equivalent to: `auto r = i; r -= n; return r;`.

{/* source:cpp-ranges-slide-view-iterator-operator-arith2:0004 */}
4) Let [`current_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) and [`last_ele_`](/docs/cpp/library/ranges/slide_view/iterator#Data_members) be the underlying iterators to the begin and end of the sliding window, respectively. Equivalent to: `return x.last_ele_ - y.last_ele_;`, if `last_ele_` is present. Otherwise, `return x.current_ - y.current_;`.

{/* source:cpp-ranges-slide-view-iterator-operator-arith2:0005 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `slide_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-slide-view-iterator-operator-arith2:0007 */}

{/* source:cpp-ranges-slide-view-iterator-operator-arith2:0008 */}
3) A decremented iterator.

{/* source:cpp-ranges-slide-view-iterator-operator-arith2:0009 */}
4) A distance between given iterators.
