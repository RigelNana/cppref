Constructs a `slide_view` initializing the underlying data members:

{/* source:cpp-ranges-slide-view-slide-view:0002 */}
- move construct the underlying view [`base_`](/docs/cpp/library/ranges/slide_view#Data_members) with `std::move(base)`,
- the "window size" [`n_`](/docs/cpp/library/ranges/slide_view#Data_members) with `n`.

### Parameters

{/* source:cpp-ranges-slide-view-slide-view:0003 */}
<ParameterList>
  <Parameter name="base">the source view</Parameter>
  <Parameter name="n">the "sliding window" size</Parameter>
</ParameterList>

### Example

{/* source:cpp-ranges-slide-view-slide-view:0004 */}
```cpp
#include <algorithm>
#include <iostream>
#include <ranges>

int main()
{
    const auto source = {1, 2, 3, 4};

    auto slide = std::views::slide(source, 3);

    std::ranges::for_each(slide, [](std::ranges::viewable_range auto&& w)
    {
        std::cout << '[' << w[0] << ' ' << w[1] << ' ' << w[2] << "]\n";
    });
}
```

Output:

```text
[1 2 3]
[2 3 4]
```
