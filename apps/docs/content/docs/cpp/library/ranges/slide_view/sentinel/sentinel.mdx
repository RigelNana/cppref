{/* source:cpp-ranges-slide-view-sentinel-sentinel:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying sentinel [`end_`](/docs/cpp/library/ranges/slide_view/sentinel#Data_members) with `ranges::sentinel_t<V>()`.

{/* source:cpp-ranges-slide-view-sentinel-sentinel:0003 */}
2) A private constructor which is used by `slide_view::end`. This constructor is not accessible to users. Initializes [`end_`](/docs/cpp/library/ranges/slide_view/sentinel#Data_members) with `end`.
