{/* source:cpp-ranges-split-view-find-next:0001 */}
Searches for the next occurrence of pattern in the underlying view. Equivalent to:

{/* source:cpp-ranges-split-view-find-next:0002 */}
`auto [b, e] = ranges::search(ranges::subrange(it, ranges::end(`[`base_`](/docs/cpp/library/ranges/split_view#base)`)),` [`pattern_`](/docs/cpp/library/ranges/split_view#pattern)`);`
`if (b != ranges::end(`[`base_`](/docs/cpp/library/ranges/split_view#base)`) and ranges::empty(`[`pattern_`](/docs/cpp/library/ranges/split_view#pattern)`))`
`{`
`    ++b;`
`    ++e;`
`}`

`return {b, e};`

### Parameters

{/* source:cpp-ranges-split-view-find-next:0003 */}
<ParameterList>
  <Parameter name="it">an iterator to the position at which to start the search</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-split-view-find-next:0004 */}
A subrange that represents the next position of the pattern, if it was found. An empty subrange otherwise.
