{/* source:cpp-ranges-split-view-base:0001 */}
Returns a copy of the underlying view [`base_`](/docs/cpp/library/ranges/split_view#base).

{/* source:cpp-ranges-split-view-base:0002 */}
1. 1) Copy constructs the result from the underlying view.

{/* source:cpp-ranges-split-view-base:0003 */}
2. 2) Move constructs the result from the underlying view.

### Return value

{/* source:cpp-ranges-split-view-base:0004 */}
1. 1) A copy of the underlying view.

{/* source:cpp-ranges-split-view-base:0005 */}
2. 2) A view move-constructed from the underlying view.

### Example

{/* source:cpp-ranges-split-view-base:0006 */}
```cpp
#include <iomanip>
#include <iostream>
#include <ranges>
#include <string_view>
 
int main()
{
    constexpr std::string_view keywords{"this throw true try typedef typeid"};
    std::ranges::split_view split_view{keywords, ' '};
    std::cout << "base() = " << std::quoted(split_view.base()) << "\n"
                 "substrings: ";
    for (auto split : split_view)
        std::cout << std::quoted(std::string_view{split}) << ' ';
    std::cout << '\n';
}
```

Output:

```text
base() = "this throw true try typedef typeid"
substrings: "this" "throw" "true" "try" "typedef" "typeid"
```
