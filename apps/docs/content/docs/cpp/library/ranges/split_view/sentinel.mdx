#### `operator==(std::ranges::split_view::iterator, std::ranges::split_view::sentinel)`

{/* source:cpp-ranges-split-view-sentinel:0006 */}
<DeclarationDoc>
  <Declaration language="cpp" since="C++20" code={`friend constexpr bool operator==( const /*iterator*/& x,
                                 const /*sentinel*/& y );`} />

Equivalent to `return x.cur_ == y.end_ and !x.trailing_empty_;`.

The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::split_view::sentinel` is an associated class of the arguments.
