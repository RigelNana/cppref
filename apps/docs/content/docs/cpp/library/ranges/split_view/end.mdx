{/* source:cpp-ranges-split-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/split_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/split_view/sentinel) representing the end of the resulting subrange. Equivalent to:

{/* source:cpp-ranges-split-view-end:0002 */}
`constexpr auto end()`
`{`
`    if constexpr (ranges::common_range<V>)`
`        return` [`iterator`](/docs/cpp/library/ranges/split_view/iterator)`{*this, ranges::end([`base_`](/docs/cpp/library/ranges/split_view#base)), {}};`
`    else`
`        return` [`sentinel`](/docs/cpp/library/ranges/split_view/sentinel)`{*this};`
`}`

### Return value

{/* source:cpp-ranges-split-view-end:0003 */}
An [`iterator`](/docs/cpp/library/ranges/split_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/split_view/sentinel).

### Example

{/* source:cpp-ranges-split-view-end:0004 */}
```cpp
#include <cassert>
#include <ranges>
#include <string_view>
 
int main()
{
    constexpr std::string_view keywords{"bitand bitor bool break"};
    std::ranges::split_view kw{keywords, ' '};
    assert(4 == std::ranges::distance(kw.begin(), kw.end()));
}
```
