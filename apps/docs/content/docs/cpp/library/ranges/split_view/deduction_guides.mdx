These [deduction guides](/docs/cpp/language/templates/ctad) are provided for `split_view` to allow deduction from a range and a delimiter.

{/* source:cpp-ranges-split-view-deduction-guides:0002 */}
1. 1) The delimiter is a range of elements.

{/* source:cpp-ranges-split-view-deduction-guides:0003 */}
2. 2) The delimiter is a single element.

### Example

{/* source:cpp-ranges-split-view-deduction-guides:0004 */}
```cpp
#include <ranges>
#include <string_view>
#include <type_traits>
using std::operator""sv;
 
int main() {
    std::ranges::split_view w1{"a::b::c"sv, "::"sv};
    static_assert(std::is_same_v<
        decltype(w1),
        std::ranges::split_view<std::string_view, std::string_view>>);
 
    std::ranges::split_view w2{"x,y,z"sv, ','};
    static_assert(std::is_same_v<
        decltype(w2),
        std::ranges::split_view<std::string_view, std::ranges::single_view<char>>>);
}
```
