{/* source:cpp-ranges-split-view:0001 */}
1. 1) `split_view` takes a [`view`](/docs/cpp/library/ranges/view) and a delimiter, and splits the [`view`](/docs/cpp/library/ranges/view) into subranges on the delimiter.

{/* source:cpp-ranges-split-view:0002 */}
2. 2) *[RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject)*. The expression `views::split(e, p)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `split_view(e, p)` for any suitable subexpressions `e` and `p`.

{/* source:cpp-ranges-split-view:0003 */}
`split_view` models the concepts [`forward_range`](/docs/cpp/library/ranges/forward_range), and [`common_range`](/docs/cpp/library/ranges/common_range) when the underlying [`view`](/docs/cpp/library/ranges/view) `V` models respective concepts.

{/* source:cpp-ranges-split-view:0004 */}
The inner range (`ranges::range_reference_t<split_view>`) is a `ranges::subrange<ranges::iterator_t<V>>`, which models [`common_range`](/docs/cpp/library/ranges/common_range), models [`sized_range`](/docs/cpp/library/ranges/sized_range) when `ranges::iterator_t<V>` models `std::sized_sentinel_for<ranges::iterator_t<V>>`, and models [`contiguous_range`](/docs/cpp/library/ranges/contiguous_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), and [`forward_range`](/docs/cpp/library/ranges/forward_range) when `V` models respective concepts.

{/* source:cpp-ranges-split-view:0005 */}
Unlike [`lazy_split_view`](/docs/cpp/library/ranges/lazy_split_view), `split_view` maintains the continuity of the subrange, making it suitable for string splitting.

### Notes

{/* source:cpp-ranges-split-view:0009 */}
Before [P2210R2](https://wg21.link/P2210R2), `split_view` used a *lazy* mechanism for splitting, and thus could not keep the bidirectional, random access, or contiguous properties of the underlying view, or make the iterator type of the inner range same as that of the underlying view. Consequently, it is redesigned by [P2210R2](https://wg21.link/P2210R2), and the lazy mechanism is moved to [`lazy_split_view`](/docs/cpp/library/ranges/lazy_split_view).

{/* source:cpp-ranges-split-view:0010 */}
The delimiter pattern generally should not be an ordinary string literal, as it will consider the null terminator to be necessary part of the delimiter; therefore, it is advisable to use a [`std::string_view`](/docs/cpp/library/string/basic_string_view) literal instead.

### Example

{/* source:cpp-ranges-split-view:0011 */}
```cpp
#include <iomanip>
#include <iostream>
#include <ranges>
#include <string_view>
 
int main()
{
    using std::operator""sv;
    constexpr auto words{"Hello^_^C++^_^20^_^!"sv};
    constexpr auto delim{"^_^"sv};
 
    for (const auto word : std::views::split(words, delim))
        // with string_view's C++23 range constructor:
        std::cout << std::quoted(std::string_view(word)) << ' ';
    std::cout << '\n';
}
```

Output:

```text
"Hello" "C++" "20" "!"
```
