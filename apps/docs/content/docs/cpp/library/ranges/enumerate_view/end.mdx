{/* source:cpp-ranges-enumerate-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/enumerate_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/enumerate_view/sentinel) that compares equal to the end iterator of the `enumerate_view`.

{/* source:cpp-ranges-enumerate-view-end:0002 */}
Let [`base_`](/docs/cpp/library/ranges/enumerate_view#Data_members) denote the underlying view.

{/* source:cpp-ranges-enumerate-view-end:0003 */}
1) Equivalent to:

```cpp
if constexpr (ranges::forward_range<V> and 
              ranges::common_range<V>  and 
              ranges::sized_range<V>)
    return /*iterator*/<false>(ranges::end(base_), ranges::distance(base_));
else
    return /*sentinel*/<false>(ranges::end(base_));
```

{/* source:cpp-ranges-enumerate-view-end:0004 */}
2) Equivalent to:

```cpp
if constexpr (ranges::forward_range<const V> and 
              ranges::common_range<const V>  and 
              ranges::sized_range<const V>)
    return /*iterator*/<true>(ranges::end(base_), ranges::distance(base_));
else
    return /*sentinel*/<true>(ranges::end(base_));
```

### Parameters

{/* source:cpp-ranges-enumerate-view-end:0005 */}
(none)

### Return value

{/* source:cpp-ranges-enumerate-view-end:0006 */}
An [`iterator`](/docs/cpp/library/ranges/enumerate_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/enumerate_view/sentinel) representing the end of the `enumerate_view`, as described above.
