{/* source:cpp-ranges-enumerate-view-sentinel-operator:0001 */}
Computes the distance between the underlying [`iterator`](/docs/cpp/library/ranges/enumerate_view/iterator) of `x` and the underlying [`sentinel`](/docs/cpp/library/ranges/enumerate_view/sentinel) of `y`.

{/* source:cpp-ranges-enumerate-view-sentinel-operator:0002 */}
These function templates are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `enumerate_view::sentinel` is an associated class of the arguments.

### Parameters

{/* source:cpp-ranges-enumerate-view-sentinel-operator:0003 */}
<ParameterList>
  <Parameter name="x">an [`iterator`](/docs/cpp/library/ranges/enumerate_view/iterator)</Parameter>
  <Parameter name="y">a [`sentinel`](/docs/cpp/library/ranges/enumerate_view/sentinel)</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-enumerate-view-sentinel-operator:0004 */}
1) `x.base() - y.base()`

{/* source:cpp-ranges-enumerate-view-sentinel-operator:0005 */}
2) `y.base() - x.base()`
