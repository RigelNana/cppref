{/* source:cpp-ranges-enumerate-view-iterator-iterator:0001 */}
Construct an iterator.

{/* source:cpp-ranges-enumerate-view-iterator-iterator:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying iterator [`current_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) with `ranges::iterator_t<Base>()` and the underlying index [`pos_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) with `0`.

{/* source:cpp-ranges-enumerate-view-iterator-iterator:0003 */}
2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Initializes [`current_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) with `std::`[`move`](/docs/cpp/library/utility/move)`(i.current_)` and [`pos_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) with `i.pos_`.

{/* source:cpp-ranges-enumerate-view-iterator-iterator:0004 */}
3) A private constructor which is used by [`enumerate_view::begin`](/docs/cpp/library/ranges/enumerate_view/begin) and [`enumerate_view::end`](/docs/cpp/library/ranges/enumerate_view/end). This constructor is not accessible to users. Initializes [`current_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) with `std::move(current)` and [`pos_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) with `pos`.
