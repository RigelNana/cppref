{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0001 */}
Increments or decrements the [`iterator`](/docs/cpp/library/ranges/enumerate_view/iterator/iterator).

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0002 */}
Let [`current_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) be the underlying iterator and [`pos_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) be the underlying index.

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0003 */}
1) Equivalent to `++current_; ++pos_; return *this;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0004 */}
2) Equivalent to `++current_;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0005 */}
3) Equivalent to `auto tmp = *this; ++*this; return tmp;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0006 */}
4) Equivalent to `--current_; --pos_; return *this;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0007 */}
5) Equivalent to `auto tmp = *this; --*this; return tmp;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0008 */}
6) Equivalent to `current_ += n; pos_ += n; return *this;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0009 */}
7) Equivalent to `current_ -= n; pos_ -= n; return *this;`

### Parameters

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0010 */}

  <Parameter name="n">position relative to current location</Parameter>

### Return value

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0011 */}
1,4,6,7) `*this`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0012 */}
2) (none)

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith:0013 */}
3,5) a copy of `*this` that was made before the change
