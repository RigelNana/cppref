{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0001 */}
Performs iterator arithmetic or calculates the distance.

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0002 */}
[`pos_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) is the underlying index, and [`Base`](/docs/cpp/library/ranges/enumerate_view/iterator#Member_types) is the (possibly const-qualified) type of underlying view.

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0003 */}
Equivalent to:

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0004 */}
1) `auto temp = i; temp += n; return temp;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0005 */}
2) `return i + n;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0006 */}
3) `auto temp = i; temp -= n; return temp;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0007 */}
4) `return i.pos_ - j.pos_;`

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0008 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `enumerate_view::iterator<Const>` is an associated class of the arguments.

<ParameterList>

### Return value

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0010 */}
1,2) An incremented iterator.

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0011 */}
3) A decremented iterator.

{/* source:cpp-ranges-enumerate-view-iterator-operator-arith2:0012 */}
4) A distance between given iterators.
