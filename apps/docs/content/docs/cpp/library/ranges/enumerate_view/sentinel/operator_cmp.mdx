{/* source:cpp-ranges-enumerate-view-sentinel-operator-cmp:0001 */}
Compares the underlying iterator of `x` with the underlying sentinel of `y`.

{/* source:cpp-ranges-enumerate-view-sentinel-operator-cmp:0002 */}
Let [`current_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) denote the underlying iterator of `x` and [`end_`](/docs/cpp/library/ranges/enumerate_view/sentinel#Data_members) denote the underlying sentinel of `y`. Equivalent to:

{/* source:cpp-ranges-enumerate-view-sentinel-operator-cmp:0003 */}
`return x.current_ == y.end_;`.

{/* source:cpp-ranges-enumerate-view-sentinel-operator-cmp:0004 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `enumerate_view::sentinel<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-enumerate-view-sentinel-operator-cmp:0005 */}
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
