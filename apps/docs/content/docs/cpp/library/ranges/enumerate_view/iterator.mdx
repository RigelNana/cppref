{/* source:cpp-ranges-enumerate-view-iterator:0001 */}
The return type of [`enumerate_view::begin`](/docs/cpp/library/ranges/enumerate_view/begin), and of [`enumerate_view::end`](/docs/cpp/library/ranges/enumerate_view/end) when the underlying view `V` is a [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-enumerate-view-iterator:0002 */}
The type `/*iterator*/<true>` is returned by the const-qualified overloads. The type `/*iterator*/<false>` is returned by the non-const-qualified overloads.
