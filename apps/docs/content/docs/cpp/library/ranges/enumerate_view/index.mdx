{/* source:cpp-ranges-enumerate-view:0001 */}
1) `enumerate_view` is a range adaptor that takes a [`view`](/docs/cpp/library/ranges/view) and produces a view of [`tuple`](/docs/cpp/library/utility/tuple)s. `i`<sup>th</sup> element (the tuple) of the resulting sequence holds:

- the value equal to `i`, which is a zero-based index of the element of underlying sequence, and
- the reference to the underlying element.

{/* source:cpp-ranges-enumerate-view:0002 */}
2) The name `views::enumerate` denotes a [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). Given a subexpression `e`, the expression `views::enumerate(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `enumerate_view<views::all_t<decltype((e))>>(e)` for any suitable subexpression `e`.

{/* source:cpp-ranges-enumerate-view:0003 */}
3) Ensures that the reference type of the underlying type can be moved.

{/* source:cpp-ranges-enumerate-view:0004 */}
`enumerate_view` models the concepts [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`input_range`](/docs/cpp/library/ranges/input_range), [`common_range`](/docs/cpp/library/ranges/common_range), and [`sized_range`](/docs/cpp/library/ranges/sized_range) when the underlying view `V` models respective concepts.

### Example

{/* source:cpp-ranges-enumerate-view:0011 */}
```cpp
#include <iostream>
#include <map>
#include <ranges>
#include <vector>
 
int main()
{
    constexpr static auto v = {'A', 'B', 'C', 'D'};
 
    for (auto const [index, letter] : std::views::enumerate(v))
        std::cout << '(' << index << ':' << letter << ") ";
    std::cout << '\n';
 
#if __cpp_lib_ranges_to_container
    // create a map using the position of each element as key
    auto m = v | std::views::enumerate | std::ranges::to<std::map>();
 
    for (auto const [key, value] : m)
        std::cout << '[' << key << "]:" << value << ' ';
    std::cout << '\n';
#endif
 
    std::vector<int> numbers{1, 3, 5, 7};
 
    // num is mutable even with const, which does not propagate to reference to
    // make it const, use `std::views::enumerate(numbers) | std::views::as_const`
    // or `std::views::enumerate(std::as_const(numbers))`
    for (auto const [index, num] : std::views::enumerate(numbers))
    {
        ++num; // the type is int&
        std::cout << numbers[index] << ' ';
    }
    std::cout << '\n';
}
```

Possible output:

```text
(0:A) (1:B) (2:C) (3:D)
[0]:A [1]:B [2]:C [3]:D
2 4 6 8
```
