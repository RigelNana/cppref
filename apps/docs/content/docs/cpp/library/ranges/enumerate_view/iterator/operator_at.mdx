Returns an element at specified relative location. Equivalent to: `return` [`reference-type`](/docs/cpp/library/ranges/enumerate_view/iterator#Member_types)`(`[`pos_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members)` + n, `[`current_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members)`[n]);`.

### Parameters

{/* source:cpp-ranges-enumerate-view-iterator-operator-at:0002 */}
<ParameterList>
  <Parameter name="n">position relative to current location</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-enumerate-view-iterator-operator-at:0003 */}
The element at displacement `n` relative to the current location.
