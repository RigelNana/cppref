{/* source:cpp-ranges-enumerate-view-iterator-iter-move:0001 */}
Let [`current_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) be the underlying iterator, [`pos_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) be the underlying index, and [`Base`](/docs/cpp/library/ranges/enumerate_view/iterator#Member_types) be the (possibly cv-qualified) type of the underlying sequence.

{/* source:cpp-ranges-enumerate-view-iterator-iter-move:0002 */}
Equivalent to:

{/* source:cpp-ranges-enumerate-view-iterator-iter-move:0003 */}
```cpp
template<class D, class B>
using tuple = std::tuple<D, ranges::range_rvalue_reference_t<B>>;
 
return tuple<difference_type, Base>(i.pos_, ranges::iter_move(i.current_));
```

{/* source:cpp-ranges-enumerate-view-iterator-iter-move:0004 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `enumerate_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-enumerate-view-iterator-iter-move:0006 */}
A tuple that contains an index and the result of applying `ranges::iter_move` to the stored iterator.
