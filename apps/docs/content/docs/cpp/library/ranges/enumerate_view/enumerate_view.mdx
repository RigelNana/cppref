Constructs a `enumerate_view`.

{/* source:cpp-ranges-enumerate-view-enumerate-view:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying view [`base_`](/docs/cpp/library/ranges/enumerate_view#Data_members). After construction, [`base()`](/docs/cpp/library/ranges/enumerate_view/base) returns a copy of `V()`.

{/* source:cpp-ranges-enumerate-view-enumerate-view:0003 */}
2) Initializes the underlying view [`base_`](/docs/cpp/library/ranges/enumerate_view#Data_members) with `std::move(base)`.
