{/* source:cpp-ranges-enumerate-view-sentinel-sentinel:0001 */}
Constructs a [`sentinel`](/docs/cpp/library/ranges/enumerate_view/sentinel).

{/* source:cpp-ranges-enumerate-view-sentinel-sentinel:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying sentinel with `ranges::sentinel_t<Base>()`.

{/* source:cpp-ranges-enumerate-view-sentinel-sentinel:0003 */}
2) Conversion from `/*sentinel*/<false>` to `/*sentinel*/<true>`. Move constructs the underlying sentinel [`end_`](/docs/cpp/library/ranges/enumerate_view/sentinel#Data_members) with `std::move(other.end_)`.

{/* source:cpp-ranges-enumerate-view-sentinel-sentinel:0004 */}
3) A private constructor which is used by `enumerate_view::end`. Move constructs the `end_` with `std::move(end)`. This constructor is not accessible to users.
