{/* source:cpp-ranges-enumerate-view-iterator-operator-cmp:0001 */}
Compares the underlying [`iterators`](/docs/cpp/library/ranges/enumerate_view/iterator). Let [`pos_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) be the underlying index.

{/* source:cpp-ranges-enumerate-view-iterator-operator-cmp:0002 */}
1) Equivalent to `return x.pos_ == y.pos_;`.

{/* source:cpp-ranges-enumerate-view-iterator-operator-cmp:0003 */}
2) Equivalent to `return x.pos_ <=> y.pos_;`.

{/* source:cpp-ranges-enumerate-view-iterator-operator-cmp:0004 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::enumerate_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-enumerate-view-iterator-operator-cmp:0005 */}
The `\<`, `\<=`, `\>`, `\>=`, and `!=` operators are [`synthesized`](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
