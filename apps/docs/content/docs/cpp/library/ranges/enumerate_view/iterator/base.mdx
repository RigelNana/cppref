Returns the underlying iterator. Let [`current_`](/docs/cpp/library/ranges/enumerate_view/iterator#Data_members) be the underlying iterator.

{/* source:cpp-ranges-enumerate-view-iterator-base:0002 */}
1) Equivalent to: `return current_;`.

{/* source:cpp-ranges-enumerate-view-iterator-base:0003 */}
2) Equivalent to: `return std::move(current_);`.

(none)

### Return value

{/* source:cpp-ranges-enumerate-view-iterator-base:0005 */}
