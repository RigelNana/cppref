Constructs a `common_view`.

{/* source:cpp-ranges-common-view-common-view:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying view. After construction, [`base()`](/docs/cpp/library/ranges/common_view/base) returns a copy of `V()`.

{/* source:cpp-ranges-common-view-common-view:0003 */}
2) Initializes the underlying view with `std::move(r)`.
