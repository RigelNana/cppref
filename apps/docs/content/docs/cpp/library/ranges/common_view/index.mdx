{/* source:cpp-ranges-common-view:0001 */}
1) Adapts a given [`view`](/docs/cpp/library/ranges/view) with different types for iterator/sentinel pair into a [`view`](/docs/cpp/library/ranges/view) that is also a [`common_range`](/docs/cpp/library/ranges/common_range). A `common_view` always has the same iterator/sentinel type.

{/* source:cpp-ranges-common-view:0002 */}
2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). Let `e` be a subexpression. Then the expression `views::common(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

- `views::all(e)`, if it is a well-formed expression and `decltype((e))` models [`common_range`](/docs/cpp/library/ranges/common_range);
- `common_view{e}` otherwise.

This specialization of `std::ranges::enable_borrowed_range` makes `common_view` satisfy [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range) when the underlying view satisfies it.

### Notes

{/* source:cpp-ranges-common-view:0007 */}
`common_view` can be useful for working with legacy algorithms that expect the iterator and sentinel are of the same type.

### Example

{/* source:cpp-ranges-common-view:0008 */}
```cpp
#include <iostream>
#include <iterator>
#include <list>
#include <numeric>
#include <ranges>
 
int main()
{
    auto v1 = {1, 2, 3, 4, 5};
    auto i1 = std::counted_iterator{v1.begin(), std::ssize(v1)};
    auto r1 = std::ranges::subrange{i1, std::default_sentinel};
//  auto e1 = std::accumulate(r1.begin(), r1.end(), 0); // error: "common range" required
    auto c1 = std::ranges::common_view{r1};
    std::cout << "accumulate: " << std::accumulate(c1.begin(), c1.end(), 0) << '\n';
 
    // inherited from ranges::view_interface:
    std::cout << "c1.front(): " << c1.front() << '\n';
    std::cout << "c1.back(): " << c1.back() << '\n';
    std::cout << "c1.data(): " << c1.data() << '\n';
    std::cout << "c1[0]: " << c1[0] << '\n';
 
    auto v2 = std::list{1, 2, 3, 4, 5};
    auto i2 = std::counted_iterator{v2.begin(), std::ssize(v2)};
    auto r2 = std::ranges::subrange{i2, std::default_sentinel};
//  auto e2 = std::accumulate(r2.begin(), r2.end(), 0); // error: "common range" required
    auto c2 = std::ranges::common_view{ r2 };
    std::cout << "accumulate: " << std::accumulate(c2.begin(), c2.end(), 0) << '\n';
 
    // inherited from ranges::view_interface:
    std::cout << "c2.front(): " << c2.front() << '\n';
//  auto e3 = c2.back(); // error: "bidirectional range" required
//  auto e4 = c2.data(); // error: "contiguous range" required
//  auto e5 = c2[0];     // error: "random access range" required
}
```

Possible output:

```text
accumulate: 15
c1.front(): 1
c1.back(): 5
c1.data(): 0x7f19937f00d0
c1[0]: 1
accumulate: 15
c2.front(): 1
```
