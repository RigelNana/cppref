{/* source:cpp-ranges-common-view-base:0001 */}
Returns a copy of the underlying view.

{/* source:cpp-ranges-common-view-base:0002 */}
1) Copy constructs the result from the underlying view.

{/* source:cpp-ranges-common-view-base:0003 */}
2) Move constructs the result from the underlying view.

### Parameters

{/* source:cpp-ranges-common-view-base:0004 */}
(none)

### Return value

{/* source:cpp-ranges-common-view-base:0005 */}
A copy of the underlying view.

### Example

{/* source:cpp-ranges-common-view-base:0006 */}
```cpp
#include <iostream>
#include <ranges>
#include <string>
 
int main()
{
    std::string str { "C++20" };
    auto view = std::views::common(str);
 
    std::string copy_of_str = view.base();
    std::cout << "copy of str: [" << copy_of_str << "]\n";
    std::cout << "view.base(): [" << view.base() << "]\n";
 
    std::string move_str = std::move(view.base());
    std::cout << "moved str:   [" << move_str << "]\n";
    std::cout << "view.base(): [" << view.base() << "]\n"; // unspecified
}
```

Possible output:

```text
copy of str: [C++20]
view.base(): [C++20]
moved str:   [C++20]
view.base(): []
```
