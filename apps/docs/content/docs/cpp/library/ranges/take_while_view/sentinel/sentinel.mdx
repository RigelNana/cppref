Constructs a sentinel.

{/* source:cpp-ranges-take-while-view-sentinel-sentinel:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying sentinel and the pointer to predicate.

{/* source:cpp-ranges-take-while-view-sentinel-sentinel:0003 */}
2. 2) Initializes the underlying sentinel with `end` and the pointer to predicate with `pred`.

{/* source:cpp-ranges-take-while-view-sentinel-sentinel:0004 */}
3. 3) Conversion from `/*sentinel*/<false>` to `/*sentinel*/<true>`. Copy constructs corresponding members.
