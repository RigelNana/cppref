{/* source:cpp-ranges-take-while-view-pred:0001 */}
Returns a reference to the stored predicate [`pred_`](/docs/cpp/library/ranges/take_while_view#Data_members).

{/* source:cpp-ranges-take-while-view-pred:0002 */}
If `*this` does not store a predicate (e.g. an exception is thrown on the assignment to `*this`, which copy-constructs or move-constructs a `Pred`), the behavior is undefined.

### Parameters

{/* source:cpp-ranges-take-while-view-pred:0003 */}
(none)

### Return value

{/* source:cpp-ranges-take-while-view-pred:0004 */}
A reference to the stored predicate.

### Example

{/* source:cpp-ranges-take-while-view-pred:0005 */}
```cpp
#include <ranges>
 
int main()
{
    static constexpr int a[]{1, 2, 3, 4, 5};
    constexpr auto v = a | std::views::take_while([](int x){ return x < 4; });
    const auto pred = v.pred();
    static_assert(pred(3));
}
```
