{/* source:cpp-ranges-take-while-view-end:0001 */}
Returns a [`sentinel`](/docs/cpp/library/ranges/take_while_view/sentinel) representing the end of the view.

{/* source:cpp-ranges-take-while-view-end:0002 */}
Let [`base_`](/docs/cpp/library/ranges/take_while_view#Data_members) denote the underlying view.

{/* source:cpp-ranges-take-while-view-end:0003 */}
1. 1) Effectively returns `/*sentinel*/<false>(ranges::end(base_), std::addressof(pred()))`.

{/* source:cpp-ranges-take-while-view-end:0004 */}
2. 2) Effectively returns `/*sentinel*/<true>(ranges::end(base_), std::addressof(pred()))`.

{/* source:cpp-ranges-take-while-view-end:0005 */}
Overload (1) does not participate in overload resolution if `V` is a [simple view](/docs/cpp/library/ranges#Helper_concepts) (that is, if `V` and `const V` are views with the same iterator and sentinel types).

### Parameters

{/* source:cpp-ranges-take-while-view-end:0006 */}
(none)

### Return value

{/* source:cpp-ranges-take-while-view-end:0007 */}
A [`sentinel`](/docs/cpp/library/ranges/take_while_view/sentinel) representing the end of the view.
