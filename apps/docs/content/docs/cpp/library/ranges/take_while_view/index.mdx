{/* source:cpp-ranges-take-while-view:0001 */}
1. 1) A range adaptor that represents [`view`](/docs/cpp/library/ranges/view) of the elements from an underlying sequence, starting at the beginning and ending at the first element for which the predicate returns `false`.

{/* source:cpp-ranges-take-while-view:0002 */}
2. 2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::take_while(e, f)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `take_while_view(e, f)` for any suitable subexpressions `e` and `f`.

{/* source:cpp-ranges-take-while-view:0003 */}
`take_while_view` models the concepts [`contiguous_range`](/docs/cpp/library/ranges/contiguous_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), and [`input_range`](/docs/cpp/library/ranges/input_range) when the underlying view `V` models respective concepts.

### Example

{/* source:cpp-ranges-take-while-view:0007 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    for (int year : std::views::iota(2020)
                  | std::views::take_while([](int y){ return y < 2026; }))
        std::cout << year << ' ';
    std::cout << '\n';
 
    const char note[]{"Today is yesterday's tomorrow!..."};
    auto not_dot = [](char c){ return c != '.'; };
    for (char x : std::ranges::take_while_view(note, not_dot))
        std::cout << x;
    std::cout << '\n';
}
```

Output:

```text
2020 2021 2022 2023 2024 2025
Today is yesterday's tomorrow!
```
