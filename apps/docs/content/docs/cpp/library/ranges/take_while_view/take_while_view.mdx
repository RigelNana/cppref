{/* source:cpp-ranges-take-while-view-take-while-view:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying view and the predicate.

{/* source:cpp-ranges-take-while-view-take-while-view:0003 */}
