Returns an iterator to the first element of the view. Effectively calls `ranges::begin` on the underlying view [`base_`](/docs/cpp/library/ranges/take_while_view#Data_members).

{/* source:cpp-ranges-take-while-view-begin:0002 */}
Overload (1) does not participate in overload resolution if `V` is a [simple view](/docs/cpp/library/ranges#Helper_concepts) (that is, if `V` and `const V` are views with the same iterator and sentinel types).

### Parameters

{/* source:cpp-ranges-take-while-view-begin:0003 */}
(none)

### Return value

{/* source:cpp-ranges-take-while-view-begin:0004 */}
`ranges::begin(base_)`, where [`base_`](/docs/cpp/library/ranges/take_while_view#Data_members) is the underlying view.
