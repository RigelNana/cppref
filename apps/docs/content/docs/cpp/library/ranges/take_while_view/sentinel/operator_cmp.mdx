{/* source:cpp-ranges-take-while-view-sentinel-operator-cmp:0001 */}
Compares a `take_while_view::/*sentinel*/` with an iterator into (possibly const-qualified) view `V`. The iterator is typically obtained from a call to [`take_while_view::begin`](/docs/cpp/library/ranges/take_while_view/begin).

{/* source:cpp-ranges-take-while-view-sentinel-operator-cmp:0002 */}
Returns `true` if `x` compares equal to the underlying sentinel of `y` (i.e. [`y.base()`](/docs/cpp/library/ranges/take_while_view/sentinel/base)), or if the predicate returns `false` when applied to `*x`.

{/* source:cpp-ranges-take-while-view-sentinel-operator-cmp:0003 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `take_while_view::sentinel<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-take-while-view-sentinel-operator-cmp:0004 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Parameters

{/* source:cpp-ranges-take-while-view-sentinel-operator-cmp:0005 */}
<ParameterList>

  <Parameter name="y">sentinel to compare</Parameter>

### Return value

{/* source:cpp-ranges-take-while-view-sentinel-operator-cmp:0006 */}
`y.end_ == x || !std::invoke(*y.pred_, *x)`, where `end_` denotes the stored sentinel and `pred_` denotes the stored pointer to predicate.
