{/* source:cpp-ranges-zip-view-iterator-operator-cmp:0001 */}
Compares the underlying iterators.

{/* source:cpp-ranges-zip-view-iterator-operator-cmp:0002 */}
Let *`current_`* be the underlying *tuple-like* object of iterators to elements of adapted views.

{/* source:cpp-ranges-zip-view-iterator-operator-cmp:0003 */}
1. 1) Returns:
   - `x.current_ == y.current_` if `/*all-bidirectional*/<Const, Views...>` is `true`.
   - Otherwise, `true` if there exists an integer `0 <= i < sizeof...(Views)` such that `bool(std::get<i>(x.current_) == std::get<i>(y.current_))` is `true`. Otherwise, `false`.

{/* source:cpp-ranges-zip-view-iterator-operator-cmp:0004 */}
2. 2) Equivalent to `return x.current_ <=> y.current_;`.

{/* source:cpp-ranges-zip-view-iterator-operator-cmp:0005 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::zip_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-zip-view-iterator-operator-cmp:0006 */}
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
