{/* source:cpp-ranges-zip-view-zip-view:0001 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) all adapted [`view`](/docs/cpp/library/ranges/view) objects.

{/* source:cpp-ranges-zip-view-zip-view:0002 */}
The default constructor is deleted if [`std::is_default_constructible_v`](/docs/cpp/library/meta/is_default_constructible) is `false` for at least one type in `Views...`.

{/* source:cpp-ranges-zip-view-zip-view:0003 */}
2. 2) Move constructs every adapted [`view`](/docs/cpp/library/ranges/view) object in [`views_`](/docs/cpp/library/ranges/zip_view#Data_members) from the corresponding view in `views...`.
