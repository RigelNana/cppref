{/* source:cpp-ranges-zip-view:0001 */}
1. 1) `zip_view` is a range adaptor that takes one or more [`view`](/docs/cpp/library/ranges/view)s, and produces a [`view`](/docs/cpp/library/ranges/view) whose ith element is a tuple-like value consisting of the *i*th elements of all views. The size of produced view is the minimum of sizes of all adapted views.

{/* source:cpp-ranges-zip-view:0002 */}
2. 2) `views::zip` is a customization point object.

When calling with no argument, `views::zip()` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `auto(views::empty<std::tuple<>>)`. Otherwise, `views::zip(rs...)` is expression-equivalent to `ranges::zip_view<views::all_t<decltype((rs))>...>(rs...)`.

{/* source:cpp-ranges-zip-view:0003 */}
`zip_view` always models [`input_range`](/docs/cpp/library/ranges/input_range), and models [`forward_range`](/docs/cpp/library/ranges/forward_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), or [`sized_range`](/docs/cpp/library/ranges/sized_range) if all adapted [`view`](/docs/cpp/library/ranges/view) types model the corresponding concept.

{/* source:cpp-ranges-zip-view:0004 */}
`zip_view` models [`common_range`](/docs/cpp/library/ranges/common_range) if

{/* source:cpp-ranges-zip-view:0005 */}
- `sizeof...(Views)` is equal to `1`, and the only adapted view type models [`common_range`](/docs/cpp/library/ranges/common_range), or
- at least one adapted view type does not model [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), and every adapted view type models [`common_range`](/docs/cpp/library/ranges/common_range), or
- every adapted view type models both [`random_access_range`](/docs/cpp/library/ranges/random_access_range) and [`sized_range`](/docs/cpp/library/ranges/sized_range).

### Customization point objects

{/* source:cpp-ranges-zip-view:0006 */}
The name `views::zip` denotes a *customization point object*, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as *`__zip_fn`*.

{/* source:cpp-ranges-zip-view:0007 */}
All instances of *`__zip_fn`* are equal. The effects of invoking different instances of type *`__zip_fn`* on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `views::zip` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-zip-view:0008 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `views::zip` above, *`__zip_fn`* models

{/* source:cpp-ranges-zip-view:0009 */}
- `std::invocable<__zip_fn, Args...>`,
- `std::invocable<const __zip_fn, Args...>`,
- `std::invocable<__zip_fn&, Args...>`, and
- `std::invocable<const __zip_fn&, Args...>`.

{/* source:cpp-ranges-zip-view:0010 */}
Otherwise, no function call operator of *`__zip_fn`* participates in overload resolution.

### Example

{/* source:cpp-ranges-zip-view:0017 */}
```cpp
#include <array>
#include <iostream>
#include <list>
#include <ranges>
#include <string>
#include <tuple>
#include <vector>
 
void print(auto const rem, auto const& range)
{
    for (std::cout << rem; auto const& elem : range)
        std::cout << elem << ' ';
    std::cout << '\n';
}
 
int main()
{
    auto x = std::vector{1, 2, 3, 4};
    auto y = std::list<std::string>{"α", "β", "γ", "δ", "ε"};
    auto z = std::array{'A', 'B', 'C', 'D', 'E', 'F'};
 
    print("Source views:", "");
    print("x: ", x);
    print("y: ", y);
    print("z: ", z);
 
    print("\nzip(x,y,z):", "");
 
    for (std::tuple<int&, std::string&, char&> elem : std::views::zip(x, y, z))
    {
        std::cout << std::get<0>(elem) << ' '
                  << std::get<1>(elem) << ' '
                  << std::get<2>(elem) << '\n';
 
        std::get<char&>(elem) += ('a' - 'A'); // modifies the element of z
    }
 
    print("\nAfter modification, z: ", z);
}
```

Output:

```text
Source views:
x: 1 2 3 4
y: α β γ δ ε
z: A B C D E F
 
zip(x,y,z):
1 α A
2 β B
3 γ C
4 δ D
 
After modification, z: a b c d E F
```
