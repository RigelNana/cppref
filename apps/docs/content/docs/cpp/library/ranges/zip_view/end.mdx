{/* source:cpp-ranges-zip-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/zip_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/zip_view/sentinel) that compares equal to the end iterator of the [`zip_view`](/docs/cpp/library/ranges/zip_view).

{/* source:cpp-ranges-zip-view-end:0002 */}
Let [`views_`](/docs/cpp/library/ranges/zip_view#Data_members) denote the underlying tuple of views.

### Return value

{/* source:cpp-ranges-zip-view-end:0003 */}
1. 1) Equivalent to:
   - `return /*sentinel*/<false>(/*tuple-transform*/(ranges::end, views_));`, if `/*zip-is-common*/<Views...>` evaluates to `false`. Otherwise,
   - `return begin() + std::iter_difference_t</*iterator*/<false>>(size());`, if `(ranges::random_access_range<Views> && ...)` evaluates to `true`. Otherwise,
   - `return /*iterator*/<false>(/*tuple-transform*/(ranges::end, views_));`.

{/* source:cpp-ranges-zip-view-end:0004 */}
2. 2) Equivalent to:
   - `return /*sentinel*/<true>(/*tuple-transform*/(ranges::end, views_));`, if `/*zip-is-common*/<const Views...>` evaluates to `false`. Otherwise,
   - `return begin() + std::iter_difference_t</*iterator*/<true>>(size());`, if `ranges::random_access_range<const Views> && ...` evaluates to `true`. Otherwise,
   - `return /*iterator*/<true>(/*tuple-transform*/(ranges::end, views_));`.

### Parameters

{/* source:cpp-ranges-zip-view-end:0005 */}
(none)

### Return value

{/* source:cpp-ranges-zip-view-end:0006 */}
An iterator or sentinel representing the end of the `zip_view`, as described above.

### Notes

{/* source:cpp-ranges-zip-view-end:0007 */}
`ranges::range<const ranges::zip_view<Views...>>` is modeled if and only if for every type `Vi` in `Views...`, `const Vi` models [`range`](/docs/cpp/library/ranges/range).
