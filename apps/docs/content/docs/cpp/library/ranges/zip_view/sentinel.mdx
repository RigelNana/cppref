{/* source:cpp-ranges-zip-view-sentinel:0001 */}
The return type of [`zip_view::end`](/docs/cpp/library/ranges/zip_view/end) when the underlying view is not a [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-zip-view-sentinel:0002 */}
The type `/*sentinel*/<true>` or `/*sentinel*/<false>` treats the underlying view as const-qualified or non-const-qualified respectively.
