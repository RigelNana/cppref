Construct an iterator.

{/* source:cpp-ranges-zip-view-iterator-iterator:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying tuple of iterators to their default values.

{/* source:cpp-ranges-zip-view-iterator-iterator:0003 */}
2. 2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Move constructs the underlying tuple of iterators *`current_`* with `std::move(i.current)`.

{/* source:cpp-ranges-zip-view-iterator-iterator:0004 */}
This iterator also has a private constructor which is used by `zip_view::begin` and `zip_view::end`. This constructor is not accessible to users.
