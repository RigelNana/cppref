{/* source:cpp-ranges-zip-view-iterator-operator-arith2:0001 */}
Let *`current_`* denote the underlying *tuple-like* object of iterators to elements of adapted views.

{/* source:cpp-ranges-zip-view-iterator-operator-arith2:0002 */}
1. 1,2) Returns the iterator `i` incremented by `n`. Equivalent to: `auto r = i; r += n; return r;`.

{/* source:cpp-ranges-zip-view-iterator-operator-arith2:0003 */}
2. 3) Returns the iterator `i` decremented by `n`. Equivalent to: `auto r = i; r -= n; return r;`.

{/* source:cpp-ranges-zip-view-iterator-operator-arith2:0004 */}
3. 4) Let *`DIST(k)`* be `difference_type(std::get<k>(i.current_) - std::get<k>(j.current_))`. Returns the smallest absolute value among `DIST(n)` for all integers `0 <= n < sizeof...(Views)`.

{/* source:cpp-ranges-zip-view-iterator-operator-arith2:0005 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `zip_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-zip-view-iterator-operator-arith2:0007 */}
1. 1,2) a copy of `i` that is advanced by `n`

{/* source:cpp-ranges-zip-view-iterator-operator-arith2:0008 */}
2. 3) a copy of `i` that is advanced by `-n`

{/* source:cpp-ranges-zip-view-iterator-operator-arith2:0009 */}
3. 4) the distance between `i` and `j`
