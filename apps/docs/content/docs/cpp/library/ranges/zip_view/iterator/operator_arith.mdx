{/* source:cpp-ranges-zip-view-iterator-operator-arith:0001 */}
Increments or decrements each of the underlying *`is_...`* iterators in the underlying tuple-like object [`current_`](/docs/cpp/library/ranges/zip_view/iterator#Data_members).

{/* source:cpp-ranges-zip-view-iterator-operator-arith:0002 */}
1. 1) Equivalent to `/*tuple-for-each*/([](auto& i) { ++i; }, current_); return *this;`

{/* source:cpp-ranges-zip-view-iterator-operator-arith:0003 */}
2. 2) Equivalent to `++*this;`

{/* source:cpp-ranges-zip-view-iterator-operator-arith:0004 */}
3. 3) Equivalent to `auto tmp = *this; ++*this; return tmp;`

{/* source:cpp-ranges-zip-view-iterator-operator-arith:0005 */}
4. 4) Equivalent to `/*tuple-for-each*/([](auto& i) { --i; }, current_); return *this;`

{/* source:cpp-ranges-zip-view-iterator-operator-arith:0006 */}
5. 5) Equivalent to `auto tmp = *this; --*this; return tmp;`

{/* source:cpp-ranges-zip-view-iterator-operator-arith:0007 */}
6. 6) Equivalent to `/*tuple-for-each*/([&]<class I>(I& i) { i += iter_difference_t<I>(x); }, current_); return *this;`

{/* source:cpp-ranges-zip-view-iterator-operator-arith:0008 */}
7. 7) Equivalent to `/*tuple-for-each*/([&]<class I>(I& i) { i -= iter_difference_t<I>(x); }, current_); return *this;`
