{/* source:cpp-ranges-zip-view-iterator-iter-move:0001 */}
Equivalent to: `return /*tuple-transform*/(ranges::iter_move, i.current_);`, where [`current_`](/docs/cpp/library/ranges/zip_view/iterator#Data_members) denotes the underlying tuple-like object that holds iterators to elements of adapted views.

{/* source:cpp-ranges-zip-view-iterator-iter-move:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `zip_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-zip-view-iterator-iter-move:0004 */}
`std::move(*i)` if `*i` is an lvalue reference, otherwise `*i`
