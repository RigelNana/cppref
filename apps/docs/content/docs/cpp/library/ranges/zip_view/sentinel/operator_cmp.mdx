{/* source:cpp-ranges-zip-view-sentinel-operator-cmp:0001 */}
Compares the underlying tuple of iterators of `x` with the underlying tuple of sentinels of `y`.

{/* source:cpp-ranges-zip-view-sentinel-operator-cmp:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `zip_view::sentinel<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-zip-view-sentinel-operator-cmp:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Return value

{/* source:cpp-ranges-zip-view-sentinel-operator-cmp:0005 */}
Let `x.current_` denote the underlying tuple of iterators, and `y.end_` denote the underlying tuple of sentinels.

{/* source:cpp-ranges-zip-view-sentinel-operator-cmp:0006 */}
Returns

{/* source:cpp-ranges-zip-view-sentinel-operator-cmp:0007 */}
- `true` if at least one underlying iterator, obtained by expression equivalent to `std::get<i>(x.current_)`, evaluates equal (using an appropriate `operator==`) to some underlying sentinel, obtained by expression equivalent to `std::get<i>(y.end_)`, for some index i in ranges `0 <= i < sizeof...(Views)`, `false` otherwise.
