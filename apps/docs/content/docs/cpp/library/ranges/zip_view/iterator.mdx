{/* source:cpp-ranges-zip-view-iterator:0001 */}
The iterator type of a possibly const-qualified `zip_view`, returned by [`zip_view::begin`](/docs/cpp/library/ranges/zip_view/begin) and in certain cases by [`zip_view::end`](/docs/cpp/library/ranges/zip_view/end).

{/* source:cpp-ranges-zip-view-iterator:0002 */}
The type `/*iterator*/<true>` or `/*iterator*/<false>` treats the underlying views as const-qualified or non-const-qualified respectively.
