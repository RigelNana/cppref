{/* source:cpp-ranges-elements-view:0001 */}
1) Accepts a [`view`](/docs/cpp/library/ranges/view) of tuple-like values, and issues a view with a value type of the `N`<sup>th</sup> element of the adapted view's value-type.

{/* source:cpp-ranges-elements-view:0002 */}
2) Every specialization of `views::elements` is a [RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::elements<M>(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `elements_view<views::all_t<decltype((e))>, M>{e}` for any suitable subexpression `e` and constant expression `M`.

{/* source:cpp-ranges-elements-view:0003 */}
3) Ensures that the elements of the underlying view are tuple-like values<InlineRevision since="C++23">, see [`tuple-like`](/docs/cpp/library/utility/tuple/tuple-like)</InlineRevision>.

{/* source:cpp-ranges-elements-view:0004 */}
4) Ensures that dangling references cannot be returned.

{/* source:cpp-ranges-elements-view:0005 */}
`elements_view` models the concepts [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`input_range`](/docs/cpp/library/ranges/input_range), [`common_range`](/docs/cpp/library/ranges/common_range), and [`sized_range`](/docs/cpp/library/ranges/sized_range) when the underlying view `V` models respective concepts.

### Example

{/* source:cpp-ranges-elements-view:0011 */}
```cpp
#include <iostream>
#include <ranges>
#include <string>
#include <tuple>
#include <vector>
 
int main()
{
    const std::vector<std::tuple<int, char, std::string>> vt
    {
        {1, 'A', "α"},
        {2, 'B', "β"},
        {3, 'C', "γ"},
        {4, 'D', "δ"},
        {5, 'E', "ε"},
    };
 
    for (int const e : std::views::elements<0>(vt))
        std::cout << e << ' ';
    std::cout << '\n';
 
    for (char const e : vt | std::views::elements<1>)
        std::cout << e << ' ';
    std::cout << '\n';
 
    for (std::string const& e : std::views::elements<2>(vt))
        std::cout << e << ' ';
    std::cout << '\n';
}
```

Output:

```text
1 2 3 4 5
A B C D E
α β γ δ ε
```
