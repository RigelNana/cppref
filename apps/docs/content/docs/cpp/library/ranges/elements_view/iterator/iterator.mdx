Construct an iterator.

{/* source:cpp-ranges-elements-view-iterator-iterator:0002 */}
1) [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying iterator `current_` via its default member initializer (`= ranges::iterator_t<Base>()`).

{/* source:cpp-ranges-elements-view-iterator-iterator:0003 */}
2) Initializes the underlying iterator `current_` with `std::move(current)`.

{/* source:cpp-ranges-elements-view-iterator-iterator:0004 */}
3) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Initializes the underlying iterator `current_` with `std::move(i.current)`.
