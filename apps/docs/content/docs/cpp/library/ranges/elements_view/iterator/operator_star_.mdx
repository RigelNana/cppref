{/* source:cpp-ranges-elements-view-iterator-operator-star:0001 */}
Returns the element into `V` the underlying iterator points to.

{/* source:cpp-ranges-elements-view-iterator-operator-star:0002 */}
Effectively returns `/*get-element*/(this->base())`, where for an expression `e`, `/*get-element*/(e)` is

{/* source:cpp-ranges-elements-view-iterator-operator-star:0003 */}
- `std::get<N>(*e)`, if `ranges::range_reference_t<Base>` is a reference type. Otherwise, `static_cast<E>(std::get<N>(*e))`, where `E` is `std::remove_cv_t<std::tuple_element_t<N, ranges::range_reference_t<Base>>>`.

### Parameters

{/* source:cpp-ranges-elements-view-iterator-operator-star:0004 */}
(none)

### Return value

{/* source:cpp-ranges-elements-view-iterator-operator-star:0005 */}
The current element.

### Notes

{/* source:cpp-ranges-elements-view-iterator-operator-star:0006 */}
`operator->` is not provided.

### Example

{/* source:cpp-ranges-elements-view-iterator-operator-star:0007 */}
```cpp
#include <iostream>
#include <ranges>
#include <string_view>
#include <tuple>
 
int main()
{
    using T = std::tuple<int, char, std::string_view>;
 
    const auto il = {
        T{1, 'A', "α"},
        T{2, 'B', "β"},
        T{3, 'C', "γ"},
    };
 
    const auto view {il | std::views::elements<2>};
 
    const auto iter {view.begin() + 1};
 
    std::cout << *iter << '\n';
}
```

Output:

```text
β
```
