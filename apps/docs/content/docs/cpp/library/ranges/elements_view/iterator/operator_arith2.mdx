{/* source:cpp-ranges-elements-view-iterator-operator-arith2:0001 */}
1,2) Returns the iterator `i` incremented by `n`.

{/* source:cpp-ranges-elements-view-iterator-operator-arith2:0002 */}
3) Returns the iterator `i` decremented by `n`.

{/* source:cpp-ranges-elements-view-iterator-operator-arith2:0003 */}
4) Returns the distance between `x` and `y`.

{/* source:cpp-ranges-elements-view-iterator-operator-arith2:0004 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `elements_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-elements-view-iterator-operator-arith2:0006 */}
1,2) `[&]{ auto j = i; j += n; return j; }()`

{/* source:cpp-ranges-elements-view-iterator-operator-arith2:0007 */}
3) `[&]{ auto j = i; j -= n; return j; }()`

{/* source:cpp-ranges-elements-view-iterator-operator-arith2:0008 */}
4) `x.base() - y.base()`
