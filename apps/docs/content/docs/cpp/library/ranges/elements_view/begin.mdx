{/* source:cpp-ranges-elements-view-begin:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/elements_view/iterator) to the first element of the `elements_view`.

{/* source:cpp-ranges-elements-view-begin:0002 */}
Let [`base_`](/docs/cpp/library/ranges/elements_view#Data_members) be the underlying view.

{/* source:cpp-ranges-elements-view-begin:0003 */}
1) Equivalent to `return /*iterator*/<false>(ranges::begin(base_));`

{/* source:cpp-ranges-elements-view-begin:0004 */}
2) Equivalent to `return /*iterator*/<true>(ranges::begin(base_));`

### Parameters

{/* source:cpp-ranges-elements-view-begin:0005 */}
(none)

### Return value

{/* source:cpp-ranges-elements-view-begin:0006 */}
Iterator to the first element.
