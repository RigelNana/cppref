Constructs an `elements_view`.

{/* source:cpp-ranges-elements-view-elements-view:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying view [`base_`](/docs/cpp/library/ranges/elements_view#Data_members). After construction, [`base()`](/docs/cpp/library/ranges/elements_view/base) returns a copy of `V()`.

{/* source:cpp-ranges-elements-view-elements-view:0003 */}
2) Initializes the underlying view [`base_`](/docs/cpp/library/ranges/elements_view#Data_members) with `std::move(base)`.

### Parameters

{/* source:cpp-ranges-elements-view-elements-view:0004 */}
<ParameterList>
  <Parameter name="base">the underlying view</Parameter>
</ParameterList>

### Example

{/* source:cpp-ranges-elements-view-elements-view:0005 */}
```cpp
#include <array>
#include <iostream>
#include <ranges>
#include <tuple>
 
void println(auto const& v)
{
    for (auto const& e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}
 
int main()
{
    using namespace std::literals;
 
    const std::array<std::tuple<int, char, std::string>, 2> vt
    {
        std::tuple{1, 'A', "α"s},
        std::tuple{2, 'B', "β"s},
    };
 
    [[maybe_unused]]
    auto empty = std::views::elements<0>;
 
    println(std::views::elements<0>(vt));
    println(std::views::elements<1>(vt));
    println(std::views::elements<2>(vt));
}
```

Output:

```text
1 2
A B
α β
```
