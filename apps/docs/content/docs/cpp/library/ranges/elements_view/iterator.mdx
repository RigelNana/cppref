{/* source:cpp-ranges-elements-view-iterator:0001 */}
The return type of [`elements_view::begin`](/docs/cpp/library/ranges/elements_view/begin), and of [`elements_view::end`](/docs/cpp/library/ranges/elements_view/end) when the underlying view is a [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-elements-view-iterator:0002 */}
The type `/*iterator*/<true>` is returned by the const-qualified overloads. The type `/*iterator*/<false>` is returned by the non-const-qualified overloads.

### Member types

{/* source:cpp-ranges-elements-view-iterator:0003 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`Base` (private)</DescriptionTerm>
    <DescriptionBody>`const V` if `Const` is `true`, otherwise `V`. (exposition-only member type*)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`iterator_concept`</DescriptionTerm>
    <DescriptionBody>

Denotes:

    - [`std::random_access_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `Base` models [`random_access_range`](/docs/cpp/library/ranges/random_access_range). Otherwise,
    - [`std::bidirectional_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `Base` models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range). Otherwise,
    - [`std::forward_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `Base` models [`forward_range`](/docs/cpp/library/ranges/forward_range). Otherwise,
    - [`std::input_iterator_tag`](/docs/cpp/library/iterator/iterator_tags).

    </DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`iterator_category` (conditionally present)</DescriptionTerm>
    <DescriptionBody>

Not defined, if `Base` does not model [`forward_range`](/docs/cpp/library/ranges/forward_range). Otherwise,

    - [`std::input_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `std::get<N>(*current_)` is an rvalue. Otherwise, let `C` be the type `std::iterator_traits<std::iterator_t<Base>>::iterator_category`.
    - [`std::random_access_iterator_tag`](/docs/cpp/library/iterator/iterator_tags), if `C` models `std::derived_from<std::random_access_iterator_tag>`. Otherwise,
    - `C`.

    </DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`value_type`</DescriptionTerm>
    <DescriptionBody>`std::remove_cvref_t<std::tuple_element_t<N, ranges::range_value_t<Base>>>`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`difference_type`</DescriptionTerm>
    <DescriptionBody>`ranges::range_difference_t<Base>`</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
