Computes the distance between the underlying iterator of `x` and the underlying sentinel of `y`.

{/* source:cpp-ranges-elements-view-sentinel-operator:0002 */}
These function templates are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `elements_view::sentinel` is an associated class of the arguments.
