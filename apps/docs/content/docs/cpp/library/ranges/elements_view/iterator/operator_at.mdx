{/* source:cpp-ranges-elements-view-iterator-operator-at:0001 */}
Returns an element at specified relative location, as if by `/*get-element*/(this->base() + n)`, where for an expression `e`, `/*get-element*/(e)` is

{/* source:cpp-ranges-elements-view-iterator-operator-at:0002 */}
- `std::get<N>(*e)`, if `ranges::range_reference_t<Base>` is a reference type. Otherwise, `static_cast<E>(std::get<N>(*e))`, where `E` is `std::remove_cv_t<std::tuple_element_t<N, ranges::range_reference_t<Base>>>`.

### Parameters

{/* source:cpp-ranges-elements-view-iterator-operator-at:0003 */}
<ParameterList>
  <Parameter name="n">position relative to current location</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-elements-view-iterator-operator-at:0004 */}
The element at displacement `n` relative to the current location.

### Example

{/* source:cpp-ranges-elements-view-iterator-operator-at:0005 */}
```cpp
#include <iostream>
#include <ranges>
#include <string_view>
#include <tuple>
 
int main()
{
    using T = std::tuple<int, char, std::string_view>;
 
    const auto il =
    {
        T{1, 'A', "α"},
        T{2, 'B', "β"},
        T{3, 'C', "γ"},
    };
 
    std::cout << std::views::elements<0>(il)[1] << ' '   // 2
              << std::views::elements<1>(il)[1] << ' '   // B
              << std::views::elements<2>(il)[1] << '\n'; // β
}
```

Output:

```text
2 B β
```
