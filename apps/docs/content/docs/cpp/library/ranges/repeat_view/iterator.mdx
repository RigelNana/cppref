## std::ranges::repeat_view::iterator::iterator

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++23" code={`/*iterator*/() = default;`} />
  <Declaration id="2" language="cpp" since="C++23" code={`constexpr explicit /*iterator*/
    ( const W* value, /*index-type*/ b = /*index-type*/() );`} />
  (exposition only*)
</DeclarationDoc>

Constructs an iterator. Overload (2) is called by [`begin()`](/docs/cpp/library/ranges/repeat_view#begin) and [`end()`](/docs/cpp/library/ranges/repeat_view#end) of [`ranges::repeat_view`](/docs/cpp/library/ranges/repeat_view).

1) Initializes [`value_`](/docs/cpp/library/ranges/repeat_view/iterator#value) with `nullptr` and value-initializes [`current_`](/docs/cpp/library/ranges/repeat_view/iterator#current).

2) Initializes [`value_`](/docs/cpp/library/ranges/repeat_view/iterator#value) with `value` and [`current_`](/docs/cpp/library/ranges/repeat_view/iterator#current) with `b`.

If `Bound` is not [`std::unreachable_sentinel_t`](/docs/cpp/library/iterator/unreachable_sentinel_t) and `b` is negative, the behavior is undefined.
