{/* source:cpp-ranges-repeat-view:0001 */}
1) A range factory that generates a sequence of elements by repeatedly producing the same value. Can be either bounded or unbounded (infinite).

{/* source:cpp-ranges-repeat-view:0002 */}
2) `views::repeat(e)` and `views::repeat(e, f)` are [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `repeat_view<std::decay_t<decltype((E))>>(e)` and `repeat_view(e, f)` respectively for any suitable subexpressions `e` and `f`.

{/* source:cpp-ranges-repeat-view:0003 */}
3) Determines whether a type is [`integer-like`](/docs/cpp/library/iterator/is-integer-like) and has a usable [`difference type`](/docs/cpp/library/iterator#Types_and_writability).

{/* source:cpp-ranges-repeat-view:0004 */}
`repeat_view` models [`random_access_range`](/docs/cpp/library/ranges/random_access_range). If `Bound` is not [`std::unreachable_sentinel_t`](/docs/cpp/library/iterator/unreachable_sentinel_t), `repeat_view` also models [`sized_range`](/docs/cpp/library/ranges/sized_range) and [`common_range`](/docs/cpp/library/ranges/common_range).

### Customization point objects

{/* source:cpp-ranges-repeat-view:0005 */}
The name `views::repeat` denotes a customization point object, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [semiregular](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as `__repeat_fn`.

{/* source:cpp-ranges-repeat-view:0006 */}
All instances of `__repeat_fn` are equal. The effects of invoking different instances of type `__repeat_fn` on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `views::repeat` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-repeat-view:0007 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `views::repeat` above, `__repeat_fn` models

{/* source:cpp-ranges-repeat-view:0008 */}
- `std::invocable<__repeat_fn, Args...>`,
- `std::invocable<const __repeat_fn, Args...>`,
- `std::invocable<__repeat_fn&, Args...>`, and
- `std::invocable<const __repeat_fn&, Args...>`.

{/* source:cpp-ranges-repeat-view:0009 */}
Otherwise, no function call operator of `__repeat_fn` participates in overload resolution.

## std::ranges::repeat_view::repeat_view

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++23" code={`repeat_view() requires std::default_initializable<W> = default;`} />
  <Declaration id="2" language="cpp" since="C++23" code={`constexpr explicit repeat_view( const W& value, Bound bound = Bound() );`} />
  <Declaration id="3" language="cpp" since="C++23" code={`constexpr explicit repeat_view( W&& value, Bound bound = Bound() );`} />
  <Declaration id="4" language="cpp" since="C++23" code={`template < class... WArgs, class... BoundArgs >
    requires std::constructible_from<W, WArgs...>
          && std::constructible_from<Bound, BoundArgs...>
constexpr explicit
    repeat( std::piecewise_construct_t, std::tuple<WArgs...> value_args,

            std::tuple<BoundArgs...> bound_args = std::tuple<>{} );`} />
</DeclarationDoc>

1) Default-initializes [`value_`](/docs/cpp/library/ranges/repeat_view#value) and value-initializes [`bound_`](/docs/cpp/library/ranges/repeat_view#bound).

2) Initializes [`value_`](/docs/cpp/library/ranges/repeat_view#value) with `value` and initializes [`bound_`](/docs/cpp/library/ranges/repeat_view#bound) with `bound`.

If `Bound` is not [`std::unreachable_sentinel_t`](/docs/cpp/library/iterator/unreachable_sentinel_t) and `bool(bound >= 0)` is `false`, the behavior is undefined.

3) Initializes [`value_`](/docs/cpp/library/ranges/repeat_view#value) with `std::move(value)` and initializes [`bound_`](/docs/cpp/library/ranges/repeat_view#bound) with `bound`.

If `Bound` is not [`std::unreachable_sentinel_t`](/docs/cpp/library/iterator/unreachable_sentinel_t) and `bool(bound >= 0)` is `false`, the behavior is undefined.

4) Initializes [`value_`](/docs/cpp/library/ranges/repeat_view#value) with `std::make_from_tuple<T>(std::move(value_args))` and [`bound_`](/docs/cpp/library/ranges/repeat_view#bound) with `std::make_from_tuple<Bound>(std::move(bound_args))`.

If `Bound` is not [`std::unreachable_sentinel_t`](/docs/cpp/library/iterator/unreachable_sentinel_t) and `bool(bound >= 0)` is `false`, the behavior is undefined.

### Example

{/* source:cpp-ranges-repeat-view:0019 */}
```cpp
#include <iostream>
#include <ranges>
#include <string_view>
using namespace std::literals;
 
int main()
{
    // bounded overload
    for (auto s : std::views::repeat("C++"sv, 3))
        std::cout << s << ' ';
    std::cout << '\n';
 
    // unbounded overload
    for (auto s : std::views::repeat("I know that you know that"sv)
                | std::views::take(3))
        std::cout << s << ' ';
    std::cout << "...\n";
}
```

Output:

```text
C++ C++ C++
I know that you know that I know that you know that I know that you know that ...
```
