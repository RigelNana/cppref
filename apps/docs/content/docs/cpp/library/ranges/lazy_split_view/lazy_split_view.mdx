Constructs a `lazy_split_view`.

{/* source:cpp-ranges-lazy-split-view-lazy-split-view:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying view [`base_`](/docs/cpp/library/ranges/lazy_split_view#base) and the delimiter [`pattern_`](/docs/cpp/library/ranges/lazy_split_view#pattern).

{/* source:cpp-ranges-lazy-split-view-lazy-split-view:0003 */}
2. 2) Initializes the underlying view `base_` with `std::move(base)` and the delimiter `pattern_` with `std::move(pattern)`.

{/* source:cpp-ranges-lazy-split-view-lazy-split-view:0004 */}
3. 3) Initializes the underlying view `base_` with `views::all(std::forward<R>(r))` and the delimiter `pattern_` with `ranges::single_view{std::move(e)}`.
