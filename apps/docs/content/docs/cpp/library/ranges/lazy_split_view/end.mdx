{/* source:cpp-ranges-lazy-split-view-end:0001 */}
Returns an iterator or sometimes a sentinel representing the end of the [`view`](/docs/cpp/library/ranges/view). Let [`base_`](/docs/cpp/library/ranges/lazy_split_view#base) be the underlying view.

{/* source:cpp-ranges-lazy-split-view-end:0002 */}
1. 1) Returns an iterator. Equivalent to: `return /*outer_iterator*/</*simple_view*/<V>>{*this, ranges::end(base_)};`.

{/* source:cpp-ranges-lazy-split-view-end:0003 */}
2. 2) Returns an [`outer_iterator`](/docs/cpp/library/ranges/lazy_split_view/outer_iterator) or a [`std::default_sentinel`](/docs/cpp/library/iterator/default_sentinel). Equivalent to:

```cpp
if constexpr (ranges::forward_range<V> && ranges::forward_range<const V> &&
              ranges::common_range<const V>)
    return /*outer_iterator*/<true>{*this, ranges::end(base_)};
else
    return std::default_sentinel;
```

### Return value

{/* source:cpp-ranges-lazy-split-view-end:0004 */}
An [`outer_iterator`](/docs/cpp/library/ranges/lazy_split_view/outer_iterator) or a [`std::default_sentinel`](/docs/cpp/library/iterator/default_sentinel) representing the end of the [`view`](/docs/cpp/library/ranges/view).

### Example

{/* source:cpp-ranges-lazy-split-view-end:0005 */}
```cpp
#include <iostream>
#include <ranges>
#include <string_view>
 
int main()
{
    constexpr std::string_view keywords{"false float for friend"};
    std::ranges::lazy_split_view kw{keywords, ' '};
    const auto count = std::ranges::distance(kw.begin(), kw.end());
    std::cout << "Words count: " << count << '\n';
}
```

Output:

```text
Words count: 4
```
