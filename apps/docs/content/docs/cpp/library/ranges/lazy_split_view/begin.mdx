{/* source:cpp-ranges-lazy-split-view-begin:0001 */}
Returns an [`outer_iterator`](/docs/cpp/library/ranges/lazy_split_view/outer_iterator) to the first element of the [`lazy_split_view`](/docs/cpp/library/ranges/lazy_split_view/lazy_split_view).

{/* source:cpp-ranges-lazy-split-view-begin:0002 */}
Let [`base_`](/docs/cpp/library/ranges/lazy_split_view#base) be the underlying view and [`current_`](/docs/cpp/library/ranges/lazy_split_view#current) be the underlying caching object (may not be present).

{/* source:cpp-ranges-lazy-split-view-begin:0003 */}
1. 1) Equivalent to:

```cpp
constexpr auto begin()
{
    if constexpr (ranges::forward_range<V>)
        return /*outer_iterator*/</*simple_view*/<V>>{*this, ranges::begin(base_)};
    else
    {
        current_ = ranges::begin(base_);
        return /*outer_iterator*/<false>{*this};
    }
}
```

{/* source:cpp-ranges-lazy-split-view-begin:0004 */}
2. 2) Equivalent to `return /*outer_iterator*/<true>{*this, ranges::begin(base_)};`.

### Return value

{/* source:cpp-ranges-lazy-split-view-begin:0005 */}
[`outer_iterator`](/docs/cpp/library/ranges/lazy_split_view/outer_iterator) to the first element.
