Returns a copy of the underlying view [`base_`](/docs/cpp/library/ranges/lazy_split_view#base).

{/* source:cpp-ranges-lazy-split-view-base:0002 */}
1. 1) Copy constructs the result from the underlying view *`base_`*.

{/* source:cpp-ranges-lazy-split-view-base:0003 */}
2. 2) Move constructs the result from the underlying view *`base_`*.

### Return value

{/* source:cpp-ranges-lazy-split-view-base:0004 */}
A copy of the underlying view [`base_`](/docs/cpp/library/ranges/lazy_split_view#base).

### Example

{/* source:cpp-ranges-lazy-split-view-base:0005 */}
```cpp
#include <iostream>
#include <ranges>
#include <string_view>
 
void print(std::string_view rem, auto const& r, std::string_view post = "\n")
{
    for (std::cout << rem; auto const& e : r)
        std::cout << e;
    std::cout << post;
}
 
int main()
{
    constexpr std::string_view keywords{ "this,..throw,..true,..try,.." };
    constexpr std::string_view pattern{",.."};
    constexpr std::ranges::lazy_split_view lazy_split_view{keywords, pattern};
    print("base() = [", lazy_split_view.base(), "]\n"
          "substrings: ");
    for (auto const& split: lazy_split_view)
        print("[", split, "] ");
}
```

Output:

```text
base() = [this,..throw,..true,..try,..]
substrings: [this] [throw] [true] [try] []
```
