{/* source:cpp-ranges-lazy-split-view-outer-iterator:0001 */}
The return type of [`lazy_split_view::begin`](/docs/cpp/library/ranges/lazy_split_view/begin), and of [`lazy_split_view::end`](/docs/cpp/library/ranges/lazy_split_view/end) when the underlying view is a [`common_range`](/docs/cpp/library/ranges/common_range) and [`forward_range`](/docs/cpp/library/ranges/forward_range).

{/* source:cpp-ranges-lazy-split-view-outer-iterator:0002 */}
If either `V` or `Pattern` is not a [simple view](/docs/cpp/library/ranges#Helper_concepts) (e.g. if `ranges::iterator_t<const V>` is invalid or different from `ranges::iterator_t<V>`), `Const` is `true` for iterators returned from the const overloads, and `false` otherwise. If `V` is a simple view, `Const` is `true` if and only if `V` is a [`forward_range`](/docs/cpp/library/ranges/forward_range).

## std::ranges::lazy_split_view::outer_iterator::outer_iterator

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++20" code={`/*outer_iterator*/() = default;`} />
  <Declaration id="2" language="cpp" since="C++20" code={`constexpr explicit /*outer_iterator*/( Parent& parent )
    requires (!ranges::forward_range<Base>);`} />
  <Declaration id="3" language="cpp" since="C++20" code={`constexpr /*outer_iterator*/( Parent& parent,
                              ranges::iterator_t<Base> current )

    requires ranges::forward_range<Base>;`} />
  <Declaration id="4" language="cpp" since="C++20" code={`constexpr /*outer_iterator*/( /*outer_iterator*/<!Const> i )
    requires Const && std::convertible_to<ranges::iterator_t<V>,

                                          ranges::iterator_t<Base>>;`} />
</DeclarationDoc>

1. 1) Value initializes the non-static data members with their default member initializer, that is:

    - `parent_ = nullptr;`,
    - `current_ = iterator_t<Base>();` (present only if `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range)),

2. 2) Initializes *`parent_`* with `std::addressof(parent)`.
3. 3) Initializes *`parent_`* with `std::addressof(parent)` and *`current_`* with `std::move(current)`.
4. 4) Initializes *`parent_`* with `i.parent_`, *`current_`* with `std::move(i.current_)`, and *`trailing_empty_`* with `t.trailing_empty_`. The `trailing_empty_` is initialized with its default member initializer to `false`.

## std::ranges::lazy_split_view::outer_iterator::operator++

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++20" code={`constexpr /*outer_iterator*/& operator++();`} />
  <Declaration id="2" language="cpp" since="C++20" code={`constexpr decltype(auto) operator++(int);`} />
</DeclarationDoc>

1. 1) The function body is equivalent to:

```cpp
const auto end = ranges::end(parent_->base_);
if (/*cur*/() == end)
{
    trailing_empty_ = false;
    return *this;
}
const auto [pbegin, pend] = ranges::subrange{parent_->pattern_};
if (pbegin == pend)
    ++/*cur*/();
else if constexpr (/*tiny_range*/<Pattern>)
{
    /*cur*/() = ranges::find(std::move(/*cur*/()), end, *pbegin);
    if (/*cur*/() != end)
    {
        ++/*cur*/();
        if (/*cur*/() == end)
            trailing_empty_ = true;
    }
}
else
{
    do
    {
        auto [b, p] = ranges::mismatch(/*cur*/(), end, pbegin, pend);
        if (p == pend)
        {
            /*cur*/() = b;
            if (/*cur*/() == end)
                trailing_empty_ = true;
            break; // The pattern matched; skip it
        }
    } while (++/*cur*/() != end);
}
return *this;
```

2. 2) Equivalent to:

```cpp
if constexpr (ranges::forward_range<Base>)
{
    auto tmp = *this;
    ++*this;
    return tmp;
}
else
{
    ++*this; // no return statement
}
```

## operator==(std::ranges::split_view::outer_iterator)

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++20" code={`friend constexpr bool operator==( const /*outer_iterator*/& x,
                                  const /*outer_iterator*/& y )

  <Declaration id="2" language="cpp" since="C++20" code={`friend constexpr bool operator==( const /*outer_iterator*/& x,

1. 1) Equivalent to `return x.current_ == y.current_ and x.trailing_empty_ == y.trailing_empty_;`.
2. 2) Equivalent to `return x./*cur*/() == ranges::end(x.parent_->base_) and !x.trailing_empty_;`. The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::split_view::outer_iterator` is an associated class of the arguments.
