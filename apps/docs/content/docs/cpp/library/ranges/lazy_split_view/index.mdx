{/* source:cpp-ranges-lazy-split-view:0001 */}
1. 1) `lazy_split_view` takes a [`view`](/docs/cpp/library/ranges/view) and a delimiter, and splits the [`view`](/docs/cpp/library/ranges/view) into subranges on the delimiter.

    Two major scenarios are supported:

    - The view is an [`input_range`](/docs/cpp/library/ranges/input_range), the delimiter is a single element (wrapped in a [`single_view`](/docs/cpp/library/ranges/single_view)).
    - The view is a [`forward_range`](/docs/cpp/library/ranges/forward_range), the delimiter is a [`view`](/docs/cpp/library/ranges/view) of elements.

{/* source:cpp-ranges-lazy-split-view:0002 */}
2. 2) A [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::lazy_split(e, f)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `lazy_split_view(e, f)`.

{/* source:cpp-ranges-lazy-split-view:0003 */}
3. 3) The exposition-only concept `/*tiny-range*/<Pattern>` is satisfied if `Pattern` satisfies [`sized_range`](/docs/cpp/library/ranges/sized_range), `Pattern::size()` is a constant expression and suitable as a template non-type argument, and the value of `Pattern::size()` is less than or equal to 1. Notably, [`empty_view`](/docs/cpp/library/ranges/empty_view) and [`single_view`](/docs/cpp/library/ranges/single_view) satisfy this concept.

{/* source:cpp-ranges-lazy-split-view:0004 */}
`lazy_split_view` models the concepts [`forward_range`](/docs/cpp/library/ranges/forward_range) and [`input_range`](/docs/cpp/library/ranges/input_range) when the underlying [`view`](/docs/cpp/library/ranges/view) `V` models respective concepts, and models [`common_range`](/docs/cpp/library/ranges/common_range) when `V` models both [`forward_range`](/docs/cpp/library/ranges/forward_range) and [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-lazy-split-view:0005 */}
The inner range (`ranges::range_reference_t<lazy_split_view>`) models the concepts [`forward_range`](/docs/cpp/library/ranges/forward_range) and [`input_range`](/docs/cpp/library/ranges/input_range) when the underlying [`view`](/docs/cpp/library/ranges/view) `V` models respective concepts. It does not model [`common_range`](/docs/cpp/library/ranges/common_range), and cannot be used with algorithms that expect a [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range) or higher.

{/* source:cpp-ranges-lazy-split-view:0006 */}
Unlike [`split_view`](/docs/cpp/library/ranges/split_view), `lazy_split_view` does not maintain the continuity of the subrange.

### Notes

{/* source:cpp-ranges-lazy-split-view:0010 */}
The name `lazy_split_view` is introduced by the post-C++20 defect report [P2210R2](https://wg21.link/P2210R2). It has the same lazy mechanism as that of the old `split_view` before change.

### Example

{/* source:cpp-ranges-lazy-split-view:0011 */}
```cpp
#include <algorithm>
#include <iostream>
#include <ranges>
#include <string_view>
 
auto print = [](auto const& view)
{
    // `view` is of std::views::lazy_split_view::__outer_iterator::value_type
 
    for (std::cout << "{ "; const auto element : view)
        std::cout << element << ' ';
    std::cout << "} ";
};
 
int main()
{
    constexpr static auto source = {0, 1, 0, 2, 3, 0, 4, 5, 6, 0, 7, 8, 9};
    constexpr int delimiter{0};
    constexpr std::ranges::lazy_split_view outer_view{source, delimiter};
    std::cout << "splits[" << std::ranges::distance(outer_view) << "]:  ";
    for (auto const& inner_view: outer_view)
        print(inner_view);
 
    constexpr std::string_view hello{"Hello C++ 20 !"};
    std::cout << "\n" "substrings: ";
    std::ranges::for_each(hello | std::views::lazy_split(' '), print);
 
    constexpr std::string_view text{"Hello-+-C++-+-20-+-!"};
    constexpr std::string_view delim{"-+-"};
    std::cout << "\n" "substrings: ";
    std::ranges::for_each(text | std::views::lazy_split(delim), print);
}
```

Output:

```text
splits[5]:  { } { 1 } { 2 3 } { 4 5 6 } { 7 8 9 }
substrings: { H e l l o } { C + + } { 2 0 } { ! }
substrings: { H e l l o } { C + + } { 2 0 } { ! }
```
