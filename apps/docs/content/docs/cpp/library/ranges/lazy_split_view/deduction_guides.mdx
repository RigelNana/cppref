These [deduction guides](/docs/cpp/language/templates/ctad) are provided for `lazy_split_view` to allow deduction from a range and a delimiter.

{/* source:cpp-ranges-lazy-split-view-deduction-guides:0002 */}
1. 1) The delimiter is a range of elements.

{/* source:cpp-ranges-lazy-split-view-deduction-guides:0003 */}
2. 2) The delimiter is a single element.

### Example

{/* source:cpp-ranges-lazy-split-view-deduction-guides:0004 */}
```cpp
#include <ranges>
#include <string_view>
#include <type_traits>
using std::operator""sv;
 
int main()
{
    std::ranges::lazy_split_view w1{"a::b::c"sv, "::"sv};
    // type of w1 is lazy_split_view<string_view, string_view>:
    static_assert(std::is_same_v<
        decltype(w1),
        std::ranges::lazy_split_view<
            std::basic_string_view<char, std::char_traits<char>>,
            std::basic_string_view<char, std::char_traits<char>>>>);
 
    std::ranges::lazy_split_view w2{"x,y,z"sv, ','};
    // type of w2 is lazy_split_view<string_view, single_view<char>>:
    static_assert(std::is_same_v<
        decltype(w2),
        std::ranges::lazy_split_view<
            std::basic_string_view<char, std::char_traits<char>>,
            std::ranges::single_view<char>>>);
}
```
