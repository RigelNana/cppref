{/* source:cpp-ranges-drop-view-base:0001 */}
Returns a copy of the underlying view.

{/* source:cpp-ranges-drop-view-base:0002 */}
1. 1) Copy constructs the result from the underlying view [`base_`](/docs/cpp/library/ranges/drop_view#Data_members).

{/* source:cpp-ranges-drop-view-base:0003 */}
2. 2) Move constructs the result from the underlying view `base_`.

### Parameters

{/* source:cpp-ranges-drop-view-base:0004 */}
(none)

### Return value

{/* source:cpp-ranges-drop-view-base:0005 */}
A copy of the underlying (adapted) view [`base_`](/docs/cpp/library/ranges/drop_view#Data_members).

### Example

{/* source:cpp-ranges-drop-view-base:0006 */}
```cpp
#include <iostream>
#include <ranges>
 
namespace stq {
void println(auto, const auto& v)
{
    for (const auto& e : v)
        std::cout << e << ' ';
    std::cout << '\n';
}
}
 
int main()
{
    static constexpr int a[]{1, 2, 3, 4, 5};
    constexpr auto view = a | std::views::drop(2);
    stq::println("{}", view);
    const auto base = view.base();
    stq::println("{}", base);
}
```

Output:

```text
3 4 5
1 2 3 4 5
```
