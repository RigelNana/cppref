{/* source:cpp-ranges-drop-view:0001 */}
1. 1) A range adaptor consisting of elements of the underlying sequence, skipping the first *N* elements.

{/* source:cpp-ranges-drop-view:0002 */}
2. 2) [*RangeAdaptorObject*](/docs/cpp/library/named_req/RangeAdaptorObject). Given `T` is `std::remove_cvref_t<decltype((e))>` and `D` is `ranges::range_difference_t<decltype((e))>`), the expression `views::drop(e, f)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

   `((void)f,` [decay-copy](/docs/cpp/library/standard_library/decay-copy)`(e))`, if `T` is a [`ranges::empty_view`](/docs/cpp/library/ranges/empty_view), except that the evaluations of `e` and `f` are indeterminately sequenced; otherwise, `T(ranges::begin(e) + inc, ranges::end(e), /*to-unsigned-like*/(ranges::distance(e) - inc))`, if `T` is a specialization of `ranges::subrange` that models both [`random_access_range`](/docs/cpp/library/ranges/random_access_range) and [`sized_range`](/docs/cpp/library/ranges/sized_range), and `T` needs to store the size (see [ranges::subrange::subrange()](/docs/cpp/library/ranges/subrange/subrange) for details), where `inc` is `std::min<D>(ranges::distance(e), f)`; otherwise, `U(ranges::begin(e) + inc, ranges::end(e))`, if `T` is a specialization of `std::span`, [`std::basic_string_view`](/docs/cpp/library/string/basic_string_view), `ranges::iota_view`, or `ranges::subrange` that models both [`random_access_range`](/docs/cpp/library/ranges/random_access_range) and [`sized_range`](/docs/cpp/library/ranges/sized_range), where `U` is `std::span<typename T::element_type>`, if `T` is a specialization of `std::span`; `T` otherwise;

   <Revision since="C++23">
   otherwise, if `T` is a specialization of [`ranges::repeat_view`](/docs/cpp/library/ranges/repeat_view): `views::repeat(*e.value_, ranges::distance(e) - inc)`, if `T` models [`sized_range`](/docs/cpp/library/ranges/sized_range); in such case `e` is evaluated only once; `((void)e, auto(f))` otherwise, except that the evaluations of `e` and `f` are indeterminately sequenced;
   </Revision>

   otherwise, `drop_view(e, f)`.

   In all cases, `decltype((f))` must model `std::convertible_to<D>`.

{/* source:cpp-ranges-drop-view:0003 */}
`drop_view` models the concepts [`contiguous_range`](/docs/cpp/library/ranges/contiguous_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`input_range`](/docs/cpp/library/ranges/input_range), [`common_range`](/docs/cpp/library/ranges/common_range), and [`sized_range`](/docs/cpp/library/ranges/sized_range) when the underlying view `V` models respective concepts.

This specialization of [`ranges::enable_borrowed_range`](/docs/cpp/library/ranges/borrowed_range) makes `drop_view` satisfy [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range) when the underlying view satisfies it.

### Example

{/* source:cpp-ranges-drop-view:0008 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    const auto nums = {1, 2, 3, 4, 5, 6, 7};
 
    std::cout << "drop " << 2 << ": ";
    for (int i : std::ranges::drop_view{nums, 2})
        std::cout << i << ' ';
    std::cout << '\n';
 
    std::cout << "drop " << 3 << ": ";
    for (int i : nums | std::views::drop(3))
        std::cout << i << ' ';
    std::cout << '\n';
 
    std::cout << "drop " << 4 << ": ";
    for (int i : std::views::iota(1, 8) | std::views::drop(4))
        std::cout << i << ' ';
    std::cout << '\n';
 
    // Note that dropping more than the number of elements is OK:
    for (int dp : {5, 6, 7, 890, 100500})
    {
        std::cout << "drop " << dp << ": ";
        for (int i : std::views::iota(1, 8) | std::views::drop(dp))
            std::cout << i << ' ';
        std::cout << '\n';
    }
}
```

Output:

```text
drop 2: 3 4 5 6 7
drop 3: 4 5 6 7
drop 4: 5 6 7
drop 5: 6 7
drop 6: 7
drop 7:
drop 890: 
drop 100500:
```
