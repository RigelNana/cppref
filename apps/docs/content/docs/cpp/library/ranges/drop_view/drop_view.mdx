Constructs a `drop_view`.

{/* source:cpp-ranges-drop-view-drop-view:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying view [`base_`](/docs/cpp/library/ranges/drop_view#Data_members) and initializes the count [`count_`](/docs/cpp/library/ranges/drop_view#Data_members) to `0`. After construction, [`base()`](/docs/cpp/library/ranges/drop_view/base) returns a copy of `V()` and [`size()`](/docs/cpp/library/ranges/drop_view/size) equals to the size of the underlying view.

{/* source:cpp-ranges-drop-view-drop-view:0003 */}
2. 2) Initializes the underlying view `base_` with `std::move(base)` and the count `count_` with `count`. After construction, [`base()`](/docs/cpp/library/ranges/drop_view/base) returns a copy of `base` and [`size()`](/docs/cpp/library/ranges/drop_view/size) returns `ranges::size(base) - count` if the size of `base` is not less than `count`, or `0` otherwise.

### Example

{/* source:cpp-ranges-drop-view-drop-view:0005 */}
```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <iterator>
#include <ranges>
 
int main()
{
    constexpr std::array hi{'H', 'e', 'l', 'l', 'o', ',',
                            ' ', 'C', '+', '+', '2', '0'};
 
    std::ranges::for_each(hi, [](const char c){ std::cout << c; });
    std::cout << '\n';
 
    constexpr auto n = std::distance(hi.cbegin(), std::ranges::find(hi, 'C'));
 
    auto cxx = std::ranges::drop_view{hi, n};
 
    std::ranges::for_each(cxx, [](const char c){ std::cout << c; });
    std::cout << '\n';
}
```

Output:

```text
Hello, C++20
C++20
```
