{/* source:cpp-ranges-drop-view-size:0001 */}
Returns the number of elements.

{/* source:cpp-ranges-drop-view-size:0002 */}
Let [`base_`](/docs/cpp/library/ranges/drop_view#Data_members) be the underlying view, [`count_`](/docs/cpp/library/ranges/drop_view#Data_members) be the stored count (the number passed to the constructor, or `0` if `*this` is default constructed). Equivalent to:

{/* source:cpp-ranges-drop-view-size:0003 */}
```cpp
const auto s = ranges::size(base_);
const auto c = static_cast<decltype(s)>(count_);
return s < c ? 0 : s - c;
```

### Parameters

{/* source:cpp-ranges-drop-view-size:0004 */}
(none)

### Return value

{/* source:cpp-ranges-drop-view-size:0005 */}
The number of elements.

### Example

{/* source:cpp-ranges-drop-view-size:0006 */}
```cpp
#include <array>
#include <ranges>
 
int main()
{
    constexpr std::array a{42, 43, 44};
    static_assert(std::ranges::drop_view{std::views::all(a), 0}.size() == 3);
    static_assert(std::ranges::drop_view{std::views::all(a), 1}.size() == 2);
    static_assert(std::ranges::drop_view{std::views::all(a), 2}.size() == 1);
    static_assert(std::ranges::drop_view{std::views::all(a), 3}.size() == 0);
    static_assert(std::ranges::drop_view{std::views::all(a), 4}.size() == 0);
}
```
