Returns a sentinel or an iterator representing the end of the `drop_view`.

{/* source:cpp-ranges-drop-view-end:0002 */}
Effectively returns `ranges::end(base_)`, where [`base_`](/docs/cpp/library/ranges/drop_view#Data_members) is the underlying view.

### Parameters

{/* source:cpp-ranges-drop-view-end:0003 */}
(none)

### Return value

{/* source:cpp-ranges-drop-view-end:0004 */}
A sentinel or an iterator representing the end of the view.

### Example

{/* source:cpp-ranges-drop-view-end:0005 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <ranges>
 
int main()
{
    namespace ranges = std::ranges;
    constexpr char url[]{"https://cppreference.com"};
 
    const auto p = std::distance(ranges::begin(url), ranges::find(url, '/'));
    auto site = ranges::drop_view{url, p + 2}; // drop the prefix "https://"
 
    for (auto it = site.begin(); it != site.end(); ++it)
        std::cout << *it;
    std::cout << '\n';
}
```

Output:

```text
cppreference.com
```
