{/* source:cpp-ranges:0000 */}
The ranges library is an extension and generalization of the algorithms and iterator libraries that makes them more powerful by making them composable and less error-prone.

{/* source:cpp-ranges:0001 */}
The library creates and manipulates range *views*, lightweight objects that indirectly represent iterable sequences (*ranges*). Ranges are an abstraction on top of

{/* source:cpp-ranges:0002 */}
- `[begin, end)` – iterator pairs, e.g. ranges made by implicit conversion from containers. All algorithms that take iterator pairs now have overloads that accept ranges (e.g. [`ranges::sort`](/docs/cpp/library/algorithm/ranges/sort))
- `begin + [0, size)` – counted sequences, e.g. range returned by [`views::counted`](/docs/cpp/library/ranges/counted_view)
- `[begin, predicate)` – conditionally-terminated sequences, e.g. range returned by [`views::take_while`](/docs/cpp/library/ranges/take_while_view)
- `[begin, ..)` – unbounded sequences, e.g. range returned by [`views::iota`](/docs/cpp/library/ranges/iota_view)

{/* source:cpp-ranges:0003 */}
The ranges library includes [range algorithms](/docs/cpp/library/algorithm/ranges), which are applied to ranges eagerly, and [range adaptors](/docs/cpp/library/ranges#Range_adaptors), which are applied to views lazily. Adaptors can be composed into pipelines, so that their actions take place as the view is iterated.

### Example

{/* source:cpp-ranges:0033 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    auto const ints = {0, 1, 2, 3, 4, 5};
    auto even = [](int i) { return 0 == i % 2; };
    auto square = [](int i) { return i * i; };
 
    // the "pipe" syntax of composing the views:
    for (int i : ints | std::views::filter(even) | std::views::transform(square))
        std::cout << i << ' ';
 
    std::cout << '\n';
 
    // a traditional "functional" composing syntax:
    for (int i : std::views::transform(std::views::filter(ints, even), square))
        std::cout << i << ' ';
}
```

Output:

```text
0 4 16
0 4 16
```
