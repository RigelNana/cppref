Constructs a `subrange`.

{/* source:cpp-ranges-subrange-subrange:0002 */}
For the definitions of `/*make-unsigned-like-t*/` and `/*different-from*/`, see [`make-unsigned-like-t`](/docs/cpp/library/ranges#make-unsigned-like-t) and [`different-from`](/docs/cpp/library/ranges#different-from) respectively.

{/* source:cpp-ranges-subrange-subrange:0004 */}
2. 2) If `[i, s)` is not a [valid range](/docs/cpp/library/iterator#Ranges), the behavior is undefined.

{/* source:cpp-ranges-subrange-subrange:0005 */}
3. 3) If any of the following conditions is satisfied, the behavior is undefined:
   - `[i, s)` is not a valid range.
   - `n ==` [`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(ranges::distance(i, s))` is `false`.
