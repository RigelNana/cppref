{/* source:cpp-ranges-subrange-get:0001 */}
Provides [structured binding](/docs/cpp/language/declarations/structured_binding) support.

{/* source:cpp-ranges-subrange-get:0002 */}
1. 1) Obtains the iterator or sentinel from a `subrange` lvalue (or a const rvalue) when `N == 0` or `N == 1`, respectively.

{/* source:cpp-ranges-subrange-get:0003 */}
2. 2) Same as (1), except that it takes a non-const `subrange` rvalue.

{/* source:cpp-ranges-subrange-get:0004 */}
3. 3) Overloads (1,2) are imported into `namespace std`, which simplifies their usage and makes every `subrange` with a copyable iterator a [`pair-like`](/docs/cpp/library/utility/tuple/tuple-like) type.

### Parameters

{/* source:cpp-ranges-subrange-get:0005 */}
<ParameterList>
  <Parameter name="r">a subrange</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-subrange-get:0006 */}
1,2) If `N` is `0`, returns `r.begin()`. Otherwise (`N` is `1`), returns `r.end()`.

### Example

{/* source:cpp-ranges-subrange-get:0007 */}
```cpp
#include <array>
#include <iostream>
#include <iterator>
#include <ranges>

int main()
{
    std::array a{1, -2, 3, -4};

    std::ranges::subrange sub_a{std::next(a.begin()), std::prev(a.end())};
    std::cout << *std::ranges::get<0>(sub_a) << ' '   // == *(begin(a) + 1)
              << *std::ranges::get<1>(sub_a) << '\n'; // == *(end(a) - 1)

    *std::get<0>(sub_a) = 42; // OK
//  *std::get<2>(sub_a) = 13; // Error: index can only be 0 or 1
}
```

Output:

```text
-2 -4
```
