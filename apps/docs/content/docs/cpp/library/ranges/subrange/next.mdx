{/* source:cpp-ranges-subrange-next:0001 */}
Returns a `subrange` whose [`begin_`](/docs/cpp/library/ranges/subrange#begin) is incremented (or decremented if `n` is negative). The actual increment (or decrement) operation is performed by [`advance()`](/docs/cpp/library/ranges/subrange/advance).

{/* source:cpp-ranges-subrange-next:0002 */}
1. 1) Returns a copy of `*this`.

{/* source:cpp-ranges-subrange-next:0003 */}
Equivalent to: `auto tmp = *this;` `tmp.advance(n);` `return tmp;`

{/* source:cpp-ranges-subrange-next:0004 */}
2. 2) Returns a `subrange` moved from `*this`.

{/* source:cpp-ranges-subrange-next:0005 */}
Equivalent to: `advance(n);` `return std::move(*this);`

### Parameter

{/* source:cpp-ranges-subrange-next:0006 */}
<ParameterList>
  <Parameter name="n">number of maximal increments of the iterator</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-subrange-next:0007 */}
As described above.

### Notes

{/* source:cpp-ranges-subrange-next:0008 */}
The difference between this function and [`advance()`](/docs/cpp/library/ranges/subrange/advance) is that the latter performs the increment (or decrement) in place.

### Example

{/* source:cpp-ranges-subrange-next:0009 */}
```cpp
#include <array>
#include <iterator>
#include <print>
#include <ranges>

int main()
{
    std::array arr{1, 2, 3, 4, 5, 6, 7};
    std::ranges::subrange sub{std::next(arr.begin(), 2), std::prev(arr.end(), 2)};
    std::println("1) sub: {}", sub);
    std::println("2) sub: {}", sub.next());
    std::println("3) sub: {}", sub.next(2));
}
```

Output:

```text
1) sub: [3, 4, 5]
2) sub: [4, 5]
3) sub: [5]
```
