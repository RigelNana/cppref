{/* source:cpp-ranges-subrange:0001 */}
1. 1) The `subrange` class template combines together an iterator and a sentinel into a single [`view`](/docs/cpp/library/ranges/view). It models [`sized_range`](/docs/cpp/library/ranges/sized_range) whenever the final template parameter is `subrange_kind::sized` (which happens when `std::sized_sentinel_for<S, I>` is satisfied or when `size` is passed explicitly as a constructor argument).

{/* source:cpp-ranges-subrange:0002 */}
2. 2) Determines whether `From` is convertible to `To` without [qualification conversions](/docs/cpp/language/expressions/implicit_cast#Qualification_conversions). Equivalent to:

   ```cpp
   template<class From, class To>
   concept /*uses-nonqualification-pointer-conversion*/ =
       std::is_pointer_v<From> && std::is_pointer_v<To> &&
           !std::convertible_to<std::remove_pointer_t<From>(*)[],
                                std::remove_pointer_t<To>(*)[]>;
   ```

{/* source:cpp-ranges-subrange:0003 */}
3. 3) Determines whether `From` is convertible to `To` without derived-to-base conversion:

   ```cpp
   template<class From, class To>
   concept /*convertible-to-non-slicing*/ =
       std::convertible_to<From, To> &&
           !/*uses-nonqualification-pointer-conversion*/
               <std::decay_t<From>, std::decay_t<To>>;
   ```

### Example

{/* source:cpp-ranges-subrange:0010 */}
```cpp
#include <map>
#include <print>
#include <ranges>

void make_uppercase(char& v)
{
    v += 'A' - 'a';
}

void uppercase_transform(std::multimap<int, char>& m, int k)
{
    auto [first, last] = m.equal_range(k);
    for (auto& [_, v] : std::ranges::subrange(first, last))
        make_uppercase(v);
}

int main()
{
    std::multimap<int, char> mm{{4, 'a'}, {3, '-'}, {4, 'b'}, {5, '-'}, {4, 'c'}};
    std::println("Before: {}", mm);
    uppercase_transform(mm, 4);
    std::println("After:  {}", mm);
}
```

Output:

```text
Before: {3: '-', 4: 'a', 4: 'b', 4: 'c', 5: '-'}
After:  {3: '-', 4: 'A', 4: 'B', 4: 'C', 5: '-'}
```
