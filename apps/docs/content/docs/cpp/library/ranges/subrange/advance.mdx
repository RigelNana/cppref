{/* source:cpp-ranges-subrange-advance:0001 */}
Increments or decrements [`begin_`](/docs/cpp/library/ranges/subrange#begin):

{/* source:cpp-ranges-subrange-advance:0002 */}
- If `I` models [`bidirectional_iterator`](/docs/cpp/library/iterator/bidirectional_iterator) and `n < 0` is `true`, decrements [`begin_`](/docs/cpp/library/ranges/subrange#begin) by `-n` elements.

{/* source:cpp-ranges-subrange-advance:0003 */}
Equivalent to: `ranges::advance(`[`begin_`](/docs/cpp/library/ranges/subrange#begin)`, n);` `if constexpr (`[`StoreSize`](/docs/cpp/library/ranges/subrange#StoreSize)`)`[`size_`](/docs/cpp/library/ranges/subrange#size)` +=` [`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(-n);` `return *this;`

{/* source:cpp-ranges-subrange-advance:0004 */}
- Otherwise, increments [`begin_`](/docs/cpp/library/ranges/subrange#begin) by `n` elements, or until [`end_`](/docs/cpp/library/ranges/subrange#end) is reached.

{/* source:cpp-ranges-subrange-advance:0005 */}
Equivalent to: `auto d = n - ranges::advance(`[`begin_`](/docs/cpp/library/ranges/subrange#begin)`, n,`[`end_`](/docs/cpp/library/ranges/subrange#end)`);` `if constexpr (`[`StoreSize`](/docs/cpp/library/ranges/subrange#StoreSize)`)`[`size_`](/docs/cpp/library/ranges/subrange#size)` -=` [`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(d);` `return *this;`

{/* source:cpp-ranges-subrange-advance:0006 */}
According to the preconditions of [`ranges::advance`](/docs/cpp/library/iterator/ranges/advance), if `n < 0` is `true` and [`begin_`](/docs/cpp/library/ranges/subrange#begin) cannot be decremented by `-n` elements, the behavior is undefined.

### Parameters

{/* source:cpp-ranges-subrange-advance:0007 */}
<ParameterList>
  <Parameter name="n">number of maximal increments of the iterator</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-subrange-advance:0008 */}
`*this`

### Example

{/* source:cpp-ranges-subrange-advance:0009 */}
```cpp
#include <algorithm>
#include <array>
#include <iostream>
#include <iterator>
#include <ranges>

void print(auto name, auto const sub)
{
    std::cout << name << ".size() == " << sub.size() << "; { ";
    std::ranges::for_each(sub, [](int x) { std::cout << x << ' '; });
    std::cout << "}\n";
};

int main()
{
    std::array arr{1, 2, 3, 4, 5, 6, 7};
    std::ranges::subrange sub{std::next(arr.begin()), std::prev(arr.end())};
    print("1) sub", sub);
    print("2) sub", sub.advance(3));
    print("3) sub", sub.advance(-2));
}
```

Output:

```text
1) sub.size() == 5; { 2 3 4 5 6 }
2) sub.size() == 2; { 5 6 }
3) sub.size() == 4; { 3 4 5 6 }
```
