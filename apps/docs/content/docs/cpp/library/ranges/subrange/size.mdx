{/* source:cpp-ranges-subrange-size:0001 */}
Obtains the number of elements in the `subrange`:

{/* source:cpp-ranges-subrange-size:0002 */}
- If [`StoreSize`](/docs/cpp/library/ranges/subrange#StoreSize) is `true`, returns [`size_`](/docs/cpp/library/ranges/subrange#size). Otherwise, returns [`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)([`end_`](/docs/cpp/library/ranges/subrange#end) `-` [`begin_`](/docs/cpp/library/ranges/subrange#begin)).

{/* source:cpp-ranges-subrange-size:0003 */}
For the definition of `/*make-unsigned-like-t*/`, see [`make-unsigned-like-t`](/docs/cpp/library/ranges#make-unsigned-like-t).

### Return value

{/* source:cpp-ranges-subrange-size:0004 */}
As described above.

### Example

{/* source:cpp-ranges-subrange-size:0005 */}
```cpp
#include <functional>
#include <iostream>
#include <ranges>
#include <utility>

int main()
{
    const auto v = {2, 2, 2, 7, 1, 1, 1, 1, 8, 2, 2, 2, 2, 2};

    // the value type of views::chunk_by is the ranges::subrange

    auto to_pair = [](auto sub) { return std::make_pair(sub[0], sub.size()); };
                                                                 /* ^^^^ */
    auto pairs = v | std::views::chunk_by(std::equal_to{})
                   | std::views::transform(to_pair);

    for (auto x : pairs bitor std::views::keys)
        std::cout << x << ' ';
    std::cout << '\n';
    for (auto x : pairs bitor std::views::values)
        std::cout << x << ' ';
    std::cout << '\n';
}
```

Output:

```text
2 7 1 8 2
3 1 4 1 5
```
