These [deduction guides](/docs/cpp/language/templates/ctad) are provided for [`std::ranges::subrange`](/docs/cpp/library/ranges/subrange).

{/* source:cpp-ranges-subrange-deduction-guides:0002 */}
1. 1) Deduces the template arguments from the type of iterator and sentinel. The `subrange` is sized if `std::sized_sentinel_for<S, I>` is satisfied, as determined by the default template argument.

{/* source:cpp-ranges-subrange-deduction-guides:0003 */}
2. 2) Deduces the template arguments from the type of iterator and sentinel, while the size of range is specified. The `subrange` is always sized.

{/* source:cpp-ranges-subrange-deduction-guides:0004 */}
3. 3) Deduces the template arguments from the type of range. The `subrange` is sized if the size can be obtained from the range or its iterator and sentinel.

{/* source:cpp-ranges-subrange-deduction-guides:0005 */}
4. 4) Deduces the template arguments from the type of range, while the size of range is specified. The `subrange` is always sized.

{/* source:cpp-ranges-subrange-deduction-guides:0006 */}
For the definition of `/* make-unsigned-like-t */`, see [`make-unsigned-like-t`](/docs/cpp/library/ranges#make-unsigned-like-t).

### Notes

{/* source:cpp-ranges-subrange-deduction-guides:0007 */}
While constructing the `subrange` object,

{/* source:cpp-ranges-subrange-deduction-guides:0008 */}
- for (1,2), the behavior is undefined if the iterator-sentinel pair does not denote a valid range,
- for (2,4), the behavior is undefined if the given size is not equal to the size of the range.
