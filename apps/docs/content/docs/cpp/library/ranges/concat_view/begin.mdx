Returns an [`iterator`](/docs/cpp/library/ranges/concat_view/iterator) to the beginning of the [`concat_view`](/docs/cpp/library/ranges/concat_view).

{/* source:cpp-ranges-concat-view-begin:0003 */}
2) Equivalent to [`iterator`](/docs/cpp/library/ranges/concat_view/iterator)`<true> it(this, std::in_place_index<0>, ranges::begin(std::get<0>([`views_`](/docs/cpp/library/ranges/concat_view#views))); it.template [`satisfy`](/docs/cpp/library/ranges/concat_view/iterator/helpers#satisfy)`\<0>(); return it;`.

### Return value

{/* source:cpp-ranges-concat-view-begin:0004 */}
As specified above.

### Example

{/* source:cpp-ranges-concat-view-begin:0005 */}
The preliminary version can be checked out on [Compiler Explorer](https://godbolt.org/z/ffoo7o3f5).

```cpp
#include <ranges>
#include <string_view>
using namespace std::literals;
 
int main()
{
    static constexpr auto c = {"🐱", "🐶"};
    static constexpr auto a = {"🤡"sv};
    static constexpr auto t = {"💚"sv};
    static constexpr auto cat{std::views::concat(c, a, t)};
    static_assert(*cat.begin() == "\U0001F431" and
                  cat.begin()[1] == "🐶" and
                  *(cat.begin() + 2) == "\N{CLOWN FACE}");
}
```
