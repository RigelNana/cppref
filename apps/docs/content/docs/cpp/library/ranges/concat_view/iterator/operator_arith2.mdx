{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0001 */}
Increments or decrements the [`iterator`](/docs/cpp/library/ranges/concat_view/iterator/iterator).

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0002 */}
1) Equivalent to `auto t = it; t += n; return t;`.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0003 */}
2) Equivalent to `return it + n;`.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0004 */}
3) Equivalent to `auto t = it; t -= n; return t;`.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0005 */}
4) Let `Ix` be `x.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.index()` and `Iy` be `y.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.index()`: if `Ix > Iy` is `true`, equivalent to `difference_type result = ranges::distance(y.`[`get-iter`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-iter)`<Iy>(), y.`[`get-end`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-end)`<Iy>()); for (std::size_t I = Iy + 1; I < Ix; I++) result += ranges::distance(x.`[`get-view`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-view)`<I>()); return result + ranges::distance(x.`[`get-begin`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-begin)`<Ix>(), x.`[`get-iter`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-iter)`<Ix>());`. Otherwise, if `Ix < Iy` is `true`, equivalent to `return -(y - x);`. Otherwise, equivalent to `return x.`[`get-iter`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-iter)`<Ix>() - y.`[`get-iter`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-iter)`<Iy>();`.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0006 */}
If `x.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.valueless_by_exception() || y.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.valueless_by_exception()` is `true`, the behavior is undefined.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0007 */}
5) Let `Ix` be `x.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.index()`, equivalent to `difference_type result = ranges::distance(x.`[`get-iter`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-iter)`<Ix>(), x.`[`get-end`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-end)`<Ix>()); for (std::size_t I = Ix + 1, count = sizeof...(Views); I < count; I++) result += ranges::distance(x.`[`get-view`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-view)`<I>()); return -result;`.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0008 */}
Let `Fs` be the pack that consists of all elements of `Views` except the first element, the expression in the `requires` clause is equivalent to `(std::sized_sentinel_for<ranges::sentinel_t<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Views>>, ranges::iterator_t<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Views>>> && ...) && (ranges::sized_range<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Fs>> && ...)`.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0009 */}
If `x.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.valueless_by_exception()` is `true`, the behavior is undefined.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0010 */}
6) Equivalent to `return -(x - std::default_sentinel);`.

{/* source:cpp-ranges-concat-view-iterator-operator-arith2:0011 */}
Let `Fs` be the pack that consists of all elements of `Views` except the first element, the expression in the `requires` clause is equivalent to `(std::sized_sentinel_for<ranges::sentinel_t<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Views>>, ranges::iterator_t<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Views>>> && ...) && (ranges::sized_range<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Fs>> && ...)`.
