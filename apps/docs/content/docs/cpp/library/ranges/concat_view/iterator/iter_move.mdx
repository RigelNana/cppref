{/* source:cpp-ranges-concat-view-iterator-iter-move:0001 */}
Returns the result of applying [`ranges::iter_move`](/docs/cpp/library/iterator/ranges/iter_move) to the underlying iterator contained in [`it_`](/docs/cpp/library/ranges/concat_view/iterator#it).

{/* source:cpp-ranges-concat-view-iterator-iter-move:0002 */}
Let `Ref` be [`concat-rvalue-reference-t`](/docs/cpp/library/ranges/concat_view#concat-rvalue-reference-t)`<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Views>...>`. Equivalent to `return std::visit([](const auto& i) -> Ref { return ranges::iter_move(i); }, it.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`);`.

{/* source:cpp-ranges-concat-view-iterator-iter-move:0003 */}
If `it.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.valueless_by_exception()` is `true`, the behavior is undefined.

{/* source:cpp-ranges-concat-view-iterator-iter-move:0004 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `concat_view::iterator<Const>` is an associated class of the arguments.
