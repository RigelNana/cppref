{/* source:cpp-ranges-concat-view-iterator-operator-star:0001 */}
Returns a reference to the current element in the [`concat_view`](/docs/cpp/library/ranges/concat_view).

{/* source:cpp-ranges-concat-view-iterator-operator-star:0002 */}
Equivalent to `using reference = `[`concat-reference-t`](/docs/cpp/library/ranges/concat_view#concat-reference-t)`<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Views>...>; return std::visit([](auto&& it) -> reference { return *it; }, `[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`);`.

{/* source:cpp-ranges-concat-view-iterator-operator-star:0003 */}
If `it.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.valueless_by_exception()` is `true`, the behavior is undefined.

### Return value

{/* source:cpp-ranges-concat-view-iterator-operator-star:0004 */}
As described above.

### Notes

{/* source:cpp-ranges-concat-view-iterator-operator-star:0005 */}
`operator->` is not provided.
