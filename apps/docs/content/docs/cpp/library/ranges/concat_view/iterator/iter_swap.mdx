{/* source:cpp-ranges-concat-view-iterator-iter-swap:0001 */}
Swaps the objects pointed to by the underlying iterators of `x` and `y`. Equivalent to [`std::visit`](/docs/cpp/library/utility/variant/visit)`([&](const auto& it1, const auto& it2) { if constexpr (std::is_same_v<decltype(it1), decltype(it2)>) ranges::iter_swap(it1, it2); else ranges::swap(*x, *y); }, x.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`, y.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`);`.

{/* source:cpp-ranges-concat-view-iterator-iter-swap:0002 */}
The expression in the `requires` clause is equivalent to `std::swappable_with<std::iter_reference_t</*iterator*/>, std::iter_reference_t</*iterator*/>> && (... && std::indirectly_swappable<ranges::iterator_t<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Views>>>)`.

{/* source:cpp-ranges-concat-view-iterator-iter-swap:0003 */}
If `x.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.valueless_by_exception() || y.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.valueless_by_exception()` is `true`, the behavior is undefined.

{/* source:cpp-ranges-concat-view-iterator-iter-swap:0004 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `concat_view::iterator<Const>` is an associated class of the arguments.

### Exceptions

{/* source:cpp-ranges-concat-view-iterator-iter-swap:0006 */}
Let `its` be a pack of lvalues, where each value is of the corresponding type in `const ranges::iterator_t<`[`maybe-const`](/docs/cpp/library/ranges#maybe-const)`<Const, Views>>`.

{/* source:cpp-ranges-concat-view-iterator-iter-swap:0007 */}
