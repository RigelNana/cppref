{/* source:cpp-ranges-concat-view-iterator-operator-arith:0001 */}
Increments or decrements the [`iterator`](/docs/cpp/library/ranges/concat_view/iterator).

{/* source:cpp-ranges-concat-view-iterator-operator-arith:0002 */}
| Overload | Equivalent to (let `I` be `it.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.index()`) |
| --- | --- |
| (1) | `++`[`get-iter`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-iter)`<I>(); `[`satisfy`](/docs/cpp/library/ranges/concat_view/iterator/helpers#satisfy)`<I>(); return *this;` |
| (2) | `++*this;` |
| (3) | `auto tmp = *this; ++*this; return tmp;` |
| (4) | [`prev`](/docs/cpp/library/ranges/concat_view/iterator/helpers#prev)`<I>(); return *this;` |
| (5) | `auto tmp = *this; --*this; return tmp;` |
| (6) | `auto offset = `[`get-iter`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-iter)`<I>() - `[`get-begin`](/docs/cpp/library/ranges/concat_view/iterator/helpers#get-begin)`<I>(); if (n > 0) `[`advance-fwd`](/docs/cpp/library/ranges/concat_view/iterator/helpers#advance-fwd)`<I>(offset, n); else if (n < 0) `[`advance-bwd`](/docs/cpp/library/ranges/concat_view/iterator/helpers#advance-bwd)`<I>(offset, -n); return *this;` |
| (7) | `*this += -n; return *this;` |

{/* source:cpp-ranges-concat-view-iterator-operator-arith:0003 */}
If `it.`[`it_`](/docs/cpp/library/ranges/concat_view/iterator#it)`.valueless_by_exception()` is `true`, the behavior is undefined.
