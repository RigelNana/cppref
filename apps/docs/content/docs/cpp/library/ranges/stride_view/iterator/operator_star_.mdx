{/* source:cpp-ranges-stride-view-iterator-operator-star:0001 */}
Returns the elements into `V` the underlying iterator [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) points to.

{/* source:cpp-ranges-stride-view-iterator-operator-star:0002 */}
Equivalent to: `return *current_;`.

### Parameters

{/* source:cpp-ranges-stride-view-iterator-operator-star:0003 */}
(none)

### Return value

{/* source:cpp-ranges-stride-view-iterator-operator-star:0004 */}
The current element.

### Notes

{/* source:cpp-ranges-stride-view-iterator-operator-star:0005 */}
`operator->` is not provided.

### Example

{/* source:cpp-ranges-stride-view-iterator-operator-star:0006 */}
```cpp
#include <ranges>
 
int main()
{
    constexpr static auto v = {'a', 'b', 'c', 'd', 'e'};
    constexpr auto view{v | std::views::stride(2)};
    constexpr auto iter{view.begin() + 1};
    static_assert(*iter == 'c');
    static_assert(*(view.begin() + 2) == 'e');
}
```
