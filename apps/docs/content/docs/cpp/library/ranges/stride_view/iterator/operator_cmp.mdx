{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0001 */}
Compares the underlying iterators/sentinels.

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0002 */}
Let [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) be the underlying iterator, and [`end_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) be the underlying sentinel.

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0003 */}
1. 1) Equivalent to `return x.current_ == x.end_;`.

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0004 */}
2. 2) Equivalent to `return x.current_ == y.current_;`.

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0005 */}
3. 3) Equivalent to `return x.current_ < y.current_;`.

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0006 */}
4. 4) Equivalent to `return y < x;`

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0007 */}
5. 5) Equivalent to `return !(y < x);`

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0008 */}
6. 6) Equivalent to `return !(x < y);`

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0009 */}
7. 7) Equivalent to `return x.current_ <=> y.current_;`.

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0010 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::stride_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-stride-view-iterator-operator-cmp:0011 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
