{/* source:cpp-ranges-stride-view-size:0001 */}
Returns the number of elements.

{/* source:cpp-ranges-stride-view-size:0002 */}
Let [`base_`](/docs/cpp/library/ranges/stride_view#Data_members) be the underlying view and [`stride_`](/docs/cpp/library/ranges/stride_view#Data_members) be the stored stride value. Equivalent to:

{/* source:cpp-ranges-stride-view-size:0003 */}
```cpp
return /*to-unsigned-like*/(/*div-ceil*/(ranges::distance(base_), stride_));
```

### Parameters

{/* source:cpp-ranges-stride-view-size:0004 */}
(none)

### Return value

{/* source:cpp-ranges-stride-view-size:0005 */}
The number of elements. The returned value is calculated as if by expression

{/* source:cpp-ranges-stride-view-size:0006 */}
`(ranges::size(base_) / stride_) + ((ranges::size(base_) % stride_ ? 1 : 0)`.

### Example

{/* source:cpp-ranges-stride-view-size:0007 */}
```cpp
#include <forward_list>
#include <ranges>
 
int main()
{
    namespace vs = std::views;
    constexpr static auto v = {1, 2, 3, 4, 5};
    static_assert
    (
        vs::stride(v, 1).size() == 5 and
        vs::stride(v, 2).size() == 3 and
        vs::stride(v, 3).size() == 2 and
        vs::stride(v, 4).size() == 2 and
        vs::stride(v, 5).size() == 1 and
        vs::stride(v, 6).size() == 1
    );
 
    std::forward_list list{v};
//  auto s = vs::stride(list, 2).size(); // Error: not a sized_range
}
```
