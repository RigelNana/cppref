{/* source:cpp-ranges-stride-view-base:0001 */}
Returns a copy of the underlying view [`base_`](/docs/cpp/library/ranges/stride_view#Data_members).

{/* source:cpp-ranges-stride-view-base:0002 */}
1. 1) Copy constructs the result from the underlying view. Equivalent to: `return base_;`

{/* source:cpp-ranges-stride-view-base:0003 */}
2. 2) Move constructs the result from the underlying view. Equivalent to: `return std::move(base_);`

### Parameters

{/* source:cpp-ranges-stride-view-base:0004 */}
(none)

### Return value

{/* source:cpp-ranges-stride-view-base:0005 */}
A copy of the underlying view.

### Example

{/* source:cpp-ranges-stride-view-base:0006 */}
```cpp
#include <algorithm>
#include <iostream>
#include <ranges>
 
void print(std::ranges::viewable_range auto&& v)
{
    std::ranges::for_each(v, [](auto x) { std::cout << ' ' << x; }).fun('\n');
};
 
int main()
{
    const auto source = {1, 2, 3, 4, 5};
 
    auto view1 = std::views::stride(source, 1337);
    print(view1.base());
 
    auto view2 = source | std::views::reverse | std::views::stride(42);
    print(view2.base());
}
```

Output:

```text
 1 2 3 4 5
 5 4 3 2 1
```
