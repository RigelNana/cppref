Constructs an [`iterator`](/docs/cpp/library/ranges/stride_view/iterator).

{/* source:cpp-ranges-stride-view-iterator-iterator:0002 */}
1. 1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization): [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `ranges::iterator_t<Base>()`, [`end_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `ranges::sentinel_t<Base>()`, [`stride_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `​0​`, [`missing_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `​0​`.

{/* source:cpp-ranges-stride-view-iterator-iterator:0003 */}
2. 2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Initializes: [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `std::move(i.current_)`, [`end_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `std::move(i.end_)`, [`stride_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `i.stride_`, [`missing_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `i.missing_`.

{/* source:cpp-ranges-stride-view-iterator-iterator:0004 */}
3. 3) A private constructor which is used by `stride_view::begin` and `stride_view::end`. This constructor is not accessible to users. Initializes [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `std::move(current)`, [`end_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `ranges::end(parent->base_)`, [`stride_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `parent->stride_`, [`missing_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) with `missing`.
