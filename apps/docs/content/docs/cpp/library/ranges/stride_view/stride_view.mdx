{/* source:cpp-ranges-stride-view-stride-view:0001 */}
Constructs a `stride_view` initializing the underlying data members:

{/* source:cpp-ranges-stride-view-stride-view:0002 */}
- move construct the underlying view [`base_`](/docs/cpp/library/ranges/stride_view#Data_members) with `std::move(base)`,
- construct the [`stride_`](/docs/cpp/library/ranges/stride_view#Data_members) with `stride`.

{/* source:cpp-ranges-stride-view-stride-view:0003 */}
If `stride < 1` the behavior is undefined.

### Parameters

{/* source:cpp-ranges-stride-view-stride-view:0004 */}
<ParameterList>
  <Parameter name="base">the source view</Parameter>
  <Parameter name="stride">the stride value</Parameter>
</ParameterList>

### Example

{/* source:cpp-ranges-stride-view-stride-view:0005 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <ranges>
#include <string_view>
 
void print(std::string_view rem, auto v, std::string_view term = "\n")
{
    std::cout << rem << ": ";
    std::ranges::copy(v, std::ostream_iterator<int>(std::cout, " "));
    std::cout << term;
};
 
int main()
{
    auto source = std::views::iota(1, 10);
    print("source", source);
 
    for (int stride_value : std::views::iota(1, 6))
    {
        auto strided_view = std::views::stride(source, stride_value);
 
        print("stride", std::views::single(stride_value), "-> ");
        print("result", strided_view);
    }
}
```

Output:

```text
source: 1 2 3 4 5 6 7 8 9
stride: 1 -> result: 1 2 3 4 5 6 7 8 9
stride: 2 -> result: 1 3 5 7 9
stride: 3 -> result: 1 4 7
stride: 4 -> result: 1 5 9
stride: 5 -> result: 1 6
```
