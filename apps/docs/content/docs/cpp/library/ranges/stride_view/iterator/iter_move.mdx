{/* source:cpp-ranges-stride-view-iterator-iter-move:0001 */}
Returns the result of applying [`ranges::iter_move`](/docs/cpp/library/iterator/ranges/iter_move) to the underlying iterator [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members).

{/* source:cpp-ranges-stride-view-iterator-iter-move:0002 */}
Equivalent to `return ranges::iter_move(i.current_);`.

{/* source:cpp-ranges-stride-view-iterator-iter-move:0003 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `stride_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-stride-view-iterator-iter-move:0005 */}
The result of applying [`ranges::iter_move`](/docs/cpp/library/iterator/ranges/iter_move) to the stored iterator.
