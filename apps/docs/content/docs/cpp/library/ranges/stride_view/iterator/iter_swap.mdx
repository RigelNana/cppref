{/* source:cpp-ranges-stride-view-iterator-iter-swap:0001 */}
Swaps the objects pointed to by two underlying iterators (each denoted as [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members)).

{/* source:cpp-ranges-stride-view-iterator-iter-swap:0002 */}
Equivalent to `ranges::iter_swap(x.current_, y.current_);`.

{/* source:cpp-ranges-stride-view-iterator-iter-swap:0003 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `stride_view::iterator<Const>` is an associated class of the arguments.
