Returns a copy of the underlying stride object [`stride_`](/docs/cpp/library/ranges/stride_view#Data_members). Equivalent to `return stride_;`.

### Parameters

{/* source:cpp-ranges-stride-view-stride:0002 */}
(none)

### Return value

{/* source:cpp-ranges-stride-view-stride:0003 */}
The stride value.

### Example

{/* source:cpp-ranges-stride-view-stride:0004 */}
```cpp
#include <ranges>
 
int main()
{
    constexpr auto view = std::views::iota(1337)
                        | std::views::stride(42);
    static_assert(view.stride() == 42);
}
```
