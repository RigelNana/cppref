{/* source:cpp-ranges-stride-view-iterator-operator-arith2:0001 */}
Increments or decrements the [iterator](/docs/cpp/library/ranges/stride_view/iterator/iterator).

{/* source:cpp-ranges-stride-view-iterator-operator-arith2:0002 */}
Let [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members), [`end_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members), [`stride_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members), and [`missing_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) be the data members of the [iterator](/docs/cpp/library/ranges/stride_view/iterator/iterator).

{/* source:cpp-ranges-stride-view-iterator-operator-arith2:0003 */}
1. 1,2) Equivalent to `auto r = i; r += n; return r;`.

{/* source:cpp-ranges-stride-view-iterator-operator-arith2:0004 */}
2. 3) Equivalent to `auto r = i; r -= n; return r;`.

{/* source:cpp-ranges-stride-view-iterator-operator-arith2:0005 */}
3. 4) Let `N` be `x.current_ - y.current_`. Returns:
- `(N + x.missing_ - y.missing_) / x.stride_`, if [`Base`](/docs/cpp/library/ranges/stride_view/iterator#Member_types) models [`forward_range`](/docs/cpp/library/ranges/forward_range).
- `-/*div-ceil*/(-N, x.stride_)`, if `N < 0`.
- `/*div-ceil*/(N, x.stride_)` otherwise.

{/* source:cpp-ranges-stride-view-iterator-operator-arith2:0006 */}
4. 5) Equivalent to `return /*div-ceil*/(x.end_ - x.current_, x.stride_);`.

{/* source:cpp-ranges-stride-view-iterator-operator-arith2:0007 */}
5. 6) Equivalent to `return -(s - x);`.

{/* source:cpp-ranges-stride-view-iterator-operator-arith2:0008 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::stride_view::iterator<Const>` is an associated class of the arguments.
