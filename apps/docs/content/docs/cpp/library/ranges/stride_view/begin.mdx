{/* source:cpp-ranges-stride-view-begin:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/stride_view/iterator) to the first element of the `stride_view`.

{/* source:cpp-ranges-stride-view-begin:0002 */}
1. 1) Equivalent to `return iterator<false>(this, ranges::begin(base_));`.

{/* source:cpp-ranges-stride-view-begin:0003 */}
2. 2) Equivalent to `return iterator<true>(this, ranges::begin(base_));`.

{/* source:cpp-ranges-stride-view-begin:0004 */}
Overload (1) does not participate in overload resolution if `V` is a [simple view](/docs/cpp/library/ranges#Helper_concepts) (that is, if `V` and `const V` are views with the same iterator and sentinel types).

### Parameters

{/* source:cpp-ranges-stride-view-begin:0005 */}
(none)

### Return value

{/* source:cpp-ranges-stride-view-begin:0006 */}
[Iterator](https://en.cppreference.com/mwiki/index.php?title=cpp/ranges/stride_view/Iterator&action=edit&redlink=1) to the first element of the view.

### Example

{/* source:cpp-ranges-stride-view-begin:0007 */}
A link to test: [Compiler Explorer](https://godbolt.org/z/36zTEETx1).

```cpp
#include <print>
#include <ranges>
 
int main()
{
    constexpr auto v = {'A', 'B', 'C'};
    const auto x = v | std::views::stride(2);
    const auto y = v | std::views::reverse | std::views::stride(2);
    const auto z = v | std::views::stride(2) | std::views::reverse;
    std::println("{} {} {}", *x.begin(), *y.begin(), *z.begin());
}
```

Output:

```text
A C C
```
