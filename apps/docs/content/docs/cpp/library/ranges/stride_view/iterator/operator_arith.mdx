{/* source:cpp-ranges-stride-view-iterator-operator-arith:0001 */}
Increments or decrements the [iterator](/docs/cpp/library/ranges/stride_view/iterator/iterator).

{/* source:cpp-ranges-stride-view-iterator-operator-arith:0002 */}
Let [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members), [`end_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members), [`stride_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members), and [`missing_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) be the data members of the [iterator](/docs/cpp/library/ranges/stride_view/iterator/iterator).

{/* source:cpp-ranges-stride-view-iterator-operator-arith:0003 */}
1. 1) Equivalent to

```cpp
missing_ = ranges::advance(current_, stride_, end_);
return *this
```

Before the call [`current_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members) should not be equal to [`end_`](/docs/cpp/library/ranges/stride_view/iterator#Data_members).

{/* source:cpp-ranges-stride-view-iterator-operator-arith:0004 */}
2. 2) Equivalent to `++*this;`.

{/* source:cpp-ranges-stride-view-iterator-operator-arith:0005 */}
3. 3) Equivalent to `auto tmp = *this; ++*this; return tmp;`.

{/* source:cpp-ranges-stride-view-iterator-operator-arith:0006 */}
4. 4) Equivalent to

```cpp
ranges::advance(current_, missing_ - stride_);
missing_ = 0;
return *this;
```

{/* source:cpp-ranges-stride-view-iterator-operator-arith:0007 */}
5. 5) Equivalent to `auto tmp = *this; --*this; return tmp;`.

{/* source:cpp-ranges-stride-view-iterator-operator-arith:0008 */}
6. 6) Equivalent to

```cpp
if (n > 0)
{
    ranges::advance(current_, stride_ * (n - 1));
    missing_ = ranges::advance(current_, stride_, end_);
}
else if (n < 0)
{
    ranges::advance(current_, stride_ * n + missing_);
    missing_ = 0;
}
 
return *this;
```

If `n > 0`, then before the call to this function the `ranges::distance(current_, end_)` must be greater than `stride_ * (n - 1)`.

Note that if `n < 0`, the `ranges::distance(current_, end_)` is always greater than (non-positive) `stride_ * (n - 1)`.

{/* source:cpp-ranges-stride-view-iterator-operator-arith:0009 */}
7. 7) Equivalent to `return *this += -n;`.
