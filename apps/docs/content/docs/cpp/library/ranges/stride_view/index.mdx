{/* source:cpp-ranges-stride-view:0001 */}
1. 1) `stride_view` is a range adaptor that takes a [`view`](/docs/cpp/library/ranges/view) and a number `n` and produces a view, that consists of elements of the original view by advancing over `n` elements at a time. This means that each `m`<sup>th</sup> element of the produced view is `(n * i)`<sup>th</sup> element of the original view, for some non-negative index `i`. The elements of the original view, whose "index" is not a multiple of `n`, are not present in the produced view.

{/* source:cpp-ranges-stride-view:0002 */}
Let `S` be the size of the original view. Then the size of produced view is:

- `(S / n) + (S % n ? 1 : 0)`, if `S >= n`; otherwise,
- `1`, if `S > 0`; otherwise,
- `​0​`, and the resulting view is empty.

{/* source:cpp-ranges-stride-view:0003 */}
2. 2) The name `views::stride` denotes a [RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject). Given subexpressions `e` and `n`, the expression `views::stride(e, n)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `stride_view(e, n)`.

{/* source:cpp-ranges-stride-view:0004 */}
The `n` must be greater than `​0​`, otherwise the behavior is undefined.

{/* source:cpp-ranges-stride-view:0005 */}
`stride_view` always models [`input_range`](/docs/cpp/library/ranges/input_range), and models [`forward_range`](/docs/cpp/library/ranges/forward_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), and/or [`sized_range`](/docs/cpp/library/ranges/sized_range), if adapted [`view`](/docs/cpp/library/ranges/view) type `V` models the corresponding concept. `stride_view<V>` models [`common_range`](/docs/cpp/library/ranges/common_range) whenever the underlying view `V` does.

### Example

{/* source:cpp-ranges-stride-view:0012 */}
```cpp
#include <algorithm>
#include <iostream>
#include <ranges>
#include <string_view>
using namespace std::literals;
 
void print(std::ranges::viewable_range auto&& v, std::string_view separator = " ")
{
    for (auto const& x : v)
        std::cout << x << separator;
    std::cout << '\n';
}
 
int main()
{
    print(std::views::iota(1, 13) | std::views::stride(3));
    print(std::views::iota(1, 13) | std::views::stride(3) | std::views::reverse);
    print(std::views::iota(1, 13) | std::views::reverse | std::views::stride(3));
 
    print("0x0!133713337*x//42/A$@"sv | std::views::stride(0B11) |
          std::views::transform([](char O) -> char { return 0100 | O; }),
          "");
}
```

Output:

```text
1 4 7 10
10 7 4 1
12 9 6 3
password
```
