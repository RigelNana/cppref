{/* source:cpp-ranges-stride-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/stride_view/iterator) or a [sentinel](https://en.cppreference.com/mwiki/index.php?title=cpp/ranges/stride_view/sentinel&action=edit&redlink=1) representing the end of the [`stride_view`](/docs/cpp/library/ranges/stride_view).

{/* source:cpp-ranges-stride-view-end:0002 */}
Let [`base_`](/docs/cpp/library/ranges/stride_view#Data_members) and [`stride_`](/docs/cpp/library/ranges/stride_view#Data_members) be the underlying data members.

{/* source:cpp-ranges-stride-view-end:0003 */}
1. 1) Let `Const` be defined as `using Const = false;` and `Base` as `using Base = V;`.

{/* source:cpp-ranges-stride-view-end:0004 */}
2. 2) Let `Const` be defined as `using Const = true;` and `Base` as `using Base = const V;`.

{/* source:cpp-ranges-stride-view-end:0005 */}
Equivalent to:

{/* source:cpp-ranges-stride-view-end:0006 */}
```cpp
if constexpr (ranges::common_range<Base> &&
              ranges::sized_range<Base> &&
              ranges::forward_range<Base>)
{
    auto missing = (stride_ - ranges::distance(base_) % stride_) % stride_;
    return iterator<Const>(this, ranges::end(base_), missing);
}
else if constexpr (ranges::common_range<Base> &&
                   !ranges::bidirectional_range<Base>)
{
    return iterator<Const>(this, ranges::end(base_));
}
else
{
    return std::default_sentinel;
}
```

### Parameters

{/* source:cpp-ranges-stride-view-end:0007 */}
(none)

### Return value

{/* source:cpp-ranges-stride-view-end:0008 */}
An [`iterator`](/docs/cpp/library/ranges/stride_view/iterator) to the element following the last element, if the underlying view `V` models [`common_range`](/docs/cpp/library/ranges/common_range). Otherwise, the [`std::default_sentinel`](/docs/cpp/library/iterator/default_sentinel) which compares equal to the end iterator.

### Notes

{/* source:cpp-ranges-stride-view-end:0009 */}
`stride_view<V>` models [`common_range`](/docs/cpp/library/ranges/common_range) whenever the underlying view `V` does.
