{/* source:cpp-ranges-stride-view-iterator-operator-at:0001 */}
Returns an element at specified relative location.

{/* source:cpp-ranges-stride-view-iterator-operator-at:0002 */}
Equivalent to: `return *(*this + n);`.

### Parameters

{/* source:cpp-ranges-stride-view-iterator-operator-at:0003 */}
<ParameterList>
  <Parameter name="n">position relative to current location</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-stride-view-iterator-operator-at:0004 */}
The element at displacement `n` relative to the current location.

### Example

{/* source:cpp-ranges-stride-view-iterator-operator-at:0005 */}
```cpp
#include <ranges>
 
int main()
{
    constexpr static auto v = {'a', 'b', 'c', 'd', 'e'};
    constexpr auto view{v | std::views::stride(2)};
    constexpr auto iter{view.begin() + 1};
    static_assert(*iter == 'c');
    static_assert(iter[0] == 'c');
    static_assert(iter[1] == 'e');
}
```
