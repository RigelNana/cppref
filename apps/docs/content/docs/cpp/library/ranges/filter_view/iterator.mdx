{/* source:cpp-ranges-filter-view-iterator:0001 */}
The return type of [`filter_view::begin`](/docs/cpp/library/ranges/filter_view).

{/* source:cpp-ranges-filter-view-iterator:0002 */}
This is a [`bidirectional_iterator`](/docs/cpp/library/iterator/bidirectional_iterator) if `V` models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), a [`forward_iterator`](/docs/cpp/library/iterator/forward_iterator) if `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range), and [`input_iterator`](/docs/cpp/library/iterator/input_iterator) otherwise.

{/* source:cpp-ranges-filter-view-iterator:0003 */}
Modification of the element denoted by this iterator is permitted, but results in undefined behavior if the resulting value does not satisfy the filter's predicate.
