#### operator==(std::ranges::filter_view::iterator, std::ranges::filter_view::sentinel)

<DeclarationDoc>
  <Declaration language="cpp" since="C++20" code={`friend constexpr bool operator==( const /*iterator*/& x,
                                  const /*sentinel*/& y );`} />
</DeclarationDoc>

Equivalent to `return x.current_ == y.end_;`, where `current_` is the underlying iterator wrapped in [`filter_view::iterator`](/docs/cpp/library/ranges/filter_view/iterator). The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`. This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::filter_view::sentinel` is an associated class of the arguments.
