{/* source:cpp-ranges-filter-view:0001 */}
1. 1) A range adaptor that represents [`view`](/docs/cpp/library/ranges/view) of an underlying sequence without the elements that fail to satisfy a predicate.

{/* source:cpp-ranges-filter-view:0002 */}
2. 2) [`RangeAdaptorObject`](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::filter(e, p)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to `filter_view(e, p)` for any suitable subexpressions `e` and `p`.

{/* source:cpp-ranges-filter-view:0003 */}
`filter_view` models the concepts [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`input_range`](/docs/cpp/library/ranges/input_range), and [`common_range`](/docs/cpp/library/ranges/common_range) when the underlying [`view`](/docs/cpp/library/ranges/view) `V` models respective concepts.

{/* source:cpp-ranges-filter-view:0009 */}
#### std::ranges::filter_view::begin

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr /*iterator*/ begin();`} />
  (exposition only*)
</DeclarationDoc>

In order to provide the amortized constant time complexity required by the [`range`](/docs/cpp/library/ranges/range) concept, this function caches the result within the `filter_view` object for use on subsequent calls. Equivalent to

```cpp
if constexpr (!ranges::forward_range<V>)
    return /*iterator*/{*this, ranges::find_if(base_, std::ref(*pred_))};
else
{
    if (!begin_.has_value())
        begin_ = ranges::find_if(base_, std::ref(*pred_)); // caching
    return /*iterator*/{*this, begin_.value())};
}
```

The behavior is undefined if `pred_` does not contain a value.

### Example

{/* source:cpp-ranges-filter-view:0013 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    auto even = [](int i) { return 0 == i % 2; };
    auto square = [](int i) { return i * i; };
 
    for (int i : std::views::iota(0, 6)
               | std::views::filter(even)
               | std::views::transform(square))
        std::cout << i << ' ';
    std::cout << '\n';
}
```

Output:

```text
0 4 16
```
