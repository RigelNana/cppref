{/* source:cpp-ranges-chunk-by-view-pred:0001 */}
Returns a reference to the contained `Pred` object. Equivalent to `return *pred_;`.

{/* source:cpp-ranges-chunk-by-view-pred:0002 */}
The behavior is undefined if [`pred_`](/docs/cpp/library/ranges/chunk_by_view#pred) does not contain a value.

### Parameters

{/* source:cpp-ranges-chunk-by-view-pred:0003 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-by-view-pred:0004 */}
A reference to the contained `Pred` object.

### Example

{/* source:cpp-ranges-chunk-by-view-pred:0005 */}
```cpp
#include <cassert>
#include <concepts>
#include <functional>
#include <initializer_list>
#include <ranges>
 
int main()
{
    const auto v = {1, 1, 2, 2, 1, 1, 1};
    auto chunks = v | std::views::chunk_by(std::equal_to{});
    auto pred = chunks.pred();
    static_assert(std::same_as<decltype(pred), std::equal_to<>>);
    assert(pred(v.begin()[0], 1));
}
```
