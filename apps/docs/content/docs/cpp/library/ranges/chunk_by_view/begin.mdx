{/* source:cpp-ranges-chunk-by-view-begin:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/chunk_by_view/iterator) to the first element of the [`chunk_by_view`](/docs/cpp/library/ranges/chunk_by_view).

{/* source:cpp-ranges-chunk-by-view-begin:0002 */}
Equivalent to:

{/* source:cpp-ranges-chunk-by-view-begin:0003 */}
```cpp
ranges::iterator_t<V> iter;
 
if (begin_.has_value())
    iter = begin_.value();
else
{
    iter = /*find_next*/(ranges::begin(base()));
    begin_ = iter; // caching
}
 
return /*iterator*/(*this, ranges::begin(base()), iter);
```

{/* source:cpp-ranges-chunk-by-view-begin:0004 */}
The behavior is undefined if the underlying predicate [`pred_`](/docs/cpp/library/ranges/chunk_by_view#pred) does not contain a value.

### Parameters

{/* source:cpp-ranges-chunk-by-view-begin:0005 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-by-view-begin:0006 */}
[`Iterator`](/docs/cpp/library/ranges/chunk_by_view/iterator) to the first element.

### Notes

{/* source:cpp-ranges-chunk-by-view-begin:0007 */}
In order to provide the amortized constant-time complexity required by the [`range`](/docs/cpp/library/ranges/range) concept, this function caches the result within the data member [`begin_`](/docs/cpp/library/ranges/chunk_by_view#begin) for use on subsequent calls.
