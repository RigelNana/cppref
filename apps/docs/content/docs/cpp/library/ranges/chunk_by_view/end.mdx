{/* source:cpp-ranges-chunk-by-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/chunk_by_view/iterator) or a [sentinel](/docs/cpp/library/iterator/default_sentinel) representing the end of the [`chunk_by_view`](/docs/cpp/library/ranges/chunk_by_view).

{/* source:cpp-ranges-chunk-by-view-end:0002 */}
Equivalent to:

{/* source:cpp-ranges-chunk-by-view-end:0003 */}
```cpp
if constexpr (ranges::common_range<V>)
    return /*iterator*/(*this, ranges::end(base_), ranges::end(base_));
else
    return std::default_sentinel;
```

### Parameters

{/* source:cpp-ranges-chunk-by-view-end:0004 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-by-view-end:0005 */}
An [`iterator`](/docs/cpp/library/ranges/chunk_by_view/iterator) to the element following the last element, or a sentinel which compares equal to the end iterator.

### Notes

{/* source:cpp-ranges-chunk-by-view-end:0006 */}
`end()` returns an iterator if and only if the underlying view is a [`common_range`](/docs/cpp/library/ranges/common_range): `chunk_by_view<V,Pred>` models [`common_range`](/docs/cpp/library/ranges/common_range) whenever `V` does.
