  {/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0001 */}
  Increments or decrements the [iterator](/docs/cpp/library/ranges/chunk_by_view/iterator/iterator).

  {/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0002 */}
  Let [`parent_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members), [`current_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members), and [`next_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members) be the appropriate underlying (exposition-only) data-members of [`iterator`](/docs/cpp/library/ranges/chunk_by_view/iterator/iterator).

  {/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0003 */}
  Let [`find-next`](/docs/cpp/library/ranges/chunk_by_view/helpers#find_next) and [`find-prev`](/docs/cpp/library/ranges/chunk_by_view/helpers#find_prev) be appropriate (exposition-only) member functions of `ranges::chunk_by_view`.
</DeclarationDoc>

{/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0004 */}
1. 1) Equivalent to:

```cpp
current_ = next_;
next_ = parent_->/*find-next*/(current_);
return *this;
```

{/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0005 */}
The behavior is undefined if before the call to this operator [`current_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members) is equal to [`next_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members).

{/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0006 */}
2. 2) Equivalent to: `auto tmp = *this; ++*this; return tmp;`.

{/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0007 */}
3. 3) Equivalent to:

```cpp
next_ = current_;
current_ = parent_->/*find-prev*/(next_);
return *this;
```

{/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0008 */}
4. 4) Equivalent to: `auto tmp = *this; --*this; return tmp;`.

### Parameters

{/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0009 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0010 */}
1,3) `*this`

{/* source:cpp-ranges-chunk-by-view-iterator-operator-arith:0011 */}
2,4) a copy of `*this` that was made before the change.
