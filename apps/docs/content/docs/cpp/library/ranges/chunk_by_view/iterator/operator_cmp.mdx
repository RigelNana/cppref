  Compares the underlying iterators.

  <DeclarationDescription>
    {/* source:cpp-ranges-chunk-by-view-iterator-operator-cmp:0002 */}
    1. 1) Equivalent to `return x.`[`current_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members)` == y.`[`current_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members)`;`.

    {/* source:cpp-ranges-chunk-by-view-iterator-operator-cmp:0003 */}
    2. 2) Equivalent to `return x.`[`current_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members)` == x.`[`next_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members)`;`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-ranges-chunk-by-view-iterator-operator-cmp:0004 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::chunk_by_view::iterator` is an associated class of the arguments.

{/* source:cpp-ranges-chunk-by-view-iterator-operator-cmp:0005 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
