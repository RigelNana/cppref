{/* source:cpp-ranges-chunk-by-view-iterator-operator-star:0001 */}
Returns the current element in the `chunk_by_view`.

{/* source:cpp-ranges-chunk-by-view-iterator-operator-star:0002 */}
Equivalent to: `return ranges::subrange(`[`current_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members)`, `[`next_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members)`)`.

{/* source:cpp-ranges-chunk-by-view-iterator-operator-star:0003 */}
Before the call to this operator [`current_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members) must not be equal to [`next_`](/docs/cpp/library/ranges/chunk_by_view/iterator#Data_members), otherwise the behavior is undefined.

### Parameters

{/* source:cpp-ranges-chunk-by-view-iterator-operator-star:0004 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-by-view-iterator-operator-star:0005 */}
The current element.
