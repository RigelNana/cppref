{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-at:0001 */}
Returns an element at specified relative location.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-at:0002 */}
Let [`parent_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) and [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) be the data members of the [`iterator`](/docs/cpp/library/ranges/adjacent_transform_view/iterator/iterator). Equivalent to:

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-at:0003 */}
```cpp
return apply([&](const auto&... iters) -> decltype(auto)
             {
                return invoke(*parent_->fun_, iters[n]...);
             },
             inner_.current_);
```

### Parameters

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-at:0004 */}
<ParameterList>
  <Parameter name="n">position relative to current location</Parameter>
</ParameterList>

### Return value

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-at:0005 */}
The element at displacement `n` relative to the current location.
