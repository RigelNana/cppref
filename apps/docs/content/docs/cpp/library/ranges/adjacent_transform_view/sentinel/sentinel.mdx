Construct a sentinel.

{/* source:cpp-ranges-adjacent-transform-view-sentinel-sentinel:0002 */}
1) Default constructor. [Default-initializes](/docs/cpp/language/initialization/default_initialization) the underlying sentinel [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel#Data_members).

{/* source:cpp-ranges-adjacent-transform-view-sentinel-sentinel:0003 */}
2) Conversion from `/*sentinel*/<false>` to `/*sentinel*/<true>`. Move constructs the underlying sentinel [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel#Data_members) with [`std::move`](/docs/cpp/library/utility/move)`(i.inner_)`.

{/* source:cpp-ranges-adjacent-transform-view-sentinel-sentinel:0004 */}
3) This sentinel also has a private constructor which is used by `ranges::adjacent_transform_view::end`. This constructor is not accessible to users. Initializes the underlying sentinel [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel#Data_members) with `inner`.
