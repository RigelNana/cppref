{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-star:0001 */}
Returns the current element in the `adjacent_transform_view`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-star:0002 */}
Let [`parent_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) and [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) be the data members of the [`iterator`](/docs/cpp/library/ranges/adjacent_transform_view/iterator/iterator). Equivalent to:

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-star:0003 */}
```cpp
return apply([&](const auto&... iters) -> decltype(auto)
             {
                 return invoke(*parent_->fun_, *iters...);
             },
             inner_.current_);
```

### Parameters

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-star:0004 */}
(none)

### Return value

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-star:0005 */}
The current element.

### Exceptions

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-star:0006 */}
Let `Is` be the pack `0, 1, ..., (N - 1)`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-star:0007 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::invoke(*parent_->fun_, *std::get<Is>(inner_.current_)...))`
