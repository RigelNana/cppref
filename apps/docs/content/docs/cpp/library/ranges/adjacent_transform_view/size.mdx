{/* source:cpp-ranges-adjacent-transform-view-size:0001 */}
Returns the number of elements.

{/* source:cpp-ranges-adjacent-transform-view-size:0002 */}
Let [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view#Data_members) be the underlying object of type [`InnerView`](/docs/cpp/library/ranges/adjacent_transform_view#Member_types) (that is the `ranges::adjacent_view<V,N>`).

{/* source:cpp-ranges-adjacent-transform-view-size:0003 */}
1,2) Equivalent to `return inner_.size();`.

### Parameters

{/* source:cpp-ranges-adjacent-transform-view-size:0004 */}
(none)

### Return value

{/* source:cpp-ranges-adjacent-transform-view-size:0005 */}
The number of elements, may be `0` if the size of the underlying view `V` is less than `N`.

### Example

{/* source:cpp-ranges-adjacent-transform-view-size:0006 */}
```cpp
#include <ranges>
 
int main()
{
    constexpr static auto v = {1, 2, 3, 4, 5, 6};
 
    auto f = [](auto...) { return 0; }; // dummy
 
    constexpr int width1 {4};
    constexpr auto view1 = v | std::views::adjacent_transform<width1>(f);
    static_assert(view1.size() == 3);
    static_assert(view1.size() == (v.size() - width1 + 1));
 
    constexpr int width2 {8};
    constexpr auto view2 = v | std::views::adjacent_transform<width2>(f);
    // window is too wide, so view2 has no elements:
    static_assert(view2.size() == 0);
}
```
