{/* source:cpp-ranges-adjacent-transform-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/adjacent_transform_view/iterator) or a [`sentinel`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel) representing the end of the [`adjacent_transform_view`](/docs/cpp/library/ranges/adjacent_transform_view).

{/* source:cpp-ranges-adjacent-transform-view-end:0002 */}
Let [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view#Data_members) be the underlying `ranges::adjacent_view`.

{/* source:cpp-ranges-adjacent-transform-view-end:0003 */}
1) Equivalent to:

```cpp
if constexpr (ranges::common_range<InnerView>)
    return /*iterator*/<false>(*this, inner_.end());
else
    return /*sentinel*/<false>(inner_.end());
```

{/* source:cpp-ranges-adjacent-transform-view-end:0004 */}
2) Equivalent to:

```cpp
if constexpr (ranges::common_range<const InnerView>)
    return /*iterator*/<true>(*this, inner_.end());
else
    return /*sentinel*/<true>(inner_.end());
```

### Parameters

{/* source:cpp-ranges-adjacent-transform-view-end:0005 */}
(none)

### Return value

{/* source:cpp-ranges-adjacent-transform-view-end:0006 */}
An [`iterator`](/docs/cpp/library/ranges/adjacent_transform_view/iterator) to the element following the last element, if the underlying view `V` models [`common_range`](/docs/cpp/library/ranges/common_range). Otherwise, a [`sentinel`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel) which compares equal to the end iterator.

### Notes

{/* source:cpp-ranges-adjacent-transform-view-end:0007 */}
`adjacent_transform_view<V,F,N>` models [`common_range`](/docs/cpp/library/ranges/common_range) whenever the underlying view `V` does.
