{/* source:cpp-ranges-adjacent-transform-view-sentinel-operator-cmp:0001 */}
Compares the underlying iterator of `x` with the underlying sentinel of `y`.

{/* source:cpp-ranges-adjacent-transform-view-sentinel-operator-cmp:0002 */}
Equivalent to: `return x.`[`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members)`== y.`[`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel#Data_members)`;`.

{/* source:cpp-ranges-adjacent-transform-view-sentinel-operator-cmp:0003 */}
This function template is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `adjacent_transform_view::sentinel` is an associated class of the arguments.

{/* source:cpp-ranges-adjacent-transform-view-sentinel-operator-cmp:0004 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
