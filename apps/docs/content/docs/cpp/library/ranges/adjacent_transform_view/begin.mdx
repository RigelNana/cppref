{/* source:cpp-ranges-adjacent-transform-view-begin:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/adjacent_transform_view/iterator) to the first element of the [`adjacent_transform_view`](/docs/cpp/library/ranges/adjacent_transform_view).

{/* source:cpp-ranges-adjacent-transform-view-begin:0002 */}
Let [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view#Data_members) be the underlying `ranges::adjacent_view`.

{/* source:cpp-ranges-adjacent-transform-view-begin:0003 */}
1) Equivalent to `return /*iterator*/<false>(*this, inner_.begin());`.

{/* source:cpp-ranges-adjacent-transform-view-begin:0004 */}
2) Equivalent to `return /*iterator*/<true>(*this, inner_.begin());`.

### Parameters

{/* source:cpp-ranges-adjacent-transform-view-begin:0005 */}
(none)

### Return value

{/* source:cpp-ranges-adjacent-transform-view-begin:0006 */}
Iterator to the first element.

### Example

{/* source:cpp-ranges-adjacent-transform-view-begin:0007 */}
```cpp
#include <ranges>
 
int main()
{
    auto sum = [](auto... args) { return (... + args); };
 
    constexpr auto view = std::views::iota(13, 1337)
                        | std::views::adjacent_transform<3>(sum);
 
    static_assert(*view.begin() == 42 and 42 == 13 + 14 + 15);
}
```
