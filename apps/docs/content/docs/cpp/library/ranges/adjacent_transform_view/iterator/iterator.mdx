{/* source:cpp-ranges-adjacent-transform-view-iterator-iterator:0001 */}
Construct an iterator.

{/* source:cpp-ranges-adjacent-transform-view-iterator-iterator:0002 */}
1) Default constructor. [Value-initializes](/docs/cpp/language/initialization/value_initialization) the underlying pointer [`parent_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) with `nullptr`, and [default-initializes](/docs/cpp/language/initialization/default_initialization) the underlying iterator [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members).

{/* source:cpp-ranges-adjacent-transform-view-iterator-iterator:0003 */}
2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Initializes the underlying pointer [`parent_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) with `i.parent_`, and move constructs the underlying iterator [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) with [`std::move`](/docs/cpp/library/utility/move)`(i.inner_)`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-iterator:0004 */}
3) This iterator also has a private constructor which is used by `ranges::adjacent_transform_view::begin` and `ranges::adjacent_transform_view::end`. This constructor is not accessible to users. Initializes [`parent_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) with `std::addressof(parent)`, and move constructs [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) with `std::move(inner)`.
