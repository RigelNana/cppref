{/* source:cpp-ranges-adjacent-transform-view:0001 */}
1) `adjacent_transform_view` is a range adaptor that takes a [`view`](/docs/cpp/library/ranges/view) and an invocable object `fun`, and produces a [`view`](/docs/cpp/library/ranges/view) whose `i`th element is a value that is the result of applying `fun` to each element in `[i, i + N)` of the original view. `F` always has [arity](https://en.wikipedia.org/wiki/arity) `N`.

{/* source:cpp-ranges-adjacent-transform-view:0002 */}
Let `S` be the size of the original view. Then the size of produced view is:

- `S - N + 1`, if `S >= N`,
- `0` otherwise, and the resulting view is empty.

{/* source:cpp-ranges-adjacent-transform-view:0003 */}
2) The name `views::adjacent_transform<N>` denotes a [RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject). Given subexpressions `e` and `f`, and a constant expression `N`, the expression `views::adjacent_transform<N>(e, f)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

- `((void)e, views::zip_transform(f))`, if `N` is equal to `0` and `decltype((e))` models [`forward_range`](/docs/cpp/library/ranges/forward_range) (except that the evaluations of `e` and `f` are [indeterminately sequenced](/docs/cpp/language/expressions/eval_order#Ordering)),
- `adjacent_transform_view<views::all_t<decltype((e))>, std::decay_t<decltype((f))>, N>(e, f)` otherwise.

{/* source:cpp-ranges-adjacent-transform-view:0004 */}
3) The name `views::pairwise_transform` denotes a [RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject) that behaves exactly as `views::adjacent_transform<2>`. In particular, the arity of `F` is also `2` and `fun` is a binary invocable object.

{/* source:cpp-ranges-adjacent-transform-view:0005 */}
`adjacent_transform_view` always models [`forward_range`](/docs/cpp/library/ranges/forward_range), and models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), or [`sized_range`](/docs/cpp/library/ranges/sized_range), if adapted [`view`](/docs/cpp/library/ranges/view) type models the corresponding concept.

### Example

{/* source:cpp-ranges-adjacent-transform-view:0013 */}
```cpp
#include <array>
#include <iostream>
#include <ranges>
 
int main()
{
    constexpr static std::array data{1, 2, 3, 4, 5, 6};
    constexpr int window{3};
 
    auto Fun = [](auto... ints) { return (... + ints); };
    // Alternatively, the Fun could be any ternary (if window == 3) callable, e.g.:
    // auto Fun = [](int x, int y, int z) { return x + y + z; };
 
    constexpr auto view = data | std::views::adjacent_transform<window>(Fun);
 
    static_assert(
        view.size() == (data.size() - window + 1)
        && std::array{6, 9, 12, 15}
        == std::array{view[0], view[1], view[2], view[3]}
        && view[0] == Fun(data[0], data[1], data[2])
        && view[1] == Fun(data[1], data[2], data[3])
        && view[2] == Fun(data[2], data[3], data[4])
        && view[3] == Fun(data[3], data[4], data[5])
    );
 
    for (int x : view)
        std::cout << x << ' ';
    std::cout << '\n';
}
```

Output:

```text
6 9 12 15
```
