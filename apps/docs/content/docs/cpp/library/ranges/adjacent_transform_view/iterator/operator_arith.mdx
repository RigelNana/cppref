{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0001 */}
Increments or decrements the [`iterator`](/docs/cpp/library/ranges/adjacent_transform_view/iterator).

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0002 */}
Let [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members) be the underlying iterator and [`Base`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Member_types) be the exposition-only member type.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0003 */}
Equivalent to:

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0004 */}
1) `++inner_; return *this;`

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0005 */}
2) `auto tmp = *this; ++*this; return tmp;`

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0006 */}
3) `--inner_; return *this;`

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0007 */}
4) `auto tmp = *this; --*this; return tmp;`

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0008 */}
5) `inner_ += n; return *this;`

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0009 */}
6) `inner_ -= n; return *this;`

### Parameters

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0010 */}

### Return value

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0011 */}
1,3,5,6) `*this`

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-arith:0012 */}
2,4) a copy of `*this` that was made before the change
