{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0001 */}
Compares the underlying iterators: [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members).

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0002 */}
1) Equivalent to `return x.inner_ == y.inner_;`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0003 */}
2) Equivalent to `return x.inner_ < y.inner_;`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0004 */}
3) Equivalent to `return x.inner_ > y.inner_;`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0005 */}
4) Equivalent to `return x.inner_ <= y.inner_;`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0006 */}
5) Equivalent to `return x.inner_ >= y.inner_;`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0007 */}
6) Equivalent to `return x.inner_ <=> y.inner_;`.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0008 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::adjacent_transform_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-adjacent-transform-view-iterator-operator-cmp:0009 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
