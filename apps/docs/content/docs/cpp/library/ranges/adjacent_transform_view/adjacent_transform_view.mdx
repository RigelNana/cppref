Constructs an [`adjacent_transform_view`](/docs/cpp/library/ranges/adjacent_transform_view).

{/* source:cpp-ranges-adjacent-transform-view-adjacent-transform-view:0002 */}
1) Default constructor. [Default-initializes](/docs/cpp/language/initialization/default_initialization) the underlying data members [`fun_`](/docs/cpp/library/ranges/adjacent_transform_view#Data_members) and [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view#Data_members).

{/* source:cpp-ranges-adjacent-transform-view-adjacent-transform-view:0003 */}
2) Move constructs the underlying data members: [`fun_`](/docs/cpp/library/ranges/adjacent_transform_view#Data_members) with `std::move(fun)` and [`inner_`](/docs/cpp/library/ranges/adjacent_transform_view#Data_members) with `std::move(base)`.

### Example

{/* source:cpp-ranges-adjacent-transform-view-adjacent-transform-view:0005 */}
```cpp
#include <algorithm>
#include <iostream>
#include <iterator>
#include <ranges>
 
int main()
{
    constexpr static auto v = {1, 2, 3, 4, 5};
    constexpr auto mul = [](auto... x) { return (... * x); };
    constexpr auto view = std::views::adjacent_transform<3>(v, mul);
    std::ranges::copy(view, std::ostream_iterator<int>(std::cout, " "));
    std::cout << '\n';
}
```

Output:

```text
6 24 60
```
