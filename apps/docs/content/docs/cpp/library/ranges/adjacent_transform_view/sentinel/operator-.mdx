Computes the distance between the [`iterator`](/docs/cpp/library/ranges/adjacent_transform_view/iterator) `x` and the [`sentinel`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel) `y`.

{/* source:cpp-ranges-adjacent-transform-view-sentinel-operator:0002 */}
1) Equivalent to: `return x.`[`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members)`- y.`[`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel#Data_members)`;`.

{/* source:cpp-ranges-adjacent-transform-view-sentinel-operator:0003 */}
2) Equivalent to: `return y.`[`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/sentinel#Data_members)`- x.`[`inner_`](/docs/cpp/library/ranges/adjacent_transform_view/iterator#Data_members)`;`.

{/* source:cpp-ranges-adjacent-transform-view-sentinel-operator:0004 */}
These function templates are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `adjacent_transform_view::sentinel` is an associated class of the arguments.
