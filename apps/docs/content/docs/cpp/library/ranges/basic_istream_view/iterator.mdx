{/* source:cpp-ranges-basic-istream-view-iterator:0001 */}
`ranges::basic_istream_view<Val, CharT, Traits>::iterator` is the type of the iterators returned by [`begin()`](/docs/cpp/library/ranges/basic_istream_view#begin) of `ranges::basic_istream_view<Val, CharT, Traits>`.

{/* source:cpp-ranges-basic-istream-view-iterator:0002 */}
`iterator` is an [`input_iterator`](/docs/cpp/library/iterator/input_iterator), but does not satisfy [`LegacyInputIterator`](/docs/cpp/library/named_req/InputIterator), and thus does not work with pre-C++20 [`algorithms`](/docs/cpp/library/algorithm).
