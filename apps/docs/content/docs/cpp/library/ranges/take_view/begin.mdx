{/* source:cpp-ranges-take-view-begin:0001 */}
Returns an iterator to the first element of the `take_view`.

{/* source:cpp-ranges-take-view-begin:0002 */}
1. 1) Returns a `std::counted_iterator` or a `ranges::iterator_t<V>`.

{/* source:cpp-ranges-take-view-begin:0003 */}
2. 2) Returns a `std::counted_iterator` or a `ranges::iterator_t<const V>`.

{/* source:cpp-ranges-take-view-begin:0004 */}
Overload (1) does not participate in overload resolution if `V` is a [simple view](/docs/cpp/library/ranges#Helper_concepts) (that is, if `V` and `const V` are views with the same iterator and sentinel types).

### Parameters

{/* source:cpp-ranges-take-view-begin:0005 */}
(none)

### Return value

{/* source:cpp-ranges-take-view-begin:0006 */}
The result depends on the concepts satisfied by possibly const-qualified underlying view type `Base`, which is `V` for ([1](/docs/cpp/library/ranges/take_view/begin#Version_1)) or `const V` for ([2](/docs/cpp/library/ranges/take_view/begin#Version_2)).

{/* source:cpp-ranges-take-view-begin:0007 */}
Let [`base_`](/docs/cpp/library/ranges/take_view#Data_members) be the underlying view, [`count_`](/docs/cpp/library/ranges/take_view#Data_members) be the underlying counter (equals to `0` if `take_view` was default initialized).

{/* source:cpp-ranges-take-view-begin:0008 */}
| The underlying view type satisfies ... | [`random_access_range`](/docs/cpp/library/ranges/random_access_range) | yes | no |
| --- | --- | --- | --- |
| [`sized_range`](/docs/cpp/library/ranges/sized_range) | yes | `ranges::begin(base_)` | `std::counted_iterator(ranges::begin(base_), ranges::range_difference_t<Base_>(this->size()))` |
| | no | `std::counted_iterator(ranges::begin(base_), count_)` | `std::counted_iterator(ranges::begin(base_), count_)` |

### Example

{/* source:cpp-ranges-take-view-begin:0009 */}
```cpp
#include <concepts>
#include <forward_list>
#include <iostream>
#include <ranges>
#include <string_view>
#include <type_traits>
using namespace std::literals;
 
int main()
{
    {
        static constexpr auto v = {"∀x"sv, "∃y"sv, "ε"sv, "δ"sv};
        auto view = std::ranges::take_view(v, 8);
        auto iter = view.begin();
        std::cout << *iter << '\n';
        static_assert(
            std::ranges::sized_range<decltype(v)> and
            std::ranges::random_access_range<decltype(v)> and
            std::is_same_v<decltype(iter), decltype(std::ranges::begin(v))>
        );
    }
 
    {
        std::forward_list v = {"Ax"sv, "Ey"sv, "p"sv, "q"sv};
        auto view = std::ranges::take_view(v, 8);
        auto iter = view.begin();
        std::cout << *iter << '\n';
        static_assert(
            not std::ranges::sized_range<decltype(v)> and
            not std::ranges::random_access_range<decltype(v)> and
            std::is_same_v<decltype(iter),
                std::counted_iterator<
                    std::forward_list<std::string_view>::iterator>>
        );
    }
}
```

Output:

```text
∀x
Ax
```
