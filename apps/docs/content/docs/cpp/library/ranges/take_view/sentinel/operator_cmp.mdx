{/* source:cpp-ranges-take-view-sentinel-operator-cmp:0001 */}
Compares a `take_view::/*sentinel*/` with a [`std::counted_iterator`](/docs/cpp/library/iterator/counted_iterator) (typically obtained from a call to [`take_view::begin`](/docs/cpp/library/ranges/take_view/begin)).

{/* source:cpp-ranges-take-view-sentinel-operator-cmp:0002 */}
Returns `true` if `y` points past the Nth element (where N is the number passed to the [constructor of `take_view`](/docs/cpp/library/ranges/take_view/take_view)), or if end of underlying view is reached.

{/* source:cpp-ranges-take-view-sentinel-operator-cmp:0003 */}
The exposition-only alias template `/*add-const-if*/` is defined as `template<bool C, class T> using /*add-const-if*/ = std::conditional_t<C, const T, T>;`.

{/* source:cpp-ranges-take-view-sentinel-operator-cmp:0004 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::take_view::sentinel<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-take-view-sentinel-operator-cmp:0005 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Return value

{/* source:cpp-ranges-take-view-sentinel-operator-cmp:0007 */}
`y.count() == 0 || y.base() == x.end_`, where `end_` denotes the underlying sentinel.
