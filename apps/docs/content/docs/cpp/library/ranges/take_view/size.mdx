Returns the number of elements, which is the smaller of the count passed to the constructor and the size of the underlying view.

{/* source:cpp-ranges-take-view-size:0002 */}
Let [`base_`](/docs/cpp/library/ranges/take_view#Data_members) be the underlying view, [`count_`](/docs/cpp/library/ranges/take_view#Data_members) be the underlying counter (equals to `0` if default constructed). Equivalent to

{/* source:cpp-ranges-take-view-size:0003 */}
```cpp
auto n = ranges::size(base_);
return ranges::min(n, static_cast<decltype(n)>(count_));
```

### Parameters

{/* source:cpp-ranges-take-view-size:0004 */}
(none)

### Return value

{/* source:cpp-ranges-take-view-size:0005 */}
The number of elements.

### Example

{/* source:cpp-ranges-take-view-size:0006 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    constexpr int arr[]{1, 2, 3};
 
    for (int i = 0; i != 6; ++i)
    {
        const auto tv = std::ranges::take_view{arr, i};
        std::cout << tv.size() << ' ';
    }
    std::cout << '\n';
}
```

Output:

```text
0 1 2 3 3 3
```
