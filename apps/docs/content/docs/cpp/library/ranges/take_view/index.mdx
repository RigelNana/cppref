{/* source:cpp-ranges-take-view:0001 */}
1. 1) A range adaptor that represents [`view`](/docs/cpp/library/ranges/view) of the elements from an underlying sequence, starting at the beginning and ending at a given bound.

{/* source:cpp-ranges-take-view:0002 */}
2. 2) `views::take` is a [`RangeAdaptorObject`](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::take(e, f)` results in a view that represents the first `f` elements from `e`. The result is not necessarily a `take_view`.

`views::take(e, f)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to (where `T` is `std::remove_cvref_t<decltype((e))>` and `D` is `ranges::range_difference_t<decltype((e))>`):

- `((void)f, `[`decay-copy`](/docs/cpp/library/standard_library/decay-copy)`(e))`, if `T` is a [`ranges::empty_view`](/docs/cpp/library/ranges/empty_view), except that the evaluations of `e` and `f` are indeterminately sequenced;
- `U(ranges::begin(e), ranges::begin(e) + std::min<D>(ranges::distance(e), f))`, if `T` is a specialization of [`std::span`](/docs/cpp/library/container/span), [`std::basic_string_view`](/docs/cpp/library/string/basic_string_view), or [`ranges::subrange`](/docs/cpp/library/ranges/subrange) that models both [`random_access_range`](/docs/cpp/library/ranges/random_access_range) and [`sized_range`](/docs/cpp/library/ranges/sized_range), where `U` is
  - [`std::span<typename T::element_type>`](/docs/cpp/library/container/span), if `T` is a specialization of `std::span`;
  - `T`, if `T` is a specialization of `std::basic_string_view`;
  - [`ranges::subrange<ranges::iterator_t<T>>`](/docs/cpp/library/ranges/subrange), if `T` is a specialization of `ranges::subrange`;
- `ranges::iota_view(*ranges::begin(e), *(ranges::begin(e) + std::min<D>(ranges::distance(e), f)))`, if `T` is a specialization of [`ranges::iota_view`](/docs/cpp/library/ranges/iota_view) that models both [`random_access_range`](/docs/cpp/library/ranges/random_access_range) and [`sized_range`](/docs/cpp/library/ranges/sized_range);

<Revision since="C++23">
- otherwise, if `T` is a specialization of [`ranges::repeat_view`](/docs/cpp/library/ranges/repeat_view):
  - `views::repeat(*e.value_, std::min<D>(ranges::distance(e), f))`, if `T` models [`sized_range`](/docs/cpp/library/ranges/sized_range); is such case `e` is evaluated only once;
  - `views::repeat(*e.value_, static_cast<D>(e))` otherwise;
</Revision>

- otherwise, `take_view(e, f)`.

In all cases, `decltype((f))` must model `std::convertible_to<D>`.

{/* source:cpp-ranges-take-view:0003 */}
`take_view` models the concepts [`contiguous_range`](/docs/cpp/library/ranges/contiguous_range), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range), [`forward_range`](/docs/cpp/library/ranges/forward_range), [`input_range`](/docs/cpp/library/ranges/input_range), and [`sized_range`](/docs/cpp/library/ranges/sized_range) when the underlying view `V` models respective concepts. It models [`common_range`](/docs/cpp/library/ranges/common_range) when the underlying view `V` models both [`random_access_range`](/docs/cpp/library/ranges/random_access_range) and [`sized_range`](/docs/cpp/library/ranges/sized_range).

This specialization of [`std::ranges::enable_borrowed_range`](/docs/cpp/library/ranges/borrowed_range) makes `take_view` satisfy [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range) when the underlying view satisfies it.

### Example

{/* source:cpp-ranges-take-view:0009 */}
```cpp
#include <algorithm>
#include <iostream>
#include <ranges>
 
int main()
{
    namespace views = std::views;
    auto print = [](char x){ std::cout << x; };
 
    for (const char nums[]{'1', '2', '3'};
         int n : views::iota(0, 5))
    {
        std::cout << "take(" << n << "): ";
        // safely takes only upto min(n, nums.size()) elements:
        std::ranges::for_each(nums | views::take(n), print);
        std::cout << '\n';
    }
}
```

Output:

```text
take(0): 
take(1): 1
take(2): 12
take(3): 123
take(4): 123
```
