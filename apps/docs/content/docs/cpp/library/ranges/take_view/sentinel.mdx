{/* source:cpp-ranges-take-view-sentinel:0001 */}
The return type of [`take_view::end`](/docs/cpp/library/ranges/take_view/end) when the underlying view is not a [`sized_range`](/docs/cpp/library/ranges/sized_range).

{/* source:cpp-ranges-take-view-sentinel:0002 */}
The type `/*sentinel*/<true>` is returned by the const-qualified overload. The type `/*sentinel*/<false>` is returned by the non-const-qualified overload.
