{/* source:cpp-ranges-view-interface-back:0001 */}
The default implementation of `back()` member function returns the last element in the view of the derived type. Whether the element is returned by value or by reference depends on the `operator*` of the iterator type.

{/* source:cpp-ranges-view-interface-back:0002 */}
1. 1) Let `derived` be `static_cast<D&>(*this)`. Equivalent to `return *ranges::prev(ranges::end(derived));`. The behavior is undefined if [`empty()`](/docs/cpp/library/ranges/view_interface/empty) is `true` (i.e. the beginning iterator compares equal to the sentinel), even if the iterator obtained in the same way is dereferenceable.

{/* source:cpp-ranges-view-interface-back:0003 */}
2. 2) Same as (1), except that `derived` is `static_cast<const D&>(*this)`.

### Parameters

{/* source:cpp-ranges-view-interface-back:0004 */}
(none)

### Return value

{/* source:cpp-ranges-view-interface-back:0005 */}
The last element in the view.

### Notes

{/* source:cpp-ranges-view-interface-back:0006 */}
In C++20, no type derived from [`std::ranges::view_interface`](/docs/cpp/library/ranges/view_interface) in the standard library provides their own `back()` member function.

{/* source:cpp-ranges-view-interface-back:0007 */}
However, following derived types cannot use the default implementations, as they never satisfy neither [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range) nor [`common_range`](/docs/cpp/library/ranges/common_range):

{/* source:cpp-ranges-view-interface-back:0008 */}
- [`std::ranges::basic_istream_view`](/docs/cpp/library/ranges/basic_istream_view)
- `std::ranges::lazy_split_view`
- [`std::ranges::split_view`](/docs/cpp/library/ranges/split_view)
- [`std::ranges::take_while_view`](/docs/cpp/library/ranges/take_while_view)

{/* source:cpp-ranges-view-interface-back:0009 */}
The inherited `back()` member function is available for [`std::ranges::empty_view`](/docs/cpp/library/ranges/empty_view), but a call to it always results in undefined behavior.
