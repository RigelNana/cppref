{/* source:cpp-ranges-view-interface-cbegin:0001 */}
The default implementation of `cbegin()` member function returns a constant beginning iterator of the range.

{/* source:cpp-ranges-view-interface-cbegin:0002 */}
1. 1) Let `derived` be a reference bound to `static_cast<D&>(*this)`.

{/* source:cpp-ranges-view-interface-cbegin:0003 */}
    Equivalent to `return ranges::cbegin(derived);`.

{/* source:cpp-ranges-view-interface-cbegin:0004 */}
2. 2) Same as (1), except that `derived` is `static_cast<const D&>(*this)`.

### Parameters

{/* source:cpp-ranges-view-interface-cbegin:0005 */}
(none)

### Return value

{/* source:cpp-ranges-view-interface-cbegin:0006 */}
A constant beginning iterator of the range.

### Notes

{/* source:cpp-ranges-view-interface-cbegin:0007 */}
All range adaptors and range factories in the standard library and [`std::ranges::subrange`](/docs/cpp/library/ranges/subrange) use the default implementation of `cbegin`.
