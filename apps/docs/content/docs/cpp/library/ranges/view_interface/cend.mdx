{/* source:cpp-ranges-view-interface-cend:0001 */}
The default implementation of `cend()` member function returns the sentinel for the constant iterator of the range.

{/* source:cpp-ranges-view-interface-cend:0002 */}
1. 1) Let `derived` be a reference bound to `static_cast<D&>(*this)`. Equivalent to `return ranges::cend(derived);`.

{/* source:cpp-ranges-view-interface-cend:0003 */}
2. 2) Same as (1), except that `derived` is `static_cast<const D&>(*this)`.

### Parameters

{/* source:cpp-ranges-view-interface-cend:0004 */}
(none)

### Return value

{/* source:cpp-ranges-view-interface-cend:0005 */}
The sentinel for the constant iterator of the range.

### Notes

{/* source:cpp-ranges-view-interface-cend:0006 */}
All range adaptors and range factories in the standard library and [`std::ranges::subrange`](/docs/cpp/library/ranges/subrange) use the default implementation of `cend`.
