{/* source:cpp-ranges-view-interface-empty:0001 */}
The default implementation of `empty()` member function checks whether the object of the derived type's size is `0` (if valid), or whether the beginning iterator and the sentinel compare equal.

{/* source:cpp-ranges-view-interface-empty:0002 */}
1. 1) Let `derived` be a reference bound to `static_cast<D&>(*this)`. Equivalent to `return ranges::size(derived) == 0;` if `D` satisfies [`sized_range`](/docs/cpp/library/ranges/sized_range). Otherwise, equivalent to `return ranges::begin(derived) == ranges::end(derived);`.

{/* source:cpp-ranges-view-interface-empty:0003 */}
2. 2) Same as (1), except that `derived` is `static_cast<const D&>(*this)`.

### Parameters

{/* source:cpp-ranges-view-interface-empty:0004 */}
(none)

### Return value

{/* source:cpp-ranges-view-interface-empty:0005 */}
`true` if the size of the object of the derived type is `0` (if `D` satisfies [`std::ranges::sized_range`](/docs/cpp/library/ranges/sized_range)), or its beginning iterator and the sentinel compare equal, `false` otherwise.

{/* source:cpp-ranges-view-interface-empty:0009 */}
Although [`std::ranges::basic_istream_view`](/docs/cpp/library/ranges/basic_istream_view) inherits from [`std::ranges::view_interface`](/docs/cpp/library/ranges/view_interface) and does not declare the `empty()` member function, it cannot use the default implementation, because it never satisfies neither [`std::ranges::sized_range`](/docs/cpp/library/ranges/sized_range) nor [`std::ranges::forward_range`](/docs/cpp/library/ranges/forward_range).

### Example

{/* source:cpp-ranges-view-interface-empty:0010 */}
```cpp
#include <array>
#include <ranges>
 
int main()
{
    constexpr std::array a{0, 1, 2, 3, 4};
    static_assert(!std::ranges::single_view(a).empty());
    static_assert((a | std::views::take(0)).empty());
    static_assert(!(a | std::views::take(5)).empty());
    static_assert((a | std::views::drop(5)).empty());
    static_assert(!(a | std::views::drop(3)).empty());
    static_assert(std::views::iota(0,0).empty());
    static_assert(!std::views::iota(0).empty());
}
```
