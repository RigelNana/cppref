{/* source:cpp-ranges-view-interface-size:0001 */}
The default implementation of `size()` member function obtains the size of the range by calculating the difference between the sentinel and the beginning iterator.

### Return value

{/* source:cpp-ranges-view-interface-size:0002 */}
1. 1) [`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(ranges::end(static_cast<D&>(this)) - ranges::begin(static_cast<D&>(this)))`.

{/* source:cpp-ranges-view-interface-size:0003 */}
2. 2) [`to-unsigned-like`](/docs/cpp/library/ranges#to-unsigned-like)`(ranges::end(static_cast<const D&>(this)) - ranges::begin(static_cast<const D&>(this)))`.

### Notes

{/* source:cpp-ranges-view-interface-size:0004 */}
Following derived types may use the default implementation of `size()`:

{/* source:cpp-ranges-view-interface-size:0005 */}
- [`std::ranges::drop_while_view`](/docs/cpp/library/ranges/drop_while_view)

{/* source:cpp-ranges-view-interface-size:0006 */}
Following types are derived from [`std::ranges::view_interface`](/docs/cpp/library/ranges/view_interface) and do not declare their own `size()` member function, but they cannot use the default implementation, because their iterator and sentinel types never satisfy [`sized_sentinel_for`](/docs/cpp/library/iterator/sized_sentinel_for):

{/* source:cpp-ranges-view-interface-size:0007 */}
- [`std::ranges::basic_istream_view`](/docs/cpp/library/ranges/basic_istream_view)
- [`std::ranges::filter_view`](/docs/cpp/library/ranges/filter_view)
- [`std::ranges::join_view`](/docs/cpp/library/ranges/join_view)
- `std::ranges::lazy_split_view`
- [`std::ranges::split_view`](/docs/cpp/library/ranges/split_view)
- [`std::ranges::take_while_view`](/docs/cpp/library/ranges/take_while_view)
