{/* source:cpp-ranges-chunk-view-inner-iterator-operator:0001 */}
Calculates the distance (in number of underlying elements) between the [`iterator`](/docs/cpp/library/ranges/chunk_view/inner_iterator) and [`sentinel`](/docs/cpp/library/iterator/default_sentinel).

{/* source:cpp-ranges-chunk-view-inner-iterator-operator:0002 */}
Let [`parent_`](/docs/cpp/library/ranges/chunk_view/inner_iterator#Data_members) be the underlying pointer to the enclosing `chunk_view`.

{/* source:cpp-ranges-chunk-view-inner-iterator-operator:0003 */}
1. 1) Equivalent to:

    ```cpp
    return ranges::min(i.parent_->remainder_,
                       ranges::end(i.parent_->base_) - *i.parent_->current_);
    ```

{/* source:cpp-ranges-chunk-view-inner-iterator-operator:0004 */}
2. 2) Equivalent to `return -(s - i);`.

{/* source:cpp-ranges-chunk-view-inner-iterator-operator:0005 */}
These functions are not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::ranges::chunk_view::inner-iterator` is an associated class of the arguments.
