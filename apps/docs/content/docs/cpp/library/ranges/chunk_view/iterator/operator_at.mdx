Returns an element at specified relative location.

{/* source:cpp-ranges-chunk-view-iterator-operator-at:0002 */}
Equivalent to: `return *(*this + pos);`.

  <Parameter name="pos">position relative to current location</Parameter>

### Return value

{/* source:cpp-ranges-chunk-view-iterator-operator-at:0004 */}
