Returns the current element in current chunk in the `chunk_view`.

{/* source:cpp-ranges-chunk-view-inner-iterator-operator-star:0002 */}
Let [`parent_`](/docs/cpp/library/ranges/chunk_view/inner_iterator#Data_members) be the underlying pointer to `chunk_view`. Equivalent to: `return **`[`parent_`](/docs/cpp/library/ranges/chunk_view/inner_iterator#Data_members)`->`[`current_;`](/docs/cpp/library/ranges/chunk_view#Data_members).

{/* source:cpp-ranges-chunk-view-inner-iterator-operator-star:0003 */}
Before invocation of this operator the expression `*this == std::default_sentinel` must be `false`.

### Return value

{/* source:cpp-ranges-chunk-view-inner-iterator-operator-star:0005 */}
