  {/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0001 */}
  Performs [iterator](/docs/cpp/library/ranges/chunk_view/iterator) arithmetic or calculates the distance.

  {/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0002 */}
  Let `current_`, `end_`, `n_`, and `missing_` be the underlying [data members](/docs/cpp/library/ranges/chunk_view/iterator#Data_members).

  {/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0003 */}
  Equivalent to:

  <DeclarationDescription>
    {/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0004 */}
    1. 1,2) `auto r = i; r += pos; return r;`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0005 */}
    2. 3) `auto r = i; r -= pos; return r;`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0006 */}
    3. 4) `return (i.current_ - j.current_ + i.missing_ - j.missing_) / i.n_;`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0007 */}
    4. 5) `return /*div-ceil*/(i.end_ - i.current_, i.n_);`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0008 */}
    5. 6) `return -(y - x);`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0009 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `chunk_view::iterator<Const>` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0011 */}
1,2) An incremented iterator.

{/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0012 */}
3) A decremented iterator.

{/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0013 */}
4) A distance (in number of elements, i.e. chunks) between given iterators.

{/* source:cpp-ranges-chunk-view-iterator-operator-arith2:0014 */}
5,6) A distance (in number of elements) between given iterator and sentinel.
