{/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0001 */}
  Compares the underlying iterators (or the underlying iterator and the default sentinel (2)).

{/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0002 */}
  Let `current_` and `end_` be the underlying [data members](/docs/cpp/library/ranges/chunk_view/iterator#Data_members).

{/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0003 */}
  Equivalent to:

  <DeclarationDescription>
    {/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0004 */}
    1. 1) `return x.current_ == y.current_;`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0005 */}
    2. 2) `return x.current_ == x.end_;`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0006 */}
    3. 3) `return x.current_ < y.current_;`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0007 */}
    4. 4) `return y < x;`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0008 */}
    5. 5) `return !(y < x);`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0009 */}
    6. 6) `return !(x < y);`.

    {/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0010 */}
    7. 7) `return x.current_ <=> y.current_;`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0011 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::ranges::chunk_view::iterator<Const>` is an associated class of the arguments.

{/* source:cpp-ranges-chunk-view-iterator-operator-cmp:0012 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
