{/* source:cpp-ranges-chunk-view:0001 */}
`chunk_view` takes a [`view`](/docs/cpp/library/ranges/view) and a number `n` and produces a range of views (the *chunks*) of the original view, such that each *chunk*, except maybe the last one, has the size `n`. These *chunks* are non-overlapping, successive sub-ranges of the elements of the original view, in order.

{/* source:cpp-ranges-chunk-view:0002 */}
Let `s` be the size of the original view. If `s` is not the multiple of `n`, the size of the *last* produced view is exactly `s % n` (the remainder). Otherwise, the size of each *chunk*, including the last one, is `n`.

{/* source:cpp-ranges-chunk-view:0003 */}
The size of produced view is `/*div-ceil*/(s)`.

{/* source:cpp-ranges-chunk-view:0004 */}
If the `n` is not greater than `0` the behavior is undefined.

{/* source:cpp-ranges-chunk-view:0005 */}
1. 1) An implementation that supports the underlying view `V` that models only [`input_range`](/docs/cpp/library/ranges/input_range).

{/* source:cpp-ranges-chunk-view:0006 */}
2. 2) A partial specialization that supports the underlying view `V` that models [`forward_range`](/docs/cpp/library/ranges/forward_range) or stronger. Models [`common_range`](/docs/cpp/library/ranges/common_range) if the underlying view `V` is [`forward_range`](/docs/cpp/library/ranges/forward_range), [`common_range`](/docs/cpp/library/ranges/common_range), and either [`sized_range`](/docs/cpp/library/ranges/sized_range) or non [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range).

{/* source:cpp-ranges-chunk-view:0007 */}
3. 3) The name `views::chunk` denotes a *[RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject)*. Given subexpressions `e` and `n`, the expression `views::chunk(e, n)` is [*expression-equivalent*](/docs/cpp/language/expressions#Expression-equivalence) to `chunk_view(e, n)`.

{/* source:cpp-ranges-chunk-view:0008 */}
4. 4) Computes the smallest integer value that is not less than the quotient of dividing `num` by `denom`. Equivalent to:

```cpp
I r = num / denom;
if (num % denom)
    ++r;
return r;
```

### Notes

{/* source:cpp-ranges-chunk-view:0015 */}
If `V` models [`input_range`](/docs/cpp/library/ranges/input_range) [(1)](/docs/cpp/library/ranges/chunk_view#Version_1), `chunk_view`'s iterator has a dedicated type: [`outer_iterator::value_type`](/docs/cpp/library/ranges/chunk_view/outer_iterator/value_type) that is itself an input view.

{/* source:cpp-ranges-chunk-view:0016 */}
If `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range) or stronger [(2)](/docs/cpp/library/ranges/chunk_view#Version_2), `chunk_view` defers to `views::take` for its `value_type`.

{/* source:cpp-ranges-chunk-view:0017 */}
If `V` models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range) or stronger ranges [(2)](/docs/cpp/library/ranges/chunk_view#Version_2), the need to calculate size the last chunk correctly (from the end [`iterator`](/docs/cpp/library/ranges/chunk_view/iterator)) requires the underlying range type `V` to be [`sized_range`](/docs/cpp/library/ranges/sized_range).

### Example

{/* source:cpp-ranges-chunk-view:0019 */}
```cpp
#include <algorithm>
#include <iostream>
#include <ranges>
 
auto print_subrange = [](std::ranges::viewable_range auto&& r)
{
    std::cout << '[';
    for (int pos{}; auto elem : r)
        std::cout << (pos++ ? " " : "") << elem;
    std::cout << "] ";
};
 
int main()
{
    const auto v = {1, 2, 3, 4, 5, 6};
 
    for (const unsigned width : std::views::iota(1U, 2U + v.size()))
    {
        auto const chunks = v | std::views::chunk(width);
        std::cout << "chunk(" << width << "): ";
        std::ranges::for_each(chunks, print_subrange);
        std::cout << '\n';
    }
}
```

Output:

```text
chunk(1): [1] [2] [3] [4] [5] [6]
chunk(2): [1 2] [3 4] [5 6]
chunk(3): [1 2 3] [4 5 6]
chunk(4): [1 2 3 4] [5 6]
chunk(5): [1 2 3 4 5] [6]
chunk(6): [1 2 3 4 5 6]
chunk(7): [1 2 3 4 5 6]
```
