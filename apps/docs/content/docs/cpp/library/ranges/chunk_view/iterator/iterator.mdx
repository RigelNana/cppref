  Construct an iterator.

  <DeclarationDescription>
    {/* source:cpp-ranges-chunk-view-iterator-iterator:0002 */}
    1. 1) Default constructor. [`Value-initializes`](/docs/cpp/language/initialization/value_initialization) the underlying [`data members`](/docs/cpp/library/ranges/chunk_view/iterator#Data_members):
       - `current_` with `ranges::iterator_t<Base>()`,
       - `end_` with `ranges::sentinel_t<Base>()`,
       - `n_` with `​0​`,
       - `missing_` with `​0​`.

    {/* source:cpp-ranges-chunk-view-iterator-iterator:0003 */}
    2. 2) Conversion from `/*iterator*/<false>` to `/*iterator*/<true>`. Initializes the underlying [`data members`](/docs/cpp/library/ranges/chunk_view/iterator#Data_members):
       - `current_` with `std::move(i.current_)`,
       - `end_` with `std::move(i.end_)`,
       - `n_` with `i.n_`,
       - `missing_` with `i.missing_`.

    {/* source:cpp-ranges-chunk-view-iterator-iterator:0004 */}
    3. 3) A private constructor which is used by `ranges::chunk_view::begin` and `ranges::chunk_view::end`. This constructor is not accessible to users. Initializes the underlying [`data members`](/docs/cpp/library/ranges/chunk_view/iterator#Data_members):
       - `current_` with `current`,
       - `end_` with `ranges::end(parent->base_)`,
       - `n_` with `parent->n_`,
       - `missing_` with `missing`.
  </DeclarationDescription>
</DeclarationDoc>
