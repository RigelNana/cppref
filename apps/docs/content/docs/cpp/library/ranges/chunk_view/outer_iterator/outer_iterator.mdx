Construct an iterator.

{/* source:cpp-ranges-chunk-view-outer-iterator-outer-iterator:0002 */}
1. 1) Move constructor. Move-initializes the underlying pointer [`parent_`](/docs/cpp/library/ranges/chunk_view/outer_iterator#Data_members) with `other.`[`parent_`](/docs/cpp/library/ranges/chunk_view/outer_iterator#Data_members).

{/* source:cpp-ranges-chunk-view-outer-iterator-outer-iterator:0003 */}
2. 2) A private constructor which is used by [`chunk_view::begin`](/docs/cpp/library/ranges/chunk_view/begin). This constructor is not accessible to users. Initializes [`parent_`](/docs/cpp/library/ranges/chunk_view/outer_iterator#Data_members) with `std::addressof(parent)`.
