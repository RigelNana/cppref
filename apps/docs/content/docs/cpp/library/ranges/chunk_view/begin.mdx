{/* source:cpp-ranges-chunk-view-begin:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/chunk_view/iterator) to the first element of the `chunk_view`.

{/* source:cpp-ranges-chunk-view-begin:0002 */}
Let [`base_`](/docs/cpp/library/ranges/chunk_view#Data_members) denote the underlying view.

{/* source:cpp-ranges-chunk-view-begin:0003 */}
1. 1) Available only if `V` models [`input_range`](/docs/cpp/library/ranges/input_range). Equivalent to:

```cpp
current_ = ranges::begin(base_);
remainder_ = n_;
return __outer_iterator(*this);
```

[`current_`](/docs/cpp/library/ranges/chunk_view#Data_members), [`remainder_`](/docs/cpp/library/ranges/chunk_view#Data_members), and [`n_`](/docs/cpp/library/ranges/chunk_view#Data_members) are underlying exposition only data members of [`chunk_view`](/docs/cpp/library/ranges/chunk_view).

{/* source:cpp-ranges-chunk-view-begin:0004 */}
2. 2) Available if `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range). Equivalent to: `return iterator<false>(this, ranges::begin(base_));`, where [`iterator`](/docs/cpp/library/ranges/chunk_view#Nested_classes) is exposition only nested class.

{/* source:cpp-ranges-chunk-view-begin:0005 */}
3. 3) Available if `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range). Equivalent to: `return iterator<true>(this, ranges::begin(base_));`, where [`iterator`](/docs/cpp/library/ranges/chunk_view#Nested_classes) is exposition only nested class.

### Parameters

{/* source:cpp-ranges-chunk-view-begin:0006 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-view-begin:0007 */}
An iterator to the first element of the [`chunk_view`](/docs/cpp/library/ranges/chunk_view), as described above.
