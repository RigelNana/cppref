{/* source:cpp-ranges-chunk-view-size:0001 */}
Returns the number of elements, which is the smallest integer value that is not less than the quotient of dividing the size of underlying view [`base_`](/docs/cpp/library/ranges/chunk_view#Data_members) by the underlying data member [`n_`](/docs/cpp/library/ranges/chunk_view#Data_members), that holds the number passed to the constructor (`0` if default constructed). Equivalent to

{/* source:cpp-ranges-chunk-view-size:0002 */}
```cpp
return __to_unsigned_like(__div_ceil(ranges::distance(base_), n_));
```

### Parameters

{/* source:cpp-ranges-chunk-view-size:0003 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-view-size:0004 */}
The number of elements.

### Example

{/* source:cpp-ranges-chunk-view-size:0005 */}
```cpp
#include <ranges>
 
int main()
{
    constexpr static auto v = {1, 2, 3, 4, 5};
    constexpr auto w{ std::ranges::chunk_view(v, 2) };
    static_assert(w.size() == (5 / 2 + (5 % 2 ? 1 : 0)));
}
```
