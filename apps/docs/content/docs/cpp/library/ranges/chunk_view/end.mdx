{/* source:cpp-ranges-chunk-view-end:0001 */}
Returns an [`iterator`](/docs/cpp/library/ranges/chunk_view#Nested_classes) or a [`std::default_sentinel`](/docs/cpp/library/iterator/default_sentinel) that compares equal to the end iterator of the [`chunk_view`](/docs/cpp/library/ranges/chunk_view).

{/* source:cpp-ranges-chunk-view-end:0002 */}
1. 1) Available only if `V` models [`input_range`](/docs/cpp/library/ranges/input_range). Equivalent to: `return std::default_sentinel`.

{/* source:cpp-ranges-chunk-view-end:0003 */}
2. 2,3) Available if `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range). Let [`base_`](/docs/cpp/library/ranges/chunk_view#Data_members) denote the underlying adapted view, [`n_`](/docs/cpp/library/ranges/chunk_view#Data_members) denote the stored chunk size, and [`iterator`](/docs/cpp/library/ranges/chunk_view#Nested_classes) denote the nested iterator class.

{/* source:cpp-ranges-chunk-view-end:0004 */}
2. 2) Equivalent to:

```cpp
if constexpr (ranges::common_range<V> && ranges::sized_range<V>)
{
    auto missing = (n_ - ranges::distance(base_) % n_) % n_;
    return iterator<false>(this, ranges::end(base_), missing);
}
else if constexpr (ranges::common_range<V> && !ranges::bidirectional_range<V>)
    return iterator<false>(this, ranges::end(base_));
else
    return std::default_sentinel;
```

{/* source:cpp-ranges-chunk-view-end:0005 */}
3. 3) Equivalent to:

```cpp
if constexpr (ranges::common_range<const V> && ranges::sized_range<const V>)
{
    auto missing = (n_ - ranges::distance(base_) % n_) % n_;
    return iterator<true>(this, ranges::end(base_), missing);
}
else if constexpr (ranges::common_range<const V> && !ranges::bidirectional_range<const V>)
    return iterator<true>(this, ranges::end(base_));
else
    return std::default_sentinel;
```

### Parameters

{/* source:cpp-ranges-chunk-view-end:0006 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-view-end:0007 */}
An iterator or sentinel representing the end of the [`chunk_view`](/docs/cpp/library/ranges/chunk_view), as described above.
