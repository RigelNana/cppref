{/* source:cpp-ranges-chunk-view-outer-iterator-operator-cmp:0001 */}
Compares the [`iterator`](/docs/cpp/library/ranges/chunk_view/outer_iterator) and the [`sentinel`](/docs/cpp/library/iterator/default_sentinel).

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-cmp:0002 */}
Let [`parent_`](/docs/cpp/library/ranges/chunk_view/outer_iterator#Data_members) be the underlying pointer to enclosing `chunk_view`. Equivalent to:

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-cmp:0003 */}
```cpp
return *x.parent_->current_ == ranges::end(x.parent_->base_) and x.parent_->remainder_ != 0;
```

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-cmp:0004 */}
This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `std::ranges::chunk_view::outer-iterator` is an associated class of the arguments.

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-cmp:0005 */}
The `!=` operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
