{/* source:cpp-ranges-chunk-view-iterator-operator-star:0001 */}
Returns the current element in the `chunk_view`.

{/* source:cpp-ranges-chunk-view-iterator-operator-star:0002 */}
Let `current_`, `end_`, and `n_` be the underlying [data members](/docs/cpp/library/ranges/chunk_view/iterator#Data_members).

{/* source:cpp-ranges-chunk-view-iterator-operator-star:0003 */}
Equivalent to: `return views::take(ranges::subrange(current_, end_), n_)`.

{/* source:cpp-ranges-chunk-view-iterator-operator-star:0004 */}
Before the invocation the expression `current_ != end_` must be `true`, otherwise the behavior is undefined.

### Parameters

{/* source:cpp-ranges-chunk-view-iterator-operator-star:0005 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-view-iterator-operator-star:0006 */}
The current element, which is an object of [`value_type`](/docs/cpp/library/ranges/chunk_view/iterator#Member_types).
