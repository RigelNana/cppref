{/* source:cpp-ranges-chunk-view-base:0001 */}
Returns a copy of the underlying view.

{/* source:cpp-ranges-chunk-view-base:0002 */}
Let [`base_`](/docs/cpp/library/ranges/chunk_view#Data_members) be the underlying view.

{/* source:cpp-ranges-chunk-view-base:0003 */}
1. 1) Copy constructs the result from the underlying view. Equivalent to `return base_;`

{/* source:cpp-ranges-chunk-view-base:0004 */}
2. 2) Move constructs the result from the underlying view. Equivalent to `return std::move(base_);`

### Parameters

{/* source:cpp-ranges-chunk-view-base:0005 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-view-base:0006 */}
A copy of the underlying view.

### Example

{/* source:cpp-ranges-chunk-view-base:0007 */}
A link to test the example online: [Compiler Explorer](https://godbolt.org/z/K6KT6M6K3).

```cpp
#include <print>
#include <ranges>
 
int main()
{
    static constexpr auto v = {1, 2, 3, 4};
    constexpr auto w{std::ranges::chunk_view(v, 2)};
    std::println("{}", w.base());
}
```

Output:

```text
[1, 2, 3, 4]
```
