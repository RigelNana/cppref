{/* source:cpp-ranges-chunk-view-inner-iterator-iter-move:0001 */}
Returns the result of applying [`ranges::iter_move`](/docs/cpp/library/iterator/ranges/iter_move) to the stored inner iterator.

{/* source:cpp-ranges-chunk-view-inner-iterator-iter-move:0002 */}
Let [`parent_`](/docs/cpp/library/ranges/chunk_view/inner_iterator#Data_members) be the underlying pointer to the enclosing `chunk_view`, and `*i.parent_->current_` denote the cached underlying iterator of type `ranges::iterator_t<V>`.

{/* source:cpp-ranges-chunk-view-inner-iterator-iter-move:0003 */}
Equivalent to: `return ranges::iter_move(*i.parent_->current_);`.

{/* source:cpp-ranges-chunk-view-inner-iterator-iter-move:0004 */}
This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `chunk_view::inner-iterator` is an associated class of the arguments.

### Return value

{/* source:cpp-ranges-chunk-view-inner-iterator-iter-move:0006 */}
The result of applying `ranges::iter_move` to the stored iterator of type `ranges::iterator_t<V>`.

### Exceptions

{/* source:cpp-ranges-chunk-view-inner-iterator-iter-move:0007 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(noexcept(ranges::iter_move(*i.parent_->current_)))`
