{/* source:cpp-ranges-chunk-view-outer-iterator-operator-star:0001 */}
Returns the current chunk in the `chunk_view`.

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-star:0002 */}
Let [`parent_`](/docs/cpp/library/ranges/chunk_view/outer_iterator#Data_members) be the underlying pointer, and [`value_type`](/docs/cpp/library/ranges/chunk_view/outer_iterator#Nested_classes) be a nested class that is the value type of the [`iterator`](/docs/cpp/library/ranges/chunk_view/outer_iterator).

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-star:0003 */}
Equivalent to: `return value_type(*parent_);`.

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-star:0004 */}
Before invocation of this operator the expression `*this == std::default_sentinel` must be `false`.

### Parameters

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-star:0005 */}
(none)

### Return value

{/* source:cpp-ranges-chunk-view-outer-iterator-operator-star:0006 */}
The current element (a chunk).
