  {/* source:cpp-ranges-chunk-view-iterator-operator-arith:0001 */}
  Advances or decrements the [iterator](/docs/cpp/library/ranges/chunk_view/iterator/iterator).

  {/* source:cpp-ranges-chunk-view-iterator-operator-arith:0002 */}
  Let `current_`, `end_`, and `n_` be the underlying [data members](/docs/cpp/library/ranges/chunk_view/iterator#Data_members) of [`chunk_view::iterator`](/docs/cpp/library/ranges/chunk_view/iterator).
</DeclarationDoc>

{/* source:cpp-ranges-chunk-view-iterator-operator-arith:0003 */}
1. 1) Equivalent to:

   ```cpp
   missing_ = ranges::advance(current_, n_, end_);
   return *this;
   ```

   Before the invocation the expression `current_ != end_` must be `true`, otherwise the behavior is undefined.

{/* source:cpp-ranges-chunk-view-iterator-operator-arith:0004 */}
2. 2) Equivalent to: `auto tmp = *this; ++*this; return tmp;`.

{/* source:cpp-ranges-chunk-view-iterator-operator-arith:0005 */}
3. 3) Equivalent to:

   ```cpp
   ranges::advance(current_, missing_ - n_);
   missing_ = 0;
   return *this;
   ```

{/* source:cpp-ranges-chunk-view-iterator-operator-arith:0006 */}
4. 4) Equivalent to: `auto tmp = *this; --*this; return tmp;`.

{/* source:cpp-ranges-chunk-view-iterator-operator-arith:0007 */}
5. 5) Equivalent to:

   ```cpp
   if (x > 0)
   {
       ranges::advance(current_, n_ * (x - 1));
       missing_ = ranges::advance(current_, n_, end_);
   }
   else if (x < 0)
   {
       ranges::advance(current_, n_ * x + missing_);
       missing_ = 0;
   }
   return *this;
   ```

   If `x` is positive, then before the invocation the expression `ranges::distance(current_, end_) > n_ * (x - 1)` must be `true` (i.e., informally, the requested chunk should be "inside" the underlying sequence). If `x` is negative, this precondition is always met.

{/* source:cpp-ranges-chunk-view-iterator-operator-arith:0008 */}
6. 6) Equivalent to: `return *this += -x;`.
