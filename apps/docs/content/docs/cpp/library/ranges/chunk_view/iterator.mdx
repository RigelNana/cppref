{/* source:cpp-ranges-chunk-view-iterator:0001 */}
The return type of [`chunk_view::begin`](/docs/cpp/library/ranges/chunk_view/begin), and of [`chunk_view::end`](/docs/cpp/library/ranges/chunk_view/end) when the underlying view `V` is a [`common_range`](/docs/cpp/library/ranges/common_range).

{/* source:cpp-ranges-chunk-view-iterator:0002 */}
Present only if `V` models [`forward_range`](/docs/cpp/library/ranges/forward_range).

{/* source:cpp-ranges-chunk-view-iterator:0003 */}
The type `/*iterator*/<true>` is returned by the const-qualified overloads. The type `/*iterator*/<false>` is returned by the non-const-qualified overloads.
