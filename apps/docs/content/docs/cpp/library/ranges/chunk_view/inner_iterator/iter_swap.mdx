{/* source:cpp-ranges-chunk-view-inner-iterator-iter-swap:0001 */}
Applies [`ranges::iter_swap`](/docs/cpp/library/iterator/ranges/iter_swap) to the underlying cached iterators.

{/* source:cpp-ranges-chunk-view-inner-iterator-iter-swap:0002 */}
Let [`parent_`](/docs/cpp/library/ranges/chunk_view/inner_iterator#Data_members) be the underlying pointer to the enclosing `chunk_view`, and `*i.parent_->current_` denote the underlying cached iterator of type `ranges::iterator_t<V>`.

{/* source:cpp-ranges-chunk-view-inner-iterator-iter-swap:0003 */}
Equivalent to: `ranges::iter_swap(*x.parent_->current_, *y.parent_->current_);`.

{/* source:cpp-ranges-chunk-view-inner-iterator-iter-swap:0004 */}
This function is not visible to ordinary [`unqualified`](/docs/cpp/language/basic_concepts/unqualified_lookup) or [`qualified lookup`](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [`argument-dependent lookup`](/docs/cpp/language/functions/adl) when `chunk_view::inner-iterator` is an associated class of the arguments.
