  <DeclarationDescription>
    {/* source:cpp-ranges-reverse-view:0001 */}
    1) A range adaptor that represents a view of underlying [`view`](/docs/cpp/library/ranges/view) with reversed order.

    {/* source:cpp-ranges-reverse-view:0002 */}
    2) [RangeAdaptorObject](/docs/cpp/library/named_req/RangeAdaptorObject). The expression `views::reverse(e)` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to one of the following expressions, except that `e` is evaluated only once:

    - `e.base()`, if the type of `e` is a (possibly cv-qualified) specialization of `reverse_view`;
    - otherwise, if the type of `e` is (possibly cv-qualified) `ranges::subrange<std::reverse_iterator<I>, std::reverse_iterator<I>, K>` for some iterator type `I` and value `K` of type `ranges::subrange_kind`:

      - `ranges::subrange<I, I, K>(e.end().base(), e.begin().base(), e.size())`, if `K` is `ranges::subrange_kind::sized`;
      - otherwise `ranges::subrange<I, I, K>(e.end().base(), e.begin().base())`;
    - otherwise `ranges::reverse_view{e}`.

    In other words, `views::reverse` unwraps reversed views if possible.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-ranges-reverse-view:0003 */}
A `reverse_view` always models [`bidirectional_range`](/docs/cpp/library/ranges/bidirectional_range) and [`common_range`](/docs/cpp/library/ranges/common_range), and it models [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range), [`sized_range`](/docs/cpp/library/ranges/sized_range), or [`random_access_range`](/docs/cpp/library/ranges/random_access_range) if the underlying view type `V` models the corresponding concept.

This specialization of [`std::ranges::enable_borrowed_range`](/docs/cpp/library/ranges/borrowed_range) makes `reverse_view` satisfy [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range) when the underlying view satisfies it.

### Example

{/* source:cpp-ranges-reverse-view:0014 */}
```cpp
#include <iostream>
#include <ranges>
 
int main()
{
    static constexpr auto il = {3, 1, 4, 1, 5, 9};
 
    std::ranges::reverse_view rv{il};
    for (int i : rv)
        std::cout << i << ' ';
    std::cout << '\n';
 
    for (int i : il | std::views::reverse)
        std::cout << i << ' ';
    std::cout << '\n';
 
    // operator[] is inherited from std::view_interface
    for (auto i{0U}; i != rv.size(); ++i)
        std::cout << rv[i] << ' ';
    std::cout << '\n';
}
```

Output:

```text
9 5 1 4 1 3
9 5 1 4 1 3
9 5 1 4 1 3
```
