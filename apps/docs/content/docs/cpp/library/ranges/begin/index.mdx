{/* source:cpp-ranges-begin:0001 */}
Returns an iterator to the first element of the argument.

{/* source:cpp-ranges-begin:0002 */}
If the argument is an lvalue or `ranges::enable_borrowed_range<std::remove_cv_t<T>>` is `true`, then a call to `ranges::begin` is [expression-equivalent](/docs/cpp/language/expressions#Expression-equivalence) to:

{/* source:cpp-ranges-begin:0003 */}
1. `t + 0` if `t` has an array type.
   - If `std::remove_all_extents_t<std::remove_reference_t<T>>` is incomplete, then the call to `ranges::begin` is ill-formed, no diagnostic required.
2. Otherwise, <InlineRevision until="C++23">[`decay-copy`](/docs/cpp/library/standard_library/decay-copy) `(t.begin())`</InlineRevision><InlineRevision since="C++23">`auto(t.begin())`</InlineRevision>, if that expression is valid and its type models [`std::input_or_output_iterator`](/docs/cpp/library/iterator/input_or_output_iterator).
3. Otherwise, <InlineRevision until="C++23">[`decay-copy`](/docs/cpp/library/standard_library/decay-copy) `(begin(t))`</InlineRevision><InlineRevision since="C++23">`auto(begin(t))`</InlineRevision>, if `T` is a class or enumeration type, that expression is valid and its type models [`std::input_or_output_iterator`](/docs/cpp/library/iterator/input_or_output_iterator), where the meaning of `begin` is established as if by performing [argument-dependent lookup](/docs/cpp/language/functions/adl) only.

{/* source:cpp-ranges-begin:0004 */}
In all other cases, a call to `ranges::begin` is ill-formed, which can result in [substitution failure](/docs/cpp/language/templates/sfinae) when the call appears in the immediate context of a template instantiation.

### Customization point objects

{/* source:cpp-ranges-begin:0005 */}
The name `ranges::begin` denotes a *customization point object*, which is a const [function object](/docs/cpp/library/named_req/FunctionObject) of a [literal](/docs/cpp/library/named_req/LiteralType) [`semiregular`](/docs/cpp/library/concepts/semiregular) class type. For exposition purposes, the cv-unqualified version of its type is denoted as `__begin_fn`.

{/* source:cpp-ranges-begin:0006 */}
All instances of `__begin_fn` are equal. The effects of invoking different instances of type `__begin_fn` on the same arguments are equivalent, regardless of whether the expression denoting the instance is an lvalue or rvalue, and is const-qualified or not (however, a volatile-qualified instance is not required to be invocable). Thus, `ranges::begin` can be copied freely and its copies can be used interchangeably.

{/* source:cpp-ranges-begin:0007 */}
Given a set of types `Args...`, if `std::declval<Args>()...` meet the requirements for arguments to `ranges::begin` above, `__begin_fn` models

{/* source:cpp-ranges-begin:0008 */}
- `std::invocable<__begin_fn, Args...>`,
- `std::invocable<const __begin_fn, Args...>`,
- `std::invocable<__begin_fn&, Args...>`, and
- `std::invocable<const __begin_fn&, Args...>`.

{/* source:cpp-ranges-begin:0009 */}
Otherwise, no function call operator of `__begin_fn` participates in overload resolution.

### Notes

{/* source:cpp-ranges-begin:0010 */}
If the argument is an rvalue (i.e. `T` is an object type) and `ranges::enable_borrowed_range<std::remove_cv_t<T>>` is `false`, the call to `ranges::begin` is ill-formed, which also results in substitution failure.

{/* source:cpp-ranges-begin:0011 */}
The return type models [`std::input_or_output_iterator`](/docs/cpp/library/iterator/input_or_output_iterator) in all cases.

{/* source:cpp-ranges-begin:0012 */}
The C++20 standard requires that if the underlying `begin` function call returns a prvalue, the return value is move-constructed from the materialized temporary object. All implementations directly return the prvalue instead. The requirement is corrected by the post-C++20 proposal [P0849R8](https://wg21.link/P0849R8) to match the implementations.

### Example

{/* source:cpp-ranges-begin:0013 */}
```cpp
#include <cassert>
#include <ranges>
#include <vector>
 
int main() 
{
    std::vector v{3, 1, 4};
    auto vi = std::ranges::begin(v);
    auto vci = std::ranges::cbegin(v);
    assert(*vi == 3 and *vi == *vci);
    ++vi;
    ++vci; // OK: vci is modifiable object
    *vi = 42; // OK: vi points to mutable element
    // *vci = 13; // Error: vci points to immutable element
 
    int a[]{-5, 10, 15};
    auto ai = std::ranges::begin(a); // works with C-arrays as well
    assert(*ai == -5);
    *ai = 42; // OK
}
```
