Specializations of the class template `std::fpos` identify absolute positions in a stream or in a file. Each object of type `fpos` holds the byte position in the stream (typically as a private member of type [`std::streamoff`](/docs/cpp/library/io/streamoff)) and the current shift state, a value of type `State` (typically [`std::mbstate_t`](/docs/cpp/library/text/multibyte/mbstate_t)).

{/* source:cpp-io-fpos:0002 */}
The following typedef names for `std::fpos<std::mbstate_t>` are provided (although they are spelled differently in the standard, they denote the same type):

{/* source:cpp-io-fpos:0004 */}
All specializations of `fpos` meet the [*DefaultConstructible*](/docs/cpp/library/named_req/DefaultConstructible), [*CopyConstructible*](/docs/cpp/library/named_req/CopyConstructible), [*CopyAssignable*](/docs/cpp/library/named_req/CopyAssignable), [*Destructible*](/docs/cpp/library/named_req/Destructible), and [*EqualityComparable*](/docs/cpp/library/named_req/EqualityComparable) requirements.

{/* source:cpp-io-fpos:0005 */}
If `State` is trivially copy constructible, `fpos` has a trivial copy constructor. If `State` is trivially copy assignable, `fpos` has a trivial copy assignment operator. If `State` is trivially destructible, `fpos` has a trivial destructor.

{/* source:cpp-io-fpos:0008 */}
In addition, member and non-member functions are provided to support the following operations:

{/* source:cpp-io-fpos:0009 */}
- A default constructor that stores an offset of zero and value-initializes the state object.

{/* source:cpp-io-fpos:0010 */}
- A non-explicit constructor that accepts an argument of type (possibly const) [`std::streamoff`](/docs/cpp/library/io/streamoff), which stores that offset and value-initializes the state object. This constructor must also accept the special value `std::streamoff(-1)`: the `std::fpos` constructed in this manner is returned by some stream operations to indicate errors.

{/* source:cpp-io-fpos:0011 */}
- Explicit conversion from (possibly const) `fpos` to [`std::streamoff`](/docs/cpp/library/io/streamoff). The result is the stored offset.

{/* source:cpp-io-fpos:0012 */}
- `operator==` and `operator!=` that compare two objects of type (possibly const) `std::fpos` and return a `bool` prvalue. `p != q` is equivalent to `!(p == q)`.

{/* source:cpp-io-fpos:0013 */}
- `operator+` and `operator-` such that, for an object `p` of type (possibly const) `fpos<State>` and an object `o` of type (possibly const) [`std::streamoff`](/docs/cpp/library/io/streamoff)

{/* source:cpp-io-fpos:0014 */}
  - `p + o` has type `fpos<State>` and stores an offset that is the result of adding `o` to the offset of `p`.
  - `o + p` has a type convertible to `fpos<State>` and the result of the conversion is equal to `p + o`.
  - `p - o` has type `fpos<State>` and stores an offset that is the result of subtracting `o` from the offset of `p`.

{/* source:cpp-io-fpos:0015 */}
- `operator+=` and `operator-=` which can accept a (possibly const) [`std::streamoff`](/docs/cpp/library/io/streamoff) and adds/subtracts it from the stored offset, respectively.

{/* source:cpp-io-fpos:0016 */}
- `operator-` which can subtract two objects of type (possibly const) `std::fpos` producing an [`std::streamoff`](/docs/cpp/library/io/streamoff), such that for two such objects `p` and `q`, `p == q + (p - q)`.

### Notes

{/* source:cpp-io-fpos:0017 */}
Some of the [I/O streams member functions](/docs/cpp/library/io) return and manipulate objects of member typedef `pos_type`. For streams, these member typedefs are provided by the template parameter `Traits`, which defaults to [`std::char_traits`](/docs/cpp/library/string/char_traits), which define their `pos_types` to be specializations of `std::fpos`. The behavior of the I/O streams library is implementation-defined when `Traits::pos_type` is not `std::fpos<std::mbstate_t>` (aka `std::streampos`, `std::wstreampos`, etc.).
