  <DeclarationDescription>
    {/* source:cpp-io-fpos-state:0001 */}
    Manages the file position state.

    {/* source:cpp-io-fpos-state:0002 */}
    1. Returns the value of the file position state.

    {/* source:cpp-io-fpos-state:0003 */}
    2. Replaces the file position state with the value of `st`.

    {/* source:cpp-io-fpos-state:0004 */}
    For the specializations of [`std::fpos`](/docs/cpp/library/io/fpos) that are used in the standard library, `State` is always [`std::mbstate_t`](/docs/cpp/library/text/multibyte/mbstate_t).
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-fpos-state:0005 */}
<ParameterList>
  <Parameter name="st">new value for the state</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-fpos-state:0006 */}
1. The current value of the `fpos` state.

{/* source:cpp-io-fpos-state:0007 */}
2. (none)

### Example

{/* source:cpp-io-fpos-state:0008 */}
```cpp
#include <cwchar>
#include <iostream>
#include <sstream>
 
int main()
{
    std::istringstream s("test");
    std::mbstate_t st = s.tellg().state();
 
    if (std::mbsinit(&st))
        std::cout << "The stream is in the initial shift state\n";
}
```

Output:

```text
The stream is in the initial shift state
```
