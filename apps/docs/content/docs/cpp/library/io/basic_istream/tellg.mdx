Returns input position indicator of the current associated streambuf object.

{/* source:cpp-io-basic-istream-tellg:0002 */}
Behaves as [UnformattedInputFunction](/docs/cpp/library/named_req/UnformattedInputFunction), except that [`gcount()`](/docs/cpp/library/io/basic_istream/gcount) is not affected. After constructing and checking the sentry object, if `fail() == true`, returns `pos_type(-1)`. Otherwise, returns `rdbuf()->pubseekoff(0, std::ios_base::cur, std::ios_base::in)`.

### Parameters

{/* source:cpp-io-basic-istream-tellg:0003 */}
(none)

### Return value

{/* source:cpp-io-basic-istream-tellg:0004 */}
The current position of the get pointer on success, `pos_type(-1)` on failure.

### Exceptions

{/* source:cpp-io-basic-istream-tellg:0005 */}
If an internal operation throws an exception, it is caught and [`badbit`](/docs/cpp/library/io/ios_base/iostate) is set. If [`exceptions()`](/docs/cpp/library/io/basic_ios/exceptions) is set for `badbit`, the exception is rethrown.

### Example

{/* source:cpp-io-basic-istream-tellg:0006 */}
```cpp
#include <iostream>
#include <sstream>
#include <string>
 
int main()
{
    std::string str = "Hello, world";
    std::istringstream in(str);
    std::string word;
    in >> word;
    std::cout << "After reading the word \"" << word
              << "\" tellg() returns " << in.tellg() << '\n';
}
```

Output:

```text
After reading the word "Hello," tellg() returns 6
```
