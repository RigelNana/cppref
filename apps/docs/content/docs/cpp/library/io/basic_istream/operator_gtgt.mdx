  <DeclarationDescription>
    {/* source:cpp-io-basic-istream-operator-gtgt:0001 */}
    Extracts values from an input stream.

    {/* source:cpp-io-basic-istream-operator-gtgt:0002 */}
    1-11. Extracts a value potentially skipping preceding whitespace. The value is stored to a given reference `value`.

    {/* source:cpp-io-basic-istream-operator-gtgt:0003 */}
    This function behaves as a [FormattedInputFunction](/docs/cpp/library/named_req/FormattedInputFunction). After constructing and checking the sentry object, which may skip leading whitespace, extracts a value by calling [`std::num_get::get()`](/docs/cpp/library/text/locale/num_get/get).

    {/* source:cpp-io-basic-istream-operator-gtgt:0004 */}
    12. Extracts a `short` value potentially skipping preceding whitespace. The value is stored to a given reference `value`.

    {/* source:cpp-io-basic-istream-operator-gtgt:0005 */}
    This function behaves as a [FormattedInputFunction](/docs/cpp/library/named_req/FormattedInputFunction). After constructing and checking the sentry object, which may skip leading whitespace, extracts a `long` value `lval` by calling [`std::num_get::get()`](/docs/cpp/library/text/locale/num_get/get). After that:

    - If `lval < std::numeric_limits<short>::min()`, sets `failbit` and stores `std::numeric_limits<short>::min()` to `val`.
    - Otherwise, if `std::numeric_limits<short>::max() < lval`, sets `failbit` and stores `std::numeric_limits<short>::max()` to `val`.
    - Otherwise, stores `static_cast<short>(lval)` to `val`.

    {/* source:cpp-io-basic-istream-operator-gtgt:0006 */}
    13. Extracts an `int` value potentially skipping preceding whitespace. The value is stored to a given reference `value`.

    {/* source:cpp-io-basic-istream-operator-gtgt:0007 */}
    This function behaves as a [FormattedInputFunction](/docs/cpp/library/named_req/FormattedInputFunction). After constructing and checking the sentry object, which may skip leading whitespace, extracts a `long` value `lval` by calling [`std::num_get::get()`](/docs/cpp/library/text/locale/num_get/get). After that:

    - If `lval < std::numeric_limits<int>::min()`, sets `failbit` and stores `std::numeric_limits<int>::min()` to `val`.
    - Otherwise, if `std::numeric_limits<int>::max() < lval`, sets `failbit` and stores `std::numeric_limits<int>::max()` to `val`.
    - Otherwise, stores `static_cast<int>(lval)` to `val`.

    {/* source:cpp-io-basic-istream-operator-gtgt:0008 */}
    14. Extracts an extended floating-point value potentially skipping preceding whitespace. The value is stored to a given reference `value`. The library provides overloads for all cv-unqualified [extended floating-point types](/docs/cpp/language/basic_concepts/types#Extended_floating-point_types) as the referenced type of the parameter `value`.

    {/* source:cpp-io-basic-istream-operator-gtgt:0009 */}
    Determines the standard floating-point type `FP` as follows:

    - If the [floating-point conversion rank](/docs/cpp/language/expressions/usual_arithmetic_conversions#Floating-point_conversion_rank) of `/* extended-floating-point-type */` is less than or equal to that of `float`, then `FP` is `float`.
    - Otherwise, if the floating-point conversion rank of `/* extended-floating-point-type */` is less than or equal to that of `double`, then `FP` is `double`.
    - Otherwise, `FP` is `long double`.

    {/* source:cpp-io-basic-istream-operator-gtgt:0010 */}
    This function behaves as a [FormattedInputFunction](/docs/cpp/library/named_req/FormattedInputFunction). After constructing and checking the sentry object, which may skip leading whitespace, extracts an `FP` value `fval` by calling [`std::num_get::get()`](/docs/cpp/library/text/locale/num_get/get). After that:

    - If `fval < -std::numeric_limits</* extended-floating-point-type */>::max()`, sets `failbit` and stores `-std::numeric_limits</* extended-floating-point-type */>::max()` to `val`.
    - Otherwise, if `std::numeric_limits</* extended-floating-point-type */>::max() < fval`, sets `failbit` and stores `std::numeric_limits</* extended-floating-point-type */>::max()` to `val`.
    - Otherwise, stores `static_cast</* extended-floating-point-type */>(fval)` to `val`.

    {/* source:cpp-io-basic-istream-operator-gtgt:0011 */}
    15-17. Calls `func(*this)`, where `func` is an I/O manipulator.

    {/* source:cpp-io-basic-istream-operator-gtgt:0012 */}
    18. Behaves as an [UnformattedInputFunction](/docs/cpp/library/named_req/UnformattedInputFunction). After constructing and checking the sentry object, extracts all data from `*this` and stores it to `sb`. The extraction stops if one of the following conditions are met:

    - end-of-file occurs on the input sequence;
    - inserting in the output sequence fails (in which case the character to be inserted is not extracted);
    - an exception occurs (in which case the exception is caught, and only rethrown if it inserted no characters and `failbit` is enabled in `exceptions()`).

    In either case, stores the number of characters extracted in the member variable accessed by subsequent calls to [`gcount()`](/docs/cpp/library/io/basic_istream/gcount). If `sb` is a null pointer or if no characters were inserted into `sb`, calls `setstate(failbit)` (which may throw [`std::ios_base::failure`](/docs/cpp/library/io/ios_base/failure) if enabled).

    {/* source:cpp-io-basic-istream-operator-gtgt:0013 */}
    If extraction fails (e.g. if a letter was entered where a digit is expected), zero is written to `value` and `failbit` is set. For signed integers, if extraction results in the value too large or too small to fit in `value`, `std::numeric_limits<T>::max()` or `std::numeric_limits<T>::min()` (respectively) is written and `failbit` flag is set. For unsigned integers, if extraction results in the value too large or too small to fit in `value`, `std::numeric_limits<T>::max()` is written and `failbit` flag is set.

### Notes

{/* source:cpp-io-basic-istream-operator-gtgt:0017 */}
For overload ([`14`](/docs/cpp/library/io/basic_istream/operator_gtgt#Version_14)), when the extended floating-point type has a floating-point conversion rank that is not equal to the rank of any standard floating-point type, then double rounding during the conversion can result in inaccurate results. [`std::from_chars()`](/docs/cpp/library/text/from_chars) can be used in situations where maximum accuracy is important.

### Example

{/* source:cpp-io-basic-istream-operator-gtgt:0018 */}
```cpp
#include <iomanip>
#include <iostream>
#include <sstream>
 
int main()
{
    std::string input = "41 3.14 false hello world";
    std::istringstream stream(input);
 
    int n;
    double f;
    bool b;
 
    stream >> n >> f >> std::boolalpha >> b;
    std::cout << "n = " << n << '\n'
              << "f = " << f << '\n'
              << "b = " << std::boolalpha << b << '\n';
 
    // extract the rest using the streambuf overload
    stream >> std::cout.rdbuf();
    std::cout << '\n';
}
```

Output:

```text
n = 41
f = 3.14
b = false
hello world
```
