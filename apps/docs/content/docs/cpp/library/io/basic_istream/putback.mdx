{/* source:cpp-io-basic-istream-putback:0001 */}
Puts the character `ch` back to the input stream so the next extracted character will be `ch`.

{/* source:cpp-io-basic-istream-putback:0002 */}
First clears `eofbit`, then behaves as [UnformattedInputFunction](/docs/cpp/library/named_req/UnformattedInputFunction). After constructing and checking the sentry object, if [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf) is not null, calls [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf)`->sputbackc(ch)`, which calls [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf)`->pbackfail(ch)` if `ch` does not equal the most recently extracted character.

{/* source:cpp-io-basic-istream-putback:0003 */}
If `rdbuf()` is null or if `rdbuf->sputbackc(ch)` returns `Traits::eof()`, calls `setstate(badbit)`.

{/* source:cpp-io-basic-istream-putback:0004 */}
In any case, sets the [`gcount()`](/docs/cpp/library/io/basic_istream/gcount) counter to zero.

### Parameters

{/* source:cpp-io-basic-istream-putback:0005 */}
<ParameterList>
  <Parameter name="ch">character to put into input stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-istream-putback:0006 */}
`*this`

### Exceptions

{/* source:cpp-io-basic-istream-putback:0007 */}
If an internal operation throws an exception, it is caught and [`badbit`](/docs/cpp/library/io/ios_base/iostate) is set. If [`exceptions()`](/docs/cpp/library/io/basic_ios/exceptions) is set for `badbit`, the exception is rethrown.

### Example

{/* source:cpp-io-basic-istream-putback:0008 */}
Demonstrates the difference between modifying and non-modifying `putback()`.

```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::stringstream s1("Hello, world"); // IO stream
    s1.get();
    if (s1.putback('Y')) // modifies the buffer
        std::cout << s1.rdbuf() << '\n';
    else
        std::cout << "putback failed\n";
 
    std::cout << "--\n";
 
    std::istringstream s2("Hello, world"); // input-only stream
    s2.get();
    if (s2.putback('Y')) // cannot modify input-only buffer
        std::cout << s2.rdbuf() << '\n';
    else
        std::cout << "putback failed\n"; 
    s2.clear();
 
    std::cout << "--\n";
 
    if (s2.putback('H')) // non-modifying putback
        std::cout << s2.rdbuf() << '\n';
    else
        std::cout << "putback failed\n";
}
```

Output:

```text
Yello, world
--
putback failed
--
Hello, world
```
