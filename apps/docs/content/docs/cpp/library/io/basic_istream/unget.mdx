{/* source:cpp-io-basic-istream-unget:0001 */}
Makes the most recently extracted character available again.

{/* source:cpp-io-basic-istream-unget:0002 */}
<InlineRevision since="C++11">First, clears [`eofbit`](/docs/cpp/library/io/ios_base/iostate). Then,</InlineRevision> `unget` behaves as [UnformattedInputFunction](/docs/cpp/library/named_req/UnformattedInputFunction). After constructing and checking the sentry object, if any `ios_base::iostate` flags are set, the function sets `failbit` and returns. Otherwise, calls `rdbuf()->sungetc()`.

{/* source:cpp-io-basic-istream-unget:0003 */}
If `rdbuf()->sungetc()` returns `Traits::eof()`, calls `setstate(badbit)`.

{/* source:cpp-io-basic-istream-unget:0004 */}
In any case, sets the `gcount()` counter to zero.

### Parameters

{/* source:cpp-io-basic-istream-unget:0005 */}
(none)

### Return value

{/* source:cpp-io-basic-istream-unget:0006 */}
`*this`

### Exceptions

{/* source:cpp-io-basic-istream-unget:0007 */}
If an internal operation throws an exception, it is caught and [`badbit`](/docs/cpp/library/io/ios_base/iostate) is set. If [`exceptions()`](/docs/cpp/library/io/basic_ios/exceptions) is set for `badbit`, the exception is rethrown.

### Example

{/* source:cpp-io-basic-istream-unget:0008 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::istringstream s1("Hello, world.");
    char c1 = s1.get();
    if (s1.unget())
    {
        char c2 = s1.get();
        std::cout << "Got: '" << c1 << "'. Got again: '" << c2 << "'.\n";
    }
}
```

Output:

```text
Got: 'H'. Got again: 'H'.
```
