Behaves as [UnformattedInputFunction](/docs/cpp/library/named_req/UnformattedInputFunction). After constructing and testing the sentry object, reads the next character from the input stream without extracting it.

### Parameters

{/* source:cpp-io-basic-istream-peek:0002 */}
(none)

### Return value

{/* source:cpp-io-basic-istream-peek:0003 */}
If `good() == true`, returns the next character as obtained by `rdbuf()->sgetc()`.

{/* source:cpp-io-basic-istream-peek:0004 */}
Otherwise, returns `Traits::eof()`.

### Exceptions

{/* source:cpp-io-basic-istream-peek:0005 */}
If an internal operation throws an exception, it is caught and [`badbit`](/docs/cpp/library/io/ios_base/iostate) is set. If [`exceptions()`](/docs/cpp/library/io/basic_ios/exceptions) is set for `badbit`, the exception is rethrown.

### Example

{/* source:cpp-io-basic-istream-peek:0006 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::istringstream s1("Hello, world.");
    char c1 = s1.peek();
    char c2 = s1.get();
    std::cout << "Peeked: " << c1 << " got: " << c2 << '\n';
}
```

Output:

```text
Peeked: H got: H
```
