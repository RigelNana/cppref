  <DeclarationDescription>
    {/* source:cpp-io-basic-istream-seekg:0001 */}
    Sets input position indicator of the current associated streambuf object.

    {/* source:cpp-io-basic-istream-seekg:0002 */}
    <Revision since="C++11">
    Before doing anything else, `seekg` clears `eofbit`.
    </Revision>

    {/* source:cpp-io-basic-istream-seekg:0003 */}
    `seekg` behaves as [UnformattedInputFunction](/docs/cpp/library/named_req/UnformattedInputFunction), except that [`gcount()`](/docs/cpp/library/io/basic_istream/gcount) is not affected. After constructing and checking the sentry object,

    {/* source:cpp-io-basic-istream-seekg:0004 */}
    1. if `fail() != true`, sets the input position indicator to absolute (relative to the beginning of the file) value `pos`. Specifically, executes `rdbuf()->pubseekpos(pos, std::ios_base::in)` ([`pubseekpos`](/docs/cpp/library/io/basic_streambuf/pubseekpos), in turn, calls `seekpos` of the specific buffer, such as [`basic_filebuf::seekpos`](/docs/cpp/library/io/basic_filebuf/seekpos), [`basic_stringbuf::seekpos`](/docs/cpp/library/io/basic_stringbuf/seekpos), or [`strstreambuf::seekpos`](/docs/cpp/library/io/strstreambuf/seekpos)). In case of failure, calls `setstate(std::ios_base::failbit)`.

    {/* source:cpp-io-basic-istream-seekg:0005 */}
    2. if `fail() != true`, sets the input position indicator to position `off`, relative to position, defined by `dir`. Specifically, executes `rdbuf()->pubseekoff(off, dir, std::ios_base::in)`. In case of failure, calls `setstate(std::ios_base::failbit)`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-basic-istream-seekg:0006 */}
<ParameterList>
  <Parameter name="pos">absolute position to set the input position indicator to</Parameter>
  <Parameter name="off">relative position (positive or negative) to set the input position indicator to</Parameter>
  <Parameter name="dir">defines base position to apply the relative offset to. It can be one of the following constants:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`beg`](/docs/cpp/library/io/ios_base/seekdir) | the beginning of a stream |
| [`end`](/docs/cpp/library/io/ios_base/seekdir) | the ending of a stream |
| [`cur`](/docs/cpp/library/io/ios_base/seekdir) | the current position of stream position indicator |

### Return value

{/* source:cpp-io-basic-istream-seekg:0007 */}
`*this`

### Exceptions

{/* source:cpp-io-basic-istream-seekg:0008 */}
If an internal operation throws an exception, it is caught and [`badbit`](/docs/cpp/library/io/ios_base/iostate) is set. If [`exceptions()`](/docs/cpp/library/io/basic_ios/exceptions) is set for `badbit`, the exception is rethrown.

### Notes

{/* source:cpp-io-basic-istream-seekg:0009 */}
`seekg(n)` is not necessarily equivalent to `seekg(n, ios::beg)`. `std::basic_ifstream`, for example, requires the absolute position `n` to come from [`tellg()`](/docs/cpp/library/io/basic_istream/tellg).

### Example

{/* source:cpp-io-basic-istream-seekg:0010 */}
```cpp
#include <iostream>
#include <sstream>
#include <string>
 
int main()
{
    std::string str = "Hello, world";
    std::istringstream in(str);
    std::string word1, word2;
 
    in >> word1;
    in.seekg(0); // rewind
    in >> word2;
 
    std::cout << "word1 = " << word1 << '\n'
              << "word2 = " << word2 << '\n';
}
```

Output:

```text
word1 = Hello,
word2 = Hello,
```
