{/* source:cpp-io-basic-istream-gcount:0001 */}
Returns the number of characters extracted by the last [unformatted input operation](/docs/cpp/library/named_req/UnformattedInputFunction), or the maximum representable value of [`std::streamsize`](/docs/cpp/library/io/streamsize) if the number is not representable.

{/* source:cpp-io-basic-istream-gcount:0002 */}
The following member functions of `basic_istream` change the value of subsequent `gcount()` calls:

{/* source:cpp-io-basic-istream-gcount:0003 */}
- [move constructor](/docs/cpp/library/io/basic_istream/basic_istream)
- [`swap()`](/docs/cpp/library/io/basic_ios/swap)
- [`get()`](/docs/cpp/library/io/basic_istream/get)
- [`getline()`](/docs/cpp/library/io/basic_istream/getline)
- [`ignore()`](/docs/cpp/library/io/basic_istream/ignore)
- [`read()`](/docs/cpp/library/io/basic_istream/read)
- [`readsome()`](/docs/cpp/library/io/basic_istream/readsome)
- [`operator>>(basic_streambuf*)`](/docs/cpp/library/io/basic_istream/operator_gtgt)

{/* source:cpp-io-basic-istream-gcount:0004 */}
The following functions set `gcount()` to zero:

{/* source:cpp-io-basic-istream-gcount:0005 */}
- [constructor](/docs/cpp/library/io/basic_istream/basic_istream)
- [`putback()`](/docs/cpp/library/io/basic_istream/putback)
- [`unget()`](/docs/cpp/library/io/basic_istream/unget)
- [`peek()`](/docs/cpp/library/io/basic_istream/peek)

### Parameters

{/* source:cpp-io-basic-istream-gcount:0006 */}
(none)

### Return value

{/* source:cpp-io-basic-istream-gcount:0007 */}
The number of characters extracted by the last unformatted input operation, or the maximum representable value of [`std::streamsize`](/docs/cpp/library/io/streamsize) if the number is not representable.

### Example

{/* source:cpp-io-basic-istream-gcount:0008 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    char x[20];
    std::istringstream stream("Hello World");
 
    stream.read(x, sizeof x);
    std::cout << "Characters extracted: " << stream.gcount();
}
```

Output:

```text
Characters extracted: 11
```
