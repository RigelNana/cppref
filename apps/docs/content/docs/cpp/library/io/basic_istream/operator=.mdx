<DeclarationDoc>
  <Declaration id="1" language="cpp" code={`protected:
basic_istream& operator=( const basic_istream& rhs ) = delete;`} />
  <Declaration id="2" language="cpp" since="C++11" code={`protected:
basic_istream& operator=( basic_istream&& rhs );`} />

  <DeclarationDescription>
    {/* source:cpp-io-basic-istream-operator:0001 */}
    1. The copy assignment operator is protected, and is deleted. Input streams are not `CopyAssignable`.

    {/* source:cpp-io-basic-istream-operator:0002 */}
    2. The move assignment operator exchanges the [`gcount()`](/docs/cpp/library/io/basic_istream/gcount) values and all data members of the base class, except for [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf), with `rhs`, as if by calling `swap(*rhs)`. This move assignment operator is protected: it is only called by the move assignment operators of the derived movable input stream classes [`std::basic_ifstream`](/docs/cpp/library/io/basic_ifstream) and [`std::basic_istringstream`](/docs/cpp/library/io/basic_istringstream), which know how to correctly move-assign the associated streambuffers.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

### Example

{/* source:cpp-io-basic-istream-operator:0004 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::istringstream s1;
    s1 = std::istringstream("test"); // OK
 
//  std::cin = std::istringstream("test"); // ERROR: 'operator=' is protected
}
```
