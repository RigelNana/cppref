{/* source:cpp-io-basic-istream-ignore:0001 */}
Extracts and discards characters from the input stream until and including `delim`.

{/* source:cpp-io-basic-istream-ignore:0002 */}
`ignore` behaves as an [UnformattedInputFunction](/docs/cpp/library/named_req/UnformattedInputFunction). After constructing and checking the sentry object, it extracts characters from the stream and discards them until any of the following conditions occurs:

{/* source:cpp-io-basic-istream-ignore:0003 */}
- `count` characters were extracted. This test is disabled in the special case when `count` equals `std::numeric_limits<std::streamsize>::max()`.

{/* source:cpp-io-basic-istream-ignore:0004 */}
- end of file conditions occurs in the input sequence, in which case the function calls `setstate(eofbit)`.

{/* source:cpp-io-basic-istream-ignore:0005 */}
- the next available character `c` in the input sequence is `delim`, as determined by `Traits::eq_int_type(Traits::to_int_type(c), delim)`. The delimiter character is extracted and discarded. This test is disabled if `delim` is `Traits::eof()`.

### Parameters

{/* source:cpp-io-basic-istream-ignore:0006 */}
<ParameterList>
  <Parameter name="count">number of characters to extract</Parameter>
  <Parameter name="delim">delimiting character to stop the extraction at. It is also extracted</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-istream-ignore:0007 */}
`*this`

### Exceptions

{/* source:cpp-io-basic-istream-ignore:0008 */}
If an internal operation throws an exception, it is caught and [`badbit`](/docs/cpp/library/io/ios_base/iostate) is set. If [`exceptions()`](/docs/cpp/library/io/basic_ios/exceptions) is set for `badbit`, the exception is rethrown.

### Example

{/* source:cpp-io-basic-istream-ignore:0009 */}
The following example uses `ignore` to skip over non-numeric input:

```cpp
#include <iostream>
#include <limits>
#include <sstream>
 
constexpr auto max_size = std::numeric_limits<std::streamsize>::max();
 
int main()
{
    std::istringstream input("1\n"
                             "some non-numeric input\n"
                             "2\n");
    for (;;)
    {
        int n;
        input >> n;
 
        if (input.eof() || input.bad())
            break;
        else if (input.fail())
        {
            input.clear(); // unset failbit
            input.ignore(max_size, '\n'); // skip bad input
        }
        else
            std::cout << n << '\n';
    }
}
```

Output:

```text
1
2
```
