  <DeclarationDescription>
    {/* source:cpp-io-basic-istream-operator-gtgt2:0001 */}
    1,2. Performs character input operations.

    {/* source:cpp-io-basic-istream-operator-gtgt2:0002 */}
    1. Behaves as a [FormattedInputFunction](/docs/cpp/library/named_req/FormattedInputFunction). After constructing and checking the sentry object, which may skip leading whitespace, extracts a character and stores it to `ch`. If no character is available, sets [`failbit`](/docs/cpp/library/io/ios_base/iostate) (in addition to [`eofbit`](/docs/cpp/library/io/ios_base/iostate) that is set as required of a FormattedInputFunction).

    {/* source:cpp-io-basic-istream-operator-gtgt2:0003 */}
    2. Behaves as a [FormattedInputFunction](/docs/cpp/library/named_req/FormattedInputFunction). After constructing and checking the sentry object, which may skip leading whitespace, extracts successive characters and stores them at successive locations of a character array whose first element is pointed to by `s`. The extraction stops if any of the following conditions is met:

    - A whitespace character (as determined by the [`ctype<CharT>`](/docs/cpp/library/text/locale/ctype) facet) is found. The whitespace character is not extracted.
    - If `st.width()` is greater than zero, `st.width() - 1` characters are stored.
    - `n - 1` characters are stored, where `n` is defined as follows: If `st.width()` is greater than zero, `std::min(std::size_t(st.width()), N)`; otherwise, `n` is `N`.
    - End of file occurs in the input sequence (this also sets [`eofbit`](/docs/cpp/library/io/ios_base/iostate)).

    In either case, an additional null character value `CharT()` is stored at the end of the output. If no characters were extracted, sets [`failbit`](/docs/cpp/library/io/ios_base/iostate) (the null character is still written, to the first position in the output). Finally, calls `st.width(0)` to cancel the effects of [`std::setw`](/docs/cpp/library/io/manip/setw), if any.

    {/* source:cpp-io-basic-istream-operator-gtgt2:0004 */}
    3. Calls the appropriate extraction operator, given an rvalue reference to an input stream object (equivalent to `st >> std::forward<T>(value)`). This overload participates in overload resolution only if `st >> std::forward<T>(value)` is well-formed and `Istream` is a class type publicly and unambiguously derived from [`std::ios_base`](/docs/cpp/library/io/ios_base).

### Notes

{/* source:cpp-io-basic-istream-operator-gtgt2:0005 */}
Extracting a single character that is the last character of the stream does not set `eofbit`: this is different from other formatted input functions, such as extracting the last integer with `operator>>`, but this behavior matches the behavior of [`std::scanf`](/docs/cpp/library/io/c/scanf) with `"%c"` format specifier.

### Example

{/* source:cpp-io-basic-istream-operator-gtgt2:0009 */}
```cpp
#include <iomanip>
#include <iostream>
#include <sstream>
 
int main()
{
    std::string input = "n greetings";
    std::istringstream stream(input);
 
    char c;
    const int MAX = 6;
    char cstr[MAX];
 
    stream >> c >> std::setw(MAX) >> cstr;
    std::cout << "c = " << c << '\n'
              << "cstr = " << cstr << '\n';
 
    double f;
    std::istringstream("1.23") >> f; // rvalue stream extraction
    std::cout << "f = " << f << '\n';
}
```

Output:

```text
c = n
cstr = greet
f = 1.23
```
