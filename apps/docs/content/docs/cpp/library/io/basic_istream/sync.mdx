Synchronizes the input buffer with the associated data source.

{/* source:cpp-io-basic-istream-sync:0002 */}
Behaves as [UnformattedInputFunction](/docs/cpp/library/named_req/UnformattedInputFunction), except that [`gcount()`](/docs/cpp/library/io/basic_istream/gcount) is not affected. After constructing and checking the sentry object,

{/* source:cpp-io-basic-istream-sync:0003 */}
If [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf) is a null pointer, returns `-1`.

{/* source:cpp-io-basic-istream-sync:0004 */}
Otherwise, calls `rdbuf()->pubsync()`. If that function returns `-1`, calls `setstate(badbit)` and returns `-1`. Otherwise, returns `0`.

### Parameters

{/* source:cpp-io-basic-istream-sync:0005 */}
(none)

### Return value

{/* source:cpp-io-basic-istream-sync:0006 */}
`0` on success, `-1` on failure or if the stream does not support this operation (is unbuffered).

### Notes

{/* source:cpp-io-basic-istream-sync:0007 */}
As with [`readsome()`](/docs/cpp/library/io/basic_istream/readsome), it is implementation-defined whether this function does anything with library-supplied streams. The intent is typically for the next read operation to pick up any changes that may have been made to the associated input sequence after the stream buffer last filled its get area. To achieve that, `sync()` may empty the get area, or it may refill it, or it may do nothing. A notable exception is Visual Studio, where this operation discards the unprocessed input when called with a standard input stream.

### Example

{/* source:cpp-io-basic-istream-sync:0008 */}
Demonstrates the use of input stream `sync()` with file input. Note that output here is implementation-defined, since calls to [`std::basic_filebuf::sync`](/docs/cpp/library/io/basic_filebuf/sync) are implementation-defined for reads.

```cpp
#include <fstream>
#include <iostream>
 
void file_abc()
{
    std::ofstream f("test.txt");
    f << "abc\n";
}
 
void file_123()
{
    std::ofstream f("test.txt");
    f << "123\n";
}
 
int main()
{
    file_abc(); // file now contains "abc"
    std::ifstream f("test.txt");
    std::cout << "Reading from the file\n";
    char c;
    f >> c;
    std::cout << c;
    file_123(); // file now contains "123"
    f >> c;
    std::cout << c;
    f >> c;
    std::cout << c << '\n';
    f.close();
 
    file_abc(); // file now contains "abc"
    f.open("test.txt");
    std::cout << "Reading from the file, with sync()\n";
    f >> c;
    std::cout << c;
    file_123(); // file now contains "123"
    f.sync();
    f >> c;
    std::cout << c;
    f >> c;
    std::cout << c << '\n';
}
```

Possible output:

```text
Reading from the file
abc
Reading from the file, with sync()
a23
```
