<DeclarationDoc>
Defined in header [`<iostream>`](/docs/cpp/library/headers/iostream)

  <Declaration id="1" language="cpp" code={`extern std::ostream clog;`} />
  <Declaration id="2" language="cpp" code={`extern std::wostream wclog;`} />

  <DeclarationDescription>
    {/* source:cpp-io-clog:0001 */}
    The global objects `std::clog` and `std::wclog` control output to a stream buffer of implementation-defined type (derived from [`std::streambuf`](/docs/cpp/library/io/basic_streambuf)), associated with the standard C output stream [`stderr`](/docs/cpp/library/io/c/std_streams), but, unlike [`std::cerr`](/docs/cpp/library/io/basic_ostream/cerr)/[`std::wcerr`](/docs/cpp/library/io/basic_ostream/cerr), these streams are not automatically flushed and `cout` is not automatically tie()'d with these streams.

    {/* source:cpp-io-clog:0002 */}
    These objects are guaranteed to be initialized during or before the first time an object of type [`std::ios_base::Init`](/docs/cpp/library/io/ios_base/Init) is constructed and are available for use in the constructors and destructors of static objects with [ordered initialization](/docs/cpp/language/initialization#Non-local_variables) (as long as [`<iostream>`](/docs/cpp/library/headers/iostream) is included before the object is defined).

    {/* source:cpp-io-clog:0003 */}
    Unless `std::ios_base::sync_with_stdio(false)` has been issued, it is safe to concurrently access these objects from multiple threads for both formatted and unformatted output.
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-io-clog:0004 */}
The 'c' in the name refers to "character" ([stroustrup.com FAQ](https://www.stroustrup.com/bs_faq2.html#cout)); `clog` means "character log" and `wclog` means "wide character log".

### Example

{/* source:cpp-io-clog:0005 */}
```cpp
#include <iostream>
 
struct Foo
{
    int n;
    Foo()
    {
        std::clog << "static constructor\n";
    }
    ~Foo()
    {
        std::clog << "static destructor\n";
    }
};
 
Foo f; // static object
 
int main()
{
    std::clog << "main function\n";
}
```

Output:

```text
static constructor
main function
static destructor
```
