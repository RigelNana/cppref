<DeclarationDescription>
  {/* source:cpp-io-manip-uppercase:0001 */}
  Enables the use of uppercase characters in floating-point and hexadecimal integer output. Has no effect on input.

  {/* source:cpp-io-manip-uppercase:0002 */}
  1. 1) Enables the `uppercase` flag in the stream `str` as if by calling `str.setf(std::ios_base::uppercase)`.

  {/* source:cpp-io-manip-uppercase:0003 */}
  1. 2) Disables the `uppercase` flag in the stream `str` as if by calling `str.unsetf(std::ios_base::uppercase)`.

</DeclarationDescription>

{/* source:cpp-io-manip-uppercase:0004 */}
This is an I/O manipulator, it may be called with an expression such as `out << std::uppercase` for any `out` of type [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) or with an expression such as `in >> std::uppercase` for any `in` of type [`std::basic_istream`](/docs/cpp/library/io/basic_istream).

### Parameters

{/* source:cpp-io-manip-uppercase:0005 */}
<ParameterList>
  <Parameter name="str">reference to I/O stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-manip-uppercase:0006 */}
`str` (reference to the stream after manipulation).

### Example

{/* source:cpp-io-manip-uppercase:0007 */}
```cpp
#include <iostream>

int main()
{
    std::cout << std::hex << std::showbase
              << "0x2a with uppercase: " << std::uppercase << 0x2a << '\n'
              << "0x2a with nouppercase: " << std::nouppercase << 0x2a << '\n'
              << "1e-10 with uppercase: " << std::uppercase << 1e-10 << '\n'
              << "1e-10 with nouppercase: " << std::nouppercase << 1e-10 << '\n';
}
```

Output:

```text
0x2a with uppercase: 0X2A
0x2a with nouppercase: 0x2a
1e-10 with uppercase: 1E-10
1e-10 with nouppercase: 1e-10
```
