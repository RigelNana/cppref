<DeclarationDescription>
  {/* source:cpp-io-manip-skipws:0001 */}
  Enables or disables skipping of leading whitespace by the formatted input functions (enabled by default). Has no effect on output.

  {/* source:cpp-io-manip-skipws:0002 */}
  1. 1) Enables the `skipws` flag in the stream `str` as if by calling `str.setf(std::ios_base::skipws)`.

  {/* source:cpp-io-manip-skipws:0003 */}
  1. 2) Disables the `skipws` flag in the stream `str` as if by calling `str.unsetf(std::ios_base::skipws)`.

</DeclarationDescription>

{/* source:cpp-io-manip-skipws:0004 */}
The whitespace skipping is performed by the constructor of [`std::basic_istream::sentry`](/docs/cpp/library/io/basic_istream/sentry), which reads and discards the characters classified as whitespace by the [`std::ctype`](/docs/cpp/library/text/locale/ctype) facet of the stream's imbued locale.

{/* source:cpp-io-manip-skipws:0005 */}
This is an I/O manipulator, it may be called with an expression such as `out << std::noskipws` for any `out` of type [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) or with an expression such as `in >> std::noskipws` for any `in` of type [`std::basic_istream`](/docs/cpp/library/io/basic_istream).

### Parameters

{/* source:cpp-io-manip-skipws:0006 */}
<ParameterList>
  <Parameter name="str">reference to I/O stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-manip-skipws:0007 */}
`str` (reference to the stream after manipulation).

### Example

{/* source:cpp-io-manip-skipws:0008 */}
```cpp
#include <iostream>
#include <sstream>

int main()
{
    char c1, c2, c3;
    std::istringstream("a b c") >> c1 >> c2 >> c3;
    std::cout << "Default  behavior:"
                 " c1 = " << c1 <<
                 " c2 = " << c2 <<
                 " c3 = " << c3 << '\n';
    std::istringstream("a b c") >> std::noskipws >> c1 >> c2 >> c3;
    std::cout << "noskipws behavior:"
                 " c1 = " << c1 <<
                 " c2 = " << c2 <<
                 " c3 = " << c3 << '\n';
}
```

Output:

```text
Default  behavior: c1 = a c2 = b c3 = c
noskipws behavior: c1 = a c2 =   c3 = b
```
