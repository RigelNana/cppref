<DeclarationDoc>

  <Declaration language="cpp" code={`/*unspecified*/ setiosflags( std::ios_base::fmtflags mask );`} />
</DeclarationDoc>

{/* source:cpp-io-manip-setiosflags:0001 */}
When used in an expression `out << setiosflags(mask)` or `in >> setiosflags(mask)`, sets all format flags of the stream `out` or `in` as specified by the `mask`.

### Parameters

{/* source:cpp-io-manip-setiosflags:0002 */}
<ParameterList>
  <Parameter name="mask">bitmask of the flags to set</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-manip-setiosflags:0003 */}
An object of unspecified type such that

{/* source:cpp-io-manip-setiosflags:0004 */}
- if `out` is an object of type `std::basic_ostream<CharT, Traits>`, the expression `out << setiosflags(mask)`
  - has type `std::basic_ostream<CharT, Traits>&`
  - has value `out`
  - behaves as if it called `f(out, mask)`
- if `in` is an object of type `std::basic_istream<CharT, Traits>`, the expression `in >> setiosflags(mask)`
  - has type `std::basic_istream<CharT, Traits>&`
  - has value `in`
  - behaves as if it called `f(in, mask)`
{/* source:cpp-io-manip-setiosflags:0005 */}
where the function `f` is defined as:

{/* source:cpp-io-manip-setiosflags:0006 */}
```cpp
void f(std::ios_base& str, std::ios_base::fmtflags mask)
{
    // set specified flags
    str.setf(mask);
}
```

### Example

{/* source:cpp-io-manip-setiosflags:0007 */}
```cpp
#include <iomanip>
#include <iostream>

int main()
{
    std::cout << std::resetiosflags(std::ios_base::dec)
              << std::setiosflags(  std::ios_base::hex
                                  | std::ios_base::uppercase
                                  | std::ios_base::showbase) << 42 << '\n';
}
```

Output:

```text
0X2A
```
