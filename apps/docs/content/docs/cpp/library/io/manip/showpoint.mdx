<DeclarationDescription>
  {/* source:cpp-io-manip-showpoint:0001 */}
  Enables or disables the unconditional inclusion of the decimal point character in floating-point output. Has no effect on input.

  {/* source:cpp-io-manip-showpoint:0002 */}
  1. 1) Enables the `showpoint` flag in the stream `str` as if by calling `str.setf(std::ios_base::showpoint)`.

  {/* source:cpp-io-manip-showpoint:0003 */}
  1. 2) Disables the `showpoint` flag in the stream `str` as if by calling `str.unsetf(std::ios_base::showpoint)`.

</DeclarationDescription>

{/* source:cpp-io-manip-showpoint:0004 */}
This is an I/O manipulator, it may be called with an expression such as `out << std::showpoint` for any `out` of type [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) or with an expression such as `in >> std::showpoint` for any `in` of type [`std::basic_istream`](/docs/cpp/library/io/basic_istream).

{/* source:cpp-io-manip-showpoint:0005 */}
The character to use as decimal point character is determined by the numpunct facet of the locale imbued in the stream at the time of output, as described in [`std::num_put::put`](/docs/cpp/library/text/locale/num_put/put).

### Parameters

<ParameterList>
  <Parameter name="str">reference to I/O stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-manip-showpoint:0007 */}
`str` (reference to the stream after manipulation).

### Example

{/* source:cpp-io-manip-showpoint:0008 */}
```cpp
#include <iostream>

int main()
{
    std::cout << "1.0 with showpoint: " << std::showpoint << 1.0 << '\n'
              << "1.0 with noshowpoint: " << std::noshowpoint << 1.0 << '\n';
}
```

Output:

```text
1.0 with showpoint: 1.00000
1.0 with noshowpoint: 1
```
