<DeclarationDoc>
Defined in header [`<iomanip>`](/docs/cpp/library/headers/iomanip)

  <Declaration language="cpp" code={`template< class CharT >
/*unspecified*/ setfill( CharT c );`} />
</DeclarationDoc>

{/* source:cpp-io-manip-setfill:0001 */}
When used in an expression `out << setfill(c)` sets the fill character of the stream `out` to `c`.

### Parameters

{/* source:cpp-io-manip-setfill:0002 */}
<ParameterList>
  <Parameter name="c">new value for the fill character</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-manip-setfill:0003 */}
An object of unspecified type such that

{/* source:cpp-io-manip-setfill:0004 */}
- if `out` is an object of type `std::basic_ostream<CharT, Traits>`, the expression `out << setfill(c)`
  - has type `std::basic_ostream<CharT, Traits>&`
  - has value `out`
  - behaves as if it called `f(out, c)`
{/* source:cpp-io-manip-setfill:0005 */}
where the function `f` is defined as:

{/* source:cpp-io-manip-setfill:0006 */}
```cpp
template<class CharT, class Traits>
void f(std::basic_ios<CharT, Traits>& str, CharT c)
{
    // set fill character
    str.fill(c);
}
```

### Notes

{/* source:cpp-io-manip-setfill:0007 */}
The current fill character may be obtained with [`std::ostream::fill`](/docs/cpp/library/io/basic_ios/fill).

### Example

{/* source:cpp-io-manip-setfill:0008 */}
```cpp
#include <iomanip>
#include <iostream>

int main()
{
    std::cout << "default fill: [" << std::setw(10) << 42 << "]\n"
              << "setfill('*'): [" << std::setfill('*')
                                   << std::setw(10) << 42 << "]\n";
}
```

Output:

```text
default fill: [        42]
setfill('*'): [********42]
```
