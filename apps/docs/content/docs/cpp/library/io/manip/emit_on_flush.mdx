<DeclarationDescription>
  {/* source:cpp-io-manip-emit-on-flush:0001 */}
  If `os.rdbuf()` actually points to a `std::basic_syncbuf<CharT, Traits, Allocator>` `buf`, toggles whether it emits (i.e., transmits data to the underlying stream buffer) when flushed:

  {/* source:cpp-io-manip-emit-on-flush:0002 */}
  1. 1) calls `buf.set_emit_on_sync(true)`

  {/* source:cpp-io-manip-emit-on-flush:0003 */}
  1. 2) calls `buf.set_emit_on_sync(false)`

</DeclarationDescription>

{/* source:cpp-io-manip-emit-on-flush:0004 */}
Otherwise, these manipulators have no effect.

{/* source:cpp-io-manip-emit-on-flush:0005 */}
This is an output-only I/O manipulator, it may be called with an expression such as `out << std::emit_on_flush` for any `out` of type [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream).
