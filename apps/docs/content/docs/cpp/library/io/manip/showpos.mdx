<DeclarationDescription>
  {/* source:cpp-io-manip-showpos:0001 */}
  Enables or disables the display of the plus sign `'+'` in non-negative integer output. Has no effect on input.

  {/* source:cpp-io-manip-showpos:0002 */}
  1. 1) Enables the `showpos` flag in the stream `str` as if by calling `str.setf(std::ios_base::showpos)`.

  {/* source:cpp-io-manip-showpos:0003 */}
  1. 2) Disables the `showpos` flag in the stream `str` as if by calling `str.unsetf(std::ios_base::showpos)`.

</DeclarationDescription>

{/* source:cpp-io-manip-showpos:0004 */}
This is an I/O manipulator, it may be called with an expression such as `out << std::showpos` for any `out` of type [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) or with an expression such as `in >> std::showpos` for any `in` of type [`std::basic_istream`](/docs/cpp/library/io/basic_istream).

### Parameters

{/* source:cpp-io-manip-showpos:0005 */}
<ParameterList>
  <Parameter name="str">reference to I/O stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-manip-showpos:0006 */}
`str` (reference to the stream after manipulation).

### Example

{/* source:cpp-io-manip-showpos:0007 */}
```cpp
#include <iostream>

int main()
{
    std::cout
        << "showpos: " << std::showpos << 42 << ' ' << 3.14 << ' ' << 0 << '\n'
        << "noshowpos: " << std::noshowpos << 42 << ' ' << 3.14 << ' ' << 0 << '\n';
}
```

Output:

```text
showpos: +42 +3.14 +0
noshowpos: 42 3.14 0
```
