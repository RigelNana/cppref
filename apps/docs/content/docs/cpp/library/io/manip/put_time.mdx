{/* source:cpp-io-manip-put-time:0001 */}
When used in an expression `out << put_time(tmb, fmt)`, converts the date and time information from a given calendar time `tmb` to a character string according to [format string](/docs/cpp/library/io/manip/put_time#Format_string) `fmt`, as if by calling [`std::strftime`](/docs/cpp/library/chrono/c/strftime), [`std::wcsftime`](/docs/cpp/library/chrono/c/wcsftime), or analog (depending on `CharT`), according to the [`std::time_put`](/docs/cpp/library/text/locale/time_put) facet of the locale currently imbued in the output stream `out`.

### Parameters

{/* source:cpp-io-manip-put-time:0002 */}
<ParameterList>
  <Parameter name="tmb">pointer to the calendar time structure as obtained from [`std::localtime`](/docs/cpp/library/chrono/c/localtime) or [`std::gmtime`](/docs/cpp/library/chrono/c/gmtime)</Parameter>
  <Parameter name="fmt">pointer to a null-terminated `CharT` string specifying the [format of conversion](/docs/cpp/library/io/manip/put_time#Format_string)</Parameter>
</ParameterList>

### Format string

{/* source:cpp-io-manip-put-time:0003 */}
The format string consists of zero or more conversion specifiers and ordinary characters (except `%`). All ordinary characters, including the terminating null character, are copied to the output string without modification. Each conversion specification begins with `%` character, optionally followed by `E` or `O` modifier (ignored if unsupported by the locale), followed by the character that determines the behavior of the specifier. The following format specifiers are available:

### Return value

{/* source:cpp-io-manip-put-time:0005 */}
An object of unspecified type such that

{/* source:cpp-io-manip-put-time:0006 */}
- if `out` is an object of type `std::basic_ostream<CharT, Traits>`, the expression `out << put_time(tmb, fmt)`
  - has type `std::basic_ostream<CharT, Traits>&`
  - has value `out`
  - behaves as if it called `f(out, tmb, fmt)`
{/* source:cpp-io-manip-put-time:0007 */}
where the function `f` is defined as:

{/* source:cpp-io-manip-put-time:0008 */}
```cpp
template<class CharT, class Traits>
void f(std::basic_ios<CharT, Traits>& str, const std::tm* tmb, const CharT* fmt)
{
    using Iter = std::ostreambuf_iterator<CharT, Traits>;
    using TimePut = std::time_put<CharT, Iter>;

    const TimePut& tp = std::use_facet<TimePut>(str.getloc());
    const Iter end = tp.put(Iter(str.rdbuf()), str, str.fill(), tmb,
        fmt, fmt + Traits::length(fmt));

    if (end.failed())
        str.setstate(std::ios_base::badbit);
}
```

### Example

{/* source:cpp-io-manip-put-time:0009 */}
```cpp
#include <ctime>
#include <iomanip>
#include <iostream>

int main()
{
    std::time_t t = std::time(nullptr);
    std::tm tm = *std::localtime(&t);

    std::cout.imbue(std::locale("ru_RU.utf8"));
    std::cout << "ru_RU: " << std::put_time(&tm, "%c %Z") << '\n';

    std::cout.imbue(std::locale("ja_JP.utf8"));
    std::cout << "ja_JP: " << std::put_time(&tm, "%c %Z") << '\n';
}
```

Possible output:

```text
ru_RU: Ср. 28 дек. 2011 10:21:16 EST
ja_JP: 2011年12月28日 10時21分16秒 EST
```
