<DeclarationDescription>
  {/* source:cpp-io-manip-showbase:0001 */}
  1. 1) Enables the `showbase` flag in the stream `str` as if by calling `str.setf(std::ios_base::showbase)`.

  {/* source:cpp-io-manip-showbase:0002 */}
  1. 2) Disables the `showbase` flag in the stream `str` as if by calling `str.unsetf(std::ios_base::showbase)`.

</DeclarationDescription>

{/* source:cpp-io-manip-showbase:0003 */}
This is an I/O manipulator, it may be called with an expression such as `out << std::showbase` for any `out` of type [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) or with an expression such as `in >> std::showbase` for any `in` of type [`std::basic_istream`](/docs/cpp/library/io/basic_istream).

{/* source:cpp-io-manip-showbase:0004 */}
The `showbase` flag affects the behavior of integer output (see [`std::num_put::put`](/docs/cpp/library/text/locale/num_put/put)), monetary input (see [`std::money_get::get`](/docs/cpp/library/text/locale/money_get/get)) and monetary output (see [`std::money_put::put`](/docs/cpp/library/text/locale/money_put/put)).

### Parameters

{/* source:cpp-io-manip-showbase:0005 */}
<ParameterList>
  <Parameter name="str">reference to I/O stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-manip-showbase:0006 */}
`str` (reference to the stream after manipulation).

### Notes

{/* source:cpp-io-manip-showbase:0007 */}
As specifed in [`std::num_put::put`](/docs/cpp/library/text/locale/num_put/put), the showbase flag in integer output acts like the # format specifier in [`std::printf`](/docs/cpp/library/io/c/printf), which means the numeric base prefix is *not* added when outputting the value zero.

### Example

{/* source:cpp-io-manip-showbase:0008 */}
```cpp
#include <iomanip>
#include <iostream>
#include <locale>
#include <sstream>

int main()
{
    // showbase affects the output of octals and hexadecimals
    std::cout << std::hex
              << "showbase: " << std::showbase << 42 << '\n'
              << "noshowbase: " << std::noshowbase << 42 << '\n';

    // and both input and output of monetary values
    std::locale::global(std::locale("en_US.UTF8"));
    long double val = 0;
    std::istringstream("3.14") >> std::showbase >> std::get_money(val);
    std::cout << "With showbase, parsing 3.14 as money gives " << val << '\n';
    std::istringstream("3.14") >> std::noshowbase >> std::get_money(val);
    std::cout << "Without showbase, parsing 3.14 as money gives " << val << '\n';
}
```

Output:

```text
showbase: 0x2a
noshowbase: 2a
With showbase, parsing 3.14 as money gives 0
Without showbase, parsing 3.14 as money gives 314
```
