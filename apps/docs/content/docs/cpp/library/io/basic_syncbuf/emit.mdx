{/* source:cpp-io-basic-syncbuf-emit:0001 */}
Atomically transmits all pending output to the wrapped stream.

{/* source:cpp-io-basic-syncbuf-emit:0002 */}
All `emit()` calls transferring characters to the same wrapped stream buffer object appear to execute in a total order, where each `emit()` call [synchronizes-with](/docs/cpp/library/atomic/memory_order) subsequent `emit()` calls in that total order, even if these calls are made through difference instances of `std::basic_syncbuf`/`std::basic_osyncstream`. In practice, this means that `emit()` takes a lock uniquely associated with the wrapped stream object: for example, it could be held in a static hash map where the address of the wrapped stream is used as the key.

{/* source:cpp-io-basic-syncbuf-emit:0003 */}
If a call had been made to [`sync`](/docs/cpp/library/io/basic_syncbuf/sync) since the last call to `emit()`, then also flushes the wrapped stream by calling [`pubsync()`](/docs/cpp/library/io/basic_streambuf/pubsync) on it.

### Parameters

{/* source:cpp-io-basic-syncbuf-emit:0004 */}
(none)

### Return value

{/* source:cpp-io-basic-syncbuf-emit:0005 */}
`true` if all of the following is true:

{/* source:cpp-io-basic-syncbuf-emit:0006 */}
- there is a wrapped stream (the wrapped streambuf pointer is not null)
- all characters from the temporary storage were successfully sent into the wrapped stream
- the call to [`pubsync()`](/docs/cpp/library/io/basic_streambuf/pubsync), if requested, also completed successfully.

{/* source:cpp-io-basic-syncbuf-emit:0007 */}
Returns `false` otherwise.

### Notes

{/* source:cpp-io-basic-syncbuf-emit:0008 */}
Normally called by the destructor or move assignment of the owning `std::basic_osyncstream`, or by [`std::basic_osyncstream::emit`](/docs/cpp/library/io/basic_osyncstream/emit).
