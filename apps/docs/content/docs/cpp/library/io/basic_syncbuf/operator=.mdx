{/* source:cpp-io-basic-syncbuf-operator:0001 */}
First, calls [`emit()`](/docs/cpp/library/io/basic_syncbuf/emit) to transmit all pending output (and delayed flush, if any) to the wrapped stream.

{/* source:cpp-io-basic-syncbuf-operator:0002 */}
Then performs move-assignment by moving all contents from `other`, including the temporary storage, the wrapped stream pointer, policy, and all other state (such as the mutex pointer). After move, `other` is not associated with a stream, and `other.get_wrapped() == nullptr`. The put area member pointers of the base class [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf) of `other` are guaranteed to be null. Destroying a moved-from `other` will not produce any output.

{/* source:cpp-io-basic-syncbuf-operator:0003 */}
If `std::allocator_traits<Allocator>::propagate_on_container_move_assignment::value` is `false`, then the allocator is unchanged. Otherwise, after move-assignment, `get_allocator()` equals `other.get_allocator()`.
