{/* source:cpp-io-basic-syncbuf-basic-syncbuf:0001 */}
Calls [`emit()`](/docs/cpp/library/io/basic_syncbuf/emit) to transmit all pending output (and delayed flush, if any) to the wrapped stream. If an exception is thrown by this call, it is caught and ignored.

### Parameters

{/* source:cpp-io-basic-syncbuf-basic-syncbuf:0002 */}
(none)

### Notes

{/* source:cpp-io-basic-syncbuf-basic-syncbuf:0003 */}
Normally called by the destructor of the owning `std::basic_osyncstream`.
