  <DeclarationDescription>
    {/* source:cpp-io-basic-syncbuf-basic-syncbuf:0001 */}
    1. Default constructor: creates an instance of `std::basic_syncbuf` with emit-on-sync policy set to `false`, wrapped streambuffer set to `nullptr`, and using default-constructed `Allocator` as the allocator for temporary storage.

    {/* source:cpp-io-basic-syncbuf-basic-syncbuf:0002 */}
    2,3. Creates an instance of `std::basic_syncbuf` with emit-on-sync policy set to `false`, wrapped streambuffer set to `obuf`, and using `a` as the allocator for temporary storage.

    {/* source:cpp-io-basic-syncbuf-basic-syncbuf:0003 */}
    4. Move constructor: move-constructs a `std::basic_syncbuf` object by moving all contents from another `std::basic_syncbuf` object `rhs`, including the temporary storage, the wrapped stream pointer, policy, and all other state (such as the mutex pointer). After move, `rhs` is not associated with a stream, and `rhs.get_wrapped() == nullptr`. The put area member pointers of the base class [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf) of `rhs` are guaranteed to be null. Destroying a moved-from `rhs` will not produce any output.
  </DeclarationDescription>
</DeclarationDoc>
