{/* source:cpp-io-basic-syncbuf-set-emit-on-sync:0001 */}
Changes the current emit-on-sync policy.

{/* source:cpp-io-basic-syncbuf-set-emit-on-sync:0002 */}
The value `false` (the default) indicates that any flush will be postponed until a call to `emit`.

{/* source:cpp-io-basic-syncbuf-set-emit-on-sync:0003 */}
The value `true` makes flushes apply immediately.

### Parameters

  <Parameter name="b">new value for the emit-on-sync policy</Parameter>
