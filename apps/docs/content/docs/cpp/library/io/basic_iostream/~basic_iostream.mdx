Destructs the input/output stream.

### Notes

{/* source:cpp-io-basic-iostream-basic-iostream:0002 */}
This destructor does not perform any operation on the underlying stream buffer (`rdbuf()`): the destructors of the derived streams such as [`std::basic_fstream`](/docs/cpp/library/io/basic_fstream) and [`std::basic_stringstream`](/docs/cpp/library/io/basic_stringstream) are responsible for calling the destructors of the stream buffers.
