  <DeclarationDescription>
    {/* source:cpp-io-basic-iostream-operator:0001 */}
    Assigns another stream object.

    {/* source:cpp-io-basic-iostream-operator:0002 */}
    1. Copy assignment is not allowed.

    {/* source:cpp-io-basic-iostream-operator:0003 */}
    2. Move assigns another stream object. Effectively calls `swap(rhs)`. This move assignment operator is protected: it is called by the move assignment operators of the derived stream classes [`std::basic_stringstream`](/docs/cpp/library/io/basic_stringstream) and [`std::basic_fstream`](/docs/cpp/library/io/basic_fstream) which know how to properly move-assign the associated stream buffers.
  </DeclarationDescription>
