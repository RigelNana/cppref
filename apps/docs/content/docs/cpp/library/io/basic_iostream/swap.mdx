Exchanges the state with another input/output stream object. Effectively calls `basic_istream<CharT,Traits>::swap(other)`.

{/* source:cpp-io-basic-iostream-swap:0002 */}
This member function is protected: it is called by the swap member functions of the derived stream classes [`std::basic_stringstream`](/docs/cpp/library/io/basic_stringstream) and [`std::basic_fstream`](/docs/cpp/library/io/basic_fstream), which know how to correctly swap the associated stream buffers.

</ParameterList>
