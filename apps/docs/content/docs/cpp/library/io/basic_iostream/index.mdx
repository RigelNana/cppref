{/* source:cpp-io-basic-iostream:0001 */}
The class template `basic_iostream` provides support for high level input/output operations on streams. The supported operations include sequential reading or writing and formatting. This functionality is implemented over the interface provided by the [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf) class. It is accessed through [`std::basic_ios`](/docs/cpp/library/io/basic_ios) class.
