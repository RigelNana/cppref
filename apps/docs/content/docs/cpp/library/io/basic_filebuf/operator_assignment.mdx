{/* source:cpp-io-basic-filebuf-operator:0001 */}
Assigns another `basic_filebuf` object.


{/* source:cpp-io-basic-filebuf-operator:0002 */}
1) First calls [`close()`](/docs/cpp/library/io/basic_filebuf/close) to close the associated file, then moves the contents of `rhs` into `*this`: the put and get buffers, the associated file, the locale, the openmode, the is_open flag, and any other state. After the move, `rhs` is not associated with a file and `rhs.is_open() == false`.

{/* source:cpp-io-basic-filebuf-operator:0003 */}
2) The copy assignment operator is deleted; `basic_filebuf` is not [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable).

### Parameters

{/* source:cpp-io-basic-filebuf-operator:0004 */}
<ParameterList>
  <Parameter name="rhs">another `basic_filebuf` that will be moved from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-filebuf-operator:0005 */}
`*this`


### Example

{/* source:cpp-io-basic-filebuf-operator:0006 */}
```cpp
#include <cassert>
#include <fstream>
#include <iostream>
#include <string>
 
int main()
{
    std::ofstream{"test.in"} << "test\n"; // writes via a temporary object
    std::ifstream fin("test.in"); // read-only stream
    std::ofstream fout("test.out"); // write-only stream
 
    std::string s;
    std::getline(fin, s);
    std::cout << "s = [" << s << "]\n"; // s contains "test"
 
    assert(fout.is_open());
    *fin.rdbuf() = std::move(*fout.rdbuf());
    assert(!fout.is_open());
 
    std::getline(fin, s);
    std::cout << "s = [" << s << "]\n"; // s is empty input
}
```

Output:

```text
s = [test]
s = []
```
