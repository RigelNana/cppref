{/* source:cpp-io-basic-filebuf-is-open:0001 */}
Returns `true` if the most recent call to [`open()`](/docs/cpp/library/io/basic_filebuf/open) succeeded and there has been no call to [`close()`](/docs/cpp/library/io/basic_filebuf/close) since then.


### Parameters

{/* source:cpp-io-basic-filebuf-is-open:0002 */}
(none)


### Return value

{/* source:cpp-io-basic-filebuf-is-open:0003 */}
`true` if the associated file is open, `false` otherwise.


### Notes

{/* source:cpp-io-basic-filebuf-is-open:0004 */}
This function is typically called by [`std::basic_fstream::is_open()`](/docs/cpp/library/io/basic_fstream/is_open).


### Example

{/* source:cpp-io-basic-filebuf-is-open:0005 */}
```cpp
#include <fstream>
#include <iostream>
 
int main()
{
    std::ifstream fs("test.txt");
    std::filebuf fb;
    fb.open("test.txt", std::ios_base::in);
    std::cout << std::boolalpha
              << "direct call: " << fb.is_open() << '\n'
              << "through streambuf: " << fs.rdbuf()->is_open() << '\n'
              << "through fstream: " << fs.is_open() << '\n';
}
```

Output:

```text
direct call: true
through streambuf: true
through fstream: true
```
