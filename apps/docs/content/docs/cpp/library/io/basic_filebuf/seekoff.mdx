{/* source:cpp-io-basic-filebuf-seekoff:0001 */}
Repositions the file pointer, if possible, to the position that corresponds to exactly `off` characters from beginning, end, or current position of the file (depending on the value of `dir`).


{/* source:cpp-io-basic-filebuf-seekoff:0002 */}
If the associated file is not open ( `is_open() == false`), fails immediately.


{/* source:cpp-io-basic-filebuf-seekoff:0003 */}
If the multibyte character encoding is state-dependent ( [`codecvt::encoding()`](/docs/cpp/library/text/locale/codecvt/encoding) returned `-1`) or variable-length ( `codecvt::encoding()` returned `​0​`) and the offset `off` is not `​0​`, fails immediately: this function cannot determine the number of bytes that correspond to `off` characters.


{/* source:cpp-io-basic-filebuf-seekoff:0004 */}
If `dir` is not [`std::basic_ios::cur`](/docs/cpp/library/io/ios_base/seekdir) or the offset `off` is not `​0​`, and the most recent operation done on this filebuf object was output (that is, either the put buffer is not empty, or the most recently called function was [`overflow()`](/docs/cpp/library/io/basic_streambuf/overflow)), then calls `std::codecvt::unshift` to determine the unshift sequence necessary, and writes that sequence to the file by calling [`overflow()`](/docs/cpp/library/io/basic_streambuf/overflow).


{/* source:cpp-io-basic-filebuf-seekoff:0005 */}
Then converts the argument `dir` to a value `whence` of type `int` as follows:


{/* source:cpp-io-basic-filebuf-seekoff:0006 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`std::basic_ios::beg`</DescriptionTerm>
    <DescriptionBody>[`SEEK_SET`](/docs/cpp/library/io/c)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`std::basic_ios::end`</DescriptionTerm>
    <DescriptionBody>[`SEEK_END`](/docs/cpp/library/io/c)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`std::basic_ios::cur`</DescriptionTerm>
    <DescriptionBody>[`SEEK_CUR`](/docs/cpp/library/io/c)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-io-basic-filebuf-seekoff:0007 */}
Then, if the character encoding is fixed-width ( `codecvt::encoding()` returns some positive number `width`), moves the file pointer as if by `std::fseek(file, width*off, whence)` [`std::fseek`](/docs/cpp/library/io/c/fseek).


{/* source:cpp-io-basic-filebuf-seekoff:0008 */}
Otherwise, moves the file pointer as if by `std::fseek(file, 0, whence)` [`std::fseek`](/docs/cpp/library/io/c/fseek).


{/* source:cpp-io-basic-filebuf-seekoff:0009 */}
The `openmode` argument, required by the base class function signature, is usually ignored, because `std::basic_filebuf` maintains only one file position.

### Return value

{/* source:cpp-io-basic-filebuf-seekoff:0011 */}
A newly constructed object of type `pos_type` which stores the resulting file position, or `pos_type(off_type(-1))` on failure.


### Notes

{/* source:cpp-io-basic-filebuf-seekoff:0012 */}
`seekoff()` is called by `std::basic_streambuf::pubseekoff`, which is called by `std::basic_istream::seekg`, `std::basic_ostream::seekp`, `std::basic_istream::tellg`, and `std::basic_ostream::tellp`.


### Example

{/* source:cpp-io-basic-filebuf-seekoff:0013 */}
```cpp
#include <fstream>
#include <iostream>
#include <locale>
 
template<typename CharT>
int get_encoding(const std::basic_istream<CharT>& stream)
{
    using Facet = std::codecvt<CharT, char, std::mbstate_t>;
    return std::use_facet<Facet>(stream.getloc()).encoding();
}
 
int main()
{
    // prepare a 10-byte file holding 4 characters ("zß水𝄋") in UTF-8
    std::ofstream("text.txt") << "\x7a\xc3\x9f\xe6\xb0\xb4\xf0\x9d\x84\x8b";
 
    // open using a non-converting encoding
    std::ifstream f1("text.txt");
    std::cout << "f1's locale's encoding() returns "
              << get_encoding(f1) << '\n'
              << "pubseekoff(3, beg) returns "
              << f1.rdbuf()->pubseekoff(3, std::ios_base::beg) << '\n'
              << "pubseekoff(0, end) returns "
              << f1.rdbuf()->pubseekoff(0, std::ios_base::end) << '\n';
 
    // open using UTF-8
    std::wifstream f2("text.txt");
    f2.imbue(std::locale("en_US.UTF-8"));
    std::cout << "f2's locale's encoding() returns "
              << get_encoding(f2) << '\n'
              << "pubseekoff(3, beg) returns "
              << f2.rdbuf()->pubseekoff(3, std::ios_base::beg) << '\n'
              << "pubseekoff(0, end) returns "
              << f2.rdbuf()->pubseekoff(0, std::ios_base::end) << '\n';
}
```

Output:

```text
f1's locale's encoding() returns 1
pubseekoff(3, beg) returns 3
pubseekoff(0, end) returns 10
f2's locale's encoding() returns 0
pubseekoff(3, beg) returns -1
pubseekoff(0, end) returns 10
```
