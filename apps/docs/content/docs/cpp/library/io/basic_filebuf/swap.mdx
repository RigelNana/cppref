{/* source:cpp-io-basic-filebuf-swap:0001 */}
Swaps the state and the contents of `*this` and `rhs`.


### Parameters

{/* source:cpp-io-basic-filebuf-swap:0002 */}
<ParameterList>
  <Parameter name="rhs">another `basic_filebuf`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-filebuf-swap:0003 */}
(none)


### Notes

{/* source:cpp-io-basic-filebuf-swap:0004 */}
This function is called automatically when swapping [`std::fstream`](/docs/cpp/library/io/basic_fstream) objects, it is rarely necessary to call it directly.


### Example

{/* source:cpp-io-basic-filebuf-swap:0005 */}
```cpp
#include <fstream>
#include <iostream>
#include <string>
 
int main()
{
    std::ifstream fin("test.in"); // read-only
    std::ofstream fout("test.out"); // write-only
 
    std::string s;
    getline(fin, s);
    std::cout << s << '\n'; // outputs the first line of test.in
 
    fin.rdbuf()->swap(*fout.rdbuf()); //swap the underlying buffers
 
    getline(fin, s); // fails: cannot read from a write-only filebuf
    std::cout << s << '\n'; // prints empty line
}
```
