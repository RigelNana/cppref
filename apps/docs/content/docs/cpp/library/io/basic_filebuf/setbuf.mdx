virtual std::basic_streambuf<CharT, Traits>* setbuf( char_type* s, std::streamsize n )`} />
</DeclarationDoc>

{/* source:cpp-io-basic-filebuf-setbuf:0001 */}
If `s` is a null pointer and `n` is zero, the filebuf becomes unbuffered for output, meaning `pbase()` and `pptr()` are null and any output is immediately sent to file.


{/* source:cpp-io-basic-filebuf-setbuf:0002 */}
Otherwise, a call to `setbuf()` replaces the internal buffer (the controlled character sequence) with the user-supplied character array whose first element is pointed to by `s` and allows this [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf) object to use up to `n` bytes in that array for buffering.


{/* source:cpp-io-basic-filebuf-setbuf:0003 */}
This function is protected virtual, it may only be called through `pubsetbuf()` or from member functions of a user-defined class derived from `std::basic_filebuf`.


### Parameters

{/* source:cpp-io-basic-filebuf-setbuf:0004 */}
<ParameterList>
  <Parameter name="s">pointer to the first `CharT` in the user-provided buffer or null</Parameter>
  <Parameter name="n">the number of `CharT` elements in the user-provided buffer or zero</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-filebuf-setbuf:0005 */}
`this`


### Notes

{/* source:cpp-io-basic-filebuf-setbuf:0006 */}
The conditions when this function may be used and the way in which the provided buffer is used is implementation-defined.


{/* source:cpp-io-basic-filebuf-setbuf:0007 */}
-  GCC 4.6 libstdc++


{/* source:cpp-io-basic-filebuf-setbuf:0008 */}
   `setbuf()` may only be called when the [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf) is not associated with a file (has no effect otherwise). With a user-provided buffer, reading from file reads `n-1` bytes at a time.


{/* source:cpp-io-basic-filebuf-setbuf:0009 */}
-  Clang++3.0 libc++


{/* source:cpp-io-basic-filebuf-setbuf:0010 */}
   `setbuf()` may be called after opening the file, but before any I/O (may crash otherwise). With a user-provided buffer, reading from file reads largest multiples of 4096 that fit in the buffer. 


{/* source:cpp-io-basic-filebuf-setbuf:0011 */}
-  Visual Studio 2010 


{/* source:cpp-io-basic-filebuf-setbuf:0012 */}
   `setbuf()` may be called at any time, even after some I/O took place. Current contents of the buffer, if any, are lost.


{/* source:cpp-io-basic-filebuf-setbuf:0013 */}
The standard does not define any behavior for this function except that `setbuf(0, 0)` called before any I/O has taken place is required to set unbuffered output.


### Example

{/* source:cpp-io-basic-filebuf-setbuf:0014 */}
Provides a 10k buffer for reading. On linux, the strace utility may be used to observe the actual number of bytes read.

```cpp
#include <fstream>
#include <iostream>
#include <string>
 
int main()
{
    int cnt = 0;
    std::ifstream file;
    char buf[10241];
 
    file.rdbuf()->pubsetbuf(buf, sizeof buf);
    file.open("/usr/share/dict/words");
 
    for (std::string line; getline(file, line);)
        ++cnt;
    std::cout << cnt << '\n';
}
```

Possible output:

```text
356010
```
