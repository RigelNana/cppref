{/* source:cpp-io-basic-filebuf-seekpos:0001 */}
Repositions the file pointer, if possible, to the position indicated by `sp`. If the associated file is not open ( `is_open() == false`), fails immediately.


{/* source:cpp-io-basic-filebuf-seekpos:0002 */}
Reposition performs as follows:


{/* source:cpp-io-basic-filebuf-seekpos:0003 */}
1) If the file is open for writing, writes the put area and any unshift sequences required by the currently imbued locale, using [`overflow()`](/docs/cpp/library/io/basic_streambuf/overflow).

{/* source:cpp-io-basic-filebuf-seekpos:0004 */}
2) Repositions the file pointer, as if by calling [`std::fsetpos()`](/docs/cpp/library/io/c/fsetpos).

{/* source:cpp-io-basic-filebuf-seekpos:0005 */}
3) If the file is open for reading, updates the get area if necessary.

{/* source:cpp-io-basic-filebuf-seekpos:0006 */}
If `sp` was not obtained by calling [`seekoff()`](/docs/cpp/library/io/basic_streambuf/pubseekoff) or `seekpos()` on the same file, the behavior is undefined.


### Parameters

{/* source:cpp-io-basic-filebuf-seekpos:0007 */}
<ParameterList>
  <Parameter name="sp">file position obtained by [`seekoff()`](/docs/cpp/library/io/basic_streambuf/pubseekoff) or `seekpos()` called earlier on the same file</Parameter>
  <Parameter name="which">defines which of the input and/or output sequences to affect. It can be one or a combination of the following constants:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | affect the input sequence |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | affect the output sequence |

### Return value

{/* source:cpp-io-basic-filebuf-seekpos:0008 */}
`sp` on success or `pos_type(off_type(-1))` on failure.


### Notes

{/* source:cpp-io-basic-filebuf-seekpos:0009 */}
`seekpos()` is called by [`std::basic_streambuf::pubseekpos()`](/docs/cpp/library/io/basic_streambuf/pubseekpos), which is called by the single-argument versions of [`std::basic_istream::seekg()`](/docs/cpp/library/io/basic_istream/seekg) and [`std::basic_ostream::seekp()`](/docs/cpp/library/io/basic_ostream/seekp).


{/* source:cpp-io-basic-filebuf-seekpos:0010 */}
Many implementations do not update the get area in `seekpos()`, delegating to [`underflow()`](/docs/cpp/library/io/basic_streambuf/underflow) that is called by the next [`sgetc()`](/docs/cpp/library/io/basic_streambuf/sgetc).


### Example

{/* source:cpp-io-basic-filebuf-seekpos:0011 */}
On some implementations, the get area is emptied by `seekpos()` and the second `underflow()` is necessary to observe the effects.

```cpp
#include <fstream>
#include <iostream>
 
struct mybuf : std::filebuf
{
    pos_type seekpos(pos_type sp, std::ios_base::openmode which)
    {
        std::cout << "Before seekpos(" << sp << "), size of the get area is "
                  << egptr() - eback() << " with "
                  << egptr() - gptr() << " read positions available.\n";
 
        pos_type rc = std::filebuf::seekpos(sp, which);
 
        std::cout << "seekpos() returns " << rc << ".\nAfter the call, "
                  << "size of the get area is "
                  << egptr() - eback() << " with "
                  << egptr() - gptr() << " read positions available.\n";
// uncomment if get area is emptied by seekpos()
//        std::filebuf::underflow();
//        std::cout << "after forced underflow(), size of the get area is "
//                  << egptr() - eback() << " with "
//                  << egptr() - gptr() << " read positions available.\n";
 
        return rc;
    }
};
 
int main()
{
    mybuf buf;
    buf.open("test.txt", std::ios_base::in);
    std::istream stream(&buf);
    stream.get(); // read one char to force underflow()
    stream.seekg(2);
}
```

Possible output:

```text
Before seekpos(2), size of the get area is 110 with 109 read positions available.
seekpos() returns 2.
After the call, size of the get area is 110 with 108 read positions available.
```
