{/* source:cpp-io-basic-filebuf-imbue:0001 */}
Changes the associated locale so that all characters inserted or extracted after this call (and until another call to `imbue()`) are converted using the [`std::codecvt`](/docs/cpp/library/text/locale/codecvt) facet of `loc`.


{/* source:cpp-io-basic-filebuf-imbue:0002 */}
If the old locale's encoding is state-dependent and file is not positioned at the beginning, then the new locale must have the same [`std::codecvt`](/docs/cpp/library/text/locale/codecvt) facet as the one previously imbued.
