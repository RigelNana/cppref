{/* source:cpp-io-basic-filebuf-close:0001 */}
If a put area exist (e.g. file was opened for writing), first calls `overflow(Traits::eof())` to write all pending output to the file, including any unshift sequences.


{/* source:cpp-io-basic-filebuf-close:0002 */}
If the most recently called function, out of [`underflow()`](/docs/cpp/library/io/basic_filebuf/underflow), [`overflow()`](/docs/cpp/library/io/basic_filebuf/overflow), [`seekpos()`](/docs/cpp/library/io/basic_filebuf/seekpos), and [`seekoff()`](/docs/cpp/library/io/basic_filebuf/seekoff), was [`overflow()`](/docs/cpp/library/io/basic_filebuf/overflow), then calls [`std::codecvt::unshift()`](/docs/cpp/library/text/locale/codecvt/unshift), perhaps multiple times, to determine the unshift sequence according to the imbued locale, and writes that sequence to file with `overflow(Traits::eof())`.


{/* source:cpp-io-basic-filebuf-close:0003 */}
Then, closes the file as if by calling [`std::fclose()`](/docs/cpp/library/io/c/fclose), regardless of whether any of the preceding calls succeeded or failed.


{/* source:cpp-io-basic-filebuf-close:0004 */}
If any of the function calls made, including the call to [`std::fclose()`](/docs/cpp/library/io/c/fclose), fails, returns a null pointer. If any of the function calls made throws an exception, the exception is caught and rethrown after closing the file. If the file is already closed, returns a null pointer right away.


{/* source:cpp-io-basic-filebuf-close:0005 */}
In any case, updates the private member variable that is accessed by [`is_open()`](/docs/cpp/library/io/basic_filebuf/is_open).


### Parameters

{/* source:cpp-io-basic-filebuf-close:0006 */}
(none)


### Return value

{/* source:cpp-io-basic-filebuf-close:0007 */}
`this` on success, a null pointer on failure.


### Notes

{/* source:cpp-io-basic-filebuf-close:0008 */}
`close()` is typically called through the destructor of [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf) (which, in turn, is typically called by the destructor of [`std::basic_fstream`](/docs/cpp/library/io/basic_fstream).
