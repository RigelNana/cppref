{/* source:cpp-io-basic-filebuf-sync:0001 */}
If a put area exists (e.g. the file was opened for writing), calls [`overflow()`](/docs/cpp/library/io/basic_streambuf/overflow) to write all pending output to the file, then flushes the file as if by calling [`std::fflush`](/docs/cpp/library/io/c/fflush).


{/* source:cpp-io-basic-filebuf-sync:0002 */}
If a get area exists (e.g. the file was opened for reading), the effect is implementation-defined. Typical implementation may empty out the get area and move the current file position back by the corresponding number of bytes.


### Parameters

{/* source:cpp-io-basic-filebuf-sync:0003 */}
(none)


### Return value

{/* source:cpp-io-basic-filebuf-sync:0004 */}
`​0​` in case of success, `-1` in case of failure.


### Notes

{/* source:cpp-io-basic-filebuf-sync:0005 */}
`sync()` or its equivalent is implicitly called for output streams by [`close()`](/docs/cpp/library/io/basic_filebuf/close), [`seekoff()`](/docs/cpp/library/io/basic_filebuf/seekoff), and [`seekpos()`](/docs/cpp/library/io/basic_filebuf/seekpos) and explicitly called by [`std::basic_streambuf::pubsync()`](/docs/cpp/library/io/basic_streambuf/pubsync)
