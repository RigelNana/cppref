{/* source:cpp-io-basic-filebuf-basic-filebuf:0002 */}
Calls [`close()`](/docs/cpp/library/io/basic_filebuf/close) to close the associated file and destructs all other members of `basic_filebuf`. If an exception occurs during the destruction of the object, including the call to [`close()`](/docs/cpp/library/io/basic_filebuf/close), it is caught and not rethrown.


### Parameters

{/* source:cpp-io-basic-filebuf-basic-filebuf:0003 */}
(none)


### Return value

{/* source:cpp-io-basic-filebuf-basic-filebuf:0004 */}
(none)


### Notes

{/* source:cpp-io-basic-filebuf-basic-filebuf:0005 */}
Typically called by the destructor of [`std::basic_fstream`](/docs/cpp/library/io/basic_fstream).
