{/* source:cpp-io-basic-filebuf-overflow:0001 */}
Writes some data from the put area to the associated character sequence (to the file).


{/* source:cpp-io-basic-filebuf-overflow:0002 */}
Behaves like the base class [`std::basic_streambuf::overflow`](/docs/cpp/library/io/basic_streambuf/overflow), except that to write the data, first uses [`std::codecvt::out`](/docs/cpp/library/text/locale/codecvt/out) of the imbued locale to convert the characters into external (possibly multibyte) representation, stored in a temporary buffer (allocated as large as necessary), then uses file I/O to copy all fully-converted bytes into the file.


{/* source:cpp-io-basic-filebuf-overflow:0003 */}
If [`std::codecvt::always_noconv`](/docs/cpp/library/text/locale/codecvt/always_noconv) is true, the call to [`std::codecvt::out`](/docs/cpp/library/text/locale/codecvt/out) may be skipped.


{/* source:cpp-io-basic-filebuf-overflow:0004 */}
If the conversion fails with [`std::codecvt_base::error`](/docs/cpp/library/text/locale/codecvt_base), returns `Traits::eof()` without attempting any output.


{/* source:cpp-io-basic-filebuf-overflow:0005 */}
If the associated file is not open ( `is_open() == false`), returns `Traits::eof()` before doing anything.


### Parameters

{/* source:cpp-io-basic-filebuf-overflow:0006 */}
(none)


### Return value

{/* source:cpp-io-basic-filebuf-overflow:0007 */}
`Traits::not_eof(c)` to indicate success or `Traits::eof()` to indicate failure.
