  <DeclarationDescription>
    {/* source:cpp-io-cerr:0001 */}
    The global objects `std::cerr` and `std::wcerr` control output to a stream buffer of implementation-defined type (derived from [`std::streambuf`](/docs/cpp/library/io/basic_streambuf) and [`std::wstreambuf`](/docs/cpp/library/io/basic_streambuf), respectively), associated with the standard C error output stream [`stderr`](/docs/cpp/library/io/c/std_streams).

    {/* source:cpp-io-cerr:0002 */}
    These objects are guaranteed to be initialized during or before the first time an object of type [`std::ios_base::Init`](/docs/cpp/library/io/ios_base/Init) is constructed and are available for use in the constructors and destructors of static objects with [ordered initialization](/docs/cpp/language/initialization#Non-local_variables) (as long as [`<iostream>`](/docs/cpp/library/headers/iostream) is included before the object is defined).

    {/* source:cpp-io-cerr:0003 */}
    Unless `std::ios_base::sync_with_stdio(false)` has been issued, it is safe to concurrently access these objects from multiple threads for both formatted and unformatted output.

    {/* source:cpp-io-cerr:0004 */}
    Once initialized, `(std::cerr.flags() & unitbuf) != 0` (same for `std::wcerr`) meaning that any output sent to these stream objects is immediately flushed to the OS (via [`std::basic_ostream::sentry`](/docs/cpp/library/io/basic_ostream/sentry)'s destructor).

    {/* source:cpp-io-cerr:0005 */}
    In addition, `std::cerr.tie()` returns `&std::cout` (same for `std::wcerr` and [`std::wcout`](/docs/cpp/library/io/basic_ostream/cout)), meaning that any output operation on `std::cerr` first executes `std::cout.flush()` (via [`std::basic_ostream::sentry`](/docs/cpp/library/io/basic_ostream/sentry)'s constructor).
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-io-cerr:0006 */}
The 'c' in the name refers to "character" ([stroustrup.com FAQ](https://www.stroustrup.com/bs_faq2.html#cout)); `cerr` means "character error (stream)" and `wcerr` means "wide character error (stream)".

### Example

{/* source:cpp-io-cerr:0007 */}
Output to [`stderr`](/docs/cpp/library/io/c/std_streams) via `std::cerr` flushes out the pending output on [`std::cout`](/docs/cpp/library/io/basic_ostream/cout), while output to [`stderr`](/docs/cpp/library/io/c/std_streams) via [`std::clog`](/docs/cpp/library/io/basic_ostream/clog) does not.

```cpp
#include <chrono>
#include <iostream>
#include <thread>
using namespace std::chrono_literals;
 
void f()
{
    std::cout << "Output from thread...";
    std::this_thread::sleep_for(2s);
    std::cout << "...thread calls flush()" << std::endl;
}
 
int main()
{
    std::jthread t1{f};
    std::this_thread::sleep_for(1000ms);
    std::clog << "This output from main is not tie()'d to cout\n";
    std::cerr << "This output is tie()'d to cout\n";
}
```

Possible output:

```text
This output from main is not tie()'d to cout
Output from thread...This output is tie()'d to cout
...thread calls flush()
```
