{/* source:cpp-io-iostream-category:0001 */}
Obtains a reference to the static error category object for iostream errors. The object is required to override the virtual function `error_category::name()` to return a pointer to the string `"iostream"`. It is used to identify error codes provided in the exceptions of type [`std::ios_base::failure`](/docs/cpp/library/io/ios_base/failure).

### Parameters

{/* source:cpp-io-iostream-category:0002 */}
(none)

### Return value

{/* source:cpp-io-iostream-category:0003 */}
A reference to the static object of unspecified runtime type, derived from [`std::error_category`](/docs/cpp/library/error/error_category).

### Example

{/* source:cpp-io-iostream-category:0004 */}
```cpp
#include <fstream>
#include <iostream>
 
int main()
{
    std::ifstream f("doesn't exist");
    try
    {
        f.exceptions(f.failbit);
    }
    catch (const std::ios_base::failure& e)
    {
        std::cout << "Caught an ios_base::failure.\n"
                  << "Error code: " << e.code().value() 
                  << " (" << e.code().message() << ")\n"
                  << "Error category: " << e.code().category().name() << '\n';
 
    }
}
```

Possible output:

```text
Caught an ios_base::failure.
Error code: 1 (unspecified iostream_category error)
Error category: iostream
```
