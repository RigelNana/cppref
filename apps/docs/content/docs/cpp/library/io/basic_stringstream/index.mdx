{/* source:cpp-io-basic-stringstream:0001 */}
The class template `std::basic_stringstream` implements input and output operations on string based streams. It effectively stores an instance of [`std::basic_string`](/docs/cpp/library/string/basic_string) and performs the input and output operations on it.

{/* source:cpp-io-basic-stringstream:0002 */}
At the low level, the class essentially wraps a raw string device implementation of [`std::basic_stringbuf`](/docs/cpp/library/io/basic_stringbuf) into a higher-level interface of [`std::basic_iostream`](/docs/cpp/library/io/basic_iostream). The complete interface to unique [`std::basic_stringbuf`](/docs/cpp/library/io/basic_stringbuf) members is provided.
