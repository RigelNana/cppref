  <DeclarationDescription>

    {/* source:cpp-io-basic-ostringstream-str:0001 */}
    Manages the contents of the underlying string object.

    {/* source:cpp-io-basic-ostringstream-str:0002 */}
    1. Returns a copy of the underlying string. Equivalent to `return rdbuf()->str();`.

    {/* source:cpp-io-basic-ostringstream-str:0003 */}
    2. Returns a copy of the underlying string, using `a` as allocator. Equivalent to `return rdbuf()->str(a);`.

    {/* source:cpp-io-basic-ostringstream-str:0004 */}
    3. Returns a string move-constructed from the underlying string. Equivalent to `return std::move(*rdbuf()).str();`.

    {/* source:cpp-io-basic-ostringstream-str:0005 */}
    4,5. Replaces the contents of the underlying string. Equivalent to `rdbuf()->str(s);`.

    {/* source:cpp-io-basic-ostringstream-str:0006 */}
    6. Replaces the contents of the underlying string. Equivalent to `rdbuf()->str(std::move(s));`.

    {/* source:cpp-io-basic-ostringstream-str:0007 */}
    7. Replaces the contents of the underlying string. Equivalent to `rdbuf()->str(t);`.

    {/* source:cpp-io-basic-ostringstream-str:0008 */}
    This overload participates in overload resolution only if `is_convertible_v<const T&, basic_string_view<charT, traits>>` is `true`.
  </DeclarationDescription>

{/* source:cpp-io-basic-ostringstream-str:0012 */}

### Notes

{/* source:cpp-io-basic-ostringstream-str:0013 */}
The copy of the underlying string returned by [`str`](/docs/cpp/library/io/basic_ostringstream/str#top) is a temporary object that will be destructed at the end of the expression, so directly calling [`c_str()`](/docs/cpp/library/string/basic_string/c_str) on the result of `str()` (for example in `auto *ptr = out.str().c_str();`) results in a dangling pointer.

### Example

{/* source:cpp-io-basic-ostringstream-str:0015 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    int n;
 
    std::istringstream in; // could also use in("1 2")
    in.str("1 2");
    in >> n;
    std::cout << "After reading the first int from \"1 2\", the int is "
              << n << ", str() = \"" << in.str() << "\"\n";
 
    std::ostringstream out("1 2");
    out << 3;
    std::cout << "After writing the int '3' to output stream \"1 2\""
              << ", str() = \"" << out.str() << "\"\n";
 
    std::ostringstream ate("1 2", std::ios_base::ate);
    ate << 3;
    std::cout << "After writing the int '3' to append stream \"1 2\""
              << ", str() = \"" << ate.str() << "\"\n";
}
```

Output:

```text
After reading the first int from "1 2", the int is 1, str() = "1 2"
After writing the int '3' to output stream "1 2", str() = "3 2"
After writing the int '3' to append stream "1 2", str() = "1 23"
```
