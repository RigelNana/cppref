{/* source:cpp-io-basic-ostringstream-operator:0001 */}
Move assigns the string stream `other` to `*this`, effectively move-assigning both the [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) base class and the associated [`std::basic_stringbuf`](/docs/cpp/library/io/basic_stringbuf).

{/* source:cpp-io-basic-ostringstream-operator:0002 */}
Note that the base class move assignment swaps all stream state variables (except for `rdbuf`) between `*this` and `other`.
