{/* source:cpp-io-ios-base-imbue:0001 */}
Sets the associated locale of the stream to `loc`. Before returning, each function, registered by [`register_callback()`](/docs/cpp/library/io/ios_base/register_callback) is called with `imbue_event` as a parameter.

### Parameters

{/* source:cpp-io-ios-base-imbue:0002 */}
<ParameterList>
  <Parameter name="loc">new locale to associate the stream to</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-ios-base-imbue:0003 */}
The locale object associated with the stream before the operation.
