  <DeclarationDescription>
    {/* source:cpp-io-ios-base-precision:0001 */}
    Manages the precision (i.e. how many digits are generated) of floating point output performed by [`std::num_put::do_put`](/docs/cpp/library/text/locale/num_put/put).

    {/* source:cpp-io-ios-base-precision:0002 */}
    1. Returns the current precision.

    {/* source:cpp-io-ios-base-precision:0003 */}
    2. Sets the precision to the given one. Returns the previous precision.

    {/* source:cpp-io-ios-base-precision:0004 */}
    The default precision, as established by [`std::basic_ios::init`](/docs/cpp/library/io/basic_ios/init), is 6.
  </DeclarationDescription>
</DeclarationDoc>

  <Parameter name="new_precision">new precision setting</Parameter>

### Return value

{/* source:cpp-io-ios-base-precision:0006 */}
The precision before the call to the function

### Example

{/* source:cpp-io-ios-base-precision:0007 */}
```cpp
#include <iostream>
 
int main()
{
    const double d = 12.345678901234;
    std::cout << "The  default precision is " << std::cout.precision() << "\n\n";
    std::cout << "With default precision d is " << d << '\n';
    std::cout.precision(8);
    std::cout << "With high    precision d is " << d << '\n';
}
```

Output:

```text
The  default precision is 6
 
With default precision d is 12.3457
With high    precision d is 12.345679
```
