{/* source:cpp-io-ios-base-ios-base:0001 */}
Destroys the `ios_base` object.

{/* source:cpp-io-ios-base-ios-base:0002 */}
Before any of the member functions would yield undefined results, calls callbacks, registered by [`register_callback()`](/docs/cpp/library/io/ios_base/register_callback) passing [`erase_event`](/docs/cpp/library/io/ios_base/event) as parameter. Then, deallocates any memory obtained.

{/* source:cpp-io-ios-base-ios-base:0003 */}
No operations on `rdbuf` are performed, it is not destroyed.
