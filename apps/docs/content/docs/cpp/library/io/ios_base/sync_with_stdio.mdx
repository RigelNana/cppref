{/* source:cpp-io-ios-base-sync-with-stdio:0001 */}
Sets whether the standard C++ streams are synchronized to the standard C streams after each input/output operation.

{/* source:cpp-io-ios-base-sync-with-stdio:0002 */}
The standard C++ streams are the following: [`std::cin`](/docs/cpp/library/io/basic_istream/cin), [`std::cout`](/docs/cpp/library/io/basic_ostream/cout), [`std::cerr`](/docs/cpp/library/io/basic_ostream/cerr), [`std::clog`](/docs/cpp/library/io/basic_ostream/clog), [`std::wcin`](/docs/cpp/library/io/basic_istream/cin), [`std::wcout`](/docs/cpp/library/io/basic_ostream/cout), [`std::wcerr`](/docs/cpp/library/io/basic_ostream/cerr) and [`std::wclog`](/docs/cpp/library/io/basic_ostream/clog).

{/* source:cpp-io-ios-base-sync-with-stdio:0003 */}
The standard C streams are the following: [`stdin`](/docs/cpp/library/io/c/std_streams), [`stdout`](/docs/cpp/library/io/c/std_streams) and [`stderr`](/docs/cpp/library/io/c/std_streams).

{/* source:cpp-io-ios-base-sync-with-stdio:0004 */}
For a standard stream `str`, synchronized with the C stream `f`, the following pairs of functions have identical effect:

{/* source:cpp-io-ios-base-sync-with-stdio:0005 */}
1. `std::fputc(f, c)` and `str.rdbuf()->sputc(c)`.

{/* source:cpp-io-ios-base-sync-with-stdio:0006 */}
2. `std::fgetc(f)` and `str.rdbuf()->sbumpc()`.

{/* source:cpp-io-ios-base-sync-with-stdio:0007 */}
3. `std::ungetc(c, f)` and `str.rdbuf()->sputbackc(c)`.

{/* source:cpp-io-ios-base-sync-with-stdio:0008 */}
In practice, this means that the synchronized C++ streams are unbuffered, and each I/O operation on a C++ stream is immediately applied to the corresponding C stream's buffer. This makes it possible to freely mix C++ and C I/O.

{/* source:cpp-io-ios-base-sync-with-stdio:0009 */}
In addition, synchronized C++ streams are guaranteed to be thread-safe (individual characters output from multiple threads may interleave, but no data races occur).

{/* source:cpp-io-ios-base-sync-with-stdio:0010 */}
If the synchronization is turned off, the C++ standard streams are allowed to buffer their I/O independently, which may be considerably faster in some cases.

{/* source:cpp-io-ios-base-sync-with-stdio:0011 */}
By default, all eight standard C++ streams are synchronized with their respective C streams.

{/* source:cpp-io-ios-base-sync-with-stdio:0012 */}
If this function is called after I/O has occurred on the standard stream, the behavior is implementation-defined: implementations range from no effect to destroying the read buffer.

### Return value

{/* source:cpp-io-ios-base-sync-with-stdio:0014 */}
Synchronization state before the call to the function.

### Example

{/* source:cpp-io-ios-base-sync-with-stdio:0015 */}
```cpp
#include <cstdio>
#include <iostream>
 
int main()
{
    std::ios::sync_with_stdio(false);
    std::cout << "a\n";
    std::printf("b\n");
    std::cout << "c\n";
}
```

Possible output:

```text
b
a
c
```
