{/* source:cpp-io-ios-base-event:0001 */}
Specifies the event type which is passed to functions registered by [`register_callback()`](/docs/cpp/library/io/ios_base/register_callback) on specific events. The following constants are defined:

{/* source:cpp-io-ios-base-event:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`erase_event`</DescriptionTerm>
    <DescriptionBody>issued on `~ios_base()` or [`basic_ios::copyfmt()`](/docs/cpp/library/io/basic_ios/copyfmt) (before the copy of members takes place)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`imbue_event`</DescriptionTerm>
    <DescriptionBody>issued on [`imbue()`](/docs/cpp/library/io/ios_base/imbue)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`copyfmt_event`</DescriptionTerm>
    <DescriptionBody>issued on [`basic_ios::copyfmt()`](/docs/cpp/library/io/basic_ios/copyfmt) (after the copy of members takes place, but before the exception settings are copied)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
