Specifies file seeking direction type. The following constants are defined:

{/* source:cpp-io-ios-base-seekdir:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`beg`</DescriptionTerm>
    <DescriptionBody>the beginning of a stream</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`end`</DescriptionTerm>
    <DescriptionBody>the ending of a stream</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`cur`</DescriptionTerm>
    <DescriptionBody>the current position of stream position indicator</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Example

{/* source:cpp-io-ios-base-seekdir:0003 */}
```cpp
#include <iostream>
#include <sstream>
#include <string>
 
int main()
{
    std::istringstream in("Hello, World!");
    std::string word1, word2, word3, word4, word5;
 
    in >> word1;
    in.seekg(0, std::ios_base::beg); // <- rewind
    in >> word2;
    in.seekg(1, std::ios_base::cur); // -> seek from cur pos toward the end
    in >> word3;
    in.seekg(-6, std::ios_base::cur); // <- seek from cur pos (end) toward begin
    in >> word4;
    in.seekg(-6, std::ios_base::end); // <- seek from end toward begin
    in >> word5;
 
    std::cout << "word1 = " << word1 << '\n'
              << "word2 = " << word2 << '\n'
              << "word3 = " << word3 << '\n'
              << "word4 = " << word4 << '\n'
              << "word5 = " << word5 << '\n';
}
```

Output:

```text
word1 = Hello,
word2 = Hello,
word3 = World!
word4 = World!
word5 = World!
```
