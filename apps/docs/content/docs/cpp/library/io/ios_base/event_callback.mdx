{/* source:cpp-io-ios-base-event-callback:0001 */}
The type of function callbacks that can be registered using [`register_callback()`](/docs/cpp/library/io/ios_base/register_callback) to be called on specific events.

{/* source:cpp-io-ios-base-event-callback:0002 */}
`type` is a value of type [`ios_base::event`](/docs/cpp/library/io/ios_base/event) which indicates the type of the event that will invoke this callback.

{/* source:cpp-io-ios-base-event-callback:0003 */}
`ios` refers to the stream object for which the callback is invoked: `*this` is passed as the argument when callbacks are invoked by [`std::ios_base`](/docs/cpp/library/io/ios_base) and [`std::basic_ios`](/docs/cpp/library/io/basic_ios) member functions.

{/* source:cpp-io-ios-base-event-callback:0004 */}
`index` is the user-provided value passed to [`register_callback()`](/docs/cpp/library/io/ios_base/register_callback) when registering the function.
