##### Formatting flags

{/* source:cpp-io-ios-base-flags:0005 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`dec`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>use decimal base for integer I/O: see [`std::dec`](/docs/cpp/library/io/manip/hex)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`oct`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>use octal base for integer I/O: see [`std::oct`](/docs/cpp/library/io/manip/hex)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`hex`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>use hexadecimal base for integer I/O: see [`std::hex`](/docs/cpp/library/io/manip/hex)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`basefield`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>`dec | oct | hex`. Useful for masking operations</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`left`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>left adjustment (adds fill characters to the right): see [`std::left`](/docs/cpp/library/io/manip/left)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`right`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>right adjustment (adds fill characters to the left): see [`std::right`](/docs/cpp/library/io/manip/left)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`internal`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>internal adjustment (adds fill characters to the internal designated point): see [`std::internal`](/docs/cpp/library/io/manip/left)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`adjustfield`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>`left | right | internal`. Useful for masking operations</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`scientific`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>generate floating point types using scientific notation, or hex notation if combined with `fixed`: see [`std::scientific`](/docs/cpp/library/io/manip/fixed)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`fixed`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>generate floating point types using fixed notation, or hex notation if combined with `scientific`: see [`std::fixed`](/docs/cpp/library/io/manip/fixed)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`floatfield`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>`scientific | fixed`. Useful for masking operations</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`boolalpha`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>insert and extract `bool` type in alphanumeric format: see [`std::boolalpha`](/docs/cpp/library/io/manip/boolalpha)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`showbase`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>generate a prefix indicating the numeric base for integer output, require the currency indicator in monetary I/O: see [`std::showbase`](/docs/cpp/library/io/manip/showbase)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`showpoint`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>generate a decimal-point character unconditionally for floating-point number output: see [`std::showpoint`](/docs/cpp/library/io/manip/showpoint)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`showpos`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>generate a `+` character for non-negative numeric output: see [`std::showpos`](/docs/cpp/library/io/manip/showpos)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`skipws`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>skip leading whitespace before certain input operations: see [`std::skipws`](/docs/cpp/library/io/manip/skipws)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`unitbuf`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>flush the output after each output operation: see [`std::unitbuf`](/docs/cpp/library/io/manip/unitbuf)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`uppercase`](/docs/cpp/library/io/ios_base/fmtflags)</DescriptionTerm>
    <DescriptionBody>replace certain lowercase letters with their uppercase equivalents in certain output operations: see [`std::uppercase`](/docs/cpp/library/io/manip/uppercase)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
