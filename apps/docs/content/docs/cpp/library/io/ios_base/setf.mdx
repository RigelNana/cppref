  <DeclarationDescription>
    {/* source:cpp-io-ios-base-setf:0001 */}
    Sets the formatting flags to specified settings.

    {/* source:cpp-io-ios-base-setf:0002 */}
    1. Sets the formatting flags identified by `flags`. Effectively, the following operation is performed `fl = fl | flags` where `fl` defines the state of internal formatting flags.

    {/* source:cpp-io-ios-base-setf:0003 */}
    2. Clears the formatting flags under `mask`, and sets the cleared flags to those specified by `flags`. Effectively the following operation is performed `fl = (fl & ~mask) | (flags & mask)` where `fl` defines the state of internal formatting flags.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-ios-base-setf:0004 */}
<ParameterList>
  <Parameter name="flags, mask">new formatting setting. `mask` defines which flags can be altered, `flags` defines which flags of those to be altered should be set (others will be cleared). Both parameters can be a combination of the [formatting flags](/docs/cpp/library/io/ios_base/setf#Formatting_flags) constants</Parameter>
</ParameterList>

### Example

{/* source:cpp-io-ios-base-setf:0007 */}
```cpp
#include <iomanip>
#include <iostream>
#include <numbers>
 
int main()
{
    const double PI = std::numbers::pi;
    const int WIDTH = 15;
 
    std::cout.setf(std::ios::right); // equivalent: cout << right;
    std::cout << std::setw(WIDTH / 2) << "radius"
              << std::setw(WIDTH) << "circumference" << '\n';
 
    std::cout.setf(std::ios::fixed); // equivalent: cout << fixed;
    for (double radius = 1; radius <= 6; radius += 0.5)
        std::cout << std::setprecision(1) << std::setw(WIDTH / 2)
                  << radius
                  << std::setprecision(2) << std::setw(WIDTH)
                  << (2 * PI * radius) << '\n';
}
```

Output:

```text
 radius  circumference
    1.0           6.28
    1.5           9.42
    2.0          12.57
    2.5          15.71
    3.0          18.85
    3.5          21.99
    4.0          25.13
    4.5          28.27
    5.0          31.42
    5.5          34.56
    6.0          37.70
```
