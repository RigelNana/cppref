{/* source:cpp-io-ios-base-init:0001 */}
This class is used to ensure that the default C++ streams ([`std::cin`](/docs/cpp/library/io/basic_istream/cin), [`std::cout`](/docs/cpp/library/io/basic_ostream/cout), etc.) are properly initialized and destructed. The class tracks how many instances of it are created and initializes the C++ streams when the first instance is constructed as well as flushes the output streams when the last instance is destructed.

{/* source:cpp-io-ios-base-init:0002 */}
The header [`<iostream>`](/docs/cpp/library/headers/iostream) behaves as if it defines (directly or indirectly) an instance of `std::ios_base::Init` with static storage duration: this makes it safe to access the standard I/O streams in the constructors and destructors of static objects with [ordered initialization](/docs/cpp/language/initialization#Dynamic_initialization) (as long as [`<iostream>`](/docs/cpp/library/headers/iostream) is included in the translation unit before these objects were defined).

{/* source:cpp-io-ios-base-init:0003 */}
<Revision since="C++23">
Each [C++ library module](/docs/cpp/library/standard_library#Importing_modules) in a [hosted implementation](/docs/cpp/library/freestanding) behaves as if it contains an [interface unit](/docs/cpp/language/basic_concepts/modules#Module_declarations) that defines an [unexported](/docs/cpp/language/basic_concepts/modules#Exporting_declarations_and_definitions) `std::ios_base::Init` variable with [ordered initialization](/docs/cpp/language/initialization#Dynamic_initialization).

As a result, the definition of that variable is appearance-ordered before any declaration following the point of importation of a C++ library module. Whether such a definition exists is unobservable by a program that does not reference any of the standard iostream objects.
</Revision>
