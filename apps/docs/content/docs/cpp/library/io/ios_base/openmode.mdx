{/* source:cpp-io-ios-base-openmode:0001 */}
Specifies available file open flags. It is a [*BitmaskType*](/docs/cpp/library/named_req/BitmaskType), the following constants are defined:

{/* source:cpp-io-ios-base-openmode:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`app`</DescriptionTerm>
    <DescriptionBody>seek to the end of stream before each write</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`binary`</DescriptionTerm>
    <DescriptionBody>open in [binary mode](/docs/cpp/library/io/c/FILE#Binary_and_text_modes)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`in`</DescriptionTerm>
    <DescriptionBody>open for reading</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`out`</DescriptionTerm>
    <DescriptionBody>open for writing</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`trunc`</DescriptionTerm>
    <DescriptionBody>discard the contents of the stream when opening</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`ate`</DescriptionTerm>
    <DescriptionBody>seek to the end of stream immediately after open</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`noreplace` <InlineRevision since="C++23" /></DescriptionTerm>
    <DescriptionBody>open in exclusive mode</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Example

{/* source:cpp-io-ios-base-openmode:0003 */}
```cpp
#include <fstream>
#include <iostream>
#include <string>
 
int main()
{
    const char* fname = "unique_name.txt";
 
    // write to a temporary stream object
    std::fstream(fname, std::ios::out | std::ios::trunc) << "Hi";
 
    std::string s;
    std::fstream(fname, std::ios::in) >> s;
    std::cout << s << '\n';
}
```

Output:

```text
Hi
```
