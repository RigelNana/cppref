{/* source:cpp-io-ios-base:0001 */}
The class `ios_base` is a multipurpose class that serves as the base class for all I/O stream classes. It maintains several kinds of data:

{/* source:cpp-io-ios-base:0002 */}
1. state information: stream status flags.

{/* source:cpp-io-ios-base:0003 */}
2. control information: flags that control formatting of both input and output sequences and the imbued locale.

{/* source:cpp-io-ios-base:0004 */}
3. private storage: indexed extensible data structure that allows both `long` and `void*` members, which may be implemented as two arbitrary-length arrays or a single array of two-element structs or another container.

{/* source:cpp-io-ios-base:0005 */}
4. callbacks: arbitrary number of user-defined functions to be called from [`imbue()`](/docs/cpp/library/io/ios_base/imbue), [`std::basic_ios::copyfmt()`](/docs/cpp/library/io/basic_ios/copyfmt), and [`~ios_base()`](/docs/cpp/library/io/ios_base/~ios_base).

{/* source:cpp-io-ios-base:0006 */}
Typical implementation holds member constants corresponding to all values of [`fmtflags`](/docs/cpp/library/io/ios_base/fmtflags), [`iostate`](/docs/cpp/library/io/ios_base/iostate), [`openmode`](/docs/cpp/library/io/ios_base/openmode), and [`seekdir`](/docs/cpp/library/io/ios_base/seekdir) shown below, member variables to maintain current precision, width, and formatting flags, the exception mask, the buffer error state, a resizeable container holding the callbacks, the currently imbued locale, the private storage, and a static integer variable for [`xalloc()`](/docs/cpp/library/io/ios_base/xalloc).

### Defect reports

{/* source:cpp-io-ios-base:0010 */}
The following behavior-changing defect reports were applied retroactively to previously published C++ standards.

{/* source:cpp-io-ios-base:0011 */}
<DefectReportList>
  <DefectReport kind="lwg" id={1357} standard="C++98">
    <PublishedBehavior>`std::ios_base` defined `operator~`, `operator&` and `operator|` for types `openmode`, `fmtflags` and `iostate`, violating the requirements of [*BitmaskType*](/docs/cpp/library/named_req/BitmaskType)[[1]](/docs/cpp/library/io/ios_base#cite_note-1)</PublishedBehavior>
    <CorrectedBehavior>removed these definitions</CorrectedBehavior>
  </DefectReport>
</DefectReportList>

{/* source:cpp-io-ios-base:0012 */}
1. ↑ A [*BitmaskType*](/docs/cpp/library/named_req/BitmaskType) needs to support bitwise opertaions on its own. The bitwise operation support should not be provided externally.
