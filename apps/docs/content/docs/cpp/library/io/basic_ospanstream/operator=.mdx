  <DeclarationDescription>
    {/* source:cpp-io-basic-ospanstream-operator:0001 */}
    1. Move assigns the `other` to `*this`, effectively move-assigning both the [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) base class subobject and the wrapped `std::basic_spanbuf`.

    {/* source:cpp-io-basic-ospanstream-operator:0002 */}
    2. Copy assignment operator is deleted. `basic_ospanstream` is not copy assignable.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-io-basic-ospanstream-operator:0003 */}
Note that move assignment operator of the base class swaps all stream state variables (except for [`rdbuf()`](/docs/cpp/library/io/basic_ospanstream/rdbuf)) between `*this` and `other`.

{/* source:cpp-io-basic-ospanstream-operator:0004 */}
It is implementation-defined whether the `std::basic_spanbuf` wrapped in `other` still holds an underlying buffer after the move assignment.
