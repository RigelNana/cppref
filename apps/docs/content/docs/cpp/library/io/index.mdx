{/* source:cpp-io:0000 */}
C++ includes the following input/output libraries: an [OOP-style](https://en.wikipedia.org/wiki/Object-oriented_programming) [stream-based I/O](/docs/cpp/library/io#Stream-based_I.2FO) library<InlineRevision since="C++23">, [print-based family](/docs/cpp/library/io#Print_functions_.28since_C.2B.2B23.29) of functions</InlineRevision>, and the standard set of [C-style I/O](/docs/cpp/library/io#C-style_I.2FO) functions.

{/* source:cpp-io:0001 */}
The stream-based input/output library is organized around abstract input/output devices. These abstract devices allow the same code to handle input/output to files, memory streams, or custom adaptor devices that perform arbitrary operations (e.g. compression) on the fly.

{/* source:cpp-io:0002 */}
Most of the classes are templated, so they can be adapted to any basic character type. Separate typedefs are provided for the most common basic character types (`char` and `wchar_t`). The classes are organized into the following hierarchy:

The Unicode-aware print-family functions that perform formatted I/O on text that is already formatted. They bring all the performance benefits of [`std::format`](/docs/cpp/library/text/format/format), are locale-independent by default, reduce global state, avoid allocating a temporary [`std::string`](/docs/cpp/library/string/basic_string) object and calling `operator<<`, and in general make formatting more efficient compared to [iostreams](/docs/cpp/library/io#Stream-based_I.2FO) and [stdio](/docs/cpp/library/io#C-style_I.2FO).
