{/* source:cpp-io-basic-ios-swap:0001 */}
Exchanges the states of `*this` and `other`, except for the associated rdbuf objects. [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf) and `other`.rdbuf ( ) returns the same values as before the call.

{/* source:cpp-io-basic-ios-swap:0002 */}
This swap function is protected: it is called by the swap member functions of the derived stream classes such as [`std::basic_ofstream`](/docs/cpp/library/io/basic_ofstream) or [`std::basic_istringstream`](/docs/cpp/library/io/basic_istringstream), which know how to correctly swap the associated stream buffers.
