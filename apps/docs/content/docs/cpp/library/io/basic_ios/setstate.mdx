{/* source:cpp-io-basic-ios-setstate:0001 */}
Sets the stream error flags `state` in addition to currently set flags. Essentially calls clear(rdstate( ) | `state`). May throw an exception.

{/* source:cpp-io-basic-ios-setstate:0002 */}
<ParameterList>
<Parameter name="state">stream error state flags to set. It can be a combination of the following constants:</Parameter>
</ParameterList>

<DescriptionList>
    <DescriptionItem>
      <DescriptionTerm>[`goodbit`](/docs/cpp/library/io/ios_base/iostate)</DescriptionTerm>
      <DescriptionBody>no error</DescriptionBody>
    </DescriptionItem>
    <DescriptionItem>
      <DescriptionTerm>[`badbit`](/docs/cpp/library/io/ios_base/iostate)</DescriptionTerm>
      <DescriptionBody>irrecoverable stream error</DescriptionBody>
    </DescriptionItem>
    <DescriptionItem>
      <DescriptionTerm>[`failbit`](/docs/cpp/library/io/ios_base/iostate)</DescriptionTerm>
      <DescriptionBody>input/output operation failed (formatting or extraction error)</DescriptionBody>
    </DescriptionItem>
    <DescriptionItem>
      <DescriptionTerm>[`eofbit`](/docs/cpp/library/io/ios_base/iostate)</DescriptionTerm>
      <DescriptionBody>associated input sequence has reached end-of-file</DescriptionBody>
    </DescriptionItem>
</DescriptionList>

{/* source:cpp-io-basic-ios-setstate:0003 */}
(none)

{/* source:cpp-io-basic-ios-setstate:0004 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::ostringstream stream;
 
    if (!stream.fail())
        std::cout << "stream is not fail\n";
 
    stream.setstate(std::ios_base::failbit);
 
    if (stream.fail())
        std::cout << "now stream is fail\n";
 
    if (!stream.good())
        std::cout << "and stream is not good\n";
}
```

Output:

```text
stream is not fail
now stream is fail
and stream is not good
```
