Constructs a new std::basic_ios object.

{/* source:cpp-io-basic-ios-basic-ios:0002 */}
1. Default constructor. The internal state is not initialized. [`init()`](/docs/cpp/library/io/basic_ios/init) must be called before the first use of the object or before destructor, otherwise the behavior is undefined.

{/* source:cpp-io-basic-ios-basic-ios:0003 */}
2. Initializes the internal state by calling `init(sb)`. The associated stream buffer is set to `sb`.

{/* source:cpp-io-basic-ios-basic-ios:0004 */}
3. The copy constructor is <InlineRevision until="C++11">declared private and not defined</InlineRevision> <InlineRevision since="C++11">explicitly defined as deleted</InlineRevision> : I/O streams are not [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible).
