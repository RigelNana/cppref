{/* source:cpp-io-basic-ios-init:0001 */}
Sets the associated stream buffer to `sb` and initializes the internal state.

{/* source:cpp-io-basic-ios-init:0002 */}
The postconditions are as follows:

{/* source:cpp-io-basic-ios-init:0003 */}
| Element | Value |
| [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf) | `sb` |
| --- | --- |
| [`tie()`](/docs/cpp/library/io/basic_ios/tie) | null pointer |
| [`rdstate()`](/docs/cpp/library/io/basic_ios/rdstate) | `goodbit` if `sb` is not a null pointer, otherwise `badbit` |
| [`exceptions()`](/docs/cpp/library/io/basic_ios/exceptions) | `goodbit` |
| [`flags()`](/docs/cpp/library/io/ios_base/flags) | `skipws | dec` |
| [`width()`](/docs/cpp/library/io/ios_base/width) | ` 0 ` |
| [`precision()`](/docs/cpp/library/io/ios_base/precision) | `6` |
| [`fill()`](/docs/cpp/library/io/basic_ios/fill) | `widen ( ' ' )` |
| [`getloc()`](/docs/cpp/library/io/ios_base/getloc) | a copy of the value returned by `std:: locale ( )` |

{/* source:cpp-io-basic-ios-init:0004 */}
This member function is protected: it is called by the constructors of the derived stream classes [`std::basic_istream`](/docs/cpp/library/io/basic_istream) and [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream) once the associated stream buffer is known. Until this function is called, every member function (including the destructor) of the default-constructed [`std::basic_ios`](/docs/cpp/library/io/basic_ios) invokes undefined behavior. Note that basic_ios is a virtual base class, and therefore its constructor is not called by the constructors of those directly derived classes, which is why two-stage initialization is necessary.
