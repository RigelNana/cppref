{/* source:cpp-io-basic-ios-rdbuf:0001 */}
Manages the associated stream buffer.

{/* source:cpp-io-basic-ios-rdbuf:0002 */}
1. Returns the associated stream buffer. If there is no associated stream buffer, returns a null pointer.

{/* source:cpp-io-basic-ios-rdbuf:0003 */}
2. Sets the associated stream buffer to `sb`. The error state is cleared by calling [`clear()`](/docs/cpp/library/io/basic_ios/clear). Returns the associated stream buffer before the operation. If there is no associated stream buffer, returns a null pointer.

{/* source:cpp-io-basic-ios-rdbuf:0004 */}
<ParameterList>
<Parameter name="sb">Stream buffer to associate to.</Parameter>
</ParameterList>

{/* source:cpp-io-basic-ios-rdbuf:0005 */}
The associated stream buffer, or a null pointer if there was no associated stream buffer.

{/* source:cpp-io-basic-ios-rdbuf:0006 */}
May throw implementation-defined exceptions.

{/* source:cpp-io-basic-ios-rdbuf:0007 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::ostringstream local;
    auto cout_buff = std::cout.rdbuf(); // save pointer to std::cout buffer
 
    std::cout.rdbuf(local.rdbuf()); // substitute internal std::cout buffer with
                                    // buffer of 'local' object
 
    // now std::cout work with 'local' buffer
    // you don't see this message
    std::cout << "some message";
 
    // go back to old buffer
    std::cout.rdbuf(cout_buff);
 
    // you will see this message
    std::cout << "back to default buffer\n";
 
    // print 'local' content
    std::cout << "local content: " << local.str() << "\n";
}
```

Output:

```text
back to default buffer
local content: some message
```
