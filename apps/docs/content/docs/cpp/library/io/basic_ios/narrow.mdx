{/* source:cpp-io-basic-ios-narrow:0001 */}
Converts a current locale-specific character `c` to its standard equivalent. The result is converted from `char`_type to `char` if needed. If no conversion can be performed, the function returns `dfault`.

{/* source:cpp-io-basic-ios-narrow:0002 */}
Effectively calls std::use_facet \< std::ctype \<char_type\> \> (getloc( ) ).narrow (c, dfault) ;.

{/* source:cpp-io-basic-ios-narrow:0003 */}
<ParameterList>
<Parameter name="c">character to convert</Parameter>
<Parameter name="dfault">character to return if the conversion was unsuccessful</Parameter>
</ParameterList>

{/* source:cpp-io-basic-ios-narrow:0004 */}
Character converted to its standard equivalent and then to `char`. `dfault` is returned if the conversion fails.
