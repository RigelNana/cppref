{/* source:cpp-io-basic-ios-exceptions:0001 */}
Gets and sets the exception mask of the stream. The exception mask determines which error states trigger exceptions of type [`failure`](/docs/cpp/library/io/ios_base/failure).

{/* source:cpp-io-basic-ios-exceptions:0002 */}
1. Returns the exception mask.

{/* source:cpp-io-basic-ios-exceptions:0003 */}
2. Sets the exception mask to `except`. If the stream has an error state covered by the exception mask when called, an exception is immediately triggered.

{/* source:cpp-io-basic-ios-exceptions:0004 */}
<ParameterList>
<Parameter name="except">exception mask</Parameter>
</ParameterList>

{/* source:cpp-io-basic-ios-exceptions:0005 */}
1. The current exception mask.

{/* source:cpp-io-basic-ios-exceptions:0006 */}
2. (none)
