{/* source:cpp-io-basic-ios:0001 */}

{/* source:cpp-io-basic-ios:0009 */}
Straightforward implementation of std::basic_ios stores only the following members (which all depend on the template parameters and thus cannot be part of [`std::ios_base`](/docs/cpp/library/io/ios_base)):

{/* source:cpp-io-basic-ios:0010 */}
- the fill character (see
- [`fill()`](/docs/cpp/library/io/basic_ios/fill)
- ) the tied stream pointer (see
- [`tie()`](/docs/cpp/library/io/basic_ios/tie)
- ) the associated stream buffer pointer (see
- [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf)
- ).

{/* source:cpp-io-basic-ios:0011 */}
Actual implementations vary:

{/* source:cpp-io-basic-ios:0012 */}
Microsoft Visual Studio stores just those three members.

{/* source:cpp-io-basic-ios:0013 */}
LLVM libc++ stores 1 less member: it maintains the rdbuf pointer as a void * member of ios_base.

{/* source:cpp-io-basic-ios:0014 */}
GNU libstdc++ stores 4 additional members: three cached facets and a flag to indicate that fill was initialized.
