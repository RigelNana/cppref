{/* source:cpp-io-basic-ios-rdstate:0001 */}
Returns the current stream error state.

{/* source:cpp-io-basic-ios-rdstate:0002 */}
(none)

{/* source:cpp-io-basic-ios-rdstate:0003 */}
current stream error state. It is a bitmask type and can be a combination of the following constants:

{/* source:cpp-io-basic-ios-rdstate:0004 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`goodbit`](/docs/cpp/library/io/ios_base/iostate)</DescriptionTerm>
    <DescriptionBody>no error</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`badbit`](/docs/cpp/library/io/ios_base/iostate)</DescriptionTerm>
    <DescriptionBody>irrecoverable stream error</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`failbit`](/docs/cpp/library/io/ios_base/iostate)</DescriptionTerm>
    <DescriptionBody>input/output operation failed (formatting or extraction error)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`eofbit`](/docs/cpp/library/io/ios_base/iostate)</DescriptionTerm>
    <DescriptionBody>associated input sequence has reached end-of-file</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-io-basic-ios-rdstate:0005 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::ostringstream stream;
 
    if (stream.rdstate() == std::ios_base::goodbit)
        std::cout << "stream state is goodbit\n";
 
    stream.setstate(std::ios_base::eofbit);
 
    // check state is exactly eofbit (no failbit and no badbit)
    if (stream.rdstate() == std::ios_base::eofbit)
        std::cout << "stream state is eofbit\n";
}
```

Output:

```text
stream state is goodbit
stream state is eofbit
```
