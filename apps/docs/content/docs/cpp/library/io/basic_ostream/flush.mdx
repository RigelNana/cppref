{/* source:cpp-io-basic-ostream-flush:0001 */}
Writes uncommitted changes to the underlying output sequence. Behaves as an [*UnformattedOutputFunction*](/docs/cpp/library/named_req/UnformattedOutputFunction).

{/* source:cpp-io-basic-ostream-flush:0002 */}
If [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf) is a null pointer, the sentry object is not constructed.

{/* source:cpp-io-basic-ostream-flush:0003 */}
Otherwise, after constructing and checking the sentry object, calls `rdbuf()->pubsync()`. If the call returns `-1`, calls `setstate(badbit)`.

### Parameters

{/* source:cpp-io-basic-ostream-flush:0004 */}
(none)

### Return value

{/* source:cpp-io-basic-ostream-flush:0005 */}
`*this`

### Exceptions

{/* source:cpp-io-basic-ostream-flush:0006 */}
May throw [`std::ios_base::failure`](/docs/cpp/library/io/ios_base/failure) if `(exceptions() & badbit) != 0`.

### Example

{/* source:cpp-io-basic-ostream-flush:0007 */}
```cpp
#include <chrono>
#include <iostream>
#include <thread>
 
using namespace std::chrono_literals;
 
void f()
{
    std::cout << "Output from thread... ";
    for (int i{1}; i != 10; ++i)
    {
        std::this_thread::sleep_for(250ms);
        std::cout << i << ' ';
 
        // output three numbers at once;
        // the effect is observable only in real-time
        if (0 == (i % 3))
            std::cout.flush();
    }
    std::cout << std::endl; // flushes as well
}
 
int main()
{
    std::thread tr{f};
    std::this_thread::sleep_for(150ms);
    std::clog << "Output from main\n";
    tr.join();
}
```

Output:

```text
Output from main
Output from thread... 1 2 3 4 5 6 7 8 9
```
