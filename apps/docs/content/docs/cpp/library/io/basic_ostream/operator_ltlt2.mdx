  <DeclarationDescription>
    {/* source:cpp-io-basic-ostream-operator-ltlt2:0001 */}
    Inserts a character or a character string.

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0002 */}
    1. 1) Behaves as a [*FormattedOutputFunction*](/docs/cpp/library/named_req/FormattedOutputFunction). After constructing and checking the [sentry](/docs/cpp/library/io/basic_ostream/sentry) object, inserts the character `ch`. If `ch` has type `char` and the [character container type](/docs/cpp/library/string) of `os` is not `char`, `os.widen(ch)` will be inserted instead.

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0003 */}
    Padding is determined as follows: If `os.width() > 1`, then `os.width() - 1` copies of `os.fill()` are added to the output character to form the output character sequence. If `(out.flags() & std::ios_base::adjustfield) == std::ios_base::left`, the fill characters are placed after the output character, otherwise before.

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0004 */}
    After insertion, `os.width(0)` is called to cancel the effects of [`std::setw`](/docs/cpp/library/io/manip/setw), if any.

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0005 */}
    2. 2) Behaves as a [*FormattedOutputFunction*](/docs/cpp/library/named_req/FormattedOutputFunction). After constructing and checking the sentry object, inserts successive characters from the character array whose first element is pointed to by `s`. For the first and third overloads (where `CharT` matches the type of `ch`), exactly `traits::length(s)` characters are inserted. For the second overload, exactly `std::char_traits<char>::length(s)` characters are inserted. For the last two overloads, exactly `traits::length(reinterpret_cast<const char*>(s))` are inserted.

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0006 */}
    Before insertion, first, all characters are widened using `os.widen()`, then padding is determined as follows: If the number of characters to insert is less than `os.width()`, then enough copies of `os.fill()` are added to the character sequence to make its length equal `os.width()`. If `(out.flags() & std::ios_base::adjustfield) == std::ios_base::left`, the fill characters are added at the end of the output sequence, otherwise they are added before the output sequence.

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0007 */}
    After insertion, `os.width(0)` is called to cancel the effects of [`std::setw`](/docs/cpp/library/io/manip/setw), if any.

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0008 */}
    If `s` is a null pointer, the behavior is undefined.

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0009 */}
    3. 3) Calls the appropriate insertion operator, given an rvalue reference to an output stream object (equivalent to `os << value`). This overload participates in overload resolution only if the expression `os << value` is well-formed and `Ostream` is a class type publicly and unambiguously derived from [`std::ios_base`](/docs/cpp/library/io/ios_base).

    {/* source:cpp-io-basic-ostream-operator-ltlt2:0010 */}
    4. 4) Overloads that accept `char16_t`, `char32_t` etc (or null terminated sequence thereof) are deleted: `std::cout << u'X'` is not allowed. Previously, these would print an integer or pointer value.
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-io-basic-ostream-operator-ltlt2:0014 */}
Before [LWG issue 1203](https://cplusplus.github.io/LWG/issue1203), code such as `(std::ostringstream() << 1.2).str()` does not compile.

### Example

{/* source:cpp-io-basic-ostream-operator-ltlt2:0015 */}
```cpp
#include <fstream>
#include <iostream>
 
void foo()
{
    // error: operator<< (basic_ostream<char, _Traits>&, char8_t) is deleted
//  std::cout << u8'z' << '\n';
}
 
std::ostream& operator<<(std::ostream& os, char8_t const& ch)
{
    return os << static_cast<char>(ch);
}
 
int main()
{
    std::cout << "Hello, world" // uses `const char*` overload
              << '\n';          // uses `char` overload
    std::ofstream{"test.txt"} << 1.2; // uses rvalue overload
 
    std::cout << u8'!' << '\n'; // uses program-defined operator<<(os, char8_t const&)
}
```

Output:

```text
Hello, world
!
```

### Defect reports

{/* source:cpp-io-basic-ostream-operator-ltlt2:0016 */}
The following behavior-changing defect reports were applied retroactively to previously published C++ standards.

{/* source:cpp-io-basic-ostream-operator-ltlt2:0017 */}
<DefectReportList>
  <DefectReport kind="lwg" id={167} standard="C++98">
    <PublishedBehavior>the number of characters inserted for all overloads in (2) was `traits::length(s)`</PublishedBehavior>
    <CorrectedBehavior>updated the numbers for the overloads where `CharT` does not match the type of `ch`</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={1203} standard="C++11">
    <PublishedBehavior>overload for rvalue stream returned lvalue reference to the base class</PublishedBehavior>
    <CorrectedBehavior>returns rvalue reference to the derived class</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={2011} standard="C++98">
    <PublishedBehavior>padding was determined by [`std::num_put::do_put()`](/docs/cpp/library/text/locale/num_put/put)</PublishedBehavior>
    <CorrectedBehavior>determined by the operator itself</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={2534} standard="C++11">
    <PublishedBehavior>overload for rvalue stream was not constrained</PublishedBehavior>
    <CorrectedBehavior>constrained</CorrectedBehavior>
  </DefectReport>
</DefectReportList>
