{/* source:cpp-io-basic-ostream-seekp:0001 */}
Sets the output position indicator of the current associated streambuf object.

{/* source:cpp-io-basic-ostream-seekp:0002 */}
<Revision since="C++11">
Behaves as [*UnformattedOutputFunction*](/docs/cpp/library/named_req/UnformattedOutputFunction) (except without actually performing output). After constructing and checking the sentry object,
</Revision>

{/* source:cpp-io-basic-ostream-seekp:0003 */}
1. 1) if `fail() != true`, sets the output position indicator to absolute (relative to the beginning of the file) value `pos` by calling `rdbuf()->pubseekpos(pos, std::ios_base::out)`. In case of failure, calls `setstate(std::ios_base::failbit)`.

{/* source:cpp-io-basic-ostream-seekp:0004 */}
2. 2) if `fail() != true`, sets the output position indicator to offset `off` relative to `dir` by calling `rdbuf()->pubseekoff(off, dir, std::ios_base::out)`. In case of failure, calls `setstate(std::ios_base::failbit)`.

### Parameters

{/* source:cpp-io-basic-ostream-seekp:0005 */}
<ParameterList>
  <Parameter name="pos">absolute position to set the output position indicator to</Parameter>
  <Parameter name="off">relative position (positive or negative) to set the output position indicator to</Parameter>
  <Parameter name="dir">defines base position to apply the relative offset to. It can be one of the following constants:</Parameter>
</ParameterList>

- [`beg`](/docs/cpp/library/io/ios_base/seekdir) the beginning of a stream
- [`end`](/docs/cpp/library/io/ios_base/seekdir) the ending of a stream
- [`cur`](/docs/cpp/library/io/ios_base/seekdir) the current position of stream position indicator

### Return value

{/* source:cpp-io-basic-ostream-seekp:0006 */}
`*this`

### Exceptions

{/* source:cpp-io-basic-ostream-seekp:0007 */}
1. 1,2) May throw [`std::ios_base::failure`](/docs/cpp/library/io/ios_base/failure) in case of failure, if `exceptions() & failbit != 0`.

### Example

{/* source:cpp-io-basic-ostream-seekp:0008 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::ostringstream os("hello, world");
    os.seekp(7);
    os << 'W';
    os.seekp(0, std::ios_base::end);
    os << '!';
    os.seekp(0);
    os << 'H';
    std::cout << os.str() << '\n';
}
```

Output:

```text
Hello, World!
```
