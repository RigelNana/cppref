<DeclarationDoc>
  <Declaration id="1" language="cpp" code={`protected:
basic_ostream& operator=( const basic_ostream& rhs ) = delete;`} />
  <Declaration id="2" language="cpp" since="C++11" code={`protected:
basic_ostream& operator=( basic_ostream&& rhs );`} />

  <DeclarationDescription>
    {/* source:cpp-io-basic-ostream-operator:0001 */}
    1. The copy assignment operator is protected, and is deleted. Output streams are not [*CopyAssignable*](/docs/cpp/library/named_req/CopyAssignable).

    {/* source:cpp-io-basic-ostream-operator:0002 */}
    2. The move assignment operator exchanges all data members of the base class, except for [`rdbuf()`](/docs/cpp/library/io/basic_ios/rdbuf), with `rhs`, as if by calling `swap(*rhs)`. This move assignment operator is protected: it is only called by the move assignment operators of the derived movable output stream classes [`std::basic_ofstream`](/docs/cpp/library/io/basic_ofstream) and [`std::basic_ostringstream`](/docs/cpp/library/io/basic_ostringstream), which know how to correctly move-assign the associated streambuffers.
  </DeclarationDescription>
</DeclarationDoc>

### Example

{/* source:cpp-io-basic-ostream-operator:0004 */}
```cpp
#include <iostream>
#include <sstream>
#include <utility>
 
int main()
{
    std::ostringstream s;
//  std::cout = s;            // ERROR: copy assignment operator is deleted
//  std::cout = std::move(s); // ERROR: move assignment operator is protected
    s = std::move(std::ostringstream() << 42); // OK, moved through derived
    std::cout << s.str() << '\n';
}
```

Output:

```text
42
```
