{/* source:cpp-io-basic-ostream-vprint-unicode:0001 */}
Format `args` according to the format string `fmt`, and writes the result to the output stream `os`. Behaves as [*FormattedOutputFunction*](/docs/cpp/library/named_req/FormattedOutputFunction) of `os`, except that some details of error reporting [differ](/docs/cpp/library/io/basic_ostream/vprint_unicode#Exceptions).

{/* source:cpp-io-basic-ostream-vprint-unicode:0002 */}
Performs the following operations in order:

{/* source:cpp-io-basic-ostream-vprint-unicode:0003 */}
1. First, the function constructs and checks the [sentry](/docs/cpp/library/io/basic_ostream/sentry) object.
2. Initializes an automatic variable as if by `std::string out = std::vformat(os.getloc(), fmt, args);`.
3. Writes `out` to `os`:

{/* source:cpp-io-basic-ostream-vprint-unicode:0004 */}
- If `os` refers to a terminal that is only capable of displaying Unicode via a [native Unicode API](/docs/cpp/library/io/vprint_unicode#Notes), flushes `os` and writes `out` to the terminal using the native Unicode API. Otherwise, inserts the character sequence [`out.begin()`, `out.end()`) into `os`.

{/* source:cpp-io-basic-ostream-vprint-unicode:0005 */}
If writing to the terminal or inserting into `os` fails, calls `os.setstate(std::ios_base::badbit)`.

{/* source:cpp-io-basic-ostream-vprint-unicode:0006 */}
If `out` contains invalid Unicode [code units](https://en.wikipedia.org/wiki/Character_encoding#Terminology) when the native Unicode API is used, the behavior is undefined.

### Parameters

{/* source:cpp-io-basic-ostream-vprint-unicode:0007 */}
<ParameterList>
  <Parameter name="os">output stream to insert data into</Parameter>
  <Parameter name="fmt">
an object that represents the format string. The format string consists of

- ordinary characters (except `{` and `}`), which are copied unchanged to the output,
- escape sequences `{{` and `}}`, which are replaced with `{` and `}` respectively in the output, and
- replacement fields.

Each replacement field has the following format:

1. `{ arg-id (optional) }` – replacement field without a format specification
2. `{ arg-id (optional) : format-spec }` – replacement field with a format specification

`arg-id` – specifies the index of the argument in `args` whose value is to be used for formatting; if it is omitted, the arguments are used in order.

The `arg-id`s in a format string must all be present or all be omitted. Mixing manual and automatic indexing is an error.

`format-spec` – the format specification defined by the [`std::formatter`](/docs/cpp/library/text/format/formatter) specialization for the corresponding argument. Cannot start with `}`.

For basic types and standard string types, the format specification is interpreted as [standard format specification](/docs/cpp/library/text/format/spec).

For chrono types, the format specification is interpreted as [chrono format specification](/docs/cpp/library/chrono/system_clock/formatter#Format_specification).

<Revision since="C++23">
- For range types, the format specification is interpreted as [range format specification](/docs/cpp/library/text/format/range_formatter#Range_format_specification).
- For [`std::pair`](/docs/cpp/library/utility/pair) and [`std::tuple`](/docs/cpp/library/utility/tuple), the format specification is interpreted as [tuple format specification](/docs/cpp/library/text/format/tuple_formatter#Format_specification).
- For [`std::thread::id`](/docs/cpp/library/thread/thread/id) and [`std::stacktrace_entry`](/docs/cpp/library/error/stacktrace_entry), see [thread id format specification](/docs/cpp/library/thread/thread/id/formatter#Format_specification) and [stacktrace entry format specification](/docs/cpp/library/error/stacktrace_entry/formatter#Format_specification).
- For [`std::basic_stacktrace`](/docs/cpp/library/error/basic_stacktrace), no format specifier is allowed.
</Revision>

<Revision since="C++26">
- For [`std::filesystem::path`](/docs/cpp/library/filesystem/path), see [path format specification](/docs/cpp/library/filesystem/path/formatter#Format_specification).
</Revision>

For other formattable types, the format specification is determined by user-defined `formatter` specializations.

  </Parameter>
  <Parameter name="args">arguments to be formatted</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-io-basic-ostream-vprint-unicode:0008 */}
- [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) on allocation failure.
- Propagate any exception thrown by any [formatter](/docs/cpp/library/text/format/formatter), e.g. [`std::format_error`](/docs/cpp/library/text/format/format_error), without regard to the value of `os.exceptions()` and without turning on [`ios_base::badbit`](/docs/cpp/library/io/ios_base/iostate) in the error state of `os`.
- May throw [`ios_base::failure`](/docs/cpp/library/io/ios_base/failure) caused by `os.setstate(ios_base::badbit)` which is called if an insertion into `os` fails.

### Notes

{/* source:cpp-io-basic-ostream-vprint-unicode:0009 */}
If invoking the native Unicode API requires transcoding, the invalid code units are substituted with U+FFFD REPLACEMENT CHARACTER (see "The Unicode Standard - Core Specification", [Chapter 3.9](/docs/cpp/library/io/basic_ostream/vprint_unicode#External_links)).
