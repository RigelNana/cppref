{/* source:cpp-io-basic-ostream-put:0001 */}
Behaves as an [*UnformattedOutputFunction*](/docs/cpp/library/named_req/UnformattedOutputFunction). After constructing and checking the sentry object, writes the character `ch` to the output stream.

{/* source:cpp-io-basic-ostream-put:0002 */}
If the output fails for any reason, sets `badbit`.

### Parameters

{/* source:cpp-io-basic-ostream-put:0003 */}
<ParameterList>
  <Parameter name="ch">character to write</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-ostream-put:0004 */}
`*this`

### Notes

{/* source:cpp-io-basic-ostream-put:0005 */}
This function is not overloaded for the types `signed char` or `unsigned char`, unlike the formatted [`operator<<`](/docs/cpp/library/io/basic_ostream/operator_ltlt2).

{/* source:cpp-io-basic-ostream-put:0006 */}
Unlike formatted output functions, this function does not set the `failbit` if the output fails.

### Example

{/* source:cpp-io-basic-ostream-put:0007 */}
```cpp
#include <fstream>
#include <iostream>
 
int main()
{
    std::cout.put('a'); // normal usage
    std::cout.put('\n');
 
    std::ofstream s("/does/not/exist/");
    s.clear(); // pretend the stream is good
    std::cout << "Unformatted output: ";
    s.put('c'); // this will set badbit, but not failbit
    std::cout << " fail=" << bool(s.rdstate() & s.failbit);
    std::cout << " bad=" << s.bad() << '\n';
    s.clear();
    std::cout << "Formatted output:   ";
    s << 'c'; // this will set badbit and failbit
    std::cout << " fail=" << bool(s.rdstate() & s.failbit);
    std::cout << " bad=" << s.bad() << '\n';
}
```

Output:

```text
a
Unformatted output:  fail=0 bad=1
Formatted output:    fail=1 bad=1
```
