Returns the output position indicator of the current associated streambuf object.

{/* source:cpp-io-basic-ostream-tellp:0002 */}
<Revision since="C++11">
Behaves as [*UnformattedOutputFunction*](/docs/cpp/library/named_req/UnformattedOutputFunction) (except without actually performing output). After constructing and checking the sentry object,
</Revision>

{/* source:cpp-io-basic-ostream-tellp:0003 */}
If `fail()==true`, returns `pos_type(-1)`. Otherwise, returns `rdbuf()->pubseekoff(0, std::ios_base::cur, std::ios_base::out)`.

### Parameters

{/* source:cpp-io-basic-ostream-tellp:0004 */}
(none)

### Return value

{/* source:cpp-io-basic-ostream-tellp:0005 */}
current output position indicator on success, `pos_type(-1)` if a failure occurs.

### Example

{/* source:cpp-io-basic-ostream-tellp:0006 */}
```cpp
#include <iostream>
#include <sstream>
int main()
{
    std::ostringstream s;
    std::cout << s.tellp() << '\n';
    s << 'h';
    std::cout << s.tellp() << '\n';
    s << "ello, world ";
    std::cout << s.tellp() << '\n';
    s << 3.14 << '\n';
    std::cout << s.tellp() << '\n' << s.str();
}
```

Output:

```text
0
1
13
18
hello, world 3.14
```
