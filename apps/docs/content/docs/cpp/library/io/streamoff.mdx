{/* source:cpp-io-streamoff:0001 */}
The type `std::streamoff` is an implementation-defined <InlineRevision since="C++11">signed integral</InlineRevision> type of sufficient size to represent the maximum possible file size supported by the operating system. <InlineRevision since="C++11">Typically, this is an alias for `long long`.</InlineRevision>

{/* source:cpp-io-streamoff:0002 */}
It is used to represent offsets from stream positions (values of type [`std::fpos`](/docs/cpp/library/io/fpos)). A `std::streamoff` value constructed from `-1` is also used to represent error conditions by some of the I/O library functions.

### Relationship with std::fpos

{/* source:cpp-io-streamoff:0003 */}
- the difference between two [`std::fpos`](/docs/cpp/library/io/fpos) objects is a value of type `std::streamoff`

{/* source:cpp-io-streamoff:0004 */}
- a value of type `std::streamoff` may be added or subtracted from [`std::fpos`](/docs/cpp/library/io/fpos) yielding a different [`std::fpos`](/docs/cpp/library/io/fpos).

{/* source:cpp-io-streamoff:0005 */}
- a value of type [`std::fpos`](/docs/cpp/library/io/fpos) is implicitly convertible to `std::streamoff` (the conversion result is the offset from the beginning of the file).

{/* source:cpp-io-streamoff:0006 */}
- a value of type [`std::fpos`](/docs/cpp/library/io/fpos) is constructible from a value of type `std::streamoff`
