{/* source:cpp-io-basic-spanstream:0001 */}
The class template `std::basic_spanstream` implements input and output operations on streams based on fixed buffers.

{/* source:cpp-io-basic-spanstream:0002 */}
At the low level, the class essentially wraps a raw device implementation of `std::basic_spanbuf` into a higher-level interface of [`std::basic_iostream`](/docs/cpp/library/io/basic_iostream). The complete interface to unique `std::basic_spanbuf` members is provided.
