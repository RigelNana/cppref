    {/* source:cpp-io-basic-spanstream-basic-spanstream:0001 */}
    Constructs a new `basic_spanstream`.

    {/* source:cpp-io-basic-spanstream-basic-spanstream:0002 */}
    1. Uses the storage referenced by `s` as initial underlying buffer of the wrapped `std::basic_spanbuf` device. The wrapped `std::basic_spanbuf` object is constructed as `basic_spanbuf<Char, Traits>(s, mode)`.

    {/* source:cpp-io-basic-spanstream-basic-spanstream:0003 */}
    2. Move constructor. Move constructs the [`std::basic_iostream`](/docs/cpp/library/io/basic_iostream) base subobject and the wrapped `std::basic_spanbuf` from those of `rhs`, and then calls [`set_rdbuf`](/docs/cpp/library/io/basic_ios/set_rdbuf) with the address of the wrapped `std::basic_spanbuf` in `*this` to install it.

    {/* source:cpp-io-basic-spanstream-basic-spanstream:0004 */}
    3. Copy constructor is deleted. `basic_spanstream` is not copyable.
  </DeclarationDescription>
</DeclarationDoc>

| Constant | Explanation |
| --- | --- |
| [`app`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream before each write |
| [`binary`](/docs/cpp/library/io/ios_base/openmode) | open in [binary mode](/docs/cpp/library/io/c/FILE#Binary_and_text_modes) |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | open for reading |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | open for writing |
| [`trunc`](/docs/cpp/library/io/ios_base/openmode) | discard the contents of the stream when opening |
| [`ate`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream immediately after open |
| [`noreplace`](/docs/cpp/library/io/ios_base/openmode) <InlineRevision since="C++23" /> | open in exclusive mode |
