{/* source:cpp-io-c-fgetc:0001 */}
Reads the next character from the given input stream.

### Parameters

{/* source:cpp-io-c-fgetc:0002 */}
<ParameterList>
  <Parameter name="stream">to read the character from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-fgetc:0003 */}
The obtained character on success or [EOF](/docs/cpp/library/io/c) on failure.

{/* source:cpp-io-c-fgetc:0004 */}
If the failure has been caused by end of file condition, additionally sets the eof indicator (see [`std::feof()`](/docs/cpp/library/io/c/feof)) on `stream`. If the failure has been caused by some other error, sets the error indicator (see [`std::ferror()`](/docs/cpp/library/io/c/ferror)) on `stream`.

### Example

{/* source:cpp-io-c-fgetc:0005 */}
```cpp
#include <cstdio>
#include <cstdlib>
 
int main()
{
    int is_ok = EXIT_FAILURE;
    FILE* fp = std::fopen("/tmp/test.txt", "w+");
    if (!fp)
    {
        std::perror("File opening failed");
        return is_ok;
    }
 
    int c; // Note: int, not char, required to handle EOF
    while ((c = std::fgetc(fp)) != EOF) // Standard C I/O file reading loop
        std::putchar(c);
 
    if (std::ferror(fp))
        std::puts("I/O error when reading");
    else if (std::feof(fp))
    {
        std::puts("End of file reached successfully");
        is_ok = EXIT_SUCCESS;
    }
 
    std::fclose(fp);
    return is_ok;
}
```

Output:

```text
End of file reached successfully
```
