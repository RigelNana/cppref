Defined in header [`<cstdio>`](/docs/cpp/library/headers/cstdio)

  <Declaration language="cpp" code={`int fclose( std::FILE* stream );`} />
</DeclarationDoc>

{/* source:cpp-io-c-fclose:0001 */}
Closes the given file stream. Any unwritten buffered data are flushed to the OS. Any unread buffered data are discarded.

{/* source:cpp-io-c-fclose:0002 */}
Whether or not the operation succeeds, the stream is no longer associated with a file, and the buffer allocated by [`std::setbuf`](/docs/cpp/library/io/c/setbuf) or [`std::setvbuf`](/docs/cpp/library/io/c/setvbuf), if any, is also disassociated and deallocated if automatic allocation was used.

{/* source:cpp-io-c-fclose:0003 */}
The behavior is undefined if the value of the pointer `stream` is used after `fclose` returns.

### Parameters

{/* source:cpp-io-c-fclose:0004 */}
<ParameterList>
  <Parameter name="stream">the file stream to close</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-fclose:0005 */}
0 on success, [EOF](/docs/cpp/library/io/c) otherwise.

### Example

{/* source:cpp-io-c-fclose:0006 */}
```cpp
#include <cstdio>
#include <cstdlib>
 
int main()
{
    int is_ok = EXIT_FAILURE;
    FILE* fp = std::fopen("/tmp/test.txt", "w+");
    if (!fp)
    {
        std::perror("File opening failed");
        return is_ok;
    }
 
    int c; // Note: int, not char, required to handle EOF
    while ((c = std::fgetc(fp)) != EOF) // Standard C I/O file reading loop
        std::putchar(c);
 
    if (std::ferror(fp))
        std::puts("I/O error when reading");
    else if (std::feof(fp))
    {
        std::puts("End of file reached successfully");
        is_ok = EXIT_SUCCESS;
    }
 
    std::fclose(fp);
    return is_ok;
}
```

Output:

```text
End of file reached successfully
```
