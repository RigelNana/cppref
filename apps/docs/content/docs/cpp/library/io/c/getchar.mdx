{/* source:cpp-io-c-getchar:0001 */}
Reads the next character from [`stdin`](/docs/cpp/library/io/c/std_streams).

{/* source:cpp-io-c-getchar:0002 */}
Equivalent to `std::getc(stdin)`.

### Parameters

{/* source:cpp-io-c-getchar:0003 */}
(none)

### Return value

{/* source:cpp-io-c-getchar:0004 */}
The obtained character on success or [EOF](/docs/cpp/library/io/c) on failure.

{/* source:cpp-io-c-getchar:0005 */}
If the failure has been caused by end of file condition, additionally sets the eof indicator (see [`std::feof()`](/docs/cpp/library/io/c/feof)) on [`stdin`](/docs/cpp/library/io/c/std_streams). If the failure has been caused by some other error, sets the error indicator (see [`std::ferror()`](/docs/cpp/library/io/c/ferror)) on [`stdin`](/docs/cpp/library/io/c/std_streams).

### Example

{/* source:cpp-io-c-getchar:0006 */}
`std::getchar` with error checking. Exit program by entering ESC char.

{/* source:cpp-io-c-getchar:0007 */}
```cpp
#include <cctype>
#include <cstdio>
#include <cstdlib>
#include <iomanip>
#include <iostream>

int main()
{
    for (int ch; (ch = std::getchar()) != EOF ;) // read/print "abc" from stdin
    {
        if (std::isprint(ch))
            std::cout << static_cast<char>(ch) << '\n';
        if (ch == 27) // 'ESC' (escape) in ASCII
            return EXIT_SUCCESS;
    }

    // Test reason for reaching EOF.
    if (std::feof(stdin)) // if failure caused by end-of-file condition
        std::cout << "End of file reached\n";
    else if (std::ferror(stdin)) // if failure caused by some other error
    {
        std::perror("getchar()");
        std::cerr << "getchar() failed in file " << std::quoted(__FILE__)
                  << " at line # " << __LINE__ - 14 << '\n';
        std::exit(EXIT_FAILURE);
    }
    return EXIT_SUCCESS;
}
```
