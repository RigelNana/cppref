{/* source:cpp-io-c-ferror:0001 */}
Checks the given stream for errors.

### Parameters

{/* source:cpp-io-c-ferror:0002 */}
<ParameterList>
  <Parameter name="stream">the file stream to check</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-ferror:0003 */}
Nonzero value if the file stream has errors occurred, 0 otherwise.

### Example

{/* source:cpp-io-c-ferror:0004 */}
```cpp
#include <clocale>
#include <cstdio>
#include <cstdlib>
#include <cwchar>
 
int main()
{
    const char *fname = std::tmpnam(nullptr);
    std::FILE* f = std::fopen(fname, "wb");
    std::fputs("\xff\xff\n", f); // not a valid UTF-8 character sequence
    std::fclose(f);
 
    std::setlocale(LC_ALL, "en_US.utf8");
    f = std::fopen(fname, "rb");
    std::wint_t ch;
    while ((ch=std::fgetwc(f)) != WEOF) // attempt to read as UTF-8
        std::printf("%#x ", ch);
 
    if (std::feof(f))
        puts("EOF indicator set");
    if (std::ferror(f))
        puts("Error indicator set");
}
```

Output:

```text
Error indicator set
```
