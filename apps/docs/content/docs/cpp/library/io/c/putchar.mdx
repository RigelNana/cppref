{/* source:cpp-io-c-putchar:0001 */}
Writes a character `ch` to [`stdout`](/docs/cpp/library/io/c/std_streams). Internally, the character is converted to `unsigned char` just before being written.

{/* source:cpp-io-c-putchar:0002 */}
Equivalent to `std::putc(ch, stdout)`.

### Parameters

{/* source:cpp-io-c-putchar:0003 */}
<ParameterList>
  <Parameter name="ch">character to be written</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-putchar:0004 */}
On success, returns the written character.

{/* source:cpp-io-c-putchar:0005 */}
On failure, returns [EOF](/docs/cpp/library/io/c) and sets the error indicator (see [`std::ferror()`](/docs/cpp/library/io/c/ferror)) on [`stdout`](/docs/cpp/library/io/c/std_streams).

### Example

{/* source:cpp-io-c-putchar:0006 */}
```cpp
#include <cstdio>

int main()
{
    for (char c = 'a'; c != 'z'; ++c)
        std::putchar(c);

    // putchar return value is not equal to the argument
    int r = 0x1024;
    std::printf("\nr = 0x%x\n", r);
    r = std::putchar(r);
    std::printf("\nr = 0x%x\n", r);
}
```

Possible output:

```text
abcdefghijklmnopqrstuvwxy
r = 0x1024
$
r = 0x24
```
