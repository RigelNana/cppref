<DeclarationDoc>
Defined in header [`<cstdio>`](/docs/cpp/library/headers/cstdio)

  <Declaration language="cpp" code={`int fputc( int ch, std::FILE* stream );
int putc( int ch, std::FILE* stream );`} />
</DeclarationDoc>

{/* source:cpp-io-c-fputc:0001 */}
Writes a character `ch` to the given output stream `stream`.

{/* source:cpp-io-c-fputc:0002 */}
Internally, the character is converted to `unsigned char` just before being written.

{/* source:cpp-io-c-fputc:0003 */}
In C, [`putc()`](/docs/c/library/io/putc) may be implemented as a macro, which is disallowed in C++. Therefore, calls to `std::fputc()` and `std::putc()` always have the same effect.

### Parameters

{/* source:cpp-io-c-fputc:0004 */}
<ParameterList>
  <Parameter name="ch">character to be written</Parameter>
  <Parameter name="stream">output stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-fputc:0005 */}
On success, returns the written character.

{/* source:cpp-io-c-fputc:0006 */}
On failure, returns [EOF](/docs/cpp/library/io/c) and sets the error indicator (see [`std::ferror()`](/docs/cpp/library/io/c/ferror)) on `stream`.

### Example

{/* source:cpp-io-c-fputc:0007 */}
```cpp
#include <cstdio>
 
int main()
{
    for (char c = 'a'; c != 'z'; c++)
        std::putc(c, stdout);
 
    // putchar's return value is not equal to the argument
    int r = 0x102A;
    std::printf("\nr = 0x%x\n", r);
 
    r = std::putchar(r);
    std::printf("\nr = 0x%x\n", r);
}
```

Possible output:

```text
abcdefghijklmnopqrstuvwxy
r = 0x102A
*
r = 0x2A
```
