{/* source:cpp-io-c-putwchar:0001 */}
Writes a wide character `ch` to [`stdout`](/docs/cpp/library/io/c/std_streams).

### Parameters

{/* source:cpp-io-c-putwchar:0002 */}
<ParameterList>
  <Parameter name="ch">wide character to be written</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-putwchar:0003 */}
`ch` on success, `WEOF` on failure.

### Example

{/* source:cpp-io-c-putwchar:0004 */}
```cpp
#include <clocale>
#include <cstdio>
#include <cstdlib>
#include <cwchar>
#include <initializer_list>

int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");

    for (const wchar_t ch : {
        L'\u2200', // Unicode name: "FOR ALL"
        L'∀',
        L'\n'
        })
        if (std::putwchar(ch) == WEOF)
        {
            std::puts("I/O error in std::putwchar");
            return EXIT_FAILURE;
        }

    return EXIT_SUCCESS;
}
```

Possible output:

```text
∀∀
```
