{/* source:cpp-io-c-puts:0001 */}
Writes every character from the null-terminated string `str` and one additional newline character `'\n'` to the output stream [`stdout`](/docs/cpp/library/io/c/std_streams), as if by repeatedly executing [`std::fputc`](/docs/cpp/library/io/c/fputc).

{/* source:cpp-io-c-puts:0002 */}
The terminating null character from `str` is not written.

### Parameters

{/* source:cpp-io-c-puts:0003 */}
<ParameterList>
  <Parameter name="str">character string to be written</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-puts:0004 */}
On success, returns a non-negative value

{/* source:cpp-io-c-puts:0005 */}
On failure, returns [EOF](/docs/cpp/library/io/c) and sets the error indicator (see [`std::ferror`](/docs/cpp/library/io/c/ferror)) on [`stdout`](/docs/cpp/library/io/c/std_streams).

### Notes

{/* source:cpp-io-c-puts:0006 */}
The `std::puts` function appends the newline character to the output, while `std::fputs` function does not.

{/* source:cpp-io-c-puts:0007 */}
Different implementations return different non-negative numbers: some return the last character written, some return the number of characters written (or [`INT_MAX`](/docs/cpp/library/utility/types/climits) if the string was longer than that), some simply return a non-negative constant.

{/* source:cpp-io-c-puts:0008 */}
A typical cause of failure for `std::puts` is running out of space on the file system, when stdout is redirected to a file.

### Example

{/* source:cpp-io-c-puts:0009 */}
```cpp
#include <cstdio>

int main()
{
    int rc = std::puts("Hello World");

    if (rc == EOF)
        std::perror("puts()"); // POSIX requires that errno is set
}
```

Output:

```text
Hello World
```
