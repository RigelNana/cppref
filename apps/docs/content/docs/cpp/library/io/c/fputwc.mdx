  <DeclarationDescription>

    2. May be implemented as a macro and may evaluate `stream` more than once.
  </DeclarationDescription>

### Parameters

{/* source:cpp-io-c-fputwc:0003 */}
<ParameterList>
  <Parameter name="ch">wide character to be written</Parameter>
  <Parameter name="stream">the output stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-fputwc:0004 */}
`ch` on success, `WEOF` on failure. If an encoding error occurs, [`errno`](/docs/cpp/library/error/errno) is set to [`EILSEQ`](/docs/cpp/library/error/errno_macros).

### Example

{/* source:cpp-io-c-fputwc:0005 */}
```cpp
#include <cerrno>
#include <clocale>
#include <cstdio>
#include <cstdlib>
#include <cwchar>
#include <initializer_list>
 
int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
 
    for (const wchar_t ch :
    {
        L'\u2200', // Unicode name: "FOR ALL"
        L'\n',
        L'∀',
    })
    {
        if (errno = 0; std::fputwc(ch, stdout) == WEOF)
        {
            std::puts(errno == EILSEQ
                ? "Encoding error in fputwc"
                : "I/O error in fputwc"
            );
            return EXIT_FAILURE;
        }
    }
    return EXIT_SUCCESS;
}
```

Possible output:

```text
∀
∀
```
