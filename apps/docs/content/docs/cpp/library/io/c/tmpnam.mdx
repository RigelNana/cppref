{/* source:cpp-io-c-tmpnam:0001 */}
Creates a unique filename that does not name a currently existing file, and stores it in the character string pointed to by `filename`. The function is capable of generating up to [TMP_MAX](/docs/cpp/library/io/c) of unique filenames, but some or all of them may already be in use, and thus not suitable return values.

{/* source:cpp-io-c-tmpnam:0002 */}
`std::tmpnam` modifies static state and is not required to be thread-safe.

### Parameters

{/* source:cpp-io-c-tmpnam:0003 */}
<ParameterList>
  <Parameter name="filename">pointer to the character array capable of holding at least [L_tmpnam](/docs/cpp/library/io/c) bytes, to be used as a result buffer. If a null pointer is passed, a pointer to an internal static buffer is returned</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-tmpnam:0004 */}
`filename` if `filename` was not a null pointer. Otherwise a pointer to an internal static buffer is returned. If no suitable filename can be generated, a null pointer is returned.

### Notes

{/* source:cpp-io-c-tmpnam:0005 */}
Although the names generated by `std::tmpnam` are difficult to guess, it is possible that a file with that name is created by another process between the moment `std::tmpnam` returns and the moment this program attempts to use the returned name to create a file. The standard function [`std::tmpfile`](/docs/cpp/library/io/c/tmpfile) and the POSIX function [mkstemp](https://pubs.opengroup.org/onlinepubs/9699919799/functions/mkdtemp.html) do not have this problem (creating a unique directory using only the standard C library still requires the use of `tmpnam`).

{/* source:cpp-io-c-tmpnam:0006 */}
POSIX systems additionally define the similarly named function [tempnam](https://pubs.opengroup.org/onlinepubs/9699919799/functions/tempnam.html), which offers the choice of a directory (which defaults to the optionally defined macro [P_tmpdir](https://pubs.opengroup.org/onlinepubs/9699919799/basedefs/stdio.h.html)).

### Example

{/* source:cpp-io-c-tmpnam:0007 */}
```cpp
#include <cstdio>
#include <iostream>
#include <string>

int main()
{
    std::string name1 = std::tmpnam(nullptr);
    std::cout << "temporary file name: " << name1 << '\n';

    char name2[L_tmpnam];
    if (std::tmpnam(name2))
        std::cout << "temporary file name: " << name2 << '\n';
}
```

Possible output:

```text
temporary file name: /tmp/fileDjwifs
temporary file name: /tmp/fileEv2bfW
```
