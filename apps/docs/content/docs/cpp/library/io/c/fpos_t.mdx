{/* source:cpp-io-c-fpos-t:0001 */}
`std::fpos_t` is a non-array complete object type, can be used to store (by [`std::fgetpos`](/docs/cpp/library/io/c/fgetpos)) and restore (by [`std::fsetpos`](/docs/cpp/library/io/c/fsetpos)) the position and multibyte parser state (if any) for a C stream.

{/* source:cpp-io-c-fpos-t:0002 */}
The multibyte parser state of a wide-oriented C stream is represented by a [`std::mbstate_t`](/docs/cpp/library/text/multibyte/mbstate_t) object, whose value is stored as part of the value of a `std::fpos_t` object by [`std::fgetpos`](/docs/cpp/library/io/c/fgetpos).
