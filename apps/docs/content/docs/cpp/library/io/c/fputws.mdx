{/* source:cpp-io-c-fputws:0001 */}
Writes every wide character from the null-terminated wide string `str` to the output stream `stream`, as if by repeatedly executing [`std::fputwc`](/docs/cpp/library/io/c/fputwc).

{/* source:cpp-io-c-fputws:0002 */}
The terminating null wide character from `str` is not written.

### Parameters

{/* source:cpp-io-c-fputws:0003 */}
<ParameterList>
  <Parameter name="str">null-terminated wide string to be written</Parameter>
  <Parameter name="stream">output stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-fputws:0004 */}
On success, returns a non-negative value

{/* source:cpp-io-c-fputws:0005 */}
On failure, returns [EOF](/docs/cpp/library/io/c) and sets the error indicator (see [`std::ferror`](/docs/cpp/library/io/c/ferror)) on `stream`.

### Example

{/* source:cpp-io-c-fputws:0006 */}
```cpp
#include <clocale>
#include <cstdio>
#include <cwchar>
 
int main()
{
    std::setlocale(LC_ALL, "en_US.utf8");
    int rc = std::fputws(L"御休みなさい", stdout);
 
    if (rc == EOF)
        std::perror("fputws()"); // POSIX requires that errno is set
}
```

Possible output:

```text
御休みなさい
```
