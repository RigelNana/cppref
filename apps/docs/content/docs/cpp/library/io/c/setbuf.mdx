<DeclarationDoc>

  <Declaration language="cpp" code={`void setbuf( std::FILE* stream, char* buffer );`} />
</DeclarationDoc>

{/* source:cpp-io-c-setbuf:0001 */}
Sets the internal buffer to use for I/O operations performed on the C stream `stream`.

{/* source:cpp-io-c-setbuf:0002 */}
If `buffer` is not null, equivalent to `std::setvbuf(stream, buffer, _IOFBF, BUFSIZ)`.

{/* source:cpp-io-c-setbuf:0003 */}
If `buffer` is null, equivalent to `std::setvbuf(stream, nullptr, _IONBF, 0)`, which turns off buffering.

### Parameters

{/* source:cpp-io-c-setbuf:0004 */}
<ParameterList>
  <Parameter name="stream">the file stream to set the buffer to</Parameter>
  <Parameter name="buffer">pointer to a buffer for the stream to use. If a null pointer is supplied, the buffering is turned off. If not null, must be able to hold at least `BUFSIZ` characters</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-setbuf:0005 */}
(none)

### Notes

{/* source:cpp-io-c-setbuf:0006 */}
If [BUFSIZ](/docs/cpp/library/io/c) is not the appropriate buffer size, [`std::setvbuf`](/docs/cpp/library/io/c/setvbuf) can be used to change it.

{/* source:cpp-io-c-setbuf:0007 */}
[`std::setvbuf`](/docs/cpp/library/io/c/setvbuf) should also be used to detect errors, since `std::setbuf` does not indicate success or failure.

{/* source:cpp-io-c-setbuf:0008 */}
This function may only be used after `stream` has been associated with an open file, but before any other operation (other than a failed call to `std::setbuf`/`std::setvbuf`).

{/* source:cpp-io-c-setbuf:0009 */}
A common error is setting the buffer of [`stdin`](/docs/cpp/library/io/c/std_streams) or [`stdout`](/docs/cpp/library/io/c/std_streams) to an array whose lifetime ends before the program terminates:

{/* source:cpp-io-c-setbuf:0010 */}
```cpp
int main()
{
    char buf[BUFSIZ];
    std::setbuf(stdin, buf);
} // lifetime of buf ends, undefined behavior
```

### Example

{/* source:cpp-io-c-setbuf:0011 */}
`std::setbuf` may be used to disable buffering on streams that require immediate output.

```cpp
#include <chrono>
#include <cstdio>
#include <thread>

int main()
{
    using namespace std::chrono_literals;

    std::setbuf(stdout, nullptr); // unbuffered stdout
    std::putchar('a'); // appears immediately on unbuffered stream
    std::this_thread::sleep_for(1s);
    std::putchar('b');
}
```

Output:

```text
ab
```
