<DeclarationDoc>

  <Declaration language="cpp" code={`int fputs( const char* str, std::FILE* stream );`} />
</DeclarationDoc>

{/* source:cpp-io-c-fputs:0001 */}
Writes every character from the null-terminated string `str` to the output stream `stream`, as if by repeatedly executing [`std::fputc`](/docs/cpp/library/io/c/fputc).

{/* source:cpp-io-c-fputs:0002 */}
The terminating null character from `str` is not written.

### Parameters

{/* source:cpp-io-c-fputs:0003 */}
<ParameterList>
  <Parameter name="str">null-terminated character string to be written</Parameter>
  <Parameter name="stream">output stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-fputs:0004 */}
On success, returns a non-negative value

{/* source:cpp-io-c-fputs:0005 */}
On failure, returns [EOF](/docs/cpp/library/io/c) and sets the error indicator (see [`std::ferror`](/docs/cpp/library/io/c/ferror)) on `stream`.

### Notes

{/* source:cpp-io-c-fputs:0006 */}
The related function [`std::puts`](/docs/cpp/library/io/c/puts) appends a newline character to the output, while `std::fputs` writes the string unmodified.

{/* source:cpp-io-c-fputs:0007 */}
Different implementations return different non-negative numbers: some return the last character written, some return the number of characters written (or [`INT_MAX`](/docs/cpp/library/utility/types/climits) if the string was longer than that), some simply return a non-negative constant such as zero.

### Example

{/* source:cpp-io-c-fputs:0008 */}
```cpp
#include <cstdio>
 
int main(void)
{
    int rc = std::fputs("Hello World", stdout);
 
    if (rc == EOF)
        std::perror("fputs()"); // POSIX requires that errno is set
}
```

Output:

```text
Hello World
```
