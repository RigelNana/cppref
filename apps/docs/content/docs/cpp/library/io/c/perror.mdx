{/* source:cpp-io-c-perror:0001 */}
Prints a textual description of the error code currently stored in the system variable [`errno`](/docs/cpp/library/error/errno) to [`stderr`](/docs/cpp/library/io/c/std_streams).

{/* source:cpp-io-c-perror:0002 */}
The description is formed by concatenating the following components:

{/* source:cpp-io-c-perror:0003 */}
- the contents of the null-terminated byte string pointed to by `s`, followed by `": "` (unless `s` is a null pointer or the character pointed to by `s` is the null character).
- implementation-defined error message string describing the error code stored in `errno`, followed by `'\n'`. The error message string is identical to the result of `std::strerror(errno)`.

### Parameters

{/* source:cpp-io-c-perror:0004 */}
<ParameterList>
  <Parameter name="s">pointer to a null-terminated string with explanatory message</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-perror:0005 */}
(none)

### Example

{/* source:cpp-io-c-perror:0006 */}
```cpp
#include <cerrno>
#include <cmath>
#include <cstdio>

int main()
{
    double not_a_number = std::log(-1.0);
    if (errno == EDOM)
        std::perror("log(-1) failed");
    std::printf("%f\n", not_a_number);
}
```

Possible output:

```text
log(-1) failed: Numerical argument out of domain
nan
```
