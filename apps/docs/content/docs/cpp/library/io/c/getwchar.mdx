Reads the next wide character from [`stdin`](/docs/cpp/library/io/c/std_streams).

### Parameters

{/* source:cpp-io-c-getwchar:0002 */}
(none)

### Return value

{/* source:cpp-io-c-getwchar:0003 */}
The obtained wide character, or `WEOF` if an error has occurred or the end of file reached
