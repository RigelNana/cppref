{/* source:cpp-io-c-fgetwc:0001 */}
Reads the next wide character from the given input stream. `getwc()` may be implemented as a macro and may evaluate `stream` more than once.

### Parameters

{/* source:cpp-io-c-fgetwc:0002 */}
<ParameterList>
  <Parameter name="stream">to read the wide character from</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-fgetwc:0003 */}
The next wide character from the stream or `WEOF` if an error has occurred or the end of file has been reached. If an encoding error occurred, [`errno`](/docs/cpp/library/error/errno) is set to [`EILSEQ`](/docs/cpp/library/error/errno_macros).
