{/* source:cpp-io-c-fgetpos:0001 */}
Obtains the file position indicator and the current parse state (if any) for the file stream `stream` and stores them in the object pointed to by `pos`. The value stored is only meaningful as the input to [`std::fsetpos`](/docs/cpp/library/io/c/fsetpos).

### Parameters

{/* source:cpp-io-c-fgetpos:0002 */}
<ParameterList>
  <Parameter name="stream">file stream to examine</Parameter>
  <Parameter name="pos">pointer to a `fpos_t` object to store the file position indicator to</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-c-fgetpos:0003 */}
0 upon success, nonzero value otherwise. Also sets [`errno`](/docs/cpp/library/error/errno) on failure.
