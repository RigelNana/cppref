Closes the associated file.

{/* source:cpp-io-basic-ofstream-close:0002 */}
Effectively calls [`rdbuf()->close()`](/docs/cpp/library/io/basic_filebuf/close). If an error occurs during operation, `setstate(failbit)` is called.

### Parameters

{/* source:cpp-io-basic-ofstream-close:0003 */}
(none)

### Return value

{/* source:cpp-io-basic-ofstream-close:0004 */}
(none)

### Notes

{/* source:cpp-io-basic-ofstream-close:0005 */}
This function is called by the destructor of `basic_ofstream` when the stream object goes out of scope and is not usually invoked directly.
