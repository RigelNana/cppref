  </DeclarationDescription>

{/* source:cpp-io-basic-ofstream-open:0002 */}
Calls `clear()` on success. Calls `setstate(failbit)` on failure.

{/* source:cpp-io-basic-ofstream-open:0003 */}
1,2. Effectively calls `rdbuf()->open(filename, mode | ios_base::out)` (see [`std::basic_filebuf::open`](/docs/cpp/library/io/basic_filebuf/open) for the details on the effects of that call). <InlineRevision since="C++17">Overload (2) is only provided if `std::filesystem::path::value_type` is not `char`.</InlineRevision>

{/* source:cpp-io-basic-ofstream-open:0004 */}
3,4. Effectively calls (1,2) as if by `open(filename.c_str(), mode)`.

### Parameters

{/* source:cpp-io-basic-ofstream-open:0005 */}
<ParameterList>
  <Parameter name="filename">the name of the file to be opened</Parameter>
</ParameterList>
<ParameterList>
  <Parameter name="mode">specifies stream open mode. It is a [*BitmaskType*](/docs/cpp/library/named_req/BitmaskType), the following constants are defined:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`app`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream before each write |
| [`binary`](/docs/cpp/library/io/ios_base/openmode) | open in [binary mode](/docs/cpp/library/io/c/FILE#Binary_and_text_modes) |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | open for reading |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | open for writing |
| [`trunc`](/docs/cpp/library/io/ios_base/openmode) | discard the contents of the stream when opening |
| [`ate`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream immediately after open |
| [`noreplace`](/docs/cpp/library/io/ios_base/openmode) <InlineRevision since="C++23" /> | open in exclusive mode |
