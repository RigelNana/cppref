(exposition only*)

{/* source:cpp-io-basic-stringbuf-init-buf-ptrs:0001 */}
Initializes the input and output sequences from `buf` according to `mode`. `buf` and `mode` are [exposition-only data members](/docs/cpp/library/io/basic_stringbuf#Exposition-only_members) of `*this`.

{/* source:cpp-io-basic-stringbuf-init-buf-ptrs:0002 */}
Immediately after this function returns:

{/* source:cpp-io-basic-stringbuf-init-buf-ptrs:0003 */}
- If [`std::ios_base::out`](/docs/cpp/library/io/ios_base/openmode) is set in `mode`, [`pbase()`](/docs/cpp/library/io/basic_streambuf/pptr) points to `buf.front()` and `epptr() >= pbase() + buf.size()` is `true`; in addition, if [`std::ios_base::ate`](/docs/cpp/library/io/ios_base/openmode) is set in `mode`, `pptr() == pbase() + buf.size()` is `true`, otherwise `pptr() == pbase()` is `true`. If [`std::ios_base::in`](/docs/cpp/library/io/ios_base/openmode) is set in `mode`, [`eback()`](/docs/cpp/library/io/basic_streambuf/gptr) points to `buf.front()`, and `gptr() == eback() && egptr() == eback() + buf.size()` is `true`.

### Notes

{/* source:cpp-io-basic-stringbuf-init-buf-ptrs:0004 */}
For efficiency reasons, stream buffer operations can violate invariants of `buf` while it is held encapsulated in the `std::basic_stringbuf`, e.g., by writing to characters in the range [`buf.data() + buf.size()`, `buf.data() + buf.capacity()`).

{/* source:cpp-io-basic-stringbuf-init-buf-ptrs:0005 */}
All operations retrieving a [`std::basic_string`](/docs/cpp/library/string/basic_string) from `buf` ensure that the `std::basic_string` invariants hold on the returned value.

### Defect reports

{/* source:cpp-io-basic-stringbuf-init-buf-ptrs:0006 */}
The following behavior-changing defect reports were applied retroactively to previously published C++ standards.
