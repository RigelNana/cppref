    {/* source:cpp-io-basic-stringbuf-basic-stringbuf:0001 */}
    The [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf) base and the [exposition-only data members](/docs/cpp/library/io/basic_stringbuf#Exposition-only_members) `buf` and `mode` are initialized as follows.

    {/* source:cpp-io-basic-stringbuf-basic-stringbuf:0002 */}
    After initializing these subobjects, overloads (3-12) initialize the input and output sequences as if by calling [`init_buf_ptrs()`](/docs/cpp/library/io/basic_stringbuf/init_buf_ptrs).

    {/* source:cpp-io-basic-stringbuf-basic-stringbuf:0003 */}

    | --- | --- | --- | --- |
    | (1) | default-initialized | implementation-defined (see below) | `which` |
    | (2) | default-initialized | implementation-defined (see below) | `std::ios_base::in \| std::ios_base::out` |
    | (3) | default-initialized | `s` | `which` |
    | (4) | default-initialized | `std::move(s)` | `which` |
    | (5) | default-initialized | `a` | `which` |

### Notes

{/* source:cpp-io-basic-stringbuf-basic-stringbuf:0013 */}
Typically called by the constructor of [`std::basic_stringstream`](/docs/cpp/library/io/basic_stringstream).

{/* source:cpp-io-basic-stringbuf-basic-stringbuf:0014 */}
The level of support for the open modes other than [`std::ios_base::in`](/docs/cpp/library/io/ios_base/openmode) and [`std::ios_base::out`](/docs/cpp/library/io/ios_base/openmode) varies among implementations. C++11 explicitly specifies the support for [`std::ios_base::ate`](/docs/cpp/library/io/ios_base/openmode) in [`str()`](/docs/cpp/library/io/basic_stringbuf/str) and in this constructor, but [`std::ios_base::app`](/docs/cpp/library/io/ios_base/openmode), [`std::ios_base::trunc`](/docs/cpp/library/io/ios_base/openmode), and [`std::ios_base::binary`](/docs/cpp/library/io/ios_base/openmode) have different effects on different implementations.

### Example

{/* source:cpp-io-basic-stringbuf-basic-stringbuf:0016 */}
Demonstrates calling the constructor of `std::basic_stringbuf` directly:

```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    // default constructor (mode = in | out)
    std::stringbuf buf1;
    buf1.sputc('1');
    std::cout << &buf1 << '\n';
 
    // string constructor in at-end mode (C++11)
    std::stringbuf buf2("test", std::ios_base::in
                              | std::ios_base::out
                              | std::ios_base::ate);
    buf2.sputc('1');
    std::cout << &buf2 << '\n';
 
    // append mode test (results differ among compilers)
    std::stringbuf buf3("test", std::ios_base::in
                              | std::ios_base::out
                              | std::ios_base::app);
    buf3.sputc('1');
    buf3.pubseekpos(1);
    buf3.sputc('2');
    std::cout << &buf3 << '\n';
}
```

Output:

```text
1
test1
est12 (Sun Studio) 2st1 (GCC)
```
