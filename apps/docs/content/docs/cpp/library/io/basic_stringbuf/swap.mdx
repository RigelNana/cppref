{/* source:cpp-io-basic-stringbuf-swap:0001 */}
Swaps the state and the contents of `*this` and `rhs`.

{/* source:cpp-io-basic-stringbuf-swap:0002 */}
<Revision since="C++11">
The behavior is undefined if `Allocator` does not propagate on swap and the allocators of `*this` and `other` are unequal.
</Revision>

### Parameters

{/* source:cpp-io-basic-stringbuf-swap:0003 */}
<ParameterList>
  <Parameter name="rhs">another `basic_stringbuf`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-stringbuf-swap:0004 */}
(none)

### Exceptions

{/* source:cpp-io-basic-stringbuf-swap:0005 */}
<Revision since="C++11" until="C++20">May throw implementation-defined exceptions.</Revision>
<Revision since="C++20">[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::allocator_traits<Allocator>::propagate_on_container_swap::value || std::allocator_traits<Allocator>::is_always_equal::value)`</Revision>

### Notes

{/* source:cpp-io-basic-stringbuf-swap:0006 */}
This function is called automatically when swapping [`std::stringstream`](/docs/cpp/library/io/basic_stringstream) objects. It is rarely necessary to call it directly.

### Example

{/* source:cpp-io-basic-stringbuf-swap:0007 */}
```cpp
#include <iomanip>
#include <iostream>
#include <sstream>
#include <string>
 
int main()
{
    std::istringstream one("one");
    std::ostringstream two("two");
 
    std::cout << "Before swap: one = " << std::quoted(one.str())
              << ", two = " << std::quoted(two.str()) << ".\n";
 
    one.rdbuf()->swap(*two.rdbuf());
 
    std::cout << "After  swap: one = " << std::quoted(one.str())
              << ", two = " << std::quoted(two.str()) << ".\n";
}
```

Output:

```text
Before swap: one = "one", two = "two".
After  swap: one = "two", two = "one".
```
