{/* source:cpp-io-basic-stringbuf-pbackfail:0001 */}
This protected virtual function is called by the public functions [`basic_streambuf::sungetc`](/docs/cpp/library/io/basic_streambuf/sungetc) and [`basic_streambuf::sputbackc`](/docs/cpp/library/io/basic_streambuf/sputbackc) (which, in turn, are called by [`basic_istream::unget`](/docs/cpp/library/io/basic_istream/unget) and [`basic_istream::putback`](/docs/cpp/library/io/basic_istream/putback)).

{/* source:cpp-io-basic-stringbuf-pbackfail:0002 */}
1. The caller is requesting that the get area is backed up by one character (`pbackfail()` is called with no arguments or with `Traits::eof()` as the argument)

{/* source:cpp-io-basic-stringbuf-pbackfail:0003 */}
   a. First, checks if there is a putback position, and if there really isn't, fails. (stringbuf has no external character source to re-read)

{/* source:cpp-io-basic-stringbuf-pbackfail:0004 */}
   b. If the caller was wrong and the putback position is in fact available, simply decrements [`basic_streambuf::gptr()`](/docs/cpp/library/io/basic_streambuf/gptr), e.g. by calling `gbump(-1)`.

{/* source:cpp-io-basic-stringbuf-pbackfail:0005 */}
2. The caller attempts to putback a different character from the one retrieved earlier (`pbackfail()` is called with the character that needs to be put back), in which case

{/* source:cpp-io-basic-stringbuf-pbackfail:0006 */}
   a. First, checks if there is a putback position, and if there isn't, fails.

{/* source:cpp-io-basic-stringbuf-pbackfail:0007 */}
   b. Then checks what character is in the putback position. If the character held there is already equal to `c`, as determined by `Traits::eq(to_char_type(c), gptr()[-1])`, then simply decrements [`basic_streambuf::gptr()`](/docs/cpp/library/io/basic_streambuf/gptr).

{/* source:cpp-io-basic-stringbuf-pbackfail:0008 */}
   c. Otherwise, if the buffer is open for reading only, fails.

{/* source:cpp-io-basic-stringbuf-pbackfail:0009 */}
   d. Otherwise, if the buffer is open for writing (`mode && std::ios_base::out` is nonzero), then decrements [`basic_streambuf::gptr()`](/docs/cpp/library/io/basic_streambuf/gptr) and writes `c` to the location pointed to `gptr()` after adjustment.

### Parameters

{/* source:cpp-io-basic-stringbuf-pbackfail:0010 */}
<ParameterList>
  <Parameter name="c">the character to put back, or `Traits::eof()` to indicate that backing up of the get area is requested</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-stringbuf-pbackfail:0011 */}
`c` on success except if `c` was `Traits::eof()`, in which case `Traits::not_eof(c)` is returned.

{/* source:cpp-io-basic-stringbuf-pbackfail:0012 */}
`Traits::eof()` on failure.
