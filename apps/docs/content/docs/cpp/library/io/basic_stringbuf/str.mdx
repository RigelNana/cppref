  <DeclarationDescription>
    {/* source:cpp-io-basic-stringbuf-str:0001 */}
    Gets and sets the underlying string.

    {/* source:cpp-io-basic-stringbuf-str:0002 */}
    In the descriptions below, `buf` and `mode` are [exposition-only data members](/docs/cpp/library/io/basic_stringbuf#Exposition-only_members) of `*this`.

    {/* source:cpp-io-basic-stringbuf-str:0003 */}
    1. Creates and returns a [`std::basic_string`](/docs/cpp/library/string/basic_string) object containing a copy of this `std::basic_stringbuf`'s underlying character sequence. For input-only streams, the returned string contains the characters from the range `[`[`eback()`](/docs/cpp/library/io/basic_streambuf/gptr)`, `[`egptr()`](/docs/cpp/library/io/basic_streambuf/gptr)`)`. For input/output or output-only streams, contains the characters from `pbase()` to the last character in the sequence regardless of [`egptr()`](/docs/cpp/library/io/basic_streambuf/gptr) and [`epptr()`](/docs/cpp/library/io/basic_streambuf/pptr).

    {/* source:cpp-io-basic-stringbuf-str:0004 */}
    The member character sequence in a buffer open for writing can be over-allocated for efficiency purposes. In that case, only the initialized characters are returned: these characters are the ones that were obtained from the string argument of the constructor, the string argument of the most recent call to a setter overload of `str()`, or from a write operation. A typical implementation that uses over-allocation maintains a high-watermark pointer to track the end of the initialized part of the buffer and this overload returns the characters from [`pbase()`](/docs/cpp/library/io/basic_streambuf/pptr) to the high-watermark pointer.

    {/* source:cpp-io-basic-stringbuf-str:0005 */}
    <Revision since="C++20">
    Equivalent to `return std::basic_string<CharT, Traits, Allocator>(view(), get_allocator());`.
    </Revision>

    {/* source:cpp-io-basic-stringbuf-str:0006 */}
    2. Same as (1), except that `a` is used to construct the returned [`std::basic_string`](/docs/cpp/library/string/basic_string). Equivalent to `return std::basic_string<CharT, Traits, SAlloc>(view(), a);`.

    {/* source:cpp-io-basic-stringbuf-str:0007 */}
    This overload participates in overload resolution only if `SAlloc` meets the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator).

    {/* source:cpp-io-basic-stringbuf-str:0008 */}
    3. Creates a [`std::basic_string`](/docs/cpp/library/string/basic_string) object as if by move constructing it from `*this`'s underlying character sequence in `buf`. `buf` may need to be adjusted to contain the same content as in (1) at first. After that, sets `buf` to empty and calls [`init_buf_ptrs()`](/docs/cpp/library/io/basic_stringbuf/init_buf_ptrs), then returns the `std::basic_string` object.

    {/* source:cpp-io-basic-stringbuf-str:0009 */}
    4. Replaces the underlying character sequence as if by `buf = s`, then calls [`init_buf_ptrs()`](/docs/cpp/library/io/basic_stringbuf/init_buf_ptrs).

    {/* source:cpp-io-basic-stringbuf-str:0010 */}
    5. Same as (4), except the type of `s`'s allocator is not `Allocator`.

    {/* source:cpp-io-basic-stringbuf-str:0011 */}
    This overload participates in overload resolution only if `std::is_same_v<SAlloc, Allocator>` is `false`.

    {/* source:cpp-io-basic-stringbuf-str:0012 */}
    6. Replaces the underlying character sequence as if by `buf = std::move(s)`, then calls [`init_buf_ptrs()`](/docs/cpp/library/io/basic_stringbuf/init_buf_ptrs).

    {/* source:cpp-io-basic-stringbuf-str:0013 */}
    7. Implicitly converts `t` to a string view `sv` as if by `std::basic_string_view<CharT, Traits> sv = t;`, then replaces the underlying character sequence as if by `buf = sv`, then calls [`init_buf_ptrs()`](/docs/cpp/library/io/basic_stringbuf/init_buf_ptrs).

    {/* source:cpp-io-basic-stringbuf-str:0014 */}
    This overload participates in overload resolution only if `std::is_convertible_v<const StringViewLike&, std::basic_string_view<CharT, Traits>>` is `true`.
  </DeclarationDescription>

### Example

{/* source:cpp-io-basic-stringbuf-str:0020 */}
```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    int n;
 
    std::istringstream in;  // could also use in("1 2")
    in.rdbuf()->str("1 2"); // set the get area
    in >> n;
    std::cout << "after reading the first int from \"1 2\", the int is " 
              << n << ", str() = \"" << in.rdbuf()->str() << "\"\n"; // or in.str()
 
    std::ostringstream out("1 2");
    out << 3;
    std::cout << "after writing the int '3' to output stream \"1 2\""
              << ", str() = \"" << out.str() << "\"\n";
 
    std::ostringstream ate("1 2", std::ios_base::ate); // C++11
    ate << 3;
    std::cout << "after writing the int '3' to append stream \"1 2\""
              << ", str() = \"" << ate.str() << "\"\n";
}
```

Output:

```text
after reading the first int from "1 2", the int is 1, str() = "1 2"
after writing the int '3' to output stream "1 2", str() = "3 2"
after writing the int '3' to append stream "1 2", str() = "1 23"
```
