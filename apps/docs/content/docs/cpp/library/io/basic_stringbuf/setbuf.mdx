virtual std::basic_streambuf<CharT, Traits>* setbuf( char_type* s, std::streamsize n )`} />
</DeclarationDoc>

{/* source:cpp-io-basic-stringbuf-setbuf:0001 */}
If `s` is a null pointer and `n` is zero, this function has no effect.

{/* source:cpp-io-basic-stringbuf-setbuf:0002 */}
Otherwise, the effect is implementation-defined: some implementations do nothing, while some implementations clear the [`std::string`](/docs/cpp/library/string/basic_string) member currently used as the buffer and begin using the user-supplied character array of size `n`, whose first element is pointed to by `s`, as the buffer and the input/output character sequence.

{/* source:cpp-io-basic-stringbuf-setbuf:0003 */}
This function is protected virtual, it may only be called through `pubsetbuf()` or from member functions of a user-defined class derived from `std::basic_stringbuf`.

### Parameters

{/* source:cpp-io-basic-stringbuf-setbuf:0004 */}
<ParameterList>
  <Parameter name="s">pointer to the first `CharT` in the user-provided buffer or null</Parameter>
  <Parameter name="n">the number of `CharT` elements in the user-provided buffer or zero</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-stringbuf-setbuf:0005 */}
`this`

### Notes

{/* source:cpp-io-basic-stringbuf-setbuf:0006 */}
The deprecated stream buffer `std::strstreambuf` or the boost.IOStreams device [`boost::basic_array`](https://www.boost.org/doc/libs/release/libs/iostreams/doc/classes/array.html#array) may be used to implement I/O buffering over a user-provided char array in portable manner.

### Example

{/* source:cpp-io-basic-stringbuf-setbuf:0007 */}
Test for the stringstream's setbuf functionality.

```cpp
#include <iostream>
#include <sstream>
 
int main()
{
    std::ostringstream ss;
    char c[1024] = {};
    ss.rdbuf()->pubsetbuf(c, 1024);
    ss << 3.14 << '\n';
    std::cout << c << '\n';
}
```

Output:

```text
3.14 (on GNU g++/libstdc++ and SunPro C++/roguewave)
<nothing> (on MS Visual Studio 2010, SunPro C++/stlport4, CLang++/libc++)
```
