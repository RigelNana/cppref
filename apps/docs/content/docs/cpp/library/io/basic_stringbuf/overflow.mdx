{/* source:cpp-io-basic-stringbuf-overflow:0001 */}
Appends the character `c` to the output character sequence.

{/* source:cpp-io-basic-stringbuf-overflow:0002 */}
If `c` is the end-of-file indicator (`traits::eq_int_type(c, traits::eof()) == true`), then there is no character to append. The function does nothing and returns an unspecified value other than `traits::eof()`.

{/* source:cpp-io-basic-stringbuf-overflow:0003 */}
Otherwise, if the output sequence has a write position available or this function can successfully make a write position available, then calls `sputc(c)` and returns `c`.

{/* source:cpp-io-basic-stringbuf-overflow:0004 */}
This function can make a write position available if the [`std::stringbuf`](/docs/cpp/library/io/basic_stringbuf) is open for output (`(mode & ios_base::out) != 0`): in this case, it reallocates (or initially allocates) the buffer big enough to hold the entire current buffer plus at least one more character. If the [`std::stringbuf`](/docs/cpp/library/io/basic_stringbuf) is also open for input (`(mode & ios_base::in) != 0`), then `overflow` also increases the size of the get area by moving [`egptr()`](/docs/cpp/library/io/basic_streambuf/gptr) to point just past the new write position.

### Parameters

{/* source:cpp-io-basic-stringbuf-overflow:0005 */}
<ParameterList>
  <Parameter name="c">the character to store in the put area</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-stringbuf-overflow:0006 */}
`Traits::eof()` to indicate failure, `c` if the character `c` was successfully appended, or some value other than `Traits::eof()` if called with `Traits::eof()` as the argument.

### Notes

{/* source:cpp-io-basic-stringbuf-overflow:0007 */}
This function is different from a typical `overflow()` which moves the contents of the buffer to the associated character sequence because for a [`std::basic_stringbuf`](/docs/cpp/library/io/basic_stringbuf), the buffer and the associated sequence are one and the same.

### Example

{/* source:cpp-io-basic-stringbuf-overflow:0008 */}
In the implementation used to execute this example (e.g. GCC-4.9), `overflow()` over-allocates the put area to 512 bytes: a call to [`str()`](/docs/cpp/library/io/basic_stringbuf/str) would only return the four initialized bytes, but the next 508 calls to [`sputc()`](/docs/cpp/library/io/basic_streambuf/sputc) would not require new calls to `overflow()`.

```cpp
#include <sstream>
#include <iostream>
 
struct mybuf : std::stringbuf
{
    mybuf(const std::string& new_str,
          std::ios_base::openmode which = std::ios_base::in | std::ios_base::out)
        : std::stringbuf(new_str, which) {}
 
    int_type overflow(int_type c = EOF) override
    {
        std::cout << "stringbuf::overflow('" << char(c) << "') called\n"
                  << "Before: size of get area: " << egptr() - eback() << '\n'
                  << "        size of put area: " << epptr() - pbase() << '\n';
 
        int_type ret = std::stringbuf::overflow(c);
 
        std::cout << "After : size of get area: " << egptr() - eback() << '\n'
                  << "        size of put area: " << epptr() - pbase() << '\n';
 
        return ret;
    }
};
 
int main()
{
    std::cout << "read-write stream:\n";
    mybuf sbuf("   "); // read-write stream
    std::iostream stream(&sbuf);
    stream << 1234;
    std::cout << sbuf.str() << '\n';
 
    std::cout << "\nread-only stream:\n";
    mybuf ro_buf("   ", std::ios_base::in); // read-only stream
    std::iostream ro_stream(&ro_buf);
    ro_stream << 1234;
 
    std::cout << "\nwrite-only stream:\n";
    mybuf wr_buf("   ", std::ios_base::out); // write-only stream
    std::iostream wr_stream(&wr_buf);
    wr_stream << 1234;
}
```

Possible output:

```text
read-write stream:
stringbuf::overflow('4') called
Before: size of get area: 3
        size of put area: 3
After : size of get area: 4
        size of put area: 512
1234
 
read-only stream:
stringbuf::overflow('1') called
Before: size of get area: 3
        size of put area: 0
After : size of get area: 3
        size of put area: 0
 
write-only stream:
stringbuf::overflow('4') called
Before: size of get area: 0
        size of put area: 3
After : size of get area: 0
        size of put area: 512
```

### Defect reports

{/* source:cpp-io-basic-stringbuf-overflow:0009 */}
The following behavior-changing defect reports were applied retroactively to previously published C++ standards.

<DefectReportList>
  <DefectReport kind="lwg" id={169} standard="C++98">
    <PublishedBehavior>the buffer (re)allocated could only hold one extra character</PublishedBehavior>
    <CorrectedBehavior>allows more extra characters</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={432} standard="C++98">
    <PublishedBehavior>`overflow` moved [`epptr()`](/docs/cpp/library/io/basic_streambuf/pptr) to point just past the new write position if the `std::stringbuf` is open for input</PublishedBehavior>
    <CorrectedBehavior>it is not moved</CorrectedBehavior>
  </DefectReport>
</DefectReportList>
