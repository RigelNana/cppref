  <DeclarationDescription>
    {/* source:cpp-io-basic-ispanstream-span:0001 */}
    1. Gets a `span` referencing the written area if [`std::ios_base::out`](/docs/cpp/library/io/ios_base/openmode) is set in the open mode of the wrapped `std::basic_spanbuf`, or a `span` referencing the underlying buffer otherwise.

    {/* source:cpp-io-basic-ispanstream-span:0002 */}
    2. Makes the wrapped `std::basic_spanbuf` perform I/O on the buffer referenced by `s`.

    {/* source:cpp-io-basic-ispanstream-span:0003 */}
    3. Same as (2), except that `s` is obtained as if by

```cpp
std::span<const CharT> cs{std::forward<SpanLike>(r)};
std::span<CharT> s{const_cast<CharT*>(cs.data()), cs.size()};
```

. This overload participates in overload resolution only if `SpanLike` models [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range), `std::convertible_to<SpanLike, std::span<CharT>>` is `false`, and `std::convertible_to<SpanLike, std::span<const CharT>>` is `true`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-basic-ispanstream-span:0004 */}
<ParameterList>
  <Parameter name="s">`std::span` referencing the storage to be use as the new underlying buffer of stream</Parameter>
  <Parameter name="r">[`borrowed_range`](/docs/cpp/library/ranges/borrowed_range) to be use as the new underlying buffer of stream</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-ispanstream-span:0005 */}
1. A `std::span` referencing the underlying buffer or written area, depending on the open mode of the wrapped `std::basic_spanbuf`.

{/* source:cpp-io-basic-ispanstream-span:0006 */}
2,3. (none)

### Example

{/* source:cpp-io-basic-ispanstream-span:0007 */}
```cpp
#include <cassert>
#include <iostream>
#include <span>
#include <spanstream>

int main()
{
    char out_buf[16];
    std::ospanstream ost{std::span<char>{out_buf}};
    ost << "C++" << ' ' << 23 << '\0'; // note explicit null-termination
    auto sp = ost.span();
    assert(
        sp[0] == 'C' && sp[1] == '+' && sp[2] == '+' &&
        sp[3] == ' ' && sp[4] == '2' && sp[5] == '3' &&
        sp[6] == '\0'
    );
    std::cout << "sp.data(): [" << sp.data() << "]\n";
    std::cout << "out_buf: [" << out_buf << "]\n";
    // spanstream uses out_buf as internal storage, no allocations
    assert(static_cast<char*>(out_buf) == sp.data());

    const char in_buf[] = "X Y 42";
    std::ispanstream ist{std::span<const char>{in_buf}};
    assert(static_cast<const char*>(in_buf) == ist.span().data());
    char c;
    ist >> c;
    assert(c == 'X');
    ist >> c;
    assert(c == 'Y');
    int i;
    ist >> i;
    assert(i == 42);
    ist >> i; // buffer is exhausted
    assert(!ist);
}
```

Output:

```text
sp.data(): [C++ 23]
out_buf: [C++ 23]
```
