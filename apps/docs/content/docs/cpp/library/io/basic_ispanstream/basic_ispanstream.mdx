    {/* source:cpp-io-basic-ispanstream-basic-ispanstream:0001 */}
    Constructs a new `basic_ispanstream`.

    {/* source:cpp-io-basic-ispanstream-basic-ispanstream:0002 */}
    1. Uses the storage referenced by `s` as initial underlying buffer of the wrapped `std::basic_spanbuf` device. The wrapped `std::basic_spanbuf` object is constructed as `basic_spanbuf<Char, Traits>(s, mode | std::ios_base::in)`.

    {/* source:cpp-io-basic-ispanstream-basic-ispanstream:0003 */}
    2. Uses the storage referenced by `r` after converted to `std::span<const CharT>` as initial underlying buffer of the wrapped `std::basic_spanbuf` device. The wrapped `std::basic_spanbuf` object is opened in mode [`std::ios_base::in`](/docs/cpp/library/io/ios_base/openmode). This overload participates in overload resolution only if `ROS` models [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range), `std::convertible_to<ROS, std::span<CharT>>` is `false`, and `std::convertible_to<ROS, std::span<const CharT>>` is `true`.

    {/* source:cpp-io-basic-ispanstream-basic-ispanstream:0004 */}
    3. Move constructor. Move constructs the [`std::basic_istream`](/docs/cpp/library/io/basic_istream) base subobject and the wrapped `std::basic_spanbuf` from those of `rhs`, and then calls [`set_rdbuf`](/docs/cpp/library/io/basic_ios/set_rdbuf) with the address of the wrapped `std::basic_spanbuf` in `*this` to install it.

    {/* source:cpp-io-basic-ispanstream-basic-ispanstream:0005 */}
    4. Copy constructor is deleted. `basic_ispanstream` is not copyable.
  </DeclarationDescription>
