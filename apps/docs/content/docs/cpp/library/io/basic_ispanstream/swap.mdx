{/* source:cpp-io-basic-ispanstream-swap:0001 */}
Exchanges the state of the stream with those of `other`.

{/* source:cpp-io-basic-ispanstream-swap:0002 */}
This is done by calling `std::basic_istream<CharT, Traits>::swap(other)` and swapping the wrapped `std::basic_spanbuf` objects (accessible through `*rdbuf()`).
