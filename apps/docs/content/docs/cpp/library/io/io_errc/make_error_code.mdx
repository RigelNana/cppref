{/* source:cpp-io-io-errc-make-error-code:0001 */}
Constructs an [`std::error_code`](/docs/cpp/library/error/error_code) object from a value of type [`std::io_errc`](/docs/cpp/library/io/io_errc) as if by `return std::error_code(static_cast<int>(e), std::iostream_category())`.

{/* source:cpp-io-io-errc-make-error-code:0002 */}
This function is called by the constructor of [`std::error_code`](/docs/cpp/library/error/error_code) with an [`std::io_errc`](/docs/cpp/library/io/io_errc) argument.

### Parameters

{/* source:cpp-io-io-errc-make-error-code:0003 */}
<ParameterList>
  <Parameter name="e">error code number</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-io-errc-make-error-code:0004 */}
A value of type [`std::error_code`](/docs/cpp/library/error/error_code) that holds the error code number from `e` associated with the error category `"iostream"`.

### Example

{/* source:cpp-io-io-errc-make-error-code:0005 */}
```cpp
#include <iostream>
#include <system_error>
 
int main()
{
    std::error_code ec = std::make_error_code(std::io_errc::stream);
 
    // This works because of the overloaded method
    //    and the is_error_code_enum specialization.
    ec = std::io_errc::stream;
 
    std::cout << "Error code from io_errc::stream has category "
              << ec.category().name() << '\n';
}
```

Output:

```text
Error code from io_errc::stream has category iostream
```
