{/* source:cpp-io-io-errc-is-error-code-enum:0001 */}
This specialization of [`std::is_error_code_enum`](/docs/cpp/library/error/error_code/is_error_code_enum) informs other library components that values of type [`std::io_errc`](/docs/cpp/library/io/io_errc) are enumerations that hold error codes, which makes them implicitly convertible and assignable to objects of type [`std::error_code`](/docs/cpp/library/error/error_code).

### Example

{/* source:cpp-io-io-errc-is-error-code-enum:0003 */}
The comparison between `e.code()` and [`std::io_errc::stream`](/docs/cpp/library/io/io_errc) compiles because `std::is_error_code_enum<std::io_errc>::value == true`.

```cpp
#include <fstream>
#include <iostream>
 
int main()
{
    std::ifstream f("doesn't exist");
    try
    {
        f.exceptions(f.failbit);
    }
    catch (const std::ios_base::failure& e)
    {
        std::cout << "Caught an ios_base::failure.\n";
        if (e.code() == std::io_errc::stream)
            std::cout << "The error code is std::io_errc::stream\n";
    }
}
```

Output:

```text
Caught an ios_base::failure.
The error code is std::io_errc::stream
```
