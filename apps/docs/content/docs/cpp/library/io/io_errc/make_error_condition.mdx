{/* source:cpp-io-io-errc-make-error-condition:0001 */}
Constructs an [`std::error_condition`](/docs/cpp/library/error/error_condition) object from a value of type [`std::io_errc`](/docs/cpp/library/io/io_errc) as if by `return std::error_condition(static_cast<int>(e), std::iostream_category())`.

### Parameters

{/* source:cpp-io-io-errc-make-error-condition:0002 */}
<ParameterList>
  <Parameter name="e">error code number</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-io-errc-make-error-condition:0003 */}
A value of type [`std::error_condition`](/docs/cpp/library/error/error_condition) that holds the error code number from `e` associated with the error category `"iostream"`.

### Example

{/* source:cpp-io-io-errc-make-error-condition:0004 */}
```cpp
#include <iostream>
#include <system_error>
 
int main()
{
    std::error_condition ec = std::make_error_condition(std::io_errc::stream);
    std::cout << "error condition for io_errc::stream has value " << ec.value()
              << "\nand message \"" << ec.message() << "\"\n";
}
```

Output:

```text
error condition for io_errc::stream has value 1
and message "unspecified iostream_category error"
```
