  <DeclarationDescription>
    {/* source:cpp-io-ostrstream-ostrstream:0001 */}
    Constructs new output strstream and its underlying [`std::strstreambuf`](/docs/cpp/library/io/strstreambuf).

    {/* source:cpp-io-ostrstream-ostrstream:0002 */}
    1) Default-constructs the underlying [`std::strstreambuf`](/docs/cpp/library/io/strstreambuf), which creates a dynamically growing buffer, and initializes the base class with the address of the `strstreambuf` member.

    {/* source:cpp-io-ostrstream-ostrstream:0003 */}
    2) Initialized the base class with the address of the underlying [`std::strstreambuf`](/docs/cpp/library/io/strstreambuf) member, which is initialized in one of the two possible ways, both of which write to user-provided fixed-size array:

    {/* source:cpp-io-ostrstream-ostrstream:0004 */}
    - a) if the `app` bit is not set in `mode`, constructs the buffer by calling `strstreambuf(s, n, s)`. The behavior is undefined if there are less than `n` elements in the array whose first element is pointed to by `s`

    {/* source:cpp-io-ostrstream-ostrstream:0005 */}
    - b) if the `app` bit is set in `mode`, constructs the buffer by calling `strstreambuf(s, n, s + std::strlen(s))`. The behavior is undefined if there are less than `n` elements in the array whose first element is pointed to by `s` or if the array does not contain a valid null-terminated character sequence.

  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-ostrstream-ostrstream:0006 */}

<ParameterList>

  <Parameter name="s">char array to use as the output buffer</Parameter>
  <Parameter name="n">size of the array to be used as the output buffer</Parameter>
  <Parameter name="mode">specifies stream open mode. It is a bitmask type, the following constants are defined (although only `app` is used):</Parameter>

</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`app`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream before each write |
| [`binary`](/docs/cpp/library/io/ios_base/openmode) | open in [`binary mode`](/docs/cpp/library/io/c/FILE#Binary_and_text_modes) |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | open for reading |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | open for writing |
| [`trunc`](/docs/cpp/library/io/ios_base/openmode) | discard the contents of the stream when opening |
| [`ate`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream immediately after open |
| [`noreplace`](/docs/cpp/library/io/ios_base/openmode) <InlineRevision since="C++23" /> | open in exclusive mode |

### Example

{/* source:cpp-io-ostrstream-ostrstream:0007 */}

```cpp
#include <iostream>
#include <strstream>
 
int main()
{
    std::ostrstream s1; // dynamic buffer
    s1 << 1 << ' ' << 3.14 << " example\n" << std::ends;
    std::cout << s1.str();
    s1.freeze(false);
 
    char arr[15] = "Hello";
 
    std::ostrstream s2(arr, sizeof arr, std::ios_base::app);
    s2 << ", world!" << std::ends;
    std::cout << s2.str() << '\n';
    std::cout << arr << '\n'; // streams use the provided arrays
}
```

Output:

```text
1 3.14 example
Hello, world!
Hello, world!
```
