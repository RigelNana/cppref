{/* source:cpp-io-ostrstream-ostrstream:0001 */}

Destroys a [`std::ostrstream`](/docs/cpp/library/io/ostrstream) object, which also destroys the member [`std::strstreambuf`](/docs/cpp/library/io/strstreambuf), which may call the deallocation function if the underlying buffer was dynamically-allocated and not frozen.

### Parameters

{/* source:cpp-io-ostrstream-ostrstream:0002 */}

(none)

### Notes

{/* source:cpp-io-ostrstream-ostrstream:0003 */}

If [`str()`](/docs/cpp/library/io/ostrstream/str) was called on a dynamic `ostrstream` and [freeze(false)](/docs/cpp/library/io/ostrstream/freeze) was not called after that, this destructor leaks memory.

### Example

{/* source:cpp-io-ostrstream-ostrstream:0004 */}

```cpp
#include <iostream>
#include <strstream>
 
int main()
{
    {
        std::ostrstream s; // dynamic buffer 
        s << 1.23;
        std::cout << s.str() << '\n';
        s.freeze(false);
    } // destructor called, buffer deallocated 
 
    {
        std::ostrstream s;
        s << 1.23;
        std::cout << s.str() << '\n';
//      buf.freeze(false);
    } // destructor called, memory leaked
}
```

Output:

```text
1.23
1.23
```
