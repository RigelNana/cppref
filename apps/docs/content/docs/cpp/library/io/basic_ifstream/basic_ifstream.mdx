  <DeclarationDescription>
    {/* source:cpp-io-basic-ifstream-basic-ifstream:0001 */}
    Constructs new file stream.

    {/* source:cpp-io-basic-ifstream-basic-ifstream:0002 */}
    1. Default constructor: constructs a stream that is not associated with a file: default-constructs the [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf) and constructs the base with the pointer to this default-constructed [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf) member.

    {/* source:cpp-io-basic-ifstream-basic-ifstream:0003 */}
    2,3. First, performs the same steps as the default constructor, then associates the stream with a file by calling `rdbuf()->open(filename, mode | std::ios_base::in)` (see [`std::basic_filebuf::open`](/docs/cpp/library/io/basic_filebuf/open) for the details on the effects of that call). If the [`open()`](/docs/cpp/library/io/basic_ifstream/open) call returns a null pointer, sets `setstate(failbit)`. <InlineRevision since="C++17">Overload (3) is only provided if `std::filesystem::path::value_type` is not `char`.</InlineRevision>

    {/* source:cpp-io-basic-ifstream-basic-ifstream:0004 */}
    4,5. Same as `basic_ifstream(filename.c_str(), mode)`. <InlineRevision since="C++17">(5) participates in overload resolution only if `FsPath` is [`std::filesystem::path`](/docs/cpp/library/filesystem/path).</InlineRevision>

    {/* source:cpp-io-basic-ifstream-basic-ifstream:0005 */}
    6. Move constructor. First, move-constructs the base class from `other` (which does not affect the [`rdbuf()`](/docs/cpp/library/io/basic_ifstream/rdbuf) pointer), then move-constructs the [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf) member, then calls `this->set_rdbuf()` to install the new `basic_filebuf` as the [`rdbuf()`](/docs/cpp/library/io/basic_ifstream/rdbuf) pointer in the base class.

    {/* source:cpp-io-basic-ifstream-basic-ifstream:0006 */}
    7. The copy-constructor is deleted: this class is not copyable.

  </DeclarationDescription>
</DeclarationDoc>

### Parameters

<ParameterList>
  <Parameter name="filename">the name of the file to be opened</Parameter>

<ParameterList>
  <Parameter name="mode">specifies stream open mode. Following constants and bit-wise OR between them may be used:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`app`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream before each write |
| [`binary`](/docs/cpp/library/io/ios_base/openmode) | open in [binary mode](/docs/cpp/library/io/c/FILE#Binary_and_text_modes) |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | open for reading |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | open for writing |
| [`trunc`](/docs/cpp/library/io/ios_base/openmode) | discard the contents of the stream when opening |
| [`ate`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream immediately after open |
| [`noreplace`](/docs/cpp/library/io/ios_base/openmode) <InlineRevision since="C++23" /> | open in exclusive mode |

  <Parameter name="other">another file stream to use as source</Parameter>
</ParameterList>

### Example

{/* source:cpp-io-basic-ifstream-basic-ifstream:0008 */}
```cpp
#include <fstream>
#include <string>
#include <utility>
 
int main()
{
    std::ifstream f0;
    std::ifstream f1("test.bin", std::ios::binary);
    std::string name = "example.txt";
    std::ifstream f2(name);
    std::ifstream f3(std::move(f1));
}
```
