Specializes the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for `std::basic_ifstream`. Exchanges the state of `lhs` with that of `rhs`. Effectively calls `lhs.swap(rhs)`.

### Parameters

{/* source:cpp-io-basic-ifstream-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">streams whose state to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-ifstream-swap2:0003 */}
(none)

### Exceptions

{/* source:cpp-io-basic-ifstream-swap2:0004 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-io-basic-ifstream-swap2:0005 */}
```cpp
#include <fstream>
#include <iostream>
#include <string>
 
bool create_stream(std::ifstream& fs)
{
    try
    {
        std::string some_name = "/tmp/test_file.txt";
        std::ios_base::openmode some_flags = fs.trunc; // | other flags
 
        if (std::ifstream ts{some_name, some_flags}; ts.is_open())
        {
            std::swap(ts, fs); // stream objects are not copyable => swap
            return true;
        }
    }
    catch (...)
    {
        std::cout << "Exception!\n";
    }
    return false;
}
 
int main()
{
    if (std::ifstream fs; create_stream(fs))
    {
        // use fs stream
    }
}
```
