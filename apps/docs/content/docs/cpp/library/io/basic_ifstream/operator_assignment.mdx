{/* source:cpp-io-basic-ifstream-operator:0001 */}
Move assigns the file stream `other` to `*this`, effectively move-assigning both the [`std::basic_istream`](/docs/cpp/library/io/basic_istream) base class and the associated [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf).

{/* source:cpp-io-basic-ifstream-operator:0002 */}
`other` is left with no associated file. Note that the base class move assignment swaps all stream state variables (except for `rdbuf`) between `*this` and `other`.

{/* source:cpp-io-basic-ifstream-operator:0004 */}
