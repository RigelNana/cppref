{/* source:cpp-io-basic-ifstream-swap:0001 */}
Exchanges the state of the stream with those of `other`.

{/* source:cpp-io-basic-ifstream-swap:0002 */}
This is done by calling `basic_istream<CharT, Traits>::swap(other)` and `rdbuf()->swap(other.rdbuf())`.

### Parameters

{/* source:cpp-io-basic-ifstream-swap:0003 */}
<ParameterList>
  <Parameter name="other">stream to exchange the state with</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-ifstream-swap:0004 */}
(none)

### Exceptions

{/* source:cpp-io-basic-ifstream-swap:0005 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-io-basic-ifstream-swap:0006 */}
```cpp
#include <fstream>
#include <iomanip>
#include <iostream>
#include <string>
 
bool create_stream(std::fstream& fs, const std::string& path)
{
    try
    {
        std::fstream ts{path, ts.trunc | ts.in | ts.out};
        if (ts.is_open())
        {
            ts.swap(fs); // stream objects are not copyable
            return true;
        }
    }
    catch (...)
    {
        std::cout << "Exception!\n";
    }
    return false;
}
 
void use_stream(std::fstream& fs)
{
    fs.seekg(0);
    std::string data;
    fs >> data;
    std::cout << "data: " << std::quoted(data) << '\n';
}
 
int main()
{
    std::fstream fs;
    std::string path = "/tmp/test_file.txt";
    if (create_stream(fs, path))
    {
        fs.write(path.c_str(), path.length());
        use_stream(fs);
    }
}
```

Possible output:

```text
data: "/tmp/test_file.txt"
```
