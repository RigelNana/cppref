{/* source:cpp-io-basic-ifstream-is-open:0001 */}
Checks if the file stream has an associated file.

{/* source:cpp-io-basic-ifstream-is-open:0002 */}
Effectively calls [`rdbuf()->is_open()`](/docs/cpp/library/io/basic_filebuf/is_open).

### Parameters

{/* source:cpp-io-basic-ifstream-is-open:0003 */}
(none)

### Return value

{/* source:cpp-io-basic-ifstream-is-open:0004 */}
`true` if the file stream has an associated file, `false` otherwise.

### Example

{/* source:cpp-io-basic-ifstream-is-open:0005 */}
```cpp
#include <fstream>
#include <iostream>
#include <string>
 
// this file is called main.cpp
 
bool file_exists(const std::string& str)
{
    std::ifstream fs(str);
    return fs.is_open();
}
 
int main()
{
    std::boolalpha(std::cout);
    std::cout << file_exists("main.cpp")  << '\n'
              << file_exists("strange_file") << '\n';
}
```

Possible output:

```text
true
false
```
