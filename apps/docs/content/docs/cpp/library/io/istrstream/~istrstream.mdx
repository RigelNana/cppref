Destroys a `std::istrstream` object, which also destroys the member [`std::strstreambuf`](/docs/cpp/library/io/strstreambuf).

### Parameters

{/* source:cpp-io-istrstream-istrstream:0002 */}

(none)

### Notes

{/* source:cpp-io-istrstream-istrstream:0003 */}

The constructors of [`std::istrstream`](/docs/cpp/library/io/istrstream) do not create the underlying [`std::strstreambuf`](/docs/cpp/library/io/strstreambuf) in dynamically allocated mode, so the memory leaks that are possible with [`std::ostrstream::~ostrstream`](/docs/cpp/library/io/ostrstream/~ostrstream) or [`std::strstream::~strstream`](/docs/cpp/library/io/strstream/~strstream) do not apply.

### Example

{/* source:cpp-io-istrstream-istrstream:0004 */}

```cpp
#include <iostream>
#include <strstream>
 
int main()
{
    {
        std::istrstream s("1.234");
        double d;
        s >> d;
        std::cout << d << '\n';
    } // destructor called
}
```

Output:

```text
1.234
```
