{/* source:cpp-io-basic-streambuf-showmanyc:0001 */}
Estimates the number of characters available for input in the associated character sequence. [`underflow()`](/docs/cpp/library/io/basic_streambuf/underflow) is guaranteed not to return `Traits::eof()` or throw an exception until at least that many characters are extracted.

### Parameters

{/* source:cpp-io-basic-streambuf-showmanyc:0002 */}
(none)

### Return value

{/* source:cpp-io-basic-streambuf-showmanyc:0003 */}
The number of characters that are certainly available in the associated character sequence, or `-1` if `showmanyc` can determine, without blocking, that no characters are available. If `showmanyc` returns `-1`, [`underflow()`](/docs/cpp/library/io/basic_streambuf/underflow) and [`uflow()`](/docs/cpp/library/io/basic_streambuf/uflow) will definitely return `Traits::eof` or throw.

{/* source:cpp-io-basic-streambuf-showmanyc:0004 */}
The base class version returns `0`, which has the meaning of "unsure if there are characters available in the associated sequence".

### Notes

{/* source:cpp-io-basic-streambuf-showmanyc:0005 */}
The name of this function stands for "stream: how many characters?", so it is pronounced "S how many C", rather than "show many C".
