{/* source:cpp-io-basic-streambuf-sputc:0001 */}
Writes one character to the output sequence.

{/* source:cpp-io-basic-streambuf-sputc:0002 */}
If the output sequence write position is not available (the buffer is full), then calls `overflow(ch)`.

### Parameters

{/* source:cpp-io-basic-streambuf-sputc:0003 */}
<ParameterList>
  <Parameter name="ch">character to write</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-streambuf-sputc:0004 */}
The written character, converted to `int_type` with `Traits::to_int_type(ch)` on success.

{/* source:cpp-io-basic-streambuf-sputc:0005 */}
`Traits::eof()` (as returned by [`overflow()`](/docs/cpp/library/io/basic_streambuf/overflow)) on failure.

### Example

{/* source:cpp-io-basic-streambuf-sputc:0006 */}
```cpp
#include <iostream>
#include <sstream>

int main()
{
    std::ostringstream s;
    s.rdbuf()->sputc('a');
    std::cout << s.str() << '\n';
}
```

Output:

```text
a
```
