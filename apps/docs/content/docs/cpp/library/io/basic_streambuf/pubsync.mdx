  <DeclarationDescription>
    {/* source:cpp-io-basic-streambuf-pubsync:0001 */}
    Synchronizes the controlled character sequence (the buffers) with the associated character sequence.

    {/* source:cpp-io-basic-streambuf-pubsync:0002 */}
    1. Calls `sync()` of the most derived class

    {/* source:cpp-io-basic-streambuf-pubsync:0003 */}
    2. The base class version of this function has no effect. The derived classes may override this function to allow synchronizing the underlying device with the buffers.

    {/* source:cpp-io-basic-streambuf-pubsync:0004 */}
    For output streams, this typically results in writing the contents of the put area into the associated sequence, i.e. flushing of the output buffer. For input streams, this typically empties the get area and forces a re-read from the associated sequence to pick up recent changes. The default behavior (found, for example, in [`std::basic_stringbuf`](/docs/cpp/library/io/basic_stringbuf)), is to do nothing.
  </DeclarationDescription>
</DeclarationDoc>

### Return value

{/* source:cpp-io-basic-streambuf-pubsync:0006 */}

{/* source:cpp-io-basic-streambuf-pubsync:0007 */}
2. Returns `0` on success, `-1` otherwise. The base class version returns `0`.
