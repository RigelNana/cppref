  <DeclarationDescription>
    {/* source:cpp-io-basic-streambuf-pubseekoff:0001 */}
    Sets the position indicator of the input and/or output sequence relative to some other position.

    {/* source:cpp-io-basic-streambuf-pubseekoff:0002 */}
    1. Calls `seekoff(off, dir, which)` of the most derived class.

    {/* source:cpp-io-basic-streambuf-pubseekoff:0003 */}
    2. The base class version of this function has no effect. The derived classes may override this function to allow relative positioning of the position indicator.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-basic-streambuf-pubseekoff:0004 */}
<ParameterList>
  <Parameter name="off">relative position to set the position indicator to.</Parameter>
  <Parameter name="dir">defines base position to apply the relative offset to. It can be one of the following constants:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`beg`](/docs/cpp/library/io/ios_base/seekdir) | the beginning of a stream |
| [`end`](/docs/cpp/library/io/ios_base/seekdir) | the ending of a stream |
| [`cur`](/docs/cpp/library/io/ios_base/seekdir) | the current position of stream position indicator |

<ParameterList>
  <Parameter name="which">defines which of the input and/or output sequences to affect. It can be one or a combination of the following constants:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | affect the input sequence |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | affect the output sequence |

### Note

{/* source:cpp-io-basic-streambuf-pubseekoff:0005 */}
Not all combinations of parameters may be valid, see the derived versions of `seekoff` for details.

### Return value

{/* source:cpp-io-basic-streambuf-pubseekoff:0006 */}
1. The return value of `seekoff(off, dir, which)`

{/* source:cpp-io-basic-streambuf-pubseekoff:0007 */}
2. The resulting absolute position as defined by the position indicator. The base class version returns `pos_type(off_type(-1))`.
