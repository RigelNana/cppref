  <DeclarationDescription>
    {/* source:cpp-io-basic-streambuf-basic-streambuf:0001 */}
    1. Constructs the `basic_streambuf` object, initializes the six pointer members (`eback()`, `gptr()`, `egptr()`, `pbase()`, `pptr()`, and `epptr()`) to null pointer values, and the locale member to `std::locale()`, a copy of the global C++ locale at the time of construction.

    {/* source:cpp-io-basic-streambuf-basic-streambuf:0002 */}
    2. Constructs a copy of `rhs`, initializing the six pointers and the locale object with the copies of the values held by `rhs`. Note that this is a shallow copy: the pointers of the newly-constructed `basic_streambuf` are pointing into the same character array as the pointers of `rhs`.

    {/* source:cpp-io-basic-streambuf-basic-streambuf:0003 */}
    Both constructors are protected, and are only called by the concrete streambuf classes, such as [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf), [`std::basic_stringbuf`](/docs/cpp/library/io/basic_stringbuf), or [`std::strstreambuf`](/docs/cpp/library/io/strstreambuf).
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-io-basic-streambuf-basic-streambuf:0005 */}
Until C++11, it was unspecified whether `basic_streambuf` or any of its derived classes is [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible) ([LWG issue 421](https://cplusplus.github.io/LWG/issue421)), and different C++ library implementations provided different options.
