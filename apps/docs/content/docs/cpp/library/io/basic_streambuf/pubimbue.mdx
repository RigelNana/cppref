  <DeclarationDescription>
    {/* source:cpp-io-basic-streambuf-pubimbue:0001 */}
    Changes the associated locale.

    {/* source:cpp-io-basic-streambuf-pubimbue:0002 */}
    1. Sets `loc` as the associated locale. Calls `imbue(loc)` of the most derived class

    {/* source:cpp-io-basic-streambuf-pubimbue:0003 */}
    2. The base class version of this function has no effect. The derived classes may override this function in order to be informed about the changes of the locale. The derived class may cache the locale and member facets between calls to `imbue()`.
  </DeclarationDescription>
</DeclarationDoc>

### Return value

2. (none)

### Notes

{/* source:cpp-io-basic-streambuf-pubimbue:0007 */}
From within the call of `imbue()`, [`getloc()`](/docs/cpp/library/io/basic_streambuf/getloc) returns the previous locale.
