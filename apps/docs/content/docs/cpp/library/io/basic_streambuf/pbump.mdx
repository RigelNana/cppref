void pbump( int count );`} />
</DeclarationDoc>

{/* source:cpp-io-basic-streambuf-pbump:0001 */}
Repositions the put pointer ([`pptr()`](/docs/cpp/library/io/basic_streambuf/pptr)) by `count` characters, where `count` may be positive or negative. No checks are done for moving the pointer outside the put area [ `pbase()`, `epptr()` ).

{/* source:cpp-io-basic-streambuf-pbump:0002 */}
If the pointer is advanced and then [`overflow()`](/docs/cpp/library/io/basic_streambuf/overflow) is called to flush the put area to the associated character sequence, the effect is that extra `count` characters with undefined values are output.

### Parameters

{/* source:cpp-io-basic-streambuf-pbump:0003 */}
<ParameterList>
  <Parameter name="count">number to add to the put pointer</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-streambuf-pbump:0004 */}
(none)

### Notes

{/* source:cpp-io-basic-streambuf-pbump:0005 */}
Because this function takes an `int`, it cannot manipulate buffers larger than `std::numeric_limits<int>::max()` characters ([LWG issue 255](https://cplusplus.github.io/LWG/issue255)).

### Example

{/* source:cpp-io-basic-streambuf-pbump:0006 */}
```cpp
#include <fstream>
#include <iostream>
#include <string>

struct showput_streambuf : std::filebuf
{
    using std::filebuf::pbump; // expose protected
    std::string showput() const
    {
        return std::string(pbase(), pptr());
    }
};

int main()
{
    showput_streambuf mybuf;
    mybuf.open("test.txt", std::ios_base::out);
    std::ostream str(&mybuf);
    str << "This is a test" << std::flush << "1234";
    std::cout << "The put area contains: " << mybuf.showput() << '\n';
    mybuf.pbump(10);
    std::cout << "after pbump(10), it contains " << mybuf.showput() << '\n';
}
```

Output:

```text
The put area contains: 1234
after pbump(10), it contains 1234 is a test
```
