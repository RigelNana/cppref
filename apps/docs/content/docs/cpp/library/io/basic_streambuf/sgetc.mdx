{/* source:cpp-io-basic-streambuf-sgetc:0001 */}
Reads one character from the input sequence.

{/* source:cpp-io-basic-streambuf-sgetc:0002 */}
If the input sequence read position is not available, returns [`underflow()`](/docs/cpp/library/io/basic_streambuf/underflow). Otherwise returns `Traits::to_int_type(*gptr())`.

### Parameters

{/* source:cpp-io-basic-streambuf-sgetc:0003 */}
(none)

### Return value

{/* source:cpp-io-basic-streambuf-sgetc:0004 */}
The value of the character pointed to by the get pointer.

### Example

{/* source:cpp-io-basic-streambuf-sgetc:0005 */}
```cpp
#include <iostream>
#include <sstream>

int main()
{
    std::stringstream stream("Hello, world");
    std::cout << "sgetc() returned '" << (char)stream.rdbuf()->sgetc() << "'\n";
    std::cout << "peek() returned '" << (char)stream.peek() << "'\n";
    std::cout << "get() returned '" << (char)stream.get() << "'\n";
}
```

Output:

```text
sgetc() returned 'H'
peek() returned 'H'
get() returned 'H'
```
