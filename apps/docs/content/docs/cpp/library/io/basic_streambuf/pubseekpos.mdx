  <DeclarationDescription>
    {/* source:cpp-io-basic-streambuf-pubseekpos:0001 */}
    Sets the position indicator of the input and/or output sequence to an absolute position.

    {/* source:cpp-io-basic-streambuf-pubseekpos:0002 */}
    1. Calls `seekpos(pos, which)` of the most derived class.

    {/* source:cpp-io-basic-streambuf-pubseekpos:0003 */}
    2. The base class version of this function has no effect. The derived classes may override this function to allow absolute positioning of the position indicator.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-basic-streambuf-pubseekpos:0004 */}
<ParameterList>
  <Parameter name="pos">absolute position to set the position indicator to</Parameter>
  <Parameter name="which">defines which of the input and/or output sequences to affect. It can be one or a combination of the following constants:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | affect the input sequence |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | affect the output sequence |

### Return value

{/* source:cpp-io-basic-streambuf-pubseekpos:0005 */}
1. The return value of `seekpos(pos, which)`.

{/* source:cpp-io-basic-streambuf-pubseekpos:0006 */}
2. The resulting absolute position as defined by the position indicator. The base class version returns `pos_type(off_type(-1))`.
