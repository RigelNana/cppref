    {/* source:cpp-io-basic-streambuf-sbumpc:0001 */}
    Reads one character and advances the input sequence by one character.

    {/* source:cpp-io-basic-streambuf-sbumpc:0002 */}
    1. If the input sequence read position is not available, returns [`uflow()`](/docs/cpp/library/io/basic_streambuf/uflow). Otherwise returns `Traits::to_int_type(*gptr())`.

    {/* source:cpp-io-basic-streambuf-sbumpc:0003 */}
    2. Same as (1), but discards the result.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-basic-streambuf-sbumpc:0004 */}
(none)

### Return value

{/* source:cpp-io-basic-streambuf-sbumpc:0005 */}
1. The value of the character pointed to by the get pointer, or `Traits::eof()` if the read position is not available.
