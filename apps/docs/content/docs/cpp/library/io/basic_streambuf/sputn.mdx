virtual std::streamsize xsputn( const char_type* s, std::streamsize count );`} />

  <DeclarationDescription>
    {/* source:cpp-io-basic-streambuf-sputn:0001 */}
    1. Calls `xsputn(s, count)` of the most derived class.

    {/* source:cpp-io-basic-streambuf-sputn:0002 */}
    2. Writes `count` characters to the output sequence from the character array whose first element is pointed to by `s`. The characters are written as if by repeated calls to [`sputc()`](/docs/cpp/library/io/basic_streambuf/sputc). Writing stops when either `count` characters are written or a call to [`sputc()`](/docs/cpp/library/io/basic_streambuf/sputc) would have returned `Traits::eof()`.

    {/* source:cpp-io-basic-streambuf-sputn:0003 */}
    If the put area becomes full (`pptr() == epptr()`), it is unspecified whether [`overflow()`](/docs/cpp/library/io/basic_streambuf/overflow) is actually called or its effect is achieved by other means.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-basic-streambuf-sputn:0004 */}
(none)

### Return value

{/* source:cpp-io-basic-streambuf-sputn:0005 */}
The number of characters successfully written.

### Notes

{/* source:cpp-io-basic-streambuf-sputn:0006 */}
"achieved by other means" permits bulk I/O without intermediate buffering: that is how [`std::ofstream::write()`](/docs/cpp/library/io/basic_ostream/write) simply passes the pointer to the suitable system call in some implementations.

### Example

{/* source:cpp-io-basic-streambuf-sputn:0007 */}
```cpp
#include <iostream>
#include <sstream>

int main()
{
    std::ostringstream s1;
    std::streamsize sz = s1.rdbuf()->sputn("This is a test", 14);
    s1 << '\n';
    std::cout << "The call to sputn() returned " << sz << '\n'
              << "The output sequence contains " << s1.str();

    std::istringstream s2;
    sz = s2.rdbuf()->sputn("This is a test", 14);
    std::cout << "The call to sputn() on an input stream returned " << sz << '\n';
}
```

Output:

```text
The call to sputn() returned 14
The output sequence contains This is a test
The call to sputn() on an input stream returned 0
```
