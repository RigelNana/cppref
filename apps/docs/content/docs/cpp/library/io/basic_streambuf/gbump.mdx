{/* source:cpp-io-basic-streambuf-gbump:0001 */}
Skips `count` characters in the get area. This is done by adding `count` to the get pointer. No checks are done for underflow.

### Parameters

{/* source:cpp-io-basic-streambuf-gbump:0002 */}
<ParameterList>
  <Parameter name="count">number of characters to skip</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-streambuf-gbump:0003 */}
(none)

### Notes

{/* source:cpp-io-basic-streambuf-gbump:0004 */}
Because this function takes an `int`, it cannot manipulate buffers larger than `std::numeric_limits<int>::max()` characters ([LWG issue 255](https://cplusplus.github.io/LWG/issue255)).
