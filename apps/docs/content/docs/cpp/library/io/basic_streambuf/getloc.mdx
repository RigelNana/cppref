{/* source:cpp-io-basic-streambuf-getloc:0001 */}
Returns the associated locale.

{/* source:cpp-io-basic-streambuf-getloc:0002 */}
The associated locale is the value supplied to [`pubimbue()`](/docs/cpp/library/io/basic_streambuf/pubimbue) on the last call, or, if that function has not been called, the value of the global locale ([`std::locale`](/docs/cpp/library/text/locale/locale)) at the time of the construction of the streambuf.

### Parameters

{/* source:cpp-io-basic-streambuf-getloc:0003 */}
(none)

### Return value

{/* source:cpp-io-basic-streambuf-getloc:0004 */}
The associated locale.
