virtual std::streamsize xsgetn( char_type* s, std::streamsize count );`} />

  <DeclarationDescription>
    {/* source:cpp-io-basic-streambuf-sgetn:0001 */}
    1. Calls `xsgetn(s, count)` of the most derived class.

    {/* source:cpp-io-basic-streambuf-sgetn:0002 */}
    2. Reads `count` characters from the input sequence and stores them into a character array pointed to by `s`. The characters are read as if by repeated calls to [`sbumpc()`](/docs/cpp/library/io/basic_streambuf/sbumpc). That is, if less than `count` characters are immediately available, the function calls [`uflow()`](/docs/cpp/library/io/basic_streambuf/uflow) to provide more until `Traits::eof()` is returned.

    {/* source:cpp-io-basic-streambuf-sgetn:0003 */}
    3. Classes derived from `std::basic_streambuf` are permitted to provide more efficient implementations of this function.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-basic-streambuf-sgetn:0004 */}
<ParameterList>
  <Parameter name="s">pointer to the beginning of a `char_type` array</Parameter>
  <Parameter name="count">maximum number of characters to read.</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-streambuf-sgetn:0005 */}
The number of characters successfully read. If it is less than `count` the input sequence has reached the end.

### Notes

{/* source:cpp-io-basic-streambuf-sgetn:0006 */}
The rule about "more efficient implementations" permits bulk I/O without intermediate buffering: that's how [`std::ifstream::read`](/docs/cpp/library/io/basic_istream/read) simply passes the pointer to the POSIX `read()` system call in some implementations of iostreams
