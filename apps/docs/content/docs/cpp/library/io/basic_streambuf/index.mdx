{/* source:cpp-io-basic-streambuf:0001 */}
The class `basic_streambuf` controls input and output to a character sequence. It includes and provides access to

{/* source:cpp-io-basic-streambuf:0002 */}
- The controlled character sequence, also called the buffer, which may contain input sequence (also called get area) for buffering the input operations and/or output sequence (also called put area) for buffering the output operations.
- The associated character sequence, also called source (for input) or sink (for output). This may be an entity that is accessed through OS API (file, TCP socket, serial port, other character device), or it may be an object ([`std::vector`](/docs/cpp/library/container/vector), [array](/docs/cpp/language/declarations/array), [string literal](/docs/cpp/language/expressions/string_literal)), that can be interpreted as a character source or sink.

{/* source:cpp-io-basic-streambuf:0003 */}
The I/O stream objects [`std::basic_istream`](/docs/cpp/library/io/basic_istream) and [`std::basic_ostream`](/docs/cpp/library/io/basic_ostream), as well as all objects derived from them ([`std::ofstream`](/docs/cpp/library/io/basic_ofstream), [`std::stringstream`](/docs/cpp/library/io/basic_stringstream), etc), are implemented entirely in terms of `std::basic_streambuf`.

{/* source:cpp-io-basic-streambuf:0004 */}
The controlled character sequence is an array of `CharT` which, at all times, represents a subsequence, or a "window" into the associated character sequence. Its state is described by three pointers:

{/* source:cpp-io-basic-streambuf:0005 */}
- The beginning pointer, always points at the lowest element of the buffer.
- The next pointer, points at the element that is the next candidate for reading or writing.
- The end pointer, points one past the end of the buffer.

{/* source:cpp-io-basic-streambuf:0006 */}
A `basic_streambuf` object may support input (in which case the buffer described by the beginning, next, and end pointers is called get area), output (put area), or input and output simultaneously. In latter case, six pointers are tracked, which may all point to elements of the same character array or two individual arrays.

{/* source:cpp-io-basic-streambuf:0007 */}
If the next pointer is less than the end pointer in the put area, a write position is available. The next pointer can be dereferenced and assigned to.

{/* source:cpp-io-basic-streambuf:0008 */}
If the next pointer is less than the end pointer in the get area, a read position is available. The next pointer can be dereferenced and read from.

{/* source:cpp-io-basic-streambuf:0009 */}
If the next pointer is greater than the beginning pointer in a get area, a putback position is available, and the next pointer may be decremented, dereferenced, and assigned to, in order to put a character back into the get area.

{/* source:cpp-io-basic-streambuf:0010 */}
The character representation and encoding in the controlled sequence may be different from the character representations in the associated sequence, in which case a [`std::codecvt`](/docs/cpp/library/text/locale/codecvt) locale facet is typically used to perform the conversion. Common examples are UTF-8 (or other multibyte) files accessed through [`std::wfstream`](/docs/cpp/library/io/basic_fstream) objects: the controlled sequence consists of `wchar_t` characters, but the associated sequence consists of bytes.

{/* source:cpp-io-basic-streambuf:0011 */}
Typical implementation of the `std::basic_streambuf` base class holds only the six `CharT*` pointers and a copy of [`std::locale`](/docs/cpp/library/text/locale/locale) as data members. In addition, implementations may keep cached copies of locale facets, which are invalidated whenever `imbue()` is called. The concrete buffers such as [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf) or [`std::basic_stringbuf`](/docs/cpp/library/io/basic_stringbuf) are derived from `std::basic_streambuf`.
