Advances the input sequence by one character and reads one character.

{/* source:cpp-io-basic-streambuf-snextc:0002 */}
The function calls [`sbumpc()`](/docs/cpp/library/io/basic_streambuf/sbumpc) to advance the input sequence. If that function returns `Traits::eof()` meaning that input sequence has been exhausted and [`uflow()`](/docs/cpp/library/io/basic_streambuf/uflow) could not retrieve more data, `Traits::eof()` is returned. Otherwise [`sgetc()`](/docs/cpp/library/io/basic_streambuf/sgetc) is called in order to read the character.

### Parameters

{/* source:cpp-io-basic-streambuf-snextc:0003 */}
(none)

### Return value

{/* source:cpp-io-basic-streambuf-snextc:0004 */}
The value of the next character. If the input sequence has been exhausted, `Traits::eof()` is returned.
