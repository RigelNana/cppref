{/* source:cpp-io-basic-streambuf-uflow:0001 */}
Ensures that at least one character is available in the input area by updating the pointers to the input area (if needed). On success returns the value of that character and advances the value of the get pointer by one character. On failure returns `traits::eof()`.

{/* source:cpp-io-basic-streambuf-uflow:0002 */}
The function may update `gptr`, `egptr` and `eback` pointers to define the location of newly loaded data (if any). On failure, the function ensures that either `gptr() == nullptr` or `gptr() == egptr`.

{/* source:cpp-io-basic-streambuf-uflow:0003 */}
The base class version of the function calls [`underflow()`](/docs/cpp/library/io/basic_streambuf/underflow) and increments [`gptr()`](/docs/cpp/library/io/basic_streambuf/gptr).

### Parameters

{/* source:cpp-io-basic-streambuf-uflow:0004 */}
(none)

### Return value

{/* source:cpp-io-basic-streambuf-uflow:0005 */}
The value of the character that was pointed to by the get pointer before it was advanced by one, or `traits::eof()` otherwise.

{/* source:cpp-io-basic-streambuf-uflow:0006 */}
The base class version of the function returns the value returned by [`underflow()`](/docs/cpp/library/io/basic_streambuf/underflow).

### Note

{/* source:cpp-io-basic-streambuf-uflow:0007 */}
The public functions of [`std::streambuf`](/docs/cpp/library/io/basic_streambuf) call this function only if `gptr() == nullptr` or `gptr() >= egptr()`.

{/* source:cpp-io-basic-streambuf-uflow:0008 */}
The custom streambuf classes that do not use the get area and do not set the get area pointers in `basic_streambuf` are required to override this function.
