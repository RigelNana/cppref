  <DeclarationDescription>
    {/* source:cpp-io-cout:0001 */}
    The global objects `std::cout` and `std::wcout` control output to a stream buffer of implementation-defined type (derived from [`std::streambuf`](/docs/cpp/library/io/basic_streambuf)), associated with the standard C output stream [`stdout`](/docs/cpp/library/io/c/std_streams).

    {/* source:cpp-io-cout:0002 */}
    These objects are guaranteed to be initialized during or before the first time an object of type [`std::ios_base::Init`](/docs/cpp/library/io/ios_base/Init) is constructed and are available for use in the constructors and destructors of static objects with [ordered initialization](/docs/cpp/language/initialization#Non-local_variables) (as long as [`<iostream>`](/docs/cpp/library/headers/iostream) is included before the object is defined).

    {/* source:cpp-io-cout:0003 */}
    Unless `std::ios_base::sync_with_stdio(false)` has been issued, it is safe to concurrently access these objects from multiple threads for both formatted and unformatted output.

    {/* source:cpp-io-cout:0004 */}
    By specification of [`std::cin`](/docs/cpp/library/io/basic_istream/cin), `std::cin.tie()` returns `&std::cout`. This means that any input operation on `std::cin` executes `std::cout.flush()` (via [`std::basic_istream::sentry`](/docs/cpp/library/io/basic_istream/sentry)'s constructor). Similarly, `std::wcin.tie()` returns `&std::wcout`.

    {/* source:cpp-io-cout:0005 */}
    By specification of `std::cerr`, `std::cerr.tie()` returns `&std::cout`. This means that any output operation on `std::cerr` executes `std::cout.flush()` (via [`std::basic_ostream::sentry`](/docs/cpp/library/io/basic_ostream/sentry)'s constructor). Similarly, <InlineRevision since="C++11">`std::wcerr.tie()` returns `&std::wcout`</InlineRevision>.
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-io-cout:0006 */}
The 'c' in the name refers to "character" ([stroustrup.com FAQ](https://www.stroustrup.com/bs_faq2.html#cout)); `cout` means "character output" and `wcout` means "wide character output".

{/* source:cpp-io-cout:0007 */}
Because [dynamic initialization](/docs/cpp/language/initialization#Dynamic_initialization) of [templated](/docs/cpp/language/templates#Templated_entity) variables are unordered, it is not guaranteed that `std::cout` has been initialized to a usable state before the initialization of such variables begins, unless an object of type [`std::ios_base::Init`](/docs/cpp/library/io/ios_base/Init) has been constructed.

### Example

{/* source:cpp-io-cout:0008 */}
```cpp
#include <iostream>
 
struct Foo
{
    int n;
    Foo()
    {
        std::cout << "static constructor\n";
    }
    ~Foo()
    {
        std::cout << "static destructor\n";
    }
};
 
Foo f; // static object
 
int main()
{
    std::cout << "main function\n";
}
```

Output:

```text
static constructor
main function
static destructor
```
