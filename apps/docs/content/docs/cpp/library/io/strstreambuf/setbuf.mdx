  <Declaration language="cpp" until="C++26" code={`protected:
virtual streambuf* setbuf( char* s, std::streamsize n );`} /> (deprecated in C++98)
</DeclarationDoc>

{/* source:cpp-io-strstreambuf-setbuf:0001 */}

If `s` is a null pointer and `n` is zero, this function has no effect.

{/* source:cpp-io-strstreambuf-setbuf:0002 */}

Otherwise, the effect is implementation-defined: some implementations do nothing, while some implementations deallocate the dynamic member array used as the buffer and begin using the user-supplied character array of size `n`, whose first element is pointed to by `s`.

{/* source:cpp-io-strstreambuf-setbuf:0003 */}

This function is protected virtual, it may only be called through `pubsetbuf()` or from member functions of a user-defined class derived from `std::strstreambuf`.

### Parameters

{/* source:cpp-io-strstreambuf-setbuf:0004 */}

<ParameterList>

  <Parameter name="s">pointer to the first byte in the user-provided buffer</Parameter>
  <Parameter name="n">the number of bytes in the user-provided buffer</Parameter>

</ParameterList>

### Return value

{/* source:cpp-io-strstreambuf-setbuf:0005 */}

`this`

### Example

{/* source:cpp-io-strstreambuf-setbuf:0006 */}

Implementation test to check if `setbuf()` is supported on a dynamic strstream (output obtained with Sun Studio):

```cpp
#include <iostream>
#include <strstream>
 
int main()
{
    char a[100] = {};
    std::strstream str;
    str.rdbuf()->pubsetbuf(a, sizeof a);
    str << "Test string" << std::ends;
    std::cout << "user-provided buffer holds \"" << a << "\"\n";
}
```

Possible output:

```text
user-provided buffer holds "Test string"
```
