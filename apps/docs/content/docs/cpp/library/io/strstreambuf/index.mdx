  <DeclarationDescription>
    {/* source:cpp-io-strstreambuf:0001 */}
    `std::strstreambuf` is a [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf) whose associated character sequence is a character array, which may be constant (e.g. a string literal), modifiable but not dynamic (e.g. a stack-allocated array), or dynamic, in which case the `std::strstreambuf` may be allowed to reallocate the array as necessary to accommodate output (e.g. by calling `delete[]` and `new[]` or user-provided functions).

    {/* source:cpp-io-strstreambuf:0002 */}
    Typical implementation of a `std::strstreambuf` holds four private data members:

    {/* source:cpp-io-strstreambuf:0003 */}
    1) buffer state, a bitmask type which can represent any combination of the four values "allocated" (destructor will deallocate), "constant" (output not allowed), "dynamic" (output may reallocate), or "frozen" (deallocation and reallocation are not allowed)

    {/* source:cpp-io-strstreambuf:0004 */}
    2) allocated buffer size (the beginning of the buffer does not need a special data member, it may be stored in the inherited pointer [`eback()`](/docs/cpp/library/io/basic_streambuf/gptr))

    {/* source:cpp-io-strstreambuf:0005 */}
    3) pointer to user-provided allocation function

    {/* source:cpp-io-strstreambuf:0006 */}
    4) pointer to user-provided deallocation function.

  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-io-strstreambuf:0007 */}

After any call to [`str()`](/docs/cpp/library/io/strstreambuf/str) on a stream with a dynamic buffer, a call to [freeze(false)](/docs/cpp/library/io/strstreambuf/freeze) is required to allow the `strstreambuf` destructor to deallocate the buffer when necessary.

{/* source:cpp-io-strstreambuf:0008 */}

`strstreambuf` has been deprecated since C++98 and removed since C++26<InlineRevision since="C++23">. The recommended replacement is [`std::spanbuf`](/docs/cpp/library/io/basic_spanbuf)</InlineRevision>.
