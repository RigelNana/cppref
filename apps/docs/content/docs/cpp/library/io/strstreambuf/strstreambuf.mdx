  <DeclarationDescription>
    {/* source:cpp-io-strstreambuf-strstreambuf:0001 */}
    1) Constructs a `std::strstreambuf` object: initializes the base class by calling the default constructor of [`std::streambuf`](/docs/cpp/library/io/basic_streambuf), initializes the buffer state to "dynamic" (the buffer will be allocated as needed), initializes allocated size to the provided `alsize`, initializes the allocation and the deallocation functions to null (will use `new[]` and `delete[]`).

    {/* source:cpp-io-strstreambuf-strstreambuf:0002 */}
    2) Constructs a `std::strstreambuf` object: initializes the base class by calling the default constructor of [`std::streambuf`](/docs/cpp/library/io/basic_streambuf), initializes the buffer state to "dynamic" (the buffer will be allocated as needed), initializes allocated size to unspecified value, initializes the allocation function to `palloc` and the deallocation function to `pfree`.

    {/* source:cpp-io-strstreambuf-strstreambuf:0003 */}
    3-5) Constructs a `std::strstreambuf` object in following steps:

    {/* source:cpp-io-strstreambuf-strstreambuf:0004 */}
    - a) Initializes the base class by calling the default constructor of [`std::streambuf`](/docs/cpp/library/io/basic_streambuf).

    {/* source:cpp-io-strstreambuf-strstreambuf:0005 */}
    - b) Initializes the buffer state to "constant" (the buffer is a user-provided fixed-size buffer).

    {/* source:cpp-io-strstreambuf-strstreambuf:0006 */}
    - c) Determines the number of elements in the user-provided array as follows: if `n` is greater than zero, `n` is used. If `n` is zero, `std::strlen(gnext)` is executed to determine the buffer size. If `n` is negative, [`INT_MAX`](/docs/cpp/library/utility/types/climits) is used.

    {/* source:cpp-io-strstreambuf-strstreambuf:0007 */}
    - d) Configures the [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf) pointers as follows: If `pbeg` is a null pointer, calls `setg(gnext, gnext, gnext + N)`. If `pbeg` is not a null pointer, executes `setg(gnext, gnext, pbeg)` and `setp(pbeg, pbeg + N)`, where N is the number of elements in the array as determined earlier.

    {/* source:cpp-io-strstreambuf-strstreambuf:0008 */}
    6-8) Same as `strstreambuf((char*)gnext, n)`, except the "constant" bit is set in the buffer state bitmask (output to this buffer is not allowed).

  </DeclarationDescription>

### Notes

{/* source:cpp-io-strstreambuf-strstreambuf:0010 */}

### Example

{/* source:cpp-io-strstreambuf-strstreambuf:0013 */}

```cpp
#include <iostream>
#include <strstream>
 
int main()
{
    std::strstreambuf dyn; // dynamic
    std::strstream dyn_s; // equivalent stream
    dyn_s << 1.23 << std::ends;
    std::cout << dyn_s.str() << '\n';
    dyn_s.freeze(false);
 
    char buf[10];
    std::strstreambuf user(buf, 10, buf); // user-provided output buffer
    std::ostrstream user_s(buf, 10); // equivalent stream
    user_s << 1.23 << std::ends;
    std::cout << buf << '\n';
 
    std::strstreambuf lit("1 2 3", 5); // constant
    std::istrstream lit_s("1 2 3"); // equivalent stream
    int i, j, k;
    lit_s >> i >> j >> k;
    std::cout << i << ' ' << j << ' ' << k << '\n';
}
```

Output:

```text
1.23
1.23
1 2 3
```
