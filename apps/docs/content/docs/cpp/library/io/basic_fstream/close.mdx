{/* source:cpp-io-basic-fstream-close:0001 */}
Closes the associated file.

{/* source:cpp-io-basic-fstream-close:0002 */}
Effectively calls [`rdbuf()->close()`](/docs/cpp/library/io/basic_filebuf/close). If an error occurs during operation, `setstate(failbit)` is called.

### Parameters

{/* source:cpp-io-basic-fstream-close:0003 */}
(none)

### Return value

{/* source:cpp-io-basic-fstream-close:0004 */}
(none)

### Notes

{/* source:cpp-io-basic-fstream-close:0005 */}
This function is called by the destructor of `basic_fstream` when the stream object goes out of scope and is not usually invoked directly.

### Example

{/* source:cpp-io-basic-fstream-close:0006 */}
```cpp
#include <fstream>
#include <iostream>
#include <string>
 
int main()
{
    std::fstream f1("example1", std::ios::out),
                 f2("example2", std::ios::out),
                 f3("example3", std::ios::out);
 
    std::cout << std::boolalpha
              << f1.is_open() << '\n'
              << f2.is_open() << '\n'
              << f3.is_open() << '\n';
 
    f1.close();
    f2.close();
 
    std::cout << f1.is_open() << '\n'
              << f2.is_open() << '\n'
              << f3.is_open() << '\n';
}
```

Possible output:

```text
true
true
true
false
false
true
```
