{/* source:cpp-io-basic-osyncstream-get-wrapped:0001 */}
Returns a pointer to the wrapped [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf), obtained by calling [`get_wrapped()`](/docs/cpp/library/io/basic_syncbuf/get_wrapped) on the underlying `std::basic_syncbuf`.

### Parameters

{/* source:cpp-io-basic-osyncstream-get-wrapped:0002 */}
(none)

### Example

{/* source:cpp-io-basic-osyncstream-get-wrapped:0003 */}
Wrapped buffer can be safely wrapped again in a different synchronized output stream.

```cpp
#include <iostream>
#include <syncstream>
 
int main()
{
    std::osyncstream bout1(std::cout);
    bout1 << "Hello, ";
    {
        std::osyncstream(bout1.get_wrapped()) << "Goodbye, " << "Planet!" << '\n';
    } // emits the contents of the temporary buffer
    bout1 << "World!" << '\n';
} // emits the contents of bout1
```

Output:

```text
Goodbye, Planet!
Hello, World!
```
