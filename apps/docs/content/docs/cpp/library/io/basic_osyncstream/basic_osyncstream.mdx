    {/* source:cpp-io-basic-osyncstream-basic-osyncstream:0001 */}
    Constructs new synchronized output stream.

    {/* source:cpp-io-basic-osyncstream-basic-osyncstream:0002 */}
    1. 1-4) Constructs the private member `std::basic_syncbuf` using the buffer and the allocator provided, and initializes the base class with a pointer to the member `std::basic_streambuf`.

    {/* source:cpp-io-basic-osyncstream-basic-osyncstream:0003 */}
    2. 5) Move constructor. Move-constructs the `std::basic_ostream` base and the `std::basic_syncbuf` member from the corresponding subobjects of `other`, then calls [`set_rdbuf`](/docs/cpp/library/io/basic_ios/set_rdbuf) with the pointer to the newly-constructed underlying `std::basic_syncbuf` to complete the initialization of the base. After this move constructor, `other.get_wrapped()` returns `nullptr` and destruction of `other` produces no output.
  </DeclarationDescription>
</DeclarationDoc>

### Example

{/* source:cpp-io-basic-osyncstream-basic-osyncstream:0005 */}
```cpp
#include <iostream>
#include <string_view>
#include <syncstream>
#include <thread>
 
void worker(const int id, std::ostream &os)
{
    std::string_view block;
    switch (id)
    {
        default: [[fallthrough]];
        case 0: block = "██";
                break;
        case 1: block = "▓▓";
                break;
        case 2: block = "▒▒";
                break;
        case 3: block = "░░";
                break;
    }
    for (int i = 1; i <= 50; ++i)
        os << block << std::flush;
    os << std::endl;
}
 
int main()
{
    std::cout << "Synchronized output should not cause any interference:" << std::endl;
    {
        auto scout1 = std::osyncstream{std::cout};
        auto scout2 = std::osyncstream{std::cout};
        auto scout3 = std::osyncstream{std::cout};
        auto scout4 = std::osyncstream{std::cout};
        auto w1 = std::jthread{worker, 0, std::ref(scout1)};
        auto w2 = std::jthread{worker, 1, std::ref(scout2)};
        auto w3 = std::jthread{worker, 2, std::ref(scout3)};
        auto w4 = std::jthread{worker, 3, std::ref(scout4)};
    }
 
    std::cout << "\nLack of synchronization may cause some interference on output:"
              << std::endl;
    {
        auto w1 = std::jthread{worker, 0, std::ref(std::cout)};
        auto w2 = std::jthread{worker, 1, std::ref(std::cout)};
        auto w3 = std::jthread{worker, 2, std::ref(std::cout)};
        auto w4 = std::jthread{worker, 3, std::ref(std::cout)};
    }
}
```
