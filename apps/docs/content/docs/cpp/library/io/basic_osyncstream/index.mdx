{/* source:cpp-io-basic-osyncstream:0001 */}
The class template `std::basic_osyncstream` is a convenience wrapper for [`std::basic_syncbuf`](/docs/cpp/library/io/basic_syncbuf). It provides a mechanism to synchronize threads writing to the same stream.

{/* source:cpp-io-basic-osyncstream:0002 */}
It can be used with a named variable:

{/* source:cpp-io-basic-osyncstream:0003 */}
```cpp
{
    std::osyncstream synced_out(std::cout); // synchronized wrapper for std::cout
    synced_out << "Hello, ";
    synced_out << "World!";
    synced_out << std::endl; // flush is noted, but not yet performed
    synced_out << "and more!\n";
} // characters are transferred and std::cout is flushed
```

{/* source:cpp-io-basic-osyncstream:0004 */}
as well as with a temporary:

{/* source:cpp-io-basic-osyncstream:0005 */}
```cpp
std::osyncstream(std::cout) << "Hello, " << "World!" << '\n';
```

{/* source:cpp-io-basic-osyncstream:0006 */}
It provides the guarantee that all output made to the same final destination buffer ([`std::cout`](/docs/cpp/library/io/basic_ostream/cout) in the examples above) will be free of data races and will not be interleaved or garbled in any way, as long as every write to that final destination buffer is made through (possibly different) instances of `std::basic_osyncstream`.

{/* source:cpp-io-basic-osyncstream:0007 */}
Typical implementation of `std::basic_osyncstream` holds only one member: the wrapped `std::basic_syncbuf`.
