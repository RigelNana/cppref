{/* source:cpp-io-basic-spanbuf-setbuf:0001 */}
Makes the `basic_spanbuf` perform I/O on the buffer [`s`, `s + n`). Equivalently calls `this->span(std::span<CharT>(s, n))` and then returns `this`.

{/* source:cpp-io-basic-spanbuf-setbuf:0002 */}
| Set bits in open mode (affecting pointers to get area) | Return value after setting [`eback()`](/docs/cpp/library/io/basic_streambuf/gptr) | Return value after setting [`gptr()`](/docs/cpp/library/io/basic_streambuf/gptr) | Return value after setting [`egptr()`](/docs/cpp/library/io/basic_streambuf/gptr) |
| --- | --- | --- | --- |
| `std::ios_base::in` | `s` | `s` | `s + n` |

| Set bits in open mode (affecting pointers to put area) | Return value after setting [`pbase()`](/docs/cpp/library/io/basic_streambuf/pptr) | Return value after setting [`pptr()`](/docs/cpp/library/io/basic_streambuf/pptr) | Return value after setting [`epptr()`](/docs/cpp/library/io/basic_streambuf/pptr) |
| --- | --- | --- | --- |
| `std::ios_base::out && !std::ios_base::ate` | `s` | `s` | `s + n` |
| `std::ios_base::out && std::ios_base::ate` | `s` | `s + n` | `s + n` |

{/* source:cpp-io-basic-spanbuf-setbuf:0003 */}
This function is protected virtual, it may only be called through `pubsetbuf()` or from member functions of a user-defined class derived from `std::basic_spanbuf`.

### Parameters

{/* source:cpp-io-basic-spanbuf-setbuf:0004 */}
<ParameterList>
  <Parameter name="s">pointer to the first `CharT` in the user-provided buffer</Parameter>
  <Parameter name="n">the number of `CharT` elements in the user-provided buffer</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-spanbuf-setbuf:0005 */}
`this`

### Notes

{/* source:cpp-io-basic-spanbuf-setbuf:0006 */}
The deprecated stream buffer [`std::strstreambuf`](/docs/cpp/library/io/strstreambuf) or the boost.IOStreams device [`boost::basic_array`](https://www.boost.org/doc/libs/release/libs/iostreams/doc/classes/array.html#array) can also implement I/O buffering over a user-provided `char` array.
