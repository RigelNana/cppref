  <DeclarationDescription>
    {/* source:cpp-io-basic-spanbuf-basic-spanbuf:0001 */}
    1. Default constructor. Creates a `basic_spanbuf` that has no underlying buffer and is opened for both input and output. The pointers to get and put area are set to the null pointer value.

    {/* source:cpp-io-basic-spanbuf-basic-spanbuf:0002 */}
    2. Same as (1), except that the `basic_spanbuf` is opened in mode specified by `which`.

    {/* source:cpp-io-basic-spanbuf-basic-spanbuf:0003 */}
    3. Creates a `basic_spanbuf` that manages the underlying buffer referenced by `buf` (or has no underlying buffer if `buf` is empty) and is opened in mode specified by `which`. The pointers to get and put area are set as following, or to the null pointer value if not mentioned in the table:

| Set bits in open mode (affecting pointers to get area) | Return value after setting [`eback()`](/docs/cpp/library/io/basic_streambuf/gptr) | Return value after setting [`gptr()`](/docs/cpp/library/io/basic_streambuf/gptr) | Return value after setting [`egptr()`](/docs/cpp/library/io/basic_streambuf/gptr) |
| --- | --- | --- | --- |
| `std::ios_base::in` | `s.data()` | `s.data()` | `s.data() + s.size()` |

| Set bits in open mode (affecting pointers to put area) | Return value after setting [`pbase()`](/docs/cpp/library/io/basic_streambuf/pptr) | Return value after setting [`pptr()`](/docs/cpp/library/io/basic_streambuf/pptr) | Return value after setting [`epptr()`](/docs/cpp/library/io/basic_streambuf/pptr) |
| --- | --- | --- | --- |
| `std::ios_base::out && !std::ios_base::ate` | `s.data()` | `s.data()` | `s.data() + s.size()` |
| `std::ios_base::out && std::ios_base::ate` | `s.data()` | `s.data() + s.size()` | `s.data() + s.size()` |

    {/* source:cpp-io-basic-spanbuf-basic-spanbuf:0004 */}
    4. Copy constructor is deleted. `basic_spanbuf` is not copyable.

    {/* source:cpp-io-basic-spanbuf-basic-spanbuf:0005 */}
    5. Move constructor. Move-constructs the [`std::basic_streambuf`](/docs/cpp/library/io/basic_streambuf) base subobject from that of `rhs`. The pointers to get and put area, the open mode, and the underlying buffer (if any) are identical to those in `rhs` before construction. It is implementation-defined whether `rhs` still holds the underlying buffer after the move-construction.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-io-basic-spanbuf-basic-spanbuf:0006 */}
<ParameterList>
  <Parameter name="buf">a [`std::span`](/docs/cpp/library/container/span) referencing the underlying buffer</Parameter>
  <Parameter name="rhs">another `basic_spanbuf`</Parameter>
  <Parameter name="which">specifies stream open mode. It is bitmask type, the following constants are defined:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`app`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream before each write |
| [`binary`](/docs/cpp/library/io/ios_base/openmode) | open in [binary mode](/docs/cpp/library/io/c/FILE#Binary_and_text_modes) |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | open for reading |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | open for writing |
| [`trunc`](/docs/cpp/library/io/ios_base/openmode) | discard the contents of the stream when opening |
| [`ate`](/docs/cpp/library/io/ios_base/openmode) | seek to the end of stream immediately after open |
| [`noreplace`](/docs/cpp/library/io/ios_base/openmode) <InlineRevision since="C++23" /> | open in exclusive mode |
