{/* source:cpp-io-basic-spanbuf-swap:0001 */}
Swaps the state of `*this` and `rhs`.

{/* source:cpp-io-basic-spanbuf-swap:0002 */}
Calls `std::basic_streambuf<Char, Traits>::swap(rhs)`, swaps the open mode of `*this` and `rhs`, and then makes them use the underlying buffer of each other.

### Parameters

{/* source:cpp-io-basic-spanbuf-swap:0003 */}
<ParameterList>
  <Parameter name="rhs">another `basic_stringbuf`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-io-basic-spanbuf-swap:0004 */}
(none)

### Exceptions

{/* source:cpp-io-basic-spanbuf-swap:0005 */}
May throw implementation-defined exceptions.

### Notes

{/* source:cpp-io-basic-spanbuf-swap:0006 */}
This function is called automatically when swapping stream objects, it is rarely necessary to call it directly.
