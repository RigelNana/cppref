{/* source:cpp-io-basic-spanbuf-seekoff:0001 */}
Repositions the next pointer to get and/or put area, if possible, to the position that corresponds to exactly `off` characters from beginning, end, or current position of the get and/or put area of the buffer.

{/* source:cpp-io-basic-spanbuf-seekoff:0002 */}
Let *n* be the number of `CharT` elements in underlying buffer, or `0` when there is no underlying buffer, this function fails if

{/* source:cpp-io-basic-spanbuf-seekoff:0003 */}
- the next pointer to the get and/or put area to reposition is null and the computed *newoff* (see below) is not zero, which may occur if there is no underlying buffer, or the `*this` is not opened in the mode required by `which`, or
- `dir` is [`std::ios_base::cur`](/docs/cpp/library/io/ios_base/seekdir) and both [`std::ios_base::in`](/docs/cpp/library/io/ios_base/openmode) and [`std::ios_base::out`](/docs/cpp/library/io/ios_base/openmode) are set in `which`, or
- the computed *newoff* is not representable in `off_type`, less than zero, or greater than *n*.

{/* source:cpp-io-basic-spanbuf-seekoff:0004 */}
*newoff* is computed as below:

{/* source:cpp-io-basic-spanbuf-seekoff:0005 */}
- If `dir` is [`std::ios_base::beg`](/docs/cpp/library/io/ios_base/seekdir), *newoff* is `off`.
- If `dir` is [`std::ios_base::cur`](/docs/cpp/library/io/ios_base/seekdir), *newoff* is
  - `pptr() - pbase() + off` if [`std::ios_base::out`](/docs/cpp/library/io/ios_base/openmode) is set in `which`, or
  - `gptr() - eback() + off` if [`std::ios_base::in`](/docs/cpp/library/io/ios_base/openmode) is set in `which`.
- If `dir` is [`std::ios_base::end`](/docs/cpp/library/io/ios_base/seekdir), *newoff* is
  - `pptr() - pbase() + off` if [`std::ios_base::out`](/docs/cpp/library/io/ios_base/openmode) but not [`std::ios_base::in`](/docs/cpp/library/io/ios_base/openmode) is set in the open mode of `*this`,
  - otherwise, `off + n`.

{/* source:cpp-io-basic-spanbuf-seekoff:0006 */}
This function repositions the next pointer to get and/or put area to `pbuf + newoff` on success if [`std::ios_base::in`](/docs/cpp/library/io/ios_base/openmode) and/or [`std::ios_base::out`](/docs/cpp/library/io/ios_base/openmode) is correspondingly set in `which`, where *pbuf* is the pointer to the beginning of the underlying buffer, or the null pointer value if there is no underlying buffer.

### Parameters

{/* source:cpp-io-basic-spanbuf-seekoff:0007 */}
<ParameterList>
  <Parameter name="off">relative position to set the next pointer(s) to</Parameter>
  <Parameter name="dir">defines base position to apply the relative offset to. It can be one of the following constants:</Parameter>
  <Parameter name="which">defines whether the input sequences, the output sequence, or both are affected. It can be one or a combination of the following constants:</Parameter>

| Constant | Explanation |
| --- | --- |
| [`beg`](/docs/cpp/library/io/ios_base/seekdir) | the beginning of a stream |
| [`end`](/docs/cpp/library/io/ios_base/seekdir) | the ending of a stream |
| [`cur`](/docs/cpp/library/io/ios_base/seekdir) | the current position of stream position indicator |

| Constant | Explanation |
| --- | --- |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | affect the input sequence |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | affect the output sequence |

### Return value

{/* source:cpp-io-basic-spanbuf-seekoff:0008 */}
`pos_type(newoff)` on success, `pos_type(off_type(-1))` on failure.
