{/* source:cpp-io-basic-spanbuf-seekpos:0001 */}
Repositions the next pointer to the get and/or put area, if possible, to the position indicated by `sp`.

{/* source:cpp-io-basic-spanbuf-seekpos:0002 */}
Equivalent to `return seekoff(off_type(sp), std::ios_base::beg, which);`.

### Parameters

{/* source:cpp-io-basic-spanbuf-seekpos:0003 */}
<ParameterList>
  <Parameter name="sp">stream position, such as one obtained by `seekoff()` or `seekpos()`</Parameter>
  <Parameter name="which">defines whether the input sequences, the output sequence, or both are affected. It can be one or a combination of the following constants:</Parameter>
</ParameterList>

| Constant | Explanation |
| --- | --- |
| [`in`](/docs/cpp/library/io/ios_base/openmode) | affect the input sequence |
| [`out`](/docs/cpp/library/io/ios_base/openmode) | affect the output sequence |

### Return value

{/* source:cpp-io-basic-spanbuf-seekpos:0004 */}
`sp` on success or `pos_type(off_type(-1))` on failure.

### Notes

{/* source:cpp-io-basic-spanbuf-seekpos:0005 */}
`seekpos()` is called by [`std::basic_streambuf::pubseekpos()`](/docs/cpp/library/io/basic_streambuf/pubseekpos), which is called by the single-argument versions of [`std::basic_istream::seekg()`](/docs/cpp/library/io/basic_istream/seekg) and [`std::basic_ostream::seekp()`](/docs/cpp/library/io/basic_ostream/seekp).
