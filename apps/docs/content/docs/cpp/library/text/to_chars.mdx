  <DeclarationDescription>
    {/* source:cpp-utility-to-chars:0001 */}
    Converts `value` into a character string by successively filling the range `[first, last)`, where `[first, last)` is required to be a [valid range](/docs/cpp/library/iterator#Ranges).

    {/* source:cpp-utility-to-chars:0002 */}
    1. Integer formatters: `value` is converted to a string of digits in the given `base` (with no redundant leading zeroes). Digits in the range `10..35` (inclusive) are represented as lowercase characters `a..z`. If value is less than zero, the representation starts with a minus sign. The library provides overloads for all <InlineRevision since="C++23">cv-unqualified</InlineRevision> signed and unsigned integer types and for the type `char` as the type of the parameter `value`.

    {/* source:cpp-utility-to-chars:0003 */}
    2. Overload for `bool` is deleted. `std::to_chars` rejects argument of type `bool` because the result would be `"0"`/`"1"` but not `"false"`/`"true"` if it is permitted.

    {/* source:cpp-utility-to-chars:0004 */}
    3. `value` is converted to a string as if by [`std::printf`](/docs/cpp/library/io/c/printf) in the default (`"C"`) locale. The conversion specifier is `f` or `e` (resolving in favor of `f` in case of a tie), chosen according to the requirement for a shortest representation: the string representation consists of the smallest number of characters such that there is at least one digit before the radix point (if present) and parsing the representation using the corresponding [`std::from_chars`](/docs/cpp/library/text/from_chars) function recovers `value` exactly. If there are several such representations, one with the smallest difference to `value` is chosen, resolving any remaining ties using rounding according to [`std::round_to_nearest`](/docs/cpp/library/utility/types/numeric_limits/float_round_style). The library provides overloads for all cv-unqualified <InlineRevision until="C++23">standard</InlineRevision> floating-point types as the type of the parameter `value`.

    {/* source:cpp-utility-to-chars:0005 */}
    4. Same as (3), but the conversion specified for the as-if printf is `f` if `fmt` is [`std::chars_format::fixed`](/docs/cpp/library/text/chars_format), `e` if `fmt` is [`std::chars_format::scientific`](/docs/cpp/library/text/chars_format), `a` (but without leading `"0x"` in the result) if `fmt` is [`std::chars_format::hex`](/docs/cpp/library/text/chars_format), and `g` if `fmt` is [`chars_format::general`](/docs/cpp/library/text/chars_format). The library provides overloads for all cv-unqualified <InlineRevision until="C++23">standard</InlineRevision> floating-point types as the type of the parameter `value`.

    {/* source:cpp-utility-to-chars:0006 */}
    5. Same as (4), except the precision is specified by the parameter `precision` rather than by the shortest representation requirement. The library provides overloads for all cv-unqualified <InlineRevision until="C++23">standard</InlineRevision> floating-point types as the type of the parameter `value`.
  </DeclarationDescription>

### Return value

{/* source:cpp-utility-to-chars:0008 */}
On success, returns a value of type [`std::to_chars_result`](/docs/cpp/library/text/to_chars_result) such that `ec` equals value-initialized [`std::errc`](/docs/cpp/library/error/errc) and `ptr` is the one-past-the-end pointer of the characters written. Note that the string is *not* NUL-terminated.

{/* source:cpp-utility-to-chars:0009 */}
On error, returns a value of type [`std::to_chars_result`](/docs/cpp/library/text/to_chars_result) holding [`std::errc::value_too_large`](/docs/cpp/library/error/errc) in `ec`, a copy of the value `last` in `ptr`, and leaves the contents of the range `[first, last)` in unspecified state.

### Exceptions

{/* source:cpp-utility-to-chars:0010 */}
Throws nothing.

### Notes

{/* source:cpp-utility-to-chars:0011 */}
Unlike other formatting functions in C++ and C libraries, `std::to_chars` is locale-independent, non-allocating, and non-throwing. Only a small subset of formatting policies used by other libraries (such as [`std::sprintf`](/docs/cpp/library/io/c/printf)) is provided. This is intended to allow the fastest possible implementation that is useful in common high-throughput contexts such as text-based interchange ([JSON](https://en.wikipedia.org/wiki/JSON) or [XML](https://en.wikipedia.org/wiki/XML)).

{/* source:cpp-utility-to-chars:0012 */}
The guarantee that [`std::from_chars`](/docs/cpp/library/text/from_chars) can recover every floating-point value formatted by `std::to_chars` exactly is only provided if both functions are from the same implementation.

{/* source:cpp-utility-to-chars:0013 */}
It is required to explicitly cast a `bool` value to another integer type if it is wanted to format the value as `"0"`/`"1"`.

### Example

{/* source:cpp-utility-to-chars:0015 */}
```cpp
#include <charconv>
#include <iomanip>
#include <iostream>
#include <string_view>
#include <system_error>
 
void show_to_chars(auto... format_args)
{
    const size_t buf_size = 10;
    char buf[buf_size]{};
    std::to_chars_result result = std::to_chars(buf, buf + buf_size, format_args...);
 
    if (result.ec != std::errc())
        std::cout << std::make_error_code(result.ec).message() << '\n';
    else
    {
        std::string_view str(buf, result.ptr - buf);
        std::cout << std::quoted(str) << '\n';
    }
}
 
int main()
{
    show_to_chars(42);
    show_to_chars(+3.14159F);
    show_to_chars(-3.14159, std::chars_format::fixed);
    show_to_chars(-3.14159, std::chars_format::scientific, 3);
    show_to_chars(3.1415926535, std::chars_format::fixed, 10);
}
```
Possible output:
```text
"42"
"3.14159"
"-3.14159"
"-3.142e+00"
Value too large for defined data type
```
