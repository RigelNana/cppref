{/* source:cpp-text:0000 */}
The text processing library includes components for dealing with text.

{/* source:cpp-text:0001 */}
The headers [`<locale>`](/docs/cpp/library/headers/locale) and [`<clocale>`](/docs/cpp/library/headers/clocale) provide internationalization support for character classification and string collation, numeric, monetary, and date/time formatting and parsing, and message retrieval.

{/* source:cpp-text:0002 */}
The header [`<regex>`](/docs/cpp/library/headers/regex) provides a class that represents [regular expressions](https://en.wikipedia.org/wiki/Regular_expression), which are a kind of mini-language used to perform pattern matching within strings.

{/* source:cpp-text:0003 */}
The header [`<format>`](/docs/cpp/library/headers/format) provides facilities for type-safe and extensible string formatting that is an alternative to the `printf` family of functions, and intended to complement the existing C++ I/O streams library.

{/* source:cpp-text:0004 */}
*Null-terminated character sequences* (NTCTS) are sequences of characters that are terminated by a null character (the value after [value-initialization](/docs/cpp/language/initialization/value_initialization)).

{/* source:cpp-text:0005 */}
The strings library provides functions to create, inspect, and modify such sequences:

{/* source:cpp-text:0006 */}
- [null-terminated byte strings](/docs/cpp/library/text/byte) (NTBS) helper functions (including support of [wide character types](/docs/cpp/library/text/wide)),
- [null-terminated multibyte strings](/docs/cpp/library/text/multibyte) (NTMBS) helper functions.

{/* source:cpp-text:0007 */}
In addition to sophisticated locale-dependent parsers and formatters provided by the [C++ I/O](/docs/cpp/library/io) library, the [C I/O](/docs/cpp/library/io/c) library, [C++ string converters](/docs/cpp/library/string/basic_string#Numeric_conversions), and [C string converters](/docs/cpp/library/text/byte#Conversions_to_numeric_formats), the header [`<charconv>`](/docs/cpp/library/headers/charconv) provides light-weight, locale-independent, non-allocating, non-throwing parsers and formatters for arithmetic types.
