`std::from_chars_result` is the return type of [`std::from_chars`](/docs/cpp/library/text/from_chars). It has no base classes, and only has the following members.

### Data members

{/* source:cpp-utility-from-chars-result:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`ptr`</DescriptionTerm>
    <DescriptionBody>a pointer of type `const char*` <br /> (public member object)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`ec`</DescriptionTerm>
    <DescriptionBody>an error code of type [`std::errc`](/docs/cpp/library/error/errc) <br /> (public member object)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Member and friend functions

{/* source:cpp-utility-from-chars-result:0003 */}
#### `operator==(std::from_chars_result)`

<DeclarationDoc>
  <Declaration language="cpp" since="C++20" code={`friend bool operator==( const from_chars_result&,
                        const from_chars_result& ) = default;`} />
</DeclarationDoc>

Compares the two arguments using [default comparisons](/docs/cpp/language/expressions/default_comparisons) (which uses `operator==` to compare `ptr` and `ec` respectively).

This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::from_chars_result` is an associated class of the arguments.

The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

{/* source:cpp-utility-from-chars-result:0004 */}
#### `operator bool`

<DeclarationDoc>
  <Declaration language="cpp" since="C++26" code={`constexpr explicit operator bool() const noexcept;`} />
</DeclarationDoc>

Checks whether the conversion is successful. Returns `ec == std::errc{}`.

### Example

{/* source:cpp-utility-from-chars-result:0006 */}
```cpp
#include <cassert>
#include <charconv>
#include <iomanip>
#include <iostream>
#include <optional>
#include <string_view>
#include <system_error>
 
int main()
{
    for (std::string_view const str : {"1234", "15 foo", "bar", " 42", "5000000000"})
    {
        std::cout << "String: " << std::quoted(str) << ". ";
        int result{};
        auto [ptr, ec] = std::from_chars(str.data(), str.data() + str.size(), result);
 
        if (ec == std::errc())
            std::cout << "Result: " << result << ", ptr -> " << std::quoted(ptr) << '\n';
        else if (ec == std::errc::invalid_argument)
            std::cout << "This is not a number.\n";
        else if (ec == std::errc::result_out_of_range)
            std::cout << "This number is larger than an int.\n";
    }
 
    // C++23's constexpr from_char demo / C++26's operator bool() demo:
    auto to_int = [](std::string_view s) -> std::optional<int>
    {
        int value{};
#if __cpp_lib_to_chars >= 202306L
        if (std::from_chars(s.data(), s.data() + s.size(), value))
#else
        if (std::from_chars(s.data(), s.data() + s.size(), value).ec == std::errc{})
#endif
            return value;
        else
            return std::nullopt;
    };
 
    assert(to_int("42") == 42);
    assert(to_int("foo") == std::nullopt);
#if __cpp_lib_constexpr_charconv and __cpp_lib_optional >= 202106
    static_assert(to_int("42") == 42);
    static_assert(to_int("foo") == std::nullopt);
#endif
}
```
Output:
```text
String: "1234". Result: 1234, ptr -> ""
String: "15 foo". Result: 15, ptr -> " foo"
String: "bar". This is not a number.
String: " 42". This is not a number.
String: "5000000000". This number is larger than an int.
```
