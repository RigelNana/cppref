{/* source:cpp-utility-format-visit-format-arg:0001 */}
Applies the visitor `vis` to the object contained in `arg`.

{/* source:cpp-utility-format-visit-format-arg:0002 */}
Equivalent to `std::visit(std::forward<Visitor>(vis), value)`, where `value` is the [`std::variant`](/docs/cpp/library/utility/variant) stored in `arg`.

### Parameters

{/* source:cpp-utility-format-visit-format-arg:0003 */}
<ParameterList>
  <Parameter name="vis">a [`Callable`](/docs/cpp/library/named_req/Callable) that accepts every possible alternative from `arg`</Parameter>
  <Parameter name="arg">a [`std::basic_format_arg`](/docs/cpp/library/text/format/basic_format_arg) to be visited</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-format-visit-format-arg:0004 */}
The value returned by the selected invocation of the visitor.

### Notes

{/* source:cpp-utility-format-visit-format-arg:0005 */}
As of C++26, `std::visit_format_arg` is deprecated in favor of the `visit` member functions of [`std::basic_format_arg`](/docs/cpp/library/text/format/basic_format_arg).
