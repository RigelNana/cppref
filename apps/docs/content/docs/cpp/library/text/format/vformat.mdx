{/* source:cpp-utility-format-vformat:0001 */}
Format arguments held by `args` according to the format string `fmt`, and return the result as a string. If present, `loc` is used for locale-specific formatting.

### Parameters

{/* source:cpp-utility-format-vformat:0002 */}
<ParameterList>
  <Parameter name="fmt">
an object that represents the format string. The format string consists of

- ordinary characters (except `{` and `}`), which are copied unchanged to the output,
- escape sequences `{{` and `}}`, which are replaced with `{` and `}` respectively in the output, and
- replacement fields.
</Parameter>
</ParameterList>

Each replacement field has the following format:

| | |
| --- | --- |
| `{` *arg-id* `(optional)` `}` | (1) |
| `{` *arg-id* `(optional)` `:` *format-spec* `}` | (2) |

1. replacement field without a format specification
2. replacement field with a format specification

<ParameterList>
  <Parameter name="arg-id">specifies the index of the argument in `args` whose value is to be used for formatting; if it is omitted, the arguments are used in order. The `arg-id`s in a format string must all be present or all be omitted. Mixing manual and automatic indexing is an error.</Parameter>
  <Parameter name="format-spec">the format specification defined by the [`std::formatter`](/docs/cpp/library/text/format/formatter) specialization for the corresponding argument. Cannot start with `}`.</Parameter>
</ParameterList>

- For basic types and standard string types, the format specification is interpreted as [standard format specification](/docs/cpp/library/text/format/spec).
- For chrono types, the format specification is interpreted as [chrono format specification](/docs/cpp/library/chrono/system_clock/formatter#Format_specification).

<Revision since="C++23">
- For range types, the format specification is interpreted as [range format specification](/docs/cpp/library/text/format/range_formatter#Range_format_specification).
- For [`std::pair`](/docs/cpp/library/utility/pair) and [`std::tuple`](/docs/cpp/library/utility/tuple), the format specification is interpreted as [tuple format specification](/docs/cpp/library/text/format/tuple_formatter#Format_specification).
- For [`std::thread::id`](/docs/cpp/library/thread/thread/id) and [`std::stacktrace_entry`](/docs/cpp/library/error/stacktrace_entry), see [thread id format specification](/docs/cpp/library/thread/thread/id/formatter#Format_specification) and [stacktrace entry format specification](/docs/cpp/library/error/stacktrace_entry/formatter#Format_specification).
- For [`std::basic_stacktrace`](/docs/cpp/library/error/basic_stacktrace), no format specifier is allowed.
</Revision>

<Revision since="C++26">
- For [`std::filesystem::path`](/docs/cpp/library/filesystem/path), see [path format specification](/docs/cpp/library/filesystem/path/formatter#Format_specification).
</Revision>

For other formattable types, the format specification is determined by user-defined `formatter` specializations.

<ParameterList>
  <Parameter name="args">arguments to be formatted</Parameter>
  <Parameter name="loc">[`std::locale`](/docs/cpp/library/text/locale/locale) used for locale-specific formatting</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-format-vformat:0003 */}
A string object holding the formatted result.

### Exceptions

{/* source:cpp-utility-format-vformat:0004 */}
Throws [`std::format_error`](/docs/cpp/library/text/format/format_error) if `fmt` is not a valid format string for the provided arguments, or [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) on allocation failure. Also propagates any exception thrown by formatter or iterator operations.

### Example

{/* source:cpp-utility-format-vformat:0005 */}
```cpp
#include <format>
#include <iostream>

template<typename... Args>
inline void println(const std::format_string<Args...> fmt, Args&&... args)
{
    std::cout << std::vformat(fmt.get(), std::make_format_args(args...)) << '\n';
}

int main()
{
    println("{}{} {}{}", "Hello", ',', "C++", -1 + 2 * 3 * 4);
}
```

Output:

```text
Hello, C++23
```
