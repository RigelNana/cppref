{/* source:cpp-utility-format-format-to-n:0001 */}
Format `args` according to the format string `fmt`, and write the result to the output iterator `out`. At most `n` characters are written. If present, `loc` is used for locale-specific formatting.

{/* source:cpp-utility-format-format-to-n:0002 */}
Let `CharT` be `char` for overloads (1,3), `wchar_t` for overloads (2,4).

{/* source:cpp-utility-format-format-to-n:0003 */}
These overloads participate in overload resolution only if `OutputIt` satisfies the concept `std::output_iterator<const CharT&>`.

{/* source:cpp-utility-format-format-to-n:0004 */}
The behavior is undefined if `OutputIt` does not model (meet the semantic requirements of) the concept `std::output_iterator<const CharT&>`, or if `std::formatter<std::remove_cvref_t<Ti>, CharT>` does not meet the [*BasicFormatter*](/docs/cpp/library/named_req/BasicFormatter) requirements for any `Ti` in `Args`.

{/* source:cpp-utility-format-format-to-n:0005 */}
5. `std::format_to_n_result` has no base classes, or members other than `out`, `size` and implicitly declared special member functions.

### Parameters

{/* source:cpp-utility-format-format-to-n:0006 */}
<ParameterList>
  <Parameter name="out">iterator to the output buffer</Parameter>
  <Parameter name="n">maximum number of characters to be written to the buffer</Parameter>
  <Parameter name="fmt">
an object that represents the format string. The format string consists of

- ordinary characters (except `{` and `}`), which are copied unchanged to the output,
- escape sequences `{{` and `}}`, which are replaced with `{` and `}` respectively in the output, and
- replacement fields.
</Parameter>
</ParameterList>

Each replacement field has the following format:

| | |
| --- | --- |
| `{` *arg-id* `(optional)` `}` | (1) |
| `{` *arg-id* `(optional)` `:` *format-spec* `}` | (2) |

1. replacement field without a format specification
2. replacement field with a format specification

<ParameterList>
  <Parameter name="arg-id">specifies the index of the argument in `args` whose value is to be used for formatting; if it is omitted, the arguments are used in order. The `arg-id`s in a format string must all be present or all be omitted. Mixing manual and automatic indexing is an error.</Parameter>
  <Parameter name="format-spec">the format specification defined by the [`std::formatter`](/docs/cpp/library/text/format/formatter) specialization for the corresponding argument. Cannot start with `}`.</Parameter>
</ParameterList>

- For basic types and standard string types, the format specification is interpreted as [standard format specification](/docs/cpp/library/text/format/spec).
- For chrono types, the format specification is interpreted as [chrono format specification](/docs/cpp/library/chrono/system_clock/formatter#Format_specification).

<Revision since="C++23">
- For range types, the format specification is interpreted as [range format specification](/docs/cpp/library/text/format/range_formatter#Range_format_specification).
- For [`std::pair`](/docs/cpp/library/utility/pair) and [`std::tuple`](/docs/cpp/library/utility/tuple), the format specification is interpreted as [tuple format specification](/docs/cpp/library/text/format/tuple_formatter#Format_specification).
- For [`std::thread::id`](/docs/cpp/library/thread/thread/id) and [`std::stacktrace_entry`](/docs/cpp/library/error/stacktrace_entry), see [thread id format specification](/docs/cpp/library/thread/thread/id/formatter#Format_specification) and [stacktrace entry format specification](/docs/cpp/library/error/stacktrace_entry/formatter#Format_specification).
- For [`std::basic_stacktrace`](/docs/cpp/library/error/basic_stacktrace), no format specifier is allowed.
</Revision>

<Revision since="C++26">
- For [`std::filesystem::path`](/docs/cpp/library/filesystem/path), see [path format specification](/docs/cpp/library/filesystem/path/formatter#Format_specification).
</Revision>

For other formattable types, the format specification is determined by user-defined `formatter` specializations.

<ParameterList>
  <Parameter name="args">arguments to be formatted</Parameter>
  <Parameter name="loc">[`std::locale`](/docs/cpp/library/text/locale/locale) used for locale-specific formatting</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-format-format-to-n:0007 */}
A `format_to_n_result` such that the `out` member is an iterator past the end of the output range, and the `size` member is the total (not truncated) output size.

### Exceptions

{/* source:cpp-utility-format-format-to-n:0008 */}
Propagates any exception thrown by formatter or iterator operations.

### Notes

{/* source:cpp-utility-format-format-to-n:0009 */}
The libstdc++ implementation prior to GCC-13.3 had a [bug](https://gcc.gnu.org/bugzilla/show_bug.cgi?id=110990) in reporting the correct `format_to_n_result::out` value.

### Example

{/* source:cpp-utility-format-format-to-n:0010 */}
At Godbolt's Compiler Explorer: [clang (trunk) + libc++](https://godbolt.org/z/s7a5d76ET), [GCC (trunk) + libstdc++](https://godbolt.org/z/bdvxnPb1T).

```cpp
#include <format>
#include <initializer_list>
#include <iomanip>
#include <iostream>
#include <string_view>

int main()
{
    char buffer[64];

    for (std::size_t max_chars_to_write : {std::size(buffer) - 1, 23uz, 21uz})
    {
        const std::format_to_n_result result =
            std::format_to_n(
                buffer, max_chars_to_write,
                "Hubble's H{2} {3} {0}{4}{1} km/sec/Mpc.", // 24 bytes w/o formatters
                71,       // {0}, occupies 2 bytes
                8,        // {1}, occupies 1 byte
                "\u2080", // {2}, occupies 3 bytes, '₀' (SUBSCRIPT ZERO)
                "\u2245", // {3}, occupies 3 bytes, '≅' (APPROXIMATELY EQUAL TO)
                "\u00B1"  // {4}, occupies 2 bytes, '±' (PLUS-MINUS SIGN)
                ); // 24 + 2 + 1 + 3 + 3 + 2 == 35, no trailing '\0'

        *result.out = '\0'; // adds terminator to buffer

        const std::string_view str(buffer, result.out);

        std::cout << "Buffer until '\\0': " << std::quoted(str) << '\n'
                  << "Max chars to write: " << max_chars_to_write << '\n'
                  << "result.out offset: " << result.out - buffer << '\n'
                  << "Untruncated output size: " << result.size << "\n\n";
    }
}
```

Output:

```text
Buffer until '\0': "Hubble's H₀ ≅ 71±8 km/sec/Mpc."
Max chars to write: 63
result.out offset: 35
Untruncated output size: 35

Buffer until '\0': "Hubble's H₀ ≅ 71±8"
Max chars to write: 23
result.out offset: 23
Untruncated output size: 35

Buffer until '\0': "Hubble's H₀ ≅ 71�"
Max chars to write: 21
result.out offset: 21
Untruncated output size: 35
```
