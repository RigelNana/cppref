{/* source:cpp-utility-format-range-format:0001 */}
Specifies how a range should be formatted.

### Constants

{/* source:cpp-utility-format-range-format:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`disabled`</DescriptionTerm>
    <DescriptionBody>disallows range default formatter to format range</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`map`</DescriptionTerm>
    <DescriptionBody>allows to format range as map representation with modified brackets `"{"`, `"}"` and separator `": "` for underlying [*pair-like*](/docs/cpp/library/utility/tuple/tuple-like) types in the following format:<br />\{ *key-1* : *value-1*, ..., *key-n* : *value-n* \}</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`set`</DescriptionTerm>
    <DescriptionBody>allows to format range as set representation with modified brackets `"{"` and `"}"` in the following format:<br />\{ *key-1*, ..., *key-n* \}</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`sequence`</DescriptionTerm>
    <DescriptionBody>allows to format range as sequence representation with default brackets `"["`, `"]"` and separator `", "` in the following format:<br />[ *element-1*, ..., *element-n* ]</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`string`</DescriptionTerm>
    <DescriptionBody>allows to format range as string</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`debug_string`</DescriptionTerm>
    <DescriptionBody>allows to format range as escaped string</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
