{/* source:cpp-utility-format-format:0001 */}
Format `args` according to the format string `fmt`, and return the result as a string. If present, `loc` is used for locale-specific formatting.

{/* source:cpp-utility-format-format:0002 */}
1. Equivalent to `return std::vformat(fmt.get(), std::make_format_args(args...));`.

{/* source:cpp-utility-format-format:0003 */}
2. Equivalent to `return std::vformat(fmt.get(), std::make_wformat_args(args...));`.

{/* source:cpp-utility-format-format:0004 */}
3. Equivalent to `return std::vformat(loc, fmt.get(), std::make_format_args(args...));`.

{/* source:cpp-utility-format-format:0005 */}
4. Equivalent to `return std::vformat(loc, fmt.get(), std::make_wformat_args(args...));`.

### Notes

{/* source:cpp-utility-format-format:0006 */}
Since [P2216R3](https://wg21.link/P2216R3), `std::format` does a compile-time check on the format string (via the helper type `std::format_string` or `std::wformat_string`). If it is found to be invalid for the types of the arguments to be formatted, a compilation error will be emitted. If the format string cannot be a compile-time constant, or the compile-time check needs to be avoided, use [`std::vformat`](/docs/cpp/library/text/format/vformat)<InlineRevision since="C++26"> or [`std::runtime_format`](/docs/cpp/library/text/format/runtime_format) on `fmt`</InlineRevision> instead.

{/* source:cpp-utility-format-format:0007 */}
The following requirements apply to each type `T` in `Args`, where `CharT` is `char` for overloads (1,3), `wchar_t` for overloads (2,4):

{/* source:cpp-utility-format-format:0008 */}
- `std::formatter<T, CharT>` must satisfy [*BasicFormatter*](/docs/cpp/library/named_req/BasicFormatter)
- `std::formatter<T, CharT>::parse()` must be `constexpr` since [P2216R3](https://wg21.link/P2216R3) ([`std::vformat`](/docs/cpp/library/text/format/vformat) does not have this requirement)

### Parameters

{/* source:cpp-utility-format-format:0009 */}
<ParameterList>
  <Parameter name="fmt">
an object that represents the format string. The format string consists of

- ordinary characters (except `{` and `}`), which are copied unchanged to the output,
- escape sequences `{{` and `}}`, which are replaced with `{` and `}` respectively in the output, and
- replacement fields.
</Parameter>
</ParameterList>

Each replacement field has the following format:

| | |
| --- | --- |
| `{` *arg-id* `(optional)` `}` | (1) |
| `{` *arg-id* `(optional)` `:` *format-spec* `}` | (2) |

1. replacement field without a format specification
2. replacement field with a format specification

<ParameterList>
  <Parameter name="arg-id">specifies the index of the argument in `args` whose value is to be used for formatting; if it is omitted, the arguments are used in order. The `arg-id`s in a format string must all be present or all be omitted. Mixing manual and automatic indexing is an error.</Parameter>
  <Parameter name="format-spec">the format specification defined by the [`std::formatter`](/docs/cpp/library/text/format/formatter) specialization for the corresponding argument. Cannot start with `}`.</Parameter>
</ParameterList>

- For basic types and standard string types, the format specification is interpreted as [standard format specification](/docs/cpp/library/text/format/spec).
- For chrono types, the format specification is interpreted as [chrono format specification](/docs/cpp/library/chrono/system_clock/formatter#Format_specification).

<Revision since="C++23">
- For range types, the format specification is interpreted as [range format specification](/docs/cpp/library/text/format/range_formatter#Range_format_specification).
- For [`std::pair`](/docs/cpp/library/utility/pair) and [`std::tuple`](/docs/cpp/library/utility/tuple), the format specification is interpreted as [tuple format specification](/docs/cpp/library/text/format/tuple_formatter#Format_specification).
- For [`std::thread::id`](/docs/cpp/library/thread/thread/id) and [`std::stacktrace_entry`](/docs/cpp/library/error/stacktrace_entry), see [thread id format specification](/docs/cpp/library/thread/thread/id/formatter#Format_specification) and [stacktrace entry format specification](/docs/cpp/library/error/stacktrace_entry/formatter#Format_specification).
- For [`std::basic_stacktrace`](/docs/cpp/library/error/basic_stacktrace), no format specifier is allowed.
</Revision>

<Revision since="C++26">
- For [`std::filesystem::path`](/docs/cpp/library/filesystem/path), see [path format specification](/docs/cpp/library/filesystem/path/formatter#Format_specification).
</Revision>

For other formattable types, the format specification is determined by user-defined `formatter` specializations.

<ParameterList>
  <Parameter name="args">arguments to be formatted</Parameter>
  <Parameter name="loc">[`std::locale`](/docs/cpp/library/text/locale/locale) used for locale-specific formatting</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-format-format:0010 */}
A string object holding the formatted result.

### Exceptions

{/* source:cpp-utility-format-format:0011 */}
Throws [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) on allocation failure. Also propagates exception thrown by any formatter.

### Notes

{/* source:cpp-utility-format-format:0012 */}
It is not an error to provide more arguments than the format string requires:

{/* source:cpp-utility-format-format:0013 */}
```cpp
std::format("{} {}!", "Hello", "world", "something"); // OK, produces "Hello world!"
```

{/* source:cpp-utility-format-format:0014 */}
As of [P2216R3](https://wg21.link/P2216R3), it is an error if the format string is not a constant expression. [`std::vformat`](/docs/cpp/library/text/format/vformat) can be used in this case.

{/* source:cpp-utility-format-format:0015 */}
```cpp
std::string f(std::string_view runtime_format_string)
{
    // return std::format(runtime_format_string, "foo", "bar"); // error
    return std::vformat(runtime_format_string, std::make_format_args("foo", "bar")); // OK
}
```

{/* source:cpp-utility-format-format:0016 */}
<Revision since="C++26">
`std::runtime_format` can be used directly on `std::format` instead of `std::vformat` which requires [`std::basic_format_args`](/docs/cpp/library/text/format/basic_format_args) as an argument.

```cpp
std::string f(std::string_view runtime_format_string)
{
    return std::format(std::runtime_format(runtime_format_string), "foo", "bar");
}
```
</Revision>

### Example

{/* source:cpp-utility-format-format:0017 */}
```cpp
#include <format>
#include <iostream>
#include <string>
#include <string_view>

template<typename... Args>
std::string dyna_print(std::string_view rt_fmt_str, Args&&... args)
{
    return std::vformat(rt_fmt_str, std::make_format_args(args...));
}

int main()
{
    std::cout << std::format("Hello {}!\n", "world");

    std::string fmt;
    for (int i{}; i != 3; ++i)
    {
        fmt += "{} "; // constructs the formatting string
        std::cout << fmt << " : ";
        std::cout << dyna_print(fmt, "alpha", 'Z', 3.14, "unused");
        std::cout << '\n';
    }
}
```

Output:

```text
Hello world!
{}  : alpha
{} {}  : alpha Z
{} {} {}  : alpha Z 3.14
```
