{/* source:cpp-utility-format-tuple-formatter:0001 */}
The template specialization of [`std::formatter`](/docs/cpp/library/text/format/formatter) for the [`std::pair`](/docs/cpp/library/utility/pair) and [`std::tuple`](/docs/cpp/library/utility/tuple) allows users to convert a pair or a tuple to its textual representation as a collection of elements using [formatting functions](/docs/cpp/library/text/format).

{/* source:cpp-utility-format-tuple-formatter:0002 */}
The exposition-only name `/*pair-or-tuple*/` denotes either class template [`std::pair`](/docs/cpp/library/utility/pair) or [`std::tuple`](/docs/cpp/library/utility/tuple).

{/* source:cpp-utility-format-tuple-formatter:0003 */}
This specialization meets the [*Formatter*](/docs/cpp/library/named_req/Formatter) requirements if `(std::formattable<const Ts, CharT> && ...)` is `true`. It always meets the [*BasicFormatter*](/docs/cpp/library/named_req/BasicFormatter) requirements.

### Format specification

{/* source:cpp-utility-format-tuple-formatter:0004 */}
The syntax of *tuple-format-spec* is:

{/* source:cpp-utility-format-tuple-formatter:0005 */}
| | |
| --- | --- |
| *tuple-fill-and-align* `(optional)` *width* `(optional)` *tuple-type* `(optional)` | |

{/* source:cpp-utility-format-tuple-formatter:0006 */}
The *tuple-fill-and-align* is interpreted the same way as a *fill-and-align* except that the *fill* in *tuple-fill-and-align* is any character other than `{`, `}`, or `:`.

{/* source:cpp-utility-format-tuple-formatter:0007 */}
The *width* is described in [standard format width specification](/docs/cpp/library/text/format/spec#Width_and_precision).

{/* source:cpp-utility-format-tuple-formatter:0008 */}
The *tuple-type* changes the way a tuple is formatted, with certain options only valid with certain argument types.

{/* source:cpp-utility-format-tuple-formatter:0009 */}
The available tuple presentation types are:

{/* source:cpp-utility-format-tuple-formatter:0010 */}
- `m`: Indicates that both opening and closing brackets should be `""` while the separator should be `": "`.

{/* source:cpp-utility-format-tuple-formatter:0011 */}
  If `m` is chosen as the *tuple-type*, the program is ill-formed unless `sizeof...(Ts) == 2` is `true`.

{/* source:cpp-utility-format-tuple-formatter:0012 */}
- `n`: Indicates that separator, opening and closing brackets should be `""`.

#### `std::formatter<pair-or-tuple>::parse`

<DeclarationDoc>
  <Declaration language="cpp" code={`template< class ParseContext >
constexpr auto parse( ParseContext& ctx ) -> ParseContext::iterator;`} />
</DeclarationDoc>

Parses the format specifiers as a *tuple-format-spec* and stores the parsed specifiers in the current object.

If *tuple-type* or the `n` option is present, the values of `opening-bracket`, `closing-bracket`, and `separator` are modified as required.

For each element `e` in `underlying_`, calls `e.parse(ctx)` to parse an empty *format-spec* and, if `e.set_debug_format()` is a valid expression, calls `e.set_debug_format()`.

Returns an iterator past the end of the *tuple-format-spec*.

{/* source:cpp-utility-format-tuple-formatter:0018 */}
#### `std::formatter<pair-or-tuple>::format`

<DeclarationDoc>
  <Declaration language="cpp" code={`template< class FormatContext >
FormatContext::iterator

format( /*maybe-const-pair-or-tuple*/<Ts...>& elems, FormatContext& ctx ) const;`} />
</DeclarationDoc>

`/*maybe-const-pair-or-tuple*/` denotes:

- `const /*pair-or-tuple*/`, if `(std::formattable<const Ts, CharT> && ...)` is `true`,
- `/*pair-or-tuple*/` otherwise.

Writes the following into `ctx.out()` as specified by *tuple-format-spec*, in order:

- `opening-bracket_`,
- for each index `I` in `[0, sizeof...(Ts))`:
  - if `I != 0`, `separator_`,
  - the result of writing `std::get<I>(elems)` via `std::get<I>(underlying_)`, and
- `closing-bracket_`.

Returns an iterator past the end of the output range.
