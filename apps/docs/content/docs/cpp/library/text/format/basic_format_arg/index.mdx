{/* source:cpp-utility-format-basic-format-arg:0001 */}
Provides access to a formatting argument.

{/* source:cpp-utility-format-basic-format-arg:0002 */}
`basic_format_arg` objects are typically created by [`std::make_format_args`](/docs/cpp/library/text/format/make_format_args) and accessed through [`std::visit_format_arg`](/docs/cpp/library/text/format/visit_format_arg)<InlineRevision since="C++26"> or the `visit` member functions</InlineRevision>.

{/* source:cpp-utility-format-basic-format-arg:0003 */}
A `basic_format_arg` object behaves as if it stores a [`std::variant`](/docs/cpp/library/utility/variant) of the following types:

{/* source:cpp-utility-format-basic-format-arg:0004 */}
- `std::monostate` (only if the object was default-constructed)
- `bool`
- `Context::char_type`
- `int`
- `unsigned int`
- `long long int`
- `unsigned long long int`
- `float`
- `double`
- `long double`
- `const Context::char_type*`
- `std::basic_string_view<Context::char_type>`
- `const void*`
- `basic_format_arg::handle`

#### `std::basic_format_arg::basic_format_arg`

<DeclarationDoc>
  <Declaration language="cpp" since="C++20" code={`basic_format_arg() noexcept;`} />
</DeclarationDoc>

Default constructor. Constructs a `basic_format_arg` that does not hold a formatting argument. The stored object has type [`std::monostate`](/docs/cpp/library/utility/variant/monostate). To create a `basic_format_arg` that holds a formatting argument, [`std::make_format_args`](/docs/cpp/library/text/format/make_format_args) has to be used.

{/* source:cpp-utility-format-basic-format-arg:0009 */}
#### `std::basic_format_arg::operator bool`

<DeclarationDoc>
  <Declaration language="cpp" since="C++20" code={`explicit operator bool() const noexcept;`} />
</DeclarationDoc>

Checks whether `*this` holds a formatting argument. Returns `true` if `*this` holds a formatting argument (i.e. the stored object does not have type `std::monostate`), `false` otherwise.

{/* source:cpp-utility-format-basic-format-arg:0010 */}
#### `std::basic_format_arg::visit`

<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++26" code={`template< class Visitor >
decltype(auto) visit( this basic_format_arg arg, Visitor&& vis );`} />
  <Declaration id="2" language="cpp" since="C++26" code={`template< class R, class Visitor >
R visit( this basic_format_arg arg, Visitor&& vis );`} />

  <DeclarationDescription>
    Applies the visitor `vis` to the object contained in `arg`. The `visit` functions do not modify the `basic_format_arg` object on which it is called because a copy of the object is used when calling `vis`.

    1. Equivalent to `return std::visit(std::forward<Visitor>(vis), v);`, where `v` is the [`std::variant`](/docs/cpp/library/utility/variant) stored in `arg`.
    2. Equivalent to `return std::visit<R>(std::forward<Visitor>(vis), v);`, where `v` is the [`std::variant`](/docs/cpp/library/utility/variant) stored in `arg`.
  </DeclarationDescription>
</DeclarationDoc>
