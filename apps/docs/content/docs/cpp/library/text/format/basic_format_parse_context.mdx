{/* source:cpp-utility-format-basic-format-parse-context:0001 */}
Provides access to the format string parsing state consisting of the format string range being parsed and the argument counter for automatic indexing.

{/* source:cpp-utility-format-basic-format-parse-context:0002 */}
A `std::basic_format_parse_context` instance is passed to [*Formatter*](/docs/cpp/library/named_req/Formatter) when parsing the format specification.

{/* source:cpp-utility-format-basic-format-parse-context:0003 */}
A program that declares an explicit or partial specialization of `std::basic_format_parse_context` is ill-formed, no diagnostic required.

#### `std::basic_format_parse_context::advance_to`

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr void advance_to( const_iterator it );`} />
</DeclarationDoc>

Sets the beginning of the format string range to `it`. After a call to `advance_to()`, subsequent calls to `begin()` will return a copy of `it`. The behavior is undefined if `end()` is not [reachable](/docs/cpp/library/iterator#Ranges) from `it`.

{/* source:cpp-utility-format-basic-format-parse-context:0012 */}
#### `std::basic_format_parse_context::next_arg_id`

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr std::size_t next_arg_id();`} />
</DeclarationDoc>

Enters automatic argument indexing mode, and returns the next argument index, starting from 0. If `*this` has already entered manual argument indexing mode, throws [`std::format_error`](/docs/cpp/library/text/format/format_error). If the next argument index is larger than or equal to the `num_args` provided in the constructor, the call is not a core constant expression.

{/* source:cpp-utility-format-basic-format-parse-context:0013 */}
#### `std::basic_format_parse_context::check_arg_id`

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr void check_arg_id( std::size_t id );`} />
</DeclarationDoc>

Enters manual argument indexing mode. If `*this` has already entered automatic argument indexing mode, throws [`std::format_error`](/docs/cpp/library/text/format/format_error). If `id` is larger than or equal to the `num_args` provided in the constructor, the call is not a core constant expression.

{/* source:cpp-utility-format-basic-format-parse-context:0014 */}
#### `std::basic_format_parse_context::check_dynamic_spec`

<DeclarationDoc>
  <Declaration language="cpp" since="C++26" code={`template< class... Ts >
constexpr void check_dynamic_spec( std::size_t id ) noexcept;`} />
</DeclarationDoc>

If `id` is larger than or equal to the `num_args` provided in the constructor or the type of the corresponding format argument (after conversion to [`std::basic_format_arg`](/docs/cpp/library/text/format/basic_format_arg)) is not one of the types in `Ts...`, the call is not a core constant expression. A call to `check_dynamic_spec` has no effect at runtime. The program is ill-formed unless `sizeof...(Ts) >= 1`, the types in `Ts...` are unique, and each type is one of `bool`, `char_type`, `int`, `unsigned int`, `long long int`, `unsigned long long int`, `float`, `double`, `long double`, `const char_type*`, `std::basic_string_view<char_type>`, or `const void*`.

{/* source:cpp-utility-format-basic-format-parse-context:0015 */}
#### `std::basic_format_parse_context::check_dynamic_spec_integral`

<DeclarationDoc>
  <Declaration language="cpp" since="C++26" code={`constexpr void check_dynamic_spec_integral( std::size_t id ) noexcept;`} />
</DeclarationDoc>

Equivalent to call `check_dynamic_spec<int, unsigned int, long long int, unsigned long long int>(id)`. A call to `check_dynamic_spec_integral` has no effect at runtime.
