{/* source:cpp-utility-format-ranges-formatter-range-default-formatter-set:0001 */}
The class template `/*range-default-formatter*/` for range types is specialized for formatting range as a set of keys if `std::format_kind<R>` is `std::range_format::set`.

#### `std::range-default-formatter<std::range_format::set>::range-default-formatter`

<DeclarationDoc>
  <Declaration language="cpp" code={`constexpr /*range-default-formatter*/();`} />
</DeclarationDoc>

Equivalent to a call to `underlying_.set_brackets(STATICALLY_WIDEN<CharT>("{"), STATICALLY_WIDEN<CharT>("}"))` where `STATICALLY_WIDEN<CharT>("...")` is `"..."` if `CharT` is `char`, and `L"..."` if `CharT` is `wchar_t`.

{/* source:cpp-utility-format-ranges-formatter-range-default-formatter-set:0006 */}
