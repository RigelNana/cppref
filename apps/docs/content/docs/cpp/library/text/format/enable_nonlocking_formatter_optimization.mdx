{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0001 */}
This template can be used by implementations to enable efficient implementations of [`std::print`](/docs/cpp/library/io/print) and [`std::println`](/docs/cpp/library/io/println).

{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0002 */}
If `std::enable_nonlocking_formatter_optimization<T>` is `true`, printing an argument of type `T` can be performed in a more efficient way (see [`std::print`](/docs/cpp/library/io/print) for details). `std::enable_nonlocking_formatter_optimization` specializations can be `true` in the following cases:

{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0003 */}
- `T` is one of the types where [`std::formatter`](/docs/cpp/library/text/format/formatter)`<T, CharT>` is a [basic standard specialization](/docs/cpp/library/text/format/formatter#Basic_standard_specializations) or [standard specialization for a library type](/docs/cpp/library/text/format/formatter#Standard_specializations_for_library_types) (see below).
- A program may specialize this template for any cv-unqualified [program-defined type](/docs/cpp/language/basic_concepts/type-id#Program-defined_type) `T`. Such specializations must be [usable in constant expressions](/docs/cpp/language/expressions/constant_expression#Usable_in_constant_expressions) and have type `const bool`.

### Basic standard specializations

{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0004 */}
In the following list, `CharT` is either `char` or `wchar_t`, `ArithmeticT` is any cv-unqualified arithmetic type other than `char`, `wchar_t`, `char8_t`, `char16_t`, or `char32_t`:

### Standard specializations for library types

{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0006 */}
Specializations of `enable_nonlocking_formatter_optimization` for all specializations of the following standard templates are defined as `true`:

{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0007 */}
- [`std::chrono::zoned_time`](/docs/cpp/library/chrono/zoned_time) when its template parameter type `TimeZonePtr` is `const std::chrono::time_zone*`

{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0008 */}
Specializations of `enable_nonlocking_formatter_optimization` for all specializations of the following standard templates are defined as conditionally `true`:

{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0009 */}
- [`std::pair`](/docs/cpp/library/utility/pair)
- [`std::tuple`](/docs/cpp/library/utility/tuple)
- [`std::chrono::duration`](/docs/cpp/library/chrono/duration)

{/* source:cpp-utility-format-enable-nonlocking-formatter-optimization:0010 */}
Specialization of `enable_nonlocking_formatter_optimization` for all [formattable range types](/docs/cpp/library/text/format/ranges_formatter) are always defined as `false` for which the range format kind is not `std::range_format::disabled`.
