    Provides access to formatting state consisting of the formatting arguments and the output iterator.

    {/* source:cpp-utility-format-basic-format-context:0002 */}
    2. The unspecified template argument is an output iterator that appends to [`std::string`](/docs/cpp/library/string/basic_string), such as `std::back_insert_iterator<std::string>`. Implementations typically use an iterator to type-erased buffer type that supports appending to any contiguous and resizable container.

    {/* source:cpp-utility-format-basic-format-context:0003 */}
    3. The unspecified template argument is an output iterator that appends to [`std::wstring`](/docs/cpp/library/string/basic_string).
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-utility-format-basic-format-context:0004 */}
The behavior is undefined if `OutputIt` does not model `std::output_iterator<const CharT&>`.

{/* source:cpp-utility-format-basic-format-context:0005 */}
A program that declares an explicit or partial specialization of `std::basic_format_context` is ill-formed, no diagnostic required.

{/* source:cpp-utility-format-basic-format-context:0006 */}
`std::basic_format_context` objects can only be created by the implementation. User codes are only allowed to modify the format context via the `format` function of [`std::formatter`](/docs/cpp/library/text/format/formatter) specializations.

#### `std::basic_format_context::arg`

<DeclarationDoc>
  <Declaration language="cpp" code={`std::basic_format_arg<basic_format_context> arg( std::size_t id ) const;`} />
</DeclarationDoc>

Returns a `std::basic_format_arg` holding the `id`-th argument in `args`, where `args` is the parameter pack or `std::basic_format_args` object passed to the formatting function. If `id` is not less than the number of formatting arguments, returns a default-constructed `std::basic_format_arg` (holding a [`std::monostate`](/docs/cpp/library/utility/variant/monostate) object).

{/* source:cpp-utility-format-basic-format-context:0011 */}
#### `std::basic_format_context::locale`

<DeclarationDoc>
  <Declaration language="cpp" code={`std::locale locale();`} />
</DeclarationDoc>

Returns the [`std::locale`](/docs/cpp/library/text/locale/locale) passed to the formatting function, or a default-constructed `std::locale` if the formatting function does not take a locale.

{/* source:cpp-utility-format-basic-format-context:0012 */}
#### `std::basic_format_context::out`

<DeclarationDoc>
  <Declaration language="cpp" code={`iterator out();`} />
</DeclarationDoc>

Returns the iterator to the output buffer. The result is move-constructed from the stored iterator.

{/* source:cpp-utility-format-basic-format-context:0013 */}
#### `std::basic_format_context::advance_to`

<DeclarationDoc>
  <Declaration language="cpp" code={`void advance_to( iterator it );`} />
</DeclarationDoc>

Move assigns `it` to the stored output iterator. After a call to `advance_to`, the next call to `out()` will return an iterator with the value that `it` had before the assignment.
