{/* source:cpp-utility-format-formatter:0001 */}
The enabled specializations of `std::formatter` define formatting rules for a given type. Enabled specializations meet the [*BasicFormatter*](/docs/cpp/library/named_req/BasicFormatter) requirements, and, unless otherwise specified, also meet the [*Formatter*](/docs/cpp/library/named_req/Formatter) requirements.

{/* source:cpp-utility-format-formatter:0002 */}
For all types `T` and `CharT` for which no specialization `std::formatter<T, CharT>` is enabled, that specialization is a complete type and is disabled.

{/* source:cpp-utility-format-formatter:0003 */}
Disabled specializations do not meet the [*Formatter*](/docs/cpp/library/named_req/Formatter) requirements, and the following are all false:

{/* source:cpp-utility-format-formatter:0004 */}
- [`std::is_default_constructible_v`](/docs/cpp/library/meta/is_default_constructible)
- [`std::is_copy_constructible_v`](/docs/cpp/library/meta/is_copy_constructible)
- [`std::is_move_constructible_v`](/docs/cpp/library/meta/is_move_constructible)
- [`std::is_copy_assignable_v`](/docs/cpp/library/meta/is_copy_assignable)
- [`std::is_move_assignable_v`](/docs/cpp/library/meta/is_move_assignable).

{/* source:cpp-utility-format-formatter:0008 */}
Specializations such as `std::formatter<wchar_t, char>` and `std::formatter<const char*, wchar_t>` that would require encoding conversions are disabled.

A debug-enabled formatter specialization additionally provides a public non-static member function `constexpr void set_debug_format();` which modifies the state of the formatter object so that it will format the values as [escaped and quoted](/docs/cpp/library/text/format/spec#Formatting_escaped_characters_and_strings), as if the type of the format specifier parsed by the last call to `parse` were `?`. Each formatter specialization for string or character type is debug-enabled.
</Revision>

### Example

{/* source:cpp-utility-format-formatter:0012 */}
```cpp
#include <algorithm>
#include <format>
#include <iomanip>
#include <iostream>
#include <sstream>
#include <string_view>

struct QuotableString : std::string_view
{};

template<>
struct std::formatter<QuotableString, char>
{
    bool quoted = false;

    template<class ParseContext>
    constexpr ParseContext::iterator parse(ParseContext& ctx)
    {
        auto it = ctx.begin();
        if (it == ctx.end())
            return it;

        if (*it == '#')
        {
            quoted = true;
            ++it;
        }
        if (it != ctx.end() && *it != '}')
            throw std::format_error("Invalid format args for QuotableString.");

        return it;
    }

    template<class FmtContext>
    FmtContext::iterator format(QuotableString s, FmtContext& ctx) const
    {
        std::ostringstream out;
        if (quoted)
            out << std::quoted(s);
        else
            out << s;

        return std::ranges::copy(std::move(out).str(), ctx.out()).out;
    }
};

int main()
{
    QuotableString a("be"), a2(R"( " be " )");
    QuotableString b("a question");
    std::cout << std::format("To {0} or not to {0}, that is {1}.\n", a, b);
    std::cout << std::format("To {0:} or not to {0:}, that is {1:}.\n", a, b);
    std::cout << std::format("To {0:#} or not to {0:#}, that is {1:#}.\n", a2, b);
}
```

Output:

```text
To be or not to be, that is a question.
To be or not to be, that is a question.
To " \" be \" " or not to " \" be \" ", that is "a question".
```
