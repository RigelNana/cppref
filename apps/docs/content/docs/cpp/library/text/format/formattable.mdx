{/* source:cpp-utility-format-formattable:0001 */}
The concept `formattable` specifies that `std::formatter<std::remove_cvref_t<T>, CharT>` meets the requirements of [*BasicFormatter*](/docs/cpp/library/named_req/BasicFormatter) and [*Formatter*](/docs/cpp/library/named_req/Formatter) (if `std::remove_reference_t<T>` is const-qualified).

{/* source:cpp-utility-format-formattable:0002 */}
The exposition-only alias template `/* fmt_iter_for */` yields an unspecified type that satisfies `std::output_iterator<const CharT&>`.
