{/* source:cpp-utility-format-ranges-formatter:0001 */}
The template specialization of [`std::formatter`](/docs/cpp/library/text/format/formatter) for the range types allows users to convert a range to its textual representation as a collection of elements or a string using [formatting functions](/docs/cpp/library/text/format).

{/* source:cpp-utility-format-ranges-formatter:0002 */}
The specialization is derived from `range-default-formatter<std::format_kind<R>, R, CharT>`.

{/* source:cpp-utility-format-ranges-formatter:0003 */}
The specialization is enabled if `R` satisfies [`input_range`](/docs/cpp/library/ranges/input_range), `std::format_kind<R>` is not `std::range_format::disabled`, and `std::formattable<ranges::range_reference_t<R>, CharT>` is `true`.

{/* source:cpp-utility-format-ranges-formatter:0004 */}
This specialization meets the [*Formatter*](/docs/cpp/library/named_req/Formatter) requirements if `const R` models [`input_range`](/docs/cpp/library/ranges/input_range) and `ranges::range_reference_t<const R>` models `std::formattable<CharT>`. It always meets the [*BasicFormatter*](/docs/cpp/library/named_req/BasicFormatter) requirements.

### Format specification

{/* source:cpp-utility-format-ranges-formatter:0005 */}
The syntax of *range-format-spec* is:

{/* source:cpp-utility-format-ranges-formatter:0006 */}
| | |
| --- | --- |
| *range-fill-and-align* `(optional)` *width* `(optional)` `n` `(optional)` *range-type* `(optional)` *range-underlying-spec* `(optional)` | |

{/* source:cpp-utility-format-ranges-formatter:0007 */}
The syntax is fully described in [range format specification](/docs/cpp/library/text/format/range_formatter#Range_format_specification).

{/* source:cpp-utility-format-ranges-formatter:0008 */}
For specializations of `std::formatter` where `std::format_kind<R>` is either `std::range_format::string` or `std::range_format::debug_string`, the *format-spec* is *std-format-spec* instead of *range-format-spec* (which uses `std::formatter<std::basic_string<CharT>, CharT>` as the underlying formatter).
