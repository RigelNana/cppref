{/* source:cpp-text-text-encoding-comp-name:0001 */}
Compares two strings `a` and `b` encoded in ordinary literal encoding following the [Unicode Charset Alias Matching](https://www.unicode.org/reports/tr22/tr22-8.html#Charset_Alias_Matching) rules.

{/* source:cpp-text-text-encoding-comp-name:0002 */}
Two strings are considered equal when comparing from left to right after:

{/* source:cpp-text-text-encoding-comp-name:0003 */}
- removing all non-alphanumeric characters, converting all letters to the same case, and removing any standalone sequences of `'0'` characters that do not immediately follow a numeric prefix. A numeric prefix consists of a non-zero digit (`'1'` through `'9'`) optionally followed by one or more non-alphanumeric characters.

{/* source:cpp-text-text-encoding-comp-name:0004 */}
Here are the following examples:

{/* source:cpp-text-text-encoding-comp-name:0005 */}
```cpp
static_assert(/*comp-name*/("UTF-8", "utf8") == true);
static_assert(/*comp-name*/("u.t.f-008", "utf8") == true);
static_assert(/*comp-name*/("ISO-8859-1", "iso88591") == true);
static_assert(/*comp-name*/("ut8", "utf8") == false);
static_assert(/*comp-name*/("utf-80", "utf8") == false);
```

### Parameters

{/* source:cpp-text-text-encoding-comp-name:0006 */}
<ParameterList>
  <Parameter name="a, b">strings to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-text-text-encoding-comp-name:0007 */}
`true` if two strings compare equal as described above; `false` otherwise.
