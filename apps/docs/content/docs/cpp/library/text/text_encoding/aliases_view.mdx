The nested class `text_encoding::aliases_view` is a [`view`](/docs/cpp/library/ranges/view) over aliases of the character encoding.

{/* source:cpp-text-text-encoding-aliases-view:0003 */}
Let `r` denote an instance of `aliases_view`. For a non-empty range `r`:

{/* source:cpp-text-text-encoding-aliases-view:0004 */}
- `r.front()` is the primary name of the registered character encoding,
- `r` contains the aliases of the registered character encoding such that the order of the aliases is unspecified,
- each element in `r` is a non-null and non-empty null-terminated byte string encoded in the [literal character encoding](/docs/cpp/language/basic_concepts/charset#Code_unit_and_literal_encoding) and comprising only characters from the [basic character set](/docs/cpp/language/basic_concepts/charset#Basic_character_set), and
- `r` does not contain duplicate values when compared with [`std::strcmp`](/docs/cpp/library/text/byte/strcmp).

{/* source:cpp-text-text-encoding-aliases-view:0005 */}
These are the following type properties of `text_encoding::aliases_view`:

{/* source:cpp-text-text-encoding-aliases-view:0006 */}
- it models [`copyable`](/docs/cpp/library/concepts/copyable), [`random_access_range`](/docs/cpp/library/ranges/random_access_range), and [`borrowed_range`](/docs/cpp/library/ranges/borrowed_range).
- it is not required to satisfy [`common_range`](/docs/cpp/library/ranges/common_range) and [`default_initializable`](/docs/cpp/library/concepts/default_initializable).
- both `ranges::range_value_t<text_encoding::aliases_view>` and `ranges::range_reference_t<text_encoding::aliases_view>` denote `const char*`.
- `ranges::iterator_t<text_encoding::aliases_view>` is a [`ConstexprIterator`](/docs/cpp/library/named_req/ConstexprIterator).
