{/* source:cpp-text-text-encoding-name:0001 */}
Returns the primary name of `*this`. Equivalent to `return` [`name_`](/docs/cpp/library/text/text_encoding#name)`;`.

{/* source:cpp-text-text-encoding-name:0002 */}
Accessing elements of [`name_`](/docs/cpp/library/text/text_encoding#name) outside of the range `[name(), name() + std::strlen(name()) + 1)` is undefined behavior.

### Parameters

{/* source:cpp-text-text-encoding-name:0003 */}
(none)

### Return value

{/* source:cpp-text-text-encoding-name:0004 */}
Primary name [`name_`](/docs/cpp/library/text/text_encoding#name) that is represented by a null-terminated byte string.
