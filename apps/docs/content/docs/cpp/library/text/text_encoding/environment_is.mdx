{/* source:cpp-text-text-encoding-environment-is:0001 */}
Checks whether the [environment encoding](/docs/cpp/library/text/text_encoding/environment) is equal to the encoding whose MIBenum value is the specified value `I`. A call to this function is equivalent to `return environment() == I;`.

{/* source:cpp-text-text-encoding-environment-is:0002 */}
This function is deleted unless the `CHAR_BIT` is `8`.

### Template parameters

{/* source:cpp-text-text-encoding-environment-is:0003 */}
<ParameterList>
  <Parameter name="I">a `text_encoding::id` whose value to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-text-text-encoding-environment-is:0004 */}
`true` if `environment()` is equal to `I`; `false` otherwise.
