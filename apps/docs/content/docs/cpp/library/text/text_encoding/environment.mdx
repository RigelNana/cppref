{/* source:cpp-text-text-encoding-environment:0001 */}
Constructs a new `text_encoding` object representing the [environment](/docs/cpp/language/basic_concepts/main_function) encoding that refers to the implementation-defined character encoding scheme of the execution environment. The execution environment at runtime is the environment in which the program is run.

{/* source:cpp-text-text-encoding-environment:0002 */}
The environment encoding in the execution environment is distinct from the encoding of [execution character set](/docs/cpp/language/basic_concepts/charset#Execution_character_set) which is locale-specific. In other words, the environment encoding remains locale-independent, that is, the value returned by `environment()` is not affected by calls to the functions (e.g. [`std::setlocale`](/docs/cpp/library/text/locale/setlocale) and POSIX function [`setenv()`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/setenv.html)) which can modify the environment.

{/* source:cpp-text-text-encoding-environment:0003 */}
This function is deleted unless the `CHAR_BIT` is `8`.

### Parameters

{/* source:cpp-text-text-encoding-environment:0004 */}
(none)

### Return value

{/* source:cpp-text-text-encoding-environment:0005 */}
The object holding the representation of the environment character encoding.

### Notes

{/* source:cpp-text-text-encoding-environment:0006 */}
The environment encoding may differ from the global locale-associated encoding that is accessible via `std::locale().encoding()`.

{/* source:cpp-text-text-encoding-environment:0007 */}
On Windows platforms, the environment encoding can be determined by [`GetACP()`](https://learn.microsoft.com/en-us/windows/win32/api/winnls/nf-winnls-getacp) and then mapped to MIBenum values.

{/* source:cpp-text-text-encoding-environment:0008 */}
On POSIX platforms, the environment encoding is associated with the POSIX locale `""` which can be implemented to correspond to a value of [`nl_langinfo_l()`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/nl_langinfo.html) when the environment locale `""` is set before the [global C++ locale](/docs/cpp/library/text/locale/locale/global) is set to `"C"` at program startup.
