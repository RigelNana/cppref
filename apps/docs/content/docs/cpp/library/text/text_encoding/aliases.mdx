{/* source:cpp-text-text-encoding-aliases:0001 */}
Returns a non-empty range of type [`text_encoding::aliases_view`](/docs/cpp/library/text/text_encoding/aliases_view) containing the aliases of `*this` if it represents a known registered character encoding. Otherwise, returns an empty range of type [`text_encoding::aliases_view`](/docs/cpp/library/text/text_encoding/aliases_view).

### Parameters

{/* source:cpp-text-text-encoding-aliases:0002 */}
(none)

### Return value

{/* source:cpp-text-text-encoding-aliases:0003 */}
A [`view`](/docs/cpp/library/ranges/view) containing aliases of the known registered character encoding represented by `*this`; otherwise an empty range.
