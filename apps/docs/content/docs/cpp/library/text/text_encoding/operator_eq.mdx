  <Declaration id="1" language="cpp" since="C++26" code={`friend constexpr bool operator==( const text_encoding& a, 
                                  const text_encoding& b ) noexcept;`} />
  <Declaration id="2" language="cpp" since="C++26" code={`friend constexpr bool operator==( const text_encoding& a, id i ) noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-text-text-encoding-operator-eq:0001 */}
    Performs comparison operations on `text_encoding` objects.

    {/* source:cpp-text-text-encoding-operator-eq:0002 */}
    1. Compares two `text_encoding` objects. The objects compare equal if and only if [`comp-name`](/docs/cpp/library/text/text_encoding/comp-name)`(a.name(), b.name())` is `true` when both `a.mib()` and `b.mib()` are equal to `id::other`, or `a.mib()` is equal to `b.mib()`.

    {/* source:cpp-text-text-encoding-operator-eq:0003 */}
    2. Compare `text_encoding` object with a MIBenum value. The objects compare equal if and only if `a.mib()` is equal to `i`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-text-text-encoding-operator-eq:0004 */}
These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::text_encoding` is an associated class of the arguments.

{/* source:cpp-text-text-encoding-operator-eq:0005 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

### Parameters

{/* source:cpp-text-text-encoding-operator-eq:0006 */}
<ParameterList>
  <Parameter name="a, b">`text_encoding` objects to compare</Parameter>
  <Parameter name="i">`id` value to compare with the MIBenum value contained in `a`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-text-text-encoding-operator-eq:0007 */}
1. `a.mib() == id::other && b.mib() == id::other ? comp-name(a.name(), b.name()) : a.mib() == b.mib()`.

{/* source:cpp-text-text-encoding-operator-eq:0008 */}
2. `a.mib() == i`.
