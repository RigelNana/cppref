`std::to_chars_result` is the return type of [`std::to_chars`](/docs/cpp/library/text/to_chars). It has no base classes, and only has the following members.

### Data members

{/* source:cpp-utility-to-chars-result:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`ptr`</DescriptionTerm>
    <DescriptionBody>a pointer of type `char*` <br /> (public member object)</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`ec`</DescriptionTerm>
    <DescriptionBody>an error code of type [`std::errc`](/docs/cpp/library/error/errc) <br /> (public member object)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Member and friend functions

{/* source:cpp-utility-to-chars-result:0003 */}
#### `operator==(std::to_chars_result)`

<DeclarationDoc>
  <Declaration language="cpp" since="C++20" code={`friend bool operator==( const to_chars_result&,
                        const to_chars_result& ) = default;`} />
</DeclarationDoc>

Compares the two arguments using [default comparisons](/docs/cpp/language/expressions/default_comparisons) (which uses `operator==` to compare `ptr` and `ec` respectively).

This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::to_chars_result` is an associated class of the arguments.

The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.

{/* source:cpp-utility-to-chars-result:0004 */}
#### `operator bool`

<DeclarationDoc>
  <Declaration language="cpp" since="C++26" code={`constexpr explicit operator bool() const noexcept;`} />
</DeclarationDoc>

Checks whether the conversion is successful. Returns `ec == std::errc{}`.

### Example

{/* source:cpp-utility-to-chars-result:0006 */}
```cpp
#include <array>
#include <charconv>
#include <iostream>
#include <string_view>
#include <system_error>
 
void show_to_chars(auto... format_args)
{
    std::array<char, 10> str;
 
#if __cpp_lib_to_chars >= 202306L and __cpp_structured_bindings >= 202406L
    // use C++26 structured bindings declaration as condition (P0963)
    // and C++26 to_chars_result::operator bool() for error checking (P2497)
    if (auto [ptr, ec] =
            std::to_chars(str.data(), str.data() + str.size(), format_args...))
        std::cout << std::string_view(str.data(), ptr) << '\n';
    else
        std::cout << std::make_error_code(ec).message() << '\n';
#elif __cpp_lib_to_chars >= 202306L
    // use C++26 to_chars_result::operator bool() for error checking (P2497)
    if (auto result =
            std::to_chars(str.data(), str.data() + str.size(), format_args...))
        std::cout << std::string_view(str.data(), result.ptr) << '\n';
    else
        std::cout << std::make_error_code(result.ec).message() << '\n';
#else
    // fallback to C++17 if-with-initializer and structured bindings
    if (auto [ptr, ec] =
            std::to_chars(str.data(), str.data() + str.size(), format_args...);
        ec == std::errc())
        std::cout << std::string_view(str.data(), ptr - str.data()) << '\n';
    else
        std::cout << std::make_error_code(ec).message() << '\n';
#endif
}
 
int main()
{
    show_to_chars(42);
    show_to_chars(+3.14159F);
    show_to_chars(-3.14159, std::chars_format::fixed);
    show_to_chars(-3.14159, std::chars_format::scientific, 3);
    show_to_chars(3.1415926535, std::chars_format::fixed, 10);
}
```
Possible output:
```text
42
3.14159
-3.14159
-3.142e+00
Value too large for defined data type
```
