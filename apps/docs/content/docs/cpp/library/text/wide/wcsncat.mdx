  <Declaration language="cpp" code={
`wchar_t* wcsncat( wchar_t* dest, const wchar_t* src, std::size_t count );`

{/* source:cpp-string-wide-wcsncat:0001 */}

Appends at most `count` wide characters from the wide string pointed to by `src` to the end of the character string pointed to by `dest`, stopping if the null terminator is copied. The wide character `src[0]` replaces the null terminator at the end of `dest`. The null terminator is always appended in the end (so the maximum number of wide characters the function may write is `count + 1`).

{/* source:cpp-string-wide-wcsncat:0002 */}

The behavior is undefined if the destination array is not large enough for the contents of both `src` and `dest` and the terminating null wide character.

{/* source:cpp-string-wide-wcsncat:0003 */}

The behavior is undefined if the strings overlap.

### Parameters

{/* source:cpp-string-wide-wcsncat:0004 */}

<ParameterList>
  <Parameter name="dest">pointer to the null-terminated wide string to append to</Parameter>
  <Parameter name="src">pointer to the null-terminated wide string to copy from</Parameter>
  <Parameter name="count">maximum number of wide characters to copy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wcsncat:0005 */}

`dest`

### Example

{/* source:cpp-string-wide-wcsncat:0006 */}

```cpp
#include <clocale>
#include <cwchar> 
#include <iostream>
 
int main(void) 
{
    wchar_t str[50] = L"Земля, прощай.";
    std::wcsncat(str, L" ", 1);
    std::wcsncat(str, L"В добрый путь.", 8); // only append the first 8 wide chars
 
    std::setlocale(LC_ALL, "en_US.utf8");
    std::wcout.imbue(std::locale("en_US.utf8"));
    std::wcout << str << '\n';
}
```

Possible output:

```text
Земля, прощай. В добрый
```
