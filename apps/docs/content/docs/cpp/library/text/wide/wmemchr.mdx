{/* source:cpp-string-wide-wmemchr:0001 */}

Locates the first occurrence of wide character `ch` in the initial `count` wide characters of the wide character array pointed to by `ptr`.

{/* source:cpp-string-wide-wmemchr:0002 */}

If `count` is zero, the function returns a null pointer.

### Parameters

{/* source:cpp-string-wide-wmemchr:0003 */}

<ParameterList>
  <Parameter name="ptr">pointer to the wide character array to be examined</Parameter>
  <Parameter name="ch">wide character to search for</Parameter>
  <Parameter name="count">number of wide characters to examine</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wmemchr:0004 */}

Pointer to the location of the wide character, or a null pointer if no such character is found.

### Example

{/* source:cpp-string-wide-wmemchr:0005 */}

```cpp
#include <clocale>
#include <cwchar>
#include <iostream>
#include <locale>
 
int main()
{
    const wchar_t str[] = L"诺不轻信，故人不负我\0诺不轻许，故我不负人。";
    wchar_t target = L'许';
    const std::size_t sz = sizeof str / sizeof *str;
    if (const wchar_t* result = std::wmemchr(str, target, sz))
    {
        std::setlocale(LC_ALL, "en_US.utf8");
        std::wcout.imbue(std::locale("en_US.utf8"));
        std::wcout << "Found '" << target << "' at position " << result - str << '\n';
    }
}
```

Possible output:

```text
Found '许' at position 14
```
