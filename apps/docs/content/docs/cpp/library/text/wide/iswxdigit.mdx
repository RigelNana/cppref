{/* source:cpp-string-wide-iswxdigit:0001 */}

Checks if the given wide character corresponds (if narrowed) to a hexadecimal numeric character, i.e. one of `0123456789abcdefABCDEF`.

{/* source:cpp-string-wide-iswxdigit:0002 */}

If the value of `ch` is neither representable as a `wchar_t` nor equal to the value of the macro `WEOF`, the behavior is undefined.

### Parameters

{/* source:cpp-string-wide-iswxdigit:0003 */}

<ParameterList>
  <Parameter name="ch">wide character</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-iswxdigit:0004 */}

Non-zero value if the wide character is a hexadecimal numeric character, zero otherwise.

### Notes

{/* source:cpp-string-wide-iswxdigit:0005 */}

[`std::iswdigit`](/docs/cpp/library/text/wide/iswdigit) and `std::iswxdigit` are the only standard wide character classification functions that are not affected by the currently installed C locale.

### Example

{/* source:cpp-string-wide-iswxdigit:0006 */}

```cpp
#include <cwctype>
#include <iostream>
 
int main()
{
    std::cout << std::boolalpha
              << (std::iswxdigit(L'a') != 0) << ' '
              << (std::iswxdigit(L'ä') != 0) << '\n';
}
```

Output:

```text
true false
```
