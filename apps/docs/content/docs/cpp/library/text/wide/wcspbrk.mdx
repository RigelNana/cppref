{/* source:cpp-string-wide-wcspbrk:0001 */}

Finds the first character in wide string pointed to by `dest`, that is also in wide string pointed to by `src`.

### Parameters

{/* source:cpp-string-wide-wcspbrk:0002 */}

<ParameterList>
  <Parameter name="dest">pointer to the null-terminated wide string to be analyzed</Parameter>
  <Parameter name="src">pointer to the null-terminated wide string that contains the characters to search for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-wide-wcspbrk:0003 */}

Pointer to the first character in `dest`, that is also in `src`, or a null pointer if no such character exists.

### Notes

{/* source:cpp-string-wide-wcspbrk:0004 */}

The name stands for "wide character string pointer break", because it returns a pointer to the first of the separator ("break") characters.

### Example

{/* source:cpp-string-wide-wcspbrk:0005 */}

```cpp
#include <cwchar>
#include <iomanip>
#include <iostream>
 
int main()
{
    const wchar_t* str = L"Hello world, friend of mine!";
    const wchar_t* sep = L" ,!";
 
    unsigned int cnt = 0;
    do
    {
        str = std::wcspbrk(str, sep); // find separator
        std::wcout << std::quoted(str) << L'\n';
        if (str)
            str += std::wcsspn(str, sep); // skip separator
        ++cnt; // increment word count
    } while (str && *str);
 
    std::wcout << L"There are " << cnt << L" words\n";
}
```

Output:

```text
" world, friend of mine!"
", friend of mine!"
" of mine!"
" mine!"
"!"
There are 5 words
```
