### Constants

{/* source:cpp-regex-match-flag-type:0002 */}
Note: [`first`, `last`) refers to the character sequence being matched.

{/* source:cpp-regex-match-flag-type:0003 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`match_not_bol`</DescriptionTerm>
    <DescriptionBody>The first character in [`first`, `last`) will be treated as if it is not at the beginning of a line <br /> (i.e. ^ will not match [`first`, `first`)).</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`match_not_eol`</DescriptionTerm>
    <DescriptionBody>The last character in [`first`, `last`) will be treated as if it is not at the end of a line <br /> (i.e. $ will not match [`last`, `last`)).</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`match_not_bow`</DescriptionTerm>
    <DescriptionBody>`\b` will not match [`first`, `first`).</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`match_not_eow`</DescriptionTerm>
    <DescriptionBody>`\b` will not match [`last`, `last`).</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`match_any`</DescriptionTerm>
    <DescriptionBody>If more than one match is possible, then any match is an acceptable result.</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`match_not_null`</DescriptionTerm>
    <DescriptionBody>Do not match empty sequences.</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`match_continuous`</DescriptionTerm>
    <DescriptionBody>Only match a sub-sequence that begins at `first`.</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`match_prev_avail`</DescriptionTerm>
    <DescriptionBody>`--first` is a valid iterator position. <br /> When set, causes `match_not_bol` and `match_not_bow` to be ignored.</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`format_default`</DescriptionTerm>
    <DescriptionBody>Use ECMAScript rules to construct strings in [`std::regex_replace`](/docs/cpp/library/text/regex/regex_replace) ([syntax documentation](https://ecma-international.org/ecma-262/5.1/#sec-15.5.4.11)).</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`format_sed`</DescriptionTerm>
    <DescriptionBody>Use POSIX sed utility rules in [`std::regex_replace`](/docs/cpp/library/text/regex/regex_replace) ([syntax documentation](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/sed.html#tag_20_116_13_03)).</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`format_no_copy`</DescriptionTerm>
    <DescriptionBody>Do not copy un-matched strings to the output in [`std::regex_replace`](/docs/cpp/library/text/regex/regex_replace).</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`format_first_only`</DescriptionTerm>
    <DescriptionBody>Only replace the first match in [`std::regex_replace`](/docs/cpp/library/text/regex/regex_replace).</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-regex-match-flag-type:0004 */}
All constants, except for `match_default` and `format_default`, are bitmask elements. The `match_default` and `format_default` constants are empty bitmasks.
