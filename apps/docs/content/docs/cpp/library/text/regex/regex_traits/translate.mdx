{/* source:cpp-regex-regex-traits-translate:0001 */}
Obtains the comparison key for the character `c`, such that all characters that are equivalent to this character in the imbued locale produce the same key.

{/* source:cpp-regex-regex-traits-translate:0002 */}
When the regex library needs to match two characters `c1` and `c2` and the flag [`std::regex_constants::collate`](/docs/cpp/library/text/regex/syntax_option_type) is `true`, it executes `regex_traits<>::translate(c1) == regex_traits<>::translate(c2)`.

{/* source:cpp-regex-regex-traits-translate:0003 */}
Standard library specializations of [`std::regex_traits`](/docs/cpp/library/text/regex/regex_traits) return `c` unmodified.

### Parameters

{/* source:cpp-regex-regex-traits-translate:0004 */}
<ParameterList>
  <Parameter name="c">character that needs to be examined for equivalence</Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-regex-traits-translate:0005 */}
The comparison key for `c` in the currently imbued locale.
