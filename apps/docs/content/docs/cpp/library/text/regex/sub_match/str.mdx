{/* source:cpp-regex-sub-match-str:0001 */}
Converts to an object of the underlying [`std::basic_string`](/docs/cpp/library/string/basic_string) type.

{/* source:cpp-regex-sub-match-str:0002 */}
1. 1) An implicit conversion.

{/* source:cpp-regex-sub-match-str:0003 */}
2. 2) An explicit conversion.

### Return value

{/* source:cpp-regex-sub-match-str:0004 */}
The matched character sequence as an object of the underlying [`std::basic_string`](/docs/cpp/library/string/basic_string) type. If the `matched` member is `false`, then returns the empty string.

### Complexity

{/* source:cpp-regex-sub-match-str:0005 */}
Linear in the length of the underlying character sequence.

### Example

{/* source:cpp-regex-sub-match-str:0006 */}
```cpp
#include <cassert>
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    const std::string html{R"("<a href="https://cppreference.com/">)"};
    const std::regex re{"(http|https|ftp)://([a-z]+)\\.([a-z]{3})"};
    std::smatch parts;
    std::regex_search(html, parts, re);
    for (std::ssub_match const& sub : parts)
    {
        const std::string s = sub; // (1) implicit conversion
        assert(s == sub.str());    // (2)
        std::cout << s << '\n';
    }
}
```
