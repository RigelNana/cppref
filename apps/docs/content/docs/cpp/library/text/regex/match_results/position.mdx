{/* source:cpp-regex-match-results-position:0001 */}
Returns the position of the first character of the specified sub-match.

{/* source:cpp-regex-match-results-position:0002 */}
If `n == 0`, the position of the first character of the entire matched expression is returned.

{/* source:cpp-regex-match-results-position:0003 */}
If `n > 0 && n < size()`, the position of the first character of the `n`th sub-match is returned.

{/* source:cpp-regex-match-results-position:0004 */}
if `n >= size()`, a position of the first character of the unmatched match is returned.

{/* source:cpp-regex-match-results-position:0005 */}
[`ready()`](/docs/cpp/library/text/regex/match_results/ready) must be `true`. Otherwise, the behavior is undefined.

### Parameters

{/* source:cpp-regex-match-results-position:0006 */}
<ParameterList>
  <Parameter name="n">
    integral number specifying which match to examine
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-match-results-position:0007 */}
The position of the first character of the specified match or sub-match.

### Example

{/* source:cpp-regex-match-results-position:0008 */}
```cpp
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    std::regex re("a(a)*b");
    std::string target("aaab");
    std::smatch sm;
 
    std::regex_match(target, sm, re);
    std::cout << sm.position(1) << '\n';
}
```
Output:
```text
2
```
