Extracts the current [`std::match_results`](/docs/cpp/library/text/regex/match_results) from a `regex_iterator`.

### Return value

{/* source:cpp-regex-regex-iterator-operator-star:0002 */}
1. 1) Returns a reference to the current [`std::match_results`](/docs/cpp/library/text/regex/match_results).

{/* source:cpp-regex-regex-iterator-operator-star:0003 */}
2. 2) Returns a pointer to the current [`std::match_results`](/docs/cpp/library/text/regex/match_results).

### Example

{/* source:cpp-regex-regex-iterator-operator-star:0004 */}
```cpp
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    std::string hay{"1.1a2b3cjk34"};
    std::regex needle("[1234]");
    using Ri = std::regex_iterator<std::string::iterator>;
    for (Ri it{hay.begin(), hay.end(), needle}, last{}; it != last; ++it)
        std::cout << it->str();
    std::cout << '\n';
}
```
Output:
```text
112334
```
