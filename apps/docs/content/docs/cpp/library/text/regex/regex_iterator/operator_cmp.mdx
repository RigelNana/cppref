### Return value

{/* source:cpp-regex-regex-iterator-operator-cmp:0004 */}
For the sake of exposition, assume that `regex_iterator` contains the following members:

{/* source:cpp-regex-regex-iterator-operator-cmp:0005 */}
-  `BidirIt begin`;

-  `BidirIt end`;

-  `const regex_type *pregex;`

-  `std::regex_constants::match_flag_type flags;`

-  `std::match_results<BidirIt> match;`

{/* source:cpp-regex-regex-iterator-operator-cmp:0006 */}
1. 1) Returns `true` if `*this` and `rhs` are both end-of-sequence iterators, or if all of the following conditions are true:
   -  `begin == rhs.begin`
   
   -  `end == rhs.end`
   
   -  `pregex == rhs.pregex`
   
   -  `flags == rhs.flags`
   
   -  `match[0] == rhs.match[0]`

{/* source:cpp-regex-regex-iterator-operator-cmp:0007 */}
2. 2) Returns `!(*this == rhs)`.
