Default-constructs the [`std::regex_traits`](/docs/cpp/library/text/regex/regex_traits) object, including default-constructing the private [`std::locale`](/docs/cpp/library/text/locale/locale) member or any other internal state as necessary.

### Parameters

{/* source:cpp-regex-regex-traits-regex-traits:0002 */}
(none)

### Return value

{/* source:cpp-regex-regex-traits-regex-traits:0003 */}
(none)

### Example

{/* source:cpp-regex-regex-traits-regex-traits:0004 */}
```cpp
#include <iostream>
#include <regex>
 
int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    std::regex_traits<char> r1;
    std::regex_traits<wchar_t> r2;
    std::cout << "The regex locale is " << r1.getloc().name() << '\n';
}
```
Output:
```text
The regex locale is en_US.utf8
```
