{/* source:cpp-regex-regex-traits-translate-nocase:0001 */}
Obtains the comparison key for the character `c`, such that all characters that are equivalent to this character in the imbued locale, ignoring the case differences, if any, produce the same key.

{/* source:cpp-regex-regex-traits-translate-nocase:0002 */}
When the regex library needs to match two characters `c1` and `c2` and the flag [`std::regex_constants::icase`](/docs/cpp/library/text/regex/syntax_option_type) is `true`, it executes `regex_traits<>::translate_nocase(c1) == regex_traits<>::translate_nocase(c2)`.

{/* source:cpp-regex-regex-traits-translate-nocase:0003 */}
Standard library specializations of [`std::regex_traits`](/docs/cpp/library/text/regex/regex_traits) return `std::use_facet<std::ctype<CharT>>(getloc()).tolower(c)`, that is, convert `c` to lowercase, using the currently imbued locale.

### Parameters

{/* source:cpp-regex-regex-traits-translate-nocase:0004 */}
<ParameterList>
  <Parameter name="c">character that needs to be examined for equivalence, ignoring case</Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-regex-traits-translate-nocase:0005 */}
The case-insensitive comparison key for `c` in the currently imbued locale.
