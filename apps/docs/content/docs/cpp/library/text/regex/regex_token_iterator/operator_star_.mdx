Returns a pointer or reference to the current match.

### Return value

{/* source:cpp-regex-regex-token-iterator-operator-star:0002 */}
1. 1) Returns a reference to the current match.

{/* source:cpp-regex-regex-token-iterator-operator-star:0003 */}
2. 2) Returns a pointer to the current match.

{/* source:cpp-regex-regex-token-iterator-operator-star:0004 */}
The behavior is undefined if the iterator is end-of-sequence iterator.
