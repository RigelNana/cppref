  <DeclarationDescription>
    {/* source:cpp-regex-basic-regex-assign:0001 */}
    Assigns the contents to the regular expression.
    {/* source:cpp-regex-basic-regex-assign:0002 */}
    1. Assigns the contents of `other`. [`flags()`](/docs/cpp/library/text/regex/basic_regex/flags) and [`mark_count()`](/docs/cpp/library/text/regex/basic_regex/mark_count) are equivalent to the values of `other.flags()` and `other.mark_count()` after the call.
    {/* source:cpp-regex-basic-regex-assign:0003 */}
    2. Assigns the contents of `other` using move semantics. [`flags()`](/docs/cpp/library/text/regex/basic_regex/flags) and [`mark_count()`](/docs/cpp/library/text/regex/basic_regex/mark_count) are equivalent to the values of `other.flags()` and `other.mark_count()` before the assignment. After the call, `other` is in a valid, but unspecified state.
    {/* source:cpp-regex-basic-regex-assign:0004 */}
    3. 3-7) Assigns a sequence of characters to the regular expression. The syntax flags are set to `f`. [`mark_count()`](/docs/cpp/library/text/regex/basic_regex/mark_count) returns the number of marked subexpressions within the resulting subexpression after the call.
    {/* source:cpp-regex-basic-regex-assign:0005 */}
    - 3) Assigns a null-terminated string pointed to by `s`.
    {/* source:cpp-regex-basic-regex-assign:0006 */}
    - 4) Assigns a sequence of `count` characters, pointed to by `s`.
    {/* source:cpp-regex-basic-regex-assign:0007 */}
    - 5) Assigns the string `str`.
    {/* source:cpp-regex-basic-regex-assign:0008 */}
    - 6) Assigns the characters in the range [`first`, `last`).
    {/* source:cpp-regex-basic-regex-assign:0009 */}
    - 7) Assigns the characters in the initializer list `ilist`.
  </DeclarationDescription>
</DeclarationDoc>
