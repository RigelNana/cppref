{/* source:cpp-regex-match-results-str:0001 */}
Returns a string representing the indicated sub-match.

{/* source:cpp-regex-match-results-str:0002 */}
If `n == 0`, a string representing entire matched expression is returned.

{/* source:cpp-regex-match-results-str:0003 */}
If `0 < n && n < size()`, a string representing `n`th sub-match is returned.

{/* source:cpp-regex-match-results-str:0004 */}
if `n >= size()`, a string representing the unmatched match is returned.

{/* source:cpp-regex-match-results-str:0005 */}
The call is equivalent to `string_type((*this)[n])`;

{/* source:cpp-regex-match-results-str:0006 */}
[`ready()`](/docs/cpp/library/text/regex/match_results/ready) must be `true`. Otherwise, the behavior is undefined.

### Parameters

{/* source:cpp-regex-match-results-str:0007 */}
<ParameterList>
  <Parameter name="n">
    integral number specifying which match to return
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-match-results-str:0008 */}
Returns a string representing the specified match or sub match.

### Example

{/* source:cpp-regex-match-results-str:0009 */}
```cpp
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    std::string target("baaaby");
    std::smatch sm;
 
    std::regex re1("a(a)*b");
    std::regex_search(target, sm, re1);
    std::cout << "entire match: " << sm.str(0) << '\n'
              << "submatch #1: " << sm.str(1) << '\n';
 
    std::regex re2("a(a*)b");
    std::regex_search(target, sm, re2);
    std::cout << "entire match: " << sm.str(0) << '\n'
              << "submatch #1: " << sm.str(1) << '\n';
}
```
Output:
```text
entire match: aaab
submatch #1: a
entire match: aaab
submatch #1: aa
```
