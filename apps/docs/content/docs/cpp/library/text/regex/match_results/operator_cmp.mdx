{/* source:cpp-regex-match-results-operator-cmp:0001 */}
Compares two `match_results` objects.

{/* source:cpp-regex-match-results-operator-cmp:0002 */}
Two `match_results` are equal if the following conditions are met:

{/* source:cpp-regex-match-results-operator-cmp:0003 */}
- neither of the objects is ready, or
- both match results are ready and the following conditions are met:

{/* source:cpp-regex-match-results-operator-cmp:0004 */}
- `lhs.empty()` and `rhs.empty()`, or
- `!lhs.empty()` and `!rhs.empty()` and the following conditions are met:
- `lhs.prefix() == rhs.prefix()`
- `lhs.size() == rhs.size() && std::equal(lhs.begin(), lhs.end(), rhs.begin())`
- `lhs.suffix() == rhs.suffix()`

{/* source:cpp-regex-match-results-operator-cmp:0005 */}
1) Checks if `lhs` and `rhs` are equal.

{/* source:cpp-regex-match-results-operator-cmp:0006 */}
2) Checks if `lhs` and `rhs` are not equal.

{/* source:cpp-regex-match-results-operator-cmp:0007 */}
<Revision since="C++20">
The != operator is [`synthesized`](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

Type requirements

- `BidirIt` must meet the requirements of [`LegacyBidirectionalIterator`](/docs/cpp/library/named_req/BidirectionalIterator).
- `Alloc` must meet the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator).

### Return value

{/* source:cpp-regex-match-results-operator-cmp:0009 */}
1) `true` if `lhs` and `rhs` are equal, `false` otherwise.

{/* source:cpp-regex-match-results-operator-cmp:0010 */}
2) `true` if `lhs` and `rhs` are not equal, `false` otherwise.
