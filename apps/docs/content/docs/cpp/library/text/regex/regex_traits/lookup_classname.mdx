{/* source:cpp-regex-regex-traits-lookup-classname:0001 */}
If the character sequence `[``first``, ``last``)` represents the name of a valid character class in the currently imbued locale (that is, the string between `[:` and `:]` in regular expressions), returns the implementation-defined value representing this character class. Otherwise, returns zero.

{/* source:cpp-regex-regex-traits-lookup-classname:0002 */}
If the parameter `icase` is `true`, the character class ignores character case, e.g. the regex `[:lower:]` with [`std::regex_constants::icase`](/docs/cpp/library/text/regex/syntax_option_type) generates a call to `std::regex_traits<>::lookup_classname()` with `[``first``, ``last``)` indicating the string `"lower"` and `icase == true`. This call returns the same bitmask as the call generated by the regex `[:alpha:]` with `icase == false`.

{/* source:cpp-regex-regex-traits-lookup-classname:0003 */}
The following narrow and wide character class names are always recognized by `std::regex_traits<char>` and `std::regex_traits<wchar_t>` respectively, and the classifications returned (with `icase == false`) correspond to the matching classifications obtained by the [`std::ctype`](/docs/cpp/library/text/locale/ctype) facet of the imbued locale, as follows:

{/* source:cpp-regex-regex-traits-lookup-classname:0004 */}
| Character class name | Character class name | [`std::ctype`](/docs/cpp/library/text/locale/ctype) classification |
| --- | --- | --- |
| Narrow | Wide | [`std::ctype`](/docs/cpp/library/text/locale/ctype) classification |
| `"alnum"` | `L"alnum"` | [`std::ctype_base::alnum`](/docs/cpp/library/text/locale/ctype_base) |
| `"alpha"` | `L"alpha"` | [`std::ctype_base::alpha`](/docs/cpp/library/text/locale/ctype_base) |
| `"blank"` | `L"blank"` | [`std::ctype_base::blank`](/docs/cpp/library/text/locale/ctype_base) |
| `"cntrl"` | `L"cntrl"` | [`std::ctype_base::cntrl`](/docs/cpp/library/text/locale/ctype_base) |
| `"digit"` | `L"digit"` | [`std::ctype_base::digit`](/docs/cpp/library/text/locale/ctype_base) |
| `"graph"` | `L"graph"` | [`std::ctype_base::graph`](/docs/cpp/library/text/locale/ctype_base) |
| `"lower"` | `L"lower"` | [`std::ctype_base::lower`](/docs/cpp/library/text/locale/ctype_base) |
| `"print"` | `L"print"` | [`std::ctype_base::print`](/docs/cpp/library/text/locale/ctype_base) |
| `"punct"` | `L"punct"` | [`std::ctype_base::punct`](/docs/cpp/library/text/locale/ctype_base) |
| `"space"` | `L"space"` | [`std::ctype_base::space`](/docs/cpp/library/text/locale/ctype_base) |
| `"upper"` | `L"upper"` | [`std::ctype_base::upper`](/docs/cpp/library/text/locale/ctype_base) |
| `"xdigit"` | `L"xdigit"` | [`std::ctype_base::xdigit`](/docs/cpp/library/text/locale/ctype_base) |
| `"d"` | `L"d"` | [`std::ctype_base::digit`](/docs/cpp/library/text/locale/ctype_base) |
| `"s"` | `L"s"` | [`std::ctype_base::space`](/docs/cpp/library/text/locale/ctype_base) |
| `"w"` | `L"w"` | [`std::ctype_base::alnum`](/docs/cpp/library/text/locale/ctype_base) with `'_'` optionally added |

{/* source:cpp-regex-regex-traits-lookup-classname:0005 */}
The classification returned for the string `"w"` may be exactly the same as `"alnum"`, in which case [`isctype()`](/docs/cpp/library/text/regex/regex_traits/isctype) adds `'_'` explicitly.

{/* source:cpp-regex-regex-traits-lookup-classname:0006 */}
Additional classifications such as `"jdigit"` or `"jkanji"` may be provided by system-supplied locales (in which case they are also accessible through [`std::wctype`](/docs/cpp/library/text/wide/wctype)).

### Parameters

{/* source:cpp-regex-regex-traits-lookup-classname:0007 */}
<ParameterList>
  <Parameter name="first, last">a pair of iterators which determines the sequence of characters that represents a name of a character class</Parameter>
  <Parameter name="icase">if `true`, ignores the upper/lower case distinction in the character classification</Parameter>
</ParameterList>

**Type requirements**

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-regex-regex-traits-lookup-classname:0008 */}
The bitmask representing the character classification determined by the given character class, or `char_class_type()` if the class is unknown.

### Example

{/* source:cpp-regex-regex-traits-lookup-classname:0009 */}
Demonstrates a custom regex traits implementation of lookup_classname() / isctype():
```cpp
#include <cwctype>
#include <iostream>
#include <locale>
#include <regex>
 
// This custom regex traits uses wctype/iswctype to implement lookup_classname/isctype.
struct wctype_traits : std::regex_traits<wchar_t>
{
    using char_class_type = std::wctype_t;
 
    template<class It>
    char_class_type lookup_classname(It first, It last, bool = false) const
    {
        return std::wctype(std::string(first, last).c_str());
    }
 
    bool isctype(wchar_t c, char_class_type f) const
    {
        return std::iswctype(c, f);
    }
};
 
int main()
{
    std::locale::global(std::locale("ja_JP.utf8"));
    std::wcout.sync_with_stdio(false);
    std::wcout.imbue(std::locale());
 
    std::wsmatch m;
    std::wstring in = L"風の谷のナウシカ";
    // matches all characters (they are classified as alnum)
    std::regex_search(in, m, std::wregex(L"([[:alnum:]]+)"));
    std::wcout << "alnums: " << m[1] << '\n'; // prints "風の谷のナウシカ"
    // matches only the katakana
    std::regex_search(in, m,
                      std::basic_regex<wchar_t, wctype_traits>(L"([[:jkata:]]+)"));
    std::wcout << "katakana: " << m[1] << '\n'; // prints "ナウシカ"
}
```
Output:
```text
alnums: 風の谷のナウシカ
katakana: ナウシカ
```
