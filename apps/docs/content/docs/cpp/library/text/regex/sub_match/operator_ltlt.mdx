{/* source:cpp-regex-sub-match-operator-ltlt:0001 */}
Writes the representation of the matched subsequence `m` to the output stream `os`. 
Equivalent to `os << m.str()`.

### Parameters

{/* source:cpp-regex-sub-match-operator-ltlt:0002 */}
<ParameterList>
  <Parameter name="os">output stream to write the representation to</Parameter>
  <Parameter name="m">a sub-match object to output</Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-sub-match-operator-ltlt:0003 */}
`os`

### Example

{/* source:cpp-regex-sub-match-operator-ltlt:0004 */}
```cpp
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    std::string sentence{"Quick red fox jumped over a lazy hare."};
    const std::regex re{"([A-z]+) ([a-z]+) ([a-z]+)"};
    std::smatch words;
    std::regex_search(sentence, words, re);
    for (const auto& m : words)
        // m has type const` std::sub_match<std::string::const_iterator>&`
        std::cout << '[' << m << "] ";
    std::cout << '\n';
}
```
Output:
```text
[Quick red fox] [Quick] [red] [fox]
```
