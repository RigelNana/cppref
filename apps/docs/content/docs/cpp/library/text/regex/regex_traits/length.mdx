{/* source:cpp-regex-regex-traits-length:0001 */}
Calculates the length of a null-terminated character sequence, that is, the smallest `i` such that `p[i] == 0`.

{/* source:cpp-regex-regex-traits-length:0002 */}
Standard library specializations of [`std::regex_traits`](/docs/cpp/library/text/regex/regex_traits) execute `std::char_traits<CharT>::length(p);`.

### Parameters

{/* source:cpp-regex-regex-traits-length:0003 */}
<ParameterList>
  <Parameter name="p">pointer to the first element of the null-terminated character sequence</Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-regex-traits-length:0004 */}
The length of the null-terminated character string.

### Example

{/* source:cpp-regex-regex-traits-length:0005 */}
```cpp
#include <iostream>
#include <regex>
 
int main()
{
    std::cout << std::regex_traits<char>::length("Кошка") << '\n'
              << std::regex_traits<wchar_t>::length(L"Кошка") << '\n';
}
```
Output:
```text
10
5
```
