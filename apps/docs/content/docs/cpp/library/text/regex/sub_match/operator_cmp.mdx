{/* source:cpp-regex-sub-match-operator-cmp:0001 */}
Compares a `sub_match` to another `sub_match`, a [`std::string`](/docs/cpp/library/string/basic_string), a C-style string or a single character.

{/* source:cpp-regex-sub-match-operator-cmp:0002 */}
1. 1-7) Compares two `sub_match` directly.

{/* source:cpp-regex-sub-match-operator-cmp:0003 */}
2. 8-20) Compares a `sub_match` with a [`std::basic_string`](/docs/cpp/library/string/basic_string).

{/* source:cpp-regex-sub-match-operator-cmp:0004 */}
3. 21-33) Compares a `sub_match` with a C-style string.

{/* source:cpp-regex-sub-match-operator-cmp:0005 */}
4. 34-46) Compares a `sub_match` with a single character.

{/* source:cpp-regex-sub-match-operator-cmp:0006 */}
<Revision since="C++20">
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.

</Revision>

{/* source:cpp-regex-sub-match-operator-cmp:0007 */}
1. 47) `value-type-of` ﻿`<BidirIt>` is the [value type](/docs/cpp/library/iterator#Types_and_writability) of `BidirIt`.

{/* source:cpp-regex-sub-match-operator-cmp:0008 */}
2. 48) `cat-type-of` ﻿`<BidirIt>` is the result type of three-way comparison of `std::sub_match<BidirIt>`.

### Parameters

{/* source:cpp-regex-sub-match-operator-cmp:0009 */}
<ParameterList>
  <Parameter name="lhs, rhs">a `sub_match` to compare</Parameter>

  <Parameter name="s">a pointer to a C-style string to compare</Parameter>
  <Parameter name="ch">a character to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-sub-match-operator-cmp:0010 */}
Let `target` be the following values:

{/* source:cpp-regex-sub-match-operator-cmp:0011 */}
1. 1-7) `rhs`

{/* source:cpp-regex-sub-match-operator-cmp:0012 */}
2. 8-20) `typename std::sub_match<BidirIt>::string_type(str.data(), str.size())`

{/* source:cpp-regex-sub-match-operator-cmp:0013 */}
3. 21-33) `s`

{/* source:cpp-regex-sub-match-operator-cmp:0014 */}
4. 34-46) `typename std::sub_match<BidirIt>::string_type(1, ch)`

{/* source:cpp-regex-sub-match-operator-cmp:0015 */}
The return values are defined as follows:

{/* source:cpp-regex-sub-match-operator-cmp:0016 */}
| Operator | Return value | Return value |
| --- | --- | --- |
| Operator | Overloads (1-14,21-27,34-40) (overloads with parameter `lhs`) | Overloads (15-20,28-33,41-46) (overloads without parameter `lhs`) |
| `==` | `lhs.compare(target) == 0` | `rhs.compare(target) == 0` |
| `!=` | `lhs.compare(target) != 0` | `rhs.compare(target) != 0` |
| `<` | `lhs.compare(target) < 0` | `rhs.compare(target) > 0` |
| `<=` | `lhs.compare(target) <= 0` | `rhs.compare(target) >= 0` |
| `>` | `lhs.compare(target) > 0` | `rhs.compare(target) < 0` |
| `>=` | `lhs.compare(target) >= 0` | `rhs.compare(target) <= 0` |
| `<=>` | `static_cast<cat-type-of ﻿<BidirIt>> (lhs.compare(target) <=> 0)` | N/A |

### Notes

{/* source:cpp-regex-sub-match-operator-cmp:0017 */}
The return type of `operator<=>` is guaranteed to be a comparison category type. If `value-type-of` ﻿`<BidirIt>` is `char`, `wchar_t`, `char8_t`, `char16_t`, or `char32_t`, the return type of `operator<=>` is [`std::strong_ordering`](/docs/cpp/library/utility/compare/strong_ordering).
