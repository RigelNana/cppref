{/* source:cpp-regex-sub-match-swap:0001 */}
Exchanges the contents of two sub-match objects. Equivalent to

{/* source:cpp-regex-sub-match-swap:0002 */}
`this->pair<BidirIt, BidirIt>::swap(s); std::swap(matched, s.matched);`

### Parameters

{/* source:cpp-regex-sub-match-swap:0003 */}
<ParameterList>
  <Parameter name="s">a `sub_match` to swap with</Parameter>
</ParameterList>

**Type requirements**

- `BidirIt` must meet the requirements of [*LegacySwappable*](https://en.cppreference.com/mwiki/index.php?title=cpp/named_req/LegacySwappable&action=edit&redlink=1).

### Exceptions

{/* source:cpp-regex-sub-match-swap:0004 */}
[`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification:  
`noexcept(std::is_nothrow_swappable_v<BidirIt>)`

### Example

{/* source:cpp-regex-sub-match-swap:0005 */}
```cpp
#include <cassert>
#include <iostream>
#include <regex>
 
int main()
{
    const char* s = "Quick red cat";
    std::sub_match<const char*> x, y;
 
    x.first = &s[0];
    x.second = &s[5];
    x.matched = false;
 
    y.first = &s[012];
    y.second = &s[13];
    y.matched = true;
 
    std::cout << "Before swap:\n";
    std::cout << "x.str() = [" << x.str() << "]\n";
    std::cout << "y.str() = [" << y.str() << "]\n";
    assert(!x.matched and y.matched);
 
    x.swap(y);
 
    std::cout << "After swap:\n";
    std::cout << "x.str() = [" << x.str() << "]\n";
    std::cout << "y.str() = [" << y.str() << "]\n";
    assert(x.matched and !y.matched);
}
```
Output:
```text
Before swap:
x.str() = []
y.str() = [cat]
After swap:
x.str() = [cat]
y.str() = []
```
