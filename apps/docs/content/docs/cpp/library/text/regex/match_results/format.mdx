  <DeclarationDescription>
    {/* source:cpp-regex-match-results-format:0001 */}
    `format` outputs a format string, replacing any format specifiers or escape sequences in that string with match data from `*this`.
    {/* source:cpp-regex-match-results-format:0002 */}
    1. The format character sequence is defined by the range [`fmt_first`, `fmt_last`). The resulting character sequence is copied to `out`.
    {/* source:cpp-regex-match-results-format:0003 */}
    2. The format character sequence is defined by the characters in `fmt`. The resulting character sequence is copied to `out`.
    {/* source:cpp-regex-match-results-format:0004 */}
    3. 3,4) The format character sequence is defined by the characters in `fmt` and `fmt_s` respectively. The resulting character sequence is copied to a newly constructed [`std::basic_string`](/docs/cpp/library/string/basic_string), which is returned.
    {/* source:cpp-regex-match-results-format:0005 */}
    The `flags` bitmask determines which format specifiers and escape sequences are recognized.
    {/* source:cpp-regex-match-results-format:0006 */}
    The behavior of `format` is undefined if `ready() != true`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

  </Parameter>

Type requirements

- `OutputIt` must meet the requirements of [`LegacyOutputIterator`](/docs/cpp/library/named_req/OutputIterator).

### Return value

{/* source:cpp-regex-match-results-format:0008 */}
1,2) `out`

{/* source:cpp-regex-match-results-format:0009 */}
3,4) The newly constructed string containing resulting character sequence.

### Exceptions

{/* source:cpp-regex-match-results-format:0010 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-regex-match-results-format:0011 */}
```cpp
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    std::string s = "for a good time, call 867-5309";
    std::regex phone_regex("\\d{3}-\\d{4}");
    std::smatch phone_match;
 
    if (std::regex_search(s, phone_match, phone_regex))
    {
        std::string fmt_s = phone_match.format(
            "$`"   // $` means characters before the match
            "[$&]" // $& means the matched characters
            "$'"); // $' means characters following the match
        std::cout << fmt_s << '\n';
    }   
}
```
Output:
```text
for a good time, call [867-5309]
```
