{/* source:cpp-regex-match-results-size:0001 */}
Returns the number of submatches, i.e. `std::distance(begin(), end())`.

{/* source:cpp-regex-match-results-size:0002 */}
Returns `0` if `*this` does not represent the result of a successful match.

### Parameters

{/* source:cpp-regex-match-results-size:0003 */}
(none)

### Return value

{/* source:cpp-regex-match-results-size:0004 */}
The number of submatches.

### Complexity

{/* source:cpp-regex-match-results-size:0005 */}
Constant.

### Example

{/* source:cpp-regex-match-results-size:0006 */}
```cpp
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    std::regex re("a(a)*b");
    std::string target("aaab");
    std::smatch sm;
 
    std::cout << sm.size() << '\n';
 
    std::regex_match(target, sm, re);
    std::cout << sm.size() << '\n';
}
```
Output:
```text
0
2
```
