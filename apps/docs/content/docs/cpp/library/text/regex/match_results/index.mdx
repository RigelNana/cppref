{/* source:cpp-regex-match-results:0001 */}
The class template `std::match_results` holds a collection of character sequences that represent the result of a regular expression match.

{/* source:cpp-regex-match-results:0002 */}
This is a specialized allocator-aware container. It can only be default created, obtained from [`std::regex_iterator`](/docs/cpp/library/text/regex/regex_iterator), or modified by [`std::regex_search`](/docs/cpp/library/text/regex/regex_search) or [`std::regex_match`](/docs/cpp/library/text/regex/regex_match). Because `std::match_results` holds [`std::sub_match`](/docs/cpp/library/text/regex/sub_match)es, each of which is a pair of iterators into the original character sequence that was matched, it's undefined behavior to examine `std::match_results` if the original character sequence was destroyed or iterators to it were invalidated for other reasons.

{/* source:cpp-regex-match-results:0003 */}
The first [`std::sub_match`](/docs/cpp/library/text/regex/sub_match) (index 0) contained in a `std::match_result` always represents the full match within a target sequence made by a regex, and subsequent [`std::sub_match`](/docs/cpp/library/text/regex/sub_match)es represent sub-expression matches corresponding in sequence to the left parenthesis delimiting the sub-expression in the regex.

{/* source:cpp-regex-match-results:0004 */}
`std::match_results` meets the requirements of a [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer) and of a [`SequenceContainer`](/docs/cpp/library/named_req/SequenceContainer), except that only copy assignment, move assignment, and operations defined for a constant containers are supported, and that the semantics of comparison functions are different from those required for a container.

### Type requirements

{/* source:cpp-regex-match-results:0005 */}
Type requirements

- `BidirIt` must meet the requirements of [`LegacyBidirectionalIterator`](/docs/cpp/library/named_req/BidirectionalIterator).
- `Alloc` must meet the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator).
