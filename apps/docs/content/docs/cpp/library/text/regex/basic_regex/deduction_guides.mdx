This [deduction guide](/docs/cpp/language/templates/ctad) is provided for [`std::basic_regex`](/docs/cpp/library/text/regex/basic_regex) to allow deduction from an iterator range.

### Example

{/* source:cpp-regex-basic-regex-deduction-guides:0002 */}
```cpp
#include <regex>
#include <vector>
 
int main()
{
    std::vector<char> v = {'a', 'b', 'c'};
    std::basic_regex re(v.begin(), v.end()); // uses explicit deduction guide
}
```
