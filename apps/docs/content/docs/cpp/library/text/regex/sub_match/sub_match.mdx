{/* source:cpp-regex-sub-match-sub-match:0001 */}
Default constructs a [`std::sub_match`](/docs/cpp/library/text/regex/sub_match). The [`matched`](/docs/cpp/library/text/regex/sub_match#Data_members) member is set to `false` and the inherited members [`first`](/docs/cpp/library/text/regex/sub_match#Data_members) and [`second`](/docs/cpp/library/text/regex/sub_match#Data_members) are value-initialized.

{/* source:cpp-regex-sub-match-sub-match:0002 */}
This is the only publicly accessible and defined constructor.

### Example

{/* source:cpp-regex-sub-match-sub-match:0003 */}
```cpp
#include <cassert>
#include <regex>
 
int main()
{
    std::sub_match<const char*> s;
    assert(!s.matched);
}
```
