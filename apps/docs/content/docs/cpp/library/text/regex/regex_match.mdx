{/* source:cpp-regex-regex-match:0001 */}
Determines if the regular expression `e` matches the entire target character sequence. The detailed match result is stored in `m` (if present).

{/* source:cpp-regex-regex-match:0002 */}
1. 1,2) The target character sequence is represented by the range `[``first``, ``last``)`.
   <Revision until="C++23">
   If `BidirIt` does not satisfy the requirements of [*LegacyBidirectionalIterator*](/docs/cpp/library/named_req/BidirectionalIterator), the behavior is undefined.
   
   </Revision>
   
   <Revision since="C++23">
   If `BidirIt` does not model [`bidirectional_iterator`](/docs/cpp/library/iterator/bidirectional_iterator), the behavior is undefined.
   
   </Revision>

{/* source:cpp-regex-regex-match:0003 */}
2. 3,4) The target character sequence is represented by the range `[``str``, ``str + std::char_traits<CharT>::length(str)``)`.

{/* source:cpp-regex-regex-match:0004 */}
3. 5,6) The target character sequence is represented by the string `s`.

{/* source:cpp-regex-regex-match:0005 */}
4. 7) The target character sequence cannot be represented by a [`std::string`](/docs/cpp/library/string/basic_string) rvalue.

### Return value

{/* source:cpp-regex-regex-match:0012 */}
Returns `true` if the entire target sequence matches `e`, `false` otherwise.

### Notes

{/* source:cpp-regex-regex-match:0013 */}
Because `regex_match` only considers full matches, the same regex may give different matches between `regex_match` and [`std::regex_search`](/docs/cpp/library/text/regex/regex_search):

{/* source:cpp-regex-regex-match:0014 */}
```cpp
std::regex re("Get|GetValue");
std::cmatch m;
std::regex_search("GetValue", m, re);  // returns true, and m[0] contains "Get"
std::regex_match ("GetValue", m, re);  // returns true, and m[0] contains "GetValue"
std::regex_search("GetValues", m, re); // returns true, and m[0] contains "Get"
std::regex_match ("GetValues", m, re); // returns false
```

### Example

{/* source:cpp-regex-regex-match:0015 */}
```cpp
#include <cstddef>
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    // Simple regular expression matching
    const std::string fnames[] = {"foo.txt", "bar.txt", "baz.dat", "zoidberg"};
    const std::regex txt_regex("[a-z]+\\.txt");
 
    for (const auto& fname : fnames)
        std::cout << fname << ": " << std::regex_match(fname, txt_regex) << '\n';
 
    // Extraction of a sub-match
    const std::regex base_regex("([a-z]+)\\.txt");
    std::smatch base_match;
 
    for (const auto& fname : fnames)
        if (std::regex_match(fname, base_match, base_regex))
            // The first sub_match is the whole string; the next
            // sub_match is the first parenthesized expression.
            if (base_match.size() == 2)
            {
                std::ssub_match base_sub_match = base_match[1];
                std::string base = base_sub_match.str();
                std::cout << fname << " has a base of " << base << '\n';
            }
 
    // Extraction of several sub-matches
    const std::regex pieces_regex("([a-z]+)\\.([a-z]+)");
    std::smatch pieces_match;
 
    for (const auto& fname : fnames)
        if (std::regex_match(fname, pieces_match, pieces_regex))
        {
            std::cout << fname << '\n';
            for (std::size_t i = 0; i < pieces_match.size(); ++i)
            {
                std::ssub_match sub_match = pieces_match[i];
                std::string piece = sub_match.str();
                std::cout << "  submatch " << i << ": " << piece << '\n';
            }
        }
}
```

```text
baz.dat: 0
zoidberg: 0

bar.txt has a base of bar

  submatch 1: bar
  submatch 2: txt

  submatch 0: baz.dat
  submatch 1: baz
  submatch 2: dat
```
