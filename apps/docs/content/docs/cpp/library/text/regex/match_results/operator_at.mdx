{/* source:cpp-regex-match-results-operator-at:0001 */}
If `n > 0` and `n < size()`, returns a reference to the [`std::sub_match`](/docs/cpp/library/text/regex/sub_match) representing the part of the target sequence that was matched by the `n`th captured [marked subexpression](/docs/cpp/library/text/regex/ecmascript#Sub-expressions)).

{/* source:cpp-regex-match-results-operator-at:0002 */}
If `n == 0`, returns a reference to the [`std::sub_match`](/docs/cpp/library/text/regex/sub_match) representing the part of the target sequence matched by the entire matched regular expression.

{/* source:cpp-regex-match-results-operator-at:0003 */}
if `n >= size()`, returns a reference to a [`std::sub_match`](/docs/cpp/library/text/regex/sub_match) representing an unmatched sub-expression (an empty subrange of the target sequence).

{/* source:cpp-regex-match-results-operator-at:0004 */}
[`ready()`](/docs/cpp/library/text/regex/match_results/ready) must be `true`. Otherwise, the behavior is undefined.

### Parameters

{/* source:cpp-regex-match-results-operator-at:0005 */}
<ParameterList>
  <Parameter name="n">
    integral number specifying which match to return
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-match-results-operator-at:0006 */}
Reference to the [`std::sub_match`](/docs/cpp/library/text/regex/sub_match) representing the specified matched subrange within the target sequence.

### Example

{/* source:cpp-regex-match-results-operator-at:0007 */}
```cpp
#include <iostream>
#include <regex>
#include <string>
 
int main()
{
    std::string target("baaaby");
    std::smatch sm;
 
    std::regex re1("a(a)*b");
    std::regex_search(target, sm, re1);
    std::cout << "entire match: " << sm[0] << '\n'
              << "submatch #1: " << sm[1] << '\n';
 
    std::regex re2("a(a*)b");
    std::regex_search(target, sm, re2);
    std::cout << "entire match: " << sm[0] << '\n'
              << "submatch #1: " << sm[1] << '\n';
}
```
Output:
```text
entire match: aaab
submatch #1: a
entire match: aaab
submatch #1: aa
```
