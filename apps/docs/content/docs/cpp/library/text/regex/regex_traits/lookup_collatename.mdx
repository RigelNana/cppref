{/* source:cpp-regex-regex-traits-lookup-collatename:0001 */}
If the character sequence `[``first``, ``last``)` represents the name of a valid collating element in the currently imbued locale, returns the name of that collating element. Otherwise, returns an empty string.

{/* source:cpp-regex-regex-traits-lookup-collatename:0002 */}
Collating elements are the symbols found in POSIX regular expressions between `[.` and `.]`. For example, `[.a.]` matches the character `a` in the C locale. `[.tilde.]` matches the character `~` in the C locale as well. `[.ch.]` matches the digraph `ch` in Czech locale, but generates [`std::regex_error`](/docs/cpp/library/text/regex/regex_error) with error code [`std::regex_constants::error_collate`](/docs/cpp/library/text/regex/error_type) in most other locales.

### Parameters

{/* source:cpp-regex-regex-traits-lookup-collatename:0003 */}
<ParameterList>
  <Parameter name="first, last">a pair of iterators which determines the sequence of characters that represents a collating element name</Parameter>
</ParameterList>

**Type requirements**

- `ForwardIt` must meet the requirements of [*LegacyForwardIterator*](/docs/cpp/library/named_req/ForwardIterator).

### Return value

{/* source:cpp-regex-regex-traits-lookup-collatename:0004 */}
The representation of the named collating element as a character string.

### Example

{/* source:cpp-regex-regex-traits-lookup-collatename:0005 */}
```cpp
#include <iostream>
#include <regex>
#include <string>
 
struct noisy_traits : std::regex_traits<char>
{
    template<class Iter>
    string_type lookup_collatename(Iter first, Iter last) const
    {
        string_type result = regex_traits::lookup_collatename(first, last);
        std::cout << "regex_traits<>::lookup_collatename(\""
                  << string_type(first, last)
                  << "\") returns \"" << result << "\"\n";
        return result;
    }
};
 
int main()
{
    std::string str = "z|}a"; // C locale collation order: x,y,z,{,|,},~
    std::basic_regex<char, noisy_traits> re("[x-[.tilde.]]*a", std::regex::basic);
    std::cout << std::boolalpha << std::regex_match(str, re) << '\n';
}
```
Possible output:
```text
regex_traits<>::lookup_collatename("tilde") returns "~"
true
```
