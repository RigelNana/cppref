{/* source:cpp-regex-regex-token-iterator-operator-cmp:0001 */}
Checks whether `*this` and `other` are equivalent.

{/* source:cpp-regex-regex-token-iterator-operator-cmp:0002 */}
Two regex token iterators are equal if:

{/* source:cpp-regex-regex-token-iterator-operator-cmp:0003 */}
1. a) They are both end-of-sequence iterators.

{/* source:cpp-regex-regex-token-iterator-operator-cmp:0004 */}
2. b) They are both suffix iterators and the suffixes are equal.

{/* source:cpp-regex-regex-token-iterator-operator-cmp:0005 */}
3. c) Neither of them is end-of-sequence or suffix iterator and:

{/* source:cpp-regex-regex-token-iterator-operator-cmp:0006 */}
-  `position == other.position`

-  `N == other.N`

-  `subs == other.subs`

{/* source:cpp-regex-regex-token-iterator-operator-cmp:0007 */}
1. 1) Checks whether `*this` is *equal to* `other`.

{/* source:cpp-regex-regex-token-iterator-operator-cmp:0008 */}
2. 2) Checks whether `*this` is *not equal to* `other`.

{/* source:cpp-regex-regex-token-iterator-operator-cmp:0009 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
