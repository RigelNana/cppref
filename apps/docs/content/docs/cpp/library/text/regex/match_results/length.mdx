{/* source:cpp-regex-match-results-length:0001 */}
Returns the length of the specified sub-match.

{/* source:cpp-regex-match-results-length:0002 */}
If `n == 0`, the length of the entire matched expression is returned.

{/* source:cpp-regex-match-results-length:0003 */}
If `n > 0 && n < size()`, the length of `n`th sub-match is returned.

{/* source:cpp-regex-match-results-length:0004 */}
if `n >= size()`, a length of the unmatched match is returned.

{/* source:cpp-regex-match-results-length:0005 */}
The call is equivalent to `(*this)[n].length()`.

{/* source:cpp-regex-match-results-length:0006 */}
[`ready()`](/docs/cpp/library/text/regex/match_results/ready) must be `true`. Otherwise, the behavior is undefined.

### Parameters

{/* source:cpp-regex-match-results-length:0007 */}
<ParameterList>
  <Parameter name="n">
    integral number specifying which match to examine
  </Parameter>
</ParameterList>

### Return value

{/* source:cpp-regex-match-results-length:0008 */}
The length of the specified match or sub-match.
