{/* source:cpp-regex-regex-traits:0001 */}
The type trait template `regex_traits` supplies [`std::basic_regex`](/docs/cpp/library/text/regex/basic_regex) with the set of types and functions necessary to operate on the type `CharT`.

{/* source:cpp-regex-regex-traits:0002 */}
Since many of regex operations are locale-sensitive (when [`std::regex_constants::collate`](/docs/cpp/library/text/regex/syntax_option_type) flag is set), the regex_traits class typically holds an instance of a [`std::locale`](/docs/cpp/library/text/locale/locale) as a private member.

### Standard specializations

{/* source:cpp-regex-regex-traits:0003 */}
Two specializations of `std::regex_traits` are defined by the standard library:

{/* source:cpp-regex-regex-traits:0004 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`std::regex_traits<char>`</DescriptionTerm>
    <DescriptionBody></DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`std::regex_traits<wchar_t>`</DescriptionTerm>
    <DescriptionBody></DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-regex-regex-traits:0005 */}
These specializations make it possible to use `std::basic_regex<char>` (aka [`std::regex`](/docs/cpp/library/text/regex/basic_regex)) and `std::basic_regex<wchar_t>` (aka [`std::wregex`](/docs/cpp/library/text/regex/basic_regex)). To use [`std::basic_regex`](/docs/cpp/library/text/regex/basic_regex) with other character types (for example, `char32_t`), a user-provided trait class must be used.
