{/* source:cpp-regex-regex-error-operator:0001 */}
Assigns the contents with those of `other`. If `*this` and `other` both have dynamic type `std::regex_error` then `std::strcmp(what(), other.what()) == 0` after assignment.

### Parameters

{/* source:cpp-regex-regex-error-operator:0002 */}
<ParameterList>
  <Parameter name="other">another `regex_error` object to assign with</Parameter>
</ParameterList>

### Return value
