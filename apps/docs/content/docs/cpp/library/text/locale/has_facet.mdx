{/* source:cpp-locale-has-facet:0001 */}
Checks if the locale `loc` implements the facet `Facet`.

{/* source:cpp-locale-has-facet:0002 */}
The program is ill-formed if `Facet` is not a [facet](/docs/cpp/library/text/locale/locale/facet#Facet_class) or it is a volatile-qualified facet.

### Parameters

{/* source:cpp-locale-has-facet:0003 */}
<ParameterList>
  <Parameter name="loc">the locale object to query</Parameter>
</ParameterList>

### Return value

{/* source:cpp-locale-has-facet:0004 */}
Returns `true` if the facet `Facet` was installed in the locale `loc`, `false` otherwise.

### Notes

{/* source:cpp-locale-has-facet:0005 */}
`std::has_facet` must return `true` for all locales `loc` if `Facet` is one of the standard facets given [here](/docs/cpp/library/text/locale/locale).

### Example

{/* source:cpp-locale-has-facet:0006 */}
```cpp
#include <iostream>
#include <locale>
 
// minimal custom facet
struct myfacet : public std::locale::facet
{
    static std::locale::id id;
};
 
std::locale::id myfacet::id;
 
int main()
{
    // loc is a "C" locale with myfacet added
    std::locale loc(std::locale::classic(), new myfacet);
    std::cout << std::boolalpha
              << "Can loc classify chars? "
              << std::has_facet<std::ctype<char>>(loc) << '\n'
              << "Can loc classify char32_t? "
              << std::has_facet<std::ctype<char32_t>>(loc) << '\n'
              << "Does loc implement myfacet? "
              << std::has_facet<myfacet>(loc) << '\n';
}
```
Output:
```text
Can loc classify chars? true
Can loc classify char32_t? false
Does loc implement myfacet? true
```
