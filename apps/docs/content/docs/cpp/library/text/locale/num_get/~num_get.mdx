Destructs a [`std::num_get`](/docs/cpp/library/text/locale/num_get) facet. This destructor is protected and virtual (due to [base class](/docs/cpp/library/text/locale/locale/facet) destructor being virtual). An object of type [`std::num_get`](/docs/cpp/library/text/locale/num_get), like most facets, can only be destroyed when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object that implements this facet goes out of scope or if a user-defined class is derived from [`std::num_get`](/docs/cpp/library/text/locale/num_get) and implements a public destructor.

### Example

{/* source:cpp-locale-num-get-num-get:0002 */}

```cpp
#include <iostream>
#include <locale>
 
struct Destructible_num_get : public std::num_get<wchar_t>
{
    Destructible_num_get(std::size_t refs = 0) : num_get(refs) {}
    // note: the implicit destructor is public
};
 
int main()
{
    Destructible_num_get dc;
    // std::num_get<wchar_t> c; // compile error: protected destructor
}
```
