  <DeclarationDescription>
    {/* source:cpp-locale-wstring-convert:0001 */}
    Class template `std::wstring_convert` performs conversions between byte string [`std::string`](/docs/cpp/library/string/basic_string) and wide string `std::basic_string<Elem>`, using an individual code conversion facet `Codecvt`. `std::wstring_convert` assumes ownership of the conversion facet, and cannot use a facet managed by a locale.

    {/* source:cpp-locale-wstring-convert:0002 */}
    The standard facets suitable for use with `std::wstring_convert` are [`std::codecvt_utf8`](/docs/cpp/library/text/locale/codecvt_utf8) for UTF-8/UCS-2 and UTF-8/UCS-4 conversions and [`std::codecvt_utf8_utf16`](/docs/cpp/library/text/locale/codecvt_utf8_utf16) for UTF-8/UTF-16 conversions.

  </DeclarationDescription>
</DeclarationDoc>
