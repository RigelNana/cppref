{/* source:cpp-locale-moneypunct-pos-format:0005 */}

The standard specializations of [`std::moneypunct`](/docs/cpp/library/text/locale/moneypunct) return the pattern `{symbol, sign, none, value}`.

### Return value

{/* source:cpp-locale-moneypunct-pos-format:0006 */}

The object of type [`std::money_base::format`](/docs/cpp/library/text/locale/money_base) describing the formatting used by this locale.

### Notes

{/* source:cpp-locale-moneypunct-pos-format:0007 */}

While [`std::money_put`](/docs/cpp/library/text/locale/money_put) uses `pos_format` for formatting positive values and neg_format for formatting negative values, [`std::money_get`](/docs/cpp/library/text/locale/money_get) uses `neg_format` for parsing all monetary values: it assumes that `neg_format` is compatible with `pos_format`.

### Example

{/* source:cpp-locale-moneypunct-pos-format:0008 */}

```cpp
#include <iomanip>
#include <iostream>
#include <locale>
 
struct my_punct : std::moneypunct_byname<char, false>
{
    my_punct(const char* name) : moneypunct_byname(name) {}
    pattern do_pos_format() const { return {value, space, symbol, sign}; }
    pattern do_neg_format() const { return {value, space, symbol, sign}; }
};
 
int main()
{
    std::cout.imbue(std::locale("en_US.utf8"));
    std::cout << "american locale: " << std::showbase
              << std::put_money(12345678.0) << '\n';
 
    std::cout.imbue(std::locale(std::cout.getloc(), new my_punct("en_US.utf8")));
    std::cout << "locale with modified moneypunct:\n"
              << std::put_money(12345678.0) << '\n'
              << std::put_money(-12345678.0) << '\n';
}
```

Output:

```text
american locale: $123,456.78
locale with modified moneypunct:
123,456.78 $
123,456.78 $-
```
