{/* source:cpp-locale-ctype-char-ctype:0001 */}
Destructs a `std::ctype<char>` facet. This destructor is protected and virtual (due to [base class](/docs/cpp/library/text/locale/locale/facet) destructor being virtual). An object of type `std::ctype<char>`, like most facets, can only be destroyed when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object that implements this facet goes out of scope or if a user-defined class is derived from `std::ctype<char>` and implements a public destructor.

{/* source:cpp-locale-ctype-char-ctype:0002 */}
If, when this instance of `std::ctype<char>` was constructed, a custom classification table was provided and the second argument to the constructor (the boolean `del`) was `true`, then this destructor executes `delete[] table()`.
