The class `std::money_base` provides constants which are inherited and used by the [`std::moneypunct`](/docs/cpp/library/text/locale/moneypunct), [`std::money_get`](/docs/cpp/library/text/locale/money_get) and [`std::money_put`](/docs/cpp/library/text/locale/money_put) facets.

### Notes

{/* source:cpp-locale-money-base:0004 */}

The monetary format is an array of four `chars` convertible to `std::money_base::part`. In that sequence, each of `symbol`, `sign`, and `value` appears exactly once, and either `space` or `none` appears in the remaining position. The value `none`, if present, is not first; the value `space`, if present, is neither first nor last.

{/* source:cpp-locale-money-base:0005 */}

The default format, returned by the standard specializations of [`std::moneypunct`](/docs/cpp/library/text/locale/moneypunct) is `{symbol, sign, none, value}`.
