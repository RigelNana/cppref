{/* source:cpp-locale-isprint:0001 */}
Checks if the given character is classified as a printable character (including space) by the given locale's [std::ctype](/docs/cpp/library/text/locale/ctype) facet.

### Parameters

{/* source:cpp-locale-isprint:0002 */}
<ParameterList>
  <Parameter name="ch">character</Parameter>
  <Parameter name="loc">locale</Parameter>
</ParameterList>

### Return value

{/* source:cpp-locale-isprint:0003 */}
Returns `true` if the character is classified as printable, `false` otherwise.

### Possible implementation

{/* source:cpp-locale-isprint:0004 */}
```cpp
template<class CharT>
bool isprint(CharT ch, const std::locale& loc)
{
    return std::use_facet<std::ctype<CharT>>(loc).is(std::ctype_base::print, ch);
}
```

### Example

{/* source:cpp-locale-isprint:0005 */}
Demonstrates the use of `isprint()` with different locales (OS-specific).
```cpp
#include <iostream>
#include <locale>
 
int main()
{
    const wchar_t c = L'\u2122'; // trademark sign
 
    std::locale loc1("C");
    std::cout << "isprint('™', C locale) returned "
              << std::boolalpha << std::isprint(c, loc1) << '\n';
 
    std::locale loc2("en_US.UTF-8");
    std::cout << "isprint('™', Unicode locale) returned "
              << std::boolalpha << std::isprint(c, loc2) << '\n';
}
```
Possible output:
```text
isprint('™', C locale) returned false
isprint('™', Unicode locale) returned true
```
