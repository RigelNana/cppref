  <DeclarationDescription>
    {/* source:cpp-locale-codecvt-in:0001 */}
    1) Public member function, calls the member function `do_in` of the most derived class.

    {/* source:cpp-locale-codecvt-in:0002 */}
    2) If this `codecvt` facet defines a conversion, translates the external characters from the source range `[from, from_end)` to internal characters, placing the results in the subsequent locations starting at `to`. Converts no more than `from_end - from` external characters and writes no more than `to_end - to` internal characters. Leaves `from_next` and `to_next` pointing one beyond the last element successfully converted.

  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-locale-codecvt-in:0003 */}
If this `codecvt` facet does not define a conversion, no characters are converted. `to_next` is set to be equal to `to`, `state` is unchanged, and [`std::codecvt_base::noconv`](/docs/cpp/library/text/locale/codecvt_base) is returned.

{/* source:cpp-locale-codecvt-in:0004 */}
`do_in(state, from, from_end, from_next, to, to + 1, to_next)` must return `ok` if

{/* source:cpp-locale-codecvt-in:0005 */}
- this `codecvt` facet is used by [`basic_filebuf`](/docs/cpp/library/io/basic_filebuf), and
- `do_in(state, from, from_end, from_next, to, to_end, to_next)` would return `ok` where `to != to_end`.

### Return value

{/* source:cpp-locale-codecvt-in:0006 */}
A value of type [`std::codecvt_base::result`](/docs/cpp/library/text/locale/codecvt_base), indicating the success status as follows:

{/* source:cpp-locale-codecvt-in:0007 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`ok`</DescriptionTerm>
    <DescriptionBody>conversion completed</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`partial`</DescriptionTerm>
    <DescriptionBody>not enough space in the output buffer or unexpected end of source buffer</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`error`</DescriptionTerm>
    <DescriptionBody>encountered a character that could not be converted</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`noconv`</DescriptionTerm>
    <DescriptionBody>this facet is non-converting, no output written</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-locale-codecvt-in:0008 */}
The non-converting specialization `std::codecvt<char, char, std::mbstate_t>` always returns [`std::codecvt_base::noconv`](/docs/cpp/library/text/locale/codecvt_base).

### Notes

{/* source:cpp-locale-codecvt-in:0009 */}
Requires that `from <= from_end && to <= to_end` and that `state` either representing the initial shift state or obtained by converting the preceding characters in the sequence.

{/* source:cpp-locale-codecvt-in:0010 */}
The effect on `state` is deliberately unspecified. In standard facets, it is used to maintain shift state like when calling [`std::mbsrtowcs`](/docs/cpp/library/text/multibyte/mbsrtowcs), and is therefore updated to reflect the conversion state after the last processed external character, but a user-defined facet is free to use it to maintain any other state, e.g. count the number of special characters encountered.

### Example

{/* source:cpp-locale-codecvt-in:0011 */}
```cpp
#include <iostream>
#include <locale>
#include <string>
 
int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    auto const& f = std::use_facet<std::codecvt<wchar_t, char, std::mbstate_t>>
        (std::locale());
    std::string external = "z\u00df\u6c34\U0001d10b"; // or u8"zß水𝄋"
                     // or "\x7a\xc3\x9f\xe6\xb0\xb4\xf0\x9d\x84\x8b"
 
    // note that the following can be done with wstring_convert
    std::mbstate_t mb = std::mbstate_t(); // initial shift state
    std::wstring internal(external.size(), '\0'); 
    const char* from_next;
    wchar_t* to_next;
    f.in(mb, &external[0], &external[external.size()], from_next,
             &internal[0], &internal[internal.size()], to_next);
    // error checking skipped for brevity
    internal.resize(to_next - &internal[0]);
 
    std::wcout << L"The string in wide encoding: " << internal << '\n';
}
```
Output:
```text
The string in wide encoding: zß水𝄋
```
