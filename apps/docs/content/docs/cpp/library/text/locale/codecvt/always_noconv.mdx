    1) Public member function, calls the member function `do_always_noconv` of the most derived class.

    {/* source:cpp-locale-codecvt-always-noconv:0002 */}
    2) Returns `true` if both [`do_in()`](/docs/cpp/library/text/locale/codecvt/in) and [`do_out()`](/docs/cpp/library/text/locale/codecvt/out) return `std::codecvt_base::noconv` for all valid inputs.

  </DeclarationDescription>
</DeclarationDoc>

### Return value

{/* source:cpp-locale-codecvt-always-noconv:0003 */}
`true` if this conversion facet performs no conversions, `false` otherwise.

{/* source:cpp-locale-codecvt-always-noconv:0004 */}
The non-converting specialization `std::codecvt<char, char, std::mbstate_t>` returns `true`.

### Notes

{/* source:cpp-locale-codecvt-always-noconv:0005 */}
This function may be used e.g. in the implementation of [`std::basic_filebuf::underflow`](/docs/cpp/library/io/basic_streambuf/underflow) and [`std::basic_filebuf::overflow`](/docs/cpp/library/io/basic_streambuf/overflow) to use bulk character copy instead of calling [`std::codecvt::in`](/docs/cpp/library/text/locale/codecvt/in) or [`std::codecvt::out`](/docs/cpp/library/text/locale/codecvt/out) if it is known that the locale imbued in the [`std::basic_filebuf`](/docs/cpp/library/io/basic_filebuf) does not perform any conversions.

### Example

{/* source:cpp-locale-codecvt-always-noconv:0006 */}
```cpp
#include <iostream>
#include <locale>
 
int main()
{
    std::cout << "The non-converting char<->char codecvt::always_noconv() returns " 
              << std::boolalpha
              << std::use_facet<std::codecvt<char, char, std::mbstate_t>>(
                    std::locale()
                 ).always_noconv() << '\n'
              << "while wchar_t<->char codecvt::always_noconv() returns "
              << std::use_facet<std::codecvt<wchar_t, char, std::mbstate_t>>(
                    std::locale()
                 ).always_noconv() << '\n';
}
```
Output:
```text
The non-converting char<->char codecvt::always_noconv() returns true
while wchar_t<->char codecvt::always_noconv() returns false
```
