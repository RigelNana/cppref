{/* source:cpp-locale-num-put:0001 */}

Class `std::num_put` encapsulates the rules for formatting numeric values as strings. Specifically, the types `bool`, `long`, `unsigned long`<InlineRevision since="C++11">, `long long`, `unsigned long long`</InlineRevision>, `double`, `long double`, `void*`, and of all types implicitly convertible to these (such as `int` or `float`) are supported. The standard formatting output operators (such as `cout << n;`) use the `std::num_put` facet of the I/O stream's locale to generate text representation of numbers.

{/* source:cpp-locale-num-put:0002 */}

Inheritance diagram

{/* source:cpp-locale-num-put:0003 */}

If a `std::num_put` specialization is not guaranteed to be provided by the standard library (see below), the behaviors of its [`put()`](/docs/cpp/library/text/locale/num_put/put) and [`do_put()`](/docs/cpp/library/text/locale/num_put/put) are not guaranteed as specified.

### Specializations

{/* source:cpp-locale-num-put:0004 */}

The standard library is guaranteed to provide the following specializations (they are [required to be implemented by any locale object](/docs/cpp/library/text/locale/locale)):

{/* source:cpp-locale-num-put:0005 */}

Defined in header [`<locale>`](/docs/cpp/library/headers/locale)

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`std::num_put<char>`</DescriptionTerm>
    <DescriptionBody>creates narrow string representations of numbers</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`std::num_put<wchar_t>`</DescriptionTerm>
    <DescriptionBody>creates wide string representations of numbers</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-locale-num-put:0006 */}

In addition, the standard library is also guaranteed to provide every specialization that satisfies the following type requirements:

{/* source:cpp-locale-num-put:0007 */}

- `CharT` is one of
  - `char`,
  - `wchar_t`, and
  - any other implementation-defined [character container type](/docs/cpp/library/string) that meets the requirements for a character on which any of the [iostream components](/docs/cpp/library/io) can be instantiated; and
- `OutputIt` must meet the requirements of [*LegacyOutputIterator*](/docs/cpp/library/named_req/OutputIterator).

### Example

{/* source:cpp-locale-num-put:0012 */}

```cpp
#include <iostream>
#include <iterator>
#include <locale>
#include <string>
 
int main()
{
    double n = 1234567.89;
    std::cout.imbue(std::locale("de_DE.UTF-8"));
    std::cout << "Direct conversion to string:\n"
              << std::to_string(n) << '\n'
              << "Output using a german locale:\n"
              << std::fixed << n << '\n'
              << "Output using an american locale:\n";
 
    // use the facet directly
    std::cout.imbue(std::locale("en_US.UTF-8"));
    auto& f = std::use_facet<std::num_put<char>>(std::cout.getloc());
    f.put(std::ostreambuf_iterator<char>(std::cout), std::cout, ' ', n);
    std::cout << '\n';
}
```

Possible output:

```text
Direct conversion to string:
1234567.890000
Output using a german locale:
1.234.567,890000
Output using an american locale:
1,234,567.890000
```

### Defect reports

{/* source:cpp-locale-num-put:0013 */}

The following behavior-changing defect reports were applied retroactively to previously published C++ standards.

{/* source:cpp-locale-num-put:0014 */}

<DefectReportList>
  <DefectReport kind="lwg" id={427} standard="C++98">
    <PublishedBehavior>`num_put` was guaranteed to accept any `CharT` that<br />meets the requirements for a character on which<br />any of the iostream components can be instantiated</PublishedBehavior>
    <CorrectedBehavior>only guarantees to accept `char`,<br />`wchar_t` and other implementation-<br />defined character types</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={2392} standard="C++98">
    <PublishedBehavior>only character type `CharT` could be<br />guaranteed to be accepted by `num_put`</PublishedBehavior>
    <CorrectedBehavior>can guarantee to accept implementation-<br />defined character container types</CorrectedBehavior>
  </DefectReport>
</DefectReportList>
