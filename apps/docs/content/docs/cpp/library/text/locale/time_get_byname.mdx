#### std::time_get_byname::time_get_byname

<DeclarationDoc>

  <Declaration language="cpp" code={`explicit time_get_byname( const char* name, std::size_t refs = 0 );`} />

  <Declaration language="cpp" since="C++11" code={`explicit time_get_byname( const std::string& name, std::size_t refs = 0 );`} />

</DeclarationDoc>

Constructs a new `std::time_get_byname` facet for a locale with `name`.

`refs` is used for resource management: if `refs == 0`, the implementation destroys the facet, when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object holding it is destroyed. Otherwise, the object is not destroyed.

### Parameters

<ParameterList>

  <Parameter name="name">the name of the locale</Parameter>

  <Parameter name="refs">the number of references that link to the facet</Parameter>
