#### std::numpunct_byname::numpunct_byname

<DeclarationDoc>

  <Declaration language="cpp" code={`explicit numpunct_byname( const char* name, std::size_t refs = 0 );`} />

  <Declaration language="cpp" since="C++11" code={`explicit numpunct_byname( const std::string& name, std::size_t refs = 0 );`} />

</DeclarationDoc>

Constructs a new `std::numpunct_byname` facet for a locale with `name`.

`refs` is used for resource management: if `refs == 0`, the implementation destroys the facet, when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object holding it is destroyed. Otherwise, the object is not destroyed.

### Example

{/* source:cpp-locale-numpunct-byname:0009 */}
This example demonstrates how to apply numeric punctuation rules of another language without changing the rest of the locale.
```cpp
#include <iostream>
#include <locale>
 
int main()
{
    const double number = 1000.25;
    std::wcout << L"default locale: " << number << L'\n';
    std::wcout.imbue(std::locale(std::wcout.getloc(),
                                 new std::numpunct_byname<wchar_t>("ru_RU.UTF8")));
    std::wcout << L"default locale with russian numpunct: " << number << L'\n';
}
```
Output:
```text
default locale: 1000.25
default locale with russian numpunct: 1 000,25
```
