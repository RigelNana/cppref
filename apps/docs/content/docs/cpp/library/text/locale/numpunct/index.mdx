The facet `std::numpunct` encapsulates numeric punctuation preferences. Stream I/O operations use `std::numpunct` through [`std::num_get`](/docs/cpp/library/text/locale/num_get) and [`std::num_put`](/docs/cpp/library/text/locale/num_put) for parsing numeric input and formatting numeric output.

{/* source:cpp-locale-numpunct:0002 */}

The numbers that are supported by `std::numpunct` have the format described below. Here `digit` represents the radix set specified by the `fmtflags` argument value, `thousands-sep` and `decimal-point` are the results of [`thousands_sep()`](/docs/cpp/library/text/locale/numpunct/thousands_sep) and [`decimal_point()`](/docs/cpp/library/text/locale/numpunct/decimal_point) functions respectively.

{/* source:cpp-locale-numpunct:0003 */}

The format of integer values is as follows:

{/* source:cpp-locale-numpunct:0004 */}

```text
integer     ::= [sign] units
sign        ::= plusminus
plusminus   ::= '+' | '-'
units       ::= digits [thousands-sep units]
digits      ::= digit [digits]
```

{/* source:cpp-locale-numpunct:0005 */}

The number of digits between the `thousand-seps` (maximum size of `digits`) is specified by the result of [`grouping()`](/docs/cpp/library/text/locale/numpunct/grouping).

{/* source:cpp-locale-numpunct:0006 */}

The format of floating-point values is as follows:

{/* source:cpp-locale-numpunct:0007 */}

```text
floatval    ::= [sign] units [decimal-point [digits]] [e [sign] digits] |
                [sign]        decimal-point  digits   [e [sign] digits]
e           ::= 'e' | 'E'
```

### Example

{/* source:cpp-locale-numpunct:0015 */}

The following example changes the string representations of `true` and `false`:

```cpp
#include <iostream>
#include <locale>
 
struct french_bool : std::numpunct<char>
{
    string_type do_truename() const override { return "vrai"; }
    string_type do_falsename() const override { return "faux"; }
};
 
int main()
{
    std::cout << "default locale: "
              << std::boolalpha << true << ", " << false << '\n';
    std::cout.imbue(std::locale(std::cout.getloc(), new french_bool));
    std::cout << "locale with modified numpunct: "
              << std::boolalpha << true << ", " << false << '\n';
}
```

Output:

```text
default locale: true, false
locale with modified numpunct: vrai, faux
```
