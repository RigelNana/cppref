Destructs a [`std::messages`](/docs/cpp/library/text/locale/messages) facet. This destructor is protected and virtual (due to [base class](/docs/cpp/library/text/locale/locale/facet) destructor being virtual). An object of type [`std::messages`](/docs/cpp/library/text/locale/messages), like most facets, can only be destroyed when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object that implements this facet goes out of scope or if a user-defined class is derived from [`std::messages`](/docs/cpp/library/text/locale/messages) and implements a public destructor.

### Example

{/* source:cpp-locale-messages-messages:0002 */}

```cpp
#include <iostream>
#include <locale>
 
struct Destructible_messages : public std::messages<wchar_t>
{
    Destructible_messages(std::size_t refs = 0) : messages(refs) {}
    // note: the implicit destructor is public
};
 
int main()
{
    Destructible_messages dc;
    // std::messages<wchar_t> c; // compile error: protected destructor
}
```
