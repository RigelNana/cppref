{/* source:cpp-locale-ctype-ctype:0001 */}
Destructs a [`std::ctype`](/docs/cpp/library/text/locale/ctype) facet. This destructor is protected and virtual (due to [base class](/docs/cpp/library/text/locale/locale/facet) destructor being virtual). An object of type [`std::ctype`](/docs/cpp/library/text/locale/ctype), like most facets, can only be destroyed when the last [std::locale](/docs/cpp/library/text/locale/locale) object that implements this facet goes out of scope or if a user-defined class is derived from `std::ctype` and implements a public destructor.

### Example

{/* source:cpp-locale-ctype-ctype:0002 */}
```cpp
#include <iostream>
#include <locale>
 
struct Destructible_ctype : public std::ctype<wchar_t>
{
    Destructible_ctype(std::size_t refs = 0) : ctype(refs) {}
    // note: the implicit destructor is public
};
 
int main()
{
    Destructible_ctype dc;
    // std::ctype<wchar_t> c; // compile error: protected destructor
}
```
