{/* source:cpp-locale-money-get:0001 */}

Class template `std::money_get` encapsulates the rules for parsing monetary values from character streams. The standard I/O manipulator [`std::get_money`](/docs/cpp/library/io/manip/get_money) uses the `std::money_get` facet of the I/O stream's locale.

{/* source:cpp-locale-money-get:0002 */}

Inheritance diagram

{/* source:cpp-locale-money-get:0003 */}

If a `std::money_get` specialization is not guaranteed to be provided by the standard library (see below), the behaviors of its [`get()`](/docs/cpp/library/text/locale/money_get/get) and [`do_get()`](/docs/cpp/library/text/locale/money_get/get) are not guaranteed as specified.

### Specializations

{/* source:cpp-locale-money-get:0004 */}

The standard library is guaranteed to provide the following specializations (they are [required to be implemented by any locale object](/docs/cpp/library/text/locale/locale)):

{/* source:cpp-locale-money-get:0005 */}

Defined in header [`<locale>`](/docs/cpp/library/headers/locale)

<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`std::money_get<char>`</DescriptionTerm>
    <DescriptionBody>parses narrow string representations of monetary values</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`std::money_get<wchar_t>`</DescriptionTerm>
    <DescriptionBody>parses wide string representations of monetary values</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-locale-money-get:0006 */}

In addition, the standard library is also guaranteed to provide every specialization that satisfies the following type requirements:

{/* source:cpp-locale-money-get:0007 */}

- `CharT` is one of
  - `char`,
  - `wchar_t`, and
  - any other implementation-defined [character container type](/docs/cpp/library/string) that meets the requirements for a character on which any of the [iostream components](/docs/cpp/library/io) can be instantiated; and
- `InputIt` must meet the requirements of [*LegacyInputIterator*](/docs/cpp/library/named_req/InputIterator).

### Example

{/* source:cpp-locale-money-get:0012 */}

```cpp
#include <iomanip>
#include <iostream>
#include <iterator>
#include <locale>
#include <sstream>
 
int main()
{
    std::string str = "$1.11 $2.22 $3.33";
    std::cout << std::fixed << std::setprecision(2);
 
    std::cout << '\"' << str << "\" parsed with the I/O manipulator: ";
    std::istringstream s1(str);
    s1.imbue(std::locale("en_US.UTF-8"));
 
    long double val;
    while (s1 >> std::get_money(val))
        std::cout << val / 100 << ' ';
    std::cout << '\n';
 
    str = "USD  1,234.56";
    std::cout << '\"' << str << "\" parsed with the facet directly: ";
    std::istringstream s2(str);
    s2.imbue(std::locale("en_US.UTF-8"));
 
    auto& f = std::use_facet<std::money_get<char>>(s2.getloc());
    std::ios_base::iostate err;
    std::istreambuf_iterator<char> beg(s2), end;
    f.get(beg, end, true, s2, err, val);
 
    std::cout << val / 100 << '\n';
}
```

Output:

```text
"$1.11 $2.22 $3.33" parsed with the I/O manipulator: 1.11 2.22 3.33
"USD  1,234.56" parsed with the facet directly: 1234.56
```

### Defect reports

{/* source:cpp-locale-money-get:0013 */}

The following behavior-changing defect reports were applied retroactively to previously published C++ standards.

{/* source:cpp-locale-money-get:0014 */}

<DefectReportList>
  <DefectReport kind="lwg" id={427} standard="C++98">
    <PublishedBehavior>`money_get` was guaranteed to accept any `CharT` that<br />meets the requirements for a character on which<br />any of the iostream components can be instantiated</PublishedBehavior>
    <CorrectedBehavior>only guarantees to accept `char`,<br />`wchar_t` and other implementation-<br />defined character types</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={2392} standard="C++98">
    <PublishedBehavior>only character type `CharT` could be<br />guaranteed to be accepted by `money_get`</PublishedBehavior>
    <CorrectedBehavior>can guarantee to accept implementation-<br />defined character container types</CorrectedBehavior>
  </DefectReport>
</DefectReportList>
