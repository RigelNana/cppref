{/* source:cpp-locale-isgraph:0001 */}
Checks if the given character is classified as a graphic character (i.e. printable, excluding space) by the given locale's [std::ctype](/docs/cpp/library/text/locale/ctype) facet.

### Parameters

{/* source:cpp-locale-isgraph:0002 */}
<ParameterList>
  <Parameter name="ch">character</Parameter>
  <Parameter name="loc">locale</Parameter>
</ParameterList>

### Return value

{/* source:cpp-locale-isgraph:0003 */}
Returns `true` if the character is classified as graphic, `false` otherwise.

### Possible implementation

{/* source:cpp-locale-isgraph:0004 */}
```cpp
template<class CharT>
bool isgraph(CharT ch, const std::locale& loc)
{
    return std::use_facet<std::ctype<CharT>>(loc).is(std::ctype_base::graph, ch);
}
```

### Example

{/* source:cpp-locale-isgraph:0005 */}
Demonstrates the use of `isgraph()` with different locales (OS-specific).
```cpp
#include <iostream>
#include <locale>
 
int main()
{
    const wchar_t c = L'\u2a0c'; // quadruple integral
 
    std::locale loc1("C");
    std::cout << "isgraph('⨌', C locale) returned "
              << std::boolalpha << std::isgraph(c, loc1) << '\n';
 
    std::locale loc2("en_US.UTF-8");
    std::cout << "isgraph('⨌', Unicode locale) returned "
              << std::boolalpha << std::isgraph(c, loc2) << '\n';
}
```
Possible output:
```text
isgraph('⨌', C locale) returned false
isgraph('⨌', Unicode locale) returned true
```
