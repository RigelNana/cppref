`std::moneypunct_byname` is a [`std::moneypunct`](/docs/cpp/library/text/locale/moneypunct) facet which encapsulates monetary formatting preferences of a locale specified at its construction.

### Specializations

{/* source:cpp-locale-moneypunct-byname:0002 */}

The standard library is guaranteed to provide every specialization that satisfies the following type requirements:

{/* source:cpp-locale-moneypunct-byname:0003 */}

- `CharT` is one of `char` and `wchar_t`, and
- `Intl` is a possible specialization on a `bool` parameter.

#### std::moneypunct_byname::moneypunct_byname

<DeclarationDoc>
  <Declaration id="1" language="cpp" code={`explicit moneypunct_byname( const char* name, std::size_t refs = 0 );`} />
  <Declaration id="2" since="C++11" language="cpp" code={`explicit moneypunct_byname( const std::string& name, std::size_t refs = 0 );`} />
</DeclarationDoc>

Constructs a new `std::moneypunct_byname` facet for a locale with `name`.

`refs` is used for resource management: if `refs == 0`, the implementation destroys the facet, when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object holding it is destroyed. Otherwise, the object is not destroyed.

##### Parameters

<ParameterList>

  <Parameter name="refs">the number of references that link to the facet</Parameter>

### Example

{/* source:cpp-locale-moneypunct-byname:0010 */}

This example demonstrates how to apply monetary formatting rules of another language without changing the rest of the locale.

```cpp
#include <iomanip>
#include <iostream>
#include <locale>
 
int main()
{
    long double mon = 1234567;
    std::locale::global(std::locale("en_US.utf8"));
    std::wcout.imbue(std::locale());
    std::wcout << L"american locale: " << std::showbase
               << std::put_money(mon) << '\n';
    std::wcout.imbue(std::locale(std::wcout.getloc(),
                                 new std::moneypunct_byname<wchar_t>("ru_RU.utf8")));
    std::wcout << L"american locale with russian moneypunct: "
               << std::put_money(mon) << '\n';
}
```

Output:

```text
american locale: $12,345.67
american locale with russian moneypunct: 12 345.67 руб
```
