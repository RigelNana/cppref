  <DeclarationDescription>
    {/* source:cpp-locale-time-get-get-time:0001 */}
    1) Public member function, calls the protected virtual member function `do_get_time` of the most derived class.

    {/* source:cpp-locale-time-get-get-time:0002 */}
    2) Reads successive characters from the sequence `[``beg``,``end``)` and parses out the time value following the same rules as the format specifier `"%H:%M:%S"` as used by the functions [`std::get_time`](/docs/cpp/library/io/manip/get_time), [`time_get::get`](/docs/cpp/library/text/locale/time_get/get), and the POSIX function `strptime()`.

    {/* source:cpp-locale-time-get-get-time:0003 */}
    The parsed time is stored in the corresponding fields of the [`std::tm`](/docs/cpp/library/chrono/c/tm) structure pointed to by the argument `t`.

    {/* source:cpp-locale-time-get-get-time:0004 */}
    If the end iterator is reached before a valid time is read, the function sets [`std::ios_base::eofbit`](/docs/cpp/library/io/ios_base/iostate) in `err`. If a parsing error is encountered, the function sets [`std::ios_base::failbit`](/docs/cpp/library/io/ios_base/iostate) in `err`.

  </DeclarationDescription>
</DeclarationDoc>

### Return value

{/* source:cpp-locale-time-get-get-time:0006 */}
Iterator pointing one past the last character in `[``beg``,``end``)` that was recognized as a part of a valid date.

### Notes

{/* source:cpp-locale-time-get-get-time:0007 */}
For the alphabetic components of the default time format (if any), this function is usually case-insensitive.

{/* source:cpp-locale-time-get-get-time:0008 */}
If a parsing error is encountered, most implementations of this function leave `*t` unmodified.

### Example

{/* source:cpp-locale-time-get-get-time:0009 */}
```cpp
#include <iostream>
#include <iterator>
#include <locale>
#include <sstream>
 
void try_get_time(const std::string& s)
{
    std::cout << "Parsing the time out of '" << s
              << "' in the locale " << std::locale().name() << '\n';
    std::istringstream str(s);
    std::ios_base::iostate err = std::ios_base::goodbit;
 
    std::tm t;
    std::time_get<char> const& facet =
        std::use_facet<std::time_get<char>>(str.getloc());
    std::istreambuf_iterator<char> ret =
        facet.get_time({str}, {}, str, err, &t);
    str.setstate(err);
 
    if (str)
    {
        std::cout << "Hours: " << t.tm_hour << ", "
                     "Minutes: " << t.tm_min  << ", "
                     "Seconds: " << t.tm_sec  << '\n';
    }
    else
    {
        std::cout << "Parse failed. Unparsed string: ";
        std::copy(ret, {}, std::ostreambuf_iterator<char>(std::cout));
        std::cout << '\n';
    }
}
 
int main()
{
    std::locale::global(std::locale("ru_RU.utf8"));
    try_get_time("21:40:11");
    try_get_time("21-40-11");
 
    std::locale::global(std::locale("ja_JP.utf8"));
    try_get_time("21時37分58秒");
}
```
Output:
```text
Parsing the time out of '21:40:11' in the locale ru_RU.utf8
Hours: 21, Minutes: 40, Seconds: 11
Parsing the time out of '21-40-11' in the locale ru_RU.utf8
Parse failed. Unparsed string: -40-11
Parsing the time out of '21時37分58秒' in the locale ja_JP.utf8
Hours: 21, Minutes: 37, Seconds: 58
```
