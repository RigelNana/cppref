### Specializations

{/* source:cpp-locale-time-put:0004 */}
The standard library is guaranteed to provide the following specializations (they are [required to be implemented by any locale object](/docs/cpp/library/text/locale/locale)):

{/* source:cpp-locale-time-put:0005 */}
Defined in header [`<locale>`](/docs/cpp/library/headers/locale)
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`std::time_put<char>`</DescriptionTerm>
    <DescriptionBody>creates narrow string representations of date and time</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`std::time_put<wchar_t>`</DescriptionTerm>
    <DescriptionBody>creates wide string representations of date and time</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-locale-time-put:0006 */}
In addition, the standard library is also guaranteed to provide every specialization that satisfies the following type requirements:

{/* source:cpp-locale-time-put:0007 */}
- `CharT` is one of `char` and `wchar_t`, and
- `OutputIt` must meet the requirements of [`LegacyOutputIterator`](/docs/cpp/library/named_req/OutputIterator).

### Example

{/* source:cpp-locale-time-put:0012 */}
```cpp
#include <codecvt>
#include <ctime>
#include <iomanip>
#include <iostream>
 
int main()
{
    std::time_t t = std::time(nullptr);
    std::wbuffer_convert<std::codecvt_utf8<wchar_t>> conv(std::cout.rdbuf());
    std::wostream out(&conv);
    out.imbue(std::locale("ja_JP.utf8"));
 
    // this I/O manipulator std::put_time uses std::time_put<wchar_t>
    out << std::put_time(std::localtime(&t), L"%A %c") << '\n';
}
```
Output:
```text
水曜日 2011年11月09日 12時32分05秒
```
