  <Declaration language="cpp" code={`template< class Facet >
const Facet& use_facet( const std::locale& loc );`} />

  <DeclarationDescription>
    {/* source:cpp-locale-use-facet:0001 */}
    Obtains a reference to a facet implemented by `loc`.

    {/* source:cpp-locale-use-facet:0002 */}
    The program is ill-formed if Facet is not a [`facet`](/docs/cpp/library/text/locale/locale/facet#Facet_class) whose definition contains the public static member `id` or it is a volatile-qualified facet.

  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-locale-use-facet:0003 */}
<ParameterList>
  <Parameter name="loc">the locale object to query</Parameter>
</ParameterList>

### Return value

{/* source:cpp-locale-use-facet:0004 */}
Returns a reference to the facet. The reference returned by this function is valid as long as any [`std::locale`](/docs/cpp/library/text/locale/locale) object refers to that facet.

### Exceptions

{/* source:cpp-locale-use-facet:0005 */}
[`std::bad_cast`](/docs/cpp/library/utility/types/bad_cast) if `std::has_facet<Facet>(loc) == false`.

### Notes

{/* source:cpp-locale-use-facet:0006 */}
A [`std::locale`](/docs/cpp/library/text/locale/locale) object should not be a temporary if a reference to the `Facet` object obtained from `use_facet` is used after the end of statement:

{/* source:cpp-locale-use-facet:0007 */}
```cpp
// BAD:
auto& f = std::use_facet<std::moneypunct<char, true>>(std::locale{"no_NO.UTF-8"});
foo(f.curr_symbol()); // Error: f internally uses a dangling reference
                      // to a std::locale object that no longer exists.
// GOOD:
auto loc = std::locale{"is_IS.UTF-8"}; // OK: a non-temporary object
auto& f = std::use_facet<std::moneypunct<char, true>>(loc);
foo(f.curr_symbol()); // OK: f internally uses a reference to existing locale object.
```

### Example

{/* source:cpp-locale-use-facet:0008 */}
Display the 3-letter currency name used by the user's preferred locale.
```cpp
#include <iostream>
#include <locale>
 
int main()
{
    for (const char* name: {"en_US.UTF-8", "de_DE.UTF-8", "en_GB.UTF-8"})
        std::cout << "Your currency string is "
                  << std::use_facet<std::moneypunct<char, true>>(std::locale{name}).
                     curr_symbol() << '\n';
}
```
Output:
```text
Your currency string is USD
Your currency string is EUR
Your currency string is GBP
```

  <DefectReport kind="lwg" id={31} standard="C++98">
    <PublishedBehavior>the returned reference remained usable<br />as long as the locale value itself exists</PublishedBehavior>
    <CorrectedBehavior>the returned reference remains usable as<br />long as some locale object refers to that facet</CorrectedBehavior>
  </DefectReport>
  <DefectReport kind="lwg" id={38} standard="C++98">

  </DefectReport>
  <DefectReport kind="lwg" id={436} standard="C++98">
    <PublishedBehavior>it was unclear whether `Facet` can be cv-qualified</PublishedBehavior>
    <CorrectedBehavior>it can be const-qualified, but not volatile-qualified</CorrectedBehavior>
  </DefectReport>
</DefectReportList>
