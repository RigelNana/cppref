{/* source:cpp-locale-ctype-byname:0001 */}
`std::ctype_byname` is a [std::ctype](/docs/cpp/library/text/locale/ctype) facet which encapsulates character classification rules of the locale specified at its construction.

### Specializations

{/* source:cpp-locale-ctype-byname:0002 */}
The standard library is guaranteed to provide the following specializations:

#### std::ctype_byname::ctype_byname

<DeclarationDoc>
  <Declaration id="1" language="cpp" code={`explicit ctype_byname( const char* name, std::size_t refs = 0 );`} />
  <Declaration id="1" language="cpp" since="C++11" code={`explicit ctype_byname( const std::string& name, std::size_t refs = 0 );`} />
</DeclarationDoc>

Constructs a new `std::ctype_byname` facet for a locale with `name`.

`refs` is used for resource management: if `refs == 0`, the implementation destroys the facet, when the last [std::locale](/docs/cpp/library/text/locale/locale) object holding it is destroyed. Otherwise, the object is not destroyed.

##### Parameters

<ParameterList>
  <Parameter name="name">the name of the locale</Parameter>
  <Parameter name="refs">the number of references that link to the facet</Parameter>
</ParameterList>

### Notes

{/* source:cpp-locale-ctype-byname:0011 */}
`std::ctype_byname<char>` was incorrectly declared as an explicit specialization in the synopsis of [`<locale>`](/docs/cpp/library/headers/locale), and the declaration was removed by the resolution of [LWG issue 1298](https://cplusplus.github.io/LWG/issue1298), but it remains a required specialization, just like `std::ctype_byname<wchar_t>`.

### Example

{/* source:cpp-locale-ctype-byname:0012 */}
```cpp
#include <iostream>
#include <locale>
 
int main()
{
    wchar_t c = L'\u00de'; // capital letter thorn
 
    std::locale loc("C");
 
    std::cout << "isupper('Þ', C locale) returned "
              << std::boolalpha << std::isupper(c, loc) << '\n';
 
    loc = std::locale(loc, new std::ctype_byname<wchar_t>("en_US.utf8"));
 
    std::cout << "isupper('Þ', C locale with Unicode ctype) returned "
              << std::boolalpha << std::isupper(c, loc) << '\n';
}
```
Output:
```text
isupper('Þ', C locale) returned false
isupper('Þ', C locale with Unicode ctype) returned true
```
