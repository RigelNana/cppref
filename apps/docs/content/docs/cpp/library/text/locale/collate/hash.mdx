  <Declaration language="cpp" id="1" code={`public:

virtual long do_hash( const CharT* beg, const CharT* end ) const;`} />

  <DeclarationDescription>
    {/* source:cpp-locale-collate-hash:0001 */}
    1) Public member function, calls the protected virtual member function `do_hash` of the most derived class.

    {/* source:cpp-locale-collate-hash:0002 */}
    2) Converts the character sequence `[beg, end)` to an integer value that is equal to the hash obtained for all strings that collate equivalent in this locale ([`compare()`](/docs/cpp/library/text/locale/collate/compare) returns `0`). For two strings that do not collate equivalent, the probability that their hashes are equal should be very small, approaching `1.0 / std::numeric_limits<unsigned long>::max()`.

  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-locale-collate-hash:0003 */}
<ParameterList>
  <Parameter name="beg">pointer to the first character in the sequence to hash</Parameter>
  <Parameter name="end">one past the end pointer for the sequence to hash</Parameter>
</ParameterList>

### Return value

{/* source:cpp-locale-collate-hash:0004 */}
The hash value that respects collation order.

### Note

{/* source:cpp-locale-collate-hash:0005 */}
The system-supplied locales normally do not collate two strings as equivalent ([`compare()`](/docs/cpp/library/text/locale/collate/compare) does not return `0`) if [`basic_string::operator==`](/docs/cpp/library/string/basic_string/operator_cmp) returns `false`, but a user-installed [`std::collate`](/docs/cpp/library/text/locale/collate) facet may provide different collation rules, for example, it may treat strings as equivalent if they have the same Unicode normalized form.

### Example

{/* source:cpp-locale-collate-hash:0006 */}
Demonstrates a locale-aware unordered container.
```cpp
#include <iostream>
#include <locale>
#include <string>
#include <unordered_set>
 
struct CollateHash
{
    template<typename CharT>
    long operator()(const std::basic_string<CharT>& s) const
    {
        return std::use_facet<std::collate<CharT>>(std::locale()).hash(
                   &s[0], &s[0] + s.size()
               );
    }
};
struct CollateEq
{
    template<typename CharT>
    bool operator()(const std::basic_string<CharT>& s1,
                    const std::basic_string<CharT>& s2) const
    {
        return std::use_facet<std::collate<CharT>>(std::locale()).compare(
                     &s1[0], &s1[0] + s1.size(),
                     &s2[0], &s2[0] + s2.size()
               ) == 0;
    }
};
 
int main()
{
    std::locale::global(std::locale("en_US.utf8"));
    std::wcout.imbue(std::locale());
 
    std::unordered_set<std::wstring, CollateHash, CollateEq> s2 = {L"Foo", L"Bar"};
    for (auto& str : s2)
        std::wcout << str << ' ';
    std::cout << '\n';
}
```
Possible output:
```text
Bar Foo
```
