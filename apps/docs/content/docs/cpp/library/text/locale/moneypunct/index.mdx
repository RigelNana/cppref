The facet `std::moneypunct` encapsulates monetary value format preferences. Stream I/O manipulators [`std::get_money`](/docs/cpp/library/io/manip/get_money) and [`std::put_money`](/docs/cpp/library/io/manip/put_money) use `std::moneypunct` through [`std::money_get`](/docs/cpp/library/text/locale/money_get) and [`std::money_put`](/docs/cpp/library/text/locale/money_put) for parsing monetary value input and formatting monetary value output.
