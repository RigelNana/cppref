Destructs a [`std::moneypunct`](/docs/cpp/library/text/locale/moneypunct) facet. This destructor is protected and virtual (due to [base class](/docs/cpp/library/text/locale/locale/facet) destructor being virtual). An object of type [`std::moneypunct`](/docs/cpp/library/text/locale/moneypunct), like most facets, can only be destroyed when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object that implements this facet goes out of scope or if a user-defined class is derived from [`std::moneypunct`](/docs/cpp/library/text/locale/moneypunct) and implements a public destructor.

### Example

{/* source:cpp-locale-moneypunct-moneypunct:0002 */}

```cpp
#include <iostream>
#include <locale>
 
struct Destructible_moneypunct : public std::moneypunct<wchar_t>
{
    Destructible_moneypunct(std::size_t refs = 0) : moneypunct(refs) {}
    // note: the implicit destructor is public
};
 
int main()
{
    Destructible_moneypunct dc;
    // std::moneypunct<wchar_t> c; // compile error: protected destructor
}
```
