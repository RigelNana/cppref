Destructs a [`std::money_get`](/docs/cpp/library/text/locale/money_get) facet. This destructor is protected and virtual (due to [base class](/docs/cpp/library/text/locale/locale/facet) destructor being virtual). An object of type [`std::money_get`](/docs/cpp/library/text/locale/money_get), like most facets, can only be destroyed when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object that implements this facet goes out of scope or if a user-defined class is derived from [`std::money_get`](/docs/cpp/library/text/locale/money_get) and implements a public destructor.

### Example

{/* source:cpp-locale-money-get-money-get:0002 */}

```cpp
#include <iostream>
#include <locale>
 
struct Destructible_money_get : public std::money_get<wchar_t>
{
    Destructible_money_get(std::size_t refs = 0) : money_get(refs) {}
    // note: the implicit destructor is public
};
 
int main()
{
    Destructible_money_get dc;
    // std::money_get<wchar_t> c; // compile error: protected destructor
}
```
