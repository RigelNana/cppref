Destructs a [`std::money_put`](/docs/cpp/library/text/locale/money_put) facet. This destructor is protected and virtual (due to [base class](/docs/cpp/library/text/locale/locale/facet) destructor being virtual). An object of type [`std::money_put`](/docs/cpp/library/text/locale/money_put), like most facets, can only be destroyed when the last [`std::locale`](/docs/cpp/library/text/locale/locale) object that implements this facet goes out of scope or if a user-defined class is derived from [`std::money_put`](/docs/cpp/library/text/locale/money_put) and implements a public destructor.

### Example

{/* source:cpp-locale-money-put-money-put:0002 */}

```cpp
#include <iostream>
#include <locale>
 
struct Destructible_money_put : public std::money_put<wchar_t>
{
    Destructible_money_put(std::size_t refs = 0) : money_put(refs) {}
    // note: the implicit destructor is public
};
 
int main()
{
    Destructible_money_put dc;
    // std::money_put<wchar_t> c; // compile error: protected destructor
}
```
