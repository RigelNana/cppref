{/* source:cpp-locale-locale-operator-cmp:0001 */}
Tests two locales for equality. Named locales are considered equal if their names are equal. Unnamed locales are considered equal if they are copies of each other.

{/* source:cpp-locale-locale-operator-cmp:0002 */}
<Revision since="C++20">
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
</Revision>

### Parameters

{/* source:cpp-locale-locale-operator-cmp:0003 */}
<ParameterList>
  <Parameter name="other">a [std::locale](/docs/cpp/library/text/locale/locale) object to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-locale-locale-operator-cmp:0004 */}
1) `true` if `other` is a copy of `*this` or has an identical name, `false` otherwise.

{/* source:cpp-locale-locale-operator-cmp:0005 */}
2) `false` if `other` is a copy of `*this` or has an identical name, `true` otherwise.
