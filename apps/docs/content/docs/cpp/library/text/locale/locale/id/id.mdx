1) Default constructor: creates an object of type [std::locale::id](/docs/cpp/library/text/locale/locale/id) with implementation-specific content.

{/* source:cpp-locale-locale-id-id:0002 */}
2) Copy constructor is deleted; [std::locale::id](/docs/cpp/library/text/locale/locale/id) is not copyable.

### Notes

{/* source:cpp-locale-locale-id-id:0003 */}
Because locales and facets must be available for the IO stream objects with static storage duration, such as [std::cout](/docs/cpp/library/io/basic_ostream/cout), typical implementations let implicit default constructor zero-initialize the contents of [std::locale::id](/docs/cpp/library/text/locale/locale/id) during static initialization (before constructors run for static objects), and when a facet is added to any locale for the first time, the locale completes initialization of the facet's `id`.
