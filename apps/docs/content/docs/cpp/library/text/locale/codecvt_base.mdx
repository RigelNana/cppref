{/* source:cpp-locale-codecvt-base:0001 */}
The class `std::codecvt_base` provides the conversion status constants which are inherited and used by the [`std::codecvt`](/docs/cpp/library/text/locale/codecvt) facets.

### Notes

{/* source:cpp-locale-codecvt-base:0004 */}
The value `std::codecvt_base::partial` is used to indicate that either the destination range is too short to receive the results of the conversion or the input is truncated in the middle of an otherwise valid multibyte character.
