{/* source:cpp-locale-ctype-char-ctype:0001 */}
Creates a `std::ctype<char>` facet and forwards the starting reference count `refs` to the base class constructor, [`locale::facet::facet()`](/docs/cpp/library/text/locale/locale/facet/facet).

{/* source:cpp-locale-ctype-char-ctype:0002 */}
If `tbl` is null, `classic_table()` is used by all classification member functions. Otherwise, `tbl` must be a pointer to the first element of an array of masks, at least `std::ctype<char>::table_size` in size, and that array is used by all of this facet's classification member functions.

{/* source:cpp-locale-ctype-char-ctype:0003 */}
If `del` is `true`, it is assumed that the array was allocated with `new[]`, and the destructor of this facet will call `delete[] tbl`.

### Parameters

{/* source:cpp-locale-ctype-char-ctype:0004 */}
<ParameterList>
  <Parameter name="tbl">classification table to use or a null pointer</Parameter>
  <Parameter name="del">indicator whether the table needs to be deleted</Parameter>
  <Parameter name="refs">starting reference count</Parameter>
</ParameterList>
