{/* source:cpp-locale-locale-combine:0001 */}
Constructs a locale object which is a copy of `*this` except for the facet of type `Facet`, which is copied from `other`.

{/* source:cpp-locale-locale-combine:0002 */}
The program is ill-formed if Facet is not a [facet](/docs/cpp/library/text/locale/locale/facet#Facet_class) or it is a volatile-qualified facet.

### Return value

{/* source:cpp-locale-locale-combine:0003 */}
The new, nameless, locale.

### Exceptions

{/* source:cpp-locale-locale-combine:0004 */}
[std::runtime_error](/docs/cpp/library/error/runtime_error) if `other` does not implement `Facet`.

### Example

{/* source:cpp-locale-locale-combine:0005 */}
```cpp
#include <iostream>
#include <locale>
 
int main()
{
    const double number = 1000.25;
    std::cout << "\"C\" locale: " << number << '\n';
    std::locale loc = std::locale()
        .combine<std::numpunct<char>>(std::locale("en_US.UTF8"));
    std::cout.imbue(loc);
    std::cout << "\"C\" locale with en_US numpunct: " << number << '\n';
}
```
Output:
```text
"C" locale: 1000.25
"C" locale with en_US numpunct: 1,000.25
```
