  <DeclarationDescription>
    {/* source:cpp-locale-codecvt-unshift:0001 */}
    1) Public member function, calls the member function `do_unshift` of the most derived class.

    {/* source:cpp-locale-codecvt-unshift:0002 */}
    2) If the encoding represented by this `codecvt` facet is state-dependent, and `state` represents a conversion state that is not the initial shift state, writes the characters necessary to return to the initial shift state. The characters are written to a character array whose first element is pointed to by `to`. No more than `to_end - to` characters are written. The parameter `to_next` is updated to point one past the last character written.

  </DeclarationDescription>
</DeclarationDoc>

### Return value

{/* source:cpp-locale-codecvt-unshift:0003 */}
A value of type [`std::codecvt_base::result`](/docs/cpp/library/text/locale/codecvt_base), indicating the success status as follows:

{/* source:cpp-locale-codecvt-unshift:0004 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`ok`</DescriptionTerm>
    <DescriptionBody>all necessary characters were written. `state` now represents initial shift state</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`partial`</DescriptionTerm>
    <DescriptionBody>not enough space in the output buffer. `to_next == to_end`</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`error`</DescriptionTerm>
    <DescriptionBody>an unspecified error has occurred</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`noconv`</DescriptionTerm>
    <DescriptionBody>the encoding is not state-dependent, no termination sequence necessary</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Notes

{/* source:cpp-locale-codecvt-unshift:0005 */}
This function is called by [`std::basic_filebuf::close()`](/docs/cpp/library/io/basic_filebuf/close) and in other situations when finalizing a state-dependent multibyte character sequence.
