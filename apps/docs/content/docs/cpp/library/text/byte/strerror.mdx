{/* source:cpp-string-byte-strerror:0001 */}
Returns a pointer to the textual description of the system error code `errnum`, identical to the description that would be printed by [`std::perror()`](/docs/cpp/library/io/c/perror).

{/* source:cpp-string-byte-strerror:0002 */}
`errnum` is usually acquired from the `errno` variable, however the function accepts any value of type `int`. The contents of the string are locale-specific.

{/* source:cpp-string-byte-strerror:0003 */}
The returned string must not be modified by the program, but may be overwritten by a subsequent call to the `strerror` function. `strerror` is not required to be thread-safe. Implementations may be returning different pointers to static read-only string literals or may be returning the same pointer over and over, pointing at a static buffer in which `strerror` places the string.

### Parameters

{/* source:cpp-string-byte-strerror:0004 */}
<ParameterList>
  <Parameter name="errnum">integer value referring to an error code</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-strerror:0005 */}
Pointer to a null-terminated byte string corresponding to the [`errno`](/docs/cpp/library/error/errno) error code `errnum`.

### Notes

{/* source:cpp-string-byte-strerror:0006 */}
[POSIX](https://pubs.opengroup.org/onlinepubs/9699919799/functions/strerror.html) allows subsequent calls to `strerror` to invalidate the pointer value returned by an earlier call. It also specifies that it is the [`LC_MESSAGES`](/docs/cpp/library/text/locale/LC_categories) locale facet that controls the contents of these messages.

{/* source:cpp-string-byte-strerror:0007 */}
POSIX has a thread-safe version called `strerror_r` defined. Glibc [defines an incompatible version](https://www.club.cc.cmu.edu/~cmccabe/blog_strerror.html).

### Example

{/* source:cpp-string-byte-strerror:0008 */}
```cpp
#include <cerrno>
#include <clocale>
#include <cmath>
#include <cstring>
#include <iostream>
 
int main()
{
    const double not_a_number = std::log(-1.0);
    std::cout << not_a_number << '\n';
 
    if (errno == EDOM)
    {
        std::cout << "log(-1) failed: " << std::strerror(errno) << '\n';
        std::setlocale(LC_MESSAGES, "de_DE.utf8");
        std::cout << "Or, in German, " << std::strerror(errno) << '\n';
    }
}
```
Possible output:
```text
nan
log(-1) failed: Numerical argument out of domain
Or, in German, Das numerische Argument ist ausserhalb des Definitionsbereiches
```
