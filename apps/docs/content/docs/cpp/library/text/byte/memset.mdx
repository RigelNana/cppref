{/* source:cpp-string-byte-memset:0001 */}
Copies the value `static_cast<unsigned char>(ch)` into each of the first `count` characters of the object pointed to by `dest`. If the object is a [potentially-overlapping subobject](/docs/cpp/language/basic_concepts/objects#Subobjects) or is not [`TriviallyCopyable`](/docs/cpp/library/named_req/TriviallyCopyable) (e.g., scalar, C-compatible struct, or an array of trivially copyable type), the behavior is undefined. If `count` is greater than the size of the object pointed to by `dest`, the behavior is undefined.

### Parameters

{/* source:cpp-string-byte-memset:0002 */}
<ParameterList>
  <Parameter name="dest">pointer to the object to fill</Parameter>
  <Parameter name="ch">fill byte</Parameter>
  <Parameter name="count">number of bytes to fill</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-memset:0003 */}
`dest`

### Notes

{/* source:cpp-string-byte-memset:0004 */}
`std::memset` may be optimized away (under the [as-if](/docs/cpp/language/basic_concepts/as_if) rules) if the object modified by this function is not accessed again for the rest of its lifetime (e.g., [gcc bug 8537](https://gcc.gnu.org/bugzilla/show_bug.cgi?id=8537)). For that reason, this function cannot be used to scrub memory (e.g., to fill an array that stored a password with zeroes).

{/* source:cpp-string-byte-memset:0005 */}
Solutions for that include [`std::fill`](/docs/cpp/library/algorithm/fill) with volatile pointers, <InlineRevision since="C23" /> [`memset_explicit()`](/docs/c/library/string/byte/memset), <InlineRevision since="C11" /> [`memset_s`](/docs/c/library/string/byte/memset), FreeBSD [`explicit_bzero`](https://www.freebsd.org/cgi/man.cgi?query=explicit_bzero) or Microsoft [`SecureZeroMemory`](https://msdn.microsoft.com/en-us/library/windows/desktop/aa366877.aspx).

### Example

{/* source:cpp-string-byte-memset:0006 */}
```cpp
#include <bitset>
#include <climits>
#include <cstring>
#include <iostream>
 
int main()
{
    int a[4];
    using bits = std::bitset<sizeof(int) * CHAR_BIT>;
    std::memset(a, 0b1111'0000'0011, sizeof a);
    for (int ai : a)
        std::cout << bits(ai) << '\n';
}
```
Output:
```text
00000011000000110000001100000011
00000011000000110000001100000011
00000011000000110000001100000011
00000011000000110000001100000011
```
