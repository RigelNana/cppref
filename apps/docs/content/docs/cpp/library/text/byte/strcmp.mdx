{/* source:cpp-string-byte-strcmp:0001 */}
Compares two null-terminated byte strings lexicographically.

{/* source:cpp-string-byte-strcmp:0002 */}
The sign of the result is the sign of the difference between the values of the first pair of characters (both interpreted as `unsigned char`) that differ in the strings being compared.

{/* source:cpp-string-byte-strcmp:0003 */}
The behavior is undefined if `lhs` or `rhs` are not pointers to null-terminated strings.

### Parameters

{/* source:cpp-string-byte-strcmp:0004 */}
<ParameterList>
  <Parameter name="lhs, rhs">pointers to the null-terminated byte strings to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-strcmp:0005 */}
Negative value if `lhs` appears before `rhs` in lexicographical order.

{/* source:cpp-string-byte-strcmp:0006 */}
Zero if `lhs` and `rhs` compare equal.

{/* source:cpp-string-byte-strcmp:0007 */}
Positive value if `lhs` appears after `rhs` in lexicographical order.

### Example

{/* source:cpp-string-byte-strcmp:0008 */}
```cpp
#include <algorithm>
#include <cstring>
#include <iostream>
#include <vector>
 
int main() 
{
    std::vector<const char*> cats{"Heathcliff", "Snagglepuss", "Hobbes", "Garfield"};
    std::sort(cats.begin(), cats.end(), [](const char* strA, const char* strB)
    {
        return std::strcmp(strA, strB) < 0;
    }); 
 
    for (const char* cat : cats)
        std::cout << cat << '\n';
}
```
Output:
```text
Garfield
Heathcliff
Hobbes
Snagglepuss
```
