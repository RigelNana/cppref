<DeclarationDoc>
Defined in header [`<cstring>`](/docs/cpp/library/headers/cstring)
  <Declaration language="cpp" code={`void* memmove( void* dest, const void* src, std::size_t count );`} />
</DeclarationDoc>

{/* source:cpp-string-byte-memmove:0001 */}
Copies `count` characters from the object pointed to by `src` to the object pointed to by `dest`. Both objects are reinterpreted as arrays of `unsigned char`.

{/* source:cpp-string-byte-memmove:0002 */}
The objects may overlap: copying takes place as if the characters were copied to a temporary character array and then the characters were copied from the array to `dest`.

{/* source:cpp-string-byte-memmove:0003 */}
If either `dest` or `src` is an [invalid or null pointer](/docs/cpp/language/declarations/pointer#Pointers), the behavior is undefined, even if `count` is zero.

{/* source:cpp-string-byte-memmove:0004 */}
If the objects are [potentially-overlapping](/docs/cpp/language/basic_concepts/objects#Subobjects) or not [`TriviallyCopyable`](/docs/cpp/library/named_req/TriviallyCopyable), the behavior of `memmove` is not specified and [may be undefined](https://stackoverflow.com/questions/29777492).

### Parameters

{/* source:cpp-string-byte-memmove:0005 */}
<ParameterList>
  <Parameter name="dest">pointer to the memory location to copy to</Parameter>
  <Parameter name="src">pointer to the memory location to copy from</Parameter>
  <Parameter name="count">number of bytes to copy</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-memmove:0006 */}
`dest`

### Notes

{/* source:cpp-string-byte-memmove:0007 */}
`std::memmove` may be used to [implicitly create](/docs/cpp/language/basic_concepts/objects#Object_creation) objects in the destination buffer.

{/* source:cpp-string-byte-memmove:0008 */}
Despite being specified "as if" a temporary buffer is used, actual implementations of this function do not incur the overhead of double copying or extra memory. For small `count`, it may load up and write out registers; for larger blocks, a common approach (glibc and bsd libc) is to copy bytes forwards from the beginning of the buffer if the destination starts before the source, and backwards from the end otherwise, with a fall back to [`std::memcpy`](/docs/cpp/library/text/byte/memcpy) when there is no overlap at all.

{/* source:cpp-string-byte-memmove:0009 */}
Where [strict aliasing](/docs/cpp/language/basic_concepts/objects#Strict_aliasing) prohibits examining the same memory as values of two different types, `std::memmove` may be used to convert the values.

### Example

{/* source:cpp-string-byte-memmove:0010 */}
```cpp
#include <cstring>
#include <iostream>
 
int main()
{
    char str[] = "1234567890";
    std::cout << str << '\n';
    std::memmove(str + 4, str + 3, 3); // copies from [4, 5, 6] to [5, 6, 7]
    std::cout << str << '\n';
}
```
Output:
```text
1234567890
1234456890
```
