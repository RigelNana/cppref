{/* source:cpp-string-byte-strtoimax:0001 */}
Interprets an integer value in a byte string pointed to by `nptr`.

{/* source:cpp-string-byte-strtoimax:0002 */}
Discards any whitespace characters (as identified by calling [`std::isspace`](/docs/cpp/library/text/byte/isspace)) until the first non-whitespace character is found, then takes as many characters as possible to form a valid *base-n* (where n=`base`)  integer number representation and converts them to an  integer value. The valid   integer value consists of the following parts:

{/* source:cpp-string-byte-strtoimax:0003 */}
- (optional) plus or minus sign
- (optional) prefix (`0`) indicating octal base (applies only when the base is `8` or `0`)
- (optional) prefix (`0x` or `0X`) indicating hexadecimal base (applies only when the base is `16` or `0`)
- a sequence of digits

{/* source:cpp-string-byte-strtoimax:0004 */}
The set of valid values for base is `{0, 2, 3, ..., 36}`. The set of valid digits for base-`2` integers is `{0, 1}`, for base-`3` integers is `{0, 1, 2}`, and so on. For bases larger than `10`, valid digits include alphabetic characters, starting from `Aa` for base-`11` integer, to `Zz` for base-`36` integer. The case of the characters is ignored.

{/* source:cpp-string-byte-strtoimax:0005 */}
Additional numeric formats may be accepted by the currently installed C [locale](/docs/cpp/library/text/locale/setlocale).

{/* source:cpp-string-byte-strtoimax:0006 */}
If the value of `base` is `0`, the numeric base is auto-detected: if the prefix is `0`, the base is octal, if the prefix is `0x` or `0X`, the base is hexadecimal, otherwise the base is decimal.

{/* source:cpp-string-byte-strtoimax:0007 */}
If the minus sign was part of the input sequence, the numeric value calculated from the sequence of digits is negated as if by [unary minus](/docs/cpp/language/expressions/operator_arithmetic#Unary_arithmetic_operators) in the result type.

{/* source:cpp-string-byte-strtoimax:0008 */}
The functions sets the pointer pointed to by `endptr` to point to the character past the last character interpreted. If `endptr` is a null pointer, it is ignored.

{/* source:cpp-string-byte-strtoimax:0009 */}
If the `nptr` is empty or does not have the expected form, no conversion is performed, and (if `enptr` is not a null pointer) the value of `nptr` is stored in the object pointed to by `endptr`.

### Parameters

{/* source:cpp-string-byte-strtoimax:0010 */}
<ParameterList>
  <Parameter name="nptr">pointer to the null-terminated byte string to be interpreted</Parameter>
  <Parameter name="endptr">pointer to a pointer to character.</Parameter>
  <Parameter name="base">*base* of the interpreted integer value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-string-byte-strtoimax:0011 */}
- If successful, an integer value corresponding to the contents of `str` is returned.
- If the converted value falls out of range of corresponding return type, a range error occurs (setting [`errno`](/docs/cpp/library/error/errno) to [`ERANGE`](/docs/cpp/library/error/errno_macros)) and [`INTMAX_MAX`](/docs/cpp/library/utility/types/integer), [`INTMAX_MIN`](/docs/cpp/library/utility/types/integer), [`UINTMAX_MAX`](/docs/cpp/library/utility/types/integer) or `0` is returned, as appropriate.
- If no conversion can be performed, `0` is returned.

### Example

{/* source:cpp-string-byte-strtoimax:0012 */}
```cpp
#include <cinttypes>
#include <iostream>
#include <string>
 
int main()
{
    std::string str = "helloworld";
    std::intmax_t val = std::strtoimax(str.c_str(), nullptr, 36);
    std::cout << str << " in base 36 is " << val << " in base 10\n";
 
    char* nptr;
    val = std::strtoimax(str.c_str(), &nptr, 30);
    if (nptr != &str[0] + str.size())
        std::cout << str << " in base 30 is invalid."
                  << " The first invalid digit is '" << *nptr << "'\n";
}
```
Output:
```text
helloworld in base 36 is 1767707668033969 in base 10
helloworld in base 30 is invalid. The first invalid digit is 'w'
```
