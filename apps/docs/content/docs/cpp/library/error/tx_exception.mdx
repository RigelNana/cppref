{/* source:cpp-error-tx-exception:0001 */}
Defines an exception type that can be used to cancel and roll back an atomic transaction initiated by the keyword [`atomic_cancel`](/docs/cpp/language/statements/transactional_memory).

{/* source:cpp-error-tx-exception:0002 */}
If `T` is not [`TriviallyCopyable`](/docs/cpp/library/named_req/TriviallyCopyable), the program that specializes `std::tx_exception<T>` is ill-formed.

  <Declaration id="1" language="cpp" code={`explicit tx_exception( T value ) transaction_safe;`} /> (TM TS)

1-3. Constructs the exception object with `what_arg` as explanatory string that can be accessed through `what()` and `value` as the object that can be accessed through `get()`.
4. Copy constructor. If `*this` and `other` both have dynamic type `std::tx_exception<T>` then `std::strcmp(what(), other.what()) == 0`.
