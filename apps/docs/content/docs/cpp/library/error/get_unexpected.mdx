{/* source:cpp-error-get-unexpected:0001 */}
Returns the currently installed [`std::unexpected_handler`](/docs/cpp/library/error/exception/unexpected_handler), which may be a null pointer.

{/* source:cpp-error-get-unexpected:0002 */}
<Revision since="C++11">
This function is thread-safe. Prior call to `std::set_unexpected` *synchronizes-with* (see [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) the subsequent calls to this function.
</Revision>

### Parameters

{/* source:cpp-error-get-unexpected:0003 */}
(none)

### Return value

{/* source:cpp-error-get-unexpected:0004 */}
The currently installed [`std::unexpected_handler`](/docs/cpp/library/error/exception/unexpected_handler).
