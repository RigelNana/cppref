{/* source:cpp-error-unexpected:0001 */}
`std::unexpected()` is called by the C++ runtime when a [dynamic exception specification](/docs/cpp/language/exceptions/except_spec) is violated: an exception is thrown from a function whose exception specification forbids exceptions of this type.

{/* source:cpp-error-unexpected:0002 */}
`std::unexpected()` may also be called directly from the program.

{/* source:cpp-error-unexpected:0003 */}
In either case, `std::unexpected` calls the currently installed `std::unexpected_handler`. The default `std::unexpected_handler` calls [`std::terminate`](/docs/cpp/library/error/terminate).

{/* source:cpp-error-unexpected:0004 */}
<Revision until="C++11">
If a destructor reset the unexpected handler during stack unwinding and the unwinding later led to `unexpected` being called, the handler that was installed at the end of the throw expression is the one that will be called (note: it was ambiguous whether re-throwing applied the new handlers).
</Revision>
<Revision since="C++11">
If a destructor reset the unexpected handler during stack unwinding, it is unspecified which handler is called if the unwinding later led to `unexpected` being called.
</Revision>

### Exceptions

{/* source:cpp-error-unexpected:0005 */}
Throw any exception thrown by the currently installed `std::unexpected_handler`.
