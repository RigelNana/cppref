{/* source:cpp-error-errc-make-error-condition:0001 */}
Creates an error condition for an `errc` value `e`. Sets the error value to `int(e)` and error category to [`std::generic_category`](/docs/cpp/library/error/generic_category).

### Parameters

{/* source:cpp-error-errc-make-error-condition:0002 */}

<ParameterList>
  <Parameter name="e">standard error value</Parameter>
</ParameterList>

### Return value

{/* source:cpp-error-errc-make-error-condition:0003 */}
Error condition for `e`.

### Example

{/* source:cpp-error-errc-make-error-condition:0004 */}
```cpp
#include <iostream>
#include <string>
#include <system_error>
 
int main()
{
    auto err = std::make_error_condition(std::errc::invalid_argument);
    std::cout << err.message() << '\n';
}
```

Possible output:

```text
Invalid argument
```
