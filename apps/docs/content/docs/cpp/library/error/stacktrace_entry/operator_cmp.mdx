<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++23" code={`friend constexpr bool operator==( const stacktrace_entry& lhs,
                                  const stacktrace_entry& rhs ) noexcept;`} />
  <Declaration id="2" language="cpp" since="C++23" code={`friend constexpr std::strong_ordering
    operator<=>( const stacktrace_entry& lhs, const stacktrace_entry& rhs ) noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-utility-stacktrace-entry-operator-cmp:0001 */}
    1) Compares `lhs` and `rhs` for equality. Two `stacktrace_entry` values are equal if and only if they represent the same stacktrace entry, or both of them are empty.

    {/* source:cpp-utility-stacktrace-entry-operator-cmp:0002 */}
    2) Gets the relative order between `lhs` and `rhs` in the unspecified strict total order over all `stacktrace_entry` values which is consistent with the equality relation established by `operator==`.

    {/* source:cpp-utility-stacktrace-entry-operator-cmp:0003 */}
    These functions are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::stacktrace_entry` is an associated class of the arguments.

    {/* source:cpp-utility-stacktrace-entry-operator-cmp:0004 */}
    The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-stacktrace-entry-operator-cmp:0005 */}
<ParameterList>
  <Parameter name="lhs, rhs">stacktrace_entry values to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-stacktrace-entry-operator-cmp:0006 */}
1) `true` if two `lhs` and `rhs` compare equal, `false` otherwise.

{/* source:cpp-utility-stacktrace-entry-operator-cmp:0007 */}
2) `std::strong_ordering::equal` if `lhs` and `rhs` compare equal.

{/* source:cpp-utility-stacktrace-entry-operator-cmp:0008 */}
Otherwise, `std::strong_ordering::less` if `lhs` is ordered before `rhs` in the strict total order.

{/* source:cpp-utility-stacktrace-entry-operator-cmp:0009 */}
Otherwise, `std::strong_ordering::greater` (in which case `rhs` is ordered before `lhs` in the strict total order).
