  <DeclarationDescription>
    {/* source:cpp-utility-stacktrace-entry-source-file:0001 */}
    Returns the presumed or actual name of the source file that lexically contains the expression or statement whose evaluation is represented by `*this`, or an empty string on failure other than allocation failure, e.g. when `*this` is empty.

    {/* source:cpp-utility-stacktrace-entry-source-file:0002 */}
    Either `source_file` returns the presumed source file name and [`source_line`](/docs/cpp/library/error/stacktrace_entry/source_line) returns the presumed line number, or `source_file` returns the actual source file name and [`source_line`](/docs/cpp/library/error/stacktrace_entry/source_line) returns the actual line number.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-stacktrace-entry-source-file:0003 */}
(none)

### Return value

{/* source:cpp-utility-stacktrace-entry-source-file:0004 */}
The name of the source file specified above on success, an empty string on failure other than allocation failure.

### Exceptions

{/* source:cpp-utility-stacktrace-entry-source-file:0005 */}
Throws [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory for the internal data structures or the resulting string cannot be allocated.

### Notes

{/* source:cpp-utility-stacktrace-entry-source-file:0006 */}
The presumed name of the source file is what the predefined macro [`__FILE__`](/docs/cpp/language/preprocessor/replace) expands to, and can be changed by the [`#line`](/docs/cpp/language/preprocessor/line) directive.
