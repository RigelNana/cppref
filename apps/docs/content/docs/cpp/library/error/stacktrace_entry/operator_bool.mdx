    {/* source:cpp-utility-stacktrace-entry-operator-bool:0001 */}
    Checks whether the `stacktrace_entry` is non-empty, i.e. it represents an evaluation in a stacktrace.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-stacktrace-entry-operator-bool:0002 */}
(none)

### Return value

{/* source:cpp-utility-stacktrace-entry-operator-bool:0003 */}
`true` if the `stacktrace_entry` is non-empty, `false` otherwise.

### Notes

{/* source:cpp-utility-stacktrace-entry-operator-bool:0004 */}
A non-empty `stacktrace_entry` can be obtained from a `std::basic_stacktrace` created by `std::basic_stacktrace::current` or a copy of such `std::basic_stacktrace`.

{/* source:cpp-utility-stacktrace-entry-operator-bool:0005 */}
An empty `stacktrace_entry` can be created by the [default constructor](/docs/cpp/library/error/stacktrace_entry/stacktrace_entry).
