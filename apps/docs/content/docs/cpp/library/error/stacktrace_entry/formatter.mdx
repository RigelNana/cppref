  </DeclarationDescription>
</DeclarationDoc>

### Format specification

{/* source:cpp-utility-stacktrace-entry-formatter:0002 */}
The syntax of format specifications is:

{/* source:cpp-utility-stacktrace-entry-formatter:0003 */}
| fill-and-align (optional) | width (optional) |
| --- | --- |

{/* source:cpp-utility-stacktrace-entry-formatter:0004 */}
`fill-and-align` and `width` have the same meaning as in [standard format specification](/docs/cpp/library/text/format/formatter#Standard_format_specification).

{/* source:cpp-utility-stacktrace-entry-formatter:0005 */}
The formatted output matches the result of [`to_string`](/docs/cpp/library/error/stacktrace_entry/to_string), adjusted as appropriate for the format specifiers.
