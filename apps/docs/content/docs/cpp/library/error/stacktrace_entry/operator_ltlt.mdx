Defined in header [`<stacktrace>`](/docs/cpp/library/headers/stacktrace)

  <Declaration language="cpp" since="C++23" code={`std::ostream& operator<<( std::ostream& os, const std::stacktrace_entry& f );`} />

  <DeclarationDescription>
    {/* source:cpp-utility-stacktrace-entry-operator-ltlt:0001 */}
    Inserts the description of `f` into the output stream `os`. Equivalent to `return os << std::to_string(f);`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-stacktrace-entry-operator-ltlt:0002 */}
<ParameterList>
  <Parameter name="os">an output stream</Parameter>
  <Parameter name="f">a stacktrace_entry whose description is to be inserted</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-stacktrace-entry-operator-ltlt:0003 */}
`os`

### Exceptions

{/* source:cpp-utility-stacktrace-entry-operator-ltlt:0004 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-utility-stacktrace-entry-operator-ltlt:0005 */}
```cpp
#include <iostream>
#include <stacktrace>
 
int main()
{
    for (const auto& f : std::stacktrace::current())
        std::cout << f << '\n';
}
```

Possible output:

```text
0x0000000000402AA7 in ./prog.exe
__libc_start_main in /lib/x86_64-linux-gnu/libc.so.6
0x00000000004029B9 in ./prog.exe
```
