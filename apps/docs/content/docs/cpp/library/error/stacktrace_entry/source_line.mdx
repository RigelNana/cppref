  <DeclarationDescription>
    {/* source:cpp-utility-stacktrace-entry-source-line:0001 */}
    Returns a 1-based line number that lexically relates to the evaluation represented by `*this`, or 0 on failure other than allocation failure, e.g. when `*this` is empty.

    {/* source:cpp-utility-stacktrace-entry-source-line:0002 */}
    Either [`source_file`](/docs/cpp/library/error/stacktrace_entry/source_file) returns the presumed source file name and `source_line` returns the presumed line number, or [`source_file`](/docs/cpp/library/error/stacktrace_entry/source_file) returns the actual source file name and `source_line` returns the actual line number.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-stacktrace-entry-source-line:0003 */}
(none)

### Return value

{/* source:cpp-utility-stacktrace-entry-source-line:0004 */}
The line number specified above on success, 0 on failure other than allocation failure.

### Exceptions

{/* source:cpp-utility-stacktrace-entry-source-line:0005 */}
Throws [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory for the internal data structures cannot be allocated.

### Notes

{/* source:cpp-utility-stacktrace-entry-source-line:0006 */}
The presumed line number is what the predefined macro [`__LINE__`](/docs/cpp/language/preprocessor/replace) expands to, and can be changed by the [`#line`](/docs/cpp/language/preprocessor/line) directive.
