  <DeclarationDescription>
    {/* source:cpp-error-error-condition-operator-cmp:0001 */}
    Compares two error conditions.
    {/* source:cpp-error-error-condition-operator-cmp:0002 */}
    1. 1) Checks whether `lhs` and `rhs` are equal.
    {/* source:cpp-error-error-condition-operator-cmp:0003 */}
    2. 2) Checks whether `lhs` and `rhs` are not equal.
    {/* source:cpp-error-error-condition-operator-cmp:0004 */}
    3. 3) Checks whether `lhs` is less than `rhs`.
    {/* source:cpp-error-error-condition-operator-cmp:0005 */}
    4. 4) Obtains three-way comparison result of `lhs` and `rhs`.
    {/* source:cpp-error-error-condition-operator-cmp:0006 */}
    5. 5) Checks whether `code` is a semantic match for `cond`.
    {/* source:cpp-error-error-condition-operator-cmp:0007 */}
    6. 6) Checks whether `code` is not a semantic match for `cond`.
  </DeclarationDescription>

<Revision since="C++20">
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Return value

{/* source:cpp-error-error-condition-operator-cmp:0010 */}

1. 1) `true` if the error category and error value compare equal.

{/* source:cpp-error-error-condition-operator-cmp:0011 */}

2. 2) `true` if the error category or error value compare are not equal.

{/* source:cpp-error-error-condition-operator-cmp:0012 */}

3. 3) `true` if `lhs.category() < rhs.category()`. Otherwise, `true` if `lhs.category() == rhs.category() && lhs.value() < rhs.value()`. Otherwise, `false`.

{/* source:cpp-error-error-condition-operator-cmp:0013 */}

4. 4) `lhs.category() <=> rhs.category()` if it is not `std::strong_ordering::equal`. Otherwise, `lhs.value() <=> rhs.value()`.

{/* source:cpp-error-error-condition-operator-cmp:0014 */}

5. 5) `true` if either `code.category().equivalent(code.value(), cond)` or `cond.category().equivalent(code, cond.value())`.

{/* source:cpp-error-error-condition-operator-cmp:0015 */}

6. 6) `true` if neither `code.category().equivalent(code.value(), cond)` nor `cond.category().equivalent(code, cond.value())`.
