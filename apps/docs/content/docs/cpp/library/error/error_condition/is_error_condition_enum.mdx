If `T` is an error condition enum (such as [`std::errc`](/docs/cpp/library/error/errc)), this template provides the member constant `value` equal `true`. For any other type, `value` is `false`.

{/* source:cpp-error-error-condition-is-error-condition-enum:0002 */}
This template may be specialized for a [program-defined type](/docs/cpp/language/basic_concepts/type-id#Program-defined_type) to indicate that the type is eligible for [`std::error_condition`](/docs/cpp/library/error/error_condition) implicit conversions.
