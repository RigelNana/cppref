  <DeclarationDescription>
    {/* source:cpp-error-error-code-error-code:0001 */}
    Constructs new error code.
    {/* source:cpp-error-error-code-error-code:0002 */}
    1. 1) Constructs error code with default value. Equivalent to `error_code(0, std::system_category())`.
    {/* source:cpp-error-error-code-error-code:0003 */}
    2. 2) Constructs error code with `ec` as the platform-dependent error code and `ecat` as the corresponding [error category](/docs/cpp/library/error/error_category).
    {/* source:cpp-error-error-code-error-code:0004 */}
    3. 3) Constructs error code from an error code enum `e`. Equivalent to `make_error_code(e)`, where `make_error_code` is only found by [argument-dependent lookup](/docs/cpp/language/functions/adl). This overload participates in overload resolution only if `std::is_error_code_enum<ErrorCodeEnum>::value` is `true`.
    {/* source:cpp-error-error-code-error-code:0005 */}
    4. 4,5) Implicitly defined copy constructor and move constructor. Initializes the error code with the contents of the `other`.
  </DeclarationDescription>
</DeclarationDoc>
