<Revision since="C++20">
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Return value

{/* source:cpp-error-error-code-operator-cmp:0008 */}

1. 1) `true` if the error category and error value compare equal.

{/* source:cpp-error-error-code-operator-cmp:0009 */}

2. 2) `true` if the error category or error value compare are not equal.

{/* source:cpp-error-error-code-operator-cmp:0010 */}

3. 3) `true` if `lhs.category() < rhs.category()`. Otherwise, `true` if `lhs.category() == rhs.category() && lhs.value() < rhs.value()`. Otherwise, `false`.

{/* source:cpp-error-error-code-operator-cmp:0011 */}

4. 4) `lhs.category() <=> rhs.category()` if it is not `std::strong_ordering::equal`. Otherwise, `lhs.value() <=> rhs.value()`.
