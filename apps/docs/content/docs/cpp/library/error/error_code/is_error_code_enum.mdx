{/* source:cpp-error-error-code-is-error-code-enum:0001 */}
If `T` is an error code enumeration (such as [`std::io_errc`](/docs/cpp/library/io/io_errc) and [`std::future_errc`](/docs/cpp/library/thread/future_errc)), this template provides the member constant `value` equal `true`. For any other type, `value` is `false`.

{/* source:cpp-error-error-code-is-error-code-enum:0002 */}
This template may be specialized for a [program-defined type](/docs/cpp/language/basic_concepts/type-id#Program-defined_type) to indicate that the type is eligible for [`std::error_code`](/docs/cpp/library/error/error_code) implicit conversion.
