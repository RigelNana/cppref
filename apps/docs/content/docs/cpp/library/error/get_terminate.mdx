{/* source:cpp-error-get-terminate:0001 */}
Returns the currently installed [`std::terminate_handler`](/docs/cpp/library/error/terminate_handler), which may be a null pointer.

{/* source:cpp-error-get-terminate:0002 */}
This function is thread-safe. Prior call to [`std::set_terminate`](/docs/cpp/library/error/set_terminate) *synchronizes-with* (see [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) this function.

### Parameters

{/* source:cpp-error-get-terminate:0003 */}
(none)

### Return value

{/* source:cpp-error-get-terminate:0004 */}
The currently installed [`std::terminate_handler`](/docs/cpp/library/error/terminate_handler).
