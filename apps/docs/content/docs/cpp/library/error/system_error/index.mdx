{/* source:cpp-error-system-error:0001 */}
`std::system_error` is the type of the exception thrown by various library functions (typically the functions that interface with the OS facilities, e.g. the constructor of [`std::thread`](/docs/cpp/library/thread/thread)) when the exception has an associated [`std::error_code`](/docs/cpp/library/error/error_code), which may be reported.

### Example

{/* source:cpp-error-system-error:0005 */}
```cpp
#include <iostream>
#include <system_error>
#include <thread>
 
int main()
{
    try
    {
        std::thread().detach(); // attempt to detach a non-thread
    }
    catch(const std::system_error& e)
    {
        std::cout << "Caught system_error with code "
                     "[" << e.code() << "] meaning "
                     "[" << e.what() << "]\n";
    }
}
```

Possible output:

```text
Caught system_error with code [generic:22] meaning [Invalid argument]
```
