### Example

{/* source:cpp-error-system-error-system-error:0008 */}
Demonstrates how to create a `system_error` exception from an [errno](/docs/cpp/library/error/errno) value.

```cpp
#include <iostream>
#include <system_error>
 
int main()
{
    try
    {
        throw std::system_error(EDOM, std::generic_category(), "FIX ME");
    }
    catch (const std::system_error& ex)
    {
        std::cout << "code:    [" << ex.code() << "]\n"
                     "message: [" << ex.code().message() << "]\n"
                     "what:    [" << ex.what() << "]\n";
    }
}
```

Possible output:

```text
code:    [generic:33]
message: [Numerical argument out of domain]
what:    [FIX ME: Numerical argument out of domain]
```
