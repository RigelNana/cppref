<DeclarationDoc>
Defined in header [`<stacktrace>`](/docs/cpp/library/headers/stacktrace)

  <Declaration language="cpp" since="C++23" code={`template< class Allocator >
std::ostream& operator<<( std::ostream& os, const std::basic_stacktrace<Allocator>& st );`} />

  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-operator-ltlt:0001 */}
    Inserts the description of `st` into the output stream `os`. Equivalent to `return os << std::to_string(st);`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-basic-stacktrace-operator-ltlt:0002 */}
<ParameterList>
  <Parameter name="os">an output stream</Parameter>
  <Parameter name="st">a basic_stacktrace whose description is to be inserted</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-basic-stacktrace-operator-ltlt:0003 */}
`os`.

### Exceptions

{/* source:cpp-utility-basic-stacktrace-operator-ltlt:0004 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-utility-basic-stacktrace-operator-ltlt:0005 */}
```cpp
#include <stacktrace>
#include <iostream>
 
int main()
{
    std::cout << "The stacktrace obtained in the main function:\n";
    std::cout << std::stacktrace::current() << '\n';
    []{
        std::cout << "The stacktrace obtained in a nested lambda:\n";
        std::cout << std::stacktrace::current() << '\n';
    }();
}
```

Possible output:

```text
The stacktrace obtained in the main function:
 0# 0x0000000000402E7B in ./prog.exe
 1# __libc_start_main in /lib/x86_64-linux-gnu/libc.so.6
 2# 0x0000000000402CD9 in ./prog.exe
 
The stacktrace obtained in a nested lambda:
 0# 0x0000000000402DDA in ./prog.exe
 1# 0x0000000000402EB2 in ./prog.exe
 2# __libc_start_main in /lib/x86_64-linux-gnu/libc.so.6
 3# 0x0000000000402CD9 in ./prog.exe
```
