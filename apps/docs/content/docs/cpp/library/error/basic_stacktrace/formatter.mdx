  <Declaration language="cpp" since="C++23" code={`template< class Allocator >
struct formatter<std::basic_stacktrace<Allocator>>;`} />

  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-formatter:0001 */}
    The template specialization of [`std::formatter`](/docs/cpp/library/text/format/formatter) for `std::basic_stacktrace<Allocator>` allows users to convert a stacktrace object to string using [formatting functions](/docs/cpp/library/text/format) such as [`std::format`](/docs/cpp/library/text/format/format).

    {/* source:cpp-utility-basic-stacktrace-formatter:0002 */}
    No format specifier is allowed.

    {/* source:cpp-utility-basic-stacktrace-formatter:0003 */}
    A stacktrace object `s` is formatted as if by copying [`std::to_string`](/docs/cpp/library/error/basic_stacktrace/to_string)`(s)` to the output.
  </DeclarationDescription>
</DeclarationDoc>

### Example

{/* source:cpp-utility-basic-stacktrace-formatter:0004 */}
```cpp
#include <format>
#include <iostream>
#include <stacktrace>
 
int main()
{
    auto trace = std::stacktrace::current();
    std::cout << std::format("{}\n", trace);
}
```

Possible output:

```text
 0# 0x0000000000402D97 in ./prog.exe
 1# __libc_start_main in /lib/x86_64-linux-gnu/libc.so.6
 2# 0x0000000000402CA9 in ./prog.exe
```
