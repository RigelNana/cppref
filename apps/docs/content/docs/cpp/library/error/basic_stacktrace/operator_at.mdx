  <Declaration language="cpp" since="C++23" code={`const_reference operator[]( size_type pos ) const;`} />

  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-operator-at:0001 */}
    Returns a reference to the entry at specified location `pos`. No bounds checking is performed.

    {/* source:cpp-utility-basic-stacktrace-operator-at:0002 */}
    If `pos` is not within the range of the stacktrace, i.e. `pos >= size()`, the behavior is undefined.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-basic-stacktrace-operator-at:0003 */}
<ParameterList>
  <Parameter name="pos">position of the stacktrace entry to return</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-basic-stacktrace-operator-at:0004 */}
Reference to the requested entry.

### Exceptions

{/* source:cpp-utility-basic-stacktrace-operator-at:0005 */}
Throws nothing.
