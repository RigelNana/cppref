<DeclarationDoc>
  <Declaration id="1" language="cpp" since="C++23" code={`static basic_stacktrace current( const allocator_type& alloc =
                                     allocator_type() ) noexcept;`} />
  <Declaration id="2" language="cpp" since="C++23" code={`static basic_stacktrace current( size_type skip, const allocator_type& alloc =
                                     allocator_type() ) noexcept;`} />
  <Declaration id="3" language="cpp" since="C++23" code={`static basic_stacktrace current( size_type skip, size_type max_depth,
                                 const allocator_type& alloc =

                                     allocator_type() ) noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-current:0001 */}
    Let `s[i]` (0 ≤ `i` \< `n`) denote the (`i`+1)-th stacktrace entry in the stacktrace of the current evaluation in the current thread of execution, where `n` is the count of the stacktrace entries in the stackentry.

    {/* source:cpp-utility-basic-stacktrace-current:0002 */}
    1) Attempts to create a basic_stacktrace consisting of `s[0]`, `s[1]`, ..., `s[n - 1]`.

    {/* source:cpp-utility-basic-stacktrace-current:0003 */}
    2) Attempts to create a basic_stacktrace consisting of `s[m]`, `s[m + 1]`, ..., `s[n - 1]`, where `m` is `min(skip, n)`.

    {/* source:cpp-utility-basic-stacktrace-current:0004 */}
    3) Attempts to create a basic_stacktrace consisting of `s[m]`, `s[m + 1]`, ..., `s[o - 1]`, where `m` is `min(skip, n)` and `o` is `min(skip + max_depth, n)`. The behavior is undefined if the `skip + max_depth < skip` (i.e. the mathematical result of `skip + max_depth` overflows).

    {/* source:cpp-utility-basic-stacktrace-current:0005 */}
    In all cases, `alloc` is stored into the created basic_stacktrace and used to allocate the storage for stacktrace entries.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-basic-stacktrace-current:0006 */}
<ParameterList>
  <Parameter name="alloc">allocator to use for all memory allocations of the constructed basic_stacktrace</Parameter>
  <Parameter name="skip">the number of stacktrace entries to skip</Parameter>
  <Parameter name="max_depth">the maximum depth of the stacktrace entries</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-basic-stacktrace-current:0007 */}
If the allocation succeeds, the basic_stacktrace described above.

{/* source:cpp-utility-basic-stacktrace-current:0008 */}
Otherwise, an empty basic_stacktrace.
