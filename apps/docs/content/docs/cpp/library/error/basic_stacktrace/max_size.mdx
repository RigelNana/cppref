<DeclarationDoc>
  <Declaration language="cpp" since="C++23" code={`size_type max_size() const noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-max-size:0001 */}
    Returns the maximum number of elements the underlying container (typically a [`std::vector`](/docs/cpp/library/container/vector)) is able to hold due to system or library implementation limitations, i.e. `std::distance(begin(), end())` for the largest underlying container.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-basic-stacktrace-max-size:0002 */}
(none)

### Return value

{/* source:cpp-utility-basic-stacktrace-max-size:0003 */}
Maximum number of elements.

### Complexity

{/* source:cpp-utility-basic-stacktrace-max-size:0004 */}
Constant.

### Notes

{/* source:cpp-utility-basic-stacktrace-max-size:0005 */}
This value typically reflects the theoretical limit on the size of the underlying container, at most `std::numeric_limits<difference_type>::max()`. At runtime, the size of the container may be limited to a value smaller than `max_size()` by the amount of RAM available.

### Example

{/* source:cpp-utility-basic-stacktrace-max-size:0006 */}
```cpp
#include <iostream>
#include <stacktrace>
 
int main()
{
    std::stacktrace trace;
    std::cout << "Maximum size of a 'basic_stacktrace' is " << trace.max_size() << "\n";
}
```

Possible output:

```text
Maximum size of a 'basic_stacktrace' is 1152921504606846975
```
