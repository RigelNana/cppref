Defined in header [`<stacktrace>`](/docs/cpp/library/headers/stacktrace)

  <Declaration language="cpp" since="C++23" code={`template< class Allocator >
std::string to_string( const std::basic_stacktrace<Allocator>& st );`} />

  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-to-string:0001 */}
    Returns a string with a description of `st`.

    {/* source:cpp-utility-basic-stacktrace-to-string:0002 */}
    The description of a basic_stacktrace typically contains description of its entries, although the number of lines is not required to be equal to [`size()`](/docs/cpp/library/error/basic_stacktrace/size).
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-basic-stacktrace-to-string:0003 */}
<ParameterList>
  <Parameter name="st">a basic_stacktrace whose description is to be returned</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-basic-stacktrace-to-string:0004 */}
A string with a description of `st`.

### Exceptions

{/* source:cpp-utility-basic-stacktrace-to-string:0005 */}
May throw implementation-defined exceptions.

### Notes

{/* source:cpp-utility-basic-stacktrace-to-string:0006 */}
Custom allocators support for this function is not provided, because the implementations usually require platform specific allocations, system calls and a lot of CPU intensive work, while a custom allocator does not provide benefits for this function as the platform specific operations take an order of magnitude more time than the allocation.

### Example

{/* source:cpp-utility-basic-stacktrace-to-string:0007 */}
```cpp
#include <stacktrace>
#include <string>
#include <iostream>
 
int main()
{
    auto trace = std::stacktrace::current();
    std::cout << std::to_string(trace) << '\n';
}
```

Possible output:

```text
 0# 0x0000000000402D97 in ./prog.exe
 1# __libc_start_main in /lib/x86_64-linux-gnu/libc.so.6
 2# 0x0000000000402CA9 in ./prog.exe
```
