  <Declaration language="cpp" since="C++23" code={`const_reference at( size_type pos ) const;`} />

  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-at:0001 */}
    Returns a reference to the entry at specified location `pos`, with bounds checking.

    {/* source:cpp-utility-basic-stacktrace-at:0002 */}
    If `pos` is not within the range of the stacktrace, an exception of type [`std::out_of_range`](/docs/cpp/library/error/out_of_range) is thrown.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-basic-stacktrace-at:0003 */}
<ParameterList>
  <Parameter name="pos">position of the stacktrace entry to return</Parameter>
</ParameterList>

### Return value

{/* source:cpp-utility-basic-stacktrace-at:0004 */}
Reference to the requested entry.

### Exceptions

{/* source:cpp-utility-basic-stacktrace-at:0005 */}
[`std::out_of_range`](/docs/cpp/library/error/out_of_range) if `pos >= size()`.

### Complexity

{/* source:cpp-utility-basic-stacktrace-at:0006 */}
Constant.
