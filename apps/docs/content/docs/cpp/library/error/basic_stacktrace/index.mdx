    {/* source:cpp-utility-basic-stacktrace:0001 */}
    1. The `basic_stacktrace` class template represents a snapshot of the whole stacktrace or its given part. It satisfies the requirement of [`AllocatorAwareContainer`](/docs/cpp/library/named_req/AllocatorAwareContainer), [`SequenceContainer`](/docs/cpp/library/named_req/SequenceContainer), and [`ReversibleContainer`](/docs/cpp/library/named_req/ReversibleContainer), except that only move, assignment, swap, and operations for const-qualified sequence containers are supported, and the semantics of comparison functions are different from those required for a container.

    {/* source:cpp-utility-basic-stacktrace:0002 */}
    2. Convenience type alias for the `basic_stacktrace` using the default [`std::allocator`](/docs/cpp/library/memory/allocator).

    {/* source:cpp-utility-basic-stacktrace:0003 */}
    3. Convenience type alias for the `basic_stacktrace` using the [polymorphic allocator](/docs/cpp/library/memory/polymorphic_allocator).
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-utility-basic-stacktrace:0004 */}
The invocation sequence of the current evaluation `x0` in the current thread of execution is a sequence (`x0`, ..., `xn`) of evaluations such that, for `i`≥`0`, `xi` is within the function invocation `xi+1`.

{/* source:cpp-utility-basic-stacktrace:0005 */}
A stacktrace is an approximate representation of an invocation sequence and consists of stacktrace entries.

{/* source:cpp-utility-basic-stacktrace:0006 */}
A *stacktrace entry* represents an evaluation in a stacktrace. It is represented by `std::stacktrace_entry` in the C++ standard library.

### Template parameters

{/* source:cpp-utility-basic-stacktrace:0007 */}
<ParameterList>
  <Parameter name="Allocator">An allocator that is used to acquire/release memory and to construct/destroy the elements in that memory. The type must meet the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator). The program is ill-formed if `Allocator::value_type` is not `std::stacktrace_entry`.</Parameter>

### Notes

{/* source:cpp-utility-basic-stacktrace:0012 */}
Support for custom allocators is provided for using `basic_stacktrace` on a hot path or in embedded environments. Users can allocate `stacktrace_entry` objects on the stack or in some other place, where appropriate.

{/* source:cpp-utility-basic-stacktrace:0013 */}
The sequence of `std::stacktrace_entry` objects owned by a `std::basic_stacktrace` is immutable, and either is empty or represents a contiguous interval of the whole stacktrace.

{/* source:cpp-utility-basic-stacktrace:0014 */}
`boost::stacktrace::basic_stacktrace` (available in [Boost.Stacktrace](https://www.boost.org/doc/libs/release/doc/html/stacktrace.html)) can be used instead when `std::basic_stacktrace` is not available.
