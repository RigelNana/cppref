  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-operator-cmp:0001 */}
    1) Checks if the contents of `lhs` and `rhs` are equal, that is, they have the same number of elements and each element in `lhs` compares equal with the element in `rhs` at the same position.

    {/* source:cpp-utility-basic-stacktrace-operator-cmp:0002 */}
    Equivalent to `return std::equal(lhs.begin(), lhs.end(), rhs.begin(), rhs.end());`.

    {/* source:cpp-utility-basic-stacktrace-operator-cmp:0003 */}
    2) Returns the relative order of the numbers of stacktrace entries in `lhs` and `rhs` if they are not equal. Otherwise (if the numbers of elements of `lhs` and `rhs` are equal), returns the lexicographical order of the elements of `lhs` and `rhs`.

    {/* source:cpp-utility-basic-stacktrace-operator-cmp:0004 */}
    Equivalent to `if (auto cmp = lhs.size() <=> rhs.size(); cmp != 0) return cmp; else return std::lexicographical_compare_three_way(lhs.begin(), lhs.end(), rhs.begin(), rhs.end());`.

    {/* source:cpp-utility-basic-stacktrace-operator-cmp:0005 */}
    These function templates are not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::basic_stacktrace<Allocator>` is an associated class of the arguments.

    {/* source:cpp-utility-basic-stacktrace-operator-cmp:0006 */}
    The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
  </DeclarationDescription>
</DeclarationDoc>

### Return value

{/* source:cpp-utility-basic-stacktrace-operator-cmp:0008 */}
1) `true` if the contents of `lhs` and `rhs` are equal, `false` otherwise.

{/* source:cpp-utility-basic-stacktrace-operator-cmp:0009 */}
2) `lhs.size() <=> rhs.size()` if the result is not `std::strong_order::equal`, the lexicographical order of the elements of `lhs` and `rhs` otherwise.

### Complexity

{/* source:cpp-utility-basic-stacktrace-operator-cmp:0010 */}
1,2) Constant if `lhs` and `rhs` are of different size, linear in the size of `lhs` otherwise.
