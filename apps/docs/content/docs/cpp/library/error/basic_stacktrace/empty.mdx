  <DeclarationDescription>
    {/* source:cpp-utility-basic-stacktrace-empty:0001 */}
    Checks if the stacktrace has no stacktrace entries.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-utility-basic-stacktrace-empty:0002 */}
(none)

### Return value

{/* source:cpp-utility-basic-stacktrace-empty:0003 */}
`true` if the stacktrace is empty, `false` otherwise.

### Complexity

{/* source:cpp-utility-basic-stacktrace-empty:0004 */}
Constant.

### Example

{/* source:cpp-utility-basic-stacktrace-empty:0005 */}
```cpp
#include <stacktrace>
#include <iostream>
 
int main()
{
    std::cout << std::boolalpha;
    std::stacktrace bktr;
    std::cout << "Initially, bktr.empty(): " << bktr.empty() << '\n';
 
    bktr = std::stacktrace::current();
    std::cout << "After getting entries, bktr.empty(): " << bktr.empty() << '\n';
}
```

Possible output:

```text
Initially, bktr.empty(): true
After getting entries, bktr.empty(): false
```
