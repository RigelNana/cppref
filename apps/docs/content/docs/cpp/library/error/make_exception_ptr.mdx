{/* source:cpp-error-make-exception-ptr:0001 */}
Creates an [`std::exception_ptr`](/docs/cpp/library/error/exception_ptr) that holds a reference to a copy of `e`. This is done as if executing the following code:

{/* source:cpp-error-make-exception-ptr:0002 */}
```cpp
try
{
    throw e;
}
catch(...)
{
    return std::current_exception();
}
```

### Parameters

{/* source:cpp-error-make-exception-ptr:0003 */}
<ParameterList>
  <Parameter name="e">exception object to create a reference to the copy of</Parameter>
</ParameterList>

### Return value

{/* source:cpp-error-make-exception-ptr:0004 */}
An instance of [`std::exception_ptr`](/docs/cpp/library/error/exception_ptr) holding a reference to the copy of `e`, or to an instance of [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) or to an instance of [`std::bad_exception`](/docs/cpp/library/error/bad_exception) (see [`std::current_exception`](/docs/cpp/library/error/current_exception)).

### Notes

{/* source:cpp-error-make-exception-ptr:0005 */}
