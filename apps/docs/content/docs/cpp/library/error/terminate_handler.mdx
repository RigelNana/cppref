{/* source:cpp-error-terminate-handler:0001 */}
`std::terminate_handler` is the function pointer type (pointer to function that takes no arguments and returns `void`), which is installed and queried by the functions [`std::set_terminate`](/docs/cpp/library/error/set_terminate) and [`std::get_terminate`](/docs/cpp/library/error/get_terminate) and called by [`std::terminate`](/docs/cpp/library/error/terminate).

{/* source:cpp-error-terminate-handler:0002 */}
A `std::terminate_handler` shall terminate execution of the program without returning to the caller, otherwise the behavior is undefined.

{/* source:cpp-error-terminate-handler:0003 */}
The C++ implementation provides a default `std::terminate_handler` function, which calls [`std::abort()`](/docs/cpp/library/utility/program/abort). If the null pointer value is installed (by means of [`std::set_terminate`](/docs/cpp/library/error/set_terminate)), the implementation may restore the default handler instead.
