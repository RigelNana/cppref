  <Declaration id="2" language="cpp" since="C++11" code={`virtual bool equivalent( const std::error_code& code,
                         int condition ) const noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-error-error-category-equivalent:0001 */}
    Checks whether error code is equivalent to an error condition for the error category represented by `*this`.
    {/* source:cpp-error-error-category-equivalent:0002 */}
    1. 1) Equivalent to `default_error_condition(code) == condition`.
    {/* source:cpp-error-error-category-equivalent:0003 */}
    2. 2) Equivalent to `*this == code.category() && code.value() == condition`.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-error-error-category-equivalent:0004 */}

<ParameterList>
  <Parameter name="code">specifies the error code to compare</Parameter>
  <Parameter name="condition">specifies the error condition to compare</Parameter>
</ParameterList>

### Return value

{/* source:cpp-error-error-category-equivalent:0005 */}
`true` if the error code is equivalent to the given error condition for the error category represented by `*this`, `false` otherwise.
