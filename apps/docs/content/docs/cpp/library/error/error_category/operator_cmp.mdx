  <DeclarationDescription>
    {/* source:cpp-error-error-category-operator-cmp:0001 */}
    Compares to another error category.
    {/* source:cpp-error-error-category-operator-cmp:0002 */}
    1. 1) Checks whether `*this` and `rhs` refer to the same object.
    {/* source:cpp-error-error-category-operator-cmp:0003 */}
    2. 2) Checks whether `*this` and `rhs` do not refer to the same object.
    {/* source:cpp-error-error-category-operator-cmp:0004 */}
    3. 3) Orders `*this` and `rhs` by the order of `this` and `&rhs`. Equivalent to `std::less<const error_category*>()(this, &rhs)`.
    {/* source:cpp-error-error-category-operator-cmp:0005 */}
    4. 4) Orders `*this` and `rhs` by the order of `this` and `&rhs`. Equivalent to `std::compare_three_way()(this, &rhs)`.
  </DeclarationDescription>
</DeclarationDoc>

{/* source:cpp-error-error-category-operator-cmp:0006 */}
<Revision since="C++20">
The `<`, `<=`, `>`, `>=`, and `!=` operators are [synthesized](/docs/cpp/language/expressions/operators#Comparison_operators) from `operator<=>` and `operator==` respectively.
</Revision>

### Return value

{/* source:cpp-error-error-category-operator-cmp:0008 */}

1. 1) `true` if `*this` and `rhs` refer to the same object, `false` otherwise.

{/* source:cpp-error-error-category-operator-cmp:0009 */}

2. 2) `true` if `*this` and `rhs` do not refer to the same object, `false` otherwise.

{/* source:cpp-error-error-category-operator-cmp:0010 */}

3. 3) `true` if `*this` is less than `rhs` as defined by the order of `this` and `&rhs`.

{/* source:cpp-error-error-category-operator-cmp:0011 */}

4. 4) `std::strong_order::less` if `*this` is less than `rhs` as defined by the order of `this` and `&rhs`, otherwise `std::strong_order::greater` if `rhs` is less than `*this` in the order, otherwise `std::strong_order::equal`.
