{/* source:cpp-error-error-category-default-error-condition:0001 */}
Returns the error condition for the given error value.

{/* source:cpp-error-error-category-default-error-condition:0002 */}
Equivalent to `std::error_condition(val, *this)`.

{/* source:cpp-error-error-category-default-error-condition:0003 */}
Classes derived from `error_category` may override this function to map certain error values to a generic category. For example, [`std::system_category`](/docs/cpp/library/error/system_category) overrides this function to map the error values that match POSIX [errno](/docs/cpp/library/error/errno) values to [`std::generic_category`](/docs/cpp/library/error/generic_category).

### Return value
