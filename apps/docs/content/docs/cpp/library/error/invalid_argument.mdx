Defines a type of object to be thrown as exception. It reports errors that arise because an argument value has not been accepted.

{/* source:cpp-error-invalid-argument:0002 */}
This exception is thrown by [`std::bitset::bitset`](/docs/cpp/library/utility/bitset/bitset), and the [`std::stoi`](/docs/cpp/library/string/basic_string/stol) and [`std::stof`](/docs/cpp/library/string/basic_string/stof) families of functions.

##### Exceptions

1,2) May throw [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc).

##### Notes

Because copying `std::invalid_argument` is not permitted to throw exceptions, this message is typically stored internally as a separately-allocated reference-counted string. This is also why there is no constructor taking `std::string&&`: it would have to copy the content anyway.

Before the resolution of [LWG issue 254](https://cplusplus.github.io/LWG/issue254), the non-copy constructor can only accept [`std::string`](/docs/cpp/library/string/basic_string). It makes dynamic allocation mandatory in order to construct a [`std::string`](/docs/cpp/library/string/basic_string) object.

After the resolution of [LWG issue 471](https://cplusplus.github.io/LWG/issue471), a derived standard exception class must have a publicly accessible copy constructor. It can be implicitly defined as long as the explanatory strings obtained by `what()` are the same for the original object and the copied object.

### Notes

{/* source:cpp-error-invalid-argument:0009 */}
The purpose of this exception type is similar to the error condition [`std::errc::invalid_argument`](/docs/cpp/library/error/errc) (thrown in [`std::system_error`](/docs/cpp/library/error/system_error) from member functions of [`std::thread`](/docs/cpp/library/thread/thread)) and the related `errno` constant [`EINVAL`](/docs/cpp/library/error/errno_macros).

### Example

{/* source:cpp-error-invalid-argument:0010 */}
```cpp
#include <bitset>
#include <iostream>
#include <stdexcept>
#include <string>

int main()
{
    try
    {
        std::bitset<4>{"012"}; // Throws: only '0' or '1' expected
    }
    catch (std::invalid_argument const& ex)
    {
        std::cout << "#1: " << ex.what() << '\n';
    }

    try
    {
        [[maybe_unused]] int f = std::stoi("ABBA"); // Throws: no conversion
    }
    catch (std::invalid_argument const& ex)
    {
        std::cout << "#2: " << ex.what() << '\n';
    }

    try
    {
        [[maybe_unused]] float f = std::stof("(3.14)"); // Throws: no conversion
    }
    catch (std::invalid_argument const& ex)
    {
        std::cout << "#3: " << ex.what() << '\n';
    }
}
```

Possible output:

```text
#1: bitset string ctor has invalid argument
#2: stoi: no conversion
#3: stof: no conversion
```
