{/* source:cpp-error-exception-set-unexpected:0001 */}
Makes `f` the new global [`std::unexpected_handler`](/docs/cpp/library/error/exception/unexpected_handler) and returns the previously installed `std::unexpected_handler`.

{/* source:cpp-error-exception-set-unexpected:0002 */}
<Revision since="C++11">
This function is thread-safe. Every call to `std::set_unexpected` *synchronizes-with* (see [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) the subsequent calls to `std::set_unexpected` and [`std::get_unexpected`](/docs/cpp/library/error/exception/get_unexpected)
</Revision>

### Parameters

{/* source:cpp-error-exception-set-unexpected:0003 */}
<ParameterList>
  <Parameter name="f">pointer to function of type [`std::unexpected_handler`](/docs/cpp/library/error/exception/unexpected_handler), or null pointer</Parameter>
</ParameterList>

### Return value

{/* source:cpp-error-exception-set-unexpected:0004 */}
The previously-installed unexpected handler, or a null pointer value if none was installed.
