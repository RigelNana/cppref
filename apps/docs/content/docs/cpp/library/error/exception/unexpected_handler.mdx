{/* source:cpp-error-exception-unexpected-handler:0001 */}
`std::unexpected_handler` is the function pointer type (pointer to function that takes no arguments and returns `void`), which is installed and queried by the functions [`std::set_unexpected`](/docs/cpp/library/error/exception/set_unexpected) and [`std::get_unexpected`](/docs/cpp/library/error/exception/get_unexpected) and called by [`std::unexpected`](/docs/cpp/library/error/unexpected).

{/* source:cpp-error-exception-unexpected-handler:0002 */}
The C++ implementation provides a default `std::unexpected_handler` function, which calls [`std::terminate()`](/docs/cpp/library/error/terminate). If the null pointer value is installed (by means of [`std::set_unexpected`](/docs/cpp/library/error/exception/set_unexpected)), the implementation may restore the default handler instead.

{/* source:cpp-error-exception-unexpected-handler:0003 */}
A user-defined `std::unexpected_handler` is expected to either terminate the program or throw an exception. If it throws an exception, one of the following three situations may be encountered:

{/* source:cpp-error-exception-unexpected-handler:0004 */}
1. the exception thrown by `std::unexpected_handler` satisfies the dynamic exception specification that was violated earlier. The new exception is allowed to escape the function and stack unwinding continues.

{/* source:cpp-error-exception-unexpected-handler:0005 */}
2. the exception thrown by `std::unexpected_handler` still violates the exception specification:

{/* source:cpp-error-exception-unexpected-handler:0006 */}
2a. however, the exception specification allows [`std::bad_exception`](/docs/cpp/library/error/bad_exception): the thrown exception object is destroyed, and `std::bad_exception` is constructed by the C++ runtime and thrown instead.

{/* source:cpp-error-exception-unexpected-handler:0007 */}
2b. the exception specification does not allow [`std::bad_exception`](/docs/cpp/library/error/bad_exception): [`std::terminate()`](/docs/cpp/library/error/terminate) is called.
