### Standard exception requirements

{/* source:cpp-error-exception:0005 */}
Each standard library class `T` that derives from `std::exception` has the following publicly accessible member functions, each of them <InlineRevision until="C++11">do not exit with an exception</InlineRevision> <InlineRevision since="C++11">having a [non-throwing exception specification](/docs/cpp/language/exceptions/noexcept_spec)</InlineRevision>:

{/* source:cpp-error-exception:0006 */}
- [default constructor](/docs/cpp/language/classes/default_constructor) (unless other constructors are provided)
- [copy constructor](/docs/cpp/language/classes/copy_constructor)
- [copy assignment operator](/docs/cpp/language/classes/as_operator)

{/* source:cpp-error-exception:0007 */}
The copy constructor and the copy assignment operator meet the following postcondition:

{/* source:cpp-error-exception:0008 */}
- If two objects `lhs` and `rhs` both have dynamic type `T` and `lhs` is a copy of `rhs`, then `std::strcmp(lhs.what(), rhs.what())` is equal to `0`.

{/* source:cpp-error-exception:0009 */}
The `what()` member function of each such `T` satisfies the constraints specified for [`std::exception::what()`](/docs/cpp/library/error/exception/what).
