### Notes

{/* source:cpp-error-exception-exception:0005 */}
Because copying `std::exception` is not permitted to throw exceptions, when derived classes (such as [`std::runtime_error`](/docs/cpp/library/error/runtime_error)) have to manage a user-defined diagnostic message, it is typically implemented as a copy-on-write string.

{/* source:cpp-error-exception-exception:0006 */}
The Microsoft implementation includes non-standard constructors taking strings thus allowing instances to be thrown directly with a meaningful error message. The nearest standard equivalents are [`std::runtime_error`](/docs/cpp/library/error/runtime_error) or [`std::logic_error`](/docs/cpp/library/error/logic_error).
