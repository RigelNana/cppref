{/* source:cpp-thread-shared-mutex-unlock-shared:0001 */}
Releases the mutex from shared ownership by the calling thread.

{/* source:cpp-thread-shared-mutex-unlock-shared:0002 */}
The mutex must be locked by the current thread of execution in shared mode, otherwise, the behavior is undefined.

{/* source:cpp-thread-shared-mutex-unlock-shared:0003 */}
This operation *synchronizes-with* (as defined in [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) any subsequent [`lock()`](/docs/cpp/library/thread/shared_mutex/lock) operation that obtains ownership of the same mutex.

### Parameters

{/* source:cpp-thread-shared-mutex-unlock-shared:0004 */}
(none)

### Return value

{/* source:cpp-thread-shared-mutex-unlock-shared:0005 */}
(none)

### Exceptions

{/* source:cpp-thread-shared-mutex-unlock-shared:0006 */}
Throws nothing.

### Notes

{/* source:cpp-thread-shared-mutex-unlock-shared:0007 */}
`unlock_shared()` is usually not called directly: [`std::shared_lock`](/docs/cpp/library/thread/shared_lock) is used to manage shared locking.
