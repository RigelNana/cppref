The class `std::once_flag` is a helper structure for [`std::call_once`](/docs/cpp/library/thread/call_once).

{/* source:cpp-thread-once-flag:0002 */}
An object of type `std::once_flag` that is passed to multiple calls to [`std::call_once`](/docs/cpp/library/thread/call_once) allows those calls to coordinate with each other such that only one of the calls will actually run to completion.

{/* source:cpp-thread-once-flag:0003 */}
`std::once_flag` is neither copyable nor movable.
