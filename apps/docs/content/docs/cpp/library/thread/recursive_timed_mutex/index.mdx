{/* source:cpp-thread-recursive-timed-mutex:0001 */}
The `recursive_timed_mutex` class is a synchronization primitive that can be used to protect shared data from being simultaneously accessed by multiple threads.

{/* source:cpp-thread-recursive-timed-mutex:0002 */}
In a manner similar to [`std::recursive_mutex`](/docs/cpp/library/thread/recursive_mutex), `recursive_timed_mutex` provides exclusive, recursive ownership semantics. In addition, `recursive_timed_mutex` provides the ability to attempt to claim ownership of a `recursive_timed_mutex` with a timeout via the [`try_lock_for`](/docs/cpp/library/thread/recursive_timed_mutex/try_lock_for) and [`try_lock_until`](/docs/cpp/library/thread/recursive_timed_mutex/try_lock_until) member functions.

{/* source:cpp-thread-recursive-timed-mutex:0003 */}
The `recursive_timed_mutex` class satisfies all requirements of [TimedMutex](/docs/cpp/library/named_req/TimedMutex) and [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType).
