{/* source:cpp-thread-recursive-timed-mutex-unlock:0001 */}
Unlocks the mutex if its level of ownership is `1` (there was exactly one more call to [`lock()`](/docs/cpp/library/thread/recursive_timed_mutex/lock) than there were calls to `unlock()` made by this thread), reduces the level of ownership by 1 otherwise.

{/* source:cpp-thread-recursive-timed-mutex-unlock:0002 */}
The mutex must be locked by the current thread of execution, otherwise, the behavior is undefined.

{/* source:cpp-thread-recursive-timed-mutex-unlock:0003 */}
This operation *synchronizes-with* (as defined in [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) any subsequent lock operation that obtains ownership of the same mutex.

### Parameters

{/* source:cpp-thread-recursive-timed-mutex-unlock:0004 */}
(none)

### Return value

{/* source:cpp-thread-recursive-timed-mutex-unlock:0005 */}
(none)

### Exceptions

{/* source:cpp-thread-recursive-timed-mutex-unlock:0006 */}
Throws nothing.

### Notes

{/* source:cpp-thread-recursive-timed-mutex-unlock:0007 */}
`unlock()` is usually not called directly: [`std::unique_lock`](/docs/cpp/library/thread/unique_lock) and [`std::lock_guard`](/docs/cpp/library/thread/lock_guard) are used to manage exclusive locking.
