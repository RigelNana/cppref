{/* source:cpp-thread-future-category:0001 */}
Obtains a reference to the static error category object for the errors related to futures and promises. The object is required to override the virtual function `error_category::name()` to return a pointer to the string `"future"`. It is used to identify error codes provided in the exceptions of type [`std::future_error`](/docs/cpp/library/thread/future_error).

### Parameters

{/* source:cpp-thread-future-category:0002 */}
(none)

### Return value

{/* source:cpp-thread-future-category:0003 */}
A reference to the static object of unspecified runtime type, derived from `std::error_category`.
