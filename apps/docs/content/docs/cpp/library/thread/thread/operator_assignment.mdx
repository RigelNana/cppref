<DeclarationDoc>
  <Declaration language="cpp" since="C++11" code={`thread& operator=( thread&& other ) noexcept;`} />
</DeclarationDoc>

{/* source:cpp-thread-thread-operator:0001 */}
If `*this` still has an associated running thread (i.e. `joinable() == true`), calls `std::terminate()`. Otherwise, assigns the state of `other` to `*this` and sets `other` to a default constructed state.

{/* source:cpp-thread-thread-operator:0002 */}
After this call, [`this->get_id()`](/docs/cpp/library/thread/thread/get_id) is equal to the value of [`other.get_id()`](/docs/cpp/library/thread/thread/get_id) prior to the call, and `other` no longer represents a thread of execution.

### Parameters

{/* source:cpp-thread-thread-operator:0003 */}
<ParameterList>
  <Parameter name="other">another thread object to assign to this thread object</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-thread-operator:0004 */}
`*this`
