  <DeclarationDescription>
    {/* source:cpp-thread-thread-thread:0001 */}
    Constructs a new `std::thread` object.

    {/* source:cpp-thread-thread-thread:0002 */}
    1. 1) Creates a new `std::thread` object which does not represent a thread.

    {/* source:cpp-thread-thread-thread:0003 */}
    2. 2) Move constructor. Constructs the `std::thread` object to represent the thread of execution that was represented by `other`. After this call `other` no longer represents a thread of execution.

    {/* source:cpp-thread-thread-thread:0004 */}
    3. 3) Creates a new `std::thread` object and associates it with a thread of execution. The new thread of execution starts executing:

    <Revision until="C++23">
    [`INVOKE`](/docs/cpp/library/utility/functional)`(`[`decay-copy`](/docs/cpp/library/standard_library/decay-copy)`(std::forward<F>(f)), `[`decay-copy`](/docs/cpp/library/standard_library/decay-copy)`(std::forward<Args>(args))...)`
    </Revision>

    <Revision since="C++23">
    `std::invoke(auto(std::forward<F>(f)), auto(std::forward<Args>(args))...)`
    </Revision>

    {/* source:cpp-thread-thread-thread:0005 */}
    <InlineRevision until="C++23">The calls of [`decay-copy`](/docs/cpp/library/standard_library/decay-copy) are evaluated</InlineRevision> <InlineRevision since="C++23">The values produced by `auto` are [materialized](/docs/cpp/language/expressions/implicit_cast#Temporary_materialization)</InlineRevision> in the current thread, so that any exceptions thrown during evaluation and copying/moving of the arguments are thrown in the current thread, without starting the new thread.

    {/* source:cpp-thread-thread-thread:0006 */}
    This overload participates in overload resolution only if <InlineRevision until="C++20">`std::decay<F>::type`</InlineRevision> <InlineRevision since="C++20">`std::remove_cvref_t<F>`</InlineRevision> is not the same type as `std::thread`.

    <Revision until="C++20">
    If any of the following conditions is satisfied, the program is ill-formed:

    - `F` is not [`MoveConstructible`](/docs/cpp/library/named_req/MoveConstructible).
    - Any type in `Args` is not [`MoveConstructible`](/docs/cpp/library/named_req/MoveConstructible).
    - [`INVOKE`](/docs/cpp/library/utility/functional)`(`[`decay-copy`](/docs/cpp/library/standard_library/decay-copy)`(std::forward<F>(f)), `[`decay-copy`](/docs/cpp/library/standard_library/decay-copy)`(std::forward<Args>(args))...)` is not a valid expression.

    </Revision>

    <Revision since="C++20">
    If any of the following is `false`, the program is ill-formed:

    - `std::is_constructible_v<std::decay_t<F>, F>`
    - `(std::is_constructible_v<std::decay_t<Args>, Args> && ...)`
    - `std::is_invocable_v<std::decay_t<F>, std::decay_t<Args>...>`

    </Revision>

    {/* source:cpp-thread-thread-thread:0007 */}
    The completion of the invocation of the constructor [synchronizes with](/docs/cpp/library/atomic/memory_order) the beginning of the invocation of the copy of `f` on the new thread of execution.

    {/* source:cpp-thread-thread-thread:0008 */}
    4. 4) The copy constructor is deleted; threads are not copyable. No two `std::thread` objects may represent the same thread of execution.
  </DeclarationDescription>
</DeclarationDoc>

### Postconditions

{/* source:cpp-thread-thread-thread:0010 */}
1. 1) [`get_id()`](/docs/cpp/library/thread/thread/get_id) equal to `std::thread::id()` (i.e. [`joinable()`](/docs/cpp/library/thread/thread/joinable) is `false`).

{/* source:cpp-thread-thread-thread:0011 */}
2. 2) `other.get_id()` equal to [`std::thread::id()`](/docs/cpp/library/thread/thread/id) and [`get_id()`](/docs/cpp/library/thread/thread/get_id) returns the value of `other.get_id()` prior to the start of construction.

{/* source:cpp-thread-thread-thread:0012 */}
3. 3) [`get_id()`](/docs/cpp/library/thread/thread/get_id) not equal to [`std::thread::id()`](/docs/cpp/library/thread/thread/id) (i.e. [`joinable()`](/docs/cpp/library/thread/thread/joinable) is `true`).

### Exceptions

{/* source:cpp-thread-thread-thread:0013 */}
3. 3) [`std::system_error`](/docs/cpp/library/error/system_error) if the thread could not be started. The exception may represent the error condition `std::errc::resource_unavailable_try_again` or another implementation-specific error condition.

### Notes

{/* source:cpp-thread-thread-thread:0014 */}
The arguments to the thread function are moved or copied by value. If a reference argument needs to be passed to the thread function, it has to be wrapped (e.g., with [`std::ref`](/docs/cpp/library/utility/functional/ref) or [`std::cref`](/docs/cpp/library/utility/functional/ref)).

{/* source:cpp-thread-thread-thread:0015 */}
Any return value from the function is ignored. If the function throws an exception, [`std::terminate`](/docs/cpp/library/error/terminate) is called. In order to pass return values or exceptions back to the calling thread, [`std::promise`](/docs/cpp/library/thread/promise) or [`std::async`](/docs/cpp/library/thread/async) may be used.

### Example

{/* source:cpp-thread-thread-thread:0016 */}
```cpp
#include <chrono>
#include <iostream>
#include <thread>
#include <utility>
 
void f1(int n)
{
    for (int i = 0; i < 5; ++i)
    {
        std::cout << "Thread 1 executing\n";
        ++n;
        std::this_thread::sleep_for(std::chrono::milliseconds(10));
    }
}
 
void f2(int& n)
{
    for (int i = 0; i < 5; ++i)
    {
        std::cout << "Thread 2 executing\n";
        ++n;
        std::this_thread::sleep_for(std::chrono::milliseconds(10));
    }
}
 
class foo
{
public:
    void bar()
    {
        for (int i = 0; i < 5; ++i)
        {
            std::cout << "Thread 3 executing\n";
            ++n;
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
        }
    }
    int n = 0;
};
 
class baz
{
public:
    void operator()()
    {
        for (int i = 0; i < 5; ++i)
        {
            std::cout << "Thread 4 executing\n";
            ++n;
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
        }
    }
    int n = 0;
};
 
int main()
{
    int n = 0;
    foo f;
    baz b;
    std::thread t1; // t1 is not a thread
    std::thread t2(f1, n + 1); // pass by value
    std::thread t3(f2, std::ref(n)); // pass by reference
    std::thread t4(std::move(t3)); // t4 is now running f2(). t3 is no longer a thread
    std::thread t5(&foo::bar, &f); // t5 runs foo::bar() on object f
    std::thread t6(b); // t6 runs baz::operator() on a copy of object b
    t2.join();
    t4.join();
    t5.join();
    t6.join();
    std::cout << "Final value of n is " << n << '\n';
    std::cout << "Final value of f.n (foo::n) is " << f.n << '\n';
    std::cout << "Final value of b.n (baz::n) is " << b.n << '\n';
}
```

```text
Thread 2 executing
Thread 3 executing
Thread 4 executing
Thread 3 executing
Thread 1 executing
Thread 2 executing
Thread 4 executing
Thread 2 executing
Thread 3 executing

```
