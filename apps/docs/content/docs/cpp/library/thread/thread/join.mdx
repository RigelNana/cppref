{/* source:cpp-thread-thread-join:0001 */}
Blocks the current thread until the thread identified by `*this` finishes its execution.

{/* source:cpp-thread-thread-join:0002 */}
The completion of the thread identified by `*this` synchronizes with the corresponding successful return from `join()`.

{/* source:cpp-thread-thread-join:0003 */}
No synchronization is performed on `*this` itself. Concurrently calling `join()` on the same thread object from multiple threads constitutes a data race that results in undefined behavior.

### Parameters

{/* source:cpp-thread-thread-join:0004 */}
(none)

### Return value

{/* source:cpp-thread-thread-join:0005 */}
(none)

### Postconditions

{/* source:cpp-thread-thread-join:0006 */}
[`joinable()`](/docs/cpp/library/thread/thread/joinable) is `false`.

### Exceptions

{/* source:cpp-thread-thread-join:0007 */}
[`std::system_error`](/docs/cpp/library/error/system_error) if an error occurs.

### Error conditions

{/* source:cpp-thread-thread-join:0008 */}
- [`resource_deadlock_would_occur`](/docs/cpp/library/error/errc) if `this->get_id() == std::this_thread::get_id()` (deadlock detected).
- [`no_such_process`](/docs/cpp/library/error/errc) if the thread is not valid.
- [`invalid_argument`](/docs/cpp/library/error/errc) if [`joinable()`](/docs/cpp/library/thread/thread/joinable) is `false`.

### Example

{/* source:cpp-thread-thread-join:0009 */}
```cpp
#include <chrono>
#include <iostream>
#include <thread>
 
void foo()
{
    // simulate expensive operation
    std::this_thread::sleep_for(std::chrono::seconds(1));
}
 
void bar()
{
    // simulate expensive operation
    std::this_thread::sleep_for(std::chrono::seconds(1));
}
 
int main()
{
    std::cout << "starting first helper...\n";
    std::thread helper1(foo);
 
    std::cout << "starting second helper...\n";
    std::thread helper2(bar);
 
    std::cout << "waiting for helpers to finish..." << std::endl;
    helper1.join();
    helper2.join();
 
    std::cout << "done!\n";
}
```

Output:

```text
starting first helper...
starting second helper...
waiting for helpers to finish...
done!
```
