{/* source:cpp-thread-thread:0001 */}
The class `thread` represents [a single thread of execution](https://en.wikipedia.org/wiki/Thread_(computing)). Threads allow multiple functions to execute concurrently.

{/* source:cpp-thread-thread:0002 */}
Threads begin execution immediately upon construction of the associated thread object (pending any OS scheduling delays), starting at the top-level function provided as a [constructor argument](/docs/cpp/library/thread/thread/thread). The return value of the top-level function is ignored and if it terminates by throwing an exception, [`std::terminate`](/docs/cpp/library/error/terminate) is called. The top-level function may communicate its return value or an exception to the caller via [`std::promise`](/docs/cpp/library/thread/promise) or by modifying shared variables (which may require synchronization, see [`std::mutex`](/docs/cpp/library/thread/mutex) and [`std::atomic`](/docs/cpp/library/atomic/atomic)).

{/* source:cpp-thread-thread:0003 */}
`std::thread` objects may also be in the state that does not represent any thread (after default construction, move from, [`detach`](/docs/cpp/library/thread/thread/detach), or [`join`](/docs/cpp/library/thread/thread/join)), and a thread of execution may not be associated with any thread objects (after [`detach`](/docs/cpp/library/thread/thread/detach)).

{/* source:cpp-thread-thread:0004 */}
No two `std::thread` objects may represent the same thread of execution; `std::thread` is not [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible) or [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable), although it is [`MoveConstructible`](/docs/cpp/library/named_req/MoveConstructible) and [`MoveAssignable`](/docs/cpp/library/named_req/MoveAssignable).
