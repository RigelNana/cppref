{/* source:cpp-thread-thread-detach:0001 */}
Separates the thread of execution from the thread object, allowing execution to continue independently. Any allocated resources will be freed once the thread exits.

{/* source:cpp-thread-thread-detach:0002 */}
After calling `detach` `*this` no longer owns any thread.

### Parameters

{/* source:cpp-thread-thread-detach:0003 */}
(none)

### Return value

{/* source:cpp-thread-thread-detach:0004 */}
(none)

### Postconditions

{/* source:cpp-thread-thread-detach:0005 */}
[`joinable`](/docs/cpp/library/thread/thread/joinable) is `false`.

### Exceptions

{/* source:cpp-thread-thread-detach:0006 */}
[`std::system_error`](/docs/cpp/library/error/system_error) if `joinable() == false` or an error occurs.

### Example

{/* source:cpp-thread-thread-detach:0007 */}
```cpp
#include <chrono>
#include <iostream>
#include <thread>
 
void independentThread() 
{
    std::cout << "Starting concurrent thread.\n";
    std::this_thread::sleep_for(std::chrono::seconds(2));
    std::cout << "Exiting concurrent thread.\n";
}
 
void threadCaller() 
{
    std::cout << "Starting thread caller.\n";
    std::thread t(independentThread);
    t.detach();
    std::this_thread::sleep_for(std::chrono::seconds(1));
    std::cout << "Exiting thread caller.\n";
}
 
int main() 
{
    threadCaller();
    std::this_thread::sleep_for(std::chrono::seconds(5));
}
```

Possible output:

```text
Starting thread caller.
Starting concurrent thread.
Exiting thread caller.
Exiting concurrent thread.
```
