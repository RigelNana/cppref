The template specialization of [`std::formatter`](/docs/cpp/library/text/format/formatter) for the [`std::thread::id`](/docs/cpp/library/thread/thread/id) class allows users to convert a thread identifier to its textual representation using [formatting functions](/docs/cpp/library/text/format).

## Format specification

{/* source:cpp-thread-thread-id-formatter:0002 */}
The syntax of format specifications is:

{/* source:cpp-thread-thread-id-formatter:0003 */}
<DeclarationDoc>
  <Declaration language="cpp" grammar code="fill-and-align (optional) width (optional)" />
</DeclarationDoc>

{/* source:cpp-thread-thread-id-formatter:0004 */}
fill-and-align and width have the same meaning as in [standard format specification](/docs/cpp/library/text/format/formatter#Standard_format_specification). The default alignment is `>`.

{/* source:cpp-thread-thread-id-formatter:0005 */}
The formatted output matches the output of [`operator<<`](/docs/cpp/library/thread/thread/id/operator_ltlt), adjusted as appropriate for the format specifiers.

### Example

{/* source:cpp-thread-thread-id-formatter:0007 */}
```cpp
#include <format>
#include <iostream>
#include <thread>
 
int main()
{
    std::thread::id this_id = std::this_thread::get_id();
    std::thread::id null_id;
 
    std::cout << std::format("current thread id: {}\n", this_id);
    std::cout << std::format("{:=^10}\n", null_id);
}
```

Possible output:

```text
current thread id: 140046396632256
====0=====
```
