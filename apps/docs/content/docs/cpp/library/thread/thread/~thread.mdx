{/* source:cpp-thread-thread-thread:0001 */}
Destroys the thread object.

{/* source:cpp-thread-thread-thread:0002 */}
If `*this` has an associated thread (`joinable() == true`), `std::terminate()` is called.

### Notes

{/* source:cpp-thread-thread-thread:0003 */}
A thread object does not have an associated thread (and is safe to destroy) after

{/* source:cpp-thread-thread-thread:0004 */}
- it was default-constructed.
- it was moved from.
- [`join()`](/docs/cpp/library/thread/thread/join) has been called.
- [`detach()`](/docs/cpp/library/thread/thread/detach) has been called.

### Example

{/* source:cpp-thread-thread-thread:0005 */}
```cpp
#include <thread>
using namespace std::chrono_literals;
 
int main()
{
    auto bleah = std::thread{[]{ std::this_thread::sleep_for(13ms); }};
 
}   // ~thread calls std::terminate()
```

Possible output:

```text
terminate called without an active exception
```
