{/* source:cpp-thread-thread-id-operator-ltlt:0001 */}
Writes a textual representation of a thread identifier `id` to the output stream `ost`.

{/* source:cpp-thread-thread-id-operator-ltlt:0002 */}
If two thread identifiers compare equal, they have identical textual representations; if they do not compare equal, their representations are distinct.

### Parameters

{/* source:cpp-thread-thread-id-operator-ltlt:0003 */}
<ParameterList>
  <Parameter name="ost">output stream to insert the data into</Parameter>
  <Parameter name="id">thread identifier</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-thread-id-operator-ltlt:0004 */}
`ost`

### Exceptions

{/* source:cpp-thread-thread-id-operator-ltlt:0005 */}
May throw implementation-defined exceptions.

### Example

{/* source:cpp-thread-thread-id-operator-ltlt:0006 */}
```cpp
#include <chrono>
#include <iostream>
#include <thread>
using namespace std::chrono;
 
int main()
{
    std::thread t1([]{ std::this_thread::sleep_for(256ms); });
    std::thread t2([]{ std::this_thread::sleep_for(512ms); });
 
    std::clog << t1.get_id() << '\n' << t2.get_id() << '\n';
 
    t1.join();
    t2.join();
}
```

Possible output:

```text
141592653589793
141421356237309
```
