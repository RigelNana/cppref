  <DeclarationDescription>
    {/* source:cpp-thread-lock-guard-lock-guard:0001 */}
    Acquires ownership of the given mutex `m`.

    {/* source:cpp-thread-lock-guard-lock-guard:0002 */}
    1. Effectively calls `m.lock()`.

    {/* source:cpp-thread-lock-guard-lock-guard:0003 */}
    2. Acquires ownership of the mutex `m` without attempting to lock it. The behavior is undefined if the current thread does not hold a non-shared lock (i.e., a lock acquired by `lock`, `try_lock`, `try_lock_for`, or `try_lock_until`) on `m`.

    {/* source:cpp-thread-lock-guard-lock-guard:0004 */}
    3. Copy constructor is deleted.

    {/* source:cpp-thread-lock-guard-lock-guard:0005 */}
    The behavior is undefined if `m` is destroyed before the `lock_guard` object is.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-thread-lock-guard-lock-guard:0006 */}
<ParameterList>
  <Parameter name="m">mutex to acquire ownership of</Parameter>
  <Parameter name="t">tag parameter used to select non-locking version of the constructor</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-thread-lock-guard-lock-guard:0007 */}
1. Throws any exceptions thrown by `m.lock()`.

{/* source:cpp-thread-lock-guard-lock-guard:0008 */}
2. Throws nothing.
