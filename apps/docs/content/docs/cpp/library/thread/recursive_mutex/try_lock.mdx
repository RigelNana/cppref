{/* source:cpp-thread-recursive-mutex-try-lock:0001 */}
Tries to lock the mutex. Returns immediately. On successful lock acquisition returns `true`, otherwise returns `false`.

{/* source:cpp-thread-recursive-mutex-try-lock:0002 */}
This function is allowed to fail spuriously and return `false` even if the mutex is not currently locked by any other thread.

{/* source:cpp-thread-recursive-mutex-try-lock:0003 */}
A thread may call `try_lock` on a recursive mutex repeatedly. Successful calls to `try_lock` increment the ownership count: the mutex will only be released after the thread makes a matching number of calls to [`unlock`](/docs/cpp/library/thread/recursive_mutex/unlock).

{/* source:cpp-thread-recursive-mutex-try-lock:0004 */}
The maximum number of levels of ownership is unspecified. A call to `try_lock` will return `false` if this number is exceeded.

{/* source:cpp-thread-recursive-mutex-try-lock:0005 */}
Prior [`unlock()`](/docs/cpp/library/thread/recursive_mutex/unlock) operation on the same mutex *synchronizes-with* (as defined in [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) this operation if it returns `true`. Note that prior [`lock()`](/docs/cpp/library/thread/recursive_mutex/lock) does not synchronize with this operation if it returns `false`.

### Parameters

{/* source:cpp-thread-recursive-mutex-try-lock:0006 */}
(none)

### Return value

{/* source:cpp-thread-recursive-mutex-try-lock:0007 */}
`true` if the lock was acquired successfully, otherwise `false`.

### Exceptions

{/* source:cpp-thread-recursive-mutex-try-lock:0008 */}
Throws nothing.

### Example

{/* source:cpp-thread-recursive-mutex-try-lock:0009 */}
```cpp
#include <iostream>
#include <mutex>
 
int main()
{
    std::recursive_mutex test;
    if (test.try_lock())
    {
        std::cout << "lock acquired\n";
        test.unlock();
    }
    else
        std::cout << "lock not acquired\n";
 
    test.lock();
    // non-recursive mutex would return false from try_lock now
    if (test.try_lock())
    {
        std::cout << "lock acquired\n";
        test.unlock(); 
    }
    else
        std::cout << "lock not acquired\n";
 
    test.unlock();
}
```

Output:

```text
lock acquired
lock acquired
```
