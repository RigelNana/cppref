{/* source:cpp-thread-shared-timed-mutex-try-lock-shared:0001 */}
Tries to lock the mutex in shared mode. Returns immediately. On successful lock acquisition returns `true`, otherwise returns `false`.

{/* source:cpp-thread-shared-timed-mutex-try-lock-shared:0002 */}
This function is allowed to fail spuriously and return `false` even if the mutex is not currenly exclusively locked by any other thread.

{/* source:cpp-thread-shared-timed-mutex-try-lock-shared:0003 */}
Prior [`unlock()`](/docs/cpp/library/thread/shared_timed_mutex/unlock) operation on the same mutex *synchronizes-with* (as defined in [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) this operation if it returns `true`.

{/* source:cpp-thread-shared-timed-mutex-try-lock-shared:0004 */}
The behavior is undefined if the calling thread already owns the mutex in any mode.

### Parameters

{/* source:cpp-thread-shared-timed-mutex-try-lock-shared:0005 */}
(none)

### Return value

{/* source:cpp-thread-shared-timed-mutex-try-lock-shared:0006 */}
`true` if the lock was acquired successfully, otherwise `false`.

### Exceptions

{/* source:cpp-thread-shared-timed-mutex-try-lock-shared:0007 */}
Throws nothing.
