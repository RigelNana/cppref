  <Declaration id="2" language="cpp" since="C++20" code={`barrier( const barrier& ) = delete;`} />

  <DeclarationDescription>
    {/* source:cpp-thread-barrier-barrier:0001 */}
    1. Sets the both initial expected count for each phase and the current expected count for the first phase to `expected`, initializes the completion function object with `std::move(f)`, and then starts the first phase. The behavior is undefined if `expected` is negative or greater than [`max()`](/docs/cpp/library/thread/barrier/max).

    {/* source:cpp-thread-barrier-barrier:0002 */}
    2. Copy constructor is deleted. `barrier` is neither copyable nor movable.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-thread-barrier-barrier:0003 */}
<ParameterList>
  <Parameter name="expected">initial value of the expected count</Parameter>
  <Parameter name="f">completion function object to be called on phase completion step</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-thread-barrier-barrier:0004 */}
1) Any exception thrown by `CompletionFunction`'s move constructor.

### Notes

{/* source:cpp-thread-barrier-barrier:0005 */}
`expected` is permitted to be zero. However, calling any non-static member function other than the destructor on such `barrier` results in undefined behavior. In other words, such `barrier` can only be destroyed.
