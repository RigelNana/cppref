{/* source:cpp-thread-barrier-arrive:0001 */}
Constructs an `arrival_token` object associated with the phase synchronization point for the current phase. Then, decrements the expected count by `n`.

{/* source:cpp-thread-barrier-arrive:0002 */}
This function executes atomically. The call to this function [strongly happens-before](/docs/cpp/library/atomic/memory_order#Strongly_happens-before) the start of the phase completion step for the current phase.

{/* source:cpp-thread-barrier-arrive:0003 */}
The behavior is undefined if `n` is less than or equal to `0` or greater than the expected count for the current barrier phase.

### Parameters

{/* source:cpp-thread-barrier-arrive:0004 */}
<ParameterList>
  <Parameter name="n">the value by which the expected count is decreased</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-barrier-arrive:0005 */}
The constructed `arrival_token` object.

### Exceptions

{/* source:cpp-thread-barrier-arrive:0006 */}
Throws [`std::system_error`](/docs/cpp/library/error/system_error) with an error code allowed for mutex types on error.

### Notes

{/* source:cpp-thread-barrier-arrive:0007 */}
This function can cause the completion step for the current phase to start.
