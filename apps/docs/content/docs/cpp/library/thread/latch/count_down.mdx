{/* source:cpp-thread-latch-count-down:0001 */}
Atomically decrements the internal counter by `n` without blocking the caller.

{/* source:cpp-thread-latch-count-down:0002 */}
If `n` is greater than the value of the internal counter or is negative, the behavior is undefined.

{/* source:cpp-thread-latch-count-down:0003 */}
This operation [strongly happens-before](/docs/cpp/library/atomic/memory_order#Strongly_happens-before) all calls that are unblocked on this latch.

### Parameters

{/* source:cpp-thread-latch-count-down:0004 */}
<ParameterList>
  <Parameter name="n">the value by which the internal counter is decreased</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-latch-count-down:0005 */}
(none)

### Exceptions

{/* source:cpp-thread-latch-count-down:0006 */}
Throws [`std::system_error`](/docs/cpp/library/error/system_error) with an error code allowed for mutex types on error.
