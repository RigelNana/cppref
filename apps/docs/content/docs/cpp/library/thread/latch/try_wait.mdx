{/* source:cpp-thread-latch-try-wait:0001 */}
Returns `true` only if the internal counter has reached zero. This function may spuriously return `false` with very low probability even if the internal counter has reached zero.

### Parameters

{/* source:cpp-thread-latch-try-wait:0002 */}
(none)

### Return value

{/* source:cpp-thread-latch-try-wait:0003 */}
With very low probability `false`, otherwise `cnt == 0`, where `cnt` is the value of the internal counter.

### Notes

{/* source:cpp-thread-latch-try-wait:0004 */}
The reason why a spurious result is permitted is to allow implementations to use a memory order more relaxed than [`std::memory_order_seq_cst`](/docs/cpp/library/atomic/memory_order).
