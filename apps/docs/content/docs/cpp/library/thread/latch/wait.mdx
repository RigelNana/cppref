{/* source:cpp-thread-latch-wait:0001 */}
Blocks the calling thread until the internal counter reaches `0`. If it is zero already, returns immediately.

### Parameters

{/* source:cpp-thread-latch-wait:0002 */}
(none)

### Return value

{/* source:cpp-thread-latch-wait:0003 */}
(none)

### Exceptions

{/* source:cpp-thread-latch-wait:0004 */}
Throws [`std::system_error`](/docs/cpp/library/error/system_error) with an error code allowed for mutex types on error.
