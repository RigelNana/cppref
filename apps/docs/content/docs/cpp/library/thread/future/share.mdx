{/* source:cpp-thread-future-share:0001 */}
Transfers the shared state of `*this`, if any, to a [`std::shared_future`](/docs/cpp/library/thread/shared_future) object. Multiple `std::shared_future` objects may reference the same shared state, which is not possible with [`std::future`](/docs/cpp/library/thread/future).

{/* source:cpp-thread-future-share:0002 */}
After calling `share` on a [`std::future`](/docs/cpp/library/thread/future), [`valid()`](/docs/cpp/library/thread/future/valid) `== false`.

### Parameters

{/* source:cpp-thread-future-share:0003 */}
(none)

### Return value

{/* source:cpp-thread-future-share:0004 */}
A `std::shared_future` object containing the shared state previously held by `*this`, if any, constructed as if by `std::shared_future<T>(std::move(*this))`.
