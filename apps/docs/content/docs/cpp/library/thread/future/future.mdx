{/* source:cpp-thread-future-future:0001 */}
Constructs a `std::future` object.

{/* source:cpp-thread-future-future:0002 */}
1. Default constructor. Constructs a `std::future` with no shared state. After construction, [`valid()`](/docs/cpp/library/thread/future/valid) `== false`.

{/* source:cpp-thread-future-future:0003 */}
2. Move constructor. Constructs a `std::future` with the shared state of `other` using move semantics. After construction, `other.valid() == false`.

{/* source:cpp-thread-future-future:0004 */}
3. `std::future` is not [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible).
