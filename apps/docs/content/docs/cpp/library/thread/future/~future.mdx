<DeclarationDoc>
  <Declaration language="cpp" since="C++11" code={`~future();`} />
</DeclarationDoc>

{/* source:cpp-thread-future-future:0001 */}
Releases any shared state. This means:

{/* source:cpp-thread-future-future:0002 */}
- If the current object holds the last reference to its shared state, the shared state is destroyed. The current object gives up its reference to its shared state.

{/* source:cpp-thread-future-future:0003 */}
<Revision since="C++14">

    - These actions will not block for the shared state to become ready, except that they may block if all following conditions are satisfied:
      - The shared state was created by a call to [`std::async`](/docs/cpp/library/thread/async).
      - The shared state is not yet ready.
      - The current object was the last reference to the shared state.

</Revision>
