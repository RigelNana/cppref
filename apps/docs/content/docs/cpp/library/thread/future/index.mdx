{/* source:cpp-thread-future:0001 */}
The class template `std::future` provides a mechanism to access the result of asynchronous operations:

{/* source:cpp-thread-future:0002 */}
- An asynchronous operation (created via [`std::async`](/docs/cpp/library/thread/async), [`std::packaged_task`](/docs/cpp/library/thread/packaged_task), or [`std::promise`](/docs/cpp/library/thread/promise)) can provide a `std::future` object to the creator of that asynchronous operation.

{/* source:cpp-thread-future:0003 */}
- The creator of the asynchronous operation can then use a variety of methods to query, wait for, or extract a value from the `std::future`. These methods may block if the asynchronous operation has not yet provided a value.

{/* source:cpp-thread-future:0004 */}
- When the asynchronous operation is ready to send a result to the creator, it can do so by modifying shared state (e.g. [`std::promise::set_value`](/docs/cpp/library/thread/promise/set_value)) that is linked to the creator's `std::future`.

{/* source:cpp-thread-future:0005 */}
Note that `std::future` references shared state that is not shared with any other asynchronous return objects (as opposed to [`std::shared_future`](/docs/cpp/library/thread/shared_future)).

### Examples

{/* source:cpp-thread-future:0007 */}
```cpp
#include <future>
#include <iostream>
#include <thread>
 
int main()
{
    // future from a packaged_task
    std::packaged_task<int()> task([]{ return 7; }); // wrap the function
    std::future<int> f1 = task.get_future(); // get a future
    std::thread t(std::move(task)); // launch on a thread
 
    // future from an async()
    std::future<int> f2 = std::async(std::launch::async, []{ return 8; });
 
    // future from a promise
    std::promise<int> p;
    std::future<int> f3 = p.get_future();
    std::thread([&p]{ p.set_value_at_thread_exit(9); }).detach();
 
    std::cout << "Waiting..." << std::flush;
    f1.wait();
    f2.wait();
    f3.wait();
    std::cout << "Done!\nResults are: "
              << f1.get() << ' ' << f2.get() << ' ' << f3.get() << '\n';
    t.join();
}
```

Output:

```text
Waiting...Done!
Results are: 7 8 9
```

### Example with exceptions

{/* source:cpp-thread-future:0008 */}
```cpp
#include <future>
#include <iostream>
#include <thread>
 
int main()
{
    std::promise<int> p;
    std::future<int> f = p.get_future();
 
    std::thread t([&p]
    {
        try
        {
            // code that may throw
            throw std::runtime_error("Example");
        }
        catch (...)
        {
            try
            {
                // store anything thrown in the promise
                p.set_exception(std::current_exception());
            }
            catch (...) {} // set_exception() may throw too
        }
    });
 
    try
    {
        std::cout << f.get();
    }
    catch (const std::exception& e)
    {
        std::cout << "Exception from the thread: " << e.what() << '\n';
    }
    t.join();
}
```

Output:

```text
Exception from the thread: Example
```
