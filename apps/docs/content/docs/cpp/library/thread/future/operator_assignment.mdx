{/* source:cpp-thread-future-operator:0001 */}
Assigns the contents of another `future` object.

{/* source:cpp-thread-future-operator:0002 */}
1. Releases any shared state and move-assigns the contents of `other` to `*this`. After the assignment, `other.valid() == false` and [`this->valid()`](/docs/cpp/library/thread/future/valid) will yield the same value as `other.valid()` before the assignment.

{/* source:cpp-thread-future-operator:0003 */}
2. `std::future` is not [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable).

### Parameters

{/* source:cpp-thread-future-operator:0004 */}
<ParameterList>
  <Parameter name="other">a `std::future` that will transfer state to `*this`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-future-operator:0005 */}
`*this`
