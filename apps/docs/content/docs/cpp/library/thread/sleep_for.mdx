{/* source:cpp-thread-sleep-for:0001 */}
Blocks the execution of the current thread for at least the specified `sleep_duration`.

{/* source:cpp-thread-sleep-for:0002 */}
This function may block for longer than `sleep_duration` due to scheduling or resource contention delays.

{/* source:cpp-thread-sleep-for:0003 */}
The standard recommends that a steady clock is used to measure the duration. If an implementation uses a system clock instead, the wait time may also be sensitive to clock adjustments.

### Parameters

{/* source:cpp-thread-sleep-for:0004 */}
<ParameterList>
  <Parameter name="sleep_duration">time duration to sleep</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-sleep-for:0005 */}
(none)

### Exceptions

{/* source:cpp-thread-sleep-for:0006 */}
Any exception thrown by `clock`, `time_point`, or `duration` during the execution (clocks, time points, and durations provided by the standard library never throw).

### Example

{/* source:cpp-thread-sleep-for:0007 */}
```cpp
#include <chrono>
#include <iostream>
#include <thread>
 
int main()
{
    using namespace std::chrono_literals;
 
    std::cout << "Hello waiter\n" << std::flush;
 
    const auto start = std::chrono::high_resolution_clock::now();
    std::this_thread::sleep_for(2000ms);
    const auto end = std::chrono::high_resolution_clock::now();
    const std::chrono::duration<double, std::milli> elapsed = end - start;
 
    std::cout << "Waited " << elapsed << '\n';
}
```

Possible output:

```text
Hello waiter
Waited 2000.13 ms
```
