{/* source:cpp-thread-stop-callback-stop-callback:0001 */}
Constructs a new `stop_callback` object, saving and registering the `cb` callback function into the given [`std::stop_token`](/docs/cpp/library/thread/stop_token)'s associated stop-state, for later invocation if stop is requested on the associated [`std::stop_source`](/docs/cpp/library/thread/stop_source).

{/* source:cpp-thread-stop-callback-stop-callback:0002 */}
1. Constructs a `stop_callback` for the given `st` [`std::stop_token`](/docs/cpp/library/thread/stop_token) (copied), with the given invocable callback function `cb`.

{/* source:cpp-thread-stop-callback-stop-callback:0003 */}
2. Constructs a `stop_callback` for the given `st` [`std::stop_token`](/docs/cpp/library/thread/stop_token) (moved), with the given invocable callback function `cb`.

{/* source:cpp-thread-stop-callback-stop-callback:0004 */}
3,4. `stop_callback` is neither [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible) nor [MoveConstructible](/docs/cpp/library/named_req/MoveConstructible).

{/* source:cpp-thread-stop-callback-stop-callback:0005 */}
Both constructors participate overload resolution only if `Callback` and `C` satisfy [`constructible_from`](/docs/cpp/library/concepts/constructible_from) of `std::constructible_from<Callback, C>`. If `Callback` and `C` satisfy the concept but fail to satisfy its semantic requirement, the behavior is undefined.

### Parameters

{/* source:cpp-thread-stop-callback-stop-callback:0006 */}
<ParameterList>
  <Parameter name="st">a [`std::stop_token`](/docs/cpp/library/thread/stop_token) object to register this `stop_callback` object with</Parameter>
  <Parameter name="cb">the type to invoke if stop is requested</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-thread-stop-callback-stop-callback:0007 */}
1,2. [`noexcept`](/docs/cpp/language/exceptions/noexcept_spec) specification: `noexcept(std::is_nothrow_constructible_v<Callback, C>)`. Any exception thrown by constructor-initializing the given callback into the `stop_callback` object.

### Notes

{/* source:cpp-thread-stop-callback-stop-callback:0008 */}
If `st.stop_requested() == true` for the passed-in [`std::stop_token`](/docs/cpp/library/thread/stop_token), then the callback function is invoked in the current thread before the constructor returns.
