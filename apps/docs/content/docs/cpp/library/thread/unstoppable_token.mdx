{/* source:cpp-thread-unstoppable-token:0001 */}
The concept `unstoppable_token<Token>` specifies an additional requirement for a [stoppable_token](/docs/cpp/library/thread/stoppable_token) where the type does not allow stopping. That is, the expression `tok.stop_possible()` must be usable in constant expression and returns `false`.
