The concept `stoppable_token<Token>` specifies the basic interface of a stop token that is [copyable](/docs/cpp/library/concepts/copyable) and [equality_comparable](/docs/cpp/library/concepts/equality_comparable) and allows polling to see if the stop request is possible and whether the request has been made.
