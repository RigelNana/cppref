{/* source:cpp-thread-promise-promise:0001 */}
Constructs a promise object.

{/* source:cpp-thread-promise-promise:0002 */}
1. Default constructor. Constructs the promise with an empty shared state.

{/* source:cpp-thread-promise-promise:0003 */}
2. Constructs the promise with an empty shared state. The shared state is allocated using `alloc`. `Alloc` must meet the requirements of [`Allocator`](/docs/cpp/library/named_req/Allocator).

{/* source:cpp-thread-promise-promise:0004 */}
3. Move constructor. Constructs the promise with the shared state of `other` using move semantics. After construction, `other` has no shared state.

{/* source:cpp-thread-promise-promise:0005 */}
4. `promise` is not copyable.

### Parameters

{/* source:cpp-thread-promise-promise:0006 */}
<ParameterList>
  <Parameter name="alloc">allocator to use to allocate the shared state</Parameter>
  <Parameter name="other">another promise to acquire the state from</Parameter>
</ParameterList>

### Exceptions

{/* source:cpp-thread-promise-promise:0007 */}
1,2. May throw implementation-defined exceptions.
