Specializes the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::promise`](/docs/cpp/library/thread/promise). Exchanges the shared state of `lhs` with that of `rhs`. Effectively calls `lhs.swap(rhs)`.
