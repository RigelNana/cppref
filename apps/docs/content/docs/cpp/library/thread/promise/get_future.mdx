{/* source:cpp-thread-promise-get-future:0001 */}
Returns a future object associated with the same shared state as `*this`.

{/* source:cpp-thread-promise-get-future:0002 */}
An exception is thrown if `*this` has no shared state or `get_future` has already been called. To get multiple "pop" ends of the promise-future communication channel, use [`std::future::share`](/docs/cpp/library/thread/future/share).

{/* source:cpp-thread-promise-get-future:0003 */}
Calls to this function do not introduce data races with calls to [`set_value`](/docs/cpp/library/thread/promise/set_value), [`set_exception`](/docs/cpp/library/thread/promise/set_exception), [`set_value_at_thread_exit`](/docs/cpp/library/thread/promise/set_value_at_thread_exit), or [`set_exception_at_thread_exit`](/docs/cpp/library/thread/promise/set_exception_at_thread_exit) (therefore they need not synchronize with each other).

### Parameters

{/* source:cpp-thread-promise-get-future:0004 */}
(none)

### Return value

{/* source:cpp-thread-promise-get-future:0005 */}
A future referring to the shared state of `*this`.

### Exceptions

{/* source:cpp-thread-promise-get-future:0006 */}
[`std::future_error`](/docs/cpp/library/thread/future_error) on the following conditions:

{/* source:cpp-thread-promise-get-future:0007 */}
- `*this` has no shared state. The error code is set to [`no_state`](/docs/cpp/library/thread/future_errc).

{/* source:cpp-thread-promise-get-future:0008 */}
- `get_future()` has already been called on a promise with the same shared state as `*this`. The error code is set to [`future_already_retrieved`](/docs/cpp/library/thread/future_errc).
