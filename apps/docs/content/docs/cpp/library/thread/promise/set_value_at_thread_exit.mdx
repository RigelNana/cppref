{/* source:cpp-thread-promise-set-value-at-thread-exit:0001 */}
Stores the `value` into the shared state without making the state ready immediately. The state is made ready when the current thread exits, after all variables with thread-local storage duration have been destroyed.

{/* source:cpp-thread-promise-set-value-at-thread-exit:0002 */}
The operation behaves as though [`set_value`](/docs/cpp/library/thread/promise/set_value), [`set_exception`](/docs/cpp/library/thread/promise/set_exception), `set_value_at_thread_exit`, and [`set_exception_at_thread_exit`](/docs/cpp/library/thread/promise/set_exception_at_thread_exit) acquire a single mutex associated with the promise object while updating the promise object.

{/* source:cpp-thread-promise-set-value-at-thread-exit:0003 */}
Calls to this function do not introduce data races with calls to [`get_future`](/docs/cpp/library/thread/promise/get_future) (therefore they need not synchronize with each other).

### Parameters

{/* source:cpp-thread-promise-set-value-at-thread-exit:0004 */}
<ParameterList>
  <Parameter name="value">value to store in the shared state</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-promise-set-value-at-thread-exit:0005 */}
(none)

### Exceptions

{/* source:cpp-thread-promise-set-value-at-thread-exit:0006 */}
[`std::future_error`](/docs/cpp/library/thread/future_error) on the following conditions:

{/* source:cpp-thread-promise-set-value-at-thread-exit:0007 */}
- `*this` has no shared state. The error code is set to [`no_state`](/docs/cpp/library/thread/future_errc).
- The shared state already stores a value or exception. The error code is set to [`promise_already_satisfied`](/docs/cpp/library/thread/future_errc).

{/* source:cpp-thread-promise-set-value-at-thread-exit:0008 */}
Additionally:

{/* source:cpp-thread-promise-set-value-at-thread-exit:0009 */}
1. Any exception thrown by the constructor selected to copy an object of type `R`.

{/* source:cpp-thread-promise-set-value-at-thread-exit:0010 */}
2. Any exception thrown by the constructor selected to move an object of type `R`.

### Example

{/* source:cpp-thread-promise-set-value-at-thread-exit:0011 */}
```cpp
#include <future>
#include <iostream>
#include <thread>

int main()
{
    using namespace std::chrono_literals;
    std::promise<int> p;
    std::future<int> f = p.get_future();
    std::thread([&p]
    {
        std::this_thread::sleep_for(1s);
        p.set_value_at_thread_exit(9);
    }).detach();

    std::cout << "Waiting... " << std::flush;
    f.wait();
    std::cout << "Done!\nResult is: " << f.get() << '\n';
}
```

Output:

```text
Waiting... Done!
Result is: 9
```
