{/* source:cpp-thread-promise-promise:0001 */}
Abandons the shared state:

{/* source:cpp-thread-promise-promise:0002 */}
- if the shared state is ready, [releases](/docs/cpp/library/thread/promise) it.
- if the shared state is not ready, stores an exception object of type [`std::future_error`](/docs/cpp/library/thread/future_error) with an error condition [`std::future_errc::broken_promise`](/docs/cpp/library/thread/future_errc), makes the shared state ready and releases it.
