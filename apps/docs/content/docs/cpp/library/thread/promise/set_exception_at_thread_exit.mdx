{/* source:cpp-thread-promise-set-exception-at-thread-exit:0001 */}
Stores the exception pointer `p` into the shared state without making the state ready immediately. The state is made ready when the current thread exits, after all variables with thread-local storage duration have been destroyed.

{/* source:cpp-thread-promise-set-exception-at-thread-exit:0002 */}
The operation behaves as though [`set_value`](/docs/cpp/library/thread/promise/set_value), [`set_exception`](/docs/cpp/library/thread/promise/set_exception), [`set_value_at_thread_exit`](/docs/cpp/library/thread/promise/set_value_at_thread_exit), and `set_exception_at_thread_exit` acquire a single mutex associated with the promise object while updating the promise object.

{/* source:cpp-thread-promise-set-exception-at-thread-exit:0003 */}
An exception is thrown if there is no shared state or the shared state already stores a value or exception.

{/* source:cpp-thread-promise-set-exception-at-thread-exit:0004 */}
Calls to this function do not introduce data races with calls to [`get_future`](/docs/cpp/library/thread/promise/get_future) (therefore they need not synchronize with each other).

### Parameters

{/* source:cpp-thread-promise-set-exception-at-thread-exit:0005 */}
<ParameterList>
  <Parameter name="p">exception pointer to store. The behavior is undefined if `p` is `nullptr`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-promise-set-exception-at-thread-exit:0006 */}
(none)

### Exceptions

{/* source:cpp-thread-promise-set-exception-at-thread-exit:0007 */}
[`std::future_error`](/docs/cpp/library/thread/future_error) on the following conditions:

{/* source:cpp-thread-promise-set-exception-at-thread-exit:0008 */}
- `*this` has no shared state. The error code is set to [`no_state`](/docs/cpp/library/thread/future_errc).

{/* source:cpp-thread-promise-set-exception-at-thread-exit:0009 */}
- The shared state already stores a value or exception. The error code is set to [`promise_already_satisfied`](/docs/cpp/library/thread/future_errc).
