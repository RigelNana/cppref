{/* source:cpp-thread-future-error-operator:0001 */}
Assigns the contents with those of `other`. If `*this` and `other` both have dynamic type `std::future_error` then `std::strcmp(what(), other.what()) == 0` after assignment.

### Parameters

{/* source:cpp-thread-future-error-operator:0002 */}

  <Parameter name="other">another future_error object to assign with</Parameter>
</ParameterList>

### Return value
