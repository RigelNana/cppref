    {/* source:cpp-thread-future-error-future-error:0001 */}
    1. Copy constructor. Initializes the contents of the new `future_error` object with those of `other`. If `*this` and `other` both have dynamic type `std::future_error` then `std::strcmp(what(), other.what()) == 0`.

    {/* source:cpp-thread-future-error-future-error:0002 */}
    2. Constructs a new `future_error` object containing the error code `std::make_error_code(ec)`.
  </DeclarationDescription>
</DeclarationDoc>

### Notes

{/* source:cpp-thread-future-error-future-error:0004 */}
There is no standard-compliant way for the user to construct a `future_error` other than copying from another `future_error` prior to C++17. C++11 and C++14 depict an exposition-only public constructor taking a [`std::error_code`](/docs/cpp/library/error/error_code), and some implementations provide such a constructor.
