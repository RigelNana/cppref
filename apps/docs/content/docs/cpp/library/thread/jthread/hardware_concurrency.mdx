{/* source:cpp-thread-jthread-hardware-concurrency:0001 */}
Returns the number of concurrent threads supported by the implementation. The value should be considered only a hint.

### Parameters

{/* source:cpp-thread-jthread-hardware-concurrency:0002 */}
(none)

### Return value

{/* source:cpp-thread-jthread-hardware-concurrency:0003 */}
Number of concurrent threads supported. If the value is not well defined or not computable, returns `0`.

### Example

{/* source:cpp-thread-jthread-hardware-concurrency:0004 */}
```cpp
#include <iostream>
#include <thread>

int main()
{
    unsigned int n = std::jthread::hardware_concurrency();
    std::cout << n << " concurrent threads are supported.\n";
}
```

Possible output:

```text
4 concurrent threads are supported.
```
