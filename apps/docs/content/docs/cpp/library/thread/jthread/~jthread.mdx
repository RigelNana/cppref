{/* source:cpp-thread-jthread-jthread:0001 */}
Destroys the `jthread` object.

{/* source:cpp-thread-jthread-jthread:0002 */}
If `*this` has an associated thread (`joinable() == true`), calls `request_stop()` and then `join()`.

### Notes

{/* source:cpp-thread-jthread-jthread:0003 */}
The `request_stop()` has no effect if the `jthread` was previously requested to stop.

{/* source:cpp-thread-jthread-jthread:0004 */}
A `jthread` object does not have an associated thread after

{/* source:cpp-thread-jthread-jthread:0005 */}
- it was default-constructed.
- it was moved from.
- `join()` has been called.
- `detach()` has been called.

{/* source:cpp-thread-jthread-jthread:0006 */}
If `join()` throws an exception (e.g. because deadlock is detected), [`std::terminate()`](/docs/cpp/library/error/terminate) may be called.
