{/* source:cpp-thread-jthread:0001 */}
The class `jthread` represents [a single thread of execution](https://en.wikipedia.org/wiki/Thread_(computing)). It has the same general behavior as [`std::thread`](/docs/cpp/library/thread/thread), except that `jthread` automatically rejoins on destruction, and can be cancelled/stopped in certain situations.

{/* source:cpp-thread-jthread:0002 */}
Threads begin execution immediately upon construction of the associated thread object (pending any OS scheduling delays), starting at the top-level function provided as a [constructor argument](/docs/cpp/library/thread/jthread/jthread). The return value of the top-level function is ignored and if it terminates by throwing an exception, [`std::terminate`](/docs/cpp/library/error/terminate) is called. The top-level function may communicate its return value or an exception to the caller via [`std::promise`](/docs/cpp/library/thread/promise) or by modifying shared variables (which may require synchronization, see [`std::mutex`](/docs/cpp/library/thread/mutex) and [`std::atomic`](/docs/cpp/library/atomic/atomic)).

{/* source:cpp-thread-jthread:0003 */}
Unlike [`std::thread`](/docs/cpp/library/thread/thread), the `jthread` logically holds an internal private member of type `std::stop_source`, which maintains a shared stop-state. The `jthread` constructor accepts a function that takes a [`std::stop_token`](/docs/cpp/library/thread/stop_token) as its first argument, which will be passed in by the `jthread` from its internal [`std::stop_source`](/docs/cpp/library/thread/stop_source). This allows the function to check if stop has been requested during its execution, and return if it has.

{/* source:cpp-thread-jthread:0004 */}
`std::jthread` objects may also be in the state that does not represent any thread (after default construction, move from, `detach`, or `join`), and a thread of execution may be not associated with any `jthread` objects (after `detach`).

{/* source:cpp-thread-jthread:0005 */}
No two `std::jthread` objects may represent the same thread of execution; `std::jthread` is not [CopyConstructible](/docs/cpp/library/named_req/CopyConstructible) or [CopyAssignable](/docs/cpp/library/named_req/CopyAssignable), although it is [MoveConstructible](/docs/cpp/library/named_req/MoveConstructible) and [MoveAssignable](/docs/cpp/library/named_req/MoveAssignable).
