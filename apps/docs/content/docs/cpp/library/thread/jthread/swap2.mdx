Overloads the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::jthread`](/docs/cpp/library/thread/jthread). Exchanges the state of `lhs` with that of `rhs`. Effectively calls `lhs.swap(rhs)`. This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::jthread` is an associated class of the arguments.

### Parameters

{/* source:cpp-thread-jthread-swap2:0002 */}
<ParameterList>
  <Parameter name="lhs, rhs">jthreads whose states to swap</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-jthread-swap2:0003 */}
(none)

### Example

{/* source:cpp-thread-jthread-swap2:0004 */}
```cpp
#include <chrono>
#include <iostream>
#include <thread>

void foo()
{
    std::this_thread::sleep_for(std::chrono::seconds(1));
}

void bar()
{
    std::this_thread::sleep_for(std::chrono::seconds(1));
}

int main()
{
    using std::swap;

    std::jthread t1(foo);
    std::jthread t2(bar);

    std::cout << "thread 1 id: " << t1.get_id() << '\n'
              << "thread 2 id: " << t2.get_id() << '\n';

    swap(t1, t2);

    std::cout << "after std::swap(t1, t2):" << '\n'
              << "thread 1 id: " << t1.get_id() << '\n'
              << "thread 2 id: " << t2.get_id() << '\n';

    t1.swap(t2);

    std::cout << "after t1.swap(t2):" << '\n'
              << "thread 1 id: " << t1.get_id() << '\n'
              << "thread 2 id: " << t2.get_id() << '\n';

}
```

Possible output:

```text
thread 1 id: 1892
thread 2 id: 2584
after std::swap(t1, t2):
thread 1 id: 2584
thread 2 id: 1892
after t1.swap(t2):
thread 1 id: 1892
thread 2 id: 2584
```
