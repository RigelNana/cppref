{/* source:cpp-thread-jthread-jthread:0001 */}
Constructs new `std::jthread` object.

{/* source:cpp-thread-jthread-jthread:0002 */}
1. Creates new `std::jthread` object which does not represent a thread.

{/* source:cpp-thread-jthread-jthread:0003 */}
2. Move constructor. Constructs the `std::jthread` object to represent the thread of execution that was represented by `other`. After this call `other` no longer represents a thread of execution.

{/* source:cpp-thread-jthread-jthread:0004 */}
3. Creates new `std::jthread` object and associates it with a thread of execution. The new thread of execution starts executing:

<Revision until="C++23">
[`std::invoke`](/docs/cpp/library/utility/functional/invoke)([`decay-copy`](/docs/cpp/library/standard_library/decay-copy)(`std::forward<F>(f)`), `get_stop_token()`,
            [`decay-copy`](/docs/cpp/library/standard_library/decay-copy)(`std::forward<Args>(args)`...))
</Revision>
<Revision since="C++23">
`std::invoke(auto(std::forward<F>(f)), get_stop_token(),`
`            auto(std::forward<Args>(args))...)`
</Revision>

if the expression above is well-formed, otherwise starts executing:

<Revision until="C++23">
[`std::invoke`](/docs/cpp/library/utility/functional/invoke)([`decay-copy`](/docs/cpp/library/standard_library/decay-copy)(`std::forward<F>(f)`),
            [`decay-copy`](/docs/cpp/library/standard_library/decay-copy)(`std::forward<Args>(args)`...))
</Revision>
<Revision since="C++23">
`std::invoke(auto(std::forward<F>(f)),`
`            auto(std::forward<Args>(args))...)`
</Revision>

{/* source:cpp-thread-jthread-jthread:0005 */}
<InlineRevision until="C++23">The calls of [`decay-copy`](/docs/cpp/library/standard_library/decay-copy) are evaluated</InlineRevision><InlineRevision since="C++23">The values produced by `auto` are [materialized](/docs/cpp/language/expressions/implicit_cast#Temporary_materialization)</InlineRevision> in the current thread, so that any exceptions thrown during evaluation and copying/moving of the arguments are thrown in the current thread, without starting the new thread.

{/* source:cpp-thread-jthread-jthread:0006 */}
These overloads participate in overload resolution only if `std::remove_cvref_t<F>` is not the same type as `std::jthread`.

{/* source:cpp-thread-jthread-jthread:0007 */}
If any of the following is `false`, the program is ill-formed:

- `std::is_constructible_v<std::decay_t<F>, F>`
- (`std::is_constructible_v<std::decay_t<Args>, Args> && ...`)
- `std::is_invocable_v<std::decay_t<F>, std::decay_t<Args>...> ||`
  `std::is_invocable_v<std::decay_t<F>, std::stop_token, std::decay_t<Args>...>`

{/* source:cpp-thread-jthread-jthread:0008 */}
The completion of the invocation of the constructor [synchronizes with](/docs/cpp/library/atomic/memory_order) the beginning of the invocation of the copy of `f` on the new thread of execution.

{/* source:cpp-thread-jthread-jthread:0009 */}
4. The copy constructor is deleted; threads are not copyable. No two `std::jthread` objects may represent the same thread of execution.

### Postconditions

{/* source:cpp-thread-jthread-jthread:0011 */}
1. [`get_id()`](/docs/cpp/library/thread/jthread/get_id) equal to [`std::jthread::id()`](/docs/cpp/library/thread/thread/id) (i.e. [`joinable()`](/docs/cpp/library/thread/jthread/joinable) returns `false`) and `get_stop_source().stop_possible()` is `false`.

{/* source:cpp-thread-jthread-jthread:0012 */}
2. `other.get_id()` equal to [`std::jthread::id()`](/docs/cpp/library/thread/thread/id) and [`get_id()`](/docs/cpp/library/thread/jthread/get_id) returns the value of `other.get_id()` prior to the start of construction.

{/* source:cpp-thread-jthread-jthread:0013 */}
3. [`get_id()`](/docs/cpp/library/thread/jthread/get_id) not equal to [`std::jthread::id()`](/docs/cpp/library/thread/thread/id) (i.e. [`joinable()`](/docs/cpp/library/thread/jthread/joinable) returns `true`), and `get_stop_source().stop_possible()` is `true`.

### Exceptions

{/* source:cpp-thread-jthread-jthread:0014 */}
3. [`std::system_error`](/docs/cpp/library/error/system_error) if the thread could not be started. The exception may represent the error condition `std::errc::resource_unavailable_try_again` or another implementation-specific error condition.

### Notes

{/* source:cpp-thread-jthread-jthread:0015 */}
The arguments to the thread function are moved or copied by value. If a reference argument needs to be passed to the thread function, it has to be wrapped (e.g. with [`std::ref`](/docs/cpp/library/utility/functional/ref) or [`std::cref`](/docs/cpp/library/utility/functional/ref)).

{/* source:cpp-thread-jthread-jthread:0016 */}
Any return value from the function is ignored. If the function throws an exception, [`std::terminate`](/docs/cpp/library/error/terminate) is called. In order to pass return values or exceptions back to the calling thread, [`std::promise`](/docs/cpp/library/thread/promise) or [`std::async`](/docs/cpp/library/thread/async) may be used.

### Example

{/* source:cpp-thread-jthread-jthread:0017 */}
```cpp
#include <chrono>
#include <iostream>
#include <thread>
#include <utility>
 
using namespace std::literals;
 
void f1(int n)
{
    for (int i = 0; i < 5; ++i)
    {
        std::cout << "Thread 1 executing\n";
        ++n;
        std::this_thread::sleep_for(10ms);
    }
}
 
void f2(int& n)
{
    for (int i = 0; i < 5; ++i)
    {
        std::cout << "Thread 2 executing\n";
        ++n;
        std::this_thread::sleep_for(10ms);
    }
}
 
class foo
{
public:
    void bar()
    {
        for (int i = 0; i < 5; ++i)
        {
            std::cout << "Thread 3 executing\n";
            ++n;
            std::this_thread::sleep_for(10ms);
        }
    }
    int n = 0;
};
 
class baz
{
public:
    void operator()()
    {
        for (int i = 0; i < 5; ++i)
        {
            std::cout << "Thread 4 executing\n";
            ++n;
            std::this_thread::sleep_for(10ms);
        }
    }
    int n = 0;
};
 
int main()
{
    int n = 0;
    foo f;
    baz b;
    std::jthread t0; // t0 is not a thread
    std::jthread t1(f1, n + 1); // pass by value
    std::jthread t2a(f2, std::ref(n)); // pass by reference
    std::jthread t2b(std::move(t2a)); // t2b is now running f2(). t2a is no longer a thread
    std::jthread t3(&foo::bar, &f); // t3 runs foo::bar() on object f
    std::jthread t4(b); // t4 runs baz::operator() on a copy of object b
    t1.join();
    t2b.join();
    t3.join();
    std::cout << "Final value of n is " << n << '\n';
    std::cout << "Final value of f.n (foo::n) is " << f.n << '\n';
    std::cout << "Final value of b.n (baz::n) is " << b.n << '\n';
    // t4 joins on destruction
}
```
