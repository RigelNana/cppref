{/* source:cpp-thread-future-status:0001 */}
Specifies state of a future as returned by `wait_for` and `wait_until` functions of [`std::future`](/docs/cpp/library/thread/future) and [`std::shared_future`](/docs/cpp/library/thread/shared_future).

### Constants

{/* source:cpp-thread-future-status:0002 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`deferred`</DescriptionTerm>
    <DescriptionBody>the shared state contains a deferred function, so the result will be computed only when explicitly requested</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`ready`</DescriptionTerm>
    <DescriptionBody>the shared state is ready</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`timeout`</DescriptionTerm>
    <DescriptionBody>the shared state did not become ready before specified timeout duration has passed</DescriptionBody>
  </DescriptionItem>
</DescriptionList>
