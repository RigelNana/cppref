<DeclarationDoc>
  <Declaration language="cpp" since="C++11" code={`template< class Rep, class Period >
std::future_status wait_for( const std::chrono::duration<Rep,Period>& timeout_duration ) const;`} />
</DeclarationDoc>

{/* source:cpp-thread-shared-future-wait-for:0001 */}
Waits for the result to become available. Blocks until specified `timeout_duration` has elapsed or the result becomes available, whichever comes first. The return value identifies the state of the result.

{/* source:cpp-thread-shared-future-wait-for:0002 */}
If the future is the result of a call to [`std::async`](/docs/cpp/library/thread/async) that used lazy evaluation, this function returns immediately without waiting.

{/* source:cpp-thread-shared-future-wait-for:0003 */}
This function may block for longer than `timeout_duration` due to scheduling or resource contention delays.

{/* source:cpp-thread-shared-future-wait-for:0004 */}
The standard recommends that a steady clock is used to measure the duration. If an implementation uses a system clock instead, the wait time may also be sensitive to clock adjustments.

{/* source:cpp-thread-shared-future-wait-for:0005 */}
The behavior is undefined if [`valid()`](/docs/cpp/library/thread/future/valid) is `false` before the call to this function.

### Parameters

{/* source:cpp-thread-shared-future-wait-for:0006 */}
<ParameterList>
  <Parameter name="timeout_duration">maximum duration to block for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-shared-future-wait-for:0007 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>[`future_status::deferred`](/docs/cpp/library/thread/future_status)</DescriptionTerm>
    <DescriptionBody>The shared state contains a deferred function using lazy evaluation, so the result will be computed only when explicitly requested</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`future_status::ready`](/docs/cpp/library/thread/future_status)</DescriptionTerm>
    <DescriptionBody>The result is ready</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>[`future_status::timeout`](/docs/cpp/library/thread/future_status)</DescriptionTerm>
    <DescriptionBody>The timeout has expired</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

### Exceptions

{/* source:cpp-thread-shared-future-wait-for:0008 */}
Any exception thrown by `clock`, `time_point`, or `duration` during the execution (clocks, time points, and durations provided by the standard library never throw).

### Notes

{/* source:cpp-thread-shared-future-wait-for:0009 */}
The implementations are encouraged to detect the case when `valid == false` before the call and throw a [`std::future_error`](/docs/cpp/library/thread/future_error) with an error condition of [`std::future_errc::no_state`](/docs/cpp/library/thread/future_errc).

### Example

{/* source:cpp-thread-shared-future-wait-for:0010 */}
```cpp
#include <chrono>
#include <future>
#include <iostream>
#include <thread>
using namespace std::chrono_literals;
 
int main()
{
    std::shared_future<int> future = std::async(std::launch::async, []()
    {
        std::this_thread::sleep_for(3s);
        return 8;
    });
 
    std::cout << "waiting...\n";
    std::future_status status;
 
    do
    {
        switch (status = future.wait_for(1s); status)
        {
            case std::future_status::deferred:
                std::cout << "deferred\n";
                break;
            case std::future_status::timeout:
                std::cout << "timeout\n";
                break;
            case std::future_status::ready:
                std::cout << "ready!\n";
                break;
        }
    }
    while (status != std::future_status::ready);
 
    std::cout << "result is " << future.get() << '\n';
}
```

Possible output:

```text
waiting...
timeout
timeout
timeout
ready!
result is 8
```
