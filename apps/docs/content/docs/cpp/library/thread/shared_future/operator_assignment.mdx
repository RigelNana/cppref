{/* source:cpp-thread-shared-future-operator:0001 */}
Assigns the contents of another `shared_future`.

{/* source:cpp-thread-shared-future-operator:0002 */}
1. Releases any shared state and assigns the contents of `other` to `*this`. After the assignment, `this->valid() == other.valid()`.

{/* source:cpp-thread-shared-future-operator:0003 */}
2. Releases any shared state and move-assigns the contents of `other` to `*this`. After the assignment, `other.valid() == false` and [`this->valid()`](/docs/cpp/library/thread/shared_future/valid) will yield the same value as `other.valid()` before the assignment.

### Parameters

{/* source:cpp-thread-shared-future-operator:0004 */}
<ParameterList>
  <Parameter name="other">a `std::shared_future` that will transfer state to `*this`</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-shared-future-operator:0005 */}
`*this`
