{/* source:cpp-thread-shared-future-get:0001 */}
The `get` member function waits (by calling [`wait()`](/docs/cpp/library/thread/shared_future/wait)) until the shared state is ready, then retrieves the value stored in the shared state (if any).

{/* source:cpp-thread-shared-future-get:0002 */}
If [`valid()`](/docs/cpp/library/thread/shared_future/valid) is `false` before the call to this function, the behavior is undefined.

### Return value

{/* source:cpp-thread-shared-future-get:0003 */}
1. A const reference to the value stored in the shared state. The behavior of accessing the value through this reference after the shared state has been destroyed is undefined.

{/* source:cpp-thread-shared-future-get:0004 */}
2. The reference stored as value in the shared state.

{/* source:cpp-thread-shared-future-get:0005 */}
3. (none)

### Exceptions

{/* source:cpp-thread-shared-future-get:0006 */}
If an exception was stored in the shared state referenced by the future (e.g. via a call to [`std::promise::set_exception()`](/docs/cpp/library/thread/promise/set_exception)) then that exception will be thrown.

### Notes

{/* source:cpp-thread-shared-future-get:0007 */}
The C++ standard recommends the implementations to detect the case when [`valid()`](/docs/cpp/library/thread/shared_future/valid) is `false` before the call and throw a [`std::future_error`](/docs/cpp/library/thread/future_error) with an error condition of [`std::future_errc::no_state`](/docs/cpp/library/thread/future_errc).
