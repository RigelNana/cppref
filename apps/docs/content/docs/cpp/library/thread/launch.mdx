`std::launch` is a [`BitmaskType`](/docs/cpp/library/named_req/BitmaskType). It specifies the launch policy for a task executed by the [`std::async`](/docs/cpp/library/thread/async) function.

### Constants

{/* source:cpp-thread-launch:0002 */}
The following constants denoting individual bits are defined by the standard library:

{/* source:cpp-thread-launch:0003 */}
<DescriptionList>
  <DescriptionItem>
    <DescriptionTerm>`async`</DescriptionTerm>
    <DescriptionBody>the task is executed on a different thread, potentially by creating and launching it first</DescriptionBody>
  </DescriptionItem>
  <DescriptionItem>
    <DescriptionTerm>`deferred`</DescriptionTerm>
    <DescriptionBody>the task is executed on the calling thread the first time its result is requested (lazy evaluation)</DescriptionBody>
  </DescriptionItem>
</DescriptionList>

{/* source:cpp-thread-launch:0004 */}
In addition, implementations are allowed to:

{/* source:cpp-thread-launch:0005 */}
- define additional bits and bitmasks to specify restrictions on task interactions applicable to a subset of launch policies, and enable those additional bitmasks for the first (default) overload of `std::async`.
