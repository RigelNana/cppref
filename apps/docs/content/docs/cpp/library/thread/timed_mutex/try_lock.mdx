{/* source:cpp-thread-timed-mutex-try-lock:0001 */}
Tries to lock the mutex. Returns immediately. On successful lock acquisition returns `true`, otherwise returns `false`.

{/* source:cpp-thread-timed-mutex-try-lock:0002 */}
This function is allowed to fail spuriously and return `false` even if the mutex is not currently locked by any other thread.

{/* source:cpp-thread-timed-mutex-try-lock:0003 */}
If `try_lock` is called by a thread that already owns the `mutex`, the behavior is undefined.

{/* source:cpp-thread-timed-mutex-try-lock:0004 */}
Prior [`unlock()`](/docs/cpp/library/thread/timed_mutex/unlock) operation on the same mutex *synchronizes-with* (as defined in [`std::memory_order`](/docs/cpp/library/atomic/memory_order)) this operation if it returns `true`. Note that prior [`lock()`](/docs/cpp/library/thread/timed_mutex/lock) does not synchronize with this operation if it returns `false`.

### Parameters

{/* source:cpp-thread-timed-mutex-try-lock:0005 */}
(none)

### Return value

{/* source:cpp-thread-timed-mutex-try-lock:0006 */}
`true` if the lock was acquired successfully, otherwise `false`.

### Exceptions

{/* source:cpp-thread-timed-mutex-try-lock:0007 */}
Throws nothing.
