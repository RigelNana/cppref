The alias template `stop_callback_for_t` is used to obtain the stop callback type of the type `T`.

### Notes

{/* source:cpp-thread-stop-callback-for-t:0002 */}
The corresponding `stop_callback_for_t` for standard stop token types and any valid `CallbackFn` are:

{/* source:cpp-thread-stop-callback-for-t:0003 */}
- specialization of `std::stop_callback` for `std::stop_token`,
- specialization of `std::inplace_stop_callback` for `std::inplace_stop_token`,
- and unspecified type without stoppable callback registration and deregistration for `std::never_stop_token`.
