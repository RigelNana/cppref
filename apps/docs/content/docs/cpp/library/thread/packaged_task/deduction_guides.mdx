{/* source:cpp-thread-packaged-task-deduction-guides:0001 */}
1. This [deduction guide](/docs/cpp/language/templates/ctad) is provided for [`std::packaged_task`](/docs/cpp/library/thread/packaged_task) to allow deduction from functions.

{/* source:cpp-thread-packaged-task-deduction-guides:0002 */}
2. This overload participates in overload resolution only if `&F::operator()` is well-formed when treated as an unevaluated operand and `decltype(&F::operator())` is of the form `R(G::*)(A...)` (optionally cv-qualified, optionally noexcept, optionally lvalue reference qualified). The deduced type is `std::packaged_task<R(A...)>`.

{/* source:cpp-thread-packaged-task-deduction-guides:0003 */}
3. This overload participates in overload resolution only if `&F::operator()` is well-formed when treated as an unevaluated operand and `F::operator()` is an [explicit object parameter function](/docs/cpp/language/classes/member_functions#Explicit_object_parameter) whose type is of form `R(G, A...)` or `R(G, A...) noexcept`. The deduced type is `std::packaged_task<R(A...)>`.

{/* source:cpp-thread-packaged-task-deduction-guides:0004 */}
4. This overload participates in overload resolution only if `&F::operator()` is well-formed when treated as an unevaluated operand and `F::operator()` is a [static member function](/docs/cpp/language/classes/static#Static_member_functions) whose type is of form `R(A...)` or `R(A...) noexcept`. The deduced type is `std::packaged_task<R(A...)>`.

### Notes

{/* source:cpp-thread-packaged-task-deduction-guides:0005 */}
These deduction guides do not allow deduction from a function with [ellipsis parameter](/docs/cpp/language/functions/variadic_arguments), and the `...` in the types is always treated as a [pack expansion](/docs/cpp/language/templates/parameter_pack#Pack_expansion).

### Example

{/* source:cpp-thread-packaged-task-deduction-guides:0006 */}
```cpp
#include <future>

int func(double) { return 0; }

int main()
{
    std::packaged_task f{func}; // deduces packaged_task<int(double)>

    int i = 5;
    std::packaged_task g = [&](double) { return i; }; // => packaged_task<int(double)>
}
```
