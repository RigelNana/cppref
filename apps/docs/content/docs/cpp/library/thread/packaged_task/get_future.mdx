{/* source:cpp-thread-packaged-task-get-future:0001 */}
Returns a future which shares the same shared state as `*this`.

{/* source:cpp-thread-packaged-task-get-future:0002 */}
`get_future` can be called only once for each `packaged_task`.

### Parameters

{/* source:cpp-thread-packaged-task-get-future:0003 */}
(none)

### Return value

{/* source:cpp-thread-packaged-task-get-future:0004 */}
A future which shares the same shared state as `*this`.

### Exceptions

{/* source:cpp-thread-packaged-task-get-future:0005 */}
[`std::future_error`](/docs/cpp/library/thread/future_error) on the following error conditions:

{/* source:cpp-thread-packaged-task-get-future:0006 */}
- The shared state has already been retrieved via a call to `get_future`. The error category is set to [`future_already_retrieved`](/docs/cpp/library/thread/future_errc).
- `*this` has no shared state. The error category is set to [`no_state`](/docs/cpp/library/thread/future_errc).
