{/* source:cpp-thread-packaged-task-operator:0001 */}
Calls the stored task as if by [`INVOKE<R>`](/docs/cpp/library/utility/functional)`(f, args...)`, where `f` is the stored task. The return value of the task or any exceptions thrown are stored in the shared state. The shared state is made ready and any threads waiting for this are unblocked.

### Parameters

{/* source:cpp-thread-packaged-task-operator:0002 */}
<ParameterList>
  <Parameter name="args">the parameters to pass on invocation of the stored task</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-packaged-task-operator:0003 */}
(none)

### Exceptions

{/* source:cpp-thread-packaged-task-operator:0004 */}
[`std::future_error`](/docs/cpp/library/thread/future_error) on the following error conditions:

{/* source:cpp-thread-packaged-task-operator:0005 */}
- The stored task has already been invoked. The error category is set to [`promise_already_satisfied`](/docs/cpp/library/thread/future_errc).
- `*this` has no shared state. The error category is set to [`no_state`](/docs/cpp/library/thread/future_errc).
