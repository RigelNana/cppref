{/* source:cpp-thread-packaged-task-packaged-task:0001 */}
Constructs a new `std::packaged_task` object.

{/* source:cpp-thread-packaged-task-packaged-task:0002 */}
1. Constructs a `std::packaged_task` object with no task and no shared state.

{/* source:cpp-thread-packaged-task-packaged-task:0003 */}
2,3. Constructs a `std::packaged_task` object with a shared state and a copy of the task, initialized with `std::forward<F>(f)`. <InlineRevision until="C++17">The allocator `a` is used to allocate memory necessary to store the task.</InlineRevision>

{/* source:cpp-thread-packaged-task-packaged-task:0004 */}
<Revision until="C++17">These overloads participate in overload resolution only if `std::decay<F>::type` is not the same type as `std::packaged_task<R(Args...)>`. Let `t1`, `t2`, ..., `tN` be values of the corresponding types in `Args`, if [`INVOKE<R>`](/docs/cpp/library/utility/functional)`(f, t1, t2, ..., tN)` is not a valid expression, the program is ill-formed.</Revision>

<Revision since="C++17">If `std::is_invocable_r_v<R, F&, Args...>` is `false`, the program is ill-formed.</Revision>

{/* source:cpp-thread-packaged-task-packaged-task:0005 */}
If invoking `f` itself and invoking a copy of `f` behave differently, the behavior is undefined.

{/* source:cpp-thread-packaged-task-packaged-task:0006 */}
4. The copy constructor is deleted, `std::packaged_task` is move-only.

{/* source:cpp-thread-packaged-task-packaged-task:0007 */}
5. Constructs a `std::packaged_task` with the shared state and task formerly owned by `rhs`, leaving `rhs` with no shared state and a moved-from task.

### Example

{/* source:cpp-thread-packaged-task-packaged-task:0011 */}
```cpp
#include <future>
#include <iostream>
#include <thread>

int fib(int n)
{
    if (n < 3)
        return 1;
    else
        return fib(n - 1) + fib(n - 2);
}

int main()
{
    std::packaged_task<int(int)> fib_task(&fib); 

    std::cout << "Starting task\n";
    auto result = fib_task.get_future();
    std::thread t(std::move(fib_task), 42);

    std::cout << "Waiting for task to finish..." << std::endl;
    std::cout << result.get() << '\n';

    std::cout << "Task complete\n";
    t.join();
}
```

Output:

```text
Starting task
Waiting for task to finish...
267914296
Task complete
```
