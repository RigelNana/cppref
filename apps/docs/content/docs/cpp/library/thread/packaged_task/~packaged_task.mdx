Abandons the shared state and destroys the stored task object.

{/* source:cpp-thread-packaged-task-packaged-task:0002 */}
As with [`std::promise::~promise`](/docs/cpp/library/thread/promise/~promise), if the shared state is abandoned before it was made ready, an [`std::future_error`](/docs/cpp/library/thread/future_error) exception is stored with the error code [`std::future_errc::broken_promise`](/docs/cpp/library/thread/future_errc)).
