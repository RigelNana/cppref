{/* source:cpp-thread-stop-source-operator-cmp:0001 */}
Compares two `stop_source` values.
{/* source:cpp-thread-stop-source-operator-cmp:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::stop_source` is an associated class of the arguments.
{/* source:cpp-thread-stop-source-operator-cmp:0003 */}
The `!=` operator is [synthesized](/docs/cpp/language/expressions/default_comparisons#Other_defaulted_comparison_operators) from `operator==`.
### Parameters
{/* source:cpp-thread-stop-source-operator-cmp:0004 */}
<ParameterList>
  <Parameter name="lhs, rhs">`stop_sources` to compare</Parameter>
</ParameterList>
### Return value
{/* source:cpp-thread-stop-source-operator-cmp:0005 */}
`true` if `lhs` and `rhs` have the same stop-state, or both have no stop-state, otherwise `false`.
