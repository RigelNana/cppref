Overloads the [`std::swap`](/docs/cpp/library/algorithm/swap) algorithm for [`std::stop_source`](/docs/cpp/library/thread/stop_source). Exchanges the stop-state of `lhs` with that of `rhs`. Effectively calls `lhs.swap(rhs)`.
{/* source:cpp-thread-stop-source-swap2:0002 */}
This function is not visible to ordinary [unqualified](/docs/cpp/language/basic_concepts/unqualified_lookup) or [qualified lookup](/docs/cpp/language/basic_concepts/qualified_lookup), and can only be found by [argument-dependent lookup](/docs/cpp/language/functions/adl) when `std::stop_source` is an associated class of the arguments.
