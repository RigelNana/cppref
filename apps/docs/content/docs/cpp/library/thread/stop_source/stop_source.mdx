{/* source:cpp-thread-stop-source-stop-source:0001 */}
Constructs a new `stop_source` object.

{/* source:cpp-thread-stop-source-stop-source:0002 */}
1. Constructs a `stop_source` with new stop-state.

{/* source:cpp-thread-stop-source-stop-source:0003 */}
2. Constructs an empty `stop_source` with no associated stop-state.

{/* source:cpp-thread-stop-source-stop-source:0004 */}
3. Copy constructor. Constructs a `stop_source` whose associated stop-state is the same as that of `other`.

{/* source:cpp-thread-stop-source-stop-source:0005 */}
4. Move constructor. Constructs a `stop_source` whose associated stop-state is the same as that of `other`; `other` is left empty.

### Parameters

{/* source:cpp-thread-stop-source-stop-source:0006 */}
<ParameterList>
  <Parameter name="nss">an `std::nostopstate_t` placeholder object to construct an empty `stop_source`</Parameter>
  <Parameter name="other">another `stop_source` object to construct this `stop_source` object with</Parameter>
</ParameterList>

### Postconditions

{/* source:cpp-thread-stop-source-stop-source:0007 */}
1. `stop_possible()` is `true` and `stop_requested()` is `false`.

{/* source:cpp-thread-stop-source-stop-source:0008 */}
2. `stop_possible()` and `stop_requested()` are both `false`.

{/* source:cpp-thread-stop-source-stop-source:0009 */}
3. `*this` and `other` share the same associated stop-state and compare equal.

{/* source:cpp-thread-stop-source-stop-source:0010 */}
4. `*this` has `other`'s previously associated stop-state, and `other.stop_possible()` is `false`.

### Exceptions

{/* source:cpp-thread-stop-source-stop-source:0011 */}
1. [`std::bad_alloc`](/docs/cpp/library/memory/new/bad_alloc) if memory could not be allocated for the stop-state.
