{/* source:cpp-thread-future-errc-make-error-code:0001 */}
Constructs an [`std::error_code`](/docs/cpp/library/error/error_code) object from a value of type [`std::future_errc`](/docs/cpp/library/thread/future_errc) as if by:

{/* source:cpp-thread-future-errc-make-error-code:0002 */}
`std::error_code(static_cast<int>(e), std::future_category())`.

{/* source:cpp-thread-future-errc-make-error-code:0003 */}
This function is called by the constructor of [`std::error_code`](/docs/cpp/library/error/error_code) when given an [`std::future_errc`](/docs/cpp/library/thread/future_errc) argument.

### Parameters

{/* source:cpp-thread-future-errc-make-error-code:0004 */}
<ParameterList>
  <Parameter name="e">error code number</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-future-errc-make-error-code:0005 */}
A value of type [`std::error_code`](/docs/cpp/library/error/error_code) that holds the error code number from `e` associated with the error category `"future"`.
