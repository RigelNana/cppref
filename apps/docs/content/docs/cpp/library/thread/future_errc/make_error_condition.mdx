Constructs an [`std::error_condition`](/docs/cpp/library/error/error_condition) object from a value of type [`std::future_errc`](/docs/cpp/library/thread/future_errc) as if by:

{/* source:cpp-thread-future-errc-make-error-condition:0002 */}
`std::error_condition(static_cast<int>(e), std::future_category())`.

### Parameters

{/* source:cpp-thread-future-errc-make-error-condition:0003 */}
<ParameterList>
  <Parameter name="e">error code number</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-future-errc-make-error-condition:0004 */}
A value of type [`std::error_condition`](/docs/cpp/library/error/error_condition) that holds the error code number from `e` associated with the error category `"future"`.
