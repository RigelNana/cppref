  <DeclarationDescription>
    {/* source:cpp-thread-shared-lock-shared-lock:0001 */}
    Constructs a `shared_lock`, optionally locking the supplied mutex.

    {/* source:cpp-thread-shared-lock-shared-lock:0002 */}
    1. Constructs a `shared_lock` with no associated mutex.

    {/* source:cpp-thread-shared-lock-shared-lock:0003 */}
    2. Move constructor. Initializes the `shared_lock` with the contents of `other`. Leaves `other` with no associated mutex.

    {/* source:cpp-thread-shared-lock-shared-lock:0004 */}
    3-8. Constructs a `shared_lock` with `m` as the associated mutex. Additionally:

    {/* source:cpp-thread-shared-lock-shared-lock:0005 */}
    - 3) Locks the associated mutex in shared mode by calling `m.lock_shared()`.

    {/* source:cpp-thread-shared-lock-shared-lock:0006 */}
    - 4) Does not lock the associated mutex.

    {/* source:cpp-thread-shared-lock-shared-lock:0007 */}
    - 5) Tries to lock the associated mutex in shared mode without blocking by calling `m.try_lock_shared()`.

    {/* source:cpp-thread-shared-lock-shared-lock:0008 */}
    - 6) Assumes the calling thread already holds a shared lock (i.e., a lock acquired by `lock_shared`, `try_lock_shared`, `try_lock_shared_for`, or `try_lock_shared_until`) on `m`. The behavior is undefined if not so.

    {/* source:cpp-thread-shared-lock-shared-lock:0009 */}
    7. Tries to lock the associated mutex in shared mode by calling `m.try_lock_shared_for(timeout_duration)`, which blocks until specified `timeout_duration` has elapsed or the lock is acquired, whichever comes first. May block for longer than `timeout_duration`. The behavior is undefined if `Mutex` does not meet the [`SharedTimedLockable`](/docs/cpp/library/named_req/SharedTimedLockable) requirements.

    {/* source:cpp-thread-shared-lock-shared-lock:0010 */}
    8. Tries to lock the associated mutex in shared mode by calling `m.try_lock_shared_until(timeout_time)`, which blocks until specified `timeout_time` has been reached or the lock is acquired, whichever comes first. May block for longer than until `timeout_time` has been reached. The behavior is undefined if `Mutex` does not meet the [`SharedTimedLockable`](/docs/cpp/library/named_req/SharedTimedLockable) requirements.
  </DeclarationDescription>
</DeclarationDoc>

### Example

{/* source:cpp-thread-shared-lock-shared-lock:0012 */}
```cpp
#include <chrono>
#include <iostream>
#include <shared_mutex>
#include <syncstream>
#include <thread>
 
std::shared_timed_mutex m;
int i = 10;
 
void read_shared_var(int id)
{
     // both the threads get access to the integer i
     std::shared_lock<std::shared_timed_mutex> slk(m);
     const int ii = i; // reads global i
 
     std::osyncstream(std::cout) << '#' << id << " read i as " << ii << "...\n";
     std::this_thread::sleep_for(std::chrono::milliseconds(10));
     std::osyncstream(std::cout) << '#' << id << " woke up..." << std::endl;
}
 
int main()
{
     std::thread r1{read_shared_var, 1};
     std::thread r2{read_shared_var, 2};
 
     r1.join();
     r2.join();
}
```

Possible output:

```text
#2 read i as 10...
#1 read i as 10...
#2 woke up...
#1 woke up...
```
