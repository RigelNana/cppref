  <Declaration language="cpp" since="C++14" code={`template< class Rep, class Period >
bool try_lock_for( const std::chrono::duration<Rep,Period>& timeout_duration );`} />

  <DeclarationDescription>
    {/* source:cpp-thread-shared-lock-try-lock-for:0001 */}
    Tries to lock the associated mutex in shared mode. Blocks until specified `timeout_duration` has elapsed or the lock is acquired, whichever comes first. On successful lock acquisition returns `true`, otherwise returns `false`. Effectively calls `mutex()->try_lock_shared_for(timeout_duration)`.

    {/* source:cpp-thread-shared-lock-try-lock-for:0002 */}
    This function may block for longer than `timeout_duration` due to scheduling or resource contention delays.

    {/* source:cpp-thread-shared-lock-try-lock-for:0003 */}
    The standard recommends that a steady clock is used to measure the duration. If an implementation uses a system clock instead, the wait time may also be sensitive to clock adjustments.

    {/* source:cpp-thread-shared-lock-try-lock-for:0004 */}
    [`std::system_error`](/docs/cpp/library/error/system_error) is thrown if there is no associated mutex or if the mutex is already locked.

    {/* source:cpp-thread-shared-lock-try-lock-for:0005 */}
    The behavior is undefined if `Mutex` does not meet the [`SharedTimedLockable`](/docs/cpp/library/named_req/SharedTimedLockable) requirements.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-thread-shared-lock-try-lock-for:0006 */}
<ParameterList>
  <Parameter name="timeout_duration">maximum duration to block for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-shared-lock-try-lock-for:0007 */}
`true` if the ownership of the mutex has been acquired successfully, `false` otherwise.

### Exceptions

{/* source:cpp-thread-shared-lock-try-lock-for:0008 */}
- Any exceptions thrown by `mutex()->try_lock_shared_for(timeout_duration)`.

{/* source:cpp-thread-shared-lock-try-lock-for:0009 */}
- If there is no associated mutex, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::operation_not_permitted`](/docs/cpp/library/error/errc).

{/* source:cpp-thread-shared-lock-try-lock-for:0010 */}
- If the mutex is already locked, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::resource_deadlock_would_occur`](/docs/cpp/library/error/errc).
