  <Declaration language="cpp" since="C++14" code={`shared_lock& operator=( shared_lock&& other ) noexcept;`} />

  <DeclarationDescription>
    {/* source:cpp-thread-shared-lock-operator:0001 */}
    Move assignment operator. Replaces the contents with those of `other` using move semantics.

    {/* source:cpp-thread-shared-lock-operator:0002 */}
    If, prior to this call, `*this` has an associated mutex (([`mutex()`](/docs/cpp/library/thread/shared_lock/mutex) returns a non-null pointer) and has acquired ownership of it (`owns()` returns `true`), the mutex is unlocked by calling [`unlock_shared()`](/docs/cpp/library/thread/shared_mutex/unlock_shared).

    {/* source:cpp-thread-shared-lock-operator:0003 */}
    After this call, `other` has no associated mutex.
  </DeclarationDescription>
</DeclarationDoc>
