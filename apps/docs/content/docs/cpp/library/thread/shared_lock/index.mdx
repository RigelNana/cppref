{/* source:cpp-thread-shared-lock:0001 */}
The class `shared_lock` is a general-purpose shared mutex ownership wrapper allowing deferred locking, timed locking and transfer of lock ownership. Locking a `shared_lock` locks the associated shared mutex in shared mode (to lock it in exclusive mode, [`std::unique_lock`](/docs/cpp/library/thread/unique_lock) can be used).

{/* source:cpp-thread-shared-lock:0002 */}
The `shared_lock` class is movable, but not copyable – it meets the requirements of [`MoveConstructible`](/docs/cpp/library/named_req/MoveConstructible) and [`MoveAssignable`](/docs/cpp/library/named_req/MoveAssignable) but not of [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible) or [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable).

{/* source:cpp-thread-shared-lock:0003 */}
`shared_lock` meets the [`Lockable`](/docs/cpp/library/named_req/Lockable) requirements. If `Mutex` meets the [`SharedTimedLockable`](/docs/cpp/library/named_req/SharedTimedLockable) requirements, `shared_lock` also meets [`TimedLockable`](/docs/cpp/library/named_req/TimedLockable) requirements.

{/* source:cpp-thread-shared-lock:0004 */}
In order to wait in a shared mutex in shared ownership mode, [`std::condition_variable_any`](/docs/cpp/library/thread/condition_variable_any) can be used ([`std::condition_variable`](/docs/cpp/library/thread/condition_variable) requires [`std::unique_lock`](/docs/cpp/library/thread/unique_lock) and so can only wait in unique ownership mode).
