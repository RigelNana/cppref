{/* source:cpp-thread-shared-lock-operator-bool:0002 */}

### Return value

{/* source:cpp-thread-shared-lock-operator-bool:0003 */}
`true` if `*this` has an associated mutex and has acquired shared ownership of it, `false` otherwise.
