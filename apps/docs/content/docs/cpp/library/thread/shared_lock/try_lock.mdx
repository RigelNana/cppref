<DeclarationDoc>
  <Declaration language="cpp" since="C++14" code={`bool try_lock();`} />

  <DeclarationDescription>
    {/* source:cpp-thread-shared-lock-try-lock:0001 */}
    Tries to lock the associated mutex in shared mode without blocking. Effectively calls `mutex()->try_lock_shared()`.

    {/* source:cpp-thread-shared-lock-try-lock:0002 */}
    [`std::system_error`](/docs/cpp/library/error/system_error) is thrown if there is no associated mutex or if the mutex is already locked.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-thread-shared-lock-try-lock:0003 */}
(none)

### Return value

{/* source:cpp-thread-shared-lock-try-lock:0004 */}
`true` if the ownership of the mutex has been acquired successfully, `false` otherwise.

### Exceptions

{/* source:cpp-thread-shared-lock-try-lock:0005 */}
- Any exceptions thrown by `mutex()->try_lock_shared()`.

{/* source:cpp-thread-shared-lock-try-lock:0006 */}
- If there is no associated mutex, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::operation_not_permitted`](/docs/cpp/library/error/errc).

{/* source:cpp-thread-shared-lock-try-lock:0007 */}
- If the mutex is already locked, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::resource_deadlock_would_occur`](/docs/cpp/library/error/errc).
