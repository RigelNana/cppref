  <Declaration language="cpp" since="C++14" code={`~shared_lock();`} />

  <DeclarationDescription>
    {/* source:cpp-thread-shared-lock-shared-lock:0001 */}
    Destroys the lock.

    {/* source:cpp-thread-shared-lock-shared-lock:0002 */}
    If `*this` has an associated mutex (([`mutex()`](/docs/cpp/library/thread/shared_lock/mutex) returns a non-null pointer) and has acquired ownership of it (`owns()` returns `true`), the mutex is unlocked by calling [`unlock_shared()`](/docs/cpp/library/thread/shared_mutex/unlock_shared).
  </DeclarationDescription>
