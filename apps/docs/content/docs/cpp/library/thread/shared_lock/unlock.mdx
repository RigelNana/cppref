  <Declaration language="cpp" since="C++14" code={`void unlock();`} />

  <DeclarationDescription>
    {/* source:cpp-thread-shared-lock-unlock:0001 */}
    Unlocks the associated mutex from shared mode. Effectively calls `mutex()->unlock_shared()`.

    {/* source:cpp-thread-shared-lock-unlock:0002 */}
    [`std::system_error`](/docs/cpp/library/error/system_error) is thrown if there is no associated mutex or if the mutex is not locked.
  </DeclarationDescription>
</DeclarationDoc>

### Parameters

{/* source:cpp-thread-shared-lock-unlock:0003 */}
(none)

### Return value

{/* source:cpp-thread-shared-lock-unlock:0004 */}
(none)

### Exceptions

{/* source:cpp-thread-shared-lock-unlock:0005 */}
- Any exceptions thrown by `mutex()->unlock_shared()`.

{/* source:cpp-thread-shared-lock-unlock:0006 */}
- If there is no associated mutex, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::operation_not_permitted`](/docs/cpp/library/error/errc).
