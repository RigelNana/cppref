{/* source:cpp-thread-unique-lock-operator-bool:0001 */}
Checks whether `*this` owns a locked mutex or not. Effectively calls [`owns_lock()`](/docs/cpp/library/thread/unique_lock/owns_lock).

### Parameters

{/* source:cpp-thread-unique-lock-operator-bool:0002 */}
(none)

### Return value

{/* source:cpp-thread-unique-lock-operator-bool:0003 */}
`true` if `*this` has an associated mutex and has acquired ownership of it, `false` otherwise.
