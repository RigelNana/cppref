{/* source:cpp-thread-unique-lock:0001 */}
The class `unique_lock` is a general-purpose mutex ownership wrapper allowing deferred locking, time-constrained attempts at locking, recursive locking, transfer of lock ownership, and use with condition variables.

{/* source:cpp-thread-unique-lock:0002 */}
The class `unique_lock` is movable, but not copyable — it meets the requirements of [`MoveConstructible`](/docs/cpp/library/named_req/MoveConstructible) and [`MoveAssignable`](/docs/cpp/library/named_req/MoveAssignable) but not of [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible) or [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable).

{/* source:cpp-thread-unique-lock:0003 */}
The class `unique_lock` meets the [`BasicLockable`](/docs/cpp/library/named_req/BasicLockable) requirements. If `Mutex` meets the [`Lockable`](/docs/cpp/library/named_req/Lockable) requirements, `unique_lock` also meets the [`Lockable`](/docs/cpp/library/named_req/Lockable) requirements (ex.: can be used in [`std::lock`](/docs/cpp/library/thread/lock)); if `Mutex` meets the [`TimedLockable`](/docs/cpp/library/named_req/TimedLockable) requirements, `unique_lock` also meets the [`TimedLockable`](/docs/cpp/library/named_req/TimedLockable) requirements.

### Example

{/* source:cpp-thread-unique-lock:0008 */}
```cpp
#include <iostream>
#include <mutex>
#include <thread>
 
struct Box
{
    explicit Box(int num) : num_things{num} {}
 
    int num_things;
    std::mutex m;
};
 
void transfer(Box& from, Box& to, int num)
{
    // don't actually take the locks yet
    std::unique_lock lock1{from.m, std::defer_lock};
    std::unique_lock lock2{to.m, std::defer_lock};
 
    // lock both unique_locks without deadlock
    std::lock(lock1, lock2);
 
    from.num_things -= num;
    to.num_things += num;
 
    // “from.m” and “to.m” mutexes unlocked in unique_lock dtors
}
 
int main()
{
    Box acc1{100};
    Box acc2{50};
 
    std::thread t1{transfer, std::ref(acc1), std::ref(acc2), 10};
    std::thread t2{transfer, std::ref(acc2), std::ref(acc1), 5};
 
    t1.join();
    t2.join();
 
    std::cout << "acc1: " << acc1.num_things << "\n"
                 "acc2: " << acc2.num_things << '\n';
}
```

Output:

```text
acc1: 95
acc2: 55
```
