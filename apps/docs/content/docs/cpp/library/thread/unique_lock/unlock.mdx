Unlocks (i.e., releases ownership of) the associated mutex.

{/* source:cpp-thread-unique-lock-unlock:0002 */}
[`std::system_error`](/docs/cpp/library/error/system_error) is thrown if there is no associated mutex or if the mutex is not locked.

### Parameters

{/* source:cpp-thread-unique-lock-unlock:0003 */}
(none)

### Return value

{/* source:cpp-thread-unique-lock-unlock:0004 */}
(none)

### Exceptions

{/* source:cpp-thread-unique-lock-unlock:0005 */}
If there is no associated mutex or the mutex is not locked, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::operation_not_permitted`](/docs/cpp/library/error/errc).
