{/* source:cpp-thread-unique-lock-try-lock-for:0001 */}
Tries to lock (i.e., takes ownership of) the associated mutex. Blocks until specified `timeout_duration` has elapsed or the lock is acquired, whichever comes first. On successful lock acquisition returns `true`, otherwise returns `false`. Effectively calls `mutex()->try_lock_for(timeout_duration)`.

{/* source:cpp-thread-unique-lock-try-lock-for:0002 */}
This function may block for longer than `timeout_duration` due to scheduling or resource contention delays.

{/* source:cpp-thread-unique-lock-try-lock-for:0003 */}
The standard recommends that a steady clock is used to measure the duration. If an implementation uses a system clock instead, the wait time may also be sensitive to clock adjustments.

{/* source:cpp-thread-unique-lock-try-lock-for:0004 */}
[`std::system_error`](/docs/cpp/library/error/system_error) is thrown if there is no associated mutex or if the mutex is already locked by this `std::unique_lock`.

### Parameters

{/* source:cpp-thread-unique-lock-try-lock-for:0005 */}
<ParameterList>
  <Parameter name="timeout_duration">maximum duration to block for</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-unique-lock-try-lock-for:0006 */}
`true` if the ownership of the mutex has been acquired successfully, `false` otherwise.

### Exceptions

{/* source:cpp-thread-unique-lock-try-lock-for:0007 */}
- Any exceptions thrown by `mutex()->try_lock_for(timeout_duration)`.

{/* source:cpp-thread-unique-lock-try-lock-for:0008 */}
- If there is no associated mutex, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::operation_not_permitted`](/docs/cpp/library/error/errc).

{/* source:cpp-thread-unique-lock-try-lock-for:0009 */}
- If the mutex is already locked, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::resource_deadlock_would_occur`](/docs/cpp/library/error/errc).
