{/* source:cpp-thread-unique-lock-swap:0001 */}
Exchanges the internal states of the lock objects.

### Parameters

{/* source:cpp-thread-unique-lock-swap:0002 */}
<ParameterList>
  <Parameter name="other">the lock to swap the state with</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-unique-lock-swap:0003 */}
(none)

### Example

{/* source:cpp-thread-unique-lock-swap:0004 */}
```cpp
#include <iostream>
#include <mutex>
 
int main()
{
    std::mutex mtx1;
    std::unique_lock<std::mutex> guard1(mtx1);
    std::unique_lock<std::mutex> guard2;
    guard2.swap(guard1);
 
    if (!guard1 && guard2)
        std::cout << "swapped success\n";
 
    return 0;
}
```

Output:

```text
swapped success
```
