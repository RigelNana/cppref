{/* source:cpp-thread-unique-lock-owns-lock:0001 */}
Checks whether `*this` owns a locked mutex or not.

### Parameters

{/* source:cpp-thread-unique-lock-owns-lock:0002 */}
(none)

### Return value

{/* source:cpp-thread-unique-lock-owns-lock:0003 */}
`true` if `*this` has an associated mutex and has acquired ownership of it, `false` otherwise.
