{/* source:cpp-thread-unique-lock-try-lock-until:0001 */}
Tries to lock (i.e., takes ownership of) the associated mutex. Blocks until specified `timeout_time` has been reached or the lock is acquired, whichever comes first. On successful lock acquisition returns `true`, otherwise returns `false`. May block for longer than `timeout_time` until has been reached.

{/* source:cpp-thread-unique-lock-try-lock-until:0002 */}
Effectively calls `mutex()->try_lock_until(timeout_time)`.

{/* source:cpp-thread-unique-lock-try-lock-until:0003 */}
[`std::system_error`](/docs/cpp/library/error/system_error) is thrown if there is no associated mutex or if the mutex is already locked by the same thread.

{/* source:cpp-thread-unique-lock-try-lock-until:0004 */}
`Clock` must meet the [`Clock`](/docs/cpp/library/named_req/Clock) requirements. <InlineRevision since="C++20">The program is ill-formed if [`std::chrono::is_clock_v<Clock>`](/docs/cpp/library/chrono/is_clock) is `false`.</InlineRevision>

### Parameters

{/* source:cpp-thread-unique-lock-try-lock-until:0005 */}
<ParameterList>
  <Parameter name="timeout_time">maximum time point to block until</Parameter>
</ParameterList>

### Return value

{/* source:cpp-thread-unique-lock-try-lock-until:0006 */}
`true` if the ownership of the mutex has been acquired successfully, `false` otherwise.

### Exceptions

{/* source:cpp-thread-unique-lock-try-lock-until:0007 */}
- Any exceptions thrown by `mutex()->try_lock_until(timeout_time)`.

{/* source:cpp-thread-unique-lock-try-lock-until:0008 */}
- If there is no associated mutex, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::operation_not_permitted`](/docs/cpp/library/error/errc).

{/* source:cpp-thread-unique-lock-try-lock-until:0009 */}
- If the mutex is already locked, [`std::system_error`](/docs/cpp/library/error/system_error) with an error code of [`std::errc::resource_deadlock_would_occur`](/docs/cpp/library/error/errc).
