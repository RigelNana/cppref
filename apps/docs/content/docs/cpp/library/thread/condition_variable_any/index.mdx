{/* source:cpp-thread-condition-variable-any:0001 */}
The `condition_variable_any` class is a generalization of [`std::condition_variable`](/docs/cpp/library/thread/condition_variable). Whereas `std::condition_variable` works only on `std::unique_lock<std::mutex>`, `condition_variable_any` can operate on any lock that meets the [`BasicLockable`](/docs/cpp/library/named_req/BasicLockable) requirements.

{/* source:cpp-thread-condition-variable-any:0002 */}
See [`std::condition_variable`](/docs/cpp/library/thread/condition_variable) for the description of the semantics of condition variables.

{/* source:cpp-thread-condition-variable-any:0003 */}
The class `std::condition_variable_any` is a [`StandardLayoutType`](/docs/cpp/library/named_req/StandardLayoutType). It is not [`CopyConstructible`](/docs/cpp/library/named_req/CopyConstructible), [`MoveConstructible`](/docs/cpp/library/named_req/MoveConstructible), [`CopyAssignable`](/docs/cpp/library/named_req/CopyAssignable), or [`MoveAssignable`](/docs/cpp/library/named_req/MoveAssignable).

{/* source:cpp-thread-condition-variable-any:0004 */}
If the lock is `std::unique_lock<std::mutex>`, [`std::condition_variable`](/docs/cpp/library/thread/condition_variable) may provide better performance.

### Notes

{/* source:cpp-thread-condition-variable-any:0006 */}
`std::condition_variable_any` can be used with [`std::shared_lock`](/docs/cpp/library/thread/shared_lock) in order to wait on a [`std::shared_mutex`](/docs/cpp/library/thread/shared_mutex) in shared ownership mode.

{/* source:cpp-thread-condition-variable-any:0007 */}
A possible use for `std::condition_variable_any` with custom [`Lockable`](/docs/cpp/library/named_req/Lockable) types is to provide convenient interruptible waits: the custom lock operation would both lock the associated mutex as expected, and also perform the necessary setup to notify this condition variable when the interrupting signal is received.[^1]
