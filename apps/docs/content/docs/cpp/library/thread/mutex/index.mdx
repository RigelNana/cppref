{/* source:cpp-thread-mutex:0001 */}
The `mutex` class is a synchronization primitive that can be used to protect shared data from being simultaneously accessed by multiple threads.

{/* source:cpp-thread-mutex:0002 */}
`mutex` offers exclusive, non-recursive ownership semantics:

{/* source:cpp-thread-mutex:0003 */}
- A calling thread *owns* a `mutex` from the time that it successfully calls either [`lock`](/docs/cpp/library/thread/mutex/lock) or [`try_lock`](/docs/cpp/library/thread/mutex/try_lock) until it calls [`unlock`](/docs/cpp/library/thread/mutex/unlock).
- When a thread owns a `mutex`, all other threads will block (for calls to [`lock`](/docs/cpp/library/thread/mutex/lock)) or receive a `false` return value (for [`try_lock`](/docs/cpp/library/thread/mutex/try_lock)) if they attempt to claim ownership of the `mutex`.
- A calling thread must not own the `mutex` prior to calling [`lock`](/docs/cpp/library/thread/mutex/lock) or [`try_lock`](/docs/cpp/library/thread/mutex/try_lock).

{/* source:cpp-thread-mutex:0004 */}
The behavior of a program is undefined if a `mutex` is destroyed while still owned by any threads, or a thread terminates while owning a `mutex`. The `mutex` class satisfies all requirements of [Mutex](/docs/cpp/library/named_req/Mutex) and [StandardLayoutType](/docs/cpp/library/named_req/StandardLayoutType).

{/* source:cpp-thread-mutex:0005 */}
`std::mutex` is neither copyable nor movable.

### Notes

{/* source:cpp-thread-mutex:0008 */}
`std::mutex` is usually not accessed directly: [`std::unique_lock`](/docs/cpp/library/thread/unique_lock), [`std::lock_guard`](/docs/cpp/library/thread/lock_guard), <InlineRevision since="C++17">or [`std::scoped_lock`](/docs/cpp/library/thread/scoped_lock)</InlineRevision> manage locking in a more exception-safe manner.

### Example

{/* source:cpp-thread-mutex:0009 */}
This example shows how a `mutex` can be used to protect an [`std::map`](/docs/cpp/library/container/map) shared between two threads.

```cpp
#include <chrono>
#include <iostream>
#include <map>
#include <mutex>
#include <string>
#include <thread>
 
std::map<std::string, std::string> g_pages;
std::mutex g_pages_mutex;
 
void save_page(const std::string& url)
{
    // simulate a long page fetch
    std::this_thread::sleep_for(std::chrono::seconds(2));
    std::string result = "fake content";
 
    std::lock_guard<std::mutex> guard(g_pages_mutex);
    g_pages[url] = result;
}
 
int main() 
{
    std::thread t1(save_page, "http://foo");
    std::thread t2(save_page, "http://bar");
    t1.join();
    t2.join();
 
    // safe to access g_pages without lock now, as the threads are joined
    for (const auto& [url, page] : g_pages)
        std::cout << url << " => " << page << '\n';
}
```

Output:

```text
http://bar => fake content
http://foo => fake content
```
