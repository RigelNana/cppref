### Parameters

{/* source:cpp-thread-mutex-mutex:0003 */}
(none)

### Notes

{/* source:cpp-thread-mutex-mutex:0004 */}
Because the default constructor is `constexpr`, static mutexes are initialized as part of [static non-local initialization](/docs/cpp/language/initialization#Non-local_variables), before any dynamic non-local initialization begins. This makes it safe to lock a mutex in a constructor of any static object.
